# ChemClaw

[English](README.md) | 简体中文

ChemClaw 是一套面向化工业务的 AI 助手团队：帮你做客户开发、采购寻源、行情与期现研究、产业分析，并把结果整理成能直接用的报告和表格。

你可以把它当成「装好就能用的化工专家小组」——打开后侧栏里已经有专业 Bot 和协作群，点进去对话即可，不用自己组队。

对话内新增散点、雷达、热力、漏斗、树图、桑基和仪表图，保留原有五种轻量 SVG 图表。高级图表仅在需要时从本地加载，图例和图表交互无需调用模型。可在「设置 → 外观 → 高级图表」关闭扩展，以表格查看数据。

> **巨潮公告**：ChemClaw 提供免 Key 的巨潮资讯公告查询工具（chem_cninfo_search）与原件 PDF 下载和页数核验（chem_cninfo_read_pdf）。在「设置 → 连接器 → 公开研究数据」显示可用性状态；初始为「尚未查询」，真正查询后更新。第三方站点可能限流或不可达；下载不等于已提取 PDF 正文，涉及数值的结论必须继续核验原文。

## 它能做什么

- **50 位专业 Bot、15 个协作群**：覆盖内贸销售、采购、外贸、产业研究、期现、生产辅助，以及写报告、做表、做 PPT 等交付岗。
- **100+ 业务技能**：按常见化工任务编排（找下游、核供应商、看行情、做区域地图、归因涨跌等）；打开某个 Bot 或群聊，能看到用途、需要你提供什么、以及示例问法。
- **会查数、会留出处**：能接公司数据中台和公开化学/网页检索；价格尽量带日期、规格、地区、税费和来源，缺什么会标明，不拿示例数据冒充研究结果。
- **能出文件，不只聊天**：研究报告、名单、报价对比等可以落成文件，在聊天里点开预览或本机打开。

## 报告与文件怎么选格式

按内容选最合适的交付，不必死记工具名：

| 你需要的结果 | 建议格式 |
|--------------|----------|
| 价格走势、可筛选的交互表、页面里能点的图表 | **HTML**（可交互、适合看趋势） |
| 给客户/领导汇报、不需要交互趋势线（价格卡、要点页等） | **PPT**（可用 ppt-master 等做出较干净的幻灯片） |
| 有明细、底稿、可再筛选的数据 | **必须同时给 Excel** |

一句话：**有趋势或交互 → 优先 HTML；纯汇报页 → 可以 PPT；有数据底稿 → 一定要有 Excel。**

## 两种用法（二选一即可）

### 1. 独立 Windows 应用（推荐给大多数人）

1. 从 [GitHub Releases](https://github.com/zoeyzhang233666/chemclaw-bot/releases) 下载安装包（如 `ChemClaw-0.2.1-win-x64.exe`）并安装。
2. 打开 ChemClaw → **设置 → 模型**：填入你的模型 Key（默认提供 APIHub 入口，领取：https://apihub.chem-cloud.cn/ ，接口：https://apihub.chem-cloud.cn/v1 ）。
3. 如需公司化工数据：到 **设置 → 连接器 → 芯化和云数据中台**，只粘贴 Key（领取：https://mcp.chem-cloud.cn/ ）。不要把 Key 发到聊天里。
4. 在左侧点一个 Bot 或协作群，用自然语言说明产品、地区、时间和目的，例如：「帮我看华东甲醇近一个月采购谈价行情，标出缺数和来源，给我 HTML 和 Excel。」

公开化学查询和免费网页搜索通常不用公司 Key；有没有连上数据，以连接器页面的状态为准。

安装版会自动检查 ChemClaw 新版本，也可以到 **设置 → 关于 ChemClaw → 检查更新** 手动检查。Windows 下载新版安装包后提示重启，macOS 打开下载页。此前关闭了更新检查的旧版，需要先手动安装一次本版本。

关闭应用窗口后，ChemClaw 会留在系统托盘里继续运行，Bot 可以继续工作。点击托盘图标重新打开；在托盘菜单选择退出才会停止应用。首次关闭时会说明这一行为。

Bot 设置与新建 Bot 可把自定义照片批量导入可复用的头像库：成功的会留下，按内容去重，Bot 各自保留一份，删库里的照片不影响已经在用的 Bot。ChemClaw 自带的角色形象保持不变。

**设置 → 技能库** 按业务分类展示完整技能集合，提供中文名称、用途和交付物。按任务或关键词搜索，点击「使用」直接返回当前正常对话框并选中技能，在输入框补充需求后发送；保留已有草稿、附件和 Bot 常用技能。群聊默认由负责人执行，也可在输入框 @ 一位群成员改派。「安装技能」支持 ZIP、文件夹、SKILL.md 和公开 GitHub 链接，保留脚本与模板，并可选择安装分组。工具服务与凭据统一在「连接器」中配置。

### 2. 装进官方 DeepSeek Harness（DSH）桌面版

适合已经在用官方 DSH 的同学：

1. 本机需要已安装 Git。
2. 打开 DSH → **插件 → 添加插件**，填入：

   ```text
   github:zoeyzhang233666/chemclaw-bot#v0.2.1&path:/chemclaw-bot
   ```

3. 安装并启用；如提示重启请重启。也可以用同一 Release 里的 `chemclaw-bot-0.2.1.tgz` 本地路径安装。
4. 启用后同样在模型与连接器里配置 Key，再从侧栏选 Bot / 群聊开始用。

已有对话和自定义角色会保留；缺失的预设角色会自动补齐，不会无故清空你的内容。

## 开发分支中的 Linux 安装包

待发布功能批次加入 Linux x64 AppImage 和 Debian/Ubuntu deb 安装包，当前已发布的 0.2.2 尚不包含它们。在 Linux 上依次运行 `cd app`、`npm ci`、`npm run dist` 构建；发布前由平台 CI 检查启动、安装和更新。AppImage 自动更新，deb 安装后提示下载对应版本。

## 第一次可以怎么试

- 「按产品帮我找国内生产厂家，并做成可筛选名单。」
- 「华东纯碱近三个月行情，给谈价用，HTML + Excel。」
- 「把这份结论做成给客户看的 PPT（不要交互图），明细表另附 Excel。」
- 「解释最近甲醇为什么涨，标出证据和不确定的地方。」

## 使用时请记住

- ChemClaw **辅助研究和整理材料**，不做自动交易，也不控制工厂生产。
- 示例里的价格、客户、地图只是演示，不能当真实业务数据。
- 模型与数据 Key 是两种用途：模型 Key 在「模型」里填，公司数据 Key 在「连接器」里填。
