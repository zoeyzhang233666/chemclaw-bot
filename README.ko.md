# ChemClaw v0.3.0

[简体中文](README.md) | [English](README.en.md) | [日本語](README.ja.md) | **한국어** | [Русский](README.ru.md) | [Français](README.fr.md) | [العربية](README.ar.md) | [Español](README.es.md) | [Português](README.pt.md)

**화학제품 현물 거래에서 중요한 것은 실제 구매 수요가 있는 고객, 안정적으로 납품할 수 있는 공급업체, 그리고 출처·날짜·거래 조건을 확인할 수 있는 가격입니다.**

- 중질 소다회를 판매한다면 신규 유리 생산라인을 짓는 업체와 원료 수요 증가 시점을 어떻게 찾을까요?
- 프로필렌옥사이드를 구매한다면 실제 제조사와 대리점, 현물 유통업체를 어떻게 구분할까요?
- MEG를 수입한다면 해외 실생산 공장과 최종 공장 도착 원가를 어떻게 검증할까요?
- 메탄올 시장을 연구한다면 현물 가격, 선물, 재고, 정기보수 정보를 어떻게 연결할까요?

ChemClaw에는 화학산업 전문 데이터인 [**Chemcloud Data Hub**](https://mcp.chem-cloud.cn/)와 AI 모델 이용 서비스 [**APIHub**](https://apihub.chem-cloud.cn/) 연결 항목이 사전 설정되어 있습니다. 서비스별 키를 발급받아 앱 설정에 입력하면 됩니다.

Chemcloud의 「화학산업 AI 에이전트용 업계 전문지식 고품질 데이터셋」은 **2026년 상하이시 산업 고품질 데이터셋 대표 사례**로 선정되어 **2026 Global Data Ecosystem Conference**에서 소개되었습니다. [공식 발표](https://dt.sheitc.sh.gov.cn/cms/slddt/3123.jhtml). 이는 데이터 전문성에 대한 참고 근거이며, 개별 거래의 핵심 수치는 원문 확인이 필요합니다.

**전문 Bot 50개, 협업 그룹 15개, 화학산업 특화 스킬 108개**로 중국 내수 현물 거래, 수출입, 에너지·화학 선물, 산업 펀더멘털 및 퀀트 연구를 지원합니다. 대화창 내 차트, 근거를 포함한 Excel, PowerPoint, Word, 인터랙티브 웹 리포트로 결과를 받을 수 있습니다.

## 1. 범용 AI와 다른 점

일반적인 AI도 웹 검색과 문서 작성은 할 수 있습니다. ChemClaw의 강점은 **화학산업 데이터, 실무 검증 기준, 업무별 절차와 전문가 역할을 미리 구성해 두었다는 것**입니다.

| 실무 과제 | 일반 AI | ChemClaw |
| --- | --- | --- |
| **실제 원료 수요처 찾기** | 기업 목록 제시 후 별도 확인 필요 | Data Hub의 용도·전후방 기업 정보로 후보를 찾고, 환경영향평가의 원재료표·공장 정보·증설 문서로 확인 |
| **생산업체와 유통상 구분** | 공급업체 후보 탐색 | 생산 공장, 브랜드 대리점, 현물 유통망을 구분해 제품 등급·허가·COA·납기 확인 항목 생성 |
| **현물가격 비교** | 여러 가격의 기준이 다를 수 있음 | 현물 데이터 우선, 날짜·지역·규격·세금·출고/도착 기준 표시, 선물가를 현물가로 대체하지 않음 |
| **증설 및 구매 기회 탐색** | 뉴스·검색 결과 | 정부 프로젝트, EIA, 입찰, CNINFO 원본 PDF를 근거로 실제 추적할 프로젝트 목록 생성 |
| **수출입 및 공급망 조사** | 번역·일반 검색 | 해외 제조사·수입업체 확인, FOB/CFR/CIF·환율·관세·항만·운송비 분석 |
| **선물·계량 분석** | 통계 방식 설명 | 베이시스·월물 스프레드·재고·계절성·선행-후행·이벤트·실제 상장 계약 기반 백테스트 |
| **팀에 전달할 문서 작성** | 텍스트·파일 생성 | 전문 Bot 협업, 대화 내 차트, 출처가 남는 Excel·PPT·Word·웹 리포트 |

## 2. 기업·거래 기회·가격 데이터 출처

### 2.1 Chemcloud Data Hub

[데이터 키 발급](https://mcp.chem-cloud.cn/) 후 **설정 → 커넥터 → Chemcloud Data Hub**에 입력합니다. 접속 주소는 이미 설정되어 있으며 제공 항목은 계정 권한에 따라 다릅니다.

| 정보 유형 | 데이터 내용 | 활용 방법 |
| --- | --- | --- |
| **화합물** | CAS·명칭, 물질 개요, MSDS/SDS, 제품 정보, 조회 가능한 가격 | 영어 문의 제품을 식별하고 유사 화학제품 혼동 방지 |
| **기업 및 고객** | 기업 검색, 법인·주주·조직 정보, 특허, 입찰, 고객 360° | 실제 공장, 구매자, 자회사 및 프로젝트 후보 찾기 |
| **거래 및 주문** | 문의·견적, 판매·구매 주문, 재고 이동, 수금 요약 | **허가된 자사 업무 기록에 한해** 고객·주문·재고·매출채권 분석 |
| **시장 및 가격** | 시장 관련 정보, 가격 이력과 추세 | 현물 시장의 지역·등급·날짜·인도 조건별 비교 |

> 장쑤·저장 지역에서 프로필렌옥사이드를 판매합니다. Data Hub로 폴리에테르폴리올 및 프로필렌글리콜 업체를 찾고, 각 공장 홈페이지와 환경평가 원료표·증설 공시를 확인해 주세요. 공장, 사용 근거, 출처 링크, 신뢰등급, 우선 영업 순위를 Excel에 작성하고 공개되지 않은 연간 사용량은 추정하지 마세요.

### 2.2 정부 자료와 환경영향평가

중국 지방정부·환경 당국의 **EIA 보고서, 환경허가, 프로젝트 등록, 산업단지 공시**는 공장 주소·생산공정·명목 생산능력·연간 원재료 사용량을 담을 수 있습니다. 승인과 실제 가동, 시운전, 상업 생산을 구분해 검증합니다.

### 2.3 CNINFO 원본 PDF 조회 — 기본 탑재

[CNINFO](https://www.cninfo.com.cn/)의 중국 A주 상장회사 공시를 회사명·주식코드·기간·키워드로 검색하고, **원본 PDF 다운로드 및 읽을 수 있는 페이지의 본문 발췌와 페이지 번호 확인**을 지원합니다. 별도의 CNINFO 키는 필요하지 않습니다.

| 문서 | 확인할 정보 | 활용 |
| --- | --- | --- |
| **연간·반기 사업보고서** | 주력 제품, 공장, 매출, 설비투자, 건설 중 자산 | 제조 규모와 실제 사업 확인 |
| **투자·증설·공정개선 공시** | 투자 주체, 위치, 투자액, 제품, 설계 능력, 일정 | 신규 원료 수요 및 공급 증가 추적 |
| **시운전·가동·중단 공시** | 공장 상태와 진행 단계 | 계획 용량과 실제 공급을 구분 |
| **대형 계약·사업설명·질의 회신** | 계약 상대, 공정, 공급망 및 공개 수치 | 거래 관련성과 산업구조 심층 검증 |

스캔 PDF의 텍스트는 읽지 못할 수 있으므로 원본 표와 수치를 다시 확인해야 합니다.

### 2.4 조달 입찰과 현물 시세

[중국 공공자원 거래 플랫폼](https://www.ggzy.gov.cn/), 정부 조달, 대형 화학·에너지 회사의 구매 사이트 및 공장 홈페이지에서 **입찰 진행 여부, 품목, 수량, 인도 장소, 마감 기한과 원문**을 확인할 수 있습니다. 중복 보도나 이미 마감된 공고는 분리해야 합니다.

현물 가격은 Data Hub를 우선 활용하고 Longzhong, Zhuochuang/SCI99, Jinlianchuang, Baichuan, Mysteel, SunSirs, SMM 등의 열람 가능한 공개 시세와 비교합니다. 유료·회원 정보는 접근 권한에 따릅니다. 제조사 고시가, 참고 시세, 실제 거래가를 구별합니다.

### 2.5 선물·주식 및 화학 전문 자료

- **AKShare**: 이용 가능한 중국·해외 선물과 주식의 과거 OHLC에 따른 차트. 실시간 시세를 보장하지 않습니다.
- **거래소와 금융 웹사이트**: DCE, CZCE, SHFE, INE, GFEX, Sina Finance, Eastmoney, Tencent Finance 등의 공개 페이지를 참고하며 이들 모두와 전용 API가 연결된 것은 아닙니다.
- **[PubChem](https://pubchem.ncbi.nlm.nih.gov/), [OPSIN](https://opsin.ch.cam.ac.uk/), 위키백과, Huagongshe**: 화학물질 정체성·명칭·구조·관련 지식 조회. 실제 판매 등급은 제조사 SDS/TDS/COA로 확인합니다.
- **UN Comtrade / WITS**: 국가 단위 수출입 통계. 개별 회사의 직접 구매를 증명하는 자료와 구분합니다.

### 2.6 해외 업체·LinkedIn·X

해외 기업 홈페이지, 전시회 참가 명부, Kompass, Thomasnet, Europages, EC21, IndiaMART, 공개 LinkedIn 기업 페이지와 X 산업 게시물은 **공개된 기업·설비·신제품·채용·투자 동향**을 찾는 보조 경로가 될 수 있습니다. 이는 일반 검색 및 웹 접근 기능이지 사설 데이터 API 연동은 아닙니다. 해외 서비스는 사용자의 네트워크·프록시와 로그인 권한이 필요할 수 있습니다.

## 3. 국내 현물 판매와 조달

**판매**는 제품 용도에서 실제 원료를 투입하는 공장을 찾고, EIA 원재료표·기업 공시·구매 입찰로 검증합니다. **조달**은 제조사, 판매법인, 정식 대리점, 현물 유통상을 나누어 등급·공급능력·품질 서류·납기·대금 조건을 확인합니다.

> 루타일형 이산화티타늄 300톤을 우후까지 납품받고 싶습니다. Chemcloud Data Hub와 공급업체 검증 스킬로 생산 공장과 유통업체를 구분해 주세요. 공장 홈페이지, 제품 TDS와 허가 자료를 확인하고, 배송 포함 가격, 포장, COA, 최소 주문량, 실제 재고, 납기와 결제 조건이 들어간 Excel RFQ를 만들어 주세요. 확인되지 않은 값은 '문의 필요'로 표시하세요.

## 4. 해외 화학제품 무역

수출은 **대상국 산업과 수입 구조 → 실제 제조 고객·직접 수입자·유통상 → 회사 실체 → 공개 접촉 채널** 순서로 조사합니다. 수입은 생산 법인·공장·제품·명목 생산능력·가동 상황·판매 주체를 별도 검증하고 환율, FOB/CFR/CIF, 관세, VAT, 보험, 항만비, 내륙 운송비를 계산합니다.

> 인도와 인도네시아의 페인트·플라스틱 제조사를 대상으로 루타일형 TiO2를 수출하려고 합니다. UN Comtrade/WITS, 회사 사이트, 현지 등록 자료, 협회·전시회 명부, 공개된 LinkedIn 자료를 확인하세요. 실제 제조사/수입상/유통상을 구분하고 출처·증거 등급·공개 회사 연락처·영문 첫 영업 메일을 포함한 Excel을 작성하세요. 국가별 수입량을 회사별 구매량으로 쓰지 마세요.

> 사우디아라비아와 UAE의 MEG 실생산 회사를 확인하세요. 제조 법인·공장·설계능력·최근 공개 가동 정보·판매 주체를 검증하고 MEG와 DEG를 구별하세요. FOB/CFR/CIF, 환율, 관세, 운임을 수정할 수 있는 Excel 도착원가 계산표와 영문 RFQ 메일을 작성하세요.

## 5. 에너지·화학 선물 및 퀀트 연구

원유, LPG, 메탄올, 소다회, PVC, 에틸렌글리콜 등의 **현물–선물 베이시스, 월물 스프레드, 지역 가격차, 재고·가동률, 정기보수, 신규 생산능력, 원가와 마진**을 연구합니다. 계절성, 상관관계, 선행-후행, 이벤트 연구와 명시된 규칙의 백테스트를 지원합니다.

| 연구 내용 | 검증할 조건 | 결과물 |
| --- | --- | --- |
| **현·선물 베이시스** | 각각 검증한 현물/선물 가격, 같은 날짜·단위·계약 | 두 가격선과 별도 베이시스 차트, Excel |
| **월물·지역 스프레드** | 계약 만기·롤오버·지역·규격·물류비 | 스프레드, 계절성 및 이상치 |
| **통계 연구** | 실제 발표 시각, 표본 크기, 다중검정, 기간별 안정성 | Lag·p/q값·롤링 상관·히트맵 |
| **규칙 백테스트** | 실제 거래 가능 계약, 거래비용, 월물 변경과 표본외 평가 | 재현 가능한 Excel·연구 스크립트 및 성과 |

> 최근 분기의 타이창 메탄올 현물과 MA 선물 베이시스를 분석해 주세요. 현물은 Data Hub를 우선 확인하고 전문 시세로 교차 검증, 선물은 `chem_futures_history`의 실제 OHLC 및 거래소 계약 정보로 확인하세요. 날짜와 단위를 맞춰 두 가격선·별도 베이시스 그래프를 대화에 표시하고 근거 Excel과 4~6장의 PPT로 정리하세요. 현물이 누락된 구간에 선물가를 대신 넣지 마세요.

> 메탄올 항구 재고 변화가 향후 1~8주 MA 선물 수익률에 통계적으로 선행하는지 검증해 주세요. 재고의 실제 공개 시각을 사용하고 모든 Lag, 표본 수, 다중검정 후 p/q값, 연도별 안정성을 제공하세요. 결과를 재현 가능한 Excel과 인터랙티브 웹 그래프로 작성하고 통계적 상관과 인과관계를 구분하세요.

## 6. 대화 중 시각화

실제 데이터가 있는 경우 **현물 가격 꺾은선, 선물 일봉 캔들, 현·선물 비교, 베이시스, 수치 카드, 산점도, 히트맵, 레이더, 트리맵, 생키, 타임라인** 등을 대화에 표시할 수 있습니다. 실제 시가·고가·저가·종가가 없으면 캔들차트를 만들지 않습니다.

## 8. 기존 Office 문서 처리

기존 Word·PowerPoint·Excel을 불러와 **지원되는 문장 수정, 주석, 슬라이드 순서 변경, 표·수식 점검** 등의 작업을 할 수 있습니다. 복잡한 레이아웃과 계산 결과는 실제 Office 프로그램에서 최종 확인하세요.

## 9. 브라우저와 사용자 승인

데스크톱의 각 Bot은 자체 브라우저를 이용해 페이지를 열고, 사용 가능한 텍스트·표를 읽고, 클릭이나 입력을 지원합니다. **로그인·결제·CAPTCHA는 사용자에게 제어를 넘깁니다.** 게시·업로드·삭제도 승인이 필요할 수 있습니다. 해외 사이트에 접속할 때는 적절한 네트워크 또는 프록시 환경을 구성해야 합니다.

## 10. 전문 Bot과 그룹

**50개 전문 Bot과 15개 그룹**은 중국 내수 판매, 구매, 수출입, 산업 분석, 현·선물, 퀀트, 문서 작성과 자료 검증을 담당합니다. 그룹의 진행자가 역할을 분담하고 `@`로 전문 Bot을 지정할 수 있습니다.

## 11. 설치 및 연결

1. [GitHub Releases](https://github.com/zoeyzhang233666/chemclaw-bot/releases)에서 Windows EXE, macOS(Intel/Apple Silicon), Linux에 맞는 **v0.3.0** 파일을 다운로드하세요.

3. [Chemcloud Data Hub](https://mcp.chem-cloud.cn/)의 **별도 데이터 키**를 발급받아 **설정 → 커넥터**에 입력하세요.
4. 좌측의 전문가 또는 그룹을 열고 실무 질문을 입력하면 됩니다.

DeepSeek Harness Desktop 사용자는 [ChemClaw 플러그인](https://github.com/zoeyzhang233666/chemclaw-bot/tree/main/chemclaw-bot)으로도 사용할 수 있습니다.
