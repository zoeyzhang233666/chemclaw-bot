# ChemClaw v0.3.0

[简体中文](README.md) | [English](README.en.md) | **日本語** | [한국어](README.ko.md) | [Русский](README.ru.md) | [Français](README.fr.md) | [العربية](README.ar.md) | [Español](README.es.md) | [Português](README.pt.md)

**化学品の現物取引で重要なのは、実際に原料を必要としている顧客、安定供給できるサプライヤー、そして条件と出典を確認できる価格情報です。**

- 重質ソーダ灰を販売するなら、新しい生産ラインを立ち上げるガラスメーカーをどう探すか。
- 酸化プロピレンを調達するなら、製造工場・代理店・スポット在庫業者をどう見分け、納入価格を比較するか。
- 中国向けにモノエチレングリコールを輸入するなら、海外の実際の製造拠点と着荷原価をどう確認するか。
- メタノールの需給分析なら、現物価格、先物、在庫、定修・停止情報をどう一つの検証可能な分析資料にまとめるか。

ChemClaw は、化学品・企業・産業チェーン・相場に関する情報を扱う **[Chemcloud Data Hub](https://mcp.chem-cloud.cn/)** と、AI モデルを選んで利用できる **[APIHub](https://apihub.chem-cloud.cn/)** を最初から接続候補として用意しています。利用者は必要なキーを取得し、アプリの設定欄に入力すれば始められます。

Chemcloud が構築した「化学産業AIエージェント向け業界専門知識・高品質データセット」は、**2026年上海市産業別高品質データセット典型事例**に選定され、**2026 Global Data Ecosystem Conference** で紹介されました。[上海市データ局による公示](https://dt.sheitc.sh.gov.cn/cms/slddt/3123.jhtml)。これは業界データに取り組む基盤を示すものであり、個別の取引判断は引き続き原資料の照合が必要です。

**50の専門Bot、15の協業グループ、108の化学産業向けスキル**を搭載。国内外の販売・調達、エネルギー・化学品のファンダメンタルズ、現物と先物の分析、定量研究に対応し、結果をチャット内のグラフ、出典付きExcel、PowerPoint、Word、インタラクティブなWebレポートにまとめられます。

## 1. 一般的なAIと何が違うのか

汎用AIでもWeb検索や資料作成は可能です。ChemClaw の特徴は、**化学品の業界データ、取引の確認項目、調査手順、役割分担が最初から揃っていること**。各担当者が毎回データ源や検証方法を設計する必要を減らします。

| 実務上の課題 | 一般的なWeb版AI | ChemClaw |
| --- | --- | --- |
| **本当に原料を使う顧客を探す** | 企業名の候補から個別確認が必要 | データハブで用途・川下産業・企業を調べ、環境影響評価（EIA）の原材料表、工場情報、増設資料で実需要を確認 |
| **メーカーと販売代理店を見分ける** | Web上の供給者候補を整理 | 生産拠点、規格、許可証、販売チャネルを分けて確認し、在庫、COA、納期、支払条件を見積依頼項目に整理 |
| **現物相場と見積価格を比較する** | 日付や引渡条件が異なる場合がある | 現物価格を優先し、地域、グレード、税、工場渡し・納入ベース、情報日付を明示。先物価格を現物と混同しない |
| **設備増強・入札から商機を探す** | ニュースや検索結果の一覧が中心 | 企業データ、EIA、政府プロジェクト、調達公告、CNINFO原本PDFを突き合わせ、進捗と次の営業アクションを記録 |
| **輸出入の調査と調達原価** | 翻訳や一般検索は可能 | 国別市場、輸入業者と製造業者の実在性、FOB/CFR/CIF、通貨、税、港湾費用・内陸輸送費を確認 |
| **先物・定量リサーチ** | 分析手法の説明やデータ処理 | ベーシス、限月間スプレッド、季節性、在庫と価格の先行・遅行、イベント研究、実際の上場限月を使うルール検証 |
| **社内で共有できる成果物** | 文章や表を別途整理 | 役割別Botの協業、チャット内チャート、根拠付きExcel、編集可能なOffice文書、調査Webページ |

## 2. 商機・価格・企業データの情報源

### 2.1 Chemcloud Data Hub：まず接続したい業界データ

[データキーを取得](https://mcp.chem-cloud.cn/)し、ChemClaw の **設定 → コネクター → Chemcloud Data Hub** で入力します。利用可能な機能・範囲はアカウントの権限に従います。

| 分類 | 主な情報 | 取引での使い方 |
| --- | --- | --- |
| **化学物質** | CAS番号、名称、化学物質の資料、MSDS/SDS、関連製品情報、利用可能な価格情報 | 英文の引合い製品を同定し、類似名称・異なるグレードによる取り違えを防ぐ |
| **企業・顧客** | 企業検索、登記・株主・組織関係、特許・知財、入札、顧客360°情報 | 実際の製造者・使用者を探し、子会社・工場・購買案件を確認 |
| **取引・受発注** | 引合いと見積、販売・購買注文、在庫入出庫、入金・回収サマリー | **アクセス権限のある自社データだけ**を使用し、受注転換、納品・在庫・債権を分析 |
| **市場・価格** | 市場・取引先情報、利用可能な価格履歴と傾向 | 地域・品位・日付・受渡条件を揃えて現物価格を比較 |

**例：酸化プロピレンを販売する場合**

> 江蘇・浙江のポリエーテルポリオール、プロピレングリコール製造工場を Chemcloud Data Hub から調べ、工場Webサイト・EIA原料表・増設公告で実際の用途を確認してください。企業・工場ごとに根拠URLと需要の確度を示し、営業優先度付きExcelにまとめてください。未公開の年間購入量を推測値で埋めないでください。

### 2.2 政府の環境資料と設備投資情報

中国の環境影響評価書、環境行政の受理・承認情報、排出許可、開発改革部門のプロジェクト情報、産業団地の公示は、**工場所在地、設備、年間能力、原材料消費量**を確認するうえで重要です。EIAの「受理」や「承認」を「すでに操業」と扱わず、着工・試運転・商業生産を区別します。

### 2.3 CNINFO：ChemClaw に搭載された公告PDFの検索

[CNINFO](https://www.cninfo.com.cn/) の中国A株上場企業公告を会社名・証券コード・キーワード・日付から探し、**原本PDFを取得、読み取れるページの抜粋とページ番号を確認**できます。CNINFO専用キーは不要です。

| PDFの種類 | 読み取る情報 | 実務への活用 |
| --- | --- | --- |
| **年次・半期報告書** | 製品、主要拠点、売上、設備投資、建設仮勘定、事業リスク | 製造者の調査、需給、収益・生産能力の検討 |
| **設備投資・増設・技術改造公告** | プロジェクト主体、所在地、投資額、対象製品、名目能力、計画日程 | 将来の原料需要・供給増を探る |
| **稼働・試運転・停止関連公告** | 設備の状況、進捗、能力の変化 | 計画と実際に流通する数量を区別 |
| **大型契約・入札・会社再編・照会回答** | 契約主体、対象、工場・工程・サプライチェーンに関する開示 | 製品の仕入先・販売先、設備・工事案件を検証 |

PDFにない数値やページ番号は作成しません。画像スキャンなどで本文を読めない場合は原本確認が必要です。

### 2.4 調達公告・企業サイト・業界価格

[中国招標投標公共服務平台](https://www.cebpubservice.com/)、[全国公共資源交易平台](https://www.ggzy.gov.cn/)、[中国政府採購網](https://www.ccgp.gov.cn/)、石油化学企業の電子調達、企業の購買ページ、工事会社・設計会社のプロジェクトサイトから、**現在有効な入札、納入条件、数量、締切、落札履歴**を探せます。期限切れの案件は現行案件と分けます。

現物の相場は Chemcloud Data Hub を優先し、隆衆資訊、卓創資訊、金聯創、百川盈孚、Mysteel、生意社、SMMなどの公開可能な情報と照合します。**工場公表価格、業界参考価格、成約価格、うわさ**を区別します。一部情報には購読・ログイン権限が必要です。

### 2.5 先物・株式・化学物質の公開データ

- **AKShare**：取得可能な市場の株式・先物の実際の日次OHLCを利用したローソク足分析。リアルタイム保証はありません。
- **取引所・金融サイト**：中国の各商品取引所、上海国際能源交易中心、新浪財経、東方財富、騰訊財経などの公開情報から、銘柄・限月・倉庫証券・ニュースを確認します。全サイトの専用API接続を意味するものではありません。
- **[PubChem](https://pubchem.ncbi.nlm.nih.gov/)、[OPSIN](https://opsin.ch.cam.ac.uk/)、Wikipedia、化工社**：化学物質の識別、名称・構造・関連知識を確認。物性・最終製品規格は製造者のSDS/TDS/COAを優先します。
- **貿易・統計**：UN Comtrade、WITS、各国税関・統計局・業界団体の公開情報を用い、国全体の貿易額と特定企業の輸入実績を混同しません。

### 2.6 海外の企業・ソーシャルメディア

海外企業サイト、展示会の出展者名簿、Kompass、Thomasnet、Europages、EC21、Indotrading、IndiaMART、公開されたLinkedIn企業ページやXの業界投稿から、工場、商品、採用、増設、販売網に関する手掛かりを探せます。これらは**公開検索・Web閲覧による調査**であり、全サイトの専用データAPIや大量収集を保証するものではありません。

**海外サイトを利用するには、利用者側のネット接続、必要に応じたプロキシ設定、サイトのアカウント権限が必要です。** ログイン、CAPTCHA、支払い時は人による操作に引き継ぎます。

## 3. 中国国内の化学品現物取引

販売側では、川下製品と製造工程から**実際に原料を使う工場**を探し、EIAの原料表・新規プロジェクト・購買公告で確度を確認します。仕入側では、**製造工場、販売子会社、正式代理店、スポット流通業者**を分け、技術仕様・許可・見積条件・品質書類を照合します。

**調達担当者向け依頼例：**

> ルチル型酸化チタン300トンを安徽省蕪湖に納入する前提で、Chemcloud Data Hub と製造者調査スキルを使って候補を探してください。製造工場・代理店・スポット業者を分け、TDS、製造拠点、公開許可、出典を確認してください。税抜／税込、工場渡し／着荷、包装、最低発注量、COA、支払条件を比較できるExcel RFQを作り、未取得の実在庫と見積額は「要確認」にしてください。

## 4. 国際化学品貿易

輸出では**市場国 → 化学品用途 → 実際のエンドユーザー・輸入業者・代理店 → 法人・証拠**という順序で調べます。輸入では**製造法人・工場・製品グレード・設計能力・実稼働・販売チャネル**を別々に確認し、仕入価格、為替、関税、VAT、保険、港湾費・国内運賃を用いて原価を試算します。

- **海外買い手調査**：UN Comtrade/WITS等による国別需要、会社サイト、現地登記、業界団体、展示会、公開B2B情報を組み合わせる。
- **海外供給者調査**：製造者の報告書、設備投資、EPC・技術ライセンサー情報、工場・製品資料を用い、単なる取扱会社を製造者と誤認しない。
- **引合い・契約実務**：海外企業の身元確認、英語の問い合わせ（RFQ）・見積・プロフォーマインボイス（PI）、必要書類と商品コード候補、信用・決済条件の確認を支援。

**輸出営業向け依頼例：**

> インドとインドネシアの塗料・プラスチックメーカー向けにルチル型酸化チタンの見込み客を探してください。公開貿易統計、企業サイト、登記、展示会名簿、公開LinkedInページを照合し、工場／輸入商／販売代理店を分けてください。証拠の段階別Excel、企業の公開連絡先、英語の初回メールを作成してください。国別輸入量を個社の購入数量として扱わないでください。

**輸入調達向け依頼例：**

> サウジアラビアとUAEの実際のMEG製造者を調べ、法人、工場、名目能力、最新の稼働情報と販売窓口を確認してください。PubChemでMEG/DEGの名称を照合し、FOB/CFR/CIFの見積が入力可能なExcel着荷原価モデル、為替・運賃感応度表、英文RFQを作ってください。

## 5. エネルギー・化学品の先物と定量分析

対象は原油、LPG、メタノール、ソーダ灰、PVC、MEGなど。現物と先物、在庫、稼働率、新増設、定期修繕、利益率、輸出入を組み合わせて検討します。

| 研究 | 必要な確認 | 提出物 |
| --- | --- | --- |
| **ベーシス・現先比較** | 現物・先物を別々に取得し、同一日・通貨・単位に合わせる | 2系列比較、ベーシス推移、出典付きExcel |
| **限月間・地域間スプレッド** | 対象限月、ロール日、産地・品位・運賃の差 | スプレッド表、季節性、異常値 |
| **ファンダメンタルズ・イベント** | 在庫、稼働、修繕、設備投資、ニュースの実際の公表日 | 時系列イベント表、需給レポート |
| **定量分析・ルール検証** | データの利用可能時点、上場限月、売買コスト、サンプル外評価 | 再現可能なスクリプト、Excel、検定・バックテストの結果 |

**先物研究の依頼例：**

> 過去3か月の華東メタノール現物とMA先物のベーシスを調べてください。Chemcloud Data Hubの現物価格を優先し、専門相場で照合、先物は`chem_futures_history`によるOHLCと取引所情報を用いてください。同一日付・単位に揃え、チャットで現物＋先物の2系列線グラフと独立したベーシスグラフを表示し、在庫・修繕・輸入の情報源付きExcelと4〜6枚のPowerPointにまとめてください。不足する現物データは先物で代用しないでください。

**定量研究の依頼例：**

> メタノール港湾在庫の変化が、その後1〜8週間のMA先物リターンに先行するか検証してください。実際の在庫公表時刻、期貨の日次データ、lead–lagの全ラグ、サンプル数、p/q値、年別安定性を残し、研究WebページとExcelを作ってください。統計的相関と因果・売買可能性を区別してください。

## 6. チャットで使えるチャート

検証できたデータに応じて、**現物価格の折れ線、先物の日足ローソク足、2系列比較、ベーシス、指標カード、散布図、ヒートマップ、レーダー、ツリーマップ、サンキー図、タイムライン**などを会話画面に表示できます。実在するOHLCがない場合はローソク足を作りません。

## 7. 提出可能なレポートとファイル

| 形式 | 主な用途 |

## 8. 既存のOfficeファイルを扱う

既存の Word、PowerPoint、Excel を読み込み、対応している**本文の対象箇所修正、コメント、スライド順序調整、表や数式のチェック**などを実施できます。複雑なレイアウトと計算は提出前にOfficeアプリでも再確認してください。

## 9. ブラウザー操作と確認

Botごとのデスクトップブラウザーで公開ページを開き、必要な箇所の文章・表を読み、リンクをクリックし、フォームの入力を支援します。ログイン、支払い、CAPTCHAはユーザーが引き継ぎます。アップロードや投稿等は承認が必要になる場合があります。海外サイトへのアクセスにはネットワーク・プロキシの設定が必要な場合があります。

## 10. 専門Botとグループ

**50のBotと15の協業グループ**を用意。国内販売、購買、輸出、輸入、産業調査、先物スプレッド、量的分析、Office資料作成、出典確認などを担当します。グループの進行役が役割分担を組み立て、`@`で専門家を指定できます。

## 11. インストールと接続

1. [GitHub Releases](https://github.com/zoeyzhang233666/chemclaw-bot/releases) から **v0.3.0** のWindows EXE、macOS（Intel/Apple Silicon）、Linux向け対応ファイルをダウンロードします。
2. [APIHub](https://apihub.chem-cloud.cn/) に登録しAIモデル用キーを取得。ChemClawの**設定 → モデル**でAPIHubを選択し、キーを入力してモデルを選びます。比較的低価格の試用・期間別プランがあり、最新の価格や利用条件は公式ページで確認してください。
3. [Chemcloud Data Hub](https://mcp.chem-cloud.cn/) から**別のデータキー**を取得し、**設定 → コネクター**で入力します。モデル用キーとデータキーは共通ではありません。
4. 左側の専門Bot／グループを開き、自然言語でビジネス課題を入力します。

DeepSeek Harness Desktop の利用者は [ChemClawプラグイン](https://github.com/zoeyzhang233666/chemclaw-bot/tree/main/chemclaw-bot) も使用できます。

## 12. そのまま使える業務依頼例

**新規顧客開拓：**

> 華東の重質ソーダ灰の見込み客を探してください。Chemcloud Data Hubで川下企業を特定した後、EIA原材料表、ガラス新ライン計画、CNINFOのPDF、公開入札を照合してください。工場別に段階、出典、原料消費根拠、連絡すべき部門、優先度をExcelにまとめ、チャットには建設タイムラインを表示してください。

**有効な購買案件：**

> 過去30日の工業用苛性ソーダの公開調達案件を確認してください。政府・企業の正式な入札情報を優先し、まだ応募可能な案件とすでに終了した案件を分け、濃度、数量、納入先、締切、原文URL、公開連絡先をExcel化してください。

**資料作成：**

> すでに確認済みの業界調査データから、6ページの取引先説明用PowerPointと編集可能なExcelを作ってください。グラフ・数値・参照資料を一致させ、出典と未確認事項を明示してください。
