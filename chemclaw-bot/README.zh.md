# ChemClaw

[English](README.md) | 简体中文

ChemClaw 是一套面向化工业务的 AI 助手团队：帮你做客户开发、采购寻源、行情与期现研究、产业分析，并把结果整理成能直接用的报告和表格。

你可以把它当成「装好就能用的化工专家小组」——打开后侧栏里已经有专业 Bot 和协作群，点进去对话即可，不用自己组队。

本目录是可安装到官方 DeepSeek Harness（DSH）的插件包 `chemclaw-bot`；独立 Windows 应用与本插件共用同一套能力。

对话内新增散点、雷达、热力、漏斗、树图、桑基和仪表图，按需从本地加载引擎；原有五种 SVG 图表保留轻量渲染路径。在「外观」关闭「高级图表」后，新增图表以完整数据表展示。

插件包还内置加载完整的上游 [GenUI 插件](https://github.com/omdsh-dev/dsh-genui)，固定版本 0.15.0，包含时间轴、步骤、diagram/Mermaid、ECharts、函数图、三维场景、可搜索表格、表单等组件。Bot 私聊和群聊通过正文 `dsh-ui` 围栏展示，跟随 ChemClaw 主题，按钮动作回到所属会话，原有 `show_view` 继续兼容。Bot 根据回答内容自动选择视图，不要求用户知道组件名；本地表格筛选、排序和未声明动作的控件不需要模型往返。原生 `/panel` 属于 DSH 原生会话功能，Bot/群聊使用正文视图。「高级图表」开关单独控制 ChemClaw 新增的七种图表，不控制 GenUI。已有 `link:` 安装需在 DSH 插件管理中刷新/重新安装该插件包，使新增依赖和 bundle patch 生效，再重启/刷新 DSH；仅重新构建 `client.js` 不会安装新的插件依赖。

每个面向用户的最终回答都默认附带正文视图，包括概念解释和简短确认：已有图表/卡片优先，更丰富的内容使用 GenUI。这条全局交付规则自动覆盖已有、导入和未来新增的技能；技能生成的 HTML/文件是聊天视图的补充。用户明确要求纯文字时尊重该要求。通过 DSH 公开的回合结束检查，缺少视图的回答最多收到一次同回合提醒，已带视图的回答不增加补做请求。内部委派、进度通知、取消的回合和子代理不触发检查。这能减少漏图，但不能保证模型始终遵从或固定响应时间。传统 Agent 模式可显示内置 GenUI 组件和面板；ChemClaw 的 `show_view` 工具仍只用于 Bot 会话。

## 它能做什么

- **50 位专业 Bot、15 个协作群**：覆盖内贸销售、采购、外贸、产业研究、期现、生产辅助，以及写报告、做表、做 PPT 等交付岗。
- **100+ 业务技能**：按常见化工任务编排；打开某个 Bot 或群聊，能看到用途、需要你提供什么、以及示例问法。
- **会查数、会留出处**：能接公司数据中台和公开化学/网页检索；价格尽量带日期、规格、地区、税费和来源，缺什么会标明。
- **能出文件，不只聊天**：研究报告、名单、报价对比等可以落成文件，在聊天里点开预览或本机打开。

## 报告与文件怎么选格式

| 你需要的结果 | 建议格式 |
|--------------|----------|
| 价格走势、可筛选的交互表、页面里能点的图表 | **HTML** |
| 给客户/领导汇报、不需要交互趋势线 | **PPT**（含 ppt-master 等） |
| 有明细、底稿、可再筛选的数据 | **必须同时给 Excel** |

**有趋势或交互 → 优先 HTML；纯汇报页 → 可以 PPT；有数据底稿 → 一定要有 Excel。**

## 怎么安装这个插件

在官方 DSH 桌面版：**插件 → 添加插件**，填入（本机需已安装 Git）：

```text
github:zoeyzhang233666/chemclaw-bot#v0.2.0&path:/chemclaw-bot
```

安装并启用，必要时重启。也可使用 Release 中的 `chemclaw-bot-0.2.0.tgz` 完整路径。

更完整的「独立应用安装、模型与连接器、首次提问示例」见仓库根目录 [README.zh.md](../README.zh.md)。

## 侧聊

在 Bot 私聊中输入 `/side 问题`，或从详情的菜单选择「侧聊」，可以询问进展和细节，
不打断主任务。追问保存在独立标签中，侧聊不会执行工具。关闭面板会保留记录，
关闭侧聊标签会删除该段侧聊。

## Bot 浏览器

ChemClaw 独立桌面端为每个 Bot 提供独立的浏览器，并保留登录状态。
可以让 Bot 查询网站、阅读页面、点击和填写表单。在 Bot 详情中点「打开浏览器」
即可查看过程。「接管浏览器」会断开 Bot 的控制；「交还给 Bot」允许它继续操作；
「停止」还会取消 Bot 的工作。发布、上传、下载和删除需要审批；
遇到登录、付款或验证码，由你接手完成。

复用 Electron 已有的 Chromium，不需要再下载一份浏览器。
安装到官方 DSH 时保留既有默认行为。外部主机可显式配置
`browserPlugin: refs`（逐步操作）、`script`（一段脚本）或 `task`（完整目标），以及指向兼容 Chromium 的
`browserExecutablePath`。详见[浏览器设计](../docs/plans/2026-10-27-browser-automation.md)。
