## 必须理解的边界

- **3,070 万吨是样本，不是全国产能**；全国口径约 4,305–4,468 万吨，样本覆盖约 69–71%，**不是市场份额**。
- 产能 ≠ 产量；2,160.78 万吨是样本企业公开产量的加总，部分口径含贸易/代工。
- 距离是直线距离，不是铁路/水运运费。
- 1,080 万吨是 2026+ **毛增量**；金山 150 万吨为搬迁，净增约 930 万吨。
- 南方碱业 35/60 万吨冲突并列；采用 60 万吨，但保留旧口径。
- 潜客只内置广东 8 家样本，不是全量；同行未列入。

## 看什么

1. 首屏 3 张结论卡：密集区 / 本地空白 / 未来变量；
2. 地图：为什么广东本地只有一个气泡，而内蒙古/河南/山东/青海/江苏很密；
3. 矩阵：金山 330、博源 680、中盐 390；产量与产能的差；
4. 时间线：2026 博源二期、金山潜江；2027 雪天衡阳；2029+ 中盐奈曼；
5. 潜客：信义（锚点）+ 广东 8 家玻璃/日化；
6. 方法：37 条来源、9 项冲突、11 条缺口。
