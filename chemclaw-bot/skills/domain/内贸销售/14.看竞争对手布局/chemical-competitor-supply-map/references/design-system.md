# 设计系统 · HTML 与 Excel

> 视觉目标：**投行研究册的克制 + 销售作战地图的密度**。深绿/米纸/铜色，不用蓝紫渐变，不做“大屏酷炫”。

## 1. 色彩

| 变量 | 值 | 用途 |
|---|---|---|
| `--ink` | `#13231D` | 主文字、深底 |
| `--ink2` | `#173F35` | 次深底 |
| `--paper` | `#F3EFE6` | 页面背景（米纸） |
| `--card` | `#FFFDF8` | 卡片 |
| `--line` | `#DCD2C1` | 边框 |
| `--muted` | `#6E7B72` | 次要文字 |
| `--copper` | `#B4642D` | 强调、目标、动作 |
| `--amber` | `#D9A441` | 新增/项目、重点 |
| `--blue` | `#2F6F8F` | 联碱/工艺 B、链接 |
| `--olive` | `#6B7F4A` | 天然碱/工艺 C |
| `--red` | `#A23B2A` | 目标区域、警告 |

工艺色建议 4–8 个，避免红绿相邻；同一产品在所有页面/Excel 用同一 mapping。

## 2. 字体

| 场景 | 字体 |
|---|---|
| 标题/数字 | `"Noto Serif SC", "Source Han Serif SC", "Songti SC", Georgia, serif` |
| 正文 | `"Noto Sans SC", "Source Han Sans SC", "Microsoft YaHei", sans-serif` |
| 标签/数字 | `"IBM Plex Mono", "SFMono-Regular", Consolas, monospace` |

HTML 不加载外部字体（离线要求），用系统字体 fallback。Excel 用 `Microsoft YaHei`（Windows 默认）；macOS 可换 `PingFang SC`，但不要用未安装字体导致替换。

## 3. HTML 信息架构

```text
Header：品牌 + 导航 + 数据截至 + 下载 Excel
Hero：标题 + 导语 + 4 个 pill + 目标区域卡（4 个统计 + 距离带）
  └ KPI 5 张：样本 / 本地 / 300–800km / 2026+ 项目 / 覆盖度
结论 3 张：密集区 / 空白 / 未来变量
01 地图：工具栏（企业 chips / 工艺 / 图层）+ 地图 + 右侧读数
02 矩阵：搜索 / 工艺 / 仅有新增 / 排序表
03 密度：省级柱状 + 距离带 + 工艺环 + 区域表
04 时间线：深底，按年分组
05 潜客：锚点卡 + 赛道筛选 + 潜客表 + 3 张动作卡
06 方法：来源表 + 冲突卡 + 缺口 + 3 张方法结论
Footer：免责声明 + 数据口径
Drawer：企业/工厂/项目/潜客明细
Toast
```

### 3.1 首屏

- 左侧标题 2 行，第二行用斜体铜色 `em`；
- 导语不超过 3 行；
- pill 用 8px 圆点 + 11px mono；
- 目标卡深绿底，右上角 `DEMO`/`TARGET` 标签；
- 目标卡内 2×2 统计，数字 22–24px，单位 9px；
- 距离带用横条，宽度按产能比例。

### 3.2 地图

- 深绿 `#152b23` 底图；省界 `#2a4a3c`；
- 工厂气泡按工艺色，大小 `sqrt(capacity)*1.55`；
- 目标点：红色脉冲 + “目标区域”标签；
- 项目：金色菱形；
- 距离线：≤800 蓝、800–1500 金、>1500 棕，虚线，越远越淡；
- 省标签只显示 `label_province` 或当前选中省，避免全国文字糊成一团；
- 工厂标签只在产能 ≥ `label_capacity_min`、选中企业 ≤4 或 `label_show` 时显示；
- 右侧面板：默认“全国样本”；点省后显示本地在产/最近外省/潜客/销售解读。

### 3.3 矩阵

列顺序固定：

`选择 | 企业/基地 | 工艺 | 产能 | 最新产量 | 工厂 | 到目标 km | 区域覆盖线索(D) | 新增/在建 | 等级`

- 产能列带细进度条；
- 距离带用绿/蓝小字；
- 覆盖线索必须带 `D` 标签；
- 行点击打开抽屉；复选框只控制图层；
- 表头 sticky；移动端表格内部横滑，不要撑破页面。

### 3.4 图表

- 省级：横向条形，目标省铜色，其他按主导工艺色；点击定位；
- 距离带：4 根柱，0 值也显示但降低透明度；
- 工艺：环形，中心显示样本总产能；点击筛选；
- 图表背景透明，网格线 `#eee7da`，轴文字 `#8b958e`；
- 不使用 3D、阴影过多、渐变填充。

### 3.5 抽屉

- 右侧 460px，移动端 100%；
- 顶部 mono 标签 + 关闭；
- KPI 2×2；
- 工厂/项目列表可点击跳转；
- 来源块始终在底部，链接可点；
- Esc 关闭；打开时 body 不滚动。

### 3.6 响应式

| 断点 | 行为 |
|---|---|
| >1180 | 地图 1fr + 320px 侧栏；导航显示 |
| ≤1180 | 导航隐藏；地图上下堆叠；KPI 3 列 |
| ≤900 | hero 单列；目标卡在下；KPI 2 列 |
| ≤560 | KPI 1 列；标题 38px；地图工具栏换行；表格内部滚动 |

硬性：`document.documentElement.scrollWidth <= innerWidth`；隐藏抽屉不能造成横向滚动（`html,body{overflow-x:hidden}`）。

## 4. Excel 版式

### 4.1 统一规则

- 纸张 A4；除封面外横向；`fitToWidth=1`；页脚含数据截至日 + 页码；
- 表头深绿底白字 9pt 粗体；正文 8–10pt；
- 隔行浅米色；边框 `#DCD2C1`；
- 数字右对齐/居中；文字左对齐；长文本 wrap；
- 行高按中文长度估算（`cjk_height`），不要固定 15；
- 冻结窗格：矩阵 `C5`、工厂 `D5`、项目 `C5`、区域 `C5`、来源 `C5`、冲突 `C5`、缺口 `C5`；
- 自动筛选覆盖数据区；
- 打印区域只含数据区，图表放打印区外。

### 4.2 九个表

| 表 | 内容 | 关键点 |
|---|---|---|
| `00_封面` | 标题、4 个 KPI、阅读顺序、口径、免责声明 | 深绿页眉；内部超链接到各表；竖版 |
| `01_企业矩阵` | 17 行企业，16 列 | 产能条/产量/距离/覆盖/新增/等级/来源；TOP10 图 |
| `02_工厂明细` | 22 行工厂，16 列 | 经纬度、产品、备注、来源；合计=企业合计 |
| `03_新增项目` | 8 行项目，14 列 | 毛增量/净增/影响；按年排序；合计行写 2026+ |
| `04_区域对照` | 18 行省级，11 列 | 目标省高亮；需求/空白线索；TOP10 图 |
| `05_目标区域与潜客` | 目标事实 + 供应梯度 + 潜客 + 动作卡 | 锚点用量大数字；潜客 8 家；3 张动作卡 |
| `06_数据来源` | 37 条来源，7 列 | 标题/链接可点；用于列写清楚 |
| `07_口径与冲突` | 9 项冲突，7 列 | A/B 口径并列；采用/理由/影响 |
| `08_数据缺口与边界` | 11 条缺口/边界，5 列 | 类型区分缺口/边界；可执行 |

### 4.3 图表

- 只使用**可见单元格**做数据源；不要用隐藏列（避免 `plotVisOnly` 问题）；
- 分类轴用 `StrRef`（中文企业/省名不能当数值）；
- 柱状图横向、无图例、显示数值标签；
- 图表放 `R4` 或 `M4`，宽 15cm、高 8.5cm；打印区不包含图表；
- 至少 2 张图（企业 TOP10、区域 TOP10）。

### 4.4 封面

- A1:F2 深绿品牌条；
- A4:F5 产品名 34pt；
- A6 区域/副标题 14pt 铜色；
- 4 个 KPI 2×2，数字 20pt；
- 阅读顺序 8 行，带内部超链接；
- 底部方法/免责 8pt。

## 5. 文案风格

- 先结论、后解释；每段不超过 3 行；
- 用“样本/覆盖/判断/可能”，不用“全国/份额/保证”；
- 数字带单位；距离带“直线”限定；
- 推算用量加 `*`，页脚解释；
- 冲突写“采用/理由/影响”，不写“综合来看”；
- 缺口写“下一步怎么补”，不写“仅供参考”。

## 6. 禁止项

- 外部 CDN、外部字体、外部图片；
- 3D 地图、旋转地球、酷炫粒子；
- 红绿大面积对撞（目标红只做点/边）；
- 把“样本产能”写成“全国产能”；
- 把“覆盖度”写成“市场份额”；
- 在图表里用隐藏辅助列但不设 `plotVisOnly=0`；
- Excel 合并单元格重叠；
- 移动端横向溢出。

## 7. 可访问性

- 颜色不是唯一编码：工艺同时有文字标签；
- 表格表头有文字，不只用图标；
- 抽屉有 `role=dialog`、`aria-modal`、Esc 关闭；
- 按钮有 `aria-pressed`（chips）；
- 地图有 `aria-label`，并提供右侧文字读数作为替代；
- 对比度：深绿底白字 ≥ 7:1；米纸底深绿 ≥ 10:1。
