# 研究手册 · 从一个化工品到一张区域供给地图

> 目标不是“把数据填满”，而是用最少的可信数据回答销售最关心的四个问题：谁在供、离客户多远、哪里空白、先打谁。

## 0. 先定义“研究边界”

开工前写一张 A4 纸（或 `data.json` 的 `meta`）：

| 项 | 必须写清 | 反例 |
|---|---|---|
| 产品 | 全称 + 品种/规格 | 只写“碱” |
| 区域 | 省 + 市 + 经纬度 | 只写“华南” |
| 客户 | 锚点客户或目标客户群 | 只写“玻璃厂” |
| 半径 | 300/800/1500 km 或自有仓 | 不写半径 |
| 时间 | 数据截至日 + 项目观察期 | 不写日期 |
| 单位 | 万吨/年、千吨/年、实物吨/折百 | 混用 |
| 口径 | 产能/产量/销量/表观消费 | 混用 |

**先定边界，再搜数据。** 否则会陷入“全国所有企业”的无底洞。

## 1. 产品-工艺底图

### 1.1 先画工艺树

任何化工品都先问：

- 原料路线是什么？
- 主流工艺有几条？
- 每条工艺的成本、能耗、环保、产品纯度差异？
- 哪些企业用哪条路线？
- 工艺路线是否决定区域竞争力（靠近原料/靠近港口/靠近客户）？

示例（只作方法演示）：

| 产品 | 常见工艺 | 竞争含义 |
|---|---|---|
| 纯碱 | 氨碱 / 联碱 / 天然碱 | 天然碱成本低、氨碱环保压力大、联碱副产氯化铵 |
| 烧碱 | 离子膜 / 隔膜 | 离子膜主导，液碱半径短、片碱半径长 |
| 甲醇 | 煤制 / 天然气 / 焦炉气 | 煤制成本看煤价，天然气看气价，进口看港口 |
| 钛白粉 | 硫酸法 / 氯化法 | 氯化法高端但投资大，硫酸法废酸压力 |
| 塑料 | 不同单体/聚合路线 | 牌号与认证决定客户粘性 |

把工艺写进 `meta.processes`，每类一个颜色。后面的地图、矩阵、Excel 都复用这套分类。

### 1.2 企业长名单

先用“行业名称 + 产能/企业/名单/排名/产量”拉长名单，不要一开始就追求精确数字：

```text
"产品名" 产能 企业 名单
"产品名" 生产企业 排名
"产品名" 行业格局 产能 占比
"产品名" 主要厂家 基地
"产品名" 拟建 在建 扩建 项目
"产品名" 环评 公示 产能
"产品名" 年报 生产基地 产能
```

长名单的来源可以是券商、协会、行业媒体；**长名单用于“找全”，不用于“定数”**。定数要回到年报/官网/政府文件。

## 2. 目标区域与锚点客户

### 2.1 目标区域

目标区域至少要有：

- 省、市、经纬度；
- 本地在产供给（没有就写 0/空白）；
- 最近的外省供给（按直线距离排序）；
- 本地需求线索（协会/政府/龙头客户/物流调入）；
- 本地潜客样本。

**目标城市的选择**：优先选“有锚点客户 + 有物流节点 + 有产业园区”的城市；不要选只有行政意义、没有产业意义的省会。

### 2.2 锚点客户

锚点客户的作用不是“凑案例”，而是把产品放到真实工艺里：

- 它用什么规格/牌号？
- 吨耗/单耗是多少？公开产线规模能否反推用量？
- 它现在从哪买？本地/外省/进口？
- 认证周期多长？切换供应商的代价是什么？
- 它的成本结构中，这个化工品占多大比例？

**用量推算模板**

```text
年用量 ≈ 产线规模 × 单位产品耗量 × 年运行天数 × 负荷率
```

例：玻璃厂 3×900 t/d、纯碱单耗 0.2 t/t 玻璃、330 天、90% 负荷：

```text
3 × 900 × 0.2 × 330 × 0.9 ≈ 16.0 万吨/年
```

必须在报告里写“推算/假设”，不能写成企业披露。若公开数据不足，就写“用量待核”，不要编。

## 3. 在产供给普查

### 3.1 来源优先级

| 等级 | 来源 | 适合取什么 | 注意 |
|---|---|---|---|
| A | 上市公司年报/半年报/债券募集说明书；政府核准/环评/能评/安评 | 产能、产量、基地、项目、投产时间 | 口径可能是“设计产能/实际产能/产能折百” |
| B | 公司官网/IR/公众号；行业协会/统计局/海关；券商深度 | 产能、基地、行业总量、进出口 | 券商拆分可能估算，需标 B |
| C | 企业公开业务信息/招聘/招标/新闻 | 工厂存在、产品、扩产意向 | 不能单独定产能 |
| D | 物流/地图/覆盖推断 | 距离、可达性、覆盖线索 | 不能当企业披露 |

**一条产能至少一个 A/B 来源；C 只能补“存在性”，D 只能补“距离/覆盖”。**

### 3.2 企业 → 工厂拆解

常见错误：把集团产能挂在一个总部点上。正确做法：

- 企业是法人/集团；
- 工厂是物理生产基地；
- 一个企业多座工厂，分别填经纬度；
- 企业产能 = 各工厂产能之和（脚本强校验）；
- 总部地址不等于工厂地址。

**工厂字段最低要求**：企业、工厂名、省、市、经纬度、工艺、产能、产能年份、来源。

### 3.3 产能口径

必须区分：

- 设计产能 / 核定产能 / 实际产能；
- 实物量 / 折百 / 折标；
- 年产 / 日产能 × 运行天数；
- 投产时间（2025H1、2025年底、2026Q1）。

在 `note` 里保留口径；在 `cap_year` 写数据年份。不要把不同年份的产能直接相加而不标注。

### 3.4 负增量

只收集“新增”会高估净增。至少问：

- 有没有老线冷修/停产/退出？
- 有没有环保搬迁/置换？
- 有没有长期限产/成本倒挂？
- 有没有进口替代/出口转内销？

负增量可以放在 `projects` 里用负数？**本 skill 的 `projects.capacity` 必须 >0**；负增量写在 `gaps`/`narrative`/`note` 里，避免把项目表做成加减混算。若你需要严格净增模型，另建 `net_delta` 字段并改代码。

## 4. 新增/在建/搬迁项目

### 4.1 项目状态机

```text
规划 → 备案 → 环评/能评 → 开工 → 设备安装 → 试生产 → 投产
```

每个状态对应不同可信度：

- 备案/环评：规模可信，时间可能延后；
- 开工：时间更可信，仍可能延期；
- 试生产：接近实际，但达产需时间；
- 投产：可写入“已投产”，但仍需确认负荷。

### 4.2 毛增量 vs 净增

| 类型 | 毛增量 | 净增判断 |
|---|---|---|
| 全新项目 | +规模 | 通常≈规模，但要看老线是否退出 |
| 扩建 | +新增规模 | 通常≈新增，但可能替代旧线 |
| 技改 | +新规模 | 可能只是提效/置换，净增可能为 0 |
| 搬迁 | +新规模 | 老厂关停，净增≈0（除非扩产） |
| 置换 | +新规模 | 必须扣减被置换产能 |

报告里同时写“毛增量”和“净增约”，不要只写一个数。

### 4.3 对目标区域的影响

不要只写“增加供给”。要写：

- 新项目到目标城市的直线距离/运输方式；
- 是否在目标区域的经济供货半径内；
- 产品规格是否匹配本地客户；
- 投产时间是否与客户认证周期匹配；
- 对价格/竞争格局的可能影响（用“可能”，不要承诺）。

## 5. 区域需求与潜客

### 5.1 需求线索

优先级：

1. 目标省/市统计年鉴、工信/发改/园区规划；
2. 行业协会/龙头客户公开产线；
3. 海关/物流调入线索；
4. 券商/媒体区域需求测算（标 B/C）。

需求不是“市场容量”的同义词；写清“表观需求/区域需求/某赛道需求”。

### 5.2 潜客筛选

按“赛道 × 规模 × 本地化 × 认证难度 × 物流半径”筛：

| 维度 | 问题 |
|---|---|
| 赛道 | 玻璃/日化/冶金/水处理/新能源…… |
| 规模 | 产线数量、产能、门店/项目 |
| 本地化 | 是否在目标省/市，是否靠近目标仓 |
| 认证 | 切换供应商要不要送样/审厂/认证？周期多长？ |
| 物流 | 是否在 300/800 km 内？运输形态（袋/罐/散装）？ |
| 价格敏感 | 是成本导向还是指标导向？ |

**同行不列入潜客**；贸易商与终端分开；一个客户只出现一次。

### 5.3 潜客字段

至少：客户名、城市、赛道、公开规模、用量级（推算）、使用场景、优先级、为什么优先、下一步动作、证据等级、来源。

优先级建议：

- S：本地锚点/龙头，用量大，可做标杆；
- A：本地/邻市规模客户，认证可控；
- B：补充赛道/价格敏感，走量；
- C：信息不足，先验证。

## 6. 三角验证

### 6.1 冲突类型

- 同一企业不同页面产能不一致（官网 vs 年报）；
- 产能 vs 产量 vs 销量口径不一致；
- 项目规模 vs 环评规模不一致；
- 投产时间不同来源不一致；
- 区域需求 vs 本地供给反推不一致。

### 6.2 处理原则

1. **并列**：A/B 口径都写出来；
2. **采用**：选一个主口径，写理由（更新、更权威、更具体）；
3. **影响**：如果采用另一个口径，结论会怎么变；
4. **复核**：写下一步用什么文件复核（最新年报/环评/公告）。

不要用“综合来看”把冲突糊过去。冲突本身就是数据质量信号。

### 6.3 样本覆盖

若样本产能 3,070 万吨、全国口径 4,305–4,468 万吨：

```text
覆盖度 ≈ 3,070 / 4,468 ~ 3,070 / 4,305 = 69%–71%
```

只能写“样本覆盖约 69–71%”，**不能写“市场份额 69–71%”**。市场份额需要企业销量/区域销量，样本产能给不出来。

## 7. 结论写法

### 7.1 三层结论

1. **竞争密集区**：样本产能集中在哪些省、哪些工艺、为什么；
2. **区域空白/远距**：目标区域本地多少、最近外省货多远、哪个距离带是 0；
3. **未来变量**：哪些项目、什么时间、对目标区域意味着什么。

每层结论配一个“销售含义”，不要只写行业分析。

### 7.2 销售动作

把结论翻译成动作：

- 先打谁（锚点/标杆/第二供应商）；
- 用什么切入（双源/近距仓储/指标稳定性/账期/运费）；
- 什么时候打（新增产能投产前/客户检修前/年度框架前）；
- 怎么验证（送样/审厂/试单/框架）。

### 7.3 缺口与边界

至少写 5 条缺口，示例：

- 样本不是全行业；
- 负增量未系统收集；
- 距离不是运费；
- 非上市企业披露弱；
- 潜客仅目标省；
- 价格未接入；
- 进口/出口未拆分；
- 产能口径未统一。

每条缺口写“下一步怎么补”，不要写“数据有限，仅供参考”。

## 8. 交付前自检

- [ ] 目标经纬度能定位到城市；
- [ ] 每座工厂有经纬度、来源、产能年份；
- [ ] 企业产能 = 工厂产能之和；
- [ ] 距离带合计 = 样本产能；
- [ ] 项目毛增量/净增分开；
- [ ] 潜客用量标“推算”；
- [ ] 没有市场份额表述；
- [ ] 冲突有采用理由与影响；
- [ ] 缺口 ≥5 条且可执行；
- [ ] HTML/Excel 都能重新生成。
