# 验收清单 · QA Checklist

> 交付前逐条打勾。`validate.py` + `qa.py` 是硬门禁；下面是人工判断项。

## A. 数据

- [ ] `meta.product`、`region`、`province`、`city`、`asof`、`target_lon/lat` 齐全。
- [ ] 目标经纬度能定位到目标城市（不是省会/总部）。
- [ ] 每家企业至少 1 个来源；每座工厂至少 1 个来源；每个项目至少 1 个来源；每个潜客至少 1 个来源。
- [ ] 所有 `source_ids` 都能在 `sources` 找到；没有悬空 ID。
- [ ] 每座工厂有省、市、经纬度、工艺、产能、产能年份。
- [ ] 企业产能 = 其工厂产能之和（差 ≤0.51）；`total_cap` 一致。
- [ ] 距离带合计 = 工厂产能合计。
- [ ] 产量缺失写 `null`/“未披露”，没有用产能替代。
- [ ] 利用率 >135% 的企业已人工确认是否含贸易/代工/口径差异。
- [ ] 项目 `capacity > 0`；`year` 在 2000–2100；毛增量/净增分开。
- [ ] 潜客用量标 `*`；没有把同行列为潜客。
- [ ] `gaps` ≥5 条；`boundaries` ≥2 条。
- [ ] 没有任何“市场份额/市占率”结论；只有“样本覆盖/样本内占比”。

## B. 研究逻辑

- [ ] 工艺分类能解释竞争差异（成本/原料/环保/产品纯度）。
- [ ] 目标区域本地供给、最近外省供给、300–800 km 是否有货，三个问题都回答。
- [ ] 项目时间线覆盖未来 24–36 个月；搬迁/技改/置换已单列。
- [ ] 锚点客户用量有推算过程或明确写“待核”。
- [ ] 每个关键结论有销售含义（先打谁/怎么打/什么时候）。
- [ ] 冲突有 A/B 口径、采用、理由、影响；没有“综合来看”糊过去。
- [ ] 缺口是“下一步取证”，不是免责声明。

## C. HTML

- [ ] 双击可离线打开；不请求任何外部资源。
- [ ] `qa.py` 通过（内联数据/GeoJSON/ECharts、6 个章节、行数一致）。
- [ ] 地图正常渲染：省份着色、工厂气泡、项目菱形、目标脉冲、距离线。
- [ ] 点击省份 → 右侧读数切换；点击工厂 → 抽屉；点击项目 → 抽屉；点击目标 → 潜客区。
- [ ] 企业 chips 勾选/清空/全选 → 地图与右侧面板同步。
- [ ] 工艺筛选 → 地图/右侧同步；矩阵工艺筛选独立。
- [ ] 距离线/项目/标签三个图层开关有效。
- [ ] 矩阵搜索、排序、仅有新增、行点击有效。
- [ ] 潜客赛道筛选、省份定位、抽屉有效。
- [ ] 重置按钮恢复初始状态。
- [ ] 1440/1100/768/390 宽度无页面级横向滚动；表格内部可横滑。
- [ ] 抽屉打开时背景不滚动；Esc/遮罩/关闭按钮都能关。
- [ ] 控制台 0 error；无 `undefined`/`None`/`NaN` 可见文本。
- [ ] 标题、数据截至日、下载 Excel 链接正确；两个文件同目录交付。

## D. Excel

- [ ] 9 个工作表，名称/顺序正确。
- [ ] 封面：标题、4 个 KPI、阅读顺序、内部超链接、免责声明。
- [ ] 01 企业矩阵：17 行（示例）、16 列、冻结/筛选/打印区、TOP10 图。
- [ ] 02 工厂明细：22 行、经纬度、来源、合计=企业合计。
- [ ] 03 新增项目：8 行、毛增量/净增/影响、按年排序。
- [ ] 04 区域对照：18 行、目标省高亮、需求线索、TOP10 图。
- [ ] 05 目标区域与潜客：锚点卡、供应梯度、8 家潜客、3 张动作卡。
- [ ] 06 来源：37 条、标题/链接可点、用于列清楚。
- [ ] 07 冲突：9 项、A/B/采用/理由/影响。
- [ ] 08 缺口：11 条、缺口/边界分开。
- [ ] 无合并单元格重叠；无 `#REF!`/`#VALUE!`；无公式依赖（或已重算）。
- [ ] 打印预览：A4、横向、fitToWidth、页脚页码、无列被截断。
- [ ] 图表在打印区外，不遮挡数据；分类轴是文字不是数字。
- [ ] 文件能被 Excel/WPS/LibreOffice 打开；`check_office.py` verdict=pass。

## E. 可移植性

- [ ] 目录不含 DSH 专有路径/环境变量/密钥。
- [ ] `python -c "import openpyxl"` 在目标机器可用。
- [ ] `python scripts/build_all.py examples/02-minimal-template/data.json /tmp/out` 能跑通。
- [ ] `node --check scripts/templates/app.js` 通过。
- [ ] README/SKILL 中的命令与实际路径一致。
- [ ] 示例 02 明确标注“结构示例，不是研究结论”。

## F. 失败处理

| 失败 | 处理 |
|---|---|
| `validate.py` 报产能不一致 | 拆工厂/改企业产能；不要放宽阈值 |
| `qa.py` 报 HTML 未内联 | 检查 `assets` 是否存在；不要改成 CDN |
| `qa.py` 报 Excel 表数不对 | 重新生成；不要手改 |
| 地图空白 | 检查 `china_prov.json` 是否内联、`echarts.registerMap` 是否执行 |
| 移动端横向溢出 | 检查隐藏抽屉/固定宽元素；`html,body{overflow-x:hidden}` |
| LibreOffice 预览黑屏 | 渲染器失败，不是工作簿失败；停止目检，保留结构性验收 |
| 图表不显示隐藏数据 | 改用可见单元格，或设 `plotVisOnly=0` |

> 记住：**能打开 ≠ 能交付**。数据对、结构对、口径对、移动端不炸，才算完成。
