# 示例：纯碱 → 福莱特玻璃集团（完整实例）

这是 skill 的参考实例：内贸销售要开发光伏玻璃龙头福莱特、销售纯碱（重碱），扫描窗口 2026-04-15 ～ 2026-10-15。

## 文件

| 文件 | 说明 |
|---|---|
| `cards.json` | 研究结论数据文件（5 张事件卡 / 15 条证据 / 10 条推断），schema 见 `templates/scan_data.schema.json` |
| `纯碱客户切入点扫描_福莱特_2026-10-15.xlsx` | 由 cards.json 经 `build_deliverables.py` 生成的 Excel（六个 Sheet） |
| `纯碱客户切入点扫描_福莱特_2026-10-15.html` | 同一数据渲染的交互式 HTML（筛选/排序/证据点开/拜访与消息按钮） |

## 这份示例演示了什么

1. **切入点的优先级排序逻辑**：客户自身事件（首亏+主动冷修、新线达产）排前，市场时机卡（玻璃涨价×纯碱低位、产能置换大限）居中，资金面辅助卡垫底。
2. **事实与推断的分离**：每张卡的 `inference` 数组逐条标注测算类/惯例类/行情判断/政策推演；快照里的信息边界（看不到供应商名单）单独成段。
3. **"为什么是现在"的写法**：客户决策窗口（Q4 长协谈判、点火前认证期）× 我方市场位置（纯碱买方市场）的咬合，而不是"建议加强沟通"。
4. **证据链**：每张卡至少 1 条窗口内证据；关键数字（如 16,400t/d、2,700t/d）来自评级报告一手来源（E6/E7）。

## 复现方式

```bash
python ../../templates/build_deliverables.py cards.json -o . -n 纯碱客户切入点扫描_福莱特_2026-10-15
```

## 移植到其他化工品时看哪里

- 换 `meta.product` 与 `task_line`；
- 换单耗锚点（本例是 226kg 纯碱/吨玻璃，见 E14）；
- 换检索源（本例用巨潮/上交所/港交所披露、券商研报、期货周报）；
- 事件卡的五段式结构、推断类型学、Excel/HTML 模板全部不变。
