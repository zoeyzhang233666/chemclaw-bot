# 检索手册（playbook）

本手册是 SKILL.md 工作流的展开：每个分区给出"查什么、去哪查、怎么判断"。所有查询模板中的 `{公司}` 指已确认主体全称，`{产品}` 指用户销售的产品。

## 0. 通用原则

- **两轮搜索法**：第一轮宽检索锁事实，第二轮针对缺口补查。每次搜索记录：关键词、来源、日期。
- **来源可信度分层**：
  - A 级：监管/官方（国家企业信用信息公示系统、中国执行信息公开网、信用中国、交易所公告、巨潮资讯、排污许可平台、环评公示）
  - B 级：公司自披露（官网、年报、投资者关系记录、公众号）
  - C 级：主流财经/行业媒体（财联社、证券时报、化工媒体等）
  - D 级：商业信用聚合平台（企查查/天眼查/爱企查/水滴信用等）——只能作快照引用，标注快照日期，最终以 A 级核验
- **主体分层**：集团母公司、上市/经营主体、分公司（生产厂）、子公司各自独立查、独立记。处罚/涉诉挂在哪一层写清楚，绝不允许把集团的记录算到股份公司头上（或反之）。

## 1. 主体确认

**查询模板**
- `{公司} 统一社会信用代码`
- `{公司} 工商信息 法定代表人 注册资本`
- `{公司} 公司章程` / `{公司} 年度报告`（章程与年报里的信用代码最权威）
- `{公司简称} 股票代码`（上市主体的快速锚点）

**必采字段**：全称、信用代码、登记机关、法定代表人、成立日期、注册资本、注册地址、上市信息（代码/交易所/上市日）、曾用名与证券简称变更史（注意区分"工商更名"与"证券简称变更"）。

**近名主体陷阱清单**（逐条排查）：
1. 同字号集团母公司（如"XX集团" vs "XX股份有限公司"）
2. 同名/近名异地企业（"XX化工"在多省常见）
3. 分公司/生产厂（可拜访、签约需授权）
4. 核心子公司（涉诉与资质常挂在这层）
5. 证券简称戴帽史（ST/*ST）反映历史经营波动，属"经营状态"证据但非当前状态

## 2. 七项核查

| 项 | 查询模板 | 要点 |
|---|---|---|
| ① 主体与经营状态 | `{公司} 存续 注销 吊销`；`{公司} 迁址 更名` | 以公示系统为准；成立年限即"老企业信用垫"的参考 |
| ② 资本与股权 | `{公司} 注册资本 实缴`；`{公司} 参保人数`；`{公司} 控股股东 实际控制人 质押` | 实控人变更史（划转/收购报告书）要画时间线；参保人数常取不到→进核实清单 |
| ③ 实际业务 | `{公司} 年报 主营 构成`；`{公司} 产能 万吨`；`{公司} 排污许可证`；官网"成员企业/产业板块" | 产能以公司披露/官网口径为准并注日期；判断"是否生产企业"看产线、许可、员工结构 |
| ④ 司法 | `{公司} 被执行人`；`{公司} 失信 限高`；`{公司} 买卖合同纠纷`；执行信息公开网逐层查 | 涉诉分"量级统计"（聚合平台）与"个案"（判决书/年报诉讼表）；区分合同类型（买卖/工程/劳动） |
| ⑤ 异常/处罚/税务 | `{公司} 经营异常`；`{公司} 行政处罚 环保`；`信用中国 {公司}`；`{公司} 欠税 税务非正常` | 环保处罚另查属地生态环境局公示；纳税信用等级（A/B级）是正面信号 |
| ⑥ 出质/抵押 | `{公司} 股权出质`；`{公司} 动产抵押`；公示系统全项截图 | 大股东质押比例反映股东层资金压力 |
| ⑦ 舆情与停产 | `{公司} 停产 检修 停车 {近一年}`；`{公司} 事故 罚款 通报`；年报"非正常停产"披露项 | 行业性负面（周期低谷）与企业性负面分开陈述 |

## 3. 产品与工厂

- **查询模板**：`{公司} 年报 主要产品 收入构成`、`{公司} 产能 产线 基地`、`{公司} 生产许可证 采矿许可证 排污许可`、`{公司} 在职员工 年报`
- **必出内容**：主营产品收入结构（含毛利率——反映周期位置）、产能与装置构成（老线/新线、工艺路线）、基地数量与位置、许可资质清单、是否生产企业的明确判断。
- **产业链位置三段式**：上游原料 → 自身工艺/联产 → 下游流向（下游景气度必须给一句判断，这是亏损/盈利的根因）。

## 4. 采购关系（核心方法论：BOM 倒推 + 供应分层）

### 4.1 判断"它会不会买用户的产品"的五个接口
| 接口 | 典型形态 | 证据来源 |
|---|---|---|
| 原料/主材 | 工艺路线决定的大宗投入（吨品单耗×产能=需求盘子） | 年报"主要原材料"表、环评报告原辅材料清单、排污许可 |
| 辅料/助剂/催化剂/水处理 | 小额但刚需、复购频 | 环评辅料清单、招标网、供应商入围公示 |
| 包装/储运 | 编织袋/吨袋/罐车/铁路专用线 | 年报关联交易、招标公告 |
| 设备/MRO/检维修 | 技改期爆发 | 技改公告、招标网、设备中标公示 |
| 服务 | 物流、检测、工程、劳务 | 招标公告、年报"综合服务"关联项 |

**五个接口全部打不上 → 诚实输出"可能不是目标客户"**，并说明最接近的接口与差距，不要硬凑。

### 4.2 需求测算模板（必须标"估算"）
```
年需求量（估算）= 公开产能 × 吨品单耗（行业经验值/文献值，注明出处）
```
同时给出改造/工艺切换后的长期口径（如氨碱法→联碱法对原料单耗的影响），提醒销售"客户价值是动态的"。

### 4.3 供应三层结构（判断市场外购敞口）
| 层 | 内容 | 查证方法 |
|---|---|---|
| ① 内供 | 集团内关联供应、自产自用 | 关联交易公告（历史占比）、集团官网产业板块 |
| ② 长协/参股 | 长期协议、参股上游锁供 | 公告、新闻 |
| ③ 市场外购 | 年报原材料采购模式表、招标网 | **用户的机会层**：量、准入门槛、招标节奏、决策部门 |

### 4.4 决策链推断
- 大宗原料 → 归口集中采购（供应处/采购中心）+ 年度合格供方制度；
- 关联采购的定价统筹可能在集团层；
- 使用车间对质量指标有实际话语权。
全部标注"推断，需验证"。

## 5. 项目与动态

- **来源**：交易所公告（董事会决议/重大投资）、发改备案/环评公示（一二次公示、验收）、招标网、主流媒体、公司公众号。
- **时间线跨度**：近 18 个月，每条含日期、事件、金额（如披露）。
- **翻译规则**：每条动态后面写"对用户产品的含义"——新产能=原料接口变化；技改=物资/服务窗口+长期单耗变化；参股上游=供应链意图；亏损+扩产=资金链与降本敏感度。
- **财务快照**：最近 1–2 个报告期的营收/利润/经营现金流，一条横幅讲清"给账期前必看"。

## 6. 行业扩展信息源（按需添加，分区结构不变）

- 化工通用：中国化工信息网、ChemNet、化工在线、隆众/卓创资讯（价格与开工率）、各行业协会
- 环评/项目：属地生态环境局公示、全国建设项目环评统一审批平台、发改委备案公示
- 招标：中国招标投标公共服务平台、各集团电子招标平台
- 化工园区：园区管委会官网（企业名录、公示、事故通报）
- 安全/应急：应急管理部与属地局公示（重大危险源备案、事故通报）

## 7. 证据与引用规则

- 页面引用格式：`标题（发布/快照日期，来源名）+ 完整URL`
- 同一事实多个来源时取最高可信级，其余并列展示
- 无法抓取 PDF 原文时，可引用其检索结果条目/新闻转载，并在证据中注明"转引"
- 所有"推断/估算"必须带标注：估算给公式口径，推断写"推断，需验证"
