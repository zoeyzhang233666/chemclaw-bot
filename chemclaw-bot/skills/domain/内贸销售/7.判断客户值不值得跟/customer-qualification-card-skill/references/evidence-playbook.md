# 七维证据来源与检索模板

## 来源分级（写 data.json 时给 `type` 用）

| 等级 | 类型 | 例子 |
|---|---|---|
| 一级 | 定期报告 / 临时公告 / 政府文件 / 招标公告 / 协会统计 | 年报、半年报、环评公示、发改委备案、企业采购平台 |
| 二级 | 行业数据商 / 券商研报 | 隆众、生意社、钢联、卓创、百川、东方财富研报 |
| 三级 | 媒体转述 | 财联社、每经、大河财立方——**须能回链到一二级** |

一级优先；用三级时必须同时给原始来源，或在 `fact` 里注明"据媒体报道"。

## 常用入口

- **财报/公告**：巨潮资讯 `cninfo.com.cn`；上交所/深交所/港交所披露易；新浪财经公告库；东方财富 F10
- **研报**：东方财富研报 PDF `pdf.dfcfw.com`；慧博
- **产能/产线动态**：隆众资讯（我的钢铁网能源化工频道）、生意社 `100ppi.com`、钢联、卓创
- **项目/招标**：全国环评信息公开平台、各省发改委项目公示、中国招标投标公共服务平台、企业电子采购平台（如河南投资集团）、采招网
- **距离/运费**：高德/百度地图测距；运费按 0.35–0.5 元/吨·公里（公路）
- **工商/股权**：国家企业信用信息公示系统（权威）；企查查/天眼查仅作线索

## 七维检索模板（可直接复制）

| 维度 | 检索式 | 想拿到什么 |
|---|---|---|
| 产品匹配 | `{产品} 采购 招标`、`{客户} 供应商 准入`、`{客户} 原料 采购 公告` | 是否用该原料、是否公开招标、历史中标记录 |
| 需求规模 | `{客户} 产能 万吨`、`{客户} 日熔量 产量 产销`、`{产品} 单耗` | 熔量/产能/产量 → 换算年需求 |
| 真实产能 | `{客户} 冷修 点火 改产`、`{行业} 日熔量 最新`、`{客户} 复产` | 窑炉是否在产、改造/冷修计划 |
| 企业规模 | `{客户} 年报 营业收入 净利润`、`{客户} 市值` | 营收、利润、信用 |
| 距离/区域 | `{发货地} 到 {客户所在地} 公里`、`{产品} 运费 元/吨` | 运距与运费占货值比例 |
| 近期机会 | `{客户} 扩建 技改 环评 公示`、`{客户} 招标 {产品}` | 6–12 个月内的窗口 |
| 不确定性 | `{客户} 亏损 定增 委托贷款`、`{客户} 账期 承兑` | 资金链与回款风险 |

## 上市公司 5 步取证法（最省时间）

1. 巨潮搜公司名 → 打开**最新年报**的"经营情况讨论与分析"：拿产能、产量、产线数量、在建项目；
2. 同页"主要客户/供应商"或"采购模式"：看集中度与采购方式（集采/招标/长协）；
3. 临时公告：扩产、技改、招标、融资（定增/委贷/发债）——`近期机会` 与 `不确定性` 都在这；
4. 投资者互动/业绩说明会：管理层对成本与原料的表态（如"期现结合""锁价"）；
5. 行业产线动态（隆众/生意社）：验证窑炉是否真在产、是否改产。

## 写作规范

- 结论先行：`2025年营收157.4亿（+0.6%），利润总额6.2亿（+138%）`，不要贴原文；
- 数字带**年份**与**口径**（产能/产量/在产）；
- 估算标「估」，待核标「待核实」；
- 每个 `fact` 至少 1 条 `evidence`（label+url+date）；
- 查不到就如实写"无公开数据"，并把它放进 `doubts`——**空白本身是信息**。
