## 1. 演示设定

| 项 | 值 |
|---|---|
| 销售产品 | 重质纯碱 99%（散装罐车 / 吨袋） |
| 卖家假设 | 山东潍坊碱厂或一级贸易商，月可供 5,000 吨 |
| 重点区域 | 华北/华中（≤700km 优先） |
| 判断时点 | 2026-10 |

## 2. 候选客户与结果

| 客户 | 位置 | 距潍坊 | 年需求（估） | 均衡排序分 | 默认优先级 |
|---|---|---|---|---|---|
| 信义玻璃（00868.HK） | 安徽芜湖等 | ≈700km | 40–100 万吨 | **75.4** | P3 季度级经营 |
| 株洲旗滨（601636.SH） | 湖南/广东/云南 | 1300–2200km | 80–110 万吨 | 73.6 | P4 观察名单 |
| 河南安彩高科（600207.SH） | 河南安阳 | ≈480km | 10±3 万吨 | 68.6 | **P1 本周优先** |
| 山西利虎 | 吕梁交城 | ≈620km | 8–12 万吨 | 64.3 | P2 两周内拜访 |

> **排序会变，事实不变**：把"距离"权重拉到 2.5，安彩高科 72.7 分跃居第一；把"规模"拉到 2.5，旗滨/信义领先。四种预设的分值在 Excel「权重与排序」C 区、HTML 顶部按钮都能看到。

## 3. 研究轨迹（做这家的思路）

1. **先定市场**：2026-10 重碱现货 970–1,050 元/吨、纯碱厂库约 178 万吨、开工约 65%，浮法日熔量 14.1–14.3 万吨/日、均价约 1,075 元/吨——**买方市场**，客户有得挑，价格不是你的武器。
2. **定下游**：纯碱最大下游是玻璃（浮法/光伏），其次是洗涤剂、泡花碱、氧化铝。选前两类 4 家做池子。
3. **排"假客户"**：玻璃集团里有的自带纯碱（如金晶科技），要先剔除；本样例 4 家均无自产纯碱。
4. **逐维取证**（每维都有 1–2 条链接）：
   - 安彩高科：投资者互动确认"期现结合"采购 → 采购体系开放；2021 年原料供应商准入公开招标 → 有投标通道；2025-12 公告 900t/d 光伏线 4.98 亿元升级改造 → **投产换供应商窗口**；但 2023–2025 连亏扩大、2026-09 申请委托贷款并拟定增 → 账期风险。
   - 旗滨/信义：规模与信用最好，但基地在华南/西南/海外，距潍坊 1,300km 以上；集采长协 + 期货工具，新进入难。
   - 利虎：2025 年隆众多条产线改产动态证明窑炉在产；民企决策链短、无公开招标；但公司口径较旧，采购量需核。
5. **打分与排序**：事实 → 分值 → 加权。安彩赢在"距离 + 近期机会 + 可投标"，输在"连亏 + 账期"；信义赢在"规模 + 信用"，输在"运距 + 准入"。
6. **写待确认清单**：每家的 `asks` 都带"影响哪个维度 + 找谁问"，避免销售跑一趟只拿到名片。

## 4. 局限（必须知道）

- 需求为**估算**（日熔量/产能 × 单耗 × 330 天），未做客户访谈；
- 利虎的公司数据口径较旧（2021 年政府函），实际量需现场核；
- 距离为公路里程近似值，运费按 0.35–0.5 元/吨·公里估；
- 未覆盖：洗瓶剂/泡花碱/氧化铝等其他纯碱下游——用同一方法可继续扩。

## 5. 复制到新产品（改 5 处即可）

1. `meta.product` / `meta.seller` / `meta.as_of`；
2. `market`：换成本品的行情（库存、开工、价格、下游开工）；
3. `dimensions`：hint/rubric 可沿用，按 `references/scoring-rubric.md` 改单耗口径；
4. `customers`：换客户、换 7 维事实与 evidence、换 asks；
5. `presets`：按团队打法调权重（规模/机会/距离）。
