# 化工品客户沟通润色（AGENTS.md）

> 给读 `AGENTS.md` 的 agent（Codex 等）用的操作说明，与 `SKILL.md` 同源。改内容时两份同步。

## 任务

用户会给一件事：**我准备发给【客户/角色】的原话**（微信或邮件），加上产品、渠道、本次目标、背景、上一轮沟通记录。
你要产出**可直接复制发送**的商务文本，并且**一句未经提供的事实都不许新增**，同时交付 Excel + HTML 两个附件。

## 交付物

1. `<任务目录>/case.json` —— 唯一真源（结构见 `config/case.template.json`）
2. `<任务目录>/out/<客户简称>_<场景>_沟通润色.xlsx` —— 11 张表
3. `<任务目录>/out/<客户简称>_<场景>_沟通润色.html` —— 单文件自包含，可交互

## 执行步骤

1. **收料**：原话全文、产品与规格、客户（企业+角色+决策链）、渠道、目标、背景、上一轮记录。缺哪项问一次，别边写边问。
2. **抽事实台账**：把原话拆成 F1…Fn，每条给 `type`（事实/意图/承诺/推测/无据背书/无据施压/越权让价）、`source`、`disposal`。规则见 `references/01-method.md`。
3. **建产品档案**：照 `references/03-product-profile.md` 填 `product_profile`。重点是 `ban_phrases`——本品类不能说的话（如纯碱"绝对不结块"、液碱"无证也能送"）。
4. **写版本**：`P0` 原文原样保存；`A` 自然（默认）、`B` 更短、`C` 正式/邮件（必须有 `email.subject`）、`D` 缓和。一条消息只提一个请求。
5. **审计 + 占位符**：每条事实 × 4 个版本给 `✔ / ◐ / — / ▲`；正文每个 `【待填】` 都要在 `placeholders` 里登记确认人。
6. **跑脚本**：
   ```bash
   python scripts/run_all.py --case case.json --out out
   ```
   必须看到 `边界校验通过` 与 `自检：通过`。

## 硬约束（脚本会拦，别绕过）

| 错误码 | 含义 |
|---|---|
| `UNSOURCED_NUMBER` | 正文出现未经提供的数字+单位（元/吨、天、%、kg…）→ 改【待填】 |
| `BANNED_PROMISE` | 承诺词：一定/保证/绝对/可以再谈/给您申请/免费/包运费/最低价 |
| `FAKE_SCARCITY` | 稀缺话术：货源紧张/库存不多/马上涨价/最后两天 |
| `BANNED_PHRASE` | 命中该品类禁语 |
| `PLACEHOLDER_MISMATCH` | 正文【待填】多于占位符清单条目 |
| `AUDIT_INCOMPLETE` | 有事实没进审计表 / 判定符号为空 |
| `EMAIL_NO_SUBJECT` | 邮件版没有主题行 |

**改 case.json，不要改脚本。** 只有 `--force` 能强行生成，产物会带"未通过边界校验"。

## 十类越界（必须显性处理，不能悄悄留下也不能悄悄消失）

越权让价 · 无据背书 · 无据施压 · 无限承诺 · 模糊时限 · 替客户定义需求 · 越界技术判断 · 危化品资质承诺 · 大宗锁价承诺 · 跨越贸易商直接承诺终端。
详见 `references/02-boundary-rules.md`。

## 不许接的活

客户投诉/质量事故的正式回复、招投标文件、合同条款起草 —— 这三类是责任文书，直接告诉用户走客诉流程或法务，不要用润色工具硬套。

## 示例

- `examples/01-纯碱-浮法玻璃-报价跟进`：固体·袋装·非危化；4 处越界全部显性处理
- `examples/02-液碱-印染-催款`：液体·槽车·危化品；把"催"变成"对账 + 配合补件"
- `examples/03-尿素-复合肥-解释涨价`：大宗·农化；涨价不编涨幅、不设假期限
