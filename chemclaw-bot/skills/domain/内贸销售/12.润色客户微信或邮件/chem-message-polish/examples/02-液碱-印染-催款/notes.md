# 示例 02 · 32% 液碱 · 印染/水处理客户 · 催款（微信 + 电话）

> 这是 skill 的第二个示例，专门用来压测「**液体 + 危化品 + 催款**」这个组合。
> 01 号示例（重质纯碱·浮法玻璃·报价跟进）证明的是「固体货怎么把催回复变成约拜访」；02 号要证明的是另一件事：**当客户欠着钱、而你手上还握着一堆不能说的话时，这条消息怎么写才既推进又不埋雷。**

---

## 一、这个案例在演什么

| 项 | 内容 |
|---|---|
| 产品 | 32% 液碱（氢氧化钠溶液，GB/T 209-2018 Ⅲ类，第 8 类腐蚀品 UN 1824） |
| 客户 | 苏州吴江 B纺织印染有限公司（虚构）：前处理工段用碱 + 自建污水站调 pH，两处用碱 |
| 关系阶段 | 已发货、已对账、客户口头答应「这周尽量安排」后失约 |
| 渠道 | 微信（主）+ 电话（跟进）；C 版是邮件体对账函 |
| 本次目标 | 账目对齐 → 拿到本周付款排期（不是「今天就打款」） |
| 原文病症 | 一条消息里塞了催款、施压、分期、涨价、让价、四项技术承诺，六个诉求 |

真实业务里这条消息之所以「发不出去」，不是因为写得不客气——恰恰是因为**太想推进，于是把手上所有能施压的牌一次全打出去了**：内部压力（财务在催我）、假稀缺陷（货源紧张马上要涨）、越权让价（多订点我帮你申请）、绝对化承诺（绝对不结晶/浓度永不衰减/无证也能送/随时能卸）。这四张牌打出去，短期也许能逼出一笔钱，长期是把「资质」和「质量」两条命门主动交到对方手上。

---

## 二、这个案例最值得写进「看点」的三条判断

### 看点 1 · 催款最硬的杠杆不是「催」，是「对账口径」

原话只有一句「什么时候能付一下」，没有任何可核的数据。客户回一句「在走流程」就能结束对话——因为他不需要为任何具体的东西负责。

A 版把杠杆换成了**四件套**：发货批次与车数、对账金额、合同账期、按发货日推算的已逾期天数。这四个数一旦摆出来，对话的性质就变了：

- 对方要么**核对**（那就有下一步）；
- 要么**指出出入**（那也是有效回复，而且把争议提前暴露）；
- 只有第三种回答是「我不知道」，而这一句在四件套面前几乎说不出口。

注意一个细节：**账期起算日必须写明是「发货日 / 对账日 / 开票日」中的哪一个**。液碱月结客户里，这三个口径差一天，逾期天数就差一天，整笔账的性质就从「已逾期」变成「未到期」。这不是抠字眼，这是催款能不能成立的地基——所以 P3 的「填错后果」写的是「起算日错，逾期天数不成立，催款立刻变成讨价还价」。

### 看点 2 · 液碱的对账争议，八成出在「卸车」而不是「货款」

这是液体危化品和袋装固体最不一样的地方：货到厂门口不等于交付完成，**卸车这一段是双方共同作业**。客户罐区排队、接卸泵不匹配、软管接口不对、卸车超时——任何一项都会产生压车费，而压车费到底算谁的、有没有计入本次对账金额，合同里常常是模糊的。

所以 C 版（邮件·对账函）在「一、对账口径」里单独加了一句：

> 上月如发生卸车超时产生的压车费，是否已计入本次对账金额，也请一并确认。

这一句的作用不是催钱，是**先把最容易吵起来的那一块摘出来**。反过来，原话里客户上周五说的「卸车慢、我们还压了车」，正文一个字都没接——原因见看点 3。

### 看点 3 · 危化品把「催款」变成了两件不能做的事

客户上周五抛了一句「你们的碱浓度好像不太够，卸车也慢，我们还压了车」。这句话在催款语境里几乎是一个陷阱：

- 你要是**接**了，就得证明浓度没问题、卸车不慢——而这需要批次号、取样照片、卸车记录，一样都没给；接了就变成质量异议的被告。
- 你要是**驳**了（「不可能，我们的货没问题」），就把一句拖延话升级成了对立，而且一旦后续留样检测真有问题，前面这句话会被原样拿出来。
- 你要是**拿它当筹码**（「货没问题你就得付钱」），等于把两件事绑死：质量结论出来之前，货款永远付不了。

所以四版全部**刻意不提**这一条（审计 F6 = — / — / ◐ / —）。C 版那个 ◐ 只写「压车费是否已计入对账」，是**对账口径**，不是**质量回应**——两件事在文本上必须分开。真正的处理方式写在 `replies` 的第 4 条：要批次号、要取样照片、要发现异常的时间点，同步调随车质检单与留样，**在结论出来前货款与异议分开走**，涉及索赔立刻转客诉流程与法务。

这是本 skill 的边界所在：润色能帮你把「催款」和「质量异议」切成两件事，但不能替你做质量异议的正式回复——那属于责任文书，不属于润色。

## 三、原文的五处越界，为什么一句都不能留

| # | 越界类型 | 原话 | 为什么必须删 | 替代写法 |
|---|---|---|---|---|
| 1 | 无据施压 | 「我们财务天天在催我，我这边也不好交代」 | 把内部压力转嫁给客户，等于要他替你对抗你的公司；对方只需一句「那我也没办法」就结束对话，而你暴露了自己在内部没有缓冲能力 | 「发货单、磅单、随车质检单我都留着，今天就发您」——把压力换成服务 |
| 2 | 擅自分期 | 「这周能不能先安排一部分，剩下的再说」 | 「剩下的再说」是销售自己给出去的账期变更，属财务权限；说了就等于把合同账期改成口头账期 | 不提分期。客户真要分期，走 `replies` 第 2 条：**只承诺「去问」，不承诺「能批」** |
| 3 | 无据施压 | 「最近货源也紧张，价格马上要涨」 | 没有库存表/检修计划/调价函的稀缺话术＝编造；在催款里尤其致命：对方会怀疑整笔账都可谈 | 全删。要谈价格另起一条消息，并走「解释涨价」场景（不编涨幅、不设假期限） |
| 4 | 越权让价 | 「多订点我帮您申请个优惠」 | 催款时谈让价，等于告诉对方「欠钱是有效谈判手段」，后面每一笔都会被这么谈 | 全删。`replies` 第 5 条明确「货款和价格是两条线，我不拿一条换另一条」 |
| 5 | 越界技术判断 + 危化品资质承诺 | 「绝对不结晶，浓度永不衰减，无证也能送，随时能卸」 | 四句都能被现场推翻：32% 液碱低温会结晶、浓度会因吸潮与温差波动、危运需资质、卸车要专区。说了做不到，前面的对账数据也跟着不算数了 | C 版反向写：「冬季低温时段，液碱在贵司储罐与管线有结晶风险，到货温度、卸车时段与保温措施我方可按贵司作息配合」——**用真实风险换信任** |

一句话总结这五行：**催款的目标是让对方「不好意思不排」，不是让对方「怕你」。** 前四条越界都在制造后者。

## 四、四个版本各自解决什么

| 版本 | 媒介 | 字数 | 语气/推进力 | 解决什么 |
|---|---|---|---|---|
| P0 原文 | 微信 | 129 | 1 / 5 | 五处越界的原始稿，只作对照基线（不扫描、不交付） |
| A 自然版 | 微信 | 187 | 2 / 4 | 默认首发。对账四件套 → 我方补件 → 一个请求 → 一条电话出口 |
| B 更短版 | 微信 | 39 | 2 / 5 | 客户已读不回时用。只留最有压迫感的一个数（逾期天数）＋一个请求＋零成本承诺（单据我发） |
| C 正式版 | 邮件 | 468 | 5 / 3 | 对方要走流程、要抄送财务或领导时用。对账函结构：对账口径 / 随附单据 / 付款排期 |
| D 缓和版 | 微信 | 155 | 2 / 2 | 刚催过、或对方正拿质量说事时的降档版。0 个【待填】，全部换成「明细都在对账单上」 |

### A 版为什么这么排

1. **不用「在吗/方便吗」，直接说「对一下账」。** 对账是双方都要做的事，不是单方面催收——这句话一出来，对方就没有「被讨债」的防御位置。
2. **四件套一次给全。** 分期给数据会让对方一直处在「等我查一下」的状态，一次给全才有一次性核对的机会。
3. **紧接着给「我能补什么」。** 催款消息里最稀缺的是「主动权在自己手上」的感觉。把补单据摆在前面，等于说：流程卡住不是我不配合。
4. **请求只有一个，且给了台阶。** 「这周能不能走上付款流程」+「卡在哪个环节您直接说」——让对方可以回答「卡在财务签字」，而不必回答「没钱」。**给对方一个不丢脸的回答方式，是催款文案的全部技术含量。**
5. **结尾留一条电话出口。** 渠道是「微信（主）+ 电话（跟进）」，所以 A 版末尾给了一个不施压的切换许可：「微信上说不清的，我下午给您打个电话，几分钟过完，可以吗？」——这句话同时完成了两件事：预告了下一步动作，且没有把「打电话」变成一个要求。

### B 版为什么只留一个数字

「更短」不等于「把 A 删一半」。字数压到 39 字之后，能承载的只有一个数。选哪个？选**逾期天数**，不选金额——金额是「欠多少」，天数是「欠了多久」，后者的社交压力更大，而且不涉及具体钱数，不会引出「我核对一下金额」这种拖延型回复。

代价写进了审计：F2（金额）、F3（账期）、F1（批次）在 B 版全部为 —。这是明确的取舍，不是漏写。

### C 版为什么是「对账函」而不是「催款邮件」

催款邮件最容易被转发的路径是：采购 → 财务 →「这家的账有问题吧」。所以 C 版的结构完全按**财务能用**来设计：

- 一、对账口径：数据来源写明「取自双方签收的发货单与磅单」，并主动说「如与贵司账目有出入，请直接指出，我方以单据为准重新核对」——先把自己放在「可以被纠正」的位置。
- 二、随附单据：四类单据一次列全，并给出四种交付形式（补开/补寄/换收件人/同步供应商系统）。财务最容易卡在「单据不全」，这一条把借口提前拆掉。
- 三、付款排期：**只要节点，不要承诺**。结尾一句「我方要的不是当场答复，是账目清楚、节点明确」，同时约定「我方按节点跟进，不再重复打扰」——这是给下一次联系**立规矩**，不是又一次催促。
- 结尾：把冬季结晶风险与卸车时段一起提出来，并明确「今天不必答复」。危化品客户对「你是不是懂我的罐」比对你说了什么客气话更敏感。

### D 版为什么把【待填】清零

D 版是「降档版」，用在一句话就可能吵起来的时候。它的推进力最低（push = 2），换的是**不激起防御**：不报数、不问时间、只交付「账已经对好了、单据都在、您要哪份我发」。0 个【待填】不是偷懒——D 版的整个策略就是「把球完全放在对方那边」，任何数字都会把球又推回来。

## 五、「危化品 + 催款」特有的六条边界

| # | 边界 | 本案例里的体现 | 违反了会怎样 |
|---|---|---|---|
| 1 | 不承诺资质 | 「无证也能送」删除；正文与场景中一旦提运输，必同时提危运资质与专区接卸 | 无资质运输属违法，客户安全/合规部门一条就能把整笔合作停掉 |
| 2 | 不承诺卸车 | 「随时能卸」删除；改为「卸车时段我方可按贵司作息配合，具体在电话中确认」 | 卸车受客户罐区与排队影响，你控制不了；承诺了压车费就是你的 |
| 3 | 不承诺不结晶 | 「绝对不结晶」删除；C 版反向写明「有结晶风险」 | 32% 液碱结晶温度约 5℃，冬季必被验证；一次被推翻，所有数据都不作数 |
| 4 | 不承诺浓度恒定 | 「浓度永不衰减」删除 | 液碱吸潮与温差都会带来浓度波动，绝对化说法等于给自己埋检测报告 |
| 5 | 不用「包赔」换信任 | 「包赔停线损失」进 ban_phrases，正文与追问里都不出现 | 停线损失的量级远超单笔货款，销售无权承诺，且会引来自认责任的书面证据 |
| 6 | 催款不提安全/防护打折 | 送样场景明确「走有资质的运输、现场留冲洗水源、防护用品我方自带」 | 印染厂卸碱现场若无冲洗条件，属可记录的安全隐患；省下的运费远不够赔 |

第 6 条容易被忽略：**催款时客户对你的信任度是最低的，此时任何「图省事」的表述都会被解读成「这家不专业」。** 所以本案例在催款主线上一次都没提防护，但在送样与约见场景里把防护写足了——这不是跑题，是在为后续交付铺路。

## 六、事实 / 审计 / 占位符的账

- **事实 12 条（F1–F12）**：覆盖发货批次、对账金额、合同账期、逾期天数（四件套全部为【待填】）、客户两句原话（口头承诺 + 质量说法）、我方三处越界表述、我方诉求、可配合补件清单、客户工艺用途。
- **审计 12 行**：每条事实 × A/B/C/D 四格，全部有判定，无空格。
  - 刻意未提（—）：F5（客户口头承诺「这周尽量安排」）、F12（客户两处用碱）——引用前者等于当面拆穿失约；引用后者等于「我比你懂你的车间」。
  - 只弱化（◐）：F6 在 C 版弱化为「压车费是否计入本次对账」，不接质量异议本身。
  - 全部删除（▲）：F8 / F9 / F10 三条越界表述。
- **占位符 10 条（P1–P10）**：正文（A+B+C+D）里【待填】共出现 **10 处**，与清单 **10 条**严格对上——这是脚本的硬约束（`PLACEHOLDER_MISMATCH`），也是本案例刻意设计的**紧配合**：多写一处【待填】就必须多登记一个责任人。

| 位置 | 【待填】处数 | 对应占位符 |
|---|---|---|
| A 版 | 4 | P1 车数 / P2 金额 / P3 账期 / P4 逾期天数 |
| B 版 | 1 | P4 逾期天数 |
| C 版 | 5 | P1 / P2 / P3 / P4 + P10 落款联系方式 |
| D 版 | 0 | —（策略性零占位） |
| 场景·催款、场景·约见、场景·送样、调整·只对账不催款 | 另计（不计入上方配额） | P5 对账单编号 / P6 发票号 / P7 压车费口径 / P8 冬季到货安排 / P9 卸样地点 |

> 说明：脚本只统计四个版本正文里的【待填】数量，场景与调整里的【待填】不受配额约束，但仍必须登记责任人——所以 P5–P9 的「出现位置」写的是场景或调整，而不是 A/B/C/D。这是刻意的分配，不是凑数。

## 七、和 01 号示例的差别（结构复用的地方）

结构、字段、审计符号、四版骨架与 01 完全一致，可以直接拿 `case.json` 对照着改用。差异在内容策略：

| 维度 | 01 纯碱·报价跟进 | 02 液碱·催款 |
|---|---|---|
| 推进手法 | 把「催回复」包装成「核对报价口径」 | 把「催款」包装成「对账 + 配合补件」 |
| C 版结构 | 样品情况 / 报价 / 到厂拜访（三段式邀约） | 对账口径 / 随附单据 / 付款排期（对账函） |
| 数字密度 | 低（几乎不留【待填】在 A 版） | 高（A 版一次给四件套） |
| 【待填】分布 | A 版 0 处，集中在 C 版 | A 版 4 处，四版合计 10 处 |
| 特有风险 | 结块、吸潮、非危化 | 结晶、浓度衰减、危运资质、卸车压车费、碱液灼伤防护 |
| 禁语重心 | 「绝对不结块」「放多久都没事」 | 「绝对不结晶」「无证也能送」「随时能卸」「浓度永不衰减」「包赔停线损失」 |

一句话：**01 的难点是「怎么让人愿意回」，02 的难点是「人在拖钱的时候，怎么不把底牌赔进去」。**

## 八、数据口径与出处

- 国标：GB/T 209-2018《工业用氢氧化钠》为现行国家标准，Ⅲ类液碱对应 NaOH 含量 ≥ 32%（32% 液碱是郑商所烧碱期货的基准交割品级，这一牌号在国内流通最广）。
- 危险性：液碱属第 8 类腐蚀品（UN 1824），运输需危险货物道路运输资质；装卸需耐碱防护与冲洗水源，皮肤/眼睛接触按灼伤处理。
- 结晶：**32% 液碱的结晶温度约 5℃**，来自行业公开的「液碱结晶温度—浓度对照表」（32% 对应约 4.8℃，35% 对应约 12℃），属**行业经验值，不是该客户的实测数据**，也不构成对其储罐温度条件的判断。本案例据此仅在 C 版写「有结晶风险」，不写任何温度数字——正文里一个数字都不给。
- 金额、账期、逾期天数、车数：**全部【待填】**。这不是遗漏，是规则。

## 十、改这个 case 复用到别的客户

1. 换 `meta.customer` 与 `customer_profile`；`file_stem` 改成「客户简称_催款」。
2. `facts` 里 F1–F4 是四件套的壳，只需保持「全部【待填】」的写法；F5/F6 换成这个客户真实说过的两句原话。
3. `product_profile.ban_phrases` 按品类替换：液碱是「绝对不结晶/无证也能送/随时能卸/浓度永不衰减/包赔停线损失」；换到硫酸、盐酸要加「不用备案」；换到双氧水要加「放多久都不分解」。
4. 跑 `validate_case.py`，ERROR 清零再生成产物。**不要为了让某个数字留下来去改脚本**——那条规则是这条产品线的全部价值。
