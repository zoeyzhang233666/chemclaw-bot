# 04 · 渠道与语气矩阵

同一条消息，微信和邮件的判据完全不同。渠道选错，再好的文案也发不出去。

## 一、四渠道的硬约束

| 渠道 | 长度 | 结构 | 禁忌 | 适合 |
|---|---|---|---|---|
| **微信** | ≤220 字，3–5 行 | 一行一个信息点，不空行不缩进 | 不用"尊敬的""顺祝商祺""此致敬礼"；不发长段落；不连发多条 | 日常跟进、约时间、要反馈 |
| **邮件** | 200–400 字 | 主题行 + 称呼 + 分条（一、二、三）+ 请求 + 落款 | 不写"在吗"；不群发感；不省略主题 | 走流程、抄送领导、留痕、报价与调价 |
| **电话** | 开场 20 字内 | 自报 + 由头 + 占用时长 | 不寒暄超过两句；不在电话里报数字（容易记错且无痕） | 紧急事项、已读不回三次以上 |
| **当面** | 说到点为止 | 结论 → 依据 → 请求 | 不带纸质承诺出门除非已授权 | 谈条款、看现场、见技术口 |

**渠道升级规则**：微信两次无回应 → 换电话；电话通了没结论 → 当天补一条微信把结论写下来（留痕）；涉及价格条款 → 一律补邮件。

## 二、四语气 × 四渠道

| | 微信 | 邮件 | 电话 | 当面 |
|---|---|---|---|---|
| **自然** | 默认。口语、短句、结尾开放问句 | 半正式：称呼 + 分条 + "烦请告知" | 直给由头 | 先说结论 |
| **简洁** | 三句话，一件事 | 三条以内，标题即结论 | 30 秒说完 | 一页纸 |
| **正式** | 只加"您/贵司"和完整句，不加公文腔 | 分条、编号、附文件、落款 | 不适用（电话不宜过正式） | 带书面材料 |
| **缓和** | 删时间要求，把选择权交回 | 加"如时间不便，我们另行安排" | "不着急，您先忙" | 不催，只留资料 |

## 三、微信行文七条

1. **第一句给由头**，不给问候。"上周二寄到厂里的两袋样" 好过 "在吗/打扰一下"。
2. **一行一个信息点**。手机屏幕上超过两行的一句，读的人会跳。
3. **数字前置**。"半小时""两袋""周一" 这类具体信息放在句首，比放在句尾容易被注意到。
4. **一个问句收尾**。两个以上问号 = 两个请求 = 回复成本翻倍。
5. **不用感叹号**。商务场景里感叹号≈催促。
6. **不用"麻烦您尽快"**。改成"这周哪天方便"，把压力换成二选一。
7. **不用表情包和"哈"**。第一次或正式客户，一律不用；熟了以后由客户先带。

## 四、邮件结构模板

```
主题：【客户简称｜品名规格】事项一句话 — 我方公司 姓名

称呼：

一句话说明来意（承接上一次动作）。

一、<事项一：事实 + 请对方做什么>
二、<事项二：口径/编号/有效期，能写清的写清，写不清的【待填】>
三、<事项三：下一步动作与时间>

请告知合适时段/口径，我按贵司安排推进。

顺祝
商祺

姓名　公司 区域
电话/微信：【待填】
```

**主题行规则**：`【客户｜品名】事项 — 我方` 。客户一看来件人就知道跟哪个项目有关，转发给领导也不用改。

## 五、电话开场模板

```
"王工您好，我是某碱业华北区的李明，上周给您发过样品的那家。
占用您两分钟，就一件事：<一句话说清>。现在方便吗？"
```

不便时立刻收口："那我不耽误您，我下午三点再打给您，或者您方便时微信说一声都行。"——**给退路反而更容易约到**。

## 六、当面收口

见面结束前必须落一句话，否则等于没见：

> "那我回去把 <具体的两三件事> 整理成一页，周四前发您微信确认，您看行吗？"

把口头共识转成书面动作，是内贸销售最被低估的能力。
