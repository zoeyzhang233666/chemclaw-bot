# 03 · 产品档案：让同一套方法适配任意化工品

客户沟通里真正会出事的，从来不是文笔，而是**对这个品类的常识性误判**：敢不敢说"绝对不结块"、能不能承诺"随时送"、要不要先谈资质、验收到底卡哪几个指标。
产品档案就是把这类判断提前固化，让正文写出来像"懂行的人"写的。

## 一、四个必答问题

写任何一条消息之前，先用四问把这个品类过一遍：

1. **形态与危险性**：固体/液体/气体/浆料？是不是危险化学品？是否属易制毒/易制爆/强腐蚀/有毒？有没有 UN 号？
2. **包装与运输**：袋（25/50kg）、吨包、吨桶、槽车、ISO 罐、钢瓶、管输？谁负责卸车？需不需要专用资质车辆与专区？
3. **客户卡什么指标**：这个品类在客户车间被卡的是哪 2–4 个指标（含量、杂质、水分、粒度、色度、粘度、熔指、稳定性）？
4. **价格与结算口径**：出厂价 / 到厂价 / 库提价？含税否？承兑有无加价？运费谁承担？过磅差异怎么算？账期惯例？

四问答完，`product` 段就能填了。

## 二、`product` 段字段

  "price_basis": "出厂价 / 到厂价（含运费）；承兑加价按当期政策",
  "payment_norm": "现款、月结（视客户等级），大客户承兑",
  "downstream": ["浮法玻璃", "光伏玻璃", "日用玻璃", "洗涤剂", "泡花碱", "冶金"],

`ban_phrases` 会被校验脚本逐条比对正文，命中即报 `BANNED_PHRASE`。这是本 skill 最容易漏、也最值钱的一道闸。

## 三、六大品类族速查表

> 用途：给 agent 一个起点，不要当成结论。**危化品属性、资质要求、现行国标号，务必用检索核实后再写进交付物**（易制毒/易制爆目录会调整，标准会换版）。

### 族 1 · 无机酸碱盐（纯碱、烧碱/液碱/片碱、硫酸、盐酸、元明粉、氯化钙、双氧水）

| 项 | 要点 |
|---|---|
| 危险性 | 硫酸/盐酸/液碱/双氧水通常属危险化学品；**硫酸、盐酸常被列入易制毒化学品第三类**，采购需备案与流向登记 → 新客户第一条消息里主动提"资质与备案"会显得专业，承诺"不用备案"会直接出局 |
| 包装运输 | 液碱 32%/50% 槽车、吨桶；片碱 25kg 袋；纯碱吨包/50kg 袋；硫酸槽车/吨桶（专用） |
| 验收指标 | 主含量（NaOH/H₂SO₄/HCl/Na₂CO₃）、碳酸钠/氯化钠等杂质、Fe 含量、色度、不溶物、浓度衰减 |
| 常见痛点 | 吸潮结块、低温结晶（液碱）、卸车排队、储罐液位告急、浓度批次波动 |
| 禁语 | "绝对不结块""永远不会结晶""无资质也能送""浓度随便调" |

### 族 2 · 有机溶剂（甲醇、乙醇、甲苯、二甲苯、丙酮、乙酸乙酯、二氯甲烷）

| 项 | 要点 |
|---|---|
| 危险性 | 多为危险化学品（易燃、有毒）；**甲苯、丙酮等常列入易制毒第三类**；需 MSDS、危运资质、防静电与防爆要求 |
| 包装运输 | 槽车、200L 铁桶、吨桶（IBC）；禁用非专用容器 |
| 验收指标 | 纯度（GC）、水分（Karl Fischer）、色度 APHA、蒸发残渣、酸度、硫/氯杂质 |
| 常见痛点 | 水分超标影响反应、色度不稳、夏季挥发损耗、储罐氮封 |
| 禁语 | "纯度绝对 99.9%""什么国标都能过""桶装随便放" |

### 族 3 · 树脂与塑料原料（PVC、PP、PE、ABS、PS、EVA）

| 项 | 要点 |
|---|---|
| 危险性 | 成品树脂一般为非危险化学品（单体如 VCM 才属危化） |
| 包装运输 | 25kg 编织袋、吨包、散装罐车（部分） |
| 验收指标 | PVC 看 K 值/聚合度、鱼眼、杂质粒子、灰分、增塑剂吸收；聚烯烃看熔指 MFI、密度、灰分、黄度 |
| 常见痛点 | 鱼眼/晶点、批次色差、加工稳定性、配方兼容性 |
| 禁语 | "直接替换不用试""加工性能绝对没问题""色差看不出" |

### 族 4 · 化肥与农化（尿素、复合肥、氯化钾、磷铵、草甘膦）

| 项 | 要点 |
|---|---|
| 危险性 | 一般非危化；但部分农药制剂属危化/剧毒管理，另行判断 |
| 包装运输 | 40/50kg 袋、吨包、散装（尿素）；防潮要求高 |
| 验收指标 | 尿素看 N 含量（46%）、缩二脲、水分、粒度、颗粒强度；复合肥看配比与氯离子 |
| 常见痛点 | 结块、粉化、颗粒强度不足、季节性备货与跌价风险 |
| 禁语 | 替客户判断用肥季节与用量、"保证增产""绝对不结块" |

### 族 5 · 精细化工与助剂（分散剂、抗氧剂、增塑剂、催化剂、表面活性剂）

| 项 | 要点 |
|---|---|
| 危险性 | 视具体品种，常为非危化但需 MSDS |
| 包装运输 | 25kg 袋/桶、吨桶、小批量样品 |
| 验收指标 | 有效含量、羟值/酸值/环氧值、色度、挥发分、金属离子残留 |
| 常见痛点 | 配方兼容性、试产周期长、小批量多牌号、替代验证成本高 |
| 禁语 | "直接替换不用试""和进口的一样""小样就等于大货" |

### 族 6 · 工业气体（液氧、液氮、液氩、二氧化碳、氢气、乙炔）

| 项 | 要点 |
|---|---|
| 危险性 | 多为危险化学品（压力容器 + 低温/易燃），运输需危运资质与专用槽车/钢瓶 |
| 包装运输 | 钢瓶、杜瓦罐、液体槽车、管道供气 |
| 验收指标 | 纯度（99.999% 等）、露点、含氧量/含烃量、压力 |
| 常见痛点 | 断供风险高（停线成本极大）、储罐液位、气化能力、安全巡检 |
| 禁语 | "随时要随时有""断供我们包赔""不用资质也能灌" |

## 四、下游痛点 → 通用话术落点

不管卖什么，客户的痛点几乎都能归到下面六类。写正文时，**把客户的痛点当议题，不要当我方的卖点**：

| 痛点 | 客户真实担心 | 话术落点（不是推销） |
|---|---|---|
| 批次波动 | 影响我的产品一致性 | "想听车间实际用下来的感受，哪批差异大" |
| 吸潮/结块/结晶 | 影响投料与计量 | "到货后的存放和拆包方式，我们一起对一下" |
| 卸车/到货节奏 | 影响我的生产排程 | "把到货节奏当面过一遍"是拜访的正当理由 |
| 库存与断供 | 停线成本远大于差价 | 以"备份货源"定位，不做替换诉求 |
| 资质与合规 | 出了事是我担责 | 主动出示资质、备案、MSDS，比降价有用 |
| 结算与账期 | 现金流 | 先给方案口径，再谈条款；不当场答应 |

## 五、价格与结算口径（写错就是事故）

| 口径 | 含义 | 沟通里必须说清 |
|---|---|---|
| 出厂价 | 买方自提，运费与风险自担 | 是否含税、装车费谁出 |
| 到厂价 | 含运至买方厂区 | 卸车费、压车费、过磅差异 |
| 库提价 | 从指定仓库提货 | 仓储费、出库费、提货期限 |
| 承兑 | 银行承兑汇票结算 | 是否加价、贴息谁承担 |
| 月结 | 按账期结算 | 起算日（发货日/对账日/开票日）——三者差一天就是争议 |

正文里凡涉及上述任一项，只用两种写法：**引用已发文件的具体条款**，或 **`【待填】`**。
