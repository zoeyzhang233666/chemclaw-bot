# 02 · 商业边界：什么算"新增"

本文件是 skill 的判据来源。`scripts/validate_case.py` 里的规则，逐条对应这里。

## 一、七类必须显性处理的表述

| 类别 | 典型原话 | 为什么危险 | 合法替代写法 |
|---|---|---|---|
| **越权让价** | "价格可以再谈""我给您申请""最低就这个价了" | 一句顺口话变成对方谈判起点，利润与专业形象双失 | "价格以正式报价单为准"；获授权后写【待填：可让幅度与条件】 |
| **无据背书** | "很多玻璃厂都在用""质量行业最好" | 无法核验，被追问一次就破 | "随样附了质检单，指标您可以直接对" |
| **无据施压** | "货源紧张""马上涨价""最后两天" | 编造稀缺＝骗，被拆穿后所有话都不作数 | 删；或补真实依据（检修计划表、正式调价函） |
| **无限承诺** | "有什么要求都能提""我们一定配合""随时要随时有" | 把定价权与交付承诺交出去 | "我先记下来，能做到什么程度，我核实后给您准话" |
| **模糊时限** | "尽快""马上""这两天" | 对方按自己的理解记，事后必吵 | "我今天下午核对完发您""本周三前给您答复" |
| **替客户定义需求** | "您肯定需要备货""您这边是要降成本吧" | 猜错即失分，猜对也显得轻浮 | "您这边更看重到货稳定还是价格，我按您的口径准备" |
| **越界技术判断** | "我们的碱绝对不结块""这个指标肯定达标" | 化工品的批次波动是客观存在的，绝对化＝埋雷 | "常规控制水平在【待填】以内，具体以本批质检单为准" |

## 二、绝对不许出现的数字

只要用户没提供，正文里就不许出现下面任何一类：

- 单价、总价、涨跌幅、折扣率（元/吨、元、%、折）
- 数量（吨、kg、袋、车、件）
- 时间（交期、账期、有效期、账龄天数）
- 库存量、产能、开工率
- 客户的历史采购量、同行用量

需要这些位置时，统一写 `【待填】`，并在 `case.placeholders` 里登记：给谁确认、建议口径、填错后果。

> 唯一例外：`product_profile` 里的**行业公开经验值**（如"吨浮法玻璃约耗纯碱 0.2 吨"），可以作为背景知识写进工作簿的说明页，但**不得写进发给客户的正文**，且必须标注"行业经验值，非该客户实测数据"。

## 三、授权的层级

| 事项 | 谁有权批 | 批了以后怎么写 |
|---|---|---|
| 单价下浮 | 销售主管 / 价格委员会 | 写幅度与条件（量、账期、提货方式），并注明有效期 |
| 账期放宽 | 财务 | 引用合同条款编号，不口头描述 |
| 免费样品 / 包运费 | 销售主管 | 写"本次"，不写"以后都" |
| 交期承诺 | 生产/物流 | 写"以排产确认为准"，并给确认时间 |
| 技术指标承诺 | 质检 | 写"以本批质检单为准"，绝不用"绝对/保证" |

销售本人在正文里能做的，只有"记录 + 转达 + 核实后回复"。**没有授权，就没有让价。** 这不是保守，是让每一次让步都能换回东西。

## 四、什么叫"保留原意"

保留原意 ≠ 保留原话。判断标准是三条同时成立：

1. 用户想推进的那件事还在（约见 / 要反馈 / 收款 / 通知涨价 / 安排送样）；
2. 用户提到的事实一条不少（包括不利的那些）；
3. 用户的语气倾向没被反转（他说得客气，不能改成强硬；他要施压，可以改成有理由的推进，但不能变成哀求）。

反例：原文"您有什么要求可以提，我们一定配合" → 改成"贵司若有任何需求，我司必将全力支持"。这叫**升级**，不是润色。正确方向是降级。

## 五、化工品特有的边界

| 场景 | 红线 | 说明 |
|---|---|---|
| 危化品（液碱、硫酸、盐酸、甲醇、液氨…） | 不承诺"无资质也能送""随到随卸" | 危化品运输需资质与专区卸车，承诺了也做不到 |
| 有保质期/易吸潮/易结晶的品类 | 不承诺"放多久都没事" | 纯碱吸潮结块、液碱低温结晶、双氧水分解，都是常识性风险 |
| 大宗随行就市品类 | 不承诺"价格锁多久" | 锁价是商务政策，不是销售口头能给 |
| 农化/化肥 | 不替客户判断用肥季节与用量 | 客户比销售更懂自己的种植/生产节奏 |
| 危化品 + 首次合作 | 不在第一条消息里谈账期 | 先解决资质、样品、验收，再谈钱 |
| 涉及三方（贸易商/终端） | 不越过贸易商直接承诺终端 | 渠道秩序一旦破坏，长期订单全丢 |

## 六、审计符号

| 符号 | 含义 | 判定要求 |
|---|---|---|
| `✔` | 保留 | 文本中能找到对应表述，且未变形 |
| `◐` | 弱化 / 改写 | 能找到，但强度、主语或口径被调整（需在说明列写清怎么改的） |
| `—` | 刻意未提 | 该条不进正文是判断结果，必须在说明列写理由 |
| `▲` | 已删除 | 该条原话存在但被移除；必须能验证正文里确实没有 |
