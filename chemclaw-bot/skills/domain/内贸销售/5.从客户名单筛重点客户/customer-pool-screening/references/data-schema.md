  "经营状态": "存续|在业|注销|吊销|迁出|未核实",

## 2. pool.json（汇总契约，build_deliverables.py 的输入）

```json
{
  "meta": {
    "product": "纯碱（碳酸钠）",
    "region": "华东（鲁/苏/浙/皖/沪/闽/赣）",
    "preference": "真实工厂优先",
    "generated": "2026-02-11",
    "input_files": ["客户名单.csv", "现有客户池.csv"],
    "scoring": {
      "weights": {"产品匹配": 40, "工厂真实性": 25, "规模": 20, "地区": 15},
      "tiers": {"P0": 80, "P1": 60, "P2": 40}
    },
    "demand_logic": [
      {"行业": "浮法玻璃", "工序": "熔窑配合料", "作用": "主要助熔原料", "强度": "5星", "要点": "吨玻璃耗纯碱约110-150kg"}
    ],
    "notes": "数据边界声明（公开检索、需官方终核的字段等）"
  },
  "pool": [{
    "priority": "P0", "score": 95,
    "raw_name": "山东药玻", "std_name": "山东省药用玻璃股份有限公司",
    "uscc": "91370000168611868Q（财经F10单一来源，建议终核）", "status": "存续",
    "province": "山东", "region_full": "山东淄博(沂源)", "entity_type": "生产企业",
    "products": "药用玻璃模制瓶/管制瓶+胶塞铝盖",
    "demand_relation": "强|弱（间接）|弱（渠道）", "demand_logic": "一句话：哪个工序、为什么买、量级",
    "s_match": 38, "s_factory": 24, "s_scale": 18, "s_region": 15,
    "evidence": ["URL"],
    "confidence": "高|中|低", "dedup": "无|与现有池A级命中", "next_action": "下一步动作建议"
  }],
  "ambiguity": [{"raw_name": "", "candidates": "候选主体及辨识要点", "user_decision": "用户选择", "outcome": "处理结果"}],
  "not_found": [{"raw_name": "", "hints": "名单线索", "conclusion": "检索结论（含置信度）", "next_suggestion": "去向建议/相近名"}],
  "excluded": [{"raw_name": "", "std_name": "", "category": "同行自产|需求不相关|主体消亡|排重命中", "reason": "依据", "evidence": "URL或说明"}],
  "existing_pool": [{"name": "", "grade": "A级", "status": "已成交", "note": ""}]
}
```

校验规则（脚本会强制）：`meta`、`pool` 必填；pool 每行必有 `std_name/score/entity_type/demand_relation`；
四个分项得分之和应等于 score（不等则脚本按分项重算并警告）；priority 可省略（脚本按 tiers 重算）。

## 3. Excel 交付（6 表，脚本固定生成）

| 表 | 内容 |
|---|---|
| 说明与方法 | meta 全量：产品/区域/流程/评分口径/需求逻辑表/证据通道/数据边界 |
| 重点客户池(排序后) | pool 按 score 降序；19 列；首行自动筛选；优先级列色标（P0绿/P1黄/P2灰）；冻结窗格 |
| 名称歧义-确认记录 | ambiguity：候选主体、用户选择、处理结果 |
| 未找到 | not_found：结论 + 去向建议 |
| 排除企业及原因 | excluded：类别 + 依据 + 证据，类别列红色底 |
| 现有客户池(输入) | existing_pool 原样留档 |

## 4. HTML 交付（单文件、零依赖、可双击打开）

- 数据以 `const DATA = {...}` 内嵌（`</` 转义防注入）
- 五个页签：客户池 / 排除企业 / 歧义确认 / 未找到 / 说明
- 客户池页：关键词搜索 + 优先级/省份/企业类型/需求关系/置信度下拉，**改条件即重渲染**；
  点表头排序；行首勾选，底栏显示已选数量，支持「导出选中 CSV / 导出全部 CSV / 复制名单」
  （CSV 带 BOM，Excel 直开不乱码）
- 顶部信息条：产品、区域、评分权重、需求逻辑表、生成日期
