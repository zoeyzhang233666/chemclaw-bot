# 证据通道与检索纪律

## 通道优先级（每级只试一次，失败换下一级）

| 级别 | 通道 | 强度 | 用法 |
|---|---|---|---|
| A | 巨潮资讯公告全文检索 | 最强：年报/募集书/评级报告正文常载统一社会信用代码 | `http://www.cninfo.com.cn/new/fulltextSearch?keyword={企业名或代码}`，打开公告 PDF 原文取数 |
| A2 | 沪深交易所披露 | 强：债券受托管理报告、问询回复常含 USCC 与注册资本 | 上交所 `http://www.sse.com.cn/disclosure/`；深交所 `http://www.szse.cn/disclosure/` |
| B | 企业官网直连 | 强：确认主体存在、业务板块、基地分布 | 官网"关于我们/成员企业/大事记"页 |
| C | 财经站 F10 资料页 | 中：工商登记栏常含 USCC、注册资本、员工数 | 搜狐 `https://q.stock.sohu.com/cn/{6位代码}/gsjj.shtml`；东财 `https://emweb.securities.eastmoney.com/pc_hsf10/pages/index.html?type=web&code={SH|SZ}{6位}`；同花顺 `http://basic.10jqka.com.cn/{6位代码}/` |
| D | 百科/政府站/行业媒体 | 弱：兜底与沿革线索 | 百科词条、地方政府新闻页（产能/员工口径）、财经媒体报道（重组/更名） |

## 检索 query 模板

- `"{标准化企业名称}" 统一社会信用代码`
- `"{简称}" site:cninfo.com.cn`（换用引擎自带 site 语法）
- `"{全称}" 年度报告 注册资本`
- `"{简称}"{地区} 工商`（区分同名企业时加地区）

## 壳页警示

爱企查/企查查/天眼查的详情页多为 JS 壳页，直接抓取常失败或失真。
允许**通过搜索引擎快照引用其字段**作为第二来源，但不作为唯一依据；
USCC 需要两个独立来源一致才可给"高"置信度，单一来源标"需终核"。

## 统一社会信用代码自检（GB 32100-2015）

- 18 位；字符集为 `0-9` 与 `A-H J-N P-R T-W X Y`（**不含 I、O、S、V、Z**）。出现禁用字符 = 必错，丢弃该来源。
- 大陆企业法人多为 `91` 开头（工商）；`93` 农民专合社等。首位不对就该起疑。
- 同一主体两个来源冲突 → 写"未核实"并降置信度，**绝不合成**。

## 名称标准化规则

1. 归一化键：去空格、全半角统一、去括注（`(集团)`、`（曾用名…）`），用于模糊比对。
2. 简称→全称靠「地区线索 + 行业语感 + 备选主体」三件套，**不准只凭字面硬配**。
3. 注意曾用名链（如 原安徽华光集团→安徽华光光电材料科技集团→中建材凯盛矿产资源集团）与母/子公司分工（生产主体 vs 上市主体）。
4. 查无存续主体时：如实写"未找到"，可附相近名与历史沿革线索，**禁止默认替换**。

## 负面结论的处理

"未找到"也是有效结论，但要写清检索范围（用了哪些通道）与置信度；
能给出相近名（疑似口误对象）或承接主体（改制沿革）就写进"去向建议"，供用户回核原始档案。
