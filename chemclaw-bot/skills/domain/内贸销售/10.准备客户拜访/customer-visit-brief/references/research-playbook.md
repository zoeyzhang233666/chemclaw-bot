# 取证手册 · 化工品通用

> 原则：**公开信息给来源、推断标注待验证、客户说的话只认上传记录。**
> "近 6–12 个月"以生成日为锚点回溯；所有日期为数据日期或发布日期，不是检索日期。

## 1. 来源优先级（同一事实取最高级）

| 级 | 来源 | 用于 |
|---|---|---|
| P0 | 用户上传的聊天/邮件/纪要/报价单 | 第⑤节；现场基线 |
| P1 | 交易所公告（年报/半年报/募集说明书/问询回复） | 产能、基地、业绩、在建项目 |
| P2 | 评级报告（中诚信/联合等）、招股书 | 产销、行业日熔量/开工率、风险提示 |
| P3 | 政府与园区公示（项目备案/环评/观摩/招标中标公示） | 投产、点火、扩产、招标 |
| P4 | 券商研报、行业资讯（隆众/卓创/百川/生意社/Mysteel/SMM） | 产能口径、价格、库存、开工 |
| P5 | 公司官网/官微、财经媒体报道 | 地位、市占、动态（口径冲突时并列标注） |

同一事实两个口径冲突（如市占率官网 30% vs 券商 21%）→ **并列标注，不裁决**。

## 2. 检索模板（把 ⟨⟩ 替换掉即可）

- 客户基本面：`⟨企业⟩ 年报 产能 基地` ｜ `⟨企业⟩ 半年度报告 营收 净利润`
- 产能事件：`⟨企业⟩ 点火 冷修 投产 窑炉/产线 ⟨年份⟩` ｜ `⟨地区⟩ ⟨企业⟩ 项目 投产 环评 备案`
- 商务事件：`⟨企业⟩ 招标 中标 ⟨我方产品⟩` ｜ `⟨企业⟩ 评级报告 ⟨年份⟩`
- 行情-我方产品：`⟨产品⟩ 价格 ⟨年月⟩ 出厂价/送到价 ⟨卓创|生意社|Mysteel⟩`
- 行情-原料：`⟨产品⟩ 原料 成本 ⟨原盐|煤炭|电力|矿产⟩ 价格 ⟨年月⟩`
- 客户景气：`⟨客户行业⟩ 开工 库存 价格 ⟨年月⟩`
- 适配性：`⟨产品⟩ 用途 ⟨客户行业⟩ 单耗 配比` ｜ `⟨客户行业⟩ 配方 原料 要求`

每个研究面 2–4 条查询即可，**追来源而不是追条数**。

## 3. 研究面 A · 客户是什么（画像六维）

主营与地位 / 生产基地 / 公开产能（注明口径与截止日）/ 产业链位置（上游是谁、下游是谁、原料连续性敏感度）/ 规模（上市与否、营收、员工——取得到哪项写哪项）/ 采购特征（连续生产则"刚需连续到货"）。

## 4. 研究面 B · 为什么适配（化工品族适配表）

| 产品族 | 用点怎么找 | 规格红线看什么 | 单耗口径 |
|---|---|---|---|
| 无机化工（纯碱/烧碱/硅系/磷系） | 配方组分、反应物/助剂身份（助熔、中和、洗涤、脱硫） | 主含量、杂质（Fe/Cl/硫酸盐）、粒度/堆密度、级别（工业/食品） | 配方占比或行业经验单耗，标"经验值" |
| 聚合物/树脂（PP/PE/环氧/PU） | 加工环节与改性需求 | 牌号、熔指/粘度、VOC、认证（FDA/REACH） | 单件克重或配比 |
| 精细中间体/医药农化原料 | 合成路线中的哪一步 | 纯度/异构体、杂质谱、GMP/审计 | 摩尔比/收率折算 |
| 助剂/水处理/涂料油墨 | 添加工序与添加量 | 有效物含量、相容性、稳定性 | 添加比例 ppm–% |
| 化肥/农化 | 养分/原药配伍 | 养分含量、剂型、登记证 | 养分折纯 |

写"可讲卖点"时对准：**规格稳定性、供应连续性（多基地/物流）、到厂综合成本、账期、认证与响应速度**。写"切入时机"对准：新产线/新基地、现有供应商痛点（待验证）、客户降本与锁价窗口。

## 5. 研究面 C · 大事记（近 6–12 个月，≥5 条）

类型标签：点火 / 冷修 / 投产 / 中标 / 业绩 / 评级 / 行业。每条必须回答：**这改变了什么采购变量？**（需求量、规格、准入窗口、付款意愿、紧迫度）

## 6. 研究面 D · 行情（我方产品 + 原料 + 客户景气）

- 我方产品：至少 1 个客户所在区域的主流报价（区间价写区间）。
- 原料：挑 1–2 个成本占比最大的（纯碱→原盐/煤炭；树脂→单体；助剂→活性物原料）。
- 客户产品：其售价/库存/开工的变化，决定它的付款意愿与采购节奏。
- 每行：价格 + 单位 + 数据日期 + 来源（±URL）+ 方向（▼下跌/▲上涨/→低位徘徊）。
- 末尾一段"谈判含义"：把行情翻译成现场打法（压价市→打综合成本；回暖市→打锁量锁价）。

## 7. 研究面 E · 历史沟通（第⑤节）

- 只从上传记录提取"已确认 / 未解决"，每条注明依据文件。
- 无记录 → 空态文案 + 首访基线清单（在供供应商与份额 / 招标周期 / 规格红线 / 账期 / 物流验收 / 准入流程）。

## 8. 研究面 F · 问题清单（每版 5–8 问）

生成逻辑：先由 A–D 推导"本次必须搞清的变量"，再按角色分派——
采购版（量、机制、价格、物流、准入）、技术版（规格、批次、异常、送样、切换成本）、老板版（布局、决策链、合作模式、供应安全、ESG）。
每问附一句"为什么问"（对应哪个研究面/哪个待验证项）。
