# 输出规范 · Excel 8 表 + HTML 一页卡

## A. Excel（scripts/build_visit_workbook.py 自动生成）

文件名：`拜访背景卡_<客户>_<产品>_<日期>.xlsx`。主题色：深蓝 `0D4A7A`（标题/主色）、浅蓝 `D9E7F5`（表头）、斑马纹 `F4F8FC`；微软雅黑；细边框 `C9D4DE`；全表自动换行、顶端对齐；宽表横向打印+按宽缩放。

| # | 工作表 | 列结构 | 特性 |
|---|---|---|---|
| 1 | 使用说明 | 条目/说明 | 拜访前中后用法 + 数据政策 |

## B. HTML 单文件一页卡

零外链资源、内联 CSS/JS、离线可开、`window.print()` 适配 A4。文件名与 Excel 同主名。

### 设计令牌

主色 `#0d4a7a`→`#0e6ba8`→`#0e8a8a` 渐变头；语义色：红=`#b3352c`(风险/下跌)、绿=`#1a7f4b`(机会/上涨)、琥珀=`#b45309`(待验证/低位)；正文 13.5px，行高 1.55；卡片圆角 12px、细边框 `#dde5ec`。

### 区块顺序（自上而下）

1. **头部**：面包屑（工具名·技能名）→ H1 客户名 → 定位与对象副标 → 徽章（我方产品/本次目的/建议时长）→ meta 行（生成日期/数据截至/历史沟通状态）。
2. **KPI 看板**：3–6 格（大数字 + 单位 + 口径标签 + 方向箭头与红绿色）。
3. **① 客户实际做什么**：六行两列表（主营/地位/基地/产能/产业链/规模），行内来源 `<a>`。
4. **版本标签页**（采购🤝/技术🔬/老板💼）：每版 = 目标横幅 + 两栏（左：卖点讲法与风险机会；右：⑥问题清单，checkbox 可勾选，每问附"为什么问"小字）。
5. **③ 大事记**：竖排时间轴（圆点 + 日期加粗 + 类型标签 + 事件 + 意义小字来源链接）。
6. **④ 行情**：表（品种/规格/价格/变化/来源日期）+ 方向标签（▼红 ▲绿 →琥珀）+ 琥珀色"谈判含义"框。
7. **⑤ 历史沟通**：无记录 → 虚线空态框（明示"不臆测"+拖入提示）+ 基线采集 chips；有记录 → 已确认/未解决两列。
8. **来源**：`<details>` 折叠两组（客户与行业 / 行情数据），编号列表 + 链接。
9. **页脚**：工具署名 + 三条纪律声明（公开信息/不虚构/留空原则）+ 生成日期。
10. **右下打印按钮**：`onclick="window.print()"`。

### JS（≤10 行）

标签页切换：`.tab[data-v]` 点击 → 同步 `.active` 到 tab 与 `#v-<v>` 面板。无其他脚本依赖。

### 手写 HTML 的最低验收

单文件可离线打开；三标签可切换；所有来源为 `<a href>` 真链接；打印预览无横向溢出；⑤节状态与 `meta.history_note` 一致。
