## 这个样例示范的五个要点

1. **第⑤节留空纪律**：本次没有上传任何历史沟通记录，台账只有一个带"（示例）"前缀的格式演示行——绝不替客户编造"上次说过什么"。
2. **每个价格带日期+来源**：行情 8 行全部有"数据日期 + 来源 + 链接"，连基期对比（1月华北送到价 1300–1350）都给了出处，才敢写"累计跌10%+"。
3. **三级标注**：公开信息带来源；"单耗0.18–0.2吨/吨"标为行业经验值；"对产品核心诉求"整行标"推断·待验证"，现场追问而不是当事实讲。
4. **大事记必答"改变了什么采购变量"**：南通点火=新增碱耗+准入窗口；2026H1首亏=现金流优先，谈账期比谈单价有效；09-02冷修信号=现场必须核当前在产窑炉数。
5. **三版本共用底稿**：采购版7问/技术版7问/老板版6问，各配"为什么问"，均回指研究面的待验证项。

## 换一个化工品怎么复用

保持六节结构与 8 表不变，替换的是配置：产品名与规格（meta.our_product）、用点与单耗（profile 后两行）、行情品种（market：我方产品+该产品的主要原料+客户产品）、问题清单里的规格术语（如树脂版会问熔指/牌号而非堆积密度/粒度）。参考 `references/research-playbook.md` §4 的产品族适配表。
