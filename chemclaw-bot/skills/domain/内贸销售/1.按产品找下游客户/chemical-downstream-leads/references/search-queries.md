# 检索式设计：从产品名到一条能点开的吨位证据

> 这一份是 skill 的手艺核心。目标：**用最少的查询，命中写着吨位的原始文件。**

## 一、四个词槽

任何一条有效检索式，都是这四个槽的组合：

```
<原料词>  ×  <工序/设备词>  ×  <文件词>  ×  <地域词>
```

| 词槽 | 怎么造 | 通用示例 | SBS 示例 |
|---|---|---|---|
| 原料词 | 本名 / 别名 / 牌号 / 上游形态 / 英文缩写 | 产品中文名、CAS 名、商品名 | `SBS`、`苯乙烯-丁二烯-苯乙烯嵌段共聚物`、`热塑性弹性体`、`充油料` |
| 工序/设备词 | **从 lane 的"用料逻辑"里抠** | 混合/造粒/涂布/复配/浸渍/挤出 | `胶体磨`、`发育罐`、`密炼机`、`双螺杆造粒`、`熔融共混`、`充油` |
| 文件词 | 哪种文件会写吨位 | 环评/公示/验收/年报/可研/招标 | `环境影响报告表`、`受理公示`、`拟审批`、`年用量`、`t/a` |
| 地域词 | 省/市/县，**写全称** | `潍坊市` 而非「潍坊」 | `晋江市`、`寿光市`、`海安市` |

**只要四个槽都填上，命中率通常比"产品名 + 行业词"高一个量级。**

## 二、五类高命中组合（按证据强度排序）

| # | 组合 | 为什么有效 | 典型产出 |
|---|---|---|---|
| 1 | `<产品> 环评 年用量 <地域>` | 环评报告表的**原辅材料表**逐项列年用量 | `SBS 1075 t/a`、`环烷油 323 t/a` |
| 2 | `<工序设备词> 环评公示 <地域>` | **项目标题里往往没有产品名**，只有工序词 | `年产30万吨改性沥青、1000吨彩色沥青项目` |
| 3 | `<产品> 改性剂/添加剂 环评 <地域>` | 产品以助剂身份出现 | `以沥青、SBS改性剂、铁系颜料为原料` |
| 4 | `<公司名> 环评公示` / `<公司名> 年报 产能` | 定点核实已知企业 | 批复文号、产能、生产线数量 |
| 5 | `<产品> 招股书/可研/评级报告` | 上市公司披露单厂产能与行业结构 | `防水卷材年产能 2.9 亿㎡` |

### 2.1 一个反直觉但极其重要的点

**不要用产品名去筛政府公示的列表页。** 列表页只有项目名，比如：
`××有限公司年产1000万平方米SBS改性沥青防水卷材项目` —— 这里出现了产品名纯属运气；
更多时候是 `××有限公司改性沥青生产线技改项目`，产品名根本不出现。

**正确做法：用行业词 + 工序词筛列表页**（`防水卷材`、`改性沥青`、`制鞋`、`鞋底`、`热熔胶`、`电缆料`、`无纺布`…），
筛出可疑项目后再进详情页或下载 PDF 附件确认。

## 三、短缩写产品的消歧

短缩写（`SBS`/`PVC`/`PA`/`CMC`/`TPU`）会被同名噪音淹没。实测教训：搜 `SBS 改性沥青` 可能返回韩国电视台、
澳洲电视台、某商学院、某拉链品牌——**因为匹配的是"首词"而不是语义**。

**对策（按优先级）：**

1. **用全化学名**：`苯乙烯-丁二烯-苯乙烯嵌段共聚物`。
2. **中文名 + 缩写双写**：`热塑性弹性体 SBS`。
3. **加行业共现词**（下游品名）：`SBS 防水卷材`、`SBS 鞋底料`。
4. **地名写全称**：`晋江市`（写「晋江」会撞上同名小说站）。
5. **限定文件类型/站点类型**：`环评`、`公示`、`t/a`、`site:gov.cn`。
6. **换渠道**。

> **判据：同一查询返回的结果与行业无关时，不要反复换措辞试同一个引擎——换渠道。**
> 一个搜索引擎失效，不代表这个信息不存在；它只是不在那个索引里。

## 四、渠道优先级

| 级别 | 渠道 | 能拿到什么 | 能不能当证据 |
|---|---|---|---|
| **A** | 政府环评/审批/验收公示及其 PDF 附件；交易所公告全文检索；企业官网；行业协会 | 吨位、工艺、产能、原料表 | ✅ 直接引用 |
| **B** | 通用搜索引擎 | URL 线索 | ❌ 只用于发现 |
| **C** | 招标网、文库（豆丁/道客/人人文库）、百科、聚合站 | 转载的公示、报告预览 | ⚠️ 兜底；写进来源须注明它是什么，且优先回找原文 |

**两个常见陷阱：**

- **文库站只放封面页**（付费墙/JS 门禁）：能搜到标题、点进去读不到原辅材料表。→ 回找政府原始附件。
- **聚合站转载页**可能比政府原页更"好抓"，但**证据强度更低**；写进来源要写清"转载自××"。

## 五、两条不依赖搜索引擎的通路（务必掌握）

搜索引擎不可靠时，靠这两条照样能铺满地图。

### 通路 1：政务门户栏目直爬

```
省级厅首页
  → 抽取「地市局域名」列表（页面里的 *.gov.cn 主机名）
  → 逐个抓地市局首页，抽取含「环评/公示/审批/受理」的栏目链接
  → 抓「受理情况 / 拟审批公示」列表页（通常按 YYYYMM 归档）
  → 用「行业词 + 工序词」筛条目
  → 下载该条目的 PDF 附件
  → 抽取 PDF 文本 → 检索「<产品>」与「年用量 / t/a」
```

**要点：**

- 政务站多为**服务端渲染的静态 HTML**，比商业搜索引擎好抓得多；PDF 附件常常是**直链**。
- 栏目分页常是**表单提交**（隐藏字段形如 `pageModel.numberNo`、`pageNo`）而不是 `?page=2`；找不到分页就翻归档目录（`/202609/`、`/art/2026/...`）。
- 政务站普遍**限流**（首次 200、随后 403）：请求之间留间隔，别并发轰炸。
- 有些省市的栏目是 **JS 异步渲染**，静态抓取只能拿到空壳 → 换入口（省厅转发页、区县页、`行政审批局` 而非 `生态环境局`），或换省市。

### 通路 2：许可/名录类平台枚举企业池

全国排污许可、生产许可、行业准入、重点企业名录这类平台，可以**按「行业类别」筛出企业名单**（字段通常有：省 / 地市 / 单位名称 / 行业类别 / 地址）。

**它不是关键词检索器，是"行业枚举器"** —— 正确用法：

```
按行业类别枚举（如"防水建筑材料制造""制鞋业""电线电缆制造"）
  → 得到一批具名企业
  → 回到通路 1 或企业官网，逐家核实其是否真的用本产品、用量多少
```

这条通路特别适合**薄板块补量**：先解决"这个行业在华东有哪些厂"，再解决"哪家用这个料"。

## 六、从 PDF 到吨位：标准动作

1. 找到公示条目 → 定位**附件 PDF**（通常是 `P020xxxxx.pdf`、`W020xxxxx.pdf`、`doc_xxxx.html` 里的附件）。
2. 下载 PDF（不要指望网页正文里有原料表，**吨位几乎总在附件里**）。
3. **抽取文本**。注意：PDF 表格里的文字常被拆成 `S BS`、`1 0 7 5 t / a`。所以检索必须用**容错正则**：
   - `S\s*B\s*S`
   - `年\s*用\s*量`
   - `t\s*/\s*a`
   用普通字符串搜会漏掉一大半内容。
4. 命中后抄下**原文数字**，把 PDF 的 **URL** 写进来源。
5. 找不到附件或附件加密 → 退回用公示页正文的「项目概况」段（通常也有产能），置信度记「中」。

## 七、定点核实：拿到公司名之后

1. **`<公司名> 环评`**：拿到批复/受理条目 → 进详情页 → 下 PDF。
2. **`<公司名> 官网`**：找产品页/产能页；**官网自述**可以作为证据（写清是"公司官网自述"）。
3. **`<公司名> 年报/招股书`**：上市公司最硬的公开数据（产能、产量、募投项目）。
4. **`<公司名> 企查查/爱企查`**：只用于核对工商主体与存续状态，**不作为用料的证据**。

## 八、记录规范（让下一个产品能复用）

每格任务跑完，把这三点写回任务目录的 `query_log.md`：

```markdown
## Lane 02 · 建筑防水 · 山东
- 有效查询：`SBS 改性沥青防水卷材 环评 年用量 山东`、`防水卷材 环评 公示 寿光市`
- 命中站点：sthjj.weifang.gov.cn（潍坊市生态环境局）、chiping.gov.cn（茌平区）
- 失效查询：`SBS 防水卷材`（被同名噪音淹没）、`防水卷材 浙江`（返回文库封面页）
- 结论：山东可爬；浙江门户为 JS 渲染，需换入口
```

**这份日志就是下一个项目的加速器**，也是交付报告里「未覆盖缺口」的原料。

## 九、什么时候该停（"这个 lane 真的没公开证据"）

出现下面**三条以上**，就可以判定该格"公开证据为零"并在缺口里写明，而不是继续耗：

- [ ] 换过 ≥3 个渠道（搜索引擎 / 政务门户 / 企业官网 / 名录平台）
- [ ] 换过 ≥2 组词槽组合（产品名 + 文件词；工序词 + 文件词）
- [ ] 该地区的门户栏目确认是 JS 渲染或需登录
- [ ] 搜到的同类项目全是**别的产品体系**（说明这个 lane 在该地区可能真不存在）
- [ ] 本地/已有资料里该地区没有该品类企业

**"零结果"是有价值的结果** —— 它告诉销售"这个省不用派人"。写进交付报告的「负结果」一节。
