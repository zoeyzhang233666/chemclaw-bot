# 证据分级与防伪

> 这一份解决：**一条线索凭什么算"高"？什么情况下必须降级或丢弃？**

## 一、七个字段与硬要求

| 字段 | 硬要求 | 反面例子 |
|---|---|---|
| 公司 | **完整工商名称**（含"有限公司/股份"等后缀） | 「××厂」「某防水公司」 |
| 细分行业 | 体现**工序**，不是行业大类 | 「建材」→ 应写「SBS 改性沥青防水卷材生产」 |
| 省市 | `省/市` 固定格式，**写全称** | 「华东」「江苏」（无市） |
| **需求点** | 落到**具体工序**：在哪个设备、什么条件、起什么作用、掺量多少 | 「用于生产防水卷材」（等于没说） |
| **规模线索** | **原文数字**（产能/产量/年用量/生产线数/营收） | 「规模较大」「行业领先」 |
| **来源** | **你实际打开过**的 URL | 凭印象拼的域名 |
| 置信度 | 按下面第二节的判据 | 一律写「高」 |

### 需求点的好坏对照

- ❌ `以SBS为原料生产防水卷材`
- ✅ `以SBS为改性剂（掺量约4%~5%）与基质沥青在胶体磨中剪切、发育罐溶胀发育后浸渍聚酯胎基，生产I-C/I-D级弹性体改性沥青防水卷材`
- ✅（无原文佐证时）`按行业工艺推导：SBS 与白油在密炼机充油后经双螺杆造粒制 TPR 粒料，再注塑鞋底`

## 二、置信度判据（决策树）

```
来源打开后，正文/PDF 里有没有出现「产品名或等价物」？
├─ 有 ──→ 有没有跟一个具体数字？
│         ├─ 有 ──→ 高
│         └─ 无 ──→ 中（需求点写"按行业工艺推导"，规模写"未见公开数据"）
└─ 无 ──→ 主营与工序是否强匹配？
          ├─ 强匹配 ──→ 中（必须标注"按行业工艺推导"）
          └─ 弱 ────→ 低
```

补充规则：

- **"等价物"要认**：原文写「热塑性弹性体」而没写 `SBS`，只要语境是该产品，可算"有"；但要在需求点里说明。
- **来源不可点开**（只有索引号、只有单位名）→ 来源写清是什么，**置信度不得为"高"**。
- **抓不到** → 丢弃，不要降到"低"硬塞。

## 三、peer gate（同行剔除）

### 3.1 为什么要单独做

产这个产品的公司**看起来最像客户**——它们出现在同一批检索词里，有官网、有产能、有环评。
但它们买的是原料，不是你的产品。**一条同行线索混进表里，销售打过去就是给竞争对手报价。**

### 3.2 怎么建同行名单

1. 从第 1 步的行业文章里抄「主要生产企业」段（通常直接列名+产能）。
2. 从检索结果里反向识别：凡是标题形如「×××年产 X 万吨<产品>项目」的，基本都是**生产商**。
3. 名单写进任务书，让每个子代理都跑一次。
4. **交付报告里必须报出这份名单**（具名，不要写"若干"）。

> 例（某热塑性弹性体项目实际剔除）：中石化湖南石化（巴陵石化）、上海金山巴陵新材料、惠州李长荣橡胶、
> 福建古雷石化、海南巴陵化工、中国石油广西石油化工、宁波长鸿高分子、山东玉皇化工、辽宁北方戴纳索、
> 金海晨光，以及在做 SEBS/SBS 项目的新进入者。**新增产能公告 = 同行线索的富矿。**

### 3.3 还要写「板块专属排除规则」

同一个词在不同板块含义不同，必须逐板块写清"像但不是"：

| 板块 | 必须排除 | 理由 |
|---|---|---|
| 道路改性沥青 | 纯防水卷材厂 | 用同一个料，但没有道路改性装置 |
| 道路改性沥青 | 基质沥青炼厂 | 有沥青，没有改性工序 |
| 任何板块 | 纯贸易商/物流商/施工队 | 除非自有生产装置 |
| 任何板块 | 事业单位（公路管理局等） | 无自有生产实体 |
| 卫生材料 | 氢化/加氢牌号用户（如 SEBS） | 与本体牌号不是同一个产品，不能混算 |
| 热熔胶 | PUR、水性丙烯酸体系 | 配方里没有该产品 |

## 四、诚实标注（宁可写清楚，不要伪装）

来源不理想时，**写清楚 + 保留公司信息**，比换一个"看起来漂亮"的假 URL 好一百倍：

| 情况 | 来源字段怎么写 |
|---|---|
| 只有栏目页/列表页 | `××市生态环境局「拟审批公示」栏目 <栏目URL>（该栏目只渲染最新 10 条，条目直链无法固定取得；公示原文与所附报告表已抓取存档，可凭索引号 1137…5425480 检索复核）` |
| 只有站内检索页 | `巨潮资讯公告全文检索页 <URL>（检索页非公告原文，公告 PDF 直链未取得）` |
| 聚合站转载 | `<聚合站URL>（转载自××市生态环境局受理公示）` |
| 文库预览 | `<文库URL>（预览仅封面页，原辅材料表未取得）` |
| 单位名 + 文号 | `××市生态环境局《关于××公司…拟审批公示》，索引号 …（原文已抓取存档）` |

**这些条目在抽检时会被标 ⚠，这是正常且正确的**——读者一眼就知道该条证据强度弱在哪。

## 五、六个必须警惕的造假陷阱

1. **把搜索结果当证据。** 搜索页是"发现工具"，正文才是证据。
2. **文库/道客/豆丁的环评预览。** 标题很诱人（`年产1200万平方米SBS改性沥青防水卷材项目环评报告书`），点进去只有封面。→ 回找政府原始附件。
3. **"公司存在"≠"用这个产品"。** 官网证明它做防水卷材，不等于它用你的牌号。→ 必须有原料/工艺证据，否则记"中"。
4. **同集团不同主体张冠李戴。** 实测踩过：某集团"9000 万平方米卷材"数字属于其**山东寿光基地**，不能安到**江苏泰州**主体头上。→ 数字必须与**主体**对应，跨主体引用要在文中说明。
5. **单位与口径误读。** `万吨/年` 产能 ≠ `t/a` 用量；`万平方米/年` 卷材 ≠ 吨位。→ 抄原文，不要换算（除非明确写清换算依据）。
6. **把"计划/拟建"当"已投产"。** 公示分受理、拟审批、批复、验收四阶段，**只有验收/批复才是既成事实**；受理阶段的项目可能没建成。→ 在规模线索里注明阶段。

## 六、用量强度标定

见 [`industry-map.md`](industry-map.md) 第七节。要点：**按单一工厂年用量标定，口径必须写进交付表的说明页。**

## 七、优先级公式

```
置信度分：高 = 3，中 = 2，低 = 0
优先级分 = 用量强度(星级数) × 2 + 置信度分
  ≥ 11 → 高
  ≥ 9  → 中
  其余 → 低
```

含义：**"用量大且有证据"一定进高**（5★+高=13、5★+中=12、4★+高=11）；
4★但证据一般（10）或 3★但证据很强（9）算中；证据弱或用量小算低。

**优先级只用于排外呼顺序，不代表客户价值的绝对高低** —— 这句话要写进说明页。

## 八、交付前的抽样复核（必做）

从"高"置信度条目里**随机抽 5 条**，逐条回访来源，确认三件事：

1. 页面能打开；
2. 页面上**确实出现**该公司名；
3. 页面上**确实出现**你抄进「规模线索」的那个数字。

任何一条对不上 → 整批"高"都重新审。
