# 六道闸门与优先级（可实例化规则）

> 每道闸门都能**否决**一条线索。它们是交付物可信度的来源，不是可选步骤。
> **执行顺序固定：R2 → R1 → R4 → R3 → R5 → R6。** R2 必须先于 R1 —— 否则一条「采购烧碱」会被同行名单误判成 R1 而掩盖真实原因。
> 每道闸门三件事：**判定逻辑 / 命中后怎么处理 / 换一个化工品时怎么改**。以下正文与产品无关，纯碱只作举例。

---

## R1 同行闸门（最重要）

**判定逻辑**（三步，缺一不可）：

1. **名单命中**：主体是否在 [`product-profiling.md`](product-profiling.md) 的同行名单里？名单每一项都必须有原文依据（年报/公告自述其生产本产品）。
2. **路线兜底**（名单没覆盖时用）：正文里出现「本产品 + 装置/项目/产能/生产线」**且**伴随「投产/试车/试生产/建设/技改/扩产/达产/新建」→ 判为**同行新增供给**（注意：是自建产能，不是采购）。
3. **双向陷阱核验**（**名字不是证据**）：无论名单命中还是关键词命中，都要回到最近一期**年报的「业务分部/主营业务」章节**确认它是**卖**本产品还是**买**本产品。两个方向相反的陷阱都必须防：
   - **名字像同行、实际是买方 → 保留为客户**。例：振华股份（603067，湖北振华化学）是铬盐企业，公告自述纯碱为主要成本项、披露纯碱采购，是**买方**，绝不能按同行剔除。
   - **名字像客户、实际是同行 → 剔除**。例：金晶科技（600586，山东金晶）名字像浮法/超白玻璃客户，但 2025 年年度报告「（二）纯碱业务」明确载明**纯碱业务运营主体为控股子公司山东海天生物化工有限公司**，是垂直一体化纯碱生产商，必须按同行剔除。

**命中后怎么处理**：

- 同行「扩产/技改/投产/新建产能」→ **剔除**，进工作表「6 被剔除条目」，剔除原因写清「R1 同行：新增供给，非需求」。
- 主体是同行、分组是「明确采购/招标」、**标的恰好是本产品** → **仍剔除**（同行买本产品是做贸易/加工，不是我的客户）；只有标的明确是**别的产品**时才可能保留。
- **反向用法（把 R1 用成正向信号）**：同行**检修/停产/降负荷/停车/事故** ＝ 区域供给收紧 ＝ 我方补货窗口 → 归入「**其他潜在需求信号**」，并在 `与我产品的关系` 开头标 `[利好]`，正文写明「竞争对手减产、区域补货窗口」。同行**稳产/扩产/新增产能/期货套保/行业库存高** → 标 `[利空]` 或 `[中性]`。这类条目**不进「明确采购/招标」组**，而是**带方向标注进第三组**，在 Excel/HTML 里单独落在「同行动态与市场信号」分区（实现如此：带方向标注的同行信号一律保留，只标方向不删除——删掉等于丢情报；无方向标注的同行自身动态才剔除）。
- **关键限定**：判同行要同时满足「**主体是同行** 且 **事件标的是本产品**」。一条公告可以既含利空又含商机，必须按产品拆条 —— 例：世龙实业一份《投建年产 10 万吨过碳酸钠及 3 万吨纯碱》的公告，**3 万吨纯碱**部分＝同行新增供给，剔除；**10 万吨过碳酸钠**部分＝本产品下游新增需求，保留。若只按公司名判同行，会把它的过碳酸钠需求错杀。

**换产品时怎么改**：① 重建同行名单，**每个名字附「凭什么说它是同行」的原文依据**；② 重写「工艺路线关键词」（写该产品自己的工艺路线词，不要写行业名）；③ 重列本产品的双向陷阱候选 —— 对每个「名字像下游」或「名字像上游」的大公司，去翻它最近一期年报的业务分部。**这张名单必须逐个产品重建**，纯碱的名单对新化工品零价值。

**工程实现（可复制形态）**：`PEERS` 名单 ＋ `is_peer and 事件标的含本产品` 才判同行；命中同行且事件为「检修/停产/减产/降负荷/停车/事故」→ 打 `信号方向=利好` 并放进第三组；无法定方向的同行自身动态 → 剔除。

## R2 产品错配闸门

**判定逻辑**：标的**不是**本产品 —— 哪怕名字只差一两字、哪怕用途相近。四类：

1. **近名不同物**：分子式/用途相近的另一个产品（纯碱版最常误配的是招标里的「烧碱/氢氧化钠/液碱/片碱」）。
2. **金融/仓储事项**：本产品的期货、交割厂库、套期保值、价格指数 → 是金融与行情，不是产品需求。
3. **设备/包装/物流/工程**：本产品的设备、包装、运输、安装工程采购 → 不是产品需求。
4. **成品/原料倒置**：买「**用本产品做出来的中间体或成品**」的厂（例：买硅酸钠/泡花碱成品的厂、买过碳酸钠成品的厂）买的是成品，**不构成本产品需求**；反过来，**用本产品做原料去生产别的产品**才是需求。

**命中后怎么处理**：剔除并计数；若一条里本产品与其他产品并存 → **按产品拆条**（见 L4）。若判定困难，宁可保留 + 在 `与我产品的关系` 里注明「需核实其工艺路线是否使用本产品」，同时把置信度降为中/低。

**为什么必须先跑**：一条「电厂液碱采购公告」若先过 R1，会因主体不在同行名单而被保留；先过 R2 就会被干净地剔除并给出正确原因。

**换产品时怎么改**：这张清单**必须按产品重建**，做法见本文末「最容易被凑数的误配方向」。

---

## R3 地域闸门

**判定逻辑**：以第 1 步的**区域参数**（省/市清单）为准。`省市` 字段必须写**事件实际发生地**，不是注册地；集团客户要写到**基地/子公司所在地**。

**命中后怎么处理**：

- **区内** → 保留。
- **区外** → **一律保留，只标注「区外」并在表中灰置**，`与我产品的关系` 里写「区外，需评估运费」，让用户自己筛。
  > ⚠ **不要在阶段 1 就删区外条目**（本 skill 的实现如此：R3 只标注、不否决）。理由是删除会让用户
  > 无法判断「是没查到还是被过滤了」；灰置＋标注则信息无损。若确定要按运费敏感度硬筛，
  > 用工作表的「区域」列筛选，或给 config 加一条自定义闸门——但要在交付报告里写明这条规则。
  > 实践经验：区外条目里经常藏着「模式可复制到区内基地」的线索（例：某集团天津基地二线点火，
  > 价值在于其常熟基地的同款模式），一刀切删掉会丢掉这类情报。
- 特殊形态：事件地在区外、但价值在于**可复制到区内基地** → 保留，并在关系字段写明「由头可复制到哪个区内基地」。

**换产品时怎么改**：只改区域清单 ＋ **运费敏感度**。低值大宗品区外基本无意义（运费吃掉全部毛利，直接剔除）；高值小吨位/高毛利品区外可保留。运费敏感度要在建产品画像时定下来，写进报告头。

## R4 时间闸门

**判定逻辑**：以**发布日**是否落在 `WIN_START~WIN_END` 为主，以**截止日**为补充：

| 情形 | 处理 |
|---|---|
| 发布日在窗口内 | 保留 |
| 发布日早于窗口，但**截止日 ≥ 基准日**（仍在未来） | **保留**，`时效性=仍可参与` |
| 截止日 < 基准日 | `时效性=已过期`，**仍可入表**（作竞争情报/复盘），必须在时效性列标明，打分减分 |
| 生产变化类（复产/投产/点火/冷修完成）无截止日 | `时效性=仅作线索`；若公告明确写了达产/投产时间且晚于今天 → `仍可参与` |

**日期纪律**：`发布日` 取**原文链接路径里的日期**（公告类站点形如 `/finalpage/YYYY-MM-DD/`），**不要**用检索接口返回的时间戳换算值 —— 实测该时间戳是 UTC，比公告日**早一天**。发布日无法确认时不要猜，写实际能确认的日期或留空并降置信度。

**命中后怎么处理**：超窗且无未来截止日 → 剔除进「6 被剔除条目」，原因里写明发布日与窗口。生产变化类的历史条目若要保留作模式参考，必须在时效性里写明「仅作历史模式参考」，不能混进当期商机。

**换产品时怎么改**：只改 `WIN_START`/`WIN_END`/`TODAY`。**窗口长度与产品相关**：下游投资周期长、公告稀疏的产品用 90 天甚至 180 天；高频招标、价格波动快的产品用 30 天。任何异常为 0 的窗口结果先按 L3 重试再下结论。

## R5 相关性闸门

**判定逻辑**：`与我产品的关系` 必须同时写出 **用量逻辑 ＋ 量级估算**。

- ✅ 合格：「浮法玻璃日熔 600 t/d，冷修后复点火，年耗重质纯碱约 4 万吨，是其第一大原料」
- ❌ 不合格：「该公司属于玻璃行业，可能需要纯碱」（空话）
- ❌ 不合格：只写「化工企业」（无法判断用量）

量级估算必须写成「约 X 吨/年（**估算**）」并给出依据（吨耗系数 × 装置规模），系数取自 [`product-profiling.md`](product-profiling.md) 的吨耗系数表。装置规模没拿到时，写「装置规模未披露，量级待核实」并降置信度，**不许凭空写吨位**。

**命中后怎么处理**：写不出用量逻辑 → **不收**（剔除，或降为「未核实/低」进待核实表）。写完还要回头检查是否与 R1/R2 结论冲突（例如刚判定它是同行，却又写了它的采购需求 —— 必然有一处错）。

**换产品时怎么改**：判据措辞随产品变，但**结构固定**：`工序位置 → 单耗 → 装置规模 → 年需求吨位 → 为什么现在值得找我`。把这条结构写进 lane 契约，子代理自然不会写空话。

## R6 证据闸门

**判定逻辑**：`证据来源` 必须是一条**你真实抓取到内容**的 http(s) 链接（公告 PDF、政府公示页、交易平台公告页）。两个条件同时满足：① 链接可点；② **页面主体与「企业」字段一致**（域名与正文都对得上）。

**命中后怎么处理**：

- 满足 → 置信度按证据质量定（定义见下）。
- 抓不到 → `证据来源=未核实`、`置信度=低`，**单列到工作表「5 待核实（无原文链接）」**，不进正式商机池。
- **强制规则**：收口程序对任何没有 http 链接的条目，一律把置信度压成「低」并把来源改写为「未核实」—— 不依赖子代理自觉。
- **严禁编造 URL、编造公告标题、编造企业名。** 猜一个像样的域名比留空有害得多。
- **链接抽检**（收口第 5 件事）：随机抽 40–60 条，验证可达性 ＋ 主体一致性，落 `_qa_report.json`；**抽检不通过的标注而非删除**（在来源后追加「（⚠链接抽检：…）」），保留条目优于静默丢弃。

**换产品时怎么改**：规则不改，只改「什么算一手原文」——不同产品的官方来源不同（上市公司公告、政府环评、公共资源交易平台、行业协会、企业官网），在 [`channels.md`](channels.md) 里定级即可。

## 置信度分级（R6 的配套定义）

| 置信度 | 判定标准（满足其一即算） |
|---|---|
| **高** | 读到**一手官方原文正文**且有可点链接：能拿到吨数、金额、合同期、采购均价等**可复算硬数字**，或事件本身即硬事实（招标公告、点火公告、环评批准） |
| **中** | 有可点原文，但只有**定性表述**（如「本产品为主要原材料」）或只给项目产能、吨耗与年需求**要靠系数估算**；或项目主体/归属未在原文写明 |
| **低** | 只有标题或二手转述、**没有可点原文链接**（强制进「5 待核实」）；或项目与本产品的关联无法从原文证实 |

低置信度条目**保留是有价值的** —— 它告诉销售「这条要打电话问」。假的高置信度会让销售在电话里说错话。

## 优先级公式与 P1–P4 分档

```
优先级分 = 用量强度(1–5) × 置信度系数 ＋ 分组加成 ＋ 时效加成
  置信度系数：高=3  中=2  低=1
  分组加成：明确采购/招标 +6 ｜ 扩产或复产需求 0 ｜ 其他潜在需求信号 −2
  时效加成：仍可参与 +4 ｜ 仅作线索 0 ｜ 已过期 −2
分档：≥18 → P1 立即跟进 ｜ 13–17 → P2 本周跟进 ｜ 8–12 → P3 备选池 ｜ <8 → P4 仅存档
```

> 分组加成里「其他潜在需求信号 −2」是刻意的：让它排在同等证据强度的采购需求之后，
> 但不至于被挤出表（信息保留优先于排序）。阈值与各项加减都在 config 的 `priority` 段里，
> 换产品时可调。

**用量强度 1–5 怎么定**（由吨耗系数表映射，同一产品内可比、不跨产品比）：

| 强度 | 判据 |
|---|---|
| 5 | 直接投料，且本产品是该下游的**第一大原料**／单耗高（≥0.15 t/t 量级）／客户装置百万吨级 → 年需求万吨级以上 |
| 4 | 直接投料或主要原料，年需求千吨级 |
| 3 | 主原料之一但单耗低，或经中间体的间接用量，年需求千吨以下 |
| 2 | 配方级/辅助剂（助熔、沉淀剂、pH 调节），年需求百吨级 |
| 1 | 辅料微量；或仅体现为「价格敏感项」而无用量证据 |

**读法**：两个乘数决定「**值不值得打**」，两个加减项决定「**现在打还是以后打**」。所以 P1 一定是「用量大 ＋ 证据硬 ＋ 现在有采购动作」。

**复算校验**：每条卡片的分数必须能被上面的式子复算出来。例：用量强度 4 × 高(3) = 12，明确采购 +6 → 18，仍可参与 +4 → **22 分（P1）**；用量强度 1 × 高(3) = 3，明确采购 +6 → **9 分（P3）**。算不出来的分数说明字段被手改过。

## 三个分组的判别口诀

| 分组 | 定义 | `需求性质` |
|---|---|---|
| **明确采购/招标** | 有公开采购动作：招标公告、询价、竞争性磋商、采购公告、中标公告、框架协议、供应商征集；**买方与标的都明确** | 明确采购需求 |
| **扩产或复产需求** | 由**生产变化**推断：窑炉/装置点火、冷修技改完成、复产、投产/试生产、达产、提负荷、新增生产线环评或备案；**尚无公开采购动作，但本产品消耗量已确定要增加** | 推断的潜在需求 |
| **其他潜在需求信号** | 更间接：地方重大项目清单、园区新建、行业景气、**同行检修/减产造成的补货窗口**、下游集中扩产潮 | 推断的潜在需求 |

**判别口诀：`谁要买、买多少、什么时候截止` 三问全答得上 → 明确采购；只能答「它的本产品消耗量要涨」→ 推断需求；连消耗量都要靠行业景气去推 → 其他信号。**

分组**只有这三个值**，不得新造；同行/市场信号放进第三组，并在关系字段标 `[利好]`/`[利空]`/`[中性]` 方向。第一组是**唯一可以直接投标/报价**的组，第二组的打法是「提前拜访、送样、锁定年度框架，抢在它公开招标前进供应商名单」。

## 最容易被凑数的误配方向（必须按产品重建）

纯碱版实测清单（**只作格式示范，不得照抄到下个产品**）：

| 误配方向 | 为什么不是本产品需求 |
|---|---|
| **岩棉** | 岩棉＝玄武岩＋焦炭，**完全不用纯碱**；用纯碱的是**玻璃棉**，别混 |
| **气相法白炭黑** | 以四氯化硅为原料，**不耗纯碱**；只有**沉淀法白炭黑**（经硅酸钠）才间接耗纯碱 |
| **造纸** | 主耗碱剂是**烧碱**，不是纯碱 |
| **买硅酸钠/泡花碱成品的厂、买过碳酸钠成品的厂** | 它们买的是**成品**，不构成纯碱需求（生产这些成品的厂才是纯碱客户） |
| **液态锂盐/电解液/六氟磷酸锂** | 不走「碳酸钠沉锂」路线，无纯碱需求；只有碳酸锂/氢氧化锂的沉锂段才耗纯碱 |

**怎么为一个新化工品建这份清单（四步，必须做）**：

1. **列全「近名产品」**：同一元素、同一用途、名字只差一两字的其他产品 → 决定 R2 第 1 类。
2. **对每个下游方向问一句「它的工艺路线上，我这个产品到底投不投」**：投在哪个工序、有没有**替代品**（替代品是最主要误配来源：碱剂里烧碱/石灰可替代纯碱；硅源里四氯化硅可替代硅酸钠）。**看路线，不看行业名** —— 行业名相同、路线不同的两个厂，一个用量极大，一个完全不用。
3. **找「成品/原料倒置」**：哪些厂买的是「用本产品做出来的中间体或成品」（那是别人的客户，不是我的）。
4. **找「工程方/渠道方」**：总承包、设备商、环保工程公司、贸易商 —— 采购发生在他们的**业主端**，标为间接线索，不可算作本产品的直接需求。

**产出**：一张「误配方向 + 原因」表 ＋ 一组可直接写进程序的关键词对（纯碱版形态：`命中 烧碱|氢氧化钠|液碱|片碱 且不含 纯碱|碳酸钠 → 判 R2`）。这张表是**逐产品重建**的，纯碱的表对新化工品零价值。

## 吨耗系数怎么来（并必须标「（估算）」）

三个来源，按可信度从高到低：

1. **化学计量推算**：按反应式算**理论单耗**，再乘收率修正，给出**上下限**。最可靠。
2. **行业单耗经验值**：公开工艺资料、行业标准、同业公告「主要原材料」段落里的量价。有来源就写来源。
3. **反向验证（最硬）**：用公告里披露的采购量/金额/产能**回算**系数并交叉验证。例如某公告披露「采购 1,848.00 吨 / 2,274,494.33 元 / 均价 1,230.79 元每吨」，三个数能互相复算（1,848 × 1,230.79 ≈ 2,274,494），说明该口径可信、可反推该客户的用量规模；也可用「下游装置产能 × 系数 ≈ 年需求吨位」与另一条披露交叉验证是否自洽。

**三条纪律**：

- 系数是**估算**：条目里必须写成「约 X 吨/年（**估算**）」并写明依据（系数 ＋ 装置规模）；不写依据的估算按 R5 不收。
- **存在路线差异时必须给区间并说明**：同一产品既有耗本产品的路线、也有不耗本产品的路线时，要写「仅按耗本产品的那部分产能折算」。
- **不要用区间上限当结论**：上下限都可以写进数量字段，但交付口径要保守 —— 销售按上限备货会踩空。
