# 产品画像（product-profiling）— 化工品采购商机雷达 · 产品无关

> 这是整个 skill 里**唯一需要行业知识的一步**；其余环节（取数、闸门、归一化、优先级、出表）全部产品无关（→ [`channels.md`](channels.md)、`scripts/radarlib.py`）。
> 本文件的产物 = **`config/<产品>.json`**（模板 `config/product.template.json`）。填完 §7 的填空模板 ≈ 填完 config。

## 1. 产品标识（先做这一步，否则后面全是漏检）

| 项 | 怎么填 | 纯碱示例（举例） |
|---|---|---|
| 学名 | 化学命名/中文标准名 | 碳酸钠 |
| 化学式 | 分子式 | Na₂CO₃ |
| 常用俗名 | 行业口语名、地方的叫法 | 纯碱 |
| 商品名 / 规格牌号 | 按形态、品级分 | 重质纯碱 / 轻质纯碱；工业级 / 食品级（食用纯碱） |
| 英文名 | 外贸与英文公告用 | soda ash |
| CAS 号 | **必须核验后填，不要凭记忆写** | 【核验后填】 |
| 别称 / 缩写 | 简称、旧称、英文缩写 | 【核验后填】 |

**为什么这一步不能省**：**同一种东西在中文公告里可能永远只出现学名，俗名一条都没有。**
**实测**：同一个政采平台检索 `碳酸钠 → 8 条`，而 `纯碱 → 0 条`；cninfo 上 `碳酸钠` 全文 41 条，而标题检索 0 条。
→ 规则：① `aliases` 必须**学名与全部俗名同时列**；② 规格/品级单列，因为它决定 lane（食品级 → 食品发酵 lane）；③ 别称多、缩写歧义大时（短缩写会被同名噪音淹没）**改用全化学名或「中文名+缩写」双写**。

## 2. 下游应用地图（8–12 个 lane）

### 2.1 一个 lane 必须写全四件事（照抄这个结构）

```markdown
### Lane NN · <lane 名>
- 用料逻辑：在哪个工序、起什么作用、在配方/配合料里是什么角色（能写到掺量就写）
- 用量强度：★★★★（口径：单客户 <量级>/年）
- 目标企业候选（5–8 家，具名可查证）：<公司1>、<公司2>、…
- 产业集聚地：<省/市集群，写全称>
- 检索词：<产品词> × <工序词> × <文件词> × <地域词>
- 本 lane 排除：什么像但不是（汇总进 §5 误配清单）
```

### 2.2 用量强度口径（写死，不要自创）

| 星级 | 单客户年用量 |
|---|---|
| ★★★★★ | 千吨级/年 |
| ★★★★ | 百吨级 |
| ★★★ | 数十吨级 |
| ★★ | 十吨级及以下 |

**口径必须写进交付表的说明页**，否则读者无法判断「★★★★」是多少。`config.strength_rules` 就是把每个行业的星级写成 pattern + weight。

### 2.3 ⭐ 必须主动找的两类「渠道型 lane」（最容易漏）

| 类型 | 是什么 | 纯碱例（举例） | 为什么容易漏 |
|---|---|---|---|
| **复配 / 转售型** | 把本产品当**配方单体**，与其它组分复配成配方产品再转售 | 洗涤剂 / 洗衣粉厂（本产品作助洗剂、缓冲碱配进配方） | 它是"配方厂"不是"本产品行业"，按行业分类想不到 |
| **深加工型** | 拿本产品做原料，做成另一个产品 | 小苏打厂（Na₂CO₃→NaHCO₃）、硅酸钠厂、过碳酸钠厂、亚硫酸钠厂 | 检索时只出现**工序词/产物词**，产品名常不出现 |

**判据**：这两类用量强度常常不低，且公告标题里**很少出现本产品名** → 检索词必须带工序词与产物词（→ §6）。

### 2.4 怎么切 lane（来源与收口）

- 来源按可靠性：① 行业媒体/协会市场分析 → 拿到**下游消费结构百分比**（例：「某年消费结构：A 44.2%、B 17.8%…」）→ 按百分比定**重心与目标条数**；② 上市公司年报/招股书/评级报告的「行业情况」「原材料采购」章节 → 单厂产能、采购量价；③ 券商研报/年鉴；④ 自己按物性推导（**兜底，须标注「按工艺推导」**）。
- 切法：从**「这个产品被用在哪个工序、起什么作用」**出发，不要从行业分类出发——同一个行业词在不同产品下可能属于不同 lane，甚至不属于任何 lane。
- **lane 收口判据**（缺一条就不算收口）：☐ 用料逻辑能写清（工序+掺量/角色） ☐ 5–8 家具名候选 ☐ 检索词四槽填满 ☐ 本 lane 的排除规则 ☐ 对应的落盘文件前缀。

### 2.5 示例：纯碱的 12 个 lane（仅作举例，规则本体与产品无关）

| NN | lane | 用料逻辑（工序/作用） | 强度 | 集聚地举例 |
|---|---|---|---|---|
| 01 | 浮法 / 光伏 / 日用玻璃 | 玻璃配合料中引入 Na₂O，降低熔化温度 | ★★★★★ | 江苏（常熟/吴江/昆山）、浙江（绍兴/长兴/平湖）、安徽（蚌埠）、山东 |
| 02 | 碳酸锂 / 氢氧化锂 | 硫酸盐法焙烧后**碳酸钠沉锂** | ★★★★★ | 江西宜春、江苏、四川（区外） |
| 03 | 小苏打（碳酸氢钠） | Na₂CO₃ + CO₂ + H₂O → 2NaHCO₃ | ★★★★ | 山东、江苏、内蒙古（区外） |
| 04 | 硅酸钠（泡花碱） | 纯碱 + 石英砂熔融 | ★★★★ | 山东、福建（泉州）、江苏 |
| 05 | 过碳酸钠 | 纯碱 + 双氧水 | ★★★ | 江苏、山东 |
| 06 | 洗涤剂 / 洗衣粉 | 助洗剂、缓冲碱（配方级，吨位大） | ★★★★ | 浙江（丽水）、安徽（合肥）、上海 |
| 07 | 纺织印染与皮革 | 前处理/染色碱剂（数十 kg/吨布，集群吨位极大） | ★★★★ | 浙江（绍兴柯桥）、江苏（常州/南通/盐城）、福建（石狮） |
| 08 | 亚硫酸钠 / 焦亚硫酸钠 | 纯碱吸硫 | ★★★ | 江苏、山东 |
| 09 | 沉淀法白炭黑 | 经硅酸钠间接耗用（**气相法不算**，见 §5） | ★★ | 福建、江苏、山东 |
| 10 | 氧化铝（烧结法）/ 稀土 / 钠法脱硫 / 水处理 | 助熔、沉淀剂、碱剂（少量） | ★★ | 山东（魏桥/信发集群）、江西赣州 |
| 11 | 钠离子电池正极 | 纯碱作**钠源**直接投料 | ★★★★ | 江苏、浙江、安徽 |
| 12 | 玻纤 / 玻璃棉 / 陶瓷釉料 / 医药食品级 | 配方少量 | ★ | 浙江（桐乡）、山东 |

**候选企业示例（具名，来自本轮演算语料）**：
- 玻璃 lane：耀皮玻璃（常熟/天津）、旗滨集团（绍兴/长兴/平湖）、南玻（吴江）、台玻（昆山）、中建材（蚌埠）、信义玻璃（芜湖/德清）、福莱特（嘉兴/安徽）、亚玛顿（常州）、山东药玻、德力股份、中国巨石（桐乡）、泰山玻纤。**注意：金晶科技看起来是玻璃客户，实际自产纯碱 → 见 §4。**
- 锂盐 lane：赣锋、永兴材料、江特电机、九岭锂业（江西宜春集群）。
- 洗涤 lane：纳爱斯（丽水）、联合利华（合肥）、白猫（上海）。

**硬要求**：`targets` 里必须是**具名、可查证**的企业，不允许写「某类企业」「相关厂家」。

## 3. 吨耗系数怎么定

### 3.1 三种来源与优先级

| 优先级 | 来源 | 怎么得到 | 用法 |
|---|---|---|---|
| ① 最高 | **化学计量推算** | 按反应式/计量对象算理论值，可复算 | 写成区间，注明反应式 |
| ② 次之 | **行业单耗经验值** | 年报/研报/协会披露的单耗 | 与①比对，差异要解释 |
| ③ 验证用 | **公告披露反推** | 用披露的采购量 ÷ 产能/产量 | 反过来校验①②，不单独用 |

### 3.2 化学计量推算怎么写（照公式做）

```
理论吨耗 = (反应式中本产品摩尔数 × 本产品摩尔质量) ÷ (目标产品摩尔数 × 目标产品摩尔质量)
实际口径 = 理论吨耗 ÷ 纯度 ÷ 收率   （或 × 过量系数）
```

- **举例 A · 锂盐沉锂段（按 Na₂CO₃ 计量）**：沉锂反应中 Na₂CO₃ 与 Li₂CO₃ 为 1:1 摩尔 → 理论值 ≈ 105.99 ÷ 73.89 ≈ **1.43 t 纯碱 / t Li₂CO₃**；行业披露口径 **1.8–2.0**（多投 + 损失）。→ 条目写「1.8–2.0（估算），理论值 1.43，差值为过量与收率」。
- **举例 B · 硅酸钠（按 Na₂O·3.3SiO₂ 计）**：3.3 mol SiO₂ 配 1 mol Na₂CO₃ → 理论值 ≈ 105.99 ÷ (61.98 + 3.3×60.08) ≈ **0.41 t/t**；行业口径 **0.35–0.45**，自洽。
- 规则：**写清「按什么反应式、什么计量对象」算的**；算出的理论值与行业口径差距大时，两个都留并说明差异来源（过量、收率、纯度、含水量）。

### 3.3 用公告披露反推验证

- **可用的披露形态**（cninfo 全文检索能挖到）：`采购量`、`采购金额`、`采购均价`、供应商名与定价机制。
  实测：某产品 `纯碱采购` 全文检索在窗口内 **142 条**，命中主体多为**债券评级报告**与**季度经营数据/问询函回复**，正文直接写量价。
  例：某上市公司问询函回复列出「2025 年度向某供应商采购纯碱 **1,848.00 吨 / 227.45 万元 / 均价 1,230.79 元每吨**」，而 1,848 × 1,230.79 ≈ 2,274,500 元 = 227.45 万元 → **量×价≈金额 是最低成本的防错校验**。
- **反推系数**：需要**同一条线索里既有采购量、又有产能/产量** → `吨耗 = 采购量 ÷ 产量`，再与 §3.2 / 行业口径比对。
- **只有一个数字时不要造系数**；拿不到产能就在条目里写「无法估算」。

### 3.4 落表规则

- `config.tonnage[]` 每条必须有：`industry` / `pattern` / `coefficient` / `unit` / `basis` / `strength`。
- 系数是**估算**：凡在「与我产品的关系」里用数字，必须标 **「（估算）」** 并写依据（反应式 / 行业口径 / 公告出处）。
- **不给无出处的数字**——写「未知/无法估算」永远优于编一个像样的数。

## 4. 同行名单怎么建（R1 闸门的事实来源）

### 4.1 什么算同行

- **自产该产品**的主体 —— 含**在建 / 拟建产能**（不只看已投产）。
- **垂直一体化**企业：自己下游用、同时也自产 → **也算同行**（最容易漏的一类）。
- 收入结构里有该产品业务分部的主体。

### 4.2 ⭐ 两个方向相反的陷阱（必须逐条排查）

| 陷阱 | 纯碱例（举例） | 结论 |
|---|---|---|
| **名字像同行、实际是买方** | 振华股份（603067）：铬盐企业，公告自述纯碱为主要成本项并披露纯碱采购 | 是**买方**，绝不能按同行剔除 |
| **名字像客户、实际是同行** | 金晶科技（600586）：名字像浮法/超白玻璃客户，但年报「纯碱业务」载明**运营主体为控股子公司山东海天生物化工** | 垂直一体化纯碱生产商，**必须按同行剔除** |

**铁律：同行身份必须核验年报的业务分部，不能看名字。**

### 4.3 建法（四步）

1. 用「产品词 × 产能词」检索（`<产品> (装置|项目|产能|生产线)`）→ 得到自称生产该产品的主体名单（含在建/拟建）。
2. **核验年报的业务分部 / 经营范围**，把「**生产**该产品」与「**使用**该产品」彻底分开。
3. 写入 `config.peers.names`；并用 `config.peers.subject_patterns` 描述「主体确实在生产该产品」的词（工艺路线词一类）。**names 与 patterns 同时命中才按同行剔除**——否则会把下游误杀。
4. 交付前跑一次全局比对，并在**交付报告里具名报出被剔除的同行**（含剔除依据）。

### 4.4 反向用法（别把信息浪费掉）

- 同行 **扩产 / 投产** = **新增供给，利空** → 不得放进「明确采购/招标」或「扩产或复产需求」。
- 同行 **检修 / 停产 / 降负荷** = 区域供给收紧、客户转向外部货源 → **对我方是利好补货窗口**，归入「其他潜在需求信号」，并在「与我产品的关系」里写明「竞争对手减产、区域补货窗口」。
- `peers.role_reversal` 两个方向都要写：`customer_not_peer`（像同行实际是买方）、`peer_not_customer`（像客户实际是同行）。

## 5. 误配清单怎么建（R2 闸门的事实来源）

### 5.1 五类（每类给纯碱例）

| 类型 | 纯碱例（举例） | 判据 |
|---|---|---|
| 近名但不同的产品 | 烧碱 / 氢氧化钠 / 液碱 / 片碱（**最常被误配**）；碳酸氢钠、碳酸锂、碳酸钙、碳酸钡、碳酸钾、碳酸氢铵 | 化学式不同 → 不是本产品需求 |
| 不耗该产品的工艺路线 | **岩棉**＝玄武岩＋焦炭，**完全不用纯碱**（用纯碱的是**玻璃棉**，别混）；**气相法白炭黑**原料是四氯化硅，不耗纯碱（只有**沉淀法**经硅酸钠间接耗） | 该分支的原料表里就没有本产品 |
| 买成品而非原料的厂 | 买硅酸钠/泡花碱成品的厂、买过碳酸钠成品的厂 | 它买的是**成品**，不是本产品 |
| 期货 / 仓储 / 行情类 | 纯碱期货、交割厂库、套期保值、价格指数 | 不是采购需求，最多归「其他信号」 |
| 非原料采购 | 本产品的设备 / 包装 / 物流采购 | 非产品需求 |

另一条易错项：**液态锂盐 / 电解液 / 六氟磷酸锂不走「碳酸钠沉锂」路线**，无纯碱需求；只有碳酸锂/氢氧化锂的沉锂段才耗。

### 5.2 为一个新化工品建这份清单的问法（照问，逐条落表）

1. 有哪些**名字相近、化学式不同**的产品？（→ 近名产品清单）
2. 每个已知下游里，**有没有走另一条工艺路线的分支**？（→ 岩棉/玻璃棉、气相法/沉淀法白炭黑式的分支）
3. 下游企业里，哪些是**买本产品做成的中间品**，而不是买本产品？（→ 买成品厂）
4. 有没有**金融 / 仓储 / 贸易**而非生产消费的事项会带着产品名出现？（→ 期货/厂库/指数）
5. 有没有**非原料采购**（设备、包装、物流）会带产品名？（→ 剔除）
6. 反向自检：这份清单里**有没有混进本产品的下游产物**？（→ 有就立刻移出，见 5.3）

### 5.3 铁律

`gates.mismatch_terms` **只放「根本不是本产品需求」的项**。
**本产品的下游产物绝不能放进去**——它们正是用来**反推需求**的桥。例：纯碱的下游小苏打 / 硅酸钠 / 过碳酸钠要留在画像里（用于判断谁在买纯碱）；真正该剔的是**买这些成品**的厂。

## 6. 检索词库怎么建（产物就是 config 的关键词数组）

### 6.1 构造公式

```
学名 ＋ 俗名 ＋ 商品名/规格 ＋ 英文名/CAS ＋ 下游用途词 ＋ 招标类词 ＋ 采购类词
```

### 6.2 词槽与去处

| 词槽 | 怎么造 | 落到 config |
|---|---|---|
| 产品词 | 学名、全部俗名、商品名/规格、英文名、CAS | `product.aliases`（+`name`/`chemical_name`/`cas`/`english`） |
| 下游用途词 | 从 §2 每个 lane 的**工序词与产物词**里抠（不是行业名） | `lanes[].keywords` |
| 招标类词 | 招标 / 询价 / 中标 / 竞争性磋商 / 竞价 / 比价 / 框架协议 / 集中采购 / 采购公告 / 公开询价 | `product.tender_terms` |
| 采购类词 | 采购 / 采购量 / 采购金额 / 采购均价 / 主要原材料 / 原燃料采购 / 原材料采购 / 供应商 | `product.procure_terms` |
| 地域词 | 省/市/县，**写全称** | `region.keywords` |

### 6.3 组合纪律

- 一次检索 = 一个词。cninfo / epoint 的**多词是 AND 分词，不是短语匹配** → 窄词组合命中率极低，**宽词 + 人工筛**更划算。
- **学名与俗名两轮都跑**；任何 0 条都要用**对照词**验证是不是真零（→ channels.md §3.3）。
- 搜政府列表页时用**行业词 + 工序词**筛，不要指望产品名出现在项目标题里。
- **产物必须是能直接填进 config 的数组**，不要停在「我大概知道该搜什么」。
