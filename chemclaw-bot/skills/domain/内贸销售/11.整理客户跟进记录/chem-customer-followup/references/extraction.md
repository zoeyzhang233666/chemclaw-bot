# 素材解析与四类边界

这份文件解决两个问题：**从素材里怎么抽**，以及**抽出来的东西该放哪一类**。

---

## 一、通用抽取顺序

```text
清点素材 → 每条给证据编号 → 按时间铺平（不分类）→ 回头打七类标签
   → 四类清单归并 → 算停滞与逾期 → 出字段确认 → 生成交付物
```

**先铺平再分类**是硬规矩。边读边分类会把"客户问价"记成"客户需求"，把"我方介绍产能"记成"客户关注点"。

---

## 二、各类素材的坑

### 微信截图 OCR

| 坑 | 处理 |
|---|---|
| 只有 `月日 时:分`，没有年份 | 按 as_of 推断；若推出未来日期，年份 −1 |
| 截图倒序（最新在最上） | 按时间戳重排后再编号 |
| **语音条** | OCR 抓不到内容 → 一律进「待确认」，并在正文时间线留一条"内容不明"记录 |
| 合并转发 / 长文截图被切两半 | 合并为一条，`source` 写 `截图7-8` |
| 撤回、"对方已删除" | 记为「待确认：曾有消息被撤回，内容不明」 |
| 红框/马赛克遮挡 | 只记可见部分，被遮部分写明「被遮挡，不可读」 |
| 群聊里多方发言 | `actor` 必须写具体人（王建国/张工），不能只写"客户" |
| 表情、语音通话记录 | 无业务信息，不入时间线（可省略） |

OCR 常见错字：把「吨」认成「屯」、把「承兑」认成「承竞」、把数字 `0` 认成 `O`。**涉及数字与专有名词，宁可回头核对原图。**

### 邮件

| 坑 | 处理 |
|---|---|
| 引用历史（`-----原始邮件-----` 以下） | **不要重复计入**，只在新内容里抽；历史部分用于校正时间 |
| 附件缺失（"详见附件"） | 正文结论照记；附件内容进「待确认」，写清文件名 |
| 抄送/密送名单 | 是**决策链线索**，记入 profile（决策链/对接人），不要写进时间线正文 |
| 一封邮件列了 4 点异议 | 拆成 4 条记载，或 1 条 + 子项；不要压成一句 |
| 落款日期与发信时间不一致 | 以发信时间为准 |

### 会议纪要

| 坑 | 处理 |
|---|---|
| 分不清谁说的 | `actor` 宁缺毋滥；分不清就写「双方」，并在 `note` 标「归属待确认」 |
| 概括 vs 原话 | 纪要是**二手**，`confidence` 最多给「中」；能引到原话才给「高」 |
| 手写批注（页边、划线） | **单独进「待确认」**，数字模糊尤其如此（`1?30`） |
| 会后待办混在正文 | 我方待办 → 承诺；客户待办 → 待确认（卡在客户） |
| 一份纪要跨 5 小时、多个议题 | 按议题拆条，不要整份算一条 |

### 报价单

报价单是我方立场的**书面证据**，每个字段都是一个条件：

```text
价格 / 税 / 运费归属 / 包装 / 交期 / 付款方式 / 有效期 / 最小起订量 / 质量标准
```

注意：
- **报价单上的条件是「我方立场」，不是「客户需求」**——这是最常见的串层错误
- 有效期必须落到 `meta.quote_expiry`，用于「剩 N 天」提醒
- 页边手写（底线价、领导批示）→ 进「待确认」，不要直接当结论

### 电话/拜访记录

转述性质，`confidence` 默认「中」。若记录里有明确引号原话，可升「高」并标注"电话原话"。

## 三、时间推断规则

- 只有 `月日` → 用 as_of 的年份；若该日期晚于 `as_of + 7 天`，判定为去年
- 只有 `今天/明天/后天` → 按该条记录的上下文日期推算
- 排序键：`(推断后的完整日期, 时间字符串)`，时间缺失排当天末尾
- **别用素材文件名的日期当 as_of**

## 四、四类边界决策树

拿到一句话，按顺序问：

```text
这句话是谁说的？
├─ 客户说的 ──→ 是条件/要求/期望吗？
│              ├─ 是  → ① 客户需求
│              └─ 否  → 是反对/不满/拒绝吗？
│                       ├─ 是 → ② 客户异议
│                       └─ 否 → 客户动作（问价、催办、转发资料、约见面）
├─ 我方说的 ──→ 是承诺（有交付物/有期限）吗？
│              ├─ 是  → ③ 我方承诺
│              └─ 否  → 我方动作（寄样、报价、拜访）
└─ 说不清 / 读不出 → ④ 待确认（+ 若有疑问，进 unknowns）
```

## 五、20 个易混案例

| # | 情况 | 正确归类 | 为什么 |
|---|---|---|---|
| 1 | 客户问「你们纯碱什么价？」 | 客户动作 | 只是问价，不是需求；后来给了用量才是需求 |
| 2 | 客户说「月用 3000 吨」 | 客户需求（数量） | 明确的数量陈述 |
| 3 | 客户说「我问问领导」 | 客户动作 | 无业务信息，是进度信号 |
| 4 | 客户说「价格太高了」 | 客户异议 | 明确的反对 |
| 5 | 客户对某条件**没反对** | 不入任何表 | 沉默不是同意 |
| 6 | 我方报价单写「款到发货」 | 我方动作/立场 | 我方条件，不是客户需求 |
| 7 | 我方说「保供条款可以写进合同」 | 我方承诺 | 有交付物 |
| 8 | 我方说「我们产能 50 万吨」 | 我方动作 | 介绍，不是承诺 |
| 9 | 客户说「先寄个样」 | 客户需求（送样要求） | 明确要求 |
| 10 | 客户说「资质还没给我们」 | 客户异议 | 对我方未交付的反对 |
| 11 | 客户催「文件什么时候给」 | 客户动作 | 催办，不算业务推进（影响停滞口径） |
| 12 | 客户转发比价表 | 客户动作 | 行为本身不是需求 |
| 13 | 客户说「等长约到期再谈」 | 客户异议（结构性） | 明确的暂缓理由 |
| 14 | 客户说「这次合作顺利可以谈年框」 | 客户需求（未来意向） | 明确表达的意向，但要标"意向≠承诺" |
| 15 | 我方提出「罐区中转」方案 | 我方方案（≠客户需求） | 我方主动提的解法 |
| 16 | 行业惯例「化工都是月结」 | 不入表 | 不是客户说的 |
| 17 | 客户口头「可以谈年框量」 | 需求 + 低置信说明 | 意向，不是采购承诺；不得写成"客户承诺 2000 吨" |
| 18 | 纪要概括「客户对价格有意见」 | 异议，confidence=中 | 二手概括，非原话 |
| 19 | 手写「底线 1?30」 | 待确认 | 数字不可辨认 |
| 20 | 客户说「你们跟 XX 家比贵 100」 | 异议（价格）+ 竞品情报 | 一句两用：异议入表，竞品信息可进 AI 摘要 |

## 六、必须进「待确认 / 无法辨认」的清单

出现以下任一情况，**不许猜，进 unknowns**：

- 语音条未转写
- 截图被遮挡 / 截断 / 严重模糊
- 手写数字辨认不清
- 附件缺失（正文引用了但没上传）
- 纪要前后矛盾（如"3 月到期"与批注"2 月底"）
- 人名/公司名 OCR 明显错字且无法校正
- 会议中"谁说的"无法归属，且该句影响结论
- 报价单价格与邮件价格冲突且无法判断先后

`unknowns` 每条要写：`source`（哪份素材）、`issue`（什么问题）、`need`（需要用户做什么）、`status`（待补 / 可选）。

## 七、原话与转述

| 写法 | 场景 |
|---|---|
| `客户：<q>价格给我报个有诚意的</q>` | 有原文，直接引，最有说服力 |
| `客户表示价格需更有竞争力` | 转述，`confidence` 降为中 |
| `（据纪要整理）客户要求月结 30 天` | 二手，标注来源性质 |

**引用不改字**：客户说"贴着我们内控的线"，不要润色成"接近内控上限"。谈判时业务员会照着卡念，改一个字就可能失真。
