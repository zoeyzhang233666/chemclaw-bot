# 危险化学品买方资质与销售合规提醒（化工品 · 内贸销售）

这份 skill 不替企业做法律判断，它做一件更具体的事：**在一单生意成交前，把"这个产品是不是危化品、买方要不要资质、我要留什么、要不要备案"四个问题，用可核验的依据写清楚，并把缺口变成一封能直接发出去的要资料邮件。**

产物是 **自包含交互 HTML + 12 表 Excel + case.json**。HTML 可点选产品、勾选清单、生成话术；Excel 可归档、可打印、可交给合规部复核。

## 何时触发

- "我要向 XX 卖 XX，对方用途 XX，需要什么资质？"
- "这个产品算不算危化品 / 是不是易制爆 / 要不要备案？"
- "客户准入要收哪些证照？留几年？"
- "纯碱 / 烧碱 / 硫酸 / 双氧水 卖给玻璃厂、印染厂、电镀厂，合规上有什么区别？"
- 投标前、首单前、供应商审核、客户合规问卷

## 输出契约（硬性）

| 产物 | 说明 | 命名 |
|---|---|---|
| `case.json` | 唯一事实源 | `{案例编号}.json` |
| `*.html` | 自包含交互卡，双击可开，无需联网 | `{产品}_{买方}_合规提醒.html` |
| `*.xlsx` | 12 个工作表，含下拉勾选与链接 | 同名 `.xlsx` |

交付前必须运行 `scripts/verify.py` 并得到 `RESULT: PASS`。

## 五步工作流

### 第 0 步：锁定产品身份（最容易出错的一步）

先问清 **名称 + CAS + 浓度 + 形态 + 等级**。同一个 CAS 的不同形态通常不改变判定（纯碱轻质/重质），但**浓度会改变判定**：

| 产品 | 判定分界 | 依据 |
|---|---|---|
| 过氧化氢溶液 | 含量 **>8%** 才是危化品 | 目录 2015 条目 |
| 氨溶液 | 含氨 **>10%** 才是危化品 | 目录 2015 条目 |
| 次氯酸钠溶液 | 含有效氯 **>5%** 才是危化品 | 目录 2015 条目 |
| 甲醛溶液 | 含量 **≥37%** 才是危化品 | 目录 2015 条目 |
| 碳酸钠（纯碱） | 任何形态、任何浓度都不是 | 未列入目录 |

**名称混淆是最高频事故**：纯碱（Na₂CO₃）、小苏打（NaHCO₃）不是危化品；烧碱（NaOH）、液碱、片碱是危化品（皮肤腐蚀 1A）。合同、发票、COA、SDS、包装标识必须写 CAS。

### 第 1 步：出判定卡

判定顺序（不可跳步）：

1. **查目录**：《危险化学品目录（2015 版）》按品名、别名、CAS 三路检索，留存截图；
2. **查四类名录**：剧毒（目录内 148 种）、易制爆（2017 年版）、易制毒（分类和品种目录）、重点监管（第一批/第二批）、特别管控（第一版）；
3. **看 GHS**：调本批 SDS，比对危化品确定原则（腐蚀 1A/1B/1C、急性毒性 1–3、易燃、氧化等）；
4. **给结论**：四态之一 —— 非危化品 / 危化品（普通） / 危化品（剧毒或易制爆） / 需鉴定（危险特性未确定）；
5. **写边界**：什么情况下翻盘（杂质、浓度、品名误写、食品级分支）。

不确定就写"需鉴定 / 无法判定"，**不得猜**。法第一百二十四条：危险特性尚未确定的化学品，任何单位和个人不得擅自经营。

### 第 2 步：买方公开资质核查（四态，不许合并）

| 状态 | 含义 | 处理 |
|---|---|---|
| **A 公开可见** | 已取得可点开的公开证据（年报、官网、交易所公告、许可平台） | 可直接引用，附链接与日期 |
| **B 需核对原件** | 有公开入口或间接证据，但没拿到原件/截图 | 写进索取清单，**不能据此下结论** |
| **C 无公开信息** | 公开渠道查不到，或依法不公开 | 必须向买方索取 |
| **NA 不适用** | 该资质对本品种/用途不适用 | 必须附不适用依据（法条/目录） |

纯碱这类非危化品，买方**不需要**危化品经营/使用许可、剧毒购买许可证、易制爆用途说明、易制毒备案——这些项应写 **NA 并附依据**，而不是留空。真正要收的是：营业执照、开票信息、收货授权、用途说明、排污许可（行业相关）。

### 第 3 步：合规清单与留存矩阵

按"销售方 / 买方 / 双方"三组拆，每条给：依据、留存年限、是否备案、时点、证据形式。

留存口径（本 skill 固定写法）：

- 危化品中**剧毒、易制爆**销售记录：**≥3 年**（法第六十一条，旧条例为 1 年，已提高）；
- 一般化工品：无法定 3 年要求，**建议 ≥5 年**（诉讼时效 3 年 + 余量）；
- 会计凭证：**30 年**（《会计档案管理办法》）；
- 剧毒/易制爆：销售、购买后 **3 日内**报县级公安备案并录入计算机系统；**禁止互联网销售**（法第六十三条）。

### 第 4 步：缺口 → 话术

每个缺口一句话"要什么"，再生成三版草稿：邮件标准版 / 邮件仅列缺口 / 微信短版。原则：

- 首封只列 4 项必备，不要一次要 12 项；
- 明确"仅用于准入与合规留档"，写保存年限；
- 先给对等材料（我方 SDS/COA/执照样张），再要对方材料。

### 第 5 步：生成与校验

```bash
python scripts/build_workbook.py case.json out.xlsx
python scripts/build_html.py case.json out.html
python scripts/verify.py case.json --html out.html --xlsx out.xlsx
```

`verify.py` 会查：占位符、标签配对、核查项/义务项条数、12 表齐全、状态下拉、链接数、空表。必须 PASS。

## 禁忌

1. **不猜判定**：查不到目录收录情况就写"需核验"，不写"应该不是"。
2. **不把 pH 当判定依据**：纯碱溶液 pH 11–12 仍不是危化品；判定看目录与确定原则。
3. **不把 A/B/C 合并**："公开可查"不等于"已核实"。
4. **不用旧法条**：留存年限、备案时限以《危险化学品安全法》（2026-05-01 施行）为准；旧条例只作对照。
5. **不省 CAS**：名称混淆是这类业务最大的实际风险。
6. **不省略"不适用"的依据**：NA 也要写清为什么 NA。
7. **不把示例买方信息写成已核实**：统一社会信用代码、经营范围原文没拿到就写"待核"。

## 样例结论（纯碱 → 福莱特）

- 判定：**非危险化学品**（未列入目录 2015，GHS 皮肤刺激 2 / 眼刺激 2A）；
- 买方资质：危化品相关 6 项全部 **NA**；需收 4 项必备（执照/开票/收货授权/用途）；
- 留存：无法定 3 年要求，建议 5 年；会计凭证 30 年；**无需公安备案**；
- 关键风险不在危化品，而在**食品级分支**与**与烧碱混称**。
