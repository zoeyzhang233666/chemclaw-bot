# 01 · 判定流程与规则

> 适用法律：《中华人民共和国危险化学品安全法》（2025-12-27 通过，**2026-05-01 施行**）。判定时点不同，结论依据会变——2026-05-01 之前签的合同，应按当时的《危险化学品安全管理条例》复核。

## 一、判定树（按顺序走，不可跳步）

```
产品（名称 + CAS + 浓度 + 形态 + 等级）
│
├─ 1. 是否列入《危险化学品目录（2015 版）》？
│     ├─ 是 → 危化品（继续查 2、3、4）
│     └─ 否 → 继续 1b
│        1b. 危险特性是否已确定？
│             ├─ 已确定且不落入确定原则 → 非危化品，结束
│             └─ 未确定/疑似 → 按 60 号令鉴定分类，鉴定前不得经营
│
├─ 2. 是否剧毒？（目录内标注"剧毒"，共 148 种）
│     └─ 是 → 买方需剧毒化学品购买许可证；销售方查验 + 记录 3 年 + 3 日内报公安
│
├─ 3. 是否易制爆？（《易制爆危险化学品名录（2017 年版）》）
│     └─ 是 → 买方需本单位合法用途说明；销售方查验 + 记录 3 年 + 3 日内报公安；禁止互联网销售
│
├─ 4. 是否易制毒？（《易制毒化学品的分类和品种目录》）
│     ├─ 第一类 → 购买许可证（省级公安）
│     └─ 第二/三类 → 购买前向县级公安备案，取得购买备案证明
│
└─ 5. 是否重点监管 / 特别管控 / 监控化学品？
      └─ 是 → 叠加储存、装卸、自动化与备案要求（不改变"是否危化品"）
```

## 二、判定依据的优先级

| 优先级 | 依据 | 作用 |
|---|---|---|
| 1 | 《危险化学品目录（2015 版）》（2828 条） | **是否危化品的唯一入口** |
| 2 | 目录"备注"栏（剧毒标注） | 是否剧毒 |
| 3 | 《易制爆危险化学品名录（2017 年版）》 | 是否易制爆 |
| 4 | 《易制毒化学品的分类和品种目录》 | 是否易制毒、第几类 |
| 5 | 《重点监管的危险化学品名录》《特别管控危险化学品目录》 | 叠加管控 |
| 6 | 本批 SDS + GB 30000 系列 | 确定原则比对、GHS 分类 |
| 7 | 60 号令鉴定分类报告 | 未列入但特性不明时 |

## 三、浓度 / 形态 / 等级：什么时候会影响结论

### 3.1 会改变"是否危化品"

| 产品 | 分界（目录原文表述） | 低于分界 |
|---|---|---|
| 过氧化氢溶液 | 含量 **＞8%** | 不是危化品（但仍属氧化性物质，按 SDS 管理） |
| 氨溶液 | 含氨 **＞10%** | 不是危化品（仍有刺激性） |
| 次氯酸钠溶液 | 含有效氯 **＞5%** | 不是危化品 |
| 甲醛溶液 | 含量 **≥37%** | 不是危化品 |

> 以上分界务必以《目录》原文与最新版 SDS 复核；不同版本表述可能有"＞"与"≥"的差异。

### 3.2 不改变"是否危化品"，但改变合规路径

| 变化 | 影响 |
|---|---|
| 轻质 ↔ 重质（纯碱） | 堆积密度、装载率、投料与计量；判定不变 |
| 工业级 ↔ 食品添加剂级 | 触发 GB 1886.1 与食品生产许可（SC）；判定不变 |
| 固体 ↔ 溶液 | 防护等级、包装、混存禁忌；判定不变 |
| 无水 ↔ 水合物 | 有效成分折算、结算口径；判定不变 |

### 3.3 会"翻盘"的情形

- **副产碱含硫化钠**：硫化钠是危化品，整批可能按危化品或混合物管理，必须先做成分分析；
- **品名误写**：合同写"碱"、实发烧碱（NaOH），整单按危化品处理，且可能构成"匿报"；
- **混合物**：由多种组分构成且未列入目录的，按 60 号令做鉴定分类。

## 四、四类"名录"速查（易错点）

| 名录 | 判定要点 | 常见误判 |
|---|---|---|
| 剧毒化学品 | 目录备注"剧毒"，148 种 | 把"有毒"当"剧毒"；液氨不是剧毒 |
| 易制爆 | 2017 年版，按**含量**分档 | 双氧水 ≤8% 不是易制爆 |
| 易制毒 | 分三类，硫酸/盐酸/甲苯为第三类 | 以为"第三类不用备案"——购买仍需县级公安备案 |
| 重点监管 | 第一批 60 种（2011）及后续批次 | 把重点监管当"危化品"本身；它是叠加要求 |

## 五、判定卡的写法（四态）

| 结论 | 写法 | 后续动作 |
|---|---|---|
| 非危化品 | "未列入目录 2015；GHS 分类不落入确定原则" | 走一般化工品流程；保留比对截图 |
| 危化品（普通） | "列入目录第 X 条；皮肤腐蚀 1A" | 经营许可、SDS/标签、危货运输 |
| 危化品（剧毒/易制爆） | 叠加"买方资质查验 + 记录 3 年 + 3 日备案 + 禁网售" | 最严流程，逐单留痕 |
| 需鉴定 | "危险特性未确定，按 60 号令鉴定" | 鉴定前不报价、不交付 |
