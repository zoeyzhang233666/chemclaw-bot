# 02 · 买方资质核查：四态口径与公开渠道

## 一、四态定义（不可合并）

| 状态 | 判定标准 | 能不能写进合规结论 |
|---|---|---|
| **A 公开可见** | 已取得可点开的公开证据（年报、交易所公告、官网、政府许可平台），且与本次交易相关 | 可以，附链接 + 日期 |
| **B 需核对原件** | 存在公开入口或间接证据，但未取得原件/截图/证书编号 | **不可以**，只能写"需核对" |
| **C 无公开信息** | 公开渠道无此类信息，或依法不公开（如内部授权、客户名单） | 不可以，必须索取 |
| **NA 不适用** | 本品种/本用途不触发该资质 | 可以，但必须附依据 |

> 失败模式：把"天眼查能看到"写成 A。公开摘要不是登记原文，不能替代营业执照。

## 二、按产品类别拆资质（矩阵）

| 产品类别 | 买方需 | 销售方需 | 备案 |
|---|---|---|---|
| 非危化品（纯碱、小苏打、元明粉） | 营业执照、开票信息、收货授权、用途说明；行业许可（如排污许可） | 营业执照；SDS/COA/标识 | 无 |
| 危化品（普通，如烧碱、盐酸） | 营业执照；转售需危化品经营许可；使用许可视品种与用量 | 危化品经营许可证；SDS + 标签；危货运输 | 无（除非叠加易制毒/易制爆） |
| 剧毒化学品 | 危险化学品安全生产/使用/经营许可证之一，或**剧毒化学品购买许可证** | 经营许可（市级发证）；查验 + 记录 3 年 | 销售后 3 日内报县级公安 |
| 易制爆 | 许可证件 或 **本单位合法用途说明** | 经营许可；查验 + 记录 3 年 | 销售后 3 日内报县级公安；禁网售 |
| 易制毒 | 第一类：购买许可证；第二/三类：**购买备案证明** | 非药品类易制毒经营许可/备案（第三类 30 日内） | 购买前备案 |
| 食品添加剂级 | 食品生产许可证（SC） | SC 或上游 SC + 批次检验 | 无 |
| 进口/出口 | 报关、危包证、SDS 中外文 | 进出口检验 | 海关 |

## 三、公开渠道清单（能查到什么、查不到什么）

| 渠道 | 能拿到 | 局限 |
|---|---|---|
| 巨潮资讯 / 上交所 / 港交所 | 年报、公告、主营、基地、审计意见 | 不含营业执照原文 |
| 公司官网 | 产品、基地、资质荣誉 | 自述，非登记信息 |
| 国家企业信用信息公示系统 | 登记事项、经营范围、经营异常、严重违法失信 | 有验证码，自动化抓取困难；需人工截图 |
| 全国排污许可证管理信息平台 | 排污许可证编号、行业类别、有效期 | 需按企业名逐个查 |
| 信用中国 | 行政处罚、失信记录 | 同名企业需甄别 |
| 应急管理部许可公开 | 危化品安全生产/经营/使用许可 | 更新有滞后 |
| 地方生态环境部门 | 环评批复、验收公示 | 分散，按项目主体查 |

## 四、索取清单（按优先级）

**首单必备（4 项）**

1. 营业执照副本（加盖公章，含经营范围页）
2. 开票信息 + 一般纳税人资格
3. 收货授权委托书 + 经办人身份证
4. 用途说明（自用/转售、最终产品、年用量）

**建议（3 项）**：排污许可证/登记回执、环评批复、质量/技术协议

**分支（按情形）**：食品生产许可证（食品级）、下游转售资质（转售）、承运人道路运输经营许可证（自提）

**可选**：ISO 9001/45001、安全生产标准化、廉洁承诺

## 五、话术原则

- 首封只列 4 项，不要一次 12 项；
- 说清"用于准入与合同归档，保存 ≥5 年"；
- 先给对等材料（SDS/COA/执照样张），降低对方防备；
- 不说"监管要求"如果只是内部制度要求——把法定与内部分开写，客户更配合。
