# 03 · 法条索引（新法 vs 旧条例）

> 基准：《中华人民共和国危险化学品安全法》，2025-12-27 第十四届全国人大常委会第十九次会议通过，主席令第六十四号，**自 2026-05-01 起施行**。
> 旧《危险化学品安全管理条例》（国务院令第 344 号，2011/2013 修订）在冲突范围内让位于新法；**剧毒/易制爆销售记录保存期由 1 年提高为 3 年**，是本轮最容易被忽略的变化。

## 一、判定与定义

| 条款 | 要点 | 实务用法 |
|---|---|---|
| 第三条 | 危化品定义 + 目录管理制度；目录由应急管理部会同有关部门确定、公布、调整 | 判定的入口：先查目录 |
| 第六条 | 不得生产、使用、经营国家禁止的危化品；不得违反限制性使用规定 | 禁止类品种直接否决 |
| 第一百二十四条 | 危险特性尚未确定的，由应急/生态环境/卫健部门组织鉴定；未确定前不得从事生产经营 | 查不到就"需鉴定"，不得放行 |

## 二、经营（销售方义务）

| 条款 | 要点 | 实务用法 |
|---|---|---|
| 第五十三条 | 经营（含仓储经营）实行许可；未经许可不得经营；不得向无证企业采购 | 卖方资质门槛 |
| 第五十四条 | 经营许可 6 项条件（场所、培训、制度、专职安管、预案、其他） | 办证/换证自查 |
| 第五十五条 | 剧毒、易制爆 → 市级发证；其他 → 县级；构成重大危险源的储存 → 市级 | 判断去哪办证 |
| 第五十七条 | 销售时应提供符合标准的 SDS；不得经营无 SDS/标签的产品；买方有权索取 SDS | 纯碱虽非法定强制，客户准入普遍要求 |
| 第六十条 | 销售剧毒/易制爆应**查验**买方许可证件或证明文件，不得向不具备者销售；按证载品种数量销售；禁止向个人销售 | 查验义务的核心条款 |
| 第六十一条 | 销售剧毒/易制爆应如实记录购买单位名称、地址、经办人姓名、身份证号、品种、数量、用途；**记录与复印件保存 ≥3 年**；销售/购买后 **3 日内**报县级公安备案并录入计算机系统 | 台账模板与时限 |
| 第六十二条 | 使用单位不得出借、转让；确需转让的，只能转给有资质的单位，并在 3 日内备案 | 客户转售场景 |
| 第六十三条 | **禁止互联网销售、购买剧毒/易制爆** | 电商、自建站、微信群接单都要下架 |
| 第六十五条 | 危货道路/水路运输须许可；托运人应委托有资质承运人；经妥善处理可按普货运输的，按交通运输部办法 | 运输责任划分 |
| 第八十三条 | 不得在普货中夹带危化品，不得匿报、谎报为普货 | 混装/匿报的高压线 |
| 第一百零四条 | 未如实记录、超期保存不足 3 年、未按时备案 → 公安责令改正，可罚 2–10 万元 | 罚则 |
| 第一百零七条 | 向无资质单位销售剧毒/易制爆 → 应急部门责令改正、没收违法所得、罚 20–50 万元，可吊证 | 罚则 |

## 三、购买（买方义务）

| 条款 | 要点 |
|---|---|
| 第五十八条 | 持危化品安全生产/使用/经营许可证的企业，凭相应许可证购买剧毒、易制爆；其他单位购买剧毒 → 县级公安**剧毒化学品购买许可证**；购买易制爆 → **本单位合法用途说明**；个人禁购（农药、生活用品除外） |
| 第五十九条 | 剧毒购买许可证材料：营业执照/法人证书、品种数量说明、用途说明、经办人身份证明；3 个工作日内决定 |
| 第四十八条 | 使用规定种类危化品且用量达标的化工企业，需**危险化学品安全使用许可证**（品种与数量标准由应急管理部会同有关部门公布） |

## 四、记录与档案（本 skill 的留存口径）

| 事项 | 年限 | 依据 |
|---|---|---|
| 剧毒/易制爆销售记录、经办人身份证明复印件、许可证件复印件或证明文件 | **≥3 年** | 法第六十一条 |
| 重复使用危化品包装物、容器的检查记录 | ≥3 年 | 法第三十三条 |
| 剧毒化学品及构成重大危险源危化品的收发记录 | ≥3 年 | 法第四十一条 |
| 一般化工品商务资料（合同、COA、磅单、签收） | 建议 ≥5 年 | 诉讼时效 3 年 + 余量（内部制度） |
| 会计凭证、会计账簿 | 30 年 | 《会计档案管理办法》 |
| 年度财务会计报告 | 永久 | 同上 |

## 六、条文原文摘录（便于直接引用）

**第五十三条**：国家对危险化学品经营（包括仓储经营，下同）实行许可制度。未经许可，任何单位和个人不得经营危险化学品。危险化学品经营企业不得向未经许可从事危险化学品生产、经营活动的企业采购危险化学品。

**第六十条**：危险化学品生产企业、经营企业销售剧毒化学品、易制爆危险化学品，应当查验本法第五十八条第一款、第二款规定的相关许可证件或者证明文件，不得向不具有相关许可证件或者证明文件的单位销售剧毒化学品、易制爆危险化学品。对持剧毒化学品购买许可证购买剧毒化学品的，应当按照许可证载明的品种、数量销售。

**第六十一条**：……应当如实记录购买单位的名称、地址，经办人的姓名、身份证号码以及所购买的剧毒化学品、易制爆危险化学品的品种、数量、用途。销售记录以及经办人的身份证明复印件、相关许可证件复印件或者证明文件的保存期限不得少于三年。……应当在销售、购买后三日内，将……品种、数量以及流向信息报所在地县级人民政府公安机关备案，并录入计算机系统。

**第一百二十七条**：本法自 2026 年 5 月 1 日起施行。

> 旧条例对照：第四十一条曾规定销售记录"保存期限不得少于 1 年"，新法提高为 3 年。2026-05-01 之后仍按 1 年留存的台账，属于不合规。
