# 04 · 话术模板与语气

## 原则

1. **先给对等材料，再要资料**：随信附我方 SDS、COA 样张、营业执照，客户更愿意配合。
2. **法定与内部分开写**：法定必填项说"依《危险化学品安全法》第 X 条"；内部准入说"我方供应商管理办法"。
3. **首封只列 4 项**：执照、开票、收货授权、用途。其余后补。
4. **写保存年限与用途**：消除"资料会不会外流"的顾虑。
5. **给截止时间但不施压**：写"如本周内齐备，可赶上 X 月排产"。

## 模板 A：首单准入（非危化品，标准版）

主题：`【资料补充】{买方简称} × {产品}（CAS {CAS}）供应商准入资料`

```
尊敬的 {买方简称} 采购部：

您好！关于我司拟向贵司供应 {产品}（CAS {CAS}，{等级/标准}）一事，
计划 {数量}，交货至 {基地/库位}。

经我方合规核对：{产品}未列入《危险化学品目录（2015 版）》，
不属于剧毒、易制爆、易制毒及重点监管化学品，本单无需危险化学品经营许可、
购买资质查验与公安备案。为完成供应商准入与合同归档，仍需请贵司协助提供：

1. 营业执照副本复印件（加盖公章，需含经营范围页）；
2. 开票信息及一般纳税人资格证明；
3. 收货授权委托书及经办人身份证复印件（请注明收货库位与联系人）；
4. 用途说明：本批用于 {最终产品}（自用），并请给出年度用量预估。

以上资料仅用于供应商准入与合规留档，我方将保存不少于 5 年，不用于其他用途。
如贵司需要，我方可同步提供本批 SDS、COA 样张及我方营业执照。

顺颂商祺！
{我方公司} · 销售部
```

## 模板 B：仅列缺口（跟进版）

```
您好！上次提到的准入资料，目前还差 {N} 项，其余已归档：

{1. 缺口一}
{2. 缺口二}

这两项齐备后即可走合同流程。如需我方先提供什么材料配合，请直接说。
```

## 模板 C：微信短版

```
王经理您好，关于{P}首单的准入资料，麻烦帮忙安排几份：
①营业执照副本盖章件（含经营范围页）；②开票信息+一般纳税人证明；
③收货授权书和经办人身份证；④用途说明（{用途}，附年度用量）。
{P}不是危化品，不需要危化品许可证，这些是供应商建档和合同归档用的。
资料齐了我这边当天走合同流程，SDS 和 COA 样张我先发您。
```

## 模板 D：客户质疑"为什么只有你们要这么多"

```
理解您的顾虑。这几项不是我方额外加码：{法定项}是《危险化学品安全法》
第 X 条的要求；{内部项}是我方供应商管理办法的规定，主要用于对账与收货授权。
您可以把营业执照的经营范围页遮掉敏感信息，只保留名称、统一社会信用代码与经营范围。
```

## 不该写的话

| 不要写 | 原因 | 改成 |
|---|---|---|
| "危化品都要这些" | 纯碱不是危化品，说错显得不专业 | "本品种为非危化品，危化品资质不适用" |
| "监管要求提供全部 12 项" | 多数是内部准入项 | 分开写法定/内部 |
| "不提供就不发货" | 首单阶段容易谈崩 | 给截止日与替代方案 |
| "我们保证没问题" | 判定有边界条件，不能保证 | "按现行目录判定为非危化品，附依据" |
| "大概 / 应该 / 听说" | 合规结论不能模糊 | "需核验 / 无公开信息" |
