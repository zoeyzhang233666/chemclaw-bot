# 设计规范（HTML + Excel）

两个交付物的视觉规则。目标不是好看，是**一眼能排序、一眼能定位、打印出来还能读**。

---

## 一、信息架构（页面顺序不可乱）

结果页的第一屏必须同时给出「地图」和「区域汇总」——用户要的是"哪里值得去"，不是"有哪些公司"。

```
01 地图（左）+ 区域/城市详情（右）
02 城市/园区清单（可排序、可过滤）
03 下游行业结构（谁在真正消耗）
04 客户线索库（按类型/下游/置信度过滤）
05 新建扩产项目（正负增量）
06 价格水平（区际 + 区内到厂价）
07 走访优先级与路线（S 级卡片 + 周计划 + 预算）
08 口径、证据与缺口
```

每一节都要有「一句灰色说明」告诉读者怎么用这张图（`.sh .d`），不要只放标题。

## 二、视觉令牌

| 用途 | 值 |
|---|---|
| 主色（选中/强调） | `#0b6b5b`（深青，专业而非科技蓝） |
| 辅助（提示/负向） | `#b45309` 琥珀、`#a02c2c` 砖红 |
| 背景 / 卡片 / 线 | `#f4f6f8` / `#fff` / `#e4e8ee` |
| 正文 / 次要 / 弱 | `#101828` / `#344054` / `#667085` |
| S 级 / A / B / C | `#c2410c` / `#0f766e` / `#1d4ed8` / `#8492a6` |

字体：`-apple-system, "PingFang SC", "Microsoft YaHei"`；数字用 `tabular-nums`（表格里数字对齐）。
圆角：卡片 14–16px、按钮 9px、标签 999px。
阴影：`0 1px 2px rgba(16,24,40,.04), 0 8px 24px -12px rgba(16,24,40,.18)`（克制，不要发光）。

**决策原则**：颜色只用来编码一个维度。地图里颜色=等级，就不要再用颜色表示需求；需求用气泡大小。

## 三、必须写对的几处 CSS（踩过坑）

```css
/* 1) 选中态必须比基础态优先级高 */
.maptools .btn{background:rgba(255,255,255,.94);}
.maptools .btn.on{background:var(--teal);border-color:var(--teal);color:#fff;}   /* 必须写在后面或提权 */

/* 2) 进度条：内联元素设宽高无效 */
.bar .track{display:block;width:100%;height:8px;background:#e9eef4;border-radius:4px;overflow:hidden}
.bar .fill{display:block;height:100%;min-width:2px;border-radius:4px;background:var(--teal)}

/* 3) 地图等比，不要用 boundingCoords 拉伸 */
geo:{map:'china', center:[118.55,31.15], zoom:3.05, scaleLimit:{min:1.2,max:12}}
```

翻页/打印：`@media print` 隐藏顶栏、工具栏、输入框；`section{page-break-inside:avoid}`。

## 四、图表选型

| 表达 | 用什么 | 为什么 |
|---|---|---|
| 区域分布 | 中国省界地图 + 城市散点 | 一眼看出"集中在哪一块" |
| 需求结构 | 环形图（`radius:['46%','74%']`） | 份额比较，中空放标签 |
| 城市排序 | 横向条形（Top 12，按等级着色） | 排序比饼图清楚 |
| 价格对比 | 竖向条形（本地高亮、其余灰） | 只突出锚点 |
| 占比对比 | 侧栏 CSS 进度条 | 比图表更紧凑，便于和文字并排 |

规则：一个图只回答一个问题；轴上不放单位，单位写在标题或副标题里。

## 五、Excel 规范

- 12 张表，**顺序固定**，表名带序号（`01 概览与结论` … `12 方法与缺口`），便于口头引用。
- 每张表：第 1 行标题（15pt 粗体）、第 2 行副标题（含产品/区域/截止日/单位/口径提示）、第 4 行表头（深青底白字）、第 5 行起数据。
- 数据区一律：`auto_filter` + `freeze_panes` + 斑马纹（`F7F9FA`）+ 细边框。
- 颜色编码：等级 S/A/B/C、类型（生产/贸易/同行/误判）、置信度（高/中/低）三套填充色，全簿统一。
- 数值列用 `ColorScaleRule` 着色（需求、指数、用量），不要手动涂。
- **不放公式**：全部写静态值。否则对方打开时若未重算会看到 0，且无法直接复制。
- 行高按 CJK 字符宽度估算（汉字算 2 字宽），否则中文会挤成一行。
- 每张表底部留「说明/口径」文字区，不要只给数字。

## 六、文案规范

- 标题写结论不写主题："华东第一需求池在凤阳" 优于 "区域分析"。
- 每条判断都要带数字或对比："单客户均值 3.7 万吨，是绍兴的 12 倍"。
- 禁止无主体的被动句："需求较大" → "凤阳单城 150 万吨，占区域 16%"。
- 置信度、估算、未核实三个词必须显式出现，不要用"约""大概"含糊。
