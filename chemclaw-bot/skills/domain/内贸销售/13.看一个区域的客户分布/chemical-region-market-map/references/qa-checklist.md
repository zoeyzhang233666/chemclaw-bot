# 交付前检查清单

## 一、跑这三条

```bash
python scripts/validate.py data.json        # 0 error（warning 要逐条看过）
python scripts/build_all.py data.json --out out --name 产品-区域
python scripts/qa.py data.json "out/产品-区域区域市场地图.html" "out/产品-区域客户分布与走访优先级.xlsx"
```

`qa.py` 自动核对：

- HTML 无残留占位符、数据对象非空、`registerMap` 存在；
- 浏览器渲染后：城市行 = 城市数、企业行 = 企业数、项目行 = 项目数、下游卡 = 下游数、`canvas ≥ 4`、侧栏数据条 > 0；
- 页面正文无 `NaN` / `undefined`；
- Excel 12 张表、城市行数、客户行数、省级合计 = 企业总数。

## 四、已知 bug 与症状对照（本 skill 已内置修复）

| 症状 | 根因 | 修法 |
|---|---|---|
| 页面空白 / 控制台语法错误 `window.{...}` | 占位符 `__DATA__` 同时匹配了 JS 变量名 | 用 `%%DATA%%`，并保留占位符计数校验 |
| 地图横向拉宽、形状变形 | 用了 `geo.boundingCoords`，ECharts 按容器长宽比拉伸 | 改 `center + zoom` |
| 选中标签白底白字 | `.maptools .btn` 覆盖了 `.btn.on` | 补 `.maptools .btn.on` 规则 |
| 数据条只有灰槽 | `.fill` 是 inline span，宽高无效 | `display:block` |
| Excel 中文挤成一行 | openpyxl 不自动行高 | 按 CJK 2 字宽估算行高 |
| Excel 打开全 0 | 写了公式但未重算 | 全部写静态值 |
| 城市气泡重叠成一坨 | zoom 太小 | 提高 zoom 或改用按等级筛选 |
