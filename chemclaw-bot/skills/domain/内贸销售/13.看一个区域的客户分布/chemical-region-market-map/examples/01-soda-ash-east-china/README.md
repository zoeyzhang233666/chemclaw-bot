## 值得学的几处

1. **`narrative.conclusions` 每条都带数字与对比**，不写"需求旺盛"这类空话。
2. **同行与误判各成一节**：8 家同行写清"我们是竞品"；6 条误判写清"它实际用什么"。
3. **`method` 里有校准过程**：913 / 3,465 ≈ 26%，与华东玻璃产能占比互相印证。
4. **`gaps` 点名具体缺口**：县域名录覆盖 60%–70%、贸易商销量无法核实、项目增量误差 ±30%。
5. **`tier` 显式写入**：本例用的是按机会指数排名得到的 S/A/B/C，而不是作者最初的手工猜测（两者不同，见 git 历史里的 tier vs tier2）。
