# 交付前体检清单

生成之后、发给销售之前，逐条打勾。任何一条不过，就不要发。

## 数据

1. [ ] 所有区域取的是**同一天**（或同一周）的价格，日期写在图上。
2. [ ] 规格/牌号一致；含税口径一致；出厂 vs 到厂的差异写进 `basis_note`。
3. [ ] 每条价格能回溯到原始文章（`series.sources` 有 URL + 日期）。
4. [ ] 缺失样本用 `null` 且曲线断开，**没有插值**；`gap_note` 已写明。
5. [ ] 供需数字标注「估算」，没有冒用统计口径。

## 计算

6. [ ] 裸价差、运费、残差三列同时存在，且残差 = 裸价差 − 运费（抽查 2 行手算）。
7. [ ] 至少两种运输方式可比；水运对内陆枢纽显示「不可达」而不是给一个数。
8. [ ] 江海联运/长江港口已加中转费，没有算出「比实际便宜」的运价。
9. [ ] 基准区可切换，切换后 KPI、表、矩阵、统计全部重算（点一次验证）。

## 表达

10. [ ] 结论带数字，且区分「运费已解释」与「结构性偏紧」。
11. [ ] 没有出现「套利机会」「稳赚」这类表述；`disclaimer` 在页面底部与 Excel 里都有。
12. [ ] 每个区域至少一条数据缺口，写清缺什么、怎么补。

## 一致性

13. [ ] HTML 与 Excel 的最新价一致（`qa.py` 会核对 5/5）。
14. [ ] Excel 十张表齐全，缺口条数 = 各区域 gaps 之和。
15. [ ] 页面在 1440 宽与手机宽度下都不横向溢出（浏览器缩放 80%/100%/125% 各看一眼）。

## 快速自检命令

```bash
python scripts/build_all.py data.json --out out --name 产品多地区价格对比
node scripts/smoke.cjs "out/产品多地区价格对比.html"   # 需要 Node
```

`smoke.cjs` 用最小 DOM 桩跑一遍页面脚本，能抓到「白屏」级别的 JS 错误，
以及换基准区/换发货地/改费率后的重算异常。
