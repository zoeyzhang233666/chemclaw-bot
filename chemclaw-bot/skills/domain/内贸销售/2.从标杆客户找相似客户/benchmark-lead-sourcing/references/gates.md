# 五道 gate 与打分

每道 gate 都能**否决**一条线索。它们是交付物可信度的来源，不是可选步骤。

---

## 1. trace gate（每条都要有出处）

- 有 A 级证据（公告/官网原文写明该原料或该工序）→ `置信度 高`
- 只有 B/C 级（主体与业务板块可确认，用途属工艺推断）→ `中`
- 抓不到 → `来源 未核实` + `置信度 低`

低置信度条目**保留是有价值的**：它告诉销售「这条要电话问」。假的高置信度会让销售在电话里说错话。

## 2. subject gate（防域名劫持）

写入 `来源` 前确认**打开的页面与公司名对应**。三类失败要区分（见 `evidence-channels.md` 第 3 节）：
劫持 → 剔除 URL；反爬 → 保留并标注「建议人工复核」；坏链 → 保留公司、标注链接不可用。

## 3. peer gate（同行不是客户）

**最容易发生、也最伤销售信任的错误**：把同产品的生产方当成客户。

判定方法：用 A 级通道搜「公司名 + 产品名」，看命中片段把它当作**对外销售的产品**还是**采购的原料**。前者是 peer，剔除。

工程做法：在 `project.json` 的 `peer_keywords` 写入工艺路线关键词（如纯碱：`["氨碱","联碱","天然碱","纯碱生产"]`），`merge_leads.py` 命中即剔除并计数；**同时**把具名同行写进 `report_notes.json` 的 `peers`，交付报告必须列出。

典型误判形态（实测）：

| 形态 | 例子（纯碱项目） |
|---|---|
| 集团内自供原料的「客户」 | 金晶科技（子公司山东海天生物化工年产销约135万吨纯碱） |
| 副产/联产同产品的化工企业 | 华昌化工（联碱法纯碱）、浙江龙盛（子公司龙山化工40万吨纯碱） |
| 名称像下游、实为上游 | 苏盐井神（纯碱产销）、雪天盐业（电池级纯碱） |
| 跨区同行 | 三友化工、远兴能源、双环科技、和邦生物、江盐集团 |

## 4. link gate（抽检，标注而非删除）

抽 **≥40 条**链接判断「可达」与「主体一致」，落盘 `leads_raw/_qa_report.json`：

```json
[{"公司":"","来源":"","可达":true,"主体一致":true,"备注":"正常 / 反爬拦截，浏览器可访问，建议人工复核 / 404 / 空页"}]
```

若 A 级公告 PDF 占多数，把 PDF 也纳入抽检（200 + `application/pdf`），并如实备注「仅验证文件存在，正文未解析」。
`merge_leads.py` 会把未通过的条目标注进 `来源`（追加 `（⚠链接抽检：…）`），**保留条目**优于删除。

## 5. dedup gate（归一化去重）

跨 lane 必然重复。归一化：去括号内容 → 去掉 `股份有限公司/有限责任公司/有限公司/集团有限公司/集团/公司/股份` 后缀 → 比对。重复时保留**置信度更高**的那条。

---

## 过滤（不是 gate，但同样会移除条目）

- **区域过滤**：`region.provinces` 之外的条目剔除并在日志计数（因为用户要的是能跑的区域）。
- **弱相似过滤**：只有单一弱维度命中的（例如「下游市场」相同、但自身不消耗该原料）→ 剔除或降到低优先级，并在 `report_notes.json` 的 `weak_excluded` 里列名。

## 打分

### 用量强度（星级）

按**细分行业**关键词判定，取第一个命中的级别：

| 星级 | 含义 | 示例（纯碱项目配置） |
|---|---|---|
| ★★★★★ | 单客户可达千吨级/年 | 光伏玻璃、浮法、泡花碱、碳酸锂、氧化铝烧结法、洗涤、玻璃棉 |
| ★★★★ | 百吨级 | 印染、皮革、味精发酵、造纸脱墨、纤维素醚、电子玻璃、冶炼、焦化 |
| ★★★ | 数十吨级 | 医药原料药、陶瓷釉料、耐火、食品添加剂 |
| ★★ | 十吨级及以下 | 试剂、特种、卷烟 |

### 优先级

```
score = 强度星级 × 2 + 置信度分（高=3 / 中=2 / 低=0）
score ≥ 11 → 高      # 5星且有证据，或 4星且证据强
score ≥ 9  → 中      # 4星证据一般，或 3星但证据很强
否则       → 低
```

阈值与分值都可在 `project.json` 的 `priority_thresholds` / `confidence_scores` 里改。

**不要因为某个板块全是「中」就以为打错了**：某些板块天然单厂用量小（医药、陶瓷），但单价高、认证后粘性强，不应低估——这一点要写进报告的说明页。

### 品类归并（做统计用）

`细分行业` 字段由各 lane 自由填写，会有几十上百个取值，直接统计没有意义。在 `project.json` 的 `buckets` 里用关键词把它归并成 12–18 个大类。

**归并只匹配 `细分行业` 字段，绝对不要匹配 `需求点`**——需求点是自由叙述文本，常出现「复配」「制剂」等词，会把无关企业错误吸进某个品类（实测踩过的坑，会让某一类虚高 30% 以上）。
