# 失败日志（实测踩过的坑 → 修法）

按「症状 → 原因 → 修法」记。这些坑在弱 agent 身上几乎必然重演。

---

## 致命级（导致零产出）

### 1. 子代理上下文耗尽、直接崩溃

**症状**：子代理报 `failed before it finished`、`It left no closing message`，工作区无任何产出。
**原因**：lane 把公告检索的 `pageSize` 开到 30（单次返回几百 KB JSON），还把原始返回写成中间转储文件读进上下文。
**修法**：`pageSize ≤ 10`；brief 明写「禁止创建任何中间转储文件」；强制「每 5 条增量落盘」；崩溃后改用**枚举式 brief**（见 `lane-brief-template.md`）。

### 2. 空占位文件

**症状**：lane 文件只有 3 字节 `[]`，合并时解析异常。
**修法**：`` 先写 `[]` 占位再干活是禁止动作；合并脚本读文件前 `strip()`，空内容跳过并打印。

### 3. UTF-8 BOM 导致解析失败

**症状**：`json.decoder.JSONDecodeError: Unexpected UTF-8 BOM`。
**修法**：所有读入统一 `encoding="utf-8-sig"`（兼容有/无 BOM）；脚本写文件用 `encoding="utf-8"`（不带 BOM）。

## 数据质量级（不致命但会毁掉可信度）

### 4. 把同行当客户（最高频、最伤信任）

**修法**：peer gate。三种典型漏网形态：①集团内自供原料的「客户」（如金晶科技自己产纯碱）；②副产/联产同产品的化工企业（联碱法、天然碱）；③名称像下游、实为上游（盐化工企业）。
工程兜底：`project.json` 的 `peer_keywords` + 报告里列出具名同行。

### 5. 域名劫持

**症状**：写入的「官网」点开是反诈警示页、直播站、博彩站、域名出售页。
**修法**：subject gate——写入前确认页面内容与公司名一致；企业改名后旧域名常被抢注，不要按「形似域名」猜。

### 6. 置信度取值超出枚举

**症状**：写成 `中高`、`较高`，打分表查不到而回退默认值。
**修法**：合并时归一化（`中高→中`、`较高→高`、`较低→低`），其余非法值一律降为 `中`。

### 7. 跨 lane 重复

**症状**：同一家公司出现在两个 lane。
**修法**：归一化公司名去重，保留置信度更高的一条；同一集团的不同工厂**不要**合并成一条（它们是不同的采购主体）。

### 8. 品类归并串味

**症状**：统计出某品类异常偏多。
**原因**：归并关键词同时匹配了「需求点」——自由叙述文本里常出现「复配」「制剂」等词。
**修法**：**只匹配「细分行业」字段**。改完立刻从虚高回到正常。

### 9. 优先级阈值过松/过紧

**症状**：某板块一半以上都是「高」，失去区分度；或把 4 星的行业龙头压成「中」。
**修法**：`score = 强度×2 + 置信度分`，`≥11` 为高。这样「5 星有证据」与「4 星且证据强」都进高优先级。阈值放在配置里，可按项目调。

### 10. 弱相似条目污染名单

**症状**：名单里出现「下游市场相同但自己不消耗该原料」的企业（深加工厂、只做组装的厂），或行业内工艺根本不用该原料的厂（拜耳法氧化铝之于纯碱）。
**修法**：判定「是否自有窑炉/反应装置」「该原料是否进入主流程」；不满足则剔除或降到低优先级，并在报告的 `weak_excluded` / `process_mismatch` 里列名。

## 环境级（浪费轮次）

### 11. 把「联网工具失败」当成「没网」

**症状**：`web_fetch` 报 `resolves to a non-public IP address`、`web_search` 报无 API Key，agent 就宣布无法取证。
**修法**：**同一台机器上换个通道各试一次**——Python `urllib`、`curl`、PowerShell `Invoke-WebRequest`。实测某沙箱里 `web_fetch`/`web_search` 全灭，而 Python 与 PowerShell 直连 cninfo 完全正常。
**通道优先级**：宿主原生工具 → `scripts/fetch.py` → shell 直连 → 用户代抓（并整体降一档置信度）。

### 12. 反复重试搜索引擎

**症状**：连试 Bing/百度/360/搜狗/Yandex/DDG 全部失败，烧掉十几轮。
**修法**：每级通道只试一次。**发现新企业靠模型产业知识，核验靠 A/B/C 三级**；搜索只在宿主工具可用时作为加速器。

### 13. 把反爬拦截当坏链

**症状**：抽检把百科 403、企业信息平台壳页判成「不可达」，用户以为链接坏了。
**修法**：区分三类——劫持（剔除 URL）、反爬（标注「建议人工复核」）、真空页/故障站（标注链接不可用）。只有第一、三类需要换源。

### 14. 子代理说「完整 JSON 在主回复里」但消息里只有摘要

**修法**：brief 从一开始就写明「用 write 写文件，回复只给一句概况，不要贴 JSON」。已发生的，回一条消息要求它「原样重发/直接落盘，不要重新做研究」。

### 15. glob 捡到中间文件

**修法**：约定 `_` 前缀 = 中间产物，合并脚本跳过。

### 16. 省份统计出现荒谬数字（如「166 个省级地区」）

**原因**：`所在地` 由 lane 自由填写（`浙江/杭州`、`天津`、`浙江杭州（千岛湖…）`），按 `/` 切分拿不到省份。
**修法**：用省份白名单在字符串里查找首个命中项；找不到记「未标注」。区域过滤同时用这份白名单。

## 脚本/平台级

### 17. Windows PowerShell 5.1 用 ANSI 读取 `.ps1`

**症状**：脚本里的中文变成乱码、报语法错误；`.ps1` 被拒绝执行（未签名）。
**修法**：若必须写 PowerShell 包装脚本，**脚本内容全部用 ASCII**（中文只走命令行参数），并在每次调用前 `Set-ExecutionPolicy -Scope Process Bypass -Force`。跨平台项目请直接用 `scripts/fetch.py`，绕开这个问题。

### 18. 控制台中文乱码（不影响数据）

**症状**：脚本输出的中文在 Windows 控制台显示为乱码。
**修法**：这只是显示层；文件内容是 UTF-8 正常的。需要时可 `[Console]::OutputEncoding=[Text.Encoding]::UTF8`，或把统计写入文件再读。

### 19. A 级公告 PDF 无法自动解析

**症状**：想从公告正文抓「采购金额/单耗」，抓不到。
**原因**：`adjunctUrl` 指向二进制 PDF，纯标准库无 PDF 解析能力。
**修法**：只用检索接口返回的 `announcementContent` 高亮片段作证据，PDF 链接作为人工复核入口；报告里如实写明这一边界。

## 一条通用规律

**失败几乎都发生在「子代理要读大块内容」的时刻**，而不是判断环节。所以所有纪律都指向同一件事：
**先落盘、再汇报；限制单次读取体量；让每条 lane 的产出保持在 12–20 条。**
