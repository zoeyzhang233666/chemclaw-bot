# 结果结构（固定不变的部分）

产品会变，**结构不变**。任何化工品的交付物都长这样，销售拿到手不需要重新学。

---

## 1. lane 产出：`leads_raw/NN_<lane>.json`

UTF-8 JSON 数组，字段固定九个：

```json
[
  {
    "公司": "福莱特玻璃集团股份有限公司",
    "细分行业": "光伏玻璃（超白压延）",
    "省市": "浙江/嘉兴",
    "需求点": "熔窑配合料助熔剂：产品名提供 Na2O，降低熔融温度与玻璃液粘度；窑炉连续运行需稳定供应",
    "规模线索": "嘉兴、安徽凤阳等多基地，日熔量行业前二（公告口径）",
    "相似维度": "产品结构（超白原片）+ 工艺路线（熔窑助熔）",
    "相似逻辑": "与标杆同为超白压延/浮法熔窑工艺，配合料体系一致、单耗相近，故需求同源。",
    "来源": "http://static.cninfo.com.cn/finalpage/....PDF",
    "置信度": "高"
  }
]
```

| 字段 | 约束 |
|---|---|
| `公司` | 全称或「全称（简称，代码）」。跨 lane 去重按归一化名 |
| `细分行业` | 10 字内短标签（统计用）。**不要**在这里写长句 |
| `省市` | `省份/城市`；省份必须命中 `region.provinces` |
| `需求点` | 到工序级：在哪一步、起什么作用、投料形态/计量方式 |
| `规模线索` | 产线数、日熔量、产能、基地数；**没有证据就不要写数字** |
| `相似维度` | `维度（具体落点）`，可两项用 ` + ` 连接 |
| `相似逻辑` | 为什么相似→相似原料需求，1–2 句，必须点到工序与不可替代性 |
| `来源` | 可点开的 URL；多个用空格分隔；核不到写 `未核实` |
| `置信度` | 只能 `高` / `中` / `低`（枚举外的值会被降级为 `中`） |

`leads_raw/` 下**以 `_` 开头的文件不参与合并**（约定为中间产物：`_qa_report.json`、`_qa_todo.json`、`_patch*.json`）。

## 2. 合并结果：`leads.json`

在九字段基础上增加：`板块`（来自 lane 配置）、`用量强度`（★）、`优先级`（高/中/低），并在 `来源` 里追加抽检标注。

## 3. Excel：`下游潜客池.xlsx`（5 个工作表）

| 表 | 内容 |
|---|---|
| ① 标杆客户画像 | 主体信息、六要素表（含证据链接）、五维判据表（相似点落在哪一项 + 为什么带来相似需求）、复制话术、本批按相似维度的命中分布 |
| ② 说明与行业地图 | 条数/分布/置信度统计、用法建议、打分口径、**数据来源与核验方法**、**使用边界**、行业地图（板块/细分方向/用料逻辑/用量强度/采购与开发要点） |
| ③ 客户线索总表 | 13 列：序号 / 行业板块 / 细分行业 / 公司名称 / 所在地 / 用量强度 / 需求点（用料工序）/ **相似维度（相似点落在哪一项）** / **为什么会产生相似原料需求** / 规模线索 / 优先级 / 置信度 / 线索来源；冻结窗格 + 自动筛选 |
| ④ 重点客户TOP | 只含高优先级，按板块排序 |
| ⑤ 分布统计 | 按板块（含高优先级数）/ 按省份 / 按细分品类（已归并）/ 按置信度 / 按优先级 |

## 4. HTML：`标杆客户复制与潜客池报告.html`（单文件，9 节）

| 节 | 内容 |
|---|---|
| 0 一页摘要 | 条数、覆盖、高优先级数、置信度分布、复制逻辑一句话 |
| 1 标杆客户画像 | 主体信息 + 六要素表（每行带证据链接）+ 证据强度说明 |
| 2 相似性判据 | 五维判据表（判据 + 为什么相似→相似需求）+ 本批维度命中分布 |
| 3 应用地图与 lane 设计 | 行业地图表（含渠道型 lane 的说明） |
| 4 潜客池 | 板块分布表 + 省份分布 + **重点客户表** + **全量线索表（可搜索/多维筛选）** |
| 5 证据与置信度分级 | 高/中/低三档判定标准 + 电话里怎么用 + 取证通道说明 + 使用边界 |
| 6 被剔除名单 | 6.1 同行（peer gate）6.2 工艺不符 6.3 弱相似或主体风险 |
| 7 未覆盖的缺口与负结果 | 检索为零的方向、通道限制、只能电话核实的部分 |
| 8 可复制动作清单 | 4–8 步 SOP（含标杆硬事实、报价与账期打法） |

技术约束：**内联 CSS/JS、零外链、零 CDN**（离线可打开）；带 `@media print` 打印样式，浏览器「打印 → 另存为 PDF」即可分发包；表格支持关键词搜索与板块/省份/优先级/置信度/相似维度筛选，并实时显示命中行数。

---

## 5. 使用边界（必须写进交付物）

1. **需求点分两类**：有公告/官网原文佐证的为实证（置信度高）；披露率低的行业按工艺推导（置信度中）——首次接触需向对方研发/品控确认实际品种与用量。不得把推断表述成对方披露过。
2. **不含联系人**：本 skill 不产出电话/邮箱/经营状态，正式外呼前用企业信息平台补齐并核对是否停产、是否被并购。
3. **不含经销商**：只收有自有生产实体的工厂；但「把该产品当原料深加工/复配再转售」的厂属于合格客户，单独成板块。
4. **同行名单必须列出**：用户需要知道「已经排掉了谁」。
5. **A 级公告只能取到高亮片段**：PDF 为二进制，自动化仅能确认文件存在；正文细节（采购金额、单价、单耗）需人工点开复核。
6. **缺口要写**：零命中的行业、因区域限制未纳入的省份、因非上市无原文只能电话核实的板块，都要在报告第 7 节列明。
