# 相似性框架：怎么把「标杆客户」翻译成「该打谁」

这是本 skill 与「按工商行业门类匹配」的根本区别。
工商门类是**注册口径**（一家玻璃厂和一家纯碱厂可能都注册成「非金属矿物制品业」）；相似性是**用料口径**（它在配方里干什么、用量由什么决定）。

---

## 1. 五个判定维度（通用骨架）

| 维度 | 判据（要在候选企业身上能判定） | 为什么会带来相似原料需求 |
|---|---|---|
| **产品结构** | 最终产品是否与标杆同属一个化学体系/配方骨架 | 配方里必须有该组分，产品不变则原料需求结构不变 |
| **工艺路线** | 该原料以什么身份进入主流程：助熔剂 / 化学计量反应物 / 中和成盐剂 / 脱硫剂 / 聚合单体 / 溶剂 | 替代会造成质量或收率损失，属刚性消耗 |
| **下游市场** | 下游行业是否对原料无替代；终端景气决定开工率 | 开工率决定消耗节奏与补库周期 |
| **规模** | 是否自有窑炉/反应装置、单厂年用量量级 | 用量规模决定其必然走「厂家直采 + 长协」而非零星采购 |
| **产业链位置** | 是否中游加工厂、对该原料是纯采购方 | 决策在工厂端、用量可预测，成功经验（报价/账期/到货节奏）可直接复制 |

**判定纪律**：命中的维度越多，越值得优先外呼。只命中单一弱维度（尤其只有「下游市场」相同、自身并不消耗该原料）的企业 → 剔除或降为低优先级，并在报告里写明理由。

---

## 2. 换产品时，用五个问题把维度实例化

给任何化工品做画像，回答这五问即可得到该产品的判据：

1. **身份**：它在下游配方/流程里扮演什么角色？（助熔剂？反应物？中和剂？脱水剂？pH 缓冲？脱硫剂？复配单体？）
2. **体系**：哪些最终产品**化学上离不开**它？（如钠钙硅玻璃离不开 Na₂O；沉淀法白炭黑离不开硅酸钠）
3. **工序**：在哪个工序、什么条件、什么投料形态（粉料/溶液/计量级）？
4. **量级**：单吨产品或单条产线的单耗是多少？→ 推出「5 星=千吨级/年」的行业名单
5. **边界**：谁是同行（自己也生产该产品）？谁只是贸易商？谁是「以它为原料但用量极小」的假客户？

## 3. 已实例化的例子（三个不同化工品）

### 纯碱 Na₂CO₃（本项目）

- 身份：玻璃熔窑**助熔剂**（提供 Na₂O）、碳酸锂**沉淀剂**（化学计量）、洗涤剂**助洗剂/填充**、脱硫**钠碱**、CMC/味精**中和成盐剂**
- 产品结构判据：钠钙硅玻璃、硅酸盐、钠盐体系
- 工艺路线判据：熔窑连续熔化 / 反应釜沉淀 / 中和工序
- 5 星 lane：光伏玻璃、浮法、日用与药用玻璃、泡花碱、碳酸锂、氧化铝（烧结法）、洗涤、玻璃棉
- 同行关键词：`氨碱`、`联碱`、`天然碱`、`纯碱生产`
- 典型弱相似（剔除）：玻璃深加工厂（外购原片、不熔化）、拜耳法氧化铝（用烧碱）、纯烧碱路线造纸/纤维素醚

### 钛白粉 TiO₂（颜料级）

- 身份：涂料/塑料/油墨中的**遮盖颜料**（配方核心组分，非助剂）
- 产品结构判据：溶剂型/水性涂料、母粒、装饰纸、化纤消光
- 工艺路线判据：分散研磨工序投料（颜基比决定单耗）
- 5 星 lane：建筑涂料、工业涂料、塑料母粒、造纸装饰纸
- 同行关键词：`钛白粉生产`、`硫酸法`、`氯化法`
- 弱相似（剔除）：仅做涂料代工但配方由品牌方提供、不自主采购颜料的厂；经销商

### 柠檬酸（食品/工业级）

- 身份：酸味剂、pH 调节剂、螯合剂、清洗剂
- 产品结构判据：饮料/调味品配方、工业清洗剂、混凝土缓凝、油田
- 工艺路线判据：配料/复配工序（计量级投料）
- 5 星 lane：饮料与茶饮、洗涤与家清、混凝土外加剂、工业清洗
- 同行关键词：`柠檬酸生产`、`发酵法柠檬酸`
- 弱相似（剔除）：仅转售的贸易商、以柠檬酸钠为主业的复配厂（若其自产柠檬酸则属同行）

> 结论：**框架不变，判据随产品重写**。写 `project.json` 的 `similarity_dimensions` 时，就是在写这份产品的五维判据。

## 4. 产出要求：每条线索必须能回答两个问题

1. `相似维度`：相似点**具体落在哪一项**（写成「维度（具体落点）」，如 `工艺路线（熔窑助熔）`、`产业链位置（配方型批量用料）`）
2. `相似逻辑`：**这种相似为什么带来相似的原料需求**——必须点到工序、投料身份与不可替代的原因

反例（不要这样写）：
> ❌「同属玻璃行业，相似度高」—— 这是工商门类匹配，销售无法在电话里用。

正例：
> ✅「与标杆同属钠钙硅熔窑连续成型工艺，配合料中纯碱提供 Na₂O 并使石英砂在 1500℃ 级熔窑中降低熔化温度与玻璃液粘度；原料需求结构一致，纯碱属不可替代的批量原料。」
