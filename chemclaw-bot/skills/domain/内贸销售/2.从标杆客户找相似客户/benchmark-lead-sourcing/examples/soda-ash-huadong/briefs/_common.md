# lane 共用作业纪律（所有 lane 必读，逐条遵守）

## 0. 任务性质
你在为一家**纯碱**（重质纯碱（浮法/光伏玻璃、氧化铝、脱硫）／轻质纯碱（洗涤、泡花碱、印染）／食品级、药用级（发酵、原料药））供应商梳理**华东**
的下游用料工厂线索。标杆客户是**株洲旗滨集团股份有限公司（旗滨集团，601636.SH）**。
你要找的是**业务特征与标杆相似、因而会产生同类纯碱需求**的工厂，
**不是**按工商行业门类匹配。

产品用途总述：玻璃熔窑助熔剂与唯一钠源、碳酸锂沉淀剂、泡花碱（硅酸钠）主原料、洗涤助洗剂与pH缓冲、脱硫钠碱、印染与制革中和剂、发酵与成盐用碱

## 1. 相似性判据（每家都要判定命中哪几项）
- **产品结构**：最终产品是否为钠钙硅（或超白/特种）玻璃、硅酸盐及其深加工品，Na₂O 是否为配方必需组分
- **工艺路线**：是否为高温熔窑/反应窑连续生产，纯碱是否以配合料助熔剂或化学计量反应物进入主流程（替代会造成质量或收率损失）
- **下游市场**：下游是否为建筑、光伏、汽车、电子、医药包材、日化、纺织等对纯碱无替代的行业，开工率是否决定消耗节奏
- **规模**：单厂纯碱年用量是否数百吨以上（领先者千吨至万吨级），是否有自有窑炉/反应装置
- **产业链位置**：是否为产业链中游加工制造厂、对纯碱为纯采购方（不含贸易商，更不含纯碱同行）

## 2. 取证通道（按优先级，每级只试一次）
1. **你自己的联网搜索/抓取工具**（宿主提供则优先——发现企业主要靠它）。
2. **结构化取证脚本**（仅需 Python 标准库；工作目录任意）：
```bash
python "./benchmark-lead-sourcing\scripts\fetch.py" cninfo -k "<公司名> 纯碱" -n 8 --snippet 240
python "./benchmark-lead-sourcing\scripts\fetch.py" cninfo -k "纯碱 <行业词>" -n 8
python "./benchmark-lead-sourcing\scripts\fetch.py" html "https://<官网>/" --grep "纯碱"
python "./benchmark-lead-sourcing\scripts\fetch.py" sina -c <6位A股代码>
```
   注意：公告检索的 `pageSize` 必须 ≤10；产品**别名/学名**索引很差，要用正式名；短公司名会被模糊匹配污染，必须逐条判读高亮片段。
3. shell 直连（curl / iwr）兜底。三条通道各试一次即可，**不要反复重试搜索引擎**。

## 3. 硬性纪律（同类代理曾因违反而零产出崩溃）
1) 目标产出 12–20 条，绝不贪多。
2) 每家公司最多抓 1–2 个页面；抓取失败**直接跳过，不重试、不换域名反复试**。
3) 总网络调用 ≤30 次；**禁止创建任何中间转储文件**。
4) **每完成 5 条就用 write 增量落盘**（读回已有数组 → 追加 → 覆盖写），崩溃也要有产出。
5) 严禁编造公司名、产能数字或 URL；核不到就写 `未核实` + `置信度 低`。
6) 写入来源前确认页面**确实属于该公司**（点开是反诈页/影视站/博彩站/出售页的域名一律弃用）。
7) 只收**华东**（山东/江苏/浙江/安徽/上海）
   有**自有生产实体**的工厂；不含经销商/贸易商。但把纯碱当原料**深加工/复配再转售**的厂属于合格客户。
8) **peer gate（同行不是客户）**：自己也生产纯碱的企业必须剔除，并在回复里说明剔除了谁。
   本产品同行线索关键词：氨碱、联碱、天然碱、纯碱生产、纯碱厂

## 4. 必须回答的两个问题（每家都要写清楚）
- `相似维度`：从 产品结构/工艺路线/下游市场/规模/产业链位置 中选 1–2 项，写成「维度（具体落点）」。
- `相似逻辑`：**这种相似为什么带来相似的原料需求**——点到工序、投料身份、为何不可替代。
  ⚠️ 禁止写「同属XX行业、相似度高」这类工商门类式表述。

## 5. 落盘格式（严格照抄字段名，UTF-8，JSON 数组，路径见各 lane 文件）
```json
[
  {
    "公司": "某某股份有限公司（简称，代码）",
    "细分行业": "光伏玻璃",
    "省市": "浙江/嘉兴",
    "需求点": "在哪个工序、起什么作用、投料形态/计量方式",
    "规模线索": "产线数/日熔量/产能（没有证据就不要写数字）",
    "相似维度": "产品结构（超白原片）+ 工艺路线（熔窑助熔）",
    "相似逻辑": "与标杆同为……据……故需求同源。",
    "来源": "可点开的 URL（多个用空格分隔；核不到写 未核实）",
    "置信度": "高"
  }
]
```
- `细分行业`：10 字内短标签（用于统计），不要写长句。
- `省市`：`省份/城市`，省份必须命中：山东 / 江苏 / 浙江 / 安徽 / 上海。
- `置信度`：只有 `高`（原文写明该原料/工序）、`中`（主体与工序可确认，用途属工艺必然）、`低`（主体都没核到）。

## 6. 回复方式
**只回一句概况**：条数、置信度分布（高中低）、剔除的同行名单、放弃原因。
**不要把 JSON 贴进回复。**
