# 报价草稿 · 七要素写法与口径表述

一份能直接发出去的内贸报价单，缺任何一段都会让对方来回问。

## 结构

```
① 商品明细：序号/产品/规格牌号/数量/单位/单价/金额/备注
② 价格与口径：税费口径文字 + 运费口径文字 + 价税构成（不含税金额、税额、税率、价税合计）
③ 数量与执行口径：试单量 vs 月用量；正式合同以书面确认数量为准；超出部分单价怎么算
④ 交付条件：交货地点 / 运输方式 / 交期 / 包装
⑤ 付款条件
⑥ 报价有效期：起止日期 + 逾期处理 + 波动条款
⑦ 待客户确认事项 + 备注 + 生成说明（谁在什么时候确认了单价）
```

## 口径标准表述

税费口径（三选一，写全票种，别只写"含税"）：

- `含税（13% 增值税专用发票）` — 化工品内贸默认，一般纳税人客户
- `含税（9% 增值税专用发票）` — 运输/部分服务，或客户要求
- `含税（3% / 普票）` — 小规模纳税人，或客户不要专票
- `不含税（税额另计）` — 报价不含税，合同另计税额

运费口径（三选一）：

- `到厂价（含运费）` — 我方送到客户厂区，报价含全程运费与卸货协调
- `出厂价（不含运费）` — 客户自提或自理运输
- `送到站（含运费至指定站）` — 送到铁路/港口站，站到厂客户自理

纯碱这类大宗，运费能占到货价的 5%~15%，**口径错一个字，几十元/吨就出去了**，所以口径只能由销售选。

## 价税构成怎么算

含税口径（单价 1580、数量 200、税率 13%）：

```
金额（价税合计） = 1580 × 200 = 316,000.00
不含税金额      = 316,000.00 ÷ 1.13 = 279,646.02
税额            = 316,000.00 − 279,646.02 = 36,353.98
```

不含税口径：

```
不含税金额 = 1580 × 200 = 316,000.00
税额       = 316,000.00 × 13% = 41,080.00
价税合计   = 357,080.00
```

Excel 里全部用 `IF(单价="","待填单价", …)` 包一层，单价空着时不显示 `#VALUE!`。

## 有效期与波动条款

- 纯碱/甲醇等大宗：默认 **7 天**，最多 15 天；锁价要另行审批。
- 必须写逾期后果："逾期未确认的，价格与交期需重新确认"。
- 必须写波动条款："原材料大幅波动时我方有权提前书面通知调整"。

## 待客户确认事项（这一段最值钱）

把两类东西全部列出来，一条不落：

- A 类里标"待客户确认"的字段；
- B 类里用了假设的字段（写"按我方假设「X」，请客户确认"）；
- `unreadable` 里的手写/遮挡数字；
- 有效期天数本身。

这一段是报价单的免责清单，也是下一轮沟通的提问清单。删掉它，报价单就等于替客户做了所有决定。

## 模板占位符（`templates/报价模板_默认.md`）

公司有自己的版式时，复制它改成自己的，占位符保持不变即可：

| 占位符 | 内容 |
|---|---|
| `{{company}}` `{{contact}}` | 我方抬头 / 联系人 |
| `{{quote_no}}` `{{quote_date}}` `{{valid_until}}` `{{valid_days}}` | 单号 / 日期 / 有效期 |
| `{{customer}}` `{{customer_contact}}` | 客户抬头 / 联系人 |
| `{{product}}` `{{grade}}` | 产品 / 规格 |
| `{{quantity}}` `{{qty}}` `{{qty_unit}}` | 数量口径原文 / 报价数量 / 单位 |
| `{{unit_price}}` `{{amount}}` `{{net}}` `{{tax}}` `{{tax_rate}}` | 单价 / 价税合计 / 不含税 / 税额 / 税率 |
| `{{tax_mode}}` `{{freight_mode}}` | 税费 / 运费口径 |
| `{{place}}` `{{incoterm}}` `{{delivery_date}}` `{{packaging}}` `{{payment}}` | 交付与付款 |
| `{{pending}}` | 待客户确认清单（自动成列表） |

用法：`build_quote.py fields.json --template 我的报价模板.md …`
未识别的占位符会原样留在文里，方便一眼发现漏改。

## 排版要求（Excel 05 表）

- 单价/数量/金额全部引用「04 价格与口径」，改一处全表联动；
- 单价空 → 显示"待填单价"，金额不出现 `#VALUE!`；
- 行高按字数估算，长规格文本不许被裁切（`build_xlsx.row_height`）；
- 打印区域固定、横向、缩放到 1 页宽，A4 出来就是正式版式。

## 反例

| 写法 | 问题 |
|---|---|
| "价格面议" | 不是报价单 |
| "含税价 1580" | 没说票种，客户默认 13% 专票，后续扯皮 |
| "数量 800 吨" | 把月用量当首单量 |
| "有效期一个月" | 大宗价格一个月不锁等于白送调价权 |
| 条款里不写运输方式 | 到厂/出厂差价没人认领 |
| 待确认事项写"详见附件" | 等于没写 |
