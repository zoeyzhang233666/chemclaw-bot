# 产品画像（product profile）字段说明

`products/<product>.json` 是“换品类”时唯一需要大改的配置文件。它只描述产品事实与
商务默认值，**永远不包含价格**。

## 必填

| 字段 | 说明 | 例 |
|---|---|---|
| `product_id` | 稳定英文 id，文件名一致 | `soda-ash` |
| `product_name` | 中文品名 + 形态/等级 | `纯碱（重质）` |
| `aliases` | 客户可能说的别名、英文、CAS/分子式 | `["碳酸钠","Soda Ash","Na2CO3"]` |
| `standard` | 国标/行标/企标；没有就写“客户验收标准” | `GB/T 210-2022 工业碳酸钠` |
| `grades` | 等级/牌号列表，每个带用途和典型指标 | 重质/轻质 |
| `packaging` | 常见包装形态 | 吨包、编织袋、槽车 |
| `documents` | 随货/准入单证 | COA、MSDS、营业执照 |
| `tax` | 适用税率与票种（需财务复核） | 13% 专票 |
| `commercial_defaults` | 报价默认口径（仍须销售确认） | 7 天、元/吨、到厂价 |
| `price_policy` | 固定写“不包含价格” | 见示例 |

## 选填

| 字段 | 说明 |
|---|---|
| `cas` | CAS 号；混合物可留空 |
| `hs_code` | 出口/报关用；内贸可留空 |
| `storage` | 储存条件、禁配物 |
| `transport` | 运输方式、危化品属性 |
| `downstream` | 下游行业，用于理解客户用途 |
| `sources` | 标准/法规/行业来源，带 URL 与访问日期 |

## 换品类检查清单

- [ ] 产品名是否能把“大类”落到“具体等级/牌号”？
- [ ] 客户给的指标是否逐条保留原话，没有擅自换算？
- [ ] 包装单重、托盘、缠膜、卸车方式是否写清？
- [ ] 税率/票种是否财务复核过？
- [ ] 是否误把公开行情价写进 `commercial_defaults`？（不允许）
- [ ] 是否有“待客户确认”的字段，而不是用行业惯例补齐？

## 示例

- 纯碱：`products/soda-ash.json`
- 空白模板：`products/_template.json`
