# 字段 schema · 询盘标准化

10 个业务字段 + 2 个我方口径。字段结构冻结：加字段要同步改 `scripts/_common.py` 的 `FIELD_SPEC`，
不然工作台、Excel、草稿、自检四处会漂移。

## A 类 · 必须补充后才能报价

| key | 字段 | 单位/形式 | 判定口径 | 不算数的写法 |
|---|---|---|---|---|
| `product` | 产品名称 | 文本 | 客户原话中的品名；重质/轻质、牌号能区分就区分 | "你们的碱"（无品名） |
| `grade` | 规格 / 牌号 | 文本 | 客户给的内控指标原话，分号连接 | "符合国标"（未给指标） |
| `quantity` | 数量 | 吨 | 必须拆"试单量 / 月用量"，报价默认取试单量 | 只有"用量不小" |
| `place` | 交货地点 | 文本 | 省市 + 厂区/仓库（含卸车条件更好） | "你们送过来" |
| `customer` | 客户名称 | 文本 | 开票主体全称；只有简称 → 待客户确认 | "盐城华宇玻璃"（无有限公司） |

## B 类 · 可先按假设准备

| key | 字段 | 默认假设 | 客户改口时的动作 |
|---|---|---|---|
| `packaging` | 包装 | 1000kg 吨包，栈板+缠膜 | 按客户指定改；槽车散装要确认卸车泵与罐容 |
| `delivery_date` | 交期 | 款到后 5~7 个工作日到厂 | 客户要求具体到货日 → 按排产回签，留缓冲 |
| `payment` | 付款条件 | 款到发货（电汇） | 客户要账期 → 走信用审批，不在报价阶段口头松动 |
| `incoterm` | 运输方式 | 汽运整车 | 偏远/小批量改零担或铁路，成本差异要重算 |
| `validity` | 报价有效期 | 7 天 | 锁价/长约另行审批；大宗随行就市不要给 30 天 |

## C 类 · 我方口径（不可从询盘单向提取）

| key | 字段 | 取值 |
|---|---|---|
| `tax_mode` | 税费口径 | 含税（13% 增值税专用发票）／含税（9%）／含税（3%/普票）／不含税（税额另计） |
| `freight_mode` | 运费口径 | 到厂价（含运费）／出厂价（不含运费）／送到站（含运费至指定站） |

询盘里出现"13% 专票""送到厂"这类字样，只写进 `hint`（工作台显示为线索），**不自动选中**。

## 状态机

```
已提取 extracted  ──销售确认──▶ 保持 extracted
      │
      ├─ 拿不到原文（客户没说） ─▶ 缺 missing（A 类）/ 我方假设 assumed（B 类）
      └─ 有值但需客户点头 ─────▶ 待客户确认 tbc
```

规则：

- A 类空值只能是 `missing` 或 `tbc`；写了值还标 `tbc` 时，闸门照样拦住（"待确认"不算有值）。
- B 类空值默认 `assumed`，渲染时补默认值并强制加"（我方假设 · 待客户确认）"。
- 每条有值的行都要有 `source`（素材编号 + 原句），否则自检报 WARN。

## 易混案例

| 情形 | 正确记法 | 原因 |
|---|---|---|
| "月用量 800 吨，先试单 200 吨" | 数量 = `试单 200 吨；月用量 800 吨`，报价数量 200 | 首单按 800 报等于自降单价 |
| "一个月怎么也得七八百吨吧" | 数量 = 缺，问法："首单多少吨？" | 概数不是数量 |
| "1?30 元/吨"（手写） | 进 `unreadable`，不填任何字段 | 猜数字会毁掉整张报价单 |
| "我们只要重质碱" | 产品 = 重质纯碱 | 通用名能落到具体品类就落 |
| "指标按你们厂标" | 规格 = 待客户确认，附我方标准指标供其确认 | "按厂标"不是客户指标 |
| "送货上门" | 交货地点 = 待客户确认；运费线索记"倾向到厂价" | 没有地点算不出到厂价 |
| 询盘里写"请注明付款条件" | 付款条件 = 我方假设（客户并未给出） | 客户提问 ≠ 客户给条件 |
| "含税"两个字 | 税费口径 hint；仍需我方选具体税种/票种 | 含税 ≠ 必然 13% 专票 |
| 同一客户两个厂区 | 交货地点写清厂区；必要时拆两条询盘 | 泰州厂 ≠ 南通基地，运费差很多 |
| 客户说"价格好我们可以签年框" | 不进字段，进备注/待确认 | 意向不是承诺 |
