# 失败日志 · 症状 → 根因 → 改法

出问题先在这里找，再改代码。每条都对应代码里的一个具体位置。

## 抽取类

| 症状 | 根因 | 改法 |
|---|---|---|
| 产品抽成"碱"或空 | 品名词表短词优先 | `PRODUCTS` 长词在前，取最左命中 |
| 规格里出现重复项（`180 目` + `粒度 180 目`） | 多个正则都命中 | `ex_grade` 里有包含去重，新增词表时保留逻辑 |
| 数量只抽到月用量 | 只匹配一种口径 | `ex_quantity` 必须同时返回试单与月用量，`quote_quantity` 取试单 |
| 客户名是"我们是盐城华宇玻璃" | 前缀没剥 | 抽完统一 `re.sub(r"^(?:我们|我司|本公司|我们是)", "", …)` |
| 客户名抽成"盐城的厂" | 词表里放了单独"厂" | 全称词表只认 公司/集团 后缀；"厂"不进后缀 |
| 交货地点带一长串括号备注 | 正则窗口太宽 | 在 `（`/`(` 处截断 |
| 付款条件抽成"款到发货" | 客户只是问"请注明付款条件" | 只有客户自己说出条件才记；问句不算 |
| 交期只到"10 月" | 少了"底/上旬"分支 | `DATE_PATTERNS` 要含 `(\d{1,2})\s*月\s*(上旬|中旬|下旬|底)` |
| 手写 `1?30` 被算成数字 | 正则太宽 | `[0-9]\s*\?\s*[0-9]` 一律进 `unreadable` |
| 图片/PDF 上传后像"识别了" | 前端伪 OCR | 只登记文件名，明确提示"请粘贴 OCR 文字" |

## 闸门类

| 症状 | 根因 | 改法 |
|---|---|---|
| 单价空着按钮却亮了 | 闸门只查了字段 | `blockers()` 四项都要查：字段/税费/运费/单价+确认语 |
| 写了值但状态是"待客户确认"，闸门放行 | `_row_ready` 只看有没有值 | 必须同时 status ∉ {missing, tbc} |
| 改完价格后草稿没变旧 | 没设 stale | 任何 input 都要 `touch()` → stale + 提示条 |
| 脚本没确认语也能出报价 | 只判了 `--price` | `build_quote` 必须校验 `ack`，缺则 exit 2 |

## 报价类

| 症状 | 根因 | 改法 |
|---|---|---|
| 报价里"待确认"清单少了几条 | 只遍历了 A 类 | B 类假设 + unreadable + 有效期都要进 |
| 假设写成事实（"付款：款到发货"） | 没打标签 | 用 `effTagged()`，B 类非提取值一律带"（我方假设 · 待客户确认）" |
| 含税金额算成 `单价×数量×1.13` | 含税/不含税口径搞反 | 含税：`net = amount/(1+rate)`；不含税：`net = amount` |
| 报价单号 `QT-26102001` | 只取了数字末 8 位 | `auto_quote_no` 取前 8 位日期 + 尾号 |
| 生成说明日期与报价日期不一致 | 用了 `today()` | 用 `price.confirmed_at`，命令行可传 `--confirmed-at` |
| 模板渲染留着 `{{…}}` | 占位符没覆盖 | 故意保留，便于一眼发现；`selfcheck` 会报"未出现模板占位符"失败 |

## Excel 类

| 症状 | 根因 | 改法 |
|---|---|---|
| 金额列 `#VALUE!` | 空价直接相乘 | `IF(单价="","待填单价",…)` |
| 长规格被裁成半行 | 用了固定行高 | `row_height(text, chars_per_line)` 估算 |
| 单价列被自动填了默认 | 代码里给了 fallback | 04 表单价默认必须 `write_blank`；只有 `build_quote --ack` 已确认时才写值 |
| 演示工作簿里单价还是空的 | `sheet_price` 无条件清空 | 已确认场景按 `doc["price"]["unit_price"]` 写入，官方版仍为空 |
| 05 表不跟着 04 变 | 写的是静态值 | 全部 `write_formula` 引用 `'04 价格与口径'!$C$x` |
| 打印出来表格断页 | 没设 print_area / fit | `set_landscape()` + `fit_to_pages(1,0)` + `print_area` |

## HTML 类

| 症状 | 根因 | 改法 |
|---|---|---|
| 打开是空白 | JSON 里含 `</script>` 或引号没转义 | `json.dumps(ensure_ascii=False)` 后直接内嵌；避免 `</script>` 字面量 |
| 打开有上传区但没有默认文本 | textarea 只在点击“载入示例”时填 | `init()` 里预填 `__DEMO_TEXT__` 并 `pasteWrap.open = true` |
| 导出的字段 JSON 带了价格 | 导出整个 `price` 段 | 只导出 `meta/fields/gate/notes/unreadable`，单价永不进字段文件 |
| 改了字段进度不动 | 只改了 DOM 没重渲染 | 每次 `input` 都 `renderAll()` |
| 窄屏横向滚动 | 固定像素宽度 | 网格用 `minmax()` + 1080px 断点 |
| 复制按钮无效 | `file://` 下 clipboard 受限 | `navigator.clipboard` 失败要 fallback 到 `execCommand` |
| 打印出整页工具 | 没写 print 媒体查询 | `@media print` 隐藏上传/字段/闸门，只留草稿 |

## 流程类

| 症状 | 根因 | 改法 |
|---|---|---|
| 业务员拿"待客户确认"去报价 | 以为标了就能用 | A 类里带"待确认"的一律不许出草稿 |
| 客户觉得被敷衍 | 缺口清单只有"请补充资料" | 每个缺口给一句可直接发的问法（见 SKILL 第 4 步） |
| 报价发出后客户说"你上面写的是月结" | 假设没标 | 见"假设写成事实" |
| 同一客户两次报价不一致 | 没有留痕 | 报价单号归档 + `confirmed_at` + 05 表备注 |
