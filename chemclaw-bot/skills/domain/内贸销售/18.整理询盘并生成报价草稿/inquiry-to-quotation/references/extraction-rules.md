# 抽取规则 · 从散装素材到标准字段

目标不是"抽得全"，而是**抽错了能被一眼看见**。所以每条值都带出处原句与置信度。

## 1. 素材切块

在文本文件里用块标记分隔素材，`extract.py` 会切成独立素材并编号：

```
【素材01 微信截图 OCR · 2026-10-18 至 10-19】
…
【素材02 邮件 · 2026-10-19 14:32】
…
```

也认 `### 素材01 …` 这种 Markdown 写法。没有标记时整篇算一块（编号 `素材01`）。
编号一旦生成不得复用——三个月后复核，靠的就是它。

## 2. 图片 / PDF / 语音怎么进

脚本不跑 OCR。做法是先转文字再切块：

| 素材 | 处理 | 备注 |
|---|---|---|
| 微信截图 | OCR 出文字，按"发送人：内容"逐行保留 | 保留时间戳；语音条标"未转写"，进 unreadable |
| PDF 需求表 | 抽文字层；扫描件靠 OCR | 表格按行转 `字段：值`，别丢单位 |
| Excel 需求表 | 直接读单元格成文本 | 表头要带上，别只剩值 |
| 邮件 | 保留发件人/主题/正文/签名 | 签名常藏着公司全称、电话、开票信息 |
| 手写批注 | 只抄得清的数字；模糊的整条进 unreadable | 典型：`1?30`、`1 630?` |

工作台 HTML 的上传区支持直接拖 `.txt/.md/.csv/.eml/.html` 并在浏览器里重跑一遍轻量识别；
图片/PDF 只能登记文件名，文字要人补——这是有意为之，避免"看起来识别了"。

## 3. 各字段的识别锚点

| 字段 | 锚点 | 注意 |
|---|---|---|
| 产品 | 品名词表（纯碱/重质纯碱/SBS/甲醇/钛白粉…），取最左、最具体的命中 | 词表要长词优先，"重质纯碱"先于"纯碱" |
| 规格 | `Na2CO3 ≥ 99.2%`、`Fe2O3 ≤ 0.003%`、`烧失量 ≤ 0.5%`、`180 目`、`白度`、`熔指` | 只抄原话；短命中若被长命中包含就丢掉（`粒度 180 目` 保留，`180 目` 丢） |
| 数量 | `月用量/月需求/每月` → 月用量；`试单/首批/首单/先来` → 试单量 | 两个都要；报价取试单量 |
| 交货地点 | 优先 `交货地点：`/`收货地址：` 显式行，截到"（"为止；否则在"送到/运到/到厂"附近找省市 | 只有省没有厂区 → 提示补厂区 |
| 客户名称 | 邮件签名/抬头里的 `…有限公司|集团`；只有行业词（…玻璃/化工/材料）无"有限公司" → 待客户确认 | 全称优先；简称取最长命中 |
| 包装 | `1000kg 吨包`、`编织袋`、`槽车`、`散装`、`栈板`、`缠膜` | 短命中被长命中包含则去重 |
| 交期 | `10 月底前`、`本月下旬`、`款到后 7 个工作日`、`现货` | 带上"前/之前/到货"更准确 |
| 付款条件 | `款到发货`、`预付 30%`、`月结 30 天`、`账期 60 天`、`承兑` | 仅当客户明确说；"请注明付款条件"不算 |
| 税费线索 | `13% 增值税专用发票`、`普票`、`不含税` | 只写 hint，不选中 |
| 运费线索 | `送到/到厂/含运费` vs `出厂/自提/运费另计` | 只写 hint，不选中 |

## 4. 置信度

| 级别 | 含义 | 处理 |
|---|---|---|
| 高 | 原文直述、数字明确 | 可直接确认为"已提取" |
| 中 | 需要上下文拼接（如地点从窗口里拼出来、公司简称） | 让销售点头 |
| 低 | 推断（如简称补全、模糊单位） | 一律"待客户确认"，不许作为报价依据 |

## 5. 脏数据三类（必须进 unreadable）

1. **数字被遮挡**：`1?30`、`163[0/8]`。正则 `[0-9]\s*\?\s*[0-9]` 命中即记。
2. **未转写语音**：截图里出现语音条但无文字。素材自述含"无法辨认/看不清/语音未转写"也记。
3. **裁剪/遮挡的表格**：比价表、报价单最常被挡；宁可缺，不要猜。

unreadable 会进：工作台草稿的"待客户确认事项"、Excel 07 表、报价草稿第七段。

## 6. 冲突处理

同一字段多处出现不一致时：

- 时间晚的优先，但**旧的也要留痕**（在 `note` 里写"素材01 说 200 吨，素材02 改 300 吨"）；
- 数量、价格、交期这三类冲突**不自动取值**，标"待客户确认"；
- 地点冲突（两个厂区）→ 标"待客户确认"，并提示拆单。

## 7. 别做的事

- 不要用"行业通常"补字段值；
- 不要做单位换算（吨/kg/包）后写进字段；要换就在报价的数量列写清换算依据；
- 不要把客户问价当成采购需求，也不要把我方报价单里的条件当成客户要求；
- 不要为了"看起来完整"给空字段填默认值——B 类默认值只能出现在渲染层，且必须带"（我方假设）"。
