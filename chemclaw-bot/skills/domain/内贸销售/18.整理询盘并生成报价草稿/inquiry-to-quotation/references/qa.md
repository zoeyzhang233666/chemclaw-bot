# 交付前自检清单

按顺序打勾。打不动的那一项就是返工点。

## 一、字段

- [ ] 素材全部编号，每条提取值都能指回"素材0X + 原句"
- [ ] 数量是两段式（试单 X；月用量 Y），报价数量取试单量
- [ ] 规格是客户原话，没有单位换算、没有补漏项
- [ ] 交货地点到"省市 + 厂区"，只写"送到厂"的已标待客户确认
- [ ] 客户名称：简称已标"待客户确认 · 开票全称待补"
- [ ] 付款条件：客户没说 → 标"我方假设"，不是"已提取"
- [ ] 税费/运费口径都是空的（待人选择），询盘线索只进 hint
- [ ] `unreadable` 已收全（遮挡、手写、未转写语音）
- [ ] A 类没有空值的行还挂着"已提取"状态

## 二、闸门

- [ ] 初始打开工作台，按钮是灰的，且能列出"还差哪几项"
- [ ] 只填单价、不改其他 → 仍然灰
- [ ] 只选口径、不填价 → 仍然灰
- [ ] 勾了确认语但 A 类还缺 → 仍然灰
- [ ] 全部满足 → 按钮可点，文案不再带"还差"

## 三、报价草稿

- [ ] 七要素齐全（明细/价格口径/数量口径/交付/付款/有效期/待确认）
- [ ] 单价数字与销售确认值逐字一致（分毫不能差）
- [ ] 价税构成算对：含税时 `不含税 + 税额 = 价税合计`
- [ ] B 类假设逐条带"（我方假设 · 待客户确认）"
- [ ] 待客户确认清单不漏（含有效期本身）
- [ ] 生成说明写明"谁、什么时候确认了单价"
- [ ] 没有出现任何系统生成的建议价/参考价

## 四、HTML 工作台

- [ ] 单文件、离线可开，无外链依赖
- [ ] 打开即显示上传区 + 默认询盘文本（不是空白页等用户点“载入示例”）
- [ ] 上传区可拖拽；文本文件自动识别；图片/PDF 明确提示要补 OCR 文字
- [ ] 缺失行黄色高亮，待确认行有别色，假设行为虚线
- [ ] 每行可改值、可改状态，改完进度与闸门即时更新
- [ ] “导出字段 JSON”可用，且导出内容不含价格
- [ ] 生成后：复制 / 导出 .md / 打印 PDF / 转合同审阅 四个动作都能用
- [ ] 改动字段后出现"草稿已过期"提示
- [ ] 1440 与 900 宽度下无横向滚动、无文字被裁切
- [ ] `node scripts/selftest_workbench.mjs 工作台.html --price 1180` 无 errors

## 四之二、案例研究页（可选交付）

- [ ] 客户原声、字段表、缺口、四道锁、报价效果五段齐全
- [ ] 演示价区域有醒目 DEMO 声明，不写成“系统建议价”
- [ ] 微信截图、邮件、需求表的来源能对应上
- [ ] 公开行情只出现在“研究依据”，且有“不进入报价”的说明
- [ ] 1440 / 900 / 390 宽度无横向滚动、无文字裁切；打印时隐藏导航
- [ ] `node scripts/selftest_case.mjs 案例研究.html` 无 errors

## 五、Excel 工作簿

- [ ] 7 个表都在，页签颜色区分
- [ ] 02 表状态列下拉四选项，缺失/待确认条件格式生效
- [ ] 04 表单价单元格为空（浅黄底提示"填这里"），税/运费为下拉
- [ ] 04 表试算：单价空 → "待填单价"；只填价、未选税费/运费 → 仍是 "待填单价"；价 + 口径都齐 → 三项都对
- [ ] 05 表单价/数量/金额全部引用 04 表，改一处全表联动
- [ ] 05 表未填价时显示"待填单价"，无 `#VALUE!`/`#NAME?`
- [ ] 长规格文本行高够，无裁切
- [ ] 打印区域、横向、1 页宽
- [ ] `python scripts/selfcheck.py … --xlsx` 全绿

## 六、边界与话术

- [ ] 交付时明确说明"这是草稿，需我方负责人审阅后发出"
- [ ] 说明"价格是你填的，系统没有定价"
- [ ] 说明"B 类是按假设准备的，报价里已标注，需客户确认"
- [ ] 如果客户资料里有期望价/比价，只作为备注，不进单价
- [ ] 如果交付了演示价版本，文件名、页面、工作簿都标了 DEMO，并写明“不是建议价/成交价”

## 常见返工点

1. 数量只有一个值 → 分不清首单与月用量；
2. 客户名简称被补成有限公司 → 开票出错；
3. 税费口径写"含税"不写票种 → 后续扯皮；
4. Excel 金额公式没包 `IFERROR` → 空价显示 `#VALUE!`；
5. 草稿过期了没提示 → 发出旧版本。
