# Changelog

## 1.1.0 — 2026-10-19

- 新增纯碱完整案例的可上传素材：微信截图 PNG、邮件 .eml、需求表 XLSX、扫描件 PDF。
- 工作台打开即显示上传区 + 默认询盘文本；新增“导出字段 JSON”。
- 新增静态案例研究页 `案例研究_纯碱询盘报价.html`：客户原声、字段提取、缺口、四道锁、报价效果、复用方法。
- 新增演示版报价（销售确认 1,180 元/吨，明确标 DEMO）与对应 Excel。
- Excel 的 04 表支持在“已确认价格”场景写入真实单价；官方版仍保持空单价。
- 新增产品画像 `products/soda-ash.json`、空白模板、JSON Schema、研究手册、安装文档。
- 新增 `examples/README.md` 与 `_skeleton/`；补充案例复现命令与自检脚本。
- 修复 Excel 价格/口径单元格在演示工作簿中不写入的问题；修复案例页移动端横向溢出。
- Excel 03 表只列真正的 A 类缺口（字段 + 税费/运费/单价/确认），已齐时显示“A 类已齐”；
  B 类已提取项用绿色而非“假设”色，避免把客户原话误标成我方假设。
- 工作台“待客户确认”行改为黄色虚线高亮，与“缺失”行同一视觉语言。
- Excel 04/05 公式加了口径闸：只填单价、未选税费/运费口径时仍显示“待填单价”，不再默认按含税算；
  05 表在价格未确认时不再写“含税单价 / 0.00 元”，改为“待我方填写单价并选择口径后自动计算”。
