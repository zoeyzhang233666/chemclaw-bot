03

缺口不是一句“请补充资料”

每个 A 类缺口，给一句能直接发给客户的话；B 类缺口写清假设值与影响。
必须

客户全称 / 开票信息

微信与邮件都只给到“江苏盐城华宇玻璃”，没有营业执照全称、税号、开户信息。

建议问法“能否发一下营业执照全称、纳税人识别号和开票信息？报价单抬头需要与发票一致。”
必须确认

付款条件

客户只要求“注明付款条件”，没有说自己的账期或预付比例。

建议问法“贵司常规是款到发货、预付 30%，还是月结？账期多少天？”
可假设

报价有效期

客户要求写有效期，但没有给天数；纯碱随行就市。

建议问法“本报价按 7 天有效，是否满足贵司内部比价周期？”
无法辨认

比价表 1?30

手写/涂改数字无法辨认，不能猜成 1,130 / 1,230 / 1,630。

建议问法“比价表最后一行单价字迹看不清，能否补录一个清晰数字？不补也不影响本次报价。”

06

这套方法怎么复用到别的化工品

换产品只换“产品画像 + 提取词表 + 报价条款”；字段结构、A/B 分桶、价格闸门、输出格式不变。
STEP 01

收料

微信截图、邮件、PDF/Excel 需求表；先编号，保留原话，不替客户合并冲突。

STEP 02

抽字段

10 个标准字段 + 税费/运费口径线索；每条带出处、置信度、状态。

STEP 03

分两桶

A 类必须补齐；B 类可按假设，但每条都写“我方假设 · 待客户确认”。

STEP 04

过闸门

A 类齐、口径选、单价填、确认勾选；缺一项按钮就是灰的。

STEP 05

出草稿

七要素报价 + 复制/导出/打印 + 转合同审阅；改任何值标“已过期”。

跨 Agent 的可移植性

Claude / Codex

把整个目录放进 skills 目录，SKILL.md 的 frontmatter 提供 name / description；脚本用 python 直接跑。

ChemClaw / WorkBuddy

若不支持技能目录，把 SKILL.md 作为系统提示词，附上 examples 的输入输出；脚本仍可独立运行。

纯人工 / Excel

不跑脚本也能用：照 02 表逐项填，03 表看缺口，05 表按七要素写；价格列永远手填。

硬边界：没有默认价、参考价、区间价、建议价、历史价回填。任何“先填一个看看效果”的占位价都不允许进入正式报价。
