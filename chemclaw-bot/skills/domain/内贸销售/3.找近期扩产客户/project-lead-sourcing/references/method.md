# 方法论：为什么以「项目」为单位，以及怎么把它做对

## 1. 两种视角，别混

| | 公司视角（企业表） | **项目视角（本 skill）** |
|---|---|---|
| 记录单位 | 一家公司 | **一个具体项目** |
| 回答的问题 | 谁在用这个产品 | **未来 N 个月里，哪个项目会新增对本产品的需求** |
| 销售时点 | 只能靠行业常识猜 | **从建设阶段 + 预计投产时间推出来** |
| 数据源 | 公司主页、年报、公司资料页 | **备案 / 环评公示 / 招标 / 公告 / 新闻** |
| 失效方式 | 名单很长但不知道先打谁 | 条数少，但每条都有触点 |

项目视角的价值在于它自带**时间维度和触发事件**。一家公司"可能是客户"没法排优先级；"某公司 3 万吨装置在 2027-03 投产、纯碱是沉锂工序的钠源"可以直接排进季度的拜访计划。

## 2. 需求从哪来：只有三种

一个项目会新增对本产品的需求，本质上只有三条路径：

1. **本产品进入产品分子**（`主原料`）——有化学计量关系，单耗可以算。
   例：纯碱 + 锂盐 → 碳酸锂（沉锂工序），理论单耗约 1.4~1.8 t/t。
2. **本产品参与反应但不进入最终分子**（`辅料`）——pH 调节、浸出、中和、脱硫。
   例：氧化铝/锂云母浸出调 pH、烟气脱硫。
3. **本产品作为配合料组分**（`助剂`）——玻璃配合料助熔剂、澄清剂、分散剂。
   例：光伏玻璃配合料约 0.20~0.24 t 纯碱/吨玻璃；水玻璃（硅酸钠）约 0.41~0.51 t 纯碱/吨。

### 需求性质：直接 vs 间接

- `直接`：需求落在**该项目自身的工序**上。绝大多数项目属于这类。
- `间接`：只落在衍生环节（尾气/废水中和、副产利用）。这类要**降权**——量的确定性低，且常常由环保口径而非生产口径决定。

判定方式：看 `需求点` 与 `单耗依据` 的文本里需求是不是"附带的"。本 skill 用关键词 + 角色交叉判定（`间接` + 非主原料）。

## 3. 画应用地图（lane 设计）

**一个 lane = 一个下游应用方向**。不要按企业分 lane，要按"用料逻辑"分——同一个 lane 里的企业工艺相近，可以复用同一套话术与单耗依据。

每个 lane 写四件事：

| 字段 | 要求 |
|---|---|
| `logic` | 本产品在该方向的**哪个工序、起什么作用**，能给量级就给 |
| `intensity` | 1~5 星。5★=单点年需求千吨级以上；4★=千吨级；3★=百吨级；2★=十吨级；1★=更小/不确定 |
| `clusters` | 产业集聚地（省市），用来把检索范围收窄 |
| `seeds` | 5~8 家具名候选企业（不必全中，是给 lane 的起点） |

### 三类容易被漏掉的方向

1. **渠道型**：把本产品当配方单体再复配、转售的厂（复配添加剂厂、洗涤剂复配厂）。
2. **深加工型**：拿本产品做原料再做下一级产品的厂（泡花碱厂拿纯碱做水玻璃）。
3. **环保末端型**：脱硫脱硝、废水中和、飞灰处理。量不小，但工程化程度高、单体用量取决于环保口径，**通常给 3★ 左右并标为间接**。

### 反例（很重要的负结果）

**下游行业在萎缩时，lane 里会几乎搜不到东西——这本身就是最有价值的结论。**
纯碱华东那一轮：光伏玻璃板块在 2026 年深度下行，主体在**关停、减值、拆窑炉**而不是新建（某 550t/d 窑炉停产、某上市公司正在拆除其光伏玻璃窑炉）。这个板块只产出 4 条。**必须把这个"负结果"写进交付说明**，否则用户会以为是自己没找够。

同理，锂电材料在 2026 年出现停缓建潮（多个项目终止/缩减）。**联系前必须先确认项目是否仍在推进**——这类要写进 lane brief 的风险提示。

## 4. 单耗怎么估（有依据的粗算 >> 无出处的精算）

优先顺序：

1. **化学计量式**（最硬）。从反应式算理论单耗，再说明实际通常高于理论。
   例：沉锂 `Na₂CO₃ + Li₂SO₄ → Li₂CO₃ + Na₂SO₄`，理论单耗 = 106/74 ≈ 1.43 t 纯碱/t 碳酸锂；工程上取 1.5~1.8。
2. **配合料配比 / 原辅材料清单**（环评报告里的"主要原辅材料"表是金矿）。
3. **行业经验区间**，并明确标注是经验值。
4. 都拿不到 → **`无法估算`**。

**输出要求**：`单耗依据` 写"怎么来的"，`年需求量估算` 写"算式 + 结果 + 假设"。必须带满产假设说明，因为满产是上限口径——**没有产量结构数据时，要把"若全部走 A 路线"讲清楚**。

例（真实条目）：
```
单耗依据: 沉锂工序 Na2CO3+Li2SO4→Li2CO3+Na2SO4，理论 1.43 t/t；工程取值 1.5~1.8
年需求量估算: 按满产 3 万吨/年碳酸锂 × 1.5~1.8 t/t ≈ 4.5~5.4 万吨/年纯碱（上限口径，
             公告未披露实际产量结构）
```

## 5. 覆盖率与诚实

两个数字决定这份交付的可信度，**都要如实报告**：

- **年需求量可估算的比例**（纯碱那轮是 37/103 ≈ 36%）。公开公告普遍不披露碱耗，所以这个比例低是**正常**的，不是失败。
- **无来源（未核实）的条数**。这些置信度一律降为「低」，只能电话确认。

**不要把"估算"和"事实"混在一列里**——`设计产能` 是事实，`年需求量估算` 是推断，交付物里必须分列。

## 6. 时间窗怎么理解

`window_months` 约束的是**预计投产时间落入的区间**，不是"现在在建"。

- `未来 6 个月` = 预计投产时间在 `today ~ today+6 个月`。
- 因此**已投产但刚投产**（近 6 个月内）的项目也属于当期机会——它正在达产爬坡，供应商名单还在调整。
- **在建但投产时间未披露**的，不能当作"什么都不用做"：合格供应商入库 + 送样检测本身要 1~3 个月，等到点火再切入就晚了。规则见 [`timing.md`](timing.md)。
