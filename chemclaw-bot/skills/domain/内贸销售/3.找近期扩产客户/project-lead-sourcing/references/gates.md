# 五道闸门

管线里每一道闸门都在挡一类**特定**的错误。跳过任何一道，交付物就会出现对应的失效。

## 闸门 1：地区闸门（merge 时自动）

**挡的错**：lane 抓到了区外的项目，混进表里，用户按地区筛的时候发现一半是别的省。

- 规则：`省市` 第一段（按 `/`、`、`、空格切）去掉"省/市/自治区"后缀后，必须匹配 `region.provinces` 之一（前缀匹配，容忍"山东省"vs"山东"）。
- `region.provinces` 为空 = 不限地区。
- 被剔除的记录**不静默丢弃**：写入 `merge_stats.json → out_of_region_details`，并在交付说明里列名。

## 闸门 2：peer gate（merge 时自动）

**挡的错**：**把同行当客户**。这是这类名单最致命的错误——销售打电话过去推销对方自己生产的产品。

- 规则：`公司` 命中 `config.peer_keywords` 任一关键词 → 剔除。
- `peer_keywords` **必须按本次产品重写**。用产品名 + "生产/制造/实业"去查一遍"国内还有谁在生产这个产品"，把清单填进去。
- **副作用也要管**：检索中发现的、**不在名单里**但明显自产该产品的主体，lane 必须剔除并**单独报告**，由你补进 `peer_keywords`。
- 判定线索：年报自述产品含本产品；公告里在建自己的本产品装置；企业名叫"XX碱业""XX化工"且主营含本产品。

**真实教训**：纯碱那一轮，两条"最强线索"最后都被 peer gate 否掉了——

| 主体 | 表面 | 真相 |
|---|---|---|
| 山东金晶科技（600586） | 光伏玻璃产能巨大 → 纯碱大客户 | 半年报自述产品**含"纯碱"**：玻璃-纯碱一体化，**同行** |
| 江西世龙实业（002748） | 10 万吨过碳酸钠 → 可折 7~7.5 万吨/年纯碱 | 董事会决议"加速纯碱项目建设"，**自建纯碱自供**，需求内部化 |

如果没有这道闸门，报表会多两条假的旗舰线索，销售把最宝贵的精力投在同行身上。

## 闸门 3：去重（merge 时自动）

**挡的错**：同一条产线被多个 lane / 多次披露，重复计数，`条数` 虚高。

- 键：`norm_company(公司)` + `项目名称` 去空格与标点后前 24 字。
- 冲突时保留**置信度更高**的一条；置信度相同保留先出现的。
- **跨 lane 的同一项目**也会被这条规则合并（同一家公司在两个 lane 里出现很正常）。

### 需要人工处理的重复

自动去重抓不住"项目名不同但其实是同一条产线"的情况。**必须人工比对**：
- **同一厂址 + 相似产线名 + 不同年份的公告** → 大概率是同一条产线。
- 处理方式：删掉旧的那条，并把新条目的 `规模线索` 写清产能变更沿革。

工具：`scripts/dedupe_manual.py`（或直接在 lane JSON 里删）。

## 闸门 4：链接闸门（`b2bctl qa`）

**挡的错**：来源链接是坏的，销售点不开，整张表的可信度崩塌。

- 抽样 ≥40 条，优先非聚合站。
- 判定与两类失败的区分见 [`evidence.md`](evidence.md) 第 4 节。
- 结论进 `抽检结论` 字段，**不拼进 `来源`**。

## 闸门 5：交付自检（`b2bctl check`）

**挡的错**：交付物结构坏了但没发现（Excel 少一个表、HTML 内联 JS 语法错误、说明缺第四块）。

```bash
python scripts/b2bctl.py check <项目目录>
```

检查项：
- Excel 存在、sheet 数 ≥5、总表行数 = 线索数 + 1
- HTML 存在、含"时间线/企业表/切入点/企业背景/证据与来源"、产品名与地区名已渲染
- HTML 内联 JS 通过 `node --check`（有 node 时）
- `方法与边界说明.md` 存在且四块齐全；`GAPS:BEGIN` 标记是否还在（第四块没写完）

**退出码非 0 就是没通过，不要带着失败交付。**

## 闸门之外：`collect` 的字段校验

严格说这不是闸门而是**前置校验**，但它挡的错很常见：

| 校验项 | 挡的错 |
|---|---|
| 18 个采集字段齐全 | lane 偷懒少字段，merge 时 KeyError 或被静默丢弃 |
| `建设阶段` 可识别 | lane 写了"试生产阶段"这类自由文本，不归一化就会掉进"未披露" |
| `产品角色` 在词表内 | lane 自造词（"主要原料""添加剂"），筛选和话术都会失效 |
| `置信度` ∈ 高/中/低 | lane 写了"较高"，权重计算会 fallback 成 低 |
| `来源` 是 http(s) URL 或 `未核实` | lane 写了"公司年报"这种无法点击的描述 |
| 未命中 peer / 未越界地区 | 提前发现，不用等到 merge |

```bash
python scripts/b2bctl.py collect <项目目录>
```
