# research.json 数据契约

一份 `research.json` = 一次研究。它是**唯一的人/模型手写事实源**；`data.json`、HTML、Excel 全部由它派生。
所以这里的原则是：**手写的只有原始事实，派生指标一律交给 `assemble.py`**。

```bash
python scripts/validate.py research.json        # 先过契约
python scripts/build_all.py research.json --out out
```

字段分三类：`必须` / `建议` / `可缺（缺则自动留缺口）`。可以整块不写，写了就要按下面的形状写。

---

## meta（必须）

| 字段 | 类型 | 说明 |
|---|---|---|
| `product` | str | 品种名，用于标题与文件名。如 `纯碱`、`玻璃` |
| `asof` | `YYYY-MM-DD` | 数据基准日。序列晚于它会被截断 |
| `spec` | str | 规格/品位。**决定报价可比性**：`重质 ≥99.2%`、`浮法 5mm 大板` |
| `region` | str | 重点市场，可用 `沙河 · 华北` 形式同时给点位与区域 |
| `unit` | str | 默认 `元/吨`。玻璃可能用 `元/重箱`，须与现货表一致 |
| `title` | str | 可选，页面大标题 |
| `peer_products` | [str] | 可选，首屏品种切换器的候选（未接入数据的会显示“尚未接入”） |
| `anomaly_pct` | float | 可选，异常波动阈值，默认 `3.5`（%） |
| `suggest_quote` / `suggest_term` | num / str | 可选，话术生成器的预填报价与商务条件 |
| `exchange` / `contract` | str | 可选，期货交易所与合约，未填时从 `futures` 推断 |

## futures（有场内期货建议写）

```json
"futures": {"exchange": "郑商所", "code": "SA", "series": "raw/纯碱_daily.json",
            "note": "主连连续合约，不含税、含交割成本"}
```

`series` 支持三种形状，`common.load_series` 都能吃：

- `fetch_futures.py` 输出的 `{"name":..., "rows":[{d,o,c,h,l,v,amt,pct}]}`
- 纯数组 `[{...}]`
- 东财原始 klines 字符串数组 `"2026-10-19,945,953,..."`

**不要**把期货价填进 `spot`。期货是**不含税、含交割成本**，现货是**含税、出厂/送到**，
两者相减没有经济含义。想看两者关系，写进 `caveats` 说明换算路径，并在 `facts` 里
标成“基差（需同日）”而不是“价差”。

## anchor（现货锚，强烈建议）

首屏和话术里“当前价是多少”取的就是它。缺 `anchor` 时 `assemble.py` 自动取**最新一条现货**，
并在锚龄 >7 天时追加一条 caveat（提醒读者这批现货不新）。

```json
"anchor": {"label":"华东重碱主流价", "value":1150, "unit":"元/吨",
           "range_lo":1150, "range_hi":1150,
           "date":"2026-10-16",
           "basis":"含税 · 出厂 · 待核",
           "prev_date":"2026-10-13", "prev_mid":1160,
           "note":"现货不是期货，逐日报价；此价为二手引用，未见当日原表",
           "src":"同花顺 iFinD 口径（二手引用）"}
```

`prev_mid` 用来算首屏日涨跌；没有就留空，不要拿别的日期凑。

## spot（现货表，至少 1 条）

```json
{"region":"沙河", "sub":"华北 · 5mm 大板（出厂）", "product":"浮法玻璃 5mm 大板",
 "lo":917, "hi":917, "tax":"含税", "basis":"现金出厂价",
 "date":"2026-10-12", "conf":"高", "note":"原文 10.55 元/㎡ 折算", "src":"我的钢铁网 2026-10-12"}
```

| 字段 | 取值 | 注意 |
|---|---|---|
| `region` | 华东/华北/华中/华南/西北/东北/全国/沙河… | 自由文本，但同一地区写法要统一 |
| `sub` | 细分市场 | 会作为卡片小标题，写“地区 · 规格（提货方式）”最清晰 |
| `product` | 规格原文 | **必须写清品位/厚度/牌号** |
| `lo` / `hi` | 数字 | 单点报价填相同值；`lo==hi` 会被标为“单点” |
| `tax` | `含税` / `不含税` | 不许留白，不许写“含税待核”以外的模糊词 |
| `basis` | 出厂/送到/现金/承兑 | 影响比价，务必写 |
| `date` | `YYYY-MM-DD` | 现货是逐日报价，日期不同不可比 |
| `conf` | `高` / `中` / `缺口` | `中` = 二次引用或换算得来；`缺口` = 不可用于报价 |
| `src` | 来源 | 写“媒体 + 日期 + 文章关键词”，方便回溯 |

**单点 vs 区间**：`lo==hi` 会被统计为单点。与区间中值混比会放大/缩小价差，
报告会自动提示单点占比。

## spread_base（区域价差基准）

```json
"spread_base": {"region":"沙河", "dates":["2026-10-08"]}
```

`assemble.py` 只在 `dates` 指定的日期上、按 `product` 分组算价差——**跨日期不算**，
因为不同日期的价格差是时间差，不是区域差。`dates` 留空则自动取“同日 ≥2 地区”的最近一天。

## cost_lines（成本参考线）

```json
{"name":"天然气制完全成本（反推）", "value":1105, "date":"2026-10-09",
 "src":"五矿期货：现货 960 元/吨、利润 -144.74 元/吨 → 反推",
 "note":"派生值：由两个公开数字相减得到，非原文直接披露"}
```

画在分位条上，用来回答“价格跌到成本下面没有”。**派生值必须在 `note` 里写明反推过程**，
否则读者会当它是原始披露。

## margins（分工艺路线毛利）

```json
{"date":"2026-10-09", "routes":{"天然气制":-144.74}, "src":"五矿期货月报",
 "note":"仅取得天然气路线；煤制气、石油焦未取得"}
```

`routes` 的键就是路线名，**什么品种就写什么路线**：纯碱用 `氨碱/联碱（双吨）/天然碱`，
玻璃用 `天然气制/煤制气/石油焦`，PVC 用 `乙烯法/电石法`。报告按数据里的键动态渲染列与曲线，
不预设工艺。

兼容旧写法：`{"ammonia":-202,"hou":-184,"natural":108}` 会被自动映射为
氨碱 / 联碱（双吨）/ 天然碱，但新写的稿子请直接用 `routes`。

## upstream / downstream

```json
{"name":"纯碱（重质，华东主流）", "value":1150, "unit":"元/吨",
 "chg":"含税；期货主连 953（不含税）", "date":"2026-10-16",
 "direction":"down", "logic":"纯碱占浮法成本约三成…", "src":"…"}
```

`direction` 取 `up` / `down` / `gap`。**没有数字时 `value` 填 `null`、`direction` 填 `gap`**，
`chg` 里写清缺什么。报告会在表尾列出该品种“常见但未取数”的品种——
这份清单来自 `common.py` 的 `CHAIN_HINTS`，是给研究者的待办，不是给读者的结论。

## balance（供需与库存）

```json
{"k":"浮法玻璃样本库存", "v":"359.14 万吨", "date":"2026-10-15",
 "prev":"周环比 -6.97", "src":"玻璃观察 2026-10-19 基本面汇总"}
```

`v` 用字符串，因为单位多样（万吨、万吨/日、%、元/吨）。**同一指标两个口径时并列两条**，
在 `prev` 或 `note` 里写明“口径冲突，不可相加”——不要取平均。

## margins / events / facts / talk

```json
"events": [{"date":"2026-10-15","tag":"价格","title":"期货探至 848，创样本新低",
            "price_ref":848,"impact":"利空","detail":"…","src":"…"}],
"facts":  [{"kind":"价格","k":"期货主连","v":"858 元/吨","note":"…","src":"…","tip":"…"}],
"talk":   [{"q":"现在什么价？","a":"分两个口径给您：…"}]
```

- `tag`：价格 / 政策 / 检修 / 供给 / 需求 / 库存 / 成本 / 区域 / 分析
- `impact` 只允许 `利多` / `利空` / `中性`，且必须是对**已发生事件**的事后描述
- `price_ref` 填事件当日的期货收盘价，`assemble.py` 会自动对齐到最近交易日
- `facts.kind` 用于分组着色；`tip` 是“怎么用这条事实”的一句话
- **`talk.a` 里不许出现方向判断**。`talk.q` 是客户原话，允许出现“抄底”等词——
  `check_html.py` 已经对 `.q` 豁免，但 `.a` 会被扫

## gaps（数据缺口，必须写）

```json
{"item":"燃料分路线成本", "status":"缺口",
 "detail":"只取得天然气制一条路线…",
 "impact":"无法判断哪条路线先退出…",
 "fix":"补天然气/石油焦/动力煤三条燃料价，按单耗折算"}
```

`status` 取 `缺口` / `口径冲突` / `待更新`。**`impact` 和 `fix` 都不能省**：
前者告诉销售“这个缺口会不会让报价出错”，后者告诉下一个人“怎么补”。

`gaps` 为空时 `validate.py` 会警告——一份没登记的缺口清单，通常意味着没查到位。

## caveats（口径提醒）

凡是“读者可能误用”的地方都写一条：期货 vs 现货、含税 vs 不含税、单点 vs 区间、
不同统计范围、派生值、数据滞后。这些会原样出现在报告第 10 节、Excel 第 12 表、封面“使用前必读”。

## sources（来源清单）

```json
{"name":"我的钢铁网《[玻璃]：2026年10月12日沙河市场浮法玻璃价格行情》",
 "date":"2026-10-12","type":"现货日报","url":"https://…"}
```

`type` 常见值：现货日报 / 产业数据 / 研究报告 / 行情数据 / 政策公告 / 交易所公告 / 协会统计。
**没有 url 的来源要标 `未取得原链接`**，不要留空冒充有链接。
