# 范本 02 · 玻璃 × 沙河（跨品种验证）

**这次要证明的是：换一个品种，脚本一个字都不用改。**

纯碱的毛利是三条工艺路线、单位只有元/吨；玻璃是另一套工艺路线、三种计价单位、
区域价差只有两个地区。两者的 `research.json` 形状完全不同，但走同一条流水线。

| 项 | 内容 |
|---|---|
| 基准日 | 2026-10-19 |
| 期货 | 郑商所 FG 主连 **858 元/吨**（不含税，10-19 收盘） |
| 现货锚 | 沙河 5mm 大板 **917 元/吨**（2026-10-12，含税，现金出厂价） |
| 近 1 年 | 区间 848–1,171，当前 **1.7% 分位**，距低点（10-15 创下）仅 10 元/吨 |
| 近 3 年 | **0.6% 分位**；近 5 年 0.3% |
| 样本极值 | 高 3,163（2021-07-19）／低 848（2026-10-15），回撤 72.9% |
| 毛利（10-09） | **天然气制 −144.74 元/吨**（只有这一条路线） |
| 供需 | 产量 14.25、表需 15.25 万吨/日；样本库存 359.14 万吨（周环比 −6.97） |
| 区域价差 | 沙河 917 ↔ 湖北 990，同日（10-08）同规格，差 **+73 元/吨** |

## 与范本 01 的四处不同（都是"品种无关"的证据）

**① 毛利路线名由数据决定**

```json
// 纯碱
"margins": [{"date":"2026-10-14", "routes":{"氨碱":-202,"联碱（双吨）":-184,"天然碱":108}}]
// 玻璃
"margins": [{"date":"2026-10-09", "routes":{"天然气制":-144.74}}]
```

报告自动只渲染数据里出现的路线：玻璃只有一个 `天然气制`，图例和列就只有一个。
脚本里没有任何 `if product == ...`。

**② 三种计价单位并存**

| 来源 | 原始单位 | 折算 |
|---|---|---|
| 沙河（我的钢铁网） | 元/㎡ | 10.55 × 换算系数 → 917 元/吨（原文给的） |
| 湖北（我的钢铁网） | 元/重量箱 | 49.5 元/箱，1 重量箱 = 50 kg → 990 元/吨 |
| 期货 / 五矿月报 | 元/吨 | 直接用 |

这里有个真实陷阱：5mm 玻璃按密度 2.5 g/cm³ 理论为 **80 ㎡/吨**，
但原文把 10.55 元/㎡ 还原成 917 元/吨，隐含 **86.9 ㎡/吨**（差异来自厚度公差或原文系数）。
报告的处理是：**用原文的 917，并在 `caveats` 里把两个系数都写出来**，而不是自己重算一个数。

**③ 成本线是反推值，必须标注**

五矿月报给的是"现货 960 元/吨、天然气制利润 −144.74 元/吨"，
成本 = 960 + 144.74 ≈ 1,105 元/吨。这是**两个公开数字相减**得到的派生值：

```json
{"name":"天然气制完全成本（反推）", "value":1105,
 "note":"派生值：由两个公开数字相减得到，非原文直接披露；仅作参考线"}
```

报告会把它画在分位条上，同时在 `caveats` 里声明这是反推，不作为报价依据。

**④ 区域价差只有两个地区，但是真正的"同日同规格"**

```json
"spread_base": {"region":"沙河", "dates":["2026-10-08"]}
```

`dates` 指定后，`assemble.py` 只在 2026-10-08 这一天算价差——沙河 917、湖北 990，
差 73 元/吨。数据里还有 10-12 的沙河和 10-09 的湖北，但**不参与价差计算**，
因为跨日期相减得到的是时间差 + 区域差的混合物。

## 这份报告的 7 条缺口

1. **分规格逐日报价不全** —— 只有 5mm 两个交易日，3.8/4.8/6mm 无序列
2. **燃料分路线成本** —— 只有天然气一条路线，煤制气/石油焦完全没有
3. **终端需求无当期数字** —— 竣工、汽车、光伏都只有定性描述
4. **库存口径不可相加** —— 全国样本 359.14 / 沙河 68.30 / 湖北 29.66（滞后一个月）
5. **三种计价单位并存** —— 折算系数不一致（80 vs 86.9 ㎡/吨）
6. **产能置换与冷修明细** —— 只有标题级信息
7. **历史事件覆盖不足** —— 只梳理了 2026-10；近一年 25 次异常波动中 20 次在更早月份，
   全部标“未取得可靠来源”。这一条是刻意的：**宁可显示"不知道"，也不补一个编的原因**。

## 一个值得强调的发现

**跌价去库**：10-15 期货探至 848 元/吨创样本新低，同一周样本库存却降了 6.97 万吨
（359.14 万吨），表需 15.25 高于产量 14.25 万吨/日。

这个组合初看矛盾（价格跌、库存也跌），报告的处理是**把两件事并列陈述**，
并指出"去库由节后补货驱动"（隆众 10-16 的判断），**不解释成"需求好转"**。
这正是这份底稿的用处：给销售一个能自洽的事实组合，而不是一个漂亮的故事。
