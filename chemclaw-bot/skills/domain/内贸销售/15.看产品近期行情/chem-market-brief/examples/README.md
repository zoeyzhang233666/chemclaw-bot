## 01 纯碱（全量）

- 期货：郑商所 SA 主连，1,888 根日线（2019 起）
- 现货：华东/华北/华中/华南/西北/东北 + 全国均价 + 华东最新，全部带日期与来源
- 特色：三种工艺路线毛利（氨碱 / 联碱双吨 / 天然碱）、区域价差 420 元/吨（西北↔华南）
- **刻意保留 6 条缺口**：分区域现货止于 2026-08-11、轻碱无分省报价、无同一时点跨区价差、
  原盐/合成氨/氯化铵无数字、出口 9–10 月明细缺失、厂库 179.26 vs 167 万吨口径冲突
- 重点：期货 953（不含税）与现货 1,150（含税）**并列但不相减**

## 02 玻璃（跨品种验证）

- 期货：郑商所 FG 主连，1,888 根日线；近 1 年 848–1,171，当前 858（1.7% 分位）
- 现货：沙河 5mm 大板 917、小板 913、湖北 5mm 990、全国均价 960、沙河指数 899.52
- 特色 1：**同一天同规格的区域价差** —— 2026-10-08 沙河 917 vs 湖北 990，差 73 元/吨
- 特色 2：**三种计价单位** —— 元/㎡（沙河）、元/重量箱（湖北）、元/吨（期货与资讯），
  折算过程写进 `spot.basis` 与 `caveats`，并说明 80 ㎡/吨（理论）与 86.9 ㎡/吨（原文）的差异
- 特色 3：毛利只有一条路线（`天然气制: -144.74`），报告自动只渲染这一列——
  证明路线名由数据决定，脚本不预设工艺
- 重点：成本线 1,105 元/吨是**反推值**，`note` 里写明推导方式，不当原始披露

## 怎么跑

```bash
cd ../scripts
python build_all.py ../examples/01-soda-ash-national/research.json \
                    --out ../examples/01-soda-ash-national/output --name 纯碱-全国
python build_all.py ../examples/02-glass-shahe/research.json \
                    --out ../examples/02-glass-shahe/output --name 玻璃-沙河
```

## 怎么改

1. 复制一个目录 → 改名（如 `03-caustic-soda-east/`）
2. 换 `research.json` 内容（照 `references/data-contract.md`）
3. 期货序列：`python fetch_futures.py <品种> --out raw/<品种>_daily.json`
4. 重跑，直到 `validate.py` 0 error、`check_html.py` 0 error、`qa_render.py` 0 失败

`build/` 与 `output/` 都是派生物，可以随时删掉重生成。
