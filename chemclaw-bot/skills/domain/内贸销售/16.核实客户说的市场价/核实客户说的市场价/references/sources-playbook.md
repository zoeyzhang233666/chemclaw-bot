# 去哪些渠道查市场价格

目标只有一个：**拿到一条六项口径齐全、能点开链接复核的报价**。

宁可只有三条干净的报价，也不要十条查不到出处的数字。

---

## 一、来源分层（按可信度）

| 层级 | 来源类型 | 可信度 | 特点 | 例子 |
|---|---|---|---|---|
| **A** | 专业化工资讯平台日更 | 高 | 有具体日期、地区、规格、税费口径说明 | 隆众资讯、卓创资讯、生意社、金联创、百川盈孚、中宇资讯 |
| **B** | 期货交易所/交易所公布 | 高（但口径不同） | 期货价是标准品、不含税、交割地固定，**不能直接当现货价** | 郑商所 SA（纯碱）、大商所、上期所 |
| **C** | 行业门户/综合资讯转载 | 中 | 常转载 A 层数据，需找到原文 | 我的钢铁网 mysteel、化工网、新浪财经转载 |
| **D** | 企业挂牌价/调价函 | 中 | 反映厂家报价，不是市场成交 | 上市公司公告、企业公众号 |
| **E** | 行业群/朋友圈/客户转述 | 低 | 只能当"线索"，必须回到 A/B 层核实 | 微信群截图、电话传话 |

**主报价必须来自 A 层且链接可点。** 只有 E 层数据时，结论写"无法验证"。

## 二、按品种找入口

### 通用入口

```
{品种} 现货价格 今日          site:100ppi.com   （生意社）
{品种} 市场价格 华东 送到      隆众/卓创日更标题通常含地区与交付口径
{品种} 价格行情 2026年10月
```

### 常见品种的具体入口提示

| 品种 | A 层入口 | 注意 |
|---|---|---|
| 纯碱 | 隆众资讯纯碱日更（经 mysteel 转载常见） | 轻质/重质分开报，重质常标"送到" |
| 烧碱 | 隆众液碱/片碱 | 32% 液碱与 99% 片碱不是同一物 |
| 尿素 | 隆众、卓创尿素 | 小颗粒/中颗粒/大颗粒价差明显 |
| 甲醇 | 卓创、隆众港口/内地 | 太仓/江苏港口价与内地价差大 |
| 钛白粉 | 生意社、隆众 | 金红石型/锐钛型分开 |
| 丙烯酸 | 隆众 | 普酸/精酸不同 |
| 双氧水 | 隆众 | 27.5%/35%/50% 浓度差别大 |
| 中间体（小众） | 企业挂牌 + 行业群交叉 | 公开日更少，可靠性要标"中/低" |

## 三、单条报价的验收清单

拿到一条报价，逐项打勾，缺一项就不合格：

- [ ] **日期**：具体到年月日（不是"近期""本周"）
- [ ] **规格**：含量/牌号/形态，能对上客户的需求
- [ ] **地区**：到省/区域，能对上客户的交付地
- [ ] **税费**：页面有没有写"含税/不含税""现金含税价格"这类备注
- [ ] **交付**：出厂 / 送到 / 库提 / 集港
- [ ] **数值**：区间（下沿–上沿）还是点价
- [ ] **来源名**：能说出是隆众还是卓创还是转载
- [ ] **URL**：能点开，且点开后能看到上面这些信息

**以上任意一项缺失，这条报价只能进「数据缺口」或「参考」，不能当主区间。**

## 四、读页面时容易漏的三个细节

### 1. 表格底部的备注

很多平台的税费和单位写在表格下面一行小字，例如：

> 表单中的价格为现金含税价格，单位为元/吨

**这一行决定了税费和付款口径。** 一定要读。

### 2. 一句话里含多个规格

例如：「轻质出厂 1000-1100 元/吨，重质报价 1050-1200 元/吨送到」

- 轻质是**出厂**，重质是**送到**——同一篇文章里两种交付口径
- 不能把 1000-1100 当成重质的区间

### 3. 转载要找到原文

`mysteel.com` 上很多化工日更是转载隆众的。记录来源时写：

```
"source": "隆众资讯（经我的钢铁网 mysteel.com 转载）"
```

这样既标明了原始出处，也标明了你实际看到的页面。

## 五、历史序列怎么取

要给 7 天 / 30 天 / 3 个月的变化，需要**同一来源、同一口径**的连续点。

做法：

1. 在 A 层平台的日更页面里，按日期往前翻（多数平台 URL 含日期，如
   `.../a/26102015/xxxx.html`，其中 `261020` = 2026-10-20）
2. 每个点记录：日期、低、高、中值、来源、URL
3. **口径必须一致**：如果某天的报价是出厂，另一天是送到，不能连成一条线
4. 点数：3 个月内尽量取 12 个以上；少于 3 个点不要画趋势，只列数据

`research.json` 的 `history[]` 按日期升序排，`assemble.py` 会自动算窗口变化和价格带。

## 六、期货价怎么用

**能用的地方**：
- 说明方向（期货跌了，现货通常也会跟）
- 说明标准品的价格锚

**不能用的地方**：
- ❌ 当现货参考价（期货是不含税、标准品、交割地固定）
- ❌ 直接和客户说的现货价比（税基、地区、品质都不同）

报告里可以单列一个"期货参考"小节，并写明"仅说明税基与品质差异，不作为现货参考价"。

---

## 七、查不到怎么办

按顺序尝试，然后**据实说明**：

| 尝试 | 记录方式 |
|---|---|
| 换关键词（品种别名、CAS 号、商品名） | — |
| 换平台（A 层全部试过） | — |
| 查邻近品种作为方向参考 | 写进"参考"，不进主区间 |
| 问企业挂牌价 | 写进"企业挂牌价"栏，标注"非市场成交价" |
| 全部失败 | `gaps[]` 写"该品种无公开日更报价"，结论写"无法验证" |

**绝不**因为查不到就编一个"市场价大约 XXX"。
查到的是缺口，输出也必须是缺口。
