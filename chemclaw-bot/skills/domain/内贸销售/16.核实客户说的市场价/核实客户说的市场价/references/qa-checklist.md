# 交付前自检清单

出报告之前，逐条过一遍。**任何一条打不了勾，就不要把文件发给客户或主管。**

---

## 一、数据可靠性

- [ ] 主报价来自 A 层来源（专业日更），链接可点开
- [ ] 点开后能看到日期、规格、地区、税费、交付口径
- [ ] 报价日期不超过基准日
- [ ] 六项口径齐全：数值+单位、规格、地区、税费、交付、日期
- [ ] 历史序列是**同一来源、同一口径**的连续点
- [ ] 历史点 ≥ 3 个（少于 3 个不画趋势线）
- [ ] 被排除的报价写明了 `exclude_reason`
- [ ] 没有把期货价当现货参考价

## 二、口径处理

- [ ] 客户缺哪些口径，全部标成「未说明/未注明」，没有替客户补
- [ ] 税费换算只在两侧税基**明确且不同**时做，系数写出来了
- [ ] 交付换算只在**有运费**时做
- [ ] 缺运费的地方显示「无法直接折算」，没有出现任何估算运费
- [ ] 账期差异（承兑 vs 现金）若存在，已标注"未计入贴现成本"
- [ ] 规格不一致时判了"口径不一致"，没有硬比

## 三、计算正确性

- [ ] 偏离金额 = 客户价 − 区间中值，能手工验算
- [ ] 偏离比例 = 偏离金额 ÷ 区间中值
- [ ] 相对上沿、相对下沿的差值都给了
- [ ] 中间计算没有提前四舍五入
- [ ] `data.json` 的 `steps` 能复现每一个数

## 四、判定合规

- [ ] **没有使用任何固定百分比阈值**判断"明显"
- [ ] "明显"的尺度来自该报价自身的半宽
- [ ] 判定用了近 3 个月价格带交叉核对
- [ ] 客户价落在历史带内时，写了"可能是不同日期的价格"
- [ ] 没有断言客户在压价 / 提供虚假信息
- [ ] 无法比较时，给出了"缺哪一项"，而不是含糊的"数据不足"

## 五、语言合规

- [ ] 全文没有出现：底价、建议报价、让价幅度、谈判策略、抄底、锁定利润
- [ ] 没有预测性表述（"预计""下周会""建议尽快"）
- [ ] 没有承诺性表述（"保证""一定能成交"）
- [ ] 称呼客户为"客户"或直接陈述价格事实，不带情绪判断

## 六、成品文件

- [ ] HTML 用 Chrome/Edge 打开正常，价格带图、走势图、地区图都渲染出来
- [ ] HTML 里没有外部链接请求（离线也能看）
- [ ] 切换地区/规格/税费/交付后，结论会跟着变
- [ ] 点价格数字能跳/显示来源、日期、原始口径
- [ ] "与客户沟通的事实要点"按钮能出内容
- [ ] 微信/邮件润色草稿只有事实，没有价格承诺
- [ ] Excel 打开无报错，12 张表齐全
- [ ] 改 `01!B5` 客户价，`04` 的偏离金额、比例、判定**自动变化**
- [ ] Excel 里没有 `_=` 开头的坏公式残留
- [ ] 模拟数据带【模拟】标注

## 八、按场景的额外检查

### 只有点价、没有区间

- [ ] 报告注明"该来源只给点价，不可当区间用"
- [ ] 结论只写"高于/低于该点价 X 元"，不写"明显"

### 完全查不到同规格报价

- [ ] 结论写"无法验证"
- [ ] 不画价格带图（或画成空的并说明原因）
- [ ] 仍然给出确认清单

### 客户价来自旧日期

- [ ] 用 3 个月窗口指出这个价出现在什么时候
- [ ] 措辞是中性的（"该价位对应 4–5 月水平"），不是"你的信息过时了"

### 跨区比价

- [ ] 参与比价的地区是同规格同税基同交付
- [ ] 写了可比性说明（运距、供需差异）
- [ ] 没有说"某地更便宜所以我们贵了"

### 模拟案例

- [ ] 客户原话带【模拟】
- [ ] 页面顶部有模拟标注横幅
- [ ] Excel 封面有模拟说明
- [ ] 客户价格从未在任何地方被当作市场报价
