# 口径规则：六项基准 + 九类差异因素

客户说"市场才 1400"，你要能回答：**那是哪一种 1400**。

---

## 一、六项基准口径

任何价格，只有这六项定死了，才是一个**可以拿来比的价格**。

| # | 口径 | 常见取值 | 缺了会怎样 | 怎么问 |
|---|---|---|---|---|
| 1 | **数值 + 单位** | 元/吨、元/公斤、元/瓶 | 单位错一位，结论全错 | "是元/吨吧？" |
| 2 | **规格 / 纯度** | ≥99.2%、工业级/食品级、粒度 | 食品级比工业级贵，轻质比重质便宜 | "您要的是哪个纯度/牌号？" |
| 3 | **地区 / 交付地** | 华东、山东、送到江苏某厂 | 跨区差价可能几百元 | "送到哪个厂？" |
| 4 | **税费** | 含税（13%）、不含税 | 差 11.5%（1400 vs 1582） | "这个价含税吗？" |
| 5 | **交付** | 出厂、送到、库提、集港 | 差运费，常见 50–300 元/吨 | "是出厂价还是送到价？" |
| 6 | **日期** | 具体某天 | "现在"可能是上个月 | "这个价是哪天看到的？" |

**记录格式（写进 research.json 的 spot / history 条目）：**

```json
{
  "date": "2026-10-20",
  "spec": "重质纯碱（重碱），工业级 Na₂CO₃ ≥99.2%",
  "region": "华东地区",
  "tax": "含税",
  "delivery": "送到",
  "low": 1050,
  "high": 1200,
  "unit": "元/吨",
  "source": "隆众资讯（经我的钢铁网转载）",
  "url": "https://..."
}
```

## 二、九类差异因素

按**影响金额从大到小**排列。写进 `calibers[]` 时要写"往哪个方向影响多少"，
不能只写"有影响"。

### 1. 规格与纯度

| 情形 | 价格方向 | 典型幅度 |
|---|---|---|
| 食品级 vs 工业级 | 食品级更贵 | 几百到上千元/吨 |
| 主含量 99.5% vs 99.0% | 高含量更贵 | 几十到几百 |
| 粒度/目数不同（重碱） | 特定粒度更贵 | 几十 |
| 铁含量、不溶物等指标 | 指标严的更贵 | 几十到几百 |

写清楚：客户说的是什么规格，市场报的是什么规格，**是否同一档**。

### 2. 地区

| 情形 | 价格方向 |
|---|---|
| 主产区 vs 消费区 | 消费区通常贵（含运费） |
| 运距远 | 更贵 |
| 区域供需紧张 | 更贵 |

注意：**不能因为某地便宜就说"市场价是那个"**。要看客户的交付地在哪。

### 3. 税费

- 增值税一般 13%（化工品大多适用；个别品种/小规模纳税人不同）
- 换算：`含税 = 不含税 × (1 + 税率)`，`不含税 = 含税 ÷ (1 + 税率)`
- **客户未说明时不换算**，按市场税基直接比，并在结论里标注风险

### 4. 出厂 / 到厂（交付）

- 出厂价 = 送到价 − 运费
- **换算必须先有运费**。没有运费 → "无法直接折算"
- 报告里把这个写成"待确认"，不要写"暂按 80 元估算"

### 5. 采购数量

- 整车（30 吨左右）vs 零单
- 月用量 100 吨 vs 10 吨
- 年度框架 vs 单笔
- 数量影响的是"能不能拿到区间下沿"，不改变市场区间本身

### 6. 包装

| 包装 | 价格方向 |
|---|---|
| 吨袋 | 基准 |
| 25kg 小袋 | 更贵（包装+人工） |
| 槽车/散装 | 更便宜 |

### 7. 账期

- 现金 vs 承兑 vs 月结 30/60/90 天
- 承兑有贴现成本，**不能默认等同现金**
- 如果没有贴现率 → 不换算，标注"账期差异未计入"

### 8. 物流费用

- 运费因距离、车型、回程车、季节差异很大
- 不能凭经验估，要问物流或客户
- 如果客户报的是"自提价"，那和送到价差的就是全程运费

### 9. 个别低价成交

这是最容易出错的一类。规则：

| 情况 | 处理 |
|---|---|
| 有据可查的成交（有合同/发票/公开成交记录） | 可作为"参考"，标注"个别成交，不代表主流区间" |
| 听来的传闻（"我朋友说 XX 拿货才 1200"） | **不进市场价格**，只能列进"待核实" |
| 抛货/清库存/尾货 | 单独说明，不能代表市场 |

**绝不把个别成交当市场价格。** 市场参考区间来自公开报价的主流区间，
个别成交是"可能存在的最低点"，两者性质不同。

## 三、口径不一致时的三种处理

| 差异类型 | 能否换算 | 处理 |
|---|---|---|
| 只有税费不同 | ✅ 能（法定税率） | 换算，并在报告里写出公式 |
| 只有交付不同 | ⚠️ 需运费 | 有运费就换算；没有就"无法直接折算" |
| 只有账期不同 | ⚠️ 需贴现率 | 没贴现率就标注"未计入" |
| 规格不同 | ❌ 不能 | 判"口径不一致"，请客户确认规格 |
| 地区不同 | ⚠️ 需运距 | 只能做"邻近地区参考"，不能当客户所在地价格 |

## 四、写进报告的表达方式

**好**：
> 客户所述 1400 元/吨未说明含税/出厂口径。市场主报价为含税·送到 1050–1200 元/吨。
> 若客户价为含税出厂，需加运费后比较；当前运费未知，因此**暂无法直接折算**。

**不好**：
> 客户说的 1400 比市场 1125 高 24%，明显偏高。

（后者忽略了口径差异，把一个可能同口径的价格判成了异常。）

## 五、口径缺失时的措辞模板

| 缺失项 | 措辞 |
|---|---|
| 税费 | "客户未说明是否含税，暂按与市场同税基比较，结论需在确认税费后复核" |
| 交付 | "客户未说明出厂/送到，若为出厂价则需另加运费，当前无法直接折算" |
| 规格 | "客户所述规格未细分粒度/纯度，与市场报价口径可能不一致，建议先确认规格" |
| 日期 | "客户未说明价格取得日期，若为较早日期，可能对应不同的市场水平" |
| 数量 | "客户未说明采购量，批量与零星采购的实际成交位置通常不同" |
| 来源 | "客户未说明价格来源，建议请其提供平台名称或截图以便核对" |
