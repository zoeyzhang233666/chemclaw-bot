# 交付前自检清单

> 打印此页，逐条打勾。任何一项未通过都不要交付。

## A. 变量筛选（核心）

- [ ] **A1** 入选变量数在 **3–6** 之间
- [ ] **A2** 分类分布：同一分类 ≤2 个，且至少覆盖 2 个不同分类
- [ ] **A3** 每个变量都做了三维打分（重要性 / 可验证性 / 紧迫度，均为 1–5 整数）
- [ ] **A4** 排序依据是综合分（重要性×2 + 可验证性 + 紧迫度），不是直觉
- [ ] **A5** 候选池完整，用户点名的指标都进了候选池
- [ ] **A6** 每个落选候选都写了**具体**理由（不是"重要性低"）
- [ ] **A7** 与新入选变量高度相关的，已降为二级观察并写了**提级阈值**

## B. 变量内容（七要素）

对**每一个**入选变量逐项检查：

- [ ] **B1** ① 当前事实：有数值 + 日期 + 口径
- [ ] **B2** ② 近期变化：有方向和幅度（不只是"有所变化"）
- [ ] **B3** ③ 历史位置：有分位/极值/同比，或明确写"不可得"
- [ ] **B4** ④ 关注原因：说清它如何影响供需或价格机制
- [ ] **B5** ⑤ 传导机制：是可检验的因果链，不是名词堆叠
- [ ] **B6** ⑥ 验证条件：确认/否证/失效三类齐全，且**都有数字阈值**
- [ ] **B7** ⑦ 数据来源：具体到来源名 + 频率 + **下次可观测日期**

## C. 事件处理

- [ ] **C1** 所有事件都标了确定性档位
- [ ] **C2** "时点模糊"档都写了"以…为准"
- [ ] **C3** "条件触发"档都写了**不代表必然发生**
- [ ] **C4** 没有把市场传闻/预期写成既定事实
- [ ] **C5** `影响路径` 写的是机制，不是"利好/利空"

## D. 数据纪律

- [ ] **D1** 同指标多口径已**分行列出**，没有取平均
- [ ] **D2** 没有跨口径比较或相减（如隆众库存减卓创库存）
- [ ] **D3** 缺失值统一写 `数据缺失`，没有留空或写 0
- [ ] **D4** 估算值都标了 `估算/推算`
- [ ] **D5** 代理指标都写了代理关系 + 使用边界
- [ ] **D6** 缺口登记表每条四列齐全（指标/为什么不可得/替代/局限）
- [ ] **D7** 每个数值都能追到来源

## E. 合规红线

- [ ] **E1** 全文**没有**多空预测
- [ ] **E2** 全文**没有**"建议做多/做空/买入/卖出/建仓/目标价"
- [ ] **E3** 没有"将上涨/将下跌"式断言
- [ ] **E4** 结尾有"不构成投资建议"声明

## F. 产物质量

- [ ] **F1** HTML 可离线打开（无外部 CDN）
- [ ] **F2** 三个视图（卡片/时间线/快照）都能切换
- [ ] **F3** 分类筛选、自选收藏、搜索正常工作
- [ ] **F4** Excel 8 个 sheet 齐全
- [ ] **F5** Excel `05` 表回写下拉可用
- [ ] **F6** HTML 与 Excel 的数字**完全一致**（同源生成）
- [ ] **F7** 跑过 `scripts/check.py` 且通过

## G. 可用性

- [ ] **G1** 每个变量的"下次可观测"是**具体日期或明确周期**，不是"近期"
- [ ] **G2** 打开看板的人能在 30 秒内知道"这周该查什么"
- [ ] **G3** 判断修正条件能直接用于决策（能在看到新数据时立刻判断是否触发）

---

## 常见返工原因

| 症状 | 根因 | 处方 |
|---|---|---|
| 变量卡片读起来像行业综述 | 缺 ⑥ 验证条件 | 每个变量补数字阈值 |
| 事件线全是"预计" | 没做确定性分档 | 按 `事件确定性分级.md` 重写 |
| 数据看起来"太整齐" | 缺失被估算掩盖 | 回退到 `数据缺失` + 缺口登记 |
| 两个产物数字对不上 | 手工改了其中一个 | 改 payload 后重新生成 |
| 被读成"看多报告" | 混入方向词 | 删掉所有"利好/看涨/建议" |
