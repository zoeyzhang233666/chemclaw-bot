# 变量筛选标准

## 一、为什么要筛选

新手做产业跟踪最典型的失败方式是：**列 30 个指标，每天看一遍，什么也没跟踪到。**

原因有三：
1. 指标之间高度共线（港口库存、港口提货、周度表需其实是同一件事的不同切面）。
2. 很多指标一个月只更新一次，无法支撑周度决策。
3. 指标再多，如果不预先定义"什么信号意味着我错了"，就失去了跟踪的意义。

**本 Skill 的核心主张：3–6 个变量 + 明确的修正条件 > 30 个指标 + 每日盯盘。**

---

## 二、三维打分模型

对候选池中的每个指标打分（0–5 整数）：

### 维度 A：产业逻辑强度（importance）

| 分 | 判定标准 | 例子 |
|---|---|---|
| 5 | 直接决定供需平衡或价格形成机制的核心变量 | 甲醇港口库存、MTO 开工 |
| 4 | 显著影响但非唯一决定 | 进口到港量、基差结构 |
| 3 | 重要但传导有滞后或已被其他变量覆盖 | 内地厂库、煤价 |
| 2 | 间接相关 | 下游终端订单、宏观情绪 |
| 1 | 弱相关/仅背景 | 汇率、股市 |

### 维度 B：可验证性（verifiability）

| 分 | 判定标准 |
|---|---|
| 5 | 公开、高频（日/周）、有多个独立来源可交叉验证 |
| 4 | 公开、周度或月度，单一权威来源但口径稳定 |
| 3 | 需行业付费/会员，或仅有机构估算，但有二手转述可追 |
| 2 | 商业数据（船舶追踪、终端调研），公开渠道只有定性描述 |
| 1 | 企业不披露、无任何替代口径 |

> **可验证性 ≤ 2 的变量，原则上不单独成卡**。若产业逻辑强度为 5（如霍尔木兹海峡通行），可作为变量，但必须在"口径与局限"中写明二手依赖程度。

### 维度 C：周期匹配度（urgency）

| 分 | 观察周期 1 个月时 |
|---|---|
| 5 | 日频或周频更新，且未来 30 天内会有 ≥3 次新读数 |
| 4 | 周频，未来 30 天有 2–3 次 |
| 3 | 周频但下一次临近边界 / 月度数据 |
| 2 | 月度或季度，30 天内至多 1 次 |
| 1 | 年度/不定期，本周期内无法更新 |

### 综合分与排序

```
综合分 = A × 2 + B + C     （满分 16）
```

**排序必须用综合分**，不能因某个指标"听起来重要"（A=5 但 B=1）就排在前面。
紧迫度单列一档：`C=5 且 A≥4` 的变量，即使综合分稍低，也应排在前列——因为它在周期内能给出最多反馈。

## 三、硬性约束

### 3.1 数量约束
- 入选 **3–6 个**。少于 3：说明候选池没挖够或不敢做判断；多于 6：说明没做取舍。
- 用户点名的指标全部进候选池，但**不保证入选**。

### 3.2 分类均衡
分类集合：`供给 / 需求 / 库存 / 成本 / 价差 / 政策`

- 同一分类**最多 2 个**。
- 至少要覆盖 **2 个不同分类**（否则视角单一）。
- 若某分类（如"政策"）在本周期确实没有可验证的政策节点，可以不选，但要在"二级观察"中说明。

### 3.3 共线性处理
若两个候选变量描述同一机制（例如"港口库存"与"港口提货量"），保留综合分高的那个，另一个降为**二级观察**，并写明：

> 提级条件：当 X 超过 Y 时，将其提为独立变量。

### 3.4 落选必须留痕
落选的候选必须在"候选池与筛选"表中写明：
- `verifiability`：可验证性描述
- `reason`：落选的**具体**理由（不能写"重要性低"，要写"与 V1 高度相关，且更新滞后 1 周"）

## 四、二级观察（Watchlist Tier 2）

二级观察不是"不看了"，而是**不占卡片、不设完整验证矩阵，但设提级阈值**。

写法要求：每条必须包含
1. 为什么本周期不单列（弹性小 / 与新入选变量共线 / 数据滞后）
2. **提级触发条件**（带数字）

示例（甲醇案例）：

> **煤炭成本（鄂尔多斯 Q5500）**
> 煤价重返千元上方是估值锚抬升，但煤制甲醇利润仍 +1070 元/吨，短期不构成减产驱动。
> **提级条件**：坑口价单周涨幅 >3% 且煤制甲醇利润低于 300 元/吨。

## 五、验证条件设计规范

每个变量必须给出三类条件，且**必须带可观测阈值**：

| 类型 | 含义 | 写作要求 |
|---|---|---|
| **确认信号** | 原判断被数据强化 | 给阈值 + 时间窗，如"连续 2 周增加 ≥3 万吨" |
| **否证信号** | 原判断需修正 | 给阈值，如"回落至 32 万吨以下" |
| **变量失效** | 变量本身失真，不能再用它判断 | 说明哪种情况会让指标失去解释力 |

### 常见错误

| 错误写法 | 问题 | 正确写法 |
|---|---|---|
| "关注库存变化" | 无阈值，无法执行 | "连续 2 周环比增加 ≥3 万吨" |
| "若需求好转则价格上行" | 混入方向预测 | "MTO 开工回升至 70% 以上，表明需求修复，原'需求塌陷'判断需下调" |
| "库存变动反映供需" | 空话 | "到港恢复但库存仍降 → 提货强劲，说明缺货是真实的" |

### "变量失效"为什么重要

产业数据经常出现**指标本身失真**的情况，比判断错误更危险：

- 口径变化（样本扩容、统计方法调整）
- 结构性变化（交割库新增、仓单货源切换）
- 数据质量问题（误报、迟报）

**必须预先写明：出现什么情况，这个指标就不能再用来支撑结论。** 这是本框架区别于普通监测清单的关键。
