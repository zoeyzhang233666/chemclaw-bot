# 输出模板说明

## 一、产物清单

| 产物 | 文件 | 说明 |
|---|---|---|
| 交互式 HTML 看板 | `index.html` | 单文件、无外部依赖、可离线打开 |
| Excel 工作簿 | `*.xlsx` | 8 个 sheet，含回写区与下拉校验 |
| 数据源 | `payload_*.py` | 单一事实源，改这里即可重新生成 |

**两个产物由同一份 payload 生成，数字天然一致。** 不要手工改其中任何一个，改 payload 后重新生成。

---

## 二、HTML 看板结构

### 三个视图（顶部切换）

1. **变量卡片**：3–6 张卡片，每张含
   - 顶部：排名、名称、分类标签、三维星级（重要性/可验证性/紧迫度）、下次观测时间
   - 主体左栏：当前状态、近期变化、历史位置
   - 主体右栏：为什么值得盯、传导机制、迷你趋势图
   - 关键可核对数据（列表）
   - **判断修正条件**（三色：绿=确认 / 橙=否证 / 琥珀=失效）
   - 数据来源与更新节奏 + 口径与局限（虚线框）

2. **事件时间线**：按日期排序，颜色区分档位
   - 绿框 = 确定/进行中；蓝框 = 定期数据；黄框 = 条件触发
   - 已过去的节点灰化

3. **产业状态快照**：表格，一行一指标，含口径列

### 页面下方区块

- `01 候选池与筛选依据`：入选打 ✓，落选打 —，每项都有理由
- `02 二级观察`：不进卡片但写了提级阈值
- `03 数据缺口登记`：四列齐全
- `04 固定观察节奏`：周/日/月查询清单

### 交互功能

| 功能 | 说明 |
|---|---|
| 分类筛选 | 全部 / ★自选 / 各分类 |
| 自选收藏 | 点击 ☆ 存 localStorage，刷新不丢 |
| 全文检索 | 搜索框实时过滤卡片与事件 |
| 视图切换 | 三个 tab |

## 三、Excel 工作簿结构

| Sheet | 内容 | 特点 |
|---|---|---|
| `00 封面` | 品种、周期、口径声明、使用规则、导航 | 说明"这是观察工具不是预测" |
| `01 变量观察总表` | 21 列全景表，一行一变量 | 核心交付，带筛选 |
| `02 当前产业状态` | 指标/当前值/近期变化/历史位置/口径/来源 | 多口径分行 |
| `03 未来事件时间线` | 日期/分类/事件/档位/距今天数/确定性/影响/来源 | 距今天数自动算 |
| `04 候选池与筛选` | 入选与落选理由 + 二级观察 | 体现筛选过程 |
| `05 验证条件与触发器` | 三类条件 + 回写区 | 下拉：未触发/确认/否证/失效 |
| `06 数据缺口登记` | 指标/为什么不可得/替代/局限 | — |
| `07 观察日程` | 固定节奏 + 本期关键节点 | — |

**回写区说明**：`05` 表的 `本次状态`（G 列）设了下拉校验，`处理动作/备注`（H 列）留空供记录。条件格式会在选择"确认/否证/失效"时自动变色。

## 四、数据契约（payload）

### 顶层

```python
PAYLOAD = {
    "meta": {...},          # 品种、周期、口径
    "as_of": "2026-10-19",  # 数据截止
    "snapshot": [...],      # 产业状态快照
    "events": [...],        # 未来事件
    "candidates": [...],    # 候选池
    "variables": [...],     # 入选变量（3-6 个）
    "secondary": [...],     # 二级观察
    "gaps": [...],          # 数据缺口
    "charts": {...},        # 可选：迷你趋势图数据
    "weekly_calendar": [...],  # 可选：固定观察节奏
}
```

### 必填字段

| 区块 | 必填字段 |
|---|---|
| `meta` | commodity, cycle, contract_focus, region_focus, price_basis, research_position |
| `snapshot[]` | indicator, value, recent, history, scope, source |
| `events[]` | date, date_label, title, kind, cat, certainty, impact, source |
| `candidates[]` | name, cat, verifiability, selected, reason |
| `variables[]` | vid, name, cat, rank, importance, verifiability, urgency, horizon, current, recent_change, history_pos, why, mechanism, key_data, verify_yes, verify_no, invalidate, source, freq, next_date, confidence, gap |
| `secondary[]` | name, why |
| `gaps[]` | item, why, workaround, limit |

### 约束

- `variables` 数量 3–6
- `rank` 唯一
- `cat` ∈ {供给, 需求, 库存, 成本, 价差, 政策}
- `importance / verifiability / urgency` 为 1–5 整数

## 五、使用命令

```bash
# 安装依赖（仅需 openpyxl/xlsxwriter，若已有可跳过）
pip install xlsxwriter openpyxl lxml

# 一键构建
python scripts/make.py --payload my_case.py --html out/index.html --xlsx out/观察表.xlsx

# 静态校验（无浏览器环境也可用）
python scripts/check.py out/index.html out/观察表.xlsx
```

`make.py` 会先跑契约校验，不通过直接报错并列出问题。

## 六、换品种的方法

1. 复制 `templates/payload_template.py`
2. 只改 payload 内容，**不必改任何渲染代码**
3. 参考 `examples/示例-纯碱-骨架.py` 的最小结构

**渲染器是通用的**：新增品种、增删变量、改口径都不需要碰 `render_html.py` / `render_excel.py`。

## 七、常见问题

**Q：趋势图数据没有怎么办？**
`charts` 整体可选。缺省时卡片不显示迷你图，不影响其它内容。

**Q：想加一个自定义字段？**
在 `contract.py` 的 `SCHEMA` 里加到 `optional`，渲染器用到时再加。必填字段不建议随意增加。

**Q：HTML 打不开/样式错乱？**
本模板无外部依赖，直接双击打开即可。若企业环境限制脚本，可改用打印样式（Ctrl+P）。

**Q：Excel 中文乱码？**
用 Excel 或 WPS 打开。生成时已指定 UTF-8，若用 CSV 中转会丢失，请直接用 xlsx。
