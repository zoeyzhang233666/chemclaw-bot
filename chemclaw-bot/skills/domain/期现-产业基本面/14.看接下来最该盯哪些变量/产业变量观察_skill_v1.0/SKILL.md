# 产业变量观察：从"产业状态"到"3–6 个该盯的变量"

## 这个 Skill 解决什么问题

用户要的不是"几十项泛泛监测指标"，而是**一份能执行的观察清单**：

- 现在产业处于什么状态（可核实的事实）
- 未来一段时间有哪些**已经公开**的事件和**确定的**数据发布节点
- 因此，**只有这 3–6 个变量值得持续盯**，其余的为什么先不盯
- 每个变量：现在多少、怎么变的、在历史上什么位置、为什么它影响价格、去哪查、什么时候能拿到新数据、出现什么信号就要改判断

**三条铁律**（违反任何一条，产出即不合格）：

1. **不对未知未来事件下确定性判断。** 条件触发类事件只写"观察窗口"，不写"将于 X 日发生"。
2. **不做多空预测、不给方向建议。** 可以写"需重新评估原有产业判断"，不能写"看涨/看跌/建议做多"。
3. **不编造数据。** 拿不到就登记为"数据缺失"并说明替代口径与局限，见 `references/数据缺失处理规则.md`。

## 工作流（七步）

### Step 0 · 锁定研究边界

先把这几项问清楚，或从用户话里提取；缺失时用**默认值并在产出中显式声明**：

| 项目 | 必答 | 默认值 |
|---|---|---|
| 品种 | ✓ | — |
| 研究周期 | ✓ | 1 个月 |
| 期货或现货 | | 期现兼顾 |
| 重点区域 | | 该品种主产销区（如甲醇：华东港口+西北内地） |
| 现有判断 | | "待建立基线"（不预设多空） |
| 自选指标 | | 用户点名的一律进候选池，但**是否入选仍按统一标准打分** |

> 用户点名"想看看港口库存/装置开工/进口到港/煤炭成本"时，**不能机械照单全收**。它们全部进候选池（Step 3），能否入选由实际数据和事件决定，落选的要在"候选池与筛选"里写明理由。

### Step 1 · 快速核对当前产业状态

按六类核心指标逐项取数，**每项必须带：数值 + 日期 + 口径 + 来源**：

| 类别 | 典型指标 |
|---|---|
| 价格 | 期货主力收盘、现货（区域/规格）、基差、月差、区域价差 |
| 库存 | 港口/社会库存、厂库、待发订单、仓单 |
| 开工 | 行业产能利用率、分工艺（煤/气/油/焦炉气）、分区域 |
| 产量/供应 | 周产量、月度产量、进口量、到港量、装机/检修损失量 |
| 下游需求 | 主力下游开工（如甲醇的 MTO）、传统下游加权开工、订单 |
| 成本利润 | 原料价格（煤/气）、生产利润、下游利润、进口成本/到岸价 |

**关键要求**：
- 同一指标存在多口径时（如甲醇 MTO 开工"外采"vs"全口径"、库存"隆众"vs"卓创"），**必须分行列出并标注口径**，绝不跨口径比较或相减。
- 每个指标要判断"历史位置"：近五年同期什么分位、历史极值、同比/环比。没有历史序列就写"历史分位不可得"。

### Step 2 · 梳理未来已公开事件与数据节点

只收两类：
1. **已披露的产业事件**：检修、复产、投产、扩产、政策/会议、天气与季节性节点、出口/进口配额、履约截止。每条标注确定性：
   - `已披露·确定时点`（有明确日期）
   - `已披露·时点模糊`（"计划 X 月底"但未定）
   - `已披露·进行中`（已开始，结束时间待定）
   - `条件触发`（只在某条件成立时才发生，**不是必然事件**）
2. **有固定发布节奏的数据**（这类最可靠）：周度库存/开工、月度海关、交易所仓单/交割、政策例会。

> 禁止把"市场预期某装置将停车"写成事件；写成"机构转述计划，以周报装置动态为准"，并归入"待兑现"。

### Step 3 · 建立候选池并打分筛选

把 Step 1/2 中出现的所有相关指标 + 用户点名指标全部列进候选池，逐个用**三维打分**：

```
入选分 = 产业逻辑强度(0–5) × 可验证性(0–5) × 周期匹配度(0–5)
```

- **产业逻辑强度**：能否直接改变供需平衡或价格形成机制？只是相关的（如宏观情绪）给 1–2 分。
- **可验证性**：在观察周期内能否拿到可交叉验证的数据？纯商业付费、无公开替代的给 ≤2。
- **周期匹配度**：1 个月周期里能否至少完成一次"假设→验证"闭环？半年才更新一次的指标给 ≤2。

**硬性规则**：
- 最终入选 **3–6 个**，少于 3 说明还没挖穿，多于 6 说明没做取舍。
- 同类（如库存类）**最多保留 2 个**，避免卡片同质。
- 入选变量之间若高度相关（相关系数意义上的共线），把次要的那个降为**二级观察**并写出"提级阈值"。
- **落选项必须写理由**，不是删掉。

详细评分表与阈值见 [`references/变量筛选标准.md`](references/变量筛选标准.md)。

### Step 4 · 为每个变量填写七要素

每个入选变量必须完整回答（缺一项即不合格）：

| 要素 | 写作要求 | 反例 |
|---|---|---|
| ① 当前事实 | 数值+日期+口径+来源 | "库存处于低位"（无数字无日期） |
| ② 近期变化 | 环比/同比的**方向与幅度** | "库存有所变化" |
| ③ 历史位置 | 分位/极值/同比，或明确写"不可得" | 只写"低位"不给参照 |
| ④ 关注原因 | 它如何影响供需平衡或价格机制 | "重要指标"（空话） |
| ⑤ 传导机制 | 一句可检验的因果链 | 罗列名词 |
| ⑥ 验证条件 | 确认信号 / 否证信号 / 变量失效，各给**可观测阈值** | "关注存变化"（无阈值） |
| ⑦ 数据来源与节奏 | 具体来源 + 更新频率 + **下次可观测日期** | "行业网站" |

### Step 5 · 明确数据缺口

凡是拿不到的，写进缺口登记表五列：`指标 / 为什么不可得 / 替代口径 / 局限 / 是否会持续监测`。

典型情况：商业船舶追踪、企业不公告的装置开停、次月才发布的月度海关数据、需付费终端的分库数据。

规则见 [`references/数据缺失处理规则.md`](references/数据缺失处理规则.md)。

### Step 6 · 排序并生成产物

1. 排序：按 `重要性×2 + 可验证性 + 紧迫度` 降序。
2. 用模板引擎生成：
   - **HTML 交互看板**：变量卡片、事件时间线、产业状态快照、候选池、数据缺口、观察日程；支持分类筛选、自选收藏（localStorage）、全文检索。
   - **Excel 工作簿**：封面、变量总表、产业状态、事件线、候选池、验证触发器（带回写下拉）、数据缺口、观察日程共 8 个 sheet。
   - 命令见 [`references/输出模板说明.md`](references/输出模板说明.md)。

### Step 7 · 自检（交付前逐条过）

见下方"交付前自检清单"，**通过才交付**。

## 交付前自检清单

- [ ] 入选变量数在 3–6 之间，且分类没有超过一半集中在同一类
- [ ] 每个变量都有 ①–⑦ 七要素，验证条件给了**数字阈值**而非"关注变化"
- [ ] 每个变量的"下次可观测"是一个**具体日期或明确的周期**
- [ ] 同一指标不同口径已分行并标注，没有跨口径比较/相减
- [ ] 事件按确定性分档，"条件触发"没有被写成"将会发生"
- [ ] 全文没有多空预测、没有"建议做多/做空/买/卖"类表述
- [ ] 落选候选都写了理由，数据缺口都已登记
- [ ] 所有数值都有来源与日期；估算值都标了"估算/机构口径"
- [ ] HTML 能离线打开、三个视图可切换；Excel 8 个 sheet 齐全
- [ ] 两个产物的数字**完全一致**（同源生成）

## 快速开始

```bash
# 依赖（多数环境已有）
pip install xlsxwriter openpyxl lxml

# 1. 直接构建自带甲醇案例
python scripts/make.py

# 2. 换成自己的品种
cp templates/payload_template.py my_case.py
#    → 按注释填空（六步取数 + 候选打分 + 验证阈值）
python scripts/make.py --payload my_case.py --html out/index.html --xlsx out/观察表.xlsx

# 3. 自检（可在无浏览器环境运行）
python scripts/check.py out/index.html out/观察表.xlsx --payload my_case.py
```

`make.py` 会先跑契约校验（变量数 3–6、分类合法、打分为 1–5 整数等），不通过直接报错并列出问题。

## 适用边界

**适合**：有较强供需逻辑和可观测数据的化工品、工业品现货与期货跟踪。

**不适合**：
- 要求给出买卖建议、点位、目标价 → 本 Skill 只做观察框架
- 纯技术面择时 → 与本框架无关
- 数据完全不可得的冷门小品种 → 只能产出候选清单与缺口登记，无法产出验证条件
- 想一次性跟踪 20 个以上变量 → 应拆分为不同周期/不同品种的多期跟踪

**周期适配提示**：

| 周期 | 优先看什么 | 事件侧重 |
|---|---|---|
| 2 周 | 日频价差/基差、周度库存与开工、装置意外 | 短期检修、到港、交割 |
| 1 个月 | 周度库存+开工+进口+下游开工、月度产量 | 检修结束、政策会议、月度数据 |
| 1 季度 | 产能投放、季节性（限气/用肥/旺季）、政策 | 投产、环保限产、长协/配额、季节性拐点 |
