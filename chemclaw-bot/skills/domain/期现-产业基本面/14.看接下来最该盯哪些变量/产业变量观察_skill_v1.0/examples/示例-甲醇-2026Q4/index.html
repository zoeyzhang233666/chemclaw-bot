#1

港口库存去库终结？—— 隆众 vs 卓创双口径的拐点确认

库存 重要性 可验证性 紧迫度 下次观测：2026-10-22（下周库存），之后 10-29、11-05、11-12 周度（每周三/四）

当前状态

隆众 10-14 口径 36.72 万吨（+6.21），卓创 10-15 口径 41.33 万吨（+3.92，同比 -73.07%）

近期变化

10-08 的 30.51 万吨为历史低点 → 10-14 首次回升；华南 +9.37 万吨（广东进口+内贸双补充），华东 -3.16 万吨

历史位置

绝对水平近五年同期最低；较 2025-11 峰值 167.4 万吨 -78%；但已出现 3 月以来首次方向反转

为什么值得盯

甲醇港口库存是华东/华南定价的实物锚。库存极低 → 现货升水/基差走强；库存见底回升 → 基差收敛、近月强驱动消失。10-08 至 10-14 的 +6.21 万吨是本轮行情第一个"现实转弱"证据，必须确认是单周波动还是趋势起点

与供需 / 价格的传导

港口库存 = 到港量 + 内贸补充 - 提货量（含 MTO 刚需、传统下游、出口）。当前到港极低（10 月进口约 40-47 万吨 vs 正常 80-100 万吨），但 MTO 停车使提货同步塌陷，两者赛跑决定库存方向

甲醇港口库存（万吨，隆众口径）
卓创 10-15 口径为 41.33 万吨，样本不同不可混用

关键可核对数据

  • ①隆众周度港口总库存（华东/华南分列）
  • ②卓创沿海库存
  • ③华东/华南周度提货量
  • ④江苏/浙江/广东分库库存
  • ⑤内地-港口价差（太仓-内蒙-550 约 318 元/吨，套利窗口）

判断修正条件

✓ 确认信号
隆众口径连续 2 周环比增加 ≥3 万吨且华南/华东同时累库，同时太仓基差跌破 400 元/吨 → 确认库存拐点，原"低库存支撑近月"判断需下调
✗ 否证信号
隆众口径再度回落至 32 万吨以下、且卓创同比降幅仍在 -70% 以上 → 低库存叙事延续，需把关注点移回进口与 MTO 成本
⚠ 变量失效 / 口径失真
到港恢复但库存仍去化（说明提货极强）或库存累库但基差逆势走强（说明可流通货源结构性紧张，库存数字失真）

#2

霍尔木兹海峡通行与伊朗装置 —— 进口断档的真伪

供给 重要性 可验证性 紧迫度 下次观测：10-23 起伊朗 11 月装船观察窗；11-10 海关 10 月数据；每周一/二国际甲醇周报 日频/周频（船期+装置），月度（海关）

当前状态

10 月进口预估 40-47 万吨（大地：45-50 万吨）；9 月伊朗装船仅约 21.3-24 万吨；伊朗开工约 37%、日产约 1.3 万吨；约 660 万吨伊朗产能仍停车

近期变化

伊朗多套装置曾重启（Marjan、Busher、Apadana、Kaveh 等），但 ZPC 开一停一，装船量受海峡通行直接约束；美伊谈判暂无实质进展

历史位置

进口量为近五年同期最低（同比 -54%）；海外甲醇月度产量 337 万吨、同比 -23.29%，海外开工 53.35%

为什么值得盯

中国甲醇进口依赖中东，伊朗占进口约 55-60%。海峡通行是进口的"闸门"，而 10 月剩余两周到港量已被确认为低位——这意味着 11 月上旬前的港口偏紧是"已锁定"的，真正有分歧的是 11 月下旬及以后

与供需 / 价格的传导

海峡通行量 → 伊朗装船 → 航程约 20-25 天 → 中国到港 → 港口库存。同时海峡紧张会抬高保费/运费，推升 CFR 到岸成本，从而抬升甲醇的进口成本锚

甲醇期货主力合约收盘价（元/吨）
10-09 无可靠收盘价，取盘中 3820 附近并标注；10-19 起主力切换至 2701，跨合约不严格可比

关键可核对数据

  • ①霍尔木兹海峡日通行船数（Kpler/Lloyd's List 类船舶追踪）
  • ②伊朗甲醇周度产量与开工
  • ③伊朗月度装船量
  • ④中国周频到港量（华东/华南）
  • ⑤CFR 中国报价与华东进口价差

判断修正条件

✓ 确认信号
海峡通行明显恢复（日通行回到常态一半以上）+ 伊朗装船单月回升至 30 万吨以上 → 进口断档结束，浮仓释放将成为最大下行变量，原"供给硬缺口"判断需立即修正
✗ 否证信号
海峡持续受阻且 11 月装船仍低于 25 万吨 → 12 月到港继续偏低，进口逻辑延续，需把库存变量的权重下调
⚠ 变量失效 / 口径失真
海峡恢复但因冬季限气伊朗无法出货（通行≠有货），或伊朗货源改道其他国家而非中国，导致"通行改善"未能传导到中国到港

更新频率

置信度
中（装置与装船可由研报交叉验证，海峡通行细节不透明）
⚠ 口径与数据局限：海峡实际通行量为商业数据，公开渠道仅有二手转述；伊朗装置开停属企业/政治信息，无官方披露，只能依赖三家以上机构交叉
#3

沿海外采 MTO 停车潮的深度与复产时点

需求 重要性 可验证性 紧迫度 下次观测：每周四前后开工；10-20 诚志一期计划停车兑现；每周装置动态清单 周度（开工）+ 事件驱动（停车/复产）

当前状态

外采 MTO 开工 60.91%（10-08）；MTO 全口径 76.69%（10-14，-3.01pct）；外采 MTO 理论利润 -4000 元/吨级（另一机构测 -1800~-2000）

近期变化

10-10 渤化停车、10-11 联泓停车、10-15 诚志一期降负、10-18 诚志二期停车、10-20 诚志一期计划停车；宁波富德 9-19、恒通 9-18 已停；鲁西、兴兴、斯尔邦持续停车

历史位置

江浙外采 MTO 开工处历史极低位；MTO 利润为历年最差区间（2018 年同类亏损驱动的停车持续约 3 个月，至次年春节前后才复产）

为什么值得盯

需求负反馈是 10-12 日大跌的直接触发。关键分歧在于：这是"高价逼出来的短停"，还是"持续到 2027 年的结构性退出"。它决定港口提货塌陷的速度，也决定基差修复是靠期货上涨还是现货下跌

与供需 / 价格的传导

甲醇价格 → 外采 MTO 现金流 → 停车/降负 → 港口外采需求下降 → 港口提货与库存 → 甲醇现货。反向：MTO 利润修复（甲醇跌或烯烃涨）→ 复产 → 外采需求回归

甲醇期货主力合约收盘价（元/吨）
10-09 无可靠收盘价，取盘中 3820 附近并标注；10-19 起主力切换至 2701，跨合约不严格可比

关键可核对数据

  • ①隆众/卓创 MTO 产能利用率（外采与一体化分列）
  • ②华东 MTO 单体利润
  • ③各外采装置（诚志一期/二期、渤化、联泓、兴兴、斯尔邦、鲁西、宁波富德、恒通、天津）开停台账
  • ④PP/PE 价格与 PP-3MA 价差
  • ⑤港口周度提货量

判断修正条件

✓ 确认信号
外采 MTO 开工跌破 50%，或出现第 2 家"原计划复产"装置再度延期，且 PP-3MA 价差未扩大 → 负反馈加深，原"需求弹性有限、下行空间受限"需下修
✗ 否证信号
甲醇大幅回落后 MTO 单体利润回升至 -500 元/吨以内且有装置提前复产（如诚志二期/渤化）→ 负反馈见底，应按"需求修复"路径重估
⚠ 变量失效 / 口径失真
装置停车实际原因是原料短缺（买不到货）而非亏损，或一体化 MTO 外卖甲醇扩大（如 CTO 外放），导致开工下降但港口供给增加

主力换月与基差结构 —— 现货紧张如何兑现

价差 重要性 可验证性 紧迫度 下次观测：每日收盘；关键节点 11-13（MA2611 最后交易日）、11-20 前后主力完整切换至 2701 日频，11 月中交割为终点

当前状态

MA2611 10-16 收 3366 元/吨（当时主力）；MA2701 10-19 收 3143 元/吨，10-20 开 3146 元/吨（新主力）；太仓 3983 元/吨（10-16）；太仓基差 629 元/吨（10-16，+77）

近期变化

10-09 主力盘中 3925（阶段高）→ 10-12 早盘跌至 3521(-7.65%) → 10-13 收 3453(-6.73%) → 10-16 MA2611 收 3366 → 10-19 MA2701 收 3143；基差自 975 回落至 629，但仍在历史极端区间；MA2611 持仓 10-16 已降至 22.92 万手，日减仓 3.32 万手，移仓加速

历史位置

正常年份基差约 100 元/吨，旺季高点通常不超 500 元/吨；当前 629 元/吨处于历史分位 99% 以上；主力换月将把"近月价格"从 11 合约平滑过渡到 01 合约

为什么值得盯

基差是甲醇期现研究的核心价格。极值基差意味着两种可能：①现货真缺、期货将向现货修复（上涨）；②现货将被压制、期货向现货靠拢（下跌）。11 月合约交割与换月是这两种路径的裁决点，直接影响套保效率与采购时点

与供需 / 价格的传导

基差 = 现货 - 期货。港口库存低位 + 可流通货源紧 → 现货强势 → 基差走阔；换月/交割时仓储、资金成本被定价 → 月差结构反映市场对 11-12 月库存的预期；基差收敛路径（现货跌 vs 期货涨）决定产业客户套保与点价策略

太仓基差（现货-主力，元/吨）
三组基差来源口径不一致，仅看方向与量级；正常年份约 100 元/吨，旺季高点一般不超 500

关键可核对数据

  • ①MA2611/MA2701 收盘、成交、持仓
  • ②太仓现货与基差（分月基差：现货/月中/月下/11下）
  • ③MA01-05 月差
  • ④郑商所仓单数量与交割预报
  • ⑤河南/内地仓单货源价格（当前期货锚定转为河南仓单货）

判断修正条件

✓ 确认信号
基差收敛方式为"现货跟随下跌"（太仓跌破 3800 且基差收窄至 300 以内），同时仓单大幅增加 → 现货紧张被证伪，原"近强远弱"判断下修
✗ 否证信号
期货快速向现货修复（近月重返 3600 以上）而现货坚挺，基差收敛但现货不跌 → 现货真缺确认，需重新评估下游补库与套保对冲规模
⚠ 变量失效 / 口径失真
基差走弱是因为交割库/仓单结构变化（如新增交割库、仓单货源切换至河南）而非供需，或期现口径错配（用不同区域/税基现货直接相减）

02二级观察（不进卡片，但跌破阈值要提级）

这些变量的信息价值真实存在，但在这个 1 个月周期内要么弹性小、要么与主变量共线。

煤炭成本（鄂尔多斯 Q5500）
煤价重返千元上方是估值锚抬升，但煤制甲醇利润仍 +1070 元/吨，短期不构成减产驱动。观察它是因为：若煤价二次上行至 850+ 元/吨而甲醇回落，内地利润被压缩，会触发内地装置降负（供给端新增收缩），这是当前"库存拐点"叙事之外的对冲力量。触发条件：坑口价单周涨幅 >3% 且煤制利润低于 300 元/吨。
内地厂库与待发订单
厂库 35.69 万吨（+3.46）连续累积，与港口极端低位形成背离，是判断"内地-港口套利流向"的关键。但它与港口库存高度相关，更适合作为 V1 的验证子项，不单独占卡片位。
传统下游开工
甲醛/醋酸/MTBE 合计约占需求三分之一，但季节性明显、单周波动大，短期不改变边际定价。作为 V3 的补充验证。
出口/转口价差与出口量
东南亚-中国 CFR 价差约 190 美元/吨确实打开出口窗口，且出口对港口提货有支撑；但实际出口量月度才见，且体量小于 MTO 缺口，暂列二级。
宝丰 280 万吨新装置外售决策
10 月底投产但配套烯烃年底才投产，是否外售甲醇未定；即使外售，量级也需与国能榆林检修（45 天）对冲，短线影响有限。已列入事件时间线跟踪。
MA 仓单与限仓政策
11 月交割前有交易层面意义，但更偏规则变量而非产业变量，本周期不单列。

指标为什么不可得替代口径局限
霍尔木兹海峡逐日通行量 属商业船舶追踪（Kpler、Lloyd's List Intelligence）付费数据，公开渠道仅有二手转述（如"通行仍处极低水平"，无具体船数） 用"伊朗装船量+中国周频到港量"间接代理；跟踪 3 家以上研报的口径一致性 无法做到日内更新，结论存在 1-2 周时滞
伊朗单套装置开停状态 伊朗甲醇装置（Kaveh、Kimiya、Sabalan、Marjan、ZPC、Busher、Apadana 等）无官方披露，仅有研报转述 以"伊朗日均产量/开工率"的机构估算替代单套装置台账 来源为估算，不同机构差异可达 10pct，不可当作实测
