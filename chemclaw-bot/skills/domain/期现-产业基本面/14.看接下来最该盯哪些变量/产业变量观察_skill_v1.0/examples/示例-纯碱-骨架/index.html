为什么值得盯

高库存+产能扩张下，库存拐点是纯碱最强的定价信号：去库对应现货企稳，累库对应进一步压价

与供需 / 价格的传导

产能投放/开工 → 周产量 → 企业库存 → 现货报价与基差 → 盘面

关键可核对数据

  • ①企业库存总量
  • ②分区域库存
  • ③厂家待发订单
  • ④纯碱库存天数

判断修正条件

✓ 确认信号
连续 3 周去库且降幅 >3%，同时现货报价止跌 → 过剩压力缓解，原“累库压价”判断需上调
✗ 否证信号

⚠ 变量失效 / 口径失真
若口径调整（样本扩容）或厂家转出口导致库存下降但国内供给未变，则不能以库存下降推断供给收缩

02二级观察（不进卡片，但跌破阈值要提级）

这些变量的信息价值真实存在，但在这个 1 个月周期内要么弹性小、要么与主变量共线。

原盐/煤炭成本
决定现金成本支撑；但当前供给过剩，成本更多是底部约束而非驱动。提级条件：现货跌破行业平均现金成本且开工明显下降。
轻碱/重碱价差
反映重碱相对强弱，但与日熔量高度相关，暂作二级。提级条件：轻碱价格显著强于重碱且持续 2 周以上。

03数据缺口登记

凡是无法稳定获得的指标，一律在这里写明「为什么拿不到 / 用什么替代 / 局限在哪」， 而不是用估算值冒充实测值。

指标为什么不可得替代口径局限
新增产能实际达产率 企业不披露，只能从月度产量与区域库存间接推断 用周产量增量 + 区域库存反向估算 无法区分“新装置达产”与“老装置提负荷”，结论存在歧义
玻璃厂纯碱库存天数 属于终端调研数据，公开渠道多为定性描述 以下游成品库存与采购节奏代理 只能判断方向，不能量化
