# 示例：纯碱骨架

本目录演示**同一个引擎换品种**——只改数据，不改任何渲染代码。

## 文件

| 文件 | 说明 |
|---|---|
| `payload_纯碱.py` | 数据源（含"待核实"占位，表示正式使用时须填真实数据） |
| `index.html` | 生成的看板 |
| `纯碱-变量观察.xlsx` | 生成的工作簿 |

## 这个示例想说明什么

### 1. 不同品种的变量结构完全不同

| | 甲醇 | 纯碱 |
|---|---|---|
| 定价主要矛盾 | **进口断供 + 港口极低库存** | **产能扩张 + 高库存** |
| 首要变量 | 港口库存 | 企业库存方向 |
| 第二位 | 中东供应/海峡 | 玻璃日熔量（需求） |
| 第三位 | MTO 开工 | 开工率/周产量 |
| 第四位 | 基差与换月 | 现货与基差 |
| 成本地位 | 二级（利润仍厚） | 二级（成本是底部约束） |

**照搬甲醇的变量清单去套纯碱是错的。** 港口库存对纯碱几乎无意义（纯碱以内陆产销为主），而对甲醇是命门。这就是"变量必须由实际数据支撑"的意义。

### 2. 事件类型不同

- 甲醇：地缘/船期（**条件触发**为主）——高度不确定，只能设观察窗
- 纯碱：投产节点 + 玻璃冷修/点火（**计划类**为主）——时点模糊但可追踪

同样要分档，但档位分布完全不同。

## 使用方式

本骨架中大量数值写作"待核实"。正式使用时：

1. 打开 `payload_纯碱.py`
2. 把所有"待核实"替换为当日真实数据（带日期与来源）
3. 把 `<<<>>>` 占位符替换为实际内容
4. 运行：

```bash
python scripts/make.py --payload examples/示例-纯碱-骨架/payload_纯碱.py \
    --html examples/示例-纯碱-骨架/index.html \
    --xlsx examples/示例-纯碱-骨架/纯碱-变量观察.xlsx
```

5. 运行自检：

```bash
python scripts/check.py examples/示例-纯碱-骨架/index.html \
    examples/示例-纯碱-骨架/纯碱-变量观察.xlsx \
    --payload examples/示例-纯碱-骨架/payload_纯碱.py
```

> 当前骨架的自检结果为 34/34 通过——因为验证条件、threshold 等**结构性要求**都已满足，
> 只是数值待填。这正是骨架的用途：**先搭对结构，再填数据**。

## 注意

> 本骨架**不是一份已完成的研究**，不能直接用于决策。
> 其中的"待核实"若是臆造数据，产物即不合格（见 `references/数据缺失处理规则.md`）。
