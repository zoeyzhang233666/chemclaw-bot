# SBS 产业链价格地图（实例记录）

这是本技能的一次真实研究留档，既当"完成态参考"，也当"研究过程长什么样"的说明。

## 一句话结论

SBS 干胶/油胶的当日主流报价集中在 13,000–15,650 元/吨区间，
上游丁二烯、苯乙烯同处 1.1 万–1.35 万元/吨量级；下游四个应用方向本次均未取到授权报价。

## 数据与口径

| 项 | 值 |
|---|---|
| 数据日 | 2026-10-15（部分资讯为 2026-10-16 早间提示） |
| 单位 | 元/吨 |
| 来源 | 现货报价库（结构化地区报价）、市场资讯（早间提示类文字行情） |
| 链条 | 5 列 12 节点 15 条关系；有价环节 8 个，应用环节 4 个 |

链条结构：石脑油 →（蒸汽裂解）乙烯 → 苯乙烯；石脑油 →（重整/抽提）纯苯 →（加氢）环己烷（聚合溶剂）；
丁二烯 + 苯乙烯 →（阴离子溶液聚合）SBS → 干胶 / 充油油胶 → 改性沥青·防水卷材 / 鞋材 / 胶黏剂 / 聚合物改性·电缆料。

## 这份实例刻意演示的几点

1. **不平均**：上游每个品种按地区逐条列（如丁二烯华东聚合级、华北、华中、华南、东北、西北工业级分开），
   节点上的代表值能在 `rows` 里逐字找到，并在 `basis` 里写明是哪个口径。
2. **区分工艺投入**：环己烷作为聚合溶剂用**虚线**连接，避免读者误以为它与丁二烯、苯乙烯等量消耗。
3. **缺口如实留空**：SBS 改性沥青、热熔胶（观测数为 0），鞋材 / 胶黏剂 / 防水卷材 / 聚合物改性·电缆料
   （无授权序列）——都画成缺口卡片，没有编造价格。
4. **资讯口径单独成表**：早间提示里的区间价、涨跌、"无货无价格"等信息放进附加明细，
   不与结构化报价混排（两者口径不同：一个是逐条报价，一个是文字行情）。
5. **明确记录"无货"**：如某牌号缺货、暂无报盘，作为记录写入并标 `missing`，图上不出价格数字。

## 已知限制

- 部分 SBS 记录的原始地区字段是占位值（原文为"地区"），本实例写作"未细分"，**不代表真实地区**。
- 多数记录未提供税制/币种/提货方式（原文"税制未提供"），因此不作跨口径比价与价差计算。
- 产业链传导关系为**示意**（通用工艺路径），不是本次数据可证实的因果结论。
- 参照品（道路沥青、丁苯橡胶）单独成表，**不与 SBS 混算价差**。
