# 化工产业链价格地图研究

面向任意化工品（SBS、PP、MDI、纯碱、有机硅、磷酸铁锂……）的可复用研究方法与交付格式。
目标不是"画一张好看的图"，而是**让每个数字都能追到原始记录，让没查到的部分明确留空**。

## 什么时候用

- 用户要"某化工品的产业链 / 上下游 / 价格地图 / 最新报价 / 报价明细 / 产业链图"。
- 用户要给某产品做上下游成本—价格传导的结构化梳理。
- 用户已有数据，需要一版可交互、可转发的产业链价格页面。

不适用：只要一个品种的单点价格（直接答即可）；没有价格数据的纯工艺路线图（用普通流程图即可）。

## 交付物（固定这一套）

| 文件 | 作用 | 是否必出 |
|---|---|---|
| `<product>-chain.html` | 主交付物：自包含离线交互页面 | **必出** |
| `chain-data.json` | 页面背后的数据（可复核、可复现、可交接） | **必出** |
| 研究说明 | 口径、方法、缺口、来源（可并入 HTML 的说明区块） | **必出** |

HTML 必须满足：单文件、内联 CSS/JS、**零外部资源**（无 CDN、无外链字体、无图片、无 iframe），
断网也能打开——因为这份文件通常会被转发给看不到内网/外网的人。

## 五步流程

1. **先问清标的与范围**（一次问完，别串问）
   - 具体品种与规格（SBS？SBS 干胶 / 油胶分开？）
   - 地区范围（全国 / 华东华南 / 单一市场）
   - 时间口径（最新一日 / 近一周）
   - 下游要覆盖哪些应用（取不到价也要列出来留缺口）
   目标不清晰就先问，不要凭默认值替用户决定。

2. **定产业链结构**（先骨架，后价格）
   上游原料 → 中间体 → 本体 → 下游应用，逐环节定"为什么它在链上"。
   结构关系写清楚是**示意**：除非有资料明确记载，不要声称某条传导关系已被证实。
   副产物、溶剂/助剂投入用虚线区分，避免读者误读为等量消耗。

3. **逐环节取价**（每个数字都要有记录）
   - 价格只从授权数据源取，一条记录一条来源；**不得凭印象、经验或"市场普遍认为"填数**。
   - 同一环节多地区/多规格时，逐条列，不要平均成一个"市场价"。
   - 单位必须落到每一条记录上；**没有单位的价格不允许画进价格图**。
   - 明确没查到（无货、无报盘、需要权限、检索结果为 0 条）的，写进缺口清单，**不用 0 或估算值占位**。

4. **校验后生成页面**
   ```bash
   python scripts/validate_dataset.py chain-data.json      # 数据契约：缺单位/缺值当零/连线悬空
   python scripts/build_chain_html.py chain-data.json      # 生成自包含交互 HTML
   python scripts/verify_html.py <out>.html --source chain-data.json   # 产物自检
   node scripts/verify_render.js <out>.html                # 可选：渲染冒烟（无 Node 可跳过）
   ```
   三个校验脚本都是纯标准库（verify_render.js 需要 Node，可选），不联网、不装包。

5. **交付与说明**
   聊天里给结论（一句判断 + 最多两条支撑/局限），不要复述整张表；
   文件用 `[标题](artifact:相对路径)` 链接给出；来源与口径放在 HTML 的说明区块里，正文只给短引用。

## 硬规则（违反任何一条都要返工）

- **缺值不当零**：查不到就写缺口，不写 0、不写估算区间。
- **单位必填**：`meta.unit` + 每条记录；缺单位的数字不得画成价格图。
- **不跨口径比较**：不同地区、规格、税制、币种、提货方式不得混算或比价；不把报价行平均成一个"产品价"。
- **不做自算价差**：不能自己算本产品与原料的价差/利润；只有原始记录里给出来的差值才能引用。
- **图上数字必须能在记录里找到**：节点标注价要来自它的原始记录，并在口径里写明它是哪一条/如何代表。
- **结构关系不冒充事实**：产业链传导关系默认标注为示意/推断；有明确记载的才可标为有据。

## 数据模型与文件说明

- 数据结构（`chain-data.json` 全部字段）：`references/data-contract.md`
- 研究流程与提问模板：`references/workflow.md`
- HTML 交付规范与交互形态：`references/html-deliverable.md`
- 数据源适配与降级（有 MCP 数据工具 / 有联网 / 什么都没有）：`references/adapters.md`
- 完整实例：`examples/sbs/`（SBS 全链，含真实价格与缺口）
- 空模板：`examples/template-example/`（只有结构，无价格，起手照抄它）

## 脚本

| 脚本 | 输入 | 输出 |
|---|---|---|
| `scripts/validate_dataset.py` | chain-data.json | 错误/警告清单，退出码 1 = 有错 |
| `scripts/build_chain_html.py` | chain-data.json | 自包含交互 HTML |
| `scripts/verify_html.py` | HTML（+ `--source`） | 自包含/几何/数据一致性自查 |
| `scripts/verify_render.js` | HTML | 渲染冒烟（Node，可选） |
| `scripts/chain_layout.py` | — | 布局引擎，被上面两个脚本共用，不单独运行 |

先用 `examples/template-example/chain-data.json` 起手，把 nodes 换成目标品种再取价。
