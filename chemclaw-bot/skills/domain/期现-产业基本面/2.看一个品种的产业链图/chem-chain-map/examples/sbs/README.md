## 一、这张图的范围

```
原油 ─→ 石脑油/LPG ─→ 裂解产物、重整芳烃 ─→ 乙烯、纯苯、C4、C8
                                                  │
              苯 + 乙烯 → 乙苯 → 苯乙烯 ────────┤
                     C4 → 丁二烯 ──────────────┤
                                                  ↓
                                              【SBS】
                                                  │
        ┌──────────┬──────────┬──────────────┬───┴────────┐
   改性沥青   热熔胶/压敏胶   TPR 鞋底料   改性聚烯烃    胶黏剂
        │          │           │              │
    防水卷材    BOPP 胶带     鞋底          家电汽配
    沥青路面
        │          │           │              │
   建筑防水    包装物流     鞋类制造      家电与汽车
   公路建设
```

**向上 2 层**：苯乙烯、丁二烯（及其各自的原料：苯、乙烯、乙苯、C4 馏分）。
**向下 2 层**：改性沥青→防水卷材/沥青路面；TPR→鞋底；热熔胶→胶带；改性聚烯烃→家电汽配。

**延长线**（不计入覆盖）：原油、石脑油/LPG、裂解汽油/重整芳烃。为了让"原料是哪来的"能看懂，画到了原油这一列。

## 二、节点分类（36 个）

| `node_class` | 数量 | 例 |
|---|---|---|
| `commodity` 化学品 | 21 | 目标品种 SBS，及其原料链：苯乙烯、丁二烯、乙苯、纯苯、乙烯、C4 馏分、C8 芳烃、裂解汽油、加氢混合芳烃、石脑油、LPG、原油、基质沥青 |
| `material` 配方材料 / 制品 | 10 | SBS 改性沥青、防水卷材、沥青路面、TPR 鞋底料、鞋底、热熔胶、BOPP 胶带、胶黏剂、改性聚烯烃、填充油 |
| `application` 终端应用 | 5 | 公路与市政道路、建筑与市政防水、鞋类制造、包装物流、家电汽车内外饰 |

同族的 SIS / SEBS / TPU / EVA / POE / ESBR 计入 `commodity`（它们是独立化学品，各有 CAS）。

> 注意：SEBS 是 SBS 加氢的**衍生化学品**（`conversion`），SIS 是**同族并列品**，TPU/EVA/POE/SBR 是**替代品**（`substitution`）。这四类在图上的位置与画法完全不同。

## 三、关系类型分布（48 条）

| 类型 | 条数 | 说明 |
|---|---|---|
| `conversion` 原料转化 | 14 | 石脑油→乙烯、苯+乙烯→乙苯→苯乙烯、C4→丁二烯、SM+BD→SBS、SBS→SEBS |
| `byproduct` 副产 | 2 | 裂解 C4、裂解汽油 |
| `blend` 配方共混 | 10 | SBS→改性沥青、SBS→TPR、SBS→热熔胶、SBS→改性聚烯烃、基质沥青→改性沥青、填充油→油胶 |
| `processing` 成型加工 | 5 | 改性沥青→卷材、TPR→鞋底、热熔胶→胶带、路面层 |
| `application` 终端应用 | 7 | 卷材→建筑防水、路面→公路、鞋底→鞋类、胶带→包装 |
| `substitution` 替代 | 7 | TPU/EVA/POE/ESBR/SIS ↔ SBS |
| `route_option` 工艺路线 | 3 | LPG→乙烯、裂解汽油→苯乙烯、TDA 旁支（自环） |

（本版未建独立的 `coproduction` 边：裂解装置的多产品关系用 `byproduct` + `route_option` 表达，因裂解产物主次明确。）

**关键取舍**：`SBS → 鞋` 这条路**被 `forbidden_links.json` 的 F01 明确禁止**。真实链条是
`SBS →(blend) TPR 鞋底料 →(processing) 鞋底 →(application) 鞋类制造`。
把终端用途写成化学转化产品，是产业链图最常见、也最污染成本模型的一种错误。

## 四、量化参数的三种口径

| 边 | 数值 | 口径 | 为什么这么给 |
|---|---|---|---|
| 边 | 数值与单位 | `basis_grade` | 说明 |
|---|---|---|---|
| 乙苯 → 苯乙烯 | 1.04 t 乙苯 / t 苯乙烯 | 工业级乙苯 → 聚合级苯乙烯 | 质量收率 ~96% 折算，含循环乙苯回收 |
| 苯 → 乙苯 | 0.758 t 纯苯 / t 乙苯 | 石油苯 545 → 工业级乙苯 | 烷基化（含反烃化）收率折算 |
| 乙烯 → 乙苯 | 0.272 t 乙烯 / t 乙苯 | 聚合级 → 工业级 | 同上 |
| 丁二烯 → SBS | 0.70 t / t SBS 干胶 | SBS 干胶（非充油） | S/B = 30/70 配方比，非化学计量 |
| 苯乙烯 → SBS | 0.30 t / t SBS 干胶 | SBS 干胶（非充油） | 同上 |
| 石脑油 → 乙烯 | 3.0 t / t 乙烯 | 石脑油（重整料/裂解料） | 不同裂解深度差异大，属文献级 |
| C4 馏分 → 丁二烯 | 2.1 t 裂解 C4 / t 丁二烯 | 聚合级 99.5% | 抽提装置基准（C4 含丁二烯约 45%，收率 95%） |
| SBS → 改性沥青 | 0.042 t / t 改性沥青 | I-C/I-D 改性沥青 | 掺量区间 3.5%~5.5%（随气候分区与沥青配伍变化） |
| SBS → TPR 鞋底料 | 0.65 t / t TPR 料 | 注塑级 TPR 鞋底料 | 配方比 |
| SBS → 热熔胶 | 0.32 t / t 热熔胶 | 包装类 SBS 基热熔胶 | 配方比 |
| 基质沥青 → 改性沥青 | 0.95 t / t 改性沥青 | 90#/70# A 级 | 配方比 |

## 七、几个刻意的决定

| 决定 | 理由 |
|---|---|
| `N_C8A`（混合 C8 芳烃）保留但**不建** C8→苯 的转化边 | 甲苯歧化(TDA)的原料是甲苯与 C9 芳烃，不是 C8。为了"图形完整"画一条 C8→苯，就是把不同工艺混成一条链。改成自环 `route_option` 登记，并在 F10 里写明这是**方向存疑边** |
| SBS→SEBS 用 `conversion` | 加氢是真实的化学反应，SEBS 的分子里含 SBS 的骨架 |
| SIS 用 `substitution` 而不是 `conversion` | SIS 用的是异戊二烯，不是"SBS 变的" |
| 终端应用不出边 | `application` 节点若还有下游，说明它不是真终端 |
| 延长线不透明化 | 让人一眼看出"这几列只是为了让原料路线看得懂，不是核心结论" |
