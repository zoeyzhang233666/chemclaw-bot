# 04 · 证据、核验与数据获取

> 产业链图的信用 = 每条边的可回溯程度。这一页规定"什么算证据""怎么核验""怎么抓"。

---

## 1. 证据分级

| 等级 | 定义 | 例 | 能支撑什么 |
|---|---|---|---|
| **A** | 官方、协会、标准、上市公司公告/年报、政府统计 | 中国石油和化学工业联合会、海关总署、公司年报、GB/T 标准、EIA、SEC 10-K | 产能、产量、消费结构、进出口、工艺路线 |
| **B** | 行业媒体深度报道、期货公司/券商研究、行业协会刊物 | 中国化工信息周刊、卓创/隆众研究文章、期货公司品种年报 | 产能、工艺、单耗区间、消费结构 |
| **C** | 信息商公开页、企业官网产品页、百科（需交叉验证） | oilchem.net 公开 SEO 页、企业官网、化工百科 | 价格点、规格、别名、CAS |
| **D** | 二手转载、论坛、无署名内容、AI 摘要 | 各类聚合站、微信公众号转述 | **只能做线索，不得支撑量化关系** |

**校验器规则**：量化关系若只挂 D 级来源 → FATAL。节点/关系无任何来源 → FATAL。

### 引用规范

- 每条 `sources` 必须有：`title`、`publisher`、`date`、`url`、`tier`、`verified`、`key_quotes`
- `verified`：
  - `opened` = 正文已打开并摘录了关键句
  - `opened_title_only` = 只看到标题/摘要
  - `snippet_only` = 只见搜索片段（**不能支撑具体数字**）
- `key_quotes` 要摘**原句**，不要转述。这是复盘时唯一能救你的东西。

## 2. 核验动作清单

对每个进入核心清单的节点，至少完成：

| 动作 | 通过标准 |
|---|---|
| 身份核验 | CAS 在权威库（PubChem/CAS Common Chemistry/标准物质目录）查得到；或明确写"不适用" |
| 名称核验 | 至少两个独立来源使用同一名称；别名进 `aliases` |
| 环节核验 | `node_role` 有依据（是单体、中间体，还是配方材料） |
| 方向核验 | 上游确实向下游供货，而不是反过来（看企业产线、工艺描述） |
| 价格口径核验 | 规格、区域、税制、基准日 4 项齐全，否则标 `price_partial` |
| 产能口径核验 | "是单产品产能还是合计产能"必须写清（SBS 12 万吨 vs SBC 合计 17 万吨） |

### 三个高发错误

1. **合计产能当单产品产能**。SBC 装置可切换 SBS/SEBS/SIS，把 17 万吨全记成 SBS 会高估 ~40%。
2. **把"规划/环评"当"已投产"**。`stage` 必须区分：`已投产` / `在建` / `环评公示` / `规划`。
3. **把不同牌号价格平均**。干胶与油胶、注塑级与挤出级，价差可达 15%+。

## 3. 公开数据获取策略

### 3.1 价格

优先级：
1. **交易所/官方**：上期所、大商所、郑商所日行情（有标准合约规格，A 级）
2. **公开信息商页面**：oilchem.net 的 `seo-<id>-7.html` 这类公开点价页（C 级）
3. **企业挂牌价**：上市公司/集团官网价格公告
4. **协会月报**：中国石油和化学工业联合会、各子行业协会
5. **付费库**（用户自备）：卓创、隆众、Wind、Mysteel

`tools/fetch_prices.py` 演示了第 2 类的抓法：按 `seo_id` 拉取一款产品的全国主流市场均价序列。

**抓取纪律**：
- 频率：同一站点 ≤ 1 次/8 秒，连续失败 3 次即停（避免 451/403）。
- 记录：每次抓取写入 `fetched_at` 与 `url`，可复现。
- 冲突：不同来源价格差异 >2% 时，**分别保留两条序列**，标注来源，不要平均。
- 抓不到：写 `available: false` + `gap` 说明，**不留空、不填 0**。

### 3.2 产能与企业

- 上市公司年报/公告（A）
- 行业协会产能统计（A/B）
- 环评公示、投资项目备案（A，但要注意是"拟建"）
- 行业媒体产能盘点（B）

**产能台账要求**：每家企业至少记 `node_id`、`province`、`capacity_*`、`capacity_unit`、`capacity_status`（`verified_sbs` / `verified_sbc_total` / `estimated`）、`evidence`。

### 3.3 工艺与单耗

- 工艺教科书、设计手册（B）
- 专利（A/B，注意是实验室还是工业）
- 企业技术介绍、装置开工报道（B）
- 期货公司品种专题（B，常给工业单耗区间）

**单耗落地三步**：找到工艺 → 找到收率或单耗基准 → 换算成"每吨目标产品"的口径并写明假设。

## 4. 抓取失败怎么办（缺口登记范式）

任何缺口都必须能回答三问：

1. **缺什么**（价格？产能？单耗？CAS？）
2. **为什么缺**（一单一议 / 牌号分散 / 付费库 / 企业未披露 / 多产品平衡无换算）
3. **到哪里补**（具体渠道名 + 需要什么权限或报告）

写进 `missing_flags` + `price_mapped_note` / `quant.basis`，就会自动进 Excel 第 09 页。

**示例**（SBS 干胶价格）：

> `price_missing`：SBS 干胶出厂价主要见于付费数据库（卓创/隆众），公开页仅零星牌号报价，不构成连续序列；补充渠道：付费库月度均价、主要企业年度挂牌价、协会月报。

## 5. 置信度标注

| 字段 | 何时用 |
|---|---|
| `identification_confidence` | 节点身份的可信度（`low` 用于"存在但规格/牌号不明"） |
| `quant_confidence` | 单耗的可信度（`low` 用于文献区间中值） |
| `verified` | 来源的阅读深度 |

**呈现规则**：置信度低的数字，在图上/Excel 里必须**带标记**（如浅黄底），不能与高置信数字混在一起，否则会被当成同等可靠。

---

## 6. 版本与更新

- 每次重抓价格，更新 `prices_verified.fetched_at`，保留旧文件为 `*.YYYYMMDD.json`。
- 数据变了但结论没变，也要在图谱页脚标注"数据截至"。
- `core_checklist.frozen_at` 一旦写入**不改**；若要扩大范围，新建 v2 清单并保留 v1，便于对比覆盖率变化。
