# 示例说明（甲醇 2026-10-12 ~ 2026-10-16）

⚠️ **本目录所有数值均为某一次真实生成的示例数据，仅用于展示交付物的结构与格式。**
使用本技能时应以自己采集的数据为准，不要把这些结论、指标或数值当作通用模板内容。

## 文件

| 文件 | 说明 |
| --- | --- |
| `example_methanol_2026W42.html` | 交互 HTML 周报成品：首屏核心变化 → 期现结构 → 供需库存 → 成本价差 → 事件时间线 → 同期比较 → 下周变量 → 缺口 → 底稿 |
| `example_methanol_2026W42.xlsx` | 15 张表的 Excel 底稿 |

## 这个示例演示了哪些"硬规则"

1. **周窗口含节假日处理**：报告周 10-12～10-16 为 5 个交易日，但上一周只有 10-08/10-09 两天（国庆），
   因此基期用 10-09，并在首页写明。
2. **周变动同合约相减**：近月 −12.23%、主力 −4.37%、远月 +1.75%，没有使用主力连续。
3. **契约不等**：MA2611 持仓从 42.6 万手降到 22.9 万手、MA2705 从 9.7 万升到 13.6 万，量在向远月迁移。
4. **口径不合并**：金联创"华东+华南港口社会库存 30.44 万吨（10-15）"与隆众"港口样本库存 30.51 万吨（10-08）并列披露。
5. **区间报价取中值**：太仓报盘 4850–4900 → 4875 并标注"区间中值"。
6. **计划不是事实**：宝丰四期 280 万吨"计划 10 月中下旬出合格品"在正文与待验证变量中均标"计划口径"。
7. **缺口诚实**：加工价差、甲醇周度产量、煤炭到厂价、CFR 中国逐日值等列为缺口，不做估算。
8. **因果不下结论**：把"10-12 竞拍全面流拍""10-13 MTO 亏损创新高"与当日盘面并列呈现，
   并明确写出"缺少逐笔成交与席位归因，不足以认定为唯一原因"。
