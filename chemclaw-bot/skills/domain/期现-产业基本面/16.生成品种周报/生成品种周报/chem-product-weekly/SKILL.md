# 生成品种周报（chem-product-weekly）

## 0. 这份技能解决什么

把一周的**价格、期现结构、供需、库存、成本、装置事件**整理成一份可以拿去开会/发给客户的周报：

- **只写已发生的事实**：每个数字都带 `日期 + 口径（品名/规格/地区/含税否/单位）+ 来源`。
- **不罗列新闻**：新闻只作为"事件"，必须落到"哪一天、谁、多少、影响什么口径"。
- **不做预测**：不写"下周会涨/会跌"。下周只写**已知将披露/落地的事件**和**待验证变量**。
- **区分"本周变化"与"背景信息"**：窗口外的事实一律标注为背景，不得混入本周变化。
- **缺口就是缺口**：拿不到的数值明确写入缺口清单，禁止估算、插值、编造。

## 1. 先确定时间口径（第一步，不能跳过）

| 项 | 规则 |
| --- | --- |
| 报告周 | 自然周周一 00:00 — 周五 收盘（国内商品期货）。**必须是一整周**；若周一/周五休市，顺延到该周首末交易日并注明 |
| 基期（周初打点） | 上一周最后一个交易日收盘。若上周因节假日只有 1–2 个交易日，仍用它作基期，并在首页写明 |
| 周变动 | **同一合约**：本周最后交易日收盘 − 上周最后交易日收盘。**禁止**用主力连续（`XX0`/`主力`）算周涨跌幅，换月跳空会制造假涨跌 |
| 周末数据 | 周五收盘后至周日发布的库存/开工数据，标注"数据日期"与"发布日"，二者可能不同 |
| 窗口外数据 | 下周一及以后的数据只允许出现在"下周事件/待验证变量"，并标 `窗口外` |
| 历史同期 | 取去年同月的**同一周序**（如均为 10 月第 3 个完整周），并按合约月份一一对齐（2611↔2511、2701↔2601） |

> 详见 `references/01-周度统计口径与算法.md`。

## 2. 工作流（7 步）

### 步骤 1：建目录与数据源探测
```
<workdir>/
  collect.py          # 抓取器（期货日线 / 资讯 / 报价）
  raw/_src/           # 原始响应，命名 <源>_<品种>_<日期>.json
  data/               # 清洗后的结构化数据 + facts.json + metrics.json
  build/              # 交付物（HTML / XLSX）
```
先跑一遍"可达性探测"：期货日线接口、资讯站、报价站各取 1 条，记录**哪些能拿到、哪些要付费/被墙**。
把结论写进 `data/sources.json`，后面每一步都以它为准。

### 步骤 2：采集四类数据
1. **期货**：各合约日线（开高低收、成交量、持仓量）。至少要覆盖近月、次近月、主力、远月 4 个合约。
2. **现货**：品种基准价/现货价日报（含日度序列）、地区报价（华东/华北/西北/华南…）、外盘（CFR/FOB）。
3. **供需**：库存（港口/厂库/社会）、开工率、产量、检修损失量、进出口（月度）、下游开工与库存。
4. **事件**：装置停车/检修/重启/投产、竞拍与流拍、政策、地缘、天气。

> 各数据源的可达性、接口形态与解析要点见 `references/02-数据源与解析.md`；抓取器参考 `scripts/` 下的模板。

### 步骤 3：写事实台账 `data/facts.json`
每一条事实一条记录，字段固定：
```json
{"date":"YYYY-MM-DD","time":"14:01","what":"事件原文口径","entity":"主体",
 "impact":"机构评述（可选，注明不代表本报告结论）","src":"来源名","url":"原文链接",
 "bg": false}
```
`bg: true` 表示窗口外背景。价格类事实另存 `anchors[]`：`{date, name, value, unit, basis, note, src, url}`，
`basis` 必须写清"含税现汇/厂提/送到/出罐/区间中值"。

### 步骤 4：算指标 `data/metrics.json`
用 `scripts/metrics.py` 一次算完并打印自检：
- 各合约周均价/最高/最低/周初/周末/周涨跌/周涨跌幅/持仓变化/成交量；
- 月差矩阵（近−远）逐日；
- 基差（现货 − 各合约收盘）逐日；
- 区域价差（同口径可比时才做差，并写明两个价格的口径）；
- 外盘序列 + 内外价差方向；
- 历史同期对齐表；
- 主力切换检测（若窗口内切换，必须单独披露）。

### 步骤 5：写结论 —— 只写"变化/确认/未定"
- **本周核心变化 3–5 条**：每条必须带数字与日期（"MA近月 −12.23%，远月 +1.75%，近远月差由 927 收敛至 407"）。
- **已被证据确认**：本周有哪些说法得到了数据支持（带来源日期）。
- **仍未证伪/待验证**：哪些是预期、计划、传闻。
- **禁止**："涨跌预测""机构观点转述当作结论""因果认定"。事件与价格只做**时间并列**，不写"因为A所以B"。

### 步骤 6：出交付物
1. **交互 HTML 周报**（模板 `assets/weekly_report.html`，把数据替换成 `window.__DATA__`）：
   首屏=核心变化+价格指标卡+重点事件；下方按期现结构、供需库存、成本价差、事件时间线、同期比较、下周变量组织。
   图表必须支持 hover 提示、历史区间切换（10/20/45/全部）、点击事件跳原文、底稿折叠展开。
2. **Excel 底稿**（模板 `assets/weekly_workbook.xlsx`，或按 `scripts/build_xlsx.py` 约定生成 15 张表）：
   `00_说明与口径 / 01_本周vs上周 / 02_历史价格 / 03_基差 / 04_月差 / 05_供需指标 / 06_上游原料 /
     07_价格锚点 / 08_事件 / 09_重要变化 / 10_趋势指标 / 11_外盘 / 12_历史同期 / 13_缺口清单 / 14_来源记录`

### 步骤 7：自检（缺一不可，见 `references/05-质检清单.md`）
- [ ] 每个数字都能在"来源记录"里找到 URL；
- [ ] 没有主力连续算的周涨跌幅；
- [ ] 没有窗口外数据混进本周结论；
- [ ] 两个机构口径并列披露、没有相减；
- [ ] 缺口清单非空且诚实；
- [ ] HTML 离线可打开（无外链 CDN / 无外部字体）。

## 3. 品种适配（换品种时只改这些）

| 需要改的 | 位置 | 说明 |
| --- | --- | --- |
| 合约列表 | `metrics.py` 的 `CONTRACTS` | 按品种主力月规律填（甲醇 1/5/9 与 11/12 并存） |
| 价格锚点 | `facts.json` 的 `anchors` | 现货基准价、地区报价、外盘报价 |
| 供需指标 | `facts.json` 的 `fund` | 该品种的库存/开工/产量/进出口/下游 |
| 上游原料 | `facts.json` 的 `upstream` | 煤/天然气/原油/乙烯/电石… |
| 下游产品 | `chain` | 3–6 个主要下游的基准价与周变动 |
| 事件关键词 | 采集脚本里的 `KEYWORDS` | 装置名、企业名、政策关键词 |
| 月差对 | `metrics.py` 的 `PAIRS` | 近−次近、近−主力、主力−远月、近−远 |

**不得**把示例品种（甲醇）的指标、结论、数值写进技能本体。示例只放在 `examples/`，并在开头注明"示例数据，仅展示格式"。

## 4. 常见坑

1. **节假日周**：只用 2 个交易日算出的"周均价"不能与正常周直接比较 → 标注交易日数。
2. **主力换月**：窗口内切换主力会让"主力涨跌"失真 → 用单合约，或明确标出切换日。
3. **交割月合约**：流动性极低的近交割合约不纳入周度比较，只做说明。
4. **机构口径差异**：库存/开工率同名不同源（如"港口样本库存"vs"港口社会库存"）→ 并列披露、标注统计范围。
5. **区间报价**：现货是区间时取中值并注明"区间中值"，不要伪装成成交价。
6. **基差不可交易**：现货基准价与期货价格在交割地/品规/运费上不同 → 必须加口径警示。
7. **数据日期≠发布日**：周五发布的数据常常是周三/周四的日期 → 两个都写。
8. **"计划"不是"事实"**：投产/重启/停车计划一律标"计划口径，非已发生"。
