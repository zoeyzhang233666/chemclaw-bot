# 事件分类与因果边界

## 事件分类（打标签，便于统计）
| 一级 | 二级示例 |
| --- | --- |
| 供给-装置 | 停车、检修、降负、重启、投产、事故 |
| 供给-进口 | 外盘装置停车/重启、装船、海峡/航运、关税 |
| 需求-装置 | 下游停车/降负/重启、新装置投产 |
| 需求-终端 | 季节性、订单、出口订单 |
| 价格机制 | 竞拍成交/流拍、企业调价、限价、期货限仓/提保 |
| 政策 | 产业政策、补贴、环保、安全 |
| 宏观/地缘 | 战争、制裁、汇率、利率、天气 |

## 每条事件必须能回答
1. 哪一天？（数据日期 vs 发布日期）
2. 谁？（企业/国家/机构）
3. 多少？（产能、吨数、价格、百分比）
4. 影响哪个口径？（国产供给 / 进口 / 下游需求 / 成本）
5. 是**已发生**还是**计划**？

## 因果边界（硬规则）
- ✅ "10-10 沿海多家MTO停车；10-12 MA2611 盘中一度跌超6%。两件事在时间上相邻。"
- ❌ "因为MTO停车，所以盘面大跌。"
- ✅ "机构认为下跌与MTO负反馈有关（XX期货10-13日评），本报告不将其作为结论。"
- ❌ 把机构观点改写成报告自己的判断。

## 价格异动的描述模板
```
时间：2026-10-12（周一）09:00-11:30
幅度：MA2611 盘中最低 3536，较前收 3835 下挫 299（-7.8%）
同日公开事实：①10-12 竞拍全面流拍；②伊朗表态美国接受部分条件
时间关系：事实①发生在竞价时段（10:14 见报），与价格下挫同处上午
结论边界：无逐笔成交与席位数据，不认定单一原因
```
