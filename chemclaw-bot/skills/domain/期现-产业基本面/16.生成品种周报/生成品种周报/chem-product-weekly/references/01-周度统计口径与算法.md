# 周度统计口径与算法

## 1. 周窗口
- 交易日历以交易所公布为准（脚本里用 `calendar(trading_days)` 判定）。
- 报告周 = 该自然周的首末**交易日**；交易日数 ≤3 时，在首页醒目标注"本周仅 N 个交易日"。
- 周初打点 = 上一周最后交易日；若上周只有 1–2 个交易日（节假日），仍然使用，并写明。

## 2. 周度价格指标（逐合约，不用主力连续）
```
week_avg   = mean(close[d] for d in 本周交易日)
week_high  = max(high[d])
week_low   = min(low[d])
chg        = close[本周最后交易日] - close[上周最后交易日]
chg_pct    = chg / close[上周最后交易日] * 100
oi_chg     = oi[本周最后交易日] - oi[本周第一个交易日]
vol_total  = sum(volume[d])
```
> 若必须给"主力"口径，额外输出 `dominant_days[]`（逐日持仓量最大合约）并检测切换；
> 窗口内发生切换的，**禁止**给出主力的周涨跌幅。

## 3. 月差
```
spread(a,b)[d] = close[a][d] - close[b][d]     # 正=Back（近高远低）
周内变化 = spread[本周最后交易日] - spread[上周最后交易日]
```
标准月差对：`近月-次近月`（展期成本）、`近月-主力`（近月挤水）、`主力-远月`（远端预期）、`近月-远月`（曲线总斜率）。
只有四者都下降，才可以写"曲线整体走平/挤水"。

## 4. 基差
```
basis[d] = spot[d] - close[contract][d]
```
- 现货必须写清：品名、规格、地区、交货方式（厂提/送到/出罐）、含税否、是否为区间中值。
- 若现货只有部分日期，**不要插值补全**；用"可用点 + 区间"描述，并把缺失写入缺口清单。
- 基差不等于可交易基差：需扣运费、仓储、交割成本、品规升贴水。报告里必须有一句口径警示。

## 5. 区域价差
- 只有当两个地区价格**同口径**（同规格、同交货方式、同含税基准）时才做差。
- 不同来源/不同口径时，只做方向对比（"华东跌幅 > 山东跌幅"），不做数值差。

## 6. 内外价差
- 外盘用当日汇率中值折算，注明汇率日期与来源；未取得汇率时不折算，只报外盘绝对值与方向。
- 进口成本 = (外盘价 + 运费) × 汇率 × (1+关税) + 港杂费。**任何一项缺失就不算**，写入缺口。

## 7. 历史同期
- 去年同月、同周序（同为第 3 个完整周）；按合约月份对齐（2611↔2511）。
- 输出：去年同周均价、去年同周收盘、本年对应日收盘、价差、同比%。

## 8. 趋势指标（可选但推荐）
- 均差类（M10−M20）：由正转负 = 短期均线下穿长期均线，只作技术描述，不作买卖建议。
- 库存/开工的同比与环比要分开列，不要混在一句话。

## 9. 趋势与因果的边界
- 可以写"X 发生在 D 日，价格在同日/次日变动 Y"；**不可以**写"X 导致 Y"。
- 若确需讨论传导，必须写"机制上可能的路径是…（无逐笔数据，不构成因果认定）"。
