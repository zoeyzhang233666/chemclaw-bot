# 模板替换变量（HTML / Excel）

## HTML（`assets/weekly_report.html`）
模板中只有一个数据注入点：
```html
<script>window.__DATA__ = {...};</script>
```
`__DATA__` 结构：
```jsonc
{
  "meta": {"product":"甲醇","code":"MA","window":["2026-10-12","2026-10-16"],
           "prev":["2026-10-08","2026-10-09"],"lastyear":["2025-10-13","2025-10-17"],
           "title":"…","note":"…"},
  "futures": {"MA2701": {"prev_close":…, "week_avg":…, "week_close":…, "chg":…, "chg_pct":…,
                          "oi_start":…, "oi_end":…, "daily":{…}}},
  "spot":     [["2026-10-12", 4643.33], …],
  "basis":    {"MA2611": [[date, value], …], "MA2701": [...]},
  "spread":   {"MA2611-MA2701": [[date, value], …]},
  "foreign":  [[date, cfr, rdam], …],
  "trend":    [[date, diff, m10, m20], …],
  "events":   [{"date","time","what","entity","impact","src","url","bg"}],
  "anchors":  [{"date","name","value","unit","basis","note","src","url"}],
  "fund":     [{"date","metric","value","unit","chg","period","src","url","in_week"}],
  "upstream": [...], "chain": [...], "gaps": [...], "lastyear": {...},
  "nextweek": [{"when","what","known","url"}],
  "variables":[{"code","title","confirmed","open","watch"}]
}
```

## Excel（`assets/weekly_workbook.xlsx`）
按 `scripts/build_xlsx.py` 的 `sheet()` 约定生成：第 1 行标题、第 2 行口径说明、第 4 行表头、第 5 行起数据。
所有数值列设置数字格式；缺值用 `None`（渲染为空），不要写 0。
