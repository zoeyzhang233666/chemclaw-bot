# 指标与口径字典（按模块，可按品种增删）

## A. 价格与期现
| 指标 | 定义 | 必带口径 |
| --- | --- | --- |
| 期货收盘 | 合约日线收盘价 | 交易所、合约、含税、单位、手数 |
| 现货基准价 | 资讯机构综合评估价 | 机构、品名规格、地区、含税、交货方式 |
| 地区报价 | 分区域市场价/出厂价 | 地区、厂提/送到/出罐、汇率（外盘） |
| 基差 | 现货 − 期货 | 哪两个价、是否可交割品规 |
| 月差 | 近月 − 远月 | 哪两个合约、正负含义 |
| 区域价差 | A地 − B地 | 两地口径是否一致 |
| 外盘 | CFR/FOB | 基准港、单位（美元/吨、美分/加仑、欧元/吨） |

## B. 供给
| 指标 | 说明 |
| --- | --- |
| 开工率（%） | 注明是否含一体化（如"含CTO"），机构口径不同不可混 |
| 周产量（万吨） | 与开工率同口径 |
| 检修损失量（万吨） | 常为周度 |
| 进口/出口（万吨） | 月度，注明海关口径与均价 |
| 新增产能（万吨/年） | 必须标"计划/在建/投产"，计划不得当事实 |

## C. 需求
| 指标 | 说明 |
| --- | --- |
| 下游开工率（%） | 分行业（如聚烯烃、甲醛、醋酸…）或加权 |
| 下游利润/亏损（元/吨） | 注明是现金流还是完全成本 |
| 下游库存（万吨） | 社会库存 / 企业库存分开 |
| 政策/新增需求 | 只能定性，除非有计量数据 |

## D. 库存
- 港口库存、厂库、社会库存、注册仓单：**机构不同 = 口径不同**，并列不合并。
- 库存变化一律同时给"绝对量"与"变化量"，并写清"较上期"的上期是哪一天。

## E. 成本
- 上游原料价（煤/气/油/乙烯/电石）、加工费、副产品收益、现金成本、完全成本、单吨利润。
- 缺任一项 → 只报两端价格方向，不算价差。
