# 口径与冲突处理手册

**本技能的差异化不在于"知道甲醇产能是多少"，而在于知道这个数字有几个版本、为什么不同、
什么时候该用哪个。** 这一页是处理冲突的标准动作。

---

## 一、先分清五层口径

任何化工品的关键数据，都可能落在下面某一层。**引用时不写层，就等于没写。**

| 层 | 含义 | 典型例子 |
|---|---|---|
| L1 名义产能 | 建成即可计入，含长期停车 | 氮肥协会"总产能" |
| L2 有效产能 | 剔除长期停车/僵尸装置 | 隆众"产能基数" |
| L3 在产产能 | 当年有实际产量 | 企业年报"在产装置" |
| L4 可流通量 | 扣除一体化自用 | 甲醇"可外销占比" |
| L5 实际供需 | 减去库存变动后的真实松紧 | 需要库存数据才能算 |

**规则：跨层比较是无效的。** "1.15 亿吨产能 vs 1.08 亿吨基数"不是矛盾，是 L1 vs L2。

## 二、冲突处理四步法

### 步骤 1：并列，不择一
```json
{"项目": "2025 年末总产能",
 "数值A": "1.15 亿吨/年（氮肥协会）",
 "数值B": "10,804.5 万吨（隆众产能基数）",
 "差异原因": "是否剔除长期停车装置",
 "建议": "双列并标注机构"}
```

### 步骤 2：写出差异原因（不要写"数据待核实"）
- 母公司/子公司归属不同
- 统计时点不同（年末 vs 年中）
- 是否含在建/试车装置
- 是否含联产品
- 口径是否含出口/进口

### 步骤 3：给出使用建议
明确告诉读者："做趋势分析用 A，做可流通量用 B"。

### 步骤 4：在 caveats 里留档
`research.json` 的 `caveats` 数组会显示在 HTML 与 Excel 的显眼位置。

## 三、六类高频冲突与标准答案

### 冲突 1：全国产能有两个数
- **本质**：L1 vs L2，或不同统计样本。
- **处理**：双列 + 机构 + 时点 + 是否剔除停车装置。
- **禁止**：取平均、只留一个、写"约"。

### 冲突 2：企业产能有三个数（集团/单厂/存量）
- **本质**：口径层级不同。
- **处理**：在表格里明确标注口径列，并在表注写"三者不可混用"。
- **示例**：宝丰 2000（集团含规划）/ 1400（单厂）/ 440（存量）。

### 冲突 3：下游占比年份不同
- **本质**：结构在变（MTO 从 44% 升到 48.9%）。
- **处理**：分年分机构列，明确"禁止相加或画成一个饼图"。
- **补充**：如果只有一年有权威值，其他分项沿用旧年份时，**必须声明**。

### 冲突 4：单耗因技术代际不同
- **本质**：技术进步（DMTO 3.0 → 2.87 → 2.66）。
- **处理**：给区间 + 说明代际，做利润测算时声明用哪个值。
- **禁止**：用一个值算全行业利润还不说明。

### 冲突 5：开工率口径不同
- **本质**：样本企业数不同、是否含检修、是否加权。
- **处理**：标注"隆众/卓创/金联创/协会"口径，不同机构的开工率不可直接比较趋势。

### 冲突 6：进口量与进口依存度
- **本质**：分子分母年份或口径不一致。
- **处理**：自算时两个数必须同年同口径；如果做不到，标缺口。

## 四、数字的可信度分级

在 `sources[].confidence` 里标注，并在正文中体现：

| 级别 | 标准 | 例子 |
|---|---|---|
| 高 | 交易所/国标/统计局/协会年报原文 | 郑商所合约文本、GB 338 |
| 中高 | 期货公司/数据商研报，可回溯数据源 | 期货日报转隆众 |
| 中 | 第三方研究机构（观研/华经/中研普华） | 二手汇总，口径常不明 |
| 低 | 企业宣传稿、无出处的媒体转述 | 仅作线索，不进正文数字 |
| 缺口 | 拿不到 | 必须写"缺口"并说明补法 |

**规则：中/低级别来源的数字，不得单独支撑关键结论。**

---

## 五、"约"字的纪律

`validate.py` 会对含"约/左右/大概/预计"且无来源的数字报警。正确用法：

- ✗ "甲醇产能约 1.1 亿吨"（无来源、无时点）
- ✓ "1.15 亿吨/年（中国氮肥工业协会，2025 年末，S01）"
- ✓ "约 1428 万吨（隆众预估，2025 全年，S03）"—— **"预估"必须带预估者的名字**

---

## 六、方向性措辞禁令

品种入口页是**认知框架**，不是**观点报告**。`validate.py` 会拦截：

- 看涨 / 看跌 / 做多 / 做空 / 抄底 / 追高
- "预计将上涨" / "有望走强" / "恐将下跌"

允许的中性表达：
- "成本中枢可能上移（S03 判断，非本页结论）"
- "利润不足时装置降负（机制描述，非预测）"
- "若库存持续累积，则月差通常走弱（历史规律，非当前预测）"

---

## 七、缺口怎么写才算合格

三条缺一不可：

```json
{"area": "港口/厂库/仓单库存",
 "desc": "华东、华南港口库存；生产企业库存；期货仓单量本轮未取得绝对值",
 "how": "交易所仓单日报为公开数据（czce.com.cn），港口库存需订阅卓创/隆众",
 "impact": "库存-价格关系与月差判断缺数据支撑"}
```

- `area`：缺什么
- `desc`：具体缺到哪一步（"总量"还是"分区域"，"日度"还是"月度"）
- `how`：**可执行的补数路径**（哪个网站、哪个接口、要不要订阅）
- `impact`：这个缺口会让什么分析无法完成

**只有 `desc` 没有 `how` 的缺口，等于放弃。**
