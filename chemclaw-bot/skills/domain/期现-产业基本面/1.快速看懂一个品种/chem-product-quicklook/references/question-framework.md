# 8 问框架：每一问要拿到什么、坑在哪

这是"快速看懂一个品种"的骨架。每一问都有**必须拿到的字段**（拿不到就是缺口，必须写）
和**常见陷阱**（写错了比不写更糟）。

---

## 问 1：这是什么？（身份识别）

**必须拿到**
- 中文通用名、英文名、**别名**（木醇/木精这类俗称必须列，资讯里高频出现）
- **CAS 号**（唯一主键）、分子式、分子量
- **HS 编码**（决定进口数据怎么查）
- 危险品属性（UN 号、危险类别、是否危化品目录内）—— 影响运输与仓储成本
- **计价单位与形态**（元/吨？含税？液碱还分 32%/50%？）
- **牌号/等级划分**及其差异（国标等级 vs 商业牌号是两回事）

**坑**
1. **同名异物**：不同 CAS 的"××醇"不是一回事。CAS 不确认不要往下做。
2. **只写国标等级不写商业牌号**：现货报价用的是"某企业 优等品"，不是"GB 338"。
3. **忽略计价形态差异**：32% 液碱和 50% 液碱、轻质纯碱和重质纯碱，价格与下游都不同，
   只写一个"烧碱价格"就是错的。
4. **HS 编码只写 6 位**：6 位是国际通用，中国 8–10 位才对应真实税率与监管条件。
   6 位可查联合国/海关总署归类，10 位必须查中国税则，查不到就标缺口。

**输出**
`product.*` 全部字段 + `product.identity_confidence`（说明凭什么确认身份）

## 问 2：怎么做出来的？（工艺路线与核心原料）

**必须拿到**
- 有几条主流路线，各占多少产能（**必须是公开统计，不是感觉**）
- 每条路线的**核心原料**及其**单耗**
- 主要**工艺单元**（气化/转化/合成/精制…）
- 关键**装置规模**（单套能到多大）
- **副产物/联产**（影响成本核算）
- 技术代际差异（如 MTO 一代约 3.0、DMTO-Ⅲ 2.66）

**坑**
1. **单耗来源混杂**：教材典型值、设计值、企业盘库实测值三者含义完全不同。
   写的时候必须标类型（本技能用 `SB 工艺典型值` 标注）。
2. **把单套规模当行业平均**：单套 280 万吨 ≠ 平均 280 万吨。
3. **忽略联产**：氨醇联产装置的"甲醇产能"不是一个纯数字。
4. **区域决定路线**：同一品种在不同地区主路线可能不同（煤/气/油头），要分区域讲。

**输出**
`panels.routes` 的 routes 块 + `chain` 里上游与工艺两列

## 问 3：用在哪？（下游与终端）

**必须拿到**
- 下游**分项占比**（带年份 + 机构），且说明占比是"消费量占比"还是"产能占比"
- 每个主要下游的**单耗**（1 吨下游产品吃多少吨本品）
- 下游的**终端行业**（板材→地产、MTBE→汽油调和）
- 下游的**集中度与利润状态**（谁在亏、谁在扩产）

**坑**
1. **占比年份混用**：2024 年 MTO 占 44%、2025 年占 48.9%，直接相加或画成一个饼图就是错的。
2. **忽略"名义产能"与"有效产能"**：下游产能大但开工低，对本品需求没那么大。
3. **只讲最大下游**：最大下游占 49% 时，剩下 51% 的构成才是边际变化的来源。
4. **单耗口径不清**：0.45 吨甲醇/吨甲醛，指的是 37% 甲醛水溶液还是 100% 甲醛？必须问清。

**输出**
`panels.demand` + `chain` 下游与终端两列

## 问 4：谁在生产？（企业与产能、区域分布）

**必须拿到**
- **全国总产能/产量**（带机构 + 时点）
- **企业名单与产能**：至少前 10 家，标注口径（集团/单厂/单套/存量/含规划）
- **区域分布**：省或大区，占比
- **规模结构**（如 ≥100 万吨装置占多少）
- **在建/拟建项目**及其时间

**坑**
1. **口径混用**（本技能最高频的错误）：集团 2000 万吨、单厂 1400 万吨、存量 440 万吨
   是同一家公司的三个数字，混用会算出完全错误的集中度。
2. **把规划产能当在产**：环评公示的项目不能算进产能。
3. **忽略"一体化自用"**：配套下游的甲醇装置对外几乎不销售，对市场可流通量的贡献是 0。
   内蒙古 2025 年一体化产能占 59%，这个数字比总产能更能解释价格。
4. **用"龙头集中"代替数字**：CR5 是多少就是多少，查不到就说缺口。

**输出**
`panels.capacity`（companies + regions + 在建表）+ 口径冲突表

详见 `capacity-survey.md`。

## 问 5：怎么流动？（贸易与区域市场）

**必须拿到**
- 进口量/出口量（分年、分国别）
- 进口依存度（分子分母口径要一致）
- 主要贸易流（哪个区域产、哪个区域销、中间怎么运）
- **主流集散地与交割地**（是否重合）
- 区域价差与运费结构

**坑**
1. **进口依存度自算**：进口量/表观消费量，两个数必须同年同口径。
2. **忽略"净进口 vs 净出口"转折**：某区域可能因为一个新装置从净流出变净流入。
3. **运费缺失**：区域价差研究的核心是运费，没有运费数据就做不了套利分析。

**输出**
`panels.trade_futures` 的贸易与区域块

## 问 6：有没有期货？（交易所、合约、交割、期现）

**仅在 `has_futures = true` 时展开；否则见 SKILL.md 的降级处理。**

**必须拿到（逐条核交易所原文）**
- 交易所、交易代码、交易单位、报价单位、最小变动价位
- 涨跌停板、最低交易保证金
- 合约月份、最后交易日、最后交割日
- **交割品级**（对应哪个国标等级、有无替代品与升贴水）
- 交割单位、交割方式、交割地点
- 上市时间

**期现关系必须讲清**
- 期货价是**不含税**的，现货多是**含税**的 → 基差前先换算，否则符号会翻转
- 交割地与主产区/主销区是否重合
- 交割标准品与主流现货规格的差异（等外品？品牌？包装？）

**坑**
1. **抄二手合约要素**：涨跌停、保证金这些会调整，必须查交易所当期规则。
2. **忽略税率**：这是基差失真最常见的来源。
3. **把主力合约价格当现货**。
4. **忽略合约月份特性**：1/5/9 主力与全年 1–12 月挂牌是两回事。

详见 `futures-rules.md`。

## 问 7：盯什么？（供需库存价格成本基差指标）

**必须拿到**（每条都要有"为什么看"，不能只有指标名）
- **供应端**：开工率（全国+分路线）、产量、进口到港、新增产能
- **需求端**：主要下游开工率、装置利润、订单/出口
- **库存**：港口库存、企业库存、期货仓单
- **价格成本**：现货价（六项口径）、原料价、分路线成本、外盘价
- **期现**：基差、月差、交割升贴水

**坑**
1. **只列指标不讲逻辑**：读者要的是"这个数变了意味着什么"。
2. **忽视指标间的领先滞后**：装置利润领先开工、开工领先产量、产量领先库存。
3. **拿不到就跳过**：不写指标和写"数据缺失"是两种态度，后者才是专业的。

详见 `indicator-library.md`。

## 问 8：逻辑怎么串？（产业逻辑）

把 1–7 串成可验证的因果链，每条链至少 3 环：

```
成本链：原料价 → 分路线成本 → 产地出厂价 → 加运费 → 销区到货价 → 期货重心
供给链：开工率 + 进口到港 → 产量 + 进口 → 可流通量 → 库存 → 基差
需求链：下游利润 → 下游开工 → 采购量 → (回到可流通量)
负反馈：下游亏损 → 降负停车 → 需求塌陷 → 现货跌 → 期货跌更快 → 基差走强
```

**坑**
- 链条里出现"因此价格上涨"就是方向判断 → 品种入口页不做方向判断。
- 链条要可被数据证伪：每一环都要有对应指标能观测。

**输出**
`panels.indicators` 的 logic 块 + `chain` 节点的 research.summary
