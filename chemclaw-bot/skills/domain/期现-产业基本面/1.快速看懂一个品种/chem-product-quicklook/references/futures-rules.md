# 期货合约与交割要素采集清单

**所有条款以交易所当期原文为准。本技能不内置任何品种的合约条款。**

## 一、必采字段（逐条打勾）

| 字段 | 说明 | 常见错 |
|---|---|---|
| 交易所 | 郑商所/大商所/上期所/广期所/能源中心 | 写"中国期货市场" |
| 交易代码 | 2 个字母 | 与品种简称混淆 |
| 交易单位 | 吨/手 | 写成"手/吨" |
| 报价单位 | 元/吨 | — |
| 最小变动价位 | 元/吨 | 遗漏 |
| 每日价格波动限制 | ±X% 或 ±X 元 | 抄旧版 |
| 最低交易保证金 | % | 与"交易所保证金"和"期货公司加收"混淆 |
| 合约交割月份 | 1–12 月 或 特定月份 | 与"主力合约月份"混淆 |
| 最后交易日 | 交割月第 N 个交易日 | — |
| 最后交割日 | 交割月第 N 个交易日 | — |
| 交割品级 | 对应国标等级 + 替代品与升贴水 | 只写国标号 |
| 交割地点 | 指定仓库/厂库 | — |
| 交割方式 | 仓库交割/厂库交割/车板交割 | — |
| 交割单位 | 吨 | 与交易单位混淆 |
| 上市时间 | 年月 | — |

## 二、期现衔接必须核清的 5 件事

### 1. 税费口径
- 期货报价通常**不含税**；现货报价通常**含税**。
- 基差 = 现货 − 期货，**不做税换算，符号可能整体翻转**。
- 换算：不含税 = 含税 / (1 + 13%)（增值税率以当期为准）。

### 2. 交割地与产销区
- 交割地是否在主流消费地/集散地？
- 主产区到交割地的运费，是基差的隐含成本项。

### 3. 交割品级 vs 主流现货规格
- 交割标准品对应哪个等级（优等品/一等品）？
- 有无替代交割品？升贴水多少？
- 主流现货是否都能交割？（不能交割的货不能用于套保）

### 4. 包装与计量
- 散装/桶装？计量以入库计量为准？
- 液体化工品的密度换算会带来误差。

### 5. 仓单与注销
- 仓单有效期、强制注销时点。
- 注销压力集中在哪个合约？

## 三、基差计算的规范写法

**必须写清 6 项，缺一不可：**

```
基差 = 华东太仓甲醇（优等品，含税，出厂，元/吨，2026-10-19，卓创）
     − MA2601（不含税，收盘，元/吨，郑商所）
```

六项：`规格 · 地区 · 含税口径 · 时间 · 来源 · 期货合约`

**常见错误**
- ✗ "基差 = 现货 − 期货"（没有具体标的）
- ✗ 用主力连续价格算基差（拼接价有跳空）
- ✗ 跨期比较不同合约的基差

## 四、无期货品种

`has_futures: false` 时：
1. `research.futures` 不填数组
2. 必须给 `gapnote`，格式：
   ```json
   {"type": "gapnote", "title": "无期货合约说明",
    "text": "该品种目前无境内期货合约，期现关系与交割规则不适用。价格跟踪以现货报价为主，需注意报价的六项口径。"}
   ```
3. 面板从"贸易与期现"改为"贸易与区域市场"
4. 研究框架去掉"期现"维度，换成"贸易流/区域价差"

## 五、采集流程

1. 打开交易所官网的"合约文本"页 → 逐条抄进 `futures.items[].rows`
2. 打开"交割细则"→ 抄交割品级、升贴水、交割地
3. 用 `fetch_source.py` 存原文截图/文本到 `raw/`，便于复核
4. 若交易所站点反爬（如返回 412），**标记为缺口并说明**，可用二手转录但必须在
   `rows[].v` 里注明"（转自××，需以交易所原文复核）"

> 甲醇案例中 czce.com.cn 被反爬拦截 3 次，最终采用东财转录并全程标注"需复核"。
> **这不是妥协，是诚实。**
