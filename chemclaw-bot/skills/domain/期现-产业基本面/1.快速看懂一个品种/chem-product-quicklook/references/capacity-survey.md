# 企业与产能调查方法

产能数据是化工品类研究里**最容易出错、也最值钱**的部分。

---

## 一、先定口径，再收数据

拿到任何一个企业产能数字，先问三个问题：

1. **这是谁的产能？** 集团 / 子公司 / 单个法人 / 单个装置
2. **什么状态？** 在产 / 试车 / 在建 / 拟建 / 已停产
3. **含什么？** 纯本品 / 联产（氨醇联产）/ 含配套下游

**标准标注格式**（在 `companies[].note` 里写清）：

```
"{口径说明}，如：2024年末在产控股口径；2025年产量195.5万吨"
```

---

## 二、数据源优先级

| 优先级 | 来源 | 能拿到什么 | 缺点 |
|---|---|---|---|
| 1 | 上市公司年报/公告/投资者关系问答 | 产能、产量、在建、口径最清晰 | 只覆盖上市主体 |
| 2 | 环评公示/节能审查公示 | 具体装置规模、工艺、投产时间 | 是"拟建"，不等于在产 |
| 3 | 交易所/协会年度报告 | 全国总量、规模结构、开工率 | 不分企业 |
| 4 | 期货公司/数据商研报 | 企业名单 + 产能汇总 | 口径常不统一 |
| 5 | 行业协会会议报告 | 权威总量与结构 | 更新频率低 |
| 6 | 企业官网/宣传稿 | 项目信息、投产新闻 | 有夸大倾向，仅作线索 |

**规则：企业级数字尽量追到年报或环评原文；追不到就标"置信度中/低"。**

---

## 三、区域分布的三个层次

1. **省/自治区** —— 最实用，能对上地方政策与运距
2. **大区**（西北/华北/华东/华南/西南/东北）—— 用于宏观结构判断
3. **化工园区/基地** —— 用于物流与调研路线

**坑：** 不同来源的大区划分可能不同（如是否把山东算华东），
引用时必须写明"含/不含××"。

**特别关注"可外销 vs 一体化自用"**：
主产区产能大但若大部分自用，对市场价格的解释力很弱。
例如内蒙古 2025 年一体化产能占 59%，剩余 41% 才是可外销的。

---

## 四、集中度怎么算

- **CR5 / CR10**：前 N 家企业产能 / 全国总产能。**分子分母必须同口径。**
- 若企业产能是"含规划"的，则 CR 会虚高 → 必须用"存量在产"口径重算。
- 查不到 CR 就写缺口，不要用"行业集中度较低"这类话术替代。

---

## 五、在建/拟建项目表规范

每条项目必须含：

| 字段 | 例 |
|---|---|
| 项目名称 | 中煤榆林煤炭深加工基地二期 |
| 装置规模 | 220 万吨甲醇 + 90 万吨烯烃 |
| 投资额 | 238.88 亿元 |
| 状态 | 全部中交、联动试车 |
| 时间 | 2026-07 |
| 业主 | 中煤陕西榆林能源化工 |
| 来源 | S12 |
| 置信度 | 中（媒体转述） |

**状态分级**（不要混用）：
`环评公示 → 备案 → 开工 → 土建 → 安装 → 中交 → 试车 → 投产 → 达产`

只有"投产"及以后才能进产能统计。

---

## 六、产能调查的产出物

1. 企业表（前 10–15 家，带口径）
2. 区域表（省级 + 大区 + 占比）
3. 规模结构（如 ≥100 万吨装置占比）
4. 在建项目表
5. **口径冲突表**（见 `caliber-and-conflict.md`）

---

## 七、验证技巧

- **交叉验证**：协会总量 vs 企业加总，差额应能解释（小企业、未统计装置）。
- **反向验算**：用全国产能 × 开工率，看是否接近公布的产量。
- **时间一致性**：同一张表里不要混用 2024 年末与 2025 年中。
- **单位检查**：万吨 vs 吨，亿元 vs 万元，是 Excel 里最隐蔽的错误。
