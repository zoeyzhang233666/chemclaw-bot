# 常见工艺路线模板（方法参考，参数必须重新核来源）

⚠️ **本文件只提供"路线长什么样、参数长什么样"的骨架。
任何数字都是示例，用于说明格式，不得作为成品数据使用。**
每个品种都要重新查来源、重新核口径。

---

## 一、碳一化工（合成气路线）

### 煤制
```
备煤 → 气化（气流床/固定床/流化床）→ 变换 → 净化（低温甲醇洗）
     → 压缩 → 甲醇合成（Cu 基催化剂，5–8 MPa，230–260 ℃）→ 精馏
```
**参数位**：吨甲醇原料煤、氧耗、碳排强度、单套规模、气化炉型

### 天然气制
```
天然气 → 脱硫 → 蒸汽转化 SMR（或自热转化）→ 变换 → 脱碳
       → 压缩 → 合成 → 精馏
```
**参数位**：吨甲醇天然气耗、单套规模、碳排强度

### 焦炉气制
```
焦炉煤气 → 净化（脱硫脱萘）→ 补碳（富氢气需补 CO₂）→ 压缩 → 合成 → 精馏
```
**参数位**：单套规模、补碳方式、与焦化开工的联动关系

### CO₂ / 生物质制（绿色甲醇）
```
绿氢（电解水/副产氢）+ CO₂ 捕集 → 甲醇合成 → 精馏
生物质 → 气化 → 净化 → 合成 → 精馏
```
**参数位**：绿氢耗、CO₂ 耗、认证体系（ISCC 等）、碳足迹

## 二、氯碱路线

### 离子膜法烧碱
```
原盐精制 → 电解（离子膜）→ 烧碱液（32%）→ 蒸发浓缩（50%）→ 固碱（片碱/粒碱）
                        └→ 氯气 → 下游（PVC/氯乙酸等）
```
**参数位**：吨碱盐耗、电耗（kWh/t）、氯碱平衡

**关键**：烧碱与液氯是**联产**，氯碱平衡决定开工，只看烧碱价格会误判。

---

## 三、纯碱路线

### 氨碱法 / 联碱法 / 天然碱
```
氨碱：原盐 + 石灰石 → 氨化盐水 → 碳化 → 碳酸氢钠 → 煅烧 → 纯碱 + 氯化钙废液
联碱：与合成氨联产，副产氯化铵
天然碱：开采 → 溶解 → 蒸发结晶
```
**参数位**：吨碱盐耗、石灰石耗、氨耗、能耗、废液处理

**关键**：轻质/重质纯碱用途不同，重质靠再结晶或挤压法。

## 四、烯烃路线

### MTO / MTP
```
甲醇 → 脱水（二甲醚）→ 流化床反应（SAPO-34 催化剂）→ 乙烯+丙烯 → 分离
```
**参数位**：吨烯烃甲醇单耗（技术代际差异大：3.0 / 2.87 / 2.66）、烯烃比、催化剂寿命

### PDH（丙烷脱氢）
```
丙烷 → 脱氢（Pt 或 Cr 系催化剂）→ 丙烯
```
**参数位**：吨丙烯丙烷耗、副产氢

### 蒸汽裂解
```
石脑油/轻烃 → 裂解炉 → 急冷 → 分离 → 乙烯/丙烯/丁二烯/芳烃
```
**参数位**：吨乙烯石脑油耗、综合能耗

---

## 五、聚酯链

```
PX → PTA（氧化）→ PET（缩聚，与 MEG 共聚）→ 纤维/瓶片/薄膜
MEG：乙烯 → 环氧乙烷 → 水合 → 乙二醇
```
**参数位**：吨 PTA 的 PX 耗、吨 PET 的 PTA+MEG 耗、醋酸作为溶剂/助剂的单耗

---

## 六、通用模板（任何品种套用）

```
【原料 A】+【原料 B】 →（工艺单元 1）→（工艺单元 2）→【本品种】
                                    └→【副产物 C】
```

**必须填的 5 个参数位**
1. 主原料单耗（吨/吨 或 Nm³/吨）
2. 能耗（电/蒸汽）
3. 单套经济规模
4. 副产物/联产品及其比例
5. 三废与碳排

## 七、参数来源的三种类型（写稿必须区分）

| 类型 | 来源 | 标注方式 |
|---|---|---|
| 设计/教材典型值 | 工艺手册、设计规范 | `工艺典型值`（本技能用 SB） |
| 公开统计均值 | 协会/数据商统计报表 | `S01 公开统计` |
| 企业实测值 | 年报、环评、投产新闻 | `S0x 实测/披露` |

**禁止**把典型值当成某企业的实测值陈述。
