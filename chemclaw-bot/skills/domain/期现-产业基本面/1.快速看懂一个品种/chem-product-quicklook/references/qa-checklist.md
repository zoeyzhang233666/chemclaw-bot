# 交付前自检清单

按顺序过一遍，全部打勾才能交付。

---

## A. 事实纪律（最重要）

- [ ] 每一个关键数字都有**来源 id + 日期 + 口径**
- [ ] 没有"约/左右/大概"修饰且**没有来源**的数字
- [ ] 没有"业内普遍认为/一般来说/据统计"这类无主语句
- [ ] 典型工艺参数已标注为"工艺典型值"，未被当作企业实测值
- [ ] 研究判断已显式标注"研究判断"
- [ ] 全文**无方向性措辞**（看涨/看跌/抄底/追高/有望走强）
- [ ] 拿不到的数据全部进入缺口清单，且有可执行的补数路径

## B. 口径一致性

- [ ] 全国产能/产量：多口径已并列，标注机构与时点
- [ ] 企业产能：已标注集团/单厂/存量口径，未混用
- [ ] 下游占比：分年分机构列示，未把不同年份相加
- [ ] 单耗：已说明技术代际或版次差异
- [ ] 进口依存度：分子分母同年同口径，或标缺口
- [ ] 单位统一（万吨 vs 吨；亿元 vs 万元）

## C. 结构完整性

- [ ] 8 个问题全部有回答（无期货品种第 6 问用降级说明）
- [ ] 产业链 5 列齐全，每列 ≥1 节点，总数 ≥10
- [ ] 每个节点都有 `research.summary` 和 `research.points`
- [ ] 每个节点都有 `actions` 且 id 都在 `scenes` 里
- [ ] 每个节点都有缺口说明字段（即使内容为"不适用"）
- [ ] 6 个面板都存在且非空
- [ ] 来源清单覆盖正文所有引用的 Sxx

## D. 数据真实性

- [ ] 价格不是手写的，是从序列算出来的（`build_anchors.py`）
- [ ] 分位数、区间、成交/持仓都是计算值
- [ ] 没有虚构的企业产能、装置规模、投产时间
- [ ] 没有把拟建/环评项目算进在产产能

## E. 技术校验

```bash
python scripts/validate.py research.json          # 必须 error=0
python scripts/build_html.py research.json --out out/
python scripts/build_xlsx.py research.json --out out/
python scripts/qa_render.py "out/xxx.html"        # 必须 0 失败
python scripts/check_xlsx.py "out/xxx.xlsx" --research research.json  # 必须 error=0
```

- [ ] validate 0 error
- [ ] qa_render 全部通过（无 JS 异常、无横向溢出、交互可用）
- [ ] check_xlsx 全部通过
- [ ] HTML 单文件，断网可打开
- [ ] Excel 12 张表齐全

## F. 交付说明

- [ ] 明确列出交付物路径
- [ ] 列出关键数字的来源与日期
- [ ] 列出缺口清单（缺什么、为什么、怎么补）
- [ ] 说明哪些内容是研究判断而非事实

---

## 常见返工原因

| 返工项 | 预防 |
|---|---|
| 被指出"这个数字哪来的" | 第 2 步就把来源记进 JSON，别事后补 |
| 下游占比加总超过 100% | 分年份分机构列，别跨年相加 |
| 企业产能对不上 | 一开始就问清口径 |
| 期货条款过时 | 每次交付前重查交易所 |
| 页面显示但数据没进 Excel | 数据只写在 research.json，不要绕过它 |
| 点击节点报"未登记" | actions 的 id 必须在 scenes 里 |
