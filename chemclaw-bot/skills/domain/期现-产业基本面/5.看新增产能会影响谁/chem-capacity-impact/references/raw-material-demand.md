# 第 3 步：上游原料需求测算（Raw Material Demand）

> 这一步唯一能站得住脚的东西是**有出处的单耗**。
> 没有出处时，允许给数字，但必须**标记为情景参数**，并且在报告里与"证据单耗"分开展示。

---

## 1. 单耗的四个等级

| 等级 | 定义 | 典型来源 | 报告里怎么标 |
|---|---|---|---|
| **C1 工程值** | 环评/可研/工艺许可商/企业公示的原辅材料表 | 环评报告书"主要原辅材料消耗表" | `工程取值（E1）` |
| **C2 实测/统计区间** | 行业资讯商或统计年鉴给出的区间 | 隆众/卓创技术参数、装置台账 | `区间中值（E2）`，并列出上下限 |
| **C3 化学计量下限** | 由反应式与摩尔质量推得，理论最小值 | 自己按元素守恒算 | `理论下限`，**不能当实际单耗** |
| **C4 情景假设** | 无任何出处，按经验预设 | 报告作者假设 | `情景参数（假设）`，必须可调 |

**纪律**：
- C3（计量下限）只能用来做"最低不可能低于"的校验，不能当实际值。工业装置单耗必然高于计量值（损失、副产物、循环不守恒）。
- C1 一定优于 C2：如果环评表写"丙烷 46.8 万吨/年"，就不要用"行业平均 1.20"。
- 每个单耗都要带**单位**（t 原料 / t 产品），并按**干基/湿基、纯度、计量基准**写清。

---

## 2. 多段工艺 = 单耗连乘

一条产品线往往不是一步反应，而是"原料 → 中间体 → 目标产品"多段：

```
丙烷 ──PDH──> 丙烯 ──聚合──> 聚丙烯 ──> 粒料
       r1           r2
单耗合计 = r1 × r2        （t 丙烷 / t 聚丙烯）
```

规则：
1. **逐段列单耗**，不要直接写合计（合计是派生结果，便于发现哪一段是误差来源）；
2. **上游中间体的时间起点**：中间体可能是**外购**的（则本项目不是该原料的新增需求方），必须写明"自建 / 外购"；
3. **副产物的抵减**：副产氢气、燃料气、残液属于正的外部性，可以算，但**不能用来冲减原料需求**，必须单列；
4. **内部转供**：一体化装置中，PDH 丙烯全部自用于 PP 时，丙烯需求与 PP 产能严格绑定；若部分外销，要按比例拆。

---

## 3. 测算公式（单段 / 多段通用）

设达产年产量 `Q`（t，公称设计产能）、各段单耗 `r_i`、纯度折算 `p`。

```
第 i 段原料需求 = Q × r_i / p_i           （t/年，达产满负荷）
多段合计（原始原料） = Q × Π(r_i) / Π(p_i)
```

按负荷率 `LF`（开工率）折算：

```
该年原料需求 = Q × LF_年 × Π(r_i)/Π(p_i)
```

其中 `LF_年` 是**全年平均负荷**，不是某一时点的开工率——投产首年的 `LF_年` 必须由投产月份 + 爬坡曲线共同决定（见 `production-scenarios.md`）。

---

## 4. 必须一起算的四个"看不见的需求"

| 需求 | 为什么容易漏 | 怎么算 |
|---|---|---|
| **开车/试车原料** | 试车期会大量消耗原料而不出合格产品 | 约 0.5–1 个月设计原料量，按 `试车消耗系数` 单列 |
| **催化剂与助剂** | kg/t 级，但往往是高价值 Specialty | 按环评或工艺资料；无资料则标缺口 |
| **公用工程原料** | 蒸汽、循环水、氮气背后的燃料 | 能查到能耗指标就折标煤 |
| **库存缓冲与损耗** | 装置稳定运行前原料存量大 | 通常 15–30 天用量，只出现在现金流测算中 |

---

## 5. 场景化输出（不要只给一个数）

每个原料输出**三档**：`保守（爬坡慢+开工低）/ 中性 / 乐观（爬坡快+满负荷）`，并说明每档用了什么参数。中数字是派生的，**参数才是判断依据**。

同时输出：
- **达产满负荷年需求**（上限，最容易被他引用、也最容易被误用）；
- **投产首年实际需求**（首年增量，这是真正会冲击市场的量）；
- **稳定运行后年需求**（长期均衡量的近似）；
- **相对上游市场的占比**（该原料需求 ÷ 上游全国产量或进口量）。

---

## 6. 单耗的敏感性：为什么要做

装置在**牌号切换**（均聚/共聚）、**负荷变化**、**原料品质波动**（丙烷含丙烷纯度、含硫量）时，单耗会显著漂移。
报告应给出**单耗 ±5% / ±10% 对原料需求的影响**，让人看到："即使单耗误差 10%，结论量级是否改变？"

如果结论只在精确到 ±2% 时才成立，那这个结论**不稳健**，必须写清楚。

---

## 7. 常见错误

1. **拿化学计量值当实际单耗**（把 1.0476 写成 1.048），会低估原料需求 10–20%；
2. **忽略中间体外购**：把外购丙烯的贸易量算成本项目对丙烯的新增需求；
3. **忘了纯度折算**：工业丙烷不是 100% 丙烷；
4. **把副产氢气收入当成原料需求抵扣**：需求是需求，收入是收入；
5. **单位混乱**：万吨/年 / 万吨/月 / 吨/日混用，最容易在"按月投产"里出错（本技能统一用 t/年 存储，展示层再换算）。
