# 交付前自检清单（QA Checklist）

按顺序过一遍，任何一项「否」都不要交付。前 6 项可脚本化，后 6 项必须人工看。

---

## A. 脚本检查（`python scripts/build_all.py <项目目录>`）

| # | 检查项 | 通过标准 |
|---|---|---|
| A1 | `validate.py` 无 error | `== 0 error ==`；有 error 时 `build_all` 自动中止 |
| A2 | `claim` 字段不缺 | 每条结论都能追到 `facts`/`gaps`/`sources` 之一 |
| A3 | xlsx 13 张表齐全 | `check.py` 报告"工作表 13 个" |
| A4 | xlsx 有公式 | 公式总数 > 50（`06_月度爬坡明细` 应有 72 条以上） |
| A5 | xlsx 无 `#VALUE!/#REF!/#DIV/0!` 风险 | `check.py` 无 error（已扫描"分母是文本/空"的公式） |
| A6 | HTML 无外部依赖、无占位符残留 | `check.py` 报"内联超链接 0 个"、无 `__DATA__` |

## B. 数字一致性（人工抽查 5 处，必须与 data.json 对齐）

| # | 抽查点 | 应相等的两处 |
|---|---|---|
| B1 | 设计产能 | HTML KPI ① = xlsx `00` 表 = `project.design_capacity_t` |
| B2 | 全国占比 | HTML ② = xlsx `04` C 列 ÷ 分母 = `compute.capacity_share` |
| B3 | 基准首年产量 | HTML ④ = xlsx `05` = xlsx `06` 月度合计 |
| B4 | 原料需求 | HTML ③ = xlsx `07` = 首年产量 × 系数 |
| B5 | 替代口径差异 | xlsx `04` 第五节 = HTML ② 卡片下的"差异 pct" |

**做一次 Excel 重算验证**（有 Excel 时）：`Application.CalculateFullRebuild` 后扫描
`#VALUE|#REF|#DIV|#NAME|#N/A|#NUM`，必须为 0。已在本技能示例上验证：9 张计算表 0 错误。

## C. 口径检查（最容易出错，逐条问）

| # | 问题 | 常见错误 |
|---|---|---|
| C1 | 分母是哪一年？ | 用 2024 年产能当 2026 年分母 |
| C2 | 分母含不含在建？ | 名义产能与有效产能混用 |
| C3 | 分母是产能还是产量？ | 用产量做分母，占比虚高 |
| C4 | 「华东」包不包山东、福建？ | 两套口径（1,513 万吨 33.5% vs 22%）混用 |
| C5 | 分子是公称还是实际？ | 把设计产能当实际产出 |
| C6 | 多套口径是否都列出？ | 只留一套，掩盖冲突 |
| C7 | 表观消费 = 产量 + 进口 − 出口？ | 漏掉净出口 |

## D. 三条纪律（人工确认，最容易被忽略）

| # | 纪律 | 错误示范 | 正确做法 |
|---|---|---|---|
| D1 | **不把设计产能当首年产量** | 40 万吨项目写"新增供给 40 万吨" | 写"首年 8.71 万吨（21.8%），稳态 36 万吨" |
| D2 | **不预测价格方向** | "新增产能将压制价格" | "占区域产能 2.64%（温和档），可观测指标为跨区流入量与价差" |
| D3 | **缺数就写缺口** | 编一个"行业平均运费 150 元/吨" | `gap: 运费未找到，已标 E5` |

## E. 呈现检查（打开 HTML 走一遍）

| # | 动作 | 期望 |
|---|---|---|
| E1 | 打开页面 | 首屏能看到「模拟输入」横幅（若 `simulated: true`）、标题、6 个 KPI |
| E2 | 拖「开车月份」到 3 月 | 首年产量数字实时变大，图表跟着变 |
| E3 | 拖「稳定开工率」到 60% | 稳态产量下降，且「首年原料需求」同步下降 |
| E4 | 点产业链图任一节点 | 右侧抽屉打开，显示企业、产能、影响强度分项、证据与链接 |
| E5 | 按 Esc 或点遮罩 | 抽屉关闭 |
| E6 | 窗口缩到 400px 宽 | KPI 变 2 列、区块单列、不出现横向滚动条（表格内部滚动除外） |
| E7 | 断网后打开 | 图表仍渲染（ECharts 已内联） |
| E8 | 打印预览 | 顶栏与抽屉隐藏，正文可读 |

## F. 文字检查

| # | 检查 | 通过标准 |
|---|---|---|
| F1 | 禁用词 | `BANNED_WORD` 为 0（见 `no-forecast-policy.md`） |
| F2 | 模拟声明 | 若 `simulated: true`，HTML 顶部横幅 + xlsx `00` 表红底提示 + 文件名不含真实企业名 |
| F3 | 业主名 | 模拟项目必须用中性占位（"某化工新材料公司"），绝不写真实上市公司 |
| F4 | 证据等级 | 每个数字旁边都能看到 E1–E5；无等级的数字视为缺口 |
| F5 | 来源日期 | 每条来源带日期；无日期的来源降级为 E5 |
