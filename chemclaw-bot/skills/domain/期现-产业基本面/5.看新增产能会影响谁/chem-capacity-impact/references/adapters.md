# 通用适配：换品种、换工艺、换项目规模

> 本技能的引擎与模板**不含任何具体产品名**。换品种只改 `project.json`，不改 `scripts/`。
> 判断是否被"写死"：在 `scripts/` 与 `templates/` 中搜索具体品种名/工艺名/企业名，出现即为缺陷。

---

## 1. 六种典型化工链的适配示例

| 品种类 | 链形态 | 关键单耗来源 | 注意 |
|---|---|---|---|
| **烯烃/聚烯烃**（PP、PE、PVC、乙二醇） | 原料 → 中间体 → 聚合物 | 环评原辅料表；聚合催化剂 g/t | 副产氢、燃料气；牌号影响单耗 |
| **基础无机**（纯碱、烧碱、尿素、黄磷） | 矿/盐 → 中间体 → 产品 | 设计院可研、行业标准 GB/HG | 联产比例（如联碱 NH₄Cl）；盐卤水计量 |
| **氯碱/PVC** | 原盐 → 电解 → Cl₂/H₂/NaOH → VCM → PVC | 电耗 kWh/t 是核心；乙烯法/电石法双路线 | 氯碱平衡，要考虑另一产品去向 |
| **磷/氟化工** | 磷矿/萤石 → 黄磷/HF → 下游 | 矿品位折算（P₂O₅%、CaF₂%） | 品位波动直接改变单耗 |
| **煤化工**（甲醇、合成氨、MTO） | 煤 → 气化 → 合成气 → 产品 | 煤耗 t 标煤/t；煤种热值 | 煤质（热值、灰分）是单耗主变量 |
| **精细化工/中间体** | 多步反应，单程收率低 | 采购/生产 BOM、SDS、专利 | 目数、纯度、异构体比例 |

## 2. 换品种时的七个改写点

1. **`meta.product / product_en / process`**：改产品名与工艺名。
2. **`chain.nodes / edges`**：按真实反应链重画；`unit_key` 指向新单耗。
3. **`unit_consumption`**：换成新链的每一段；能查环评就查环评。
4. **`capacity_bases`**：换分母（全国/区域/牌号）；注意"有效产能"口径。
5. **`stakeholders`**：换具名企业清单（同行/下游/物流）。
6. **`regional`**：换区域边界（省份清单必须写明）。
7. **`assumptions.steady_lf / ramp_months`**：按**装置类型**重设——聚合装置与无机装置爬坡完全不同：
   - 大型石化一体化：`ramp_months` 9–18，`steady_lf` 0.85–0.95
   - 中小型无机/精细化工：`ramp_months` 3–9，`steady_lf` 0.70–0.90（更高依赖订单）
   - 单一装置加氢/精制：`ramp_months` 1–3

**不要复用上一个品种的 `ramp_months`**——这是最常见错误迁移。

## 3. 项目规模不同时改什么

| 规模 | 影响 | 调整 |
|---|---|---|
| <1 万吨/年 | 占全国比例极小，重点在**局部区域/细分牌号** | 改用 `grade` 分母或区域分母做主结论 |
| 1–20 万吨/年 | 区域级影响 | `regional` 与 `radius` 为主 |
| 20–100 万吨/年 | 区域结构性、全国边际 | 六个分母全用 |
| >100 万吨/年 | 全国结构性 | 需评估进出口平价、跨区域套利 |

## 4. 工艺路线不同时，单耗连乘怎么变

| 情形 | 处理 |
|---|---|
| 单一装置，原料直接进 | 一段单耗 |
| 一体化（如 PDH+聚合） | 两段连乘，分别给出；中间体自建则上游需求 = 原料 × 乘积 |
| 中间体外购 | 该段 `on_site: false`，不产生对上游的新增需求；改产生对中间体市场的需求 |
| 多路线并存（电石法/乙烯法） | 分别建两个 `unit_consumption` 组，按产能占比加权 |
| 联产（如纯碱联产氯化铵、氯碱联产烧碱） | 主产品单耗 + 副产品产出比，单列 |

## 5. 证据可得性差异的处理

| 品种 | 环评可查性 | 单耗来源建议 |
|---|---|---|
| 大宗石化（PP/PE/芳烃） | 高（项目多、公示充分） | 环评原辅料表 E1 |
| 无机（纯碱/烧碱/尿素） | 高 | 环评 + 设计院可研 E1 |
| 煤化工 | 中 | 环评 + 能耗指标 E1/E2 |
| 精细化工/医药中间体 | 低（商业机密，单耗不公开） | 工艺专利、SDS、物料平衡估算 → 标 C3/C4 |
| 新材料（锂电材料等） | 低 | 招股书 BOM、上市公司公告 |

**纪律**：精细化工得不到 C1 时，必须在报告里把单耗明确标为 `C3/C4`，且相关性结论降级为"情景"。

## 6. 移植到其他产业（非化工）

本技能的方法框架对以下场景同样成立，只需替换单耗来源：
- 有色冶炼（电解铝：氧化铝 1.92、阳极炭块 0.42、直流电耗）
- 钢铁（铁矿石品位 → 生铁 → 粗钢）
- 建材（水泥：熟料系数、煤耗）
- 新能源材料（多晶硅：硅粉、电耗）

**唯一不变的三条**：① 项目事实必须核验；② 分母口径必须写死；③ 首年产量必须经爬坡积分。
