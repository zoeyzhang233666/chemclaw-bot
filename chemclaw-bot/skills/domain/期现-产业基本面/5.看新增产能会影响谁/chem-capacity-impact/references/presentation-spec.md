# 呈现规范：HTML 影响研究报告 与 Excel 工作簿

> HTML 给人和现场演示看，Excel 给审阅、归档和二次加工用。**两者数字必须来自同一次计算**。

---

## A. HTML：首屏到交互的七层结构

| 层 | 区块 | 必须出现的内容 | 不合格表现 |
|---|---|---|---|
| L0 | **模拟/口径横幅** | `meta.simulated=true` 时顶部红/黄条；数据截止日；唯一数据源声明 | 模拟项目未标注 |
| L1 | **首屏 KPI** | 设计产能 · 占全国% · 占区域% · 原料年需求 · 首年产量区间 · 最大缺口 | 只有情绪化结论 |
| L2 | **项目事实核验卡** | 7 必核字段 + 每项证据等级色块 + 5 项阶段性情景 | 只有一段文字 |
| L3 | **相对规模** | 六分母占比条 + 口径说明 + 规划上限情景 | 只给一个百分比 |
| L4 | **上游原料需求** | 逐段单耗卡（含证据等级）+ 三档需求 + 纯度/副产说明 | 只给"年需 XX 万吨" |
| L5 | **产量情景** | 六情景表 + 月度爬坡曲线 + "首年 ≠ 设计产能"醒目提示 | 把 40 万吨当首年 |
| L6 | **产业链影响图** | 可交互节点（上游/同行/下游/物流/副产/政策），点击出抽屉 | 静态图片 |
| L7 | **参数计算器** | 投产月/开工率/爬坡/单耗可调，实时联动产量与原料需求 | 需要刷新页面 |

### A.1 视觉规范

- 深色底 + 单一强调色（建议暖橙/青），**证据等级用 5 色**：E1 绿 / E2 青 / E3 黄 / E4 橙 / E5 红。
- 数值必须带单位与年份；百分比保留 1–2 位小数，**不要"约"字掩盖精度来源**。
- 每个图表下方一行 "数据来源：… ｜ 数据日：…"。
- 移动端可读：宽度 ≤ 720px 时 KPI 卡改 2 列，图改纵向。

### A.2 参数计算器的四组控件

| 控件 | 范围 | 联动 |
|---|---|---|
| 开车月份 | 1–12（或被推迟的年月） | 首年可产月数 |
| 稳定开工率 | 50%–100% | 稳态产量、原料需求 |
| 爬坡月数 | 0–24 | 逐月负荷曲线 |
| 原料单耗 | ±30% | 上游原料需求 |

实时输出：首年产量、稳定产量、首年原料需求、稳定原料需求、占区域比（若分母不变）。
**同时显示"设计产能上限"参照线**，让用户看到自己调到了哪里。

### A.3 交互图（产业链影响图）

- 节点按 `stakeholders[].type` 着色；线宽 ∝ 影响强度分。
- 点击节点 → 右侧抽屉：受影响企业清单、产能、证据、影响机制、相关价格（若有）。
- 必须有一个"仅显示高影响"开关，避免图太乱。

### A.4 离线要求（硬性）

- **零外链**：所有 CSS/JS 内联；图表库内联（ECharts 已随包提供）。
- 双击即可打开；断网可用。
- 文件 < 3 MB 为宜（ECharts 内联约 1 MB）。

## B. Excel：表结构与公式要求

| # | 表名 | 关键列 | 是否含公式 |
|---|---|---|---|
| 1 | `00_封面与口径` | 标题、数据截止、模拟声明、度量口径、颜色图例 | 否 |
| 2 | `01_项目事实核验` | 7 必核字段、证据等级、来源、URL、核对结论 | 否 |
| 3 | `02_现有产能基准` | 分母阶梯、口径、年份、来源、替代口径 | 否 |
| 4 | `03_原料单耗` | 逐段单耗、等级 C1–C4、区间、纯度、来源 | 是（连乘） |
| 5 | `04_产能相对规模` | 六指标、占比、每项释义 | 是（引用 02） |
| 6 | `05_产量情景` | 六情景参数、首年产量、稳态产量、达产年 | 是（引用 03/05） |
| 7 | `06_月度爬坡明细` | 60 个月 × 各情景负荷与产量 | 是 |
| 8 | `07_原料需求测算` | 每档情景 × 每段原料的年需求 | 是（引用 03/06） |
| 9 | `08_受影响对象` | 节点、企业、类型、产能、影响强度、机制 | 是（强度分） |
| 10 | `09_区域供应格局` | 区域产能/需求/自给率/半径/邻区 | 是（自给率） |
| 11 | `10_计算结果汇总` | 三大分类（事实/计算/情景）结论 | 否（文本） |
| 12 | `11_待核实事项` | 缺口、影响、补齐路径、优先级 | 否 |
| 13 | `12_来源清单` | 名称、类型、URL、抓取日期 | 否 |

### B.1 公式纪律

1. **参数单元格与公式单元格用不同底色**（参数浅黄底、公式白底），避免有人手填覆盖公式。
2. 所有派生值必须是**公式**，不是固化的数值——审阅者改参数能重算。
3. 公式引用用**同表相对地址**或**明确的跨表 `'表名'!$A$1`**，不要跨文件。
4. 每个公式列旁加"说明"批注（openpyxl `Comment`），写明公式含义与假设。
5. 页面设置：冻结首行、自动筛选、列宽、打印横向。标题行主题色。

### B.2 与 HTML 的一致性校验

`scripts/check_xlsx.py` 用 `openpyxl` 读回工作簿，校验：
- 表数 ≥ 13，每张表首行非空；
- 关键公式已写入（抽查若干单元格含 `=`）；
- 关键数值与 `compute.py` 的输出一致（容差 0.5%）。

## C. 三类结论的呈现位置

| 类别 | HTML | Excel |
|---|---|---|
| 事实 | 核验卡的绿色/蓝色标签 | `01_项目事实核验` + `10_计算结果汇总` 的事实段 |
| 计算 | 图表与卡片，标注公式 | `04/07/09` 的公式列 |
| 情景 | 计算器和情景表，标注"假设" | `05/06/07` 的假设列 + `10` 的情景段 |

**任何"情景"标签的内容不得出现在"事实"区块内。**

## D. 禁用表述（HTML/Excel/说明文档通用）

| 禁用 | 替代 |
|---|---|
| 将上涨 / 将下跌 / 利好 / 利空 / 看涨 / 看跌 | 描述机制与量级，例："区域自给率由 X% 升至 Y%，外部流入量可能被压缩" |
| 必然 / 铁定 / 毫无疑问 | 删除，或改为"在 … 假设下" |
| 预计涨 XX 元 / 目标价 | 不输出价格预测 |
| 业内普遍认为（无出处） | 给出具体机构名与 URL |

校验：`scripts/validate.py` 会对 `project.json` 的前瞻词表报 error；`check_html.py` 对产物文本再查一遍。
