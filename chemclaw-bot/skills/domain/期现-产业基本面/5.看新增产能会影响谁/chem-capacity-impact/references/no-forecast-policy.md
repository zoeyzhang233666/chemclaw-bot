# 不预测价格：禁用词与改写表

本技能的产出是**产能影响的量级与机制**，不是价格判断。以下词句一律不得出现在 HTML、Excel、结论三者中。
`scripts/validate.py` 会对 `conclusions`、`facts`、`gaps` 以及 `project.verdict` 做 `BANNED_WORDS` 扫描，
命中即报 `BANNED_WORD` 警告；交付前应清零。

---

## 一、一级禁用（出现即必须改写）

| 禁用表述 | 为什么不行 | 改成什么 |
|---|---|---|
| 价格上涨 / 下跌 / 走强 / 走弱 | 方向性预测 | 「供给端增量 X 万吨；可观测指标是区域库存、跨区流入量与价差」 |
| 利多 / 利空 | 交易语言，隐含方向 | 「对上游需求是量的增加；能否兑现取决于采购合约」 |
| 看涨 / 看跌 | 方向性判断 | 「机制上压低/抬升该区域的**相对**议价空间（不给幅度）」→ 更稳妥：「改变区域供需缺口的方向与大小」 |
| 必然 / 一定会 / 注定 | 把概率说成确定 | 「在假设 X 成立时，Y 会随之变化」 |
| 将带动价格上涨 | 因果跳跃 | 「将带来 X 万吨/年的原料需求（计算值），对应上游开工率变化需另行核实」 |
| 价格弹性为 X | 需要计量模型，本技能不做 | 「按行业口径，需求变动 1% 对应…（无公开弹性，标为缺口）」 |
| 预计盈利 / 利润将达 | 财务预测 | 「按公开单耗与当前原料/产品价差，可测算理论现金成本区间（不给结论）」 |
| 建议做多/做空/建仓 | 投资建议 | 删除 |

## 二、二级禁用（易被误读为预测，需加限定）

| 表述 | 问题 | 建议改写 |
|---|---|---|
| 「冲击市场」 | 太笼统 | 「占区域产能 2.64%，属『温和』档」 |
| 「替代进口」 | 需要贸易流证据 | 「可能改变进口货源流向，需以到港量核实」 |
| 「挤压利润」 | 方向性 | 「压缩同质货源的相对价差空间（需以实际成交价核实）」 |
| 「产能过剩」 | 结论性 | 「区域产能增速高于需求增速，缺口方向改变」 |
| 「开工率下降」 | 预测 | 「按行业口径，新增供给 X 万吨对应同等开工率下的缺口变化」 |

## 三、允许且必须使用的表达

这些是**机制与量级**语言，可以也应当用：

- 「占全国产能 0.81%，属『可以忽略』档；占 500 km 竞争半径 5.16%，属『明显』档」
- 「达产后年需进口丙烷 42.5 万吨，为 2024 年中国丙烷进口量的 1.45%」
- 「首年产量 8.71 万吨，相当于设计产能的 21.8%；若直接按设计产能计入，将高估 4.6 倍」
- 「区域自给率由 1.85 升至 1.89，由净输出转为净输出（变化 +2.61 个百分点）」
- 「可观测指标：华东跨区流入量、宁波口岸丙烷到港量、华东-华北价差」
- 「机制上，本地化供给增加会缩短下游采购半径；能否转化为订单取决于牌号与供应商导入」

## 四、价格可以出现的三种场景

价格数字不是禁区，**方向判断**才是。允许：

1. **陈述当前或历史价格**（带日期、规格、地区、含税口径、来源）：
   「2026-09-24 华东 PP 拉丝 9,900–9,930 元/吨（含税现汇），来源 XX」
2. **并列多区域价差**（只给数值，不给趋势）：
   「华东−华北 +130~150 元/吨（当日）」
3. **作为成本或价差的输入**（明确标注为"给定价格下的算术结果"）：
   「按 CP 丙烷 680 美元/吨与 11% 综合税负测算的到岸成本量级（不给利润结论）」

## 五、自检方法

```bash
python scripts/validate.py <project.json>     # 看有没有 BANNED_WORD
```

同时在 HTML 中人工确认三处：
- 顶部 KPI 区：不得出现箭头上下或"涨/跌"字样；
- ⑥ 产业链图节点详情：影响强度只到"分值+档位"；
- ⑧ 三类结论：情景栏每条都以「若……则……」的假设句开头。
