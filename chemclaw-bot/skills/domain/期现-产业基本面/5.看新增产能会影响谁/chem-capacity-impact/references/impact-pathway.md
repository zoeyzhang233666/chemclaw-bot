# 第 5~6 步：影响路径与区域格局（Impact Path & Regional Position）

> 本步骤的产出是**影响路径图**，不是涨跌结论。
> 每条路径都必须能回答："通过什么机制？量有多大？多快传导？多可靠？"

---

## 1. 影响路径的六类节点

产业链影响图上的节点，按"谁受到什么影响"分类。每类节点都要有**具名企业**，不能只写行业名。

| 类型 | 方向 | 影响机制 | 例子（通用描述） |
|---|---|---|---|
| `upstream` | 上游原料 | 新增需求 → 采购量增加 → 上游议价能力与物流需求变化 | 本项目投产后该原料年采购量增加 X 万吨 |
| `competitor` | 同区域同行 | 新增供给 → 客户被分流 → 区域份额被稀释 | 500 km 内 N 家同行合计产能 Y，本项目占 Z% |
| `downstream` | 下游用户 | 新增供给（尤其本地化供应）→ 采购半径缩短、牌号更全 | 区域内 BOPP/注塑/无纺布企业 |
| `logistics` | 物流/仓储 | 运量增量 → 流向翻转（由输入改为输出）、运费谈判 | 港口/铁路专用线/汽运车队/交割库 |
| `byproduct` | 副产物市场 | 副产（氢、燃料气）外售 → 局部小市场增加 | 副产氢的管道/槽车外售 |
| `policy` | 政策/准入 | 能耗、产能置换、出口退税、反倾销 | 只描述已公布政策，不预测政策走向 |

## 2. 影响强度打分（0–100，可解释）

每个受影响节点算一个**影响强度分**，由四项相乘/加权：

| 维度 | 取值 | 说明 |
|---|---|---|
| **体量 B**（0–1） | `本节点相关的量 / 该节点市场主体量`，截断到 1 | 例如"原料需求占上游市场 1.2%"（=0.012）远超阈值时记满 |
| **传导 T**（0–1） | 直接同物料=1.0；同工艺不同环节=0.6；替代关系=0.3 | 供应链关系的确定性 |
| **时滞 L**（0–1） | ≤3 个月=1.0；3–12 个月=0.7；>12 个月=0.4 | 越慢，短期越可忽略 |
| **确定性 K**（0–1） | E1=1.0 / E2=0.8 / E3=0.6 / E4=0.5 / E5=0.2 | 证据等级 |

```
强度 = 100 × (0.35·B̂ + 0.25·T + 0.20·L + 0.20·K)
```

其中 `B̂ = min(1, log10(1 + 100·B) )` 做对数压缩，避免"占比小就归零"。**权重可调，但必须在报告里写明**。

输出分档：`≥70 高` / `45–70 中` / `<45 低`。分档只是提示，**不是结论**。

## 3. 区域供应格局的四个坐标

| 坐标 | 数据 | 说明 |
|---|---|---|
| **区域产能** `C_r` | 本省/大区现有产能 | 分母 |
| **区域表观需求** `D_r` | 区域产量 + 净调入 | 需求量 |
| **自给率** `C_r / D_r` | 目前是输入型还是输出型 | **< 1** 输入型、**≈ 1** 平衡、**> 1** 输出型 |
| **邻区价差与运费** | 与主要流入源（如其他大区）的价差 vs 运费 | 决定"外部货源是否还有套利空间" |

**新增后的判断逻辑（只描述机制，不给价格方向）：**

```
若 自给率 由 <1 升至 ≈1 或 >1：
   区域将从"净输入"转为"自给/净输出"
   → 外部货源流入量被挤压（这是可观测的物流量变化，不是价格判断）
   → 区域内同行的销售半径被迫外扩
若 自给率 仍 <1：
   → 新增量被本地缺口吸收，对外部流入影响有限
```

> **必须写"如果……则机制是……"，而不是"因此价格会……"。**
> 运输半径经济学：固体粒料公路经济半径通常 500–800 km，汽运成本约 0.5–1.0 元/(吨·km) 量级（须按当期实际核）；液体化工更短（300–500 km）。当区域自给率越过 1，超出半径的货源必须承担 **运费倒挂** 才会进入——这才是"物流市场受影响"的具体含义。

## 4. 受影响对象清单怎么排优先级

| 顺位 | 对象 | 判断依据 |
|---|---|---|
| 1 | **竞争半径内的同类装置** | 距离 ≤ 500 km 且同品种，份额稀释最直接 |
| 2 | **区域内的下游用户** | 就地采购可省运费，是最先受益/被重新谈判的对象 |
| 3 | **上游原料供应商与贸易商** | 新增需求量级 ≥ 上游市场 0.5% 就需关注 |
| 4 | **本地物流与仓储** | 流向翻转、运量增量 |
| 5 | **副产物承接方** | 副产氢、燃料气的本地承接能力 |
| 6 | **跨区流入方** | 原先把货发到该区域的外区企业 |

## 5. 三类结论必须物理分离

报告中任何一句话，都必须能归入以下三类之一，并明确标注：

| 类别 | 标记 | 判据 | 例子 |
|---|---|---|---|
| **已确认事实** | `事实` | 有 E1/E2 出处 | "该项目环评公示设计产能 40 万吨/年（E1，URL，日期）" |
| **有依据的计算** | `计算` | 公式 + 输入均来自事实，或输入为明确标注的假设 | "占华东 PP 产能 18%（40 ÷ 222）" |
| **基于假设的情景** | `情景` | 依赖假设参数（投产月、开工率、爬坡、单耗） | "若 4 月开车、s 曲线 12 个月，首年产量约 13.5 万吨" |

**纪律**：`情景` 类结论**不得**与 `事实` 混写在同一句里。混写是产能研究最常见的误导来源。

## 6. 语言规范（替代"涨跌判断"）

| ❌ 不要写 | ✅ 改成 |
|---|---|
| 新增 40 万吨将压制 PP 价格 | 新增 40 万吨占华东产能 18%；若如期投产，区域自给率将由 X 升至 Y（机制：外部流入被挤压） |
| 丙烷需求大增，利好上游 | 达产后丙烷年需求约 47 万吨，相当于该区域某接收站进口量的 Z% |
| 同行企业将受严重冲击 | 500 km 内 N 家同行合计 Y 万吨，本项目占其 Z%；其向本区域销售的半径可能外扩 |
| 预计价格下跌 | 不输出价格方向。可给出：区域价差 A、运费 B、自给率 C 三组事实，读者自行判断 |

## 7. 必须列出的不确定性

1. 投产时间（公告计划 vs 实际）——历史偏差常达 3–12 个月；
2. 实际达产负荷——可能长期低于设计值；
3. 开工率与检修安排；
4. 上游原料可得性（进口配额、关税、运价）；
5. 下游需求是否同步增长（若下游无增长，新增即净冲击）；
6. 同区域其他在建项目——合计冲击远大于单项目。

这六条要作为报告的**固定收尾章节**，且每条给出"当前核实到哪一步"。
