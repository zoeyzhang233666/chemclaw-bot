# 第 1 步：项目事实核验（Project Fact Verification）

> 这一步的产出物是**一张事实核验卡**，不是一段新闻摘要。
> 核心问题：**这个项目真实存在吗？它现在到哪一步了？公告里的产能数字到底代表什么？**
> 只要这一步没做完，后面的所有计算都建立在流沙上。

---

## 1. 七个必核字段（缺一即降级）

一条新增产能项目，必须逐项核实以下七件事。每一项都要**独立地**标注证据等级与出处。

| # | 字段 | 要核到什么程度 | 常见坑 |
|---|---|---|---|
| 1 | **项目业主** | 准确的工商主体全称（不是简称、不是集团名）；是否新设项目公司；股东结构；是否"某集团下属某公司" | 把集团名当成业主；把 EPC 总包方当成业主；把"某某新材"的园区公司当成上市公司实体 |
| 2 | **建设地点** | 省 / 市 / 区县 / 化工园区名称；尽量到"XX 经济技术开发区 XX 化工新材料一体化项目"级别 | 只写"华东""华南"；园区名称与项目名称张冠李戴（同一园区常有多个业主） |
| 3 | **产品与规格** | 产品名称 + 牌号范围 + 形态（粒料/粉料/薄膜级/纤维级） | "聚丙烯"可能是均聚、无规共聚、抗冲共聚产品组合，影响单耗与下游 |
| 4 | **设计产能** | 数值 + 单位 + 是"单套装置"还是"规划总规模"；有无分期 | 把**规划/远期**规模当成**一期设计**规模；把万吨写成吨位混乱；把"公称能力"与"日产×340 天"混用 |
| 5 | **工艺路线** | 装置组成（几套单元）+ 每套的技术许可商/工艺名称；一体化与否 | 只写"PDH-PP 一体化"却不知道 PDH 用 Oleflex 还是 Catofin；把"外购丙烯聚合"写成"PDH" |
| 6 | **项目阶段** | 只取五个标准词：`拟建 / 备案(含环评) / 在建 / 试车 / 已投产` | 把"环评受理"写成"在建"；把"签约"写成"备案"；把"土建开工"当成"装置开车" |
| 7 | **预计投产时间** | 公告原文怎么写就怎么记（"计划 2027 年 6 月建成"≠"2027 年 6 月投产"）；注明公告发布日期 | 用新闻标题的年份覆盖公告原文；把"建成"当"投产"；不区分"计划"与"已确定" |

**附加字段（有则更好，无则标缺口）**：总投资额、分期安排、配套公用工程（氢气、蒸汽、循环水）、主要设备供应商、是否有期货交割/品牌注册计划、下游配套或自建改性粒料装置。

## 2. 证据等级（五级，写进核验卡）

| 等级 | 含义 | 典型来源 | 能否支撑"设计产能"计算 |
|---|---|---|---|
| **E1 一手官方** | 项目业主或政府主管部门的原始文件 | 环评报告书/公示原文、生态环境部门批复、发改委备案证、企业自投公告、公司年报/半年报、交易所问询回复 | ✅ 可以，最高权重 |
| **E2 行业权威媒体** | 有编辑审核的行业媒体原发报道 | 中国化工报、隆众资讯、卓创资讯、化工在线、各省发改委官网新闻、园区官网 | ✅ 可以，需注明日期 |
| **E3 综合媒体转载** | 门户/财经媒体转述，未给出原始出处 | 各类财经号、行业公众号、门户转载 | ⚠️ 仅作线索，必须回原文 |
| **E4 机构口径汇总** | 第三方数据库的产能统计/在建项目表 | 咨询机构、行业协会统计数据 | ⚠️ 可用于"现有产能"基准，需标口径与年份 |
| **E5 待确认/自述** | 无任何可点开出处、仅在口径中出现 | 传闻、销售口中、未公开的会议信息 | ❌ 只能标"待确认"，不得进入计算 |

> **纪律**：`E5` 不能填进 `design_capacity`。宁可把产能写成"待确认"，也不要用一个没有出处的数去做占比和原料需求测算——后面所有数字都会被它污染。

## 3. 核验方法：按"由强到弱"的检索顺序

### 3.1 第一优先——环评 / 备案（能拿到单耗的最佳来源）

新增化工装置**必须**走环评，环评报告书里有一张"主要原辅料及能源消耗表"，这是**最接近工程实际的单耗来源**。检索路径：

| 通道 | 检索式示例 | 能拿到什么 |
|---|---|---|
| 地市生态环境局官网 | `site:<城市>生态环境局 <业主简称> 环境影响报告书` | 环评全文 PDF（含原辅料表） |
| 省级生态环境厅 | `省份 环境影响评价 受理公示 <产品> <年份>` | 受理/拟审批/批复公告 |
| 全国建设项目环评平台 | `建设项目环境影响评价 <项目名>` | 公示原文 |
| 发改委备案 | `省份 企业投资项目备案 <业主简称> <产品>` | 备案证载明的产能、投资、建设地点 |
| 园区官网 | `园区名 项目 开工 / 签约` | 开工时间、分期安排 |

**环评原文的四个读法**：
1. 先看**建设规模**——装置套数、单套能力、总能力，确认"设计产能"是几套相加还是只有一期。
2. 再找**主要原辅材料消耗表**——这是单耗的一手证据，直接抄进 `unit_consumption` 并标注 `来源=E1`。
3. 看**工艺流程与污染源**——据此确认工艺路线（Oleflex / Catofin / 环管 / 气相法），而不是听新闻里的笼统说法。
4. 看**建设工期与投产时间表**——环评里通常写"建设周期 XX 个月"，据此反推投产窗口。

### 3.2 第二优先——上市公司公告

用 `cninfo`（巨潮资讯）按**公告原文**检索，而不是按新闻检索：
- 项目投资公告：通常会写"建设规模 XX 万吨/年、投资额、建设期、预计投产时间"。
- 可行性研究报告公告、非公开发行募集说明书：有更细的技术经济指标。
- **年报/半年报的"在建工程"**：有进度百分比和累计投入，是判断"是否真的在建"的硬证据。
- 交易所问询回复函：常披露产能口径是否包含规划产能。

**关键判断**：公告里的"XX 万吨/年"到底是**已投产**、**在建**还是**规划**？A 股公司报告中这三者经常混在一段里说。

### 3.3 第三优先——行业资讯的装置数据库

隆众 / 卓创 / 化工在线 的"装置动态""新增产能跟踪"能给出**投产时间点**和**实际开车状态**，但它们**不提供单耗**。
用来做两件事：① 校正"预计投产时间"的最新变化；② 校正现有产能基准。

### 3.4 第四优先——设备与工程承包商

设计院 / 工艺许可商（UOP、Lummus、专利商中标公告）发布的中标信息，能反推工艺路线和开车节奏。

## 4. 五种必须主动排除的"假项目"

| 假项目类型 | 识别特征 | 处理 |
|---|---|---|
| **重复计入** | 同一项目在"一期/二期""规划/详设"两个口径里被算两次 | 拆成两条记录，标明口径，计算时只取"已备案及以上" |
| **长期停滞** | 环评已批 3 年以上无开工记录、无年报在建工程新增 | 阶段标为 `拟建`，并在 `gaps` 里注明"公示后无实质进展" |
| **更名 / 换主体** | 项目名称改了、业主换了，旧新闻仍在传播 | 以最新公告主体为准，保留旧名作为别名 |
| **范围混淆** | "化工新材料一体化项目"包含多个产品，新闻只说总数 | 只取本产品对应的装置，不从总投资额推算产能 |
| **"规划"冒充"在建"** | 只有签约仪式、框架协议，无环评、无备案、无土建 | 阶段只能标 `拟建`，且必须注明"仅有签约/框架协议" |

## 5. 事实核验卡的推荐结构

核验卡要能一眼看出**哪一条是硬的、哪一条是软的**。推荐字段：

```
项目名称 / 业主全称 / 建设地点 / 产品与牌号 / 设计产能（数值+单位+口径）
工艺路线（装置组成 + 技术许可）/ 项目阶段 / 预计投产时间（原文 + 公告日）
总投资 / 分期安排 / 牵头环评批复文号
每条事实 → 证据等级 E1~E5 → 来源名称 → 可点开 URL → 抓取日期
核对结论：已确认事实 / 尚未确认事项 / 与本项目相关但不计入的条目
```

---

## 6. 与"设计产能"相关的三个口径陷阱

1. **公称能力 ≠ 实际负荷下的产量。** 40 万吨/年指在标准工况、标准产品质量分布下的公称能力；实际年产量受开工率、检修、牌号切换影响，通常低于公称。
2. **一期产能 ≠ 规划总产能。** 公布"规划 XX 万吨"，常常只先建 40 万吨。**计算占比用一期设计产能**，同时在情景里单列"规划全部落地的上限"。
3. **新增 ≠ 净新增。** 若同区域同期有装置退出/停车（甚至本项目业主有老装置关停），行业净新增可能小于 40 万吨。**本项目自身**的新增是 40 万吨，行业层面的净增量要单独核。

---

## 7. 核验的完成判据

核验卡过关的条件（四条全满足才能进入第 2 步）：

- [ ] 七个必核字段全部有值，或明确标注"未找到"；
- [ ] 设计产能、工艺路线、项目阶段三项的证据等级 ≥ E2（理想是 E1）；
- [ ] 每条事实都有可点击 URL + 抓取日期，或明确写 `未核实`；
- [ ] 已在 `gaps` 中列出所有影响计算精度的未确认项（尤其是实际开工率与投产月份）。

做不到前两条时，报告必须把该项目的结论降级为"情景测算"而非"事实测算"，并在显著位置声明。
