# chem-capacity-impact · 看新增产能会影响谁

一个面向产业基本面研究的技能：给定「某项目计划新增某产品 X 万吨/年产能」，
输出**项目事实核验 → 相对规模 → 上游原料需求 → 投产情景 → 区域格局 → 受影响主体**的完整分析，
并交付一份单文件交互式 HTML 报告 + 一份 13 表 Excel 计算工作簿。

---

## 它解决什么问题

「新增 40 万吨 PP 会影响谁？」这个问题有四个经典陷阱：

| 陷阱 | 错误答案 | 本技能的答案 |
|---|---|---|
| 把设计产能当首年产量 | 「新增供给 40 万吨」 | 首年 **8.71 万吨**（基准）/ 稳态 36 万吨 / 上限 40 万吨（高估 4.6 倍） |
| 只算全国占比就下结论 | 「占全国 0.81%，可以忽略」 | 占区域 2.64%（温和）、占竞争半径 5.16%（**明显**） |
| 掩盖分母口径冲突 | 只用一个分母 | 华东产能两套口径并列：2.64% vs 4.02%，差 1.38 pct |
| 顺手预测价格 | 「供给增加，价格承压」 | 只给量级、机制与可观测指标，**不输出方向** |

## 快速开始

```bash
python scripts/build_all.py examples/01-pp-pdh-40wt-sim
```

一条命令完成：口径校验 → 计算 → Excel → HTML → 结构自检。任何一步有 error 即中止，不产出半成品。

```
output/聚丙烯新增40万吨产能_影响研究报告.html          单文件交互式报告，双击即开，离线可用
output/聚丙烯新增40万吨产能_影响研究_计算工作簿.xlsx    13 表，261 个公式，可审计
```

换成自己的项目：复制 `examples/_skeleton/`，按 README 填 `project.json`，再跑同一条命令。

## 交互式报告里有什么

- **项目事实核验卡**：七项必核字段，每项带证据等级徽标（E1–E5）
- **六组分母占比条**：每组给百分比 **+ 档位 + 含义**，而不是孤零零一个数
- **原料需求连乘表**：单耗 × 纯度逐项展开，给首年/稳态/上限三档需求
- **五情景对比 + 爬坡曲线**：37 个月负荷率曲线叠加，直观看出首年损失多少
- **参数计算器**：拖动开车月份 / 开工率 / 爬坡月数 / 单耗系数，产量与原料需求实时重算
- **产业链影响图**：SVG 手绘布局，点击任意节点弹出抽屉，显示具名企业、产能、影响强度分项、证据与原文链接
- **三类结论物理分离**：事实（绿）/ 计算（蓝）/ 情景（橙），互不混写
- **待核实清单**：每条缺口写明影响哪一步计算、怎么补、优先级

响应式（手机单列）、可打印、无任何外部请求（ECharts 已内联）。

## Excel 工作簿结构

| 表 | 内容 |
|---|---|
| `00_封面与口径` | 项目名、口径声明、模拟输入警示、图例 |
| `01_项目事实核验` | 七项字段 + 证据等级 + 结论 |
| `02_现有产能基准` | 六组分母，含年份、边界、口径、替代口径 |
| `03_原料单耗` | 单耗、依据等级、区间、纯度、证据 |
| `04_产能相对规模` | 占比公式 + 档位 + **口径冲突并列** |
| `05_产量情景` | 五情景参数与结果 |
| `06_月度爬坡明细` | **逐月公式**（72 个），可改参数看结果联动 |
| `07_原料需求测算` | 产量 × 系数，含首年/稳态/上限 |
| `08_受影响对象` | 主体、产能、影响强度分项 |
| `09_区域供应格局` | 自给率、供给增量、半径同行 |
| `10_结论分类` | 事实 / 计算 / 情景 |
| `11_待核实事项` | 缺口 + 影响 + 补齐路径 + 优先级 |
| `12_来源清单` | 全部来源、日期、用途、链接 |

公式真实可算（已用 Excel 重算验证：9 张计算表 0 个 `#VALUE!`/`#REF!`）。
填充色编码：绿=事实输入、蓝=计算结果、橙=情景参数、黄=需留意、白=公式。

## 三条铁律

1. **不把设计产能当首年产量** —— 首年 / 稳态 / 上限三档并列，并算出差多少倍
2. **不预测价格方向** —— 只描述量级、机制与可观测指标
3. **缺数就写缺口** —— 不编造行业均值，把缺口写进 `gaps` 并说明补齐路径
