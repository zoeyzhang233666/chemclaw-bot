# 05 · 交付物规范

## 一、HTML 交互报告

### 技术要求

| 项 | 要求 |
|---|---|
| 单文件 | 全部 CSS/JS/数据内联，**零外部依赖** |
| 数据载体 | `<script id="payload" type="application/json">{...}</script>` |
| 离线可用 | 双击打开即可，不需要服务器、不需要网络 |
| 图表 | 原生 SVG + CSS，不引 CDN（ECharts/Chart.js 一律不用） |
| 打印 | 有 `@media print` 规则，打印时隐藏交互控件 |
| 兼容 | Chrome/Edge/Firefox 现代版本 |

### 七个页签

#### 01 全景

- **KPI 五连**：样本产能合计、集团/法人数、CR5、电石法占比、覆盖率
- **集团产能比较**（Top 12 横向条形，点击开抽屉）
- **工艺路线构成**（SVG 环形图）
- **省级产能分布**（横向条形，点击筛选）
- **省级产能·按工艺堆叠**（堆叠条，橙=电石法 蓝=乙烯法）
- **产业带（区域）结构**
- **产品等级构成**
- **口径提示横幅**：说明全国口径多套并存、样本 ≠ 全国

#### 02 产能地图

- 省份简化轮廓（SVG polygon，31 个省级行政区）
- 基地气泡：**面积 ∝ 产能**，颜色 = 主导工艺
- 悬停 tooltip：基地名、法人、省市、产能、工艺拆分、装置数
- 点击气泡 → 抽屉（基地信息 + 装置明细 + 同集团其他基地）
- 点击省份 → 筛选该省
- 图例 + 精度声明（「坐标为厂址或城市级，非测绘精度」）

#### 03 企业与集团

- 表格：集团、全称、实际控制人/性质、产能、占样本比、法人数、基地数、覆盖省份、工艺构成
- 点击行 → 抽屉：集团概况 → 企业→集团关系 → 生产基地与装置

#### 04 装置明细

- 唯一事实层，一行一装置
- 列：装置ID、基地/法人、省/市、产品/等级、工艺、产能、口径、投产年、状态、来源/可信度
- 顶部显示：条数、合计、**当前口径**
- 切换口径会改变参与汇总的装置集合

#### 05 在建拟建

- **项目流水线**：按阶段分列（拟建→备案→环评→在建→试车→爬坡），显示毛产能/退出/净增
- **年度增量图**：堆叠柱（电石法 vs 乙烯法），标注项目数
- **项目表格**：可点击查看进展时间线
- **提示**：毛新增 ≠ 净新增；加权仅作情景参考

#### 06 口径与校验

- 全国产能口径并列表（编号、指标、数值、单位、年份、来源机构、等级、定义）
- 集中度指标卡：CR1/CR3/CR5/CR10/HHI（集团）+ CR5/HHI（法人）+ 平均单厂规模
- 统计口径说明：联产/副产/长期停产/产品等级
- 重复统计校验结果表：规则、级别、对象、信息、处理建议

#### 07 数据与来源

- 来源清单：编号、类型、标题（可点击）、发布机构、日期、等级
- 数据缺口清单：编号、缺口项、影响范围、当前状态、补齐方式、优先级

### 视觉规范

- 深色深蓝主题（研究型报告质感）
- 工艺固定配色：**电石法 `#ff7a45`（橙）/ 乙烯法 `#2fb4ff`（蓝）/ 混合 `#b084ff`（紫）/ 未核实 `#7d8ea6`（灰）**
- 状态标签：在产（绿）、长期停车（黄）、检修（橙）、未核实（灰）
- 可信度标签：A（绿）/ B（蓝）/ C（黄）/ D（红）
- 数字统一用等宽字体，保留 1 位小数

### 数据完整性检查（交付前必跑）

用 CDP 或浏览器 DevTools 确认：

```js
// 页面无 JS 异常
// 关键元素已填充（非空、非默认占位）
['#kpi-cap','#tb-group','#tb-unit','#tb-src','#bar-group','#donut-route',
 '#stack-prov','#map','#pipe','#tb-bench','#tb-check'].forEach(s => {
  const e = document.querySelector(s);
  console.log(s, e ? (e.children.length || e.textContent.slice(0,20)) : 'MISSING');
});
```

**常见坑**：
- `init()` 绑在 `DOMContentLoaded` 上，但脚本在 body 末尾 → 事件已触发，init 永不执行。
  正确写法：

```js
if (document.readyState === "loading") {
  document.addEventListener("DOMContentLoaded", init);
} else {
  init();
}
```

- 某个 `#bar-xxx` 容器在 HTML 里漏写，`bars()` 里 `el.innerHTML` 抛 TypeError，
  后续所有渲染中断 → **KPI 全部显示「—」**。这是最典型的一处「看起来渲染成功但数据全空」。

## 二、Excel 工作簿

### 19 个工作表

| # | 表名 | 内容 |
|---|---|---|
| 00 | 封面 | 标题、口径、版本、免责 |
| 01 | 口径与样本范围 | 产品边界、主体边界、基准年、样本策略、覆盖率 |
| 02 | 核心结论 | 5–8 条带数字的结论，每条注明依据 |
| 03 | 集团汇总 | 集团、控制人、产能、占比、法人/基地数、省份、工艺构成、**来源** |
| 04 | 法人汇总 | 主体全称、代码、性质、信用代码、地址、产能、核验依据、**来源** |
| 05 | 基地清单 | 基地、法人、省市园区、坐标、精度、产能、装置数、来源 |
| 06 | 装置明细 | **唯一事实层**，23 列含原文表述、数据年份、状态、配套、来源URL、可信度 |
| 07 | 区域汇总(省) | 省、产能、占比、企业数、工艺拆分 |
| 08 | 区域汇总(市) | 市、产能、企业数 |
| 09 | 工艺路线汇总 | 工艺、产能、占比、企业数、代表企业 |
| 10 | 产品等级汇总 | 等级、产能、占比 |
| 11 | 在建拟建项目 | 19 列含阶段、预计投产、置换退出、净增、投资额、时间线、来源 |
| 12 | 新增净额还原 | 毛新增 → 置换退出 → 净新增 的逐项还原过程 |
| 13 | 重复统计校验 | R1–R14 全部校验结果 |
| 14 | 汇总公式与溯源 | 每个汇总值的**计算公式**与数据来源链 |
| 15 | 口径对比 | 全国多套口径并列 + 本样本各口径对比 |
| 16 | 数据缺口 | 缺口项、影响、状态、补齐方式、优先级 |
| 17 | 来源清单 | 编号、类型、标题、机构、日期、URL、等级、备注 |
| 18 | 企业集团关系树 | 集团 → 法人 → 基地 → 装置 缩进树 |

### 格式要求

- 标题行加粗、深色底、白字
- 每个数据表前 3 行：表名、说明、表头（便于直接阅读）
- 数字列保留 1 位小数，千分位
- 长文本列自动换行 + 合适列宽
- 冻结表头
- **至少 3 个原生 Excel 图表**（用 openpyxl 的 `BarChart`/`PieChart`，不嵌图片）
- 每个产能行必须能追溯到 `来源编号`

### 「14_汇总公式与溯源」表怎么填

这是最容易被忽略、但最体现专业度的一张表。示例：

| 汇总项 | 值 | 公式 | 数据来源 |
|---|---|---|---|
| 样本设计产能合计 | 1,423.0 | `=SUM(06_装置明细!L:L)` 中 basis=design 的行 | 各企业年报/环评 |
| 集团合计（中泰） | 109.0 | `=SUMIFS(06!L, 06!F, "中泰集团", 06!K, "design")` | 中泰 2025 年报 p15 |
| CR5 | 38.4% | 前五集团产能 / 样本合计 | 本表计算 |
| 覆盖率 | 47.5% | 样本合计 / 2,993（协会口径） | 中国氯碱工业协会 |
| 净新增 2026 | 待确认 | Σ项目规模 − Σ置换退出（多数未披露） | 项目库 |

## 三、命名与交付

### 文件命名

```
{产品}产能分布报告_{年份}年_{YYYYMMDD}.html
{产品}企业产能明细表_{年份}年_{YYYYMMDD}.xlsx
```

例：`PVC产能分布报告_2025年_20261020.html`

### 交付时必须一并说明

1. **样本覆盖了多少家、覆盖率多少**，并明确「不等于全国总产能」
2. **采用了哪套全国口径作分母**，其余口径列在哪里
3. **哪些数字是未知的**，列在数据缺口表
4. **校验结果**：ERROR 数（应为 0）、WARN 数及处置
