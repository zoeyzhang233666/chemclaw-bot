# 06 · 数据源目录与检索技巧

## 一、一手来源（A 级）——优先用这些

### 巨潮资讯网（cninfo）— 上市公司定期报告

**最优先的来源。** 中国上市公司年报/半年报/季报/公告全文。

- 网址：https://www.cninfo.com.cn
- PDF 直链格式：`https://static.cninfo.com.cn/finalpage/{YYYY-MM-DD}/{docId}.PDF`
- 搜索技巧：站内搜索公司简称 → 公告类别筛选「年度报告」

**年报里必看的章节**：

| 关键词 | 位置 | 能拿到什么 |
|---|---|---|
| 产能与开工情况 / 主要产品的产能情况 | 「经营情况讨论与分析」 | **设计产能、产能利用率、在建产能** |
| 主要控股参股公司分析 | 同上 | 子公司名单与各自营收/净利 |
| 合并范围 / 子公司情况 | 财务报表附注 | 持股比例、注册地 |
| 释义 | 报告开头 | **子公司法定全称**（最可靠的公司名来源） |
| 在建工程 / 重要在建工程项目 | 财务报表附注 | 在建项目、预算、进度 |
| 同业竞争 / 行业地位 | 经营讨论 | 竞争对手名单、全国总量 |
| 主要原材料采购 | 经营讨论 | **判断工艺路线**（采购电石=电石法，采购乙烯=乙烯法） |

### 评级报告（A 级）

中诚信国际、联合资信、大公国际、东方金诚、上海新世纪。

- 中国货币网（chinamoney.com.cn）
- 各评级机构官网（lhratings.com、ccxi.com.cn 等）

**价值**：会列「主要单体企业产能」「主要生产基地」「产能利用率」，且常有
**集团口径与上市口径的区分说明**，是解决归属混乱的最佳材料。

### 环评公示（A 级）

各省/市生态环境厅（局）网站、建设项目环境影响评价信息平台。

**价值**：**唯一能拿到装置级细节的公开来源**——厂址、装置规模、工艺、原料、
产品方案、建设期。新建项目在环评阶段就必须公示。

搜索：`{企业名} 环境影响报告书 公示 site:sthjt.{省简拼}.gov.cn`

### 项目备案（环保/发改）

- 全国投资项目在线审批监管平台
- 各省发改委网站

**价值**：项目代码、备案时间、建设地点、投资额、建设规模。

### 安全生产许可证 / 排污许可（A 级）

- 应急管理部、各省应急管理厅（危化品安全生产许可）
- 全国排污许可证管理信息平台（permit.mee.gov.cn）

**价值**：**核定产能**（`approved` 口径）。这是政府许可的上限，与设计产能常不同。

**注意**：许可证未列某产品 ≠ 该企业不产该产品（见 `04_enterprise_group_traps.md` 陷阱 5）。

### 产能置换公告（A 级）

各省工信厅「产能置换方案公示」。

**价值**：新建项目对应的退出产能吨数 —— 这是算「净新增」的唯一可靠来源。

### 行业协会（A/B 级）

| 行业 | 协会 |
|---|---|
| 氯碱、PVC | 中国氯碱工业协会（ccaon.com）、中国氯碱网 |
| 纯碱 | 中国纯碱工业协会 |
| 氮肥、尿素 | 中国氮肥工业协会 |
| 磷肥 | 中国磷复肥工业协会 |
| 石化整体 | 中国石油和化学工业联合会 |
| 氟硅、有机硅 | 中国氟硅有机材料工业协会 |

协会年度统计常给出：企业家数、总产能、产量、开工率、区域分布、退出产能。
**这是全国口径的权威来源，引用时必须写明是哪个协会、哪一年。**

## 二、权威二手（B 级）

- 券商行业深度报告（东方财富研报、慧博、巨潮研报）—— 竞争格局章节有企业产能表
- 卓创资讯、隆众资讯、百川盈孚 —— 产能/产量/开工率，但**口径需核实**
- 主流财经媒体转引一手公告（证券时报、上海证券报、财联社、每经）
- 政府通稿（省国资委、地方发改委、园区管委会）

## 三、一般二手（C 级）——只作线索

- 行业资讯网站（化工网、中化新网）
- 行业盘点文章（「国内外 XX 家 XX 生产企业介绍」类）
- 百科（百度百科、维基）
- 企业官网「公司简介」（常是宣传口径，含在建/规划）

**规矩**：C 级数字进入报告必须标 C，且不得作为核心结论的唯一依据。
有 A/B 级冲突时一律以高级别为准。

## 四、未核实（D 级）

- 查不到出处
- 与一手来源矛盾
- 仅口口相传/论坛/非专业自媒体

**规矩**：只登记，不采信，不进汇总。

## 五、检索技巧

### 5.1 年报 PDF 提取

```python
import pypdf

reader = pypdf.PdfReader("annual_report.pdf")
for i, page in enumerate(reader.pages):
    t = page.extract_text()
    if "产能" in t and ("聚氯乙烯" in t or "PVC" in t):
        print(f"--- p{i+1} ---")
        print(t[:1500])
```

批量提取关键词上下文（见 `examples/pvc-china-2025/build/_extract.py`）。

### 5.2 搜索语法

```
site:static.cninfo.com.cn {企业} 年度报告
{企业} 环境影响报告书 公示
{企业} 安全生产许可证 许可范围
{省} 产能置换方案 公示 {产品}
{集团} 主要生产基地 产能 万吨
```

### 5.3 判断一个数字可不可信的快速方法

1. **有没有年份？** 没有年份的产能数字，可信度直接降一级
2. **有没有限定词？** 「约」「超」「预计」「规划」→ 不是实测值
3. **是产能还是产量？** 「年产 X 万吨」在中文里两种意思都有，要看上下文
4. **是设计还是实际？** 如果和「利用率 >100%」同时出现，这个数就是设计产能
5. **是集团还是公司？** 看主语是「XX 集团」还是「XX 股份」
6. **是否含糊树脂/特种牌号？** 与全国总量对比时必查

### 5.4 交叉验证策略

一个数字至少要有两条独立来源，或一条 A 级来源。

冲突时的处理优先级：

```
A 级一手（年报/环评/许可/协会） > B 级权威二手 > C 级一般二手 > D
同级别冲突 → 取更新的、定义更明确的，另一个记入口径对比
```

**绝不能**取平均、取中位数、或「取一个看起来合理的」。

## 六、按产品的取数侧重

| 产品类型 | 关键来源 | 特别注意 |
|---|---|---|
| 氯碱（PVC/烧碱） | 氯碱协会 + 上市公司年报 | 集团/上市口径差异极大；糊树脂是否含 |
| 纯碱 | 纯碱协会 + 远兴/三友/山东海化年报 | 联碱法联产氯化铵 |
| 尿素 | 氮肥协会 + 气头/煤头成本区分 | 产能置换频繁 |
| 甲醇 | 石化联合会 + 装置级环评 | 大量小装置，样本难全 |
| 聚烯烃 | 石化联合会 + 中石化/中石油/民营大炼化 | 油头/煤头/PDH 路线 |
| 钛白粉 | 钛白粉行业协会 + 龙佰/中核钛白 | 硫酸法/氯化法 |
| 有机硅 | 氟硅协会 + 合盛/新安/东岳 | 单体与下游分开 |
| 磷酸铁锂 | 券商 + 企业公告 | 产能过剩，实际开工率极低 |
| 负极材料 | 券商 + 贝特瑞/璞泰来 | 石墨化配套 |

## 七、常见数据陷阱速查

| 陷阱 | 表现 | 应对 |
|---|---|---|
| 吨 vs 万吨 | 数字大 10000 倍 | R12 校验 |
| 折百 vs 实物 | 烧碱差 2–3 倍 | 明确标注 |
| 设计 vs 实际产量 | 利用率 >100% | 看有没有「利用率」同现 |
| 集团 vs 上市 | 差接近一倍 | 看主语 |
| 含糊树脂 vs 纯粉 | 差 5% | 对照全国口径定义 |
| 在册 vs 在产 | 差 100 万吨级 | 看有没有长期停车说明 |
| 毛新增 vs 净新增 | 差 30–50% | 查置换公告 |
| 投产 vs 达产 | 试车到满产要 1–2 年 | 分阶段记录 |
