# 02 · 完整作业流程

## 时间预算（单品种，1 人）

| 阶段 | 占比 | 产出 |
|---|---|---|
| 定口径与边界 | 10% | 报告首页的口径声明 |
| 建企业名录骨架 | 20% | 四层链表（产能留空） |
| 逐装置取数 | 40% | 装置明细表 |
| 校验与修正 | 15% | 零 ERROR 的校验报告 |
| 出报告 | 15% | HTML + Excel |

**取数占不到 40% 通常意味着口径没定清楚就在乱搜。**

## 第 1 步：定口径与边界

### 必答的四个问题

1. **产品边界**：统计到哪个层级？
   - 纯粉/通用级算不算，特种牌号算不算，糊树脂/乳液树脂算不算
   - 中间体（VCM、EDC）算不算——通常**不算**
2. **主体边界**：境外算不算？在建算不算？已停产未注销算不算？
3. **基准年**：取最近完整财年；跨年数据逐个标年份
4. **样本策略**：先覆盖大集团 + 主产省份，明确目标覆盖率

### 实操

把答案写成一段话，放在报告 `01_口径与样本范围` 工作表最上方，并在 HTML 首页显示。
后面所有争议都用这段话来裁决。

## 第 2 步：建企业名录骨架（产能先留空）

### 2.1 拿到企业名单

按优先级：

1. **协会年度统计**：中国氯碱工业协会（PVC/烧碱）、中国纯碱工业协会、中国氮肥工业协会、
   中国石油和化学工业联合会。协会年报常给出「企业家数、总产能、平均规模」
2. **上市公司年报的「同业竞争」/「主要竞争对手」段落** —— 这里有经审计的对手名单
3. **券商行业深度报告的竞争格局章节** —— 通常附企业产能表格（C 级，作线索）
4. **行业媒体年度盘点** —— 作线索，逐家回溯一手

### 2.2 拆到法人

对每个集团，找：

- 年报「主要子公司」表 / 「合并范围」
- 发行文件（招股书、募集说明书）的**释义表**——这里会给子公司法定全称
- 国家企业信用信息公示系统（统一社会信用代码）

**注意**：分公司（如「XX 集团氯碱化工分公司」）不是独立法人，但它可能持有安全许可证，
取数时要按「基地」而非「法人」处理。

### 2.3 拆到基地

- 年报「主要生产基地」「主要厂区」描述
- 环评公示（生态环境局/省厅网站）—— 有厂址、规模、工艺，质量最高
- 政府园区公示、招商资料
- 项目备案（投资项目在线审批监管平台）

### 2.4 补坐标

- **厂址级**（precise）：有明确地址时用地名 + 园区名定位
- **城市级**（city）：只知道城市
- **省级**（province）：只知道省份

**必须如实标注精度。** 地图上城市级气泡可能重叠，不能假装是精确厂址。

### 骨架完成的标志

能回答：「这个集团有几个法人、几个基地、分别在哪个省哪个市哪个园区、谁控股」
——**即使所有产能数字还是空的**。

## 第 3 步：逐装置取数

### 3.1 取数顺序（硬性，不可跳级）

```
① 巨潮资讯 / 交易所年报「产能与开工情况」表
② 评级报告（中诚信、联合资信、大公、东方金诚）
③ 环评公示 / 项目备案 / 产能置换公告
④ 安全生产许可证 / 排污许可证
⑤ 协会统计
⑥ 券商深度报告
⑦ 行业媒体 / 行业盘点
```

低级别来源只能用于**补齐**和**交叉验证**，不能覆盖高级别来源。

### 3.2 年报怎么读

在 PDF 里搜这些关键词：

- 「产能与开工情况」「主要产品的产能情况」「设计产能」「产能利用率」
- 「主要控股参股公司分析」「合并范围」「子公司情况」
- 「释义」——拿子公司法定全称
- 「同业竞争」「行业地位」——拿全国总量与竞争格局
- 「在建工程」「重要在建工程项目」——拿在建项目

**原文照录**到 `capacity_note` 字段。原文有「约」「超」「预计」就保留这些限定词。

### 3.3 装置级 vs 企业级

大部分年报只披露**企业合并口径**（如「聚氯乙烯树脂 260 万吨/年」），不拆到厂。

处理方式：

- **能拆就拆**：有环评/项目备案的厂，用环评数字建装置行
- **不能拆就留空**：建一条 `capacity = null` 的装置行，`capacity_note` 写明
  「年报仅披露合并口径 X 万吨，未拆分至各厂」，并把缺口登记进 `16_数据缺口`
- **绝不按基地数量平均分摊** —— 这是最常见的编造方式

### 3.4 判断工艺路线

- 年报/官网明说的，直接用
- 看原料：采购电石 / 自备电石 → 电石法；采购乙烯 / 配套乙烯裂解 → 乙烯法
- 看产品牌号与装置名称：「乙炔法」「氧氯化法」「MTO」
- **判断不了就写 `unknown`**，不要按地域猜（西部≠一定是电石法，渤化、盐湖镁业都在西部但都是乙烯法）

### 3.5 判断运行状态

| 状态 | 判据 |
|---|---|
| `running` 在产 | 有近期产量/利用率披露 |
| `maintenance` 检修 | 临时停产公告，明确恢复时间 |
| `idle` 长期停车 | 停车超 6–12 个月，无明确复产计划 |
| `shutdown` 已退出 | 破产、注销、拆除、搬迁关停 |
| `unknown` 未核实 | 查不到 |

**破产/注销的主体一律标 `shutdown`，产能不计入在产供给。** 但在「在册产能」口径下可单列。

## 第 4 步：跑校验

```bash
python build/assemble.py          # 合并分片 + 自检报告
python build/assemble.py --emit   # 额外写出 data/final.json
```

输出包含：集团/法人/基地/装置/项目/来源计数、覆盖率、集团排序、区域/省份/工艺分布、
集中度、口径分布、可信度分布、状态分布，以及 R1–R14 校验结果。

处理原则：

- **ERROR 清零**
- **WARN 逐条处理**：要么修数据，要么在报告里写明为什么不修
- **INFO 记录**：通常是提示性信息（地址重复、可信度不一致），在报告备注里说明

## 第 5 步：算集中度与覆盖率

```python
from pcd_model import Aggregator, cr_n, hhi, concentration_label, coverage

a = Aggregator(ds, basis="design")
by_group = a.by_group()
total = a.total()
print(cr_n(by_group.values(), 5))   # CR5
print(hhi(by_group.values()))       # HHI
print(coverage(total, 2993))        # 覆盖率，分母写清来源
```

**必须同时报集团口径和法人口径。** 两者差距本身是结论：

- PVC 实例：集团口径 CR5 = 38.4%，法人口径 CR5 = 41.0%
  → 说明头部集团内部法人较分散，集团层面控制力强于单一法人

## 第 6 步：分离增量

项目分九个阶段（`planned` / `filed` / `eia` / `construction` / `commissioning` /
`rampup` / `operating` / `suspended` / `cancelled`）。

关键约束：

- `operating` 的项目必须已在存量装置层录入，否则会漏计
- 反过来，存量已录了装置的项目，**不得在增量预测里再算一次**
- 净新增 = 规模 − 置换退出；置换未披露 → `net = null`，标「待确认」
- 加权情景只作参考，必须标注

## 常见返工原因

| 症状 | 根因 | 预防 |
|---|---|---|
| 集团总量虚高一倍 | 集团 + 子公司重复加 | 建骨架时就定好归属链 |
| 全国总量对不上 | 口径混用 | 第 1 步写死口径 |
| 地图气泡重叠严重 | 坐标只到城市级 | 尽量取园区级坐标，标注精度 |
| 工艺占比离谱 | 把 unknown 硬归了类 | 未核实就单列 |
| 增量预测偏高 | 没扣置换 | R11 校验 |
| 交付后被质疑数字 | 没有来源与可信度 | 每行带 source_id + confidence |
