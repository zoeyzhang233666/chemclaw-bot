# 化工品生产企业与产能分布调研

## 这个技能解决什么问题

用户要回答「这个产品谁在做、在哪做、能做多少」。表面是一张企业名单，实质是一道**归属与口径**题：
同一批产能会被集团、上市公司、子公司、基地、装置五个层次反复计数；同一句「产能」可能是
设计产能、核定产能、有效产能或实际产量；同一年的全国总量在不同机构手里相差几十万吨到上百万吨。

做错的方式高度雷同：

- 把集团总量和它旗下上市公司的产能相加 → **重复统计**，虚增一倍
- 把「计划产能」「环评产能」「已投产产能」混在一个总数里
- 用「全国总产能 = 我找到的几家企业之和」交差
- 把停产、破产、已注销主体的产能算进在产供给
- 遇到没披露的数字就按行业均值补一个 → **编造**

这个技能的产出必须能扛住反问：「这个 260 万吨是哪份文件哪一页？含不含糊树脂？这家厂算在哪个集团？」

## 什么时候用

触发场景（任一命中即可）：

- 「整理【某产品】在中国的生产企业和产能」「产能分布」「主要生产企业有哪些」
- 「XX 集团有多少产能」「哪几个厂」「装置多大、哪年投产」
- 「在建/拟建/扩产项目有哪些，什么时候投产」
- 「行业集中度多少」「CR5」「前几家占多少」
- 「产能统计口径含不含联产/副产/长期停产/不同牌号」
- 期货研究里的「供给端梳理」「产业基本面」「上游产能」

**不适用**：只问价格行情（用 `chem-market-brief`）、只找下游客户（用 `b2b-lead-sourcing`）、
只看某个区域的市场机会（用 `chemical-region-market-map`）。

## 核心方法论：四层归属链

**任何产能数字，必须能唯一地落在一条链上：**

```
装置 (unit)  →  基地 (plant)  →  法人 (entity)  →  集团 (group)
```

- **装置**是唯一事实层：一行 = 一个装置的一条产能事实（产品、等级、规模、口径、工艺、投产年、状态、来源）
- **基地**是地理与园区层：一个法人可以有多基地，一个基地可以有多法人
- **法人**是法律主体层：统一社会信用代码、控股关系、是否上市
- **集团**是控制权层：实际控制人、集团性质

**加总规则**：沿链条**只加一次**。

- 集团合计 = Σ 该集团全部法人的全部基地的全部装置 —— 加了集团就**不能**再加子公司
- 报「集团口径」时说清是集团还是上市主体（两者常常差一倍，见 `references/04_enterprise_group_traps.md`）
- 只统计 **同一口径（basis）** 的装置；`design` 与 `actual` 绝不混在一个合计里

## 产能口径（basis）：四选一，不许混

| 值 | 中文 | 含义 | 典型来源 |
|---|---|---|---|
| `design` | 设计产能 | 装置设计规模，最常用于行业统计 | 年报「产能情况」表、环评批复、项目备案 |
| `approved` | 核定/许可产能 | 政府许可上限 | 安全生产许可证、排污许可、产能置换公告 |
| `effective` | 有效产能 | 扣除长期停车、检修、去瓶颈后的可用产能 | 少有公开披露，多为券商/协会测算 |
| `actual` | 实际产量 | 当年实际产出，不是产能 | 年报「产量」、统计局产量 |

**报告必须展示口径并列，不取平均。** 全国总量出现多个数字时，列表说明各自定义与年份差异，
由用户判断——不要替用户选一个「最对的」然后悄悄用它当分母。

## 工艺路线（route）：四选一

`carbide`（电石法/乙炔法）、`ethylene`（乙烯法，含煤制烯烃乙烯法）、`mixed`、`unknown`。

**未核实的工艺必须单列 `unknown`，不并入任何一类。** 工艺占比是很多品种的核心分析维度
（成本曲线、政策风险、能耗双控），猜错会带偏整篇结论。

## 可信度分级

| 级 | 含义 | 例子 |
|---|---|---|
| **A** | 一手文件原文 | 上市公司年报/公告、评级报告、环评公示、安全生产许可、协会统计 |
| **B** | 权威二手 | 主流财经媒体转引一手、券商深度报告、政府通稿 |
| **C** | 一般二手 | 行业资讯网站、百科、行业盘点文章 |
| **D** | 未核实/存疑 | 查不到出处、与一手矛盾、仅口口相传 |

**每条产能记录必须同时带 `source_id` 与 `confidence`。** C 级数字可以作为线索列入，
但不得进入核心结论；D 级只登记不采信。

## 执行步骤

### 第 1 步：先定口径与边界（30 分钟内必须做完，别跳过）

写下并让用户确认（或明确写进报告首页）：

1. **产品边界**：统计到哪个层级？纯粉算不算糊树脂？含不含共聚树脂/氯化聚氯乙烯？
   （PVC 的例子：行业口径 2,993–3,088 万吨含糊树脂 162–164.5 万吨，只算纯粉会差 5%）
2. **主体边界**：含境外产能吗？含在建吗？含已停产未注销吗？
3. **基准年**：通常取最近一个完整财年；跨年数据必须标年份
4. **样本策略**：优先覆盖大集团 + 高集中度省份，明确写出覆盖率

### 第 2 步：建企业名录（先建骨架，再填数）

按四层链建骨架，**产能先留空**：

1. 从行业榜单/协会统计/多份年报的「同业竞争」「主要竞争对手」段落拿到集团名单
2. 每个集团拆到法人（用年报「主要子公司」表、发行文件释义表）
3. 每个法人拆到基地（用年报「主要生产基地」、环评、政府园区公示）
4. 骨架完成后再逐装置填产能

**为什么先骨架**：先填数会在发现归属错误时全部返工；骨架对了，数字只是补洞。

### 第 3 步：逐装置取数（一手优先）

取数顺序（硬性）：

1. **巨潮资讯网 / 交易所公告**的年报「产能与开工情况」表 —— 最优先
2. 评级报告（中诚信、联合资信、大公）—— 会列单体企业产能与利用率
3. 环评公示、项目备案、产能置换公告 —— 装置级细节
4. 安全生产许可证、排污许可 —— 核定产能
5. 协会统计（中国氯碱工业协会、氮肥协会等）
6. 券商深度报告、行业媒体 —— 只用于补齐与交叉验证

**原文照录**：`capacity_note` 字段存原文表述，不要改写。原文写「约」「超」「预计」就保留。

### 第 4 步：跑重复统计校验（不许跳过）

用 `build/pcd_model.py` 里的 `DupChecker`，14 条规则覆盖：

- R1/R2 孤儿装置与孤儿基地（归属链断裂）
- R3 坐标缺失
- R4 同基地同口径同工艺同产品的疑似重复装置
- R5 口径混用
- R6 来源缺失
- R7 产能缺失（保留为未知，**不得估算**）
- R8 工艺未核实
- R9 集团级与装置级双重计数
- R10 项目与存量装置重复
- R11 置换未扣减
- R12 量纲异常（吨 vs 万吨）
- R13 可信度与来源等级不符
- R14 名称碰撞（同一主体两个 ID）

**ERROR 必须清零才能交付。WARN 必须逐条在报告里说明。**
典型真实告警（本技能用 PVC 实跑出来的）：

```
[WARN] R11 PR01 项目「年产96万吨PVC」的置换情况为「未查到置换方案」但未填写 retired_capacity
[WARN] R10 PR09 项目「广西华谊二期40万吨」阶段为已运行，请确认存量装置已录入且不在增量中重复计
[INFO] R13 U-P041-01 自评 B 与来源 A 不一致（安全许可未单列该产品条目，人工降级）
```

### 第 5 步：算集中度与覆盖率

- **CRn / HHI 必须在同一分母下计算**（同一口径、同一来源范围）
- 同时给**集团口径**和**法人口径**——两者差异本身就是结论
- **覆盖率 = 样本合计 ÷ 全国口径**，写在报告首页。覆盖率低于 70% 时，CRn 会系统性低估，
  必须在图表下标明
- 永远不要写「全国总产能 = Σ 样本」

### 第 6 步：分离增量

在建/拟建不能和存量混在一个合计里。

- 分阶段：备案 → 环评 → 在建 → 试车 → 爬坡 → 已投产
- **净新增 = 规模 − 置换退出**。置换退出未披露时，净增记 `null`，标注「待确认」，不进基准预测
- 加权情景（在建 0.85、试车 0.95、环评 0.45、备案 0.25、拟建 0.10）只能作为**情景参考**，
  必须标注「不是预测」

### 第 7 步：出交付物

见 `references/05_output_spec.md`。两份：交互式 HTML + Excel。

## 交付物结构

### HTML（单文件、零外部依赖、可离线打开）

七个页签：

1. **全景** —— KPI + 集团比较 + 工艺构成 + 省级分布 + 区域结构 + 产品等级
2. **产能地图** —— 省份轮廓 + 基地气泡（面积∝产能，颜色=工艺），点省份筛选，点气泡看抽屉
3. **企业与集团** —— 集团→法人→基地→装置 关系树
4. **装置明细** —— 唯一事实层，可切口径
5. **在建拟建** —— 项目流水线 + 年度增量图 + 项目时间线抽屉
6. **口径与校验** —— 全国口径并列表 + 集中度 + 统计口径说明 + 校验结果
7. **数据与来源** —— 来源清单 + 数据缺口清单

硬性要求：

- 口径切换器（设计/有效/核定/实际）**不允许跨口径相加**
- 每个产能数字旁有来源编号与可信度标签
- 缺失数据显示「—」或「未知」，**不显示 0**
- 打印友好

### Excel（19 个工作表）

`00_封面` `01_口径与样本范围` `02_核心结论` `03_集团汇总` `04_法人汇总` `05_基地清单`
`06_装置明细` `07_区域汇总(省)` `08_区域汇总(市)` `09_工艺路线汇总` `10_产品等级汇总`
`11_在建拟建项目` `12_新增净额还原` `13_重复统计校验` `14_汇总公式与溯源` `15_口径对比`
`16_数据缺口` `17_来源清单` `18_企业集团关系树`

## 硬性红线

1. **禁止编造估算值**。没找到就写「数据缺口」，登记进 `16_数据缺口` 表。
2. **禁止跨口径相加**。design 与 actual 不能进同一个合计。
3. **禁止集团 + 子公司重复计数**。
4. **禁止把样本合计称为全国产能**。必须报覆盖率。
5. **禁止把毛新增当净新增**。置换未扣减要标「待确认」。
6. **禁止用产量反推产能**。超产（利用率>100%）普遍存在，反推会低估。
7. **禁止把停产/破产/已注销主体计入在产**。单列状态，单独说明。
8. **工艺未核实就写 unknown**，不要按「看起来像」归类。

## 与其它技能的配合

- 需要价格与利润 → `chem-market-brief`
- 需要区域拜访优先级 → `chemical-region-market-map`
- 需要下游客户名单 → `b2b-lead-sourcing`
- 需要用新建项目找客户 → `project-lead-sourcing`

本技能的产能数据库可以直接作为上面几个技能的上游输入（谁在哪、能做多少）。
