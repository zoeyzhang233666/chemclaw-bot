# 交付前自检清单

> 逐项打勾。任何一项「否」，都不要交付。

## 一、口径

- [ ] 产品边界已写明（含不含特种牌号/糊树脂/共聚物）
- [ ] 主体边界已写明（含不含境外、在建、已停产未注销）
- [ ] 基准年已标注
- [ ] 报告首页有「全国多套口径并列」的说明，且**没有取平均**
- [ ] 用于计算覆盖率的分母已说明来自哪个机构
- [ ] 所有汇总都是**同一 basis**，没有 design 与 actual 混算

## 二、归属链

- [ ] 装置 → 基地 → 法人 → 集团，四层都能对上
- [ ] 集团合计**没有**再加子公司
- [ ] 集团口径与上市主体口径已分别标注
- [ ] 已注销/被吸收合并的法人没有被单独录产能
- [ ] 分公司与母公司的产能没有重复
- [ ] 名字相近的不同主体没有被合并
- [ ] 不产目标产品的关联法人没有被误录

## 三、数据质量

- [ ] 每条产能记录都有 `source_id`
- [ ] 每条产能记录都有 `confidence`（A/B/C/D）
- [ ] 缺失数字是 `null`/「—」，**不是 0，也不是估算值**
- [ ] 没有任何「按基地数量平摊」「按行业均值补齐」的操作
- [ ] 没有用产量反推产能
- [ ] 原文表述保留在 `capacity_note`（含「约」「超」「预计」等限定词）
- [ ] 工艺未核实的记为 `unknown`，没有硬归类

## 四、增量

- [ ] 在建/拟建与存量**没有**混在一个合计里
- [ ] 已投产项目在装置层有对应记录
- [ ] 毛新增与净新增已区分
- [ ] 置换未披露的项目，净增记 `null` 并标注「待确认」
- [ ] 加权情景标注了「不是预测」

## 五、校验

- [ ] `python build/assemble.py` 的 **ERROR = 0**
- [ ] 每条 WARN 都有处置说明（改数据 / 说明理由）
- [ ] INFO 已扫阅，有价值的写进报告备注
- [ ] R4（疑似重复装置）逐条确认过
- [ ] R10（项目与存量重复）逐条确认过
- [ ] R11（置换未扣减）逐条确认过

## 六、HTML

- [ ] 双击可打开，断网可看
- [ ] 控制台**无 JS 异常**
- [ ] KPI 显示真实数字（不是「—」/「加载中」）
- [ ] 七个页签都有内容（无空 div）
- [ ] 地图气泡数 = 有坐标且有产能的基地数
- [ ] 省份轮廓完整（31 个省级行政区）
- [ ] 切换口径后数字变化正确，且不跨口径相加
- [ ] 集团/省份/工艺/状态筛选都能联动
- [ ] 点集团 → 抽屉出关系树
- [ ] 点基地气泡 → 抽屉出装置明细
- [ ] 点项目 → 抽屉出时间线
- [ ] 每个产能数字旁有来源编号与可信度
- [ ] 有打印样式

## 七、Excel

- [ ] 19 张表齐全
- [ ] 每个产能源行有来源编号
- [ ] 14_汇总公式与溯源 表填写完整（每个汇总值能追到公式）
- [ ] 15_口径对比 表列出了所有全国口径
- [ ] 16_数据缺口 表非空
- [ ] 至少 3 个原生图表
- [ ] 表头冻结、列宽合理、长文本换行

## 八、结论

- [ ] 核心结论每条都带具体数字
- [ ] 每条结论都能追溯到具体来源
- [ ] 没有把「样本合计」说成「全国总产能」
- [ ] 明确写了「本报告覆盖 X 家、覆盖率 Y%」
- [ ] 数据缺口清单已如实呈现

## 九、交付说明

- [ ] 已告知用户：样本覆盖范围与覆盖率
- [ ] 已告知用户：采用的全国口径与其余口径的位置
- [ ] 已告知用户：哪些关键数字是未知的
- [ ] 已告知用户：校验结果（ERROR 0 / WARN 数及处置）

---

## 快速命令

```bash
# 1. 合并分片 + 自检 + 校验
python build/assemble.py --emit

# 2. 生成 HTML
python build/render_html.py --data data/final.json --out output/report.html

# 3. 生成 Excel
python build/build_excel.py --data data/final.json --out output/detail.xlsx

# 4. 验证 HTML 运行时
node build/cdp_check.js "file:///.../output/report.html"
```
