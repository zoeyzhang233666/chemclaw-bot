# 实例：中国 PVC（聚氯乙烯）生产企业与产能分布（2025 年度）

这是一个**完整跑通**的实例，可作为任何化工品产能梳理的参照。

## 一句话结论

中国 PVC 已进入**结构性过剩 + 工艺路线切换**阶段：在册产能约 2,932–3,088 万吨
（多套口径并列），行业开工率仅 74%，CR5 仅约 38%（集团口径），
2020 年后退出产能全部为电石法，新增产能则以乙烯法为主。

## 如何复现

```bash
cd build

# 1. 合并分片 + 自检 + 校验
python assemble.py --emit

# 2. 生成 HTML
python -c "
import sys; sys.path.insert(0,'.')
from pcd_model import load, DupChecker
from render_html import render
d = load('../data/final.json')
fs = DupChecker(d).run()
checks=[{'rule':f.rule,'severity':f.severity,'subject':f.subject,'message':f.message,'fix':f.fix} for f in fs]
render(d, '../output/report.html', checks)
"

# 3. 生成 Excel
python -c "
import sys; sys.path.insert(0,'.')
from pcd_model import load, DupChecker
from build_excel import build
d = load('../data/final.json')
build(d, '../output/detail.xlsx', DupChecker(d).run())
"
```

## 本实例验证出的关键结论

### 一、全国产能有七套口径，极差 156 万吨

| 口径 | 数值（万吨） | 来源 |
|---|---|---|
| 商务部 | 2,962 | 政府口径 |
| 中盐内蒙古化工年报 | 2,932 | 电石法 2,055 + 乙烯法 877 |
| 中国氯碱工业协会 | 2,993 | 净增 205 万吨 |
| 华经产业研究院 | 3,017 | 电石法 72.61% |
| 国金证券（百川盈孚） | 3,038 | — |
| 宁夏英力特年报 | 3,087.5 | 含糊树脂 164.5 |
| 北元集团年报（转引氯碱网） | 3,088 | 含糊树脂 162 |

**同一年的「净增」也有 137 与 205 两个数**——不是同年同口径，禁止混用。

### 二、三处被广泛误引的数字，本报告已修正

1. **「3,088 万吨，中国氯碱网」**——3,038 是百川盈孚，2,993 才是氯碱协会。
2. **「在建 8 个项目 370 万吨」**——出自标普全球分析师会议表述，未公布名单。
   逐条落到书面来源仅 **226 万吨**，缺口 144 万吨无公开项目对应。
3. **「2025 年新增产能 84.3% 为乙烯法」**——这是含改扩建的「新增产能」口径。
   2025 年实际投产装置中，陕西金泰 60 万吨 + 甘肃耀望 30 万吨 = **90 万吨是电石法**。

### 三、最典型的归属陷阱：天业集团 vs 新疆天业

- 新疆天业股份有限公司（600075）：PVC **134 万吨**
- 新疆天业（集团）有限公司（控股股东，非上市）：宣传口径 140 万吨
- 集团在十户滩代建 50 万吨 PVC 项目（上市公司不投资，仅享优先购买权）

若把「集团 140」和「上市公司 134」各录一条 → 合计 274 万吨，虚增一倍。
若把十户滩 50 万吨计入上市公司 → 184 万吨，同样是错的。

### 四、工艺路线反转

- 电石法占比：样本 63.8%，全国约 70%（视口径）
- 2020 年后**退出的全部是电石法**；2025 年新增产能中乙烯法占 84.3%
- 但**「乙烯法 = 低成本」不成立**：浙江镇洋（纯外购乙烯）2026H1 PVC 毛利率 **-23.24%**，
  2026-09-19 起临时停产；成本优势取决于**一体化程度**，不是工艺路线本身

### 五、成本结构差异

同为电石法，成本地位完全不同：

- **自备电石**：中泰（电石自给）、北元（50 万吨电石）、君正（238.3 万吨）、
  鄂尔多斯电冶（配套）、亿利（64 万吨）、英力特（40 万吨）
- **电石全外购**：宜宾天原（2025 年电石采购 26.52 亿元，占成本 15.54%）
  → 不属于「西北电石一体化低成本」象限

### 六、真实存在的供给退出

- **鸿达兴业/内蒙古乌海化工**：110 万吨，2023-10 破产重整，2024-04 集团破产，
  股票已股债双退，2026-03 再被受理重整 → 标 `shutdown`
- **湖北宜化**：2025 年部分 PVC 装置永久关停（吨数未披露）
- **天津渤化**：原电石法随「两化」搬迁淘汰，改乙烯法 120 万吨
- **宁夏英力特**：2026-09-22 起 PVC 线临时停产（价格不及预期，连亏四年）
- **浙江镇洋**：2026-09-19 起临时停产 ≤4 个月

## 复用到其它产品的步骤

1. 复制整个 `build/` 目录到新项目
2. 按 `templates/dataset_schema.json` 建 `data/` 分片（先建骨架，产能留空）
3. 改 `assemble.py` 里的 `REGION_MAP`（如产品出口依赖沿海，可调整为「沿海/内陆」分区）
4. 改 `render_html.py` 里的 `REGION_MAP` 与 `ROUTE_LABELS`（工艺枚举按产品替换）
5. 改 `assets/style.css` 里的工艺配色变量
6. 跑 `assemble.py` → `render_html.py` → `build_excel.py`
7. 按 `templates/checklist.md` 逐项自检
