## 各品种的工艺路线与关键区分维度

| 品种 | 工艺路线枚举 | 必须额外的区分维度 |
|---|---|---|
| **甲醇** | 煤制 / 天然气制 / 焦炉气制 / CO2加氢 / 矿热炉尾气 | 是否配套 MTO / 是否配套乙醇 |
| **尿素** | 煤制 / 天然气制 / 焦炉气制 | 限气敏感性（冬季气头停产）、出口法检 |
| **纯碱** | 氨碱法 / 联碱法 / 天然碱 | 副产品氯化铵（联碱法经济性）、重质/轻质 |
| **PVC** | 电石法 / 乙烯法 | 电石供应、烧碱联产（氯碱平衡） |
| **PTA** | PX 法（唯一） | 是否配套聚酯、加工费区间 |
| **乙二醇** | 乙烯法 / 煤制（合成气） | 油头 vs 煤头成本分化 |
| **烧碱** | 离子膜法 / 隔膜法 | 液碱 vs 固碱、氯碱平衡 |
| **玻璃** | 浮法 / 光伏 / 超白 | 日熔量（吨/日）而非万吨/年 |
| **碳酸锂** | 锂辉石 / 锂云母 / 盐湖 / 回收 | 是否配套自有矿 |
| **工业硅** | 矿热炉 | 电价敏感性、枯水期 |
| **PP/PE** | 油制 / 煤制 / PDH / 轻烃 | 新装置投产节奏是主要变量 |
| **苯乙烯** | 乙苯脱氢 / PO-SM | 一体化程度 |

### 关键差异：产能单位不是万吨/年

| 品种 | 单位 | 处理 |
|---|---|---|
| 玻璃 | 吨/日（日熔量） | `capacity_wt` 存"万吨/年"折算值，`capacity_note` 注明原始日熔量 |
| 电解铝 | 万吨/年 | 正常 |
| 部分精细化工 | 吨/年 | 折算为万吨 |

**统一原则**：`capacity_wt` 一律存"万吨/年"，原始口径写进 `capacity_note`。`calc_impact.py` 内部按 `capacity_wt × 10000 / 365` 得日产能，因此单位必须严格是万吨/年。

## 换品种时的"陷阱清单"

每个品种都有自己的经典误读。建台账前先列出 5 个：

### 甲醇（已收录）
1. MTO 停车 ≠ 甲醇停车（斯尔邦 80 万吨 MTO vs 10 万吨甲醇）
2. 流拍 ≠ 停车（兖矿榆林 10/15 竞拍全流拍，装置运行平稳）
3. 一期停 ≠ 二期停（新奥一期检修 vs 二期长停）
4. 配套装置同步检修 ≠ 同一装置（凯越甲醇 70 vs 乙醇 50）
5. 焦炉气制 ≠ 天然气制（赤峰博源 15 vs 远兴博源 100）

### 尿素（示例）
1. 气头冬季限气 ≠ 检修（是政策性降负荷，事件类型应记为`降负荷`）
2. 装置检修 ≠ 减产（部分企业有库存缓冲）
3. 新增产能投产 ≠ 供应增量（转产/试车期不计）
4. 车用尿素/工业尿素分流 ≠ 农用供给减少
5. 出口法检/配额 ≠ 装置停车（是流通端）

### 纯碱（示例）
1. 联碱法检修常与氯化铵同步，但记录时只算纯碱侧
2. 天然碱成本低，其检修对价格影响权重不同于氨碱
3. "检修"与"降负荷"要分清（纯碱常降负荷运行）
4. 光伏玻璃点火 ≠ 纯碱需求立即增加（有爬坡）
5. 期现套保库存 ≠ 装置产能

### PVC（示例）
1. 电石法检修常因电石供应紧张而非计划
2. 氯碱平衡：烧碱利润好时 PVC 可能被迫高开工
3. 乙烯法检修与乙烯裂解装置检修联动
4. 出口订单 ≠ 国内供给
5. 社会库存高时检修对价格影响被削弱

## 新增一个品种的实操步骤

```bash
# 1. 复制甲醇案例作为骨架
cp -r skill/examples/methanol-cn-2026q4 case/

# 2. 改 datum.json（品种名、窗口、分母）
# 3. 清空并重建 units.json（该品种装置档案）
# 4. 清空并重建 status_events.json / planned_events.json
# 5. 改 companies.json 的 process_routes 与 regions

# 6. 跑引擎看量级是否合理
CASE_DIR=case python skill/scripts/calc_impact.py

# 7. 出交付物
CASE_DIR=case python skill/scripts/build_excel.py
CASE_DIR=case python skill/scripts/build_html.py
```

### 量级合理性自检

新品种第一次跑出来，用这个公式判断有没有错：

```
国内确认减产 / 窗口内全国理论产能 应该落在 0.5% ~ 8%
```

- < 0.3%：可能漏了大量事件，或把阈值设得太严
- > 15%：可能重复计算，或把长期停车/传闻算进去了

以甲醇为例：`70.84 / 2547.9 = 2.78%`，落在合理区间。

## 不要改的部分

- **四条公式**：数学上是恒等式，改了就错
- **三个口径隔离**：domestic / overseas / unconfirmed 的分离逻辑
- **去重键**：`unit_id + event_family + 时间重叠`
- **七类事件类型**：语义清晰且覆盖完整
- **置信度三档**：official / industry / rumor
- **"不输出价格结论"红线**

## 什么时候需要扩展代码

| 场景 | 需要加什么 |
|---|---|
| 品种有"产能置换"（如 PVC、水泥） | 新增事件类型 `产能置换`，并处理"新旧产能不同时存在" |
| 品种有"政策性限产"（如尿素限气、工业硅枯水期） | 新增 `政策性限产`，`downtime_load` 按实际负荷 |
| 装置有"轮检"（多条线轮流检修） | 按产线拆分 `unit_id`，分别建事件 |
| 需要跟踪库存 | 在 `datum.json` 加 `inventory_series`，HTML 加一张图 |
| 需要对比多品种 | 复制 `case/` 为 `case-{品种}/`，用 `CASE_DIR` 切换 |
