# 05 · 证据渠道与抓取策略

这一节是本技能最"实操"的部分。装置级事实的可得性因站点而异，以下是 2026 年 10 月对**甲醇**实测的结论，换品种时结构可复用。

---

## 渠道优先级

| 级别 | 渠道 | 可信度 | 装置细节颗粒度 | 抓取难度 |
|---|---|---|---|---|
| 1 | 企业公告（巨潮/交易所/官网） | `official` | 高（但少写具体检修日） | 易 |
| 2 | **专业机构日评/装置汇总表**（隆众、金联创） | `industry` | **最高** | 部分付费墙 |
| 3 | **生意社 PriceSeek / 商品情报** | `industry` | 高（免费全文） | 易 ⭐ |
| 4 | **化销网装置动态/竞拍快讯** | `industry` | 高（逐日状态） | 易 ⭐ |
| 5 | 期货公司研报（华泰、东吴、国贸、正信等） | `industry` | 中（装置清单+开工率） | 易 |
| 6 | 财经媒体转载（新浪、东财、搜狐） | 旁证 | 中 | 易 |
| 7 | 社媒/股吧/财富号 | `rumor` | 低 | 易 |

**结论：优先把 2/3/4 打满，再用 1 和 5 交叉验证。**

---

## 各站点实测（甲醇，2026-10）

### ⭐ 生意社 —— 性价比最高的装置事实源

| 入口 | URL 模式 | 可得内容 |
|---|---|---|
| 商品动态列表 | `https://www.100ppi.com/news/list-14--397-{page}.html` | 甲醇全部资讯标题+日期，可翻页 |
| 文章详情 | `https://www.100ppi.com/news/detail-{YYYYMMDD}-{id}.html` | **全文免费**，含装置产能与状态 |
| **商品情报** | `https://m1.100ppi.com/news/intelligence_filter-pid-397` | 近 5 日逐条装置快讯（最浓缩） |

**情报页是本案例最有价值的发现**：每天 5–8 条，形如

```
10月14日 兖矿集团甲醇竞拍情况：兖矿国宏64万吨/年煤制甲醇装置双炉运行中。
榆林兖矿一期60万吨、二期80万吨均运行平稳。
10月16日 内蒙古新奥：一期60万吨运行平稳，二期60万吨自7月1日停车至今，恢复时间待定。
文莱BMC 85万吨/年甲醇装置已重启恢复正常负荷运行。
```

**抓取要点**：
- 列表页正则：`<a href="(https://www\.100ppi\.com/news/detail-\d{8}-\d+\.html)"[^>]*>(.*?)</a>\s*<span>(\d{4}-\d{2}-\d{2} \d{2}:\d{2})</span>`
- 详情页正文：`<h1>` 之后到 `【版权声明】` 之前的 `<p>` 段落
- 情报页只有第一页有效，`-2`/`-p2` 返回空壳 → **需滚动重抓积累时序**

### ⭐ 化销网 —— 逐日装置状态最细

| 入口 | URL |
|---|---|
| 甲醇资讯列表 | `https://www.huaxiaowang.com/index/quote/infolist?catid=13&page={n}` |
| 详情 | `https://www.huaxiaowang.com/index/quote/infoshow?id={id}` |

**内容形态**：`"新乡中新30万吨/年甲醇装置已重启，负荷提升中。"`、`"榆林煤化（凯越）70万吨/年煤制甲醇装置目前重启中，预计10月初产出产品，该项目于9月4日展开此次检修。"`

**抓取要点**：
- 列表正则是相对链接：`href="(/index/quote/infoshow\?id=(\d+))"[^>]*>(.*?)</a>.*?<span[^>]*>(\d{4}-\d{2}-\d{2} \d{2}:\d{2})</span>`
- 详情正文：`发布时间：` 之后到 `化销网资讯` 之前
- 单页 20 条，**翻 40 页可覆盖约 2 个月**；需多次运行积累更长时序
- 平台自注"信息由相关企业自行提供，真实性未经证实" → 仍归 `industry`（企业报价系统），但**关键结论应由第二来源印证**

### 隆众（经我的钢铁网转载）—— 装置汇总表最完整

| 入口 | 可得性 |
|---|---|
| `https://www.oilchem.net/26-{MMDD}-{..}.html` | ❌ 付费墙，正文抓不到 |
| `https://nenghua.m.mysteel.com/a/{YYMMDDHH}/{HASH}_abc.html` | ⚠️ 仅首段可抓，表格被截断 |
| `https://nenghua.mysteel.com/a/{YYMMDDHH}/{HASH}.html` | ⚠️ 同上，且常 404 |

**但从 Exa 检索摘要中能拿到完整的表格首行链**，形如：

```
省份 企业简称 产能（万吨/年） 装置动态
榆林兖矿榆林能化 140 一期+二期装置运行平稳
陕西神木 60 20万吨装置+40万吨装置运行平稳
榆林凯越 70 9月4日停车检修，为期25天，下游配套乙醇同步检修
陕西奥维乾元 20 8月29日停车检修，预计30天左右
内蒙久泰（托县） 200 装置稳定生产
内蒙新奥 120 一期于9月4日停车检修，预计9月23日逐步重启；二期……
```

**策略：用 `advanced_search(engine="exa")` 定向检索"隆众 西北/华北/华东/华中/西南 大区甲醇装置汇总 {月份}"，从摘要提取事实，再用其他渠道印证。**

隆众的分区体系（可直接作为 `regions` 模板）：

```
西北（内蒙古、榆林）｜西北（新疆、宁夏）｜华北（山西）｜华北（河北、天津）
华东（山东鲁中/鲁北/鲁东）｜华东（山东南部、江苏北部）｜华东（江苏、上海）
华东（安徽）｜华中（河南、湖北、湖南、江西）及关中
西南（四川、重庆、云南、贵州、广西、青海）｜华南（海南）｜东北（黑龙江）
```

另有日度《[损失量]：中国甲醇装置检修数据统计（YYYYMMDD）》——**这是行业标准口径的检修损失量表**，但同样在付费墙后，只能作为方法论参照。

### 金联创

- 列表可抓：`https://chem.315i.com/cmlc/3-7-1-qydt-zzdt`
- 详情页返回 `HTTP 507`（付费）→ **只用列表标题做线索**（如"9月22日山西孝义鹏飞甲醇装置停车"）

### 期货公司研报 / 期货日报

- 常含"装置清单 + 产能 + 开工率"，如东吴期货 2026-09-16 的 MTO 装置清单
- 可从新浪财经、东方财富、慧博、发现报告获取
- 用途：交叉验证开工率与产能口径

### 微信公众号 / 新浪微博长文

- 常有"国内甲醇开工底部已现"这类汇总，含**检修产能合计、分月恢复节奏**（如"7-8月检修产能约2486万吨，9月上旬重启228万吨，另有247万吨延续至9月中下旬"）
- 归 `industry`（属机构观点转述），数字需标注"转述"

## 检索技巧

### 引擎选择

| 引擎 | 实测表现 |
|---|---|
| `exa` | **最有效**，返回内容含完整正文首段，最适合装置表 |
| `tavily` | 可用，但常混入非相关结果 |
| `bing` / `multi` | 噪声大，易被网站聚合页污染 |

**推荐调用**：

```python
advanced_search(
  engine="exa",
  maxResults=8,
  query="隆众 甲醇装置汇总 西北 内蒙古 榆林 产能 装置动态 停车检修 开车 2026年9月 新奥 国泰 久泰"
)
```

### 查询构造

把**品种 + 机构栏目名 + 大区 + 企业名 + 动作词 + 月份**拼在一起，比自然语句有效得多：

```
✅ "隆众 甲醇 装置汇总 华北 山西 产能 装置动态 停车 2026年9月 华昱 鹏飞 蔺鑫"
❌ "山西甲醇装置最近怎么样"
```

### 时间过滤

`advanced_search(timeRange="month", ...)` 可限定近一月，但**装置汇总常被反复转载**，宽时间范围反而更容易命中最新一期。

## 抓取实现（Python 标准库，无需 requests）

```python
import gzip, urllib.request, re

def get(url, timeout=25):
    req = urllib.request.Request(url, headers={
        'User-Agent': 'Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 '
                      '(KHTML, like Gecko) Chrome/124.0 Safari/537.36',
        'Accept-Encoding': 'gzip, deflate',
        'Accept-Language': 'zh-CN,zh;q=0.9',
    })
    with urllib.request.urlopen(req, timeout=timeout) as r:
        raw = r.read()
    if raw[:2] == b'\x1f\x8b':
        raw = gzip.decompress(raw)
    for enc in ('utf-8', 'gbk', 'gb18030'):
        try:
            return raw.decode(enc)
        except UnicodeDecodeError:
            continue
    return raw.decode('utf-8', 'replace')
```

**注意**：
- 不要依赖 `brotli`（常未安装）；请求头里只声明 `gzip, deflate`
- Windows 终端输出中文需 `sys.stdout.reconfigure(encoding='utf-8', errors='replace')`
- 文件读写统一 `encoding='utf-8-sig'` 读取、`encoding='utf-8'` 写入
- 站点间 `sleep 0.25~0.5s`，避免触发限流

## 证据留痕要求

每个来源必须记录：

```json
{
  "name": "化销网 装置动态",
  "date": "2026-09-28",
  "url": "https://www.huaxiaowang.com/index/quote/infoshow?id=191292",
  "quote": "榆林煤化（凯越)年产70万吨/年煤制甲醇装置目前重启中，预计10月初产出产品，该项目于9月4日展开此次检修"
}
```

- `quote` **必须是原文逐字引用**，不要改写、不要缩写
- `name` 要能区分栏目（"化销网 装置动态" vs "化销网 竞拍"）
- `date` 用**发布日**，不是采集日

## 采证完成度自检

- [ ] 每个大区至少有 1 个装置表来源
- [ ] 每套建档装置至少有 1 条带链接的原始来源

- [ ] 传闻类信息已单独标注，未混入确认事件
- [ ] 有开工率/周产量的第三方数据用作量级参照
