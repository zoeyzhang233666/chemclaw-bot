# 04 · 影响量计算口径

目标：把"装置产能"换算成"**实际减少的产量**"。核心纪律是**永远不要拿设计产能当减产量**。

---

## 四条公式

### 1. 停车 / 检修 / 意外故障

```
L = (产能 ÷ 365) × 窗口内停留天数 × (基准负荷 − 事件期负荷)
```

停车时 `事件期负荷 = 0`、`基准负荷 = 1.00`，简化为：

```
L = 产能 ÷ 365 × 天数
```

**算例 · 新奥一期 60 万吨，9/4–9/26 共 23 天**：

```
L = 60 × 10000 ÷ 365 × 23 × (1.00 − 0.00) = 37,808 吨
```

**算例 · 久泰托县 200 万吨，10/10–10/20（窗口内 11 天）**：

```
L = 200 × 10000 ÷ 365 × 11 = 60,274 吨
```

### 2. 降负荷

```
L = (产能 ÷ 365) × 天数 × (基准负荷 − 实际负荷)
```

**算例 · 四川达兴 20 万吨，负荷 45%，窗口内 41 天**：

```
L = 20 × 10000 ÷ 365 × 41 × (1.00 − 0.45) = 12,356 吨
```

> 关键：这里用的是**减产量系数 0.55**，不是 1.0。如果按全停算会得到 22,466 吨，虚高 82%。

### 3. 新增产能

```
A = (产能 ÷ 365) × 窗口内运行天数 × 爬坡负荷
```

**算例 · 荣信二期 90 万吨，7/31 点火，窗口内 82 天，爬坡负荷 0.85**：

```
A = 90 × 10000 ÷ 365 × 82 × 0.85 = 171,863 吨
```

> 新增产能**与检修损失分列，绝不相互抵销**。理由：检修损失是"确定的少产"，新增是"不确定的会产"，两者置信度完全不同，合并会掩盖不确定性。

### 4. 复产

```
不单独计算
```

理由：复产的"可恢复供应"已经在对应的停车事件里体现过（那段时间记为减产）。如果再算一次增产，等于把同一段扰动重复计入。

**输出中 `loss_t = 0`，并给出 `reason` 说明。**

## 参数取值规则

### `baseline_load`（基准负荷）

| 情形 | 取值 |
|---|---|
| 装置此前满负荷 | `1.00`（默认） |
| 此前就有限产/缺原料 | 按实际（需来源支持） |
| 无信息 | `1.00`，并在 `load_note` 说明 |

### `downtime_load`（事件期负荷）

| 事件类型 | 取值 | 依据要求 |
|---|---|---|
| `计划检修` / `实际停车` / `意外故障` | `0.0` | 无需额外依据 |
| `降负荷` 有数值 | 来源给出的数值 | ✅ 可用，进入确认口径 |
| `降负荷` 无数值（"低负荷"/"开工不满"） | 假设 `0.5` | ❌ 标 `load_assumed=true` + `exclude_from_confirmed=true` |

**为什么"低负荷"不能进确认口径**：负荷从 40% 到 80% 都是"低负荷"，减产量差 3 倍。用中值假设可以给出量级，但不能当成确认数据。

### `ramp_load`（新装置爬坡负荷）

| 阶段 | 取值 |
|---|---|
| 投料试车 | `0.3–0.5` |
| 刚出合格品 | `0.6–0.8` |
| 稳定运行 1–2 个月 | `0.85`（默认） |
| 达产 | `1.0`（需明确"满负荷"表述） |

**投产 ≠ 达产。** 现代煤化工大装置（如 280 万吨级）从投料到满产通常 3–6 个月。

## 天数计算

### 含首尾

```
days = (end_date − start_date).days + 1
```

9/4 到 9/26 = 23 天（含两端）。

### 窗口裁剪

事件若跨越窗口边界，只计算落在窗口内的部分：

```
s2 = max(start_date, window_start)
e2 = min(end_date, window_end)
days = 0 if e2 < s2 else (e2 − s2).days + 1
```

**算例 · 新奥二期 7/1 停车至今，窗口 7/20 起**：

```
实际停车 112 天，但窗口内只算 (10/20 − 7/20) + 1 = 93 天
L = 60 × 10000 ÷ 365 × 93 = 152,877 吨
```

### 结束日未知

按 `window_end` 处理，并在 `status_note` 与 `11_数据缺口与冲突` 里明确"恢复时间未定，影响量随停车时间线性增长"。

### 模糊时间表述

| 表述 | 取值 | 标注 |
|---|---|---|
| "7月下旬" | 7/25 | 推定 |
| "8月" | 8/1 | 推定，并给区间 |
| "上周" | 报道日 − 7 | 推定 |
| "近日" | 报道日 − 2 | 推定 |
| "为期 N 天"（无结束日） | 起始日 + N | 倒推 |
| "预计 N 天" | 起始日 + N，并注明"预计" | 倒推 |

**所有推定值必须在 `conflict` 或 `status_note` 里写明"推定"。**

## 三个口径隔离

```
domestic_confirmed  国内 + 可核验量        → 进"国产供给影响"合计
overseas            境外装置              → 只影响进口/到港，单独列示
unconfirmed         传闻/待核/假设负荷     → 单独列示，不进合计
stock_stop          窗口前已停/已拆除      → 单列，不算窗口内边际变化
```

**绝不能做的运算**：

- ❌ `国内减产 + 境外减产`
- ❌ `检修损失 − 新增产能`（应为分列展示）
- ❌ `确认合计 + 未确认合计`

## 分母与量级参照

| 指标 | 来源要求 | 用途 |
|---|---|---|
| 全国总产能 | 标注机构 + 日期 | 算"占窗口内理论产能比例" |
| 周产量 | 标注机构 + 周次 | 算"折合几周产量" |

**算例 · 甲醇 2026-07-20 ~ 10-20**：

```
国内确认减产 = 70.84 万吨
窗口内理论产能 = 10000 万吨 × 93/365 = 2547.9 万吨
占比 = 70.84 / 2547.9 = 2.78%

周产量参照 = 202.4 万吨/周
折合 = 70.84 / 202.4 = 0.35 周
```

这些数字**只说明量级**，不构成供应松紧判断。

## 敏感性处理

对参数不确定的事件，在 HTML 里给出区间：

| 不确定来源 | 处理 |
|---|---|
| 结束日未知 | 下端=已过天数；上端=预计结束日 |
| 负荷无数值 | 中值假设 + 上下界（40%~60%） |
| 爬坡负荷 | 0.80~0.90 区间 |
| 产能两口径 | 取下限计算，注明上限（如渭化 40 vs 46 万吨） |

`calc_impact.py` 返回的 `loss_upper_t` 给出"假设全停的天数 × 日产能"作为上界，便于对照。
