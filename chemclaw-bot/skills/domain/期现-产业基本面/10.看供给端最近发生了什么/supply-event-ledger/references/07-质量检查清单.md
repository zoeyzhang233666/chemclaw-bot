# 07 · 质量检查清单

交付前逐项打勾。任何一项不过，不要交付。

---

## A. 事实层

- [ ] 每套装置有唯一 `unit_id`，且能对应到一个具体生产基地
- [ ] 同一企业的不同基地、不同分期已拆分建档
- [ ] 上游原料装置与下游加工装置未混为一谈（MTO/乙醇/烯烃等）
- [ ] 每个事件的产能有来源支撑，冲突口径已在 `capacity_note` 标注
- [ ] 每条事件至少 1 个带 `url` 的 `sources` 条目
- [ ] `quote` 为原文逐字引用，未改写
- [ ] 来源 `date` 为发布日，且 ≤ `as_of`
- [ ] 单装置 ≥ 50 万吨的重大事件有 ≥ 2 个独立来源

## B. 去重层

- [ ] 同一装置同一事件的多源报道已合并为一条
- [ ] `dedupe_check` 字段已填写，能说明合并/不合并理由
- [ ] 计划日与实际执行日未各立一条
- [ ] 停车与复产未各算一次影响量
- [ ] 同名不同装置（不同产品/产能）未合并
- [ ] 集团模糊表述（"伊朗多套装置"）未与可拆分表述重复登记

## C. 分类层

- [ ] 七类事件类型使用正确（计划检修/实际停车/意外故障/复产/降负荷/新投产/试车）
- [ ] `复产` 类未计入减产量
- [ ] `新投产`/`试车` 与检修损失分列，未相互抵销
- [ ] 工艺路线已区分（煤制/天然气制/焦炉气制/其他）
- [ ] 大区划分与来源体系一致

## D. 计算层

- [ ] 所有减产量使用 `产能/365 × 天数 × (基准负荷−事件期负荷)`，非直接取产能
- [ ] 降负荷事件使用了实际负荷系数，非按全停计算
- [ ] 天数含首尾，跨窗口事件已按窗口裁剪
- [ ] `baseline_load` 与 `downtime_load` 语义未混用（停车类 `downtime_load=0`）
- [ ] 新增产能已乘爬坡负荷，且未与损失相抵
- [ ] 缺少负荷数值的降负荷事件已标 `load_assumed` 并排除出确认口径
- [ ] 推定日期（"7月下旬""为期20天"）已标注
- [ ] 结束日未知的事件按窗口末日计算并说明

## E. 口径隔离层

- [ ] 境外装置（`scope=overseas`）未并入国产供给合计
- [ ] 传闻（`confidence=rumor`）未进入任何确认合计
- [ ] 窗口前已停车（`stock_stop`）单列，未计入窗口内边际变化
- [ ] 未确认/待核事项单独列示，未与确认合计相加
- [ ] 检查 `家底`：`国内确认 + 境外 + 未确认 + 存量` 四类互斥且完备

## F. 时间层

- [ ] 所有已发生事件 `start_date` 落在窗口内，或已标 `starts_before_window`
- [ ] 未来事项（`planned_events.json`）**没有**出现在已发生合计中
- [ ] 未来事项有 `planned_window`（当点估计不可靠时）
- [ ] 未来事项的 `potential_supply_wt` 未参与计算

## G. 表达层

- [ ] 报告明确说明"不构成供应预警/价格判断/交易建议"
- [ ] 每个数字可追溯到具体装置 + 日期 + 来源
- [ ] 缺失数据标注为缺口，而非估算填充
- [ ] 参数假设（爬坡负荷、低负荷中值）已明示
- [ ] 限制条件（推定日期误差、产能口径冲突）已列出

## H. 技术层

- [ ] `python skill/scripts/check_xlsx.py` → PASS
- [ ] `python skill/scripts/check_html.py` → PASS
- [ ] `node skill/scripts/check_html_runtime.js <html>` → PASS
- [ ] Excel 各汇总 Sheet 合计 == 引擎合计（误差 < 1 吨）
- [ ] HTML 单文件可离线打开（ECharts 已内联，无外链依赖）
- [ ] HTML 图表实际渲染出数据（非空白画布）
- [ ] 抽屉点击、筛选、切换均可用
- [ ] 中文无乱码（UTF-8）

## 三个"看起来对但其实错"的检查点

### 1. 合计数字太整

如果算出来刚好是 `1,000,000 吨` 或 `500,000 吨`，几乎肯定是拿产能乘天数了。正确结果应该带零头（如 `708,411.2`）。

### 2. 确认合计里出现了"传闻"装置

抽查最大那一两个事件，点开来源看：是机构资讯还是股吧？股吧来的必须降级。

### 3. 时间线图很"满"

如果甘特图上所有装置都有条带、没有空白，说明把计划事件也画进去了，或者把窗口前的老停车也算进来了。**健康的时间线应该有大片空白。**
