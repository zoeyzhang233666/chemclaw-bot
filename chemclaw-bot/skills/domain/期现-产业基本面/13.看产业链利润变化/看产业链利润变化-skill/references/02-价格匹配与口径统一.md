# 02 价格匹配与口径统一

> 价差测算 90% 的错误来自价格序列不匹配，而不是公式写错。
> 本文是一份逐项核对清单：拿到任意两条价格序列，按此核对即可。

## 一、价格五要素（缺一不可）

任何进入模型的数字，都必须能回答这五个问题：

| 要素 | 必须写清楚 | 常见错误 |
|---|---|---|
| **单位** | 元/吨、元/kg、元/kWh、美元/吨 | kg 与吨混用（千倍错误） |
| **地区** | 华东/西北/内蒙乌海，或"全国基准" | 用西北电石价配山东 PVC 价 |
| **规格/牌号** | PVC SG-5、电石发气量≥300L/kg、液碱 32% | 用 SG-3 的价格算 SG-5 |
| **税费** | 含 13% 增值税 / 不含税 | 一边含税一边不含税 |
| **频率与时点** | 日/周/月，结算价/收盘价/现货均价 | 期货结算价当现货价 |

记录格式建议：
```
序列名 | 数值 | 单位 | 地区+规格 | 税费 | 日期 | 来源 | 原始链接
```

## 二、地区不匹配怎么办

**方案 A（推荐）**：统一到同一地区。全部用华东价，或全部用西北价。
**方案 B**：用全国基准，并在报告显著位置声明"未含区域价差"。
**方案 C**：显式建模区域价差（电石运费 + 产品运费），需要运费数据。

绝不能做的：把不同地区的产品价和原料价直接相减，然后称之为"利润"。
以 PVC 为例，乌海与山东的电石到厂价差可达 400–600 元/吨，
这个量级足以让"盈利"变"亏损"。

## 三、税费口径

- **产品与原料必须同类**：都含税 → 价差含税（本案例采用）；都不含税 → 价差不含税。
- 若产品含税、原料不含税：必须先把原料价 ×1.13，否则价差被系统性高估。
- 增值税是价外税，**不构成企业成本**。不要"再扣一次增值税"。
- 可抵扣的进项税：不含税口径下无需考虑；含税口径下价差本身已隐含税负中性。

## 四、频率对齐

| 组合 | 对齐方式 |
|---|---|
| 日 + 日 | 按日期内连接（join），缺一方则留空 |
| 日 + 周 | 周值对应其覆盖区间（如周一至周五）的日均 |
| 日 + 月 | 月值对应该月日均 |
| 周 + 月 | 月内各周的均值 |

**对齐后必须记录样本量**。如果 40 周里只有 13 周能对齐，就在报告里写"13 周可得"，
而不是假装 40 周都有数据。

## 五、缺数据的处理策略（重要）

按优先级：

1. **有现货就用现货** —— 最佳。
2. **有官方/行业披露锚点** —— 可以用锚点之间线性插值，但必须：
   - 只在两个真实锚点之间插值，**绝不外推**
   - 逐日标记 `interp`
   - 在图表上用虚线或不同颜色区分
3. **有强相关代理** —— 例如用"期货主力收盘 + 历史平均基差"代理现货：
   - 必须计算并披露基差统计量（均值、标准差、极值）
   - 标注为 `proxy`
   - 说明这不是真实成交价
4. **什么都没有** —— **留空**。图表留缺口，表格写"—"。

### 反例（必须避免）
> "2025 年 11 月电石价格缺失，按前后月份线性插值补全。"

这是错的：它在长达数月、跨越季节性变化（如枯水期电价上调）的区间里制造出一条假曲线，
后续所有"利润变化"都建立在这个假设上。正确做法是：留空，并说明"该区间无电石报价，不做测算"。

## 六、基差校准（期货代理现货）

当只有期货数据时：
```
基差 basis = 现货价 − 期货收盘价
平均基差 = mean(basis)  （用两者都有数据的时间窗计算）
代理现货价 = 期货收盘 + 平均基差
```
必须披露：
- 重叠样本数（越多越可信，建议 ≥30）
- 基差均值、中位数、标准差、极值
- 代理值的适用范围（只在基差结构稳定时有效）

本案例：重叠 60 个交易日，基差均值 −119.7 元/吨，中位 −114，标准差 55.2，区间 [−293, −1]。

## 七、价格来源分级（用于报告标注）

| 等级 | 含义 | 报告标注 |
|---|---|---|
| A | 交易所/官方统计/权威资讯机构日度现货 | 无需标注 |
| B | 行业协会统计、周报均值 | 标注"周均" |
| C | 锚点插值 | 标注 `interp` |
| D | 期货代理、相关品代理 | 标注 `proxy` + 基差统计 |
| E | 来自新闻表述的单一报价（如"最高 2750 元/吨"） | 标注原文表述 |
| F | 无来源 / 估计值 | **不得进入利润计算** |

## 八、常见数据源与可得性（2026 年实测）

| 数据 | 源 | 可得性 | 备注 |
|---|---|---|---|
| 期货日线（含历史） | 新浪财经 | ✅ 长期免费 | 主力连续与各月合约均可 |
| 现货基准价 | 生意社（100ppi） | ⚠️ 仅近约 93 天 | 图表接口有窗口限制；需 cookie 握手 |
| 现货历史 | 卓创/隆众 | ❌ 需付费 | 部分文章会披露具体数值，可作文本溯源 |
| 周度成本与利润 | 隆众资讯（油化频道文章） | ✅ 可抓取 | 需 UA 轮换，页面需 >20KB 校验 |
| 历史现货 | 东方财富 K 线接口 | ⚠️ 常被断连 | 需重试与降级 |
