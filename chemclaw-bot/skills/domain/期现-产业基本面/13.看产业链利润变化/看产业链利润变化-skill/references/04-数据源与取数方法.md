# 04 数据源与取数方法

> 本文记录 2026 年实测可用的数据源、接口、以及反爬与降级方案。
> 环境会变化，凡标注"实测"的都附了验证日期。

## 一、期货日线（最可靠）

**新浪财经**：`https://stock2.finance.sina.com.cn/futures/api/jsonp.php/var%20_X=/InnerFuturesNewService.getDailyKLine?symbol=V0`

- 主力连续：`V0`；月度合约：`V2510`、`V2601` 等
- 返回字段：`d`(日期) `o` `h` `l` `c`(收盘) `s`(结算) `v`(成交量)
- 特点：**可回溯多年、免费、稳定**（实测 2026-10，拉取 271 个交易日无缺失）
- 用途：作为长期价格骨架；有现货时用现货，无现货时用"期货 + 基差"代理

## 二、现货基准价（生意社 / 100ppi）

- 商品页：`https://www.100ppi.com/mprice/detail-1-{pid}.html`
- 图表接口：`https://www.100ppi.com/mprice/getVarietyChart-1-{pid}.html?type=json`
- **限制**：图表接口只返回最近约 **93 天**；直接请求商品页会返回 636 字节的反爬页
- **解法**：先访问首页完成 cookie 握手（模拟 `HW_CHECK` 校验），再带 cookie 请求
- 常用 pid：PVC 树脂 SG-5 = `107`，电石 = `640`，液碱 = `368`
- 发现更多 pid：抓 `https://www.100ppi.com/rawmex/` 页面的链接（可得到 500+ 品种）

**取数伪代码**：
```python
s = requests.Session(); s.headers['User-Agent'] = UA
s.get('https://www.100ppi.com/')            # 握手拿 cookie
r = s.get(CHART_URL % pid)                   # 再请求图表接口
data = json.loads(unpack_packer(r.text))     # 部分接口为 packer 压缩格式
```

## 三、第三方成本与利润（隆众 / Mysteel 油化频道）

- 列表页：`https://www.mysteel.com/oilchem/article/3yb4pa/`
- 文章标题形如《中国PVC电石法企业生产成本周数据分析》
- **可提取**：全国/西北/山东的电石法成本与毛利、周环比
- **反爬**：部分文章返回 4581 字节的拦截页
  - 对策：UA 轮换（3 个以上）+ 内容长度校验（`len(html) > 20000`）+ 重试
  - 实测：列表第 1 页即可拿到 40 篇文章链接，够用数月
- 用途：**交叉验证**（不是拿来当输入的）

## 四、不可用/受限的源（实测记录）

| 源 | 状态 | 说明 |
|---|---|---|
| 东方财富 K 线接口 | ❌ | `RemoteDisconnected`，多次重试无效 |
| 百川盈孚 | ⚠️ | Nuxt SSR，页面内无历史序列 |
| 卓创资讯 | ❌ | 详情页需登录/付费 |
| 中国化工网详情页 | ⚠️ | 仅返回 6 行价格 |
| 搜狗/必应搜索 API | ⚠️ | 常见 429/鉴权失败 |

## 五、搜索与网页抓取工具选择

优先顺序：
1. **结构化 API**（新浪、生意社图表接口）—— 最稳
2. **资讯文章正文**（隆众、中国化工报）—— 用于取单耗、成本结构、行业结论
3. **搜索结果** —— 只用于定位文章，不作数据源

注意：搜索结果里的数字**不能直接当数据用**，必须点进原文核对表述。

## 六、降级策略

```
目标：某品种 1 年日度现货价
├─ 生意社有近 93 天 → 取之，标 spot
├─ 更早区间 → 从资讯文章里挖"某月某日价格为 X"的表述，作锚点
│   └─ 锚点 ≥ 2 个 → 锚点间线性插值，标 interp，不外推
├─ 同时拉期货日线 → 计算重叠期基差 → 生成代理价，标 proxy
└─ 以上皆无 → 留空，报告中说明"该区间无可靠价格，未做测算"
```

## 七、单一原料主导型链条的处理

如果某原料占成本 70% 以上（如电石之于 PVC），则**该原料的价格可得性决定整个模型是否可用**：
- 优先把资源投入到这个原料的价格上
- 其他辅料可以用截面典型值（并明确标注）
- 报告里必须提示用户："结论对该原料价格高度敏感，请以你的实际采购价替换"

## 八、取数脚本约定

所有取数脚本应：
1. 联网失败时**明确报错**，不静默返回空值
2. 原始响应落盘（`raw/`），便于事后核对
3. 输出带 `source`、`fetched_at`、`n_rows` 的清单文件（`series_manifest.json`）
4. 可重复执行且幂等（同一天重跑结果一致）
