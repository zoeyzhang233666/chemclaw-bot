# 01 工艺流程与单耗口径

> 单耗是整条测算链的地基。单耗错了，后面所有精算都是错的。
> 本文的作用：给出常见工艺的物料平衡、单耗区间、以及**最容易踩的四个口径陷阱**。

## 一、四个必须分清的口径

### 陷阱 1：装置本级 vs 全链（电耗差 20 倍）
以 PVC 为例：

| 口径 | 数值 | 含义 |
|---|---|---|
| PVC 装置电耗 | 450–500 kWh/t | 只算 PVC 装置的聚合、汽提、干燥、公用工程 |
| 电石电耗 | 3400–3600 kWh/t 电石 | 电石炉本身的电耗（矿热炉） |
| 综合电耗（全链） | ≈8500 kWh/t PVC | 从石灰石/兰炭到 PVC 的**全部**电耗，已含电石环节 |

**错误做法**：把"外购电石 1.45 t/t"和"综合电耗 8500 kWh/t"放进同一个模型。
这会把电石环节的电耗重复计一遍（1.45×3500≈5075 kWh），成本虚增约 2100 元/吨。

**正确做法**：二选一，并明确声明。
- 外购电石口径：只计电石采购价 + PVC 装置电耗（450 kWh）
- 一体化口径：计电石自产电耗（≈5075 kWh）+ 石灰/兰炭 + PVC 装置电耗

### 陷阱 2：外购 vs 自产（价格含义完全不同）
- 外购电石：电石按**市场价**进入成本。
- 自产电石：电石按**内部成本**进入成本，市场价只影响机会成本。
两者的"电石成本"数值可能差 500–1000 元/吨，直接比较没有意义。

### 陷阱 3：折百 vs 实物量（烧碱 32% 液碱）
- 采购价通常报"32% 液碱"的实物吨价。
- 成本核算需折百（100% NaOH）或统一按实物量。
- `折百单价 = 实物吨价 ÷ 0.32`，单耗也要同步换成折百口径。
**混用会差 3 倍以上。**

### 陷阱 4：kg/t 与 t/t 的量级（计算机最易犯的错）
催化剂、助剂普遍是 kg/t（1–2 kg/吨），单价却是 元/吨。
`1.2 kg × 9500 元/吨` 若不做 ×0.001 换算，会算出 11400 元而不是 11.4 元。
**凡是辅料，先看单耗量级，量级不对就是忘了换算。**

## 二、电石法 PVC（案例工艺）

### 物料平衡链路
```
兰炭 + 石灰石 ──→ 电石 CaC₂ ──┐
                              ├→ 乙炔 C₂H₂ ──┐
氯气 + 氢气 ──→ 氯化氢 HCl ────┘              ├→ 氯乙烯 VCM ──→ 聚合 → PVC
                                              │
副产：电石渣（水泥原料）、联产烧碱（氯碱装置）
```

### 单耗表（多来源并列，注明适用范围）

| 指标 | 数值 | 来源 | 适用范围 |
|---|---|---|---|
| 电石 CaC₂ | 1.45–1.50 t/t | 国标口径（前瞻产业研究院/新浪财经 2022-01-17 引国家标准） | 外购电石，PVC 装置本级 |
| 电石 CaC₂ | 1.35–1.42 t/t | 隆众资讯行业统计标准（2024-12） | 外购电石，行业统计 |
| 电石 CaC₂ | 1.40–1.60 t/t | 中国化工网 | 外购电石，较宽区间 |
| 氯化氢 HCl | 750–850 kg/t | 国标口径 | 气体计价 |
| 氯化氢 HCl | 630–650 kg/t | 隆众行业统计 | 气体计价 |
| PVC 装置电耗 | 450–500 kWh/t | 国标口径 | 外购电石企业 |
| 综合电耗 | ≈8500 kWh/t | 中国化工报 2025-11-05 | 一体化全链 |
| 电石电耗 | 3400–3600 kWh/t 电石 | 联成化学（台塑）公开资料 | 电石厂 |
| 汞触媒 | 1.2 kg/t PVC | 专利 CN103408392A | 低汞/无汞触媒 |
| 综合收率 | 96–98% | 行业经验值 | 悬浮聚合 |

### 成本结构参照（用于合理性校验）
隆众统计的电石法 PVC 成本构成：
- 电石 65–70%
- 氯化氢 14.7%
- 电 5.9%
- 制造费用 5.6%
- 其他（辅料、蒸汽等）余额

> ⚠ 注意：文献中"氯化氢 14.7%"是按**液氯市价**折算 HCl 的口径。
> 若企业氯气自产（氯碱配套），HCl 应按"氯的内部成本"计价，占比会降到 5% 左右。
> 两种口径都成立，但**必须在报告里说清用哪一种**，因为利润会差约 390 元/吨。

### 联产烧碱：要不要抵减？
氯碱装置同时产出氯气和烧碱。PVC 消耗氯，烧碱是联产。
- 若企业是氯碱一体化：烧碱收益应抵减 PVC 成本（"以碱补氯"）。
- 若企业外购电石与 HCl：通常不抵减。
**实证结论（本案例 40 周回测）**：把烧碱收益全额抵减后，与第三方毛利的偏差从 −92 元/吨扩大到 +64 元/吨，
平均绝对偏差从 155 增大到 278 元/吨。说明**第三方"电石法毛利"口径并未按烧碱计价**。
因此基准模型不抵减，把"氯碱一体化口径"作为独立情景提供。

## 三、乙烯法 PVC（对照组）

| 指标 | 数值 | 说明 |
|---|---|---|
| 乙烯 | 0.48–0.50 t/t | 氧氯化法 |
| 氯气 | 0.58–0.60 t/t | 或 VCM 外购 |
| VCM | 1.002 t/t | 外购 VCM 路线 |
| 电耗 | 约 500 kWh/t | 装置本级 |

成本特征：乙烯占绝对主导，**不产生电石渣**，但需处理二氯乙烷（EDC）副产。
与电石法不能比"利润"，只能比"各自原料价差"。

## 四、其他常见链条的口径提示

| 链条 | 关键单耗 | 口径陷阱 |
|---|---|---|
| 纯碱（氨碱/联碱/天然碱） | 原盐 1.5 t/t、石灰石 1.3 t/t、氨 0.35 t/t | 三种工艺成本结构完全不同，不可合并；联碱法要扣氯化铵 |
| 烧碱（离子膜） | 原盐 1.5 t/t、直流电 2100–2300 kWh/t | 电耗是直流电，不是交流电；折百口径 |
| 尿素 | 合成氨 0.58 t/t、CO₂ | 煤头/气头完全不同 |
| 甲醇 | 煤 1.5–1.6 t/t 或天然气 1000 Nm³/t | 煤种（无烟煤/烟煤）与热值差异极大 |
| 玻璃 | 纯碱 0.2 t/t、石英砂 0.7 t/t、燃料 | 燃料口径（石油焦/天然气/煤制气）差异大 |
| 螺纹钢（长流程） | 铁矿石 1.6 t/t、焦炭 0.45 t/t、废钢 | 高炉 vs 电炉是两条链 |
| 碳酸锂 | 锂辉石 7–8 t/t、纯碱 2 t/t | 锂辉石品位（6%/5.5%）必须标 |

## 五、单耗取用决策树

```
用户提供企业实测单耗？
├─ 是 → 用实测值（最高优先级），并在报告中标注"企业实测"
└─ 否 → 有国标/行业标准？
        ├─ 有 → 用标准中值，标注标准名称与版本
        └─ 无 → 用行业协会/资讯机构的统计值
                └─ 多个来源冲突 → 全部列出，说明差异原因，取中值并标注区间
```
