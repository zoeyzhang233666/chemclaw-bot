# 05 交叉验证与 QA 清单

> 模型能算出数字 ≠ 数字正确。本文给出三层验证：**内部一致性**、**外部交叉验证**、**交付前清单**。

## 一、内部一致性（自己做，5 分钟）

### 1. 独立手算复核
不要复用模型函数。用最朴素的公式重算一遍：
```python
raw = 电石单耗 * 电石价 / 收率
aux = HCl单耗 * HCl价 / 收率 + 触媒kg / 1000 * 触媒价 / 收率
energy = 电耗 * 电价 + 汽耗 * 汽价
spread = 产品价 - raw
profit = spread - energy - aux - 制造费用
```
两者差异应 < 0.02 元/吨。若不一致，说明模型里有多余的项或漏项。

### 2. 占比合理性
主导原料占原料成本的比例，必须落在文献区间内。
- OK：电石占原料 76.7%，行业 60–75% → 基本吻合
- 异常：若算出 40% 或 95%，几乎一定是单耗或单价错了

### 3. 量级检查（专治单位错误）
| 物料 | 合理量级 | 异常信号 |
|---|---|---|
| 触媒 | 5–30 元/吨 | >100 元 → 忘了 kg→吨 |
| 助剂 | 5–50 元/吨 | 上千 → 单位错 |
| 电（450 kWh） | 200–300 元/吨 | 上万 → 把 kWh 当吨 |
| 主原料 | 2000–4000 元/吨 | 与产品价倒挂 → 查口径 |

### 4. 方向性检查
- 收率下降 → 原料成本上升，能源不变
- 主导原料涨价 → 利润下降
- 产品涨价 → 利润上升
- 敏感性矩阵应单调

## 二、外部交叉验证（最关键）

### 方法：找一家第三方机构的"成本/毛利"口径，做周度或月度对比

要点：
1. **口径不同是正常的**。第三方"毛利"通常已扣全部制造成本，而你的"加工价差"只扣原料。
2. **核心指标是方向一致率**，不是绝对误差：
   - ≥85% 同号 → 可用于方向判断
   - <70% 同号 → 模型有结构性问题，必须回头查
3. 偏差均值若稳定偏离，说明存在**系统性遗漏项**（如漏了某项能源、或口径选择错）。
   - 若加上某项后偏差显著缩小 → 该项应纳入
   - 若加上后偏差变大 → **说明不该加**，撤掉

### 本案例的验证过程（可作为模板）

**第一轮**：理论制造利润 vs 隆众全国电石法毛利，40 周
```
偏差均值 −92 元/吨，平均绝对偏差 155，标准差 173，同号 37/40（92.5%）
```
结论：方向可靠，存在系统性低估（我们的利润偏高 92 元）。

**第二轮（假设检验）**：怀疑漏计联产烧碱收益，加上 `0.75 t/t × 烧碱价` 抵减
```
偏差均值变为 +64 元/吨，平均绝对偏差恶化到 278，同号仍 37/40
```
结论：**假设被证伪**。加入烧碱后反而更差，说明第三方口径不含烧碱抵减。
→ 撤掉该抵减，保留为独立情景。**这就是"用数据否掉自己的假设"，比坚持假设更可信。**

**第三轮（机制验证）**：单独看有烧碱价格的 13 周
```
这 13 周偏差均值 −14 元/吨（远好于全样本 −92）
但 偏差 与 烧碱价 的相关系数 −0.69，暗示存在"以碱补氯"的部分支撑
```
结论：在烧碱价格可得的时段，模型精度显著提高；全样本偏差主要来自缺烧碱数据的时段。
这是**方向性证据**，不足以做定量校准（样本仅 13 周），故在报告中作为"观察"而非"校准"陈述。

### 校准的正确做法
- 允许做**口径校准**：把偏差解释为可命名、可验证的结构性差异。
- 不允许做**拟合校准**：为了让数字好看而调系数——那是曲线拟合，不是研究。

## 三、交付前 QA 清单

### 数据层
- [ ] 每个序列有：单位、地区、规格、税费、日期范围、样本量、来源链接
- [ ] 插值区间已标记，且未外推
- [ ] 代理值已披露基差统计
- [ ] 无来源的数字未进入计算
- [ ] 缺失区间在图表中是空白

### 计算层
- [ ] 独立手算一致（<0.02 差异）
- [ ] 主导原料占比落入行业区间
- [ ] 辅料量级正常（无千倍错误）
- [ ] 收率只作用于原料与辅料
- [ ] 能源成本不随收率变化
- [ ] 敏感性方向单调

### 表达层
- [ ] 三层指标名称正确，未把价差叫利润
- [ ] "企业实际利润"未输出，或已注明基于企业提供数据
- [ ] 无法计入的成本已单列
- [ ] 变化研究含 30天/3个月/1年三档
- [ ] 每条结论可点击追溯参数与来源

### 代码层
- [ ] Python 引擎 ↔ HTML 内嵌 JS 引擎结果一致
- [ ] Excel 公式回算与引擎一致
- [ ] **修改输入后，HTML 与 Excel 都能正确联动**（活公式验证）
- [ ] 所有校验脚本可一键运行且退出码正确

## 四、常见"看起来对但错"的情形

| 现象 | 真实原因 |
|---|---|
| 利润恒为负，且随价格同向变化 | 把原料价错配成了产品价 |
| 加工价差极大（如 3000+） | 漏了主原料项，或单耗写成 0 |
| 各物料成本加起来远超产品价 | 单位换算（kg/吨）错误 |
| 敏感性与常识相反 | shock 作用在了错误的键上（如给 `product` 之外的商品加了变动） |
| Excel 与 HTML 不一致 | Excel 公式引用错行（相对引用偏移） |
| 联产抵减让结果更差 | 说明第三方口径不含该项——这是发现，不是 bug |
