# 03 指标定义与命名规范

> 这一页决定输出是否可信。术语一旦被误用，读者会得出方向相反的结论。
> 本案例中就出现过：加工价差 +1083 元/吨，而理论制造利润 −431 元/吨——一个说暴利，一个说亏损。

## 一、三层指标定义

### ① 理论加工价差（Gross Processing Spread）
```
理论加工价差 = 产品含税价 − Σ(原料单耗 ÷ 收率 × 单价)
```
- **只扣原料**。不含电、汽、辅料、人工、折旧。
- 回答："买原料、卖产品，中间还剩多少空间？"
- 用途：观察**产业链利润在上下游之间怎么分配**；也是期货跨品种套利的核心指标。
- **不是利润**。它没有扣除任何加工环节的花费。

### ② 理论制造利润（Theoretical Manufacturing Profit）
```
理论制造利润 = 理论加工价差 − 已核实的能源 − 已核实的辅料 − 可核实的制造费用
```
- "已核实"是定语：只扣有可靠单价的项目。
- 回答："在能把成本算清的范围内，还剩多少？"
- 仍不是净利润（见 ③）。

### ③ 企业实际利润（Reported Net Profit）
```
企业实际利润 = 理论制造利润 − 财务费用 − 销售费用与物流 − 检修与开停车损失
               − 环保处置 − 税金及附加 − 所得税 ± 其他损益
```
- **本 skill 默认不输出这一层。**
- 只有在用户提供了该企业真实的成本表、费用表与销售价格时才计算，并标注"基于企业提供数据"。
- 用行业均价反推"某企业赚多少"是**最常见也最严重的误用**。

## 二、必须显式单列的内容

### 无法计入的成本（Gaps）
下列项目若缺少可核实单价，一律列入清单，不进任何利润数字：

- 财务费用（利息、融资成本）
- 销售费用与物流运费
- 增值税进销项税额差（如口径不一致时）
- 检修与开停车损失
- 环保处置（电石渣、废水、废气）
- 地方电价/汽价差异
- 固定资产减值、汇兑损益
- 自产中间品的电耗（外购口径下）
- 联产副产品收益（外购口径下）

输出格式：
```
| 无法计入的成本项 | 为什么算不了 | 可能的量级 | 建议获取途径 |
```

### 数据缺口（Data Gaps）
- 缺失日期区间
- 代理值与插值比例（如"181 天中 118 天为插值"）

## 三、禁用表述对照表

| ❌ 禁用 | ✅ 应改为 |
|---|---|
| 电石法 PVC 利润为 1083 元/吨 | 电石法 PVC 理论加工价差为 1083 元/吨 |
| 行业净利润 −431 元/吨 | 理论制造利润 −431 元/吨（未含财务与销售费用） |
| 该企业每吨赚 500 元 | 按行业平均单耗测算，理论制造利润为 500 元/吨；企业实际利润需其自身成本数据 |
| 加工毛利 | 明确指出是"加工价差"还是"毛利"，并给公式 |
| 完全成本 | 说明包含哪些项、不包含哪些项 |
| 利润率 | 说明分子分母（如"理论制造利润 ÷ 含税售价"） |

## 四、输出模板

### 抬头（必须包含）
```
品种/产业链：____    工艺：____（产能占比 __%）
时间范围：____ 至 ____    数据冻结日：____
价格口径：含税/不含税    增值税率：____
地区口径：全国基准 / ____    是否含区域价差：是/否
```

### 结论区（按此顺序）
```
1) 主导原料：____，占总成本 __%（行业区间 __–__%）→ 合理性校验：通过/偏离
2) 理论加工价差：____ 元/吨（较 __ 前 __%）
3) 理论制造利润：____ 元/吨（已计入：原料、能源、辅料、制造费用）
4) 无法计入的成本：__ 项（财务费用、销售物流……）
5) 盈亏平衡：PVC 售价需达 ____ 元/吨（当前 ____）
6) 敏感性：主导原料每涨 100 元/吨 → 利润 −__ 元/吨
7) 数据局限：____
```

### 变化研究（30天/3个月/1年）
```
| 窗口 | 期初 | 期末 | 变化 | 变化率 | 主要驱动 |
| 30 天 | | | | | 产品价 __ / 原料价 __ |
```
驱动分解建议用：`Δ价差 ≈ Δ产品价 − (单耗 ÷ 收率) × Δ原料价`，把残差单独列出。

## 五、口径不匹配时怎么写结论

当理论模型与第三方数据（如资讯机构的"毛利"）口径不同时：

**错误写法**：
> 我们算出 −431，隆众是 −619，误差 188 元，模型偏差 30%。

**正确写法**：
> 本模型理论制造利润 −431 元/吨，隆众同期"电石法毛利" −619 元/吨。
> 两者差 188 元/吨，主要来自：隆众样本为特定期企业、含区域运费差异、
> 且其成本口径含全部制造成本而本模型部分辅料单价为截面值。
> 40 周回测中方向一致率 92.5%（37/40），**可用于判断方向，不可用于精确定价**。

## 六、一句话原则

> **宁可说"这个指标我算不全"，也不要把一个口径不明的数字包装成"利润"。**
