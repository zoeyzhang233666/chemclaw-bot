## 快速开始

### 场景 A：我只想看结论
直接打开 `examples/01-PVC电石法完整案例/output/PVC电石法-产业链利润研究与成本计算器.html`。
单文件、离线可开，所有参数都能改，改完实时重算。

### 场景 B：我要测自己的企业
1. 打开 Excel 模型，进 `01_参数与单耗`。
2. 把黄色格（单耗、单价、收率、制造费用）换成你自己的数据。
3. `02/03/07` 三张表自动重算。
4. 需要追溯来源看 `08_公式与来源`。

### 场景 C：我要测别的品种
```bash
python scripts/new_chain.py 纯碱-氨碱法 ./纯碱测算
# 然后编辑 ./纯碱测算/chain_config.json
```

## 三条红线

1. **加工价差 ≠ 利润**。只扣原料的价差，不能叫利润。
2. **理论制造利润 ≠ 企业净利润**。财务费用、销售物流、税费都没扣。
3. **缺数据就留空**。不要插值出一段假曲线，宁可报告里写"该区间无数据"。
