# 看产业链利润变化（理论加工价差 / 理论利润测算）

## 这个 skill 解决什么问题

用户想知道"这条链现在赚不赚钱、钱赚在哪个环节、变化来自哪里"。
错误做法是直接给一个"行业利润"数字——这类数字通常既不可核实、口径也不明。
本 skill 的做法是：**把利润拆成可以逐项核验的物理量（单耗）与价格量（单价）**，
算出"理论加工价差"和"理论制造利润"，并明确声明哪一部分**算不了**。

## 铁律（违反任何一条，输出即为不合格）

1. **缺少关键数据时，只算有依据的加工价差，绝不编造完整利润。**
   缺口要显式列成"无法计入的成本"清单，而不是用估计值填平。
2. **三层指标必须分开命名**，不得混用、不得互相替代：
   - `理论加工价差` = 产品价 − 原料成本（只含原料）
   - `理论制造利润` = 加工价差 − 已核实的能源/辅料/制造费用
   - `企业实际利润` = **本 skill 不输出**，除非用户提供了该企业的内部成本与费用数据
3. **不得把加工价差称作"企业净利润"**，也不得说"某企业赚了 X 元/吨"。
4. **用户提供的真实单耗优先于行业典型值**；使用典型值时必须标注适用工艺与来源。
5. **不同工艺的原料数据不得混用**（外购电石 vs 一体化 vs 乙烯法，三者篮子完全不同）。
6. **每个数字都要能追溯到：日期 + 规格 + 地区 + 税费口径 + 来源**。
   缺任一项的，标注为"待核实"，不要当成已核实值。

## 九步工作流

接到任务后，先确认三件事（缺则问）：**品种/产业链、时间范围、指定工艺**。

### 步骤 1｜核实工艺路线
- 确认主流工艺及其占比（例：中国 PVC 电石法约占 72%，乙烯法约 28%）。
- 如果用户指定了工艺，就用指定工艺；没指定则用**产能占比最高的主流工艺**，并说明为什么选它。
- 明确该工艺的**物料平衡链路**：从哪些原料出发、经过哪些中间体、副产什么。
- 产出：一段工艺说明 + 一张链路图（HTML 里画，Excel 里列表）。

### 步骤 2｜原料构成、单耗、收率及来源
- 逐项列出：物料名称 / 单耗 / 单位 / 该单耗的**适用范围** / 来源。
- **同一指标出现多个来源时，并列成表，不做平均**。差异往往是工艺口径不同造成的（例：电石 1.45 t/t 是外购口径，1.35–1.42 是行业统计口径）。
- 收率：明确它作用于哪些物料（通常只作用原料与辅料，**不作用能源**）。
- 单位换算写成显式系数（kg→0.001 吨；kWh 直接乘元/度）。

### 步骤 3｜价格序列口径统一
必须逐条核对五件事：**单位、地区、规格/牌号、含税/不含税、频率与时区**。
- 产品与原料必须同为含税或同为不含税，否则价差含税性不一致。
- 地区不一致时，要么统一到同一地区，要么明确声明"本模型为全国基准，未含区域价差"。
- 频率不一致时，高频向低频对齐（日→周→月取均价），并记录对齐方式。
- **数据不足时不要外推**：宁可留空并标注，也不要插值出一段假曲线。
  如确需插值，只能用**文献明确披露的锚点**之间线性插值，并全程标记 `interp`。
- 详见 `references/02-价格匹配与口径统一.md`。

### 步骤 4｜单位原料成本与成本占比
- `单位成本 = 单耗 × 换算系数 × 单价 ÷ 收率`（仅原料/辅料除收率）。
- 计算各物料占原料成本、占总成本的比例。
- **用占比做第一道合理性检查**：主导原料占比必须落在行业文献区间内，
  否则说明单耗或价格错了（例：电石法 PVC 电石占总成本应约 65–75%）。

### 步骤 5｜能源、辅料、制造费用（只用可核实数据）
- 能源：电、蒸汽、燃料，按实物单耗 × 单价。
- 辅料：催化剂、助剂、包装，注意 kg/t 量级（最易出现千倍错误）。
- 制造费用：人工、折旧、包装、维修，说明折算依据（人数、投资额、折旧年限）。
- **凡是无可靠单价的项目，一律不进利润，只进"无法计入的成本"清单。**

### 步骤 6｜三层指标分别呈现
按步骤 5 的规则输出三块内容，并把**无法计入的成本**单独列出来。
- 详见 `references/03-指标定义与命名规范.md`。

### 步骤 7｜变化研究（30 天 / 3 个月 / 1 年）
- 给出三个窗口的：价差水平、变化幅度、极值及其日期。
- 拆解变化来源：**产品价变动贡献 vs 原料价变动贡献**（用弹性或桥接分解）。
- 标注每段数据的来源等级（现货 / 代理 / 插值），不能把代理值当现货汇报。

### 步骤 8｜敏感性分析（±5% / ±10%）
- 双因素矩阵：主导原料价 × 产品价。
- 单因素弹性：每个物料价格 ±5%/±10% 对利润的影响，按影响大小排序。
- 盈亏平衡：使理论利润为 0 所需的售价 / 可承受的原料涨幅。
- 报告中给出**一句话结论**：例如"电石每涨 100 元/吨，PVC 成本增加约 150 元/吨"。

### 步骤 9｜工艺路线对比（同口径）
- 各工艺给各自的成本指标（电石法看加工价差，乙烯法看乙烯-PVC 价差），
  **不要用同一个"利润"数字横比不同工艺**。
- 说明各自的核心变量（电石法=电石价与电价；乙烯法=乙烯价；一体化=电力自给率）。

## 交付物

1. **交互式 HTML**（单文件、离线可开，内联图表库）
   - 可修改：单耗、单价、收率、能耗、是否计入各项费用 → 实时重算
   - 必含：历史价差曲线、成本占比图、敏感性矩阵、工艺对比
   - 每个结果可点开看参数与来源
2. **Excel 模型**（多工作表、**活公式**）
   - 必含：原料单耗 / 历史价格 / 成本构成 / 加工价差 / 可纳入费用 / 敏感性分析 / 公式与来源
3. **文字报告**（案例化，含结论、风险与局限）

## 验证（交付前必做）

运行 `scripts/` 下的校验脚本，全部通过才算完成：
- 独立手算复核（不复用模型函数）
- Python 引擎 ↔ HTML 内嵌 JS 引擎逐项比对
- Excel 公式回算 ↔ 引擎逐项比对 + **改输入看是否联动**
- 合理性断言（主导原料占比、单位量级、收率方向、敏感性方向）
