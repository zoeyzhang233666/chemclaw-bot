# 研究设计：问题树、范围与提纲写法

## 一、把标题拆成问题树

几乎所有"专题研究"标题都能落到六类问题之一或组合：

| 类型 | 典型标题 | 核心问题 | 关键数据 |
| --- | --- | --- | --- |
| 供给冲击 | X 新增产能对供应格局的影响 | 名义新增多少？有效新增多少？谁被替代？ | 项目台账、产能结构、成本曲线 |
| 需求变化 | X 下游需求走弱的影响 | 需求降多少？哪个下游降？弹性多大？ | 下游开工、产量、消费结构 |
| 政策冲击 | 出口退税取消的影响 | 政策改变哪个量？多久传导？ | 政策文本、出口量、内外价差 |
| 成本驱动 | 原料涨价对 X 的影响 | 成本上行多少？能传导多少？ | 原料价、单耗、加工费 |
| 竞争格局 | 行业集中度变化 | 谁在扩张？集中度怎么变？ | 企业产能、并购、CRn |
| 区域迁移 | 产能向西北转移的影响 | 区域平衡如何变？运费影响多大？ | 区域产能/需求、运费 |

**拆解方法**：对每个问题问三遍"那又怎样？"，直到落到"哪个数字变化多少"。

例：
- 新增产能多少 → 名义 1300 万吨
- 那又怎样 → 但净新增 790 万吨（扣退出与置换）
- 那又怎样 → 已真实放量 620 万吨
- 那又怎样 → 2027 年净有效新增 285 万吨，对应过剩约 40 万吨
- 那又怎样 → 价格中枢下移，氨碱被挤出

## 二、范围界定

必须写下四件事：

1. **时间**：数据截止日 + 预测窗口（如"2026Q4–2027Q4"）。
2. **空间**：全国 / 某区域；是否含进口。
3. **品种与形态**：纯碱要区分轻质/重质；尿素区分大小颗粒；不同形态价格与需求不同。
4. **不纳入**：明确写出来，防止膨胀。

## 三、提纲写法（每章五件套）

```json
{
  "no": "03",
  "title": "在建与新投产项目核验",
  "question": "哪些项目已投产、在建、规划？哪些只是搬迁置换？",
  "why": "预计投产与已发生供给差一个量级，不核验就会高估供给",
  "verify": "投产状态是否有公告/统计依据；是否净新增",
  "data": ["项目台账", "开工与投产日期", "置换披露"],
  "method": "逐项目三态核验 + 证据强度"
}
```

**自检问题**：

- 删掉这一章，报告还成立吗？成立就删。
- 这一章的结论能被哪张表支持？没有就补数据或删章。
- 这一章和上一章是什么关系（递进/并列/反驳）？说不清说明结构乱。

## 四、章节包目录（按需组合，不要照抄）

| 章节包 | 用途 | 常见于 |
| --- | --- | --- |
| research_design | 问题、范围、口径 | 全部 |
| structure | 产能结构、工艺、集中度 | 供给类 |
| projects | 项目三态核验 | 供给类 |
| calculation | 有效供给折算 | 供给类 |
| cost | 成本曲线与出清 | 供给/采购 |
| demand | 需求侧约束 | 全部 |
| price_history | 价格库存历史校验 | 全部 |
| region | 区域格局与物流 | 销售/区域类 |
| company | 企业集团与行为 | 竞争格局 |
| process | 工艺路线与替代 | 研发 |
| chain | 产业链传导 | 成本类 |
| policy | 政策与合规 | 政策类 |
| conclusion | 结论与反证 | 全部 |
| risk | 风险与情景 | 管理层 |

## 五、一个合格的提纲长什么样

- 5–10 章，每章能独立回答一个问题。
- 章节之间存在递进关系，能画出依赖箭头。
- 每章都有"依赖数据"，且这些数据在数据源清单里能找到。
- 用户能看懂每一章为什么存在——看不懂就说明 `why` 没写清。
