# 数据源与检索方法

## 一、来源分层（决定证据强度）

| 层级 | 来源类型 | 用法 | 例子 |
| --- | --- | --- | --- |
| A | 企业公告、年报、招股书、环评/备案公示；国家统计局、海关总署、行业协会 | 可直接引用为事实 | 远兴能源公告、国家统计局产量、海关出口 |
| B | 行业媒体引用第三方数据（卓创、隆众、生意社、百川、钢联） | 可引用，注明"据XX" | 期货日报引用卓创开工率 |
| C | 券商研报、公众号、自媒体转述 | 仅作线索，必须回到 A/B 验证 | "某研报称……" |
| D | 无出处、AI 生成、论坛 | 不得引用 | — |

登记时写：`id / org / title / date / url / tier / note(口径)`。

## 二、按题目类型的数据清单

### 供给/产能类

- 产能结构：总产能、工艺分项（天然碱/联碱/氨碱等）、年份序列
- 企业清单：集团、主体、区域、工艺、产能、成本档位
- 项目台账：名称、企业、产能、开工、计划投产、实际投产、状态
- 退出与置换：关停公告、搬迁置换方案
- 产量/开工：周度或月度，注意口径（全国/样本企业）

### 需求类

- 消费结构占比
- 主要下游产量与开工（玻璃日熔、光伏装机、地产竣工、化肥施用）
- 出口/进口量（海关）
- 替代品价格与用量

### 价格/成本类

- 现货价（区域、规格、含税）
- 年度均价（做历史对比用）
- 原料价、单耗、加工费
- 成本档位（完全成本 / 现金成本）
- 库存（厂内 / 社会 / 交易所）

## 三、检索技巧

- 优先用"指标 + 期间 + 机构"组合，例如"纯碱 产量 2025年1-11月 国家统计局"。
- 中文财经网站常可用 `.shtml.md` 后缀取正文（新浪财经实测有效）。
- 部分数据平台（如 100ppi.com 详情页）有反爬，只能用其汇总页/年度均价。
- 找不到当月数据时，用"累计值 + 增速"倒推，并在口径里注明是倒推。
- 同一指标至少找两个来源交叉，差异写进 `note`。

## 四、口径冲突处理

冲突是常态，处理有固定写法：

1. **并列保留**：两个来源都登记，`note` 写清差异（样本、税率、规格、时点）。
2. **明确采信**：在 `method_notes` 写"本报告采用 X 口径，理由：……"。
3. **不做混合运算**：不同口径的数字不得相减得出"差额"，除非你先把口径拉齐并写出来。
4. **量化影响**：口径差异对结论的影响写到缺口或计算的口径说明里。

例（纯碱库存）：卓创口径 162.89 万吨（2026-10-15）、隆众口径 187.27 万吨（2026-08-28）。差异约 24 万吨，来源是统计样本不同。报告只用一条序列做趋势判断，不跨口径加总。

## 五、常见数据陷阱

| 陷阱 | 表现 | 应对 |
| --- | --- | --- |
| 设计产能当产量 | "新增 550 万吨"直接加到产量 | 乘爬坡率与时间权重 |
| 规划当在建 | 项目尚未开工就算进未来供给 | 三态核验 |
| 名义新增当净新增 | 忽略搬迁置换、关停 | 逐项标注是否净新增 |
| 年度均价当现价 | 用 2025 年均价 1275 判断 2026 | 现价必须用日频点位 + 日期 |
| 全国价当区域价 | 忽略运费与区域过剩 | 用区域价与价差 |
| 单月数据当趋势 | 检修季产量下降被读成减产周期 | 用 3 个月移动或同比 |
| 同比基数失真 | 去年低基数导致高增长 | 看两年复合或绝对值 |
