# 证据、结论分级与反证条件

## 一、结论四类

| 类型 | 定义 | 读者怎么用 | 必须附带 |
| --- | --- | --- | --- |
| 事实 | 可直接对应来源的陈述 | 可直接对外引用 | 来源 ID |
| 计算 | 由公开数据按明确公式算出的数字 | 可复算、可质疑参数 | 公式 + 参数 + 口径 |
| 解释 | 基于事实的机理说明 | 帮助理解，但可能有别的解释 | 至少一条替代解释 |
| 判断 | 依赖假设的结论 | 决策依据，但需监控 | 反证条件 |

**常见错误**：把判断写成事实（"新增产能将导致价格下跌"应写成"在需求不改善的前提下，价格中枢大概率下移"）。

## 二、置信度

主观刻度，不是概率。给分要有理由：

| 等级 | 含义 | 典型情形 |
| --- | --- | --- |
| 高 | 数据齐全、多源交叉、机理清晰 | 已投产项目的产能与时间都有公告 |
| 中 | 主证据充分，但一处关键参数缺失 | 有产能结构数据，缺装置级清单 |
| 中低 | 依赖较多假设或单一来源 | 退出产能仅有媒体转述 |
| 低 | 数据稀薄，方向性判断 | 无日频价格、无区域数据 |

在 `audience_note` 或正文里写清"置信度中，因为缺 X"。

## 三、反证条件

判断类结论必须写"什么会让我改口"。好的反证条件是**可观测、有时点、可量化**的：

| 差 | 好 |
| --- | --- |
| 如果情况变化 | 若 2027Q1 末库存降至 120 万吨以下且开工率回到 85% 以上，本结论作废 |
| 如果供给减少 | 若氨碱退出累计达 200 万吨/年（以公告为准），再平衡提前至 2027H1 |
| 如果需求好转 | 若浮法日熔回升至 15.5 万吨以上并维持 2 个月，需求侧拖累判断改口 |

每份报告至少有 5 条结论带反证条件，且集中在结论章与关键变量表。

## 四、证据链的完整性

一份结论从写出来到能被追问，需要这几环：

```
结论 → 证据 ID（来源/缺口）→ 计算 ID → 输入参数 → 原始数据行 → 数据源
```

工具保证后四环：`sources`、`calculations`、`datasets`、`url`。你在写作时要保证前三环不跳。

**引用完整性由校验器强制**：

- 引用了未登记的 ID → 校验失败。
- 登记的来源没有任何地方引用 → 自检失败。

## 五、措辞规范

| 场景 | 不要写 | 改写成 |
| --- | --- | --- |
| 数据缺失 | "行业内普遍认为约 500 万吨" | "装置级退出规模未取得（缺口 G05），据媒体转述约 X 万吨，仅作方向参考" |
| 趋势不确定 | "供给过剩将进一步加剧" | "在需求同比 −3% 的假设下，2027 年过剩约 40 万吨" |
| 时间不确定 | "未来有望改善" | "再平衡最早出现在 2027H2，前提是……" |
| 责任不明 | "市场认为" | "三家券商研报均认为（C 级证据）" |
| 口径混用 | "库存下降 20 万吨" | "卓创口径库存由 180.58 万吨降至 162.89 万吨（−17.69 万吨）" |

## 六、自检

- [ ] 每条结论都有类型与置信度。
- [ ] 判断类结论都有反证条件，且可观测。
- [ ] 解释类结论至少提到一种替代解释。
- [ ] 没有把"预计/可能/有望"写成确定事实。
- [ ] 没有跨口径相减。
