# 资料缺口：分级、表述与处理

缺口不是失败，隐瞒缺口才是。研究做到一定程度必然有数据拿不到，专业做法是**显式标注 + 量化影响 + 给出补法**。

## 一、分级

| 严重度 | 判定 | 处理 |
| --- | --- | --- |
| high | 影响核心结论的量级或方向 | 正文显著标注；结论置信度下调；用更粗口径替代并说明 |
| medium | 影响幅度，不影响方向 | 在相关章节标注；给区间而非点值 |
| low | 影响表述精度 | 在缺口页登记即可 |

## 二、必填五要素

```json
{
  "id": "G01",
  "topic": "装置级产能与退出清单",
  "missing": "逐装置的产能、投产/关停月份、工艺与区域",
  "why": "行业统计只到企业级，装置级数据为商业数据库付费内容",
  "impact": "退出产能规模无法精确核定，K3 上下各约 30 万吨/年",
  "workaround": "用企业级产能 + 媒体披露的关停事件近似，并在正文标注",
  "next_step": "采购卓创/隆众装置级数据库，或从省级环评公示逐项爬取",
  "severity": "high"
}
```

## 三、表述模板

**正文标注**（放在使用该数据的那一段里）：

> 装置级退出规模未取得（缺口 G01）。本报告采用企业级口径估算，退出产能可能有 ±30 万吨/年的误差，对应结论 CC-08 的时点判断可能前后移动一个季度。

**结论附带**：

> 置信度：中（因缺口 G01，退出规模为估算）

**封面/首屏**：

> 资料缺口 6 项，其中 high 级 2 项，已逐项说明影响。

## 四、绝对禁止的四种"糊过去"

| 做法 | 为什么不行 | 应该怎么做 |
| --- | --- | --- |
| 用"行业普遍认为"代替数据 | 无法验证、无法追责 | 登记缺口 + 标注转述来源层级 |
| 凭空估算后当事实写 | 数字进了决策链 | 估算必须标注为"测算"并给区间 |
| 只写"数据有限" | 读者不知道影响多大 | 量化影响（哪条结论、多少量级） |
| 悄悄换口径与前一节数据拼接 | 造成趋势假象 | 并列口径 + 说明采信理由 |

## 五、常见可接受替代路径

| 缺什么 | 替代 |
| --- | --- |
| 当月产量 | 累计值 + 增速倒推 |
| 装置级产能 | 企业级产能 + 财报分项 |
| 日频价格 | 周均价 / 月均价，并注明频率 |
| 区域库存 | 全国库存 + 区域价差推断 |
| 在建项目进度 | 开工公告 + 建设期推算，标注为推算 |
| 下游实际产量 | 下游开工率 × 产能，并注明假设 |

## 六、缺口页的写法

Excel `10_资料缺口` 必须包含：ID、主题、缺什么、为什么缺、对结论的影响、当前处理、严重度、下一步。
