# 七步流程详解

每一步都有明确的输入、产出和"不许进入下一步"的门槛。跳步是这个技能最常见的失败原因。

---

## 第 1 步：界定问题

**输入**：用户的一句话标题（可能很模糊）。
**产出**：`research_brief`

要做的事：

1. 把标题拆成**可回答的子问题**（4–7 个）。判断标准：能不能对应到某张表或某个来源？"未来供应格局如何"不可回答；"2027 年有效新增供给是多少"可回答。
2. 划**纳入 / 不纳入**。范围不清会导致无限膨胀。例："不纳入海外产能细分布局（仅作为出口吸纳能力提及）"。
3. 列出**关键假设**。假设要在结论里被检验，不是藏起来。

**门槛**：每个问题都要能说出"用什么数据回答、去哪找"。说不出的问题要么删掉，要么写进资料缺口。

---

## 第 2 步：出提纲，等确认

**输入**：`research_brief` + 受众。
**产出**：`audience_frameworks.<受众>.chapters` + 一份可读的提纲 Markdown。

每章必须五件套齐全：

| 要素 | 回答 | 反例 |
| --- | --- | --- |
| 要回答的问题 | 这一章的结论句是什么形状 | "介绍行业概况" |
| 为什么需要这一章 | 它支撑哪条结论、不写会缺什么 | 省略不写 |
| 验证/证伪什么 | 什么结果会让这一章推翻前文 | "了解行业" |
| 依赖数据 | 具体到指标与频率 | "行业数据" |
| 方法 | 结构分解 / 情景测算 / 历史类比 | 无 |

**门槛**：把提纲交给用户，**停下来**。用户可能删章、换顺序、加问题。不要"顺便"把研究做完——提纲是判断权的移交点。

---

## 第 3 步：取证

**输入**：提纲 + 数据清单。
**产出**：`sources`（带 ID 与层级）、`data_gaps`。

检索顺序（效率与可靠性兼顾）：

1. 企业公告、年报、招股书、环评/备案公示 → A 级
2. 国家统计局、海关总署、行业协会 → A 级
3. 行业媒体引用第三方（卓创、隆众、生意社、百川）→ B 级
4. 券商研报、公众号 → C 级，仅作线索，必须回到 1–3 验证

三条纪律：

- 先登记再引用：任何要写进报告的数字，先在 `sources` 里有 ID。
- 同指标多来源时保留全部，口径写进 `note`，由你判断采信哪个并说明理由。
- 三次检索仍拿不到 → 登记 `data_gaps`，写清"缺什么、为什么缺、影响、下一步"，然后用更粗的替代口径继续（并说明是替代口径）。

---

## 第 4 步：项目核验

只在题目涉及产能/供给/扩张时做，但一旦涉及就必须做。

对每个项目产出：ID、企业、区域、工艺、名义产能、开工时间、计划投产、实际/预计、**状态**、**状态依据**、**证据 ID**、证据强度、是否净新增、替代对象。

三态定义见 `capacity-verification.md`。核心纪律：**规划不是在建，在建不是已投产，已投产不等于满负荷。**

---

## 第 5 步：测算与结论分级

测算要求：

- 一条计算 = 一个 `id` + 公式 + 输入参数 + 输出 + 口径说明 + 证据。
- 参数要有出处（爬坡率、负荷率、时间权重）。
- 给区间而不是点估计：低 / 基准 / 高，写清各自假设。

结论要求：

- 类型：事实 / 计算 / 解释 / 判断。
- 置信度：高 / 中 / 低（主观刻度，写清理由）。
- 反证条件：什么可观测事件会让你改口。

---

## 第 6 步：按受众改写

同一份数据结构，通过 `audience` 切换：

- 章节包组合不同（见 `audience-adaptation.md`）
- 图表数量与类型不同
- 结论的展开深度不同：管理层读结论 + 后果，研究员读推导 + 口径

不要为每个受众重写一遍数据。改 `meta.audience` 或命令行 `--audiences` 即可。

---

## 第 7 步：自检与交付

依次运行：

```bash
python scripts/common.py validate case.json      # 结构与引用
python scripts/build_all.py case.json            # 生成
node   scripts/qa_dom.mjs 报告.html              # 页面 JS 与交互
python scripts/qa_xlsx.py 数据底稿.xlsx          # 页签与内容
```

再人工对照 `quality-gates.md`。**没过的项要在交付说明里写出来**，不要静默交付。
