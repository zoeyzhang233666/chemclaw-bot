# 期现与产业基本面核验：涨跌有没有基本面支撑

> 一句话职责：**给定「品种 + 时间窗口」，先测量价格与期现结构的真实变化，再用独立于价格的现实指标（库存、开工、产量、贸易、下游需求、成本）检查现实市场是否同步改变，最后把证据分成「现实供应变化 / 现实需求变化 / 成本变化 / 预期指标」并标出支撑、背离与数据不足。**

## 0. 三条不可违反的铁律

1. **期货（或任何价格）上涨本身不是基本面改善的证据。**价格只能作为"待解释对象"，不能作为解释变量。任何指标进入判定前，必须独立于价格取得。
2. **单一库存指标下降 ≠ 全产业供给紧张。**必须同时看：口径（总库存/分项）、时点（是否假期停开单）、历史位置、去化速率是否可持续。反例请见 `examples/pp-2026q4`：库存同期上涨 45.77%，价格却涨 8.29%。
3. **不给出多空交易结论。**唯一结论形态是："这轮上涨有/没有/部分有可验证的现实基本面支撑，支持与背离的分别是哪些证据，哪些无法核实。"出现"建议做多/做空/看涨看跌"即为越界。

## 1. 何时启用

触发语（中/英）：
- 「【品种】在过去【时间】出现明显上涨，请检查这轮行情是否伴随可验证的现实基本面变化」
- "PP 10月这波涨到底有没有基本面"、"这波是成本推动还是供需驱动"
- "看涨跌有没有基本面支撑"、"期现结构有没有印证"、"基差走弱说明什么"
- "是否只是预期在涨"、"现货跟不跟"、"库存降了是不是真的缺货"

不适用：单看价格位置（→ 用行情简报类技能）、单纯解释新闻影响（→ 用新闻事件类技能）、寻找交易机会（→ 不是本技能职责）。

## 2. 执行流程（六步，严格按序）

```
Step 1 锚定真实窗口  →  Step 2 测量价格与期现结构  →  Step 3 六区块证据采集
                                                              ↓
Step 6 输出与复核   ←  Step 5 证据分级与四轴归类  ←  Step 4 口径对齐与时滞标注
```

### Step 1 · 锚定真实上涨窗口（禁止预设涨幅）

- **先找数据、后定窗口。**必须让"涨幅"由原始序列算出来，而不是先假设一个涨幅再去找证据。
- 判定"明显行情"：主窗口涨幅绝对值 ≥ 5%，或单日 ≥ 5%，且能由原始序列复算。
- 输出**至少三层窗口**，因为同一段行情在不同窗口里结论可能相反：
  - 主窗口（如 10/01→10/19，+8.29%）
  - 事件窗口（如 10/08 节后首日，期货 +7.08%）
  - 中期窗口（如 7/01→10/19，+35.47%，含 3 月与 9 月两波）
- 若用户给的区间与数据不符，**如实指出并给出数据支持的区间**，不要迁就用户的说法。
- 无法获取逐日序列时，用"锚点法"：取月初/月末、节前/节后等已公开披露点，并标注每点为"已核验 / 推算 / 缺失"。

详见 `references/01-window-and-price.md`。

### Step 2 · 测量价格与期现结构

必算清单（有期货品种）：

| 指标 | 公式 | 用途 |
|---|---|---|
| 现货涨幅 / 期货涨幅 | (P_t − P_0)/P_0 | 谁领涨：期货大幅领先 → 情绪/预期定价 |
| 同期涨幅差 | 期货% − 现货% | 差 ≥ 3pct 即需警惕"盘面独走" |
| 基差 | Spot − Futures | 正=现货升水；走强=现实偏紧，走弱=预期驱动 |
| 基差变化 | ΔBasis | 结合现货方向判断 |
| 月差 | P_near − P_far | Back/Contango 揭示近端现实与远端预期 |
| 持仓量变化 | ΔOI | 增仓=新资金押注（预期），非现货证据 |
| 成交/持仓比 | Vol/OI | 换手过热提示 |

**无期货品种**：期现结构不可用，必须改用**替代结构**——
1. 区域价差（产区 vs 销区、华东 vs 华南）
2. 出厂价 vs 市场价差
3. 上下游加工价差（下游价 − 上游价，见 Step 3-⑥）
4. 高低端牌号/品质价差

详见 `references/02-basis-and-term-structure.md`。

### Step 3 · 六区块证据采集

按固定六区块采集，**每项必须记录：数值、日期、口径、来源、证据等级**。字段规范见 `references/03-evidence-blocks.md`。

| # | 区块 | 必采指标 | 常见缺失 |
|---|---|---|---|
| ① | 价格表现 | 现货（分区域/规格）、期货、基差、月差 | 期货历史收盘（免费源受限） |
| ② | 现实供给 | 产量、产能、产能利用率、检修/复产、新增产能、进口 | 检修损失量（万吨/周） |
| ③ | 现实需求 | 分下游开工率、订单、成品库存、出口、表观消费 | 订单与利润量值、月度出口 |
| ④ | 库存与贸易 | 总库存、分项库存、历史分位、去化速率 | 历史序列（分位无法计算） |
| ⑤ | 成本与利润 | 原油/原料价格、各工艺路线成本、加工价差、传导率 | 一体化毛利（口径复杂） |
| ⑥ | 预期指标 | 远月定价、持仓、板块共振、政策/地缘、机构预测 | — |

### Step 4 · 口径对齐与统计滞后

- 建立**口径台账**：现货口径（含税/地区/规格）、期货合约（主力移仓）、库存口径（总/分项）、利润口径（机构推算假设）。
- 每个指标标注**发布节奏与滞后**：日度（价格）/ 周度（开工、库存，滞后3–5天）/ 月度（产量、进出口，次月中下旬）。
- **硬规则：不得用滞后指标否定日度价格异动，也不得用日度价格证明滞后指标改善。**
- 跨口径量（如"全国现货参考价 − 某合约期货价"）只允许作方向参考，不得报绝对值精度。

### Step 5 · 证据分级与四轴归类

1. **来源分级**：A=官方/交易所/官方指数原始数据；B=专业机构一手行业数据（隆众、金联创、卓创、期货公司周报）；C=媒体转述/二手；D=推断测算。
2. **结论只由 A/B 级支撑**；C 级仅作线索并标注；D 级必须写"测算"且不得单独支撑任何结论。
3. **逐条判定与价格的关系**：
   - `支撑上涨`：窗口内变化方向与价格同向，且性质为现实（非预期）
   - `背离`：方向相反，或该指标揭示驱动实为预期/成本而非所声称的供需
   - `数据不足`：无量值或无可核验原始来源 → 显式标注，禁止估算填充
   - `中性/预期`：无方向性，或本身属于预期类
4. **四轴归类**：现实供应变化 / 现实需求变化 / 成本变化 / 主要体现预期。
5. **禁止合并矛盾**：若两个口径结论相反（如 PDH 价差两口径一个走阔一个持平），**并列呈现**，并说明口径差异，不得择一。

判定逻辑与状态机见 `references/04-evidence-classification.md`；状态机伪代码可直接移植。

### Step 6 · 输出与复核

**必交付两件**（模板见 `templates/`）：
1. **交互式 HTML 报告**：六区块卡片 + 证据状态筛选 + 点选查看完整历史与原始来源链接 + 一致/背离/无法核实三联表 + 口径与滞后说明。
2. **Excel 工作簿**（11 表）：封面 / 现货期货 / 基差月差 / 供需平衡 / 库存与贸易 / 成本与利润 / 证据分类 / 历史序列 / 来源清单 / 指标规则 / 口径与滞后。

**复核清单**（`references/07-qa-checklist.md`）：
- [ ] 主窗口涨幅可由原始序列复算
- [ ] 每条证据都有日期、口径与来源
- [ ] 无任何期货价格上涨被当作证据
- [ ] 缺失项全部显式标注，无估算填充
- [ ] 无多空方向或交易建议
- [ ] 已区分"现实已发生"与"预期将发生"
- [ ] 已说明统计滞后与口径冲突

## 3. 输出格式（严格遵循）

最终回答必须包含且仅包含以下结构：

```
1. 窗口与价格事实（复算得出，标明数据状态）
2. 期现结构（基差/月差/涨幅差；无期货品种给替代结构）
3. 现实供给 / 现实需求 / 库存贸易 / 成本利润 四块要点
4. 证据分类矩阵（支撑 / 背离 / 数据不足）
5. 结论口径：本轮上涨的性质（现实驱动 / 成本传导 / 预期定价 / 混合）
6. 尚无法核实的部分
```

**结论句式模板**：
> 本轮【品种】【窗口】上涨 __%，现货真实上涨为【是/否/部分】。驱动结构为【成本传导主导 / 现实供需改善 / 预期与情绪主导 / 混合】，依据是【最强 1–2 条证据】；存在【背离项】。库存/需求等领域【有/无】可验证改善。本报告不给出方向建议。

## 4. 关键陷阱（实战中最容易犯）

| 陷阱 | 表现 | 纠偏 |
|---|---|---|
| 用期货上涨充当证据 | "期货大涨说明市场看好供需" | 期货只作待解释对象；找同期现货、库存、开工 |
| 单指标定性 | "库存降了 → 缺货 → 看涨" | 看口径、时点、历史分位、去化持续性 |
| 假期数据误读 | 节后库存跳升 45% 判定"严重过剩" | 假期停开单造成机械累库，看节后 2–3 周 |
| 跨口径比较 | 用全国参考价减某合约算精确基差 | 标注口径混合，只取方向 |
| 成本推动误认供需 | 产量降就觉得缺货 | 产量降若因装置停车/亏损，是"偶发性收缩"；同时看产能投放节奏 |
| 用预测值当现实 | 引用"预计下周涨至 X"为证据 | 预测归入预期类 |
| 无视时序错配 | 说"原油涨带动 PP"，但跳涨当日原油下跌 | 逐日对齐，找驱动事件的真实时点 |
| 择一呈现矛盾口径 | PDH 价差两口径冲突只报一个 | 并列 + 说明口径 |

## 6. 数据源优先级

1. **A 级**：大商所/郑商所/上期所行情、国家统计局流通领域重要生产资料价格、海关总署进出口
2. **B 级**：生意社逐日参考价（免费且可回溯）、隆众/金联创/卓创周报、期货公司产业链周报
3. **C 级**：财经媒体转述（用于确认事件与定性，不作定量支撑）
4. 免费源受限时（如需登录的历史库、被墙的行情 API），**明确标注"未能取得"**，用可公开核验的锚点替代，并在 Excel「08_来源清单」记录抓取日期。

## 7. 合规边界

- 不输出买卖方向、仓位、点位、策略组合。
- 不将第三方机构观点表述为事实。
- 明确标注数据抓取日期，价格类数据注明"仅为历史数据，非实时报价"。
