# 适配演示：同一个 PP 涨价案例，"假如没有期货"该怎么做？

目的：验证本技能**在无期货化工品上的可迁移性**。
做法：保留 PP 的全部现货与产业数据，**删除基差、月差、持仓**三个维度，
然后用 `references/05-no-futures-playbook.md` 的替代结构重新组织证据。

> 现实前置说明：PP 是有期货品种。本节是"假设无期货"的方法演练，
> 用来检验迁移路径能否在信息量减少的情况下仍给出稳健结论。

---

## 1. 失去的信息 vs 补偿方案

| 失去的维度 | 原本提供了什么 | 无期货时的替代 | 替代品质量 |
|---|---|---|---|
| 基差 | 现货 vs 盘面谁更强 | **出厂价 vs 市场价裂口**（金联创：石化/中油上调出厂价，贸易商报价跟涨） | 中 |
| 月差/期限结构 | 市场对远期供需的定价 | **加工价差**（PP − 丙烯）+ **计划产能投放节奏** | 中高 |
| 持仓/成交 | 资金押注意愿 | **贸易商囤货意愿 / 下游备货节奏**（定性） | 低 |
| 期货涨幅 vs 现货涨幅 | 是否盘面独走 | **上下游涨幅比（传导率 β）** | 高 |

**结论：失去的 4 项中，3 项有可用替代，1 项（持仓）无法替代但影响有限。**

---

## 2. 无期货版的"期现结构"：用加工价差重建

### 2.1 加工价差（承担基差的功能）

```
加工价差 = P_PP − P_丙烯
10/01：9,933.33 − 9,707.67 = 225.66 元/吨
10/19：10,756.67 − 10,534.33 = 222.34 元/吨
Δ = −3.32（−1.47%）
```

**判读（与基差功能等价）**：
- 有期货时：基差走强 = 现货比盘面硬
- 无期货时：加工价差走阔 = 下游比上游硬
- 本案例加工价差**持平** → **下游没有比上游更强** → 涨价不是下游拉动的

> 这一步与有期货版的结论完全一致：**成本传导型，非需求拉动**。

### 2.2 传导率 β（承担"期货领先度"的功能）

```
β = Δ_PP% / Δ_丙烯% = 8.29 / 8.52 = 0.973
```
β ≈ 1 → 完全传导 → **成本推动**（与有期货版 §5 结论一致）。

### 2.3 出厂价 vs 市场价裂口（替代"基差走弱"信号）

检索到的原始描述（S02，金联创 2026-10-15）：
> "石化及中油企业**相继上调出厂价格**，成本端强势托底，为本轮涨价提供核心支撑"
> "贸易商报价顺势跟涨，主流牌号现货报价持续稳步上行"
> "需求端……下游对高位货源普遍存在**抵触情绪**，整体采购策略偏谨慎，多采取随用随采，**大规模投机性补货较少**"

**判读**：出厂价上调且市场价跟涨 → 现货端偏强（与基差走强一致）；
但**成交抵抗**（随用随采、无投机补货）→ 对应有期货版中"需求背离"的证据。
在无期货语境下，**"挂牌价上调 + 成交清淡"的裂口，就是最好的替代信号**。

### 2.4 区域价差（应补采，本案例缺失）

PP 有华东/华南/华北三大区价差，本案例**未取得**各区域报价，因此标为**数据不足**。
这正是无期货品种最常见的短板——必须靠多区域现货报价建立"结构"。

## 3. 无期货版的证据矩阵（删除基差/月差/持仓后）

| 主轴 | 支撑上涨 | 背离 | 数据不足 |
|---|---|---|---|
| 现实供给 | 产量 −7.63% | 产能 +11.5%、Q4 投产 | 检修损失量、进口 |
| 现实需求 | — | 塑编 40.18%、BOPP 24.37%、注塑 30.66%、订单不足 | 订单/利润/出口量值 |
| 库存与贸易 | — | 库存 +45.77% | 历史分位、分项库存 |
| 成本变化 | 丙烯 +8.52%、丙烷 +9.23% | 石脑油成本 −1.15% | 两口径冲突、毛利 |
| 预期（替代） | — | 计划产能、下游备货意愿低 | — |

有期货版：**7 支持 / 18 背离 / 7 数据不足**
无期货版：**4 支持 / 13 背离 / 6 数据不足**（删除了 3 条基差/月差/持仓相关证据）

**支持数下降 43%，但结论性质不变**：
> 成本传导型上涨，现实需求未同步改善。

**这说明**：本技能的结论并不依赖期货维度；期货维度主要贡献"预期定价"的识别力，
而"现实是否改善"由供给/需求/库存/成本四个板块独立判定。

## 4. 无期货版本应如何改造交付物

### HTML 报告
| 原模块 | 改造 |
|---|---|
| 「基差与月差结构」图 | → 「**加工价差趋势**」+「**区域价差**」双图 |
| 价格口径选择器（含期货） | → 多地区现货 + 多规格 |
| 涨幅统计条（含期货涨跌幅差） | → 换成"上下游涨幅比 β" |
| 新增模块 | 「**出厂价 vs 市场价裂口**」 |

### Excel 工作簿
| 原表 | 改造 |
|---|---|
| `01_现货期货` | → `01_现货多口径`（地区 × 规格矩阵） |
| `02_基差月差` | → `02_价差结构`（加工价差 + 区域价差 + 出厂-市场价差） |
| 其他 9 表 | 不变 |

### 复核清单增项
- [ ] 已选 ≥2 个地区/规格的现货口径
- [ ] 已计算 ≥1 条加工价差与 β
- [ ] 已观察出厂价与市场价是否裂口
- [ ] 未把"近亲品种期货结构"表述为本品种自身结构

## 5. 迁移到其他无期货品种的模板（以烧碱为例）

| 区块 | 指标 | 替代说明 |
|---|---|---|
| 价格 | 32% 液碱（华东/山东/华南）、片碱、99% 固碱 | 多规格多区域 |
| 结构 | **液碱-片碱价差**（加工关系）、烧碱-纯碱比价 | 加工价差 |
| 供给 | 氯碱装置开工、检修、新增产能 | 常规 |
| 需求 | 氧化铝开工、粘胶、印染、造纸开工 | 常规 |
| 库存 | 液碱罐存、片碱厂库 | 常规 |
| 成本 | 原盐、电（氯碱电耗极高）→ **电价是核心变量** | 成本 |
| 预期 | 氧化铝新产能、出口（澳洲/印尼） | 替代持仓 |

**关键差异**：烧碱的"期现结构"最接近的替代是 **液碱 vs 片碱的加工价差**，
以及 **烧碱/纯碱比价**（纯碱有期货，可作代理）。

---

## 6. 结论

无期货品种**完全可以**使用本技能。
需要删除 3 个维度（基差/月差/持仓），并用 **加工价差 + 传导率 β + 出厂-市场裂口 + 区域价差** 四件套替代。
替代后结论的**方向与性质判定保持稳健**，只是"预期定价"的识别力会下降——
这正是无期货品种研究的固有局限，应在报告中**明确声明**，而不是用估算去填补。
