# 05 · 无期货品种完整适配路径

适用：烧碱、纯碱（液碱/片碱无交割品）、钛白粉、环氧乙烷、双氧水、丙烯酸、己二酸、苯酐、DOP、
氯化石蜡、异丙醇、对苯二酚、有机硅等多种化工品（部分有相关期货如纯碱期货，但其现货规格/区域与期货标的并不一一对应）。

## 5.1 指标映射总表

| 区块 | 有期货版本 | **无期货版本（替代）** | 替代有效性 |
|---|---|---|---|
| 价格表现 | 现货 + 期货 + 基差 + 月差 | 现货（多地区/多规格）+ 区域价差 + 出厂-市场价差 | 高 |
| 期现结构 | 基差、月差、持仓 | **加工价差 + 传导率 β** | 中高 |
| 现实供给 | 产量、开工、检修、进口 | 同左（完全一致） | 高 |
| 现实需求 | 分下游开工、订单、出口 | 同左 + **下游成品库存** | 高 |
| 库存贸易 | 总库存、分项、分位 | 同左 | 高 |
| 成本利润 | 原料价 + 各路线成本 + 毛利 | 同左 + **上下游价差** | 高 |
| 预期 | 远月定价、持仓、板块 | **计划产能 + 投产时点 + 下游备货意愿 + 关联期货代理** | 中 |

## 5.2 "期限结构"的替代方案（核心）

无期货就没有月差，但市场对"未来 vs 现在"的看法仍可被观测：

### 方案 A：加工价差（首选，可量化）
```
加工价差 = P_下游 − P_上游 × 单耗
π% = 加工价差 / P_上游 × 100%

π 扩张 → 下游现实需求强 / 产业链利润向下游转移（偏现实）
π 持平 → 纯成本传导（成本推动型）
π 收缩 → 下游传导受阻 / 需求弱（背离信号）
```

### 方案 B：产区-销区价差
```
区域价差 = P_销区 − P_产区
走阔 → 物流受阻或区域缺货（现实）
收窄 → 产区压力外溢，需求承接不足
```

### 方案 C：出厂价调整滞后
多数无期货品种依赖**厂家挂牌价**调价：
- 出厂价连续上调且市场价跟涨 → 现实偏强
- 出厂价上调但市场价不跟、成交清淡 → **需求背离**
- 这种"挂牌 vs 成交"的裂口，是替代"基差走弱"的最佳信号

### 方案 D：借用近亲品种期限结构（代理）
若品种的上下游有期货，可用其结构作代理：
| 无期货品种 | 可用代理 |
|---|---|
| 丙烯 / 丙烯酸 | PP/PL（聚丙烯）月差与基差 |
| 液碱 / 片碱 | 纯碱期货月差（仅方向参考，需注明） |
| 钛白粉 | 无，改用涂料/塑料下游开工 |
| 甲醇下游（甲醛、二甲醚） | 甲醇期货月差 |
| 环氧乙烷 / 乙二醇 | 乙二醇期货 |

> 代理使用时**必须**在报告中注明"代理指标，非本品种自身结构"。

## 5.3 报告结构差异

无期货版本的 HTML 报告需要：

1. 删除"基差与月差结构"图，替换为「**上下游价差 / 加工价差趋势图**」
2. 在"价格口径"选择器中，把期货相关选项替换为**多地区现货**对比
3. 新增「**出厂价 vs 市场价裂口**」图表区块
4. 证据分类中，"预期"轴改用「计划产能投放 / 下游备货意愿 / 关联品种情绪」

Excel 工作簿差异：
- `01_现货期货` → `01_现货多口径`
- `02_基差月差` → `02_价差结构`（区域价差 + 加工价差 + 出厂-市场价差）

## 5.4 无期货案例的核验重点（经验规律）

| 品种特征 | 现实信号 | 最常见的假信号 |
|---|---|---|
| 厂家集中度高（烧碱、钛白粉） | 龙头调价 + 检修计划 | 挂牌价上调但成交清淡 |
| 下游分散（丙烯酸、DOP） | 下游开工 + 订单 | 贸易商囤货推价 |
| 季节性明显（尿素、氯化铵） | 季节需求节奏 | 淡季囤货被误认为需求 |
| 出口导向（SBS、部分助剂） | 出口订单、海运费 | 汇率与退税扰动 |
