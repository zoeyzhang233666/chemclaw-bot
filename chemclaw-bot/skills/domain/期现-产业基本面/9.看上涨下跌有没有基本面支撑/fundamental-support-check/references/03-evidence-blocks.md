# 03 · 六区块证据字段与采集规范

每条证据必须是一个**自洽的记录**。下表每行对应 `templates/01-evidence-board.csv` 的一列。

## 字段规范（强制）

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `id` | 字符串 | ✅ | 形如 `S3`、`D1`、`I2`、`C4`、`E1` |
| `cls` | 枚举 | ✅ | `供给` / `需求` / `库存` / `成本` / `预期` / `价格` |
| `name` | 字符串 | ✅ | 指标全称，含规格（如"PP拉丝 商业库存总量"） |
| `period` | 字符串 | ✅ | 观测期（如"2026-10-08周"），必须早于报告日期 |
| `metric` | 字符串 | ✅ | **实测值 + 变化**，如"68.78万吨(+21.59万吨，+45.77%)" |
| `hist` | 字符串 | ✅ | 历史位置（分位/同比/区间），无序列则写"—" |
| `verdict` | 字符串 | ✅ | 与价格关系的简短判定，如"支撑"/"背离"/"情绪定价" |
| `status` | 枚举 | ✅ | `支撑上涨` / `背离` / `数据不足` / `中性/预期` |
| `tier` | 枚举 | ✅ | `A` / `B` / `C` / `D` / `—`（数据不足项用 `—`） |
| `src` | 列表 | ✅ | 来源 ID 列表，对应来源清单 |
| `comment` | 字符串 | ✅ | 解读，必须说明**为什么**是这个状态 |

## ① 价格表现

| 指标 | 采集要点 |
|---|---|
| 现货（主规格） | 逐日或锚点；记录口径 |
| 现货（次规格） | 验证是否单一牌号缺货 |
| 期货 | 主连日收盘；标注合约代码 |
| 基差 | 同日同口径 |
| 月差 | 至少两个合约 |
| 涨幅差/持仓 | 事件窗口必采 |

## ② 现实供给

| 指标 | 单位 | 采集要点 | 常见陷阱 |
|---|---|---|---|
| 产量 | 万吨 | 月度或累计，取同比 | 同比降幅须查成因 |
| 产能 | 万吨/年 | 已投产总量 | 与产量口径区分 |
| 产能利用率 | % | 周度，环比变化 | 单周持平≠收紧 |
| 检修/停车/复产 | 万吨/年（**必须带产能**） | 装置名 + 产能 + 日期 | 只有装置名无产能 → 无法加总 |
| 检修损失量 | 万吨/周 | 若能量化优先用 | 常缺失 |
| 新增/计划产能 | 万吨/年 | 区分"已投产/在建/计划" | 计划≠落地 |
| 进口量 | 万吨 | 月度 | 常只有"到港有限"定性 |

**净供给变化公式**（量化装置事件）：
```
NetChange = Σ(重启产能) − Σ(停车产能) − Σ(新增检修产能)     单位：万吨/年
若 NetChange < 0 → 供给收紧
若缺任一项产能 → 标"数据不足"，禁止用装置数量代替产能
```

## ③ 现实需求

| 指标 | 单位 | 采集要点 |
|---|---|---|
| 分下游开工率 | % | 至少 3 个主下游；必须有历史对比 |
| 综合下游开工 | % | 与分行业口径不同，不可混用 |
| 订单/成品库存 | 定性+定量 | 仅定性时标"数据不足" |
| 下游利润 | 元/吨 | 仅定性时标"数据不足" |
| 出口 | 万吨 | 月度 |
| 表观消费 | 万吨 | 产量+进口−出口−库存变化 |

**需求同步性判据**：
- 价格上涨期开工率**上升** → 需求支撑（强）
- 价格上涨期开工率**持平** → 需求中性
- 价格上涨期开工率**下降** → **需求背离**（本案例：塑编 40.56%→40.18%）

## ④ 库存与贸易

| 指标 | 采集要点 |
|---|---|
| 总库存 | 数值 + 上期 + 变化 + 变化% |
| 分项库存 | 生产企业/贸易商/港口分列 |
| 历史分位 | 需 ≥3 年同周次序列；无则显式标缺失 |
| 去化速率 | 连续 2–3 周同向才可确认 |

**库存判读四问**（缺一不可）：
1. **口径**：是总库存还是分项？样本企业变了没有？
2. **时点**：是否跨越长假、月末结算、检修集中期？
3. **历史位置**：在同周次上处于什么分位？
4. **速率**：单周跳还是趋势性去库/累库？

> 反例（本案例）：10/08 商业库存 +45.77%，单看会判"严重过剩"；但当日为节后首日，
> 上游停开单导致机械性累库。正确做法：标记为"背离但需排除假期扰动"，并要求节后 2–3 周数据复核。

## ⑤ 成本与利润

| 指标 | 公式 |
|---|---|
| 原料价格 | 直接采集（原油、丙烷、丙烯、煤、甲醇…） |
| 工艺路线成本 | 各路线分列（油制/PDH/MTO/煤制/乙烷） |
| 加工价差 | 下游价 − 上游价×单耗 |
| 成本传导率 β | Δ下游% / Δ上游% |
| 一体化毛利 | 仅在有完整收率与加工费口径时计算，否则标缺失 |

**传导率 β 判读**：
| β | 判读 |
|---|---|
| β ≈ 1 (0.9–1.1) | 完全传导：**成本推动型**，下游自身供需未改善 |
| β < 0.8 | 传导受阻：下游需求弱 |
| β > 1.2 | 需求溢价：下游现实强于上游 |

> 本案例：PP 涨 8.29% / 丙烯涨 8.52% → β ≈ 0.97（完全传导），加工价差 225.66→222.34（几乎不动）
> → **结论：成本传导型上涨，非现实供需缺口。**这是本方法最具辨识度的一步。

## ⑥ 预期指标（**最容易污染结论的区域**）

只允许以下类型进入：

| 类型 | 示例 | 处理 |
|---|---|---|
| 远月合约定价 | PP2709 = 8421 | 预期证据 |
| 持仓/成交变化 | 增仓 6 万手 | 资金行为 |
| 板块共振 | 多品种涨停 | 系统性溢价 |
| 政策/地缘事件 | 海峡关闭传闻 | 未发生的供给冲击 |
| 机构预测 | "预计下周 10400" | 预测值，不是现实 |
| 计划产能/计划检修 | "Q4 拟投产 800 万吨" | 未落地 |

**强制规则**：预期类证据**永远不能**填 `支撑上涨` 状态，只能是 `中性/预期` 或 `背离`（当它揭示"驱动其实是预期"时）。

## ⑦ 证据等级赋值规则

| 等级 | 判定标准 |
|---|---|
| **A** | 交易所行情、统计局/海关原始发布、官方商品指数（生意社参考价、隆众公开价格） |
| **B** | 专业机构的量化行业数据（隆众/金联创/卓创周报的开工、库存、产量、成本） |
| **C** | 媒体转述、二手评论、海外基准（如 Trading Economics CFD） |
| **D** | 本报告自行推算（价差、传导率、毛利估算）→ 必须写"测算" |
| **—** | 数据不足，无来源 |
