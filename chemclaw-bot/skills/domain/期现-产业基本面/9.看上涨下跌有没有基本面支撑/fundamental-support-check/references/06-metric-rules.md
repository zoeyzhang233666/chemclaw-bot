# 06 · 指标计算规则（R01–R14）

实现参考：`scripts/build_report.py`；Excel 版见工作簿 `09_指标规则` 工作表。

| 编号 | 指标 | 定义/公式 | 判定阈值 | 所需数据 | 无期货适配 |
|---|---|---|---|---|---|
| **R01** | 窗口涨幅 | `R=(P_end−P_start)/P_start` | `\|R\|≥5%` 为明显行情；3–5% 温和；<3% 未达门槛 | 同口径逐日/锚点序列 | 同左 |
| **R02** | 历史分位 | `PR=(低于当前样本数+0.5×相等样本数)/N` | ≥80% 高位；≤20% 低位；N<60 标"样本不足" | ≥3 年同口径序列 | 同左 |
| **R03** | 基差 | `Basis=Spot−Futures` | 正=现货升水；走强+现货涨→现实紧；走弱+期货涨→预期驱动 | 同日同口径现货+期货 | **改用区域价差/出厂-市场价差** |
| **R04** | 月差 | `Spread=P_near−P_far` | >0 Back（近紧远松）；<0 Contango | 两个合约 | **改用加工价差作期限代理** |
| **R05** | 库存变化速度 | `Δ%=(Inv_t−Inv_{t−1})/Inv_{t−1}` | 周环比>+15% 异常（排除假期）；连续 3 周同向才确认 | 周度库存 | 同左 |
| **R06** | 库存历史位置 | 当前库存在过去 N 年同周次的分位 | >70% 偏高；<30% 偏低 | ≥3 年周度序列 | 同左 |
| **R07** | 产能利用率 | `开工=实际产量/有效产能` | 环比连续↓≥2周→供给收紧；单周持平不构成证据 | 周度开工+检修 | 同左 |
| **R08** | 装置事件净效应 | `Net=Σ重启−Σ停车−Σ新增检修`（万吨/年） | <0 供给减少；缺产能则标数据不足 | 装置名+产能+日期 | 同左 |
| **R09** | 产量同比 | `(Q_t−Q_{t−12})/Q_{t−12}` | ≤−5% 实质收缩；须查成因（需求 vs 停车） | 月度产量 | 同左 |
| **R10** | 下游开工率 | `下游实际产量/设计产能` | 价格涨而开工降→需求背离 | 分下游周度开工 | 同左 |
| **R11** | 加工价差 | `Spread=P_下游−P_上游×单耗` | 走阔→利润修复/需求好；持平+双涨→纯成本传导 | 上下游同期价 | **★核心指标** |
| **R12** | 成本传导率 | `β=ΔP_下游%/ΔC_上游%` | 0.9–1.1 完全传导；<0.8 受阻；>1.2 需求溢价 | 上下游同期价 | **★核心指标** |
| **R13** | 与价格同步性 | 指标窗口变化方向与价格方向是否同向 | 同向=支撑；反向=背离；无量=数据不足 | 指标窗口变化 | 同左 |
| **R14** | 证据分级 | A 官方/B 机构/C 媒体/D 测算 | 结论仅由 A/B 支撑；C 仅线索；D 不单独支撑 | 来源元数据 | 同左 |

## 6.1 复合指标（本技能自定义）

### M01 · 盘面独走度
```
Diverge = 期货涨幅% − 现货涨幅%
≥3pct → "盘面独走"，预期类权重上调
```
本案例：7.08% − 2.84% = **4.24pct**

### M02 · 成本传导完整度
```
TC = 1 − |β − 1|
TC≥0.9 → 完全传导（成本推动成立）
```
本案例：β = 8.29/8.52 = 0.973 → TC = 0.973

### M03 · 供给收缩可信度
区分"偶发性收缩"与"趋势性收缩"：
```
Credibility = 产量降幅的证据强度 ÷ 产能扩张速度
若同期年度计划新增产能增速 > 需求增速 → 判为"偶发性收缩"，支撑力打折
```
本案例：产量 −7.63%，但全年新增产能 +11.5% > 需求增速 4–5% → **偶发性收缩**，支撑力打折。

### M04 · 库存方向冲突度
```
Conflict = 1 if sign(库存变化) ≠ sign(价格变化) else 0
冲突时必须有独立解释（假期/停开单/统计口径），否则记为"背离"
```

### M05 · 远期定价背离度
```
FWD = (P_far − Spot) / Spot
FWD 显著为负 → 市场自身不认同现货水平的可持续性
```
本案例：(8421 − 10756.67)/10756.67 = **−21.7%**

## 6.2 数据质量评分（0–100）

用于在报告中提示证据基础的可信度：

```
DQ = 40 × (已核验证据占比)
   + 25 × (A/B 级证据占比)
   + 20 × (有历史序列的指标占比)
   + 15 × (六区块覆盖度)
```
本案例估算：已核验 ~62% → 24.8；A/B ~85% → 21.3；有序列 ~30% → 6；覆盖 6/6 → 15
→ **DQ ≈ 67**（中等：价格与供给可信，库存/贸易/需求历史序列不足）

## 6.3 单位与格式规范

| 类别 | 单位 | 小数位 |
|---|---|---|
| 价格（国内） | 元/吨 | 2 |
| 价格（国际） | 美元/吨、美元/桶 | 2 |
| 产能/产量/库存 | 万吨、万吨/年 | 2 |
| 开工率/占比 | % | 2 |
| 价差 | 元/吨 | 2 |
| 持仓/成交 | 手 | 0 |

金额一律**含税**或**不含税**二者择一并在口径台账声明，不得混用。
