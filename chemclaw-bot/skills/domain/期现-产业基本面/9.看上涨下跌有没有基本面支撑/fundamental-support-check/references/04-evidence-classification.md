# 04 · 证据分级、四轴归类与判定状态机

## 4.1 两个正交维度

任何一条证据都要同时落在两个维度上：

```
维度 A（性质）：  现实供应变化 | 现实需求变化 | 成本变化 | 主要体现预期
维度 B（方向）：  支撑上涨 | 背离 | 数据不足 | 中性
```

它们是**正交**的：一条"预期"证据也可以是"支撑"（如"计划停产 100 万吨"），
但按本技能规则，预期类**不得**判为 `支撑上涨`（因为它尚未发生），只能判 `中性/预期` 或 `背离`。

## 4.2 状态判定状态机（可直接实现）

```python
def classify(evidence, price_dir, cfg):
    """
    evidence: dict(change_dir, is_realized, has_value, tier, confounds)
    price_dir: +1 涨 / -1 跌
    """
    # ① 无量值 → 数据不足（最高优先级，先斩后奏）
    if not evidence["has_value"]:
        return "数据不足"

    # ② 未发生的未来事件 → 归入预期，不得算支撑
    if not evidence["is_realized"]:
        return "中性/预期"

    # ③ 现实指标：方向与价格同向 → 支撑
    if evidence["change_dir"] == price_dir:
        status = "支撑上涨"
    elif evidence["change_dir"] == 0:          # 持平
        status = "中性/预期"
    else:
        status = "背离"

    # ④ 混杂因素降级：含假期/口径污染的样本，不得单独支撑
    if cfg.get("confound_holiday") and evidence.get("period_overlaps_holiday"):
        status = "背离" if status == "支撑上涨" else status
        evidence["comment"] += "（跨假期，含机械性扰动，需后续数据复核）"

    # ⑤ 证据等级约束：C 级不得单独支撑
    if evidence["tier"] == "C" and status == "支撑上涨":
        evidence["comment"] += "（C级二手来源，仅作线索）"

    return status
```

## 4.3 四轴归类的具体规则

| 证据 | 归入轴 | 理由 |
|---|---|---|
| 产量同比、产能利用率、装置停车/复产 | **现实供应变化** | 已经发生的产量调整 |
| 检修损失量、净供给变化 | **现实供应变化** | 已发生的供给减少 |
| 产能投放计划、在建装置 | **预期**（不是供应变化） | 未落地 |
| 下游开工率、订单、成品库存、出口量 | **现实需求变化** | 已发生的需求强度 |
| 下游"预计开工回升" | **预期** | 预测 |
| 原油/丙烷/丙烯/煤价、工艺成本 | **成本变化** | 已发生的成本抬升/下降 |
| 加工价差、传导率 | **成本变化**（传导性） | 反映传导而非需求 |
| 基差、月差、持仓、板块共振、地缘传闻、机构预测 | **预期** | 定价与情绪 |

**边界案例**：基差归"预期"还是"价格"？→ 归 `价格` 区块呈现，但在四轴中归 **预期**，
因为它是市场对未来供需的定价结果，不是现实量。同理，月差归 **预期**。

## 4.4 证据等级（A/B/C/D）与使用约束

| 等级 | 能否作为核心论据 | 能否单独支撑结论 | 呈现要求 |
|---|---|---|---|
| A 官方/交易所 | ✅ | ✅ | 标注发布机构与日期 |
| B 专业机构 | ✅ | ✅ | 标注机构名与报告日期 |
| C 媒体/二手 | ⚠️ 仅线索 | ❌ | 必须写"转述" |
| D 测算 | ⚠️ 辅助 | ❌ | 必须写"测算"+公式 |
| — 缺失 | ❌ | ❌ | 灰色"缺失" |

## 4.5 矛盾证据处理原则

1. **不得择一**：当两个口径给出相反结论（如 PDH 加工价差：机构口径走阔 +37%，直接原料口径持平 −1.5%），必须**并列呈现 + 说明口径差异 + 标注为数据不足**。
2. **不得加权平均**：不同口径的数值不可平均成一个"综合分"。
3. **不得用强证据掩盖弱证据**：一条 A 级支撑证据不能抵消三条 B 级背离证据。
4. 允许给出的"综合判断"只有定性表述：如"成本传导主导、现实需求背离"。

## 4.6 最终判定的四种性质

| 性质 | 标志性证据组合 | 本案例 |
|---|---|---|
| **现实供需改善** | 库存去化 + 开工上行 + 产量收缩（因需求而非停车） + 基差走强 | ❌ 不成立 |
| **成本推动 / 成本传导** | 原料同步大涨 + β≈1 + 加工价差持平 + 下游利润压缩 | ✅ 成立 |
| **预期 / 情绪定价** | 期货涨幅 >> 现货 + 板块共振 + 增仓 + 事件驱动 + 远月不跟 | ✅ 同时成立 |
| **混合** | 多条证据跨类别成立 | 本案例为 **成本传导 + 预期定价** 混合 |

## 4.7 禁止输出的表述黑名单

以下句式一旦出现即视为失败：

- "因此短期看涨/看跌"、"建议逢低做多/逢高做空"
- "期货大涨说明基本面转好"
- "库存下降，证明供给紧张"（未做四问）
- "预计将涨至 X 元"（把预测当结论）
- "机构普遍认为"（无具体来源）
