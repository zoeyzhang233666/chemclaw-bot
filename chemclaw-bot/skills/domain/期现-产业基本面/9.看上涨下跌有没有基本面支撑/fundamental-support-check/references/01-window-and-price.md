# 01 · 窗口锚定与价格测量

## 1.1 核心原则：先测量，后解释

**禁止**：先假设"某品种涨了 10%"，再去找支持证据。
**必须**：先取原始价格序列 → 用公式算出涨幅 → 由实际涨幅确定窗口 → 才进入归因。

> 实战教训（本包案例）：用户与检索线索中流传"节后飙升 7%"的说法，实际是**期货单日涨幅**；
> 同期现货只涨 **2.84%**，而 10 月整月现货涨幅为 **+8.29%**。
> 若不先测量，会得出"现货暴涨"的错误前提。

## 1.2 窗口分层

| 层级 | 定义 | 本案例取值 | 作用 |
|---|---|---|---|
| **主窗口** | 覆盖最大涨幅、且两端都有原始披露值 | 10/01 → 10/19，+8.29% | 主结论依据 |
| **事件窗口** | 驱动事件发生的自然日/交易日 | 10/08 节后首日，期货 +7.08% / 现货 +2.84% | 判断"谁领涨" |
| **中期窗口** | 覆盖完整行情周期（含前期涨幅） | 07/01 → 10/19，+35.47% | 判断"这是新涨还是延续" |
| **跨年窗口** | 同比位置 | 2026 年初 6300 → 9 月中高位 | 判断历史分位 |

规则：
- 主窗口两端**必须**是已披露的原始值，不得用推算值。
- 中期窗口若含多波行情，必须拆分说明（本案例：3 月一波 +40%、9 月一波 +6%、10 月一波 +8.29%）。
- 若用户给的时间区间与数据冲突，**在报告中显式更正**，并保留用户原表述。

## 1.3 "明显行情"的量化门槛

| 情形 | 阈值 | 处理 |
|---|---|---|
| 主窗口涨幅 | ≥ 5% | 认定为"明显行情"，启动完整核验 |
| 主窗口涨幅 | 3%–5% | 核验但结论用"温和波动"表述 |
| 主窗口涨幅 | < 3% | 提示"未达明显行情门槛"，只做价格描述 |
| 单日涨幅 | ≥ 5% | 标记为"异动"，须单独查当日消息面 |
| 期货−现货涨幅差 | ≥ 3pct | 标记"盘面独走风险"，预期类证据权重上调 |

## 1.4 数据状态标签（每个数字都要带一个）

| 标签 | 含义 | 能否用于结论 |
|---|---|---|
| `已核验` | 来自 A/B 级原始披露，日期与口径明确 | ✅ 可作为核心证据 |
| `推算` | 由涨幅/金额反推，或区间取中值 | ⚠️ 仅作辅助，须写明推算方式 |
| `口径混合` | 两端口径不同（如全国参考价减某合约） | ⚠️ 仅取方向，不报精度 |
| `缺失` | 未取得或未披露 | ❌ 显式标灰，禁止估算填充 |
| `区间` | 原始数据为区间（如"10450–10650"） | ⚠️ 取中值须注明 |

## 1.5 计算公式

```
窗口涨幅         R = (P_end − P_start) / P_start × 100%
绝对涨幅(元/吨)   ΔP = P_end − P_start
年化(仅作参考)    R_ann = (1+R)^(365/天数) − 1        # 窗口<30天时慎用，易失真
历史分位          PR = (低于当前值样本数 + 0.5×等于当前值样本数) / 有效样本数 × 100%
样本充分性        交易日样本 < 60 或周度样本 < 52 → 标注"样本不足"
```

## 1.6 现货口径记录表（每个品种都要填）

| 字段 | 示例 | 为什么重要 |
|---|---|---|
| 规格/牌号 | PP 拉丝 T30S | 不同牌号价差可达 1000 元/吨 |
| 是否含税 | 含税 | 含税/不含税差约 13% |
| 地区 | 全国参考价 / 华东主流 | 区域价差可达数百元 |
| 交货方式 | 出库价 / 送到价 | 相差运费 |
| 数据机构 | 生意社 / 隆众 / 卓创 | 同一天可差数十元 |
| 更新频率 | 日度 | 决定能否逐日对齐 |

## 1.7 价格序列缺失时的锚点法

无法取得逐日序列时，按以下优先级取锚点，并在报告中画出"离散点位"而非连续线：

1. 机构周报"本周均价"（每周一个点）
2. 快讯中"X 日价格为 Y，较月初涨 Z%"（可反推月初值）
3. 节前/节后首日、月中、月末等结构化点位
4. 官方月度均价（统计局流通领域重要生产资料）

⚠️ **任何情况下都不得在缺失区间做插值连线**，否则会造出不存在的行情形状。
