# 02 · 基差、月差与无期货替代结构

## 2.1 基差

```
Basis = Spot − Futures            # 现货 − 期货
Basis% = Basis / Futures × 100%   # 便于跨品种比较
ΔBasis = Basis_t − Basis_t-1
```

### 判读矩阵（这是本技能最重要的一张表）

| 现货方向 | 期货方向 | 基差变化 | 判读 | 证据倾向 |
|---|---|---|---|---|
| ↑ | ↑↑ | 走弱（收窄） | 期货领先现货，盘面在给"未来"定价 | **预期驱动** |
| ↑↑ | ↑ | 走强（扩大） | 现货比盘面更紧，现实偏紧 | **现实驱动** |
| ↑ | ↑ | 基本不变 | 现货与盘面同步，通常是**成本对等传导** | **成本驱动** |
| ↑ | ↓ | 大幅走强 | 盘面交易远期供给，现货紧 | 现实与预期分裂 |
| ↓ | ↓↓ | 走强 | 现货抗跌 | 现实暂不弱 |

> **正基差 ≠ 看涨依据**。高基差可由"高现货价格 + 悲观远月"形成，历史上多以现货补跌修复。
> 必须同时回答："这个基差是现货涨出来的，还是期货跌出来的？"

### 口径污染警告

基差必须是**同日、同规格、同地区、同含税口径**。以下做法会制造假基差：
- 用"全国现货参考价" − "某近月合约结算价"（地区与交割品不同）
- 用"华东主流报价" − "主力合约"（主力可能在盘中移仓）
- 用不同日期的现货（如节前价）对同日期货

处理：能对齐则对齐；不能对齐时，标 `口径混合`，**只报方向与量级，不报精确值**。

## 2.2 月差与期限结构

```
Spread(near, far) = P_near − P_far
Spread% = Spread / P_far
```

| 结构 | 定义 | 含义 |
|---|---|---|
| **Back（近强远弱）** | Spread > 0 | 近端现实偏紧 / 远端定价供给宽松。深度 Back 且现货升水 → "近紧远松" |
| **Contango（远强近弱）** | Spread < 0 | 近期过剩、市场预期未来收紧（或含仓储成本） |
| 平坦 | ≈0 | 无结构性信号 |

**核心用法**：月差是"市场自己写的供需预期曲线"。
- 若远月合约价格显著低于现货（如本案例 PP2709 = 8421 vs 现货 10756），说明**市场本身就不认为高价格可持续**——这是预期类证据，也常是"涨势顶部信号"的量化线索。
- 若现货涨、近月涨、远月不涨：现实驱动 → **结构性支撑**
- 若现货涨、近月涨、远月更涨：预期驱动 → **趋势性预期**

## 2.3 涨幅差与持仓

```
同期涨幅差 = 期货涨幅% − 现货涨幅%
ΔOI = OI_t − OI_t-1          # 持仓量变化
Turnover = Volume / OI       # 换手率
```

判读：
- 涨幅差 ≥ 3pct：**盘面独走**，必须找到同期**板块级**证据（同板块其他品种是否同步大涨）
- 增仓上涨：新资金入场 → 押注未来（预期类证据），不是现货紧张
- 减仓上涨：空头回补 → 也可能是"被动上涨"
- 今日持仓较前值下降而价格上行 → 空头减仓主导，持续性存疑

> **板块共振法则**：若同日同板块多个品种涨停/大涨（本案例：甲醇、PX、纯苯、苯乙烯主力封涨停），
> 则该品种的涨幅很大程度是**系统性风险溢价**，个别品种的供需对其解释力被大幅稀释。此时必须下调"供需驱动"的权重。

## 2.4 无期货品种的替代结构 ★

没有期货，就没有基差和月差。**但"期限结构"的经济含义可以用以下四个替代物承接：**

### 替代物 1：上下游加工价差（首选）

```
加工价差 = P_下游 − P_上游 × 单耗
加工价差% = 加工价差 / P_上游 × 100%
```

它承担了"近端现实 vs 远端预期"的部分功能：价差扩张 = 下游有需求溢价；价差持平 = 纯成本传导。

### 替代物 2：区域价差

```
区域价差 = P_销区 − P_产区
```
- 走阔：物流紧张或区域缺货（现实信号）
- 收窄：产区库存压力向销区传导

### 替代物 3：出厂价 vs 市场价

```
出厂-市场价差 = P_出厂 − P_市场
```
- 出厂价持续上调且市场价跟涨 → 上游主动挺价，现货偏强
- 出厂上调但市场价不跟 → 需求承接不足（背离信号）

### 替代物 4：品质/牌号价差

高低端牌号价差走阔 → 结构性短缺（如本案例纤维料与拉丝料同涨，说明非单一牌号缺货）。

## 2.5 对照表：有期货 / 无期货指标映射

| 有期货品种指标 | 无期货替代指标 | 替代有效性 |
|---|---|---|
| 基差 | 出厂价−市场价差、区域价差 | 中（缺"标准化合约锚"） |
| 月差 | 加工价差、期货（若品种近亲有期货，如 PP 之于丙烯） | 中 |
| 期现涨幅差 | 上游涨幅 vs 下游涨幅（传导强度） | 高 |
| 持仓/成交 | 订单量、排产、贸易商库存 | 中 |
| 期货远月定价 | 产能投放计划 + 新产能投产时点 | 中 |

> 若品种的近亲有期货（如丙烯之于 PP、纯碱之于玻璃），**优先借用近亲品种的期限结构作为代理**，
> 并明确标注"代理指标"。
