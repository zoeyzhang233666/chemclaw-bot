# 07 · 交付前复核清单

逐项打勾，任何一项未通过都不得交付。

## A. 窗口与价格

- [ ] 主窗口起止两端均为**已披露原始值**（非推算、非区间中值）
- [ ] 涨幅可由原始序列**独立复算**，报告中的数字与复算一致
- [ ] 已给出事件窗口与中期窗口，且说明三者关系
- [ ] 每个价格数字带**数据状态标签**（已核验/推算/口径混合/缺失）
- [ ] 现货口径写明：规格、含税、地区、交货方式、机构、频率
- [ ] 未在缺失区间插值连线

## B. 期现结构

- [ ] 基差为**同日同口径**；若不能对齐，已标 `口径混合` 且只报方向
- [ ] 已计算期货−现货涨幅差，并据此判断是否"盘面独走"
- [ ] 月差至少两个合约，并给出 Back/Contango 判读
- [ ] 持仓变化已归入**预期类**，未当作供需证据
- [ ] 无期货品种：已用加工价差/区域价差/出厂-市场价差替代，并注明

## C. 六区块完整性

- [ ] ① 价格表现 ✅
- [ ] ② 现实供给：产量、产能利用率、装置事件（**带产能**）、新增产能
- [ ] ③ 现实需求：≥3 个下游开工率 + 订单/成交定性
- [ ] ④ 库存与贸易：总库存 + 变化 + 变化速度 + 历史位置（四问齐备）
- [ ] ⑤ 成本与利润：原料 + 工艺路线 + 加工价差 + 传导率 β
- [ ] ⑥ 预期指标：远月/持仓/板块/政策计划/机构预测（且全部归入预期）

## D. 证据质量

- [ ] 每条证据都有 日期 + 口径 + 来源 + 等级
- [ ] **没有任何一条**证据以"期货/价格本身上涨"作为依据
- [ ] 缺失项全部显式标注为「缺失」，**零估算填充**
- [ ] C 级来源均标注为"转述/线索"，未单独支撑结论
- [ ] D 级测算均标注"测算"并给出公式
- [ ] 矛盾口径**并列呈现**，未择一、未平均

## E. 结论纪律

- [ ] 结论仅描述**性质**（现实驱动/成本传导/预期定价/混合），不含方向
- [ ] 全文无"做多/做空/看涨/看跌/建议买入/目标价"
- [ ] 已分别列出：**支持** / **背离** / **无法核实** 三类
- [ ] 已说明统计滞后（日/周/月）及其影响
- [ ] 已说明"单一库存指标不足以判定供给紧张"

## F. 交付物

- [ ] HTML：六区块完整、可筛选、可点选查看历史与来源链接
- [ ] HTML：离线可打开（无外部 CDN 依赖）
- [ ] Excel：11 个工作表齐全（封面/现货期货/基差月差/供需平衡/库存贸易/成本利润/证据分类/历史序列/来源清单/指标规则/口径滞后）
- [ ] Excel：来源清单含 URL 与抓取日期
- [ ] 两件交付物的数字**完全一致**
- [ ] 已做后端校验：无 JS 运行时报错、无空区块、无 `None`/`NaN` 泄漏

## G. 常见返工点速查

| 症状 | 修复 |
|---|---|
| 结论写成"涨势有基本面支撑，建议关注" | 删去建议句；把"支撑"限定到具体证据 |
| 库存下降就写"供给偏紧" | 补做库存四问；补历史分位 |
| 只有定性没有数字 | 标"数据不足"，不要编造数字 |
| 引用了机构预测当证据 | 移入预期类 |
| 期现结构用不同日期 | 重算或标口径混合 |
| 报告与 Excel 数字不一致 | 以 Excel 为准重新生成 HTML |
