## 五条核心结论

### 1｜唯一走完全链条的是塔里木二期 45 万吨

2026-03-27 试压 → 04-23 挤压造粒实物料试车 → 05-21 中交 → 07-16 一次开车
→ 07-25 打通全流程出合格 PP → 07-30 首发 → 09-24 首次高负荷标定 → **10-15 全面商业运营**。

这是全库中唯一可以写"已形成有效供应"且无需加任何限定的装置。
它包含了中国石油自主 PP 技术首次工业化应用、同等规模大型挤压造粒机组首次国产化两个技术里程碑。

### 2｜已开车但未形成稳定供应：古雷 95 万吨 + 中煤榆林 60 万吨

**中沙古雷**：40 万吨（抗冲/无规）+ 55 万吨（均聚/无规）两条线已于 2026-09 中旬测试开车一次成功，
55 万吨线 2026-04-26 中交（比合同节点提前 35 天）。**但乙烯龙头装置计划 10 月底才投料试车**——
聚合线开车 ≠ 乙烯稳定供料。11 月"全面投产"是目标而非既成事实。

**中煤榆林二期**：2×30 万吨（不是 45 或 60 单套），2026-07-12 中交，
**2026-08-05 挤压机组联动试车成功产出第一粒 PP 料**，全流程负荷待观察。

### 3｜2026 年内最大变数在四套"年底投产"的装置

华锦阿美 100 + 荣信 40 + 东明盛海 35 + 宝丰宁东四期 25 = **200 万吨**，
全部停留在"设备安装"且无任何试车报道。

**荣信最危险**：2025-12 土建收官时设备安装仅完成 **12%**，却报"2026 年底出产品"。

### 4｜最强的反向信号：利华益维远 20 万吨，装置已建成却"择机安排试生产"

- PDH 装置 2023-11-21 就已投产
- PP 装置到 2026-04-27 业绩说明会仍是："已建设完成，公司将结合市场供需形势，**择机安排试生产**"
- 年报显示工程进度 100%、**未转固**

它证明：**PP 装置的开车时点由价差决定，不由工程进度决定。** 这个案例应当用来校准对所有项目的判断。

### 5｜新疆是全国最拥挤的地方：未来新增 530 万吨

准东（宝丰 195 + 兖矿新疆 40 + 新疆能化 50）、哈密（山能 40 + 疆纳 35）、
库车（塔河 50）、乌鲁木齐（乌石化 45）同时推进。

这占现有全国产能的 10.7%，但本地消费能力有限，几乎全部依赖外运——
这不是"新疆供应过剩"，是**全国物流与价差格局要重画**。

## 怎么把这个案例改成你的产品

1. 复制 `data/` 到新目录
2. 清空 `projects.json` 的 `projects`/`excluded`、`progress.json` 的 `progress`、`sources.json` 的 `sources`
3. 改 `config.json`：`product` / `baseline_capacity_wan` / `baseline_capacity_source` / `route_baseline_2026` / `region_baseline_2026`
4. 改 `scripts/ppctl.py` 顶部的 `ROUTE_CLASS`（每个产品的工艺路线不同）
5. 按 `references/02-字段口径.md` 重新建档
6. `python scripts/ppctl.py all <目录>`

**本案例的 `projects.json` 是最好的字段填法参照**——尤其看 `uncertainty`、`dup_note`、`watch` 三个字段的写法。
