# 05 · 汇总口径

本文回答：**怎么把逐项目的档案加总成一个能用的平衡表**，以及**哪些数字不许加总**。

## 一、四类互斥的产能状态

任何时刻，每一套装置只属于以下一类。四类相加 = 名义新增合计，**不重复、不遗漏**。

| 状态 | 判定（`stage` 取值） | 能否计入当前供给 |
|---|---|---|
| **已投产** | 运行 / 达产 / 投产 | ✅ 可以 |
| **试车调试** | 试车 | ❌ 不可以（未形成稳定商品供应） |
| **建设中** | 中交 / 设备安装 / 建设 / 开工 | ❌ 不可以 |
| **计划中** | 核准 / 环评批复 / 环评受理 / 备案 / 拟建 | ❌ 不可以 |
| （单列）暂停取消 | 暂停 / 取消 | 不参与净增计算 |
| （单列）替代退出 | 由 `replace_wan` 给出 | 从供给中**扣减** |

### 为什么"试车"要单列，不能并入已投产

这是本方法与常见行业统计最大的差异点。

- 试车装置可能只开几天就停（催化剂问题、原料不足、设备故障）
- 试车产出的料常常是过渡料/协议料，不进正常价格体系
- 上游原料装置未贯通时，聚合线开车也无法连续生产

案例中的中沙古雷：40 万吨线和 55 万吨线在 2026-09 中旬均测试开车一次成功，
**但乙烯龙头装置要到 10 月底才投料试车**。聚合线开车 ≠ 乙烯稳定供料。
把它算作"已投产 95 万吨"会让 2026 年的供给增量虚高近 20%。

## 二、年度汇总的归年规则

| 状态 | 归到哪一年 | 理由 |
|---|---|---|
| 已投产 | **`actual_online_date` 的实际年份** | 事实优先，不看你"计划"是哪年 |
| 试车调试 | `latest_plan_date` 的年份 | 尚未形成供应，按预期归年 |
| 建设中 | `latest_plan_date` 的年份 | 同上 |
| 计划中 | `latest_plan_date` 的年份 | 同上 |
| 计划日期缺失 | 归入"未定"桶（代码用 9999） | **不猜测** |

### 两个容易错的细节

**细节 1：已投产的项目按实际年份归，不按计划年份归。**

东华能源茂名一期：计划建成年份与投产年份不同，实际 2023-09-15 投产 →
归 2023 年，不归计划年份。否则会与现有产能基数重复计算。

**细节 2：一个项目不同装置可能落在不同年份。**

塔里木二期 PP 装置 2026-07 出合格品，PE 装置可能更早或更晚。
按装置归年，然后项目层面呈现"跨年"。

## 三、净新增与占比

```
名义新增（某年）  = 已投产 + 试车调试 + 建设中 + 计划中
替代退出（某年）  = 该年所有装置的 replace_wan 之和
净新增（某年）    = 名义新增 − 替代退出
占现有产能比      = 净新增 / 基准产能
```

**基准产能必须写明口径与来源日期。** 行业里同一个产品的"现有产能"能差出几百万吨：

案例中 PP 的四个口径：

| 口径 | 数值 | 来源 |
|---|---|---|
| 金联创 2026-10-15 | 4969.5 | 本台账基数 |
| 卓创 2026-12-31 预测 | 5192.5 | 含年内新增 |
| 2025 年末 | 4903 | — |
| 2025-06 | 4773 | — |

**占现有产能比这个数字，换一个分母就能差 8%。** 所以必须：
1. 固定一个基数并写清来源
2. 把所有备选口径并列列出（进 `config.json` 的 `baseline_alternatives`）
3. 在正文里说明"若换用另一口径，该比例为 X%"

## 四、隐性供给缺口 ★

**定义**：名义计划落在目标年份、但当前工程证据不支持在该年内形成供应的产能。

这是本方法区别于所有"投产计划表"的核心。业界通行的做法是把所有"计划 2026 年投产"的项目加总，
得到一个漂亮的大数字；本方法认为这个数字必须再打一次折。

### 三条机械可审计的判定规则

**R1｜已明确延期且幅度大**
```
条件：latest_plan 年份 ≤ 目标年份  且  delay_months ≥ 6
含义：已经公开推迟超过半年，年内达成概率低
```

**R2｜仍是批文阶段**
```
条件：latest_plan 年份 ≤ 目标年份  且  stage ∈ {拟建, 备案, 环评受理, 环评批复, 核准}
含义：连土建都没开始，年内投产在工程上不成立
```

**R3｜主体仍在设备安装且无试车报道**
```
条件：stage == 设备安装
含义：设备安装到出合格品通常还需 6-12 个月（管道预制、仪表调试、单机试车、联动试车）
```

**三条规则都不依赖主观打分**，任何人拿到同样的数据都会得出同样的判定结果。这是设计上的刻意选择——
期现研究的结论要经得起别人复核。

### 案例：280 万吨的缺口

2026 年名义新增 480 万吨，其中 280 万吨（58%）被判定为隐性缺口：

| 项目 | 产能 | 规则 | 依据 |
|---|---|---|---|
| 华锦阿美 | 100 | R3 | 32 套装置 2025-12-25 机械竣工，2026-07-16 总体建设完成，2026-09-28 单机试车收尾，但 PP 无独立中交/试车通稿 |
| 荣信化工 | 40 | R3 | 2025-12 土建收官时设备安装仅完成 12%，却报"2026 年底出产品" |
| 东明盛海 | 35 | R3 | 2026-01 仍在土建施工，无试车报道 |
| 宝丰宁东四期 | 25 | R3 | 公司 2026-09-10 称 12 月下旬出合格乙烯丙烯，PP 无试车报道 |
| 镇海 5#PP | 40 | R1 | 会议定"5 月初出合格产品"，至 2026-10 无任何确认，实质延期约 5 个月+ |
| 利华益维远 | 40 | R1+R3 | 建成未开车，公司称"择机安排试生产" |

**这就是整个技能最有价值的一个数字**：不是 480 万吨，而是 200 万吨左右。

## 五、爬坡折扣（不做但要说）

**设计产能 ≠ 年度产量。本方法明确不把设计产能折算为产量。**

理由：
1. 开工率由价差驱动、逐月变化，属于另一套跟踪体系
2. 新装置爬坡曲线非线性
3. 把两者混算会得出"看似精确、实则错误"的供应增量

但必须在正文里**定性说明爬坡影响**，让读者知道 480 万吨对当年实际供应量的含义可能只有 200 万吨级。

参考区间（写在 `config.json` 的 `ramp_up_discount`）：
- 首年产能利用率：40%-70%
- 稳定后：75%-90%
- 从投料到满负荷：1-3 个月（顺利）/ 6-12 个月（不顺）

**表述方式**：
> 2026 年名义新增 480 万吨；扣除隐性缺口 280 万吨后，年内可落地约 200 万吨；
> 再考虑新装置首年爬坡（利用率 40%-70%），对 2026 年实际产量的贡献约在 80-140 万吨量级。
> 该数字仅为量级判断，不作为产量预测。

## 六、地区汇总

按 `province` 汇总，输出：已投产 / 试车 / 在建+计划 / 合计 / 替代退出 / 装置数 / 项目数。

### 三个必须注意的点

**1. 区域归属要落到"装置所在地"，不是"企业注册地"。**
案例：宝丰能源注册在宁夏，但其新疆项目在准东，必须计入新疆。
如果按注册地归属，新疆的 530 万吨会被错记到宁夏，区域结论完全反了。

**2. 区域产能占比的分子分母口径必须一致。**
行业机构给的"某省占全国 X%"通常是**现有产能**结构。
拿它去比"未来新增的地区占比"是错的——分母不同。要么都用现有产能，要么都用新增产能。

**3. 集中度风险要单独提示。**
案例：新疆未来新增 530 万吨，占全国现有产能 10.7%，但新疆本地消费能力有限，
几乎全部依赖外运。这不是"新疆供应过剩"，是"全国物流格局重画"。区域表里看不出来，必须在正文里写。

## 七、工艺路线汇总

按 `process` 汇总，核心指标：

```
某路线新增 / 该路线现有产能 = 该路线的扩张倍数
```

案例（PP）：

| 路线 | 新增 | 现有 | 扩张倍数 |
|---|---|---|---|
| 油制 | — | 2924.5 (56.3%) | — |
| 煤制 | — | 1034.0 (19.9%) | — |
| PDH | — | 980.0 (18.9%) | — |

扩张倍数越高，该路线在边际定价中的话语权变化越大。
若 PDH 的扩张倍数显著高于油制，意味着**丙烷进口价对 PP 成本曲线的影响力上升**。

## 八、多口径披露：一张必须有的表

机构预测分歧越大，越说明这个品类的投产节奏难以判断。案例中 2026 年新增产能的机构预测：

| 来源 | 口径 | 数值 |
|---|---|---|
| 卓创资讯 2026-08 | 计划新增 | 370 |
| 金联创 + ChemNet | Q4 计划 | 430 |
| 金联创 2026-06 | 计划新增 | 460 |
| 江苏省化工行业协会 | — | 545 |
| 卓创早期 | — | 565 |

**最高与最低相差 195 万吨（53%）。**

**方法论上的态度**：不用任何机构的总量去倒推项目，只做逐项目工程证据加总。
然后把机构口径和自己的加总并列，判断"我站在市场预期的哪一侧"。
如果你的加总显著低于机构，要么是你漏了项目，要么是机构高估了——两种都是有用的结论。

## 九、汇总表必须带的限定语

任何一张汇总表、任何一个数字，都要能回答：

1. 统计范围是什么（哪些项目、哪个时间窗）
2. 产能状态是什么（已投产/试车/在建/计划，哪一类还是要全部）
3. 分母是什么（现有产能哪个口径、什么日期）
4. 是否已扣除替代退出
5. 是否已扣除隐性缺口

**不允许出现不标状态的裸产能数字。**

## 自检清单

- [ ] 四类状态互斥，相加等于跟踪产能合计
- [ ] 已投产项目按实际投产日期归年，不按计划年份
- [ ] 计划日期缺失的项目归入"未定"，没有猜年份
- [ ] 基准产能口径与日期已写明，备选口径已并列
- [ ] 隐性缺口按 R1/R2/R3 机械判定，每条都附了依据
- [ ] 没有把设计产能折算为产量
- [ ] 爬坡影响已定性说明，且标注"不作产量预测"
- [ ] 地区归属按装置所在地，不按企业注册地
- [ ] 区域占比的分子分母口径一致
- [ ] 机构预测分歧已并列披露
- [ ] 每个产能数字都带状态标签
