# 01 · 检索与信源

本文回答两个问题：**去哪里找**、**找到的东西算什么等级**。

## 一、检索的两条主线

### 主线 A：最近 6-12 个月新披露的项目

目的是抓住"才刚刚浮出水面"的增量，这些项目还没进入任何机构的统计表。

按披露环节倒推，每个环节对应一种可检索的公开文件：

| 披露环节 | 典型文件 | 检索关键词 | 能拿到什么 |
|---|---|---|---|
| 项目备案 | 省投资项目在线审批监管平台、备案证 | `<产品> 项目备案`、`<企业> 备案 公示` | 项目名称、业主、投资额、建设地点、拟开工/拟建成时间 |
| 环评第一次公示 | 环境影响评价公众参与第一次公示 | `<项目名> 环境影响评价 第一次公示` | 项目概况、装置清单、产能、产品方案 |
| 环评征求意见稿 / 报批前公示 | 环境影响报告书征求意见稿、报批前公示 | `<项目名> 环境影响报告书 征求意见稿` | **最详细的装置级产能清单**（本项目最重要的信源） |
| 环评受理 / 批复 | 省生态环境厅受理公示、批复（含文号） | `<项目名> 环评 受理 公示`、`关于<项目名>环境影响报告书的批复` | 权威的、法律意义上的产能与装置配置 |
| 核准 / 备案批复 | 省发改委核准批复 | `关于<项目名>核准的批复` | 主体工程装置清单（常与环评口径略有差异） |
| 节能审查 | 节能报告审查意见 | `<项目名> 节能审查` | 能耗指标、间接印证规模 |
| 社会稳定风险评估 | 稳评公众参与公告 | `<项目名> 社会稳定风险评估 公众参与` | 早期项目线索（比环评更早） |
| 用地/规划 | 建设用地规划许可、选址公示 | `<项目名> 用地 公示` | 确认项目真实落地 |

> **环评征求意见稿和环评批复是最高性价比的信源。** 它一次给出装置清单、单套产能、工艺路线、总投资、年操作时间，
> 而且是一手文件。本项目 37 个项目里有 22 个的核心字段来自环评文件。

### 主线 B：未来 1-2 年预计投产的在建项目

目的是抓"已经进入工程阶段、投产时间可预期"的增量。

| 工程节点 | 典型文件 | 检索关键词 | 价值 |
|---|---|---|---|
| 开工 | 开工仪式通稿（政府网站、央企/国企官网、EPC 承包商） | `<项目名> 开工`、`<项目名> 开工仪式` | 项目从纸面进入实施的分界点 |
| 建设里程碑 | 大件吊装、框架封顶、球罐封顶 | `<项目名> 吊装`、`<装置> 封顶` | 判断真实进度的硬证据 |
| 机械竣工 / 中交 | 中交通稿（EPC 单位最常发） | `<装置> 中交`、`<项目名> 机械竣工` | 从施工转入生产准备的节点 |
| 试车 | 单机试车、联动试车、投料试车、挤压造粒试车 | `<装置> 试车成功`、`<装置> 投料` | **最关键**：开车与否的分水岭 |
| 投产 / 出合格品 | 企业公告、新闻通稿 | `<装置> 产出合格`、`<企业> 投产公告` | 形成供应的确证 |
| 达产 / 商运 | 高负荷标定、商业运营发布会 | `<项目> 商业运营`、`<项目> 满负荷` | 不确定性消除的终点 |

> **EPC 承包商官网是被严重低估的信源。** 中国化学工程各建设公司（华陆、五环、三化建、十四化建、十六化建）、
> 中石化各工程公司会主动发布自己承建装置的中交/试车通稿，往往比业主更早、更详细。
> 案例中"古雷 55 万吨 PP 中交""中煤榆林 Unipol PP 产出第一粒料"都来自承包商通稿。

## 二、信源分级

| 等级 | 定义 | 典型信源 | 能否单独支撑"已投产" |
|---|---|---|---|
| **A** | 一手权威 | 企业公告/定期报告、生态环境部门环评批复与公示原文、政府核准或备案文件、企业官方发布（官网、官方公众号） | 可以 |
| **B** | 一手转载或专业数据库 | 政府网站/权威媒体（新华、人民、中国日报、中国能源报）对一手文件的**完整转述**、金联创/卓创/隆众等专业机构数据库、券商研报 | 可以，但需注明是转述 |
| **C** | 二手行业资讯 | 化工网（ChemNet）、搜狐号、微信公号的整理与转述 | **不可以**，只能做线索 |
| **D** | 弱证据 | 百科、自媒体汇编、论坛帖子 | 不可以，仅定位线索 |

**判定等级的实操口径**：

- 看到"据某机构统计"→ 至少是 B，但要问是原始数据库还是二手转述
- 看到"据不完全统计""盘点""一文看懂"→ C
- 标题含"或""有望""预计"且无文件链接 → C 或 D
- 政府网站转载权威媒体（如 `sasac.gov.cn` 转央广网）→ A（政府背书）或 B（明确标注转载源）

## 三、检索引擎的实操经验

不同引擎对不同类型的中文查询效果差异极大。**按查询类型选引擎**，不要死用一个。

| 查询类型 | 推荐引擎 | 说明 |
|---|---|---|
| 中文化工产业查询 | `keenable` | 中文化工内容覆盖最好，长尾项目名召回率高 |
| 政府文件（原文） | 直接 `web_fetch` 政府域名 | 站内搜索往往比通用引擎更准 |
| 专业机构数据 | `advanced_search` + 机构名 | 如 `卓创资讯 PP 产能 2026` |
| 财经/券商 | `yfinance`/`sec_edgar` 不适用时用 `advanced_search` | 中文财经内容用通用引擎即可 |

**已知失效或低质量的路径（踩过坑，勿反复尝试）**：

- `googlenews` 域内搜索常 ETIMEDOUT
- `gdelt` 常返回 HTTP 429（限流）
- `searxng` 公共实例大面积 429
- 部分化工资讯站（如 chemnet 的某些页面）有安全拦截，返回"正在进行安全检查"
- `web_fetch` 对部分站点 30s 超时 → 改用 `Invoke-WebRequest -UseBasicParsing -TimeoutSec 40` 带 UA 头下载后本地解析
- 部分国内站点只支持 http 而非 https，且抓取工具只收 https → 同上，用本地下载

**UA 头必带**。大量化工资讯站、政府站会对无 UA 的请求返回空页或 403。

## 四、检索的四个深度层级

不要一上手就追求全量。按需要选择深度：

**L1 扫面（30 分钟）**：用行业资讯的"年度投产计划汇总表"拿到线索池。产出 30-60 条项目名称与粗口径产能。
此时全部标 C 级，**不写任何结论**。

**L2 定位（1-2 小时）**：对每条线索找到至少一个 A/B 级来源，确认项目真实存在、业主是谁、产能在哪个数量级。
剔除归属错误、口径混算、已投产、非本产品（这一步能砍掉 20-40% 的线索）。

**L3 建档（每个重点项目 20-40 分钟）**：对进入未来 2 年窗口的项目，逐条建立进展事实链，
每个关键节点必须有来源。这是工作量的主体。

**L4 深核（针对 5-10 个最关键项目）**：专门去查企业公告、上交所/深交所披露、投资者关系答复、
政府专项会议纪要，把"最新预计投产时间"钉死。找出信息缺口并明确标注。

## 五、必须检索的三类"反向信息"

大多数研究者只找"有利证据"。要判断投产时间，**反向信息往往更有价值**：

1. **延期信号**：设备安装完成率低、施工通稿里不再提投产时间、招工/采购计划推迟、企业把该项目从在建工程中移出
2. **不确定性披露**：企业说"择机""视市场情况""结合供需形势安排试生产"——这是最强的延期信号
3. **退出与置换**：老旧装置关停公告、五部委《关于开展石化化工行业老旧装置摸底评估的通知》后的地方执行文件

> 案例中最有价值的一条判断，来自利华益维远 2026-04-27 业绩说明会的原话"20 万吨/年高性能聚丙烯装置已建设完成，
> 公司将结合市场供需形势，**择机安排试生产**"。这句话把该项目从"2026 年投产"直接改判为"时间不可预测"。

## 六、检索记录的最小要求

每一条检索结果，在入库前必须能回答：

- 消息日期（发布日）？
- 事实发生日期（事情本身是哪天发生的）？
- 发布者是谁？是原始文件的发布方，还是转述者？
- 给出的是"批复口径"还是"行业统计口径"？

四个都答不上来的，不进库。
