期现知识解释 · 场景 18 · 用通俗语言解释一个期现问题

甲醇港口库存下降，为什么甲醇价格仍然可能下跌？

品种：甲醇（郑州商品交易所(CZCE)） 现货地区：江苏太仓（华东主流市场与主要交割地） 期货合约：MA2701（2027年1月）；10月16日之前主力为 MA2611 数据截至：2026-10-19（期货日线）/ 2026-10-20（部分现货快讯） 生成时间：2026-10-20 12:38
01

直接回答

先给结论，后面每一句都能在数据区找到对应数字

可以下跌，但要把'库存下降'和'价格下跌'放到同一个时间尺度上检验：这次核对窗口里，库存自10月8日统计期低点开始已经转为累库，价格下跌发生在'库存仍在历史低位'而不是'库存还在下降'的背景下。7月至10月8日库存确实从64.15万吨降到30.51万吨（-52%），但同一段时间价格是暴涨的。

同期并存核对：NOT FOUND（同一周内'库存下降+价格下跌'未出现） 结论性质：分尺度成立 机制存在 ≠ 本次已发生

用大白话说

港口库存就像“全国最大的几个罐子”里还剩多少货。罐子里的货少，通常意味着“货紧、要涨价”； 但这次真正发生的是：罐子里的货确实很少（2026-10-08 只剩 30.51 万吨，是这段统计里最低的）， 可就在同时，新的船又开始陆续到港、下游最大的买家（做烯烃的工厂）停了车，所以价格从节后的高点一路往下走。 换句话说：“库存低”是一个状态，“下游还要不要货”才是决定涨跌的方向盘。库存低不会自动等于价格涨。
还要特别注意一件事：从 2026-10-08 的 30.51 万吨到 2026-10-14 的 36.72 万吨， 库存其实已经回升了 6.21 万吨。所以网上常见的说法“库存下降，价格却跌”， 严格讲应该是“库存曾经降得很低、现在开始回升，价格同时在高位回落”。时间尺度不一样，说法就完全不一样。

4.1 港口库存 vs 期货

库存：隆众样本港口库存（万吨，左轴，周度 15 期）；价格：MA2701 收盘（元/吨，右轴，日度 9 点）

低谷出现在 2026-10-08（30.51 万吨），此后已回升；而期货在 10/8-10/9 冲高后回落。 两条线的“拐点”几乎同时但方向相反：库存见底回升，价格见顶回落。

4.2 太仓现货、期货与基差

现货为隆众太仓日度订价（10/16 为成交区间中值）；基差 = 现货 − 期货收盘

基差在 10/13 一度收窄到 610 元/吨，10/15 又回到 813 元/吨， 说明现货跌得比期货慢——这是“低库存仍在托底现货”的直接证据。

4.3 月差 MC（远月 − 近月）

MC = MA2701 − MA2611；负值代表近月升水（back 结构）

MC 从 -412 收敛到 -192（变化 220）： 近月依然比远月贵，但“贵”的程度在快速缩小，即市场在用月差表达“短期货紧、远期供应恢复”。

4.4 换月陷阱：2611 与 2701 的价差

同一日期两个合约的收盘价，10/19 主力由 2611 切换为 2701

如果直接用 MA2611 在 2026-10-09 的收盘价和 MA2701 在 2026-10-19 的收盘价相减， 会得到 -18.04% 的“跌幅”，其中约 2/3 来自换月跳空，不是真实跌幅。正确口径是同一合约或涨跌幅比较。

5.2 月差与库存变化

// 月差（本页定义） MC = F(far) − F(near) MC > 0 → contango（近月贴水） MC < 0 → backwardation（近月升水） 2026-09-30: 2,972 − 3,384 = -412 2026-10-19: 3,143 − 3,335 = -192 ΔMC = -192 − (-412) = 220 // 周度库存变化 ΔInv = Inv(t) − Inv(t−1) 2026-10-14: 36.72 − 30.51 = +6.21 万吨 环比 = ΔInv / Inv(t−1) = +20.35%
// 库存流量恒等式（只能算“表观提货”，不是真实需求） ΔInv = 到港 − 提货 − 损耗 ± 口径差 ⇒ 表观提货 = 到港 − ΔInv = 15.90 − 6.21 = 9.69 万吨

06

产业逻辑：库存为什么会“失灵”，以及什么时候不失灵

甲醇的教科书链条是 库存↓ → 现货紧 → 涨价；但链条上有三个必须同时满足的前提

6.1 教科书链条的三个前提（缺一个，结论就会反转）

前提1 货真的少去库原因必须是“提货多”，不是“到不了货”或“没人要”
前提2 下游真要下游开工率、利润至少在正常水平，能持续接货
前提3 缺口能持续进口/国内产量不能马上补上，否则期货先跌
本次核对：前提1 部分成立（10/8 是外轮断供造成的被动去库）；前提2 不成立（江浙 MTO 负荷 20.06%）；前提3 不成立（到港 3.88 → 15.90 万吨）。 三个前提只满足部分，所以“库存低”没能兑现成“价格上涨”。

6.2 六条可验证的路径

路径预期表现用什么验证本次的对应情况
L1 库存下降 + 下游抢货 现货涨得比期货快 → 基差走强；近月强于远月 → back 加深看下游开工率是否上升、基差是否同步走强2026-09 → 10/08 的价格上涨更接近这一路径（库存下降同时价格暴涨）
L2 库存下降 + 下游被迫停车 库存下降只反映'没人接货' → 价格与基差同时走弱看MTO/传统下游开工率是否下降、现货成交是否萎缩2026年10月：江浙MTO负荷20.06%，传统需求进入淡季
L3 库存下降但已被提前定价 见报时利多出尽 → 价格反而回落比较库存发布日与随后1-3日的价格反应10/8库存30.51万吨发布 → 10/9主力涨超6%，随后一周回吐
L4 口径/地区错配 全国去库，但交割地在累库 → 盘面压力大拆分华东/华南；对照交割库与主流库区10/14 全国+6.21，但华东-3.16、华南+9.37
L5 库存低但供应预期恢复 期货先跌（交易未来累库），现货暂稳 → 基差被动走强看到港量、外盘开工与进口预期到港从3.88→15.90万吨；隆众称11月非伊供应或回升
L6 成本/地缘盖过库存 库存变化的解释力显著下降看原油/煤价与运输是否主导当日行情10/9 涨超6%的直接归因是霍尔木兹封锁

6.3 甲醇特有的产业特点（和黑色、有色不一样的地方）

  • 沿海是“进口+内地补充”的双来源市场。港口库存对外轮到港极其敏感，中东（伊朗）装置和霍尔木兹海峡的地缘变化会直接跳到港口库存上， 所以库存下降经常是“船没来”，不是“货被抢光”。本次 10/8 到港仅 3.88 万吨、显性外轮 2.35 万吨，就是典型。
  • 需求高度集中在 MTO。沿海一套大型烯烃装置的降负荷，能抵掉好几套传统下游（甲醛、醋酸、二甲醚）的采购量。 所以看需求不能只看“下游开工总量”，要看沿海 MTO 负荷——本次江浙 20.06%。
  • 内地与沿海是两套定价体系。内蒙北线、山东与太仓之间有运费窗口；内地价格跌、港口挺价时会拉开价差，导致“内地货倒流港口”。 本次未取得内蒙同日的可比值 → 记为缺口。
  • 仓单与可交割量 ≠ 港口库存。交割库只覆盖部分库区，且交割品要求优等品；港口“样本库存”里相当一部分是不满足交割条件或不在交割库的货。
  • “冬季限气”是每年 Q4 的老剧本。伊朗/中亚装置冬季限气停产 → 进口减量 → 港口去库的预期，会在 Q4 提前被交易。它既支撑远期，也容易被“预期已被交易”反向打脸。

术语表（点一下术语有气泡）

符号方向是全篇最容易出错的地方，单独列一栏
术语一句话符号方向准确含义与陷阱
基差（主流口径） 现货价 − 期货价正 = 现货升水；负 = 现货贴水国内期现研究默认口径。'基差走强' = 该差值变大（向正值方向移动）。必须先写明谁减谁，因为反过来的定义符号完全相反。
基差（替代口径） 期货价 − 现货价与上一条相反原油等品种常用。若同一份文件里口径混用，会把'走强'写成'走弱'，是最常见的低级错误。
月差 MC 远月合约价 − 近月合约价>0 contango（近月贴水）；<0 back（近月升水）同时必须写清是哪两个合约。MA 常见的近月-远月组合是 2611/2701、2701/2705。
港口样本库存 被统计样本库区在统计时点的在库量—甲醇是'样本港口库存'（华东+华南显性样本库），不等于全社会库存，也不等于可交割库存。
周度库存变化 本周库存 − 上周库存正 = 累库；负 = 去库甲醇库存是周度指标，各机构发布日不同（周三/周四）；'库存下降'必须配日期与周期。
到港量 统计周期内靠泊卸货量—分外轮（进口）与内贸船；只有'显性'部分计入样本库存，'非显性'部分在统计外。
表观提货量 到港量 − 库存净增—恒等式推导，只是流向近似，不是真实需求。
CFR中国 成本加运费到中国口岸的美元价—不含港杂、关税、增值税，必须换算成含税到岸成本才能与国内现货比。
进口扳平价 进口到岸含税成本国内价 − 到岸成本 = 进口盈亏由 CFR 乘汇率 乘 (1+关税5%) 再加海运保险与港杂，最后乘 (1+增值税13%) 得到。
MTO 甲醇制烯烃—甲醇最大下游。沿海外采型MTO对港口需求影响最大；MTO负反馈 = 烯烃亏损 → 降负荷 → 减少甲醇采购 → 港口提货下降。
back / contango 近月升水 / 近月贴水见月差back 常对应现货紧张；contango 需要期货价覆盖仓储+资金成本。
合约换月 主力从近月切换到远月—会造成价格跳空与持仓转移；跨换月比较绝对价格会失真，应比较涨跌幅或基差/月差。
