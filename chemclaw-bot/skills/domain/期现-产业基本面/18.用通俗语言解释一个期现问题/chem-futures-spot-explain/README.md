# 用通俗语言解释一个期现问题 · 快速上手

> 场景 18。给一个期现问题 + 一个品种，产出「讲明白」的解释：
> 1 个自包含交互式 HTML + 1 个可重算的 Excel 工作簿。

## 30 秒判断要不要用

| 你听到的是 | 用这个技能 |
|---|---|
| “库存降了，为什么价格还跌？” | ✅ |
| “基差走强说明什么？” | ✅ |
| “月差怎么翻负了？” | ✅ |
| “跌到成本线了吗？” | ✅（可能答“数据不足”，这本身就是正确答案） |
| “明天会不会涨？” | ❌ 本技能不做预测与建议 |
| “给我画个价格走势图” | ❌ 用行情/简报类技能 |

## 三条最容易踩的坑

1. **把“库存低”当成“库存在下降”**——水平 vs 变化，这是最常见的一句错话。
2. **跨换月比较绝对价格**——会把跳空算成涨跌（本次案例里能虚增 3 倍跌幅）。
3. **没找到案例就编一个**——本技能明确要求写“未找到”，并降级为理论假设。

## 示范案例的结论（给个直觉）

> **甲醇港口库存下降，为什么价格还能跌？**
> 因为“库存下降”和“价格下跌”不在同一个时间尺度上：
> 9 月到 10 月 8 日库存确实从 64.15 万降到 30.51 万吨，但那段价格是暴涨的；
> 10 月 14 日库存已经回升到 36.72 万吨，价格才开始回落。
> 真正成立的是：**库存处在历史低位时，价格仍然可以跌**——价格定价的是“后面还有多少船要来”。
