# deliverables-checklist.md — 交付前 40 项检查

> 逐项打勾。任何一项 FAIL 不得交付。建议把本清单复制到交付说明里附上结果。

## A. 事实与证据（10 项）

- [ ] A1 页面标题、数据截止日、生成时间齐全
- [ ] A2 进入“事实”区的每个数字都有来源 ID 与日期
- [ ] A3 转引来源标注了原机构（如“隆众资讯（经曲合网转载）”）
- [ ] A4 估值/惯例值标注 `estimation` / `convention`，未混入事实
- [ ] A5 事实核对矩阵给出 `成立 / 部分成立 / 未找到` 的明确判定
- [ ] A6 若未找到“同周期并存”，正文第一段必须说明（不得含糊）
- [ ] A7 理论假设单列，且明确写“本次未证实”
- [ ] A8 数据缺口列表 ≥ 3 条，且每条给“怎么补”
- [ ] A9 没有任何“记忆中”的数字（全部有本轮取数链接）
- [ ] A10 同一指标的多家口径差异（如有）已说明，未混用

## B. 口径与公式（10 项）

- [ ] B1 基差写明“谁减谁”（现货−期货 或 反向）
- [ ] B2 基差写明收盘口径还是结算口径，必要时两种都给
- [ ] B3 月差写明合约对与“谁减谁”
- [ ] B4 现货写明地区 / 品质 / 交货条件 / 是否含税
- [ ] B5 期货写明合约月份与是否主力
- [ ] B6 跨换月的区间只用比值口径，且显式提示不能比较绝对价
- [ ] B7 每个公式都有单位与算例
- [ ] B8 进口扳平包含关税与增值税，运保费与港杂标注性质
- [ ] B9 成本类指标区分现金流成本与完全成本
- [ ] B10 符号一致性自检（F10）全部通过

## C. 结构完整性（8 项）

- [ ] C1 ① 直接回答在最前，且不用“一般来说”开头
- [ ] C2 ② 概念解释包含定义与口径，不只是教科书定义
- [ ] C3 ③ 相关市场指标含真实数据（库存/现货/期货/基差/开工等）
- [ ] C4 ④ 公式与图表可交互、可复算
- [ ] C5 ⑤ 产业关系（至少 5 组指标关系）
- [ ] C6 ⑥ 为什么矛盾能同时成立的解释（有数据支撑）
- [ ] C7 ⑦ 事实 / 推断 / 假设 三分
- [ ] C8 ⑧ 数据不足时显式声明

## D. 交互与可用性（6 项）

- [ ] D1 默认入门模式，可切专业模式，切换后内容确实不同
- [ ] D2 术语可点（气泡显示定义与符号方向）
- [ ] D3 可改 品种/合约/日期 并重算，结果刷新可见
- [ ] D4 单文件、零外部资源（无 CDN、无外链字体/图片）
- [ ] D5 打印/导出 PDF 时布局不破（工具栏隐藏、卡片不跨页断）
- [ ] D6 移动端宽度下不横向溢出

## E. 生成物技术检查（6 项）

- [ ] E1 HTML 占位符残留 = 0
- [ ] E2 `probe_html.js` 返回 `errors: []`，且图表节点数 > 0
- [ ] E3 `check_formulas.js` 全 PASS
- [ ] E4 Excel 重算后无 `#VALUE!` `#N/A` `#NAME?` `#REF!`
- [ ] E5 Excel 派生列是公式而非死值（抽查 ≥ 5 处）
- [ ] E6 Excel 表结构与约定一致（封面/概念/公式/库存/价格基差/月差/运营/进口/案例/事实推断/缺口/来源）
