## QT1 库存-价格背离（本技能示范案例）

**用户话术**：“库存降了，为什么价格还跌？”

**判断依据**：问题里同时出现“库存方向”和“价格方向”，且两者相反。

**必取数据**：海关口的周度库存（全国+分地区）、企业库存、到港量、主交割地现货、主力/近月期货日线、最大下游开工率、基差、月差。

**解释骨架**
1. 尺度核对：月度、周度、日度分开算，先证明“同一周内是否真的并存”。
2. 若并存不存在 → 直接指出“库存下降是水平描述，不是本周变化”。
3. 若并存存在 → 从六抽屉里找真正的原因，并给验证指标。
4. 结论落到“价格定价的是流量预期，不是库存水平”。

**最容易说错**：把“库存处于历史低位”说成“库存本周下降”；用 9 月的去库配 10 月的下跌。

**反例条件**：若同期下游开工率上升、基差走强，则“下游停车导致被动去库”这条路径被否掉。

## QT2 基差走强 / 走弱意味着什么

**必取数据**：主交割地现货（日度订价）、目标合约收盘与结算、交割成本明细、库存与月差。

**解释骨架**
1. 先写口径：`Basis = 现货 − 期货`，哪个地区、哪个合约、收盘还是结算。
2. 拆成“现货变了”还是“期货变了”（分子分母都动时，基差变化不代表现货强弱）。
3. 走强三因：现货紧（库存低+下游抢货）/ 期货预期悲观（交易未来累库）/ 交割成本抬升。
4. 走弱的镜像。
5. 给“基差走强 ≠ 涨”的反例：期货跌得比现货快，基差也会走强。

**最容易说错**：不谈口径；把基差走强等同于看涨。

## QT3 月差变化（翻正/翻负）

**必取数据**：两个合约的收盘/结算/持仓/成交、库存、仓储与资金成本、换月日历。

**解释骨架**
1. 写清 `MC = 远月 − 近月`（或注明相反），哪个合约对。
2. 先排除换月造成的主力切换假象（看持仓与成交）。
3. 结构解释：back 对应现货紧张 / contango 对应宽松+仓储成本。
4. 与库存、基差交叉验证：库存低但月差收敛 → 市场在交易未来累库。

**最容易说错**：符号搞反；跨换月比较；用临近交割的清淡合约报价。

## QT4 成本支撑 / 跌到成本线了吗

**必取数据**：原料价格（同日）、单耗、加工费、副产品、现金流成本 vs 完全成本、边际产能分布、库存与开工。

**解释骨架**
1. 明确“哪条成本线”（现金流 / 完全），说明为什么用现金流。
2. 算成本折点，给区间而非单点。
3. 说明成本线是移动的（随原料价）。
4. 说明刚性供给：有库存、有长约、有配套下游的企业不会立刻停。
5. 若缺同日原料价 → **直接写缺口**。

**最容易说错**：用完全成本当支撑；用上个月的煤价算这个月的成本。

## QT5 进口窗口（打开了为什么没跌 / 关闭了为什么还跌）

**必取数据**：CFR（基准港）、汇率、关税、增值税、运保费、港杂、国内现货、到港量、罐容与船期信息。

**解释骨架**
1. 完整公式链（不要跳步）。
2. 敏感性：CFR ±、汇率 ± 对到岸成本的影响。
3. 时滞：利润→船期 2-6 周；到港量是滞后确认。
4. 约束：罐容、窗口、交割月、信用证。
5. 盘面价差：期货可能已经把未来到港打进价格。

**最容易说错**：漏增值税；用固定运保费；把“有利润”当“马上到港”。

## QT6 开工-需求（开工高为什么还涨）

**必取数据**：上游开工/产量/检修损失、下游（尤其最大下游）开工、成品库存、基差、库存。

**解释骨架**
1. 先说清是上游还是下游开工。
2. 上游开工高但库存下降 → 需求更强或出口/外流。
3. 下游开工低但价格涨 → 供给断得更狠（进口断供型）。
4. 交叉验证：现货成交、基差、区域价差。

**最容易说错**：上游下游混用；用全国开工率解释地区矛盾。

## QT7 区域价差（太仓和内蒙差这么多正常吗）

**必取数据**：两地同日同品质价格、运费、交割地设置、流向与套利窗口、当地供需。

**解释骨架**
1. 算价差，与运费+损耗比较。
2. 判断“窗口是否打开、货会不会流动”。
3. 说明交割地决定了哪个价格主导盘面。
4. 缺同日数据 → 缺口。

**最容易说错**：跨日比较；忽略品质与交货条件；忽略运费会跳。

## QT8 事件驱动（涨停后为什么暴跌）

**必取数据**：事件性质与持续时间、受影响的产能/船期、库存与基差、持仓变化、当日归因（研报/媒体）。

**解释骨架**
1. 把事件拆成“影响什么、影响多久、影响多大”。
2. 区分“供给实际损失”与“风险溢价”。
3. 溢价回吐本身就是下跌理由。
4. 看持仓：增仓下跌（空头主动）vs 减仓下跌（多头撤退）含义不同。

**最容易说错**：把一次装置事故当长期供给损失；不区分溢价与实际损失。
