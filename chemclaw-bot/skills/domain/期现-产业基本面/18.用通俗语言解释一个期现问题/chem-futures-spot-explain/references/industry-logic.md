## 1. 甲醇产业链骨架

```
上游：动力煤 / 天然气 / 焦炉气
  ├─ 煤制甲醇（内蒙、陕西、山西、山东为主，成本低、内陆）
  ├─ 天然气制（西南、西北，冬季限气）
  └─ 焦炉气制（山西、河北，副产属性）
中游：贸易 + 港口/库区（华东：太仓、江阴、宁波；华南：广东、福建）
下游：
  ├─ MTO/MTP（沿海外采型：宁波、嘉兴、连云港 → 甲醇最大单一需求）
  ├─ 甲醛（板材，山东/河北）
  ├─ 醋酸（华东）
  ├─ MTBE（调油，山东）
  ├─ 二甲醚
  └─ 燃料/其他
外盘：中东（伊朗、沙特、阿曼）、东南亚、南美 → CFR 中国
```

**结构特征（决定了所有期现关系的形态）**

1. **两个市场**：内地（煤制、成本定价）与沿海（进口+内地补充、供需定价），中间靠运费窗口连接。
2. **进口占比高**：沿海价格对**外轮到港**高度敏感，地缘与船期能直接改写港口库存。
3. **需求集中**：沿海 MTO 单套装置的量级 ≈ 若干套传统下游，需求端看 MTO 就抓住了七成。
4. **仓储属性强**：液体化工，罐容有限，库存“搬家”比“消失”容易。港口去库可能只是把货挪到下游罐里。
5. **季节性**：Q4 冬季限气（伊朗/中亚/西南气头）→ 进口与国产双减 → 年末常有一波“预期抢跑”；Q2-Q3 需求淡季。

## 2. 五组核心指标关系（可迁移到所有液体化工品种）

### R1 库存 ↔ 价格
- 教科书：库存下降 → 现货紧张 → 价格上涨。
- **成立前提**：① 去库是“提货多”，不是“到不了货”；② 下游真的在接货；③ 缺口能持续。
- 三条前提缺一条，结论就可能反转。**这是本技能最常用来解释矛盾的地方。**

### R2 基差 ↔ 库存
- 低库存且下游抢货 → 基差走强（现货升水扩大）。
- 低库存但下游停车（被动去库）→ 基差可以偏弱：现货没人抢，期货也不敢涨。
- 库存高但已跌破进口成本 → 基差可能被动走强（现货跌无可跌，期货先跌）。

### R3 月差 ↔ 库存
- back（近月升水）= 现货紧张的结构性表达；contango = 供应宽松，期货价要覆盖仓储资金。
- **换月会制造假信号**：主力切换前后月差可能突然跳变，必须先看持仓与成交是否还活跃。

### R4 开工 ↔ 需求
- 上游开工率（产量）↑ = 供给宽松；下游开工率 ↑ = 需求改善。**两者不能混用。**
- MTO 负荷是甲醇的“需求总闸”。区级负荷跌到低位时，传统下游的季节性变化基本被淹没。

### R5 进口窗口 ↔ 供给
- 进口利润 > 0 且持续 → 后续到港增加（时滞通常 2-6 周）。
- 到港未兑现前，价格可能先跌（市场交易预期），也可能不跌（船拿不到、罐容满）。
- **到港量是滞后确认变量**，进口利润是先行变量。

## 3. 矛盾解释的产业版“六抽屉”

| 抽屉 | 甲醇专属版本 |
|---|---|
| 尺度不同 | 月度去库 vs 周度累库（本题） |
| 口径不同 | 全国合计 vs 华东/华南分项；样本港口 vs 企业库存 |
| 存量 vs 流量 | 港口库存历史低位，但本周到港 15.90 万吨 |
| 预期 vs 现实 | 冬季限气缺口 vs 11 月非伊供应恢复 |
| 被提前定价 | 库存数据公布当日即涨停（利好出尽） |
| 外生冲击盖过 | 霍尔木兹海峡、原油、宏观资金 |

## 4. 甲醇特有的“容易说错”的六句话

| 容易说错 | 应该说 |
|---|---|
| “库存下降了所以涨” | “库存在X周去库，同期下游开工Y%、基差Z，因此这次去库是需求驱动/供给断供驱动” |
| “港口库存就是可交割货” | “样本港口库存不是可交割量，交割库只覆盖部分库区” |
| “基差为正就能套利” | “基差要超过交割成本（仓储+资金+出入库+检验+损耗+税差）才可能有套利空间” |
| “开工率高说明供应过剩” | “要先说清是上游开工还是下游开工” |
| “跌到成本线了” | “跌到哪条成本线？现金流成本还是完全成本？哪一天的原料价？” |
| “进口有利润所以会跌” | “有利润到有船期通常 2-6 周，且需要罐容与窗口” |

## 5. 迁移到其他品种时的替换清单

| 模块 | 甲醇 | 纯碱 | PTA | 玻璃 | 适用于… |
|---|---|---|---|---|---|
| 主交割地 | 太仓/华东 | 沙河/华中 | 华东主港 | 沙河/湖北 | 都要写清 |
| 最大下游 | MTO | 玻璃/光伏 | 聚酯 | 地产竣工 | 需求集中度决定解释难度 |
| 进口依赖 | 高（中东） | 低 | 中（PX上游） | 低 | 决定“外盘/地缘”权重 |
| 关键成本 | 动力煤 | 原盐+煤炭/联碱 | PX | 纯碱+燃料 | 决定成本支撑口径 |
| 仓储属性 | 液体罐容 | 袋装/散装库 | 液体 | 平板玻璃占地 | 决定“库存搬家”难度 |
| 季节性 | 冬季限气 | 光伏装机 | 聚酯旺季 | 竣工周期 | 决定 Q4 剧本 |

迁移时**必须替换**：交割地、最大下游、进口依赖、成本口径、季节性；**不必替换**：8 步法、矛盾六抽屉、事实核对矩阵、交付物结构。
