# data-sources.md — 取数顺序、检索式、机构口径差异

## 0. 铁律

1. **没有 URL 和日期的数字不进“事实”区。**
2. 同一指标优先取**原始机构**（隆众 / 卓创 / 交易所 / 期货公司研报），只能拿转引时标注“（经××转载）”。
3. 估值（运保费、港杂、单耗）必须标 `estimation` / `convention`，不得写成事实。
4. 拿不到就写 GAP，**不要用“大致/约”凑一个数**。
5. 记忆中的数字不算数据：重算过的旧数也要重新取一次并更新日期。

## 1. 取数顺序

| 顺序 | 指标 | 去哪取 | 频度 |
|---|---|---|---|
| 1 | 港口库存（全国+分地区） | 隆众（经 mysteel 能化转载）、曲合网、同花顺/金十快讯 | 周度 |
| 2 | 企业库存 / 到港量 | 隆众周度数据分析 | 周度 |
| 3 | 现货价格（太仓等） | 隆众早报/日评、mysteel 热门价格表 | 日度 |
| 4 | 期货日线（收盘/结算/持仓/成交） | 新浪财经期货 API、交易所官网 | 日度 |
| 5 | 基差/月差 | **自己算**（不要直接抄别家的基差） | 日度 |
| 6 | 开工率 / 周产量 / 检修损失 | 隆众开工数据、期货公司周报 | 周度 |
| 7 | 下游（MTO/甲醛/醋酸/MTBE/二甲醚） | 隆众下游开工、MTO 负荷 | 周度 |
| 8 | 外盘（CFR 中国、国际产量/开工） | 隆众外盘、亚洲周度 CFR | 周度 |
| 9 | 成本（动力煤/天然气、煤制利润） | CCTD、隆众成本表、期货公司研报 | 周度 |
| 10 | 事件（地缘/装置/政策/天气） | 交易所公告、公司公告、财经媒体 | 事件驱动 |

## 3. 常见站点的坑

| 站点 | 坑 | 处理 |
|---|---|---|
| mysteel 能化 `nenghua.mysteel.com/a/<yymmddHH>/<ID>.html` | 正文常被截断到 300-400 字，后面是“…” | 截断不影响关键数字时可用；需要全文时找同题转载 |
| mysteel `www.mysteel.com/hot/<id>.html` | 页面是 GBK/UTF-8 混合，直接抓会乱码 | 取 `RawContentStream` 字节后按 UTF-8 解码 |
| 同花顺 `news.10jqka.com.cn` / `goodsfu.10jqka.com.cn` | 标题里的数字最可靠，正文常被裁剪 | 只用标题+首段数字，并注“转引” |
| 曲合网 `quheqihuo.com/news/<id>.html` | 列表页 `makc/list_3590_all.html` 只有日期链接 | 先取 `/makc/YYYY-MM-DD/list_history_3590_1.html`，再进 `/news/<id>.html` |
| 东方财富 `finance.eastmoney.com/a/<id>.html` | 页面广告多，正文在中间 | 取正文段落即可 |
| 交易所 | 结算价与收盘价不同 | 需要精确基差时取交易所结算价；否则明确写“收盘口径” |

## 4. 机构口径差异（必须写进口径说明）

| 维度 | 差异点 | 后果 |
|---|---|---|
| 库存 | 样本库区数量、是否含华南、是否含保税 | 同一周不同机构的“总库存”能差几十万吨 |
| 基差 | 现货用订价还是区间中值；期货用收盘还是结算；比哪个合约 | 同一交易日能差几十到几百元 |
| 月差 | 谁减谁（近−远 vs 远−近） | 符号完全相反 |
| 开工率 | 产能利用率 vs 开工负荷；样本企业数 | 同一周能差一两个百分点 |
| 到港量 | 是否含内贸船、是否只算显性 | 影响表观提货的解读方向 |
| 进口成本 | 运保费、港杂、是否含增值税 | 能差 300-500 元/吨 |
| 成本 | 现金流成本 vs 完全成本 | “亏不亏”结论可能相反 |

## 6. 检索失败时的兜底顺序

1. 换检索式（加机构名、加“数据分析/周评/早间提示”等栏目名）
2. 换站点（mysteel → 曲合网 → 同花顺 → 金十 → 东财）
3. 换口径（分地区→总量；日度→周度）
4. 依然拿不到 → **写 GAP**，并给出“怎么补”（终端/订阅/公告）

> 第 4 步不是失败，是诚实。交付物里“数据缺口”这一节本身就是加分项。
