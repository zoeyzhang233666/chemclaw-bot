# concepts-and-caveats.md — 概念定义与陷阱

> 每条都按 **定义 / 符号方向 / 口径要素 / 陷阱** 四段写。任何一条缺口径，写出来的解释就是不可核对的。

---

## 1. 现货价（Spot）

- **定义**：某一地区、某一品质、某一时间、某一交货条件（出厂/出库/到岸）下成交或报价的价格。
- **符号方向**：无（绝对值）。
- **口径要素**：地区（太仓 / 宁波 / 广东 / 内蒙北线 / 山东）、品质（优等品 ≥99.9% / 粗醇）、交货（出库现汇 vs 承兑 vs 到岸）、是否含税（含13%增值税与否）。
- **陷阱**：
  - “甲醇多少钱一吨”这个问题本身不完整——至少缺地区与交货条件。
  - 报价区间中值 ≠ 收盘订价。区间中值只能做方向参考，不能拿来做基差结论。
  - 承兑价通常比现汇高 20-40 元/吨（含资金成本），跨口径比较会凭空多出“利润”。

## 2. 期货价（Futures）

- **定义**：交易所标准化合约的价格，报价含税（甲醇含13%增值税），单位元/吨。
- **符号方向**：无。
- **口径要素**：合约月份（MA2611 / MA2701）、收盘价 vs 结算价、主力 vs 非主力、连续合约的拼接方式。
- **陷阱**：
  - **收盘 ≠ 结算**。郑商所甲醇按加权均价定结算价，二者可能差十几到几十元；基差用哪个必须写明。
  - **换月**：主力从近月切到远月时价格跳空。跨换月只能比涨跌幅/基差/月差，不能比绝对价。
  - 连续合约（如“MA0主连”）在不同软件里换月规则不同，直接拿来算涨跌幅会出错。

## 3. 库存（Inventory）

- **定义**：统计时点在某类仓库里的在库量。
- **符号方向**：ΔInv = Inv(t) − Inv(t−1)，正=累库（宽松），负=去库（收紧）。注意符号惯例是“库存上升 = 供给宽松 = 利空”。
- **口径要素**：样本范围（港口显性样本库 / 企业库存 / 全社会 / 交割库）、地区（华东 / 华南 / 分省）、频度（周度 / 日度）、发布日（周三或周四）。
- **陷阱**：
  - **“库存低”≠“库存在下降”**。前者是水平，后者是变化。本题就栽在这里。
  - **港口库存 ≠ 可交割量**：交割库只覆盖部分库区；品质不符的货进不了仓单。
  - **总量 ≠ 结构**：全国+6.21 万吨，可能同时是华东 −3.16、华南 +9.37。交割地在华东时，华南累库对盘面的压力小、对华南基差的压力大。
  - **“库存搬家”**：港口去库 + 企业累库可以同时出现（贸易商/下游把货从港口提走存到厂里），总量未必真的紧。
  - 转引页面偶尔会把“到港量环比”错标在“库存”上，必须自己用相邻两期相减复核。

## 4. 基差（Basis）

- **定义**：现货与期货的价差。
- **符号方向**：
  - 国内主流：`Basis = Spot − Futures`，**正 = 现货升水**（现货比期货贵）。
  - 国际/部分机构：`Basis' = Futures − Spot`，与本式符号完全相反。
  - `Basis%` = Basis / Futures × 100%（用于跨品种、跨时间比较）。
  - **“基差走强” = 这个差值变大（向正方向移动）**，不等于现货涨价。
- **口径要素**：哪个交割地现货、哪个合约、收盘还是结算、是否含税、是否同一天（期货夜盘与现货订价时点不同）。
- **陷阱**：
  - 只写“基差 813”不写谁减谁，读者无法判断是升水还是贴水。
  - 用结算价算基差却又说“收盘基差”。
  - 拿华东现货去比华南交割的成本。
  - 基差为正不必然能套利：要扣交割成本（仓储、资金、出入库、损耗、增值税差）。

## 5. 月差（Calendar Spread, MC）

- **定义**：两个不同交割月合约的价差。
- **符号方向**（本技能统一）：
  - `MC = F(远月) − F(近月)`
  - `MC > 0` → contango（期货升水 / 近月贴水），通常对应供应宽松、需要期货价覆盖仓储资金成本。
  - `MC < 0` → backwardation / back（近月升水），通常对应现货紧张。
  - **注意**：很多软件显示“近月−远月”，与上式相反。写月差必须同时写“哪两个合约 + 谁减谁”。
- **口径要素**：具体合约对（2611/2701、2701/2705）、收盘/结算、是否适逢换月。
- **陷阱**：
  - 换月期“月差跳变”其实只是主力切换，不是结构变化。
  - 老合约临近交割成交清淡，报价失真。
  - 月差走强（back 加深）在看涨库存缺口时成立；在**库存累库 + 需求崩塌**时也可能先走强（近月还有硬缺口），随后快速收敛——本次就是这样：MC 从 −412 收敛到 −192。

## 6. 开工率 / 产能利用率（Utilization）

- **定义**：实际产量 / 名义产能（或有效产能）。
- **符号方向**：开工上升 = 供给增加（利空上游价格）；但**下游开工上升 = 需求增加**（利多）。同一句话里“开工”指的是上游还是下游，必须写明。
- **口径要素**：样本企业数、是否扣检修、是产能利用率还是开工负荷、全国还是分地区。
- **陷阱**：
  - **上游开工率与下游开工率不可混用**。
  - 产能利用率 100% 附近时，边际增量要靠新装置或提负荷，弹性很小。
  - 一体化装置（煤制甲醇配套烯烃）的甲醇“开工”对市场供应意义有限——它不外售。

## 7. 产量 / 检修损失量

- **定义**：周产量（吨/周）与因检修减少的产量。
- **符号方向**：产量上升 = 供给宽松。
- **陷阱**：产量是**流量**，库存是**存量**，二者不能直接互相替代；但可以用来判断库存变化是“供给驱动”还是“需求驱动”。

## 8. 到港量（Arrivals）

- **定义**：统计周期内靠泊卸货量，分**外轮**（进口）与**内贸船**。
- **符号方向**：到港增加 = 供给宽松。
- **口径要素**：显性（计入样本库存）/ 非显性、内贸是否计入、周期起止日。
- **陷阱**：
  - **到港 ≠ 库存增量**。到港包含非显性码头货、转口/复出口船、内贸补充；库存只统计显性样本库。
  - “表观提货 = 到港 − 库存净增”是恒等式的机械结果，**不是真实需求**。
  - 用“外轮显性 < 库存净减”判断本周是“进口断供型被动去库”才是有意义的用法。

## 9. 进口成本 / 进口扳平价（Import Parity）

- **定义**：把 CFR 美元报价换算成国内交货口径的人民币含税成本。
- **公式**：`到岸含税 = [CFR × FX × (1+关税) + 海运保险 + 港杂] × (1+增值税)`
- **符号方向**：`进口利润 = 国内现货 − 到岸含税`；>0 表示进口有利润（理论上利多进口量）。
- **口径要素**：CFR 是哪个基准（中国主港/东南亚/韩国）、汇率（中间价 vs 结汇价）、运保费、港杂、关税率、增值税。
- **陷阱**：
  - **漏算增值税**会让成本低估 10% 以上。
  - 运保费在特殊时期（如海峡封锁）可能翻倍，用平时的固定值会严重低估。
  - “有进口利润”≠“能进口”：还要有船、有罐容、船期能落在窗口内。

## 10. 成本支撑（Cost Floor）

- **定义**：让边际产能停产的现金成本，不是行业平均完全成本。
- **符号方向**：价格接近现金成本 → 下方支撑增强。
- **口径要素**：原料（动力煤/天然气）、单耗、加工费、副产品抵扣、是否含折旧、区域（内蒙 vs 山东 vs 沿海）。
- **陷阱**：
  - **完全成本当支撑线**是最常见错误。停产决策看的是现金流，不是折旧。
  - 成本会随原料价格下移，“成本线”本身是移动的。
  - 有库存/有长约的企业即使亏损也会继续生产（刚性供给）。

## 11. MTO / 下游负反馈

- **定义**：甲醇制烯烃装置因烯烃与甲醇价差恶化而降低负荷或停车，进而减少甲醇采购。
- **符号方向**：MTO 负荷下降 = 甲醇需求下降（利空）。
- **口径要素**：沿海（宁波/嘉兴/连云港等）外采型 vs 内地煤制一体化；区级负荷 vs 单套装置负荷。
- **陷阱**：
  - 一体化装置的“停产”对市场供应/需求的影响方向与沿海外采型相反。
  - 区级负荷 20.06% 这种数字背后可能只剩一套装置在运行；不写明细就说不清“还剩谁在买”。

## 12. 表观消费 / 表观提货

- **定义**：用供给与库存变化反推的“消费量”。
- **公式**：`表观消费 = 产量 + 进口 − 出口 − Δ库存`（口径不同略有差异）。
- **陷阱**：混入损耗、口径差、统计外流向。只能做方向判断，不能当精确需求。

## 13. 期货手续费/保证金/交割成本（做套利必须）

- **交割成本**包括：仓储费、出入库费、检验费、资金成本、损耗、增值税差。
- **陷阱**：基差 > 交割成本 ≠ 无风险套利，还要考虑能不能交得上货、库容、时间。

## 14. 事件驱动（地缘 / 装置事故 / 政策）

- **定义**：由非基本面连续性变化引发的价格跳变。
- **符号方向**：取决于事件对供给/需求的方向，但**持续时间**比方向更重要。
- **陷阱**：
  - 把一次装置事故当成长期供给损失（通常几天到几周）。
  - 把地缘溢价当成新的均衡价格。
  - 忽略“溢价回吐”本身就是下跌理由。
