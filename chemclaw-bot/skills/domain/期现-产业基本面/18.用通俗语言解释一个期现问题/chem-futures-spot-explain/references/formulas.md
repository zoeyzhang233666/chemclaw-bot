# formulas.md — 全部公式、符号方向与算例

> 约定：`S` = 现货价，`F` = 期货价，`Inv` = 库存，下标 `t` 为期数，`pct` 一律 ×100 后带 `%`。
> **每条公式都必须配：单位、符号含义、算例。** 没有算例的公式不能进交付物。

---

## F1 区间涨跌幅

```
涨跌幅% = (P_end − P_start) / P_start × 100%
```

- 单位：%
- 符号：正=涨，负=跌
- **要求：起止必须同一合约。** 若跨越换月，只能得到“比值口径”的涨跌幅，且**不能**用绝对价差当“跌了多少”。

算例（甲醇 2026-10-09 → 10-19，同一合约 MA2701）：
```
(3143 − 3338) / 3338 × 100% = −5.84%
```
对照（错误做法，MA2611 3835 → MA2701 3143）：
```
(3143 − 3835) / 3835 × 100% = −18.04%   ← 含换月跳空，不能当跌幅
```

## F2 库存周度变化

```
ΔInv = Inv(t) − Inv(t−1)              单位：万吨
环比% = ΔInv / Inv(t−1) × 100%
```

- 符号：ΔInv > 0 累库（宽松）；< 0 去库（收紧）
- 必须同时报**日期**与**周期长度**（周度/月度）

算例：
```
2026-10-14: 36.72 − 30.51 = +6.21 万吨，环比 +20.35%
2026-09-02 → 10-08: 30.51 − 64.15 = −33.64 万吨（−52.4%）
```

**复核规则**：资讯原文给的环比必须与本表算出来的对比，偏差 > 0.011 就标记“不一致”，并回原文核对——这通常是转引时把别的指标（如到港量）的环比抄错了。

## F3 基差（两种口径）

```
口径A（国内主流）Basis  = S − F        正 = 现货升水
口径B（国际常用）Basis' = F − S = −Basis
基差率 Basis% = (S − F) / F × 100%
```

- 单位：元/吨、%
- **基差走强** = Basis 变大（无论正负）；**基差走弱** = Basis 变小
- 口径要素：现货地区/品质/交货条件、期货合约、收盘还是结算、是否同一天

算例（2026-10-15，太仓 3983，MA2701 收盘 3170）：
```
Basis = 3983 − 3170 = 813 元/吨
Basis% = 813 / 3170 × 100% = 25.65%
Basis(结算) = 3983 − 3231 = 752 元/吨   ← 同一交易日，两个口径差 61 元/吨
```

## F4 月差

```
MC = F(far) − F(near)                  单位：元/吨
MC% = MC / F(near) × 100%
```

- `MC > 0` → contango（近月贴水）；`MC < 0` → backwardation（近月升水）
- **必须写明合约对**；换月期要避开或注明

算例：
```
2026-10-09: MC = 3338(2701) − 3835(2611) = −497 元/吨（back，−12.96%）
2026-10-19: MC = 3143(2701) − 3335(2611) = −192 元/吨（back，−5.76%）
ΔMC = −192 − (−497) = +305 元/吨（back 收敛）
```

## F5 库存流量恒等式（表观提货）

```
ΔInv = 到港 − 提货 − 损耗 ± 口径差
⇒ 表观提货 = 到港 − ΔInv
```

- 单位：万吨（周期内）
- **不是真实需求**：混入内贸船、非显性码头货、转口船、统计时点差
- 正确用法：判断“到港 < 去库”= 进口断供型被动去库；“到港 > 累库”= 供给恢复但提货没跟上

算例：
```
2026-10-14: 到港 15.90 − 库存净增 6.21 = 表观提货 9.69 万吨
2026-10-08: 到港 3.88 − 库存净减 8.84 = 表观提货 12.72 万吨（> 到港，说明在消耗存量）
```

## F6 进口到岸含税成本（进口扳平）

```
CIF(¥)     = CFR × FX × (1 + 进口关税)
到岸(不含税) = CIF(¥) + 海运保险 + 港杂
到岸(含税)   = 到岸(不含税) × (1 + 增值税)
进口利润     = 国内现货 − 到岸(含税)
盘面进口价差 = 期货价 − 到岸(含税)
```

- 单位：元/吨
- 默认税率：甲醇关税 5%、增值税 13%
- 海运保险与港杂**必须标 estimation / convention**

算例（2026-10-19，CFR 444 美元，汇率 6.72，运保 75，港杂 50）：
```
CIF = 444 × 6.72 × 1.05 = 3132.86
到岸(不含税) = 3132.86 + 75 + 50 = 3257.86
到岸(含税)   = 3257.86 × 1.13 = 3681.39
进口利润（现货 3940）= 3940 − 3681.39 = +258.61 元/吨
盘面进口价差（用 MA2701 收盘 3143）= 3143 − 3681.39 = −538.39 元/吨
```
> 盘面比进口成本低 538 元/吨，说明期货已经比“现在能买到的进口货”便宜——这是“市场在交易未来累库”的价格证据。

## F7 区域价差

```
区域价差 = P(销区/交割地) − P(产区)
```
- 单位：元/吨
- 用于判断“运费窗口是否打开、货会不会倒流”
- 需要同一天、同品质、同交货条件

算例（未取得同日数据 → **缺口**，不做估算）：
```
太仓 − 内蒙北线 = GAP（缺同日内蒙北线价格）
```

---

## F8 成本折点

```
现金流成本 = 原料价 × 单耗 + 加工费 + 其他变动成本
成本折点价 = 现金流成本 − 副产品收益
完全成本   = 现金流成本 + 折旧摊销
```

- **判断支撑用现金流成本，不用完全成本**
- 单位：元/吨
- 缺同日原料价 → 直接写缺口

## F9 库存-价格关系（定量）

```
同口径周度样本：[ΔInv_i, ΔP_i]
做法：对价格取对数差分，剔除换月、地缘事件周
报告门槛：样本 < 24 个点不报相关系数；报则必须给样本期、口径、剔除说明
```

- 本项目的实际情况：只有 8 个周度点 → **判定“样本不足”，不报相关系数**
- 这是硬规则：**宁可说“样本不足”，也不要报一个漂亮但没意义的 r**

## F10 符号一致性自检（必须自动跑）

```
1) Basis > 0 ⟺ S > F
2) MC < 0 ⟺ F(near) > F(far)
3) ΔInv > 0 ⟺ 累库（与“宽松”同向）
4) 基差走强 ⟺ Basis(t) > Basis(t−1)（不要求为正）
5) 跨换月的区间不得同时给出“同合约涨跌幅”和“绝对价差跌幅”
```

任何一条不成立 → 页面与 Excel 都算 FAIL，不得交付。
