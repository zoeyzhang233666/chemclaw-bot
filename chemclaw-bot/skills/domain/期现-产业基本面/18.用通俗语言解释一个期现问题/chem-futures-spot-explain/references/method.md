# method.md — 8 步法详解

## S0 问题卡

```
{
  "question":   "甲醇港口库存下降，为什么甲醇价格仍然可能下跌？",
  "product":    "甲醇（MA，郑商所，20吨/手）",
  "spot":       "江苏太仓 出库现汇 含13%增值税 元/吨",
  "futures":    "MA2701（2027年1月）；2026-10-19 前主力为 MA2611",
  "window":     "2026-09-02 → 2026-10-19",
  "depth":      "beginner / pro",
  "defaults_used": ["现货地区=太仓（华东主交割地）", "基差口径=现货−期货收盘"],
  "unresolved": ["用户未指定合约 → 默认当前主力"]
}
```

**规则**
- 时间窗口必须写起止，且**库存日期与价格日期要各自标注**（库存按周、价格按日，天然对不齐）。
- 用户没说地区就取“主交割地/主流市场”，并在页面写“默认来自交割地惯例”，不要默认到用户没提的城市。
- 用户说的品种没有期货合约 → 改做现货/远期研究，页面标题也要改，不能挂一个虚构的期货价。

## S1 概念拆解

对每个概念回答四个问题：
1. **它是什么**（一句话，能用大白话复述）
2. **它怎么算**（谁减谁、分母是什么）
3. **口径五件套**：合约 / 地区 / 品质 / 时间 / 税
4. **它最容易骗人把式是什么**（陷阱）

例：基差
- 是什么：现货比期货贵多少。
- 怎么算：`现货 − 期货`（国内主流）或 `期货 − 现货`（国际常用）。
- 口径：太仓 vs MA2701 vs 优等品 vs 某日 vs 均含13%增值税 vs 用收盘还是结算价。
- 陷阱：符号反了、结算价当收盘价、跨换月比较。

## S2 数据取证

取数顺序（先存量、后流量、再预期）：

1. **库存**（周度，全国 + 分地区）
2. **现货价格**（主交割地日度订价）
3. **期货价格**（目标合约日线：收盘/结算/持仓/成交量）
4. **基差/月差**（自己算，不抄别家）
5. **开工率 / 产量**（上游 + 下游，尤其最大下游）
6. **进口/出口**（CFR、到港、汇率、税率）
7. **成本**（原料价、单耗、加工费）
8. **事件**（装置事故、政策、地缘、天气、限气）

每条数据必须落成：

```
{value, date, spec, region, tax_unit, source_id, source_url, source_type, note}
```

`source_type` 取值：`机构数据` / `机构数据转引` / `机构日评` / `机构周评` / `机构报价` / `期货公司研究` / `财经媒体` / `行情数据` / `政策发布` / `惯例值` / `估价`。

> 转引要写清“原机构（经转载方）”。同一数据两家都给时优先取机构原表；只能拿转引时，标题里注明转引链。

## S3 事实核对矩阵（核心）

把用户的一句话拆成子命题，**每个子命题单独选尺子**：

| 子命题 | 尺子 | 成立标准 | 不成立的常见原因 |
|---|---|---|---|
| 库存下降 | 周度环比（或月度） | ΔInv < 0 且在看同一周 | 把“水平低”说成“在下降” |
| 价格下跌 | 同一合约的日/周涨跌幅 | pct < 0 且合约一致 | 跨换月直接相减 |
| 二者并存 | **同一主计量期** | 同一周期内两者方向相反 | 用 A 期库存解释 B 期价格 |
| 因果 | 事件时间先后 + 反证条件 | 有先后、有机制、有排除项 | 只做相关不做排除 |

输出模板：

```
P1 库存下降      → 月度成立（64.15→30.51，-52.4%）；本周不成立（30.51→36.72，+20.4%）
P2 价格下跌      → 成立（MA2701 3338→3143，-5.84%，同一合约口径）
P3 同周期并存    → 未找到（8 个周度变化点中无“库存降 + 价格跌”）
P4 库存指标无用  → 属推断，不成立
```

**判定规则**
- 只要 P3 不成立，正文第一句就必须写“严格讲，本窗口未出现……”，并用“低库存时价格仍可下跌”的表述替代“库存下降价格却跌”。
- 不能为了叙事顺畅，把两个时段拼成一句话。**宁可承认没找到，也不要编一个案例。**

## S4 指标计算

- 所有结果都要能复算：公式、输入、单位、符号方向一起给出。
- 衍生指标**不得手填**。写进 `data.json` 的只能是原始值与来源；派生值交给脚本算。
- 两种口径都算（基差：收盘 / 结算；涨跌幅：同合约 / 跨换月），并把差异显式展示出来——差异本身就是最好的教学内容。

## S5 产业逻辑

每条路径写成三段式：

```
L2 库存下降 + 下游被迫停车
  预期表现：库存下降只反映“没人接货” → 价格与基差同时走弱
  验证指标：MTO/下游开工率下降、现货成交萎缩、基差走弱
  反证条件：若下游开工上升而库存仍降，则该路径不成立
  本次对应：江浙 MTO 负荷 20.06%（10/15），浙江两套烯烃已停车
```

必须覆盖的五组关系：库存-价格、基差-库存、月差-库存、开工-需求、进口窗口-供给。缺哪组要写为什么缺（通常是因为缺数据）。

## S6 矛盾解释：六个抽屉

| 抽屉 | 一句话 | 本次例子 |
|---|---|---|
| 尺度不同 | 一句话里含两个时间段 | 9 月去库 vs 10 月下跌 |
| 口径不同 | 全国/地区、收盘/结算、订价/区间中值 | 全国+6.21、华东-3.16、华南+9.37 |
| 存量 vs 流量 | 库存水平低，但每周仍在到货 | 库存历史低位 + 到港 15.90 万吨 |
| 预期 vs 现实 | 市场交易的是还没到港的船 | 11 月非伊供应恢复预期 |
| 被提前定价 | 利好见报当天就吃完 | 10/8 库存 30.51 → 10/9 涨超 6% |
| 外生冲击盖过 | 当日主变量不是库存 | 地缘/海峡封锁、原油 |

只在有数据支撑时使用；用不上就不写，不要凑六大原因。

## S7 产出

先用脚本生成 `data.json`，再生成 HTML/Excel。
- **不要手改生成物**：下次重跑会被覆盖，且 HTML 与 Excel 的数字会分叉。
- 文案与数字分离：文案里不允许出现“写死的数字”，一律从 `data.json` 取。
