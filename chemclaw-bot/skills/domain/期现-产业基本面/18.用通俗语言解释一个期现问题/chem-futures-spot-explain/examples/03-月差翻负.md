# 案例 03 · 月差收敛：近月还贵，但没那么贵了（甲醇 2026-10）

## 问题卡

| 项 | 值 |
|---|---|
| 问题 | 甲醇月差一直在收敛，是back结构要结束了吗？ |
| 合约对 | MA2611（近） / MA2701（远） |
| 窗口 | 2026-09-30 → 2026-10-19 |

## 定义先行（不然必错）

```
MC = F(远月) − F(近月) = MA2701 − MA2611
MC < 0 → back（近月升水 / 期货贴水）
MC > 0 → contango（近月贴水 / 期货升水）
```

> 若你看到的是“近月−远月”，符号完全相反——**报月差必须写清谁减谁**。

## 直接回答

**是 back 结构在收敛，但还没有转成 contango。** MC 从 −497（10-09）收窄到 −192（10-19），共 +305 元/吨：
近月依然比远月贵，但“贵”的程度在快速下降。市场在用月差表达：**短期仍有硬缺口，远期供应会回来**。

## 数据

| 日期 | MA2611 | MA2701 | MC（远−近） | MC% |
|---|---|---|---|---|
| 09-30 | 3384 | 2972 | −412 | −12.2% |
| 10-09 | 3835 | 3338 | **−497** | −13.0% |

| 10-16 | 3366 | 3192 | −174 | −5.2% |
| 10-19 | 3335 | 3143 | **−192** | −5.8% |

## 三条解释路径与验证

**M1 换月假象（已排除）**
- 检验：10-19 主力已由 MA2611 切到 MA2701，但 MA2611 当日仍成交 64.7 万手、持仓 18 万手，不是“僵尸合约”。
- 结论：价差变化是真实的结构变化，不是持仓转移造成的报价失真。

**M2 供应恢复预期（主要路径）**
- 验证：到港 3.88 → 15.90 万吨；隆众称 11 月非伊供应或回升；国际周产量 +4.16%
- 结论：远月被“供应回来”压制，近月被“眼下没货”撑住 → back 收敛

**M3 需求崩塌（加速路径）**
- 验证：江浙 MTO 负荷 20.06%，浙江两套烯烃已停
- 结论：需求端塌方让近月的“硬缺口”变小，back 收敛更快

## 最容易说错

1. **符号反了**：把 −192 说成“contango”。
2. **跨换月比较绝对价**：10-09 的 3835 是 MA2611，10-19 的 3143 是 MA2701，直接相减是跳空不是跌幅。
3. **用清淡合约**：临近交割的老合约报价失真，月差会假跳。
4. **只看月差不看持仓**：换月期不看持仓与成交，分不清真假。

## 反例条件

- 若 MA2611 在 11 月合约到期前出现“最后交易日逼仓”，MC 可能再度走深（−300 以下）。
- 若 11 月到港不及预期（周均低于 10 万吨），back 可能重新扩大。
