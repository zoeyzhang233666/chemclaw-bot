| 项 | 值 |

| 问题 | 甲醇港口库存下降，为什么甲醇价格仍然可能下跌？ |

## S1 概念

库存（存量，周度，样本港口）、库存变化（流量，周环比）、到港量（流量，外轮+内贸船）、基差（现货−期货）、月差（远月−近月）、MTO 负荷（需求总闸）、进口扳平（供给端机会成本）。

## S3 事实核对（核心）

| 尺度 | 库存 | 价格 | 并存？ |
|---|---|---|---|
| 月度（09-02 → 10-08） | 64.15 → 30.51（**−52.4%**） | 同期暴涨（10/8 涨停、10/9 涨超 6%） | **否** |
| 周度（10-08 → 10-14） | 30.51 → 36.72（**+20.4%，累库**） | 10/12 起高位回落 | 方向是“累库+下跌” |
| 日度（10-09 → 10-19） | 无当周增量（最近一期为累库） | 3338 → 3143（**−5.84%**，同合约） | **否** |

**判定**：本窗口 8 个周度变化点中，没有“库存环比为负且期货环比为负”的组合。
→ 结论：**不能**说“库存下降价格却跌”。真正成立的是“**库存处于统计期最低时，价格仍然可以跌**”。

## S4 计算（节选）

```
库存环比 = (36.72 − 30.51) / 30.51 × 100% = +20.35%
基差(10/15) = 3983 − 3170 = 813 元/吨；基差率 25.65%
月差 MC(10/09) = 3338 − 3835 = −497；MC(10/19) = 3143 − 3335 = −192；ΔMC = +305
到岸含税 = (444 × 6.72 × 1.05 + 75 + 50) × 1.13 = 3681.39 元/吨
表观提货 = 15.90 − 6.21 = 9.69 万吨（≠ 真实需求）
```

## S5 逻辑路径（节选）

**L2 库存下降 + 下游被迫停车**
- 预期：库存下降只反映“没人接货”→ 价格与基差同时走弱
- 验证：MTO 负荷下降、现货成交萎缩
- 本次：江浙 MTO 20.06%，浙江两套烯烃 9 月下旬已全停
- 反证：若下游开工上升而库存仍降，此路径不成立

**L5 库存低但供应预期恢复**
- 预期：期货先跌（交易未来累库），现货暂稳，基差被动走强
- 验证：到港量、外盘开工、进口预期
- 本次：到港 3.88 → 15.90 万吨；隆众称 11 月非伊供应或回升

## S6 矛盾原因（本次真的用得上四条）

1. **尺度不同**：9 月去库 vs 10 月下跌，两句话都对，拼起来就成了假矛盾。
2. **口径不同**：全国 +6.21，华东 −3.16，华南 +9.37。
3. **存量 vs 流量**：港口库存历史低位，但每周仍在到货。
4. **被提前定价**：10/8 库存数据 → 10/9 涨超 6%，利好当天吃完。
