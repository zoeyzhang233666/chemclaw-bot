# 案例 06 · 装置事故涨停，为什么两天就全跌回去了（甲醇 2026-10-08 → 10-15）

## 问题卡

| 项 | 值 |
|---|---|
| 问题 | 节后第一天甲醇涨停，怎么一周就跌回来了？地缘影响是假的吗？ |
| 品种 | 甲醇 MA｜MA2611（主力） |
| 窗口 | 2026-10-08 → 2026-10-15 |

## 直接回答

地缘影响是**真的**，但它影响的是**风险溢价**，不是**实际供给损失**。溢价来得快、去得也快：

- 10-08 涨停（MA2611 收 3625，+300）、10-09 盘中涨超 6% 报 3790
- 10-12 盘中跌超 6%、跌破 3600；10-15 收 3354（−4.28%）
- 两周不到，涨幅基本回吐

**理由有三条，按重要性排序**：
1. **溢价回吐**：10-11 伊朗称美方已接受部分重开海峡条件 → 供应风险溢价收缩
2. **需求端塌方**：江浙 MTO 21%以下（20.06%），浙江两套烯烃 9 月下旬已全停 → 高价撑不住
3. **供给预期恢复**：到港 3.88 → 15.90 万吨；隆众称 11 月非伊供应可能回升

## 事件性质拆解（这是本案例的方法论重点）

| 问题 | 本次答案 |
|---|---|
| 影响什么？ | 外轮到港（伊朗/中东货源）+ 运输路线（霍尔木兹） |
| 影响多久？ | 取决于海峡通航——不是永久性产能损失 |
| 影响多大？ | 用“周度到港量”量化：3.88 万吨（10-08），显性外轮仅 2.35 万吨 |
| 是否已完全反映？ | 10-09 涨停 + 研报归因 → 当天基本反映 |

> **判断事件驱动型行情，不是看事件有多大，而是看“事件会不会持续、能不能被量化”。**
> 持续性靠通航/装置重启新闻，量化靠到港量、开工率、库存。

## 持仓给出的二次信号

- 10-09：MA2611 持仓 45.4 万手（较 10-08 减少约 8.9 万手）——涨停中减仓，部分多头兑现
- 10-12：成交 320 万手（放量）、持仓降至 42.6 万手——放量下跌 + 减仓 = 多头撤退
- 10-15：持仓 26.2 万手——主力开始向 MA2701 转移

**增仓下跌与减仓下跌的含义不同**：前者是空头主动打压（更弱），后者是多头撤退（更可能是获利了结）。
本次以“多头撤退 + 换月”为主，因此下跌节奏偏震荡而非崩塌。

## 三条解释路径的验证状态

| 路径 | 状态 | 依据 |
|---|---|---|
| 地缘溢价回吐 | 部分证实 | 10-11 海峡重开消息 + 10-12 开盘跳水；但市场归因同时提到下游 |
| MTO 负反馈 | 部分证实 | 江浙负荷 20.06%、浙江装置已停、现货成交转弱 |
| 估值过高回归 | 部分证实 | 基差一度 846（基差率 26%），期现严重劈叉后收敛 |

## 最容易说错

1. 把一次地缘事件当作永久供给损失。
2. 用“涨价说明影响大”来评估影响，而不去量化到港量。
3. 把溢价回吐说成“市场不理性”。
4. 忽略下游负反馈——高价本身就会制造需求毁灭。

## 反例条件

若海峡再次实质封锁且持续时间超过 4 周、周度到港连续低于 5 万吨 → 溢价会重新变成实际缺口，价格会再创新高。
这条反例说明：**事件驱动的解释必须给出“什么情况下重新成立”。**
