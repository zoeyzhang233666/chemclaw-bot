# 案例 05 · 进口窗口打开了，为什么价格还在跌（甲醇 2026-10-19）

## 问题卡

| 项 | 值 |
|---|---|
| 问题 | 算下来进口有利润，为什么甲醇期货还在跌？不是说进口成本托底吗？ |
| 品种 | 甲醇 MA｜MA2701 |
| 窗口 | 2026-10-19 |

## 直接回答

**“进口有利润”是供给恢复的信号，不是价格的支撑。** 完整的因果链是：

```
进口利润为正 → 2-6 周后到港增加 → 港口累库 → 期货先行下跌
```

也就是说，进口利润打开**恰恰是价格下跌的理由之一**，不是托底的墙。
真正能托底的是“当期可得到的货的成本”，而当期你买不到那么便宜的船（运保费涨、窗口紧、罐容有限）。

## 算一遍（含敏感性）

```
CFR 中国 444 美元/吨 × 汇率 6.72 × (1 + 5% 关税) = 3132.86 元/吨
+ 海运保险 75（估价）+ 港杂 50（惯例值）= 3257.86 元/吨（不含增值税）
× (1 + 13% 增值税) = 3681.39 元/吨（到岸含税）

进口利润（对太仓区间中值 3940）= 3940 − 3681.39 = +258.61 元/吨
盘面价差（对 MA2701 3143）     = 3143 − 3681.39 = −538.39 元/吨
```

**关键观察：现货比进口成本贵 259 元，但期货比进口成本便宜 538 元。**
两者相差近 800 元——这正是基差（813）的来源。市场用基差告诉你：**眼下的货紧，未来的货松。**

敏感性（汇率 × CFR，到岸含税，元/吨）：

| 汇率＼CFR | 420 美元 | 444 美元 | 470 美元 |
|---|---|---|---|
| 6.60 | 3430 | 3618 | 3822 |
| 6.72 | 3490 | **3681** | 3889 |
| 6.85 | 3555 | 3750 | 3961 |

读法：CFR 每涨 10 美元，到岸成本约涨 76 元/吨；汇率每涨 0.1，约涨 47 元/吨。

## 五个“有利润但不跌/不涨”的真实原因

1. **时滞**：利润→船期 2-6 周，价格先动、货后到。
2. **运保费失真**：特殊时期海峡封锁，运保费可能从 40 涨到 120，本页用的是估价 75，估值误差会改变结论。
3. **罐容与窗口**：港口库容满、信用证开不出、船期压在交割月之后，都会让“理论利润”落不了地。
4. **盘面已定价**：期货已经跌到进口成本以下 538 元，说明市场提前把未来到港打进去了。
5. **口径**：CFR 基准港不同（中国主港 vs 东南亚）能差 5-15 美元；用错基准全盘皆错。

## 最容易说错

- 漏算增值税（直接低估 400 元/吨以上）。
- 用上周的运保费算这周的成本。
- 把“进口利润”当成“进口已经发生”。
- 用国内现货价去比 CFR（中间少了关税、增值税、运保、港杂）。

## 反例条件

若接下来两周到港量回落到 8 万吨以下，且进口利润仍在 200 以上 → 说明是“拿不到船/罐容紧”，
利润落不了地，价格反而可能反弹。这条反例必须写进报告，否则解释就是单向的。
