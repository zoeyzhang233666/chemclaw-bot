# 新案例模板：从零建一个上下游成本传导研究

复制 `project.template.json` 到 `examples/02-你的链条/project.json`，按下面六步填。

## 步骤 0：先确认值不值得做

做之前先回答三个问题。任何一个答不上来，先别开始算：

1. **上游真是下游的原料吗？** 有替代路线吗？进口占比大不大？
2. **单耗有可靠来源吗？** 理论单耗（分子量比）是下限，工业单耗必然更高。
3. **两条价格能取到同一时间范围、同一口径吗？** 一个是日度现货、另一个是月度长协，
   放在一起算阶段传导会得到假结果。

## 步骤 1：填 `process`（核实工艺）

- `route`：一句话说清用什么工艺
- `equation`：配平的反应式
- `verified`：**没有可靠来源就填 `false`**。报告会自动标红提醒读者
- `note`：写清依据（工艺说明、行业标准、企业公告）

理论单耗怎么算：把反应式配平，用分子量比得出下限。例如
PX（106.17）氧化成 PTA（166.13），理论单耗 = 106.17 / 166.13 = **0.639**。
工业实际值一定会高于这个数（副反应、损失、回收率），案例里用 0.655。

## 步骤 2：取两条价格

必须同时满足：

| 要求 | 原因 |
|---|---|
| 同一时间范围 | 少一天就少一个可比点 |
| 同一税基（都含税或都不含） | 含税与不含税差 13%，直接相减就错了 |
| 同一地区/交付口径 | 华东送到价 vs 华南出罐价不可直接比 |
| 同一频率 | 日度对上日度；月度对月度 |
| 保留原始单位和日期 | 换算是最后一步，换了就再也查不回 |

填进 `upstream.series` / `downstream.series`，格式 `{"YYYYMMDD": 价格}`。
（也可以放在 `price_series` 里，用 `series_key` 指过去。）

**单位警告**：如果上游是 CFR 美元报价，要先换算成元/吨：
`元/吨 = CFR × 汇率 × (1 + 关税率) × (1 + 增值税率)`。
换算完**必须检查数量级**——大宗化工品通常在 3,000 ~ 15,000 元/吨。
算出 11 元或 108,525 元，就是漏了或多了关税/汇率。

## 步骤 3：填 `materials`（单耗）

```
"materials": [
  {"name": "上游产品名", "unit": 0.655, "low": 0.648, "high": 0.665,
   "unit_basis": "吨/吨", "source": "来源"}
]
```

- `unit`：主模型用的工业单耗
- `low` / `high`：区间，用于敏感性。**宁宽不宁窄**，不同装置代际差一整代
- `source`：必须写。没来源的单耗宁可留空并标注，也不要编一个

`optional_materials` 里列出**没有纳入计算**的辅料（例如醋酸），
说明缺什么数据、影响多少元/吨。这一栏不填，读者会以为价差扣全了成本。

## 步骤 4：设断点

`params.breakpoints` 按价格走势的转折点切段，通常一年 4~6 段。
断点必须是实际的交易日（周期内的日期），否则分析会报错。

怎么找转折点：看价格曲线的大级别高点低点，以及装置集中检修/投产的时间。

## 步骤 5：设校准锚点

找 2~3 个**公开披露过加工费/价差**的时点，填进 `calibration_anchors`。
这是唯一能证明"我没算错"的手段。

```
{"date": "2026-09-24", "kind": "daily", "reported": 662.63,
 "source": "期货日报 / 建信期货"}
```

判断标准：

- 偏差在 **±150 元/吨内** → 口径可接受（各家采样企业与取价时点不同）
- 偏差**正负交替** → 统计差异，正常
- 偏差**系统性朝同一方向**且超过 200 → 公式或单位有问题，回去查步骤 2

## 步骤 6：生成与自检

```powershell
python scripts/build_all.py examples/02-你的链条/project.json --out-dir out
```

会依次跑：分析 → HTML → Excel → HTML 静态校验 → Excel 数值勾稽 → 浏览器实测。

## 交付前必须自查的四条

1. [ ] 报告里**每一次**出现"价差"的地方都带了"不是利润"的限定
2. [ ] 没有任何"预计/看涨/看跌/建议"式表述（`check_html.py` 会自动扫）
3. [ ] 背离区间里讲不清原因的，写的是"**原因未确认**"，不是编一个理由
4. [ ] 上游若是台阶式评估价，报告里披露了变动天数占比

## 常见错误对照表

| 症状 | 病因 |
|---|---|
| 成本 11 元/吨或 10 万元/吨 | 汇率换算多做或漏做 |
| 价差 1,500 以上，比公开数据高 1,400 | 同上（把元/吨当美元又换了一遍） |
| 原料成本占比 > 100% | 单耗或单位错 |
| 原料成本占比 < 50%（大宗品） | 单耗偏低或价格口径不一致 |
| 传导率动辄 3、5、10 倍 | 上游台阶式评估价，分母太小 |
| 价差全年一条直线 | 两条价格来自不同频率，或前值填充过度 |
| 恒等残差不为 0 | 计算组合有 bug（正常情况下必然是 0） |
