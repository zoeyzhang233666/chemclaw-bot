# 数据源与取价方法

按"先验证能拿到，再批量抓"的顺序。每条都要同时记下六个字段：
**数值 · 规格 · 地区 · 含税与否 · 日期 · 来源**。缺一项就不许进价格表。

## 一、国内日度评估价（首选，覆盖化工全品类）

### 生意社（100ppi.com）

**基准价日评**：每个交易日 08:30 发布一篇，标题形如
`10月20日生意社PTA基准价为7054.50元/吨`，正文含 `当日价 / 最小值 / 最大值 / 中位值 / 平均值 / 一年位置`。

按品种筛选的列表页（**推荐**，能按品种分页翻到一年前）：

```
https://www.100ppi.com/news/list-14-1217-{产品ID}-{页码}.html
```

- PX：产品 ID `388`
- PTA：产品 ID `442`
- 每页 50 条，一年约 6~7 页

**反例（别再用）**：

| 做法 | 结果 |
|---|---|
| `list-14--388-{page}` 深翻页 | 产品全站资讯流，PX 条目稀疏，26 页只回溯到 2026-02 |
| `?date=YYYYMMDD` 日期参数 | 被服务器忽略，返回当前页 |
| `graph/cindex.php` 图表接口 | 每次请求混淆随机化，无法解析 |

**必要请求头**：`Cookie: HW_CHECK=<值>` + `Referer`，否则返回"安全验证"页。
用 `urllib` + 自签证书上下文；`Invoke-WebRequest` 会 TLS 握手失败。

### 卓创资讯（sci99.com）/ 隆众资讯（oilchem.net）

- 卓创日评：`https://www.sci99.com/news/{id}.html`，日更，含现货加工费与开工负荷
- 隆众周度加工费：经我的钢铁网转载 `https://nenghua.mysteel.com/a/{date}/{hash}.html`，
  正文有"中国PTA加工费均值 xxx 元/吨"，**这是最好的加工费锚点**
- 注意：`nenghua` 的**列表页**有反爬行为验证，**文章详情页**可正常取

## 二、期货日线（免费、无 key）

东方财富行情接口：

```
https://push2his.eastmoney.com/api/qt/stock/kline/get
  ?secid={市场}.{代码}&fields1=f1,f2,f3&fields2=f51,f52,f53&klt=101&fqt=0&beg=YYYYMMDD
```

- 郑商所 PTA 主连：`115.TAM`；01 合约：`115.TA01`
- 返回 `klines` 字符串数组：`日期,开,收,高,低,量,额`

**两个坑**：

1. **必须绕过系统代理**（`requests` 设 `session.trust_env = False`，`proxies={'http':None,'https':None}`）。
   走本地代理会 `RemoteDisconnected`。
2. 这个接口**不稳定**，偶尔整段时间拒绝连接。期货数据不是本 Skill 的必需项，
   拿不到就跳过，用现货评估价即可完成全部八步。

## 三、事件与供需证据

**100ppi 品种资讯列表**（标题即事件摘要，非常适合做事件时间线）：

```
https://www.100ppi.com/news/list-{分类}--{产品ID}-{页码}.html
```

- PTA：`list-16--442-{page}`（26 页回溯到 2025-09）
- PX：`list-14--388-{page}`

用标题关键词打标签即可构建事件库：

| 标签 | 关键词 |
|---|---|
| 装置 | 停车 检修 重启 复产 开车 投产 降负 故障 不可抗力 |
| 供需库存 | 开工 负荷 库存 产量 产能 加工费 减产 |
| 进出口 | 出口 进口 关税 BIS 反倾销 美金 CFR |
| 下游需求 | 聚酯 涤纶 瓶片 长丝 短纤 织造 订单 纺 |

## 四、取不到时的替代顺序

1. 换同一品种的另一个资讯商（卓创 → 隆众 → 生意社 → 我的钢铁）
2. 用期货日线替代"下游现货价"，并**明确标注这是期货不是现货**
3. 用月度均价替代日度，**只做月度级别结论**，不做日度时滞分析
4. 全都没有 → 写进 `gaps`，不做这一列

## 五、绝对不要做的事

- 不要从图片图表里"目测读数"当数据
- 不要用某天的价格乘一个系数推算另一天的价格
- 不要把"行业人士称约 5000 元"写进价格表
- 不要混合不同来源拼成一条连续序列而不披露拼接点
