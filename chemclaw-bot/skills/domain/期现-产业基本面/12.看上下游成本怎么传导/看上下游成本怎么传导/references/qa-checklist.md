# 交付前检查清单

逐条打勾。任何一条打不上，就不要交付。

## A. 事实与口径

- [ ] 上游是不是下游的原料，已核实到可引用来源（不是"一般认为"）
- [ ] 反应式写出来了，理论单耗与工业单耗都给了
- [ ] 单耗有区间，主模型用的值说明了为什么选它
- [ ] 没进模型的辅料/成本项，逐项列出并量化影响
- [ ] 两个价格的口径六项齐全：数值·规格·地区·含税·日期·来源
- [ ] 单位自检通过：原料成本占下游价 60%~98%
- [ ] 如果用了美元价，换算公式与汇率日期都写出来了
- [ ] 锚点校验做过，偏差 <±150 元/吨（超了就要解释口径差异）

## B. 因果与利润（最容易犯的两条）

- [ ] 全报告没有出现"上游带动下游""因为上游涨所以下游涨"这类因果断言
- [ ] 相关系数只描述为"观察到的相关性"，附 lag 与样本数
- [ ] 加工价差**每一处**都带"价差口径，不是利润"的限定语
- [ ] 没有把加工价差写成"毛利""盈利""赚了 x 元"
- [ ] 背离区间的原因，要么有事件证据，要么写"原因未确认"

## C. 数据质量披露

- [ ] 评估价 vs 成交价说清楚了
- [ ] 上游"台阶式"更新（变动天数）披露了，传导率 >1 的阶段有降级说明
- [ ] 异常跳变的日期标出来了，没有静默剔除
- [ ] 缺失日期与前值填充天数披露了
- [ ] 数据缺口章节存在，且每条缺口写了影响

## D. 交付物

- [ ] HTML 单文件，双击能开，不依赖网络
- [ ] Excel 9 张表齐全，公式列可见
- [ ] 两个文件的数字同源（同一份 analysis.json）
- [ ] `check_html.py` 0 失败
- [ ] `check_xlsx.py` 0 失败
- [ ] `selftest.py` 打印"全部通过"

## E. 表述

- [ ] 没有预测未来涨跌（不写"预计""有望""看涨"）
- [ ] 没有投资/交易建议
- [ ] 数字都有单位
- [ ] 报告里能倒查到每一个数是怎么算的
