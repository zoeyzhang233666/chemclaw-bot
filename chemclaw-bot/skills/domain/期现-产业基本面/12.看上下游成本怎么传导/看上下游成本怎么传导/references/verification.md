# 工艺与单耗核实方法

单耗是整条成本链的分母，抄错一位小数，一年的价差全错。
本篇给出**怎么核实**，以及 PX→PTA 的实测结论供参照。

## 一、核实顺序（从硬到软）

| 优先级 | 来源 | 特点 |
|---|---|---|
| 1 | 反应式 + 分子量算理论值 | 物理下限，不会被商业利益扭曲 |
| 2 | 行业标准 / 工艺专利 | 最硬，但常要付费 |
| 3 | 期货公司深度研报 / 交易所培训材料 | 免费、有公式、可引用 |
| 4 | 产业资讯（隆众/卓创/生意社） | 最新，但常是转述 |
| 5 | 新闻与公众号 | 只用来交叉印证，不作唯一依据 |

**淘汰标准**：说不出出处的"行业普遍 0.66/0.67"、把副产收益算成负单耗却不说明的、
把不同工艺代际的数值混在一起的。

## 二、理论单耗怎么算

由反应式的化学计量比乘以分子量比：

```
理论单耗 = 上游分子量 / 下游分子量
```

PX→PTA：PX C8H10 分子量 106.17，PTA C8H6O4 分子量 166.13

```
理论单耗 = 106.17 / 166.13 = 0.639 吨 PX / 吨 PTA
```

反应式 `PX + 3O2 → PTA + 2H2O`，原子经济性 100%（无副产物），
所以 0.639 是**物理下限**，实际工业单耗必然高于它（损失、回收率、纯度）。

## 三、实际单耗怎么定

取区间中值做主线，用上下界做敏感性。PX→PTA 实测：

| 口径 | 数值 | 来源 |
|---|---|---|
| 理论下限 | 0.639 | 分子量比 |
| 早期装置 | 0.665 | 隆众：PX 单耗由 0.665 降至 0.648 |
| **计算口径（通用）** | **0.655** | 期货公司研报通用加工费公式 |
| 新装置 | 0.648 | 同上 |
| 六套装置实测 | 0.650~0.658 | 产业调研 |

**为什么选 0.655**：它是行业"加工费"公式的通用系数，用它与公开报告的
加工费数值对得上（见 `calibers.md` 的锚点校验）。若用 0.639，
算出的价差会系统性偏高约 150~200 元/吨。

## 四、辅料与公用工程

主模型只放**主原料**，辅料单列 `optional_materials` 并说明是否纳入。

PX→PTA：

| 项目 | 单耗 | 说明 |
|---|---|---|
| PX | 0.648~0.665 | 主原料，进主模型 |
| 醋酸 | 0.04（早期）→ 0.029（新建 ≥250 万吨） | 溶剂，**未纳入**（缺同期间价格序列） |
| 氧气 | 0.578 | 来自空分，随装置配套 |

醋酸对价差的影响：按醋酸 2,500 元/吨、单耗 0.03~0.04 估算，
约 **75~100 元/吨**。报告里要写明"这部分未计入"。

## 五、别把工艺方向搞反

加工链上常见的方向错误：

| 错误说法 | 实际 |
|---|---|
| 歧化/二甲苯分离是 PX 的**下游** | 是 PX 的**上游**（先有这些工艺才得到 PX） |
| PTA 可以用非 PX 路线商业化生产 | 国内装置**全部**是 PX 氧化路线，无商业化替代 |
| 生物基路线已替代石化 PTA | 仅 FDCA→PEF 万吨级示范，占总量 <0.1% |

## 六、交付前必须回答的四个问题

1. 上游是不是下游的**唯一/主要**原料？占成本多少？
2. 实际单耗是多少，区间多宽，来源是哪一个？
3. 有没有替代路线？如果没有，说清依据。
4. 哪些成本项**没有**进模型？逐项列出。
