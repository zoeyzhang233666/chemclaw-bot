# 口径换算与校验锚点

单位、税基、地区这三件事错了，整份报告的数字就全错了。
本篇给出换算公式、**必须做的自检**，以及用真实行业数值做锚点校验的方法。

## 一、单位换算（唯一正确写法）

### 美元 CFR → 人民币元/吨（含税）

```
上游价(元/吨) = CFR(美元/吨) × 汇率 × (1 + 关税率) × (1 + 增值税率)
```

- PX 等芳烃进口关税常见 **2%**；增值税 **13%**
- 汇率取报价日或合同约定日，必须在报告里写明用的是哪一天、哪个来源
- **常见错误**：漏掉关税项，或把"×1.13"写成"÷1.13"

### 元/吨 ↔ 美元/吨 的数量级自检

化工品 CFR 报价通常在 **700~1300 美元/吨**，对应人民币 **6,000~11,000 元/吨**。
如果你算出来是 11 元/吨 或 108,000 元/吨，说明小数点或系数错了。
**每次做换算后，都把结果打印出来看一眼数量级，不要直接喂进模型。**

### 每 1 美元/吨 对应多少元/吨成本

```
PTA 成本对 PX 的敏感度 = 单耗 × 汇率 × (1+关税) × (1+增值税) / 1
                      ≈ 0.655 × 7.0 × 1.02 × 1.13 ≈ 5.3 元/吨
```

行业常说的"PX 变动 1 美元，PTA 成本变动约 5 元"即由此而来。
如果你的模型算出来是 50 元或 0.5 元，立刻停下来查单位。

## 二、税基与地区

| 口径 | 说明 | 能否与另一口径直接相减 |
|---|---|---|
| 含税现款 / 不含税 | 差 13% 增值税 | **不能**，必须统一 |
| 承兑 / 现款 | 承兑有资金成本，通常比现款高 | 不能直接相减 |
| 出厂 / 到厂 / 主港自提 | 运费与港杂费不同 | 不能直接相减 |
| 华东 / 山东 / 华南 | 区域价差可达数百元 | 只能同区相减 |
| 评估价（生意社/卓创基准价）/ 实际成交 | 评估价是模型价，非成交 | 可比趋势，不可当成交价对外报价 |

**本 Skill 的默认口径**：元/吨、含税、现款、华东主港自提、生意社或卓创的日度评估价。

## 三、必须做的两个自检

### 自检 1：原料成本占下游价格的比例

```
原料成本占比 = (单耗 × 上游价) / 下游价
```

化工单耗型产业链的正常区间是 **60%~98%**。

- 若算出 **>100%**：单耗偏大，或上游价是美元值却当成元/吨用了
- 若算出 **<20%**：单耗偏小，或下游价取错了品种/单位
- PX→PTA 参考值：**约 96%~98%**（PTA 几乎全部成本是 PX）

### 自检 2：用真实行业报告的加工费做锚点校验

这是本 Skill 最重要的一步。做法：

1. 先用 `0.655 × PX` 算出模型的加工价差序列
2. 从公开研究报告/资讯里找 **2~3 个已知日期的加工费数值**
3. 算模型值与该日期的偏差

**判定标准**：

| 偏差 | 判定 |
|---|---|
| ±50 元/吨以内 | 口径基本一致，可用 |
| ±150 元/吨以内 | 可用，但需在报告里说明偏差来自统计样本差异 |
| 偏差几百到上千元/吨 | **口径不同，停下来查**，不要调参数去凑 |

### PX→PTA 的实测校验结果（本 Skill 已跑通）

用生意社 PX/PTA 基准价 + 单耗 0.655，对照三个独立来源：

| 锚点 | 模型值 | 报告值 | 偏差 |
|---|---|---|---|
| 2025-10 月均加工费 | 91 | 154（界面新闻） | −63 |
| 2026-08-20~26 周均 | 838 | 713（隆众资讯） | +125 |
| 2026-09-24 单日现货 | 531 | 663（期货日报/建信期货） | −132 |

三个锚点偏差都在 ±150 元/吨内且方向不一致（有正有负），
说明是**统计样本差异**（各机构采样企业、权重、取价时点不同），
不是公式错误。这是可以接受的，但必须在报告里如实列出。

**反例（曾经错过）**：如果把 PX 的元/吨报价再乘一次汇率，会得到
加工价差约 1,700~2,000 元/吨，比所有公开数据高 1,400 元/吨以上。
偏差远超 ±150，属于口径错误，必须停下重查。

## 四、评估价"台阶"对传导率的影响

日度评估价常常是**阶梯式更新**的：上游可能连续十几天不调价，某天一次性跳 300 元。
而下游（尤其是有期货的品种）每天都动。

后果：在"上游没动、下游动了"的阶段，

```
传导率 = Δ下游价 / Δ原料成本 ≈ Δ下游价 / 0 ≈ 几倍甚至几十倍
```

这个数字**没有意义**。脚本会给出：

- `steps.up_change_days` / `steps.down_change_days`：各自变动了多少天
- `stages[].pass_through_valid`：分母是否足够大（<成本 1% 视为无效）
- `flat_context`：每个上游台阶内下游的累计变动

**报告写法**："上游在 274 个交易日中仅 28 天调整报价，呈台阶式；
该阶段上游成本仅变动 131 元/吨，传导率 3.72 不具备解释力，
观察到的是下游自身供需定价。"

PX→PTA 实例：PX 基准价一年内只有 **28 天**发生变动，PTA 有 **249 天**变动。
这个不对称是解读所有传导率的前提。
