## 一、自动检查（必须全绿）

```bash
python scripts/selftest.py                                    # 33 项判定逻辑单测
python scripts/check_html.py  out/晨报.html build/data.json   # HTML 结构与数字同源
python scripts/check_xlsx.py  out/晨报.xlsx build/data.json   # Excel 逐格对齐
node   scripts/simulate_render.js out/晨报.html               # 渲染结果（无浏览器时）
python scripts/qa_render.py   out/晨报.html --shots shots     # 真浏览器（有 playwright 时）
```

- [ ] `selftest.py` 全通过
- [ ] `check_html.py` 无 FAIL（尤其：占位符已替换、无外链、方向性表述扫描通过）
- [ ] `check_xlsx.py` 无 FAIL（指标逐格与 data.json 一致）
- [ ] `simulate_render.js` 输出 ALL PASS（3 卡 / 3 面板 / ≥4 图表）

> 沙箱环境注意：`qa_render.py` 依赖 Playwright 通过管道启动浏览器，若被沙箱拒绝（`PermissionError: [WinError 5]`），属预期边界，跳过即可——`check_html.py` + `simulate_render.js` 已覆盖结构、数字、DOM 与图表 option。不要为绕过它去改沙箱。

## 二、时间与口径（最容易出错，逐条核）

- [ ] 报告日填写正确；若为非交易日，已顺延到最近交易日并注明
- [ ] 每条指标的 `data_date` 是**它自己的发布日期**，不是报告日
- [ ] 每条事件的 `event_date` 是发生日，与发布日分开
- [ ] `stale_days > 1` 的指标在正文中未被称为「今天」「当日」「最新变化」
- [ ] 周度/月度数据用「截至 X 日」表述
- [ ] 期货与现货时点一致（同为收盘或同为盘中）；盘中价单独标注
- [ ] 主连已处理换月（检查 `data.json` 里 `rolled` 字段与 `main_month`）
- [ ] 含税现货与不含税期货的基差未引出套利结论

**自检问句**：随便挑三条正文里的数字，问「这个数字是哪天、哪个区域的、含不含税？」——答不出来说明四要素缺失。

## 三、有没有把旧闻当新闻

- [ ] `events` 中 `status=repeat` 的条目，正文里均标了「旧闻·仅进展更新」，且未排在 A 级
- [ ] 每条 A 级事件的 `event_date` 均 ≥ 基线日
- [ ] 已核对关键页面/URL 的时间戳，排除去年同日的稿件（见 `research-playbook.md` 第 2 节）
- [ ] 没有「XX 海峡仍受阻」「XX 装置仍在停车」这类把持续性状态写成当日新增的表述

**自检问句**：把晨报里所有「今日 / 本期 / 新增」的句子挑出来，逐条问「这真的是基线之后才发生的吗？」

---

## 四、有没有凑篇幅

- [ ] 每个品种都至少有一条 A 级变化，或明确写了「本品种无可核实的实质新增变化」
- [ ] 没有「震荡偏弱」「关注库存拐点」这类无量化、无路径的句子
- [ ] C 级（噪声）条目未被放进 HTML 正文（只出现在 Excel 台账与「被排除资讯」区）
- [ ] 每条事件的 `impact_path` 都能说清「经由哪个环节、影响哪个数据」
- [ ] 若某品种确实无变化，是明写「无」，而不是用旧数据重新包装

**自检问句**：删掉任意一条，读者会损失信息吗？如果不会，它就不该在晨报里。

---

## 五、缺口是否诚实

- [ ] 所有未取得的数据都进了「数据缺口」表，含「缺什么 / 为什么 / 怎么补」
- [ ] 没有任何估算值、同比反推值、上月数据顶替当期值
- [ ] 缺口表里的「怎么补」是可执行的（具体到来源与栏目），不是「继续关注」
- [ ] `excluded` 表里每条都写了排除理由，重要的还给了核对方式

---

## 六、数字对不对（抽样复核）

- [ ] 抽 3 条 A 级指标，手工重算 `变动 = 本期 − 上期`，与页面一致
- [ ] 抽 2 条派生指标（基差/月差），按其 `formula` 重算，与页面一致
- [ ] 期货收盘与至少一个外部来源交叉核对过（如生意社结算表）
- [ ] 同一指标在 HTML 与 Excel 中数值完全相同（`check_xlsx.py` 已自动校验）
- [ ] 摘要卡、指标表、抽屉三处显示的是同一口径的同一个数
