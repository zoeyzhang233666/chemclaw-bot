# 变化检测、去重与分级：规则与推导

本文是晨报「只写新增与实质变化」这条铁律的实现说明。每一条规则都来自实战中踩过的坑。

---

## 1 基线对比：变动只能相对上一期

### 规则

`变动 = 本期值 − 上一期晨报同口径值`。

不得与更早的旧值相减来冒充「本期变动」。例如本期库存 41.33 万吨，上一期晨报记的是 37.41 万吨（10-08 口径），那么变动就是 +3.92；不能拿 9-30 的 45.08 相减得出「大幅去库 3.75」——那是上一期已经说过的变化。

### 基线空位的处理（最易出错）

上一期若**没有发布**这个指标（`base = null`），本期数值**不能**与任何陈旧值相减，必须判为「新增指标」，`abs = null`。

错误示范：上期该指标为空位，程序回退去拿了一个月前的值，算出「+0.00%」，读者会误以为「本期没有变化」。实际是「上一期没这个数据，本期首次出现」。

### 上一期沿用旧值的识别

实战中另一种情况：上一期晨报里库存写的是 41.33（其实是 10-15 的数据），本期源头仍是最新的 10-15 数据 41.33。此时两者相同，若直接相减会得到 0，掩盖了真实的 +10.48%（相对 10-08）。

处理：若「上期值 == 本期值」但「上期记录的日期 ≠ 本期配置指定的基线日期」，则回退使用配置里显式的 `base`，并把 `base_source` 标为「配置指定（上一期沿用了源头未更新）」，让读者知道这个基线是怎么来的。

### 陈旧数据的降级

`stale_days = 数据发布日期 − 报告日`。

- `stale_days = 0/1`：正常，视为当期数据；
- `stale_days > 1`：页面打「未更新」标签，级别最多到 B，正文只能写「截至 X 日，较上期…」，**不得**写「今天」「最新变化」「今日上涨」等措辞。

周度/月度数据天然如此：库存 10-15 发布、报告日 10-20，它是「最新有效值」，不是「当天变化」。这两者必须分开表达。

## 2 同口径：不同税基与不同时点不能相减

- 期货不含税、含交割成本；现货为含税厂提/库提报价。基差 = 含税现货 − 不含税期货，**只能用于观察期现结构**，不能据此得出无风险套利结论。
- 现货报价有「品牌报价 / 市场主流价 / 出厂价 / 送到价」之分。同一张表里混用会导致价差失真。
- 时间口径：价格类指标一律「报告日收盘 vs 基线日收盘」。盘中价单独标「盘中参考」，不参与涨跌计算。

反例（本技能开发中真实出现过）：摘要卡用主连 10-20 盘中价 3,117 计算 -0.83%，而下方指标表用 10-19 收盘 3,143 vs 10-16 的 3,366 计算 -6.63%。同一屏两个跌幅，读者无法判断哪个是「本期变化」。修正后统一为收盘对收盘，盘中价仅作附注。

## 3 事件去重（D1）

### 为什么不能只靠文本相似度

中文财经稿件是**改写**而非转载。实测同一件事的两篇稿子，2-gram Jaccard 相似度只有 **0.05–0.07**——远低于任何可用阈值。若把阈值降到 0.05，会把所有行业新闻混成一团。

实测数据（本案例）：

| 事件对 | 关系 | 相似度 |
|---|---|---|
| E01 / E02 | 同一海峡袭击事件的两次报道 | 0.059 |
| E07 / E20 | 同一区域价格行情 | 0.064 |
| E10 / E20 | 完全不同的两件事 | 0.049 |

可以看到「同事件」与「不同事件」的相似度区间完全重叠，**字符串相似度在这类语料上不可用**。

### 实际采用的判定：实体 + 数字指纹 + 时间窗

三条判据，命中任一即为同一事件：

**a) 实体 + 数字指纹**
把 `entity` 归一到规范名（「霍尔木兹/海峡/Hormuz」→「霍尔木兹海峡」），再看 `quant` 字段里的数字集合是否有交集。
理由：同一件事的改写稿几乎必然复述关键数字（「170 艘降至 8-20 艘」「330 万吨」），而不同事件的数字极少完全相同。

**b) 实体 + 类型族 + 时间窗**
同实体、同类型族（`plant/maintenance/restart/shutdown` 归一为 `plant`）、事件日相差 ≤1 天，且其中一方无量化信息时也判为同一事件。
理由：持续性事件（地缘冲突、检修进行中）会被反复报道，实体相同即是同一线索。

**c) 文本相似度 ≥ 0.55**
仅用于兜底真正的原文转载。

### 实体归一的注意事项

归一表要**由具体到宽泛**排序，否则宽泛词会抢先命中。

踩过的坑：把「PVC 开工」这个事件归一到「煤-兰炭-电石成本」，因为标题里出现了「电石」二字；把「山东明泉报价」与「临沂 PVC 行情」错误合并，因为都属于「价格」类型且数字有重叠。

修正：实体只从 `entity` 字段精确匹配，不扫标题；并把「开工/秋检/停车装置」的优先级提到「电石/煤价」之前。

## 4 旧闻识别（D2）

若 `event_date < baseline_date`，说明这条信息在上一期就已经存在。

处理不是删除，而是：

1. 标记 `status = "repeat"`；
2. 写入 `repeat_note`：「该事件发生于上一期基线（2026-10-16）之前，本期仅更新进展」；
3. 级别上限设为 **B**（评分再高也不能是 A）。

为什么不删：装置长期停车、产能投放计划这类信息是判断后续变化的背景，删掉会让读者看不懂「为什么今天开工率这么低」。但把它排在 A 级事件里，就等于把旧闻包装成新闻——这是晨报最容易失去可信度的地方。

---

## 5 泛评剔除（D3）

以下三类判为 C 级（噪声），不进正文 HTML，但保留在 Excel 台账与页面「被排除资讯」区：

1. **无量化**：「甲醇短期震荡偏弱，关注库存拐点」——没有数字，没有机制，无法验证；
2. **纯观点归纳**：「机构观点汇总：多数看空」——它描述的是别人的看法，不是产业变化；
3. **无明确影响路径**：「市场情绪转弱」——说不出经由哪个环节传导。

判据是：**能不能填出 `impact_path`（影响路径）**。填不出，就说明这条信息还没被理解透，不该出现在晨报里。

## 6 重要性分级

```
score = 影响路径 30 + 量化 25 + 时效性 20 + 独特性 15 + 覆盖度 10
A ≥ 70   B 45–69   C < 45
```

指标的级别则按模块阈值判定（`assemble.py` 的 `THRESHOLD`）：

| 模块 | A 级 | B 级 | C 级 |
|---|---|---|---|
| 价格 | 单日 ≥2% 或绝对变动 ≥100 元 | 单日 ≥1% 或任何非零变动 | 零变动 |
| 基差 | 变动 ≥60 元 | 变动 ≥30 元 | <30 元 |
| 月差 | 变动 ≥40 元 | 变动 ≥20 元 | <20 元 |
| 库存/开工/需求 | ≥2 个百分点或 ≥3% | ≥1 个百分点或 ≥1% | 其余 |

阈值可调，但**必须在同一期内保持一致**，否则同一份晨报里会出现「这条 23 元不重要、那条 25 元很重要」的自相矛盾。

## 7 主连换月陷阱

### 现象

主连不是固定合约，换月日会跳接到下一个合约。若直接用「今日收盘 / 昨日收盘」，会得到一天的假涨跌。

### 实测

2026-10-20 甲醇：
- 主连前收 3,143（MA2701）→ 当日 3,117，朴素计算 **-0.83%**；
- 但当日主力已切换，MA2701 自身为 3,143 → 3,117，实际 **-0.50%**；
- 差异来自新旧合约的价差，不是行情。

### 判定与处理

```
若 |今日开盘 − 昨日收盘| / 昨日收盘 > 8%  →  判为换月
   日涨跌 = 今日收盘 / 今日开盘 − 1        （日内涨跌）
   置 rolled = True，页面提示「换月跳接」
否则
   日涨跌 = 今日收盘 / 昨日收盘 − 1
```

8% 的阈值来自经验：正常隔夜跳空极少超过 5%，而换月跳接通常在 10% 以上。同时配置 `main_month_label` 后，`data.json` 会额外给出 `main_month.pct_day`，即真实主力合约的日涨跌，可直接对照。

## 8 方向性表述过滤

### 必须拦截

- 「预计…将上涨/下跌」「后市有望…」「看涨/看跌」
- 「抄底」「囤货待涨」「追涨杀跌」
- 「底部已现」「触底反弹」「已见底」
- 「上涨空间打开」「建议建仓/囤货」
- 「必然/肯定/无疑会涨跌」

### 必须放行（否则会误伤正常研究表述）

- 条件句：「**若**进口恢复，港口**将**集中到港」——这是传导逻辑；
- 历史事实：「10月19日主力**下跌** 6.62%」——已发生的事实；
- 情形推演：「**如果**海峡复航，甲醇地缘溢价**将**回落」。

实现方式：先剔除「若/如果/假如/一旦/倘若」引导的条件分句，再做正则匹配。这样既拦住预测，又不砍掉机制描述。

### 为什么这条重要

晨报一旦出现方向性判断，读者就会拿它当建议；判断错了，整份研究的可信度一起崩。而「只陈述已发生的事实 + 交代需要继续验证什么」，是研究员能长期交付的唯一姿态。
