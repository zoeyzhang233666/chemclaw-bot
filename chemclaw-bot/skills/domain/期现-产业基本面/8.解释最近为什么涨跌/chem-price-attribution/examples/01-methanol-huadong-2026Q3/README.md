# 案例 01：华东甲醇 2026-06-30 → 2026-10-19

真实案例，全部数字可追溯。用来演示本 Skill 的完整输出，也用来验证脚本改动没有破坏结论。

## 一、结论速览

| 口径 | 起 | 止 | 涨跌 |
|---|---|---|---|
| 现货（生意社华东基准价） | 2813.33 | 3966.67 | **+41.00%**（+1153.34 元/吨） |
| 期货主连 MA0 | 2428 | 3143 | +29.45% |
| 同一合约 MA2611 | 2394 | 3335 | **+39.31%** |
| 基差（现货−MA2611） | 419.33 | 631.67 | 峰值 1264（9/29） |

现货与期货真实涨幅接近，主连的 +29% 是换月名义价造成的假象。

## 二、五个价格阶段

| 阶段 | 区间 | 现货变化 | 关键事实 |
|---|---|---|---|
| P1 | 06-30→07-10 | 2813.33→2650.00（−5.8%） | 7/6 低点 2518.33；煤价同向下跌 |
| P2 | 07-10→08-26 | 2650.00→2990.00（+12.8%） | 煤 +8.5%，盘面 +17.9%；伊朗装置停车 |
| P3 | 08-27→09-28 | 2846.67→4443.33（**+56.1%**） | 基差 86.83→1194.33；开工率反升 |
| P4 | 09-29→10-09 | 4585→4733.33（+3.2%） | 现货新高但基差反而收敛到 898.33 |
| P5 | 10-12→10-19 | 4643.33→3966.67（−14.6%） | 10/13 单日 −12.78%；煤价仍在涨 |

## 三、八因子证据等级

| 排名 | 因子 | 等级 | 一句话 |
|---|---|---|---|
| 1 | 进口与外盘价格 | E1 | 伊朗多套装置停车 + 霍尔木兹航运，进口端被打穿 |
| 2 | 煤炭成本 | E1 | +22.21%，是"底"不是"幅度" |
| 3 | 原油与地缘 | E1 | +55.03%，与霍尔木兹风险同步 |
| 4 | 下游需求 MTO | E1 | 10/14 负反馈爆发，是下跌延续的第一顺序证据 |
| 5 | 基差·月差·期现结构 | E1 | 逐日可复算，顶部基差先行见顶 |
| 6 | 政策·事故·地缘 | E2 | 事件齐全但多为事后披露 |
| 7 | 装置检修·开工率 | E2 | 事件多，但开工率方向不支持"供给收缩" |
| 8 | 港口库存 | E3 | 只有定性表述，无逐周序列 |

## 四、演示的三条方法论要点

1. **复核先行**：主连 +29.45% vs 同一合约 +39.31%，差 10 个百分点，全因 9/30 换月名义价。
2. **反证必须露出**：第 5 条假设"国内装置检修致供给收缩"证据等级 **E4，方向相反**
   （9/21 开工率 83.8%、环比 +1.1pct、周产量 189.3 万吨），保留在报告里。
3. **未解释片段**：10/13 现货单日 −12.78%（4643.33→4050），当日无对应事件，
   10/14 的 MTO 公告还没发。报告里并列两种可能，不擅自选。

## 六、换品种要改什么

只改 `case.json` 与 `raw/`：

1. `case` / `window` / `history_start`；
2. `spot` / `futures` / `futures_front` 三个文件路径；
3. `meta.baseline_contract`（换成一个全窗口有成交的合约）与 `meta.spread_pair`；
4. `drivers` 里十个因子的文件名与指标名；
5. `periods`（可先留空，用异动识别的结果）；
6. 重写 `narrative.json`。

`scripts/` 一行都不用改。
