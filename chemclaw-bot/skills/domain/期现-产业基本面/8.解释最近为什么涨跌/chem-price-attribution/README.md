# 期现及产业基本面研究：解释最近为什么涨跌

一份可复现的**价格涨跌归因**工作流：给定品种、市场与时间区间，
系统检查十个标准因素，每个因素给出实数或明确标注「无可用数据」，
把价格异动、事件时点与各因素变化做时间对齐，再按证据强弱排列候选解释。

**产出**：单文件交互式 HTML 归因报告 + 13 表 Excel 工作簿 + 一套可反跑的脚本。

---

## 它解决什么问题

行情涨了或跌了，团队里总有四五种说法：成本推动、装置检修、进口受阻、
需求爆发、资金炒作。多数时候这些说法**都有一点道理，但都没被检验过**。

这份报告的立场是：

> 不告诉你"是什么原因"，而是告诉你**每个说法各自被证据支持到什么程度**，
> 以及**哪一个说法被数据直接否掉了**。

## 五条硬规矩

1. **先复核涨跌幅再解释。** 起点从真实价格数据里定，不从叙事需要里定。
   同一波行情换起点能差 16 个百分点。
2. **不预测。** 全文无「预计／看涨／看跌／抄底」。
3. **不做伪精确的百分比分解。** 排序只是排序，不写"成本解释了 40%"。
4. **缺数据就写缺口。** 不用行业经验值冒充实测值，不用插值凑序列。
5. **相关不等于因果。** "时间吻合"与"数据支持"分开标记。

## 十因子

1 本品种期现价格 · 2 上游原料成本 · 3 能源价格 · 4 装置检修与开工率 ·
5 新增产能 · 6 进出口与贸易政策 · 7 库存与结构 · 8 下游需求 ·
9 政策事故突发事件 · 10 基差／月差／期现结构

## 证据四级

| 等级 | 含义 |
|---|---|
| **E1** | 数据支持（有序列、显著、方向一致） |
| **E2** | 数据 + 事件时间吻合 |
| **E3** | 仅时间吻合 |
| **E4** | 缺乏证据／无法检验／**方向相反** |

方向相反的因子一律 E4，进了反证清单——这是本工具最有用的一格。

## HTML 报告有什么

- 首屏三条涨幅口径并列（现货／主连／同一合约），以及为什么它们不一样；
- 自动标注的价格异动与阶段切分；
- 十因子驱动树，可按 成本／供给／需求／库存／政策／期现结构 筛选；
- 事件时间线与价格叠加，标出每个事件相对阶段的领先天数；
- 点任意因子 → 抽屉里同时给出**同期图表、变化幅度、原始来源、证据判断**；
- **框选任意区间做局部归因**（拖动／下拉／快捷按钮三种方式）；
- 数据缺口清单与"这份报告不能说明什么"。

## 一条命令

```bash
python scripts/build_all.py --case examples/01-methanol-huadong-2026Q3/case.json
```

依次跑：异动识别 → 时间对齐 → 证据分级 → 汇总 → HTML → Excel → 三道自检。
任一失败即中止；全绿时打印 `HTML 通过 / Excel 通过 / 引擎 通过`。

`scripts/selftest.py` 把方法纪律写成了断言（缺失不填 0、反证不升级、阶段首尾相接、
主力不选空壳合约……），改脚本后必须仍然 12/12。

## 示例案例

`examples/01-methanol-huadong-2026Q3/` — 华东甲醇 2026-06-30 → 2026-10-19：

- 现货 **+41.00%**，主连 +29.45%，同一合约 MA2611 **+39.31%**（差额来自换月名义价）
- 基差（现货−MA2611）419.33 → 631.67，9/29 峰值 1264
- 十个因子里，**"国内装置检修致供给收缩"这条常见解释被数据否掉**：
  9/21 周度开工率 83.8%、环比 +1.1pct、周产量 189.3 万吨，供给在增。该假设标 E4 保留在报告里。

## 不做什么

不预测价格；不做百分比归因分解；不把时间吻合写成原因；
不在缺数据处编数；不因为结论好听就把它排前面。
