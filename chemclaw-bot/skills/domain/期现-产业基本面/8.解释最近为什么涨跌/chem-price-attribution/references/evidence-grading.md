# 证据分级：E1 / E2 / E3 / E4

本 Skill 的一切判断都收敛到这四个等级。它的作用不是给结论"加分"，
而是让读者一眼看出**哪句话是数据撑着的，哪句话只是我推测的**。

## 一、四个等级

| 等级 | 名称 | 判定条件 | 报告里的措辞 |
|---|---|---|---|
| **E1** | 数据支持 | 有可复算的逐日（或逐周）序列；窗口内变化幅度显著（\|z\| ≥ 1.0）；变化方向与价格一致 | 「数据显示……」 |
| **E2** | 数据 + 时间吻合 | 已达到 E1，**并且**存在可引事件，事件日期落在价格阶段起点前 1–3 个交易日内 | 「数据显示……，且事件时点吻合」 |
| **E3** | 仅时间吻合 | 只有事件、没有可比数据；或指标方向一致但不显著（\|z\| < 1.0） | 「时间上吻合，但缺少数据支持」 |
| **E4** | 缺乏证据 / 无法检验 | 无可用数据；**或**指标方向与价格相反 | 「无法检验」／「方向相反，不能解释」 |

## 二、关键边界（这里最容易出错）

### 1. 方向相反 → 一律 E4

若价格下跌而某指标上涨，该指标**不是**"支持下跌"的证据，哪怕它涨得很显著。
它进入 `counter_evidence`（反证清单），报告必须点名。

> 案例：2026-09-28→10-19 现货 −10.73%，同期秦皇岛 5500 大卡煤价 +4.15%。
> 煤炭成本在该区间被判 E4，并写入反证："成本在涨、价格在跌"。

### 2. 无数据 ≠ 没有影响

无数据只能得出"无法检验"，**不能**得出"该因素不重要"。
所有无数据的因子必须以 E4 出现在报告里，不许整块消失。

### 3. 显著性阈值

- `|z| ≥ 1.0` → 显著。z 由「窗口内变化量」对「历史上等长窗口变化量的分布」标准化得到，
  即：这一次的涨跌幅，在历史上算不算大。
- `|z| < 1.0` → 方向一致但幅度普通，最高只能给 E3。
- 历史上样本不足（等长窗口 < 8 个）时不计算 z，直接按 E3 处理，并标注"历史样本不足"。

### 4. 事件的"时间吻合"窗口

事件必须落在**价格阶段起点之前 1–3 个交易日**才算"领先"。
落在阶段中点或之后的事件属于**滞后反应**，只能解释"延续"不能解释"起点"，写作时要说明。

> 案例：MTO 降负公告 10/14，而现货单日重挫发生在 10/13、盘面顶部在 10/9。
> 因此该事件只能解释下跌的延续，不能解释下跌的起点——报告里必须写明。

### 5. 不允许叠加升级

同一驱动下有多条弱证据，**不能**因为条数多就升到 E1。
聚合时取该驱动下**最强的一条**作为驱动等级；条数只影响排序分，不影响等级。

## 三、排序分（只是排序工具）

```
驱动得分 = max(该驱动下各条目的等级权重)
等级权重：E1=4.0  E2=3.0  E3=1.5  E4=0.0
```

同分时，按"是否有可复算数值 → 事件数 → 字母序"稳定排序。

**这个分数绝不能被解释为"解释力百分比"。** 报告里只出现名次，不出现"占 X%"。
除非建立了经样本外验证的量化模型，否则任何百分比拆分都是伪精确。
