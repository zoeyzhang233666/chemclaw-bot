# 方法：从价格异动到证据排序

本文说明 `scripts/` 里每一步在算什么、为什么这么算。

## 一、先复核涨跌幅（不是可选步骤）

### 1.1 窗口端点取真实观测

窗口首末值取「≥ 起始日的第一个观测」与「≤ 结束日的最后一个观测」，
并**记录实际日期**。报告里永远写实际日期，不写窗口日期。

### 1.2 窗口内零观测 → 直接报 ND

区间内一个观测都没有时，**不得**返回"变化 0%"。
这是最隐蔽的错误：缺失会被读者读成"没变化"。
`align_series.window_stats` 对此有硬性拦截，`selftest.py` 有对应用例。

### 1.3 三口径并列

同一段行情至少给出三条涨幅：

| 口径 | 用途 |
|---|---|
| 现货 | 产业感受的锚 |
| 期货主连 | 盘面观感（含换月噪声） |
| 同一合约（如 MA2611） | 与现货可比的真实盘面涨幅 |

三者的差异本身就是结论的一部分：若主连涨幅显著低于同一合约，第一嫌疑是换月，不是挤仓。

## 二、异动识别

### 2.1 双条件

```
价格显著：|z(日收益率)| ≥ 2.0，z 基于滚动 60 日
成交量显著：z(成交量) ≥ 1.5
异动 = 价格显著 AND 成交量显著
```

单独的极端价格（如换月名义价）标记为 `price_only`，**不计入异动**；
单独放量但没有价格意义标记为 `vol_only`，同样不计入。

若数据源缺成交量，`detect(require_volume=True)` 默认**不**把它算作异动。
宁可漏报，不可误报。

### 2.2 聚类

相邻异动日间隔 ≤ 3 个交易日合并为一个簇，簇间视为独立事件。

## 三、阶段切分

用 Zigzag：从起点开始跟踪极值，当反向幅度超过 `phase_thr`（默认 3%~6%）时确认一个拐点。
实现上用方向状态机（`dirn ∈ {0, 1, -1}`），并要求方向被后续走势确认后才落点，
避免"每根 K 线都拐一次"。

**阶段必须首尾相接并覆盖全窗口**，`selftest.py::t_phase_segmentation_edges` 强制执行。

## 四、时间对齐

对每个因子序列，在**同一个窗口**上做：

1. 窗口首末值与实际日期；
2. 绝对/相对变化；
3. z 值 = 本次变化量 / 历史等长窗口变化量的标准差；
4. 历史分位（当前值在 `history_start` 之后所有观测中的排名）；
5. 方向一致性（与现货同向 / 反向）。

### 期现结构单独算

- 基差 = 现货 − **固定合约**收盘；
- 月差 = 固定一对合约的价差；
- 主力按**当日有效合约**中持仓量最大者，持仓量低于 500 手的残量合约排除
  （否则会选中已到期的空壳，制造假月差）。

## 五、局部归因（框选区间）

用户拖选一段图形后，对该区间**重跑**同一套规则：

- 区间内变化 → 显著性与方向；
- 方向相反且显著 → E4 反证；
- 区间内无观测 → "本区间内无观测"，不插值；
- 只有披露值、无逐日序列的因子 → **也要列出**，标注"仅有报告披露值，无法做区间重算"。

局部归因**不放宽**证据标准：区间越短，能达标的因子越少，这是正确行为。

### 缺失的边界

局部归因的 z 值用「区间内逐日收益的标准差 × √n」近似，
与全窗口基于历史等长窗口分布的 z 值**口径不同**，数值不可直接比较。
因此局部归因的等级仅用于**区间内**的相对排序，不与整段归因的等级混用。

## 六、排序

见 `evidence-grading.md`。再强调一次：排序分不是解释力，报告只出名次不出百分比。

## 七、可复现性

- 所有数字都由脚本从 `raw/` 原始文件算出，Excel 的 `12_复算校验` 表逐项复核；
- `raw/` 里每个文件都带来源 URL 与抓取时间；
- `scripts/build_all.py` 一条命令重跑全部产物；
- `scripts/selftest.py` 把方法纪律写成断言（缺失不填 0、反证不升级、阶段首尾相接…）。
