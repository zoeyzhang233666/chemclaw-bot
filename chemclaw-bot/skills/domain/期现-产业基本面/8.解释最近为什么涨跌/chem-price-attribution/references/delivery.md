# 交付与话术

## 一、交付什么

| 产物 | 说明 |
|---|---|
| `{市场}{品种}_归因报告.html` | 单文件、零外链、双击即开；含框选局部归因 |
| `{市场}{品种}_归因工作簿.xlsx` | 13 个工作表，含复算校验 |
| 一句结论 | 见下 |

文件命名带市场，避免不同案例互相覆盖。

## 二、一句结论怎么写

好的：

> 这是一轮「外生冲击打穿进口端 + 低库存放大 + 下游亏损后负反馈」的三段式行情，
> 不是单一煤炭成本推动；价格在 10/9 见顶后回落，回落的第一顺序证据是 MTO 降负的需求负反馈，
> 而不是成本回落。

差的：

> 主要原因是成本推动，进口次之，需求第三。（← 伪百分比分解）
> 预计后市将维持震荡偏强。（← 预测）
> 煤炭上涨直接导致甲醇上涨。（← 把相关当因果）

**句式模板**：

```
这是一轮「{阶段1的定性} + {阶段2} + {阶段3}」的行情，不是单一 {最常见的那个说法}；
价格在 {日期} 出现 {结构信号}，{方向的}第一顺序证据是 {证据等级最高且时间吻合的那个}，
而不是 {容易被误认的那个}。
```

## 三、被反问时的答法

| 对方问 | 答 |
|---|---|
| "到底哪个因素占多少？" | "没有经样本外验证的量化模型，任何百分比拆分都是伪精确。我只能告诉你哪几条有数据支持、强度排序如何。" |
| "煤涨了 13%，甲醇涨了 56%，这不就是成本推动吗？" | "煤价确实同向，但弹性差 4 倍以上，成本只能解释'底'不能解释'幅度'。而且 9 月下旬国内开工率还在升。" |
| "装置检修那么多，供给不是收缩了吗？" | "数据方向相反：9/21 周度开工率 83.8%、环比 +1.1pct，周产量 189.3 万吨。这条假设我标了 E4。" |
| "现货涨 41%、期货只涨 29%，是不是现货挤仓？" | "是换月造成的错觉。主连 9/29—9/30 切换，9/30 主连报 2972、同日 MA2611 报 3384，差 412。用同一合约算是 +39.31%，与现货基本一致。" |
| "那后面怎么走？" | "这不在本报告范围内。我能给的是：当前基差多少、处在什么分位、成本位置在哪、有没有出现顶部结构。方向判断请自己下。" |

## 四、必须随报告一起说的话

交付时主动讲清三件事，不要等对方问：

1. **这份报告不预测。** 它解释已经发生的涨跌。
2. **缺哪几项数据。** 港口周度库存没有逐周序列、单耗没有实测值，
   所以"库存驱动"只到 E3、"完全成本"干脆没算。
3. **哪条假设被自己的数据否掉了。** 国内装置检修那条是反向的，我保留了它并标了 E4。

第三条最能建立信任——**主动展示被否掉的假设，比展示五条成立的假设更有说服力**。

## 五、交付检查

- [ ] HTML 双击能开，无外链请求（断网可用）
- [ ] 五个抽屉都能点开，四件套齐全（同期图表／变化幅度／原始来源／证据判断）
- [ ] 框选一段后，反证因子被点名
- [ ] Excel `12_复算校验` 全部为"是"
- [ ] 全文无"预计/看涨/看跌/抄底/见底"
- [ ] "未解释的片段"章节非空
