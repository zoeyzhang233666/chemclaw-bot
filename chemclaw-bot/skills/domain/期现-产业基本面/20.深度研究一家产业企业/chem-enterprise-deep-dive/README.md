# README · chem-enterprise-deep-dive

**一句话**：把一个企业名称，变成一份"每条结论都能点开原文"的产业企业研究档案（HTML 交互档案 + 17 Sheet Excel 台账），适用于上市与非上市化工/材料/能源企业。

## 30 秒上手

```bash
# 用真实案例当模板
cp examples/example-1-shandong-haihua-soda-ash/data.json my.json
# 按 references/03-data-schema.md 逐字段替换后渲染
python scripts/build.py my.json -o output --strict
```

产出：
- `output/企业深研_{公司}_{用途}.html` —— 12 区块交互档案，可离线打开
- `output/企业深研_{公司}_{用途}.xlsx` —— 17 Sheet 台账，每行带证据编号

依赖：Python 3.9+、`openpyxl`（缺失自动降级 CSV）。HTML 零依赖。

## 它解决的问题

| 传统做法 | 本 Skill |
|---|---|
| 把集团产能当上市公司产能 | 主体消歧表 + 并表/合营/兄弟公司分层 |
| 把经营范围当产品清单 | 只收有装置/产能/许可证据的品种 |
| 一堆「据公开资料」无法溯源 | 每条结论挂 `E编号`，点开即见原文与日期 |
| 估算值混进披露值 | D 级估算强制写 `basis`，`--strict` 不过就失败 |
| 没查到的地方留白 | 统一「无公开资料」+ `gaps[]` 缺口清单与核实途径 |
| 顺手写「预计明年扭亏」 | 明令禁止预测；公司口径预测必须标注来源 |

## 案例一：山东海化（真实）

- 主体：山东海化股份有限公司，`91370000706206553L`，深交所 000822
- 关键结论：纯碱设计产能 280 万吨/年（氨碱法，老线 120 + 新线 160），2025 年产能利用率 97.29%；2025 年营收 47.45 亿元、归母净利 −13.88 亿元；48.37 亿元"氨碱改联碱"改造工程（100 万吨联碱置换 120 万吨氨碱，副产氯化铵 103 万吨）
- 该案例专门演示了四类坑：①集团（山东海化集团）与上市公司的资产边界；②骊潍新材料 51% 但为合营企业不并表；③小苏打厂是租赁经营集团资产；④中盐（内蒙古）碱业 29% 参股产能不计入

## 案例二：教学最小样例（虚构）

仅含 6 条证据、3 个产品、1 个基地、2 个项目，用来演示非上市企业的写法：**没有财务表 → 章节显示「不推测营收与盈利」**，规模仅用公开产能/员工数/中标金额表达。

## 常见问题

**Q：找不到年报怎么办？**
非上市企业没有年报：改走「环评公示 + 安许/排污许可 + 官网产品页 + 政府项目备案 + 招投标公告」，产能优先用环评口径，财务章节留空并在 `gaps` 写明。

**Q：产能有好几个数怎么办？**
都要，且标清定义（规模/生产面积口径/现能力/设计产能/实际产量）。见 `04-evidence-grading.md` §4。

**Q：能加图表吗？**
可以，但图表只能由 data.json 的数据生成，不允许"为了好看"插行业曲线。当前版本用 KPI 卡、泳道图、时间线与地图表达，足够承载结论。

**Q：能做成报告/PPT 吗？**
先出 HTML 与 Excel，再基于同一份 data.json 改写；不要在另写一份时改动数字。
