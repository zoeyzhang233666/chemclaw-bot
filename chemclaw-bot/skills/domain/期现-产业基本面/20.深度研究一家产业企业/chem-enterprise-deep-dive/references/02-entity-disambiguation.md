# 02 · 主体消歧与资产边界判定规则

> 一份企业研究档案最常见的硬错误不是「数字查错」，而是「主体搞错」。本文件把主体边界做成可执行的判定树。

---

## 1. 唯一主键：统一社会信用代码

- 一切数字（产能、产量、资产、员工、许可）必须挂到一个 **18 位统一社会信用代码** 上。
- 分公司（`XX 厂`、`XX 分公司`）**没有独立法人资格**，代码是母公司的，产能在母公司名下。
- 若拿不到代码：A 股上市公司用「股票代码 + 年报」代替，非上市企业用「信用公示系统页面 + 注册地址 + 成立日期」三者组合锁定，并标注为 B 级。

## 2. 候选主体分类判定树

```
拿到一个名称
├─ 名称完全一致？
│   ├─ 是 → 比对代码/注册地址/成立日期 → 一致 = 研究主体
│   └─ 否 → 进入"近名"分支
├─ 近名分支
│   ├─ 含"集团"二字且为母公司 → 控股股东，单独成主体，不并入
│   ├─ 研究主体 + "XX厂/分公司" → 分公司，产能在母公司，纳入生产单元
│   ├─ 研究主体 + "XX有限公司" 且持股≥50% → 查是否并表（见 §3）
│   ├─ 研究主体 + "XX有限公司" 且持股<50% → 联营企业，不并表
│   ├─ 控股股东 + "XX有限公司"（兄弟公司）→ 不属研究主体，列入"易混淆主体"
│   └─ 同城同行业但无股权关系 → 同名竞争对手，列入消歧表"排除"
└─ 无任何公开工商信息 → 标 NA，不得据名称推断产能或产品
```

## 3. 「持股 50% 以上但仍不并表」的判定（必查）

满足下列任一，按合营企业 / 权益法处理，**不得并表、不得计入产能**：

1. 章程或投资协议约定**董事会重大事项需三分之二以上表决通过**，且少数股东委派董事足以否决；
2. 董事会席位中本方委派人数**未过半**；
3. 协议约定共同控制（joint control）；
4. 年报会计政策明确写「按权益法核算」。

> 案例：某上市化工企业持有某新材料公司 **51%**，但因董事会 5 席中本方仅 3 席且重大事项需 2/3 通过，年报将其列为**合营企业**、权益法核算——产能与收入均不并表。若把它当子公司，产能与财务都会算错。

## 4. 「100% 持股但资产不是自己的」

- **租赁经营**：企业租用集团/第三方厂房的整体资产经营（如年租金 375 万元租用集团小苏打厂资产）。此时：生产主体是承租方（可计入其产量），但**资产所有权属出租方**，产能归属要写「租赁经营，资产非自有」。
- **代销/代加工**：产品生产方是关联方，销售由本方分公司承担。产品**不得**计入本方产品与产能清单，只能记入产业链「关联交易」。

## 5. 集团资产边界三问（每个工厂都要过）

1. 这座工厂的**法人主体**是谁？（代码）
2. 研究主体对它**直接或间接持股**多少？**合并范围**里有没有它？
3. 它的资产是否已被**租赁/托管/代管**给研究主体？（若是，注明「经营在体、资产在体外」）

三问答案不一致时，以**合并范围附注**为准，其他口径仅作说明。

## 6. 消歧表必填字段

| 字段 | 说明 |
|---|---|
| `name` | 主体全称 |
| `uscc` | 统一社会信用代码（拿不到写 `null`，不编造） |
| `relation` | 与研究主体的关系：研究主体 / 控股股东 / 实际控制人 / 分公司 / 全资子公司 / 控股子公司 / 合营企业 / 联营企业 / 兄弟公司 / 同名无关企业 |
| `verdict` | 判定依据（一句话，写清为什么纳入或排除） |
| `in_scope` | true / false |
| `ev` + `grade` | 证据编号与等级 |

## 7. 典型命名陷阱

| 陷阱 | 例子 | 正确处理 |
|---|---|---|
| 集团与上市公司同名同字号 | 「XX 集团有限公司」vs「XX 股份有限公司」 | 做成两个主体，集团资产单列 |
| 上市公司全资子公司沿用老厂名 | 「XX 氯碱树脂有限公司」实为股份公司 100% 子公司 | 归入并表子公司，产能计入 |
| 分公司被媒体当作独立公司 | 「XX 股份公司 XX 厂」 | 标注「分公司，非独立法人」 |
| 参股公司名称含「海化/XX」 | 「中盐（内蒙古）碱业」持股 29% | 联营企业，产能不计入 |
| 第三方聚合平台给的成立日期与年报不同 | 工商登记日 vs 批准设立日 | 以年报为准，差异写明 |
| 官网地址与年报地址不一致 | 氯化钙厂在寒亭区 vs 滨海新区 | 两说并列，标 B/C 级，列为待核验 |
