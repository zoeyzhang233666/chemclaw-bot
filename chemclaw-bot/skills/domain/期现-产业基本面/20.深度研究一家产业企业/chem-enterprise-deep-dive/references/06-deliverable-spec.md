# 06 · 交付物规格（HTML 档案 / Excel 台账）

## 1. HTML：单文件交互档案

### 1.1 技术约束

- **单文件**，内联 CSS/JS，无 CDN、无外部字体、无接口请求 → 可离线打开、可邮件转发、可打印。
- 目标浏览器：Chrome / Edge ≥ 100。宽度自适应，≥960px 为设计主线。
- 地图为手绘 SVG 示意轮廓 + 城市坐标投影，**不是**真实地理图，需保留提示。
- 打印样式：隐藏筛选栏与证据抽屉，卡片不跨页断开。

### 1.2 视觉语言（已内置于 build.py）

| 元素 | 规格 |
|---|---|
| 主色 | 深海军蓝 → 亮蓝渐变 `#0d1f3f → #1554c0`，强调色同主蓝 |
| 语义色 | 绿 `#1a7f4f`=正常/已核实；黄 `#8a6100`=待复核；红 `#c0392b`=关注/在建；紫 `#5b46b8`=估算/参股 |
| 卡片 | 白底、1px `#e4e8ee` 边框、14px 圆角、极浅投影 |
| 区块标题 | 蓝色方块序号 + 标题 + 灰色提示语 |
| 字体 | Microsoft YaHei / PingFang SC 栈；数字用等宽数字（`tabular-nums`） |

### 1.3 十二区块与信息密度

| # | 区块 | 必须包含 | 交互 |
|---|---|---|---|
| 1 | Hero | 全称、一句话定位、代码、上市信息、研究目的、检索窗口、4–6 关键数字 | — |
| 2 | 主体信息与消歧 | 分组工商字段（每字段带证据）+ 消歧表 | 点击字段证据 |

### 1.4 交互规范

- **证据抽屉**：点击任意 `E05` → 右侧 560px 面板滑出，含标题/发布方/日期/类型/原文摘录/URL/备注；`Esc` 或点遮罩关闭。
- **筛选器**：每个下拉为单选（全部 + 各取值），关键词为全文包含匹配；命中数实时显示；「重置」清空。
- **地图联动**：点击标记或卡片，双方高亮并滚动到对应卡片。
- **等级徽章**：`A 已核实 / B 多源 / C 单源 / D 估算 / NA 无资料`，悬停显示判定标准。
- **无资料占位**：统一灰色「无公开资料」，不显示空白单元格。

### 1.5 文案纪律

- 不出现「预计」「有望」「将大幅」，除非引号内是公司原文并注明口径。
- 结论卡答案 ≤ 30 字，理由里用 `<b>` 突出可核验数字。
- 每个区块开头一句 `lead` 说明"这一节回答什么问题"。

## 2. Excel：17 Sheet 台账

### 2.1 通用规范

- 每个 Sheet：首行深蓝底白字表头，冻结首行，自动筛选，正文自动换行。
- 每张业务表**最后一列之前**必有 `证据编号`（多值用「、」分隔）与 `等级` 两列。
- `16_证据台账` 的 `URL` 列自动超链接。
- Sheet 名带两位数字前缀，保证顺序稳定。

## 3. 交付话术（随文件一起给出）

用三句话交代清楚，避免用户误读：

1. **做了什么**：研究主体锁定为什么代码的哪家公司，覆盖哪九个章节，检索窗口到哪天。
2. **哪里有底气**：共 N 条证据，其中 A 级 x 条（年报/公告/环评/证照），关键结论如产能、股权、项目均有一手来源。
3. **哪里有缺口**：列出 3–6 项主要「无公开资料 / 待核验」，并给出下一步核实途径（哪个网站、找哪个部门）。

> 不要用「数据仅供参考」「请以官方为准」这类空话充当免责声明；写清**具体**的强项与缺口。
