# 05 · 交付前自检清单（40 项）

交付前逐条打勾。任何一条不过，就不要交付。可用 `python scripts/build.py data.json -o out --strict` 先跑机器可校验的前 6 项。

## A. 主体与股权（1–10）

1. [ ] 研究主体的统一社会信用代码已取得并有 A 级证据
2. [ ] 至少列出 5 个近名/关联主体并逐个判定纳入或排除
3. [ ] 控股股东与**实际控制人**层级写清（国资 → 集团 → 主体）
4. [ ] 合并范围子公司与「参股/合营」已分开列示
5. [ ] 核查过「>50% 但不并表」的合营企业（章程/董事会表决机制）
6. [ ] 核查过「租赁经营/代销/代加工」导致的资产与产能错位
7. [ ] 同集团兄弟公司已单列为「易混淆主体」，其产能未计入
8. [ ] 分公司已标注「非独立法人」
9. [ ] 成立时间与上市时间区分（批准设立日 vs 工商登记日）
10. [ ] 股权质押/冻结状态已核实

## B. 产品与产能（11–20）

11. [ ] 产品清单只含「有装置/产能/许可证据」的品种，无经营范围堆砌
12. [ ] 每个产品的产能**口径**（设计产能/产量/企业自述）已标明
13. [ ] 一个产品多口径时全部并列，未擅自取舍
14. [ ] 产能利用率取自年报「主要产品产能情况」表
15. [ ] 工艺路线写清（如氨碱法/联碱法/离子膜/空气吹出法）
16. [ ] 装置级信息有环评或安许支撑（台数、套数、规格）
17. [ ] 停产、减值、老旧装置状态已标出
18. [ ] 估算产能均带 `estimate:true` + `basis`
19. [ ] 在建/拟建项目未混入现有产能
20. [ ] 有下游流向说明（谁买、做什么用）

## C. 基地与区域（21–26）

21. [ ] 每个基地写清**法人主体归属**与所在地
22. [ ] 并表/不并表在基地层面标明
23. [ ] 原盐/蒸汽/电等内部配套关系写清（谁供谁）
24. [ ] 区域布局覆盖省内、省外、海外（无则写「无公开资料」）
25. [ ] 分地区收入占比与合计口径差异已说明
26. [ ] 地图标注了「示意图，非精确边界」

## D. 财务与经营（27–33）

27. [ ] 财务表覆盖 3 年 + 最近一期，且标明单位与是否经审计
28. [ ] 亏损年份注明是否含大额减值
29. [ ] 经营现金流异常时给出票据口径双数字
30. [ ] 分产品收入占比与毛利率已列
31. [ ] 前五大客户/供应商集中度与关联方占比已列
32. [ ] 非上市主体**未**推测营收与利润
33. [ ] 未出现任何「预计明年/未来将」式经营预测（公司口径除外且已标注）

## E. 风险与事件（34–38）

34. [ ] 行政处罚、诉讼、被执行/失信各自给出结论（含「无/未查询」结论）
35. [ ] 安全环保：检查次数、整改、事故，以及环境信息依法披露名单
36. [ ] 关键证照有效期已列并标出临近到期
37. [ ] 关联交易额度与实际发生额、关联担保余额已列
38. [ ] 近 12 个月重要动态按日期倒序，覆盖公告 + 项目 + 治理 + 市场

## F. 交付质量（39–40）

39. [ ] 每条结论都有 `E` 编号；每个 `E` 编号都能在台账中找到且 URL 可打开
40. [ ] 缺口清单（`gaps`）已列出缺失项与核实途径；免责声明与检索窗口已在文末显示

## 机器自检（可选）

```bash
# 严格口径校验（证据编号/等级/估算 basis）
python scripts/build.py data.json -o out --strict

# 无头浏览器 DOM 与交互回归（需本地 Chromium 与 websocket-client）
python scripts/_shot.py out/企业深研_XXX.html out shot_cfg.json

# 截图非空探测（避免"白屏交付"）
python scripts/_probe.py out/shot_top.png
```

`_shot.py` 会输出：页面高度/宽度、卡片数、证据数，以及 13 项 CHECK（股权树、地图标记、时间线、产品卡、筛选下拉、证据抽屉、筛选命中数、地图联动等），最后给出 `CHECK_FAILED` 计数，应为 0。
