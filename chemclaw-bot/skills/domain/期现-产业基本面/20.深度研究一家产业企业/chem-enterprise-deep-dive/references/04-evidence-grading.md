# 04 · 证据分级、摘录取证与冲突处理

---

## 1. 五级刻度（唯一评价标准）

| 等级 | 名称 | 判定条件 | 例 |
|---|---|---|---|
| **A** | 官方一手 | 由法定主体或监管部门**直接发布**，可下载原文 | 交易所公告/年报、环评批复、安全生产许可证、排污许可证、采矿许可证、政府处罚决定书、法院公告 |
| **B** | 多源或自述 | 企业官网/官微的自述事实，或 ≥2 家相互独立的可信来源一致 | 官网「年产能 40 万吨」、新华网转载企业稿、两家财经媒体同日报道同一公告内容 |
| **C** | 单一二手 | 只有 1 个非官方来源，或来源本身是聚合/索引页 | 单家财经媒体报道、行业资讯网「暂不报价」、公告索引页（只看到标题） |
| **D** | 估算 | 由公开数据经算式推得，非任何主体披露 | 「公司产能 ÷ 行业有效产能」得份额；「160+100=260 万吨」 |
| **NA** | 无公开资料 | 检索后未获得可用信息 | 未披露的采购方名单、泰安子公司具体项目 |

**升档规则**：C 级信息若能找到官方原文，立即升为 A 并把官方链接放前面；B 级自述若能对上环评/年报数字，升 A。

## 2. 一条合格证据的五个要素

```
标题（谁发的什么文件） + 发布方 + 日期 + URL + 原文摘录
```

缺任一项都不是合格证据。摘录要求：
- 直接复制原文句子（可截断），**不改写任何数字**；
- 摘录里应至少包含一个你在正文引用的关键数字（如总投资额、产能、比例），便于交叉核对；
- 若正文数字来自表格而非语句，摘录写表名 + 「表内数：…」。

## 3. 引用方式

- 正文**只写编号** `E05`，不写「据某媒体」；编号点击即弹证据。
- 一个判断可挂多条证据（如产能既要年报也要环评），全部列出。
- 同一 URL 只建一条证据，多个结论共享。
- 不给「来源：公开资料」「来源：网络」这种无法溯源的写法。

## 4. 冲突处理四原则

1. **时间优先**：同主体同事项的两年口径不一致时，以最新一期年报为准，并注明旧口径。
2. **口径并列，不改写**：一个产品出现「规模 240 万吨 / 生产面积口径 160 万吨 / 现能力 150 万吨」时，三条都写，标清各自定义，不选「看起来最合理」的那条。
3. **级别高者胜，但必须解释**：A 级与 B 级冲突时用 A，并在 `note` 写「官网口径为 X，年报口径为 Y，本档案采用年报口径」。
4. **合计不平衡就说明，不归一**：分地区收入行合计大于总额（披露格式差异）时，标注「口径差异，不强行加总」，绝不按比例缩放。

## 5. 三种特殊情形的写法

### 5.1 公司自己给的预测
写成「公司测算/预可研口径：年均可实现营收 X、税后净利 Y、IRR Z%」，并在 `finance_caveat` 或 `conclusion_note` 声明：**这是公司口径，不是本档案的预测**。

### 5.2 媒体的时间表
写「媒体称计划 X 月开工、Y 年投产（未见公司公告原文，待核实）」，等级 C，并进 `gaps`。

### 5.3 只有标题没有正文
写「据公告索引，X 日发布《…》公告（正文未获取）」，等级 C。**不得**根据标题推断公告内容。

## 6. 「已核实 / 无公开资料 / 待核验」三档交付口径

| 档位 | 判定 | 在交付物中的呈现 |
|---|---|---|
| 已核实 | A 级证据，或有 ≥2 独立来源支持 | 正常显示 + 等级徽章 |
| 待核验 | C 级单源、口径冲突、媒体时间表 | 黄色徽章 + 进 `gaps[]` |
| 无公开资料 | 检索未获得，或已明示不适用 | 灰色「无公开资料」+ 进 `gaps[]` 并给核实途径 |

**空值处理**：已知缺失但重要（如「行政处罚明细」「被执行记录」）必须显式写 `null` 并说明「年报称无处罚 / 未查询裁判文书网」，不能省略字段，否则读者会误以为已核实。

## 7. 数字书写的口径惯例（化工/期现）

- 产能：`万吨/年`；烧碱注明「以 100% NaOH 计」；液碱注明折百或商品量（如「32% 液碱 87 万吨/年」）。
- 价格：注明`元/吨`、`含税/不含税`、`出厂/到厂`、`区间（上/下半年）`。
- 财务：`亿元`，保留两位小数；同比用 `%` 并注明「归母」「扣非」。
- 时间：`YYYY-MM-DD`；只有月份写 `YYYY-MM`；只有年份写 `YYYY年`。
- 比例：持股比例写 `%` 并附股数（若披露）。
