# 01 · 检索 Playbook（分阶段信息源与话术）

按「先官方、再自述、后二手」的顺序检索。每拿到一条可用信息，**立刻**记入证据台账（标题 / 发布方 / 日期 / URL / 原文摘录 / 等级），不要等到最后回忆。

---

## A. 主体与工商信息

| 要找什么 | 首选来源 | 检索方式 / 话术 |
|---|---|---|
| 全称、统一社会信用代码、注册地址、法定代表人、注册资本 | A 股/港股/债券公告的年报「公司基本情况」章节 | 巨潮资讯网按代码检索年报，PDF 内搜索「统一社会信用代码」「注册地址」「法定代表人」 |
| 成立时间、上市时间 | 年报「公司简介」+ 招股说明书 | 注意第三方聚合平台常给「工商登记日」，与「批准设立日」不同，两者并存要标注 |
| 经营范围全量 | 国家企业信用信息公示系统（gsxt）/ 信用中国 | 年报通常只给「主要从事」，全量经营范围需信用公示系统；**不要**把经营范围当产品 |
| 经营状态异常、年报异常 | gsxt「经营异常名录」、信用中国 | 关键词：`<企业全称> 经营异常` |
| 行政处罚 | 信用中国、地方生态环境局/应急管理局公示 | 关键词：`<企业全称> 行政处罚 决定书` |
| 被执行 / 失信 / 限高 | 中国执行信息公开网、裁判文书网 | 按企业名称精确检索；空结果不等于无记录，需在 `gaps` 写明「未查询/未能核验」 |
| 资质与许可（安许、排污、采矿、食品、饲料） | 地方应急管理局、生态环境局、自然资源局公示 | 证照有效期是供应商调查的高价值字段，必查到期日 |

## B. 股权与实际控制人

1. 年报「股东情况」：前十大股东、控股股东持股数与比例、质押/冻结情况。
2. 年报「关联方及关联交易」附注：母公司、实际控制人、同一控制下企业清单 —— **这是判定「集团 vs 上市公司」最可靠的来源**。
3. 年报「合并范围」附注：子公司名称、注册资本、持股比例、取得方式（设立/同一控制下合并/非同一控制下合并）。
4. 集团官网「成员企业」页：可补全上市体系外的兄弟公司（能源、包装、物流、环保等），用于识别**易混淆主体**。
5. 增资/收购公告：投资额、持股比例、会计核算方法（长期股权投资权益法 vs 合并）。

**特别注意三种「看着像子公司其实不是」**：
- 持股 >50% 但章程约定共同控制 → 合营企业（权益法，不并表）；
- 持股 100% 但是**租赁经营**的他人资产（如租用集团厂房）→ 产能归属要写清；
- 名称含公司名但实为控股股东的子公司（兄弟公司）→ 绝不可并入。

## C. 产能与装置

| 口径 | 来源 | 特征关键词 |
|---|---|---|
| 设计产能（最权威） | 年报「行业经营性信息分析」/「主要产品产能情况」表 | 设计产能、产能利用率、在建产能、投资建设情况 |
| 环评/安评口径 | 生态环境局受理与批复公示、企业官网环评一次公示 | 环境影响评价、批复、潍滨环审字、新建/改建装置清单 |
| 企业自述 | 企业官网「公司简介/生产基地」页 | 年产能、装置套数、工艺名称、投产年份 |
| 政府/协会口径 | 行业协会统计、工信部/发改委目录、园区招商页 | 产能置换方案、行业准入 |

**装置（unit）级信息**拿法：环评公示的「建设内容」段通常给出台/套数量与规格（如「16台碳化塔、7台滤碱机」），是判断工艺与产能最细的公开材料。

**工艺判别小抄（纯碱）**：氨碱法（Solvay）→ 有石灰窑 + 蒸氨 + 钙液（白泥）副产；联碱法（侯氏）→ 有合成氨 + 氯化铵副产；天然碱 → 有蒸发/结晶与碱矿采矿权。见到「氯化铵」即联碱，「石灰窑/蒸氨」即氨碱。

## D. 产业链位置

- 上游：年报「主要原材料及能源采购」表（采购额、占比、均价上下半年对比）+ 关联采购附注。
- 内部一体化：企业官网生产基地介绍里「XX厂的废液送XX厂」这类句子，是闭环关系最直接的证据。
- 下游：分产品收入表 + 前五大客户集中度（年报「销售客户情况」）+ 销售分公司/出口国家清单。
- 替代与竞争：行业部分（有效产能、产量、表观消费、下游开工率）用以定位份额，注意注明数据是公司援引哪家机构（卓创/隆众/百川）。

## E. 项目清单（在建/拟建）

优先级从高到低：
1. **对外投资/投资建设公告**：投资总额、资金来源、建设期、效益测算（营收/净利/IRR/回收期）—— 引用时必须写「公司测算，非预测」。
2. **董事会/股东会决议公告**：议案通过与否、关联方回避情况。
3. **环评公示（受理 → 拟批复 → 批复）**：装置清单、产能、总投资，日期链最完整。
4. **重点项目名单/园区公示**：省级重点项目、产能置换方案。
5. **基础设计/开工/中交/投料新闻**：进度节点，多为企业官网（B 级）。
6. 行业媒体（ChemNet、隆众等）：只作为 C 级补充，且必须与公告交叉核对。

**时间表取舍**：公告给「建设期 24 个月」是可引用的；媒体给「X 月开工、Y 年投产」若无公告支撑，写为「媒体口径，待公告核实」。

## F. 风险与事件

- 年报「重大风险提示」「重大诉讼仲裁」「处罚及整改」「诚信状况」「担保情况」「资产减值」附注 —— 这几节基本覆盖合规面。
- 「环境信息依法披露」名单：企业是否被列为重点排污单位、年度报告是否按期披露。
- 安全生产：专项检查次数、隐患整改率、许可证有效期。
- 近 12 个月动态：交易所公告全列表（按日期倒序）+ 集团官网「集团要闻/行业资讯」+ 主流财经媒体。

## G. 财务与分业务

年报取：营收/归母/扣非/经营现金流/总资产/净资产/EPS/ROE、分产品（营收、占比、毛利率、同比）、分地区、分销售模式、成本构成（原材料/能源动力/人工/折旧）、研发投入与人员、前五大客户与供应商集中度。

**易错点**：
- 分地区表的行项目有时合计不等于总额（披露格式差异），不要强行加总或按比例归一，标注即可。
- 归母净利同比动辄 −3000% 这类数字是数学结果，不等于经营恶化倍数，正文要给解释（如含大额减值）。
- 现金流大幅波动要看票据（银行承兑）口径：剔除票据后的经营现金流往往完全不同，两个数都要写。

## H. 检索话术模板

```
<企业全称> 年报 统一社会信用代码
<企业全称> 主要产品 设计产能 产能利用率
<产品> 项目 环境影响评价 第一次公示 <企业简称>
<企业全称> 董事会 投资建设 公告 总投资
<企业全称> 关联交易 采购 原材料 占比
<企业全称> 行政处罚 决定书
<产品> 全国 有效产能 产量 表观消费 <年份>
<企业全称> <产品> 价格 调价 报价
```

公告类优先在巨潮资讯网 / 交易所披露平台按「公司代码 + 日期区间」检索，PDF 直接下载后全文搜索关键词，比读摘要更可靠。
