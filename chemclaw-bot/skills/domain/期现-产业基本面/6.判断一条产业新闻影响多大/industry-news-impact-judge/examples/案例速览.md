## 案例 1 · 新疆广汇新能源「5·8」气化炉闪爆（甲醇）

| 项目 | 内容 |
|---|---|
| 编号 | `CASE-MEOH-2023-0508` |
| 品种 | 甲醇 |
| 事件类型 | 生产安全事故 → 非计划停车（ACCIDENT） |
| 时间 | 2023-05-08 18:08 |
| 企业 | 新疆广汇新能源有限公司（广汇能源 600256.SH 控股子公司） |
| 装置 | 造气 B 系列 5 号气化炉，120 万吨/年甲醇联产 7 亿方 LNG |
| 后果 | 1 死 6 伤（2 重伤），直接经济损失 460.78 万元 |
| 定性 | 压力管道泄漏引起的一般生产安全责任事故（A1） |
| 旧闻判定 | **旧闻+新进展**（事故 2023-05；调查报告 2023-09；整改评估报告 2026-04-30） |
| 时效评分 | **1/5**（历史回溯 · 已充分传导） |

### 核心结论

| 口径 | 数值 | 读法 |
|---|---|---|
| 占全国甲醇有效产能 | 1.13% | 局部可感 |
| 占西北地区产能（折算） | 3.23% | 主产区内值得跟踪 |
| 占全国煤制甲醇产能 | 1.49% | 工艺口径 |
| 占全国月均产量 | 20.14% | ⚠️ 产能/月产量，**不是损失** |
| 理论影响量 L | **0.26 万 ～ 8.77 万吨** | 区间而非点值，取决于 d 与 k |
| 事故可归因份额 | **缺口** | 年报未单列，禁止分配 |

### 这个案例演示了哪些规则

| 规则 | 案例中的体现 |
|---|---|
| 首屏核验卡 | 8 要素齐备，明确写「政府确认（A1）」 |
| 旧闻识别 | 命中「多轮转载」「时间久远」；未命中「换时间」「换主体」 |
| 多口径分母 | 同时给全国/西北/煤制/月产量四个占比 |
| 产能≠产量 | 明确写出 1.13% 是产能占比，不能当减产 |
| 假设显性化 | d（7/10/15/20/30）、k（0.125/0.5/1.0）、r（0.8895 + 3 套备选）全部单列 |
| 计划≠事实 | 「A 系列 50% 占比」「全厂停车 10 天」均标注为假设 |
| 三分法隔离 | 「已全面停产」列入未确认（D 级），不计入汇总 |
| 缺口保留 | 6 条缺口，事故可归因份额显式留 `null` |
| 不给价格结论 | 行情章节只列事实；全文 0 处「预计上涨/下跌」 |

### 数据质量

| 检查项 | 结果 |
|---|---|
| 一手来源 | 事故调查报告（T1）、上市公司年报（T2） |
| 独立确认源 | 2 个（政府 + 上市公司） |
| 媒体转载 | 3+ 轮（澎湃/新浪/搜狐/安全管理网） |
| 自检 | **29 项全 PASS** |
