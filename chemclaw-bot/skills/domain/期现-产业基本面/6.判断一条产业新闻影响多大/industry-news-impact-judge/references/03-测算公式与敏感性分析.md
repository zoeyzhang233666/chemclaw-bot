# 03 · 测算公式与敏感性分析（公式库）

> **铁律**：任何产量影响数字，都必须能倒推出下面这个式子，且每个参数都有出处或明确标注为"假设"。
> 写不出式子 → 不写数字。

---

## 一、基础公式

### F1 日均产能

```
D = Q / 365            [吨/日]
```
- `Q` 设计产能（吨/年）。必须有出处（批复文件 / 年报"设计产能"栏 / 公告）。

### F2 基础理论产量影响（单套装置）

```
L = Q × (d / 365) × r × k      [吨]
```
| 参数 | 含义 | 取值依据 | 缺省处理 |
|---|---|---|---|
| `Q` | 设计产能 | 权威源 | 缺则**终止计算** |
| `d` | 受影响天数 | 政府/公告/计算 | 缺则**不计算**，只给日均产能 |
| `r` | 假设开工率 | ①该厂历史产量/产能 ②区域开工率 ③行业开工率 | 用①优先；无则用②；再无则用③ |
| `k` | 波及系数 | 事故波及范围、是否隔离、是否有备用系列 | 不确定时取 0.5 并标"假设" |

### F2' 用实际产量口径（更稳的写法）

当有历史产量数据时，用**实际产量率**替代"设计产能×开工率"：

```
r_actual = 近3年实际产量均值 / (设计产能 × 3)          [无量纲]
L = 近3年实际产量均值 × (d / 365) × k
```
> 本案例采用此口径，因为它把"该厂真实跑不满"这件事直接吸收进参数里，避免高估。

### F3 产能占比（三口径同出）

```
p_nat  = Q / C_nat     全国有效产能占比
p_reg  = Q / C_reg     区域有效产能占比
p_proc = Q / C_proc    工艺细分产能占比（如煤制甲醇）
```

### F4 折算成"全国产量多少天"

```
全国日产量 P_d = 全国年产量 / 365
覆盖天数 T_cover = L / P_d           [天]
```
> 这个指标比"占比万分之几"更好用：它回答"这个事件相当于抹掉了全国几天的产量"。

### F5 相对区域月产量的冲击

```
区域月产量 P_reg_m = C_reg × 区域开工率 / 12
冲击比例 = L / P_reg_m
```

### F6 检修 vs 事故的不同口径

**计划检修**不应按"天数×产能"算作损失，因为检修计划通常已经体现在年度排产中：

```
检修期固定损失  L_fix  = Q × (d/365) × r
检修期基准损失  L_base = Q × (d/365) × r_season      # 该时段若不停检的开工率
增量损失        ΔL     = L_fix − L_base               # 通常远小于 L_fix
```
> 只有当"检修时长 > 历史常规时长"或"检修时点非常规"时，ΔL 才显著。
> **没有 r_season 基准时，不给 ΔL 数字，只说明"检修属常规排产，净影响有限但不可量化"。**

### F7 新项目投产（爬坡）

```
一个产能年内的产量 = Q × Σ(每月负荷率)/12
典型爬坡（须以同工艺项目实证为参照，不得凭空假设）：
  第1季度 ≤30% / 第2季度 50%~70% / 第3季度起 80%~90%
Δ供给 = 新产能产量 − 被替代的老产能产量       # 单纯"投产"≠"净增供给"
```
> **严禁**把"环评批复产能""计划投产产能"直接加入有效产能表。

### F8 事故的"单元口径"

```
L_事故 = Q_单元 × (d/365) × r × k
Q_单元 = 全厂产能 × 单元产能份额
单元产能份额 = 1 / 并列单元数       （如 B 系列 8 台气化炉 → 1/8）
k = 是否整列停车 / 是否可切换备用单元
```
> 单台设备事故常见误区：直接拿全厂产能 × 天数，会高估数倍。

### F9 限电/限气降负荷

```
L = Q × (d/365) × r_class × δ        # δ = 降负荷幅度（如限电至 60% → δ = 0.4）
```

### F10 停产 → 下游传导的粗算（仅在有明确供货关系时使用）

```
下游受影响产量 = 上游减供量 / 单耗
```

## 二、参数取值规范

### 2.1 开工率 r 的取值优先级

| 优先级 | 来源 | 说明 |
|---|---|---|
| ① | 该装置 3 年以上实际产量 / 设计产能 | **最可靠**，吸收检修、限电、故障 |
| ② | 该区域同期开工率（隆众/卓创） | 次优 |
| ③ | 行业同期开工率 | 兜底 |
| ④ | 无数据 | **不取值**，保留缺口 |

> 常见错误：用 100% 开工率算"理论最大损失"。这在化工装置上几乎必然高估 20%~35%。

### 2.2 波及其他系列（k）的判定

| 情形 | k |
|---|---|
| 单台设备事故，其余单元满负荷，且有备用单元 | 0.5（单台份额影响） |
| 单系列停车，另有并列系列 | 系列份额 |
| 全厂停车（停电、总降压站、全厂性事故） | 1.0 |
| 不确定 | 0.5，标"假设" |

### 2.3 天数 d 的写法

```
已确认天数 d_c   ：事件日 → 有明确日期的节点（调查报告/公告/复产公告）
假设天数 d_a     ：事件日 → 假定的复产日（必须写"假设"，且给区间）
总天数 d = d_c + d_a
```

## 三、敏感性分析矩阵（必做）

对 `d` 与 `r` 双因素做矩阵，输出 `L`：

|        | d 短 | d 基准 | d 长 |
|---|---|---|---|
| r 低 | L11 | L12 | L13 |
| r 中（基准） | L21 | **L22** | L23 |
| r 高 | L31 | L32 | L33 |

再用 F4 折算为"覆盖全国产量天数"，让非专业读者也能理解量级。

## 四、算例（本 Skill 配套 methanol CASE-MEOH-2023-0508）

```
Q      = 1,200,000 吨/年        [T2 年报·设计产能]
产量 3 年均 = (91.09+112.64+116.5)/3 = 106.74 万吨
r_actual = 106.74 / 120 = 0.8895
D      = 1,200,000 / 365 = 3,287.7 吨/日
若 d = 10 天, k = 1.0:
L = 1,067,400 × (10/365) × 1.0 = 29,244 吨 ≈ 2.92 万吨
全国日产量 = 7,150 万吨 / 365 = 19.59 万吨/日
T_cover = 2.92 / 19.59 = 0.149 天
```
> 结论只说明"量级很小"，**不说明价格方向**。

## 五、绝对不能做的几件事

1. ❌ 用"预计产能"参与有效产能加权
2. ❌ 把计划检修按事故停车口径全额算作损失
3. ❌ 缺天数时自行假设一个整数（如"大概 20 天"）然后当真值输出
4. ❌ 用 2024 年产量数据去解释 2023 年事件而不说明
5. ❌ 用不同年份的分子分母算占比
6. ❌ 把测算结果直接推导为"利多/利空"并给价格目标
