# 05 · 可观察指标与后续研究入口

## 二、按事件类型挑选"最该先看"的 3 个指标

| 事件类型 | 首看 3 项 |
|---|---|
| 单装置事故/停车 | ①该企业是否发临时公告 ②西北/本区域开工率周变化 ③港口库存周变化 |
| 计划检修 | ①检修清单里是否含该企业 ②区域库存 ③月差 |
| 复产 | ①复产公告/报道 ②区域开工率回升 ③销区到货 |
| 新投产 | ①投料成功公告 ②该企业月度/季度产量 ③区域产能基数更新 |
| 限电/限气 | ①政府通知原文 ②区域开工率 ③气头/煤头开工分化 |
| 进口/海外 | ①船期到港 ②CFR 中国 ③内外盘价差 |

## 三、后续研究入口（HTML 报告里做成按钮）

| 按钮 | 指向 | 该做什么 |
|---|---|---|
| **看价格反应** | 事件前后 T-5 ~ T+10 的现货/期货/基差快照 | 只描述**发生了什么**，不推导为什么 |
| **看同区域企业** | 同区域同品种装置清单 | 找"替代供给"与"受益/受损方" |
| **看历史同类事件** | 同品种历史事件库 | 找同类事件的时间线与市场反应做参照 |
| **看仓库/物流** | 港口库存、发运 | 判断缺口是"运输问题"还是"真实减产" |
| **看装置档案** | 该企业所有装置 | 判断是否"多点开花" |

## 四、写作规范：不要在指标建议里夹带结论

| ❌ 不要写 | ✅ 应该写 |
|---|---|
| "关注甲醇反弹机会" | "关注基差是否由贴水转升水" |
| "利空下游" | "MTO 装置利润若跌破现金成本，需核查是否降负荷" |
| "供应减少将推涨价格" | "若复产延后至 X 日，累计减产量将达 Y 万吨" |
| "市场情绪偏多" | "港口库存低于去年同期 N 万吨，需确认是否因到港延迟" |
