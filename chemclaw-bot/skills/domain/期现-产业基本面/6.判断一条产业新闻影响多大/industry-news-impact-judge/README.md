# 判断一条产业新闻影响多大

> 给定一条产业新闻，回答三个问题：**这是真的吗？影响多大？还差什么信息？**
> 全会话不提供价格涨跌结论。

---

## 这个技能解决什么问题

看到「某大厂装置爆炸停车」「某地新产能投产」「某装置检修」这类新闻时，最常见的三种错误：

1. **把转载当新消息** —— 三天前的新闻换个标题再发一次，被当成新增供给冲击
2. **把产能当产量** —— 「占全国 1%」听着很小，但那只是产能占比，不是减产
3. **把点值当结论** —— 「影响 1.1 万吨」，却不说是怎么算的、假设了什么

本技能用固定 8 步把这些问题逐一拆开。

---

## 8 步工作流

| 步 | 做什么 | 产出 |
|---|---|---|
| 1 | 溯源：找原始来源、首发时间、转载路径，识别旧闻 | 核验卡（8 要素 + 旧闻判定 + 时效评分） |
| 2 | 交叉验证：企业公告 / 政府公示 | 独立确认源数量 |
| 3 | 抽要素：企业 / 装置 / 产品 / 产能 / 地区 / 时间 / 事件类型 | 七要素表 |
| 4 | 定位：在产业链哪一环，往上传还是往下传 | 产业链节点 + 传导路径 |
| 5 | 算占比：对全国 / 区域 / 工艺三种分母 | 多口径占比 |
| 6 | 算影响：检修 / 停车 / 复产 / 投产的理论产量影响 | 影响量 L + 敏感矩阵 |
| 7 | 三分法：已发生 / 不确定 / 待验证 | 三张分离的表 |
| 8 | 列指标：接下来看什么能修正判断 | 可观察指标清单 |

## 三条硬约束

### 1. 严格三分：事实 / 计算 / 未确认

- **已确认事实**：有 A1/A2 级来源（政府文书、上市公司公告）
- **客观计算**：公式与输入都公开，任何人可复算
- **未确认信息**：单独一栏，**不计入任何汇总**

不允许把「预计」「计划」写成「已投产」「已停车」。

### 2. 假设必须显性化

任何测算都必须说明：**装置产能 Q、事件持续时间 d、假设开工率 r、影响系数 k、计算公式**。

三个假设参数单独列出，用户可改。改了要能自动重算。

### 3. 缺口保留，不得编造

数据拿不到就写「未获取」，**不得用 0、均值或任何估算填补**。

每条缺口要写清：缺什么、卡住哪个结论、本报告如何处理。

## 适用品种

方法论与品种无关。已配好完整数据的是**甲醇**（产能基准、产业链节点、指标清单）。

换品种需要替换三处：
1. `capacity_basis`（产能分母表）
2. `chain.nodes` + `chain.impact_paths`（产业链节点与传导路径）
3. `observables`（可观察指标）

其余流程、公式、证据规则不变。详见 `references/07-化工品种台账（甲醇示例）.md` 的「换品种适配清单」。

## 常见误区（`references/01` 有完整版）

| 误区 | 正解 |
|---|---|
| 「占全国 1%，忽略不计」 | 还要看区域口径、看时长、看是否可替代 |
| 「产能占比 = 减产幅度」 | 产能是能力，产量影响 = Q × (d/365) × r × k |
| 「预计新增 100 万吨」 → 当成已投产 | 预计 ≠ 已投产，须查投产公告 |
| 「计划检修 20 天」 = 「减产 20 天产量」 | 检修常与淡季重叠，增量损失 ΔL = L_检修 − L_基线 |
| 「事故导致年产量下降 21%」 | 年报若未单列事故，则该归因**不成立** |

## 示例结论长什么样

> 涉事装置 120 万吨/年甲醇，占全国有效产能 **1.13%**、占西北地区 **3.23%**（口径见产能基准表）。
> 事件本身已由政府调查报告确认（A1）；但**停产时长、波及范围、事故单独造成的产量损失**三项未披露。
> 按 L = Q × (d/365) × r × k 测算，在 d=7~30 天、k=0.125~1.0 的情景下，影响量区间为 **0.26 万 ~ 8.77 万吨**。
> **以上为情景测算，不是实际减产。** 后续需跟踪：西北开工率、检修清单是否出现该企业、公司季度产量披露。

注意这段话里：有结论、有区间、有口径、有缺口、有后续指标，**但没有一句价格判断**。
