# 判断一条产业新闻影响多大

## 0. 这个 Skill 解决什么问题

研究者每天收到大量产业消息："某厂 120 万吨甲醇装置临时停车""某地纯碱厂检修 20 天""某装置爆炸"。
**它们的共同问题是：听了没数——不知道是大是小、是真是假、是新的还是去年的。**

本 Skill 把一条新闻**量化成"规模、覆盖范围、置信度"三件东西**，而不是直接给涨跌结论。

> **核心立场（不可越界）**
> 1. 只回答"这条消息有多大、影响谁、还差什么信息"，**不给价格涨跌结论**。
> 2. **严格三段式**：先核验真实性/时效性/来源 → 再识别事件与规模 → 最后才讨论产业影响。
> 3. **新闻报道里的"预计产能" ≠ 已投产**；**"计划停车" ≠ 实际产量减少**。
> 4. 计算理论影响量**必须**写明：装置产能、事件持续时间、假设开工率、计算公式。
> 5. 数据缺口**保留缺口**，写"未获取"，**严禁编造停产天数、开工率、影响量**。

## 1. 工作流程（强制顺序，不可跳跃）

```
STAGE 0  接收与规范化        ← 原文/链接/截图 → 结构化文本
STAGE 1  消息核验（真实性/时效性/来源）   ← 先做，做完才能往下
STAGE 2  事实确认（公告/政府/第三方交叉）
STAGE 3  事件要素抽取（企业/装置/产品/产能/地区/时间/事件类型）
STAGE 4  产业链定位（环节 + 直接产品 + 上下游传导）
STAGE 5  装置档案匹配 + 产能占比计算
STAGE 6  理论影响量测算（事件类型 × 公式）
STAGE 7  三分法结论：已发生 / 不确定 / 待核验
STAGE 8  可观察指标清单 + 后续研究入口
STAGE 9  交付（HTML 首屏核验卡 + Excel 工作簿）
```

**门禁（Gate）**：STAGE 1 未完成前，**不得**输出任何"影响多大"的数量结论；若来源完全无法核验，只输出核验卡 + 待核验清单，事件进入"未经确认"专区，**不计入确认影响汇总**。

详细操作步骤见 `references/01-工作流与核验规则.md`。

## 2. 消息核验卡（首屏必展示）

| 字段 | 说明 | 数据来源要求 |
|---|---|---|
| 首发来源 | 谁最先发布（媒体/企业/政府/自媒体） | 需可点击原文链接 |
| 首发时间 | YYYY-MM-DD HH:MM（精确到小时最佳） | 页面时间戳 / 抓取留痕 |
| 转载路径 | 首发 → 主流转载站 → 二次加工 | 至少 2 条独立路径 |
| 旧闻判定 | 新 / 旧闻重发 / 旧闻+新进展 / 无法判定 | 见 `references/02-来源分级与旧闻识别.md` |
| 事实确认状态 | 政府确认 / 公告确认 / 多方独立确认 / 单一媒体 / 未确认 | 见证据等级表 |
| 证据等级 | A1 / A2 / B / C / D | 见 `references/02` |
| 与市场认知差 | 已被定价 / 局部已定价 / 未被定价（仅描述，不推导涨跌） | 需持仓/基差等旁证 |

**旧闻重发的 6 个识别信号**
1. 文中"去年/近期"等模糊时间词 + 无明确日期；
2. 转载页时间新、原文时间旧（页面 meta 与正文日期不一致）；
3. 同一事件已有**后续进展**（如"已复产"），但转载版本停留在"停车"；
4. 引用的是年报/季报中的历史数据而非事件；
5. 多家转载内容**逐字一致**，且首发站已删除/失效；
6. 事件与"预计/计划/拟"字眼绑定，实为环评/备案公示而非投产。

## 3. 事件类型 → 产能单元 → 测算公式

不同事件类型，**影响的是不同"单元"**，必须分清：

| 事件类型 | 受影响单元 | 是否等于产量减少 | 测算口径 |
|---|---|---|---|
| 装置事故 / 闪爆 / 火灾 | 单台炉 / 单套装置 / 全厂 | 否，需看是否波及其他系列 | 装置 + 波及系数 |
| 非计划停车 | 单套合成装置 | 通常近似是，但需确认是否外购甲醇补供 | 产能 × 天数 × 开工率 |
| 计划检修 | 单套或多套 | 否，检修通常已含在年度排产中 | 相对**季节性基准**的增量损失 |
| 限电 / 限气 / 环保 | 区域多装置 | 否，多为降负荷 | 产能 × 降负幅度 × 天数 |
| 复产 / 重启 | 单套 | 是"收益力"而非"损失" | 同上，符号取正 |
| 新项目投产 | 新增产能 | **否**，投产 ≠ 达产 | 爬坡曲线折算 |
| 破产 / 关停 | 永久产能 | 是，长期供给减少 | 剔除出有效产能 |

**通用公式（必须逐项写明）**

```
日均产能 D = 设计产能 Q / 365                         [吨/日]
理论产量影响 L = Q × (d / 365) × r × k                [吨]
   Q = 设计产能（吨/年），须有出处
   d = 受影响天数，须有出处；无出处则 d 留空，不计算
   r = 假设开工率（0~1），须给出依据（历史产量/区域开工率）
   k = 波及系数（0~1），事故/波及范围不确定时取 <1 并标注为假设

相对全国产能占比 = Q / 全国有效产能
相对区域产能占比 = Q / 区域有效产能
产量损失占全国月均产量比 = L / 全国月均产量
```

公式库与敏感性分析模板见 `references/03-测算公式与敏感性分析.md`。

## 4. 三分法结论（输出必须这样组织）

**① 已确认的事实性影响**（证据等级 A/B 且数量口径可计算）
- 例：某装置 X 万吨/年，政府确认某日发生事故，公司年报确认全年该厂产量同比下降 Y 万吨。

**② 仍存在不确定性的影响**（方向确定、幅度不确定）
- 例：装置停车时长未公布 → 影响量以区间给出，标明"区间来自假设而非事实"。

**③ 后续需要验证的信息**（明确列出"问谁、查哪里、看什么"）
- 例：公司临时公告 / 下期季报产量 / 隆众&卓创周度开工率 / 港口库存 / 期货基差。

**"未经确认的事件"单独成区**，不并入 ①② 的合计。

## 5. 可观察指标清单（按品种模板化）

见 `references/05-可观察指标与后续研究入口.md`，每个品种给出：
- 现货：产区出厂价、销区价、区域价差
- 期货：主力合约、月差、基差
- 库存：港口库存、企业库存、订单待发量
- 开工：全国开工率、区域开工率、分工艺（煤制/气制/焦炉气）开工率
- 物流：运费、到港量、出疆/出省发运量

## 6. 交付物

| 交付物 | 生成方式 | 说明 |
|---|---|---|
| 交互式 HTML 报告 | `scripts/build_report.py` + `assets/templates/news-impact-report.template.html` | 首屏核验卡 → 事件 → 时间线 → 产业链 → 装置与产能占比 → 影响测算（可实时调参）→ 三分法 → 来源 → 指标 → 缺口 |
| Excel 工作簿（22 Sheet） | `scripts/build_workbook.py` | 封面/核验卡/来源溯源/转载路径/事件要素/时间线/装置档案/产能基准/产能占比/影响量测算/敏感矩阵/产量缺口分解/产业链节点/传导路径/三分法-已确认/三分法-不确定/待核验清单/数据缺口/可观察指标/行情背景/同区域企业/证据等级说明 |
| 数据 JSON（中间层） | 手写，遵循 `assets/templates/case_data.schema.json` | **单一数据源**，HTML 与 Excel 都由它生成；每个数字回指 `source_id` |
| 质量自检报告 | `tools/self_check.py --strict` | 29 项检查，覆盖 §8 全部 8 条硬约束；**0 FAIL 才能交付** |

**一键生成**

```bash
python scripts/build_report.py   case_data.json -o news-impact-report.html
python scripts/build_workbook.py case_data.json -o news-impact-workbook.xlsx
python tools/self_check.py       case_data.json --strict
```

**HTML 交互要求**
- 首屏：消息核验卡（首发来源、发布时间、重复转载、事实确认状态、旧闻判定、时效评分）
- 点击产业链节点 → 上下游关系抽屉
- 点击企业 → 装置档案
- 入口按钮：「看价格反应」「看同区域企业」
- **影响测算器**：滑块调 `d`/`r`、下拉选 `k`，`L` 与各口径占比实时重算，并同步刷新敏感矩阵
- 颜色语义固定：🟩 已确认 / 🟨 不确定 / 🟥 未确认或缺口

**Excel 亮点**
- 「影响量测算」黄底单元格＝可改假设，绿底＝自动重算结果
- 「敏感矩阵」为活公式，改产能或开工率会全表联动
- 所有以 `=` 开头的说明文字强制按文本写入（否则 Excel 会当公式报 `#VALUE!`）

## 7. 跨品种 / 跨事件适配

1. **换品种**：只改「产能基准表」和「产业链节点表」+ 指标模板，其余流程与公式不变。
2. **换事件类型**：按 §3 表选"受影响单元"和"测算口径"。
3. **换地区**：产能占比的分母从"全国"切换为"省/区域/园区"。
4. **海外事件**：分母改为全球产能/中国进口量，传导路径增加"进口→港口库存→内外盘价差"。

**禁止**：把 A 品种的影响量直接套用到 B 品种；把单厂产能当作区域产能。

## 8. 质量自检（交付前必过）

运行 `python tools/self_check.py case_data.json --strict`，29 项检查必须 **0 FAIL**。

| # | 检查 | 对应硬约束 |
|---|---|---|
| ① | 来源可追溯：S* 编号都真实存在；量化表带 grade/source | 每个数字有来源 |
| ② | 计划 vs 既成事实：无「预计」→「已投产/已停车」偷换；停产范围明确写已确认/未确认 | 不得把计划当事实 |
| ③ | 检修口径 vs 事故口径分离；情景标注假设性质 | 两类事件不同口径 |
| ④ | 假设显性化：r / k / d / 备选 r 全部单列且公式可复算 | 必须说明产能、时长、开工率、公式 |
| ⑤ | 缺口保留：三要素齐备；未用 0 冒充缺口；不确定份额显式留 `null` | 不得编造 |
| ⑥ | 不给价格方向：0 处「预计上涨/下跌」；有免责声明；行情章节只描述不推导 | 不给涨跌结论 |
| ⑦ | 未确认项隔离：已确认项必为 A/B 级；未确认项不进汇总 | 未确认单独展示 |
| ⑧ | 旧闻证据链：判定在枚举内；≥3 条信号；时效评分 0–5；核验卡必填项齐备 | 旧闻判定要有证据 |
| ⑨ | 可观察指标：≥3 条，且每条写明「在哪看 / 频率 / 异常判据」 | 交付可跟踪性 |

> `self_check` 只做**可机械判定**的部分。表述是否越界这类需要判断的，工具给 WARN 提示人工复核，不假装能自动判对。

## 10. 快速开始

```bash

python scripts/calc_impact.py --capacity 1200000 --days 30 --rate 0.8895 --k 0.125

# 2) 填好 case_data.json 后一键出报告
python scripts/build_report.py   assets/case_methanol_guanghui/case_data.json -o out.html
python scripts/build_workbook.py assets/case_methanol_guanghui/case_data.json -o out.xlsx

# 3) 自检（必须 0 FAIL）
python tools/self_check.py assets/case_methanol_guanghui/case_data.json --strict
```
