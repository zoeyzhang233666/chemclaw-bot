# 当前价格处在历史什么位置

## 这个技能解决什么

销售、采购、业务分析最常问的一句是：**「现在这个价，历史上算高还是低？」**

这个问题看起来简单，但有四个必踩的坑：

1. **把区间位置当分位**。`(现价 − 历史最低) / (历史最高 − 最低)` 算出来的是「区间位置」，不是「有多少比例的历史报价日比今天便宜」。两者可以差 10 倍。
2. **拿不完整的序列算长周期分位**。某个口径只有 2 年公开数据，却报了「5 年分位」——那不是 5 年分位，是 2 年分位贴了个假标签。
3. **插值/前值填充**。现货是锯齿状的、有缺口的。填平之后波动率被压低、分位被拉偏，且再也看不出哪里缺过数据。
4. **口径混用**。华东换成全国、重质换成轻质、含税换成不含税、出厂换成送到——每换一项，分位数就不是同一个东西了。

本技能把这四个坑做成**结构性约束**，而不是靠自觉：
- 分位只从真实观测计数得出，同时并列给出「含并列 / 中位秩 / 区间位置」三种口径并标注差异；
- 样本不足 20 条时**明确输出「不计算」**，不外推；
- 缺口留空并统计，绝不填；
- 不同口径各自独立计算，绝不拼接。

## 交付物（两件，缺一不可）

| 交付物 | 内容 | 硬要求 |
|---|---|---|
| **交互式 HTML** | 首屏当前价 / 区间变动 / 历史分位 / 最高最低；可缩放价格曲线 + 分位带 + 年度季节性对比；1年/3年/5年切换；悬浮看日期·价格·来源；点异常点看同期事件；导出原始序列 | 单文件、离线可开、零外链 |
| **Excel 工作簿** | 原始序列、历史分位、统计指标、同期对比、季节性、异常点、事件、缺口、方法说明、来源 | **统计列必须是真实公式**，改原始价即联动重算 |

两份必须**同源同数**：HTML 与 Excel 由同一份 `build/data.json` 生成，并交叉对账。

## 执行流程

### 第 1 步：先定口径，再找数（不要反过来）

先写死这七项，缺一项就不要往下走：

| 要素 | 例 |
|---|---|
| 品种 + 规格 | 纯碱 · 重质（≥99.2%，GB/T 210-2022 优等品） |
| 地区 | 华东（不是全国） |
| 含税 | 含税（增值税 13%） |
| 交付 | 主流市场报价 / 实单商谈（非严格出厂或送到） |
| 单位 | 元/吨 |
| 价格类型 | 区间中值 / 单点基准价 / 结算价 |
| 数据日期 | 2026-07-28 |

> 判据：如果这句话不能原样念给客户听而不引起追问，口径就没定清楚。

详见 `references/quoting-rules.md`。

### 第 2 步：取数并对齐观测

用 `scripts/` 里的采集与解析件，或用自己的数据源，最终必须落到统一结构：

```json
{"date": "2026-07-28", "lo": 1180, "hi": 1250, "mid": 1215,
 "basis": "华东重质纯碱主流市场", "url": "<原文链接>"}
```

**每一行都要带可点开的原文链接**——这是后面「可核验」的唯一依据。

### 第 3 步：跑统计核心

```bash
python scripts/price_stats.py --check build/data.json
python scripts/assemble.py            # 生成 build/data.json
python validate.py                    # 口径/分位/缺口一致性校验
```

`scripts/price_stats.py` 是与品种无关的统计核，包含：
经验分位（含并列/中位秩）、区间位置、分位数、描述统计、涨跌幅、
按真实自然日间隔折算的年化波动率、最大回撤、季节性矩阵与指数、
三条独立异常判据、工作日缺口识别。

### 第 4 步：出 HTML

```bash
python scripts/build_html.py build/data.json --out "out/xxx历史价格位置分析.html"
python scripts/check_html.py "out/xxx历史价格位置分析.html"
```

`check_html.py` 是无人值守验收：无 JS 报错、三张图真的画出了像素、
交互真的切得动、CSV 真的导得出、1600/1280/420 三档宽度无横向溢出。

### 第 5 步：出 Excel（公式必须是活的）

```bash
python scripts/build_xlsx.py build/data.json --out "out/xxx.xlsx"
python scripts/check_xlsx.py "out/xxx.xlsx"
```

`check_xlsx.py` 做三件事：
1. 确认关键单元格**存的是公式而非数字**；
2. 用 LibreOffice 重算，读回缓存值；
3. 与 `build/data.json` 逐个窗口对账（分位、极值、中位数、区间位置）。

> 这一步不能跳。openpyxl 只写公式不写缓存值，不重算就无法证明公式算得对。

### 第 6 步：写人话结论

首屏一句话必须同时包含三件事：**当前价、分位、样本的真实起点**。
例：

> 华东重质纯碱当前 1215 元/吨，落在 2024-07-17 以来真实观测的 0.28% 分位——
> 即历史上有 99.72% 的报价日比今天更贵。但请注意：该口径的公开日度记录起点就是 2024-07-17，
> 「3 年」与「5 年」窗口的样本完全相同，这不是五年数据齐全。

## 八段式报告结构（客户要看的顺序）

| # | 段落 | 必须回答的问题 |
|---|---|---|
| 1 | 最新可靠报价 | 多少钱？什么规格、哪个地区、含不含税、怎么交付、单位、哪天的、谁给的 |
| 2 | 历史序列 | 30 天 / 3 月 / 1 年 / 3 年 / 5 年各自能取到多少条真实观测 |
| 3 | 分位与统计 | 1/3/5 年的最高最低均值中位数 + **经验分位**（不是区间位置） |
| 4 | 同期对比 | 同年同月比去年、比前年如何；季节性指数 |
| 5 | 近期变化与波动 | 涨跌幅、绝对变动、波动幅度、年化波动率、最大回撤 |
| 6 | 异常与事件 | 哪些日期统计上异常；有哪些能点开原文的同期事件 |
| 7 | 口径变更与可比性 | 规格/地区/含税/统计方法有没有变过，哪天变的，还能不能比 |
| 8 | 上游联动（可选） | 若给了原油或上游原料基准，在口径合理时展示同步变动 |

## 三条不可谈判的红线

1. **不预测未来价格。** 全文不出现「预计」「有望」「将上涨」。只陈述已发生的观测。
2. **不用最高最低价推算分位。** `(P−min)/(max−min)` 只能叫「区间位置」，且必须与实际分位并列展示、标注区别。
3. **不插值、不模拟补价。** 缺失就是缺失，缺口单列成表。任何一格「—」都要能解释成「那天真的没有公开报价」。

## 反例：下面这些写法都是错的

- 「目前价格处于历史 5% 分位」——但序列只有 2 年，却没说。
- 「价格接近历史底部」——凭最高最低目测，没有计数。
- 「3 年分位 12%」，而 3 年里 60% 的日期没数据，直接用 `ffill` 填平后再算。
- 把华东重质、全国基准、华东轻质三条线画在一张图上连成一条，算一个总分位。
- Excel 里分位列是粘贴的数值，客户改了个价格，分位纹丝不动。

## 换个品种怎么用

只有两处需要改：

1. **数据源**：写一个适配器，产出上文的 `{date, lo, hi, mid, value, basis, url}` 列表。
2. **文案**：`build_html.py` / `build_xlsx.py` 里的品种名、地区、单位、口径描述。

统计核、校验器、图表、Excel 表结构全部复用。见 `examples/02-template/`。
