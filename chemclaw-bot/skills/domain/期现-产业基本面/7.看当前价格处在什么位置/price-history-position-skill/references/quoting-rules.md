# 口径判定规则与不可比清单

「这个价现在贵不贵」这个问题，**答案的正确性完全取决于口径**。
口径错了，统计做得再漂亮也是错的。

---

## 1. 七项口径，缺一项就不报价

拿到任何一个价格，先过这七问：

| # | 要素 | 必答内容 | 反例（不能接受） |
|---|---|---|---|
| 1 | **品种** | 通用名 + 行业习惯名 | 「碱」——是纯碱还是烧碱？ |
| 2 | **规格** | 含量/纯度/牌号/执行标准 | 「纯碱」——重质 99.2% 与轻质价差 100–300 元/吨 |
| 3 | **地区** | 到具体产销区 | 「国内」——华东与西北价差可达 800 元/吨 |
| 4 | **含税** | 含税（税率）/ 不含税 | 缺这一项直接差 13% |
| 5 | **交付** | 出厂 / 送到 / 库提 / 船板价 / 实单商谈 | 「出厂价」当「到厂价」用，运费谁承担没说 |
| 6 | **单位** | 元/吨、元/千克、美元/吨 | 进出口货常混用美元 |
| 7 | **日期** | 具体到日 | 「近期」「目前」不可核算 |

### 判定话术

把口径连成一句话念出来：

> 「**华东**地区**重质纯碱（≥99.2%）**主流市场报价 **1180–1250 元/吨**，**含税（13%）**，**实单商谈**，数据日期 **2026-07-28**。」

如果这句话不能原样念给客户而**不引起追问**，就说明还有要素没定清楚。

## 2. 跨口径不可比清单

以下任意一组之间**不可直接比较、不可算同一个分位、不可拼接成一条序列**：

| A | B | 为何不可比 |
|---|---|---|
| 华东地区价 | 全国基准价 | 样本范围不同，全国价是多区域加权，华东只是其中一个局部 |
| 重质纯碱 | 轻质纯碱 | 用途与供需不同，价差常见 100–300 元/吨，且方向会反转 |
| 含税价 | 不含税价 | 恒定 13%（或 9%/6%，视品种）差异 |
| 出厂价 | 送到价 | 运费+风险归属不同，跨区可达数百元 |
| 现货报价 | 期货结算价 | 一个是即期实物，一个含持仓成本与预期 |
| 主流市场区间 | 单笔成交价 | 前者是报价带，后者可能因账期/批量偏离 |
| 周度/月度均价 | 日度报价 | 频率不同，波动率与分位都不同 |
| 国内人民币价 | 进口美元价 | 汇率+关税+海运，需显式换算 |

### 正确做法

**各自独立计算，并列呈现**，用来回答「这是全国现象还是区域现象」这类问题——

> 三条序列分位都很低 → 行业性的，不是华东独有
> 只有华东低 → 区域性问题（物流、库存、单一装置）

## 3. 报价类型的识别

| 类型 | 识别特征 | 统计上怎么处理 |
|---|---|---|
| **区间报价** | 「1180–1250 元/吨」 | 取中值做主序列，上下沿各自单列计算 |
| **单点基准价** | 「基准价 1215 元/吨」 | 直接作为观测值 |
| **带调整的报价** | 「下调 50 元/吨至 1180–1250」 | 记录区间，调整量只作事件注记 |
| **不分规格报价** | 「纯碱主流报价 1300 元/吨」 | **排除**，不要猜它是重质还是轻质 |
| **含运费/不含运费** | 「车板价」「送到价」「出厂价」 | 分别成独立序列 |

> 反例：早期日评只写「华东地区纯碱主流报价 1300 元/吨」，没有规格。
> 把它塞进「重质序列」是伪造口径；正确做法是**排除并记录排除条数**。

## 4. 口径变更的检测与披露

### 4.1 四类变更

1. **规格变更**：某天起开始/停止披露某规格
2. **地区变更**：「华东」→「全国」或反之
3. **计价变更**：含税↔不含税、出厂↔送到
4. **频率变更**：日更→周更，或某月只发了几期

### 4.2 检测方法：逐月覆盖率

```
覆盖率(月) = 该月该规格有报价的天数 / 该月工作日数
```

覆盖率从 0% 跳到持续 100% 的那一个月 = **口径断点月**。

### 4.3 披露格式（必须写进报告）

> **口径变更（影响可比性）**：该数据源在 **2024-08 之前完全不披露重质纯碱价格**
> （35 个月中仅 24 个月有该品种报价，11 个月为 0 覆盖），2024-08 起转为持续披露。
> 因此基于该序列的 3 年/5 年窗口实际只有 **2024-07-17 至 2026-07-28** 的观测，
> 5 年窗口与 3 年窗口样本完全相同——**这不是「5 年数据齐全」，而是该口径只有这么长的历史**。

### 4.4 三条披露纪律

1. **断点必须量化**（哪个月、覆盖率多少），不能只说「数据有变化」。
2. **窗口的真实起止日期与样本数必须出现在同一张表里**，不能只写「3 年」。
3. **短于窗口名的样本必须显式提醒**（「3 年窗口实际只有 2 年数据」）。

## 5. 交付前的口径自检

- [ ] 七项口径齐全，且能连成一句让人不追问的话
- [ ] 主序列与辅助序列**分别计算**，没有拼接
- [ ] 排除的观测（不分规格等）有计数并说明理由
- [ ] 口径变更已量化（覆盖率表 + 断点月）
- [ ] 每个窗口都披露真实起止日期与样本数
- [ ] 样本不足的窗口写「不计算」，而不是给个近似值
