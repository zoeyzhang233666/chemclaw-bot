# 交付前自检清单

分三段：**数据 → HTML → Excel**。每段都有可执行的检查器，不要靠肉眼。

---

## A. 数据段

### A1. 结构完整性

```bash
python validate.py
```

必须 `FAIL=0`。检查项：

- [ ] 每条观测都有 `date / lo / hi / mid / url`
- [ ] 日期严格升序、无重复
- [ ] 序列末值 == 分析的 `last_value` == 窗口「止」
- [ ] 每条观测的日期都能在原始抓取中**找到对应原文**（证明没有凭空生成）

### A2. 分位可复算

- [ ] 用原始观测独立重算「含并列」与「中位秩」分位，与报告一致（容差 0.02 个百分点）
- [ ] 每个窗口的 `n_obs` 与独立重算的样本数一致
- [ ] 区间位置 == `(现价−最低)/(最高−最低)`，且**与分位是不同的数**（若恰好相等要能解释）

### A3. 外部事实校验

- [ ] 至少抽 2 个日期，把价格与**原文/第三方同日口径**核对
  （案例中核对了 2026-07-28 的 1180–1250，与生意社原文一致）

### A4. 缺口与离群

- [ ] 缺口段数与单日缺失数已统计
- [ ] 缺口明细已列出（起止 + 缺失工作日数）
- [ ] **没有任何一格被插值或前值填充**（用 `grep` 查代码里有没有 `ffill`/`interpolate`）

### A5. 口径

- [ ] 覆盖率表已生成，断点月已识别
- [ ] 每条序列的 `first_date` 与真实口径起点一致
- [ ] 「5 年」与「3 年」样本相同的情况**已显式说明**，没有含糊成「5 年数据」

## B. HTML 段

```bash
python scripts/check_html.py "out/xxx.html"
```

必须 `FAIL=0`。检查项（全部自动化）：

- [ ] **零 JS 报错**（捕获 `pageerror` 与 `console.error`）
- [ ] **三张图真的画出了像素**（读 canvas 非透明像素数，不是只检查容器存在）
- [ ] KPI 卡 ≥ 4 个
- [ ] 表格行数足够（不是空壳）
- [ ] 关键文案存在：「经验分位」「口径变更」「数据缺口」
- [ ] 切「3 年」按钮后图表重绘
- [ ] 切「三者对比」后 series 数 ≥ 2
- [ ] 分位带 + 异常点开关生效
- [ ] **CSV 导出真的下载到文件且体积合理**
- [ ] 1600 / 1280 / 420 三档宽度**均无横向溢出**

### 横向溢出的正确测法

```python
pg.set_viewport_size({"width": w, "height": 900})
pg.wait_for_timeout(900)
pg.evaluate("Object.keys(window.__CH__).forEach(k => window.__CH__[k].resize())")
pg.wait_for_timeout(900)          # 必须等 ECharts 用自己的旧尺寸重排完
ov = pg.evaluate("document.documentElement.scrollWidth - document.documentElement.clientWidth")
```

> 不等 resize 稳定就测量，会把「图表还没重排」误报成「页面溢出」。
> 反过来，若真的溢出，用「找最外层、父级无 overflow 裁剪、右边界超宽」的算法定位元凶。

### 验收要点（肉眼补充）

- [ ] 首屏一眼能看到：当前价、区间变动、历史分位、最高最低
- [ ] 分位所在列标题写明「经验分位」，区间位置列写明「（非分位）」
- [ ] 样本不足的窗口显示「有效观测 N 条，低于门槛，不计算」，而不是空白或 0
- [ ] 每个价格都能追溯（悬浮显示来源链接）

## C. Excel 段

```bash
python scripts/check_xlsx.py "out/xxx.xlsx"
```

必须 `FAIL=0`。三层检查：

### C1. 公式是活的

- [ ] 分位列存的是 `=COUNTIFS(...)`，不是数字
- [ ] 统计列存的是 `=MIN/MAX/MEDIAN/AVERAGE(...)`
- [ ] 原始序列的中值列是 `=(C+D)/2`，不是粘贴值
- [ ] 工作表内**没有 `#NAME?` / `#REF!` / `#DIV/0!` / `#VALUE!`**

### C2. 重算并与 HTML 对账

- [ ] 用 LibreOffice `recalculate` 生成带缓存值的新文件
- [ ] 逐窗口比对 n / min / max / median / 两个分位 / 区间位置（容差 5e-4）
- [ ] 07 表（同期对比）与 08 表（季节矩阵）的同年同月数值**互相一致**

### C3. 结构与可读性

- [ ] 工作表数量与命名符合预期
- [ ] 每个统计表都有一句「怎么读这张表」
- [ ] 方法说明表列出全部公式与常见误用
- [ ] 来源表每条都可点击

## D. 红线检查（人工最后过一遍）

在全文里搜这些词，出现即为不合格：

| 搜索词 | 为什么 |
|---|---|
| `预计` `有望` `将会` `料将` `后市看` | 预测未来价格 |
| `历史分位` 出现在 `(P-min)/(max-min)` 旁边 | 区间位置冒充分位 |
| `ffill` `fillna` `interpolate` `插值` `补齐` | 伪造价格 |
| `5 年数据`（而样本只有 2 年） | 夸大样本范围 |
| `接近底部` `处于底部`（无计数支撑） | 目测代替统计 |

### 结论句必须含三要素

> 当前价 **X** 元/吨，落在 **<真实起点日期>** 以来真实观测的 **Y%** 分位，
> 即历史上有 **Z%** 的报价日比今天更贵；样本 **N** 条，
> <若短于窗口名，必须在此说明>。
