# 统计量定义、公式与边界条件

这一份是**审阅级**文档：客户或风控问「你这个分位怎么算的」，把这张表给他看。

---

## 0. 记号

- `x` = 当前价（当期最新可靠报价）
- `W` = 窗口内全部真实观测值集合，`n = |W|`
- `d ≤ e` 区间，按**日期**回看，不按行数
- 所有计算**只在真实观测上进行**，不存在任何插补值

---

## 1. 经验分位（这是一个计数，不是插值）

### 1.1 含并列（inclusive）

```
pct_inclusive = #{v ∈ W : v ≤ x} / n × 100
```

含义：**历史上有百分之多少的报价日，价格不高于今天。**
当 `x` 恰为窗口最低值且该值出现多次时，这个数不为 0。

### 1.2 中位秩（midrank）

```
pct_midrank = ( #{v ∈ W : v < x} + 0.5 × #{v ∈ W : v = x} ) / n × 100
```

含义：把「等于今天」的观测按一半计入。
现货价格大量日期取值相同（报价没变），这一口径用于抵消并列值带来的跳变。

### 1.3 该用哪个？

| 场景 | 用哪个 | 理由 |
|---|---|---|
| 对外一句话结论 | 含并列 | 最容易解释：「99.7% 的日子比今天贵」 |
| 严谨统计口径 | 中位秩 | 并列值处理无偏 |
| 两个都报 | **推荐** | 并注明两者差异来源 |

报告中**两个都列**，且并排列出 `pct_above = 100 − pct_inclusive`（高于现价占比）。

### 1.4 边界

- `n < 20` → **不计算**，输出 `"样本不足，不计算"`。原因：20 个点以下，一个异常值就能让分位跳 5 个百分点以上，报出来是误导。
- `n ≥ 20` 但窗口真实覆盖不足（如「3 年窗口」里只有 2 年有数据）→ 算，但**必须同时披露真实起止日期与样本数**。
- 结果范围恒为 `[0, 100]`。

## 2. 区间位置（不是分位，永远不要单独叫它分位）

```
range_position = (x − min(W)) / (max(W) − min(W)) × 100     (max > min)
```

含义：纯几何位置。**它不回答「多少比例的日子比今天贵」。**

### 为什么必须分开

现货锯齿状，`min` 与 `max` 往往只出现一两次，是两个极端点。
当前价恰为窗口最低点时：

| 指标 | 值 |
|---|---|
| 经验分位（含并列） | 0.72% |
| 经验分位（中位秩） | 0.36% |
| 区间位置 | **0.00%** |

三个数都对，含义完全不同。只看区间位置会严重低估「还有很多人报价更高」这一事实。

> 硬规则：报告里区间位置所在列的标题必须写成「区间位置（非分位）」。

## 3. 描述统计

| 统计量 | 公式 | 备注 |
|---|---|---|
| 最低 / 最高 | `min(W)` / `max(W)` | 标注出现日期 |
| 均值 | `Σv / n` | 对极端值敏感 |
| 中位数 | 排序后正中（偶数取中间两数均值） | 推荐与分位配套使用 |
| 样本标准差 | `√(Σ(v−x̄)² / (n−1))` | n<2 不计算 |
| 变异系数 | `std / mean` | 跨品种比较波动性用 |
| P10/P25/P75/P90 | 线性插值分位数（与 Excel `QUARTILE.INC` 一致） | 仅用于画分位带 |
| IQR | `Q3 − Q1` | 异常判据用 |

> `QUARTILE.INC` 与实际「经验分位」**不是同一回事**：前者是插值分位数，后者是计数。报告主结论只用**经验分位**，插值分位数只做图形参考。

## 4. 涨跌幅与波动

### 4.1 区间涨跌

```
pct_change = (x − v_start) / v_start × 100
abs_change = x − v_start
```

`v_start` = 窗口内**最早一条**真实观测，其日期须一并报出（窗口起点未必是自然日，可能是首个报价日）。

### 4.2 年化波动率（关键：现货报价不等距）

**错误做法**：对相邻报价算收益率后直接 `× √252`。
**理由**：相邻两条报价可能隔 1 天，也可能隔 10 天（节假日/漏报）。当成等距会系统性低估波动。

**本技能算法**：

```
对每条相邻观测对 (t-1, t)：
    r_t = ln(P_t / P_{t-1})
    Δ_t = (date_t − date_{t-1}).days          # 真实自然日差
    g_t = r_t / Δ_t                            # 日均对数收益
ann_vol = std_sample(g_t) × √365 × 100
```

同时给出：
- `mean_abs_daily_pct`：日均绝对变动
- `max_abs_daily_pct`：最大单日变动
- `pct_days_ge_1pct`：单日变动 ≥1% 的天数占比

### 4.3 最大回撤

```
mdd = min over t of ( (P_t − running_max_t) / running_max_t )
```

必须同时报**峰值日**与**谷值日**，否则无法复核。

## 5. 季节性

### 5.1 年 × 月矩阵

对每个 `(year, month)` 桶，取该桶内全部真实观测的均值与条数。
**没有观测的桶留空**，不是 0，也不回填。

### 5.2 季节性指数

```
season_index[m] = mean(该月所有年份的月均价) / mean(全部月均价) × 100
```

- `100` = 全期平均水平
- `>100` = 该月历史均价高于全年平均
- 样本月份数 < 2 时标注「参考价值有限」

> 季节性指数**只描述历史相对位置**，绝不能读成「今年 9 月会涨」。

## 6. 异常判据（三条独立，分别标注，不合并成一句「异常」）

| 判据 | 规则 | 捕捉什么 |
|---|---|---|
| `level_mad` | 相对**滚动一年**中位数，稳健 z `= 0.6745 × (P − median) / MAD` ≥ 2.5 | 水平偏离（慢变量） |
| `iqr_fence` | `P < Q1 − 1.5·IQR` 或 `P > Q3 + 1.5·IQR` | 分布尾部 |
| `jump` | `|相邻报价日变动| ≥ 3%` | 单日突变 |

用 **MAD 而非 σ**：σ 会被极端值本身污染，导致「异常点把阈值拉高从而不算异常」。MAD 稳健。

三条判据会重复命中同一现象（一次跳变既是 jump 又可能越 IQR）——所以**分别列，不合并计数**。

同时提示：**统计异常 ≠ 有事件**。事件时间线只收可点开原文的事实，二者不做强行配对。

## 7. 缺口

按**工作日**统计（周末本就不报价）：

```
连续缺口段 = 连续 ≥ 3 个工作日无报价
单日缺失   = 孤立 1 个工作日无报价（多为法定假日或当日未发日评）
```

两者分别计数并列明细。**全部留空，不插值、不前值填充。**

不填的理由：
1. 填充会人为压低波动率；
2. 填充会改变分位分母，让「有多少比例的日子比今天贵」失真；
3. 填充后**再也看不出哪里缺过数据**，这是最严重的——审计线索被销毁。

## 8. 口径断点（最容易出错、也最影响结论）

需要检测并在报告中标出的四类变化：

| 变化 | 检测方法 | 后果 |
|---|---|---|
| **规格变化** | 序列中途开始/停止披露某规格 | 前后不可比 |
| **地区变化** | 从「华东」扩到「全国」或反之 | 价差结构性位移 |
| **含税/交付变化** | 报价说明措辞改变 | 直接 13% 量级差异 |
| **频率变化** | 月披露条数骤降 | 短窗口样本不足 |

**输出格式**：逐月覆盖率表（该月有该规格报价的天数 / 该月工作日数）。
覆盖率从 0% 跳到 100% 的那个月，就是断点月。

> 案例结论：生意社华东纯碱日评在 2024-07 之前**完全不披露重质纯碱**，
> 2024-07 覆盖率 48%，2024-08 起 100%。
> 所以「3 年分位」的真实样本是 2024-07-17 起的 358 条，**不是完整三年**。
> 「5 年分位」与「3 年分位」样本完全相同——**必须明说，不能含糊成「5 年数据」**。

## 9. 上游联动（可选，仅在口径合理时）

若提供原油或上游原料基准：

1. 确认两者**计价口径可比**（同币种、同单位、同期频率）；
2. 对齐到共同日期，只保留双方都有观测的日期；
3. 计算同期变动率序列，展示方向一致性；
4. **不做回归拟合、不给传导系数**，除非有足够样本且明确标注为统计描述。

口径不可比时（如一个是含税出厂价、一个是期货结算价），**明确写「不具备可比性，不做联动展示」**，而不是硬凑一张图。

## 10. Excel 公式对照

| 指标 | Excel 公式（工作簿中实际使用） |
|---|---|
| 窗口内观测数 | `=COUNTIFS(日期,">"&起,日期,"<="&止)` |
| 经验分位（含并列） | `=(COUNTIFS(值,"<="&现价, 日期,">"&起, 日期,"<="&止))/n` |
| 经验分位（中位秩） | `=(COUNTIFS(值,"<"&现价,...)+0.5*COUNTIFS(值,"="&现价,...))/n` |
| 区间位置 | `=(现价-最低)/(最高-最低)` |
| 最低/最高/中位数 | `MIN/MAX/MEDIAN(窗口内取值辅助列)` |
| 标准差 | `STDEV.S(...)` |
| 分位数 | `QUARTILE.INC(...,0.25)` |
| 同年同月均价 | `AVERAGEIFS(值, 日期,">="&DATE(y,m,1), 日期,"<"&DATE(y,m+1,1))` |

> 实现说明：`MIN/MAX/MEDIAN` 的「条件」通过一张**辅助矩阵**实现
> （每行一条原始观测 × 每列一个窗口，单元格 `=IF(在窗口内, 价格, "")`），
> 再用普通 `MIN/MAX/MEDIAN` 作用在整列上。
> 这样每个单元格都是最简标量公式，**不依赖数组公式求值规则**——
> 数组 `IF`、`MINIFS/MAXIFS`、`AGGREGATE` 在不同 Excel/LibreOffice/WPS 版本上行为不一致，会让客户打开就看到 `#NAME?`。
