## T0 官方原文

### 生态环境部 `www.mee.gov.cn`

- **可读性**：全文可读（政策文件、征求意见函）
- **入口**：`https://www.mee.gov.cn/xxgk2018/160/167/index_6700.html`（公告与通知栏目）
- **坑 1**：列表页可能是 iframe，直接抓列表拿不到条目，要按 `xxgk2018/xxgk/xxgk06/2026MM/t2026MMDD_xxxxxxx.html` 的规律解析
- **坑 2**：Python `urllib` 与 PowerShell `Invoke-WebRequest` 常见 `SSL: UNEXPECTED_EOF_WHILE_READING` 或 502。**用 `curl.exe -s -L --max-time 45 -H "User-Agent: ..."` 可通**
- **坑 3**：路径少一层就 404。看到 `xxgk/xxgk06/...` 先试 `xxgk2018/xxgk2018/`→ 实际是 `xxgk2018/xxgk/xxgk06/`
- **取什么**：文号、索引号、成文日期、截止日期、反馈邮箱——这些是 C1 的凭证

### 财政部 `szs.mof.gov.cn`

- **可读性**：全文可读
- **坑**：Python/PS 直连常 502，curl 可通
- **取什么**：公告编号、生效日期、**附件产品清单**（判"是否涉及本品种"的决定性证据）

### 其他值得挂的官方源

| 源 | 站点 | 用途 | 已知情况 |
|---|---|---|---|
| 国家发改委 | ndrc.gov.cn | 产业政策、价格机制 | 需按栏目轮询 |
| 商务部 | mofcom.gov.cn | 贸易救济、进出口 | 同上 |
| 海关总署 | customs.gov.cn | 分国别进出口（HS 编码） | 月报，滞后约 3 周 |
| 应急管理部 | mem.gov.cn | 安全事故通报 | 环保安全类必查 |
| 上交所 e互动 | sns.sseinfo.com | 上市公司问答 | **需登录，常拿不到** |
| 巨潮资讯 | cninfo.com.cn | 公司公告原文 | 需按代码检索，可能有验证码 |

## T1 一手行业资讯（化工）

### 隆众资讯 `www.oilchem.net`

**最重要也最受限的源。**

- **可读性**：正文对非会员**全部拦截**
- **实际能拿到**：标题、列表页时戳 `[2026-10-19 15:27]`、URL 内嵌日期（`26-1019-15-hash.html`）、栏目首页"热点聚焦"首条约 60 字导语
- **拦截特征**：正文 div 只有 122 字符，内容为"注册为会员，可获得相关产品15天的免费浏览权…400-658-1688"
- **反爬**：连续请求后返回 **HTTP 451**（地区法律原因）或 429
- **编码坑**：响应强制 `Content-Encoding: br`，即使请求头写 `Accept-Encoding: identity`。Python 必须 `pip install brotli` 并显式解压，否则得到乱码
- **meta 坑**：`<meta name="publishTime">` 是**抓取时间**，不是发布时间
- **最佳用法**：①用列表页时戳建时间线；②通过转载方拿正文；③装置汇总表看能否找到 Mysteel 转载版

**能拿到正文的替代通道**：

- 新浪财经/东方财富转载隆众数据（带"（隆众资讯）"标注）
- 期货公司研报引用隆众数值（可读到具体数字）
- Mysteel 转载装置汇总（可读约 400 字摘要表格）

### 金联创 `www.315i.com`

- **可读性**：原文付费
- **最佳通道**：**新浪财经与东方财富常全文转载**，正文完整且标注"来源：金联创"，这两处是可读正文的主要来源
- **特征**：文章有作者署名（如"常婷"），转载页有"（文章来源：金联创）"
- **价值**：C/MTO 行业开工、装置停车时间线做得细

### Mysteel `nenghua.mysteel.com`

- **可读性**：装置汇总类可读约 400 字摘要后截断（截断处出现"资讯编辑：…"）
- **价值**：**省别企业简称 + 产能 + 装置状态**的表格，是建装置台账最实用的来源
- **局限**：只给状态不给起始日期；表格后段常被截断

### 卓创资讯 / SMM

- 卓创：与隆众类似的付费模式
- SMM：快讯可读约 300 字后截断，适合环评/项目类快讯

## T2 转载与媒体

### 新浪财经 `finance.sina.com.cn`

- **可读性**：全文可读，页面自带 `YYYY年MM月DD日 HH:MM`
- **关键**：署名"市场资讯"的稿件，文首会标"来源：XXX"——**这是追溯首发方的关键**
- **注意**：新浪时间 = 转载时间，"转自：新华财经"的稿件原文是新华社电头

### 东方财富 `finance.eastmoney.com`

- **可读性**：全文可读
- **关键区分**：
  - `finance.eastmoney.com` = 财经频道（转载，标注"文章来源"）
  - `caifuhao.eastmoney.com` = **财富号自媒体**，可靠性降 C，只作旁证
- **价值**：与新浪互为转载对照，可判定转载顺序（谁先谁后）

### 化销网 `www.huaxiaowang.com`

- **可读性**：正文可读，但极短（1-2 句）
- **红线**：页面自述"本信息由相关企业自行提供，真实性未经证实" → 只能作旁证，不能单独确认
- **价值**：装置停车状态的日度快照，可与机构口径交叉核对

### 世纪新能源网 `www.ne21.com`

- **可读性**：可读
- **红线**：页面自述"本站未对其内容进行核实"
- **价值**：绿色甲醇/氢能项目的备案、撤销、投资额、建设期细节（含具体批复文号日期）

### 100ppi 生意社

- **可读性**：**常被反爬拦截**，返回约 660 字节的"正在进行安全检查，请稍候..."
- **退路**：只能用搜索引擎摘要，标 `summary_only`
- **注意**：摘要里的数字要与其它源交叉验证才可用

### 七禾网、各类行业门户

- 可读，但**时效性极易错配**：可能挂着几年前的稿子
- **必检**：文中提到的库存水平、价格、开工率是否与本窗口其它源量级一致。若差 4 倍或方向相反 → 判定超窗/错配，**拒用并记录理由**

## 抓取工程要点

### 编码

```python
for enc in ('utf-8', 'gb18030'):
    try:
        text = raw.decode(enc); break
    except UnicodeDecodeError:
        continue
```
**不要**在循环里同时 append 多个尝试结果——失败的尝试会污染语料（本技能开发中踩过：`audit_quotes.py` 因此产生假阴性）。

### Brotli

```python
if resp.headers.get('Content-Encoding') == 'br':
    import brotli
    body = brotli.decompress(body)
```

### 时间戳提取（隆众列表页）

时间戳在 `<a>` 之后的 `<span>` 里，属于同一个 `<li>`：

```python
for m in re.finditer(r'<li[^>]*>(.*?)</li>', html, re.S):
    blk = m.group(1)
    a = re.search(r'<a[^>]*href="([^"]+)"[^>]*>(.*?)</a>', blk, re.S)
    rest = re.sub(r'\s+', ' ', re.sub(r'<[^>]+>', ' ', blk[a.end():]))
    ts = re.search(r'\[?(20\d\d-\d\d-\d\d\s+\d\d:\d\d)\]?', rest)
```

### HTML 标签把句子切断

页面里 `<p><strong>10月10日</strong>：渤化MTO装置停车</p>`，纯文本提取会得到"10月10日：渤化MTO装置停车"——**引文时必须按读者看到的形态引用**，或者干脆不加引号改写为"页面原文（日期与内容分列）"。

### 访问受阻的处置

| 现象 | 含义 | 处置 |
|---|---|---|
| HTTP 451 | 地区法律原因受限 | 记入访问限制日志；换转载通道 |
| HTTP 429 | 频率限制 | 降速重试；仍失败则记录 |
| 会员墙（正文 122 字符） | 付费拦截 | 标 `title_only`，不推断内容 |
| 反爬页（"安全检查"） | 人机验证 | 标 `summary_only` |
| 需登录（e互动/巨潮） | 身份验证 | 记录卡点，列入待验证取证路径 |

**统一原则：受阻 ≠ 不存在。** 写"未取得正文"，不写"未发现相关报道"。
