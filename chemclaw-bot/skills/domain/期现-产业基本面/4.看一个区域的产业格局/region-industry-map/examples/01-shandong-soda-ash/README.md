# 示例 01：山东省纯碱产业格局

一个**完整的、可直接复用的**工作示例。数据截至 2026-10-20。

## 这个示例回答了什么

> 请展示【纯碱】在【山东省】的产业分布：生产企业、产能、工厂位置、园区、上下游、
> 新增项目、价格物流特征、集中度与价差因素；数据缺失处明确标记。

## 一句话结论

> 山东可核实的纯碱在产主体只有 **2 家**（山东海化 280 万吨/年、山东海天生物化工 150 万吨/年），
> 合计 **430 万吨/年**，**全部落在潍坊**；工艺全部为氨碱法；
> 2028 年前唯一的供给变化是海化以 100 万吨联碱**减量置换** 120 万吨氨碱（净减 20 万吨/年）。

## 这个示例特意演示了几件事

| 演示点 | 在数据里怎么看 |
|---|---|
| **注册地址 vs 生产地址** | `sites[0]`（海化）：注册地与厂区同址，标注"注册地同址"；`sites[2]`（海天）：注册地"金晶大道 1 号"，生产地址是"园区内现有厂区" |
| **企业 ≠ 厂区** | 海化集团下分列"纯碱厂"与"小苏打厂"两条，后者不产能 |
| **衍生品不进合计** | 小苏打厂 `capacity = null`，`capacity_basis` 写明"产品为碳酸氢钠，非纯碱" |
| **否证条目** | 新龙、亚星、鲁西、德州实华 4 条，`capacity = null`，`note` 写否证依据，`source_ids` 指向年报/官网 |
| **多口径并列** | `capacity = 280` 与 `capacity_scope_total = 450` 同时存在，`coverage_note` 说明差额 |
| **净增量不是毛新增** | `projects[0]`：capacity 100、capacity_retired 120 → 净减 20 万吨/年纯碱，同时净增 103 万吨/年氯化铵 |
| **点位降级** | 海天 `precision = 县级`：OSM 企业面落在滩涂、与厂址矛盾，主动降级不冒充 |
| **价格口径并列** | 同一天 5 个口径（华东出厂 / 华东送到 / 全国均价 / 期货 / 贸易商零售）全部并列，不取平均 |
| **缺口成体系** | `narrative.gaps` 7 条，每条有 why / impact / how / priority |

## 点位精度分布（这是真实调研的样子）

| 精度 | 数量 | 说明 |
|---|---|---|
| 精确 | 2 | 海化纯碱厂（OSM 工业面 + 与氯碱/溴素/小苏打厂相邻）、小苏打厂车间 |

## 大缺口（诚实交代）

1. **缺政府侧全名单**：排污许可平台按"无机碱制造"拉出的山东名单没取到，"只有 2 家"目前是
   上市公司年报 + 资讯机构 + 协会分企业表三方交叉的下限。
2. **海天 150 万吨的构成**：工程原文是"100 万吨/年纯碱工程"，市面通行 150 万吨，差额 50 万吨无原文；
   工艺（氨碱）也只有研报 + 民间整理的 C 级交叉。
3. **海化减量置换是否已开工**：只有"计划 2026-10 开工"的媒体转述，没有开工通报、二次环评批复或备案号。
4. **山东单省分规格连续价格序列**：资讯机构按华东大区报价，山东本地只有商务局不分规格的月度监测。

## 勘误记录

调研过程中被推翻的两个初始假设，保留在此以免后来者重复踩坑：

- **"山东海天生物化工扩产"不成立**：金晶科技 2025 年报与 2026 半年报均只写"年产能 150 万吨"，
  无在建纯碱产能、无环评/备案。
- **"山东新龙集团纯碱项目"不成立**：新龙是氯碱企业（烧碱/双氧水/三氯氢硅），其 10 万吨过碳酸钠
  项目是**耗**纯碱，属需求方。
