# 取证通道与口径陷阱

按"要回答哪个问题"组织。每条通道都注明**能拿到什么**、**拿不到什么**、**坑在哪**。

---

## 1. 生产企业名单与产能

### 1.1 上市公司年报"主要产品产能"表（首选，A 级）

- 位置：年报正文"主营业务分析"或"主要控股参股公司分析"；半年报同表。
- 能拿到：设计产能、产能利用率、在建产能、产量、销量。
- 坑：只覆盖上市主体，**不覆盖同集团未上市厂区**；有的公司只写"年产能 X 万吨"不写利用率。
- 例：海化 2025 年报"纯碱 设计产能 280 万吨、产能利用率 97.29%、在建产能 无"——一句话同时解决产能、开工率、有无扩建。

### 1.2 行业协会分企业产量表（B 级）

中国纯碱工业协会按月发《全国纯碱产量（分企业）》。价值在于**反证名单完整性**：
表里只有两家山东企业，就支撑"山东只有两家"的判断。同理，氯化铵分会表里没有山东主体，
可以反证"山东没有联碱装置"。

### 1.3 省市工信/发改/生态环境公示（A 级）

- 排污许可证（全国排污许可管理信息平台）：按行业类别（如"无机碱制造"）拉名单，
  许可的**产品、产能、地址、工艺**都在里面——这是唯一能一次性解决"企业名单 + 工艺 + 产能 + 地址"的通道。
- 环评一次/二次公示：建设地点、建设规模、主要设备（"拆除 16 台碳化塔"就是工艺路线的硬证据）。
- 节能审查/产能置换公示：置换比例、退出产能写得最清楚。

### 1.4 资讯机构产能表（B/C 级）

隆众、卓创、百川、观研天下的分企业产能表。价值：覆盖非上市企业、给"有效产能"口径。
坑：口径不统一（有效产能 vs 设计产能 vs 在产产能），同一家企业不同年份数字会跳（280 / 300 / 320）。

### 1.5 交易所投教材料（B 级）

郑商所、大商所的品种投教材料里有"分省产能/产量统计表"，注明数据源（国家统计局 + 某资讯机构）。
价值：**省级总量口径**的现成来源，适合做覆盖度分母。坑：年份旧（常见 2020 年数据），必须写明年份。

### 1.6 "反证"也是成果

查不到 ≠ 不存在。要主动做否证，并把否证入表：

- 查企业年报/官网产品清单 → 没有本品；
- 查协会分企业表 → 名单里没有；
- 查投资者问答 → 董秘答的是别的产品。

山东案例里四个否证对象（新龙、亚星、鲁西、德州实华）都单列一行、`capacity = null`、
`note` 写"否证：……"。这样下一次调研不用重复劳动，也不会有人再把它们加回来。

## 2. 注册地址 vs 生产地址

| 通道 | 拿到的是 | 可靠性 |
|---|---|---|
| 国家企业信用信息公示系统 | 工商注册地址 | 只证明法人登记地 |
| 排污许可证 | 生产经营场所地址（≈ 厂址） | **高**，优先 |
| 环评公示"建设地点" | 厂址 | **高** |
| 企业官网"成员企业/联系我们" | 厂区地址 | 中—高 |
| 招聘网站 | 厂区或办公地址 | 低，看职位类型 |
| 地图 POI | 可能是办公楼 | 低 |

**操作顺序**：先排污许可 → 再环评 → 再官网厂区页 → 最后才用地图 POI。
把四类地址**分别写进 `reg_address` 与 `plant_address`**，并在 `note` 写清哪个是哪个。

## 3. 坐标

### 3.1 通道

| 通道 | 适用 | 精度 |
|---|---|---|
| 环评报告附图 / 批复坐标 | 厂区 | 精确 |
| 排污许可证地址 + 街景核对 | 厂区 | 精确 |
| **OSM Overpass** `landuse=industrial` + `name` 匹配 | 厂区/园区面 | 精确（面心） |
| **Nominatim** 地名检索 | 镇/园区/港口 | 园区级或县级 |
| 园区规划环评中心坐标 | 园区 | 园区级 |
| 政府公告中的"XX 路与 XX 街交口东侧" | 厂区 | 精确（需人工核） |

### 3.2 OSM 用法（可复制的查询）

```
# 找有名称的工业用地面（比关键词搜索靠谱得多）
[out:json][timeout:60];
(
  way["name"~"海化"](36.5,118.5,37.5,119.6);
  relation["name"~"海化"](36.5,118.5,37.5,119.6);
  node["name"~"海化"](36.5,118.5,37.5,119.6);
);
out center tags;

# 找港口/站场
[out:json][timeout:60];
(
  node["name"~"潍坊港"](36.4,118.6,37.6,119.6);
  way["name"~"潍坊港"](36.4,118.6,37.6,119.6);
);
out center tags;
```

- POST 到 `https://overpass-api.de/api/interpreter`，`data=<query>`；
- 必须带 `User-Agent`；**批间隔 ≥ 2 秒**，否则 429；
- 备用端点 `https://overpass.kumi.systems/api/interpreter`；
- 结果里的 `center.lat/lon` 就是面的中心点；
- `https://www.openstreetmap.org/{type}/{id}` 可直接点开复核。

### 3.3 三个真实教训

1. **串名检索**：中文地名检索很容易串到同名词。本案例"齐鲁化学工业区"检索到新疆工信厅，"巨野化工产业园"
   检索到重庆一个公交站。**必须做省内范围校验**。
2. **面在对岸**：OSM 有"山东海天生物化工"的工业面，但它在下营镇以东 7 km 的海上滩涂。
   面存在 ≠ 面正确 → 降到县级。
3. **同厂区多要素**：海化厂区在 OSM 里被拆成"纯碱厂""氯化钙厂""溴素厂""氯碱树脂厂""小苏打厂一/二车间"
   多个面。这反而是**加分证据**（证明是盐化工一体化基地），但要点清楚你用的是哪个面。

## 4. 化工园区

| 通道 | 内容 |
|---|---|
| 省政府化工园区认定名单 | 官方名单与级别（省级/市级）——**唯一权威来源** |
| 园区扩区批复 | 四至范围、面积（如"鲁政字〔2026〕86 号，扩区后 56.30 km²"） |
| 园区规划环评 | 主导产业、选址、中心坐标 |
| 园区官网 | 入园企业名单、公用工程、铁路/港口配套 |
| 赛迪/石化联合会园区榜单 | 竞争力排名，用于判断园区层级 |

坑：园区宣传页的"入驻企业 N 家"是招商口径，含贸易与注册型企业，**不能当生产厂区数**。

## 5. 上游

| 通道 | 拿到什么 |
|---|---|
| 年报"采购情况" | 原料占比、均价、是否外采（"石灰石 100% 外采""原盐占采购额 38.65%"） |
| 采矿许可证 / 自然资源厅公示 | 盐场/矿山的采矿面积、生产规模 |
| 企业"首船进口原料抵港"新闻 | 真实揭示原料缺口与港口路径 |
| 环评原辅材料表 | 单耗（吨/吨产品）、年耗量——**这是唯一的单耗来源，不要自己拍** |

---

## 6. 下游

| 通道 | 拿到什么 |
|---|---|
| 下游企业年报 | 产线数量与日熔量（如"5×600t/d"）、开工停产情况 |
| 地方产业集群报道 | 企业数量、产值、产量（"年产酒瓶 21 亿只"） |
| 园区招商资料 | 深加工企业数 |
| 环评原辅材料表 | 单耗与采购来源 |

坑：**不要把产能直接换算成需求**。吨玻璃耗纯碱、吨纯碱耗原盐，都要有来源才写；没有就只描述规模。

---

## 7. 物流

| 通道 | 拿到什么 |
|---|---|
| 港口志/港口集团资料 | 泊位数、岸线、通过能力、**装卸货种清单**（含本品是硬证据） |
| 省市交通运输厅公告 | 航道工程、吞吐增量 |
| 铁路资料 | 专用线里程、接轨站 |
| 交易所交割公告 | 交割厂库/仓库、仓单额度、指定交货地、升贴水 |
| 政府"海河联运/复航"新闻 | 内河通道及其量级 |

## 8. 价格

| 通道 | 拿到什么 | 坑 |
|---|---|---|
| 资讯机构日评（隆众/卓创/百川/生意社） | 分大区、分规格报价 | **按大区（华东/华北）出，不是按省**；出厂价与送到价要分开 |
| 地方政府价格监测（商务局周报） | 本地周度价格 | 常不分规格、不标含税，只能当趋势 |
| 期货行情 | 主力连续价 | 不含税不含运费，≠ 现货 |
| 贸易商报价 | 小批量/零售价 | 显著高于出厂价，混用会虚高 |

**同一个日期，不同口径的价格不能对比。** 山东案例里同一天有 5 个口径
（华东出厂 1000、华东送到 1100、全国均价 971、期货 953、贸易商 1200），全部并列展示。

## 9. 项目

| 通道 | 拿到什么 |
|---|---|
| 环评一次公示 | 建设内容与规模、拆除清单（→ 置换关系） |
| 环评二次/拟批准公示 | 批复进度，比"计划开工"更硬的信号 |
| 公司公告 | 投资额、置换比例、建设周期、财务测算 |
| 发改委备案 | 项目代码，证明立项 |
| 开工/投产通稿 | **实际**进度 |

坑：
- "计划 2026-10 开工"不是"已开工"；
- 有的项目环评公示写投资 46 亿、公告写 48.37 亿——**两个口径都记，不选**；
- 政策风险要单独写：如"不再审批新建联碱"是否豁免减量置换技改，这决定项目能否落地。

## 10. 通用反爬与降级

1. 遇到人机验证（如某些化工信息站）→ **换通道**，别硬刚，也别拿验证页当内容。
2. 官方 PDF 比 HTML 稳：巨潮、各级政府站的 PDF 附件优先。
3. 网页 JS 动态渲染抓不到（企业"发展历程"时间轴）→ 换站点或直接标缺口。
4. 子代理/并行调研时：**每个对象单独成条、逐条追加写入**，不要一次性搬运大段文本。
5. 用 `curl`/`Invoke-WebRequest` 抓不到时，用搜索结果的**摘要片段**并在 `note` 标注"仅见摘要，未取原文"，
   `grade` 降一级。

## 11. 一次典型调研的时间分配

| 阶段 | 占比 | 产出 |
|---|---|---|
| 名单与产能（年报 + 协会 + 资讯） | 30% | `sites[]` 的骨架 |
| 否证与去重 | 15% | 否证条目 + 缺口 |
| 地址与坐标 | 20% | `precision` 分布（现实：精确通常只占 1/3） |
| 园区与配套 | 10% | `parks[]` |
| 上下游与物流 | 15% | `upstream/downstream/nodes` |
| 价格与项目 | 10% | `prices`、`projects[]` |

坐标永远是最花时间、最容易翻车的一节。**先做能做的，剩下的老老实实标县级/市级。**
