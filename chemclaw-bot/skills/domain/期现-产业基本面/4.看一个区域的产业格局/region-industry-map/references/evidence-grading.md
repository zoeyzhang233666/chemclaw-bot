# 证据分级与门禁

## 1. 四个等级

| 等级 | 定义 | 典型来源 | 能不能单独支撑一个数字 |
|---|---|---|---|
| **A** | 一手、有法律责任、可点开 | 上市公司年报/公告、交易所公告、环评公示与批复、政府统计与价格监测、排污许可证、省政府名单 | 能 |
| **B** | 二手但专业、有署名 | 行业协会统计、主流财经媒体、资讯机构日评/产能表、港口与铁路官方资料、企业官网 | 单个数字能，**产能与工艺**建议 A+B 交叉 |
| **C** | 行业资讯、地方媒体、企业宣传、民间整理 | 化工网站、地方融媒、园区招商稿、雪球/股吧整理、券商旧研报 | 只能作辅助或交叉，**不能单独定产能/地址** |
| **D** | 未核实线索 | "有人说过""据说""待在项目汇总里看到" | 只能进缺口表或线索表，**不进任何合计** |

### 1.1 等级挂在两个地方

- `sources[].grade`：这条来源本身的等级；
- `sites[].evidence_grade`：这个站点**结论**的等级，取支撑它的最强证据，但要往下压一档：
  "来源是 A 级，但我只用了它的摘要" → 站点记 B。

### 1.2 工艺路线特别规则

工艺（氨碱/联碱/天然碱）如果只有 C 级交叉（如"雪球整理 + 2010 年研报"），
**站点仍可记 A 级（产能是年报），但必须在 `note` 写"工艺缺 A 级定案"并进 `verify` 清单**。
山东案例的海天即如此：产能 150 万吨来自年报（A），工艺只有研报+民间整理（C）。

### 1.3 缺 A 级时的写法

```
note: "工艺按氨碱（研报 + 行业整理交叉，缺 A 级定案）"
verify: ["工艺的 A 级来源（排污许可证）"]
```

不要因为缺 A 级就不写，也不要因为写了就假装是 A 级。

## 2. 五道门禁

`validate.py` 跑完输出 `error` 与 `warning`。**error 一律阻断构建**，warning 逐条判断后可以放行，
但必须在 `narrative` 或 `gaps` 里留下解释。

### 2.1 口径门

| 检查 | 级别 |
|---|---|
| `capacity` 不是数字 | error |
| `raw_capacity` 里的数字与 `capacity` 对不上（吨 vs 万吨） | warn |
| 城市站点合计 > 城市公开口径 × 1.02 | error |
| 城市覆盖度 < 60% | warn |
| `meta.capacity_unit` 缺失 | warn |

### 2.2 缺口门

| 检查 | 级别 |
|---|---|
| `narrative.gaps` 为空 | warn |
| `narrative.coverage_note` 为空 | warn |
| 站点的 `verify` 全空（应至少对最不确定的那条留一个） | 建议性，不进脚本 |
| 5 个以上站点无坐标 | warn（要求地图上明确"地区级记录"） |

### 2.3 净增门

| 检查 | 级别 |
|---|---|
| 项目缺 `status_asof` | error |
| `net < 0` 但 `capacity_retired` 为空 | warn |
| 项目 `status` 是"已投产"但 `online` 在未来 | 建议性，人工判 |
| 同一企业同一地址同时有"退出"与"新建"却没标置换关系 | 人工判 |

### 2.4 来源门

| 检查 | 级别 |
|---|---|
| `source_ids` 引用了未登记的 id | error |
| 站点完全没有 `source_ids`（只能是"未核实"） | warn |
| `sources[].url` 为空且 `grade == "A"` | warn |
| 正文出现预测性措辞（"必将""一定会""势必"） | error |

### 2.5 地址门

| 检查 | 级别 |
|---|---|
| 精确点位但 `reg_address == plant_address` 且未注明"同址" | error |
| 精确点位的 `plant_address` 含总部/写字楼关键词 | error |
| 精确点位但没有坐标 | error |
| 坐标不在中国境内 | error |
| 县级/市级却填了坐标 | warn（地图只用地区位置） |
| 同一坐标被 3 个以上站点共用 | warn |

## 4. 结论的写法

**能写的**（事实 + 由事实直接得出的结构判断）：

> 可核实的在产主体只有 2 家，合计 430 万吨/年（年报设计产能口径）；资讯机构有效产能口径为 450 万吨。
> 两家厂都在潍坊，相距约 40 公里。

**不能写的**（需要没有的吨耗数据或预测能力）：

> 山东纯碱供过于求约 50 万吨。
> 2028 年海化投产后山东价格将下跌。

判断标准一句话：**这句话有没有一个可以直接点开核对的来源？** 没有就不写。

## 5. 措辞规范

| 场景 | 写 | 不写 |
|---|---|---|
| 有公开数字 | "280 万吨/年（年报设计产能）" | "约 280 万吨" |
| 两个口径 | "430（年报）/ 450（资讯机构）" | "440 万吨左右" |
| 没有数字 | "未取得" / "未公开" / 缺口表登记 | "估计 100 万吨""应在 80-120 之间" |
| 只有线索 | "线索（D 级）：……，未取得原文" | 直接写进合计 |
| 否证 | "否证：年报产品清单无此产品" | 默默删掉 |
| 点位不确定 | "县级定位，不作装置位置" | 画个点在厂区位置 |
| 项目未开工 | "拟建（status_asof 2026-10-13），未见开工通报" | "已开工" |
