# 视觉与交互规范

两个交付物共用一套语言：深青做主色、琥珀做强调、红色只用于风险与负向数字。

---

## 1. 色板

```css
--deep:  #0b3b4a   /* 主色：标题、表头、地图未选中省 */
--deep2: #12586a   /* 主色浅一档：小标题、悬停 */
--teal:  #0e7c6b   /* 强调：正向、在产、集中度 */
--amber: #b45309   /* 警示：口径提醒、缺口、待核实 */
--red:   #a1323a   /* 负向：退出、停产、净减 */
--blue:  #1d4ed8   /* 物流节点 */
--violet:#6d28d9   /* 下游用户 */
--gold:  #a9812b   /* 项目（新增/在建） */
--ink:   #17222b   /* 正文 */
--mute:  #6b7684   /* 次要文字 */
--line:  #d9dee4   /* 分隔线 */
--bg:    #eef1f5   /* 页面底色 */
```

用法约束：

| 颜色 | 只用于 |
|---|---|
| 深青 | 结构、标题、主数据 |
| 青绿 | 在产、正向、集中度条 |
| 琥珀 | 口径提醒、缺口、"样本口径"标签 |
| 红 | 停产/退出、净减少、错误 |
| 蓝 | 港口/铁路/交割库（物流节点） |
| 紫 | 下游用户 |
| 金 | 项目 |

**不要**用渐变大色块、不要用投影堆叠。阴影只有两种：
`0 1px 2px rgba(11,59,74,.06)` 与抽屉的 `0 12px 40px rgba(11,59,74,.18)`。

---

## 2. 字体与数字

```css
font-family: "Microsoft YaHei", "PingFang SC", "Source Han Sans SC", system-ui, sans-serif;
font-variant-numeric: tabular-nums;   /* 所有数字列 */
```

- 标题：600–700 字重，字号 15/18/22/28；
- 正文：13–14px，行高 1.6；
- 表格：12.5px；
- 数字一律 tabular-nums，保证列对齐；
- **不要用衬线字体**（中文衬线在小字号下糊）。

---

## 3. HTML 信息架构

固定 10 节，导航吸顶：

```
01 总览      KPI 卡 + 一句话结论 + 口径提醒
02 地图      中国/区域底图 + 图层开关 + 度量切换 + 侧栏详情
03 工厂与企业 可筛选站点总表（搜索/工艺/状态/角色/规模/证据）
04 区域产能   城市/省份产能条形图 + 与公开口径对比 + 覆盖率
05 园区      园区卡（主导产业、落位企业、配套）
06 上中下游   桑基图 + 上游卡 + 下游卡 + 物流节点卡
07 新增项目   项目时间轴/表（毛新增 vs 退出 vs 净增）
08 价格      价格序列折线 + 口径说明 + 区域供需特征
09 集中度    CR3/CR5/HHI + Top N 条
10 口径与来源 方法网格 + 缺口网格 + 来源清单
```

### 3.1 地图规范

| 要素 | 规范 |
|---|---|
| 底图 | 省级 GeoJSON（内联 gzip+base64，`window.__GEOZ__`），离线可开 |
| 未选中省 | `#e8ecef` 填充，`#c9d1d8` 描边 |
| 有数据的省 | 按度量着色（产能/厂区数/注册企业），色阶 `#ffffff → #0e7c6b` |
| 度量切换 | `capacity` / `plants` / `registered` / `downstream` 四选一 |
| 图层开关 | 生产企业 / 贸易商 / 下游用户 / 化工园区 / 新增项目 / 物流节点 |
| 点位形状 | 精确=圆、园区级=菱形、县级/市级=灰方块（**形状即精度**） |
| 点击 | 省 → 侧栏省概览；城市 → 该市企业表；园区 → 园区卡 |
| 图例 | 固定在图内右下，含形状含义说明 |

点位形状是**语义**不是装饰：用户看到圆点就该知道这是装置位置。

### 3.2 站点总表

列：企业 / 厂区 / 角色 / 工艺 / 产能 / 状态 / 地址类型 / 精度 / 证据 / 来源。
筛选器：搜索框、工艺、状态、角色、规模（<50 / 50–200 / >200）、证据等级。
行点击打开抽屉：全部字段 + 注册地址 vs 生产地址 + 待核实清单 + 来源链接。

### 3.3 侧栏卡片

统一结构：`标题（含 id 徽标）→ 关键数字行 → 明细表 → 脚注（口径）`。
"未取得"用琥珀色且**不要**排版成 0。

## 4. Excel 规范

14 张表，顺序固定（见 `SKILL.md`）。

| 规范 | 值 |
|---|---|
| 第 1 行 | 表名（15pt 深青加粗，跨列合并） |
| 第 2 行 | 口径副标题（9.5pt 灰） |
| 第 3 行 | 空（留白） |
| 第 4 行 | 表头（白字深青底，居中，自动换行，行高 30） |
| 第 5 行起 | 数据，斑马纹 `#f5f8f9`，细边框 `#d9dee4` |
| 冻结 | `A5`（表头以下全部冻结） |
| 筛选 | 自动筛选覆盖表头与数据区 |
| 列宽 | 中文按 2 宽估算，10–46 之间 |
| 行高 | 按最长单元格估算，最多 6 行 |
| 空值 | `—`（不是空白，不是 0） |
| 数值列 | 右对齐 + 数值色彩阶（产能列） |
| 表底 | "说明与口径"区，`· ` 开头的条目，合并到表宽 |
| 公式 | **一个都不放**。全部静态值，对方打开即所见 |

工作表命名：`00_封面与目录` … `13_来源清单`，两位数前缀保证排序。

封面页必须有：品种/区域/截止日/口径/点位规则 + 关键数字块 + 目录 + 一句免责边界。

---

## 5. 文案规范

- 标题写判断，不写主题：「在产主体只有 2 家，全部落在潍坊」而不是「生产企业情况」；
- 数字后面紧跟口径：「430 万吨/年（年报设计产能）」；
- 口径冲突时在同一句里并列：「430（年报）/ 450（资讯机构）」；
- 缺数据写「未取得」，并在缺口表给出补齐路径；
- 不用感叹号、不用"重磅""震惊""爆发"；
- 结论句不超过 2 行，超过就拆。

---

## 6. 打印

`@media print` 要求：

- 隐藏导航、筛选器、抽屉、图层开关；
- 地图区域固定高度 520px（保证截图进 PDF）；
- 表格不跨页断行（`break-inside: avoid`）；
- 每个 `<section>` 前分页（`break-before: page`）；
- 黑白打印时，颜色编码的信息必须仍有文字冗余（如"● 精确"在同一行）。

---

## 7. 无障碍与窄屏

- 对比度：正文 ≥ 4.5:1；灰字 `#6b7684` 在 `#ffffff` 上为 4.6:1，**不要再浅**；
- 所有交互控件保留 `:focus-visible` 描边；
- < 1100px：侧栏改为上下堆叠；< 720px：表格横向滚动（`overflow-x:auto`），KPI 两列；
- 表格与卡片容器一律 `min-width:0`，否则 flex 子项会在窄屏撑破布局。
