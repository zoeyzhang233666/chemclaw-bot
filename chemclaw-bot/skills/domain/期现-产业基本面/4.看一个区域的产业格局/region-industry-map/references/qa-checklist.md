# 交付前检查清单

按顺序过一遍。带 ⛔ 的是硬门禁，不通过不能交付。

---

## A. 数据（人工）

### A1 名单完整性
- [ ] 每个"在产"主体都有 A 或 B 级来源
- [ ] 做过否证：至少查了 2–3 个**传闻中**的企业，并把否证结果入表
- [ ] 用协会/资讯分企业表反证过名单完整性
- [ ] 停产/退出的老厂单独成条，`status = 停产`，不进合计

### A2 产能口径
- [ ] 每个产能都能在 `raw_capacity` 里找到原文
- [ ] 单位统一（万元吨/年），吨与万吨没有混用
- [ ] 多口径冲突处并列，没有悄悄取平均
- [ ] 衍生品装置（小苏打、过碳酸钠、硅酸钠）被排除在合计外
- [ ] 城市公开口径与厂区合计做过对账

### A3 地址与点位
- [ ] ⛔ 没有任何点位来自注册地址/总部地址
- [ ] ⛔ 每个"精确"点位都能说出依据（什么要素/什么文件）
- [ ] 降到县级/市级的站点，在 `note` 写了原因
- [ ] 园区坐标注明了误差范围
- [ ] 已停产/已退出的装置没有坐标
- [ ] 坐标全部在目标省范围内

### A4 项目
- [ ] ⛔ 每个项目有 `status_asof`
- [ ] 置换/技改项目同时填了新增与退出
- [ ] "计划开工"没有写成"已开工"
- [ ] 不同产品的产能变化分开写（纯碱 -20 / 氯化铵 +103，不合并）

### A5 价格
- [ ] 每个价格观察有日期、规格、区域、口径、来源五项
- [ ] 出厂价与送到价没有混在一起比较
- [ ] 期货价、贸易商零售价标明"不作现货依据"
- [ ] 大区口径（华东）没有写成省口径（山东）

### A6 缺口
- [ ] ⛔ 缺口表里每条都有"怎么补"
- [ ] 没有用一个估计值填空缺
- [ ] 优先级标了 P0/P1/P2

## B. 构建（脚本）

```bash
cd scripts

# ⛔ 1. 校验
python validate.py ../regions.json
# 期望：error 0；每条 warning 都能一句话解释

# ⛔ 2. 构建 + 体检
python build_all.py ../regions.json --out ../out --name 品种-区域 --qa --shot ../out/qa/shot.png
# 期望：HTML ~1.4MB / XLSX 14 表 / QA 通过
```

- [ ] ⛔ `validate.py` error = 0
- [ ] ⛔ `qa.py` 0 项失败
- [ ] ⛔ `selftest.py` 末行为"—— 自检通过"（改过脚本/模板必跑）
- [ ] HTML 大小 0.9–3 MB（太小说明资产没内联，太大说明数据里塞了图）
- [ ] XLSX 打开不报"文件已损坏"
- [ ] 没有 `%%XXX%%` 占位符残留

打开 `out/qa/shot.png` 与 HTML 本体：

- [ ] ⛔ 地图有底图和点位（不是空白/灰块）
- [ ] 点位形状与精度一致（圆=精确、菱形=园区、方块=县市）
- [ ] 图例说明可读
- [ ] 图层开关、度量切换可点且生效
- [ ] 点省份 → 侧栏有内容；点园区 → 园区卡有企业
- [ ] KPI 卡数字不溢出、不被裁
- [ ] 所有图表（产能/桑基/价格/集中度）都有内容，无空白画布
- [ ] 中文无乱码/方框
- [ ] 表格不横向溢出容器
- [ ] 窄屏（≤720px）不崩
- [ ] 打印预览：地图与表格都完整

## G. 交付话术

回复用户时给三样东西：

1. **结论**（3–7 条，每条带口径）；
2. **两个文件的位置 + 各自能干什么**；
3. **最大的 3 个缺口**（诚实说哪儿不确定，下一步怎么补）。

不要只丢文件不说结论，也不要只讲结论不给文件。
