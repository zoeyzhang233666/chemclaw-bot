# 版本记录

## v1.0.0 · 2026-10-20

首个版本。以纯碱（SA）2026-07-15 → 2026-10-19 的真实研究为原型抽象而成。

### 内容
- `SKILL.md`：8 步流程、五档指标分级、反简单平均的加权传导、交付契约、常见失败模式
- `references/`：6 份规范（结构识别、代理分级、传导分析、指标口径、数据源、检查清单）
- `scripts/`：4 个可复用脚本（校验+派生、HTML、Excel、自检）
- `templates/`：JSON 骨架 + 零依赖 SVG 图表库
- `examples/soda-ash-demand-3m/`：完整案例（137 条证据 / 4 套结构 / 21 项打分 / 6 条传导 / 6 个缺口）
- `examples/urea-demand-demo/`：跨品种框架演示，证明脚本换品种无需改动

### 相对"直接写报告"的改进
1. **指标分级前置**：每条证据带 A/A-/B/C/D，报告可按等级筛选，读者能自己查"结论到底建立在什么指标上"。
2. **反简单平均**：分项指数（下游内部加权）→ 消费占比加权 → 权重敏感性，三层结构替代"取平均"。
3. **价格隔离**：价格永远不进需求打分；报告强制写出"涨价来自减产"的反例。
4. **缺口显性化**：拿不到就登记缺口并说明对结论的影响，不用估计值顶替。
5. **同源交付**：HTML 与 Excel 由同一个 JSON 生成，`check_all.py` 逐条比对数值。

### 已修复的真实缺陷（来自本项目实战）
- `section#policy` 与 `div#policy` 同 id 导致 JS 覆盖整块内容 → 新增重复 id 检测
- 手机端 `.struct` 栅格未重排导致横向溢出 → 窄屏改为块级 + 表格自适应
- 序列为空时 Excel 条件格式范围越界（`4 must be greater than 5`）→ 空表降级并提示
- 权重键与打分指标名不一致导致分项指数被拉平 → 统一映射 + 未匹配告警
- 无 KPI / 无序列时页面顶部空白 → 三级兜底（显式 kpis → 序列极值 → 结构占比）
