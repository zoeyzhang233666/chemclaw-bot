# 传导分析与加权 playbook（反"简单平均"）

> 本文件解决的唯一问题：**当三个下游有两个走弱、一个走强时，你怎么给出一个不含水分、又能被追问的结论。**

## 1. 为什么禁止简单平均

假设三个下游：浮法（权重 46%）、光伏（21%）、轻碱（33%）。

- **错误做法**：把三者"好/坏"取平均 → 得到一个无意义的中间值，且掩盖了"重碱端（67%）明显走弱"这个关键事实。
- **错误做法二**：按下游数量平均（3 个里 2 个走弱 = 偏弱）→ 完全忽略权重。

## 2. 正确做法：两级指数

### 第一级：分项景气指数（下游内部）

在该下游内部，给每个指标打分并加权：

```
分项景气指数 = Σ(指标打分 × 指标在該下游内的重要性权重) / Σ(权重)
```

打分刻度（必须锚定本区间的实际变化，不能凭感觉）：

| 打分 | 含义 | 锚定规则（示例） |
|---|---|---|
| **+2** | 明显改善 | 产量级指标环比 > +5%，且同比转正 |
| **+1** | 改善 | 环比 +1%~+5%，或库存显著去化 |
| **0** | 基本持平 / 方向不明 | 环比在 ±1% 内，或指标间相互矛盾 |
| **−1** | 走弱 | 环比 −1%~−5%，或同比负增长但幅度未扩大 |
| **−2** | 明显走弱 | 环比 < −5%，或同比降幅 >10%，或多指标同步恶化 |

指标重要性权重（可调，但必须在报告里写明）：

- 浮法玻璃：日熔量 0.40 / 订单天数 0.20 / 库存 0.15 / 开工率 0.10 / 产能利用率 0.10 / 利润 0.05
- 光伏玻璃：日熔量 0.35 / 月产量 0.20 / 表观消费 0.20 / 产能利用率 0.10 / 库存天数 0.10 / 利润 0.05
- 轻碱：轻碱厂库 0.40 / 碳酸锂产量 0.35 / 定性 0.25

> 权重设计原则：**产量级 A 指标合计不低于 0.6**，价格类权重为 0（价格不参与）。

### 第二级：加权传导指数（跨下游）

```
传导指数 = Σ(分项景气指数 × 该下游消费占比)
```

纯碱案例实测：

| 下游 | 分项指数 | 占比 | 贡献 |
|---|---|---|---|
| 浮法玻璃 | −0.40 | 46% | −0.184 |
| 光伏玻璃 | −1.75 | 21% | −0.367 |
| 轻碱综合 | +0.40 | 33% | +0.132 |
| **合计** | — | 100% | **−0.419** |

读法：下游景气整体**拖累**纯碱需求，且拖累主要来自光伏玻璃（贡献 −0.367，占全部负贡献的 2/3），
而不是"三个下游平均下来略微偏弱"。这就是可被追问的结论。

## 3. 必须做权重敏感性

换一套口径再算一次，看方向是否改变：

| 权重方案 | 加权指数 | 方向变化 |
|---|---|---|
| 基准：浮法 46 / 光伏 21 / 轻碱 33 | −0.42 | — |
| 华经口径：浮法 32 / 光伏 18 / 轻碱 50 | 见 JSON | 否 |
| 只算两玻：浮法 69 / 光伏 31 | 见 JSON | 否 |

若某个方案下方向反转，报告中必须写"结论对结构口径敏感，不建议据此下强判断"。

## 4. 措辞规范（防止被误用）

| ✅ 可以说 | ❌ 不能说 |
|---|---|
| 下游景气对纯碱需求形成拖累，主要来自光伏玻璃 | 纯碱需求下降了 X 万吨 |
| 浮法日熔量折算重碱刚需 2.92→2.846 万吨/日（推算） | 浮法需求下降 2.5%，所以纯碱需求下降 2.5% |
| 光伏玻璃价格 +24% 的同时表观消费 −13%，说明涨价来自减产 | 光伏玻璃涨价说明纯碱需求好转 |
| 厂库下降，但同期产量下降、下游原料库存天数同比上升，去库非单一需求驱动 | 厂库下降说明需求明显改善 |

## 5. 传导链条的写法

每一跳写成四元组：`上游指标 → 下游指标 ｜ 机制 ｜ 滞后 ｜ 强度 ｜ 证据`

纯碱案例：

```
房屋竣工面积 → 浮法深加工订单 ｜ 竣工带动门窗/幕墙安装 → 加工厂排单 ｜ 1-3个月 ｜ 强
深加工订单 → 浮法产销率/库存 ｜ 订单不足→随用随采→厂库累积    ｜ 即时-2周 ｜ 强
浮法日熔量 → 重碱刚需        ｜ 1吨玻璃耗约0.2吨重碱          ｜ 日度      ｜ 强（有系数）
玻璃厂重碱库存天数 → 实际采购 ｜ 降库存→少采购（二次衰减）      ｜ 即时      ｜ 中
玻璃价格 → 重碱需求          ｜ 无直接机械联系，仅经利润→冷修   ｜ 1-3个月   ｜ 弱（禁止直接等同）
```

**"二次衰减项"容易被漏掉**：即使下游产量不变，下游企业自身的原料库存天数下降，采购量也会显著低于消耗量。
所以需要 `下游原料库存天数` 这类指标（B 级，但在传导中是关键一环）。

## 6. 什么时候该说"无法判断"

满足以下任一条件时，报告结论应写"无法判断/低置信"，而不是硬给方向：

- 该下游没有任何 A 级指标；
- A 级指标之间方向相反且无法用补库/去库解释；
- 数据日期跨度过大（如区间首尾相差 2 个月以上）；
- 遇到口径断点（如 SMM 换库存口径）且未做桥接。
