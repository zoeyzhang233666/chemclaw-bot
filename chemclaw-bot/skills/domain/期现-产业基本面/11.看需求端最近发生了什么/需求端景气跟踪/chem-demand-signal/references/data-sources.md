# 数据源优先级与抓取方法

## 一、优先级（按需求研究的可用性排序）

| 层级 | 来源 | 典型指标 | 可用性 |
|---|---|---|---|
| 1 | 郑商所/大商所品种手册与投教材料 | 物耗系数、交割标准、分地域需求表 | PDF，稳定 |
| 2 | 国家统计局 / 国家能源局 / 海关总署 | 平板玻璃产量、竣工、装机、进出口 | 官网/新闻稿，月更 |
| 3 | 一手监测机构（隆众 oilchem、卓创 sci99、钢联 Mysteel、SMM） | 日熔量、开工率、库存、利润、订单天数 | 部分正文免费，深度需会员 |
| 4 | 期货公司研究所（紫金天风、光大、徽商、国金等） | 周报中的全套周度指标 + 同比 | 免费转载，引用上述机构 |
| 5 | 权威媒体转载（新华财经 cnfin、期货日报、财联社、新浪财经、东方财富） | 上述周报的正文 | 免费，稳定 |
| 6 | 行业协会公众号（SMM 光伏视界、中国玻璃报道） | 光伏玻璃价格、自律减产动态 | 免费，需筛选 |
| 7 | 产业研究院付费摘要（华经、智研、小牛行研） | 需求结构占比 | 口径常不清，只作对照 |
| 8 | 百科/问答 | — | **仅作线索，不进报告** |

## 二、抓取要点（踩过的坑）

### 能用
- `web_fetch` 抓正文；HTTPS 必需（`http://` 会报 "only https URLs are supported"）。
- 隆众 `oilchem.net/26-MMDD-HH-hash.html` 正文可直接抽取（部分文章命中会员墙）。
- 新浪财经、网易 dy、新华财经 cnfin、东方财富、期货日报：正文可直接抽取。
- 新浪期货日线接口（主连历史）：
  `https://stock2.finance.sina.com.cn/futures/api/jsonp.php/x/InnerFuturesNewService.getDailyKLine?symbol=SA0`
  返回 `{d,o,h,l,c,v,s}`，可用于计算区间涨跌与历史分位。

### 不能用 / 慎用
- **生意社 100ppi**：返回 660 字节混淆 JS（反爬），放弃。
- **东方财富 push2his**：`115.SAM` 间歇性 `Remote end closed connection`；`115.FGM` 可用。改为新浪。
- **搜索内置 `web_search`**：常返回 HTTP 500 或质量很差的聚合结果；改用 `advanced_search(engine="firecrawl")` 或 `"parallel"`，效果明显更好。
- **东财仓单/数据页**：JS 渲染，接口 404，放弃；改用期货公司周报文字证据。

### 抓不到怎么办
1. 换一篇文章（同一份周报常被 3-5 家媒体转载）。
2. 换一个指标（日熔量抓不到，用开工率 + 产量）。
3. 记为缺口（`gaps`），写清原因、补数路径、对结论的影响。
4. **绝不估算、绝不插值、绝不用"约"字糊过去**。

## 三、检索词模板

中文需求研究的高效检索词（按命中率排序）：

```
"<品种>" "<下游>" 开工率 产量 库存 周报
"<下游>" 日熔量 在产 同比
"<品种>" 下游 需求 占比 结构
"<品种>" 周报 隆众 卓创 钢联
"<下游>" 价格 上调 下调 元/平方米
"<下游>" 冷修 点火 复产 堵窑
"<品种>" 出口退税 政策 财政部
"<下游>" 企业 亏损 减产 检修
```

## 四、来源可信度标注

每条证据都带 `src` 键，映射到 `sources` 表：

```json
"sources": {"longzhong": ["隆众资讯", "行业数据机构（一手监测）"],
            "zjtk": ["紫金天风期货研究所", "期货公司研究（引用钢联/卓创/SMM）"],
            "cnfin": ["新华财经（新华社）", "国家级金融信息平台"]}
```

报告里显示"来源机构 + 来源类型"，让读者自己判断分量。

## 五、需要会员/付费的数据（如实登记为缺口）

- 光伏玻璃同口径周度日熔量完整序列
- 轻碱下游（洗涤剂、印染、造纸、硅酸钠）周度开工率
- 浮法玻璃日熔量 5 年以上数值序列（用于精确历史分位）
- 纯碱出口月度数据（含重碱/轻碱拆分）
- 玻璃厂重碱原料库存完整周度序列

这些在本 Skill 的案例里全部进了 `10_缺口清单`，没有用估计值填充。
