# 代理指标分级规范（A / A- / B / C / D）

> 一句话原则：**能算出吨数的才是需求，算不出吨数的只是景气度。**

## 分级定义

| 等级 | 定义 | 判定测试 | 能否用于"消费增长" |
|---|---|---|---|
| **A** | 直接消耗量，或按固定物耗系数可换算为消耗量的下游产量 | 问："这个数乘以一个系数，能得到本品种的吨数吗？" 能 → A | 可以，须注明系数与口径 |
| **A-** | 真实需求的结构性代理，有系统性偏差 | 方向一致但幅度会失真 | 可以，须交叉验证 |
| **B** | 由供需差推导的间接指标（库存、表观、利润） | 反映"结果"而非"消耗" | 不可单独使用 |
| **C** | 价格、期货、基差、高频情绪 | 只反映预期的交易结果 | **不可使用** |
| **D** | 机构调研的定性描述 | 无量化值 | 仅作辅助说明 |

## 逐项判定表（通用模板）

| 指标 | 等级 | 判定理由 |
|---|---|---|
| 下游日熔量 / 日投料量 | A | ×物耗系数 = 本品种日耗，直接决定刚需上限 |
| 下游月产量（统计局/机构） | A | 统计发布的下游实际产出 |
| 下游表观消费量（产量+进口−出口） | A | 最接近实际流通量（月度滞后） |
| 下游在手订单天数 | A | 直接对应未来 1–2 周的原料消耗 |
| 下游开工率 | A- | 条数口径受产线大小影响，须与产量级交叉 |
| 下游产能利用率 | A- | 分母"名义产能"定义各家不一 |
| 下游企业库存 / 库存天数 | B | =产量−出货，是购销差，可被贸易商搬库扭曲 |
| 下游产品利润 | B | 反映供给弹性，但亏损到减产有 3–6 个月滞后 |
| 下游产品价格 | C | 与消耗量无机械关系 |
| 下游期货/基差 | C | 含预期与资金 |
| 终端宏观（竣工、装机、开工） | A（终端） | 是需求的上游驱动，但频率是月度、滞后明显 |
| 销售/成交类（30 城成交、地产销售） | C | 领先终端 2–3 年，对即期需求几乎无解释力 |
| "某企业开工率同比下降" | D | 无量化值 |

## 三条实操规则

### 规则 1：每个下游至少要有一个 A 级指标

如果一个下游只有价格和利润（全是 B/C），说明这个下游**无法支撑需求结论**。
处理方式：① 继续找（企业公告、协会数据、海关数据）；② 找不到就在报告里写"低置信"并放入缺口清单，
而不是用价格凑一个结论。

### 规则 2：A 级指标要交叉验证

同一方向至少两个 A 级指标同向，才敢下结论。纯碱案例：

- 浮法玻璃：日熔量 ↓（−2.5%）+ 深加工订单同比 ↓（−9.2%）→ 两个 A 级同向向下 → 结论可信。
- 若出现"日熔量 ↑ 但订单 ↓"，说明在补库而非真实需求改善，要在报告里点出来。

### 规则 3：B 级指标必须"拆原因"

库存下降有三种原因，含义完全不同：

| 库存变化 | 伴随产量 | 伴随下游库存天数 | 真实含义 |
|---|---|---|---|
| ↓ | ↑ 或持平 | ↓ | **真实需求改善**（下游在消耗） |
| ↓ | ↓（减产） | ↑ 或持平 | **供给收缩**，需求未必好 |
| ↓ | 持平 | 持平 | 渠道搬库/期现套保，中性 |

纯碱 2026-10 的实例：厂库从 190.84 万吨降至 153.96 万吨，但同期产量由 76.85 降至 75.16 万吨/周，
且重碱下游原料库存天数 24.4 天（同比 +6.6%），所以**不能**直接说"需求好转"。

## 在数据结构里的落地

```json
{"id":"F23","kpi":"日熔量","grade":"A","value":14.23,"caliber":"钢联/卓创口径，全国在产日熔量"}
```

- `grade` 写在每条证据上，HTML 卡片与 Excel 都用它着色与筛选。
- 报告里的"指标等级"筛选器就是让读者自己检查：把 C/D 关掉后，还剩下什么支撑结论。

## 跨品种注意

同一指标在不同品种可能等级不同，必须按品种重判：

- **开工率**在纯碱（大装置、条数少）接近 A；在玻璃（200 条产线、大小差异大）只能算 A-。
- **表观消费**在纯碱（产区集中、进口少）较可靠；在甲醇（进口占比大、罐容影响大）误差更大，降为 B。
- **订单天数**在玻璃深加工有连续样本（A）；在许多化工下游没有（缺数据 → 记缺口）。
