# 需求结构识别 playbook

> 目标：在研究任何数据之前，先画出"这个品种到底被谁用掉了"，并明确每套占比的统计年份与分母。

## 1. 三层结构

```
品种（如纯碱 Na₂CO₃）
├── 规格分化         重碱（重质）/ 轻碱（轻质）—— 决定了完全不同的下游
│   ├── 直接下游产品   浮法玻璃、光伏压延玻璃 / 日用玻璃、硅酸钠、碳酸锂、洗涤剂
│   │   └── 终端应用    建筑门窗幕墙、汽车 / 组件、电站 / 包装、消费
│   └── 消费行业        房地产、光伏、汽车、日化
```

**必须先分规格。** 把重碱和轻碱混在一起谈"需求"，是需求研究里最常见的结构性错误：
重碱 95% 以上进玻璃，轻碱分散在十几个行业，两者的指标频率、可得性、驱动因素完全不同。

## 2. 占比必须带五个字段

| 字段 | 说明 | 反例 |
|---|---|---|
| `year` | 统计年份 | 写"平板玻璃占 46%"却不写年份 |
| `org` | 来源机构 | 写"行业数据" |
| `basis` | 分母定义 | 不说明是内需还是表观（含出口） |
| `items` | 各下游占比 + 对应量（有则填） | 只给百分比不给绝对量 |
| `note` | 与其他口径差异的原因 | 无 |

## 3. 为什么要并列 2–3 套口径

同一品种在不同机构手里会得到差别很大的结构，原因是**分母不同**，不是谁算错：

| 口径 | 分母 | 特点 | 玻璃类占比 |
|---|---|---|---|
| 表观消费（产量+进口−出口） | 3596 万吨（纯碱 2024） | 含出口，玻璃占比高 | 平板 46% / 光伏 21% |
| 内需（剔除出口） | 略小 | 剔除出口后玻璃占比下降 | 平板 44% / 光伏 21% |
| 全部应用（含损耗与其他） | 更大 | 分母被"其他"撑大 | 平板 32% / 光伏 18% / 泡花碱 5% / 其他 31% |

**处理办法**：选一套作为基准权重，另两套做敏感性检验。如果三套权重下结论方向一致，结论就稳；如果方向反转，必须在报告里明说"结论对结构口径敏感"。

## 4. 物耗系数：把"下游产量"翻译成"本品种消耗"

这是把下游产量级指标（A 级）变成需求的核心桥梁。系数必须来自可核验来源，并给出区间：

| 关系 | 系数 | 来源 | 注意 |
|---|---|---|---|
| 平板玻璃 ↔ 重碱 | 约 0.2 吨重碱/吨玻璃 | 郑商所投教材料 | 实际 0.18–0.22，视厚度/优等率/碎玻璃比例 |
| 1000 t/d 浮法线 ↔ 重碱 | 200 吨/日 | 同上 | 用于快速估算单线耗碱 |
| 碳酸锂 ↔ 轻碱 | 约 0.3–0.4 吨/吨（视工艺） | 行业资料 | 锂辉石/盐湖/云母工艺差异大 |
| 硅酸钠（干法） ↔ 纯碱 | 约 0.3 吨/吨 | 行业资料 | 湿法不同 |

**换算出来的量是"推算值"，必须在报告里标注推算、给出公式与局限**，不能伪装成统计发布值。

## 5. 占比数据从哪来（按可信度）

1. **协会/交易所官方材料**（中国纯碱工业协会、郑商所品种手册）——最权威，但更新慢。
2. **数据机构年度报告**（卓创、隆众）——有明确口径与年份。
3. **券商/期货公司研报**（常引用上述机构）——注明"研报引用"，可接受。
4. **产业研究院付费报告摘要**（华经、智研）——口径常不清，只能作对照。
5. **问答/百科**（知乎、chinabaogao）——仅作线索，不进报告。

## 6. 输出契约

```json
"structure": [
  {"org": "...", "year": 2024, "basis": "...", "url": "...",
   "items": [["平板玻璃", 46, 1639], ["光伏玻璃", 21, 752]],
   "note": "总量=3596万吨表观消费"}
]
```

配套还要在 `derived.transmission.weights_domestic` 里写下**实际用于加权的映射**（下游 → 权重），
并保证映射关系能被读者一路追到这张结构表。
