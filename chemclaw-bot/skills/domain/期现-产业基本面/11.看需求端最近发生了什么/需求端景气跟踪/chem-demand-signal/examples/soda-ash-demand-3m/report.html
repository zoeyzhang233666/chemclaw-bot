下游需求研究

两玻（浮法+光伏）日熔量在 3 个月内继续下行，重碱“产量级刚需”是收缩的；轻碱端因碳酸锂产量回升与厂库大幅去化呈现韧性。纯碱自身库存走低主要是碱厂检修降负荷叠加下游阶段性补库，不能据此认定终端消费增长。

规格 重质纯碱（重碱）+ 轻质纯碱（轻碱），现货为含税送到/自提价研究区间 近3个月：2026-07-15 至 2026-10-16 数据截止 2026-10-20区域 全国（重点：沙河/华北、华东、西北天然碱产区、华中）

    01

    纯碱下游消费结构（多口径并列）

    不同机构对纯碱下游占比的口径差异很大，差异来自“分母”（内需 / 表观含出口 / 全部应用），不是谁算错了。本研究并列三套结构，并在所有下游卡片上标注所采用的年份与来源。

    不同机构对纯碱下游占比的口径差异很大，差异来自“分母”（内需 / 表观含出口 / 全部应用），不是谁算错了。本研究并列三套结构，并在所有下游卡片上标注所采用的年份与来源。

    • 采用结构：以 2024 年“平板玻璃46% / 光伏玻璃21% / 日用玻璃12% / 其他21%”（卓创-协会口径，表观消费3596万吨）作为基准权重；
    • 敏感性：同时列出华经（平板32/光伏18/日用玻璃14/泡花碱5/其他31）与小牛行研（44/21/10/25）口径下的加权结果，避免结论被单一权重绑架；
    • 重碱 vs 轻碱：重碱几乎全部进入两玻，因此“平板46%+光伏21%=67%”可视为重碱总权重；轻碱权重约 33%（日用玻璃12%+锂电/洗涤/硅酸钠等）。
    占比数据为第三方研究机构统计，非海关/统计局原始发布；各机构样本与年份不同，禁止跨口径相加。
    02

    浮法玻璃：真实需求走弱，但价格与需求已“脱钩”

    浮法玻璃是重碱第一大下游（46%）。三个月内其产量级指标（日熔量、开工率）小幅下行，真实需求指标（深加工订单天数）环比略升但同比仍负，库存处于近5年同期高位。

    浮法玻璃是重碱第一大下游（46%）。三个月内其产量级指标（日熔量、开工率）小幅下行，真实需求指标（深加工订单天数）环比略升但同比仍负，库存处于近5年同期高位。

    • 产量级刚需（A级）：日熔量 14.60→14.23 万吨/日，同比 -11.8%；在产产线 197 条，年初放水 32 条、点火 16 条，日产量净减 9242 吨 [F01/F23/F31/F46]
    • 真实需求（A级）：深加工订单天数 9.4→10.1→10.0 天，同比 -9.1%~-9.2%，为近5年同期最低；机构调研口径称加工厂“人员与设备开工率同比大幅下降”，属定性描述 [F43/F20/F55/lz0916]
    • 库存（A级）：企业库存 7535.3（7月底）→6985.7（9-17）→7318.6 万重箱（10-08），同比 +16.49%~+26.65%，属被动累库 [F42/F58/F52]
    • 利润（B级）：煤制气 -40.42 → -148.2 元/吨，天然气 -173.8 → -151.9，石油焦 -190.33 → -169.1，全线亏损且煤制气亏损快速扩大 [F07/F08/F09/F17/F16/F18/F28/F27/F29]
    • 价格（C级，仅价格）：全国均价 1070→1082→1075 元/吨，区间 +0.47%，但同比 -13.81%；沙河 5mm 大板一周两降至 913 元/吨 [F40/F15/F33/F30/F22]
    • 结论：浮法端对纯碱的“潜在刚需”按 0.2 吨/吨玻璃折算为 2.92→2.846 万吨/日（推算值，非统计值），三个月下降约 2.5%；实际采购还要扣掉玻璃厂自身的重碱库存天数变化。
    价格反弹（若发生）主要反映成本 / 情绪 / 期现套利，不能作为纯碱消费增长的证据；本研究不将玻璃价格纳入需求强度打分。
    03

    光伏玻璃：减产与报表消费双降，价格修复≠需求修复

    光伏玻璃是重碱第二大下游（21%）。三个月内该行业在“价格连涨三次”的同时，日熔量、产量、表观消费全部下行——这是本次研究最典型的“价格与消费背离”案例。

    光伏玻璃是重碱第二大下游（21%）。三个月内该行业在“价格连涨三次”的同时，日熔量、产量、表观消费全部下行——这是本次研究最典型的“价格与消费背离”案例。

    • 日熔量（A级，跨口径谨慎）：卓创同口径 8.30（5月末）→7.10（9月末）万吨/日；SMM 7.60（7月中“实际运行”，已扣堵窑）；钢联 6.68（10-12）。三个口径不可直接相减 [P01/P03/P04/P11/P12]
    • 产量与消费（A级）：9月产量 164 万吨（环比 -8%），表观消费 129 万吨（环比 -13%）[P13/P14]
    • 产能利用率（A级）：52.98%（8月）→50.27%（9月），10月预计 48.00% [P15]
    • 库存天数（B级）：54（5月末）→40+（7月中）→44.69（9月末），较高点 -16% 但仍在高位，9月再度回升 [P02/P08/P10]
    • 价格（C级）：2.0mm 镀膜 8.5 → 10.0-10.25 元/㎡（+17.6%~+20.6%），较前期低点 8.25 上涨 24% [P06/P09/P19]
    • 供给弹性（B级）：约 8000 吨/日“建好可点”产能掌握在头部手中，堵窑/保窑产能恢复快于冷修；行业约 3.3 万吨产能可视为实质性出清 [P17/P18]
    光伏玻璃表观消费（129万吨）与日熔量（6.68-7.10万吨/日）分属不同来源、不同月份，只用于方向判断，不做吨数勾稽。
    04

    轻碱与其他下游：结构分化，韧性来自锂电与去库

    轻碱约占纯碱需求的三分之一，但统计最分散。三个月内可见的线索：轻碱厂库大幅去化、碳酸锂产量较 7 月回升但周度波动，传统下游（洗涤、印染、造纸）刚需平稳。

    轻碱约占纯碱需求的三分之一，但统计最分散。三个月内可见的线索：轻碱厂库大幅去化、碳酸锂产量较 7 月回升但周度波动，传统下游（洗涤、印染、造纸）刚需平稳。

    • 轻碱厂库（A级）：104.36（8-31）→93.22（10-09）→82.23 万吨（10-19），区间 -21.7%，去库幅度远大于重碱（86.48→71.73 万吨）[L04/L12/L09]
    • 碳酸锂（B级）：周产 2.45（7-17）→2.6671 万吨（9-27，环比 -4.4%）；9 月月产 12.85 万吨、环比 +10%（含新增统计来源）[L31/L32/L33]
    • 碳酸锂口径断点（关键）：SMM 自 9-4 起启用新库存口径，库存一次性上修 9-10 万吨，新旧序列不可直接比较 [L34]
    • 表观消费（B级）：截至 10-08 当周纯碱表观消费 69.45 万吨，环比 -9.23%（受假期与下游放假影响）[L01]
    • 轻碱价格：华北市场价 1250 元/吨高位持稳，西北降至 800 元/吨低位；重轻碱价差收窄至 0-70 元/吨（7月中）→ 需求分化印证 [zor0722]
    轻碱下游缺少周度开工率与订单数据，低置信：轻碱去库更可能是“碱厂减产+下游补库”共同作用，不能直接读作轻碱消费增长。
    05

    终端需求：房地产竣工是浮法的天花板，光伏装机是压延的先行指标

    下游产品的景气最终由终端决定。两玻的终端指标在本区间内均为“深负”：竣工累计同比 -23.7%，上半年国内光伏新增装机同比 -66.04%。

    下游产品的景气最终由终端决定。两玻的终端指标在本区间内均为“深负”：竣工累计同比 -23.7%，上半年国内光伏新增装机同比 -66.04%。

    • 房屋竣工面积 1-8月 21097 万㎡，累计同比 -23.7%；新开工 29894 万㎡，同比 -24.8% [R01/R02]
    • 30 大中城市商品房成交（7日均）19.17 万㎡，同比 +1%（7-22）；节后同比基本持平，处历史同期低位 [R03/R04]
    • 国内光伏新增装机 2026 上半年同比 -66.04% [S01]
    • 传导链条：竣工 → 深加工订单 → 深加工开工 → 浮法产销 → 浮法库存/日熔量 → 玻璃厂重碱采购 → 纯碱重碱需求；每级有 1-3 个月的滞后，节后“产销率冲高至近120%后回落”即为脉冲式补库的例证 [zjtk1014]
    终端指标（统计局/能源局）为月度发布且多为累计值，与研究区间的周度指标频率不一致，只能定方向。
