# 统计口径与算法（methodology）

本文件是实现"可溯源、可比、不编造"的技术规范。报告与工作簿中的每个数字都必须符合这里的规定。

---

## 1. 为什么口径必须先声明

同一个"纯碱进口额"，用不同口径可以差出几十个百分点：

| 口径选择 | 差异来源 | 处理方式（本 Skill 的默认） |
|---|---|---|
| 报告国自报进口 vs 镜像（伙伴国自报对你出口） | 转口（香港/新加坡/鹿特丹）、再出口、报关价差 | **用报告国自报进口**，因为关税与市场准入是在目的国发生的 |
| CIF vs FOB vs FAS | 运费与保险归属 | Comtrade 进口默认 **CIF**；同一序列不得混用不同价值条款 |
| 6 位 HS vs 本国 8/10 位 | 各国细分不同 | **跨国比较只用 6 位**；关税必须用本地编码 |
| 金额 vs 数量 | 价格波动掩盖真实需求 | **两者都给**；价格暴涨年份不要用金额增长冒充需求增长 |
| 当期美元 vs 不变价 | 汇率与通胀 | 默认当期名义值，**并在报告中声明未作调整** |
| 完整年度 vs 部分年度 | 最新年往往报送不全 | 标注报告国数量；**决策用最新完整年度** |

**规则**：任何跨年、跨国比较，必须同时写明：年份、来源、币种、数量单位、编码层级。

## 2. 核心指标与公式

设报告国 `i`、年份 `t`、HS6 编码 `c`、原产国 `o`（默认中国，M49=156）。

### 2.1 进口规模
```
进口额  V_i,t   = Comtrade(i, c, t, flow=M, partner=0).primaryValue     [USD, CIF]
进口净重 W_i,t  = Comtrade(i, c, t, flow=M, partner=0).netWgt           [kg]
```

### 2.2 原产国供应与份额
```
自原产国进口额  Vo_i,t = Comtrade(i, c, t, flow=M, partner=o).primaryValue
金额份额 S_i,t = Vo_i,t / V_i,t                       （V_i,t > 0）
重量份额 Sw_i,t = Wo_i,t / W_i,t                       （仅当两者净重均 > 0）
```
**注意事项**
- 分子分母必须**同一报告国、同一年、同一编码**，否则会产生虚假份额。
- 若 `Vo > V`（份额 >100%）通常是口径/转口问题 → 视为数据错误，在 `validate_outputs.py` 中报 FATAL。
- 若 `V_i,t = 0` 或缺失 → 份额记为 n/a，**不要写成 0%**（"没报数"≠"没进口"）。

### 2.3 增长率
```
CAGR = (V_i,T / V_i,t0)^(1/(T-t0)) - 1
```
- 基期 `V_i,t0` 缺失或为 0 → **n/a**，不得用其他年份替代。
- 若 `T` 为不完整年度（报告国明显偏少），同时给出 `T-1` 的完整年度 CAGR 作对照。
- 保留两位小数；增长率超过 ±100% 时必须人工复核是否有转口/一次性大单。

### 2.4 均价（仅作校验用，不作定价依据）
```
均价_i,t [USD/t] = V_i,t / (W_i,t / 1000)
```
- `W_i,t = 0` 或缺失 → n/a，**不得用 qty 顶替**（qty 单位可能是件/平方米）。
- 均价异常（显著高于/低于同类国家数倍）优先怀疑编码错配或单位错配，而不是市场信号。

### 2.5 来源国集中度
```
来源国 j 的份额 = V_i,t^(j) / Σ_j V_i,t^(j)      （仅对已取得 partner 明细的报告国）
CR1 = 最大来源国份额        HHI = Σ (份额^2)
```
HHI 接近 1 表示单一来源垄断（替代议题）；接近 0 表示充分竞争（价格战议题）。两者对应的销售策略完全不同。

## 3. 缺失值处理（硬性规则）

| 情形 | 允许的做法 | 禁止的做法 |
|---|---|---|
| 某年该国未报送 | 留空 / 显示"—"/ 标"缺口" | 填 0、线性插值、用邻近年份替代 |
| 最新年不完整 | 注明报告国数量，降级为"方向参考" | 当作完整年度下结论 |
| 净重缺失 | 显示 n/a | 用 qty 或估算密度反推 |
| 未取得来源国明细 | 标"明细缺失" | 用"中国 vs 其他"臆造份额 |
| 未取得行级关税 | 标"待核验"（gap） | 用国家平均税率、或记忆中的税率 |

## 4. UN Comtrade 取数要点（踩坑记录）

1. **全量 partner 不能用 `partnerCode=all`** → 返回 HTTP 400。正确做法：省略 `partnerCode`，按 `reporterCode` 逐个取（单次返回上限约 500 行）。
2. **限流**：`429 Too Many Requests` 与 `403 Quota Exceeded` 都会出现。必须指数退避（4→8→…→120 秒），并把成功响应落盘缓存，避免重复消耗配额。
3. **报告国数量逐年下降**：2019 年 169 个 → 2024 年 144 个 → 2025 年 119 个。因此"全球合计"是**已报送国家的合计**，不是真实世界进口总额；跨年下降可能是覆盖缺口而非需求萎缩。
4. **2025 年为部分年度**：仅可作方向参考。
5. **美国在 Comtrade 中记为 `USA`**（含波多黎各与美属维尔京），与其他来源的美国数据可能有小差异。
6. **`Other Asia, nes`（S19）通常指中国台湾**，比较时注意不要与"Other Asia"混淆进中国大陆口径。

## 5. HS 编码层级冲突的处理

| 冲突 | 例子 | 处理 |
|---|---|---|
| 同一物质不同层级 | 纯碱 2836.20（6位）；EU 2836200000（10位）；US 2836.20.00.00（10位） | 贸易数据用 6 位；关税用本地编码；**不可把 6 位贸易额与 10 位税率相乘来做估算** |
| 本国拆分更细 | 印度/印尼等在 8 位再分"工业级/食品级" | 若需要分规格，需逐国取 8 位数据；**只有当多国都能对齐时才跨国比较** |
| 规格混在同一子目 | 2836.20 同时含重质与轻质纯碱 | 必须在报告中声明"该编码不区分重质/轻质"，结论按"纯碱整体"表述 |
| 相邻编码可能相关 | 过碳酸钠（2836.99）、碳酸氢钠（2836.30） | 作为"关联编码"列出，但**不并入总额**，除非用户确认产品用途跨界 |
| 混合物与单一物 | 单一化合物入 29 章，配制品入 38 章 | 先确认是"纯物质"还是"配方"，再定编码 |

## 6. 数据的"三类信息"分级（写报告时必须标注）

| 标签 | 含义 | 写法 |
|---|---|---|
| 【贸易统计事实】 | 来自官方贸易统计系统、可复现的数字 | 直接给数 + 年份 + 来源 |
| 【产业公开信息】 | 权威机构（USGS/WTO/统计局/协会）发布的产业信息 | 给数 + 出版物名 + 年份 |
| 【初步判断】 | 分析推论 | 必须用"值得进一步核实/说明""可能""倾向于"等措辞 |

**禁止**：把【初步判断】写成【事实】；把"进口大"直接等价于"能卖进去"。

## 7. 港口中转效应

荷兰（鹿特丹）、比利时（安特卫普）、新加坡、阿联酋（杰贝阿里）的进口额常**远大于本国消费**。判断方法：
- 该国进口额大但下游产业规模小；
- 来源国结构高度分散且与邻国互补；
- 存在明显再出口。

处理：在报告中标注"进口额可能包含中转/再出口，不宜直接视为本国需求"。
