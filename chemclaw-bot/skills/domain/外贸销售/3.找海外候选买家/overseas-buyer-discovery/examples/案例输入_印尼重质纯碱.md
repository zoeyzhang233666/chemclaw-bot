# 案例输入 · 印尼重质纯碱（真实案例）

这份文件是一次真实运行的原始输入。它演示了「最小可用输入」长什么样——你不需要准备得很完整，缺的项由 Skill 按推荐值补齐。

## 原始对话输入（客户原话）

> 我是做化工品出口的，主要做纯碱。想开发印尼市场，重点是玻璃厂和相关的化工分销商。帮我找找印尼有哪些可能会买重质纯碱的公司。

## 为什么这些字段重要（对照）

**产品规格写清「重质」而不是「纯碱」**
重质纯碱用于玻璃熔窑，轻质纯碱用于洗涤剂。如果只写「纯碱」，会把洗涤剂厂（要轻质）和玻璃厂（要重质）混在一张表里，报价和规格全部错位。本案中 PT Kao Indonesia 的提单显示的是 **SODA ASH LIGHT**（轻质，用于粉状洗涤剂），必须单独标注，不能与我们提供的重质货混为一谈。

**HS 编码决定统计口径**
没有 HS 编码，就无法用 UN Comtrade / WITS 拉出国家级进口数据，也就没有「市场有多大、谁在供应」的底盘。2836.20 这个码是本案市场章节的全部数据基础。

**目标客户类型决定证据标准**
「终端生产企业」需要证明它有熔窑/反应釜（工艺相关性）；「经销商」只需要证明它在卖这个产品。两类证据强度不同，混在一起会高估。

## 本次没有提供、由 Skill 自行补齐的项

- 具体的目标港口（自行取雅加达 Tanjung Priok / 泗水 Tanjung Perak / 勿拉湾 Belawan）
- 目标价格区间（不猜，改为在报告里给出印尼到岸 CIF 均价作对标）
- 客户年用量（不猜，改为作为「后市核验清单」里的第一个必问问题）
- 印尼下游行业用碱拆分（公开免费来源没有，如实列为数据缺口，不编造）
