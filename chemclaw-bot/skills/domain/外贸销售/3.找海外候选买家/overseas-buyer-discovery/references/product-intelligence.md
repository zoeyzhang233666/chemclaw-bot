# 产品情报：做线索之前必须先弄清的事

「产品」不是四个字，而是一组会改变下游名单的约束。以纯碱为例说明方法，其他产品照此办理。

---

## 1. 规格拆解（决定下游匹配）

| 维度 | 纯碱的取值 | 影响谁 |
|---|---|---|
| 形态/堆密度 | 重质 dense（0.9–1.2 g/cm³）、轻质 light（0.5–0.6） | 玻璃用重质；洗涤剂粉体多用轻质；水玻璃两者皆可 |
| 纯度 | 99.2% min（Na₂CO₃） | 玻璃对 Fe 敏感；食品/药用需食品级 |
| 关键杂质 | Fe₂O₃（玻璃）、Na₂SO₄、Cl、盐酸不溶物 | 玻璃窑要求 Fe ≤ 0.003–0.01% |
| 工艺路线 | 天然碱（trona，美国/土耳其）vs 合成（氨碱/联碱，中国） | 天然碱 Cl/SO₄ 更低，玻璃客户偏好；合成碱价格优势 |
| 包装 | 50 kg PP 袋、1,000–1,250 kg 吨袋、散装 | 人工投料厂要袋装；大型窑可散装 |
| 认证 | ISO 9001、COA、SGS/BV、食品级 | 上市公司/外资客户必有要求 |

**动作**：把上表填满再搜索；搜到的公司一一对照“它属不属于这个规格的使用者”。

## 2. 通用产品档案模板

```
产品中文名 / 英文名 / 别名 / 化学式 / CAS / HS
规格：形态、含量、堆密度、杂质、包装、认证
主流工艺与产地（本国+主要出口国）
下游用途清单（≥8 个），每个标注：工序位置 / 用量强度 / 规格匹配 / 可否替代
价格锚点（近 12 个月区间、地区差异、税基）
贸易流向（谁能出口到目标国、关税与协定）
```

## 3. 目标国“供给缺口”判断

线索的价值取决于这个国家的**供应结构**：

| 情形 | 销售含义 | 线索重点 |
|---|---|---|
| 本国无产能，全靠进口 | 进口商/终端都在海外采购，替代空间大 | 找出进口商与最大终端 |
| 本国有产能但不足 | 需要补充进口，价格敏感 | 找出扩产中的终端与二线客户 |
| 本国有大产能且在建新产能 | 未来价格战、客户可能回流本土 | 先做 peer gate，抢长协与细分规格 |
| 本国禁止/限制进口 | 渠道窄 | 只做加工贸易或保税区客户 |

判断依据优先级：本国产能新闻（政府/企业公告）> 海关统计（HS 编码进口额）> 行业协会报告 > 新闻报道。

## 4. 反例：规格错配导致的伪线索

- 把**轻质**纯碱卖给浮法玻璃厂 → 窑炉配料上料与混合不均，通常被拒。
- 把工业级卖给**食品**客户 → 无食品级证书，直接出局。
- 把**片碱**卖给需要**粒碱**的客户 → 投料系统不匹配。
- 把 25 kg 袋卖给只有**吨袋**卸料系统的厂 → 人工成本上升。

> 结论：线索表里必须有“规格匹配”一栏，并在待验证问题里问对方具体限值。
