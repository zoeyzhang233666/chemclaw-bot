# 公开贸易证据：能拿什么、拿不到什么

外贸销售最想要“这家公司某年从中国进口了多少吨”。这份文件把现实讲清楚，并给出**在拿不到企业级报关明细时**的替代证据链。

---

## 1. 企业级贸易记录的可得性

| 国家/地区 | 企业级进口明细 | 说明 |
|---|---|---|
| 美国 | **公开**（美海关月度数据） | Panjiva/ImportYeti 等免费可查提单级记录（B/L） |
| 印度 | 部分公开 | Volza/Seair 有免费预览，明细付费 |
| 印尼、越南、泰国 | **不公开** | 印尼统计为汇总口径；企业级需付费商业数据 |
| 中国 | 不公开 | 只有海关汇总；企业与供应链关系靠公告/JV 披露 |
| 欧盟 | 部分公开（成员国不一） | 关税数据库 + 部分成员国的公开统计 |
| 拉美（巴西、墨西哥） | 部分公开 | 提单数据商有免费样品 |
| 中东 | 一般不公开 | 依赖港口/企业自述 |

> 结论：在印尼这类市场，“企业是否从中国采购纯碱”的**直接报关证据**通常拿不到；报告必须明说，不能编。

## 2. 替代证据链（按强度排序）

1. **企业自述用量**：上市公司年报“材料使用”表、ESG 报告、环评/许可文件（A 级）
2. **进口/供应的公开表述**：公司公告“新供应商”“本地化”“进口替代”措辞（A 级弱）
3. **分销商目录显示品牌来源**：如“ex ANSAC USA”，说明其在经营特定品牌（B 级，但可反推该分销商在进口）
4. **国家进口结构**：HS 编码下来源国占比与单价（市场事实，非企业证据）
5. **行业产能与新建项目**：未来供需判断
6. **行业报道/协会**：只能作线索

## 3. 国家统计怎么用才不算“冒充企业证据”

- 允许：说明“这个国家每年进口 X 万吨，美国占 Y%”，从而论证“存在进口商层级”与“替代空间”。
- 禁止：写“某玻璃厂年进口 X 吨”而来源只有全国数据。
- 允许：用全国进口量 ÷ 主要终端已知用量，估算“分销/中小客户合计份额”（标明为估算）。

## 4. 数据获取入口（无 Key 可用）

```text
UN Comtrade 预览 API（无需 Key，有限流）：
https://comtradeapi.un.org/public/v1/preview/C/A/HS?reporterCode=360&period=2024&cmdCode=283620&flowCode=M

WITS（页面可直接读，含来源国拆分与数量）：
https://wits.worldbank.org/trade/comtrade/en/country/IDN/year/2024/tradeflow/imports/partner/all/product/283620

USGS 矿产品年报（全球供需）：
https://pubs.usgs.gov/periodicals/mcs2026/mcs2026-soda-ash.pdf
```

口径提醒：Comtrade 的 `netWgt` 为净重（kg），部分国家不报；`primaryValue` 进口为 CIF。跨年比较要在报告中说明这些字段是否缺失。

## 5. 证据写法示例（可直接套用）

- **A**：“公司 2025 年度报告《Laporan Tahunan & Keberlanjutan 2025》‘Penggunaan Material’ 表列明 Soda Ash 136,904 吨（2025）、137,671 吨（2024）、145,551 吨（2023），报告未区分轻重质。”（产品：纯碱；方向：终端消耗；期间：2023–2025）
- **B**：“官网产品页将 Soda Ash Dense（ex ANSAC USA）列为在售品，规格 99.31%，堆密度 1.05 g/cm³，50 kg 袋，服务玻璃/洗涤剂/水处理客户。”（产品：重质纯碱；方向：经营；期间：网页抓取日）
- **C**：“行业名录显示其为玻璃瓶制造商，产线含熔窑；未见任何纯碱相关公开信息。”（行业：玻璃；证据：无产品层）
