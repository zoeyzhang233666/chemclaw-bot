# 客户类型识别：终端生产企业 / 直接进口商 / 经销商

外贸新人最常见的错误是“把经销商当终端，把终端当经销商”，导致报价口径错误、丢掉价格空间或泄露客户。

---

## 1. 三类主体的判定信号

| 信号 | 终端生产企业 | 直接进口商 | 经销商（是否自营进口不确定） |
|---|---|---|---|
| 官网内容 | 产品是成品（玻璃/洗涤剂），有工厂、生产线、产能 | 贸易公司，列明进口、仓储、报关 | 列“分销/批发/供应”，可能有仓储 |
| 名称 | 多为 `PT <品牌> <制造词>`，制造词如 Glass、Industri、Pabrik | 含 `Niaga`、`Perdagangan`、`Trading`、`Import` | 含 `Distributor`、`Supplier`、`Kimia` |
| 采购动机 | 生产自用，量大、稳定、重规格 | 价差与库存周转 | 价差 + 下游客情 |
| 常见证据 | 年报材料表、环评原料表、产能公告 | 进口记录、港口仓库、LARTAS 许可 | 产品目录、询价表 |
| 谈判抓手 | 总成本、批次稳定、供应连续 | CIF/DAP、付款方式、拼柜 | 起订量、账期、区域独家 |

## 2. 必须区分的四种“伪终端”

1. **品牌商（brand owner）**：只做配方与市场，生产外包给代工厂。真正买原料的是代工厂。
2. **灌装/分装商**：买浓缩液或成品再分装，不一定买原料。
3. **集团贸易子公司**：名字像工厂，实际做集团内部贸易；采购主体在别处。
4. **设备/工程公司**：项目中代为采购，不是重复采购客户。

## 3. 对进口商的追问清单（一次问清）

- 你们是自营进口（API-U）还是代进口？年清关量多少？
- 常做的品名与年进口量（吨）？轻/重形态各多少？
- 主要港口（Jakarta/Surabaya/Belawan/Medan）与仓储能力？
- 现有供应商国别结构？是否有切换意愿与切换条件？
- 账期、付款方式（T/T、L/C）、是否接受拼柜？
- 下游主要客户行业（玻璃/洗涤/水处理）与区域？

## 4. 对终端工厂的追问清单

- 年用量、月均消耗、安全库存天数？
- 用的是重质还是轻质？Fe、SO₄、堆密度限值？
- 现有合同：来源国、合同期、年度框架、价格公式？
- 供应商准入流程（样品→小试→中试→量产）要多久？
- 集团是否集中采购（总部/合资方审批）？
- 包装与卸料方式（袋装/吨袋/散装、行车/气力输送）？

## 5. 报告呈现规则

- 每条线索只给一个 `type`，无法判断写 `待确认`，并在 `why_related` 写两种假设。
- HTML 报告提供“终端工厂 / 直接进口商 / 经销商”三档筛选，避免混读。
- Excel 的“客户类型”列与“买方角色”列分开：前者是主体属性，后者是它在链条里的位置。
