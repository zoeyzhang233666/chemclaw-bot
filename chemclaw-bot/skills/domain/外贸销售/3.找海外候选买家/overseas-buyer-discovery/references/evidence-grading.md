# 证据分级：判定表、反例与打分

本文件是 `SKILL.md` §1 的展开。所有候选企业必须被打上 **A / B / C / 未核实** 之一，并附至少一条可点开的链接（未核实的除外）。

---

## 1. 三级定义（逐字判定，不看“感觉”）

| 等级 | 必须同时满足 | 典型来源 | 常见误判 |
|---|---|---|---|
| **A 有直接贸易证据** | ①指向**该企业主体**（而非集团其他公司）②该产品（或明确同类品）③出现**采购/进口/消耗**动作 ④能给出期间 | 年报“使用材料”表（吨）、进口报关记录、供应商案例研究、政府公示的进口/环评文件、招投标中标公告 | 把“行业进口统计”算成企业证据；把“产品目录”算成交易 |
| **B 有产品或业务相关证据** | ①企业真实存在且有官网/工商/年报可核 ②业务与该产品强相关：产品目录列明、工艺必然消耗、配方出现该品 ③**无**交易记录 | 官网产品页、公司简介、工艺流程图、配方表、许可证 | 把“只要是玻璃厂就必然买纯碱”当作 B（那是 C）；把第三方目录页当作 B 的唯一依据 |
| **C 仅根据行业关系推断** | 只能证明其属于相关行业 | 行业名录、协会会员、新闻提及 | 把 C 级直接写进报价单或“已确认客户” |
| **未核实** | 连“企业是否存在”都没拿到一手来源 | 无 | 编一个像样的官网域名填进去（严重后果：销售点进去是别的站，整张表作废） |

**A 级判定的三个陷阱**

1. **集团 vs 主体**：控股公司年报里的用量属于生产子公司，采购主体多半也是子公司，联系与询价对象应为子公司（例：Mulia Industrindo → PT Muliaglass）。
2. **形态不匹配**：年报写 `Soda Ash` 通常不分轻重质。玻璃窑用重质、洗涤剂多用轻质。A 级证据证明“在用该品”，不等于“在用你的规格”，须在“待验证问题”里列出。
3. **期间过期**：A 级证据超过 18 个月，只能降为“B（历史 A 级）”，除非找到更新披露。

## 2. 证据类型 → 可支撑的最高等级

| 证据类型 | 最高可支撑 | 备注 |
|---|---|---|
| 公司年报/可持续报告“材料使用”表（含吨数） | A | 需注明报告年度与页码 |
| 进口报关明细（企业级，付费库可见部分） | A | 必须写明数据库名、可见字段、期间 |
| 政府采购/招标结果（该企业中标该品） | A | 注意“中标”≠“长期用量” |
| 环评/许可文件列明原料与用量 | A | 中国最常见 |
| 供应商案例/客户名录（该企业作为客户出现） | A（弱） | 需二次验证；供应商自营网页可信度中等 |
| 官网产品目录列明该品 | B | 分销商算 B；生产商目录列明该品算“同行”，走 peer gate |
| 工艺必然消耗（浮法玻璃熔窑、水玻璃熔融窑） | B（工艺） | 需写明工艺环节，否则降 C |
| 配方表/原料清单出现该品 | B | 与规格匹配度挂钩 |
| 行业名录/协会会员/展会名录 | C | 只作线索来源 |
| 新闻报道“该行业进口了多少” | 企业证据不足 | 归入市场事实，不进企业证据 |

## 3. 反例库（真实任务中出现过的错误）

| 错误 | 为什么错 | 正确做法 |
|---|---|---|
| 把印度化工贸易站（声称“印尼最大纯碱分销商”）写进印尼客户池 | 主体在境外，是同行/竞品渠道 | 判 peer/竞品渠道，另列 |
| 把“印尼进口 84 万吨/年”写进某玻璃厂的证据 | 国家数据 ≠ 企业采购 | 企业证据必须指向企业 |
| 把 Bukalapak/Tokopedia 个人卖家写成经销商 | 无法确认企业主体 | 仅保留有 PT 名称与官网的主体 |
| 把行业展会名录里出现的公司写“有直接贸易证据” | 名录不能证明交易 | 降为 C，补官网核实 |
| 为了“内容完整”给每个字段填满 | 编造细节比留空伤害更大 | 缺就是缺，写“未取得” |
| 记录董事长/采购经理姓名和手机 | 隐私与合规风险 | 只写企业总机/企业邮箱/表单 |

## 4. 打分与排序

**线索分 = 用量强度分 × 证据等级分 × 可信度分**

| 维度 | 取值 |
|---|---|
| 用量强度 | ★★★★★=5，★★★★=4，★★★=3，★★=2，★=1，渠道型=3（按可覆盖下游用量计） |
| 证据等级 | A=1.0，B=0.7，C=0.4，未核实=0 |
| 可信度 | 高=1.0，中=0.85，低=0.6 |

bucket：

- 分 ≥ 4.0 → **P1 立即**（A 级大用量客户或覆盖多下游的进口商）
- 2.5–4.0 → **P2 本周**
- 1.5–2.5 → **P3 两周内**
- < 1.5 → **P4 观察**（仅电话核实）

**永远不要用分数替代等级**：分数用于排先后，等级用于决定“能不能报价”。
