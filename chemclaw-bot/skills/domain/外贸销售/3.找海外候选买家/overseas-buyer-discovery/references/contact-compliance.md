# 联系方式与合规：只记录“企业级、公开、可追溯”的渠道

---

## 1. 允许记录

| 渠道 | 条件 | 备注 |
|---|---|---|
| 官网 URL | 已抓取确认可打开 | 首选 |
| 企业总机/客服电话 | 官网或正式年报公布 | 上市公司常在年报“公司地址”处公布 |
| 企业邮箱 | `info@ / sales@ / marketing@ / export@ / ir@ / corsec@` 等职能邮箱 | 需记录出现在哪个页面 |
| 官网联系表单 | URL 记录 | 印尼企业常用 WhatsApp 商务号，属企业级可用 |
| 官方社交账号 | 企业认证账号 | 只记录账号名，不记录个人 |

## 2. 禁止记录

- 任何自然人姓名 + 其个人电话/邮箱/LinkedIn。
- 从第三方数据商“猜”出来的地址（`firstname.lastname@`）。
- 未标注来源的 WhatsApp 个人号。

## 3. 个人数据最小化（GDPR/PDPA 精神）

- 只保存“做业务联系所必需”的企业渠道；
- 不保存与询价无关的敏感信息（出生日期、住址、健康等）；
- 线索表以“公司”为主键，联系人为空或只写“采购部/公司秘书”这类职能描述。

## 4. 首次接触的合规礼貌点

- 首封邮件写明身份、目的、与对方相关的具体理由，并给退出方式（“如不希望再收到邮件请回复退订”）。
- 不在首封邮件附大附件（易被拦），用链接或简述。
- 不要在同一封邮件里同时报价+要客户名单；分两步。
- 印尼多为非工作时间回复，跟进节奏按 WIB（UTC+7）安排。

## 5. 记录字段

```json
"contact_struct": {
  "website": "https://…",
  "phone": "+62 21 …",
  "email": "corsec@… 或 '官网表单: https://…/contact'",
  "address": "…",
  "social": "官方号名称",
  "note": "上市公司经公司秘书/投资者关系渠道；采购联系需电话总机转接",
  "verified_on": "2026-10-19"
}
```

`note` 字段必填，用来告诉后同事“这个渠道适合什么、不适合什么”。
