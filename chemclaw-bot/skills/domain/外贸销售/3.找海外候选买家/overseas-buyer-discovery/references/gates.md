# 五道质量闸（Quality Gates）

合并后的每条线索都要过闸；不过闸的要么修，要么降级，要么删。

---

## Gate 1 · 链接可达（Link Gate）

- 逐条 `HTTP GET`（不是只看记忆里的 URL），记录状态码与标题。
- **可达**：2xx/3xx 且页面标题/正文含公司名或产品词。
- **反爬拦截**（403/429/验证码页）：标注“建议人工复核”，**不算坏链**，但也不能因此提升证据等级。
- **真空页/跳错站/域名待售**：视为坏链 → 该条的来源改为 `未核实`、等级降为 C。
- 抽样规则：≥40 条链接或全部链接的 30%（取大者），逐一填 `link_status`。

## Gate 2 · 主体一致（Entity Gate）

- 网页标题/抬头/“关于我们”里的公司名，与线索名**归一化后**必须匹配（去掉 PT/PT./Ltd/Co., Ltd/Tbk/Inc.）。
- 名字相似但地址/业务不同 → 判为不同主体，另开条目，并在 `alt_names` 注明易混对象。
- 集团与子公司混用 → 在 `buyer_entity` 字段写清楚“采购/联系主体”。

## Gate 3 · 等级与证据类型匹配（Tier Gate）

对照 `evidence-grading.md` §2 的“证据类型 → 最高等级”表：

- 目录页写 A = 违规；
- 行业推断写 A 或 B = 违规；
- 国家统计数据写进企业证据 = 违规。

修复：降级并补一条更弱但真实的描述（“该企业属于玻璃业，工艺必然消耗纯碱，未见公开采购证据”= B/C 之界，按是否能证明工艺来判断）。

## Gate 4 · 联系方式合规（Contact Gate）

允许：官网 URL、企业总机/公开客服电话、企业邮箱（`info@`、`sales@`、`marketing@`、`ir@`、`corsec@`、官网表单 URL）、企业官方社交账号。

禁止：人名、个人手机、`@gmail` 等疑似个人邮箱（除非官网明确标为采购联系邮箱）、从第三方数据商“猜”的邮箱。

每条须填 `verified_on`（核验日期）与 `channel_note`（“官网联系表单；上市公司建议走投资者关系”）。

## Gate 5 · 可跟进性（Action Gate）

- 每条至少 2 个“还需验证的关键问题”，且必须是**可回答**的问题（是/否、数字、名单），不是“他们会不会买”。
- 每条至少 1 个“下一步动作”（打电话问什么、发什么资料、查什么文件）。

---

## 通过标准

一个 lane 的所有条目：

- Gate 1–5 全过，或
- 已降级为 C/未核实 且**明确写出原因**（“未取得一手来源，仅名录提及”）。

整份交付：

- A 级条目 100% 有产品+方向+期间；
- 未核实条目比例 < 20%；
- peer 剔除名单非空（除非该国确无本土生产者，须给出证据说明）。

---

## 报告里必须呈现的四个数字

| 指标 | 含义 |
|---|---|
| 候选数与分级分布 | A/B/C/未核实 各多少 |
| 类型分布 | 终端 / 直接进口商 / 经销商 / 待确认 |
| 覆盖 lane 数 | 与“应有 lane 数”对比，说明缺口 |
| 坏链与负结果数 | 抽检坏链、无法核实的行业、被剔除的同行 |
