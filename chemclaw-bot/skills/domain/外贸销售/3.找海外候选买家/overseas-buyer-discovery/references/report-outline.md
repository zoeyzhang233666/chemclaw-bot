# 报告结构模板（HTML + 结论文字）

HTML 报告用于“看与筛”，最终回答用于“读与决策”。两者结构一致，只是粒度不同。

---

## 一、HTML 报告固定章节

1. **Hero**：产品+规格+国家+目标客户类型+报告日期+候选数与分级摘要。
2. **KPI 卡**：A/B/C/未核实 计数；类型分布；同行剔除数。
3. **§0 怎么读**：三级定义、红线（不得当买家、不得编造、须复核）、**本次未获取的东西**。
4. **§1 市场背景**：进口额/量趋势图、来源国结构表、本国产能状态（有/无/在建）。
5. **§2 候选企业筛选器**：类型/等级/地区/业务领域筛选 + 关键词搜索；卡片展开含官网、业务、产品关联证据、证据链、公开联系方式、待验证问题；按钮：生成询证邮件、加入线索档案、复制线索卡片。
6. **§3 产业关联分析表**：每家为什么相关、相关到哪一层、用量线索。
7. **§4 进口商与经销商**：类型差异、首触点、常见误判。
8. **§5 Peer Gate**：被剔除的同行/未来产能/竞品渠道，附理由与证据。
9. **§6 待验证关键问题**：按“产品与工艺层 / 商务与合规层”分组，问题要可回答。
10. **§7 市场事实附录**：每条带来源链接与期间；注明口径。
11. **Footer**：生成时间、抓取时间、“全部为待验证线索”。

## 二、最终回答（对话里）的骨架

```
一、我做了什么（1 段：产品/国家/通道/规模）
二、结论先给（候选 N 家：A x / B y / C z；最值得先打的是哪 3 家，为什么）
三、A 级证据逐条（产品+方向+期间+链接）
四、B 级最有价值的 5 家 + 缺什么证据
五、渠道层（进口商/经销商）与打法
六、被剔除的同行与竞品渠道
七、未覆盖的缺口与负结果（哪些行业/哪类数据没拿到）
八、交付物路径与下一步建议
```

## 三、写作规范

- **不给“已确认买家”**：一律“候选”“线索”“待验证”。
- **每个数字带口径**：金额/数量/年份/来源（CIF、netWgt、HS 6 位）。
- **区分三种东西**：企业级直接证据 / 产品业务证据 / 行业推断——正文里用加粗标签标出来。
- **负结果要写**：查不到的公司、被封的通道、付费墙的数据，都写进“缺口”。
- **不写没有来源的形容词**（“行业龙头”“潜力巨大”）。

## 四、Excel 工作簿固定 8 表

| 工作表 | 内容 |
|---|---|
| 00_说明与证据规则 | 字段含义、A/B/C 判定、红线、更新规则 |
| 01_候选企业总表 | 编号、公司、类型、产品相关性、证据等级、证据要点、期间、用量、官网、联系、可信度、关联原因、首要核验问题、优先级 |
| 02_证据明细 | 每条证据一行：等级、类型、来源、链接、期间、原文要点、可作为什么用、局限 |
| 03_公开联系方式 | 官网、总机、企业邮箱/表单、地址、核验日期（无个人数据） |
| 04_后市核验清单 | 每家多条待验证问题 + 渠道 + 优先级 |
| 05_行业与需求地图 | 下游行业、作用、工序位置、用量强度、集群、本次线索数 |
| 06_进口与需求数据 | HS 编码进出口序列 + 来源国结构 + 口径说明 |
| 07_排除与同业 | peer gate 结果与理由 |
| 08_话术与询盘草稿 | 按类型/等级的英文首触点草稿 + 禁止表述 + 跟进动作 |
