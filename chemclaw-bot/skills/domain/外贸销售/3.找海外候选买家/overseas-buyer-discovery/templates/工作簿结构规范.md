# 工作簿结构规范（11 个表）

Excel 线索工作簿是这次交付里**唯一能被当作资产长期使用**的东西。报告是给老板看的，工作簿是给业务员用的。所以结构必须固定、字段必须齐全。

---

## 表清单与顺序

| # | 表名 | 作用 | 行数（印尼案例） |
|---|---|---|---|
| 00 | 说明与证据规则 | 首页。谁做的、什么时候、什么口径、三级定义、红线 | 24 |
| 01 | 候选企业总表 | 主表。一家一行，可筛选排序 | 50 |
| 02 | 证据明细 | 一条证据一行。**一家企业可对应多行** | 101 |
| 03 | 公开联系方式 | 单独一张表，便于直接打电话时只开这一页 | 50 |
| 04 | 后市核验清单 | 每条线索 × 每个必问问题，一行一问答位 | 165+ |
| 05 | 行业与需求地图 | 下游行业 × 用量强度 × 代表企业 × 进入难度 | 12 |
| 06 | 进口与需求数据 | 海关统计、来源国结构、价格趋势 | 15 |
| 07 | 排除与同业 | peer gate 结果，附理由与来源链接 | 20 |
| 08 | 话术与询盘草稿 | 三类客户的英文邮件模板 + 首触话术 | 6 |
| 09 | 产业时间线 | 该市场供给端的关键事件（谁在建产能、何时投产） | 5 |
| 10 | 我的跟进档案 | **空白模板**，业务员自己填 | 1 |

## 01_候选企业总表 · 字段定义

| 列 | 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|---|
| A | 编号 | int | ✅ | 稳定 ID，报告里同号 |
| B | 企业名称 | str | ✅ | 用法定代表人实体名，含 PT/CV 前缀 |
| C | 其他名称 | str | | 集团名、品牌名、曾用名、子公司 |
| D | 客户类型 | enum | ✅ | 终端生产企业 / 直接进口商 / 经销商 / 待确认 |
| E | 证据等级 | enum | ✅ | A / B / C |
| F | 置信度 | enum | ✅ | 高 / 中 / 低 |
| G | 地区 | str | ✅ | 省 + 城市，印尼用英文省名（Jawa Barat 等） |
| H | 业务领域 | str | ✅ | 玻璃制造 / 洗涤剂日化 / 水玻璃 / 造纸 / 纺织陶瓷 / 化工分销 |
| I | 主营业务 | str | ✅ | 一句话说清它靠什么赚钱 |
| J | 产品相关性 | str | ✅ | **为什么这个产品与它有关**——这一列是名单的灵魂 |
| K | 证据摘要 | str | ✅ | 最有力的一条证据，含具体数字 |
| L | 证据期间 | str | | 年份或"未显示" |
| M | 用量线索 | str | | 有就用，没有留空，**不要估算** |
| N | 官网 | url | | |
| O | 公开联系方式 | str | | 企业级：总机/企业邮箱/地址 |
| P | 建议核验路径 | str | | 先找谁、再问什么 |
| Q | 还需验证的问题 | str | | 分号分隔，3–5 条 |
| R | 是否同行/竞品 | bool | ✅ | peer gate 结论，应为 False |

**格式要求：** 首行冻结、自动筛选、表头深蓝底白字、A 列窄、I/J/K 列宽 40–60 并自动换行。

## 02_证据明细 · 字段定义

| 列 | 字段 | 说明 |
|---|---|---|
| A | 编号 | 对应 01 表的编号 |
| B | 企业名称 | |
| C | 证据等级 | 单条证据自己的等级（可能低于企业总等级） |
| D | 证据类型 | 企业年报 / 交易所披露 / 官方统计 / 第三方贸易数据 / 企业官网 / 行业目录 / 政府公告 |
| E | 来源名称 | 机构名 + 文件类型 |
| F | 链接 | **必填**，可点击 |
| G | 期间 | 数据对应的年份或"未显示" |
| H | 原文引用 | 尽量逐字，含关键数字 |
| I | 可以用来证明什么 | 这条证据能支撑到哪一步 |
| J | 局限 | 这条证据**做不到什么**（无日期/脱敏/单笔/样品等） |

> **J 列是专业度的分水岭。** 没有 J 列的名单，看不出是"核实过"还是"搜到的"。

## 04_后市核验清单 · 字段定义

| 列 | 字段 |
|---|---|
| A | 编号 |
| B | 企业名称 |
| C | 问题类别（采购规模 / 品质规格 / 合规准入 / 商务交付） |
| D | 问题 |
| E | 客户回答（**留空待填**） |
| F | 核实状态（未问 / 已确认 / 存疑） |

生成规则：每家企业 × 每题类别 1–3 问。这样业务员打完一个电话就能填满一家企业的一整段。

## 06_进口与需求数据 · 字段定义

| 列 | 字段 | 说明 |
|---|---|---|
| A | 指标 | |
| B | 期间 | |
| C | 数值 | 数字，不加单位 |
| D | 单位 | |
| E | 口径说明 | CIF/FOB、净重/毛重、HS 版本等 |
| F | 置信度 | 高/中/低 |
| G | 来源 | 机构名 |
| H | 链接 | |
| I | 备注 | |

**铁律：** 一个数字一行，单位和口径各自占列。**不要把"2.26 亿美元（844 千吨）"塞进一个单元格**——那样以后没法做透视表。

## 07_排除与同业 · 字段定义

| 列 | 字段 |
|---|---|
| A | 企业 |
| B | 角色（同行 / 未来产能 / 竞品 / 竞品渠道 / 待定） |
| C | 判定（排除 / 保留候选 / 待定） |
| D | 理由（为什么会误判成客户，以及真相） |
| E | 来源链接 |

> 这张表的价值常常高于主表：它防止销售在半年后把同一个"假客户"重新挖出来。

## 样式规范

```python
HDR_FILL = PatternFill("solid", fgColor="0B5A96")   # 深蓝
HDR_FONT = Font(color="FFFFFF", bold=True, size=10.5, name="Microsoft YaHei")
BODY_FONT = Font(size=10, name="Microsoft YaHei")
# 证据等级用色：A=#12864B(绿) B=#B8800B(琥珀) C=#6B7280(灰)
```

- 全部工作表：`freeze_panes = "A2"`、`auto_filter.ref` 覆盖表头到最后一行
- 长文本列设 `wrap_text=True`
- 表名用中文 + 两位数字前缀，保证排序稳定
- 不要合并单元格（会破坏筛选）

## 生成方式

工作簿必须由脚本生成，不能手搓。参考 `scripts/build_xlsx.py`：

```
build_xlsx.py  <输出路径.xlsx>
输入（同目录）：
  leads_merged.json          必填  归一化后的线索
  comtrade_*.json            可选  进口统计
  peer_gate.json             可选  排除清单
  market_facts.json          可选  市场事实
```

脚本要能**重复运行**：改完 JSON 重跑，工作簿整体重建，不追加、不残留。
