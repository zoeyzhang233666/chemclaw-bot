# 贸易术语与付款方式核验要点

只列**审阅时会用到的判据**，不复制规则原文。
凡标 `[需核实]` 的，不得作为确定性结论写进报告。

## 1. Incoterms® 2020 十一个术语：谁干什么

| 术语 | 适用运输 | 风险转移 | 出口清关 | 主运费 | 保险 | 进口清关 |
|---|---|---|---|---|---|---|
| EXW | 任意 | 货物置于买方处置时（卖方场所） | **买方** | 买方 | 买方 | 买方 |
| FCA | 任意 | 交给买方指定承运人时 | 卖方 | 买方 | 买方 | 买方 |
| CPT | 任意 | 交给承运人时 | 卖方 | **卖方** | 买方 | 买方 |
| CIP | 任意 | 交给承运人时 | 卖方 | 卖方 | **卖方（ICC A）** | 买方 |
| DAP | 任意 | 到达目的地、可卸货时 | 卖方 | 卖方 | 买方 | 买方 |
| DPU | 任意 | 到达目的地、**卸货后** | 卖方 | 卖方 | 买方 | 买方 |
| FAS | 水运 | 置于装运港船边 | 卖方 | 买方 | 买方 | 买方 |
| FOB | 水运 | **装上船时** | 卖方 | 买方 | 买方 | 买方 |
| CFR | 水运 | **装上船时** | 卖方 | **卖方** | 买方 | 买方 |
| CIF | 水运 | **装上船时** | 卖方 | 卖方 | **卖方（ICC C）** | 买方 |
| DDP | 任意 | 到达目的地、可卸货时 | 卖方 | 卖方 | 卖方 | **卖方** |

**最常被搞错的三件事**

1. **CIF/CFR 的风险不在目的港。** 风险在装运港装船时转移；
   卖方之所以要订舱到目的港，是**费用与运输安排义务**，不是风险承担。
   看到合同写「CIF 下卖方承担至目的港的一切风险」——写错了，或是刻意加重卖方。
2. **CIF 的最低保险是 ICC(C)，不是 ICC(A)。** 2020 版把 CIP 提到 (A)，
   但 **CIF 仍维持 (C)**。合同若写「CIF 含一切险」就与规则不一致，须以合同为准并注明差异。
3. **DAP 不含卸货；DPU 含卸货。** 两者常被混用。

**审阅时必查的四点**

- [ ] 术语是否带**地点**（`CIF Jakarta` 而不是 `CIF`）
- [ ] 是否带**版本**（`Incoterms® 2020`）
- [ ] 正文、PI、信用证、提单、保单的术语表述是否**完全一致**
- [ ] 是否出现「同一术语、多版本并存」的条款（参见 clause-library B1）

**保险保额**

- 通行商业做法是发票金额的 **110%**。
- `[需核实]` 这一比例在 Incoterms 2020 规则文本中的具体表述与强制程度，
  未取得一手文本核对，**报告中应写成「通行做法」而非「规则要求」**。
- 币种应与合同币种一致；保单受益人/索赔地须能实际操作。

## 2. 付款方式核验要点

### T/T 预付
- 比例与时点（签约后 N 天 / 开票后 N 天）
- 预付是否可退、退还条件
- 是否需预付款保函

### T/T 见提单副本
- 「副本」的定义（扫描件？加盖船代章？）
- 放单条件与放单人的义务
- 与物权凭证的衔接：**谁持有正本提单**

### L/C（最需要细看）

| 项目 | 要确认什么 |
|---|---|
| 开证行 | 资信等级；是否需保兑 |
| 开证时限 | 相对什么事件起算（**不是绝对日期**） |
| 类型 | 不可撤销？可转让？可循环？ |
| 效期与交单期 | 装运后多少天交单 |
| 单据清单 | 是否与合同附件逐项一致 |
| 分批/转运 | 是否允许（与合同第 5 条是否一致） |
| 软条款 | 「须买方出具检验证书」「须申请人确认后付款」——**高危** |
| 费用 | 开证费、修改费、不符点费由谁承担 |
| 适用规则 | UCP600 / eUCP / ISBP |

**最常见的拒付原因**：单据与信用证描述不一致（措辞、数量、日期）。
审阅时要做的不是背 UCP，而是**确认合同项下的单据清单能被真实开出来**。

### D/P、D/A、赊销（O/A）
- 是否有信用保险（中信保等）
- 是否有额度上限与账期管理条款
- 逾期救济是否被放弃（参见 clause-library A2）

## 3. 卖方/买方视角的快速对照

| 条款主题 | 作为**卖方**要争什么 | 作为**买方**要争什么 |
|---|---|---|
| 检验 | 装运港第三方检验为初步依据，留样封存 | 目的港独立检验为最终依据 |
| 异议期 | 短而明确 | 覆盖航程 + 卸货 + 合理检验期 |
| 交期延误 | 免责事由明确、违约金有上限 | 违约金比例足够、有解除权 |
| 付款 | 预付 + 不可撤销信用证，逾期可中止与扣单 | 与验收挂钩，保留质保金 |
| 责任上限 | 封顶且对等 | 不封顶或封顶于合同金额以上 |
| 风险 | 装运港转移，保险覆盖 | 到港验收后转移 |
| 争议解决 | 中国机构、中文、中国法 | 中立地或本国 |
| 不可抗力 | 定义宽、通知期宽松 | 定义窄、须官方证明、超期可解约 |

> 报告必须**先声明我方身份**，否则上面每一行都可能被读反。

## 4. 术语选择与合规的交叉风险

| 场景 | 风险点 |
|---|---|
| EXW 出口 | 出口报关与出口退税资料在买方手上，卖方拿不到退税凭证 |
| DDP 进口国 | 卖方要承担目的国进口清关与税费，通常无当地资质 |
| FOB 由买方指定船公司 | 卖方失去对船期与提单的控制 |
| CIF 但买方指定保险公司 | 保单受益人/索赔地可能不利于卖方 |
| DAP 到内陆点 | 目的国内陆运输风险与费用被低估 |
| 危险货物 + 任意术语 | 危申报责任必须单独约定，术语本身不解决 |

## 5. 一张自检表

拿这张表过合同：

- [ ] 术语 = 三要素齐全（术语 + 地点 + 版本）
- [ ] 全链条单据术语一致
- [ ] 风险转移点与术语一致
- [ ] 保险：险别、保额、币种、受益人、索赔地
- [ ] 付款节点都以**可确定的事件**起算
- [ ] L/C 单据清单可实际开出
- [ ] 逾期付款有除利息外的救济
- [ ] 交货延误的后果（违约金/解除）双方对等
- [ ] 检验机构、地点、时点、效力四要素齐全
- [ ] 危险货物申报责任有明确分配
