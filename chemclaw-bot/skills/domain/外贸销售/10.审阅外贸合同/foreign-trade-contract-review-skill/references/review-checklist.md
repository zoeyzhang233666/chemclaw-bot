# 外贸合同审阅清单（11 类）

按顺序逐类过。每类下面的「必查项」是**至少要回答一句**的问题；
「高频问题」是实践中反复出现的坑，可直接作为检查点。

> 用法：把本清单当**核对表**，不是模板。合同里没有的，标记为「缺失」；
> 合同里有但表述含糊的，标记为「表述不清」。不要为了填满表格而虚构条款。

---

## 1. 主体与签署

**必查项**

- [ ] 双方全称、注册地址、注册号（中国：统一社会信用代码；印尼：NIB + NPWP；其他国：当地注册号）
- [ ] 签字人姓名、职务，以及**授权证明**（董事会决议 / 授权书）
- [ ] 签署日期是否填写（留空会导致交期、信用证起算点无法确定）
- [ ] 公司印章是否清晰可辨
- [ ] 合同生效条件（签字生效？盖章生效？开证生效？）
- [ ] 是否存在代理人（agent）签署，代理权限是否明确

**高频问题**

| 问题 | 后果 |
|---|---|
| 签署页日期留空 | 交期、有效期、诉讼时效起算全无依据 |
| 无授权证明 | 对方事后可主张「无权代表公司签约」 |
| 只写英文名未写注册地 | 主体识别困难，影响送达与执行 |
| 生效条件未约定 | 一方认为已生效、一方认为未生效 |

---

## 2. 产品描述、规格与质量

**必查项**

- [ ] 产品名称（中/英文）、品牌、型号/等级
- [ ] HS 编码（双方是否一致？与目的国税则是否一致？）
- [ ] 规格表：**每一项**参数的限值 + 单位 + **测试方法及版本**
- [ ] 质量标准（国标 / 行标 / 合同附件 / 双方签署的技术协议）
- [ ] 取样方法、留样（retained sample）数量与保管方
- [ ] 是否与目的国强制性标准（如印尼 SNI）挂钩；挂的是哪个标准号与版本
- [ ] 规格是否可能被单方变更；变更是否需要双方书面确认

**高频问题**

| 问题 | 后果 |
|---|---|
| 只写限值不写测试方法 | 双方各按各的方法测，结果不同无法裁决 |
| 引用标准号无版本 | 新旧版本指标不同 |
| 「并入买方另行通知的要求」 | 质量标准无边界，事后可被任意加码 |
| 「规格可随时变更」 | 合格与否无法客观判定 |

> 化工品特别注意：堆积密度、粒径分布（筛网孔径与精度）、含水量、杂质限值，
> 这些参数换方法差异极大，**必须锁方法**。

---

## 3. 数量、计量单位与溢短装

**必查项**

- [ ] 合同数量、单位（MT / kg / 包数）、每件净重
- [ ] 溢短装（±%）是谁的权利、谁承担运费差额
- [ ] 计量口径：净重 / 毛重 / 干基 / 湿基；以谁的计量为准（装运港 or 目的港）
- [ ] 数量与金额的换算基准（溢装部分是否同价）
- [ ] 分批装运时各批数量是否单独约定

**高频问题**

| 问题 | 后果 |
|---|---|
| 「数量为估算，卖方可在 ±10% 内装运」但没约定运费谁付 | 溢装运费争议 |
| 以卖方磅单为准且不可复核 | 短重索赔无据 |
| 干基/湿基混用 | 结算重量差异，化工品尤其明显 |

---

## 4. 价格、币种与贸易术语

**必查项**

- [ ] 单价、总价、大写金额是否一致
- [ ] 币种；是否允许以其他货币支付；折算汇率与取数来源
- [ ] 价格固定还是可调；含税/不含税
- [ ] 贸易术语：**完整表述 = 术语 + 地点 + Incoterms 版本**（例：`CIF Jakarta Incoterms® 2020`）
- [ ] 价格包含哪些费用（内陆、报关、包装、订舱、保险、目的港费用）
- [ ] 全链条单据（PI、合同、信用证、提单、保单）的术语表述是否一致

**高频问题**

| 问题 | 后果 |
|---|---|
| 只写 `CIF Jakarta` 不写版本 | 2010 与 2020 规则差异被放大 |
| 正文一句话允许「其他单据引用其他版本」 | 同一批货受两个版本约束 |
| 术语与装运港条款打架（CIF 却又强调只在装运港交货） | 到岸义务被实质削弱 |
| 允许对方货币支付且汇率由对方银行定 | 汇率风险与执行风险双转移 |

详见 `incoterms-and-payment.md`。

---

## 5. 付款方式、节点与信用证条件

**必查项**

- [ ] 付款方式：T/T 预付 / T/T 见提单副本 / L/C / D/P / D/A / 赊销
- [ ] 各节点金额与比例、时间点（相对什么事件起算）
- [ ] L/C：开证行、开证日、有效期、交单期、可撤销/不可撤销、保兑、可转让、分批装运
- [ ] 单据清单是否与合同附件一致
- [ ] 不符点如何处理；议付行/开证行责任
- [ ] 逾期付款：利率、计息基数、**是否有其他救济**（中止履行、扣单、解约）

**高频问题**

| 问题 | 后果 |
|---|---|
| 开证日早于合同签署日 | 付款前提客观不可履行，交期起算点失效 |
| 逾期仅按低息计息 + 放弃一切其他救济 | 货物出运后无任何杠杆 |
| 信用证单据与合同条款不一致 | 交单不符点，遭拒付 |
| 放单依赖对方银行，卖方全链条免责 | 滞箱费/堆存费无人承担 |

---

## 6. 交货期、装运港、目的港、分批与转运

**必查项**

- [ ] 装运期（起止日）、起算事件
- [ ] 装运港、目的港（含具体码头）
- [ ] 分批装运 / 转运：是否允许、谁决定
- [ ] 装船通知：时间、内容（船名、航次、ETN/ETA、提单号）
- [ ] 卸货与提货时限；超期费用承担
- [ ] 延误的后果（违约金？解除权？）
- [ ] 是否允许合并装运（与其他买家同船）

**高频问题**

| 问题 | 后果 |
|---|---|
| 「延误可在卖方指定期限内延展」 | 条款被认为失衡而排除，反落回一般违约 |
| 装运通知只要求提单副本 | 对方无法安排清关，反过来主张配合义务违约 |
| 允许合拼提单但无分票约定 | 一方被查验全船滞港 |

---

## 7. 检验、质量异议与索赔

**必查项**

- [ ] 检验机构（第三方？哪家？谁指定？谁付费？）
- [ ] 检验地点与时间点（装运港装船前 / 目的港卸货后）
- [ ] 检验报告的效力：最终？初步？可否被推翻
- [ ] 异议期限：从什么事件起算（提单日 / 到港日 / 卸货日），**是否短于运输周期**
- [ ] 索赔程序：通知形式、所需单据、举证责任
- [ ] 救济方式：降价 / 换货 / 退货 / 解约 / 损害赔偿
- [ ] 隐蔽瑕疵是否例外

**高频问题**

| 问题 | 后果 |
|---|---|
| 以卖方自有实验室报告为最终依据 + 禁止买方检验 | 举证链断裂，双方都无法自证 |
| 异议期 7 天但航程 3 周 | 买方客观上无法检验，条款面临被排除 |
| 卖方要求买方证明「装船时即不符」，却禁止装船前检验 | 逻辑上不可能完成的举证 |
| 检验费「一律由买方承担」 | 结果支持买方时仍自担成本 |

---

## 8. 风险转移、所有权与保险

**必查项**

- [ ] 风险转移点（与贸易术语一致？）
- [ ] 所有权转移点（付款完成？交货？）
- [ ] 所有权保留能否在对方国家执行；是否需要登记
- [ ] 保险：谁投保、投给谁、险别（ICC A/B/C）、保额（通常 110%）、免赔
- [ ] 保单币种与合同币种是否一致
- [ ] 索赔对象：保险人 / 承运人 / 卖方
- [ ] 产品责任险是否覆盖（尤其化工品）

**高频问题**

| 问题 | 后果 |
|---|---|
| 风险在装船转移，所有权保留到付款 | 若买方破产，取回货物可能因未公示而失败 |
| 保额只有 100% | 低于 CIF 常见最低要求（110%） |
| 只投 ICC(C) 却以为「全险」 | (C) 只保列明风险，货损常不赔 |
| 声明「所有权保留对所有第三人有效、优先于其他债权人」 | 涉及对方国家物权/破产法，合同自说无效 |

---

## 9. 违约责任、赔偿范围与责任限制

**必查项**

- [ ] 违约情形与对应责任（逐项）
- [ ] 责任上限：按什么基数、是否有例外（故意/重大过失/人身伤亡/知识产权）
- [ ] 是否排除间接损失、利润损失、商誉损失
- [ ] 违约金：比例、上限、与实际损失的关系
- [ ] 双方责任是否对等
- [ ] 是否有履约保证（预付款、保函、母公司担保）

**高频问题**

| 问题 | 后果 |
|---|---|
| 卖方封顶 5%，买方无限 | 上限过低可能被整体否定，敞口反而更大 |
| 排除一切默示保证，且无明示质量保证 | 卖方也失去了「已按标准履约」的抗辩依据 |
| 违约金过低（因而不具约束力） | 违约无成本 |
| 无任何履约担保 | 胜诉≠拿得到钱 |

---

## 10. 不可抗力、适用法律与争议解决

**必查项**

- [ ] 不可抗力定义（是否开放式）、通知义务与时限、证明文件
- [ ] 持续多久可解除
- [ ] 是否设「艰难情势（hardship）」调价条款——**通常是单方有利的高危条款**
- [ ] 适用法律
- [ ] 是否排除 CISG（先确认两国是否缔约国，再决定这句有无意义）
- [ ] 争议解决：协商前置？天数？起算点？
- [ ] 仲裁：机构、仲裁地、语言、仲裁员人数与指定方式
- [ ] 裁决执行的可行性（对方国家是否纽约公约缔约国、有无保留）
- [ ] 是否同时约定法院管辖（与仲裁冲突）
- [ ] 争议期间付款与货物保全安排

**高频问题**

| 问题 | 后果 |
|---|---|
| 仲裁机构/仲裁地/语言全部单边指向一方 | 对方抗辩「显失公平」，裁决可能被拒承认 |
| 协商前置起算点不明 | 可被用作拖延与管辖权异议 |
| 合同同时有仲裁与法院专属管辖 | 并行程序、冲突裁决 |
| 单方「成本上涨 15% 即可重新议价，谈不成可无责解约」 | 实质是对方的价格选择权 |

---

## 11. 语言版本、效力与通用条款

**必查项**

- [ ] 合同语言；是否要求对方国家语言版本
- [ ] 多版本冲突时的优先版本
- [ ] 附件与正文的优先顺序
- [ ] 完整协议条款（是否排除此前 PI、LOI、邮件）
- [ ] 修改是否必须书面签署；**邮件是否构成签字**
- [ ] 转让限制
- [ ] 通知条款（地址、方式、生效时点）
- [ ] 保密、知识产权、数据保护
- [ ] 出口管制、经济制裁、反倾销合规

**高频问题**

| 问题 | 后果 |
|---|---|
| 只签英文版，对方国家要求本地语言 | 合同效力存疑（各国差异极大，需当地律师） |
| 「邮件即可构成签署」 | 与「修改须双方签字」自相矛盾 |
| 完整协议条款排除了关键 PI 技术附件 | 质量标准失去依据 |
| 无保密条款 | 价格与规格外泄 |

---

## 12. 危险化学品专章（仅当产品为危化品时）

> 先判断：**该产品在本合同项下是否属于危险货物/危险化学品？**
> 以 SDS 第 14 部分与适用的运输规则为准，**不要凭产品名称想当然**。
> 若不属于，本章可省略，但应在报告中说明「已核，不适用」。

**必查项**

- [ ] SDS：版本、语言、是否 16 部分、是否符合 GHS 版本
- [ ] 危险分类：UN 编号、正确运输名称、类别、包装类别
- [ ] 危包证 / 包装性能检验单（中国出口）
- [ ] 运输资质：承运人、船舶、堆场是否具备资质
- [ ] 运输单据：危申报（DGD / DG Declaration）、IMDG 申报
- [ ] 目的国准入：是否需登记、许可、通报（各国差异大）
- [ ] 标签：语言、象形图、警示语
- [ ] 责任分配：谁负责申报、谁承担申报错误后果
- [ ] 应急响应：泄漏/事故的联系人与处置责任

**高频问题**

| 问题 | 后果 |
|---|---|
| 合同「双方确认非危险货物」但无任何依据文件 | 申报不符可能被船公司索赔、港口处罚甚至拒载 |
| SDS 只提供英文，由买方翻译并「独自承担翻译错误后果」 | 事故后该免责很可能不成立 |
| 合同声明卖方对 SDS 内容不负责 | 明知风险而不作为 |
| 未约定危申报责任方 | 申报错误时互相推诿，船期损失 |

## 快速判据：这份合同最可能死在哪

按经验，外贸合同争议的排序大致是：

1. **质量标准与检验**（说不清什么是合格）
2. **付款条件**（说不清什么时候该付、不付怎么办）
3. **交期与风险**（说不清什么时候交货、路上出事谁担）
4. **争议解决**（赢了拿不到钱）

审阅时间有限时，先看完这四项再谈其他。
