# 关税与进口政策：怎么查、怎么标、怎么用

这份文件对应报告第 4 节“关税与政策”。它的目标不是把税号抄全，
而是让销售在报价前**清楚哪些数能用、哪些数必须再核一次**。

---

## 一、必查的六件事

| # | 项目 | 为什么影响成交 |
|---|---|---|
| 1 | MFN 基础税率 | 决定无优惠时的成本底线 |
| 2 | 自贸协定税率（ACFTA / RCEP / 双边） | 决定能否用原产地证打价格 |
| 3 | 其他税费（增值税、预缴所得税、消费税） | 进口商实际付出的现金，常常比关税大 |
| 4 | 非关税措施：许可、配额、检验、标准、标签 | 决定货能不能进、进多久 |
| 5 | 本地化含量（TKDN 之类） | 决定中国货在项目招标里还有没有位置 |
| 6 | 反倾销/反补贴/保障措施 | 一旦触发，价格优势瞬间归零 |

---

## 二、查法（按可信度排序）

### 1. 目标国官方税则库（唯一可作为报价依据）
- 印尼：**INSW**（insw.go.id）按 HS 查 MFN 与 FTA 税率，兼看 LARTAS（进口限制）标记；税则母法为 **BTKI**（2022 版起用 HS 2022）
- 印度：CBIC Customs Tariff
- 越南：Customs Vietnam / Decree 税则表
- 通用入口：WTO Tariff Analysis Online、各国海关官网

**操作**：输入 HS 8/10 位 → 记下 MFN、对应协定税率、生效日期、以及该行是否有 LARTAS/lisensi 标记。
把截图或页面存档，写进 `sources[].url`。

### 2. 协定文本（判断资格与单证）
- ACFTA：中国—东盟自贸区《货物贸易协议》及其升级议定书；原产地证为 **Form E**
- RCEP：2022-01-01 生效，对印尼自 **2023-01-02** 起生效；原产地证为 **RCEP 原产地证明**（可自证）
- 要点：**协定税率不是自动的**——要满足原产地规则（区域价值成分/税则归类改变）+ 正确单证，
  且进口商要在报关时申请。业务上要同时确认“能不能享”和“客户会不会去享”。

### 3. 政府国别指南（了解全貌，不能替代税则库）
- US ITA **trade.gov Country Commercial Guides** → “Import Tariffs”“Import Requirements”“Trade Barriers”
- 中国商务部《国别贸易投资环境报告》《对外投资合作国别指南》
- 这些会给出“平均 MFN 税率”“约束税率覆盖率”等**宏观数字**，很适合用来做背景段落，
  但**不能**告诉你 HS 2836.20 的具体税率。

## 三、状态标记法（本技能的核心约定）

`case.json → policy.tariffs[]` 每一条必须有 `status`：

| status | 含义 | 报告里的写法 |
|---|---|---|
| `fact` / `official` | 在官方税则库/法规原文里直接看到 | “MFN 5%，据 INSW（2026-10 查询）” |
| `gap` | 只有第三方转述，或根本没查到 | “待核实：第三方汇总站称 0%（WITS 2023）” |

**`validate.py` 的规则**：`rate_pct` 有值但 `status` 不是 official ⇒ 警告；
报告中该行显示红色“待核实”徽标，不允许出现在“已核实”表格里。

### 怎么把“待核实”写得不难看
> 印尼对 HS 2836.20 的最惠国税率，公开可得的两条线索都指向 0%：
> 第三方汇总站按 WITS 2023 口径给出 0%，两家本地进口服务商也把 Form E 报为 0%。
> 但本报**没有**在 INSW 上按 8 位税号逐条核验，因此把它列为 **P0 待核实**：
> 首次报价前用 2836.20.00 在 INSW 查一次，并让进口商确认报关行用的税号一致。

这段话既给了客户方向，又保住了可信度。

## 四、非关税措施清单（逐条过一遍）

| 措施 | 查什么 | 常见坑 |
|---|---|---|
| 进口许可 / LARTAS | 该 HS 是否属“受限/lartas”类；需要 PI（进口批准）还是 LS（进口登记） | 化工品常因“危险品/矿产品”被归入某部委新规，2025 年印尼就有 9 部 Permendag 密集落地 |
| 危险品运输与包装 | UN 编号、包装类别、IMDG | 纯碱本身非危险品，但**混合物、食品级**适用不同规则 |
| 标准与认证 | SNI（印尼强制标准）、保质期/标签 | 食品级需 BPOM 注册；工业级可能不需要 |
| 清真（Halal） | 是否属强制范围 | 食品添加剂类要特别确认 |
| 本地化含量 TKDN | 招标/项目是否要求最低本地含量；产品本身是否被列入 | 纯碱是否在清单里常常查不到 → 写成缺口 |
| 反倾销/保障措施 | 目标国贸易救济公告、WTO 数据库 | 纯碱历史上在多国有贸易救济案例，务必查当期 |
| 外汇与支付 | 是否限制付汇、是否要求本币结算 | 影响付款条件与报价货币 |

## 五、写进报告的规范

1. **税率表每一行都要有“状态”列**，且必须能在报告里点到来源。
2. **区分“法定税率”和“实际税负”**：例如 PPN 法定 12%，但按 11/12 计税基础，实际约 11%；
   PPh 22 预缴依是否有 API 分为 2.5% / 7.5%。这种差别要写清，否则客户按 12% 算成本会骂人。
3. **政策变化要有时间点**：签署 ≠ 生效 ≠ 实施。写“2025-10-28 签署（ACFTA 3.0），生效待批准”。
4. **不要给“综合税负百分比”而没有拆分**：客户要的是可复算的口径。

## 六、印尼速查（案例里用到的，示例用）

| 项目 | 结论 | 状态 |
|---|---|---|
| HS 2836.20.00 | Sodium carbonates，BTKI 2022 八位税号 | 已核实（税号本身） |
| 平均 MFN | 简单平均 8.1%，农产品 8.7%，非农 8.0%；化工品“税率更高或存在未约束税目” | 已核实（trade.gov 2025-11-17，属国别指南非税则） |
| 纯碱 MFN | 第三方称 0% | **待核实** |
| ACFTA / Form E | 第三方与本地服务商均称 0% | **待核实** |
| RCEP | 对印尼 2023-01-02 生效；纯碱减让档期未核 | 部分待核实 |
| PPN | 法定 12%，按 11/12 计税基础 ⇒ 实际约 11% | 已核实（PMK 131/2024 口径） |
| PPh 22 | 2025-08-01 起：有 API 2.5%，无 API 7.5%，特定商品 7.5–10% | 已核实 |
| LARTAS / PI / LS | 2836.20.00 具体状态未查实 | **待核实** |
| TKDN | Permenperin 35/2025：有自有工厂的投资者 ≥25%，研发 +20%、BMP +15% | 已核实（政策本身），纯碱是否适用**待核实** |

> 上面这张表本身就是交付物的一部分：**它把“查到了什么”和“还差什么”摆在一起**。
> 客户看到你敢列“待核实”，对你说“已核实”的部分反而更信。
