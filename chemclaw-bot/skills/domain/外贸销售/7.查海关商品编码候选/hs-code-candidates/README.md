# hs-code-candidates · 查海关商品编码候选

给化工外贸销售用的「HS 编码候选研究」技能：输入产品信息，输出**有依据的候选编码 + 每个候选的成立条件 + 法条依据 + 监管条件与税率 + 还缺什么**，而不是一个强行凑出来的唯一编码。

> 归类错了不是改个数字：退税率可能从 13% 变 0%，监管证件可能从"无"变"A/M"，还可能构成申报不实。

## 交付物

| 文件 | 说明 |
|---|---|
| `HS归类候选研究报告_<案例号>.html` | 自包含交互页（零外部依赖）：9 个区块 —— 归类路径 / 候选卡片（搜索+筛选）/ 法律依据 / 歧义与误配 / 编码层级 / 监管条件与税率 / 缺失信息 / 待确认 / 来源 |
| `HS归类候选研究工作簿_<案例号>.xlsx` | 13 表：封面与口径、产品属性、候选编码、归类依据、缺失信息、歧义与误配、编码层级对照、关税税率、出口监管条件、申报要素填写、待确认问题、来源链接、校验统计 |
| `checks.json` | 自检结果（候选数、来源等级分布、错误与警告） |

## 快速开始

```bash
# 一键：校验 → Excel → HTML → 浏览器交互验证
python scripts/build_all.py examples/01-SBS热塑性弹性体/case.json --as-of 2026-10-19

# 新案例
python scripts/new_case.py --blank ./我的案例 --product "硫酸 98%"
# 填完 case.json 再跑 build_all.py
```

## 覆盖的产品类型

- **聚合物 / 橡胶 / 热塑性弹性体**：是否充油、是否加填料、共聚物按最大单体、初级形状、复合橡胶（示例 01）
- **同一物质的双重身份**：颜料级 vs 化学纯品（示例 02 二氧化钛）
- **制剂与原药**：零售包装、用途细分（示例 03 农药制剂）
- **混合物 / 未列名配制品**：3814 与 3824 的边界（示例 04 混合溶剂）
- **单一无机化合物 + 强监管**：浓度分岔、易制毒、危化品（示例 05 硫酸）

## 核心纪律

1. **不强行给唯一编码**：参数不足只给方向与候选，并写清缺什么。
2. **每个候选挂法条依据**：引用到"第40章注释五（一）"这种粒度。
3. **不按俗称、不按 CAS 给码**："热塑性弹性体"至少跨 3902/3903/3907/3909/4002。
4. **不用过期 10 位编码**。
5. **税率必须标版本**：HS 年份、退税文库版本、查询日期。
6. **"不适用"要写理由**：查了哪份文件、全文检索结论、何时需重新评估。
7. **交付物带免责声明**：最终以海关认定为准。

## 证据等级

| 等级 | 含义 | 可否对客户说 |
|---|---|---|
| A 官方原文 | 税则/公告/法规原文、官方数据库接口 | ✅ 说明版本与日期 |
| B 二手/供应商文件 | 商业数据库、SDS/TDS，已与官方交叉核对 | ⚠️ 说"据…" |
| C 第三方数据库 | 未核对 | ❌ 仅作线索 |
| D 待核验 | 拿不到原文或需专业判断 | ❌ 进待确认清单 |

## 环境要求

- Python 3.10+（标准库 + `openpyxl`）
- 可选：Node 22+ 与 Playwright/Chromium（用于 `verify_page.cjs` 的页面交互验证；缺失时 `build_all.py` 自动跳过）

## 重要声明

本技能产出的是**归类研究参考**，不构成法律意见，不替代报关行、海关预裁定或专业归类机构的最终判定。税则、退税文库与各类目录每年更新，使用前请核对报告中的"查询日期"与版本号。
