# 变更记录

## 1.0.0（2026-10-19）

首个版本。基于 SBS（苯乙烯-丁二烯-苯乙烯嵌段共聚物）出口归类的真实研究过程抽象而来。

**新增**

- `SKILL.md`：八步流程（定口径 → 身份固化 → 章/品目/子目/细分 → 生成候选 → 歧义单列 → 监管与税率 → 缺失信息 → 待确认 → 对外话术）。
- `references/` 8 份：归类方法与章注速查、聚合物与混合物专门规则、候选表字段与模板、编码层级与目的国、监管条件与税率口径、证据等级与不确定性、失败案例、交付前质检。
- `scripts/`：
  - `validators.py`：18 项硬规则校验（候选 ≥2、法条依据、风险点、来源 A 级 ≥2、税率格式、编码层级一致性等）。
  - `build_workbook.py`：13 表工作簿。
  - `build_html.py`：9 区块自包含交互页（tab 切换、搜索、筛选、待确认勾选）。
  - `build_all.py` / `new_case.py` / `verify_page.cjs`。
- `examples/`：5 个不同归类情形的示例 + 空白模板。

**已知限制**

- 目的国籍税率与目的国 10 位细分需要联网按各国官方数据库核实；本次仅美国（USITC HTS）取得官方接口数据，欧盟/日本/韩国/东盟标 D 级待核验。
- 申报要素与监管条件来自 B 级数据源（商业编码库），使用时须与单一窗口核对。
- 出口退税率须按现行文库（如 2026C 版）在电子税务局逐条查询，脚本只沿用 case.json 中的值。
