# 归类方法与章注速查

本文件解决三件事：**怎么按顺序推**、**化工品最常踩的章注是哪几条**、**推不下去时怎么退回来**。

---

## 一、推进顺序（不许跳步）

```
产品特征 →（类注/章注排除）→ 章 →（品目条文）→ 4 位品目 →（6 位子目）→ HS6 →（本国子目注释 + 10 位细分）→ 中国报关编码
                                                                    └→（目的国税则）→ 目的国编码
```

每一步都要留证据：

| 步 | 依据 | 输出 |
|---|---|---|
| 定章 | 类注、章注（排除条款优先） | "为什么在这个章、为什么不在相邻章" |
| 定品目 | 品目条文（4 位） | 品目条文的**原文关键词** |
| 定子目 | 子目条文（6 位）、子目注释 | 同一数级比较结论 |
| 定细分 | 本国子目注释、10 位货品名称 | "为何是该 10 位而非相邻 10 位" |
| 定目的国 | 该国税则、TARIC/HTS/关税表 | 目的国编码与税率 |

**常见跳步错误**：拿产品俗称直接搜数据库 → 得到一串候选 → 挑一个"看起来像"的 → 反写理由。这是凑编码。

## 二、归类总规则速记

| 规则 | 一句话 | 化工品常见用法 |
|---|---|---|
| 规则一 | 类章标题只为查找；法定归类按品目条文和类注章注 | 先看注释的"本章不包括……" |
| 规则二（一） | 不完整品/未制成品按成品归类 | 半成品套件、拆散件 |
| 规则二（二） | 材料混合或组合品仍按该材料所在品目；两种以上材料按规则三 | 混合物进入规则三 |
| 规则三（一） | 列名具体优先 | "颜料" vs "其他化工产品" |
| 规则三（二） | 基本特征 | 复配制剂中主成分判定 |
| 规则三（三） | 按号列顺序归最末 | 最后兜底 |
| 规则四 | 最相类似 | 罕见、未列名新物质 |
| 规则五 | 包装容器随货归类 | 零售包装的判定 |
| 规则六 | 子目在同一数级比较，按子目条文和子目注释 | 10 位细分只能与同层比 |

## 三、化工品最常踩的章注（按章）

### 第 29 章 有机化学品

- **注释一**：本章只包括"单独的已有化学定义的有机化合物"，含水、含杂质、溶解于水或有机溶剂的**仍可留在 29 章**（有严格条件）。
- **注释二**：本章不包括单独的已有化学定义的……某些产品按其他章归类（如某些糖、维生素）。
- 结论：**混合物一旦不满足 29 章注释一的条件，就掉到 38 章或更具体的品目**（如 3208、3402、3810、3824）。

### 第 32 章 鞣料/颜料/涂料

- 3206 是"其他着色料"及其制品，**颜料级与化学纯品不同**：例如二氧化钛，颜料级（经表面处理、粒度工程化）→ 3206.11；化学纯品/其他形态 → 2823。
- 3208 是涂料（溶剂型），基于合成聚合物的溶液，注意与第39章注释二（五）联动：聚合物溶液若溶剂重量 >50% → 3208。

### 第 33/34/35 章 制品类

- 33.02 工业用混合香料；33.03–33.07 主要为**零售包装**的芳香料/化妆品。
- 34.02 有机表面活性剂或制剂——**单一表面活性剂与配制成洗涤剂的差别**。
- 35.06 其他未列名胶粘剂：若 SBS 已配成胶粘剂成品，则不再是 40.02。

### 第 38 章 杂项化学品

- 38.08 杀虫剂等**零售包装或制剂**：**原药（有效成分）不归 38.08**，零售包装/配制品才归；原药看 29 章或 38.08 的具体子目。
- 38.11 防爆剂、防冻剂等配制品；38.12 橡胶配合剂（配制的橡胶助剂）。
- 38.24 **"未列名"兜底**：只有在其他品目都排除后才用；用 38.24 必须写清"为什么其他品目都不适用"。
- 38.25 残留物/废物类。

### 第 39 章 塑料

- **注释一**：塑料定义（外力成形后形状保持）。
- **注释二**：本章不包括的第（十一）项——**第四十章的合成橡胶及其制品**。
- **注释二（五）**：39.01–39.13 产品溶于挥发性有机溶剂、且溶剂 >50% → **3208**。
- **注释三**：39.01–39.11 只包括化学合成的、平均至少 5 个单体单元的聚合物等。
- **注释四**：共聚物按**重量最大的单体单元**归类；无最大者按号列顺序归最末。
- **注释六**：39.01–39.14 的"初级形状"= 液状/糊状（含分散体、溶液）+ 不规则块团粉粒片等散装形状。
- **子目注释**："聚XX"类子目指该单体单元 ≥95%；化学改性聚合物按未改性聚合物归类（接枝共聚物除外）。

### 第 40 章 橡胶

- **注释一**：橡胶包括天然橡胶、合成橡胶、从油类提取的油膏、再生胶。
- **注释三**：40.01–40.03、40.05 的"初级形状"（同 39 章口径）。
- **注释四**：合成橡胶要件（不饱和、可用硫磺硫化变为非热塑、18–29℃ 拉伸 3 倍不断/2 倍 5 分钟回复 1.5 倍内）。
- **注释五**：与硫化剂/促进剂/颜料（识别用除外）/增塑剂/增量剂（充油所加矿物油除外）/填料等混合 → **不归 40.01/40.02（→4005）**；但微量抗氧剂、稳定剂、乳化剂等仍可留在 40.02。
- **注释九**："板""片""带"仅指未切割或仅切成矩形的板片带及正几何形块。

## 四、五个高频"身份问题"

1. **纯品还是混合物？** → 决定 29 章 vs 38/32/33/34 章。
2. **基础聚合物还是配混料？** → 决定 39.01–39.14 vs 39 章制品 vs 4005。
3. **橡胶还是塑料？** → 第40章注释四要件 + 第39章注释二（十一）。
4. **初级形状还是板片带/制品？** → 注释三/注释六/注释九 + 是否已具有制品特征。
5. **原药还是制剂/零售包装？** → 决定 29/38.08/3808.9x 等，且直接影响监管证件。

## 五、推不下去时的退回清单

- 参数不足 → 只给"章 + 品目方向 + 候选"，写清缺什么（进缺失信息表）。
- 两章都能讲通 → 按规则一找**排除性注释**（哪章明确排除对方）。
- 同一章内两个品目 → 规则三（一）列名具体优先；再不行规则三（二）基本特征。
- 只有俗称 → 先还原化学身份，再进流程。
- 拿不到目的国原文 → 给 HS6 + "按该国税则确认"，标 D 级，不给具体税率。
