# 监管条件与税率口径

---

## 一、监管证件（报关单"监管条件"栏）

监管条件按 10 位编码挂载，含义是"进出口该编码货物需交验的证件"。常见字母：

| 代码 | 含义 | 触发后果 |
|---|---|---|
| 无 | 无需交验特定证件 | 正常申报 |
| A | 入境货物通关单 | 进口需报检，持通关单放行 |
| B | 出境货物通关单 | 出口需报检/换证 |
| 4 | 出口许可证 | 需先申领出口许可证 |
| 7 | 自动进口许可证 | 进口需自动许可 |
| x | 出口许可证（加工贸易） | 特定贸易方式 |
| y | 出口许可证（边境小额贸易） | 特定贸易方式 |
| 8 | 禁止出口 | 不得出口 |
| 9 | 禁止进口 | 不得进口 |

> 上表是通用含义，**具体编码的监管条件以单一窗口/税则附录口径为准**。本技能要求：把"哪个编码、什么证件、依据哪份文件、适用条件、仍需确认什么"一起写出来。

## 二、检验检疫类别

| 代码 | 含义 |
|---|---|
| M | 进口商品检验 |
| N | 出口商品检验 |
| P | 进境动植物、动植物产品检疫 |
| Q | 出境动植物、动植物产品检疫 |
| R | 进口食品卫生监督检验 |
| S | 出口食品卫生监督检验 |
| L | 民用商品入境验证（如 CCC） |

## 三、税率口径（中国进口方向）

| 栏 | 含义 | 用在哪 |
|---|---|---|
| 最惠国税率 | 对 WTO 成员及有最惠国待遇的国家适用 | 常规进口成本 |
| 暂定税率 | 对部分编码在年度内低于最惠国的临时税率 | 有 `ex` 号列时要查 |
| 协定税率 | 自贸协定项下 | 需原产地证 |
| 特惠税率 | 对最不发达国家等 | 极少 |
| 普通税率 | 对无最惠国待遇国家 | 极端情形 |
| 出口关税 | 少量资源类商品征收 | 出口成本 |
| 增值税 | 进口环节 | 13% / 9% 等 |
| 出口退税率 | 出口后按 10 位编码退还 | **影响报价与利润** |

### 协定税率怎么读

税则"协定税率(%)"栏用国家缩写 + 税率表示，例如：

```
0   东盟AS,智CL,巴PK,新西兰NZ,新加坡SG,...
3.8 东盟RASR,澳RAUR,韩RKRR
5.2 日RJPR
```

- `AS`=东盟协议、`CL`=智利、`PK`=巴基斯坦、`NZ`=新西兰、`SG`=新加坡、`CH`=瑞士、`IS`=冰岛、`AU`=澳大利亚、`KR`=韩国、`GE`=格鲁吉亚、`MU`=毛里求斯、`KH`=柬埔寨、`NI`=尼加拉瓜、`EC`=厄瓜多尔、`RS`=塞尔维亚、`MV`=马尔代夫、`HK`/`MO`=港澳。
- `R` 前缀表示 **RCEP**（如 `RJPR` = RCEP 项下日本、`RASR` = RCEP 项下东盟、`RAUR` = 澳大利亚、`RKRR` = 韩国）。
- `惠LD` = 特惠税率（最不发达国家）。

**实操提示**：同一产品在"东盟协议"与"RCEP 东盟"下的税率可能不同（如 0% vs 3.8%），出证前必须比较，并核对原产地规则。

## 四、出口退税口径

1. **退税率查哪个版本**：国家税务总局每年发布退税文库更新通知（如 2026C 版为税总货劳函〔2026〕214 号）。必须写明所依据的文库版本与启用日期。
2. **文库在哪查**：电子税务局"出口退税率查询"、单一窗口、或委托报关行查询；公开网页通常只有通知正文，不列逐条税率。
3. **政策调整追踪**：财政部/税务总局会不定期调整部分产品退税率（如公告 2026 年第2号涉及光伏、电池；第29号涉及新能源汽车、电子烟设备），要检查目标编码是否被覆盖。
4. **退税率与编码强绑定**：同一物质不同形态/是否复配，退税率可能从 13% 掉到 0%（如橡胶 40.02 与 40.05）。
5. **风险表述**：退税率未经官方查询确认时，只能说"数据源显示 X%，需按 2026C 版文库核验"，不能写进正式报价单。

## 五、其他必须排查的清单（"不适用"也要写理由）

| 项目 | 依据文件 | 怎么排查 |
|---|---|---|
| 两用物项管制 | 商务部/海关总署年度《两用物项和技术进出口许可证管理目录》 | 全文检索品名 + 编码，记录结论 |
| 出口许可证管理货物 | 商务部/海关总署年度《出口许可证管理货物目录》 | 看目录品类是否含该产品 |
| 危化品 | 《危险化学品目录》 | 查是否列名、是否含量门槛 |
| 易制毒/易制爆 | 《易制毒化学品目录》《易制爆危险化学品名录》 | 查是否列名（硫酸、盐酸、甲苯等高频误判） |
| 危险货物运输 | IMDG/IATA/ADR | 看 UN 号，与危化品分开判 |
| 反倾销/反补贴 | 商务部公告、目的国措施 | 查目的国对华该类产品措施 |
| 出口检验检疫 | 监管条件 + 检验检疫类别 | 看单一窗口 CIIC 代码 |

## 六、记录要求

每条结论必须能回答：

- **是什么**（结论）
- **凭什么**（文件名称 + 文号 + 生效日期 + URL）
- **在什么条件下成立**（适用条件）
- **还差什么**（仍需确认 + 责任人）
- **核验到哪一步**（A/B/C/D 等级 + 核验日期）
