# 聚合物与混合物专门规则（第39/40章）

> 化工外贸里最容易归错的不是无机盐，是聚合物、橡胶和复合料。这一份就是为它们准备的。

---

## 一、第39章：塑料聚合物

### 1. 共聚物按"重量最大的单体单元"归

第39章注释四：共聚物（含共缩聚物、共加聚物、**嵌段共聚物**及接枝共聚物）及聚合物混合体，应按聚合物中**重量最大的那种共聚单体单元**所构成的聚合物归入相应品目；没有任何单体单元最大时，按号列顺序归**最末**一个品目。

- 例：苯乙烯-丙烯腈共聚物（SAN），苯乙烯 > 丙烯腈 → 3903（苯乙烯聚合物）；反之 → 3902 项下丙烯腈共聚物。
- 例：苯乙烯与丁二烯比例接近（如 50/50 或 45/55）→ 归属不稳，必须给比例，否则不能给子目。

### 2. 子目层"聚XX"= 单体单元 ≥95%

第39章子目注释一（一）：子目名称冠有"聚（多）"的（如聚乙烯、聚酰胺-6,6），指该种单体单元占整个聚合物 **≥95%**。

### 3. 化学改性聚合物

第39章注释五：化学改性聚合物**按未改性聚合物归类**；但**不适用于接枝共聚物**。

### 4. 初级形状（注释六）

39.01–39.14 的"初级形状"只包括：
- 液状及糊状（含分散体：乳浊液、悬浮液及溶液）；
- 不规则形状的块、团、粉（含压型粉）、颗粒、粉片及类似的散装形状。

→ **压片、板材、型材、成品件不再是初级形状**，会掉到 39.20/39.21/39.25 等。

### 5. 39 章与"溶液"的边界

- 注释二（五）：39.01–39.13 的产品溶于挥发性有机溶剂，**溶剂重量超过溶液 50%** → 归 **3208**。
- 溶剂 ≤50% → 仍在 39 章"初级形状（溶液）"。

### 6. 39 章明确排除的相邻类

- 第40章合成橡胶及其制品（注释二（十一））
- 34.02 有机表面活性剂及制剂（注释二（六））
- 38.11 矿物油用配制添加剂（注释二（八））
- 38.19 以 39 章聚合物为基本成分的液压液（注释二（九））

## 二、第40章：橡胶与热塑性弹性体

### 1. 什么算"合成橡胶"（注释四）

必须同时满足：
1. 不饱和合成物质，**用硫磺硫化能使其不可逆地变为非热塑物质**；
2. 在 18–29℃ 之间拉长到原长度 **3 倍不断裂**；
3. 拉长到 **2 倍** 后 **5 分钟内**回复到不超过原长度 **1.5 倍**。

允许加入交联所需的硫化活化剂或促进剂；**不得加入非交联所需物质（增量剂、增塑剂、填料）**。

> 热塑性弹性体（TPE）能否满足注释四，是 40 章与 39 章分岔的第一道关。中国税则在 4002 项下专列"热塑丁苯橡胶"，实务上 SBS 走 40 章；但举证要靠技术数据（可硫化性、拉伸回弹）。

### 2. 混合的边界（注释五）—— 40.02 与 40.05 的分水岭

**（一）不归 40.01/40.02 的情形**：与下列物质混合的橡胶或橡胶混合物——
1. 硫化剂、促进剂、防焦剂或活性剂（为制预硫胶乳加入的除外）；
2. 颜料或其他着色料（**仅为识别用**加入的除外）；
3. 增塑剂或增量剂（**用油增量的橡胶中所加的矿物油除外**）、填料、增强剂、有机溶剂或其他物质。

**（二）仍留 40.01/40.02 的情形**（只要仍具原料基本特性）：
1. 乳化剂或防粘剂；
2. 少量的乳化剂分解产品；
3. **微量**的热敏剂、阳离子表面活性剂、**抗氧剂**、凝固剂、碎裂剂、抗冻剂、胶溶剂、保存剂、稳定剂、粘度控制剂或类似特殊用途添加剂。

**实操判据**：问三件事——加了什么（炭黑/白炭黑/碳酸钙/增塑剂/硫化体系？）、加了多少（微量助剂 vs 功能性填料）、目的是什么（改善加工 vs 配料）。

### 3. 国内 SBS/SBR 的 10 位落点（中国税则 4002.19 项下）

| 10 位 | 货品名称 | 关键判定 |
|---|---|---|
| 4002.1911 | 未经任何加工的丁苯橡胶（溶聚的除外） | 乳液聚合、未充油、未改性 |
| 4002.1912 | 充油丁苯橡胶（溶聚的除外） | 乳液聚合 + 充油 |
| **4002.1913** | **热塑丁苯橡胶** | 热塑（SBS 型），**未充油** |
| **4002.1914** | **充油热塑丁苯橡胶** | 热塑 + 充油 |
| 4002.1915 | 未经任何加工的溶聚丁苯橡胶 | 溶液聚合 S-SBR，未充油 |
| 4002.1916 | 充油溶聚丁苯橡胶 | 溶液聚合 + 充油 |
| 4002.1919 | 其他 | 兜底 |
| 4002.1990 | 其他（非初级形状） | 板、片、带 —— **退税率常为 0** |

> 充油 = 生产中加入矿物油等填充油（油展橡胶）。注释五（一）3 明确：充油橡胶所加的矿物油**不改变**其留在 40.01/40.02。

### 4. 热塑性弹性体（TPE）的"一族多码"

"热塑性弹性体"是一个**性能家族**，不是一个品目：

| 类型 | 化学结构 | 常见落点 |
|---|---|---|
| SBS / SEBS（苯乙烯类） | 苯乙烯-丁二烯（-苯乙烯）嵌段 | 4002.19（SBS）；氢化 SEBS 常见 4002.99 口径 |
| TPO / TPV（聚烯烃类） | 乙丙（EPDM/EPM）+ PP | 3902.30 / 4002.99 视身份 |
| TPU（聚氨酯类） | 二异氰酸酯 + 多元醇 | 3909.50 |
| TPEE（聚酯类） | 聚酯硬段 + 聚醚软段 | 3907.99 |
| TPAE（聚酰胺类） | 尼龙硬段 + 聚醚软段 | 3908.90 |
| 复配 TPE 料（compound） | 上述 + 填料/助剂/油 | 可能被按复合橡胶 4005 或塑料混合物处理 |

→ 用户说"SBS"时不能只按缩写给码，必须先确认"哪一类 TPE、是否充油、是否复配、什么形态"。

### 5. 40 章的形态分岔

| 形态 | 落点 |
|---|---|
| 胶乳/分散体 | 4002.11（SBR 胶乳）等 |
| 粒、块、碎屑（初级形状） | 4002.19 的"初级形状"细分 |
| 板、片、带、正几何形块 | 4002.1990 等"其他"（注释九） |
| 未硫化但已成特定形状（杆、管、型材、盘环） | 4006 |
| 已与配合剂混合成未硫化胶料 | 4005 |
| 已硫化 | 4007/4008 及以后 |

## 三、混合物与配制品

1. **能否留在 29 章**：只看第29章注释一（单独、已有化学定义；水溶液/含杂质的条件）。
2. **有专门品目的配制品优先**：如农药制剂 3808、涂料 3208–3210、洗涤剂 3402、胶粘剂 3506、橡胶配合剂 3812。
3. **38.24 是最后兜底**：用它必须逐条说明"为什么 29/32/33/34/35/38 的具体品目都不适用"。
4. **零售包装是硬条件**：3808.94/3808.99 等子目的"零售包装"判定要写清包装规格与标签。
