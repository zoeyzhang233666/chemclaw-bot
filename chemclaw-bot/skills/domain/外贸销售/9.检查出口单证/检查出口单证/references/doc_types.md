# 12 类出口单证：必备字段与常见坑

> 字段 id 见 `scripts/taxonomy.py`。下表的"必备"= 按行业惯例该单证通常应载明；
> 「缺失」状态正是按这张表判定的——不在这张表里的字段在该单证上显示「不适用」。

---

## 1. 销售合同 SC（Sales Contract）

| 项目 | 内容 |
| --- | --- |
| 别名词 | 销售合同、Sales Contract、S/C、Purchase Contract |
| 必备字段 | 出口商、进口商、合同号、签订日期、品名(中英)、数量、单价、总金额、币种、贸易术语、起运港、目的港、包装方式、净重、件数、付款方式、装运期、规格 |
| 不上合同的字段 | 提单号、通知方、唛头（可无） |
| 常见坑 | ① 贸易术语写出两个（正文 `CIF`、表格 `CFR`）；② 数量用 `MT` 但未写净重；③ 只写"按常规包装"没给吨袋规格；④ 修改后未改版本号 |

## 2. 形式发票 PI（Proforma Invoice）

| 项目 | 内容 |
| --- | --- |
| 必备字段 | 出口商、进口商、PI 号、日期、品名、数量、单价、总金额、币种、贸易术语、付款方式、装运期、有效期 |
| 常见坑 | ① PI 号带多余后缀（`…0817A`），后续 CI/LC 引用时对不上；② 单价含佣/不含佣未注明；③ 有效期早于合同签订日 |

## 3. 商业发票 CI（Commercial Invoice）

| 项目 | 内容 |
| --- | --- |
| 必备字段 | 出口商、进口商、收货人、CI 号、日期、品名、HS 编码、数量、单价、总金额、币种、贸易术语、起运港、目的港、净重、毛重、件数、包装方式、唛头 |
| 常见坑 | ① **金额 = 单价×数量 算错**（最常见的严重错误）；② CI 号与 LC 要求的发票号不一致；③ 收货人写"客户"而提单收货人是 `TO ORDER`；④ 品名与提单不一致（提单是"最简品名"，但不能换品） |

## 4. 装箱单 PL（Packing List）

| 项目 | 内容 |
| --- | --- |
| 必备字段 | 出口商、进口商、CI 号、日期、品名、件数、包装方式、净重、毛重、体积、唛头 |
| 不上装箱单的字段 | 单价、总金额 |
| 常见坑 | ① **净重与 CI/报关单不一致**；② 件数与提单件数不一致（含托盘/空桶）；③ 体积超出柜容量；④ 唛头与提单不一致（目的港理货靠唛头分票） |
| 说明 | 装箱单常写 `B/L No.: TO BE ADVISED`——这是**正常**占位，不是错误；不要拿去和提单比对 |

## 5. 海运提单 BL（Bill of Lading）

| 项目 | 内容 |
| --- | --- |
| 必备字段 | 提单号、发货人(Shipper)、收货人(Consignee)、通知方(Notify)、船名航次、起运港、目的港、品名、件数、包装方式、毛重、体积、唛头、装船日、运费条款 |
| 不上提单的字段 | 单价、总金额、贸易术语（CFR/CIF 体现在运费条款） |
| 常见坑 | ① **目的港写错**（近洋港口名相近，最致命）；② 发货人写成生产厂而非签约出口商；③ 件数/毛重与装箱单、报关单"三处不一"；④ 收货人 `TO ORDER` 与客户要求不符；⑤ `Place of Receipt`（收货地）与 `Port of Loading`（装运港）混淆 |
| 注意 | 提单只写"最简品名"（`SODA ASH DENSE`），比发票的详细品名短，**属合理差异** |

## 6. 质量检验证书 COA（Certificate of Analysis）

| 项目 | 内容 |
| --- | --- |
| 必备字段 | 批号、日期、品名(中英)、CAS 号、规格/执行标准、数量、包装 |
| 常见坑 | ① **CAS 号打错一位**（`497-19-8` → `497-19-2`）；② 关联合同号抄错；③ 检验标准与合同约定标准不一致；④ 批号与唛头/装箱单批号不一致 |

## 7. 安全技术说明书 SDS（Safety Data Sheet）

| 项目 | 内容 |
| --- | --- |
| 必备字段 | 品名(中英)、CAS 号、UN 编号、危险性类别、包装类别、HS 编码 |
| 常见坑 | ① **品名写成另一规格**（重质 → 轻质，物性完全不同）；② 版本号过期（GHS 修订）；③ UN 编号缺失却按普通货物订舱 |
| 说明 | SDS 是**产品级**文件，可能早于本票业务签发、版本与批次无关；批号不一致**不算错误** |

## 8. 原产地证书 CO（Certificate of Origin）

| 项目 | 内容 |
| --- | --- |
| 必备字段 | 证书号、出口商、收货人、HS 编码、品名、数量、净重、件数、原产国、唛头、签发日期、运输方式与路线 |
| 常见坑 | ① **收货人多了仓库/工厂后缀**（`PT X` vs `PT X - GUDANG CIKARANG`）——这是不同交货地址，需确认；② HS 编码与报关单前六位不一致；③ 起运港/目的港与提单不一致；④ 签发日期晚于装船日（部分自贸协定要求装运前或装运时签发） |

## 9. 出口报关单 CUSTOMS（Customs Declaration）

| 项目 | 内容 |
| --- | --- |
| 必备字段 | HS 编码、品名、数量、单价、总金额、币种、成交方式、起运港、净重、毛重、件数 |
| 常见坑 | ① **成交方式（FOB/CFR/CIF）与合同贸易术语不对应**；② 申报品名与 CI 不一致；③ 净重与装箱单不一致；④ HS 编码监管条件未满足 |

## 10. 信用证 LC（Letter of Credit，MT700）

| 项目 | 内容 |
| --- | --- |
| 必备字段 | LC 号、开证申请人(Applicant)、受益人(Beneficiary)、金额与币种、贸易术语、起运港、目的港、最迟装运期、有效期、交单期、单据要求、附加条件 |
| 常见坑 | ① **装运港/目的港与合同不同**（LC 写 `CFR QINGDAO` 这类多半是笔误）；② 单据要求中列了无法提供的单据；③ 最迟装运期早于实际装船日；④ 交单期（通常 21 天）被忽略 |
| 说明 | LC 是**开证行**文件，其条款优先于合同。发现 LC 与合同冲突时，正确做法是**改证**，不是改其它单证 |

## 11. 危包证 DGD（Dangerous Goods Declaration）

| 项目 | 内容 |
| --- | --- |
| 必备字段 | UN 编号、危险品类别、包装类别、数量、件数 |
| 说明 | 非危险品（如纯碱）本票业务不需要。若 SDS 显示非危险品而订舱要求 DGD，属于流程问题而非单证冲突 |

## 12. 检验证书 INSP（Inspection Certificate）

| 项目 | 内容 |
| --- | --- |
| 必备字段 | 品名、批号、数量、净重 |
| 说明 | 部分国家（如印尼工业原料）PSI 非强制，以客户/目的国要求为准 |

## 自动识别是怎么做的

1. 先看**文件名**（权重 3.0）：`03_商业发票_Commercial_Invoice.pdf`；
2. 再看**首页标题区前 6 行**（权重 4.0）：标题含「商业发票」；
3. 再看首页正文（权重 2.0）与全文（权重 0.3）兜底；
4. 得分最高者为识别结果，低于阈值则标 `UNKNOWN` 并退化为按文件名后缀猜测。

**为什么标题权重最高**：公司内部标准/模板文件正文里会大量出现"销售合同""原产地证"等字样，
只看全文会把"《公司出口文件标准》"误判成合同。只看标题区就能避免。

## 模板/标准类文件如何被排除

标题区出现 `模板 / TEMPLATE / 填制要求 / 作业指引 / 范本 / 文件标准 / EXPORT DOC STANDARD`，
且**不含本票业务的实号码**（如 `HYE-SC-2026-0817`）时，判为参考文件：

- 仍出现在单证清单里（让人知道"这份我看到了"）；
- 但**不参与矩阵比对**，避免模板里的示例值（如 `quantity = 100`）污染核对结果。
