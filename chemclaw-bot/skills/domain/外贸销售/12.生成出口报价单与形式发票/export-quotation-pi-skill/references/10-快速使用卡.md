# 快速使用卡（可打印）

**报价单 / 形式发票 · 5 分钟出片**

## 一、先确认这些信息（缺一项就留空，不要猜）

```
卖方：英文公司名 / 地址 / 联系人 / 电话 / 邮箱 / 税号（USCI）
买方：英文公司名 / 地址 / 联系人 / 税号（印尼 NPWP、印度 GSTIN、欧盟 VAT、巴西 CNPJ）
商品：英文品名 + 化学名 / CAS 号 / 规格（要写具体指标）/ HS 编码 / 原产地
数量：数量 + 单位（MT / KG / 桶 / 袋 / IBC）+ 件数 + 每件净重毛重
价格：★单价（必填）★币种 / 折扣 / 是否已确认
术语：EXW / FCA / FAS / FOB / CFR / CIF / CPT / CIP / DAP / DPU / DDP + 2020 + 指定地点
包装：包装描述 + 装运单位（柜型 / 空运 / 拼箱）
交期：多少天 + 起算点（收到订单 / 收到预付款 / 固定日期）+ 能否分批转运
付款：方式 + 比例（T/T 预付 %、信用证即期/远期 + 开证期限）
有效期：截止日期 或 有效天数
单据：发票 / 箱单 / 提单或空运单 / 产地证 / COA / SDS / 信用证份数
银行：是否显示；账号只有在卖方书面确认后才填入，否则一律占位
危品：状态（危险品 / 非危险品 / 待核实）+ UN 号 / 正确运输名称 / 类别 / PG / 包装 / SDS 版次
```

## 二、打开编辑器

`dist/deliverables/EX-001_QT-SIM-2610-001_Studio.html` → 双击即可（不需要服务器、不需要联网）。

| 标签页 | 做什么 |
|---|---|
| 单据 | 单号、签发日期、类型（报价单 ↔ 形式发票一键切换）、有效期 |
| 双方 | 卖方 / 买方信息、税号、联系人 |
| 商品 | 品名、CAS、规格、HS、数量、单价、折扣、包装件数毛净重、危险品状态 |
| 条款 | 贸易术语 + 指定地点、包装、交期、付款、单据清单 |
| 银行 | 占位 / 显示开关（显示前必须二次确认） |
| 检查 | A–K 十一个维度：错误（红，阻断）与提示（黄，需说明） |
| 模板 | 公司抬头、颜色、签名、常用条款；存本地，可导出 JSON 复用 |

右上角状态灯：**DRAFT 草稿 → READY FOR REVIEW 待复核 → FORMAL 正式件**。
右侧纸张上**双击任意文字即可直接改**，数量或单价一改，金额自动重算并提示重新确认。

## 三、复核过关（这一步不能跳）

1. 检查页错误清零；黄提示逐条确认并写明理由。
2. 打印前对照客户询盘：品名、规格、数量、单价、术语、地点、有效期**逐字**核对。
3. 点“复核签发”，填写复核人姓名与职务，逐项打勾 → 生成 FORMAL 正式件（水印自动去掉，页脚变 Original）。
4. 导出 Word（可继续修改）/ PDF（直接发客户）/ JSON（留档）/ Excel（内部核对）。

## 四、四条“绝不做”

| ✗ 不做 | ✓ 正确做法 |
|---|---|
| 编造银行账号、SWIFT | 填占位：`[ BANK DETAILS TO BE CONFIRMED BY THE SELLER … ]` |
| 客户没给价格就先出正式报价 | 只出带 `[ PENDING PRICE ]` 的草稿 |
| 自己加付款条件、交期、有效期 | 缺就留空，让业务确认后补 |
| 危险品状态凭印象写 | 拿最新 SDS 第 14 节核实；没核实就阻断 |

## 五、常见错误提示怎么看

| 提示 | 意思 | 处理 |
|---|---|---|
| `ITEM_PRICE` / `LINE_PRICE_MISSING` | 缺单价 | 补价格或维持草稿 |
| `AMOUNT_MISMATCH` | 单价/数量改过，总额与已确认金额不符 | 重新确认价格 |
| `BAG_COUNT_CHECK` / `PACKAGE_SUM_MISMATCH` | 数量 ÷ 每袋净重 ≠ 件数 | 改数量、净重或件数 |
| `WEIGHT_SUM_MISMATCH` | 毛重 ≠ 件数 × 单件毛重 | 核对毛重字段 |
| `DG_UNKNOWN` | 危险品状态未核实 | 查 SDS 后选 DG / 非危险品 |
| `INSURANCE_BASIS` | CIF/CIP 没写保险险别与投保比例 | 补“ICC(A) 110%”之类 |
| `COST_ALLOC_*` | 费用承担与术语规则不一致 | 改分摊或加一句例外说明 |
| `LC_TYPE` / `LC_OPENING_DATE` / `LC_BANK` | 信用证条款不完整 | 补即期/远期、开证期限、开证行要求 |
