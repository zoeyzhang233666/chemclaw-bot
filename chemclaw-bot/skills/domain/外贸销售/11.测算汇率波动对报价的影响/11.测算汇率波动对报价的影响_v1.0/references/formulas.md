# 公式与算法规范

所有符号：

| 符号 | 含义 | 单位 |
|---|---|---|
| `A` | 外币金额（Amount in FX） | 外币 |
| `R` | 汇率（1 单位外币 = X 人民币） | CNY / 外币 |
| `R_mid` | 官方中间价 | CNY / 外币 |
| `R_s` | 结汇价（银行现汇买入价） | CNY / 外币 |
| `R_b` | 购汇价（银行现汇卖出价） | CNY / 外币 |
| `band` | 银行单侧点差带 | 小数（0.0025 = 0.25%） |
| `t` | 银行费用率（手续费 + 电讯费，按比例） | 小数 |
| `C` | 出口的人民币成本 / 进口的除货款外人民币成本 | CNY |
| `S` | 进口后的人民币销售收入 | CNY |
| `M` | 毛利额 | CNY |
| `m` | 毛利率 | 小数 |

**方向符号** `sign = −1`（出口收汇）或 `+1`（进口付汇）。

---

## 1. 汇率口径

```
R_s = R_mid × (1 − band)          出口结汇（银行买入外币）
R_b = R_mid × (1 + band)          进口购汇（银行卖出外币）
```

**为什么必须分开**：销售写在报价单上的"汇率"通常是中间价，但真正到手的是现汇买入价，永远低于中间价。实测 2026-10-19：中间价 6.7208，中国银行美元现汇买入价 6.6701，低 0.75%。10 万美元一单，这个差别就是约 5,070 元人民币。

`band` 有三种来源，按可信度排序：

1. `actual_bank_settle`：银行实际成交价，最真实；
2. `mid_x_band_estimate`：中间价 × 点差带，示例估算，**必须标注不是银行报价**；
3. `mid`：纯中间价，只适合做历史分位对照，不能当成交价。

---

## 2. 人民币收付

```
出口：Rev = A × R_s × (1 − t)
进口：Pay = A × R_b × (1 + t)
```

统一写法：

```
Cash = A × R × (1 + sign × t)
```

- 出口 `sign = −1`：费用从收入里扣掉，收入变少；
- 进口 `sign = +1`：费用加到成本里，支出变多。

> 易错点：两种方向的费用符号相反，不能用同一个 `(1 − t)` 套两边。

---

## 3. 毛利

```
出口：M = Rev − C              m = M / Rev
进口：M = S − (Pay + C_oth)    m = M / S
```

分母不同：出口用收入，进口用销售收入（因为进口是"花多少钱买货、卖多少钱"的关系）。

---

## 4. 汇率敏感性

汇率变动 `n`（如 −5%）后的情景汇率与金额：

```
R' = R × (1 + n)
出口：ΔRev = A × R × n × (1 − t) = Rev × n / (1 + n) 的近似
精确：ΔCash = A × (R' − R) × (1 + sign × t) = A × R × n × (1 + sign × t)
```

**每 1% 敞口**（最直观的一个数）：

```
Exp1% = |A × R × (1 − t)| × 1%
```

含义：汇率相对变动 1%，人民币收付金额变动多少元。10 万美元 @ 6.704 ≈ 6,704 元/1%。

> 注意：`ΔCash / Cash = n`，变化率恰好等于汇率变化率——因为费用是按比例计提的。如果费用是固定金额而非比例，这个等式就不成立。

---

## 5. 平衡汇率

### 5.1 毛利归零（出口）

令 `A × R × (1 − t) = C`：

```
R*_zero = C / [A × (1 − t)]
```

例：`C = 600,000`，`A = 100,000`，`t = 0` → `R* = 6.0000`。

### 5.2 保目标毛利率（出口）

令 `M / Rev = m`，即 `Rev − C = m × Rev`，故 `Rev = C / (1 − m)`：

```
R*_m = C / [A × (1 − t) × (1 − m)]
```

例：`m = 10%` → `R* = 600,000 / (100,000 × 0.9) = 6.6667`。

### 5.3 保目标毛利额（出口）

令 `Rev − C = M_target`：

```
R*_M = (C + M_target) / [A × (1 − t)]
```

### 5.4 毛利归零（进口）

令 `S − (A × R × (1 + t) + C_oth) = 0`：

```
R*_zero = (S − C_oth) / [A × (1 + t)]
```

### 5.5 安全边际

```
Buffer = R*_zero / R − 1
```

出口时该值为负：表示汇率还要再跌这么多才亏。10 万美元案例：`6.0 / 6.704 − 1 = −10.50%`。
进口时该值为正：表示汇率还要再涨这么多才亏。

另有一个更口语化的指标：

```
毛利被吃光所需的汇率变动幅度 = M / Exp1%
```

案例：`70,399.80 / 6,704 ≈ 10.50%`，与安全边际一致（费用率为 0 时两者恒等）。

## 6. 历史分位与区间

### 6.1 分位定义

```
percentile = (count(R_i < R_current) + 0.5 × count(R_i = R_current)) / n
```

- 用 `0.5 × 相等数` 而非简单 `<`：当前值往往就在序列里（今天就是最后一天），不加权会系统性低估；
- 同时给出**严格小于**口径（`count(R_i < R_current) / n`）作为稳健性对照。案例中两个窗口严格口径均为 0.0%，结论方向一致。

### 6.2 窗口

```
start = last_date − 365 × years   （years = 1 或 3）
选定日期 ≥ start 且 ≤ last_date    （左开右闭：起点当天不在窗口内，末日含）
```

按**自然日**回看，不是按交易日数。这样"近 1 年"在任何市场都指同一段日历时间。

### 6.3 区间指标

```
距最高   drawdown = R_current / R_max − 1        （负数，表示距离高点回落多少）
距最低   upside   = R_current / R_min − 1        （正数，表示距离低点还有多少）
区间宽度 width    = R_max / R_min − 1
```

## 7. 已实现波动（只描述过去）

```
r_t  = ln(R_t / R_{t−1})
σ_d  = std(r_t)                    样本标准差
σ_a  = σ_d × √252                  年化（252 个交易日）
σ_N  = σ_a × √(N / 252)            N 日典型波动幅度
```

**这不是预测**。它只回答"过去这段时间的波动有多大"，用来判断"90 天里汇率动 0.5% 算不算正常"。
必须同时声明：历史波动不代表未来波动。

案例：USD/CNY 近 1 年年化波动 1.06%，90 天折算 ≈ 0.53%。意思是——90 天内汇率波动半个百分点在历史上属于常态量级，因此 ±1% 的敏感性档位并非极端假设。

## 8. 分批结算

### 8.1 加权汇率

```
R_w = Σ(A_i × R_i) / Σ A_i
```

### 8.2 分批折算

```
Cash_batch = Σ [A_i × R_i × (1 + sign × t)]
```

### 8.3 与一次性对比（结构效应）

一次性按"首日汇率"折算：

```
Cash_lump = (Σ A_i) × R_first × (1 + sign × t)
Δ_struct  = Cash_batch − Cash_lump
```

`Δ_struct` 只反映"各批落在不同汇率"这件事本身，**不是分批带来的收益**。

### 8.4 敏感性

对各批次同向等比例平移：

```
Cash_batch(n) = Σ [A_i × R_i × (1 + n)] × (1 + sign × t) = Cash_batch(0) × (1 + n)
```

因此分批曲线的形状与一次性完全相同，只是整体平移。**分批不降低"汇率变动 × 总敞口"这一项**，它改变的是暴露时点的分散程度。

> 必须说清楚的一句：方向未知时，分批只降低单点集中度，不降低期望损失。如果汇率确实单边下跌，"分批"只会让一部分钱躲过下跌、另一部分没躲过——不存在必然更好的方案。

## 9. 报价底线（带入出口报价）

给定目标毛利率 `m`、成本 `C`、费用率 `t`，在**汇率不变**假设下所需的最低外币金额：

```
A_min = C / [(1 − m) × (1 − t) × R]
```

推导：需要 `Rev = C / (1 − m)`，而 `Rev = A × R × (1 − t)`，故 `A = C / [(1 − m)(1 − t)R]`。

单价：`P_min = A_min / Q`（Q 为数量）。

这不是"应该报多少"（那取决于市场），而是"低于这个数就达不到目标毛利率"的底线。

---

## 10. 边界情形与陷阱

| 情形 | 处理 |
|---|---|
| `t ≥ 1` | 收入为负，无意义 → 校验时报错 |
| `m ≥ 1` | 平衡汇率分母为 0 或负 → 返回"无法达到" |
| `A = 0` | 所有比例指标无定义 → 返回空而非 0 |
| `R_current` 恰在历史极值 | 分位可能是 0% 或 100%，这是真实结果，不是 bug |
| 历史序列起点晚于窗口起点 | 样本数小于理论值，如实报告 n |
| JPY 口径 | 必须是 "100 JPY = X CNY"，用 1 JPY 会差 100 倍 |
| 中间价 vs 成交价混用 | 分位用中间价、敏感性用成交价时，必须分别标注 |
| 负数汇率/金额 | 直接拒绝，不做"绝对值修补" |
