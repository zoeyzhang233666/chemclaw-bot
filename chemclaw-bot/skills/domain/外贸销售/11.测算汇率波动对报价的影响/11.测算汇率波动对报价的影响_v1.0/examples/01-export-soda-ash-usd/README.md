# 案例 01 · 重质纯碱 10 万美元出口 · 90 天后收汇

这是一次完整的走查：从"销售给了几个条件"到"两个文件交到手上"，每一步都说清依据。

> **数据截至**：2026-10-19（中间价 09:15 公布；中行牌价 16:27:56）
> **汇率数据后续会变**，本案例的数字只对应这一天。

---

| 销售说的 | 落进 case.json | 性质 |
|---|---|---|

## 二、取到了什么汇率

### 2.1 官方中间价

```
USD/CNY 中间价 = 6.7208
来源：国家外汇管理局 / 中国外汇交易中心
时间：2026-10-19 09:15
```

**报价方向说明**：这是**直接标价**——1 美元 = 6.7208 人民币。销售看到"汇率 6.72"指的就是这个。

### 2.2 银行牌价（16:27:56，中国银行）

| 口径 | 数值 | 相对中间价 | 谁在用 |
|---|---|---|---|
| 现汇买入价 | **6.6701** | **−0.75%** | **出口结汇（本案例）** |
| 现汇卖出价 | 6.6982 | −0.34% | 进口购汇 |
| 中钞折算价 | 6.7208 | 0% | 银行内部记账，不是成交价 |

**这一栏是全案例最重要的发现**：纸面上的 6.7208 和真正到手的 6.6701，差 0.75%。10 万美元一单，光这一项就差 **5,070 元**人民币——比大多数人对"汇率风险"的想象更具体。

### 2.3 交叉核对

| 来源 | USD/CNY | 差异 | 结论 |
|---|---|---|---|
| SAFE 中间价 | 6.7208 | 基准 | — |
| 中国银行折算价 | 6.7208 | 0.00% | 一致 ✓ |
| Frankfurter（ECB） | 6.6862 | −0.52% | 口径/时点不同 |
| open.er-api | 6.69274 | −0.42% | 聚合器路径不同 |

0.4%~0.5% 的差异是正常的。**但正因为有这种差异，报价单上必须写清用的是哪个口径**，否则事后无法对账。

## 三、历史位置：现在贵还是便宜

数据：735 个交易日（2023-10-09 ~ 2026-10-19），来自 SAFE，缺失的 56 个工作日全部是法定节假日，未插值。

### 3.1 分位

| 窗口 | 样本 n | 最低 | 最高 | 均值 | **当前分位** | 距最高 | 区间宽度 |
|---|---|---|---|---|---|---|---|
| 近 1 年 | 242 | 6.7208（2026-10-19） | 7.0973（2025-10-20） | 6.8978 | **0.21%** | −5.30% | 5.60% |
| 近 3 年 | 725 | 6.7208（2026-10-19） | 7.2133（2025-04-16） | 7.0585 | **0.07%** | −6.83% | 7.33% |

**读法**：分位 0.21% 意味着，过去一年里只有 0.21% 的交易日美元比今天更便宜。换句话说——**今天的汇率处在近一年、近三年的最低位置附近**。

更直白地说：今天（2026-10-19）的 6.7208 就是这两个窗口里的**最低值本身**（表里 `min` 列显示 6.7208，出现日就是今天）。分位之所以不是 0%，是因为公式给"等于当前值"的样本记了半个权重。

> **注意本案例的实际情形**：当前值恰好是全窗口最低，所以"历史分位"和"距最低"这两个指标都退化成了边界情况——分位 ≈ 0.2%，距最低 = 0%。这是真实结果，不是计算错误。它避免了"当前值本身就在样本里"导致的系统性低估。

### 3.2 这句话能说什么、不能说什么

✅ 能说：
- "当前汇率就是近 1 年、近 3 年的最低值（分位 0.21% / 0.07%）"
- "近 1 年美元从 7.0973 跌到 6.7208，跌了 5.30%"
- "过去一年 242 个交易日里，今天是最便宜的一天"

❌ 不能说：
- "所以要赶紧锁汇"（推荐避险操作）
- "低位意味着会反弹"（预测方向）
- "不会再跌了"（预测）

**分位低不等于会涨。** 一个持续下行的品种可以在低位待很久。这正是为什么本案例只报事实、不做判断。

### 3.3 波动幅度说明了什么

```
近 1 年已实现年化波动 σ = 1.06%
90 天（≈64 个交易日）典型波动 σ_90 = 1.06% × √(90/252) ≈ 0.53%
```

用大白话讲：**过去一年里，三个月内汇率动半个百分点属于常态。** 所以下文 ±1% 的档位不是夸张假设，而是"很可能会发生的事"。

> 再次强调：这是"过去波动多大"，不是"未来会跌多少"。

## 四、基准测算

用**中间价 × 点差带**口径（因为拿不到真实成交价，点差带是示例 ±0.25%）：

```
R_base = 6.7208 × (1 − 0.0025) = 6.703998
```

| 项目 | 数值 | 算式 |
|---|---|---|
| 外币金额 | 100,000.00 USD | — |
| 基准汇率 | 6.703998 | 中间价 ×(1−点差) |
| 人民币收入 | **670,399.80** | 100,000 × 6.703998 × (1−0) |
| 人民币成本 | 600,000.00 | ⚠️ 模拟 |
| **毛利额** | **70,399.80** | 670,399.80 − 600,000 |
| **毛利率** | **10.50%** | 70,399.80 ÷ 670,399.80 |
| **每 1% 敞口** | **6,704.00** | 670,399.80 × 1% |

"每 1% 敞口 6,704 元"是整份文件最该记住的数字。它把所有汇率话题翻译成一个销售能用的句子：**汇率动一个点，我这单挪七千块。**

## 五、敏感性：±1% / ±3% / ±5%

| 汇率变动 | 情景汇率 | 人民币收入 | 较基准变化 | 毛利额 | 毛利率 |
|---|---|---|---|---|---|
| −5% | 6.368798 | 636,879.81 | **−33,519.99** | 36,879.81 | 5.79% |
| −3% | 6.502878 | 650,287.81 | **−20,111.99** | 50,287.81 | 7.73% |
| −2% | 6.569918 | 656,991.80 | −13,407.99 | 56,991.80 | 8.67% |
| −1% | 6.636958 | 663,695.80 | −6,704.00 | 63,695.80 | 9.60% |
| 0% | 6.703998 | 670,399.80 | 0 | 70,399.80 | 10.50% |
| +1% | 6.771038 | 677,103.80 | +6,704.00 | 77,103.80 | 11.39% |
| +2% | 6.838078 | 683,807.79 | +13,407.99 | 83,807.79 | 12.26% |
| +3% | 6.905118 | 690,511.79 | +20,111.99 | 90,511.79 | 13.11% |
| +5% | 7.039198 | 703,919.79 | **+33,519.99** | 103,919.79 | 14.76% |

**三句话总结：**

1. **对称**：跌 5% 亏 33,520，涨 5% 赚 33,520。因为这单是纯美元收入，没有对冲，天然对称。
2. **−5% 时毛利率从 10.50% 掉到 5.79%**，几乎腰斩——这是最该拿给老板看的一行。
3. **−3% 时毛利率还有 7.73%**，说明这单的缓冲不算薄。

## 六、平衡汇率：跌到哪儿白干

| 平衡点 | 汇率 | 距基准 | 含义 |
|---|---|---|---|
| **毛利额 = 0** | **6.0000** | **−10.50%** | 跌到 6.0 就一分不赚 |
| **保住 10% 毛利率** | **6.6667** | **−0.56%** | 只跌半个点就达不到 10% |
| 保住目标毛利额 70,399.80 | 6.0000 | −10.50% | 与毛利=0 相同（因为设定值就是当前毛利） |

### 6.1 这两个数字的反差值得单独说

- **要亏钱，汇率得跌 10.5%**（从 6.704 跌到 6.0）——按近一年 1.06% 的年化波动，90 天跌 10.5% 是**极小概率事件**。所以"这单会亏"这个担心，基本上不成立。
- **但要做到 10% 毛利，汇率只能跌 0.56%**（跌到 6.6667）——而 90 天典型波动就有 0.53%。也就是说，**"保住 10% 毛利"这个目标，本身的容错空间比正常波动还小**。

这个反差是整份测算最有价值的发现：**真正脆弱的不是"会不会亏"，而是"能不能达到预期的毛利"**。销售把 10% 写进方案时，通常没想到这个目标只值 0.56% 的汇率容错。

### 6.2 报价的下一步

如果一定要保 10% 毛利，在汇率不变的前提下需要：

```
A_min = C / [(1 − m) × (1 − t) × R]
      = 600,000 / (0.9 × 1 × 6.703998)
      = 99,455.6 USD  → 单价（按 377 吨）= 263.8 USD/吨
```

现价 100,000 USD 对应 265.3 USD/吨。也就是说，**光为了汇率容错，报价就该往上抬约 0.55%**。抬不抬得动是商务问题，但"需要抬多少"这个数是算出来的。

## 七、分批结算

### 7.1 方案（⚠️ 比例为模拟）

| 批次 | 金额 | 距今天数 |
|---|---|---|
| T/T 30% 定金 | 30,000 USD | 0 天 |
| 装运后 60 天付 40% | 40,000 USD | 60 天 |
| 提单日 90 天付 30% | 30,000 USD | 90 天 |

### 7.2 结果

```
加权汇率     = Σ(A_i × R_i) / ΣA_i = 6.7040
加权平均天数 = (30,000×0 + 40,000×60 + 30,000×90) / 100,000 = 51.0 天
分批折算合计 = 670,399.80（与一次性相同，因为各批假设汇率都取基准）
```

### 7.3 分批的敏感性

因为各批都取基准汇率，分批曲线与一次性完全重合：−5% 时同样 −33,520。

### 7.4 必须讲清的一句话

**分批不降低汇率风险。** 它降低的是"所有钱都卡在一个时间点上"的集中度。如果美元单边下跌，分批只是让 30% 的钱躲过了后续下跌、另 70% 没躲过——不存在必然更好的结果。

真正会改变分批结果的是**各批落在不同汇率上**，而那是未来的事，本文件不预测。所以这张表的正确用法是：把它当成"如果你对各批的汇率有假设，分别填进去看看总数变成多少"的试算器，而不是"分批更好"的证据。

## 八、这单没算进去的东西

按影响大小排：

| 缺口 | 本案例分析 |
|---|---|
| **结汇手续费、电讯费** | 按笔收，大额可议；费用率填 0 意味着**低估了成本** |
| **银行点差** | 用了示例 ±0.25%；中行实测买入价比中间价低 0.75%。**真实点差比示例大 3 倍**，因此基准汇率可能还偏乐观 |
| **远期锁汇点价** | 完全未取。要知道锁汇成本需要掉期点报价，属独立任务 |
| **交易日与节假日** | 2027-01-17 附近有春节，实际可结汇日可能顺延 |
| **退税** | 纯碱出口退税率会影响实际成本，未计入 |
| **成本端汇率联动** | 若部分原料以美元计价，人民币成本会随汇率同向变动，抵消部分风险 |
| **合同汇率条款** | 是否约定"汇率波动超 X% 重新议价"会改变实际暴露 |
| **多币种** | 本单单一美元，无交叉盘问题 |
| **样本口径** | 历史分位用中间价，而结汇用牌价，两者常年差 0.4%~0.8% |

**把点差这一条展开说**：本案例用 ±0.25% 算基准汇率 6.7040，但中行实际买入价是 6.6701，对应点差 0.75%。若改用真实成交价：

```
收入 = 100,000 × 6.6701 = 667,010
毛利 = 667,010 − 600,000 = 67,010（毛利率 10.05%）
```

比示例口径少 3,390 元。**这就是为什么文件里口径可以一键切换**——同一笔单子，换个口径就少三千多块，销售必须知道自己在用哪个。

## 九、交给销售的五句话

1. **今天美元中间价 6.7208（2026-10-19 09:15），出口结汇看的是银行现汇买入价 6.6701，比中间价低 0.75%。**
2. **这个价位处在近一年分位 0.21%、近三年分位 0.07%——历史最低区间附近。** 但分位低不代表会涨，这里不做方向判断。
3. **汇率每动 1%，这单挪 6,704 元；动 5%，挪 33,520 元，毛利率从 10.50% 掉到 5.79%。**
4. **要亏钱得跌到 6.0000（−10.5%），按历史波动基本不会发生；但要保住 10% 毛利，只能跌到 6.6667（−0.56%），容错比正常波动还小。**
5. **成本 60 万、目标毛利 10%、分批 30/40/30 都是模拟值，换成真实的只需在 Excel 黄底格或 HTML 输入框里改，全表立即重算。**
