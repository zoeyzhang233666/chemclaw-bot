## 案例 01 是什么

一笔中国出口**重质纯碱**（Dense Soda Ash, Na₂CO₃ ≥ 99.2%）的订单：

- 金额 100,000 美元，90 天后收汇（结算日 2027-01-17）
- 人民币成本 600,000 元 ⚠️ 模拟
- 目标毛利率 10% ⚠️ 模拟
- 分三批收：签约 30%、装运后 60 天 40%、提单日 90 天 30% ⚠️ 模拟
- 汇率数据：官方中间价（SAFE，2026-10-19 09:15）+ 中行牌价（16:27:56）

### 为什么选这个案例

它同时踩中了三个教学点：

1. **中间价 vs 实际成交价**：6.7208 vs 6.6701，差 0.75%，10 万美元差 5,070 元
2. **分位退化成边界值**：当前值恰好是全窗口最低，分位 0.21% / 0.07%，考验"这到底是 bug 还是事实"
3. **"不亏"和"达目标"是两个完全不同的距离**：−10.50% vs −0.56%

## 怎么加一个新案例

1. 建目录 `examples/02-your-case/`
2. 写 `case.json`（字段见 `references/data-contract.md`）
3. 跑：

```bash
python scripts/run_case.py examples/02-your-case/case.json
python scripts/build_html.py --scenario examples/02-your-case/build/scenario.json --out <html>
python scripts/build_xlsx.py --scenario examples/02-your-case/build/scenario.json --out <xlsx>
```

4. 跑校验（见 `references/qa-checklist.md`）
5. 写 `README.md` 走查，重点说明这个案例**新增了哪个坑**

### 值得做的后续案例

| 案例 | 价值 |
|---|---|
| 进口付汇（如进口硫磺，60 天后付款） | 验证方向切换：符号、表头、平衡汇率、危险方向全部相反 |
| 欧元出口（EUR/CNY） | 验证换币种：序列自动切换，分位与波动不同 |
| 日元（100JPY 口径） | 验证单位陷阱，最容易出 100 倍错误 |
| 180 天 OA 长账期 | 显示期限对典型波动幅度的影响 |
| 亏损订单（成本 > 收入） | 平衡汇率高于当前汇率的情形，文案不能说"还会跌多少" |

## 已知的演示局限

案例 01 是**演示性质**的，这些数字不能当真实成交依据：

- 人民币成本、目标毛利率、结算期限、分批比例均为模拟
- 银行点差带 ±0.25% 是示例，实测中行买入价对应点差约 0.75%
- 未取任何远期锁汇点价
- 汇率数据截至 2026-10-19，之后需重新取数

真实使用时，把这些替换成实际值并重跑即可。
