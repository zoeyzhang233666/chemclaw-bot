# overseas-inquiry-triage · 处理一封海外询盘

> ChemClaw 场景技能库 · 外贸销售 05
> 把一封海外询盘，变成**有原文依据的字段表 + 缺口清单 + 可直接发的英文回复草稿**，
> 而且**一个数字都不许自己编**。

---

## 30 秒看懂

| 问题 | 本技能的回答 |
|---|---|
| 客户到底要什么？ | 8 类共 64 个字段，每个值都挂一句客户原话 |
| 哪些是客户说的，哪些没人说过？ | 三态：`已明确` / `缺失` / `歧义`（+ 我方 `假设`、`内部待定`） |
| 报价前必须先问客户什么？ | A 类缺口 → 最多 6 条英文问句，点击可回原文 |
| 现在我该怎么回？ | 4 套模板 × 3 档语气，价格/交期/付款/单证全部占位符 |
| 我已经写好稿了 | 润色通道：只改语言，新增承诺一律拦下 |

**这不是一个翻译工具，是一个"防编造"工具。**
业务员最容易犯的错不是英文差，是为了让邮件"读起来完整"，把没人确认过的价格、交期、单证填进去。
本技能用字段状态机 + 占位符协议 + 三层闸门（脚本 / 页面 / 自检）把这条路堵死。

## 产物长什么样

跑一封询盘（`make_example.py`）会得到 7 个文件：

```
examples/example-1-id-soda-ash-dense/
├── 04_询盘审阅板.html      ← 主战场：左原文 / 右字段，点字段跳原文
├── 05_询盘处理工作簿.xlsx   ← 8 张表，走内部评审、留痕
├── 03_英文回复草稿.md       ← 直接复制进 Outlook
├── 06_中文缺口简报.md       ← 30 秒版，给老板
├── 01_标准化字段.json       ← 系统对接
├── 02_英文回复草稿.json
└── 07_运行自检.txt
```

### 双栏审阅板（纯前端单文件，素材不出本机）

- 六个页签：① 双栏审阅 ② 缺失与歧义 ③ 待确认问题 ④ 英文回复草稿 ⑤ 已写稿润色 ⑥ 下一步场景；
- 点右栏任一字段 → 左栏原句高亮并滚动到该行；
- 字段可改写、可标记「客户已确认」，A 类缺口随之关闭，报价闸门 `LOCKED → OPEN`；
- 回复区可切语气/模板、重新生成、预览占位符高亮、填值、复制、下载；
- 润色区粘贴自写稿 → 输出改动清单 + 新增承诺/新增数字检查（有新增就拒绝输出）。

### 工作簿（8 张表）

`00 阅读说明` → `01 询盘概要` → `02 标准化字段` → `03 原始询盘` → `04 缺失与歧义` →
`05 待确认问题` → `06 英文回复草稿` → `07 证据与素材`。
缺失=红、歧义=黄、假设=紫、已明确=绿；第 07 表是每个字段的原句出处。

## 硬约束（5 条，不可谈判）

1. **不产生价格**——没有默认价、参考价、区间价、历史价；价格位一律 `‹PRICE_PER_MT_...›`。
2. **不产生商务承诺**——库存、船期、交期、账期、单证能力、认证、样品费，客户没说就是没说。
3. **不补 CAS / HS / 公司**——CAS 只来自客户原话、我方资料或权威库（并记录来源与日期）。
4. **抽不到就留空**——`缺失` 不是 `0`，`歧义` 不是 `取个常见值`。
5. **润色不加料**——只改语言，不改事实、不升级承诺。

另外两条边界：**不给询盘真实性打分，不给成交可能性打分**；
价格去「算出口报价」，公司背景去「核验海外询盘公司」，出口监管去「查产品出口要求」。

## 快速开始

```bash
# 只需要 Python 3.9+（标准库即可；Excel 需要 openpyxl）
# 1) 一键跑通示例
python scripts/make_example.py examples/example-1-id-soda-ash-dense

# 2) 换成你自己的邮件
cp -r examples/_skeleton examples/my-inquiry
#   把客户邮件放进 examples/my-inquiry/input/（.eml / .txt / 合并 md 均可）
python scripts/make_example.py examples/my-inquiry

# 3) 打开 04_询盘审阅板.html 逐项核对
# 4) 把 03_英文回复草稿.md 的占位符填实，再发
```

命令行细节、参数、闸门说明见 `INSTALL.md`；
给别的 agent 用（Claude Code / Cursor / 本地 Agent）见 `AGENTS.md` 与 `PORTABLE_PROMPT.md`。

## 换品类

`products/` 里已有 7 个产品画像（重质纯碱、轻质纯碱、片碱、液碱、尿素 46%、钛白粉、PVC SG-5）。
换品类只要加一个 JSON：品名中英 + 别称 + 多语言别名 + CAS/EC + HS 候选 + 常见规格 + 包装选项 + 易错点。
抽取脚本会自动把客户本地语言品名对到画像上；**CAS 仍然要写明来源**。

## 已知边界（诚实说明）

- 抽取以**规则 + 产品画像**为主，不做大模型猜测：英文/印尼/越南等常见句式覆盖较好，
  小语种冷门写法会漏 → 漏了会显示"缺失"，**不会猜错**；漏了请人工补，补完再生成。
- 危险品（片碱、液碱）的订舱、危包证、目的港接受条件**不在本技能范围内**，只做提示。
- 报价、公司核验、出口监管、合同审阅都是下游场景，本技能只负责把参数**干净地交出去**。
- 模拟样例中的公司、联系人、数量均为虚构，仅用于演示。
