## 1.0.1 — 2026-10-19

### 修复

- **窄窗口下右侧字段区被原始询盘挡住看不见**（用户实测反馈：笔记本小屏 / 浏览器窗口未最大化）。
  根因有两处：① 单栏断点设在 1180px，1024/1100 宽的笔记本窗口过早退化成单列；
  ② 退化到单列时左侧"原始询盘"面板的 `max-height` 没有重置，面板按内容撑满整屏（20+ 行原文），
  把右侧字段区整块顶到屏幕下方。
  改法：断点下调到 960px（960px 以上保持左右双栏）；单栏时 `.source` 限高 `44vh` 并保留内部滚动；
  双栏列宽下限从 380/520 放宽到 320/420，避免窄屏横向挤压。
- `selftest_workbench.mjs` 新增 4 项**布局回归断言**（1440 / 1100 / 1024 / 900 四档宽度）：
  字段区不被左栏压到下方、左栏高度不超视口且可滚到底、1024–1100 宽仍为双栏、≤960 正确降级单栏。
  已用旧样式反证：改动前该断言会在 1024/1100 宽报 FAIL。

## 1.0.0 — 2026-10-19

首个可交付版本（ChemClaw 场景技能库 · 外贸销售 05）。

### 核心能力

- **八类 64 字段抽取**：买方、产品化学、规格、数量、交付与术语、商务、单证合规、买方背景；
  每个值带 `source_id` + `quote`（原句原语言）+ `locator`，三态 `stated / missing / ambiguous`。
- **三桶分级与报价闸门**：A 类（报价前必须确认）/ B 类（可带我方假设，渲染时必须标
  `(our assumption – to be confirmed)`）/ C 类（我方内部先定）。A 类未齐时 `can_quote=false`，
  页面「生成报价」按钮锁定并列出阻塞字段；人工放行需留痕（`confirmed_by`）。
- **缺口 → 问句**：只为 A 类缺口与真歧义生成问题，最多 6 条，封闭式、带客户原话锚点。
- **英文回复生成**：4 套模板（确认式 / 报价结构式 / 样品式 / 单证式）× 3 档语气，
  价格与全部商务承诺渲染为 `‹KEY›` 占位符；`build_md.py --pack` 对未确认占位符 exit 3。
- **润色通道**：用户自写稿只改语言；新增承诺 / 新增数字 / 事实值改动一律拦截并回退。
- **交付**：单文件离线 HTML 双栏审阅板（6 页签）、8 表 Excel 工作簿、可复制英文草稿、
  中文一页简报、结构化 JSON。

### 反编造机制

- `COMMITMENT_PATTERNS` 17 类承诺句式 + `PRICE_PATTERNS` 金额句式，正文与润色区常驻扫描。
- 术语与港口冲突检测：`FOB` 后接买方港口 → 标歧义并追问（FOB 中国港口 vs CFR/CIF 目的港），
  同时把价格占位符降级为 `‹PRICE_PER_MT_TERMS_TBC›`，绝不拼出错误报价口径。
- 能力问句识别：`C/O form E ... có cung cấp được không?` 这类问句不记为客户要求，
  只记歧义并要求回复"按核实结果确认"。
- 数量口径分离：试单量 / 年量 / 月量 / 单批量分字段；千分位与小数点按国别判断并写明依据。
- CAS 只能来自客户原话 / `products/` 画像 / 权威库，且必须记录来源与查证日期。
- **不评估询盘真实性，不评估成交可能性**，不出现客户分级或可信度百分比。

### 多语言

- 内置越南语、印尼语、西班牙语、葡萄牙语、阿拉伯语、俄语、日语、韩语的数字与条款锚点
  （`scripts/extract_i18n.py`）。
- 双语问句库覆盖中 / 英 / 印尼 / 越 / 葡 / 西 / 阿 / 日（`references/missing-and-questions.md`）。

### 产品画像

重质纯碱、轻质纯碱、片碱、液碱、尿素 46%、钛白粉、PVC SG-5 共 7 个，含 CAS / EC / HS 候选 /
常见规格 / 包装选项 / 易错点。换品类只需增加一个 JSON。

### 质量保障

- `scripts/selfcheck.py`：12 项产物自检 + 技能包结构自检，任何 FAIL 不许交付。
- `scripts/selftest_workbench.mjs`：24 项页面功能自测（无头 Edge/Chrome，零第三方依赖），
  覆盖点击定位、字段修正、问题关闭、报价闸门、语气切换、承诺扫描、占位符填充、润色拦截、交接 JSON。
- `scripts/make_example.py`：一条命令重建示例全部产物，新同学 30 秒内看到效果。

### 示例

- `example-1-id-soda-ash-dense`：印尼玻璃厂 · 重质纯碱，英文询盘，CFR Semarang，300 MT + 年量。
- `example-2-vn-caustic-soda-vi`：越南经销商 · 片碱，**越南语**询盘，含 FOB 港口冲突、L/C、
  包装 25 kg / 1000 kg 冲突、FORM E 能力问句。
- `examples/_skeleton`：空白骨架，换品类整目录复制。

### 已知边界

- 抽取以规则 + 产品画像为主，不做模型猜测：冷门小语种写法会漏 → 显示"缺失"，不会猜错。
- 危险品订舱、危包证、目的港接受条件不在范围内，仅作提示。
- 报价、公司核验、出口监管、合同审阅为下游场景。
