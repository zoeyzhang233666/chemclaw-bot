# 素材 02 · 客户补充微信/聊天转述（非邮件原文，仅作背景）

```text
销售备注（2026-11-04，河内展会现场，客户口头）：
- 客户说"bao bì 25kg là chính"（主要是 25kg 包装），但也提到大客户要 jumbo。
- 客户说"cần C/O form E"，并问我们"có làm được không"（能不能做），
  这是**询问**不是要求——不能当成客户已确认的条款。
- 客户提到第一次直接从中国进口，之前从韩国/日本转手，价格敏感。
```

---

## 故意设计的缺失与歧义（教学点）

| # | 情形 | 应有的处理 |
|---|---|---|
| 1 | `Thanh toán: L/C.`（付款：L/C） | 只说 L/C，缺即期/远期、期限、开证行 → **歧义**，要问 |
| 2 | `40 tấn` 与 `800 tấn/năm` | 首批与年量混在一句里 → 必须分字段，**不能把年量当首单量** |
| 3 | `FOB Hải Phòng` | **目的港写的是越南港口，但 FOB 后面应是装运港** → 卖方装运港 vs 买方指定港口冲突，**必须问清**是 FOB 中国港口还是 CIF/CFR 海防 |
| 4 | `25kg/bao` + `jumbo 1000kg` | 包装二选一，客户要**两个包装的价差** → 不能只回一个包装，也不能假设用哪个 |
| 5 | `C/O form E` + "có cung cấp được không" | 是**询问能力**，不是既定要求 → 回复只说"核实后确认"，不能承诺"包提供" |
| 6 | `xút vảy (NaOH 99%)` | 片碱 99% 明确；但未说是否危险品包装、UN 认证袋 → 危包能力需内部确认 |
| 7 | 未提报价有效期 / 目的港 / 交货期 / 币种 | **缺失**，不能用默认值填 |
| 8 | `đơn hàng đầu tiên`（首单） | 首单即可，但未说是否试单/一次性，也未说分批 → 不假设 |
| 9 | `nhà máy giấy và xử lý nước`（造纸与水处理） | 用途已给，可作为规格建议依据，但**不能据此改写客户的 99%** |
| 10 | 客户为**分销商/贸易商**而非终端工厂 | 主体性质影响核验重点（下游终端、最终用户申报），需在核验场景跟进 |

> 本样例的关键训练点：**FOB + 越南港口** 是典型的"客户把自己国家的港口写在 FOB 后面"，
> 这是外贸里最常见、后果最严重的照抄错误之一——照抄进合同等于卖方承担到越南的运费。
