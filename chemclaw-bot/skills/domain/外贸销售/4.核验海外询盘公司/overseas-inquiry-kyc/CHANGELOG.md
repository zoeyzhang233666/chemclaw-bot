# CHANGELOG

## 1.0.0 — 2026-10-19

首个可交付版本。

### 新增

- **五区块核验框架**（A 身份 / B 业务 / C 联系方式 / D 风险 / E 缺口），产品无关、国别无关。
- **三分法状态模型**：`已核实` / `存在疑点` / `未核实`（+ `不适用`），强制每条结论落到具体来源与下一步。
- **单文件交互 HTML 报告**：封面环形统计、询盘原件（模拟水印）、字段提取、注册主体、
  业务相关性（KBLI 对照）、联系方式一致性矩阵、可筛选核验结论、公开风险、
  资料索取清单、英文话术（可复制）、三分结论、来源抽屉、打印样式。
  状态筛选 / 区块筛选 / 搜索 / 展开全部 / 来源跳转 / 数字键盘可达。
- **14 表 Excel 工作簿**：封面、询盘原文、字段提取、注册主体、业务相关性、
  联系方式一致性、核验结论、公开风险、待索取资料、行动清单、状态透视、来源库、
  英文话术、方法与边界。含筛选、冻结窗格、状态底色、下拉状态选项。
- **单一数据源 `inquiry.json`**：HTML 与 Excel 由同一份数据生成，永不发散。
- **脚本工具链**：
  - `validate.py` — 结构与纪律校验（已核实必须有来源、疑点必须有边界、禁用表述检测）
  - `build_all.py` — 一键校验 + 生成两份产物 + 回执
  - `build_html.py` / `build_xlsx.py` — 各自独立的构建器
  - `check_xlsx.py` — Excel 结构自检（状态色、筛选位置、合并区冲突、列宽、乱码），无需图像渲染
  - `check_render.py` — HTML 渲染 QA（1440/820/390px：横向溢出、文字裁切、空区段、交互、控制台）
  - `selfcheck.py` — 交付前 74 条断言
  - `pack_skill.py` — ZIP 打包并校验必需条目
- **参考手册 12 篇**：快速开始、检索手册（多语种检索式）、证据分级、三分法边界案例、
  12 类联系方式矛盾、索取清单与话术、产品口径（纯碱/钛白/溶剂/树脂/化肥/锂电）、
  数据契约、可移植性、QA 清单、失败日志、国别手册（印尼 + 20 国索引）。
- **示例**：`id-soda-ash-demo`（印尼重质纯碱模拟询盘，24 条核验：4 已核实 / 2 疑点 / 18 未核实）
  与 `_skeleton`（空白骨架）。

### 关键设计决定

- **不给概率性判断**，不出现"诈骗概率""大概率是骗子"。
- **不以域名注册时间/网站新旧/邮箱后缀单独判真伪**。
- **"未核实"不等于"虚假"**：公开渠道未覆盖是常态，不得据此判定企业不存在。
- **同名企业严格隔离**：只有唯一标识（登记号/NIB/税号/LEI）相同才允许合并信息。
- **疑点必须带边界**（`boundary`）：说清"为什么它还不算致命"，防止过度解读。
- **模拟数据强制打标**：`meta.synthetic=true` 时页面出现横幅 + 水印 + 标题前缀，
  防止虚构主体被当成真实注册企业。

### 修复（开发过程中的问题，已固化进代码与文档）

- 状态单元格着色用中文文本反查导致 KeyError → 改为传 ASCII 状态键（`status_keys`）。
- 多模块重复包装 `sys.stdout` 导致 `I/O operation on closed file` → 加 `isinstance` 守卫。
- Excel 合并区与写值顺序冲突（`MergedCell` 只读）→ 先写值再合并。
- 宽表格在 390px 撑出横向滚动 → `table.tbl` 全部包 `overflow-x:auto` 容器。
- LibreOffice 渲染后端在部分环境输出全黑图 → xlsx 验收改用几何/结构断言（`check_xlsx.py`）。
