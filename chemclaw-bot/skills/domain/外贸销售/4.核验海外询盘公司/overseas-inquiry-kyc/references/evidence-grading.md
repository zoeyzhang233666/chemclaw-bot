# 证据分级（Evidence Grading）

> 一条材料能证明什么，比它有说服力更重要。

## 一、四个等级

| 等级 | 定义 | 典型来源 | 可以支撑的结论 |
|---|---|---|---|
| **A** | 官方登记、政府公示、法定义务披露 | 商事登记册、营业执照、税务登记、海关进出口商号、法院公告、制裁名单、上市公司定期报告 | 「主体存在」「许可有效」「未在名单内」 |
| **B** | 独立第三方或企业自己发布的一手资料 | 企业官网 About/Contact/Products、年报、协会会员页、ISO/REACH 证号可查 | 「该企业从事该业务」「该地址是其办公地」 |
| **C** | 二手转述 | 行业媒体、黄页、展会名录、社媒、维基 | 只能作为线索，用于形成下一步核查方向 |
| **D** | 对方自述 | 邮件、名片、报价单、公司介绍 PDF、WhatsApp 消息 | **只能提取字段，不能作结论** |

代码中的取值：`grade: "A"|"B"|"C"|"D"`。

## 二、最容易误判的五种"伪证据"

### 1. 官网写着 "since 1998 / Leading manufacturer"
官网是**自我声明**，最高只能算 B，且必须配合"页面上的联系方式能否与邮件对上"才有意义。
单独一条"官网说自己是厂家"不构成任何结论。

### 2. 营业执照上的"经营范围"
只能证明"允许做"，不能证明"正在做"。
在印尼语境下还要更细：**KBLI 是业务分类，不是许可**；有 23111 不等于有生产装置，
但连 23111 都没有却自称"玻璃制造商"，就构成一个必须要求解释的矛盾。

### 3. 域名注册时间
- 注册很早 ≠ 正规：老域名可以买来用。
- 注册很新 ≠ 假：新市场、新子公司、代理注册都常见。
**结论：不单独作为判据**，只能放进 `matrix` 当佐证项。

### 4. 有个像模像样的企业邮箱
`andi.pratama@company.co.id` 只能说明"发信人会用这个域发信"。
真正的检查是：Reply-To 有没有跳走、SPF/DMARC 是否存在、官网 Contact 页是否列同一域。
即便如此，**这些依然只是佐证**——冒充者可以用相似域名（`company-co.id`、`company.co.id.xyz`）。

### 5. 名片 + 公司介绍 PDF
自己做的，成本接近零。它们是 D 级，作用是**提供字段去核对**，不是证据本身。

## 三、判定规则（写代码时照抄）

```python
can_claim_exists   = any(grade == "A" and kind == "registry")     # 只有 A 级登记才能说"存在"
can_claim_business = any(grade in ("A","B"))                     # A/B 才能说"确实在做这行"
never_claim        = grade == "D"                                # 自述永远不能进 verified
```

对应 `checks` 里：

- `status = verified` → 必须有 A 或 B 级 `source_ids`；
- `status = unverified` → 只有 D 级或没有来源，**不算失败**，是正常状态；
- `status = discrepancy` → 必须有两条以上来源**互相矛盾**（或自述与常识的量化关系对不上）。

## 四、"缺一项" vs "对不上"

这是本 skill 最核心的区分，写报告时逐字检查：

| 场景 | 写法 | 错误写法 |
|---|---|---|
| 没给 NIB | 未核实（`unknowns: ["NIB"]`） | 疑似皮包公司 |
| 给了成立年份但查不到登记 | 未核实（口径：自述 D 级） | 虚报成立时间 |
| 签名地址是 A 市、正文说工厂在 B 市 | 存在疑点（`partial`，附说明：注册地/厂区/仓库需分离） | 地址造假 |
| 官网 Contact 邮箱是 gmail | 未核实 + 注意（常见于中小企业，但需第二渠道） | 假公司 |
| 声称 2 万 m² 产能、却年采购 2.5 万吨原料 | 存在疑点（量化算不通，要求补熔窑数据） | 骗子 |
| 要求先签 NDA 才给证照 | 存在疑点（低严重度，**是流程问题**） | 拒绝提供资料=心虚 |

## 五、引用格式

每条来源写：

```json
{
  "id": "SRC01",
  "name": "Ditjen AHU Online · Pencarian Perseroan",
  "org": "Kementerian Hukum dan HAM RI",
  "url": "https://ahu.go.id/",
  "grade": "A",
  "kind": "registry",
  "date": "2026-10",
  "retrieved": "2026-10-19",
  "note": "印尼 PT 登记官方入口；按全称或登记号检索。"
}
```

`note` 里那句"这条能证明什么、不能证明什么"比链接本身更有价值——下次复核的人看的就是这句话。
