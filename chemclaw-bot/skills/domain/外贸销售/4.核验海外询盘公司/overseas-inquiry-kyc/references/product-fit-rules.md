# 不同化工品的业务相关性口径（Product Fit Rules）

> 这一页替换的是**"什么算业务合理"**。核验框架、三分法、矩阵、话术全部不变。

## 一、通用四问

对任何产品，先回答这四问再写 `business_fit`：

1. **谁买**：这个产品的下游工厂类型是什么？（不是"化工厂"这种笼统答案）
2. **买来干什么**：在对方工艺里充当什么角色？（原料 / 助剂 / 溶剂 / 催化剂 / 包装材料）
3. **买多少**：吨级与单次订单之间能否用"产能 × 单耗"反算通？
4. **怎么用**：形态（重质/轻质、固/液、片/粉）、包装（吨袋/槽车/ISO 罐）、储运条件是否匹配？

四问里任何一问算不通，就写 `unverified`（口径待澄清），并挂上对应的 `next_ids`。

## 二、分品类口径

### 纯碱（Soda Ash, Na₂CO₃）

- **下游**：玻璃（浮法/器皿/瓶罐，最大）、洗涤剂、硅酸钠、碳酸氢钠、冶金。
- **形态**：重质（dense，0.9–1.2 g/cm³，玻璃级）/ 轻质（light，洗涤级）。**形态说错就说明对方不熟**。
- **反算**：玻璃行业的纯碱单耗约每吨玻璃 0.15–0.20 t（按配方与碎玻璃比波动）。
  用"熔窑日熔化量（t/d）× 单耗 × 330 天"验证对方报的年采购量。
- **警惕口径**：用 m² 报玻璃产能（薄厚不同差很多）、把"加工玻璃"当"原片"、把集团产能算到自己名下。
- **规格缺失**：Fe₂O₃ 上限、堆积密度、粒度分布——玻璃客户最在意，没提就要追问。

### 钛白粉（TiO₂）

- **下游**：涂料、塑料、油墨、造纸、化纤（消光）。
- **形态**：金红石型（颜料级，最主流）/ 锐钛型（造纸、化纤）。
- **关键规格**：表面处理（Al/Si/Zr）、吸油量、分散性、遮盖力、耐候等级。
- **警惕口径**：把"硫酸法/氯化法"说成下游选择依据；把牌号说错（R型/A型混淆）。

### 溶剂（甲醇、丙酮、乙酸乙酯、MIBK…）

- **下游**：涂料/油墨（稀释）、制药（反应溶剂）、胶粘剂、清洗。
- **形态**：散装（槽车/ISO 罐）为主；小批量才用桶。
- **关键**：水分、纯度、色度、是否有危化品资质（危化品经营/运输许可）。
- **警惕口径**：只报"吨"不报"槽车/罐"；危化品企业却没有相应许可——这是**实质**疑点。

### 树脂（PVC、PP、PE、环氧、不饱和聚酯）

- **下游**：管材型材（PVC）、注塑薄膜（PP/PE）、复合材料（环氧）。
- **形态**：粉料/粒料，25kg 袋或吨袋。
- **关键**：牌号（牌号决定用途）、熔指（MFI）、K值（PVC）。
- **警惕口径**：只给大类不给牌号——无法判断用途，必须追问。

### 化肥（尿素、MAP、DAP、氯化钾）

- **下游**：农业直施、复合肥厂、工业用途（车用尿素、三聚氰胺）。
- **形态**：颗粒/粉/大颗粒（区别很大）。
- **关键**：N/P/K 含量、水分、粒度、是否是农业级。
- **警惕口径**：农业与工业用途混谈；涉及进口许可（很多国家对化肥有配额/许可）。

### 锂电材料（磷酸铁、磷酸铁锂、前驱体、电解液）

- **下游**：正极材料厂、电池厂。
- **关键**：比表面积、振实密度、杂质（金属异物 ppb 级）、一致性批次。
- **警惕口径**：只说"电池级"但给不出批次数据；用"中试线"数据对量产询价。

## 三、业务相关性的三条判断线

### 线 1：产品—行业是否天然相关
纯碱 → 玻璃 ✔；纯碱 → 服装厂 ✘（除非它同时有玻璃业务）。
**不相关就要问："您是用在哪里？"** ——这是合法的问题，不是冒犯。

### 线 2：规模是否能被产能解释
用该国/该行业的单耗区间反算。算不通 → `unverified`（口径待澄清），
**不算** `discrepancy`（除非两个自述之间直接冲突）。

### 线 3：形态/包装/物流是否匹配
- 重质纯碱配吨袋 ✔；轻质纯碱配吨袋也常见，但用于玻璃就说明对方不熟。
- 溶剂配 25kg 桶且年用量 1 万吨 → 物流成本极高，说明口径或产品有误。
- 危化品配"普通仓"→ 需要危化品仓储资质。

## 四、写进 `business_fit` 的标准结构

```jsonc
{
  "headline": "一句话：产品与行业逻辑成立 / 成立但规模口径待核 / 不成立需要追问用途",
  "product_use": "该产品在对方行业里的角色（一句话）",
  "demand_math": [
    {"label": "对方自述产能", "value": "1.2 百万 m²/年", "note": "对两座浮法窑偏低，需核实口径"},
    {"label": "纯碱需求（自述）", "value": "25,000 MT/年", "note": "约 2,083 MT/月"},
    {"label": "行业粗算口径", "value": "纯碱约占配料 10–20%", "note": "需用对方熔窑 t/d 反算"}
  ],
  "keywords": [ {印尼/印度/etc 业务分类码对照} ],
  "signals":  [ {产品形态/规格/规模/物流/身份 五类信号} ]
}
```

## 五、要避免的三个错误

1. **把"行业相关"写成"客户可信"**。业务相关性成立 ≠ 主体真实 ≠ 规模属实。
2. **把"算不通"写成"造假"**。口径不同（只算一条线、只算成品面积）是最常见原因。
3. **把"对方不懂产品"当成风险**。可能是采购新手，也可能是中间人——**问一句就能区分**。
