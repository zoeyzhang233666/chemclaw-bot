# 三分法判定（Verdicts）

> 三种状态不是"好/中/差"，而是**三种不同的问题**。

## 一、三种状态的定义

| 状态 | 含义 | 客户能拿它做什么 | 典型句式 |
|---|---|---|---|
| `verified` 已核实 | 有 A/B 级来源，事实成立 | 可以写进合同前置条件 | "在 AHU 登记册检索到同名主体，登记号 XXX" |
| `discrepancy` 存在疑点 | 两个来源互相矛盾，或自述之间算不通 | 必须要求对方解释后才能推进 | "签名地址在 Cakung，正文称工厂在 Bekasi，两处均未说明用途" |
| `unverified` 未核实 | 没有可用的公开来源，或材料未取得 | 进入资料索取清单，**不影响判断** | "未取得 NIB，无法在 OSS 检索" |

## 二、最重要的边界规则

### 规则 1：查不到 ≠ 虚假
公开渠道未覆盖，只说明"现在没有证据"，不说明"证据是假的"。
> 反例（禁止出现）："检索 AHU 无结果，该公司可能不存在或为虚假注册。"
> 正例："模拟/本次未完成 AHU 检索；无结果可能来自名称写法、企业类型差异或未收录，需取得 NIB 后在 OSS 复核。"

### 规则 2：疑点必须是"两个东西对不上"
合格的疑点长这样：

- 地址：签名栏 `Cakung, Jakarta Timur` vs 正文"工厂在 Bekasi 工业区"；
- 规模：自述"两座浮法窑" + "120 万 m²/年" vs "25,000 t/年纯碱需求"，两个数不能同时成立；
- 身份：同一封邮件里同时自称 `glass manufacturer` 与 `official importer`；
- 流程：把"注册证照"和"商业机密"绑在同一个 NDA 条件下。

不合格的疑点：

- "感觉对方很不专业" → 无事实
- "邮件里有很多语法错误" → 只说明语言习惯
- "网站做得比较简单" → 与真实性无关

### 规则 3：疑点必须同时写"为什么还不算致命"
这就是 `boundary` 字段。例：

> "地址不一致本身在制造业很常见：注册地 = 办公室、厂区在郊区、仓库在港区。
> 本条按'部分一致'处理，只有无法解释的地址矛盾才升级。"

没有 `boundary` 的疑点，在评审时会被当作"过度解读"退回。

### 规则 4：严重度只对疑点有意义

| 严重度 | 判据 | 处理 |
|---|---|---|
| high | 直接影响"能不能交易"：主体不存在证据、收款账户异常、制裁命中 | 暂停报价与发运 |
| medium | 影响"怎么交易"：身份角色不清、规模口径算不通、联系方式单通道 | 继续沟通但同步补齐 |
| low | 流程/表述层面：NDA 前置、格式差异 | 记录 + 在回信里改进 |

### 规则 5：已核实也要写"它证明什么、不能证明什么"
例：
> `verified`："产品形态与用途匹配——重质纯碱是浮法玻璃主要助熔剂。"
> `boundary`："业务相关只说明询价合理，不说明主体真实，也不说明规模属实。"

## 三、高频边界案例对照表

| 情形 | 应判 | 理由 |
|---|---|---|
| 邮件域名与官网域名一致，但官网打不开 | 未核实 | 无法交叉验证 |
| 官网 Contact 页列出同一邮箱 | 已核实（C 区块一条） | 两个独立位置一致 |
| 官网 Contact 页邮箱是 gmail | 未核实（注意） | 常见，不构成疑点 |
| 对方用 freemail 发询盘但名片写企业域名 | **存在疑点**（medium） | 渠道不一致，且可核实 |
| 报价里公司抬头与签名公司名不同 | **存在疑点**（high） | 合同主体不清 |
| 要求把尾款打到第三国个人账户 | **存在疑点**（high） | 反洗钱红线 |
| 收款账户户名与公司名不一致（对方解释为"代理收款"） | **存在疑点**（high） | 解释本身也是 D 级，不能采信 |
| 制裁名单模糊命中（名称相似但国家/行业不同） | 未核实 + 要求说明 | 不能直接判命中，也不能忽略 |
| 客户自称"年采购 5000 吨"但我方产品是包装规格的吨袋小批量 | **存在疑点**（low） | 量级不匹配，要求对齐口径 |
| 交易对手是新建公司（成立 1 年） | 未核实 | 新公司是正常的，不是风险本身 |
| 交易对手是新建公司 + 要求 90 天账期 + 首单大额 | **存在疑点**（high） | 组合触发，需要担保/信用证 |

## 四、`verdict_line` 的生成规则

```text
有 discrepancy 且 severity=high     → 暂停报价与发运，先完成 P0 资料核验
有 discrepancy 但无 high             → 主体与业务逻辑未见硬矛盾，但存在需解释的疑点
无 discrepancy 但有 unverified       → 未发现明显矛盾，但关键项目仍待核实
全部 verified                        → 公开信息范围内未发现矛盾
```

注意最后一条的措辞：**"未发现矛盾"而不是"确认安全"**。公开信息永远不足以"确认安全"。

## 五、三分法在报告里的呈现

- 封面：一个环形图 + 五个区块的成绩条（每块显示已核实/疑点/未核实数）；
- 核验结论：可按状态筛选，可按区块筛选，可搜索；
- 结论区：三列并排，一眼看到"哪些能做、哪些要问、哪些没查到"；
- Excel：`06_核验结论` 有状态筛选 + 底色；`10_状态透视` 是区块 × 状态的矩阵，用于分派。

任何一页只要出现"已核实占比 17%"就说明这份报告的读者会误以为"83% 有问题"——
所以**永远同时给出三个数，不给百分比**。
