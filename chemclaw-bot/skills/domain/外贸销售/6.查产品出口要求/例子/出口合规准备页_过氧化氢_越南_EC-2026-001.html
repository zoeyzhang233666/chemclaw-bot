为什么不能把两套体系混在一起

《危险化学品目录》是安全生产与海关检验的管理口径，条目 903 的门槛是「含量>8%」；而 UN 号、类别与包装类别来自运输规则（IMDG / IATA / ADR），阈值是「8% / 20% / 60%」。同一个产品完全可能「是危险化学品但不是危险货物」，或相反。因此本页两套结论各自成表、各自挂法规。

05STEP 5按角色分工

把事项落到具体责任人：出口方、进口方、承运方、报关行与第三方各做什么。

🏭出口方（我方）
  1. 建立产品档案：CAS、浓度（w/w）、稳定剂、用途、包装规格、COA 与 SDS
  2. 完成危险特性分类鉴别报告，锁定 UN2014 / 5.1(8) / PG II
  3. 取得 IBC 性能合格证、办理使用鉴定、电子底账申报
  4. 准备中文与越南语 SDS、双语标签样张，报检前归档五类材料
  5. 报关：2847000000 / CIQ 2847000000301，说明目的地非易制毒定向国家
  6. 订舱时提交 DGD，核实承运人是否接受 50% 过氧化氢 IBC
  7. 给进口方提供越南语配方信息、SDS、标签以支持 VN SW 申报
  8. 留存：商务部 2026年第40号公告、危化品目录条目、易制爆名录、2020年第129号公告原文
🏢进口方（越南客户）
  1. 确认是否为最终用户，书面声明「工业用、非食品」
  2. 如属有条件化学品，提供《有条件化学品经营资格证》
  3. 在 VN Single Window 完成清关前化学品申报（发票+越南语译本+SDS）
  4. 按 Thông tư 01/2026/TT-BCT 完成分类与越南语标签落地
  5. 确认能否申请 ACFTA / RCEP 来料原产地证书，据以申报优惠税率
  6. 确认过氧化氢在 24/2026/NĐ-CP 附录中的分类，判断是否需要进口许可
🚢承运方/货代
  1. 按 IMDG 42-24 判断 UN2014 / PG II / IBC 可否在普通柜装载，落实隔离要求
  2. 确认船公司危险货物订舱政策与目的港危险品接收条件
  3. 排期：DG 提前申报（一般舱位预留 1–2 周），提供 DGD 模板
  4. 核实越南目的港的危险货物卸货与堆存要求
  5. 提供 B/L 危险货物标注与应急联系方式
🧾报关行
  1. 复核 2847000000 监管条件 A/B/G 含义与 CIQ 编码选择
  2. 确认目的地越南不触发定向许可证，保留公告依据
  3. 核对出口退税率为 0 的申报口径
  4. 办理出境报检与电子底账，协调属地查检与口岸放行
🔬第三方合规/翻译
  1. 出具危险特性分类鉴别报告
  2. 出具越南语 SDS 与标签翻译/本地化
  3. 协助核对越南 24/2026/NĐ-CP 附录归属（建议由越南本地合规顾问或进口方确认）

09常见误区与风险提示

同类业务最容易出错的地方；逐条确认后才算真正完成「查出口要求」。

监管条件 G ≠ 必须办证

G 是「定向」两用物项许可证。双氧水仅对缅甸/老挝/阿富汗需申请；越南出口无需，但要留存公告原文备查。

危化品属性 ≠ 危险货物分类

目录 903 回答「是不是危化品」；UN2014 / 5.1(8) / PG II 来自运输规则，两者独立成立、不能互推。

越南法规已整体换版

69/2025/QH15 自 2026-01-01 生效；24/25/26/2026 与 01/02/2026 自 2026-01-17 生效。113/2017 体系不再适用。

浓度口径必须用 w/w

分类阈值按质量分数；边界浓度（近 20% / 60%）要特别确认，否则 UN 号与 PG 会错。

稳定剂之外不得加料

加入稳定剂/惰性化学品之外的成分，产品不再属于「过氧化氢水溶液」，须另行鉴定，HS 也可能变。

空运 50% 存在禁运风险

IATA 20–40% 与 >40–60% 条目许可不同，多家承运人禁运；默认走海运，改空运须取得承运人书面意见。

进口方资质与食品用途

若属越南「有条件化学品」，进口方须持资格证；「食品级用途」会触发另一套准入。

使用边界：本案例中的企业名称、数量、包装规格为演示用假设值；法规事实均按 2026-10-19 可访问的官方来源核验，来源与核验日期见 regs 字段。

专业确认：本页为合规准备清单，不构成法律意见，不替代报关行、货运代理、DG 安全顾问、进口方或专业律师的正式判定。；危险化学品管理属性与危险货物运输分类是两套体系，本页分开判定、分开留痕，不互相推导。；凡无官方原文支撑或需专业判断的结论，均以「待确认」标注，未作猜测。
