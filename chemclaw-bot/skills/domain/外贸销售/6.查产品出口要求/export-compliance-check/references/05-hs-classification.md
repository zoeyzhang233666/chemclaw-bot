# 05 · HS 归类方法与常见坑

> 本技能**永远给"候选"，不给"结论"**。归类由报关行/归类专业人员最终确认。

---

## 归类依据的层级

1. **品目条文**（税则号列对应的商品描述）
2. **类注 / 章注**（最常被忽略，却是决定性的）
3. **归类总规则**（GRI 1–6）
4. 本国子目注释

**写候选时必须写依据**，不能只写编码。

---

## 常见坑

| 坑 | 说明 | 正确做法 |
|---|---|---|
| 忽略章注里的"水溶液" | 第 28 章章注一(二)：本章包括无机产品的**水溶液** | 水溶液仍归原品目 |
| 忽略"加稳定剂" | 第 28 章章注一(四)：为保存/运输加入稳定剂的产品仍在原品目 | 稳定剂不改变归类 |
| 加了别的成分还在原品目 | 加稳定剂**之外**的化学品可能改变一般用途 → 可能改归 3824 | 必须核对配方实质 |
| 混用 8 位与 10 位 | 中国 10 位、目的国 8 位，子目可能不同 | 分别给，别直接搬运 |
| 只看编码不看状态 | 同一物质因浓度/形态归入不同子目 | 写明适用条件 |
| 零售包装忽略 | 部分品目对"零售包装"有单独子目/申报要素 | 申报要素里单独列 |

## 过氧化氢示例（已核实结构）

```
首选：2847.00 —— 过氧化氢，不论是否用尿素固化
  ├─ 中国 10 位：2847000000
  │    依据：第 28 章章注一(二)(四)；50% 水溶液仍归 2847
  │    规范申报要素：品牌类型|出口享惠情况|成分含量|包装规格|是否零售包装|GTIN|CAS|其他
  │    CIQ 分档：2847000000101（>60% 特许）/102（20%≤C≤60%）/103（8%≤C<20%）
  │              /104（过氧化氢尿素）/301（危化品，非食品添加剂）/302（危化品，食品添加剂）
  └─ 越南 8 位：2847.00.10（液态）/ 2847.00.90（其他）
       依据：越南 AHTN 细分；水溶液按"液态"

备选：3824.99 —— 其他未列名化学产品
  仅在"加入稳定剂以外的成分、改变一般用途"时考虑
```

**尿素固化**：2847 品目原文含"不论是否用尿素固化"。若客户要尿素稳定配方，编码不变，但成分申报与 SDS 须同步更新。

## 交付物里的固定提醒

> HS 候选须经报关行或归类专业确认后，方可写入报关单与商业发票；越南子目以越南海关现行税则为准。

归类确认前，**不得**用它计算关税、不得对客户报"确定税率"。
