# 01 · 七步操作法

本文件是"查产品出口要求"的标准作业顺序。每一步都有明确产出物，前一步没做实就不要进入下一步。

---

## 第 0 步 · 锁定产品身份与 HS 候选

**目的**：把"过氧化氢"这种模糊叫法，变成一组可核对的字段。

必须记录：

| 字段 | 说明 | 常见错误 |
|---|---|---|
| 中文名 / 英文名 | 英文名要用危险货物正确运输名称的口径 | 用商品名代替化学品名 |
| CAS 号 | 唯一身份锚点 | 只写俗名（"双氧水"）就查 |
| EC / UN-CAS 索引号 | 交叉验证 | 忽略 |
| 浓度及口径 | **必须写 w/w 还是 w/v** | 50% w/v 与 50% w/w 差很多 |
| 组成 / 稳定剂 | 稳定剂名称与含量 | 只说"加了稳定剂" |
| 用途 | 工业/食品/医药/农药 | 不写用途 |
| 包装规格 | IBC 1000 L / 200 L 桶 / 25 kg 袋 | 只写"桶装" |
| 运输方式 | 海运/空运/陆运 | 不指定就假设海运 |

**HS 候选输出格式**（至少 1 个，通常 2–3 个）：

```
候选 1：2847000000（中国）/ 2847.00.10（越南）
- 名称：过氧化氢（不论是否用尿素固化）
- 依据：第 28 章章注一(二)"水溶液"、(四)"为保存或运输加入稳定剂"
- 置信度：高
- 状态：候选，待报关行确认
```

**给用户确认**：身份 + HS 候选先过一遍，再往下查。归类错了后面全错。

---

## 第 1 步 · 中国出口监管

六查一核：

1. **《危险化学品目录》**：是否列名？条目号？含量门槛？（例：过氧化氢溶液 [含量>8%]，序号 903）
2. **《易制爆危险化学品名录》**：是否列名？（涉公安备案、流向登记）
3. **易制毒 / 定向出口许可证**：是否列于易制毒或两用物项目录？**若是定向清单，看目的地是否在清单内**。
4. **出口检验（法检）**：是否属法定检验商品？是否需要电子底账、属地查检？
5. **危险特性与包装**：是否需危险特性分类鉴别报告？包装性能检验 + 使用鉴定？
6. **报关要素**：监管条件代码、CIQ 编码分档、规范申报要素、出口退税率。

**核对纪律**：每一条都要写"文号 + 生效日期 + 是否列名 + 适用条件"。看到监管条件代码不要直接下结论——先看它是普通许可证还是**定向**许可证。

---

## 第 2 步 · 目的国进口准入

四问：

1. **法规版本**：目的国化学品管理法规现在哪一版？最近是否换版？（这一条最容易出错）
2. **是否需许可**：进口许可、登记、备案？进口商是否需要资质？
3. **申报义务**：清关前是否要在电子系统申报？提交什么材料？谁提交？
4. **标签与 SDS**：要求哪种语言？多少项内容？由谁负责分类？

**目的国法规必须用"换版检查"开头**：先搜"该国 + 化学品法 + 最新修订 + 年份"，确认版本后再查细节。

---

## 第 3 步 · 关税、原产地优惠与贸易措施

1. 目的国 HS 子目（**可能与中国 10 位不对齐**，如越南把 2847 分为液态/其他）
2. MFN 税率、VAT/GST
3. 可用 FTA 与优惠税率；申请条件（原产地证书类型 + 原产地规则）
4. 反倾销/反补贴、配额、技术性贸易措施（TBT/SPS）

报价时口径：**含税还是不含税、是否可享惠、优惠需不需要客户配合出证**。

---

## 第 4 步 · 危险化学品 与 危险货物，分开判

| 问题 | 归谁管 | 依据 |
|---|---|---|
| 是不是危险化学品？ | 应急管理 + 海关检验 | 《危险化学品目录》 |
| 需不需要危化品经营/储存资质 | 应急管理 | 国务院令 591 号 |
| 能不能出口到这个国家（定向） | 商务 | 易制毒/两用物项目录 |
| 按危险货物怎么运 | 运输主管机关 + 承运人 | IMDG / IATA / ADR / GB 6944 |

同一产品可能"是危化品但不是危险货物"，也可能"是危险货物但不在危化品目录"。**两条结论各自成表，各自挂法规，禁止互相引用推导。**

---

## 第 5 步 · UN 号 / 类别 / 包装类别

只从危险货物一览表里取，按**浓度区间**取条目：

记录清单：
- UN 号
- 正确运输名称（英文原文）
- 类别 + 次要危险性
- 包装类别（PG）
- 危险标签（如 5.1 + 8）
- EmS（海运）/ 应急响应
- 包装指令（P…）/ IBC 条款（IBC02…）/ 罐柜（T…）
- 限量（LQ）/ 例外数量（EQ）
- 大包装是否禁止
- 积载与隔离要求

**边界浓度必须重新判定**（如 20%、60%），并在交付物里提醒"以 COA 实测值确认"。

---

## 第 6 步 · SDS / 标签 / 包装 / 认证

- 出口端：中文 SDS（GB/T 16483 结构，16 项）+ 中文危险公示标签
- 目的国端：当地语言 SDS（按目的国规定项数）+ 当地语言标签
- GHS 危险性分类（如"氧化性液体 类别2"），写明判定标准与版本
- 包装：UN 认证、型号、材料相容性、性能合格证与使用鉴定
- 产品标准：目的国国家标准 / 合同技术规格 / COA 指标

**双标签策略**：对危险品出口，建议在包装上同时贴出口端与目的国语言标签，减少口岸争议。

---

## 第 7 步 · 单证、角色、待确认

### 单证
每张单据写：名称 / 出具方 / 时点 / 状态（待准备、待取得、不适用）/ 说明。

### 角色
- 出口方（我方）：产品档案、检验鉴定、报检、订舱、SDS 与标签
- 进口方：资质、清关申报、目的国标签落地、原产地证配合
- 承运方/货代：订舱接受性、隔离与积载、目的港接卸
- 报关行：归类复核、监管条件、CIQ、退税率
- 第三方：分类鉴别、SDS 翻译、目的国合规顾问

### 待确认
每条写：问题 / 为什么不能确定 / 责任方 / 解除后影响哪些条目 / 闭环条件。

---

## 收尾核查

- [ ] 每条结论都有法规来源与核验日期
- [ ] 所有"待确认"都在待确认清单里，且都有责任方
- [ ] 危险化学品与危险货物没有混写
- [ ] 没有猜测的 HS / UN / PG / 许可结论
- [ ] 交付物顶部有"示例假设"与"不构成法律意见"声明
- [ ] 法规时效性表已逐条勾选
