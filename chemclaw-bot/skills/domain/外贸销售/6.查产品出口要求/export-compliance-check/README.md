# export-compliance-check · 查产品出口要求

给化工外贸销售用的「出口合规准备」技能：输入一个产品和一个目的国，输出一份**每条结论都带法规依据、适用条件、生效日期与核验状态**的分主题清单，以及仍然需要专业确认的问题。

> 不是"帮你查一下"，而是"让你在报价和承诺交期之前，知道哪些能讲、哪些必须等确认"。

## 交付物

| 文件 | 说明 |
|---|---|
| `出口合规准备页_<产品>_<国家>_<编号>.html` | 自包含交互页（零外部依赖）：身份与 HS 确认 → 主题筛选 → 逐项展开 → 运输 / 单证 / 角色 / 法规 / 时效 / 待确认 |
| `出口合规准备工作簿_<产品>_<国家>_<编号>.xlsx` | 16 个工作表，含法规索引与时效性核查 |
| `checks.json` | 数据校验结果（条数、状态分布、错误与提示） |

## 快速开始

```bash
# 一键：校验 → Excel → HTML → 浏览器验证
python scripts/build_all.py examples/01-过氧化氢-越南-海运/case.json
```

新案例：复制 `examples/_skeleton/case.json`，填 8 个输入要素，再跑上面这条命令。

## 覆盖范围

1. 产品身份与 HS 候选（含归类依据与置信度）
2. 中国出口监管（危化品目录、易制爆、定向易制毒、两用物项、法检、包装检验、报关要素、退税）
3. 目的国进口准入（法规版本、许可与资质、清关前申报、标签与 SDS、关税与原产地）
4. **危险化学品 与 危险货物 分开判定**（不互相推导）
5. UN 号 / 类别 / 包装类别 / 包装指令（只取危险货物一览表，不猜）
6. SDS / 标签 / 包装 / 认证
7. 单证清单（谁出、何时出、当前状态）
8. 出口方 / 进口方 / 承运方 / 报关行 / 第三方 的责任分工
9. 法规时效性核查 + 五级核验状态 + 待确认事项闭环

## 核心纪律

- **不猜** HS、UN 号、包装类别、许可结论
- 每条结论挂法规来源（名称 + 文号 + 生效日 + URL + 核验日）
- 过期/被替代法规显式标注
- 危化品 ≠ 危险货物，分表、分开表述
- 所有"待确认"必须进入清单并指定责任方
- 浓度 / 用途 / 包装任一改变即可能改变结论，必须写适用条件

## 环境要求

- Python 3.10+（`openpyxl`）
- 可选：Node 22+ 与 Chrome/Edge（用于 `verify_*.cjs` 页面与交互验证）

## 重要声明

本技能产出的是**合规准备清单**，不构成法律意见，不替代报关行、货运代理、DG 安全顾问、进口方或专业律师的正式判定。法规与运输规则每年/每两年更新，使用前请核对核验日期。
