### 关键设计决策

1. **HS 只给候选**，附归类依据与置信度，不写"确定编码"。
2. **危险化学品与危险货物分表**，并在页面显式声明不得互推。
3. **"待确认"必须闭环**：正文出现但清单未登记，校验器直接报 ERROR。
4. **核验日期驱动时效**：法规核验日超过 180 天自动提示复核。
5. **交付即验证**：HTML 必须通过结构与交互双重自动化验证才算完成。

### 修复记录（开发过程）

- `build_html.py`：f-string 中 CSS 连续右花括号导致 `SyntaxError` → 转义为 `{{ }}`
- `apply()`：`__tbd` 分支判断顺序错误导致筛选"仅看待确认"返回 0 条 → 改为 if/else 分支
- 搜索：`innerText` 对折叠内容返回空导致搜索 0 条 → 改用 `textContent`
- 统计口径：`待取得/待准备` 被归为"参考" → 改为"待确认"，与业务含义一致
- `build_all.py`：`"allPass": true` 字面匹配因缩进失效 → 改为正则解析
- 文件命名：括号别名导致文件名过长 → 去掉括号内容

### 已知边界

- 不提供 GHS 分类判定，只引用已由鉴定报告/SDS 确认的结论
- 不替代目的国本地合规顾问；官方名录为扫描件时一律标"待确认"
- 税率类数据若来自二手聚合，标"参考信息"，须以目的国海关原文为准
