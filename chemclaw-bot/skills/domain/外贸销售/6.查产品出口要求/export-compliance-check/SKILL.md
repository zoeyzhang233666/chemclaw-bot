# 查产品出口要求（export-compliance-check）

> 一个产品、一个目的国、一套可追溯的合规准备清单。
> 目标不是"给一个答案"，而是让销售在报价和承诺交期之前，知道哪些结论可以讲、哪些必须等专业确认。

## 何时使用

用户表达以下意图时使用本技能：

- "这个产品出口到 X 国有什么要求？"
- "帮我查一下 XX（CAS/浓度）出口到越南/印尼/欧盟……需要什么证、什么单证？"
- "危化品出口要注意什么？" / "这个是不是危险品？"
- "客户要 HS code / 要 MSDS / 问到岸价里含不含危险品附加费"
- 报价前需要确认：能否出口、目的国能否进口、运输怎么定、单证谁出

**不适用**：纯国内销售合规、非化工品的普通商品出口、目的国当地市场的营销调研（用其他技能）。

## 输入要素（缺一项就先问，不要默认）

| 要素 | 为什么关键 | 缺失时的处理 |
|---|---|---|
| 产品名称 + CAS | 锁定身份 | 必问 |
| 浓度 / 组成（写明 w/w 或 w/v） | 决定危化品门槛、UN 号、包装类别、关税子目 | 必问；不能确定就写"假设值"并在页面标注 |
| 目的国 | 决定准入法规版本与税率 | 必问 |
| 用途（工业级/食品级/医药/农药…） | 改变准入路径，甚至改变 HS | 必问 |
| 包装（IBC/桶/袋/罐/散装 + 规格） | 决定危险货物包装指令与是否豁免 | 必问 |
| 运输方式（海运/空运/陆运/多式联运） | 决定适用 IMDG / IATA / ADR | 必问 |
| 数量、Incoterms、起运港/目的港 | 影响单证与责任划分 | 可后补 |

一次问全，避免反复打断。用户没说全时，**先按最常见情形假设，并在交付物顶部显著标注"示例假设，可修改"**。

## 执行流程（七步）

### 第 0 步：确认产品身份与归类（先做，别跳）

1. 用 CAS 号交叉核对：名称、别名、分子式、EC 号。
2. 判定浓度口径（w/w vs w/v），记录来源（COA）。
3. 给出 **HS 候选**（不是单一结论）：首选编码 + 备选编码 + 归类依据（引用章注/品目条文）+ 置信度 + 状态。
4. **把身份与 HS 候选先给用户确认**，再进入分主题调查。

> 归类错了，后面全错。所以 HS 永远是"候选"，且必须写依据。

### 第 1 步：中国出口监管

逐项核对，每项都要落到"文号 + 生效日期 + 是否列名 + 适用条件"：

- 《危险化学品目录》是否列名（条目号、含量门槛）
- 《易制爆危险化学品名录》（公安备案/流向登记）
- 易制毒 / 两用物项 / 定向出口许可证（**重点：定向许可证要看目的地是否在清单内**）
- 出口检验检疫（法检）、电子底账、属地查检
- 危险特性分类鉴别报告、包装性能检验、使用鉴定
- 报关监管条件（A/B/G…）、CIQ 编码分档、申报要素
- 出口退税率（影响报价）

### 第 2 步：目的国进口准入

- 目的国化学品管理法规**现行版本**（先查是否刚换版，旧的会误导）
- 是否需要进口许可、进口商资质（如"有条件化学品"经营资格证）
- 清关前/进口申报义务（单一窗口类系统）
- 标签与 SDS 语言要求、危害公示要求
- 是否有本地质量标准（QCVN/国家标准）

### 第 3 步：关税、原产地优惠与其他贸易措施

- 目的国 HS 子目（可能与中国 10 位不对齐）
- MFN 税率、VAT/GST、优惠税率
- 可用自贸协定与原产地证书（ACFTA/RCEP/ATIGA…），以及原产地规则
- 反倾销/反补贴、配额、技术性贸易措施

### 第 4 步：危险化学品监管 与 危险货物运输 —— 分开判别

这是本技能最核心的纪律：

| | 危险化学品监管 | 危险货物运输 |
|---|---|---|
| 依据 | 《危险化学品目录》、国务院令 591 号 | IMDG / IATA / ADR / GB 6944 |
| 回答 | 是否受危化品管理、要什么证 | 按什么 UN 号、类别、包装类别运 |
| 门槛 | 由目录条目决定（如"含量>8%"） | 由运输规则决定（如 8%/20%/60% 分档） |

**两者可能同时成立，也可能只有一个成立。不得互相推导，不得在同一张表里混写。**

### 第 5 步：UN 号、类别、包装类别（严禁猜测）

- 必须来自危险货物一览表（IMDG/IATA/ADR）对应浓度区间的条目。
- 记录：UN 号、正确运输名称、类别、次要危险性、包装类别、标签、EmS、包装指令、IBC 条款、限量/例外数量、大包装是否禁止。
- 浓度落在边界时必须重新判定。
- **拿不到原文就写"待确认"，绝不填一个"看起来对"的 UN 号。**

### 第 6 步：SDS / 标签 / 包装 / 认证

- 出口端：中文 SDS（GB/T 16483 结构）+ 中文危险公示标签
- 目的国端：当地语言 SDS（目的国规定的项数）+ 当地语言标签
- GHS 危险性分类（如氧化性液体类别），并注明判定标准与依据版本
- 包装：UN 认证、IBC 型号、材料相容性、性能合格证与使用鉴定
- 产品标准/认证（目的国国家标准、合同技术规格）

### 第 7 步：单证清单 + 角色分工 + 待确认事项

- 单证：每张单据写明"谁出、什么时候出、现在什么状态"
- 角色：出口方 / 进口方 / 承运方与货代 / 报关行 / 第三方
- 待确认：每条写明"为什么不能确定、谁来确认、解除后影响哪些条目"

## 输出物

| 文件 | 内容 |
|---|---|
| `出口合规准备页_<产品>_<国家>_<编号>.html` | 自包含交互页：身份与 HS 确认 → 主题筛选 → 逐项展开 → 运输/单证/角色/法规/时效/待确认 |
| `出口合规准备工作簿_<产品>_<国家>_<编号>.xlsx` | 16 表：封面、身份、HS、中国出口、目的国、运输、标签包装、单证、角色、法规索引、时效性、状态汇总、风险误区、待确认、核对清单、填写样例 |
| `checks.json` | 校验结果（条目数、状态分布、错误与提示） |

## 五级核验状态（统一口径）

| 状态 | 含义 | 能否对客户说 |
|---|---|---|
| 已核实 | 已打开官方原文或权威一手来源，确认现行版本 | 可以，需说明依据 |
| 参考信息 | 二手/商业数据库，用于定位，未取官方原文 | 不能说"确定"，只能说"据…资料" |
| 待确认 | 缺官方原文或需专业判断 | 不能作为承诺；列入待确认清单 |
| 不适用 | 有明确理由排除（写出理由） | 可以，需给理由 |
| 不触发 | 条件明确不满足（如定向许可证 + 目的地不在清单） | 可以，但须保留依据备查 |

## 硬性纪律（违反即不合格）

1. **不猜 HS、不猜 UN 号、不猜包装类别、不猜许可结论。**
2. **每条结论必须挂法规来源**（名称 + 文号 + 生效日期 + 来源 URL + 核验日期）。
3. **过期/被替代法规必须显式标注**，否则读者会沿用旧结论。
4. **危险化学品 ≠ 危险货物**，分开成表、分开表述。
5. **所有"待确认"必须进入待确认清单并指定责任方**，不能只写在正文里。
6. **浓度/用途/包装任一改变，结论可能全变**——必须写适用条件，不能给无条件结论。
7. 交付物必须写明"不构成法律意见，不替代报关行/货代/DG 顾问/律师的正式判定"。

## 工具与脚本

```bash
# 1) 校验案例数据（先跑这个，必须全部通过）
python scripts/validators.py examples/<案例>/case.json --out examples/<案例>/checks.json --as-of 2026-10-19

# 2) 生成 Excel 工作簿
python scripts/build_workbook.py examples/<案例>/case.json --out <工作簿>.xlsx --checks examples/<案例>/checks.json

# 3) 生成交互 HTML
python scripts/build_html.py examples/<案例>/case.json --out <页面>.html --checks examples/<案例>/checks.json

# 4) 一键全流程（校验→Excel→HTML→页面渲染验证→打包）
python scripts/build_all.py examples/<案例>/case.json
```
