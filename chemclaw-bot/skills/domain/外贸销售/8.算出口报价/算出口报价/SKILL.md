# 算出口报价（化工品外贸）

## 这个 Skill 解决什么

外贸销售手里有：工厂出厂价、数量、起运港/目的港、包装方式、各项费用，以及自己决定的毛利。
需要产出：**一份能拿给客户、也能经得起财务复核的报价**。

难点从来不是"乘法"，而是：

1. **哪些费用该进哪个贸易术语**（FOB 到船上止，CFR 加运费，CIF 再加保险）；
2. **CIF 的保险费到底怎么算**（基数是 CIF 本身，是方程不是乘法）；
3. **毛利率和成本加成率不是一回事**（差 0.7 个百分点就能吃掉利润）；
4. **哪些数不能编**（运费、保险费、税费、市场价——没有依据就留空）。

本 Skill 把上述四点做成**可执行、可校验、可交付**的流程。

---

## 硬性边界（违反即视为失败）

| # | 红线 |
|---|---|
| 1 | **不得自行设定商业利润**。不提供"建议毛利""行业平均毛利"。毛利只能来自用户输入。 |
| 2 | **不得在缺乏可靠依据时编造运费、保险费或税费**。缺了就写"待补数据"，并给出补数来源。 |
| 3 | **必须准确区分 FOB / CFR / CIF 的费用范围与风险转移规则**，避免重复计费。 |
| 4 | **出口退税、税费和保险计价基数必须核实适用条件**；无依据不得自动假设（尤其不得默认出口关税 0%、退税率 13%）。 |
| 5 | **毛利率与成本加成率必须明确区分**，任何时候都要说清是哪一个、针对哪个术语。 |
| 6 | 最终目的是**帮销售准确测算不同术语下的成本与报价**，**不是代替用户制定商业价格**。所有输出措辞须体现这一点。 |

## 工作流程

### 第 0 步：确认术语与运输方式

先问清 6 件事（详见 `references/incoterms.md` §7）：
交货点、谁订舱付运费、谁投保/险别/保额、谁报关、运输方式、客户是否内陆收货。

> **术语选错，后面全错。** 集装箱进内陆点应报 FCA/CPT/CIP/DAP，不是 FOB/CIF。

### 第 1 步：收集参数（逐个标"已提供/待补"）

按 `references/parameters.md` 的字段表收集。**每一个缺失项都要记录补数来源**，不允许静默跳过。

最小可用输入（可先只填这些，其余留空看结构）：
品名、规格、HS、数量、出厂价、包装、起运港、目的港、汇率、毛利口径与数值、基准术语。

### 第 2 步：计算（用脚本，不要手算）

```bash
python scripts/calc_engine.py input.json -o output/result.json
```

引擎输出：`lines`（费用明细）、`segments`（S1–S9）、`terms`（各术语成本）、`quotes`（三术语报价）、`missing`（缺失清单）、`identity_checks`（K1–K7 校验）、`refund`（退税，单列）。

**若任一项 `identity_checks` 为 false，停下来查，不要往下走。**

### 第 3 步：生成交付物

```bash
# 交互式 HTML（首屏即结论，可实时改参数）
python scripts/build_html.py input.json -o output/报价计算器.html

# 带自动重算公式的 Excel（12 张表）
python scripts/build_xlsx.py input.json -o output/报价工作簿.xlsx
```

若某些参数是演示用的模拟值，**必须**加 `--simulated` 标记：

```bash
python scripts/build_html.py input.json -o out.html --simulated freight_usd_per_container,insurance_rate_of_cif
```

被标记的值在 HTML 显示为紫色 SIMULATED、在 Excel 显示浅紫底纹，并在报价草稿内部备注中强制提示。

### 第 4 步：人工确认后才出报价草稿

HTML 中的「英文报价草稿」有**确认门**：必须勾选"价格是我定的、不是系统建议的"才能生成。
草稿尾部带 `INTERNAL NOTE — REMOVE BEFORE SENDING`，列出所有未替换的模拟值与未确认条款。

### 第 5 步：按 QA 清单自检

逐项过 `references/qa.md`。任一项为"否"，不得外发。

## 输出说明

### 交互式 HTML（单文件，离线可用）

| 区域 | 内容 |
|---|---|
| 首屏 | 成本结构条、FOB/CFR/CIF 三价、关键缺失提示 |
| 明细 | 18 行费用明细（含承担方、状态） |
| 术语 | 各术语成本与组成段 |
| 公式 | 每条公式 + 当前代入值 |
| 敏感性 | 运费/汇率/毛利三组，滑块即时重算 |
| 方案 | 多方案并列对比 |
| 草稿 | 英文报价草稿（需确认门） |

### Excel 工作簿（12 张表，全公式驱动）

`01 基础参数` → `02 术语与口径` → `03 费用明细`（唯一录入区） → `04 术语成本` → `05 FOB-CFR-CIF报价` → `06 汇率换算` → `07 毛利测算` → `08 敏感性分析`（带图） → `09 多方案比较` → `10 缺失与假设` → `11 公式与校验` → `12 报价草稿`

改 01 或 03 任一单元格，全表联动重算。

## 关键公式速查

```
S5（运费/吨） = 柜价USD × 汇率 ÷ 装柜吨数
S6（保险费）  = 1.10r × C_CIF = C_CFR × 1.10r / (1 − 1.10r)
C_FOB = S1+S2+S3+S4+S7+S8
C_CFR = C_FOB + S5
C_CIF = C_CFR + S6
毛利率：  P = C / (1 − m)
成本加成：P = C × (1 + k)          (1+k)(1−m) = 1
外币价：  P_fx = P ÷ 汇率
```

完整推导见 `references/formulas.md`。

## 常见错误（本 Skill 已内置拦截）

| 错误 | 拦截方式 |
|---|---|
| 用 `CFR × 费率` 估保费 | 引擎强制用自洽解，K3 校验 |
| 把加成率当毛利率 | K4 恒等式 + 07 表换算对照 |
| 缺失项填 0 | 显示"待补数据"，不计算 |
| 运费重复计入 FOB 与 CFR | K1 校验 |
| 退税抵减成本 | 退税单列，V9 校验 |
| 模拟值冒充真实运价 | SIMULATED 标签 + 草稿内部备注 |
| 术语与运输方式不匹配 | 第 0 步强制确认 |
