# 变更记录

## 1.0.0 — 首个版本

### 新增
- **九段成本模型**（S1–S9）：出厂价、包装、内陆运输、港口及报关、海运费、保险费、出口税费、其他出口费用、目的地及进口环节。每笔费用只归一段，术语价 = 段之和。
- **11 个 Incoterms® 2020 术语**支持：EXW / FCA / FAS / FOB / CFR / CIF / CPT / CIP / DAP / DPU / DDP。
- **CIF 保险费自洽解**：`C_CIF = C_CFR / (1 − 1.10r)`，替代常见的 `CFR × 费率` 粗算。
- **毛利双口径**：毛利率 `P = C/(1−m)` 与成本加成率 `P = C×(1+k)`，含 `(1+k)(1−m)=1` 恒等式校验。
- **计算引擎** `scripts/calc_engine.py`：输出 lines / segments / terms / quotes / missing / identity_checks / refund。
- **交互式 HTML 计算器**：单文件、离线、首屏即结论、实时重算、公式页、敏感性、多方案、草稿确认门。
- **Excel 工作簿**（12 表）：01 基础参数 / 02 术语与口径 / 03 费用明细 / 04 术语成本 / 05 FOB-CFR-CIF报价 / 06 汇率换算 / 07 毛利测算 / 08 敏感性分析 / 09 多方案比较 / 10 缺失与假设 / 11 公式与校验 / 12 报价草稿。全部为公式驱动，改参数全表联动。
- **敏感性与多方案**：运费 ±20%、汇率 ±10%、毛利 ±3 个百分点三组情景，带折线图。
- **缺失数据机制**：缺失项显示"待补数据"而非 0，并列出补数来源；模拟值强制标记 SIMULATED（HTML 紫色 / Excel 浅紫）。
- **校验体系**：K1–K7 恒等式、V1–V10 完整性、C-1–C-13 合规口径。
- **参考文档**：incoterms / formulas / parameters / sensitivity / validation / qa / portability / citations。
- **完整算例**：重质纯碱 500 t，青岛 → 雅加达（FOB / CFR / CIF + 外币报价 + 敏感性）。
- **产品画像模板**：`products/soda-ash.json` 与 `_template.json`。

### 设计决策（记录原因）
- **不提供实时运价与汇率**：运价是货代报价资产、汇率须由用户选定口径；自动取数会诱导"用了一个看似权威但已过期的数"。
- **退税单列不抵减成本**：退税是进项增值税的退还，不是成本减免；是否贴补报价属商业决策。
- **报价草稿设确认门**：防止把"系统算出来的数"直接当成对外承诺。
- **拒绝 0 顶替缺失值**：0 会让报价"看起来算出来了"，实际少一个成本段，签下来就是亏。
