# 校验规则与失败处置

> 目的：让"算出来的数"在交付前自动被质疑一遍。
> 三类校验：**恒等式**（数对不对）、**完整性**（有没有漏）、**合规口径**（有没有越权假定）。

---

## 1. 恒等式校验（K 系列）

在 `calc_engine.py` 的 `identity_checks` 与 Excel「11 公式与校验」中同时实现。

| 编号 | 断言 | 不通过的含义 | 常见原因 |
|---|---|---|---|
| K1 | `C_CFR = C_FOB + S5` | 运费重复或漏计 | S5 被同时挂进 FOB 与 CFR |
| K2 | `C_CIF = C_CFR + S6` | 保险费重复或漏计 | 手工加了保费又走了公式 |
| K3 | `S6 = 1.10 × r × C_CIF` | 保费未用自洽解 | 用了 `CFR × 1.10r` 粗算 |
| K4 | `(1 + k)(1 − m) = 1` | 毛利两口径混用 | 把加成率填进毛利率字段 |
| K5 | `Σ(段) = 术语成本` | 有段重复或遗漏 | 术语映射表被改错 |
| K6 | `Total_fx = P_fx × Q` | 总额与单价不一致 | 手工改过总额 |
| K7 | `P_fx = P / FX` | 汇率方向反了 | 用户给的是 CNY/外币的倒数 |

**容差**：K1/K2/K5/K6 用 `1e-6`；K3/K4 用 `1e-4`（浮点与显示精度）。

---

## 2. 完整性校验（V 系列）

| 编号 | 检查项 | 判定 | 处置 |
|---|---|---|---|
| V1 | 数量 `Q > 0` | 必须 | 否则不出总额，提示"请填数量" |
| V2 | 汇率 `FX > 0` | 必须（出外币价时） | 否则外币价不显示 |
| V3 | 装柜吨数 `LOAD > 0` | 有柜价运费时必须 | 否则无法折吨价 |
| V4 | 保险费率 `r` 使 `1 − 1.10r > 0` | 必须 | 否则报"费率不可解" |
| V5 | 每个术语的**全部组成段非空** | 必须 | 任一为空 → 该术语显示"待补数据" |
| V6 | 毛利口径与数值匹配 | 必须 | `gp_value ≥ 0`；毛利率 < 100% |
| V7 | 基准术语 ∈ 支持的术语集合 | 必须 | 否则毛利口径无法应用 |
| V8 | 模拟值已被标记 | 必须 | 未替换为真实值前不得外发 |
| V9 | 退税**未**出现在任何术语成本 | **必须** | 出现即违反本项目约束 |
| V10 | 缺失清单非空时，报价草稿含内部提示 | 必须 | 防止销售直接发草稿 |

## 3. 合规口径校验（C 系列，人工必过）

这些是**程序无法完全自动判定**的，必须由销售/审核人确认打勾：

| 编号 | 问题 | 不合格的典型表现 |
|---|---|---|
| C-1 | 是否**没有**自行设定商业利润？ | 系统给出了"建议毛利 10%" |
| C-2 | 是否**没有**在无依据时编造运费/保费/税费？ | 运费按"经验值 2000 USD/柜"填了 |
| C-3 | FOB/CFR/CIF 的费用边界是否**互斥**？ | 同一笔港杂费进了 FOB 又进了 CFR |
| C-4 | 风险转移点是否写进报价/合同？ | 客户以为 CIF 到港才算交货 |
| C-5 | 保险基数是否按 **CIF × 110%**？ | 按 CFR 算保费 |
| C-6 | 险别是否明确（ICC C 还是 A）？ | 客户要求 A 却按 C 收费 |
| C-7 | 毛利率与成本加成率是否**明确区分**？ | 口头说"8 个点"没说是哪个 |
| C-8 | 毛利基准术语是否写明？ | "毛利 8%"不知是 FOB 还是 CIF |
| C-9 | 出口退税率是否**核实**而非假定？ | 一律按 13% 填 |
| C-10 | 出口关税是否核实？ | 默认填 0 |
| C-11 | 目的国进口税/原产地优惠是否单独说明？ | 直接告诉客户"进口零关税" |
| C-12 | 报价是否写明**有效期**？ | 运费汇率过期后仍按原价履约 |
| C-13 | 是否明确"本报价不代替商业定价"？ | 销售把系统输出当公司定价依据 |

## 4. 失败处置流程

```
发现校验失败
   ├─ K 系列失败 → 立刻停：说明有重复/漏计，回到 03 费用明细逐段核对
   ├─ V 系列失败 → 该术语不出价，列入缺失清单，向货代/保险/客户补数
   ├─ C 系列失败 → 不得外发报价草稿，人工补齐依据后重跑
   └─ 模拟值未替换 → 报价草稿强制带 "INTERNAL NOTE — REMOVE BEFORE SENDING"
```

### 硬性红线（任一触发即禁止生成对外报价）

1. 任意术语成本包含空段（V5）；
2. 出现退税抵减成本（V9）；
3. 毛利/加成口径与基准术语未明确（V6/V7）；
4. 数据为 SIMULATED 且用户未确认（V8）。

---

## 5. 复核节奏建议

| 时点 | 复核内容 |
|---|---|
| 每次报价前 | 汇率、海运价是否在有效期内；出口关税/退税率是否变化 |
| 每月 | 保险费率、港口费、内陆费是否需重新询价 |
| 每季 | 目的国进口税、原产地规则、反倾销/反补贴措施 |
| 每年（或政策发布时） | 出口退税率文库版本、Incoterms 是否有修订 |
