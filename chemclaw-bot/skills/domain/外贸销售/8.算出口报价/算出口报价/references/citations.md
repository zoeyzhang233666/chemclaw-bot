## 2. 出口退（免）税政策口径

### C5｜生产企业"免抵退"与外贸企业"免退税"

- **事实**：
  - 生产企业出口自产货物适用**"免抵退"**办法，退税额 = 出口货物**离岸价(FOB)** × 外汇人民币牌价 × 退税率；
  - 外贸企业适用**"免退税"**办法，退税额 = **购进出口货物的增值税专用发票注明的金额** × 退税率。
- **来源**：财政部、税务总局关于出口退（免）税的相关公告（**财政部 税务总局公告 2026 年第 11 号**）及配套管理办法。
- **取用日期**：2026（本项目核实期）。
- **限制**：
  1. 两种办法的**计税依据不同**（FOB vs 采购专票金额），不可混用；
  2. 退税额不等于利润；
  3. 未在规定期限内申报、单证不全将无法退税。

### C6｜退税与报价的关系（本项目设计决策）

- **事实（判断）**：退税是退还采购环节进项增值税，**不是成本减免，也不是系统应自动抵扣的项目**。
- **本项目做法**：退税在 HTML/Excel 中**单独成行展示，标注"参考，未抵扣"**；术语成本中不含退税；是否用退税贴补报价由销售自行决定。
- **依据**：这是商业决策而非算术问题，且不同企业（生产型/贸易型）、不同退税到账周期对现金流影响不同。

## 3. 国际贸易术语

### C7｜Incoterms® 2020 费用与风险划分

- **事实**：本节所有术语定义、费用承担、风险转移点依据 **国际商会《Incoterms® 2020》**（ICC Publication No. 723E，**2020-01-01 生效**）。
- **关键条款**：
  - FOB / CFR / CIF 的**风险转移点 = 装运港货物装上船时**；
  - CFR/CIF 卖方的运费/保险费是**费用义务**，不改变风险转移点；
  - CIF 卖方须投保**至少合同价值 110%**，无另行约定时险别为**协会货物条款 (C)**；
  - **CIP 要求 ICC (A)**（比 CIF 更严）。
- **取用日期**：本项目核实期（2026）。
- **限制**：Incoterms 只规定交货、费用、风险、手续，**不规定**价格、付款方式、所有权转移、违约救济——这些须在合同中另行约定。

### C8｜ICC 保险险别差异

- **事实**：ICC (A) 为"一切险"式最广承保，ICC (B) 居中，ICC (C) 为最低险别（仅承保重大事故，如船舶搁浅、沉没、火灾、碰撞）。
- **来源**：伦敦保险协会货物条款（Institute Cargo Clauses）A/B/C；ICC Incoterms 2020 说明。
- **限制**：C 险**不承保**偷窃、淡水雨淋、短量等常见损失。客户若要求这些保障，必须改 ICC (B)/(A) 并重算保费——**不得自动沿用 C 险费率**。

## 4. 目的国进口环节税（仅 DDP / 参考）

### C9｜印度尼西亚进口增值税（PPN）

- **事实**：印尼进口环节增值税名义税率 **12%**，通过 **DPP Nilai Lain**（其他计税基础，为关税完税价的 11/12）计算，**实际税负相当于 11%**。
- **来源**：PwC Worldwide Tax Summaries — Indonesia（间接税章节）。
- **取用日期**：本项目核实期（2026）。
- **限制**：
  1. 仅适用 DDP 报价时由卖方承担的进口环节税参考；
  2. FOB/CFR/CIF 下**进口税由买方承担，不进报价成本**；
  3. 印尼另有进口所得税（PPh 22）等，视进口商资质而定；
  4. 税率随印尼税法变动（2025 年起 VAT 调整），**报价前必须重核**。

## 5. 本项目"不提供"的数据（明确声明）

以下数据**本系统在无来源时一律不编造**，缺失即显示"待补数据"：

| 数据类型 | 为什么不做默认值 |
|---|---|
| 海运费 / 各航线运价 | 随时段、箱型、货量、船司波动，属货代报价资产 |
| 保险费率 | 取决于航线、险别、免赔额、承运人 |
| 内陆运费 / 港口费 | 取决于具体地点、车型、港口、代理 |
| 市场销售价 / 建议毛利 | **商业决策，不是技术参数** |
| 出口关税、目的国进口税 | 必须按具体编码与政策核实 |
| 装柜吨数 | 必须来自实际装箱方案 |

## 6. 引用格式约定

- 每条事实都记录**取用日期**，因为税率、运价、政策都随时间变化；
- 引用只证明"该来源在取用日如此陈述"，不等于对未来有效；
- 网页来源优先选择官方（海关总署、财政部/税务总局、ICC、PwC 税务汇总）；
- 若某事实在交付时已无法复核，应在 `references/qa.md` 中标注"需重核"。
