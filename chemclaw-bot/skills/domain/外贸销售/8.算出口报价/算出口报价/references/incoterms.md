# 贸易术语口径与责任矩阵（Incoterms® 2020）

> 依据：国际商会《Incoterms® 2020》（ICC Publication No. 723E，2020-01-01 生效）。
> 本文件的唯一作用：**把每一笔费用归到唯一一个成本段**，让"术语价 = 若干段之和"永远成立，杜绝重复计费与漏计。

---

## 1. 为什么必须先拆成本段

外贸报价出错，90% 不是算错乘法，而是：

| 典型错误 | 后果 | 根因 |
|---|---|---|
| FOB 价里含了海运费，再用 FOB 算 CFR 又加一次运费 | CFR 虚高一个运费 | 费用没有唯一归属 |
| CIF 报价用 `CFR × (1+费率)` 估保费 | 保费系统性低估 | 保险计价基数是 CIF，不是 CFR |
| 报 FOB 却把目的港费用算进成本 | 报价贵出 8–15%，丢单 | 没区分"价格含什么"与"风险何时转移" |
| 客户要 CIF，销售按 CFR 成本 + 毛利报价 | 少收整笔保费 | 术语成本边界没画清 |
| 用 FCA 的货却报 FOB（集装箱进内陆） | 交货点与风险点错误 | 术语与运输方式不匹配 |

所以本方法强制：**先把费用切成 S1–S9 九个互斥的成本段，再用"术语 = 段的子集求和"生成报价。**

## 2. 九个成本段（S1–S9）

| 段 | 名称 | 内容 | 计价单位 | 通常承担方 |
|---|---|---|---|---|
| **S1** | 出厂价 | 货物离开工厂前的裸价（不含包装、不含出口环节费用） | ¥/吨 | 卖方 |
| **S2** | 包装 | 袋装/吨袋/托盘/缠绕膜/唛头，折吨价 | ¥/吨 | 卖方 |
| **S3** | 内陆运输 | 工厂 → 起运港（或装货地）；含装车费 | ¥/吨 | 卖方 |
| **S4** | 港口及报关 | THC、报关费、单证费、码头作业、铅封、VGM 申报 | ¥/吨 | 卖方（F 组及 C 组） |
| **S5** | 海运费 | 起运港 → 目的港主运费（不含目的港费用） | 外币/柜 → 折 ¥/吨 | 卖方（C 组、D 组） |
| **S6** | 保险费 | 按 CIF 价 × 110% × 费率（见 §5） | ¥/吨 | 卖方（CIF/CIP、D 组） |
| **S7** | 出口税费 | 出口关税、出口环节附加税费 | ¥/吨 | 卖方 |
| **S8** | 其他出口费用 | 结汇/银行费、检验、认证、产地证、配额 | ¥/吨 | 卖方 |
| **S9** | 目的地及进口环节 | 目的港 THC/堆存/换单、进口清关、进口关税与进口环节税、内陆派送 | ¥/吨 | **仅 D 组由卖方承担**；F/C 组由买方承担，**不计入卖方成本** |

### 关键约定（避免重复计费的三条铁律）

1. **一段只记一次**：任何费用行只能挂在唯一一个段上。例如"货代一票全含报价"必须由销售拆成 S3/S4/S5 三段后再录入，不允许整体挂在 S5。
2. **S9 只在 D 组进入卖方成本**。FOB/CFR/CIF 的成本里出现 S9，就是重复或越界计费。
3. **S7 与"出口退税"不是一回事**。退税是**退还**进项增值税，不是成本；见 `references/formulas.md` §6。二者都不允许互相抵冲成"净出口税"。

## 3. 术语 → 成本段映射

| 术语 | 全称 | 卖方成本段 | 风险转移点 |
|---|---|---|---|
| EXW | 工厂交货 | S1 | 货物在卖方场所备妥、买方处置时 |
| FCA | 货交承运人 | S1 S2 S3 (+S4 出口清关) | 货交买方指定承运人时 |
| FAS | 船边交货 | S1 S2 S3 (+S4) | 货物置于装运港船边时 |
| **FOB** | 装运港船上交货 | S1 S2 S3 S4 S7 S8 | **装运港货物装上船时** |
| **CFR** | 成本加运费 | S1 S2 S3 S4 **S5** S7 S8 | **装运港货物装上船时** |
| **CIF** | 成本、保险加运费 | S1 S2 S3 S4 **S5 S6** S7 S8 | **装运港货物装上船时** |
| CPT | 运费付至 | S1 S2 S3 S4 S5 S7 S8 | 货交**第一承运人**时 |
| CIP | 运费和保险费付至 | S1 S2 S3 S4 S5 S6 S7 S8 | 货交**第一承运人**时 |
| DAP | 目的地交货 | 上述 + S9（不含进口税） | 到达目的地、运输工具上待卸时 |
| DPU | 目的地卸货后交货 | 上述 + S9（**含卸货**） | 目的地卸货完成时 |
| DDP | 完税后交货 | 上述 + S9 + 进口关税及进口环节税 | 目的地已办完进口清关、待卸时 |

### 恒等关系（程序必检）

```
C_FOB = S1 + S2 + S3 + S4 + S7 + S8
C_CFR = C_FOB + S5
C_CIF = C_CFR + S6
C_FCA = S1 + S2                    （出口清关费可单列进 S4）
C_CPT = C_FCA + S3 + S4 + S5       （CPT 交货点在承运人，非船上）
C_CIP = C_CPT + S6
C_DAP = C_CIP + S9(不含进口税)
C_DDP = C_DAP + 进口关税 + 进口环节税
```

> 工程实现：`scripts/calc_engine.py` 中的 `TERMS` 字典把上述映射写成数据，`compute()` 逐段求和后执行 `identity_checks`；任何一条不成立，`result.json` 的 `identity_checks` 会给出 `false`，HTML/Excel 的校验面板同步标红。

## 4. 风险转移 vs 费用承担：最容易被客户投诉的一点

**CFR / CIF 的运费与保险费是"费用义务"，不是"风险义务"。**

- 货物在装运港**装上船**那一刻起，灭失或损坏的风险已经转移给买方；
- 但卖方仍要支付到目的港的运费（CFR）和保险费（CIF）；
- 因此：**货物在海上出事，买方凭保单索赔，卖方仍需付运费**，卖方并不因为"付了运费"而承担运输途中的风险。

这条规则必须写进报价单/合同，否则买方会以"货没到港"为由拒付。

对应的英文条款模板见 `references/citations.md` §4 与 `examples/*/output/` 中的报价草稿。

## 5. CIF 保险的特殊规则（与 CFR 唯一实质差异）

依据 Incoterms® 2020 CIF 条款 A5：

1. **投保金额**：至少为**合同价值（即 CIF 价）的 110%**。合同价值即 CIF 发票金额。
2. **险别**：若无另行约定，卖方只需投保**最低险别**——协会货物条款 **(C)**（Institute Cargo Clauses (C)）；**CIP 则要求 (A)**。
3. **币种**：保险应与合同同币种。
4. **保险利益起始**：至少覆盖从交货点到指定目的地的全程。

因此保险费是一个**方程**而非一次乘法：

```
C_CIF = C_CFR + 保险费
保险费 = 1.10 × r × C_CIF        （r = 保险费率，以 CIF 为基数）
⇒  C_CIF = C_CFR / (1 − 1.10 r)
⇒  保险费 = 1.10 r × C_CFR / (1 − 1.10 r)
```

**反例**：某航线 r = 0.30%。按 `CFR × 1.10 × r` 粗算得 6.92 ¥/吨；正确解为 6.94 ¥/吨——低估约 0.33%。r 越高、差距越大（r = 2% 时低估约 2.2%）。金额小时看似无感，但这是**系统性偏低**，批次多了就是利润流失，且报价单与保单基数对不上会被财务/审计挑出。

> 若客户要求 ICC(A)、加保战争险、或保额提高到 120%/130%，必须用新的 r 重算，并在条款里写明险别与保额——**不得自动沿用 ICC(C) 的费率**。

## 6. 术语与运输方式的匹配（选错术语比算错价更麻烦）

| 运输方式 | 应当使用的术语 | 不要使用 |
|---|---|---|
| 散货/液体化工，港到港海运 | FOB / CFR / CIF | — |
| 集装箱出口至内陆点（如内陆工厂交货给客户仓库） | FCA / CPT / CIP / DAP | FOB/CIF（交货点在船上，无法覆盖内陆段风险） |
| 多式联运 | FCA / CPT / CIP | FAS（船边交货仅限海运） |
| 快递/空运 | FCA / CPT / CIP | FOB/CFR/CIF（这些术语专为海运/内河设计） |
| 客户要求卖方负责到门 | DAP / DPU / DDP | CIF（CIF 不负责目的港后的运输与清关） |

**实务提示**：化工品出口到东南亚，客户常写"CIF Jakarta"，但其收货仓库在雅加达外 200 km 的工业园区。此时 CIF 只负责到雅加达港，仓储与内陆段须另报（或改 DAP）。**报价前必须问清收货地址，而不是只看港口名。**

## 7. 术语选择自查（放在报价前问客户）

1. 交货点在哪里？（工厂 / 承运人 / 船边 / 船上 / 目的港 / 目的地仓库）
2. 谁订舱、谁付主运费？
3. 谁投保、保额多少、什么险别？
4. 谁办出口报关？谁办进口清关、付进口关税？
5. 运输方式是海运散货、集装箱，还是多式联运/空运？
6. 客户是不是内陆收货？港口名后面还有多远？

六个问题答完，术语就唯一确定了；此时成本段组合也随之唯一确定，再往下才是算钱。
