# 全部计算公式（唯一权威版）

> 本文件的公式与 `scripts/calc_engine.py`、`templates/calculator.template.html`、`scripts/build_xlsx.py` 三处实现**逐一对应**。
> 三处结果不一致 = 有人手改了中间值。校验方式见 `references/validation.md`。

---

## 0. 符号表

| 符号 | 含义 | 单位 |
|---|---|---|
| `S1 … S9` | 九个成本段单价 | ¥/吨 |
| `Q` | 出口数量 | 吨 |
| `FX` | 报价汇率（CNY / 1 外币） | — |
| `USD_container` | 海运费柜价 | USD/柜 |
| `LOAD` | 装柜吨数 | 吨/柜 |
| `r` | 保险费率（以 CIF 为基数） | 小数 |
| `m` | 毛利率（按**售价**） | 小数 |
| `k` | 成本加成率（按**成本**） | 小数 |
| `P` | 报价单价 | ¥/吨 或 外币/吨 |
| `C` | 术语成本单价 | ¥/吨 |

---

## 1. 外币计费项折成人民币（必须按"每吨"口径）

### F01 海运费折吨价

```
S5 = USD_container × FX ÷ LOAD
```

> `LOAD` 必须来自**实际装箱方案**（含 VGM 上限、包装体积、是否可堆叠），不能用理论满载值。

### F02 保险费（CIF 自洽解）

```
S6 = 1.10 × r × C_CIF            ……(定义)
C_CIF = C_CFR + S6               ……(CIF 构成)
⇒ C_CIF = C_CFR / (1 − 1.10 r)   ……(解方程)
⇒ S6   = 1.10 r × C_CFR / (1 − 1.10 r)
```

若保单设有**最低保费** `floor`（整票）：

```
S6 = MAX( 1.10 r × C_CFR / (1 − 1.10 r),  floor ÷ Q )
```

> 约束：`1 − 1.10 r > 0`，即 `r < 1/1.10 ≈ 90.9%`。实务中 r 远小于此；若用户输入超出，引擎报"保险费率不可解"而不是给出负数。

## 2. 术语成本

```
F03  C_FOB = S1 + S2 + S3 + S4 + S7 + S8
F04  C_CFR = C_FOB + S5
F05  C_CIF = C_CFR + S6
F05b C_FCA = S1 + S2                       (出口清关费单独挂 S4，如需)
F05c C_CPT = S1 + S2 + S3 + S4 + S5        (交第一承运人，非船上)
F05d C_CIP = C_CPT + S6
F05e C_DAP = C_CIP + S9(不含进口税)
F05f C_DDP = C_DAP + 进口关税 + 进口环节税
```

> `S9` 只在 D 组进入卖方成本。F/C 组的 S9 由买方承担，**不写进报价成本**。

## 3. 定价：毛利口径与加成口径（必须二选一，不可混用）

### F06 毛利润

```
GP = P − C
```

毛利永远按**售价**口径计算，这是会计定义，不随用户选哪种加价方式改变。

### F07 毛利率（margin on price/sales）

```
m = GP / P = (P − C) / P
⇒ P = C / (1 − m)
```

### F08 成本加成率（markup on cost）

```
k = GP / C = (P − C) / C
⇒ P = C × (1 + k)
```

### F09 两口径的换算（恒等式）

```
(1 + k)(1 − m) = 1
k = m / (1 − m)
m = k / (1 + k)
```

| 毛利率 m | 对应加成率 k | 说明 |
|---|---|---|
| 3.00% | 3.09% | |
| 5.00% | 5.26% | |
| **8.00%** | **8.70%** | 本项目示例使用 |
| 10.00% | 11.11% | |
| 15.00% | 17.65% | |
| 20.00% | 25.00% | |
| 30.00% | 42.86% | |

**为什么这个差别必须强调**：成本 100 时，"加成 8%"→ 售价 108，实际毛利率 **7.41%**；要达到毛利率 8%，售价须 **108.70**。按加成 8% 报价，每吨少赚 0.70（每 100 元成本）。批次大、货值高时是实打实的利润损失。

### F09b 直接定价（用户自定价格）

若用户选择 `manual_price`，则 `P = 用户输入值`，系统**只做校验与展示**，不评判高低、不给出"建议价"。

## 4. 汇率换算

### F10 外币单价

```
P_fx = P ÷ FX
```

### F11 外币总额

```
Total_fx = P_fx × Q
```

### F12 人民币总额

```
Total_cny = P × Q
```

> **汇率方向必须写清**：本系统 `FX` 定义为"1 单位外币 = 多少人民币"。若用户提供的是"1 人民币 = 多少外币"，必须先取倒数再录入。这是最容易翻车的一位小数错误。

## 5. 敏感性分析

一维情景：只动一个变量，其余不变。

### F13 运费敏感性（±k%）

```
S5' = S5 × (1 + k)
C_CFR' = C_FOB + S5'
C_CIF' = C_CFR' / (1 − 1.10 r)          ← 保险费随 CIF 同向变动，必须重解
P' = C' / (1 − m)  或  C' × (1 + k_markup)
```

> 注意：**运费涨 10%，CIF 价不是涨"10% × 运费占比"**。因为保费基数(CIF)也变了，实际涨幅略高。这就是敏感性分析要用公式而非直觉的原因。

### F14 汇率敏感性（±k%）

```
FX' = FX × (1 + k)
S5' = USD_container × FX' / LOAD         ← 外币运费折人民币成本随之变化
C_CIF' = (C_FOB + S5') / (1 − 1.10 r)
P_fx' = P' / FX'
```

> 这是最容易被忽略的**双向效应**：人民币升值 → 外币报价下降（对客户更便宜），但**同时**外币计价的运费折人民币变便宜（卖方成本下降）。两者部分抵消，净效应需算，不能只看一边。

### F15 毛利敏感性（±k 个百分点）

```
m' = m + k
P' = C / (1 − m')       ← 曲线为 1/(1−m)，越接近 100% 越陡
```

## 6. 出口退税（单列，默认不抵减报价成本）

**重要**：退税是退还采购环节的进项增值税，**不等于利润，也不等于成本减免**。是否用退税来"贴补"报价，是商业决策，**软件不得自动抵扣**。

### F16 生产企业（免抵退）

```
当期免抵退税额 = 出口货物离岸价(FOB) × 外汇人民币牌价 × 退税率
```

（依据：财政部 税务总局公告 2026 年第 11 号 相关规定；生产企业适用"免抵退"办法。）

### F17 外贸企业（免退税）

```
应退税额 = 购进出口货物的增值税专用发票注明的金额 × 退税率
```

> 注意外贸企业的计税依据是**采购专票金额**，不是 FOB 价。二者不能混用。

### F18 含税价还原（若出厂价含税）

```
不含税价 = 含税价 ÷ (1 + 增值税率)
应退税额 = 不含税价 × 退税率
```

### 展示规则（本项目的硬性要求）

退款金额在 HTML/Excel 中**单独成行、单独标注"参考，未抵扣"**；
`references/validation.md` 中的校验项 V9 保证它不出现在任何术语成本里。

## 7. 数据完整性判定（怎么算"缺失"）

```
S 段缺失 ⟺ 该段录入口径为空（null / "" / 用户未提供）
```

程序规则：
1. 缺失段不参与求和 → 下游术语价显示"待补数据"，**不显示 0**；
2. 缺失清单按"责任方 + 补数来源"列出（见 `references/parameters.md`）；
3. 模拟值必须带 `simulated: true` 标记，在 HTML 中显示为紫色，在 Excel 中底纹为浅紫，并在报价草稿内部备注中强制提示。

### 为什么不允许"用 0 顶替"

用 0 顶替缺失运费会让 FOB/CFR/CIF 三价**看起来算出来了**，但实际少了一个成本段。销售拿着这个价去谈，签下来就是亏的。**宁可显示"待补数据"，也不能显示错数。**

## 8. 一次性校对公式（Excel 与 HTML 均内置）

| 编号 | 等式 | 不成立说明 |
|---|---|---|
| K1 | `C_CFR = C_FOB + S5` | 运费被重复计入或漏计 |
| K2 | `C_CIF = C_CFR + S6` | 保险费重复或漏计 |
| K3 | `S6 = 1.10 r × C_CIF` | 保费未按自洽解计算 |
| K4 | `(1 + k)(1 − m) = 1` | 毛利率与加成率口径混用 |
| K5 | `Σ 各段 = 术语成本` | 有段被重复或遗漏 |
| K6 | `Total_fx = P_fx × Q` | 总额与单价不一致 |
| K7 | `P_fx = P / FX` | 汇率方向搞反 |
