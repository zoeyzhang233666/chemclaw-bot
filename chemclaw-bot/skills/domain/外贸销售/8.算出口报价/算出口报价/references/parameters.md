# 参数与口径字典（每个数字从哪里来）

> 本文件回答一个问题的每一个分支：**"这个数，我从哪儿拿？拿不到怎么办？"**
> 核心原则：**系统不给市场价、不给运价、不给毛利建议、不给税费默认值。**

---

## 2. 关键口径的"人话解释"

### 2.1 出厂价（S1）到底含什么？

**含**：原料、加工、人工、制造费用、工厂合理利润（这是工厂给贸易商的价格）。
**不含**：包装（另计 S2）、内陆运输（S3）、出口报关（S4）、海运费（S5）、保险（S6）、出口税（S7）、其他（S8）。

如果工厂报的是"含包装送到港价"，必须先**拆**：让工厂给包装单价与到港运费单价，否则无法生成 FOB（只有到港价会重复计 S3/S4）。

### 2.2 装柜吨数（LOAD）为什么必须来自实际方案？

化工品常见的坑：
- 25 kg 编织袋，1 t = 40 袋；
- 20GP 理论 28 m³，实际装袋装重货**受重量限制**：纯碱堆密度约 1.0–1.1 g/cm³，20GP 载重约 21–22 t 可装，但**托盘化后**降到 18–20 t；
- 吨袋（jumbo bag）1 t/袋，装柜数由**尺寸与堆高**决定，不是简单除法。

**结论**：`LOAD` 一定要问货代/仓库的实际装箱数，不能写"20GP 按 25 t 算"。

### 2.3 保险费率（r）为什么必须问保险公司？

费率取决于：
- **航线**（东南亚 vs 中东 vs 非洲差异大）；
- **险别**（ICC C / B / A，A 最全最贵）；
- **免赔额**（deductible）；
- **承运人资质与船龄**；
- **货物特性**（纯碱属普通化工品，费率通常低；但危险品完全不同）。

**不得**用一个"行业惯例 0.1%"套所有货。系统不提供任何默认费率。

### 2.4 出口关税要不要填 0？

**不能默认 0。** 必须先按 HS 编码查税则。
本项目示例（纯碱 HS 2836200000）经查出口关税税率为 **0%**，但这个 0 是**查来的**，不是假定的（见 `references/citations.md`）。

### 2.5 汇率该用哪个价？

| 场景 | 建议口径 |
|---|---|
| 报价给客户（未锁汇） | 用**保守**汇率（对卖方不利的一侧），并在报价单写明"汇率基准日" |
| 已锁汇 | 用**锁汇价** |
| 事后核算实际收益 | 用**银行结汇买入价**（实际到账） |

三者不能混。系统只接受一个 `FX` 值，因此**报价与结算必须分开算两次**，或把报价有效期写清。

### 2.6 毛利口径与基准术语，为什么两个都要问？

- **口径**：毛利率（按售价）还是加成率（按成本）？—— 影响除数/乘数。
- **基准术语**：这个毛利是"针对 FOB 价"还是"针对 CIF 价"？

举例：同样"毛利 8%"，若指 FOB，则 CIF 价 = (C_CIF)/(1−8%)；若指 CIF，则 CIF 与 FOB 的价差里也含了毛利——两者结果不同。

**不谈清基准术语，"毛利 8%"这句话没有意义。**

## 3. 缺失清单模板（HTML 与 Excel 自动生成）

系统对每个缺失项输出三列：**为什么不能自动填**、**补数来源**、**当前状态**。

| 代码 | 缺失项 | 为什么不能自动填 | 补数来源 |
|---|---|---|---|
| FREIGHT | 海运费 | 运价随船期/箱型/货量波动，是货代报价资产，不能跨航线外推 | 货代书面报价（注明有效期） |
| INSURANCE | 保险费率 | 取决于航线、险别、免赔额、承运人，不同保司差异大 | 保险公司/货代保险部 |
| INLAND | 内陆运输 | 取决于起运地、车型、装载方式、是否含装车费 | 承运人报价 |
| PORT | 港口及报关 | 取决于港口/码头、THC、单证、报关代理费 | 货代一票全含报价 |
| LOAD | 装柜吨数 | 必须来自实际装箱方案（含 VGM、托盘、堆高） | 货代/仓库装箱方案 |
| EXPORT_TAX | 出口税费 | 以税则与申报要素为准 | 海关税则、报关行 |
| OTHER | 其他出口费用 | 检验/认证/结汇费按实际发生 | 银行、检验机构、认证机构 |
| FX | 汇率 | 用户决定采用哪个价（锁汇/即期/保守） | 用户 |
| GP | 毛利/加成率 | **这是商业决策，系统不得代定** | 用户 |

## 4. 录入前必问客户的 10 个问题

1. 品名、规格（哪几个指标是硬门槛？）
2. 数量与交货期（是否分批？）
3. 贸易术语（FOB/CFR/CIF 还是 DDP？）—— 若客户只说"CIF 你报"，仍需确认保险费谁出、险别
4. 装运港与目的港**具体码头**，以及收货地址是否在内陆
5. 包装形式（25 kg 袋 / 吨袋 / 散装 / 托盘）与唛头
6. 付款方式（T/T、L/C、DP）—— 影响 S8 银行费与资金占用
7. 是否需要产地证/Form E/RCEP 原产地证
8. 目的国是否有关税优惠资格、进口商是否有进口资质
9. 报价有效期（运费与汇率是主要变量）
10. 客户对险别（ICC A/B/C）与保额（110%/120%）的具体要求
