# 算例：重质纯碱 500 t · 青岛 → 雅加达

> 本算例用于演示**完整计算流程**。其中标注 **SIMULATED** 的运杂费与保险费率是演示用的模拟值，**不是实时运价**。
> 真实报价必须替换为货代与保险公司的书面报价，并用 `--simulated` 之外的普通模式重新生成。

---

| 数量 | 500 t | 假设订单 |

## 二、计算过程

### 2.1 海运费折吨价

```
S5 = 1250 USD/柜 × 7.1000 ÷ 25 t/柜 = 355.00 ¥/t
```

### 2.2 保险费（CIF 自洽解）

先算 CFR 成本（不含保险）：

```
S_fixed = S1+S2+S3+S4+S7+S8 = 1450+60+110+95+0+25 = 1740.00   ← FOB 成本
C_CFR   = 1740.00 + 355.00 = 2095.00
```

求解 CIF 与保险：

```
C_CIF  = C_CFR / (1 − 1.10 × 0.003)
       = 2095.00 / (1 − 0.0033)
       = 2095.00 / 0.9967
       = 2101.9364

S6     = 1.10 × 0.003 × 2101.9364
       = 6.9364 ¥/t
```

> 若按常见错误 `2095 × 1.10 × 0.003 = 6.9135` 计，会**少算 0.0229 ¥/t**。单吨看似微小，500 t 即 11.5 元；且这是**系统性**低估。

### 2.3 三术语成本

| 术语 | 组成 | 成本 ¥/t |
|---|---|---|
| FOB | S1+S2+S3+S4+S7+S8 | **1740.00** |
| CFR | FOB + S5 | **2095.00** |
| CIF | CFR + S6 | **2101.94** |

### 2.4 按毛利率 8%（以 FOB 为基准）定价

```
P_FOB = 1740.00 / (1 − 0.08) = 1891.3043 ¥/t
```

其余术语按**同一毛利口径**派生（成本链相同）：

```
P_CFR = 2095.00 / (1 − 0.08) = 2277.1739
P_CIF = 2101.9364 / (1 − 0.08) = 2284.7135
```

对应成本加成率（仅供对照）：

```
k = 0.08 / (1 − 0.08) = 8.6957%
```

### 2.5 外币报价（FX = 7.1000）

| 术语 | 单价 ¥/t | 单价 USD/t | 总额 USD（500 t） |
|---|---|---|---|
| FOB | 1891.30 | 266.38 | 133,190.45 |
| CFR | 2277.17 | 320.73 | 160,364.36 |
| CIF | 2284.71 | 321.79 | 160,895.31 |

### 2.6 出口退税（参考，未抵扣成本）

本案例出厂价按**不含税价**录入（`input_tax_included: false`），引擎按 FOB 成本口径给出参考值：

```
参考退税额 = FOB 成本 × 退税率 = 1740.00 × 13% = 226.20 ¥/t
整票参考退税额 = 226.20 × 500 t = 113,100 元
```

⚠ 两种口径务必分清，**不可混用**：

| 企业类型 | 计税依据 | 本案例口径下 |
|---|---|---|
| 生产企业（免抵退） | 出口离岸价 FOB × 汇率 × 退税率 | 1740.00 × 13% = 226.20 ¥/t |
| 外贸企业（免退税） | 采购增值税专用发票金额 × 退税率 | 若出厂价含税则 `1450 ÷ 1.13 × 13% = 166.81 ¥/t` |

> 该金额**不进入任何术语成本**，也不参与定价计算（校验项 V9 保证这一点）。
> 是否用退税贴补报价，是销售与财务的商业决策，工具不代定。

## 四、这个案例说明了什么

1. **FOB → CFR 的差额 = 海运费本身**（355.00 ¥/t），一目了然，客户比价时不会被"藏起来的费用"误导。
2. **CFR → CIF 的差额只有 6.94 ¥/t**，但这是**必收**的；漏收就是纯亏，且保险公司照收不误。
3. **保费必须自洽求解**，不能用 CFR 乘费率。
4. **毛利率 8% ≠ 加成率 8%**：差 0.6957 个百分点，折算到 500 t 上约 23,300 元。
5. **运费与汇率是主要风险**：运费 +20% 且汇率 −5% 时，若报价不变，毛利会被吃掉大半。

## 五、必须替换的模拟值

在对外报价前，以下 5 项必须替换为真实书面报价：

| 项 | 当前值 | 向谁索取 |
|---|---|---|
| 内陆运输 | 110 ¥/t | 承运人/车队 |
| 港口及报关 | 95 ¥/t | 货代（一票全含报价） |
| 海运费 | 1250 USD/柜 | 货代（注明有效期） |
| 装柜吨数 | 25 t/柜 | 货代/仓库装箱方案 |
| 保险费率 | 0.30% | 保险公司/货代保险部 |

替换后重新运行：

```bash
python scripts/calc_engine.py input.json -o output/result.json
python scripts/build_html.py input.json -o output/报价计算器.html
python scripts/build_xlsx.py input.json -o output/报价工作簿.xlsx
```

（不要加 `--simulated`，或只把仍未替换的字段列入。）
