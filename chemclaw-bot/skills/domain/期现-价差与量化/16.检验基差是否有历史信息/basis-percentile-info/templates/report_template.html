1口径与合约规则（先钉死定义，再谈统计）

基差符号一旦选定不得中途翻转；现货与期货必须在同一时点、同一计价单位、同一交付逻辑下相减。

基差定义

基差 Bt = St − Ft // 元/吨，正=现货升水 基差率 rt = Bt / St // 无量纲，研究主口径 基差收益 Δh = rt+h − rt 现货收益 xh = St+h/St − 1 期货收益 yh = Ft+h/Ft − 1 恒等式 Δh ≈ xh − yh // 基差变化 = 现货变化 − 期货变化 期货贡献占比 = |yh| / (|xh| + |yh|)

为什么用基差率而不是元/吨：甲醇现货在样本期内从约 2,000 涨到约 4,700 元/吨。 同样 100 元/吨的基差，在 2,000 元价位是 5%，在 4,700 元价位只有 2%。用元/吨做跨年比较， 分位会被价格水平系统性带着走；用比率则自动按价格缩放。元/吨口径在敏感性一节单独复核。

    3滚动分位怎么算：无未来函数的三道闸门

    这是本研究最容易被做错的地方——用全样本分位当“当时可用的信号”，等于把答案先看了。

    ① 窗口严格滞后

    Pt = rank( Bt | {Bt−1, …, Bt−W} ) / N

    窗口只取 t 之前 的 W 个交易日，不含 t 本身之外的任何未来点。 分位 = 百分位秩（#小于 + 0.5×#等于）/ N，与分布形状无关。

    ② 未来收益不得回填到分位

    分位时点 = t 收益区间 = [t, t+h] // 信息检验口径 可操作口径：分位 t−h → 收益 [t−h, t]

    两种口径都给：前者回答“基差高分位的日子之后会怎样”，后者保证“用到分位和收益时都已发生”。 两者结论方向一致，才说明信息不是时点对齐造成的假象。

    ③ 数据末端必须标为“当时未知”

    若 t > T − W：
    Pt 为末端回填 → 稳定性检验剔除

    10公式与复核口径

    统计口径

    分位 Pt = ( #{Bj < Bt} + 0.5·#{Bj = Bt} ) / N, j ∈ [t−W, t−1] 分组：低 P≤k, 高 P≥1−k, 其余中间 稳健统计：均值 / 中位数 / P10 / P25 / P75 / P90 / 样本偏度 / 超额峰度 均值稳健度：抽样偏度 ≈ 样本偏度 / √n；正部占比 = Σmax(Δ,0)/Σ|Δ| 自助法：循环块自助，块长 = h，R = 8000 次；p 值取正态近似 + 经验 p 双报

    价格风险分解

    Δh = xh − yh 若 |yh| 主导 → 基差变化主要是期货在动（含时限结构/预期） 若 |xh| 主导 → 基差变化主要是现货在动（供求/物流/口径） 本样本期货贡献中位数：见“分组 × 观察期”表的期货均值列

    只看基差而不看现货与期货各自的收益是这类研究最典型的漏洞： 同一基差回归，可能来自现货大涨、也可能来自期货下跌，两者的风险敞口完全不同。
