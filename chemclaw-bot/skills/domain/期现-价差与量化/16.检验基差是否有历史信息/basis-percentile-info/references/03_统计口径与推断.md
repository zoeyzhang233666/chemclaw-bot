# 03 统计口径与推断

## 1. 每组必须报的量

| 量 | 为什么必须 |
|---|---|
| `n`（样本量） | 组越小，均值越不可信；藏 n 就是藏问题 |
| 均值 | 与用户直觉对齐 |
| 中位数 | 厚尾下比均值稳健，两者差大就说明有极值主导 |
| 标准差 / P10 / P25 / P75 / P90 | 让分布形状可见，不只给一个点 |
| 偏度 / 超额峰度 | 判断"均值是否被少数极端日绑架" |
| 正收益占比 | 最直观的"胜率"描述（不是策略胜率） |
| **现货收益均值** | 拆解的第一半 |
| **期货收益均值** | 拆解的第二半 |
| 期货贡献占比中位数 | `|y|/(|x|+|y|)`，一眼看出谁在动 |
| 换月日占比 | 判断是否被换月污染 |

## 2. 均值稳健度的两个修正量

厚尾样本里，**样本均值本身就是个高方差估计量**。两个不依赖正态假设的诊断：

### 2.1 均值的近似抽样偏度

```
skew(mean) ≈ skew(x) / √n
```

`n=100`、`skew=3` 时 `skew(mean)≈0.3`——均值仍有偏，但已不大。
`n=10`、`skew=3` 时 `skew(mean)≈0.95`——均值基本不可信，应看中位数。

### 2.2 正部占比

```
pos_share = Σ max(Δ,0) / Σ |Δ|
```

它回答："这组的**总波动幅度**里，有多大比例是向上的？"
比"正收益天数占比"更能反映"涨的时候涨得多不多"。
`pos_share > 0.6` 且 `mean > 0` 通常说明上涨集中而下跌分散。

### 2.3 均值 vs 中位数背离

`mean` 与 `median` 符号相反是重要信号：
说明有**少数极端样本**在主导均值。此时：

- 报告里两个都写
- 结论表述用"中位数显示…（均值被少数极端日拉偏）"
- 不要只挑对结论有利的那个

**本案例 h=60 低分位组**：`mean=+4.66%`、`median=+3.57%`，正收益占比 97.2%——
方向一致且高度集中，可信度高。

## 3. 差值的推断：为什么必须用块自助

### 3.1 重叠样本问题

日度数据、20 日窗口：第 t 天和第 t+1 天的"未来 20 日收益"共享 19 天。
1000 个观测里其实只有约 50 个**独立**的 20 日期间。

直接做两样本 t 检验，等价于假装有 1000 个独立样本，
**p 值会被压小一个数量级**，显著性被严重高估。

### 3.2 循环块自助（circular block bootstrap）

```
1. 块长 b = h（观察期）
2. 从原序列随机取起点，连续抽 b 个（到尾部时循环回头）
3. 重复直到长度 = n
4. 对低分位组、高分位组各做一次，算均值差
5. 重复 R 次，得到差值分布
```

块内保留原有的序列相关结构，块间近似独立——这是处理重叠样本的标准做法。

参数：

- `b = h`：至少覆盖一个完整的重叠周期
- `R = 8000`：`p` 值精度的下限约 `1/R`
- 为了不让块长吃光样本，实际用 `b = min(h, n_sample // 8)`，
  并在输出里记录实际使用的 `blocksize`

### 3.3 双 p 值

```
p_norm = 2·(1 − Φ(|obs| / sd_boot))        # 正态近似，精度不受 R 限制
p_emp  = #{|diff* − obs| ≥ |obs|} / R      # 经验 p，R 有限时下有底 ≈ 1/R
```

两个都报。当 `p_emp` 撞到下限（例如 0.0000 但 `R=8000`）时，改用 `p_norm`。

### 3.4 退化保护（宁可空着，不可乱给）

当 `块长 ≥ 样本量的一半` 时，循环块抽样会反复覆盖全样本，
**每次自助样本几乎等于原样本，方差趋近 0**，`p` 值会荒谬地变成 1.0。

本 Skill 的处理：

```python
if len(a) <= blocksize * 2:
    return {"degenerate": True, "p": None, "reason": "样本 ≤ 2×块长，循环块自助退化"}
```

报告里显示"退化，不给 p"，而不是显示一个 1.0000 的假 p。

**本案例**：`h=60` 时低/高分位各约 108/135 条，`2×60=120 > 108`，判退化；
`h=120` 同理。所以 3 月/6 月两组只报均值与中位数，不报 p。

### 3.5 非重叠子样本复核

作为第二条独立证据：每 `h` 天取一个样本，得到近似独立的子序列，
在其上重算低−高差值。

**本案例**（4 周口径）：

| 观察期 | 原样本 低−高 | 非重叠子样本 低−高 | 非重叠 n低/n高 |
|---|---|---|---|
| 5 日 | +2.89% | +2.72% | 19 / 33 |
| 10 日 | +3.77% | +4.30% | 9 / 17 |
| 20 日 | +6.47% | +7.19% | 6 / 9 |

方向与量级一致 → 说明结论不是重叠造成的。
但非重叠后 n 掉到个位数，**p 值意义有限，只作方向佐证**。

## 4. 稳定性检验的三个维度

### 4.1 年度

每年一组，看各年方向是否一致。
**只看方向，不看单年幅度**——单年约 30-40 条重叠样本，实际只有 1-2 个独立事件。

本案例 4 周口径：低分位组 3 年（2023/2024/2025）全为正，
高分位组 3 年全为负，2022 年因分位起始晚、低分位组为空。

### 4.2 月份

12 个月分组。**必须同时说明样本量不足的局限**：
4 年数据、每月约 30 条重叠样本，无法区分"季节效应"与"某年的偶然"。
报告的表述应该是"呈现形态"而不是"存在季节性"。

### 4.3 市场结构（期限结构）

用「主力 − 次主力」价差的 120 日滚动分位判定：

```
≥ 60%  → Back（近强）
≤ 40%  → Contango（远强）
其余    → 结构不明
```

只用同日两合约收盘价，无未来函数。然后按结构分组重算统计。

本案例 4 周口径三组均值：Back +0.11%、Contango −0.14%、结构不明 +0.27%——
差异不大，说明**分位信息不依赖期限结构**。

## 5. 阈值与窗口的敏感性

两张表：

**阈值表**：每个 `k ∈ {0.1,0.2,0.3,0.4}` × 每个观察期 → 低−高差值 + p

**窗口表**：每个 `W ∈ {250,500,750}` × 每个阈值 × 每个观察期

判据：
- 结论**方向**在所有组合下一致 → 稳健
- 幅度随 `k` 增大而单调收窄 → 符合"越极端越强"的经济直觉
- 某组合翻转 → 必须在报告里点出来，不能只报有利的组合

本案例：`k` 从 0.1 到 0.4，4 周差值从 +10.6% 单调收窄到约 +3%，
方向始终为正——这是"分位越极端、后续回归越强"的典型形态。

## 6. 不要做的事

| 不要 | 为什么 |
|---|---|
| 用 t 检验跑重叠日度样本 | p 值小一个数量级 |
| 只报 p<0.05 的组合 | 多重比较，选择性报告 |
| 用 R² 说"信息量大" | 厚尾 + 重叠，R² 无解释力 |
| 把"显著"说成"可交易" | 没扣成本/滑点/流动性 |
| 用全样本拟合阈值再报样本内 p | 双重窥探 |
| 对 n<20 的组下结论 | 噪声 |
| 忽略退化而硬报 p | 假精确 |
