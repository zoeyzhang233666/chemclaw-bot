# 01 口径定义与合约规则

> 这一章决定后面所有数字有没有意义。**口径没钉死之前，不要开始算统计。**

## 1. 基差定义（三选一，选完不许改）

| 定义 | 公式 | 适用 | 注意 |
|---|---|---|---|
| 水平基差 | `B = S − F` | 与报价对话、看绝对价差 | 跨价格水平不可比 |
| 基差率 | `r = (S − F) / S` | **研究主口径** | 自动按价格缩放，可跨年比较 |
| 对数基差 | `ln(S/F)` | 收益率建模 | 小基差时≈`(S−F)/S` |

本 Skill 默认 `基差率`，因为样本内价格可能翻倍（甲醇 2000→4700 元/吨），
同样 100 元/吨的水平基差在不同价位含义完全不同，分位会被价格水平带着走。

同时保留水平基差，在敏感性一节复核（HTML 面板可一键切换 `ratio / lv`）。

### 符号约定

```
基差 > 0  →  现货升水（Back / 现货强于期货）
基差 < 0  →  现货贴水（Contango / 期货强于现货）
```

**东方财富、同花顺、部分资讯站把基差写成 `期货 − 现货`，符号相反。**
接手别人的数据时，第一件事是拿一天的数字手算核对，不要相信列名。

## 2. 收益口径与恒等式

```
现货收益   x_h = S_{t+h}/S_t − 1
期货收益   y_h = F_{t+h}/F_t − 1
基差率变化 Δ_h = r_{t+h} − r_t  ≈  x_h − y_h
```

`≈` 是因为基差率分母是现货，严格展开有一阶交叉项，日度尺度下可忽略（`|x·y| < 1e-4`）。

**这一行是整份报告的核心**：`Δ_h` 必须能拆成 `x_h` 和 `y_h` 两部分。
任何只报 `Δ_h` 的分析都不完整——因为它没说清是现货在动还是期货在动。

### 期货贡献占比

```
share_fut = |y_h| / (|x_h| + |y_h|)
```

`share_fut → 1` 说明基差变化主要是期货在动（预期/期限结构驱动）；
`share_fut → 0` 说明主要是现货在动（供求/物流/口径驱动）。

## 3. 期货合约映射

### 3.1 主力连续（本 Skill 默认）

规则：**当日收盘后，持仓量（OI）最大且交割月 ≥ 当前月的合约。**

为什么用 OI 而不是成交量选主力：成交量日内跳动大，OI 更能代表真实持仓迁移。
为什么要求"交割月 ≥ 当前月"：已进入交割月的合约不应再作为远期定价基准。

换月时点：新合约 OI 首次超过旧合约的**次日**生效（避免盘中信号反复）。
换月当日会记录 `roll_day=1`，并在偏差清单里单独量化其影响。

### 3.2 近月连续（对照口径）

规则：交割月最早的合约，**但加流动性门槛**——

```
若 距最后交易日 ≤ 20 日 且 持仓量 < 主力合约持仓的 5%  →  视为"伪近月"，跳到下一合约
```

不加门槛的"近月连续"在临近交割时会切换到几乎没有成交的合约，
价格是挂单噪声，会让基差序列出现剧烈伪波动。

### 3.3 固定交割月（01/05/09）

直接取指定交割月的合约。**注意：不同年份的同一交割月是独立样本**，
不能拼成一条"连续"序列去做滚动分位（会跨越巨大的月间跳空）。
固定口径只用于**方向对照**，不用于连续分位。

### 3.4 指数合约

按各合约持仓加权合成。**不可用于基差**：它不是可交割合约，
没有对应的现货交割逻辑，基差的经济含义不成立。

## 4. 郑商所甲醇（MA）合约规则

| 项目 | 规则 |
|---|---|
| 交易单位 | 10 吨/手 |
| 报价单位 | 元/吨 |
| 最小变动价位 | 1 元/吨 |
| 最后交易日 | 合约交割月份第 10 个交易日 |
| 最后交割日 | 最后交易日后的第 3 个交易日 |
| 交割品级 | GB/T 338-2011《工业用甲醇》优等品 |
| 交割地点 | 指定交割仓库（含太仓、张家港等华东库） |

**关键含义**：主力合约在最后交易日之前很久就已换月（OI 早已转移），
所以**主力口径的基差几乎不受最后交易日直接影响**；
但如果用"近月连续"，临近交割的流动性塌陷就是主要风险源。

## 5. 现货口径的六要素

写现货来源时必须六项齐全，缺一项就标"未核实"：

```
地区（华东/太仓/江苏）· 品级（优等品）· 含税与否 · 提货方式（出厂/送到/库提）
· 时间戳（当日几点）· 数据源（谁发布的、是否模型价）
```

### 常见现货口径陷阱

| 陷阱 | 后果 |
|---|---|
| 全国基准价当华东价 | 基差水平含区位价差，绝对水平不可比 |
| 模型指导价当实盘成交价 | 平滑、滞后，且有 K/C 系数未兑现 |
| 出厂价 vs 送到价混用 | 运费被算进基差，几十到上百元/吨 |
| 含税 vs 不含税混用 | 差 13% 增值税，量级与基差相当 |
| 月均价当日价混用 | 分位被平滑，极端值消失 |
| 现货时间戳早于期货收盘 | 用早上的现货对下午的期货，含日内偏差 |

**做不到目标口径时**：明写降级链，例如

> 目标：华东太仓甲醇优等品含税出罐价（日频）
> 实际：生意社 100ppi 甲醇基准价（全国、含税、模型指导价）
> 影响：基差水平含华东 vs 全国的区位价差；分位（相对位置）受影响较小但非零；
> 已用 100ppi 公布的主力基差率逐日比对，隐含水平差中位 ≈ 0 元/吨。

## 6. 口径核验（有公开对照序列时必做）

如果数据源同时公布了"主力基差率"，就把它当**外部校验**：

```
重建基差率 = (S − F) / S × 100%
偏差 = 重建 − 公布
```

偏差集中在**换月日**是正常的（双方换月规则不同）；偏差全年均匀分布才说明口径有问题。

进一步可以反推"隐含水平差"：

```
(S − adj) − F = rate/100 × (S − adj)
⇒ adj ≈ (S − F − S·rate/100) / (1 − rate/100)
```

`adj` 中位数 ≈ 0 说明水平一致；`adj` 有系统性偏移说明现货口径或合约不匹配。
**然后把 `adj` 加回基差、重排分组，看结论是否翻转**——这是口径稳健性检验。

## 7. 本例的实际选择

| 项目 | 选择 | 理由 |
|---|---|---|
| 基差 | 基差率 `(S−F)/S` | 价格水平跨 2000→4700 |
| 现货 | 生意社 100ppi 甲醇基准价 | 唯一可得的免费日频长序列（**降级口径**） |
| 期货 | 主力连续（OI 最大） | 可交割、可交易、无合成偏差 |
| 收盘价 | 各合约收盘价 | 不用结算价（两者口径差异会污染基差） |
| 对齐 | 只保留双方都有值的交易日 | 不插值 |
