# 06 · 产业关系图谱

常见品种对的产业定位，用来做第 1 步"定关系"。**本文件的产业描述属行业常识，
未逐条核实到原始文献，使用时应结合当期报道，并在报告中标注核对级别。**

---

## 一、判断关系类型的方法

### 三个提问

1. **能不能互相替代？** 在哪些下游？切换成本高不高？
2. **是不是上下游？** 谁是谁的原料？加工费大概多少？
3. **有没有共同原料？** 共享比例？有没有独有的原料路径？

### 四类关系与特征

| 类型 | 锚 | 比价特征 | 可否当套利价差 |
|---|---|---|---|
| 上下游 | **强**（加工利润） | 有上下界，超出则装置减产/复产 | 可以（但要注意产能刚性与库存） |
| 同质替代 | **强**（替代切换） | 有区间，偏离触发替代 | 可以（注意品质差异） |
| 部分替代 | **弱** | 区间宽且不稳，可长期偏离 | 不建议 |
| 共同原料/不同下游 | **弱** | 反映两个下游相对景气，无硬锚 | 不建议 |
| 仅统计相关 | **无** | 可永久漂移 | 不可以 |

## 二、聚烯烃（PP / PE）

### PP（聚丙烯）vs LLDPE（线型低密度聚乙烯）

**关系**：部分替代 + 部分共同原料

#### 原料路径

| 品种 | 主要路径 | 说明 |
|---|---|---|
| **PP** | 石脑油裂解 → 丙烯 | 传统路径 |
| | **丙烷 → PDH → 丙烯** | **PP 独有**，可由丙烷独立扩能 |
| | 煤/甲醇 → MTO → 丙烯 | 中国特有，煤化工 |
| | 丙烯 → 聚合 → 聚丙烯 | |
| **LLDPE** | 石脑油裂解 → 乙烯 | 传统路径 |
| | **乙烷 → 裂解 → 乙烯** | 依赖乙烷船货（北美/中东） |
| | 煤/甲醇 → MTO → 乙烯 | |
| | 乙烯 → 聚合 → 聚乙烯 | |

**关键差异**：
- PP 侧可走 **PDH**，与乙烯裂解装置**脱钩**。
- PE 侧新增供给**高度绑定乙烯裂解**（尤其乙烷裂解）。
- 丙烯与乙烯的相对价差是比价的**主驱动**之一。

#### 下游重叠

| 下游 | PP | LLDPE | 重叠程度 |
|---|---|---|---|
| 包装膜 | BOPP / CPP | PE 膜 | **高**（部分场景可换） |
| 注塑件 | ✓ | ✓（HDPE 更多） | **中** |
| 编织袋 | ✓ | — | 低 |
| 农膜/工业膜 | — | ✓ | 低 |
| 无纺布（卫材） | ✓ | — | **PP 独有** |
| 汽车改性料 | ✓ | — | **PP 独有** |
| 透明包装 | 透明 PP | — | PP 独有 |
| 重包装/管材/电缆 | — | ✓ | **PE 独有** |
| 中空容器 | — | ✓（HDPE） | PE 独有 |

#### 期货标准品

| 品种 | 交易所 | 标准品 | 乘数 |
|---|---|---|---|
| PP | 大商所 | 均聚**拉丝级** | 5 吨/手 |
| 塑料（L） | 大商所 | **LLDPE 薄膜料**（7042 类） | 5 吨/手 |

**⚠ 两者不是同一商品**：拉丝级 vs 膜料，熔指、刚性、加工温度都不同。
比价里含"牌号价差"，**不能当同物比价**。

#### 对比价的含义

> 两者是**部分替代**关系，比价**没有硬锚**。它反映：
> 1. 丙烯—乙烯相对价差（成本端）
> 2. 两侧投产节奏错位（供给端）
> 3. 两侧库存与开工（需求端）
>
> **不能当套利价差**：替代只在部分下游成立，切换需要改设备/配方，
> 期货合约又不能实物互换（牌号不同）。

## 三、黑色系

### 螺纹钢 vs 热轧卷板

**关系**：同质替代（同一炼钢流程，不同轧制）

| 项目 | 说明 |
|---|---|
| 共同原料 | 铁矿石、焦炭（同一条长流程） |
| 差异 | 轧制线不同；螺纹用于建筑，热卷用于制造 |
| 比价锚 | **中等**——同一钢坯可分配，但产线切换需时间 |
| 比价含义 | 建材 vs 制造业的相对景气；卷螺差 |

**注意**：卷螺差在中国有明显的季节性和政策驱动（地产 vs 制造业、出口），
不是纯统计规律。

### 螺纹钢 vs 铁矿石

**关系**：上下游（矿石 → 生铁 → 钢）

| 项目 | 说明 |
|---|---|
| 比价含义 | 钢厂**加工利润**的粗略代理（未扣焦炭、人工、折旧） |
| 锚 | **较强**——利润为负则减产，为正则增产 |
| 注意 | 矿石品位、焦炭配比、废钢替代都会影响；高炉刚性大，减产滞后 |

### 焦煤 vs 焦炭

**关系**：上下游（焦煤 → 焦化 → 焦炭）

| 项目 | 说明 |
|---|---|
| 比价含义 | 焦化利润 |
| 锚 | 强，焦化产能受环保约束 |
| 注意 | 焦煤品质（主焦/配焦）差异大 |

## 四、油化工

### PTA vs PX

**关系**：上下游（PX → PTA）

| 项目 | 说明 |
|---|---|
| 比价含义 | PTA 加工费（PX→PTA 的加工利润） |
| 锚 | **强**，加工费跌破现金成本则减产 |
| 注意 | 加工费与 PX 价格水平有关；PTA 产能过剩时加工费长期低位 |

### 原油 vs 燃料油

**关系**：上下游（原油 → 常减压 → 燃料油）

| 项目 | 说明 |
|---|---|
| 比价含义 | 炼厂简单加工利润 |
| 锚 | 中等 |
| 注意 | 燃料油分高硫/低硫，规格差异大；船燃需求受 IMO 政策影响 |

### 甲醇 vs 尿素

**关系**：共同原料（煤/天然气）+ 部分产能可切换

| 项目 | 说明 |
|---|---|
| 共同原料 | 煤、天然气 |
| 差异 | 甲醇下游（MTO、甲醛、醋酸）；尿素下游（农业） |
| 比价含义 | 两个下游的相对景气；气头装置的产能分配 |
| 锚 | **弱**——装置可切换但成本结构不同 |

## 五、油脂油料

### 豆油 vs 豆粕

**关系**：共同原料（大豆），联产品

| 项目 | 说明 |
|---|---|
| 关系 | **联产品**——压榨大豆同时产出豆油和豆粕 |
| 比价含义 | 压榨利润的分配；出油率/出粕率固定 |
| 锚 | **强**——压榨利润 = 油×出油率 + 粕×出粕率 − 大豆成本 |
| 注意 | 油粕比（豆油/豆粕）是经典指标；受饲料需求与食用油需求双驱动 |

### 豆粕 vs 菜粕

**关系**：替代（饲料蛋白）

| 项目 | 说明 |
|---|---|
| 替代性 | **较强**——水产饲料中可部分替代 |
| 比价含义 | 蛋白料的相对性价比；替代上限受抗营养因子约束 |
| 锚 | 中等，替代比例有上限 |

### 棕榈油 vs 豆油

**关系**：替代（食用油 + 生物柴油）

| 项目 | 说明 |
|---|---|
| 替代性 | **强**——食用油可互替；生柴原料也可互替 |
| 比价含义 | 两大油脂的相对供需；受产地（马来/印尼）政策影响大 |
| 锚 | 中等偏强，但受出口税/出口禁令等政策冲击 |

## 六、能源

### 动力煤 vs 焦煤

**关系**：部分共同原料（煤），不同用途

| 项目 | 说明 |
|---|---|
| 差异 | 动力煤用于发电；焦煤用于炼焦 |
| 比价含义 | 煤炭资源的分配；部分矿井可切换 |
| 锚 | **弱** |

### 天然气 vs 尿素

**关系**：上下游（气 → 合成氨 → 尿素）

| 项目 | 说明 |
|---|---|
| 比价含义 | 气头尿素利润 |
| 锚 | 中等，但中国以煤头为主，气头占比小 |
| 注意 | 海外气价与国内气价机制不同，不能直接用国际气价 |

## 七、关系判定速查表

| 如果用户问… | 先判断 | 关键提示 |
|---|---|---|
| "这两个品种比价合理吗" | 有没有锚 | 无锚就不能说"合理/不合理" |
| "比价能不能做" | 能不能实物交割互换 | 牌号不同 → 不能 |
| "历史上最低多少" | 用 ECDF 还是极值 | 极值可能来自换月或数据错误 |
| "为什么最近比价变了" | 贡献分解 | 分清分子强还是分母弱 |
| "会不会回归" | **结构检验** | 中枢迁移则不回归 |

## 八、使用本文件的红线

1. **本文件是行业常识，不是核实过的事实。** 用在报告里时必须标 **核对级别 C**，
   或配合当期报道升级为 A/B。
2. **不要用本文件的具体数字**（如出油率、加工费）。这些数值随工艺和市场变化，
   需要当期数据支撑。
3. **产能、开工率、库存、成本的具体数值一律不用本文件**。
   这些必须来自可核对的数据库或报道。
4. **本文件只用于"定关系"这一步**，不用于解释某次具体的比价波动——
   那需要逐条事件台账。
5. 涉及政策的表述（出口税、环保限产、能耗双控）必须核对当期具体文件，
   本文件只说明机制存在。
