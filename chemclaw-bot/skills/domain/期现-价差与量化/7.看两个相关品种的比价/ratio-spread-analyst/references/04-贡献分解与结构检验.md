# 04 · 贡献分解与结构检验

比价分析的真正价值不在于"高低判断"，而在于回答：**比价的变化来自哪一边**，
以及**这个比价的"正常水平"是不是稳定的**。本文件给出这两件事的方法。

---

## 一、贡献分解

### 1.1 对数恒等式

```
r = A / B
ln r = ln A − ln B
```

对两个时点（起 t0，止 t1）：

```
Δln r = ln r(t1) − ln r(t0)
      = [ln A(t1) − ln A(t0)] − [ln B(t1) − ln B(t0)]
      = Δln A − Δln B
```

**这个等式是精确的**（不是近似），自测里有专门验证：

```
ln(a1/a0) − ln(b1/b0) == ln((a1/b1)/(a0/b0))
```

### 1.2 为什么要用对数而不是简单百分比

| 方式 | 加总性 | 说明 |
|---|---|---|
| `Δr/r = ΔA/A − ΔB/B` | ❌ 不精确 | 这是一个近似，乘数关系下不成立 |
| `Δln r = Δln A − Δln B` | ✅ 精确 | 恒等式，永远成立 |

举例：A 从 100 涨到 200（+100%），B 从 100 涨到 50（−50%），
比价从 1.0 变成 4.0（+300%）。

- 简单百分比：+100% − (−50%) = +150% ≠ +300% ❌
- 对数：ln2 − ln0.5 = 0.693 + 0.693 = 1.386 = ln4 ✅

**所以必须用对数。**

### 1.3 份额定义

```
份额_A = |Δln A| / (|Δln A| + |Δln B|) × 100%
份额_B = |Δln B| / (|Δln A| + |Δln B|) × 100%
份额_A + 份额_B = 100%
```

- **份额**回答"谁在推动"
- **符号**回答"往哪个方向"

### 1.4 三种典型形态

| 形态 | 表现 | 份额 | 解读 |
|---|---|---|---|
| **单边推动** | 一边大涨，另一边几乎不动 | 90/10 | 比价走扩是供给/需求单边事件 |
| **同向但速度差** | 两边都涨，一边涨更多 | 60/40 | 成本推动行情；比价信息含量较低 |
| **反向** | 一边涨一边跌 | 可能都接近 50 | 替代关系/相对景气切换 |

### 1.5 关键警示：份额 50/50 ≠ 无关

如果两边同时涨 10%，比价**不动**，份额 50/50。
但这不代表"两个品种没关系"——**两边都在大幅波动**。

正确表述：

> "近6月 PP 与 L 同向上涨，但涨幅接近（PP +10.8%、L +9.9%），
> 比价仅变动 +0.8%。比价稳定不代表两者独立，而是**两者力度相当**——
> 这种情况下比价的信息含量低，不宜作为判断依据。"

### 1.6 本案例的完整分解

| 区间 | PP | L | 比价 | 主导 | 份额 |
|---|---|---|---|---|---|
| 近1月 | +5.6% | +1.7% | +3.9% | PP | 76/24 |
| 近3月 | +10.8% | +9.9% | +0.8% | PP | 52/48 |
| 近6月 | +14.1% | +9.3% | +4.3% | PP | 60/40 |
| 近1年 | +42.8% | +26.8% | +12.6% | PP | 60/40 |
| 近3年 | +26.0% | +9.7% | +14.9% | PP | 71/29 |
| 近5年 | +1.9% | −5.3% | +7.5% | L | 26/74 |
| 全样本 | −12.0% | −18.9% | +8.5% | L | 38/62 |

**关键区间（2024-10-31 → 2026-05-19）**：

| 项目 | 数值 |
|---|---|
| PP | 7450 → 8944 = **+20.1%** |
| L | 8150 → 8051 = **−1.2%** |
| 比价 | 0.9141 → 1.1109 = **+21.5%** |
| 主导 | **PP，份额 94%** |

**这是全案例最干净的一个证据**：PP 涨了 20%，L 几乎没动（−1.2%），
比价走扩 21.5%。**几乎全部来自 PP 侧。**

### 1.7 分段贡献（按产业结构）

| 阶段 | 比价变化 | PP | L | 主导 |
|---|---|---|---|---|
| 2014-02 → 2016-12 | −10.0% | −12.9% | −9.0% | PP 69% |
| 2016-12 → 2019-10 | +22.3% | −17.6% | −18.0% | **L 75%** |
| 2019-10 → 2021-09 | −6.0% | +27.8% | +35.9% | PP 44% |
| 2021-09 → 2024-10 | −10.8% | −19.3% | −21.1% | **PP 61%** |
| 2024-10 → 2026-05 | +21.5% | +20.1% | −1.2% | **PP 94%** |
| 2026-05 → 2026-10 | −3.3% | −2.1% | +1.2% | L 63% |

**注意 2016-12 → 2019-10 这段**：比价 +22.3%，但主导方是 **L（75%）**——
因为 L 跌了 18%，PP 跌了 17.6%，**L 跌得更多**，所以比价上行。

这说明：**"比价上涨"不等于"分子品种走强"**，可能是分母品种更弱。
报告里必须写清是哪一种。

### 1.8 长短区间的陷阱

份额只取决于**两个端点**，不关心中间路径。所以：

- 区间越长，越容易被某个极值端点主导。
- 近5年的主导方（L，74%）与近3年（PP，71%）相反——因为 5 年前的起点选在了一个高位。
- **必须同时给多个区间**，让读者看到主导方会随区间切换。

## 二、结构检验

### 2.1 为什么必须做

"回归"这个词的前提是**存在一个稳定的均值**。如果中枢本身在迁移，
"均值回归"就是拿一个移动的靶子当靶心。

### 2.2 方法一：两段均值偏移扫描（Welch t）

对 `x = ln(比价)` 序列，遍历每个候选分割点 k（要求两段各至少 120 个样本）：

```python
mean_a = mean(x[:k]);  mean_b = mean(x[k:])
var_a  = var(x[:k]);   var_b  = var(x[k:])
se = sqrt(var_a/len(a) + var_b/len(b))
t  = (mean_b − mean_a) / se
```

取 |t| 最大的若干个**互不重叠**的断点（相邻断点至少间隔 130 个样本）。

### 2.3 本案例结果

| 断点 | t | 断点前中枢 | 断点后中枢 | 变化 |
|---|---|---|---|---|
| **2017-11-30** | **42.04** | 0.8816 | 0.9946 | **+12.8%** |
| 2026-04-14 | 41.56 | 0.9554 | 1.0582 | +10.8% |
| 2018-06-14 | 39.72 | 0.8917 | 0.9965 | +11.7% |
| 2017-05-22 | 36.80 | 0.8786 | 0.9890 | +12.6% |
| 2018-12-24 | 31.02 | 0.9066 | 0.9938 | +9.6% |

**解读**：
- **2017-11-30 的 t = 42** 在统计上是极端显著的（t > 3 就已经很显著了）。
- 断点前中枢 0.88，断点后 0.99，**中枢抬升了 12.8%**。
- 2026-04-14 的第二个断点 t = 41.56，但**断点后只有 126 个样本**，应标注为"待确认"。

### 2.4 方法二：252 日滚动均值

本案例的滚动均值轨迹：

```
0.808 (2016) → 1.08 (2020) → 0.91 (2024) → 1.017 (2026)
```

走了**两轮完整的上下**，幅度约 ±30%。

**含义**：这是一个**有慢变量的序列**，不是一个围绕固定均值的平稳过程。
任何"长期均值"都需要先指定"哪一段的长期"。

### 2.5 方法三：分阶段分位对照

| 阶段 | N | 中位数 | 当前值(1.0745)在该段分位 |
|---|---|---|---|
| 2014-2017 | 938 | 0.8866 | **100.0%** |
| 2018-2022 | 1214 | 1.0273 | **79.4%** |
| 2023-2025 | 727 | 0.9317 | **100.0%** |
| 2026 年内 | 190 | 1.0435 | 86.1% |

**这个表是最有说服力的**：同一个比价，在不同结构阶段的分位从 79.4% 到 100%。
说明"极端"这个标签很大程度上是**样本选择的产物**。

### 2.6 结论的正确写法

**不要写**：

> ❌ "比价处于 97.8% 分位，显著高于历史均值，预计将向 0.95 回归。"

三个错误：
1. 97.8% 没有说明窗口。
2. "历史均值 0.95" 忽略了中枢在 0.83–1.07 之间迁移。
3. "预计回归"是预测，且把极端当成回归理由。

**应该写**：

> ✅ "当前比价 1.0745。近5年分位 97.8%，但分位对样本定义高度敏感
> （分阶段为 79.4%–100%）。结构检验发现 2017-11-30 存在 t=42 的显著断点，
> 中枢从 0.88 抬升至 0.99；252 日滚动均值在 0.81–1.08 间迁移。
> 因此**固定历史分位不能单独作为判断依据**。比价能否回落，取决于
> 丙烯—乙烯相对价差与两侧投产节奏是否反转；本文未对此建立可检验的预测。"

## 三、共变结构：一个容易被忽略的维度

### 为什么重要

比价走扩有两种完全不同的成因：
1. 一边涨一边跌（反向，替代关系切换）
2. 两边同向但速度不同（同向，成本推动）

这两种的产业含义完全不同。**看日度收益相关系数就能区分。**

### 本案例的实测

| 时期 | 日度对数收益相关系数 |
|---|---|
| 2014-2016 | ~0.69 |
| 最近 | **0.93** |

同时 PP 年化波动率从约 20% 上升到 **33%**。

**解读**：
- 相关系数 0.93 说明两者被**同一个宏观/成本因子**驱动（原油、地缘）。
- 在这种状态下，比价的走扩主要来自"成本传导速度差"，而不是"基本面分化"。
- **比价的信息含量下降**——因为它更多反映传导时序，而不是相对强弱。

### 报告里怎么写

> "近1年两者日度对数收益相关系数 0.93（2014-2016 期间约 0.69），
> 说明当前两者高度同步、主要受共同成本因子驱动。因此比价走扩
> **不宜解读为基本面分化**，更可能是成本传导速度差异。这也是
> 判断比价能否回归时必须谨慎的原因之一。"

## 四、完整分析流程的检查清单

- [ ] 用对数恒等式，不用简单百分比
- [ ] 份额和 = 100%（验证）
- [ ] 至少给 6 个区间（近1月/3月/6月/1年/3年/5年）
- [ ] 明确"比价上涨"是分子强还是分母弱
- [ ] 份额 50/50 时说明"两边都在动"，不说"无关"
- [ ] 做了结构断点扫描（Welch t）
- [ ] 给出至少 3 个分阶段分位
- [ ] 给出了 252 日滚动均值轨迹
- [ ] 计算了日度收益相关系数（判断同向/反向）
- [ ] 结论中没有"预计回归""将回到均值"这类表述
- [ ] 明确写出"是否回归取决于什么条件"，但不做预测
