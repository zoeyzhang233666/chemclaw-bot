# 05 · 报告写作模板

本文件给出比价分析报告的固定骨架、措辞规范，以及**必须避免的句式**。

---

## 一、报告骨架（九节固定顺序）

顺序不能换——它对应"先验口径、再看数字、最后判断可信度"的认知顺序。

```
1. 两个品种是什么关系
2. 价格口径是否可比
3. 比价历史曲线与当前所处位置
4. 历史分布：分位不是用最高最低价推算的
5. 两边的价格：比价变化到底来自哪一边
6. 滚动分位：这个位置维持了多久
7. 历史极端阶段与当时的产业背景
8. 比价分布有没有因为产业结构改变而长期移动
9. 结论、限制与红线
```

### 为什么是这个顺序

- **1、2 是前提**：关系和口径不清楚，后面所有数字都不可信。
- **3、4 是"现在在哪"**：曲线 + 分布，让读者建立空间感。
- **5 是"为什么会在这"**：贡献分解，这是整个报告的核心价值。
- **6 是"维持了多久"**：区分一次性冲击和持续性状态。
- **7 是"历史上类似情况发生了什么"**：提供参照，不是预测。
- **8 是"这个参照可靠吗"**：结构检验，用来给自己的结论降级。
- **9 是"所以我到底能说什么"**：明确边界。

## 二、各节的写作规范

### 第 1 节：关系

**必须包含**：

- 关系类型（用一句话说清）
- 产业链位置表（上游/中游/下游重叠区/下游差异化区/期货标的差异）
- **"对比价的含义"**——这个比价能说明什么、不能说明什么

**示例**：

> **关系类型**：替代关系 + 部分共同原料
>
> PP 与 LLDPE 同属聚烯烃，下游部分重叠（包装膜、注塑件），但标准品工艺与牌号不同，
> 替代是局部的。PP 可用 PDH/煤制烯烃独立扩能，LLDPE 高度绑定乙烯裂解。
>
> **对比价的含义**：比价反映丙烯—乙烯相对价差 + 两侧投产节奏错位，
> **没有硬锚**，可以长期停在某个水平，也可以几十个百分点地迁移。
> 不能当作可套利的价差。

**禁止**：

- ❌ "两者高度相关，比价应该稳定在某区间"（未验证的假设）
- ❌ "作为塑料的两个品种，走势必然一致"（同属≠同质）

### 第 2 节：口径

**必须包含**：

- 十项核验表（价格类型/单位/税/运费/品质/时点/合约/交割地/乘数/日历）
- **口径风险**段落，至少 3 条
- 换月处理方式

**示例**：

> **口径风险**：
> ① 两者标准品规格不同——PP 是拉丝级、LLDPE 是薄膜料，比价天然含"牌号价差"，
> 不能当成"同物比价"；
> ② 主力连续序列不含换月复权，换月日会产生跳空（实测最大：L +5.02%、PP +8.71%，
> 均为 2026-08-18），这类跳空在异常点里单独剔除；
> ③ 未混用现货与期货，全部口径统一为期货主力连续收盘价。

**禁止**：

- ❌ 不写任何口径说明就开始给数字
- ❌ "数据已经过清洗"（清洗了什么？）

### 第 3 节：曲线与位置

**必须包含**：

- 历史比价曲线（含 252 日均值线）
- 换月日标记
- 当前值在窗口内的**位置条**（最低 → 当前 → 最高）

**禁止**：

- ❌ 只给一条没有参照线的曲线

### 第 4 节：分布

**必须包含**：

- 直方图（每根柱子是真实样本数，不是平滑后的密度）
- 当前值竖线 + 中位数竖线
- **分位口径对照表**（同一个当前值 → 不同样本 → 不同分位）
- 明确声明"分位是 ECDF，不是 (v−min)/(max−min)"

**示例**：

> 同一个当前值，分位在 **79.4% ~ 100.0%** 之间跳动。
> **这说明"极端"不是比价自身的属性，而是你选哪个样本决定的。**

**禁止**：

- ❌ 只给一个分位数字，不给对照
- ❌ 用线性反推得到的分位

### 第 5 节：贡献分解（核心）

**必须包含**：

- 两边价格在同一张图上（左轴元/吨）
- 贡献分解表：区间 / A 涨跌 / B 涨跌 / 比价变化 / 主导方 / 份额
- **明确说明"比价上涨是分子强还是分母弱"**

**示例**：

> 2024-10-31 → 2026-05-19，PP 从 7450 涨到 8944（**+20.1%**），
> L 从 8150 微跌到 8051（**−1.2%**），比价从 0.9141 升至 1.1109（**+21.5%**）。
> **PP 贡献 94%**——这是单边推动，不是两边共同作用。
>
> 但把区间拉长到 5 年，主导方变成 **L（74%）**：L 跌了 5.3%，PP 还涨了 1.9%。
> 所以"谁在主导"取决于区间选择，必须同时给出。

**禁止**：

- ❌ "比价上涨说明 PP 走强"（也可能是 L 更弱——见 2016-12→2019-10 那段）
- ❌ 只给一个区间就下结论

### 第 6 节：滚动分位

**必须包含**：

- 252 日滚动分位曲线
- 说明"在 90% 以上持续多久"这个维度

### 第 7 节：极端阶段 + 产业事件

**必须包含**：

- 极端阶段表（可点击展开）
- 每阶段的事件台账，**每条带核对级别 A/B/C**
- 明确声明"事件用于解释，不用于证明因果"

**示例**：

> 2026-05-27 · PE · 推高比价 · **A**
> 聚乙烯月评：弱需求与高供应博弈持续，聚乙烯重心下移（PP 端未同步走弱，比价走扩）
> 来源：隆众资讯《聚乙烯月评（2026年5月）》

**禁止**：

- ❌ 编造具体原因而不标核对级别
- ❌ "因为 XX 事件，所以比价上涨"（因果断言）

### 第 8 节：结构漂移

**必须包含**：

- 断点扫描结果（日期 + t 值 + 前后中枢）
- 252 日滚动均值曲线
- 分阶段统计表
- **明确说明"全样本分位是拿不同结构的数据一起排的"**

**示例**：

> 最强的断点在 **2017-11-30**（Welch t = 42.0），断点前中枢 **0.8816**、
> 断点后 **0.9946**，移动幅度约 **+12.8%**。
> 这意味着全样本分位是拿不同产业结构的数据一起排的：
> 在旧中枢时代，现在的比价几乎必然是 100% 分位。
> 因此本文**不把"处于历史高位"直接当成回归理由**。

### 第 9 节：结论与红线

**结论必须包含**：

1. 当前状态（方向、数值、分位、N）
2. **变化来自哪一边**（贡献分解的核心结论）
3. 共变结构（相关系数，判断同向/反向）
4. 分位敏感性（分位区间跨度）
5. 结构断点结论
6. 产业抓手（哪些事件在解释）
7. **明确说"不指向方向"**

**红线清单必须逐条列出**：

```
- 不因为比价处在极端位置就断定必然回归
- 不把相关性/共变说成因果
- 不插值、不回填、不外推缺失数据
- 不混用现货与期货口径
- 不给交易建议、不给目标价、不说做多/做空/做扩/做缩
- 换月日的比价跳空不得并入产业解释
```

## 三、禁用句式清单

以下句式**一律不得出现**。左边是错误写法，右边是正确写法。

| ❌ 禁用 | ✅ 改为 |
|---|---|
| "比价处于历史高位，预计将回归均值" | "比价处于 X% 分位（窗口/N），但分位对样本敏感（区间），结构检验显示中枢曾迁移，是否回落取决于……" |
| "比价明显偏高/偏低" | "比价相对该窗口中位数高 X%，分位 Y%（N=…）" |
| "两个品种高度相关，存在套利机会" | "两者日度收益相关系数 0.93，但比价无硬锚，不构成可套利价差" |
| "因为 PP 产能投放，所以比价下跌" | "同一时期 PP 进入扩能周期（核对级别 C），比价同期下行；不作因果断言" |
| "建议做扩/做缩/做多/做空" | "本文不提供交易方向" |
| "目标价 XXXX" | 删除 |
| "必然""一定会""肯定会" | 删除，或改为"在……条件下" |
| "数据显示趋势将延续" | "本文不对趋势做外推" |
| "均值是 0.96，所以会回到 0.96" | "0.96 是全样本中位数，但分阶段中位数在 0.83–1.07 间移动，不能当作回归目标" |
| "数据已清洗" | "已做以下校验：日期重复/空值/OHLC 矛盾/异常涨跌/零成交，结果见 QC 报告" |

## 四、数字呈现规范

### 小数位

| 类型 | 位数 | 例 |
|---|---|---|
| 比价 | 4 位 | 1.0745 |
| 分位 | 1 位 | 97.8% |
| 涨跌幅 | 1 位 | +21.5% |
| 价格（元/吨） | 0 位 | 9376 |
| 相关系数 | 2 位 | 0.93 |
| t 值 | 1–2 位 | 42.04 |

### 必须带 N

任何统计量后面都要能回答"多少个样本"。写法：

```
近5年分位 97.8%（N=1212）
```

不给 N 的分位是无效陈述。

### 大数字用千分位

```
有效样本 3,069 个交易日
持仓量 451,074
```

### 单位和口径写在数字旁边

```
PP 9376 元/吨（大商所主力连续收盘，2026-10-20）
```
