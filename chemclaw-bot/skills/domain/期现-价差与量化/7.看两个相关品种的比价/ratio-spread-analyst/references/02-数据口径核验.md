## 二、主力连续序列（最常见的坑）

### 它到底是什么

免费行情接口提供的"某某连续""某某主连"，绝大多数是：

```
对每个交易日：取当日持仓量最大的合约 → 用该合约的收盘价
把逐日的收盘价首尾相接 → 得到"连续"序列
```

**关键：不做复权。** 换月时价格不连续。

### 后果

换月当天，比价会出现一次跳空，幅度等于当日新旧合约的价差。
这个跳空**与产业供需无关**，是纯粹的合约切换。

### 本次 PP/L 实测的换月跳空

| 日期 | 品种 | 旧 → 新 | 新旧价差 |
|---|---|---|---|
| 2026-08-18 | L | L2609 → L2701 | **+5.02%** |
| 2026-08-18 | PP | PP2609 → PP2701 | **+8.71%** |
| 2026-04-09 | PP | PP2605 → PP2609 | +6.88% |
| 2026-04-13 | L | L2605 → L2609 | +2.46% |
| 2019-08-08 | PP | PP1909 → PP2001 | +5.18% |
| 2019-04-04 | PP | PP1905 → PP1909 | +3.10% |

**2026-08-18 这天，L 和 PP 同日换月，两个跳空叠加**，导致当天比价变动 −3.71%。
如果不做换月识别，会误判为"PP 相对 L 大幅走弱"。

### 怎么识别换月日

**不要用这个**：找出"连续序列收盘价 == 某合约收盘价"的合约。

问题：远月合约流动性差、报价可能不动，多个合约可能恰好同价。
本次实测这样会得到 **189 个"换月"**，其中 75 个是并列（ambiguous），
大量是假事件（例如 L1909 → L1905 → L1907 → L1909 来回跳）。

**要用这个**：**持仓量最大**的合约。

```python
live = [(name, oi) for each contract listed that day]
pick = max(live, key=lambda x: x[1])   # 持仓量最大
if pick != current:  # 换月
```

持仓量是平滑变化的，不会因为价格巧合而误判。
本次实测得到 **48 个真实换月**（L 25、PP 23），符合 1/5/9 合约的交替节奏。

### 交叉校验

识别完换月后，检查：

- 换月次数是否合理？（1/5/9 主力 → 一年约 3 次，13 年约 39 次，加上早期不规则，50 次左右合理）
- 换月日是否落在到期前 1-3 个月？（太早或太晚都不正常）
- 是否有"来回跳"？（A→B→A 在几天内发生，说明识别有误）

## 三、缺失数据的处理

### 铁律

**不插值、不回填、不外推。**

- 不插值：中间缺一天，就是缺一天，不做线性填充。
- 不回填：不用后一天的值补前一天。
- 不外推：不在两端延伸历史。

### 为什么

比价是逐日相除。如果一边插值、一边不插值，插值那天的比价就是**假数据**，
而且会污染滚动统计（滚动分位、滚动均值、异常检测）。

### 正确做法

```python
common_dates = sorted(set(dates_A) & set(dates_B))
# 只用交集；缺失的日子整体剔除
```

在报告里写清楚：

> "按日期交集逐日对齐，N = 3069。A 独有 2 天、B 独有 1605 天（B 上市更早），
> 独有日期整体剔除，不做填补。"

### 本案例的实际情况

| 项目 | PP (A) | L (B) |
|---|---|---|
| 覆盖区间 | 2014-02-28 → 2026-10-20 | 2007-07-31 → 2026-10-20 |
| 行数 | 3071 | 4674 |
| 日期重复 | 0 | 0 |
| 收盘空值 | 0 | 0 |
| OHLC 矛盾 | 1（2020-08-06） | 0 |
| 单日涨跌 >15% | 0 | 1（2008-12-15） |
| 零成交日 | 3 | 4 |

共同样本：**3069 天**，2014-02-28 → 2026-10-20。

L 比 PP 早上市约 6.5 年，所以 B 独有 1605 天很正常——这些日子 PP 还没上市，
无法构成比价，只能剔除。**这是正确做法，不是数据缺陷。**

## 四、数据质量闸门

`prep_data.py` 会跑以下检查，**任何 ERROR 都必须为 0 才能继续**：

| 检查 | 级别 | 说明 |
|---|---|---|
| 序列为空 | ERROR | 直接终止 |
| 日期重复 | ERROR | 会导致重复计算 |
| 收盘空值 | ERROR | 无法计算比价 |
| 收盘非正 | ERROR | 除法失效 |
| OHLC 内部矛盾 | WARN | 记录并披露，不终止 |
| 单日涨跌 >15% | WARN | 记录并披露 |
| 零成交日 | WARN | 记录并披露 |
| 连续序列找不到对应合约 | WARN | 早期历史常见 |

本次结果：**gate PASS，errors = 0**。

## 五、已知的口径局限（必须写进报告）

### 1. 标准品规格不同

| 品种 | 期货标准品 | 说明 |
|---|---|---|
| PP | 均聚拉丝级 | 拉丝用途牌号，熔指有具体要求 |
| LLDPE | 薄膜料（7042 类） | 膜级牌号 |

**比价里天然含"牌号价差"**。这不是同物比价，所以**不能**说"PP 比 L 贵 7.45% 就是不合理"。
两者是不同的商品，只是共享部分下游。

### 2. 主连不复权

见上文第二节。换月跳空必须单独标注。

### 3. 数据末端的混合报价

本次发现：2026-10-20 的 `L0` 值 8726 **不等于** `L2611` 的 9399，
且其持仓量（451,074）高于任何单一挂牌合约，成交量（618,080）也远高于 L2610（5,552）和 L2611（73,474）。

这说明**连续序列在临近换月时，可能来自多合约的混合报价路径**。

**处理**：
- 比价**水平**不受影响（约 1.07）。
- 但不宜用末端单日做精细判断（如"昨天到今天是涨是跌"）。
- 必须在报告里披露这个现象。

### 4. 期货价 vs 现货价

期货价含交割地/仓库升贴水预期，与华东现货主流价有基差。
**本次分析统一用期货主力连续收盘价，未混用现货。**

如果确实需要现货：
- 必须两边都用现货，或两边都用期货。
- 不能"一边现货历史长就用现货，另一边只有期货就用期货"。

### 5. 早期历史无逐条产业数据

2014-2016 年的产业细节很难逐日核对。这类事件在台账里标为**核对级别 C**，
并在报告中明确"未逐条核实，不单独支撑结论"。

## 六、数据来源记录模板

每个交付物都要能回答"这个数字从哪来"。模板：

```
接口地址：https://...（完整 URL）
请求方式：GET，需 Referer: ...
返回格式：JSONP，字段 [d,o,h,l,c,v,p]
字段含义：d=日期 o=开 h=高 l=低 c=收 v=成交量 p=持仓量
覆盖区间：2014-02-28 → 2026-10-20
行数：3071
已知问题：XX 日 OHLC 矛盾；末端为混合报价
获取时间：2026-10-XX
```
