chain-divergence-scan ｜ 工作区说明
============================================================

这个目录是"扫描产业链异常背离"的工作区约定。所有中间产物、交付物、
以及需要人工确认的内容都放在这里，不要混进 scripts/ 或 data/。


一、目录用途
------------------------------------------------------------
data/            价格数据（每个品种一个 CSV）。
                 格式：date,open,high,low,close,volume,open_interest,settle
                 内置 15 个品种，截至 2026-10-20，单位元/吨，主力连续。

out/             扫描产物（脚本会自己创建）。
                 scan_pack.json          完整统计（压缩版，供 HTML 使用）
                 scan_pack_pretty.json   同内容，带缩进，便于人工核对
                 hist_scan.json          历史回看的逐次结果
                 hist_scan_summary.json  每个组合的假阳性率汇总
                 series/{A}_{B}.csv      逐日价格、对数价差、滚动 z
                 series/{A}_{B}_ret.csv  逐日对数收益、滚动相关
                 series_web/web_series.json 按月抽样 + 最近 120 日（HTML 用）

工作区/          本说明 + 需要人工确认的事项（见第三节）。

examples/        完整跑通的案例，含最终交付物，可作对照。


二、一次完整作业的顺序
------------------------------------------------------------
1) 数据到位
   python scripts/fetch_futures.py --symbols PP0 L0 PX0 TA0 --out data
   并打印各品种的起止日期与交易日数，确认没有断档。

2) 关系登记（人工，最重要）
   编辑 scripts/chain_graph.py 的 UNIVERSE 与 RELATIONS，
   编辑 scripts/sources.py 补来源。每条关系十二个字段都要填。

3) 参数定死
   默认：window=60, z=2.0, persist=5, drop=0.45, perm=1200。
   一旦开始看结果，就不许再改。改了要重新写报告说明原因。

4) 扫描 + 历史回看
   python scripts/run_scan.py --data data --out out --perm 1200
   python scripts/run_hist.py --data data --out out --months 12

5) 过伪异常检查清单（references/03 的 12 项）
   逐条打勾，过不了的降级。

6) 基本面复核（五问，双方都要）
   查不到连续序列就写"未取得"，不许估算。

7) 出交付物 + 自检
   python scripts/build_excel.py --pack out/scan_pack.json --hist out/hist_scan.json --out 交付/x.xlsx
   python scripts/build_html.py --pack out/scan_pack.json --web out/series_web/web_series.json --hist out/hist_scan.json --out 交付/x.html
   python scripts/selftest.py
   python scripts/probe_html.py 交付/x.html


三、必须人工确认的事项（脚本无法代劳）
------------------------------------------------------------
[ ] 产业关系是否成立：A/B 角色、传导机制、系数 k 是否经得起追问？
[ ] 每条关系的来源是否可点击、有日期？二手转述要标注"低可靠性"。
[ ] 关系强度定级是否合理？weak 的不许进主榜单。
[ ] 换月剔除规则是否误伤？特别是长假后首日——要检查成交量比是否被正确识别。
[ ] 有没有未查明的大跳空？（本次 BU0 在 2026-10-14 就有一条，尚未定性）
[ ] 基本面事件是否真实可核验？有没有把媒体口径当成机构数据？
[ ] 当期是否存在全池级别的共同冲击？若有，需在报告里说明"相关性上升"是正常的。
[ ] 报告摘要是否敢写"没有找到异常"？
[ ] 是否逐条检查了红线词表（references/05 第 3 节）？

五、与相邻 Skill 的分工
------------------------------------------------------------
-> chem-market-brief          看单个品种的行情与价格位置
-> two-indicator-correlation  算任意两个指标（含库存）的相关性
-> 本 skill                   只在"有产业关系的品种对"之间，判"是不是异常背离"

本 skill 不输出交易建议。
