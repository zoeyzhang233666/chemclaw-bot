## 1. 价格数据（本工具的主输入）

### 1.1 免费可复算源（推荐默认）

| 来源 | 接口 | 覆盖 | 字段 | 可靠性 |
|---|---|---|---|---|
| **新浪财经期货** | `https://stock2.finance.sina.com.cn/futures/api/jsonp.php/var%20_{SYM}=/InnerFuturesNewService.getDailyKLine?symbol={SYM}` | 国内主要商品期货**主力连续**日线，最早可到 2005 年 | d/o/h/l/c/v/p/s = 日期/开/高/低/收/量/持仓/结算 | 高（公开接口，长期稳定） |

**抓取示例**：

```bash
python scripts/fetch_futures.py --symbols PP0 L0 PX0 TA0 MA0 EG0 --out data
```

代码约定：`{品种代码}0` 表示主力连续（如 `PP0`、`TA0`、`PX0`）。

### 1.2 主力连续的三个已知问题（必读）

| 问题 | 表现 | 处理 |
|---|---|---|
| **换月跳空** | 换月日价格从近月跳到远月，产生与市场无关的涨跌 | 规则识别并剔除该日收益（见 `references/02` 第 1.2 节） |
| **跨月收益被平滑** | 主力连续丢失了真实的跨月价差变化 | **无法完全修复**，只能声明局限；精确处理需逐合约拼接 |
| **流动性与不同步** | 换月前后成交量、持仓量剧变，与配对品种的日内节奏不同步 | 报告里注明；必要时改用指数合约或近月合约 |

### 1.3 与现货口径的差异

| 项目 | 期货主力连续 | 现货报价 |
|---|---|---|
| 价格水平 | 常显著贴水或升水于现货 | 实际成交/报盘价 |
| 税基 | 含税 | 含税/不含税需区分 |
| 区域 | 交割地/基准地 | 华东、华南、山东等分区域 |
| 时点 | 收盘价 | 上午/下午报盘 |

**结论**：用期货算出来的"加工费"与行业现货加工费**不是一个数**，
只能回答"相对自身历史偏不偏"，不能与行业绝对值直接比较。

### 1.4 付费/机构源（用于现货与基本面）

| 来源 | 典型内容 | 用途 |
|---|---|---|
| 卓创资讯 | PE/PP 产量、开工率、检修损失 | 判断供应端 |
| 隆众资讯 | 甲醇/乙二醇港口库存、PP 商业库存 | 判断库存与流动性 |
| 百川盈孚 | 各品种日度报价 | 现货价格 |
| CCFGroup | PX/PTA/聚酯产业链周报 | 加工费、开工 |
| 钢联（Mysteel） | 黑色产业链库存、焦化利润 | 黑色品种 |

> 这些源多为付费，**本工具不内置、不猜测、不替代**。若用户能提供导出文件，直接放入 `data/` 并按
> CSV 格式（`date,close`）读取即可。

## 4. 可比性评级规则

对每一组配对，`scripts/run_scan.py` 的 `assess_quality()` 给出 A/B/C 评级：

| 维度 | 加分条件 |
|---|---|
| 样本量 | 重叠 >= 1500 日 +2；>= 700 日 +1；否则 0 |
| 关系稳定 | 滚动相关中位数 >= 0.7 +2；>= 0.4 +1；否则 0 |
| 跨期稳定 | 三段滚动相关均值极差 <= 0.30 +1；否则 0（并记录极差） |
| 关系类型 | `cross_chain_cost` 扣 1 分 |

评级：>=4 分 → **A**；2–3 分 → **B**；<2 分 → **C**。

**用途**：C 级组合**不得**用于下"异常背离"结论，应先补齐数据或放弃该组合。

## 5. 明确不可比 / 需特别声明的情形（报告中必须出现）

1. **PX 任意组合**：PX 历史仅 745 个交易日（3.1 年），历史分位只覆盖单一制度。
2. **跨交易所组合**：如 PX（郑商所）与 PP（大商所），交易时段一致但交割/结算细节不同。
3. **期货 vs 现货加工费**：所有"加工费"类指标均为期货口径近似值。
4. **含 k 系数组合**：k 为行业近似值且随工艺迭代变化（PX-TA 从 0.665 到 0.648），
   用固定 k 会引入系统性偏差。
5. **成本共振型组合**：`cross_chain_cost` 没有产业锚，价差偏离无法解释，一律降级处理。
6. **存在数据疑点的品种**：BU0 在 2026-10-14 的跳空需核实后才可用。

## 6. 数据落地格式

`data/*.csv`：

```csv
date,open,high,low,close,volume,open_interest,settle
2026-10-20,9350,9400,9300,9376,123456,234567,9360
```

- 编码：UTF-8（带或不带 BOM 均可，读取时用 `utf-8-sig`）。
- 日期：`YYYY-MM-DD`，升序。
- `close` 为必填；其余字段缺失不影响本工具（换月检测会退化到只用日历规则）。
- 单文件一个品种，文件名 = 品种代码，如 `PP0.csv`。

## 7. 抓取与复算

```bash
# 抓取（会生成 data/{CODE}.csv）
python scripts/fetch_futures.py --symbols PP0 L0 PX0 TA0 --out data

# 全量扫描
python scripts/run_scan.py --data data --out out --perm 1200
```

**数据一致性校验**：交付 Excel 的「08 价格价差明细」底部有"交叉校验"区，
把 Excel 原生公式算出的最新比价、对数价差、全期相关与 Python 内核值并列，
两者差异应小于 1e-6（若不等，说明数据被改动过）。
