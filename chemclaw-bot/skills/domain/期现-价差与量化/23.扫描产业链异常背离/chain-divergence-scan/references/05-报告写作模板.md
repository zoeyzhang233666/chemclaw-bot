# 05 报告写作模板

> 扫描结果的报告有固定骨架。**照这个结构写，不要按"哪个组合分最高"来组织。**
> 核心原则：先讲关系、再讲数据、再讲统计、最后讲解释；结论段只说"是不是异常"，不说该怎么做。

---

## 1. 报告骨架（八段）

```
摘要（结论先行，含"没有异常"这种结论）
一、品种池与产业关系（为什么是这几对）
二、数据与可比性（单位/口径/重叠期/换月处理/已知局限）
三、统计方法与阈值（四门槛 + 参数固定声明 + 多重检验）
四、扫描结果总表（全部组合，含"偏离但未达门槛"）
五、重点组合个案（用户点名的那几对，逐个展开）
六、稳健性与历史回看（假阳性率）
七、不适用/数据不足的组合（明确排除清单）
八、观察项与合规声明（不是交易建议）
```

---

## 2. 逐段写作要求

### 摘要

必须是**一句话结论 + 一张小表**，且要敢于写"没有找到"。

好（正确）：

> 本次在 15 个化工品种、16 组产业关系中扫描，**未发现同时满足四门槛的异常背离**。
> PP-LLDPE 与 PX-PTA 均处于历史正常区间（z 分别为 -1.42 与 -0.36，连续超阈值 0 日）。
> 唯一"候选"BU/FU 因关系强度弱（weak）、关系不稳定（三段均值 0.11~0.63）、存在数据疑点而被排除。

差（把统计极值当发现）：

> 扫描发现沥青-燃料油组合价差严重偏离（z=3.21），提示存在套利机会。

差（回避结论）：

> 各组合差异较大，具体情况需结合基本面进一步分析。

### 一、品种池与产业关系

必须回答：**为什么是这几对，而不是 105 对？**
给出 C(15,2)=105 与 16 的对比，说明砍掉的那些凭什么砍掉。

> 若直接对 15 个品种做全遍历，|z|>=2 下预期约有 4.8 组纯属巧合的"显著偏离"。
> 因此先用产业关系把组合压到 16 组，每组必须能说清 A/B 角色、传导机制、系数与来源。

### 二、数据与可比性

必须列：单位、口径（期货主力连续，非现货）、对齐规则（交集，不插补）、
换月处理规则、各品种样本起点差异表、以及**哪些组合按可比性应降级**。

### 三、统计方法与阈值

必须写：四门槛定义、参数取值、**"参数在扫描前固定"的声明**、
多重检验方法（且说明 m 怎么数）、以及**门槛 3 只是门控、不是异常证据**。

### 四、扫描结果总表

必须包含**全部**组合，包括"偏离但未达门槛"和"数据不足"。
不允许只列出前几名。表格列建议：

| 组合 | 关系类型 | 强度 | z | z 分位 | 持续 | 滚动相关 | 相关变化 | 全期 r | 判定 | 可比性 |

### 五、重点组合个案

每一对按固定六小节写：

1. **产业关系**（表格：类型/强度/A 角色/B 角色/机制/系数/来源）
2. **统计结果**（表格：样本、r_level、r_daily+CI、置换 p、滚动相关+分位、corr_drop、
   价差与 z、标准化变化）
3. **四门槛核查**（逐条 通过/未通过）
4. **为什么不构成异常**（这是最重要的一节，要主动避免三种误读）
5. **基本面与事件**（表格：日期/事实/来源，**只写可公开核验的事实**）
6. **数据可比性提示**

### 六、稳健性与历史回看

必须包含历史回看表（每组的假阳性率）。并解释：

> PP-L 在 15 次回看中有 4 次被判异常（27%），说明它的价差经常"看起来异常"，
> 单次报警的信息量有限。PX-TA 15 次全不报警，与其强物料关系一致。

### 七、不适用/数据不足

必须明确列出"哪些组合本来就不该硬扫"，否则读者会误以为"没扫出异常 = 这些组合没问题"。

### 八、观察项与合规声明

观察项只能写**触发条件**，不能写方向、仓位、时机。

好：

> 若比价 z 跌破 -2.0 且连续 5 个交易日，才进入"关注"；
> 再叠加滚动相关从 0.95 跌到 0.50 以下，才可能构成异常背离。

差：

> 建议买 L 卖 PP，目标价差回归 0 轴。

## 3. 禁止出现的表述（红线词表）

| 禁止 | 改为 |
|---|---|
| "存在套利机会" / "无风险套利" | "价差处于统计偏离区间，但未达门槛" |
| "建议做多/做空/买入/卖出" | 只写触发条件，不写方向 |
| "目标价" / "止盈止损" | 不出现 |
| "低估" / "高估" | "低于/高于自身历史分位" |
| "必然回归" / "一定会收敛" | "历史上多数情形下回归，但本期未出现" |
| "A 导致 B" | "A 与 B 同向变动" |
| "相关性 0.95，说明是同一条链" | 分开报 r_level / r_daily / r_roll 三个数 |
| "数据缺失，已按趋势估算" | "数据未取得，标未取得，不估算" |

---

## 4. 必须出现的六个免责/限定句

复制进报告，逐条保留：

1. 本报告全部价格为**期货主力连续收盘价**，不等于现货成交价。
2. 主力连续在换月时拼接不同月份合约，跨月价差被记入价格变化；本工具用规则识别并剔除，
   但**无法完整还原每一次换月**。
3. 库存、开工、供需的**连续数值未取得**（多为付费数据库口径），本文只记录公开可检索的时点事实，
   **未取得即标未取得，不估算、不填补**。
4. 事件库用于解释统计差异，**不代表因果**；价格由多因素共同决定。
5. 历史偏离**不等于**未来回归；统计相关**不等于**因果。
6. 本报告为研究记录，**不构成投资建议、套利建议或交易指令**。

## 5. 一份可直接套用的结论段模板

> 以「[关系类型]」口径，[A] 与 [B] 在 [起] 至 [止] 共有 [N] 个可比交易日（有效收益样本 [n]）。
> 价格水平相关 [r_level]，**日收益相关 [r_daily]（95% CI [lo]~[hi]，N_eff=[neff]，置换检验 p=[p_perm]）**。
> 最近 [W] 日滚动相关 [r_roll]（历史分位 [pct]%），相关性变化 [corr_drop]（阈值 [drop]）。
> 当前对数价差 z = [z]（历史分位 [zpct]%），已连续 [run] 个交易日超阈值（要求 >= [persist]）。
>
> 四门槛核查：偏离幅度 [通过/未通过]；持续性 [通过/未通过]；相关显著性 [通过/未通过]（仅门控）；
> 相关性脱钩 [通过/未通过]。**判定：[判定]**。
>
> 基本面：[列出该窗口内的公开事件与来源]。
> 数据可比性：[A 级 / 需注明 PX 历史仅 745 日 / 期货口径不等于现货加工费 等]。
>
> 以上为统计描述与产业逻辑说明，不含方向判断，不构成交易建议。

## 6. 交付物检查清单（发出去之前过一遍）

- [ ] 摘要里有没有明确的"是/不是异常"结论？
- [ ] 是否列出了**全部**组合（含未达门槛的）？
- [ ] 每对重点组合是否都有"为什么不构成异常"这一节？
- [ ] 所有数字是否都能追溯到 数据源 + 口径 + 时间段 + N？
- [ ] 历史回看表是否包含？
- [ ] 是否明确了"哪些组合数据不足/关系不稳"？
- [ ] 是否出现了红线词表里的任何表述？
- [ ] 免责/限定六句是否齐全？
- [ ] Excel 与 HTML 的数字是否一致（交叉校验区）？
- [ ] 参数是否与"扫描前固定"的声明一致（没有被事后调整）？
