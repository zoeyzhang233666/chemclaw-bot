# 01 产业关系类型与配对规则

> 这一步决定了"哪些组合有资格进入统计扫描"。跳过这一步，统计扫描就会退化为数据挖掘。
> 本文件是 `scripts/chain_graph.py` 中 `RELATIONS` / `PAIR_RULES` 的说明书。

---

## 1. 为什么必须先建关系，再做统计

对 N 个品种做两两组合，会产生 C(N,2) 组：

| N | 组合数 | \|z\|≥2 下的期望"显著"数（若两两独立） |
|---|---|---|
| 10 | 45 | ≈ 2.1 |
| 15 | 105 | ≈ 4.8 |
| 20 | 190 | ≈ 8.7 |

真实市场里品种之间高度正相关，"独立性假设"不成立，但结论不变：**组合数一多，极端值必然出现，
且这些极端值里绝大多数没有产业含义**。再叠加"换窗口、换阈值、换样本起点"的自由度，
几乎可以扫描出任意想要的故事。

因此工作流的第一步是**用产业知识把组合数压下来**，并对每一组留下可审计的关系记录。

## 2. 四类产业关系

### 2.1 上下游（`upstream_downstream`）

**定义**：B 由 A 直接加工而成，存在明确的物料流；通常可以写成"吨耗系数"形式。

**判定要求（缺一不可）**：

1. 能写出反应式或工艺路径（不是"都属于化工"这种泛泛关联）；
2. 有**吨耗系数**或可折算的物料比例；
3. 有**行业公认的价差名称**（加工费、裂解利润、焦化利润等）。

**示例**：

| 组合 | 系数 k | 行业价差名称 | 来源 |
|---|---|---|---|
| PX → PTA | 0.655（早期 0.665，技术迭代后 0.648） | PTA 加工费 | S5 S6 S7 |
| 焦煤 → 焦炭 | 1.33 | 焦化利润 = J − 1.33×JM − 160 | S12 S13 S15 |
| 焦炭 → 螺纹 | 0.5 | 吨钢成本 | S13 |
| 甲醇 → PP（MTO 路径） | 约 3（吨烯烃耗甲醇） | MTO 利润 | S3 S10 |

**注意**：甲醇→PP 只能是 **medium**，因为 PP 的丙烯来源有四条（石脑油裂解、催化裂化、PDH、MTO），
MTO 只占一部分产能，甲醇价格不是 PP 的决定性成本。

### 2.2 共用原料（`common_feedstock`）

**定义**：A 与 B 不是上下游关系，但共用同一上游原料或同一条成本曲线，
因此"原料成本冲击"会同时作用于两者。

**判定要求**：

1. 明确共用的是什么（同一种原料、同一条裂解链、同一个能源成本）；
2. 说明为什么这个共用点对两者都重要（成本占比、装置耦合）；
3. **承认它不是直接物料关系**——价差没有唯一锚点，只能看比价。

**示例**：

| 组合 | 共用点 | 强度 |
|---|---|---|
| PTA / 乙二醇 | 同为聚酯（PET）原料，共用 PX/乙烯链成本与聚酯需求 | strong |
| 纯碱 / 尿素 | 同属合成氨/煤化工下游；氯化铵（联碱副产）可替代尿素 | medium |
| 甲醇 / 尿素 | 煤化工成本共振为主，无直接物料流 | weak |

### 2.3 替代（`substitute`）

**定义**：A 与 B 在终端应用中可部分互相替代，需求端存在替代弹性。

**判定要求**：

1. 说明**在哪里替代**（具体下游制品，而不是"都是化工品"）；
2. 说明替代的**方向性与弹性大小**（是否能真替代、替代比例多少）；
3. 认识到替代关系的**稳定性天然弱于上下游**——只有价格差足够大时替代才会发生，
   因此两者的相关性在大部分时间是"共同宏观/成本驱动"，而不是"替代驱动"。

**示例**：

| 组合 | 替代场景 | 强度 | 备注 |
|---|---|---|---|
| PP / LLDPE | 包装膜、注塑件、编织制品 | medium | 同时共用烯烃原料，是最常被研究的聚烯烃配对 |
| PP / PVC、L / PVC | 管材、型材、板材 | medium / weak | PVC 需求与地产强绑定，替代弹性小 |
| 沥青 / 燃料油 | 同属重质油下游 | weak | 终端（道路 vs 船燃）与定价机制差异大，**关系不稳定** |

### 2.4 同装置切换（`same_process_output`）

**定义**：A 与 B 由同一套装置生产（联产品/副产物），厂家可在两者之间调节产出比例。

**判定要求**：给出装置名称与切换机制。本次品种池中没有典型实例，故未登记。

### 2.5 跨链成本共振（`cross_chain_cost`）

**定义**：A 与 B 之间没有物料流、没有替代、也不共用主要原料，只是都受同一种上游能源
（煤、原油、天然气）影响。

**处理原则**：**一律登记为 weak，只作背景，不参与主榜单结论。**
因为它本质上就是"宏观/能源共振"，没有产业锚，任何价差偏离都无法解释。

## 3. 强度分级

| 强度 | 含义 | 是否进主榜单 |
|---|---|---|
| `strong` | 直接物料流（上下游）或同一装置；系数明确 | ✅ 进 |
| `medium` | 共用原料 / 部分替代 / 二级成本传导易 | ✅ 进（结论需注明强度） |
| `weak` | 仅成本共振、或替代弹性极小的替代 | ❌ 只作背景 |

**规则**：`PAIR_RULES['min_strength_for_primary'] = ('strong','medium')`。

---

## 4. 最小重叠期

`PAIR_RULES['min_overlap_days'] = 250`（约 1 年）。

不足 250 个可比交易日的组合直接标 **"数据不足"**，不做任何统计推断。
本次唯一相关的情况：PX0 上市于 2023-09-15，与任何品种的重叠期都只有约 745 个交易日，
满足最小值但**历史分位统计功效受限**，必须在报告中注明。

---

## 5. 禁止事项（红线）

1. ❌ **禁止对无产业关联的品种做 C(n,2) 全遍历**。
2. ❌ 禁止为了"凑出异常"而调窗口、调阈值、调样本起点。参数必须在扫描前固定并记录。
3. ❌ 禁止把 weak 关系的统计极值写进主结论（可以写进"排除说明"）。
4. ❌ 禁止在关系登记表里写"关联度高"这种无法审计的描述；必须写清角色、机制、系数、来源。

## 6. 新增一组关系时的检查清单

新增前逐条回答，答不上就不要加：

- [ ] A 与 B 分别是什么角色？（原料 / 成品 / 替代品 / 联产品）
- [ ] 传导机制一句话能说清吗？
- [ ] 有没有吨耗系数或行业价差名称？没有的话凭什么认为它们有关系？
- [ ] 这条关系在历史上稳定吗？有没有出现过制度切换（政策、工艺路线变化、产能西移）？
- [ ] 来源是什么？券商研报 / 行业协会 / 交易所 / 产业媒体，**有没有 URL 和日期**？
- [ ] 强度应该定 strong / medium / weak 中哪一档？为什么不是更高或更低？

登记格式（`chain_graph.py` 中 `RELATIONS` 的一项）：

```python
dict(
    a='PX0', b='TA0', rtype='upstream_downstream', strength='strong',
    direction='upstream_to_downstream',
    a_role='对二甲苯，PTA 的唯一主流原料',
    b_role='精对苯二甲酸，PX 经氧化加氢制得',
    mechanism='吨 PTA 约耗 0.655 吨 PX，价差即 PTA 加工费',
    k=0.655, coef_kind='吨耗系数',
    market_convention='PTA 加工费 = PTA 价格 − 0.655 × PX 价格',
    source_ids=['S5', 'S6', 'S7'],
    comparability='均为期货主力连续价；与现货加工费口径不同，需注明',
)
```
