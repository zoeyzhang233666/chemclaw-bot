# 02 统计指标与阈值

> 本文件定义 `scripts/stats_core.py` 里每一个量的公式、含义、易错点。
> 全部指标都可以手算复核，没有黑箱。

---

## 1. 价格对齐

### 1.1 可比重叠日

```
D = {d : d ∈ TradingDays(A) ∩ TradingDays(B)}
```

**规则**：

- 只取交集，**不插补、不回填、不外推**。
- 缺失日造成样本减少必须记录在"重叠交易日 / 有效收益样本"两列里。
- 两品种交易日历差异（如某些品种夜盘/日盘差异）会造成同日不同流动性，需在报告中提示。

### 1.2 主力换月与数据断档的剔除

数据源是**主力连续**，换月时会拼接不同月份合约，产生与市场无关的价格跳空。
由于接口不含逐日主力合约代码，用两条规则代理识别：

```
规则 1（日历断档）：d_i − d_{i−1} ≥ 9 个自然日
规则 2（缩量跳空）：|ln(P_i/P_{i−1})| > 5%
                    且 |ln(P_{i−1}/P_{i−2})| < 2%
                    且 |ln(P_{i+1}/P_i)| < 2%
                    且 |OI_i − OI_{i−1}| / OI_{i−1} > 10%
                    且 Vol_i / mean(Vol_{i−20..i−1}) < 1.2
```

**标记日的对数收益不参与相关与价差计算**（不插补成 0，直接剔除）。
标记日仍保留在价差序列里（因为价差水平本身仍然有效，只是它的"变化"不可信）。

**为什么要加成交量条件**：长假后首个交易日天然满足"跳空 + 前后日平静 + 持仓跳变"，
但那是假期信息集中定价，**不是换月**。用成交量比 ≥ 1.2 倍把它们区分出来（放量 → 视为真实定价）。

**已知局限**：无法完整还原每一次换月；主力连续在换月月的跨月收益已被平滑。
若需要精确处理，应改用逐月合约拼接（需下载每个合约的日线）。

## 2. 相关性

### 2.1 价格水平相关（背景口径）

```
r_level = Pearson(P_A, P_B)     # P 为原始价格
ρ_s     = Spearman(P_A, P_B)    # 秩相关，抗异常值
```

**含义**：反映长期共同趋势。
**易错点**：两品种一起涨十年，r_level 会接近 1，这**不代表**联动强。
因此 r_level 只作背景，不能作为"关系强度"的证据。

### 2.2 日收益率相关（主口径）

```
r_i = ln(P_i / P_{i−1})
r_daily = Pearson(r_A, r_B)
```

**含义**：剔除趋势后的"信息同步"程度。这是判定关系强弱的主口径。

### 2.3 置信区间（Fisher z 变换）

```
z     = atanh(r)
se    = 1 / √(n − 3)
CI_95 = [tanh(z − 1.96·se), tanh(z + 1.96·se)]
```

### 2.4 显著性（t 分布，双侧）

```
t  = |r| · √((n−2)/(1−r²))
df = n − 2
p  = 2 · (1 − CDF_t(|t|, df))
```

t 分布的 CDF 用**正则化不完全 Beta 函数**（连分式展开）计算，不依赖 scipy。
已知答案校核：`t=2.228, df=10 → p = 0.05001`；`r=0.1946, n=100 → p = 0.0524`。

### 2.5 有效样本量 N_eff（自相关修正）

```
N_eff = n · (1 − ρx·ρy) / (1 + ρx·ρy)
```

其中 ρx、ρy 分别是两条收益序列的一阶自相关。当 ρx=ρy=0 时 N_eff = n；
当 ρx=ρy=0.5 时 N_eff = 0.6n。

用 N_eff 代替 n 重算 p，得到 `p_eff`。**当 |ρ| 较大时必须以 p_eff 为准**。

### 2.6 置换检验（循环平移）

把 B 的收益序列**循环平移** k 个位置（k 随机），重算相关，重复 n_perm 次得到零分布。
循环平移保留了 B 自身的自相关结构，只破坏与 A 的对齐关系。

```
p_perm = (#{ |r_null| ≥ |r_obs| } + 1) / (n_perm + 1)
```

**用途**：识别"共同趋势造成的伪相关"与"真实同步"。默认 n_perm = 1200，seed 固定以保证可复现。

### 2.7 滚动相关

```
r_roll,t = Pearson(r_A[t−W+1..t], r_B[t−W+1..t])      W = 60（默认）
```

**相关性变化**（"脱钩"指标）：

```
corr_drop = |r_daily| − r_roll,latest
```

只有当 `corr_drop ≥ 0.45` 才算"联动明显减弱"。
注意：**若 r_daily 本身就低，corr_drop 的意义有限**，需同时看 r_roll 的绝对水平。

## 3. 标准化价格变化（跨品种可比的"σ"单位）

```
Z_n = Σ_{i=t−n+1}^{t} ln(1 + r_i) / (σ_daily · √n)
```

其中 σ_daily 为**全样本日波动率**（对数收益标准差）。

**含义**：把"涨了多少"换算成"涨了几个自身波动率"，使 9000 元/吨的 PX 和 3000 元/吨 的甲醇可以直接比较。

**易错点**：σ_daily 用全样本估计，会随时间漂移；若近期波动率显著高于历史，Z 会被低估。

本次报告使用 5 / 20 / 60 日三个窗口。

---

## 4. 价差 / 比价（对数空间）

### 4.1 有物料系数的关系

```
s_t = ln(P_B,t) − ln(k · P_A,t)
```

其中 k 为吨耗系数。等价于 `s_t = ln(P_B,t / (k·P_A,t))`。

**为什么不直接相减**：价格水平不同量纲、不同波动率，直接相减的方差会随价格水平漂移；
取对数后价差可加、与价格水平无关，且 s 的指数形式恰好是"加工费/原料成本的比值"。

**示例（PX-TA，k=0.655）**：`s = ln(PTA) − ln(0.655 × PX)`。

### 4.2 无系数的关系（只做比价）

```
s_t = ln(P_B,t) − ln(P_A,t) = ln(P_B/P_A)
```

同时报告原始比价 `ratio = P_B / P_A`（更直观，适合放在报告表格里）。

### 4.3 口径提醒（必须写进报告）

- `s` 是**对数**价差，不是元/吨。若要给元/吨的名义价差，需另算 `P_B − k·P_A`。
- 期货主力连续价按系数算出来的"加工费"**不等于行业现货加工费**。
  后者通常用现货价并扣减辅料，口径不同，不能直接比较。
- 本工具算出的 z 只回答 **"相对自身历史分布偏不偏"**，不回答"绝对水平贵不贵"。

## 5. 滚动 z（无前视）

```
mean_t = mean(s[t−W..t−1])
sd_t   = sd(s[t−W..t−1])          # 样本标准差，ddof=1
z_t    = (s_t − mean_t) / sd_t
```

**关键**：t 时刻的 z **只用 t−1 及之前的历史**，绝不含 s_t 自身。
这样在时间序列上不会产生"自我稀释"（含自身的窗口会让极端值被拉回），也是唯一可用于历史回看的写法。

**样本不足时返回 None**：窗口内有效观测 < min_obs（默认 max(20, W/3)）时不给 z。

### 持续性

```
z_run_days = 从序列末尾倒数、连续满足 |z| ≥ 阈值 的天数
```

单日跳空/数据问题会产生 |z| = 5 的一天，但 `z_run_days = 1`。
持续性门槛（默认 ≥5 日）正是为了过滤这种情形。

### 历史分位

```
z_pct = percentile_of(z_t, 历史全部 z 值)   # 单位 %
```

注意分位与 |z| 的区别：`z = −1.42` 与 `z = +1.42` 的 |z| 相同但分位可能不同（分布偏斜）。

## 6. 四门槛与综合评分

### 6.1 门槛（必须**同时**满足）

| # | 门槛 | 默认阈值 | 代码字段 |
|---|---|---|---|
| 1 | 价差/比价偏离幅度 | \|z\| ≥ 2.0 | `z_threshold` |
| 2 | 偏离持续性 | 连续 ≥ 5 个交易日 | `persist_days` |
| 3 | 全期相关显著性（**仅门控**） | Bonferroni：p_raw × m < 0.05 | — |
| 4 | 最近相关性脱钩 | corr_drop ≥ 0.45 | `drop_threshold` |

**门槛 3 的正确理解**：它确认"A 与 B 确实有稳定关系"，**不是**"证明异常"。
强产业关系的日收益相关往往高度显著（p 极小），所以这一条几乎总会通过——
报告里必须讲清楚，否则读者会把"相关显著"误读成"发现异常"。

### 6.2 综合评分（只用于排序，不用于判定）

```
score = 偏离程度(0–40) + 相关性变化(0–30) + 持续性(0–30)     # 0–100
```

- 偏离程度：`min(40, |z| / z_threshold × 20)`，|z| 达到阈值时得 20 分。
- 相关性变化：`corr_drop > 0` 时线性映射到 0–30。
- 持续性：`min(30, z_run_days / persist_days × 15)`。

**为什么要分开**：如果评分同时决定排序和判定，就会出现"评分高就一定是异常"的误解。
判定只由四门槛决定，评分只用于在同一判定内排序。

### 6.3 判定档位

| 判定 | 条件 |
|---|---|
| `异常背离（候选）` | 4 条门槛全部通过（且 strength 非 weak 才进主榜单） |
| `关注` | 通过 2–3 条门槛，且其中包含偏离幅度门槛 |
| `偏离但未达门槛` | 通过 1 条或 0 条 |
| `正常` | 无偏离（\|z\| 极小且持续性为 0） |
| `数据不足` | 重叠期 < 250 日 |

## 7. 参数默认值与固定原则

```python
DEFAULTS = dict(
    window_mask=60,        # 滚动窗口（交易日）
    recent_windows=[5,20,60],
    drop_threshold=0.45,   # 脱钩阈值
    z_threshold=2.0,       # 偏离阈值
    persist_days=5,        # 持续性
    hist_min_days=250,     # 最小重叠期
    perm_n=1200,           # 置换次数
    seed=20261020,         # 随机种子
)
```

**固定原则**：这些参数必须在扫描前确定并写进报告（交付 Excel「06 统计口径与阈值」），
**不因为结果不理想而回头调整**。若确实需要敏感性分析，应并列报告多组参数的结果，
而不是只报"调出来最好看"的那一组。

## 8. 一页速查

```
对齐:     交集，不插补
换月:     规则剔除（见 §1.2）
主相关:   Pearson(ln 收益)，带 Fisher CI + p + N_eff + 置换 p
脱钩:     |r_all| − r_roll60 ≥ 0.45
标准化:   Σln(1+r) / (σ√n)，5/20/60 日
价差:     有 k → ln(P_B) − ln(k·P_A)；无 k → ln(P_B/P_A)
z:        (s_t − mean(t−W..t−1)) / sd(t−W..t−1)，无前视
四门槛:   |z|≥2  ∧  连续≥5日  ∧  p_bonf<0.05(门控)  ∧  corr_drop≥0.45
评分:     偏离40 + 相关变化30 + 持续30（只排序）
```
