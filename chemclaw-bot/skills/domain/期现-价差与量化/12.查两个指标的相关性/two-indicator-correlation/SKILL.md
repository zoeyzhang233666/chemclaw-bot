# 查两个指标的相关性（Two-Indicator Correlation Research）

## 这个 Skill 干什么

回答四个问题，缺一不可：

1. **到底相不相关**——全样本 Pearson r（必要时加 Spearman），带 N、p 值、置信区间。
2. **在什么条件下相关**——把库存/价格各自做成「水平 / 变化」两种形态重新算，因为**水平对水平的相关最容易被共同趋势和季节性抬升**。
3. **什么时候不相关**——滚动窗口（12 / 26 / 52 周）相关系数曲线，标出脱钩与反转的区间。
4. **这个相关可不可信**——趋势、自相关、共同外部因素三类伪相关诊断。

**绝不做的事**：把相关性说成因果；自动生成交易建议；在没数据的日期上补数、插值、外推；用「周度统计填入未发布交易日」。

## 什么时候用 / 不用

用：库存 vs 价格、库存 vs 价格变化、开工率 vs 加工费、到港量 vs 基差、产量 vs 利润、两个地区价差 vs 运费等**成对指标**的定量关系。

不用：单指标走势判断（→ `chem-market-brief` / `chem-procure-brief`）；纯文本行情解读；预测价格。

## 执行流程（7 步）

### 第 0 步：先确认数据真的到手了

在写任何结论之前，先跑数据质量检查。**没有真实历史序列就不要往下走**，先跟用户确认数据来源（自有数据库、客户提供 Excel、付费源导出）。

```bash
python scripts/data_quality.py --csv data/your.csv --date-col date \
    --x-col inventory --y-col price --x-name 港口库存 --y-name 太仓现货价 \
    --freq 7 --out build/qc.json
```

输出 8 类检查：字段完整、日期可解析且无重复、时间覆盖、缺失清单、负值与跳变、相邻间隔是否等于目标频率、发布时滞、滚动窗口最低样本数。**ERROR 未清零不得继续。**

### 第 1 步：把口径写下来

打开 Excel 的「01 口径与来源」，逐项填：**单位、频率、区域/样本口径、发布时点、来源、口径风险**。示例：

| 指标 | 单位 | 频率 | 区域 | 发布时点 | 风险 |
|---|---|---|---|---|---|
| 中国甲醇样本港口库存 | 万吨 | 周度（周三调查） | 华东+华南样本港口 | 当日/次日 | 换样本、换机构不可比 |
| 江苏太仓甲醇出罐现货价 | 元/吨 | 日报（午评） | 太仓港 | 12:00 | 税基/现汇/库提口径不同 |

**同一张表里必须能回答**：两个指标的时间戳是不是同一时点？周度库存 vs 日度价格，用的是周三当天的价格还是周均价？

### 第 2 步：对齐频率（不许插值）

- 周度库存 + 日度价格 → 取**库存调查日当天**（或它之后最近的交易日）的价格；**取不到就标缺失**，不要用周均价假装是当天。
- 日度 + 日度 → 取交集；一边停更就停在那天。
- 月度 + 月度 → 注意发布滞后期，等长对齐而不是把未发布的月份填平。
- **换月/换合约/换基准日的情况**必须单独标注（例如期货主力换月会造成假跳变）。

对齐结果看 Excel「03 频率对齐」：每行有配对状态（配对成功 / 缺失-剔除）与有效配对 N。

### 第 3 步：选定形态（关键一步，最常被跳过）

| 指标性质 | 推荐形态 | 理由 |
|---|---|---|
| 库存（存量的绝对量，万吨） | **一阶差分**（周变化）或环比% | 库存水平有季节性、有中枢漂移；水平对水平会把季节性算成"相关" |
| 价格（连续报价，元/吨） | **环比变化率%** | 价格水平含通胀、含成本中枢漂移；变化率更接近"市场松紧" |
| 利率、价差、基差（本身是变化量） | 原值（水平） | 已经是变化量，再差分会放大噪声 |
| 开工率、产能利用率（0-100 有界比例） | 水平或百分点差分 | 有界，长期趋势弱 |

主口径建议：**库存差分 × 价格环比%**。同时把 3×3 全部组合都算出来放进「08 形态组合矩阵」，报告里必须写明用的是哪一格。

### 第 4 步：算总体相关

```bash
python scripts/analyze.py --csv data/your.csv --date-col week_ending \
    --x-col inventory_total --y-col spot_taicang \
    --x-form change --y-form pct \
    --windows 12,26,52 --min-pairs-ratio 0.8 \
    --breaks 2024-09-01,2025-09-01 --control-col coal_5500 \
    --sub inventory_total:level:spot_taicang:level \
    --sub inventory_total:change:spot_taicang:change \
    --out build/result.json
```

输出：Pearson r、N、p、Fisher-z 95% CI、Spearman、R²、Newey-West HAC 标准误与 HAC p、去趋势 r、一阶差分 r、两条序列的一阶自相关、有效样本量 N_eff 及修正 p。

### 第 5 步：滚动相关（必须设最小样本数）

- 窗口 12 / 26 / 52 周 + 自定义。
- 最小有效配对 = 窗口 × 80%（不低于 5）。**不足就不算**，图上留空，并标注「样本不足」。
- 找三类异常区间：**反转**（符号翻转且变化 > 0.12）、**脱钩**（|r| 从 ≥0.45 掉到 <0.2）、**突强**（|r| 从 <0.4 升到 >0.8）。

### 第 6 步：分阶段与事件对照

- 断点按**行业逻辑**设（检修季、需求淡季、新增产能投放、政策窗口、口径变更），不是为了凑结果反复切。
- 每个阶段独立报 r、N、p、Spearman，并做**方向一致性判断**：前段和后段方向相反，就必须写"阶段性失效"。
- 对异常区间去查行业事件（开工率变化、装置检修、进口到港、政策、统计口径变更）。事件只用于**解释相关性为何变化**，不能用来把相关性升级为因果。

### 第 7 步：伪相关三查 + 写结论

| 检查 | 做法 | 若失败怎么办 |
|---|---|---|
| 共同趋势 | 对时间回归取残差后再算 r；或直接用一阶差分口径 | r 大幅衰减 → 结论以变化口径为准，水平口径只作背景 |
| 自相关 | 算两条序列一阶自相关，用 N_eff = n(1−ρxρy)/(1+ρxρy) 修正 | ρ 高（>0.7）→ 报修正 p，不用名义 p 下结论 |
| 共同外部因素 | 控住煤价/开工率等第三变量求偏相关 | 偏相关明显低于基准 → 写明"控制成本后仍剩多少" |

结论模板（照抄可用）：

> 以 [口径] 的 [形态] 对 [形态] 计，2023-10-11 至 2026-09-30（N=155）两指标 Pearson r = −0.60（p<1e-4，95% CI −0.69~−0.49），Spearman ρ = −0.56。
> 26 周滚动 r 在 −0.97 ~ −0.06 之间变化，2025 年下半年出现脱钩（|r|<0.2）、2026 年一季度恢复。
> 分阶段看，第一阶段 r=−0.82、第二阶段 −0.32、第三阶段 −0.61，方向一致但强度大幅变化。
> 控制煤价后偏相关 −0.76，说明成本因素不是该相关的主要来源；两条序列一阶自相关分别为 0.89 / 0.73，有效样本量约 33，修正后 p 仍 <1e-5。
> **以上为共变强度描述，不构成因果关系判断，也不构成交易建议。**

## 工具与依赖

- Python 3.9+，**仅标准库**（`analyze.py` / `data_quality.py` / `corrlib.py` 不依赖 numpy/pandas，任何机器可跑；不需要 scipy —— t 分布、不完全 Beta、Fisher-z 全部内置实现）。
- `build_excel.py` 需要 `openpyxl`；`build_html.py` 只需标准库。
- 自检：`python scripts/selftest.py`（20 项，含 t 分布查表值、去趋势消失、滚动窗口不足返回空等）。

## 红线（逐条照做）

- ❌ 不补数：缺失留空、标缺失、从样本中剔除；不插值、不前向填充、不"按趋势估算"。
- ❌ 不把周度/月度统计摊到未发布的日子上。
- ❌ 不因为相关性高就说"A 导致 B"；不说"库存下降所以价格一定涨"。
- ❌ 不给交易建议、不给目标价、不说"建议做多/做空/囤货"。
- ❌ 不隐藏不利结果：脱钩区间、方向反转、样本不足的窗口必须出现在报告里。
- ✅ 每个数字都能追溯到：口径 + 形态 + 时间段 + N + 显著性 + 数据来源。
- ✅ 样本不足（N 低于窗口 80%）时，输出"样本不足，不计算"，而不是给一个数。
