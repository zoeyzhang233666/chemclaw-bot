# 伪相关与稳健性检查清单

> 逐条打勾。任何一条"未通过"都必须在报告里写出来，不能跳过。

## A. 数据层（先查这个，再谈统计）

- [ ] **A1 口径可比**：两个指标的统计范围一致（如"中国样本港口总库存"不能和"华东某单一仓库库存"配）。
- [ ] **A2 时点对齐**：库存调查日与价格报价日相同或差距 ≤1 个交易日，且实际使用的日期已记录（`price_date`）。
- [ ] **A3 无未来信息**：没有用价格调查日之后的库存、也没用库存发布之后的价格。
- [ ] **A4 样本连续性**：口径变更（换机构、换样本、换品种规格）的日期已标注，必要时分段处理。
- [ ] **A5 无脏值**：负值、跳变（周环比 >35%）、重复日期已核查。
- [ ] **A6 缺失如实**：缺失期在表中是空值 + 标注，不是插值结果。

## B. 统计层

- [ ] **B1 N 足够**：有效配对 N ≥ 30（低于 30 只能给探索性提示）；滚动窗口 N ≥ 窗口×80%。
- [ ] **B2 形态明示**：报告写明"库存用差分、价格用环比%"这类形态描述；3×3 矩阵已给出。
- [ ] **B3 显著性 + 强度分开报**：既报 p（是否可能偶发），也报 |r| 的档位（<0.3 弱 / 0.3–0.7 中 / >0.7 强）。
- [ ] **B4 置信区间**：给出 95% CI，避免"r=0.42"被当成精确值。
- [ ] **B5 自相关修正**：两序列 ρ₁ > 0.5 时，报 N_eff 与修正 p。
- [ ] **B6 HAC p**：时间序列下报 Newey-West 修正后的 p（与名义 p 差异大时以修正版为准）。

## C. 伪相关三查（核心）

### C1 共同趋势

- [ ] 计算"库存水平 × 价格水平"与"库存变化 × 价格变化"两种口径的 r，比较差异。
- [ ] 计算**去趋势相关**：对时间回归取残差后求 r。
- [ ] 判读：
  - 水平口径 r 高、差分口径 r 低 → **共同趋势主导**，水平相关不可用于解释。
  - 去趋势后 r 接近差分口径 r → 结论稳健。
- 常见来源：产能扩张（库存中枢抬升同时价格中枢下移）、通胀、季节性。

### C2 自相关（伪显著性）

- [ ] 算 ρ₁ₓ、ρ₁ᵧ、N_eff。
- [ ] 判读：ρ₁ > 0.7 且 N_eff < N/3 → **名义 p 严重高估显著性**，必须报修正 p。
- 常见来源：周度库存本身是缓慢移动的存量、价格有趋势/惯性。

### C3 共同外部因素

- [ ] 找出同时驱动两个指标的第三变量（煤价、原油、下游开工率、政策、汇率）。
- [ ] 计算**偏相关**（控制该变量后的 r）。
- [ ] 判读：偏相关显著低于基准 r → 部分"相关"来自共同驱动，需在结论中拆开讲。
- 注意：控制变量本身必须与两者都相关，否则偏相关没有意义（且会放大噪声）。

## D. 稳定性检查

- [ ] **D1 滚动窗口**：12 / 26 / 52 周三档，标出反转/脱钩区间。
- [ ] **D2 分阶段**：至少 3 段，检查方向是否一致；方向相反必须写"阶段性失效"。
- [ ] **D3 前后半分**：前半段与后半段的 r 差 > 0.3 时，全样本 r 不宜单独引用。
- [ ] **D4 离群点敏感性**：剔除上下 5% 后 r 的变化 <0.1 才可称"不由极值撑起"。
- [ ] **D5 换样本**：换子样本（如只华东、只华南；只旺季、只淡季）结论是否还在。
- [ ] **D6 换形态**：3×3 矩阵中，主口径结论与相邻口径（差分 vs 环比）符号一致。

## E. 因果与表达的边界

- [ ] **E1** 没有出现"导致""造成""因为…所以…"等因果措辞（除引用外部文献并明确注明）。
- [ ] **E2** 滞后结构只描述为"先后顺序与数据吻合"。
- [ ] **E3** 没有出现任何交易建议（做多/做空/囤货/建仓/止盈）。
- [ ] **E4** 没有价格预测或目标价。
- [ ] **E5** 结论段落包含"共变强度描述，不构成因果判断，不构成交易建议"的声明。

## F. 交付物自检

- [ ] HTML 打开无报错，四个图表都有数据点，改参数后指标卡同步变化。
- [ ] Excel 换数据后能重算（公式非硬编码），且"12 公式说明"与表内公式一致。
- [ ] 数据状态（真实 / 演示 / 用户提供）在 HTML 页首和 Excel 首页都**显著标注**。
- [ ] 缺失期、样本不足窗口在图表上有可见标记（留空或灰区），不是被平滑掉。

## 常见坑速查

| 现象 | 最可能的原因 | 处理 |
|---|---|---|
| r 高得离谱（>0.95）且两条序列都缓慢上行 | 共同趋势 | 改差分/去趋势 |
| r 在 0 附近来回跳 | 一个指标领先/滞后另一个 | 查滞后相关 |
| 全样本 r 显著，但每一年单独算都不显著 | 辛普森悖论 / 阶段混合 | 分阶段报告 |
| 换成周均价后 r 大变 | 前视偏差 | 严格用调查日当天价格 |
| 剔除几个极值点后 r 从 0.6 掉到 0.1 | 结论由个别事件撑起 | 点名极值日期，说明适用条件 |
| Excel 里 CORREL 报错 | 区域内有文本（如"样本不足"） | 用 `--ISNUMBER` 掩码或先清理 |
