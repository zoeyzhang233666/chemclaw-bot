# 方法说明：两指标相关性研究的正确做法

## 1. 为什么"相关系数"这件事容易做错

相关系数是一个**极易被误用**的统计量。常见错误有五类，本 Skill 的每条流程都对应堵住其中一个：

| 错误 | 后果 | 本 Skill 的对策 |
|---|---|---|
| 两个**水平序列**直接算 r | 共同趋势（通胀、产能扩张、季节性）让 r 虚高到 0.9 以上，看起来"强相关"其实毫无信息量 | 强制做「03/04 变换」与「08 形态矩阵」，主口径用变化量 |
| 只报 r 不报 N | N=8 的 r=0.8 和 N=200 的 r=0.8 完全不是一回事 | 所有表格都带 N，且报表最小样本门槛 |
| 用名义 p 值下结论 | 周度序列自相关强（ρ₁ 常 >0.8），名义 N 严重夸大显著性 | 报 `N_eff` 与修正 p，同时报 HAC（Newey-West）标准误 |
| 用全样本 r 掩盖阶段变化 | 前后段方向相反时，全样本 r 可能接近 0，也可能被某一段主导 | 滚动窗口 + 分阶段，并对"方向反转"单独标注 |
| 把相关当因果 | "库存降→价格涨"被当成交易信号 | 结论模板强制写入"共变强度描述，不构成因果"；滞后相关只允许说"先后顺序吻合" |

## 2. 形态选择：水平还是变化？

**判断依据是"指标本身是什么量"**：

- **存量（inventory, 万吨）**：有季节性、有中枢漂移、受库容上限约束 → 用**一阶差分**（周变化，万吨）看"这周是累库还是去库"；水平只在描述"库存高不高"时用（配合分位数，而不是相关系数）。
- **流量（arrival 到港量, 万吨/周）**：本身就是变化量 → 用水平。
- **价格（元/吨）**：含成本中枢漂移、通胀、品种升级 → 用**环比变化率%**；绝对差分只在单位可比时使用。
- **比例（开工率%）**：有界、趋势弱 → 用水平，或百分点差分。
- **价差/基差**：本身就是变化量 → 用水平，再差分会放大噪声。

**四种组合的经济含义不同**，不能混用：

| 组合 | 回答的问题 | 常见陷阱 |
|---|---|---|
| 库存水平 × 价格水平 | "库存高的时候价格是不是低"（截面/长期关系） | 共同趋势、季节性、样本期选择 |
| 库存变化 × 价格变化 | "这周累库，这周价格是不是跌"（短期冲击关系） | 噪声大，需足够 N |
| 库存水平 × 价格变化 | 混用，一般不推荐 | 量纲与时间概念不一致，r 常被误读 |
| 库存变化 × 价格水平 | 混用 | 同上 |

## 3. 频率对齐的三种情形

**情形 A：同频（周度库存 + 周度价格）**
直接按观测日配对。注意"周度"的定义：自然周（周一至周日）还是调查期（上周三至本周三）？以库存调查日为锚。

**情形 B：低频 + 高频（周度库存 + 日度价格）**
取**库存调查日当天**的价格。若当天无报价（节假日），取**其后最近交易日**，并在数据表里记录实际使用的日期（本 Skill 的 `price_date` 列）。**不要取周均价**——周均价包含了调查日之后的信息，属于前视偏差。

**情形 C：月度 + 月度，但发布滞后不同**
按统计期（而不是发布日期）对齐，并记录发布日期；发布时滞会影响"什么时候能知道"，在报告里单独说明。

**禁止的做法**：
- 缺失值线性插值、前向填充、用均值填补
- 把月度数据摊到每日
- 把未发布的周填成"与上周相同"

## 4. 统计量清单与定义

设有效配对为 $(x_i,y_i)$，$i=1..N$。

| 统计量 | 公式 | Excel | 说明 |
|---|---|---|---|
| Pearson r | $r=\frac{\sum(x_i-\bar x)(y_i-\bar y)}{\sqrt{\sum(x_i-\bar x)^2\sum(y_i-\bar y)^2}}$ | `CORREL` | 线性关系；对离群点敏感 |
| Spearman ρ | 秩变换后的 Pearson | `CORREL(RANK.AVG...)` | 单调关系；抗离群 |
| R² | $r^2$ | `RSQ` | 解释的方差比例 |
| t | $t=r\sqrt{(N-2)/(1-r^2)}$ | `r*SQRT((N-2)/(1-r^2))` | 自由度 N−2 |
| p（双侧） | $2\cdot P(T_{N-2}>|t|)$ | `T.DIST.2T` | p 小 ≠ 相关强 |
| 95% CI | $\tanh(\operatorname{artanh}(r)\pm 1.96/\sqrt{N-3})$ | `TANH(ATANH(r)±1.96/SQRT(N-3))` | Fisher-z |
| 一阶自相关 | $\rho_1=\frac{\sum(x_t-\bar x)(x_{t-1}-\bar x)}{\sum(x_t-\bar x)^2}$ | 便捷公式 | 需 >0 才谈有效样本修正 |
| 有效样本量 | $N_{eff}=\frac{N(1-\rho_{1x}\rho_{1y})}{1+\rho_{1x}\rho_{1y}}$ | 脚本输出 | Quenouille 近似 |
| HAC 标准误 | Newey-West 长期方差 | 脚本输出 | 处理异方差与自相关 |
| 偏相关 | 对 z 回归取残差后求 r | `CORREL(残差X,残差Y)` | 控制共同外部因素 |
| 去趋势相关 | 对时间 t 回归取残差后求 r | 脚本 / `09b` 表 | 诊断共同趋势 |

## 5. 滚动窗口的规范

- 窗口端点对齐在**窗口最后一天**，横轴是"该窗口覆盖期的末端日期"。
- 每个窗口独立计算 r，**窗口之间重叠是正常的**（不是独立样本，不要对滚动 r 再做显著性检验）。
- 最小有效配对 = $\max(5,\text{round}(W\times0.8))$。不足时输出空值并着色。
- 说"相关性在下降"时，要给出**至少连续 3 个窗口**的同向变化，单个窗口跳变可能是噪声。

## 6. 滞后相关怎么用（和不能怎么用）

- `lag>0`：用 x[t] 对 y[t+lag]，表示 **x 领先 y**。
- 峰值出现在 lag=1~2 只能说明"先后顺序与数据吻合"，**不能**证明因果。
- 若滞后 0 期 r 最大，说明两个指标是**同频共变**（都受同一个新信息驱动），这通常是"共同外部因素"的证据而不是因果链。
- 检验因果需要：外生冲击（政策/事故）、工具变量、Granger 因果（且仅对平稳序列）、事件研究法。本 Skill **不做**因果推断。

## 7. 结论写作的三条纪律

1. **三件套**：每个 r 后面必须跟 (口径, 形态, 时间段, N, p)。
2. **说清变化**：如果滚动/分阶段显示强度变化，必须写出来，不能只报全样本。
3. **划清边界**：明确写"共变强度描述，不构成因果判断，不构成交易建议"。
