# 统计公式与实现对照

本文件给出本 Skill 用到的每个统计量的**数学定义、实现位置、以及可核对的方式**。所有统计量在 `scripts/corrlib.py` 中用纯标准库实现（不依赖 scipy / numpy），Excel 工作簿中的对应公式也一并列出。

## 1. 描述统计

```
均值  x̄ = (1/N) Σ xᵢ
样本方差 s² = (1/(N-1)) Σ (xᵢ - x̄)²
样本标准差 s = √s²
```

实现：`corrlib.mean / variance / sd`（`ddof=1`）。
Excel：`AVERAGE / VAR.S / STDEV.S`。

## 2. Pearson 相关系数

```
r = Σ(xᵢ - x̄)(yᵢ - ȳ) / √[ Σ(xᵢ - x̄)² · Σ(yᵢ - ȳ)² ]
```

- 定义域 [−1, 1]；只度量**线性**关系。
- 任一侧方差为 0（常数序列）时无定义 → 返回 `None`，不返回 0。
- 缺失值：先按位置配对剔除，再计算（等价于 `CORREL` 对空单元格的处理）。

实现：`corrlib.pearson`；Excel：`CORREL`。

## 3. Spearman 秩相关

```
ρ = Pearson(rank(x), rank(y))
```

秩的处理：**并列取平均秩**（如 `[10,20,20,30] → [1,2.5,2.5,4]`）。

实现：`corrlib.rank` + `corrlib.pearson`；Excel：`RANK.AVG` 生成秩列后 `CORREL`。

## 4. R²、t 统计量与 p 值

```
R² = r²
t  = r · √[(N-2)/(1-r²)]          自由度 df = N-2
p  = 2 · P(T_df > |t|)            双侧
```

`p` 通过正则化不完全 Beta 函数计算：

```
P(|T|>t) = I_{df/(df+t²)}(df/2, 1/2)
```

`I_x(a,b)` 用连分式展开（Lentz 算法）实现，精度 1e-12。

实现：`corrlib.t_pvalue / _betainc / _betacf`；Excel：`T.DIST.2T(ABS(t), N-2)`。

**自测锚点**：`t=2.228, df=10 → p≈0.0500`；`t=1.0, df=1000 → p≈0.3173`（见 `selftest.py`）。

## 5. Fisher-z 95% 置信区间

```
z = artanh(r) = 0.5·ln((1+r)/(1-r))
SE(z) = 1/√(N-3)                   要求 N > 3
CI = tanh(z ± 1.959964·SE(z))
```

实现：`corrlib.corr_stats` 的 `ci_lo / ci_hi`；Excel：`TANH(ATANH(r) ± 1.96/SQRT(N-3))`。

注：|r| 接近 1 时先截断到 ±0.999999，避免 artanh 溢出。

## 6. Newey-West HAC 标准误

对标准化后的乘积序列 `gₜ = uₓₜ·u_yₜ`（u 为标准化的离差）：

```
S = γ₀ + 2 Σ_{L=1..q} w_L·γ_L,     w_L = 1 - L/(q+1)
γ_L = (1/N) Σ (gₜ - ḡ)(gₜ₋L - ḡ)
HAC_SE(r) = √(S/N)
```

- 阶数 q 默认取 `N//20`（周度约 7~8 期）。
- HAC p 值用正态近似：`p = 2(1-Φ(|r/HAC_SE|))`。

实现：`corrlib.hac_se_corr`；Excel 无原生实现（由 `analyze.py` 输出）。

## 7. 有效样本量（自相关修正）

```
N_eff = N·(1 - ρ₁ₓ·ρ₁ᵧ) / (1 + ρ₁ₓ·ρ₁ᵧ)      （Quenouille 近似）
修正 t = r·√[(N_eff - 2)/(1 - r²)]
修正 p = t 分布（df = N_eff - 2）
```

- `ρ₁` 为一阶自相关；若 `1+ρ₁ₓρ₁ᵧ ≤ 0`（极端反相关）则不修正。
- 结果被限制在 `[3, N]` 之间。

实现：`corrlib.effective_n`。

## 8. 去趋势相关与一阶差分相关

```
时间趋势：y ≈ a + b·t          （t = 1..N）
残差：êₜ = yₜ - (a + b·t)
去趋势相关：r_detrend = Pearson(êₓ, êᵧ)

一阶差分相关：r_diff = Pearson(Δx, Δy)，Δxₜ = xₜ - xₜ₋₁
```

- 去趋势后 r 大幅下降 → 原相关主要由**共同趋势**贡献。
- 一阶差分后 r 与差分口径 r 一致 → 结论稳健。

实现：`corrlib.linreg / detrend / diff`；Excel：`SLOPE`/`INTERCEPT` 逐行算残差（「09b 辅助计算(残差)」表）。

## 9. 偏相关（控制共同外部因素）

```
对控制变量 z 分别回归：x ≈ a₁ + b₁z + êₓ，y ≈ a₂ + b₂z + êᵧ
偏相关 = Pearson(êₓ, êᵧ)
```

等价的闭式公式：

```
r_xy·z = (r_xy - r_xz·r_yz) / √[(1 - r_xz²)(1 - r_yz²)]
```

实现：`corrlib.partial_corr`（残差法）；Excel：`CORREL(残差列X, 残差列Y)`。

## 10. 滞后相关

```
lag > 0：Pearson(x[1..N-lag], y[lag+1..N])   —— x 领先 y
lag < 0：Pearson(x[1-lag..N], y[1..N+lag])   —— y 领先 x
```

实现：`corrlib.lag_corr`。

## 11. 滚动相关

对每个窗口末端 t：

```
窗口 = [t-W+1, t]
有效配对 c = #{i ∈ 窗口 : xᵢ ≠ None 且 yᵢ ≠ None}
若 c < max(5, round(W×0.8))  →  输出 None（不计算）
否则                          →  Pearson(窗口内配对)
```

关键点：**窗口内有效配对数不足时返回空，而不是用现有数据算一个"近似值"**。

实现：`corrlib.rolling_corr / window_stats`；Excel：`CORREL(OFFSET(...))` + 计数判断。

## 12. 变换

```
level（水平）：x_t
change（差分）：x_t - x_{t-1}                       首期为 None
pct（环比%）：(x_t - x_{t-1})/|x_{t-1}| × 100       首期为 None，分母为 0 时为 None
yoy（同比%）：(x_t - x_{t-52})/|x_{t-52}| × 100     周度序列专用
```

任何变换都**不填补**首期或缺失期；`None` 在后续所有计算中被剔除。

实现：`corrlib.transform`；Excel：「04 变换后数据」表。
