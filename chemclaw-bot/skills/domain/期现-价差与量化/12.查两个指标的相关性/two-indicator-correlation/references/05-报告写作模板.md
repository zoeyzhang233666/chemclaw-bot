# 报告写作模板与话术

> 好的相关性报告读起来像一份"证据清单"，而不是一份"结论"。下面给出结构、句式与反面例子。

## 1. 报告结构（固定 8 段）

```
① 一句话结论（带口径、形态、时间段、N、r、p）
② 数据与口径（两个指标各自是什么、怎么对齐的、缺了什么）
③ 全样本结果（5 种形态组合的 r / N / p / 强度）
④ 滚动与分阶段（相关强度什么时候变、变到哪去）
⑤ 异常区间与事件对照（为什么变）
⑥ 稳健性与伪相关诊断（趋势 / 自相关 / 共同因素）
⑦ 可以怎么用 / 不能怎么用
⑧ 声明与数据状态
```

## 2. 各段句式

### ① 一句话结论

模板：

> 2023-10-11 至 2026-09-30（N=155，周度），甲醇港口库存的**周变化**与太仓现货价的**周环比变化**呈负相关：Pearson r = −0.60（p < 1e-4，95% CI −0.69 ~ −0.49），Spearman ρ = −0.56；相关强度属"中等偏强"，且**随市场阶段明显变化**。

反例（不要这样写）：
> ~~库存和价格高度负相关，说明库存降价格就涨。~~（没有口径、没有 N、把相关说成因果）

### ② 数据与口径

> 库存：中国甲醇样本港口库存（华东+华南样本仓库），单位万吨，周度，调查日周三，为第三方机构抽样统计。
> 价格：江苏太仓甲醇出罐价（进口货、库提、现汇），单位元/吨，取库存调查日当天午评报价；当天无报价时取其后最近交易日并记录实际日期。
> 对齐：两序列均按周度处理，共 156 期全部配对成功，无缺失，无插值。
> 已知口径风险：港口样本为企业申报的抽样口径，与真实社会库存存在偏差；现货报价为午评，与当日成交价可能略有差异。

### ③ 全样本结果

必须给表，且**五种组合齐列**：

| 组合 | r | N | p | 强度 |
|---|---|---|---|---|
| 库存水平 × 价格水平 | −0.708 | 156 | <1e-4 | 强 |
| 库存水平 × 价格环比% | −0.144 | 155 | 0.074 | 弱 |
| **库存差分 × 价格环比%（主口径）** | **−0.601** | **155** | **<1e-4** | **中等偏强** |
| 库存差分 × 价格差分 | −0.600 | 155 | <1e-4 | 中等偏强 |
| 库存环比% × 价格环比% | −0.591 | 155 | <1e-4 | 中等偏强 |

配一句话：**"水平口径 r=−0.71 但水平×环比只有 −0.14，说明'水平相关'与'变化相关'回答的不是同一个问题。"**

### ④ 滚动与分阶段

> 26 周滚动相关在 −0.97 ~ −0.06 之间变化。2025 年三季度起滚动相关持续走弱，于 2025 年 12 月—2026 年 1 月跌入 |r| < 0.2 的脱钩区间，2026 年 2 月后恢复至 −0.9 附近。
> 分段统计：2023-10~2024-09 r=−0.82（N=46）、2024-09~2025-09 r=−0.32（N=52）、2025-09~2026-09 r=−0.61（N=57）。三段方向一致但强度差异显著。

**必须点出**："方向一致"和"强度一致"是两件事；方向一致不代表可以外推。

### ⑤ 异常区间与事件对照

> 2025-12 ~ 2026-01 脱钩期对应：下游利润压缩、需求转弱阶段，价格主要受成本与预期驱动，库存变动对价格解释力下降。
> ⚠️ 该解释为**背景对照**，未做因果检验。

### ⑥ 稳健性与伪相关

固定四句话：

1. 去趋势后 r = −0.71（与主口径接近），说明该相关**不是单纯由共同趋势造成**。
2. 一阶差分后 r = −0.60，与主口径一致。
3. 两条序列一阶自相关为 0.89 / 0.73，有效样本量约 33，修正后 p 仍 < 1e-5（原名 p 值过于乐观）。
4. 控制动力煤价格后偏相关 −0.76，成本因素不是主要来源（但也说明煤价与两者都有正相关，需在报告中说明）。

### ⑦ 可以怎么用 / 不能怎么用

> 可以用：把"周度累库/去库"作为价格承压/支撑的**背景因素之一**，与到港量、开工率、下游利润一起看。
> 不能用于：单独据此判断涨跌、设置目标价、作为交易信号；在脱钩区间内（如 2025Q4）该关系不成立。

### ⑧ 声明

> 以上为历史共变强度的统计描述，不构成因果关系判断，也不构成任何交易建议或价格预测。数据状态：〔真实 / 客户提供 / 演示拟真〕。

## 3. 措辞对照表

| ❌ 不要写 | ✅ 应该写 |
|---|---|
| 库存下降导致价格上涨 | 库存周变化与价格周环比变化呈负相关（r=…，N=…） |
| 库存是价格的核心驱动 | 在全样本中库存变化解释了约 36% 的价格周环比方差（R²=0.36），但分阶段看解释力不稳定 |
| 相关性很强，可以放心用 | r=0.70，但滚动区间为 0.2~0.95，且有 1 段脱钩，适用条件需限定 |
| 数据略有缺失，已处理 | 缺失 X 期（日期列表），已从样本中剔除，未做插值 |
| 建议逢低囤货 | （删除，不写任何交易建议） |
| 明显负相关 | r=−0.60，p<1e-4，属中等偏强负相关 |

## 4. 图表清单（每张图必须有标题和单位）

1. 双序列对照（标准化）——看形态与转折
2. 散点 + 拟合线——看线性程度与离群点
3. 滚动相关曲线（12/26/52）——看稳定性
4. 滞后相关柱图——看先后顺序
5. 分阶段条形图（可选）——看强度差异

每张图下方一句话说明"该图支持什么判断、不能支持什么判断"。

## 5. 交付前自检 5 问

1. 每个 r 是否都带了 N 和口径？
2. 有没有把水平相关当成主要结论？（若有，是否给了差分对照？）
3. 脱钩/反转区间是否写出来了？
4. 是否出现了任何因果词或交易建议？
5. 数据状态（真实/演示）是否在显著位置标注？
