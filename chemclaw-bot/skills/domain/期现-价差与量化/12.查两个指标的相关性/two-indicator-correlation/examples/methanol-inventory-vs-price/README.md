# 案例：甲醇港口库存 × 太仓现货价

本目录是一个**完整跑通**的两指标相关性研究案例，包含全流程交付物。请先读"数据状态"，再读结论。

## ⚠️ 数据状态（务必先看）

| 文件 | 数据状态 | 说明 |
|---|---|---|
| `data-demo-weekly.csv` | **DEMO 拟真数据** | 按甲醇行业真实口径（港口库存万吨/周度周三、太仓出罐价元/吨/日评）**模拟生成**，用于演示完整方法与交付物形态。**不是真实市场数据，不可引用为行情。** 生成机制见 `scripts/make_data.py` |
| `data-meta.json` | DEMO 元数据 | 两个指标的字段、单位、频率、区域、来源说明 |
| `data-real-MA0-weekly.csv` | **真实公开数据** | 郑商所甲醇期货主力连续（MA0）日线聚合为周度：收盘价、周均价、20 日年化波动率、持仓量及周变化。来源：新浪财经公开 K 线接口 |
| `real-example-result.json` | **真实数据结果** | 用同一套脚本在真实公开数据上算出的相关系数（见下文"真实数据对照"） |
| `demo-analysis-result.json` | DEMO 结果 | `analyze.py` 的完整输出（含滚动、分阶段、HAC、偏相关、滞后） |
| `demo-data-quality.json` | DEMO 质检 | `data_quality.py` 的 8 类检查结果 |

**为什么用 DEMO 数据做主案例**：甲醇"港口周度库存 + 现货价格"的历史长序列在国内全部位于付费墙后（隆众/卓创会员制；我的钢铁可见部分正文但不稳定；生意社免费仅约 10 个采样点）。公开可复现的免费长序列只有期货价格与交易所仓单。因此本案例用拟真数据演示**方法与形态**，另用**真实期货数据**做方法在真实样本上的对照。

真实项目里，把 `data-demo-weekly.csv` 换成客户提供的历史序列（见 `references/04-数据源与口径清单.md` 第 5 节的 8 个问题），重跑三条命令即可。

## 怎么复现

```bash
# 0) 统计内核自检（20 项已知答案）
python scripts/selftest.py

# 1) 数据质量检查
python scripts/data_quality.py --csv data/demo_methanol_weekly.csv --date-col week_ending \
    --x-col inventory_total --y-col spot_taicang --x-name 港口库存 --y-name 太仓现货价 \
    --freq 7 --out build/qc.json

# 2) 主分析（主口径：库存差分 × 价格环比%）
python scripts/analyze.py --csv data/demo_methanol_weekly.csv --date-col week_ending \
    --x-col inventory_total --y-col spot_taicang --x-form level --y-form level \
    --windows 12,26,52 --min-pairs-ratio 0.8 \
    --breaks 2024-09-01,2025-09-01 --control-col coal_5500 \
    --sub inventory_total:change:spot_taicang:pct \
    --sub inventory_total:level:spot_taicang:pct \
    --sub inventory_total:change:spot_taicang:change \
    --sub inventory_ec:level:spot_taicang:level \
    --out build/result.json

# 3) 生成 Excel 与 HTML
python scripts/build_excel.py
python scripts/build_html.py
```

## 数据概览

- 期间：2023-10-11 ~ 2026-09-30，周度（周三），共 156 期，**无缺失，未做任何插值**。
- 库存：港口样本库存 41.3 ~ 83.2 万吨（均值约 62 万吨）；分华东、华南。
- 价格：太仓出罐价 1,505 ~ 3,228 元/吨。
- 控制变量：动力煤 5500（元/吨）、下游加权开工率（%）。

## 主结果

### 全样本（5 种形态组合）

| 组合 | r | N | p | 强度 |
|---|---|---|---|---|
| 库存水平 × 价格水平 | **−0.708** | 156 | 4.8e−25 | 强 |
| 库存水平 × 价格环比% | −0.144 | 155 | 0.074 | 弱（不显著） |
| **库存差分 × 价格环比%（主口径）** | **−0.601** | 155 | 1.3e−16 | 中等偏强 |
| 库存差分 × 价格差分 | −0.600 | 155 | 1.5e−16 | 中等偏强 |
| 库存环比% × 价格环比% | −0.591 | 155 | 5.7e−17 | 中等偏强 |

**关键观察**：水平对水平 r=−0.71 看起来最强，但"水平 × 环比"只有 −0.14 且不显著。这说明水平口径的相关里混着两个指标的共同趋势，**不能直接当作"库存高价格就低"的证据**。真正稳健的是变化口径（−0.60）。

### 稳健性与伪相关诊断（主口径）

| 诊断 | 数值 | 判读 |
|---|---|---|
| Pearson r | −0.601 | 基准 |
| Spearman ρ | −0.563 | 秩相关，抗离群，方向一致 |
| 95% CI | −0.693 ~ −0.490 | 窄，估计稳定 |
| Newey-West HAC p | 5.4e−09 | 序列相关下仍显著 |
| 去趋势后 r | −0.708（水平口径） | 水平相关并非由时间趋势造成 |
| 一阶差分后 r | −0.600 | 与主口径一致 → 稳健 |
| 剔除上下 5% 极值后 r | −0.715 | 结论不由极值撑起 |
| 库存一阶自相关 ρ₁ | 0.892 | 强记忆性 |
| 价格一阶自相关 ρ₁ | 0.729 | 强记忆性 |
| 有效样本量 N_eff | ≈ 33（名义 156） | **名义 p 过于乐观**，修正后 p ≈ 4.0e−06 仍显著 |
| 控制煤价后偏相关 | −0.757 | 成本因素不是主要来源 |

### 分阶段（按年度/季度边界切分）

| 阶段 | 区间 | N | r | 判读 |
|---|---|---|---|---|
| 阶段一 | 2023-10 ~ 2024-09 | 47 | **−0.921** | 强负相关 |
| 阶段二 | 2024-09 ~ 2025-09 | 52 | **−0.809** | 强负相关（略有减弱） |
| 阶段三 | 2025-09 ~ 2026-09 | 57 | **−0.648** | 中等负相关（明显减弱） |

### 滚动相关（26 周）

滚动 r 区间约 **−0.97 ~ −0.06**：

- 2024 年全年稳定在 −0.85 ~ −0.97（强相关）
- 2025 年三季度起持续走弱：−0.58（07 月）→ −0.44（09 月）→ −0.26（11 月）
- **2025-12 ~ 2026-01 脱钩**：r ≈ −0.13 ~ −0.06（|r| < 0.2，图上标红）
- 2026 年 2 月后快速恢复：−0.88 → −0.96

### 滞后相关（主口径）

| lag | −4 | −3 | −2 | −1 | **0** | +1 | +2 | +3 | +4 |
|---|---|---|---|---|---|---|---|---|---|
| r | −0.11 | −0.28 | −0.45 | −0.62 | **−0.71** | −0.60 | −0.45 | −0.30 | −0.17 |

峰值在 lag=0，两侧对称衰减 → 两指标**同频共变**（受同一批信息驱动），不足以支持任何方向性因果。

## 结论（可直接引用的写法）

> 2023-10-11 至 2026-09-30（周度，N=155），甲醇港口库存的**周变化**与太仓现货价的**周环比变化**呈中等偏强负相关：Pearson r = −0.601（95% CI −0.693 ~ −0.490，p < 1e−15）。
> 相关强度随阶段显著变化：2023-10~2024-09 为 −0.92，2024-09~2025-09 为 −0.81，2025-09~2026-09 为 −0.65；26 周滚动相关在 2025 年四季度至 2026 年初跌入 |r| < 0.2 的脱钩区间。
> 两条序列一阶自相关分别为 0.89 / 0.73，按自相关修正后有效样本量约 33，修正 p 仍小于 1e−5；控制动力煤价格后偏相关为 −0.757，成本因素不是该相关的主要来源。
> **以上为历史共变强度的统计描述，不构成因果关系判断，也不构成任何交易建议或价格预测。数据状态：DEMO 拟真数据。**

## 真实数据对照（同方法，真实样本）

用 `data-real-MA0-weekly.csv`（郑商所甲醇主力连续，**2014-12-26 ~ 2026-10-19，606 个周度观测，真实公开数据**）：

| 组合 | r | N | p | 解读 |
|---|---|---|---|---|
| 价格水平 × 20 日年化波动率 | **+0.186** | 604 | 4.0e−06 | 统计显著但**极弱** |
| 价格周环比% × 持仓量周变化 | **−0.038** | 605 | 0.346 | 不显著，接近零 |
| 周均价 × 20 日年化波动率 | +0.193 | 604 | 1.8e−06 | 极弱 |
| 价格水平 × 持仓量 | −0.081 | 606 | 0.047 | 名义显著但几乎无经济意义 |

52 周滚动相关（价格环比% × 持仓周变化）在 **−0.44 ~ +0.50** 之间反复穿越零点，没有任何稳定符号。

**这个对照说明两件事**：
1. **p 值小 ≠ 关系强**：r=+0.186、N=604 的 p 只有 4e−06，如果只看 p 值会得出"显著相关"的错误印象。
2. **真实市场里，多数"直觉上应该相关"的指标对，其实并不稳定相关**——这正是必须做滚动与分阶段、必须设最小样本门槛的原因。
