# 异常年份：识别、报告、以及为什么**不自动删除**

---

## 1. 为什么这件事很敏感

季节性的整条逻辑建立在"过去的年份彼此可比"上。一旦某一年明显不正常
（政策冲击、装置大修、极端天气、数据口径变更），它会同时污染：

- **均值** —— 被一个点拉走（4 个样本，一个 +60% 就把均值抬高 15%）；
- **标准差 / p90** —— 被抬高后，"今年处于 p95"这种结论就失去意义；
- **CV** —— 看起来"波动很大"，其实只是一年的事。

所以必须识别。**但"识别"不等于"删除"**。

## 2. 为什么绝不自动删除

1. **异常年也是真实发生过的价格。** 用户问的是"历史上这一周都发生过什么"，
   删掉最极端的那年，等于隐瞒了他最该知道的风险。
2. **删除是研究决策，不是计算步骤。** 要不要剔除、剔除后用于什么，取决于研究目的
   （做估值锚 vs 做尾部风险）。这必须由研究者决定并**留痕**，不能由脚本代劳。
3. **自动删除会制造循环论证**：先按"偏离均值"删，再算均值 —— 剩下的样本当然很整齐，
   于是报告会给出一个现实中不存在的"稳定季节性"。这是最容易骗到自己的一种做法。

**本 skill 的做法**：识别 + 标注 + 量化影响（剔除后均值会怎么变），
把决定权留给研究者，并在报告里明确写"所有年份均未被自动删除"。

## 3. 判定规则（已实现在 `_position_evidence`）

对**每一个同期位置**单独检查，而不是对全年整体检查 ——
因为异常往往只在特定时段出现（例如 2026 年甲醇是 9–10 月才暴走）。

设某位置样本 `{year: value}`，年数 `n ≥ min_years`：

```
对每年 y：
    其余年 = 除 y 外的所有值
    med_o = median(其余年)
    mad_o = median(|其余年 - med_o|)
    dev   = |value_y - med_o| / |med_o|
    z     = (value_y - med_o) / (1.4826 × mad_o)        # 1.4826 使 MAD 与 σ 可比
```

产生两类证据：

| 类型 | 条件 | 强度 |
|---|---|---|
| **决定性** `coherent-single-year` | 其余年高度一致（`mad_o/|med_o| ≤ 0.02`）**且** `dev > 0.02` | 强：其他年份几乎完全一样，就这一年不同 |
| **稳健** `robust-outlier` | `|z| ≥ 3`（MAD 距 ≥ 3σ） | 中：按稳健离散度衡量离得远 |

## 4. 三个必须处理的边界情况（都踩过坑）

### 4.1 独占极值年不产生证据

最高年/最低年天然就"偏离" —— 在 4 个样本里，最高值必然比其余 3 个都高。
如果对它也算 `z`，**每个位置都会把极值年标成异常**，证据量爆炸且毫无信息量。

**规则**：最高年/最低年如果是**独占极值**，跳过不产生证据。
只有当极值年与其他年份**并列**（≥2 年同为最高/最低）时，它才参与检验 ——
因为并列意味着它并不"排他地极端"，真正的离群可能是它自己。

### 4.2 全部年份同值 / 其余年离散度为 0

若其余年完全相等（`mad_o = 0`），`z` 会变成 `inf`：
- `inf` 进入 JSON → 前端 `Infinity` → 显示异常或比较出错；
- 更糟的是把它当"极度显著"，从而把**正常年**标成异常。

**规则**：`mad_o == 0` 时不产生 `robust` 证据，只用 `coherent` 证据（这本来就是它的强项）；
`z` 用封顶值而非 `inf`。若**所有**年份值完全相同（`len(set) < 2`），直接返回无证据 ——
没有离群可言。

### 4.3 谁是真离群年：mirror 问题

出现"尖峰"时，逐个年份算 `z` 会得到：**异常年** 和**所有正常年**都显得离群
（因为对每个正常年来说，"其余年"里包含了那个尖峰，导致 `mad_o` 很大、
正常年自己反而偏离这个被污染的中位数）。

实测反例：`[2512.9, 2512.9, 2512.9, 4300, 2512.9]`，若不管，会报 4 个正常年都是
`robust-outlier`、而真正的 2024 年因为"离其余年中位数远"被漏掉或被并列。

**规则**：若一组年份互为主要离群值，取"偏离其余年中位数幅度最大"的那一年为真离群，
其余标为 `mirror-of-*` 并记录 `mirror_of_year`，**mirror 不计入证据数**。
只有在偏离幅度 ≥ 1.5×tol 且次者 < 0.5×主者时才降级，避免误伤两个都真异常的情形
（例如 2024、2025 连续两年都高）。

## 5. 年度判级

汇总所有位置的证据到年份：

| 判级 | 条件 |
|---|---|
| `anomaly` 异常 | 决定性证据 ≥1；或稳健证据 ≥2；或稳健 ≥1 且占参与位置 ≥20% |
| `relevant` 关注 | 稳健证据 =1 |
| `watch` 提示 | 该年整体水平偏移 `mean_abs_shift ≥ 10%` |
| `normal` 正常 | 无证据 |
| `insufficient` 样本不足 | 参与位置数 < `min_years` |

同时给出 `max_abs_shift`（该年最大"剔除该年后同期均值变化"）—— 这就是**异常年对均值的实际影响**。

## 6. 报告怎么写

必须包含三件事：

1. **判级表**：年份 / 判级 / 参与位置数 / 决定性证据数 / 稳健证据数 / 最大剔除后均值变化 / 整体水平偏移；
2. **逐位置证据表**：哪一周/哪一月、哪一年、该年值、其余年中位、偏离%、稳健 z、剔除该年后均值变化；
3. **一句明确声明**：所有年份均未被自动删除；是否剔除由研究者决定。

**不要写"因为异常所以剔除后重新计算了季节性"** —— 那是在隐藏决策。

## 7. 甲醇案例的实测结果（供对照）

周度口径（52 个位置，2022 W33 起）：

| 年份 | 判级 | 证据特征 |
|---|---|---|
| 2022 | 异常（稳健 2） | W44/W46 显著低于其余年，且 2022 只有 20 周样本 |
| 2023 | 异常（决定 1 + 稳健 3） | W26–W30 深跌，W11 其余年一致而该年偏离 5% |
| 2024 | 异常（决定 1 + 稳健 5） | W20/W22 高、W02/W03 低 |
| 2025 | **关注**（稳健 1） | 8 月后持续低于其余年（W45–W51） |
| 2026 | **异常（决定 1 + 稳健 34）** | W12 起系统性高于其余年，W41 偏离 +89.9%，z≈11 |

月度口径下 2026 更清楚：10 个月里 9 个月是稳健离群，9 月偏离 **+83.5%**（z≈10.9）。

**关键读数**：2026 年在 W41 处价格 3,966.67，历史同期均值 2,481.5 ——
一个位置就把同期均值移动了 **−10.7%**（注意符号：这里 `shift=(mean_rest-mean_all)/mean_all`，
表示"剔除该年后均值会上升 10.7%"，即该年把均值向下压了）。

这类数字**必须写进报告**，因为读者需要知道"你给我的历史均值里，有多少是一年的故事"。
