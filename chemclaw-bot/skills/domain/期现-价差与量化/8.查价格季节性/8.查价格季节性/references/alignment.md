# 时间对齐规则（周次 / 月度 / 缺口 / 归一化）

对齐是所有结论的地基。对不齐，后面每个数字都是错的，而且错得很隐蔽。

---

## 1. 周度：必须用 ISO 8601 周，不能用自然周

**为什么**：自然周（一年第几个 7 天）会随年初星期几漂移。2024 年"第 1 周"可能是 1/1–1/7，
2025 年可能是 12/30–1/5 —— 拿它跨年比价，比出来的是**日历错位**，不是季节性。

**做法**：
```
ISO 年/周 = date.isocalendar()   -> (iso_year, iso_week, weekday)
x 轴位置  = ISO 周次 1..52
周值      = 该 ISO 周内【最后一个有报价日】的价格
```

- 位置用 **1..52**，表示"一年中的第几周"，与年份无关。
- 该周最后一个有报价日 = 该周内日期最大的那行（不是周内均值，也不是周一值）。
  选"最后一个"是因为它最接近"这一刻市场看到的价格"。
  **同时把周内均值、周内天数一起存下来**（引擎的 `period_mean` / `n_days`），
  方便事后核对"这个周值是不是被单日异常带偏了"。

## 2. ISO 第 53 周折叠进第 52 周

大约每 5–6 年会有一个 53 周年（2026 年就是）。若不处理，会出现一个只有个别年份才有的
第 53 个 x 位置，样本量永远为 1–2，图上多一根孤立柱子。

**做法**：`iso_week = min(iso_week, 52)`。
副作用：该年 W52 会包含 8 天数据（W52 + W53）。这是**有意的取舍** ——
宁可让 W52 略宽，也不要制造一个没有统计意义的位置。**必须在报告里说明**（见周次映射规则表）。

## 3. 春节 / 长假

春节、国庆所在的那一周，报价日可能只有 1–3 天（或整周停市）。这会带来两个问题：

1. **周值代表性下降**：3 天价格当 1 周用，波动被低估或高估。
2. **春节在公历上的漂移**：2024 春节 2/10、2025 春节 1/29、2026 春节 2/17，
   对应 ISO 周分别是 W06、W05、W08 —— **同一"春节效应"落在不同周次**。
   所以在周度口径下，春节效应会被摊薄，**不会**集中在某一个 x 位置上。

**处理原则**：
- **不剔除、不补造**。停市日不当作数据缺失（对照 `data/cn_market_holidays.txt` 扣除）。
- 该周报价日数一并记录，读者可自行判断。
- 若研究主题本身就是"春节前后"，正确做法是改 `config.json` 把窗口切到春节前后几周，
  **并改用"相对春节的偏移周数"作为 x 轴**（这不是本 skill 的默认口径，需要单独实现）。

## 4. 月度

`x 位置 = 1..12`；`月值 = 该月最后一个有报价日`。
另存 `月内天数`、`月内均值`，便于核对。

月度的好处是抗噪、样本更稳；坏处是**会抹平月内转折**
（例如某月先跌 8% 再涨 8%，月末价与月初一样，月度口径完全看不出来）。
所以默认**周度、月度两套都给**，并在报告里说明二者视角差异。

## 5. 缺失值：留空，绝不留 0、绝不插值

- 某年该位置没有任何报价 → 该格 **留空**，并记进 `years_missing`。
- 该位置的有效年数 `n` 随之变小。
- `n < min_years`（默认 3）→ 标记 `样本不足`，**不参与形态判断**，页面上用灰色/警示色显示。

**为什么这条最严格**：插值会把"没发生的事"变成看起来像观测的数字。一旦进入分位计算，
它就在偷偷改变 p10/p90，而读者完全看不出。宁可缺，不可编。

## 6. 归一化（年初 = 100）

**目的**：把"年份之间价格水平不同"从形态里剥离出来，只看年内节奏。

**做法**：
```
基准 = 该年窗口内【第一个有效观测】的价格
归一化值 = 价格 / 基准 × 100
```

**为什么不用 1 月 1 日插值**：1/1 是法定假日，根本没有报价。
硬插一个值等于在基期就引入人造数据，整条归一化曲线都会被这个假基期带偏。
用"第一个真实观测"则每个点都真实。

**注意**：
- 基准日各不相同（可能是 1 月 2 日，也可能是 1 月 5 日），报告里必须把**每年基准日与基准价**列出来
  （Excel「07 归一化面板」前四列就是干这个的）。
- 归一化只消除基期差，**不消除**真实的基本面差异。若某年全年单边上涨、
  另一年全年单边下跌，两条归一化曲线的形态差异是**真实的**，不是噪声。

## 7. 窗口（只做某段时间时）

`config.json` 里：
```json
"window": { "start_iso_week": 1, "end_iso_week": 52 }
```
做季度就把起止改成 1..13；做"年初到当前"就设 `end_iso_week` = 当前年最新周。
**窗口必须对所有年份一致**，否则不是同期比较。
