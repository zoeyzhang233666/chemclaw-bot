# 交付前检查清单

逐项打勾，任何一项"否"都不许交付。

---

## A. 口径与诚实性（最重要）

- [ ] 需求口径与实际口径**都**写出来了，且在报告第一屏
- [ ] 若发生降级：写明了**原因**、**影响**、**该口径不能推什么**
- [ ] 数据标签里**没有**把全国价/基准价写成区域现货价
- [ ] 申请年数 vs 实际覆盖年数 都写了（例："申请 10 年，实际覆盖 5 年"）
- [ ] "完整年份"的口径正确：当前年未走完时**不计入**完整年份，且与覆盖表一致
- [ ] 首屏有 **"历史已实现季节性、非预测"** 声明（HTML + Excel 封面各一处）

## B. 数据

- [ ] 每条报价都能点回原文（`source_url` 齐全）
- [ ] 做过独立重抓比对（同样的抓取再跑一次，逐行比价差异 = 0）
- [ ] `|Δ|>8%` 的跳变已逐条回原文核实，并定性为"源数据跳变"或"解析错误"
- [ ] 工作日缺报已列出，停市日已按 `cn_market_holidays.txt` 扣除
- [ ] **没有**任何插值、前值填充、补造数字
- [ ] 重复日期已识别并计数

## C. 对齐

- [ ] 周度用 ISO 8601 周，ISO 第 53 周已折叠进第 52 周
- [ ] 周值 = 该周最后一个有报价日（同时存了周内天数/均值）
- [ ] 所有年份用**同一个窗口**（同一起止位置）
- [ ] 归一化基期 = 该年第一个**真实**观测（不是 1/1 插值），且报告列出了每年基准日与基准价
- [ ] 春节/长假周已标注，且说明了处理方式（不剔除、不补造）

## D. 统计

- [ ] 分位用经验分位线性插值（与 Excel `PERCENTILE.INC` 一致），`selftest.py` 已验
- [ ] 每个同期位置都带 `n`（样本年数）
- [ ] `n < min_years` 的位置标记为"样本不足"
- [ ] 均值与中位数**并列**给出，并在 `|均值−中位| > 15%` 时高亮
- [ ] 给了季节性强度 R² 及其解读（不是只给图）
- [ ] 当前年分位/排名**剔除了当前年本身**
- [ ] 若两处"历史样本"口径不同（如统计表含当年、位置表不含当年），**两处都明确标注**

## E. 异常年

- [ ] 逐位置做了离群检验（不是只看全年整体）
- [ ] 独占极值年没有产生伪证据
- [ ] `mad=0` / 全同年份 已正确处理（无 `inf`、无误报）
- [ ] mirror 情形已处理（正常年没有被标成异常）
- [ ] **没有任何年份被自动删除**，且报告里明确写了这一点
- [ ] 给出了"剔除该年后均值变化"的量化

## F. HTML

- [ ] 零外链资源，双击可开（离线可用）
- [ ] `qa_html.py` **0 失败**
- [ ] 无 JS 报错、无 console error
- [ ] 主图真的画出了像素（分位带 polygon ≥2、曲线 path ≥3）
- [ ] 频率切换（周/月）、视图切换（绝对/归一化）、年份开关 都真的能用
- [ ] 悬停 tooltip 显示**具体年份 + 数值**
- [ ] **每条图内曲线都有图例**（曾出现图例只写 4 项而图上画了 7 条线）
- [ ] 配色里**任意两条年份线不同色**，且当前年独占暖色
- [ ] Y 轴刻度是 1/2/5×10^k 的整数（不是 2,840 / 3,368 这类怪数）
- [ ] 1600 / 1280 / 420 三档都无横向溢出
- [ ] 长表有滚动容器 + 表头吸顶（sticky）

## G. Excel

- [ ] 13 张表齐全
- [ ] 统计列是**真公式**（不是写死的数），且直连面板
- [ ] `check_xlsx.py` **0 失败**，特别是"公式重算值 = 引擎"那一项
- [ ] 用 LibreOffice `recalculate` 后核对过重算值（**`IFERROR` 会吞掉 `#VALUE!`，
      只检查"有没有公式"是查不出来的**）
- [ ] 分位公式用 `_xlfn.PERCENTILE.INC` 或外层套裸 `PERCENTILE` 兜底
- [ ] 日度表行数 = 原始 CSV 行数
- [ ] 缺口表列出了所有不可得的口径
- [ ] 无预测类禁用词（预计涨/看涨看跌/抄底/底部已现…）

## H. 回复用户

- [ ] 给了两个附件的绝对路径
- [ ] 给了 3–5 句**事实摘要**（覆盖几年、这一周历史区间、今年第几分位、哪些年份异常）
- [ ] 给了**缺口清单**
- [ ] 摘要里**没有**方向判断，没有"预计/建议/可以抄底"
- [ ] 没有在回复里重写整份报告

---

## 常见返工原因（按出现频率）

1. **Excel 公式静默失效**：裸 `PERCENTILE.INC` → `#VALUE!` → 被 `IFERROR` 吞掉 → 空白页。
   必须核对重算值。
2. **图例与图不符**：加了新曲线忘了加图例项、或调色板撞色。
3. **当前年口径混乱**：一处含当年、一处不含，却没标注。
4. **banner 与明细表矛盾**：banner 说"完整 4 年（含当前年）"，覆盖表说当前年"部分覆盖"。
5. **prompt 残留进成品**：把"必须按'全国基准价'表述，不得写成'华东现货'"这种
   内部指令写进了给用户的 banner。**交付前搜一遍有没有 "必须" / "不得" 这类指令式措辞。**
