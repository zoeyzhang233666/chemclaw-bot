# 数据源：逐渠道可用性与踩坑记录

> 本文件记录的是**实测结果**，不是"应该有"。可用性会变，用前先探活。

---

## 1. 生意社 100ppi 基准价频道 —— ✅ 首选免费源

**拿到什么**：日频"生意社XX基准价"，每条是一篇文章，正文含一句
`生意社甲醇基准价为 N 元/吨`。

**URL 模式**
```
https://me.100ppi.com/news/list--1217-{page}.html
```
`1217` 是甲醇的频道号（不同品种需换号）。列表页倒序（越新的在前面），
翻到没有新日期为止。

**解析**
```python
re.compile(r'生意社甲醇基准价为([\d,]+\.?\d*)\s*元/吨')
```

**优点**
- 完全免费、无需登录；
- 每条报价都有原文 URL，可逐行追溯（这是最值钱的一点）；
- 覆盖多年，本次一次翻 37 页拿到 2022-08-17 → 2026-10-20 共 1083 条。

**坑**
- 只给**全国基准价**，**不是**区域价。想要"华东/太仓"必须另找（见下）。
- 文章发布时间与"基准价日期"可能差一天，要取正文里的价格、用文章的计价日
  （脚本里存了 `publish_date` 供核对）。
- 页面有"会员"内容与广告，正则要锚定"基准价为"避免误抓无关数字。

## 2. 新浪财经 期货 K 线 —— ✅ 首选免费期货源

**拿到什么**：按合约的日线 OHLC + 持仓量。

**接口**
```
https://stock2.finance.sina.com.cn/futures/api/jsonp.php/var%20_x=/InnerFuturesNewService.getDailyKLine?symbol=MA2701
```
返回 JSONP，包一层 `var _x = (...)`，剥壳后是 `[日期, 开, 高, 低, 收, 成交量, 持仓]` 数组。

**主连拼接**：逐合约抓 → 按**持仓量最大**选主力 → 换月日志留痕
（`scripts/fetch_contract_history.py` 里的 `build_main_continuous()`）。

**坑**
- 单合约只有上市到摘牌之间（约 1–1.5 年），要拿 10 年必须抓很多合约再拼。
- **换月会产生人造跳空**（不同合约价差），做季节性前必须处理：
  要么用主连并**在换月日记录价差**，要么改用某个固定远月合约（但流动性差）。
  现货口径没有这个问题 —— 这也是现货更适合做季节性的原因。

## 3. 隆众（OilChem / dc.oilchem.net）—— ❌ 需登录/付费

- `queryPricePage` 需要参数：`varietiesId, twoLevelBusinessType, businessType, pageNum, pageSize`，
  参数齐了也常返回 `{"status":"400","message":"未查询到指标"}`。
- 登录态缺失时返回占位符 `dataValue: "-"`。
- 曲线接口 `queryCurveData` / `queryCurve` 返回空。

**结论**：华东/太仓现货 10 年日度**拿不到**。探 2 轮、确认是登录/付费门槛后即停止，
**不要**反复试或试图绕过。

## 6. 交易所库存/仓单

郑商所接口曾返回 HTTP 412。本 skill 的产物不依赖库存数据（季节性只看价格），
所以不作为必需项；如需，在缺口表写明未取得。

## 渠道优先级（找新数据时的顺序）

1. 该品种的**免费行业资讯日更**（生意社/化工网/我的钢铁等）—— 优先找"基准价/指导价"栏目；
2. **期货 K 线**（有场内期货时）—— 免费、可交叉验证；
3. **期货公司日报/月报** —— 常同时给现货均价 + 基差 + 分工艺利润，一条顶三条；
4. 协会/交易所周报 —— 供需与库存，不能替代价格；
5. 付费终端 —— 明确记为缺口，不要用近似值顶替。

## 口径六项（每条价格都必须能填满）

`数值 · 规格 · 地区 · 含税与否 · 数据日期 · 来源`

缺任一项 → 不能进价格表，只能进"数据缺口"。

## 本次实测：华东甲醇现货的口径降级

| 项目 | 内容 |
|---|---|
| 需求 | 华东地区（太仓/张家港）甲醇现货价格，10 年，周度 + 月度 |
| 免费渠道可得 | ❌ 隆众、卓创均需付费/登录 |
| 实际取得 | ✅ 生意社甲醇基准价（**全国口径 · 含税 · 交易指导价**，元/吨） |
| 覆盖 | 2022-08-17 → 2026-10-20，1083 个自然日报价点，5 个年份 |
| 该口径能用来做什么 | 全国价格水平的年内季节形态、当前年相对历史同期的高低 |
| 该口径**不能**用来做什么 | 区域价差、太仓/华东交割地贴水、跨区套利空间 |

**处理方式**：保留分析，首屏声明降级，全篇不出现"华东现货"作为数据标签；
标题用"华东甲醇现货价格季节性"标明**研究意图**，口径栏写明**实际口径**全国基准价。

> 这是本 skill 的核心纪律：**宁可交一份口径降级但诚实的报告，
> 也不交一份口径写着"华东现货"、数据其实是全国价的报告。**
