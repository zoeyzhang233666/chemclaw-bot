# 02 · 开工率序列构建与时点纪律

## 1. 从原文到序列：四步校验

```
原文 → 解析 → 单位/口径归一 → 时点化 → 校验
```

### 1.1 解析校验（拒绝而不是猜测）

解析器必须做**三方一致性检查**，任一不通过就丢弃该期并记入 gaps：

```python
# 总量应当落在工艺路线区间内
assert min(cwe_pct, eth_pct) <= util_total <= max(cwe_pct, eth_pct)
```

PVC 案例：`68.30%` 在 `71.94%`（电石法）与 `59.82%`（乙烯法）之间 ✅。
若不在区间内，通常说明正则抓到了错误的句子（例如抓到了"环比增加"后面的数），
此时**宁可丢弃**，不要挑一个看起来合理的。

### 1.2 单位归一

- 百分比统一成 `68.30`（不是 `0.683`），列名后缀 `_pct`
- 变化量统一成**百分点** `chg_pp`（不是相对变化的 `%`）
- 产能统一成万吨/年 `capacity_base_wt`

> 变化量的两种写法极易混淆：`环比增加 0.08%`（相对）与 `环比增加 0.08 个百分点`（绝对）。
> 资讯机构正文多用前者表示后者，需按上下文判断，并在报告中写明采用哪一种。

### 1.3 时点化（本 Skill 最核心的一条）

```python
# 因子可用的最早交易日 = 公布时间之后的第一个交易日
base_date = 严格晚于 pub_ts 的第一个交易日
```

实现要点：

| 情形 | 处理 |
|---|---|
| 发稿于交易日 18:30（收盘后） | 次日为基期 |
| 发稿于交易日 15:00（收盘时） | 次日为基期（收盘价已定，当日不可用） |
| 发稿于非交易日 | 下一个交易日为基期 |
| 发稿于交易日 09:00（开盘前） | 当日为基期（当日收盘价尚未形成） |

> 保守起见，**默认一律取严格晚于发布时间的下一个交易日**。PVC 案例采用这一保守规则，
> 2026-09-04 09:52 发布 → 基期 2026-09-07；2026-10-16 发布 → 基期 2026-10-19。

### 1.4 校验清单

- [ ] `pub_ts` 全部非空且带时区
- [ ] `stat_week_end` 严格递增、无重复
- [ ] 相邻周 `stat_week_end` 相差 7 天；若有跳周，记入 gaps
- [ ] `util_total` 全在 (0, 100) 内
- [ ] 基期日子严格大于 `pub_ts` 日期

## 2. 缺失与跳周

三档处理，**不得混用**：

| 情况 | 处理 | 报告写法 |
|---|---|---|
| 单周缺失 | 该期因子置空，前后期不插值 | 「YYYY-MM-DD 一期缺失」 |
| 连续 2–3 周缺失 | 该段窗口整体作废 | 「YYYY-MM-DD 至 YYYY-MM-DD 不可用」 |
| 长期缺口（≥4 周） | 视为两个独立样本段 | 分段统计，不拼接 |

**绝对禁止**：
- 线性插值补齐周度开工率
- 用月度产量倒推开周度开工率
- 从第三方图表上数字读出历史开工率
- 用"行业普遍认知"填一个合理值

理由：开工率因子的全部信息在于**小幅度变化**（±1 个百分点量级），
插值出来的曲线会把真实变化抹平，同时又给样本量虚增，直接破坏后续所有统计推断。

## 3. 节假日与统计周期

开工率的统计周期通常是"上周五至本周四"，遇到法定节假日会出现：

- **周期变短**（例如春节周只有 3 天）→ 开工率机械性下降
- **周期错位**（发布方改成"上月同期"）→ 与前后期不可比

处理：

1. 在 `window` 列保留原文声明的区间；周期长度 ≠ 7 天的期数打标 `irregular=1`
2. 分组统计时，**把不规则周期单独列一组**，或整段剔除
3. 若样本量本来就小（< 30），不规则周期必须剔除，不能"留着凑数"

## 4. 价格序列

### 4.1 期货连续合约的拼接规则

自行拼接连续合约时，换月规则必须写死并可复现。PVC 案例采用：

```
当另一合约满足以下全部条件时换月：
  1) 该合约成交量 > 当前合约成交量 × 130%
  2) 该合约到期日晚于当前合约
  3) 该合约交割月份 > 当前合约交割月份
```

同时保留 `roll_flag` 列，并在报告中披露换月次数（PVC 案例：2044 个交易日、103 个合约、24 次换月）。

> ⚠ 换月当天收益率会混入价差跳变。正确做法是用**复权价**计算收益；
> 本案例 `adj_close` 已按换月价差调整。

### 4.2 现货价格

现货口径必须写明：**地区 + 规格 + 含税/不含税 + 是送到价还是出厂价**。
不同地区价差常有 100–300 元/吨，混用会让"涨跌方向"都出错。

### 4.3 收益定义

```python
# 未来 h 个交易日的收益率
fwd_ret = adj_close[t + h] / adj_close[t] - 1
```

- 一律用**对数收益或简单收益中的一种**，全篇统一
- 基期 `t` 取第 1.3 节的 `base_date`
- `t + h` 必须真实存在；数据不足则置空，**不得用最后一个可用价代替**

## 5. 最小可用样本的标准（立项时就该算）

| 目标 | 最少期数 | 说明 |
|---|---|---|
| 报分布描述（中位数、四分位） | 10 期/组 | 只能描述，不能推断 |
| 显著性的基本要求 | n_eff ≥ 30 | 否则只报"不可检验" |
| 分位因子可用 | 前 52 期作历史 | 所以总期数 ≥ 52 + 30 |
| 跨年度稳定性 | 每年 ≥ 12 期 | 即至少 3 年 |

PVC 案例只有 7 期 → **所有单元均判"不可检验"**，这正是正确结论。
详见 `04-grouping-and-inference.md` 的功效计算部分。
