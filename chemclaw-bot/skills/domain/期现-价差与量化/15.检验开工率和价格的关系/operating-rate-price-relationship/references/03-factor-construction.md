# 03 · 三族因子构造与未来收益对齐

## 1. 为什么必须是三族

单看一个因子定义，无法回答"是开工率本身没信息，还是我把它切错了"。所以固定三族同时跑：

| 族 | 因子 | 经济含义 | 分组方式 |
|---|---|---|---|
| **绝对水平**（F1） | `util_total` | 当前供给是否紧张 | 固定绝对阈值 |
| **周度变化**（F2） | `util_total[t] − util_total[t−1]` | 供给在放松还是收紧 | ±阈值 |
| **历史分位**（F3） | expanding 分位 | 相对自身历史高不高 | 三分位 |

> **不允许事后只挑表现最好的那一族写进结论。** 三族的全部结果都要出现在报告里，
> 包括全空、全不显著的那些。

## 2. F1 绝对水平

```python
level_bands = [65, 70, 75]        # 按品种历史区间定一次，之后锁定
```

分 4 组：`<65%`、`65–70%`、`70–75%`、`≥75%`。

**阈值怎么定**（只允许定一次）：

1. 取该品种**有意义的产业分界**（例如电石法盈亏平衡对应的开工水平），而非数据分位
2. 若没有产业常识可用，取近 3 年开工率分布的 25/50/75 分位，**四舍五入到整数**
3. 定完写进 `config.json`，此后所有窗口、所有子样本共用

> ⚠ 若数据只有几期，阈值定在哪都"看起来"能切出差异——这正是不该看结果定阈值的原因。
> PVC 案例沿用行业习惯的 65/70/75，与本样本的实际分布无关。

## 3. F2 周度变化

```python
chg_pp = util_total.diff()             # 百分点
chg_threshold_pp = 1.0
```

分 3 组：`下降 >1pp`、`持平 ±1pp`、`上升 >1pp`。

要点：
- 单位是**百分点**，不是相对百分比
- 阈值 1.0pp 对应 PVC 周度波动的常态量级；低于此的多数是统计噪声
- 样本调整造成的跳变（如产能基数变更）会污染 `chg_pp`，必须剔除该期

## 4. F3 历史分位（expanding）

```python
def expanding_pct_rank(s, min_periods=52):
    # 只使用 t 之前（含 t）的已公布样本
    return s.expanding(min_periods=min_periods).apply(
        lambda w: (w <= w[-1]).mean(), raw=True)
```

三条铁律：

1. **只用已公布样本**：`s` 必须是按 `pub_ts` 排序后的序列，不是按统计周期排序
2. **`min_periods` 必须披露**：PVC 案例设为 52，而实际只有 7 期 → **分位因子 0 行**，
   报告里必须明确写"历史不足，分位因子不可构造"，不能静默返回空表
3. **不得用全样本排名**：`s.rank(pct=True)` 是最典型的未来函数

分 3 组：`<33%`、`33–67%`、`>67%`。

## 5. 未来收益对齐

### 5.1 对齐算法

```python
# 输入：开工率序列 u（已按 pub_ts 排序）、价格序列 px（按交易日）
for each row in u:
    base = first_trading_day_strictly_after(row.pub_ts)     # 见 02 文档 1.3
    if base is None: continue
    fwd[5]  = px.adj_close[base + 5]  / px.adj_close[base] - 1
    fwd[10] = px.adj_close[base + 10] / px.adj_close[base] - 1
    fwd[20] = px.adj_close[base + 20] / px.adj_close[base] - 1
```

三个必须守住的不变量：

1. `base_date > pub_ts`（严格大于）
2. `fwd` 的结束日必须真实存在于价格序列
3. 因子值只用 `pub_ts ≤ 该期 pub_ts` 的信息

### 5.2 重叠窗口

1/2/4 周窗口在周频数据上**必然重叠**：相邻两期的 4 周收益共享 3 周。

后果：把 n 个观测当独立样本，会把标准误低估约 √(h) 倍，p 值虚假变小。

对策（三者同时用）：

| 方法 | 参数 | 作用 |
|---|---|---|
| HAC (Newey-West) | 带宽 = 窗口 − 1 | 修正自相关下的标准误 |
| 有效样本数 | `n_eff = n / (窗口/步长)` | 报告里用 `n_eff` 判断是否够 |
| 块 bootstrap | 块长 = ⌈窗口/5⌉，2000 次 | 不依赖正态假设的置信区间 |

PVC 案例的 `n_eff`：1w → 6.0、2w → 2.0、4w → 0.5。**4 周窗口的有效样本小于 1**，
这直接说明"4 周结论不可能可靠"。

## 6. 因子构造的产物表

`panel.csv` 每行一期，列包括：

## 7. 常见构造错误

| 错误 | 后果 | 正确做法 |
|---|---|---|
| 用 `s.rank(pct=True)` 算分位 | 未来函数，IC 虚高 | expanding |
| 用 `stat_week_end` 排序后直接对齐价格 | 基期早于公布日 | 按 `pub_ts` + 下一交易日 |
| 把 `diff()` 的百分点当百分比 | 量级错 100 倍 | 明确 `_pp` 后缀 |
| 用最后可用价代替缺失的未来价 | 系统性低估波动 | 置空 |
| 样本调整后继续 `diff()` | 跳变被当成真实变化 | 断点剔除 |
| 事后按结果挑分组阈值 | 样本内过拟合 | 阈值先锁定 |
