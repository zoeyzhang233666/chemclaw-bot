# 04 · 分组统计、不确定性与功效

> 这一节决定了整个研究的诚实度。核心问题不是「显著吗」，
> 而是「**这个样本量，本来能检出多大的效应？**」

## 1. 每个单元必须报告的八个数

对「因子族 × 未来窗口」的每个单元：

| 项 | 含义 | 缺了会怎样 |
|---|---|---|
| `n` | 名义观测数 | 读者无法判断样本 |
| `n_eff` | 有效样本数 = n / (窗口/步长) | 重叠窗口被当成独立样本 |
| `mean` | 各组未来收益均值 | — |
| `median` | 中位数（抗尾部） | 小样本下均值不可靠 |
| `p25 / p75` | 四分位 | 只有均值会掩盖分布形态 |
| `MDES` | 最小可检测效应（以标准差为单位） | 无法区分"没关系"和"测不出来" |
| `prob_halfwidth` | 比例估计的 Wilson 半宽 | 分组占比本身的不确定性 |
| `verdict` | `ok` / `insufficient` | 唯一的结论开关 |

## 2. 分组统计函数

```python
def group_stat(values):
    v = [x for x in values if x is not None and not math.isnan(x)]
    if not v: return None
    return {
        "n": len(v),
        "mean": mean(v),
        "median": median(v),
        "p25": quantile(v, 0.25),
        "p75": quantile(v, 0.75),
        "sd": stdev(v) if len(v) > 1 else None,
    }
```

**空组必须保留在表里**（`n=0`，其余列空），不能因为空就删掉——
空组本身就是信息（"这个区间在这段历史里从未出现"）。

### 3.2 块 bootstrap（不依赖正态）

```python

for b in range(2000):
    # 环形抽取 ceil(n/block) 个连续块
    ...
# 取 2.5% / 97.5% 分位为置信区间
```

环形（circular）的含义：块可以从序列末尾跨到开头，避免末尾样本被系统性低估。

### 3.3 两样本检验

| 检验 | 用途 | 注意 |
|---|---|---|
| Welch t | 均值差异 | 方差不齐；小样本下仍偏乐观 |
| Mann-Whitney U | 分布差异 | 不受尾部影响；小样本最小 p 受 n 限制 |

> **小样本的残酷事实**：n=6 时，双侧 Mann-Whitney 的最小可能 p 约为 0.002（完全分离时），
> n=3 时无论怎么排都达不到 p<0.05。所以 n 太小时"检验"本身没有意义。

## 4. 功效：本研究最关键的一节

### 4.1 最小可检测效应

```python
MDES_sd = (z_alpha + z_beta) / sqrt(n_eff)      # z_alpha=1.96, z_beta=0.84 (80% 功效)
```

含义：**以标准差为单位**，这个样本量在 80% 概率下能检出的最小效应。
若 MDES = 1.14 sd，而真实效应只有 0.3 sd，那么"不显著"完全没有信息量。

### 4.2 比例估计的半宽

```python
halfwidth = 0.98 / sqrt(n_eff)                  # p=0.5 时 Wilson 半宽近似
```

含义：分组命中率的不确定性。半宽 31pp 意味着"上涨概率 60%"和"40%"无法区分。

### 4.3 达到常见效应所需样本

```python
n_needed_MDES_020sd = ((1.96 + 0.84) / 0.20) ** 2     # ≈ 197
```

即：想检出 0.2 个标准差的效应，需要约 **197 个有效样本**。
周频数据一年 52 期，4 周窗口下 n_eff = 期数 × 5/20 ≈ 期数/4，
所以需要约 **1576 周 ≈ 30 年**——这解释了为什么很多"开工率因子"研究实际上不可做。

### 4.4 PVC 案例的实际数字

| 窗口 | n_obs | n_eff | MDES (sd) | 比例半宽 (pp) | 判定 |
|---|---|---|---|---|---|
| 1 周 | 6 | 6.0 | 1.1437 | 31.24 | insufficient |
| 2 周 | 4 | 2.0 | 1.9810 | 40.55 | insufficient |
| 4 周 | 2 | 0.5 | 3.9620 | 47.03 | insufficient |

结论不是"开工率对 PVC 没用"，而是：
**「7 期数据只能检出 ≥1.14 个标准差的巨幅效应；任何温和效应都不可检验。」**

## 5. 相关性指标（辅助，不是主结论）

```python
IC = spearmanr(factor, forward_return)      # 秩相关，抗尾部
```

- 报告 IC 时必须同时给 p 与 n_eff
- 单因子 IC 在小样本下极不稳定，**不能作为唯一结论依据**
- PVC 案例仅 1w × F1 有有限 IC = +0.257143（p = 0.622787），
  这个 p 值本身就说明它没有信息

## 6. 判定规则（写死，不逐案通融）

```python
def verdict(n_eff):
    return "ok" if n_eff >= 30 else "insufficient"
```

n_eff < 30 时：

- 表格照常输出全部描述统计（让小样本的形态可见）
- **不输出** p 值作为结论依据，或输出但标注"样本不足，不作推断"
- 结论段统一写「数据不足，不可检验」，并给出所需期数

## 7. 报告里必须原样保留的句子

无论结果好坏，报告必须包含：

1. 「本研究的显著组数为 X / Y，BH-FDR(q=0.10) 后通过 Z 组」
2. 「纯噪声下，Y 个独立检验期望产生约 W 个名义显著（α=0.05）」
3. 「各单元的有效样本数 n_eff 与最小可检测效应 MDES 见附表」
4. 「以下区间不存在明确统计关系：……」（列具体日期）
5. 「以上为历史统计描述，不构成因果解释，也不构成任何交易建议」
