# 01 · 数据来源、口径与公布日历

> 开工率研究第一步永远不是算相关系数，而是回答四个问题：
> **它是什么口径？覆盖谁？什么时候公布？中间变过吗？**

## 1. 开工率的五种常见口径（不可混用）

| 口径 | 常见叫法 | 分母 | 数据来源 | 特点 |
|---|---|---|---|---|
| 产能利用率 | 开工率、产能利用率 | 名义产能（万吨/年，年化） | 资讯机构周报 | 最常用；分母变动会造成"假跳变" |
| 装置开工负荷 | 开工负荷率 | 有效运行能力 | 资讯机构 / 企业调研 | 更贴近实际产量，但样本变动更频繁 |
| 检修损失量反推 | 损失量、检修产能 | 总产能 | 检修计划表 | 前瞻性好，但依赖检修计划完整性 |
| 产量 / 产能 | 实际产量口径 | 同期天数归一 | 统计局、协会月报 | 频率低（月），公布滞后 2–4 周 |
| 装置数开工比 | 开车装置数 | 装置总数 | 企业公告 | 样本极分散，口径常变 |

**规则：一个研究里只用一个口径。** 换口径必须写成两个独立研究，不能拼成一条序列。

## 2. 必记字段（每期一行，缺一不可）

```csv
stat_week_end,window,pub_ts,util_total,cwe_pct,eth_pct,chg_pp,yoy_pp,sample_n,capacity_base_wt,url,title
2026-09-03,"20260828-0903",2026-09-04T09:52:07+08:00,68.30,71.94,59.82,0.08,-8.83,71,2878.5,https://...
```

- `stat_week_end` 统计周期**结束**日（不是发稿日）
- `window` 原文声明的统计区间，例如 `20260828-0903`（上周五至本周四）
- `pub_ts` 页面显示的**真实发布时间**，带时区
- `sample_n` 样本企业家数（含厂区时注明）
- `capacity_base_wt` 产能基数（万吨/年）
- `url` 原文链接（可复核）

## 3. 公布日历的确定方法

按优先级三条证据，缺一条就降级：

1. **原文时间戳**（页面 `publish` 字段）——首选，直接写入 `pub_ts`
2. **URL 日期码**——很多资讯站 URL 内含 `YYMMDD`，可作交叉验证
3. **行业惯例**——多数机构周四出上周五至本周四的统计，周五或下周一发稿

> ⚠ **同日公布也是可能的。** 本 Skill 的 PVC 案例中，2026-09-24、10-01、10-08 三期的发稿时间与
> 统计周期结束日是同一天（18:30 / 15:00 / 17:56）。此时不能用「公布日晚于统计日」作为校验条件，
> 而必须依赖「取公布时间之后**第一个**交易日收盘」这条规则来保证时点纪律。

## 4. 来源可达性实测（PVC 案例）

| 来源 | 可达性 | 结果 |
|---|---|---|
| `mysteel.com/oilchem` 转载的隆众周报 | ✅ 可达 | **唯一可用**：7 期，含总开工率 + 工艺路线拆分 |
| `api.mysteel.com` | ❌ `SSLEOFError` / 502 | 不可用 |
| `dt.oilchem.net` | ❌ 返回 `10010 user无权限` | 需付费账号 |
| `www.mysteel.com/oilchem/article/...` 旧路径 | ❌ 反爬「安全验证」 | 不可用 |
| 月度产量（统计局 / 协会） | ⚠ 只有零散两条 | 频率太低，不能替代周频开工率 |

**结论：一个品种能拿到多少期开工率，决定了这项研究能不能做。** 拿不到就写进 `gaps.json`，
不得用产量、图表数字化、插值或"行业感受"补齐。

## 5. 抓取脚本用法

```bash
# 1) 先单周探测，确认能解析
python scripts/fetch_utilization.py --probe 2026-10-15 --slug-map raw/slugs.json

# 2) 批量抓取（幂等，已存在的周会跳过）
python scripts/fetch_utilization.py --site mysteel_oilchem \
    --start 2026-09-01 --end 2026-10-20 \
    --out data/util_weekly.csv --gaps raw/util_gaps.json
```

`--slug-map` 是 `{"2026-10-15": "4CFEE19A39BC452A"}` 形式的文章码映射。
文章码不可推导，需从站内列表或搜索引擎取得后固化——旧文章码长期有效。

抓完后**必看** `gaps.json`：每一条都是报告里必须披露的缺口。

## 6. 原文措辞与解析对应

同一条指标在不同周可能有两种体例，解析器必须都认：

**体例 A（带工艺路线拆分）**
```
本周PVC生产企业产能利用率在68.30%，环比增加0.08%，同比减少8.83%；
其中电石法在71.94%，环比增加2.44%，同比减少4.79%，乙烯法在59.82%，环比减少5.43%，同比减少18.32%。
```

**体例 B（只有总量）**
```
截止2026年9月10日，中国PVC产能利用率在69.89%，较上期+1.58%。
```

注意两处陷阱：
- 统计区间写在**标题**里（`（20260828-0903）` 或 `(20260910）`），正文里没有 → 解析必须同时看标题
- 标题的左括号可能是 ASCII `(`、右括号是全角 `）` → 左右括号要分别匹配

## 7. 样本调整：必须记录、必须断点

PVC 案例中的真实调整：

> 从 8 月 1 日开始，甘肃金川新融 20 万吨产能退出样本，全国 PVC 产能基数变更为 2878.5 万吨/年。

处理规则：

1. 调整前的期数与调整后的期数**不做无缝拼接**，中间标注断点
2. 若样本量足够跨越调整，做两组：全样本 + 仅调整后子样本，并披露差异
3. 若样本量不足（如本例只有 7 期），在报告中**明确写出这个调整存在，且影响无法估计**
4. 产能基数变化会直接造成开工率跳变，**不能**把跳变当成"开工率下降"来解释价格

## 8. 频率选择

| 数据频率 | 支持的未来窗口 | 备注 |
|---|---|---|
| 周频（主流） | 1 / 2 / 4 周 | 本 Skill 默认 |
| 日频（装置级） | 1 / 5 / 20 日 | 需自建，成本高 |
| 月频（统计局） | 1 / 3 / 6 月 | 样本量增长极慢，建议 ≥ 8 年 |

周频数据一年只有 52 期；扣掉分位数所需的历史窗口（52 期），
**想做分位因子至少要 3 年历史**。这一点必须在立项时就说清。
