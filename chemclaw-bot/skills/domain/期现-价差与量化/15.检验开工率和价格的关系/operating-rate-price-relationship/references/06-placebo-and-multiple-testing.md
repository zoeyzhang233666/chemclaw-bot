# 06 · 安慰剂检验与多重检验校正

## 1. 为什么必须做安慰剂

开工率与价格都有季节性（冬季限电、春季检修），简单的随机打乱会**低估**真实数据的自相关，
从而**高估**显著性。安慰剂检验给出"如果没有关系，我们能看到的显著性上限"。

## 2. 年度内循环平移（首选）

```python
def placebo_test(panel, runs=2000, seed=42):
    rng = np.random.default_rng(seed)
    hits = 0
    for _ in range(runs):
        shifted = annual_circular_shift(panel)   # 年内平移，保留季节性
        if abs(ic(shifted)) >= abs(observed_ic):
            hits += 1
    return hits / runs
```

**年度内**的含义：只在同一年内平移，不跨年，这样季节相位不被打乱。

PVC 案例 2000 次后，所有单元的安慰剂 p 均为 1.0（因为只有 7 期、年内平移几乎没有自由度），
这本身就是"样本太少"的另一个证据。

## 3. 其他两种安慰剂（补充）

| 方法 | 做法 | 适用 |
|---|---|---|
| 全样本循环平移 | 整段平移任意周期 | 无季节性时更简单 |
| 相位随机化 | 随机重排各年内部顺序 | 破坏趋势、保留季节位置 |

> 三种方法结论应大致一致。若差异大，说明结果由少数点驱动，**应以最保守的为准**。

## 4. 多重检验：BH-FDR

同时检验「因子 × 窗口」共 M 个单元，未校正时假阳性率 = 1 − (1−α)^M。
PVC 案例 M = 6（F1/F2/F3 × 1w/2w... 实际有效单元数 6），α=0.05 下期望假阳性约 0.26 个。

```python
def bh_fdr(pvals, q=0.10):
    order = argsort(pvals)
    m = len(pvals)
    # 逐步校正
    for i, idx in enumerate(order):
        if pvals[idx] <= (i + 1) / m * q:
            cutoff = i
    return adjusted_q
```

报告里必须给出：

1. **名义 p**（未校正）
2. **BH q**（校正后）
3. **通过数 / 总检验数**（例如 `0 / 6`）
4. **纯噪声期望显著数** = M × α（例如 0.3 个）

> 若「通过数 0」而「期望 0.3」，说明什么也没发现，与纯噪声无法区分——这是诚实结论。
> 反过来说，如果名义显著 2 个、期望 0.3 个，才值得进一步看。

## 5. q 值门槛的选择

| q | 适用场景 | 风险 |
|---|---|---|
| 0.05 | 确证性研究 | 严格，小样本几乎不可能通过 |
| 0.10 | 探索性研究（**本 Skill 默认**） | 略宽松 |
| 0.20 | 筛选候选因子 | 假阳性多 |

改 q 必须在报告里写明理由，且**同时给出 q=0.05 与 q=0.10 两列**。

| … | … | … | … | … | … | … | … | … |

汇总句：

> 全部 6 个单元的有效样本数介于 0.5–6.0，最小可检测效应 1.14–3.96 个标准差，
> BH-FDR(q=0.10) 后通过 0 组；纯噪声下期望名义显著约 0.3 组。
> **因此本样本无法区分"开工率与价格无关"与"开工率与价格有关但效应小于可检出下限"。**

## 7. 禁止事项

- ❌ 只报名义 p，不报 q
- ❌ 只报通过 FDR 的那几组，不报总数
- ❌ 反复换安慰剂方法直到出现想要的结果
- ❌ 用"机制上应该有关系"作为不显著结果的补救说明
- ❌ 在样本不足时用 p 值说"接近显著"（n_eff<30 时 p 值本身不可信）
