# 05 · 稳定性：年度切片、工艺路线、市场阶段

> 一个只在某一年成立、或在某条工艺路线上成立的关系，
> 不能当成"开工率与价格的关系"来用。

## 1. 年度稳定性

```python
for year, grp in panel.groupby(panel.base_date.dt.year):
    if len(grp) < 12: 标记 "样本不足"
    else: 计算该年各因子各窗口的分组统计
```

判据：

| 现象 | 结论 |
|---|---|
| 每年方向一致且幅度接近 | 可称"稳定" |
| 方向一致但某几年幅度差 >2 倍 | "方向稳定、强度不稳" |
| 至少一年方向相反 | **"不稳定"**，必须以最弱的一年为准 |
| 多数年份样本 <12 期 | "年度稳定性不可评估" |

PVC 案例：7 期全在 2026 年 → 只有 1 个年度 → **年度稳定性不可评估**。
报告中必须原样写出这句，不能因为"看起来一致"就说稳定。

## 2. 工艺路线稳定性（本 Skill 的特色要求）

同一品种不同工艺路线的成本曲线不同，开工率对价格的含义可能**方向相反**。

### 2.1 PVC 的两条路线

| 路线 | 原料 | 成本敏感变量 | 占比 |
|---|---|---|---|
| 电石法 | 电石（兰炭 + 电力） | 电价、兰炭价 | 中国主流，约 75–80% |
| 乙烯法 | 乙烯 | 原油 / 乙烯单体价 | 约 20–25% |

推论（机制假设，需数据检验）：
- 电石法开工下滑 → 通常是**成本倒逼减产**，若需求不变则价格**偏强**
- 乙烯法开工下滑 → 可能是**进口乙烯到货或检修**，含义不同

因此**合并样本可能互相抵消**，表现出"总开工率与价格没关系"。

### 2.2 检验方法

```python
# 路线差值因子：电石法 − 乙烯法
route_spread = cwe_pct - eth_pct

# 1) 两条路线各自的分组统计（若有足够样本）
# 2) 路线差值作为独立因子（f4）
# 3) 报告两者方向是否相反
```

PVC 案例的 7 期中，路线数据可用 5 期，`f4` 为 `−1.11% / +3.03% / NaN / NaN / NaN`，
前两期方向相反——**但 2 个点不足以说"方向相反"**，只能记录现象。

### 2.3 报告写法（必须区分三档）

| 情况 | 写法 |
|---|---|
| 两路线都有足够样本且方向相反 | "工艺路线分化明确：A 路线 X 组偏强、B 路线相反" |
| 样本不足 | "路线拆分数据可用 N 期，不足以分别检验；记录到路线差值存在" |
| 完全无路线数据 | "该品种公开数据不含工艺路线拆分，无法检验" |

## 3. 市场阶段稳定性

把样本按价格自身的状态切段，看关系是否只在某些阶段成立。

### 3.1 三种分段方式

| 方式 | 定义 | 用途 |
|---|---|---|
| 趋势阶段 | 20 日均线上/下 | 上涨市 vs 下跌市 |
| 波动阶段 | 20 日已实现波动的中位数上下 | 平静 vs 动荡 |
| 价格水位 | 价格自身的 expanding 分位 | 高位 vs 低位 |

### 3.2 谨慎之处

价格阶段本身是**用未来信息构造**的（例如用全样本中位数分波动阶段），
必须改用 expanding 版本，否则又引入未来函数。

PVC 案例因样本太少，阶段表基本为空——这是正确结果，报表明细保留空行以体现"尝试过"。

## 4. 同向性检验（cross-check）

检验"开工率变化方向"与"同期价格变化方向"是否一致：

```python
same_time_corr = spearmanr(chg_pp, same_period_return)
```

作用：如果**同期**都没有关系，那么谈"之后的关系"就更缺乏基础。
若同期关系显著而之后不显著，说明信息已经被同期价格吸收——这是一个有价值的结论。

## 5. 月度交叉验证

用频率更低的独立数据（例如月度产量、协会开工率）做交叉验证：

| 目的 | 做法 |
|---|---|
| 检验周频结论是不是噪声 | 月度序列独立算一次，看符号是否一致 |
| 补足样本量 | 月度序列历史通常更长 |

⚠ 但**不能说"周频不够就用月度替代"**：口径、频率、覆盖范围都不同，
月度只能作为**旁证**，不能填进周频序列。

PVC 案例的月度产量文件只有表头（无数据），因此月度交叉验证一节为空，
报告里明确写"月度数据不可得"。
