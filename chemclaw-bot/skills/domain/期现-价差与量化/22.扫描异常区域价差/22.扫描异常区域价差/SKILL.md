# 扫描异常区域价差

回答一个问题：**这个品种在各个区域市场之间，哪些地区组合的价差现在明显偏离过去的区间？**

并且严格区分三件事，不许混：

1. **裸价差**——两个地区报价直接相减，只是数字；
2. **扣除运费后的参考差异**——必须用用户给的真实运费，按方向扣，扣完仍只说「参考差异」；
3. **套利机会**——本 Skill **不判断**。价差是否为机会取决于资金成本、损耗、账期、资质、库容与执行摩擦，这些不在数据里。

---

## 何时用 / 何时不用

**适用**：用户给了品种（或产品池）+ 想看的区域范围，问哪个区域偏离、价差多大、扣运费还剩多少、哪些地区组合需要注意。

**不适用**：
- 只问一个地区、一个品种的绝对价格水平 → 用行情速览类的 Skill；
- 问期现基差、跨期、跨品种 → 用基差/价差类 Skill（本 Skill 只做**同一时点、同一品种、不同地区**）；
- 用户拿不到区域报价、只有一个全国均价 → 明确告知无区域维度，不做。

---

## 开工前必须问清的四件事（缺项就按默认并声明）

| 参数 | 说明 | 默认行为 |
|---|---|---|
| **产品池** | 一个或多个品种 | 用户没给就按 `references/产品池与标准问法.md` 的推荐池 |
| **地区范围** | 全国 / 某几个大区 / 某几个省 | 默认全部有数据的地区 |
| **历史窗口** | 3 / 6 / 12 / 24 / 36 个月 | 默认 **12 个月**，且必须声明实际能拿到的窗口长度 |
| **运费** | 按**方向**给的真实单吨运费 | **没给就不扣**，界面默认关闭，标 `FREIGHT_MISSING` |

运费这一项最容易出错：用户说「大概一吨两三百」不构成可靠报价，**不能**当真实数据用。
只接受：用户明确给出的方向 + 单价 + 运输方式（+ 是否含装卸）。

## 五条硬规则（违反即视为交付失败）

### 规则 1｜先统一口径，再谈价差

每个价格点必须集齐五要素：**规格 / 地区 / 交货方式 / 税费 / 计价类型**。
缺一项 → 判 `INCOMPARABLE`，只进缺口表，不进排行榜。详见 `references/口径统一与可比性规则.md`。

典型陷阱：
- 轻质纯碱 ≠ 重质纯碱；甲醇进口（太仓）≠ 国产（山东）；PVC 电石法 ≠ 乙烯法；
- 出厂价与送到价混算，等于把运费算进价差；
- 含税与不含税相差 13%，会让全部价差整体平移。

### 规则 2｜方向固定

`spread(A→B) = P_B − P_A`，A 为基准地区，方向在整个窗口内**不翻转**。
若「谁高减谁」，序列会在交叉点穿零，分位数永远落在中间，看不到异常。

### 规则 3｜异常以各自历史分布判断，绝不按金额排序

```
pct     = 中位秩分位(该组合自身窗口内序列, 当前值)
tail    = min(pct, 1 − pct)
anomaly = 1 − 2 × tail           # 0=居中, 1=历史极值
```

600 元/吨在西北—华南可能是常态，在沙河—河北却是极端值。
**排行榜主排序 = 异常度**，金额只作副参考。

### 规则 4｜没有真实运费就不估

- 未提供 → `freight_status = MISSING`，`net = None`，界面 banner 明示「未做扣除」；
- 提供 → 按方向分别扣：`net_AB = (P_B − P_A) − fee_AB`，`net_BA = (P_A − P_B) − fee_BA`；
- 运费给的是 `元/吨·公里` → 乘以真实公路里程（路由 API 实测，不是估算）；
- **禁止**用行业平均运费、吨公里经验值、「一般 200 左右」代替用户报价。

### 规则 5｜措辞纪律

| 场景 | ✅ 可以说 | ❌ 不许说 |
|---|---|---|
| 裸价差为正 | 「B 地较 A 地高 X 元/吨」 | 「存在 X 元套利空间」 |
| 扣运费后为正 | 「扣除运费后 A→B 方向参考差异 +X 元/吨」 | 「可以套利」/「建议调货」 |
| 扣运费后为负 | 「价差不足以覆盖该方向物流成本」 | 「亏本」/「不能做」 |
| 分位 96% | 「处于该组合历史 96% 分位，属显著偏高」 | 「一定会回归」 |
| 数据不足 | 「样本不足，不下结论」 | 用插值/默认值补齐后给结论 |

## 执行流程

```bash
# 0) 依赖：python3 + openpyxl（HTML/Excel 由脚本生成，无需装前端工具）
# 1) 抓取省级挂牌报价 → data_raw/cb_rows_<product>.jsonl（逐条追加，可断点续采）
python scripts/fetch_chembook2.py soda
python scripts/fetch_chembook2.py methanol
# 2) 口径统一 → data_raw/panel_long.csv + catalog.json（规格档/地区节点/剔除记录）
python scripts/build_panel.py
# 3) 区域供需背景 → data_raw/background.json
python scripts/build_background.py
# 4) 扫描 + 出报告（HTML + Excel），全流程一键
python scripts/run_all.py --no-fetch --window 12
# 5) 有真实运费时（方向 + 单价 + 运输方式）
python scripts/run_all.py --no-fetch --freight freight.json
```

> 抓取脚本可重复执行：已抓过的报告页会跳过，中断后重跑只补缺的部分。
> 若目标站点限流，脚本会记录到 `data_raw/cb_failed_<product>.json` 并继续，
> 不影响后续步骤 —— 少抓的页只会让某些地区「窗口内无足够报价」，
> 引擎会把它们登记为缺口而不是拿旧数据凑。

`freight.json` 格式：

```json
{
  "soda": {
    "EC_SHANDONG->EC_JIANGSU": {"fee": 65, "mode": "公路散货", "unit": "元/吨", "note": "整车含装卸"},
    "EC_JIANGSU->EC_SHANDONG": {"fee": 68, "mode": "公路散货", "unit": "元/吨"},
    "N_SHAHE->H_HUBEI": {"fee": 0.20, "mode": "公路", "unit": "元/吨·公里"}
  }
}
```

**换数据**：任何 Agent 只要把价格整理成 `templates/价格长表模板.csv` 的列结构，
就能直接复用 `scan.py / report_html.py / report_excel.py`，无需改代码。
这是本 Skill 跨 Agent 通用的关键——计算与渲染层不认识任何特定数据源。

## 交互要求（HTML 必须做到）

1. 点选 **产品池 + 地区范围** → 排行榜 / 矩阵 / 地图同步重算；
2. 切 **历史窗口** → 分位、异常度按新窗口重算（前端算，不重跑后端）；
3. **运费调整开关** → 默认关闭；打开后可在组合详情里按方向录入单价与单位，立即重算扣除后差异；
4. 点排行榜任一行或矩阵单元格 → 展开该组合的完整价差曲线、区间分布（P5/P50/P95）、
   双方区域角色/供给/需求/近期动态、口径与来源；
5. 运费未提供时，展示「未提供运费，未扣除」而非 0 或空白。

## 自检（交付前必过）

- [ ] 每个价格点都能说出 规格/地区/交货/税/计价类型 与来源；
- [ ] 排行榜按**异常度**排序，不是按金额；
- [ ] 每个组合的分位都来自**它自己**的窗口序列，窗口长度已声明；
- [ ] 运费未提供时，报告里没有出现任何扣除后的数字，也没有「套利」二字；
- [ ] 方向固定，没有「谁高减谁」；
- [ ] 不可比/覆盖不足的组合全部进缺口表，没有静默丢弃；
- [ ] 数据来源、抓取时间、口径限制写在报告显眼处；
- [ ] HTML 打开即可用（无外链依赖），筛选/切窗口/运费开关都真的会重算。
