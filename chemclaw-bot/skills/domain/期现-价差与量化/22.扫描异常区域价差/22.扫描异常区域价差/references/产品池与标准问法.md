# 产品池与标准问法

## 1. 推荐产品池（按可获取区域数据的难度排序）

| 品种 | 区域数据可得性 | 可用地区数 | 说明 |
|---|---|---|---|
| **纯碱（重质/轻质）** | 好 | 16+ | 省级挂牌报价密集，2024 起有连续历史；轻重碱必须分档 |
| **甲醇** | 好 | 20+ | 省级报价密集；国产/进口必须分档 |
| **PVC（SG-5）** | 中 | 待验证 | 电石法/乙烯法必须分档；区域维度弱于纯碱/甲醇 |
| 烧碱 | 中 | 少 | 100ppi 仅山东 + 华东，区域组合有限 |
| 尿素 | 中 | 少 | 报价多以山东为主 |
| 玻璃 | 弱 | 1—2 | 多为单一市场（沙河），无法构成区域组合 |

**判断标准**：同一规格档下，**至少两个地区**有足够长的历史序列，才可能形成区域组合。
只有一个地区 → 直接登记 `SINGLE_REGION_ONLY`，不进排行榜。

## 2. 规格档（spec_tier）的定义与映射

同一品种内部必须先分档，档内才可比。

### 纯碱
| 档 | 匹配规则 | 说明 |
|---|---|---|
| `heavy` 重质 | 含「重质 / 重灰 / 99.2 / 99.0 / 优等品 / 国标 / 含量99 / 双环」 | 工业级重质，玻璃刚需 |
| `light` 轻质 | 含「轻质 / 轻灰」 | 日化、洗涤；与重质存在稳定价差结构，**不可与重质相减** |
| 剔除 | 含「阿拉丁 / 分析纯 / 试剂 / GR / AR / 食品级」；价格 > 3000；纯度 < 95% 的低含量规格 | 试剂级、小包装、低纯度不属工业大宗 |

### 甲醇
| 档 | 匹配规则 | 说明 |
|---|---|---|
| `import` 进口 | 含「进口」 | 太仓等港口进口货，含到港成本与升贴水结构 |
| `domestic` 国产 | 含「优等品 / 99.9 / 99.99 / 国标 / 合格品 / 精醇 / 工业级」 | 内地出厂/送到 |
| 剔除 | 价格 > 6000 或 < 800 | 明显异常（小包装、特殊规格） |

> 进口与国产是**两条定价曲线**，跨档相减只能作方向参考，标 `WEAK`，不进异常榜。

## 3. 标准问法 → 本 Skill 的解析

| 用户怎么说 | 解析成什么 |
|---|---|
| 「扫描一下纯碱各区域的异常价差」 | 产品池=纯碱，地区=全部，窗口=12 月，运费=未提供 |
| 「华东和华南的价差是不是不正常」 | 产品池=纯碱/甲醇（追问），地区=华东+华南，重点看该组合分位 |
| 「扣掉运费还有没有空间」 | 必须先要**方向 + 单价 + 运输方式**；不给就只出裸价差并说明 |
| 「哪个区域是价格洼地」 | 看同一规格档下各地区价格水平与相对全国中位价的偏离（不是价差分位） |
| 「最近价差怎么走」 | `chg_5d / chg_20d / slope_20d` + 价差历史曲线 |
| 「帮我排个名」 | **必须按异常度排**，不能按金额；若要按金额排，需显式声明并加警示 |

## 4. 用户参数不全时的默认与声明

| 缺什么 | 默认 | 报告里必须写 |
|---|---|---|
| 窗口 | 12 个月 | 「实际可获取历史 X 个月，长于/短于要求」 |
| 运费 | 不扣 | 顶部 banner + 表格「未启用」 |
| 地区 | 全部有数据地区 | 列出实际纳入的地区 |
| 品种 | 用户已指名；未指名则问 | 不得自行扩大产品池 |
| 规格 | 每个品种的主档（样本最多） | 「本次使用规格档：重质纯碱」 |
