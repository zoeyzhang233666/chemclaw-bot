# 口径统一与可比性规则

本文件回答一个前置问题：**哪些地区的哪些价格，才有资格放进同一个价差矩阵。**
口径没统一就做减法，得到的数字没有信息量，还会误导决策。

---

## 1. 五要素口径卡（每个价格点必须集齐）

任何进入计算的现货价格，都必须能同时说清下面五项，缺一项即判为「不可比」：

| 要素 | 必须写清 | 常见陷阱 |
|---|---|---|
| ① 品种规格 | 纯度/牌号/理化指标（如：重质纯碱 Na₂CO₃≥99.2%、总碱量；PVC SG-5 型、电石法/乙烯法、K值；甲醇 优等品/国标/进口/国产） | 轻质当重质、糊树脂当 SG-5、精醇当工业醇、乙烯法当电石法 |
| ② 地区节点 | 具体交货地（太仓 / 沙河 / 荆门 / 鄂尔多斯 等），不止是大区名 | 「华北」「华东」是统计口径，不是可交割地点 |
| ③ 交货方式 | 出厂（ex-works）/ 送到（delivered）/ 港口现货 / 库提 / 站台 | 出厂价与送到价之间隔着运费，混算等于把区域价差算成物流成本 |
| ④ 税费与票种 | 含税/不含税、专票/普票、是否含贴水升水 | 含税与不含税相差 13% 增值税，会让价差整体平移 |
| ⑤ 计价类型 | 市场价 / 出厂价 / 挂牌报价 / 成交价 / 竞拍成交 | 挂牌价通常高于可成交价，混算会制造虚假价差 |

> 输出里的每个价格必须携带 `spec + region + delivery + tax + quote_type + date + source`。
> 缺任意一项 → `comparability = INCOMPARABLE`，只进「数据缺口」表，不进排行榜。

---

## 2. 规格可比性分级

| 等级 | 判定条件 | 处理方式 |
|---|---|---|
| **A 完全可比** | 规格、交货方式、税率、计价类型全部一致 | 允许直接做价差、算历史分位 |
| **B 可调整可比** | 规格一致，仅交货方式/税率不同，且**有可靠运费或税率** | 先按运费与税率调整再比，并记录调整参数 |
| **C 弱可比** | 规格相近但不同（如纯碱轻质 vs 重质、甲醇进口 vs 国产） | 只做「方向参考」，标注 `WEAK`，不进异常榜 |
| **D 不可比** | 规格或计量单位本质不同（不同牌号、不同含水率、元/吨 vs 元/千克） | 禁止相减，进缺口表 |

关键提醒：
- **轻质 / 重质纯碱不可直接相减**。两者存在稳定价差结构，直接用轻质推算重质，等于引入未知偏差。
- **甲醇进口（太仓）与国产（山东/内蒙）不可直接相减**。进口货含到港成本与升贴水结构，与国产出厂价是两条定价曲线。
- **PVC 电石法 / 乙烯法不可混算**，且同一地区电石法与乙烯法之间本身存在正常价差。

## 3. 方向固定原则

两两价差必须**固定方向**，不能「谁高减谁」，否则历史序列会在交叉点翻转，分位数彻底失真。

- 定义：`spread(A→B) = P_B − P_A`，其中 A 为基准地区（Base），B 为对照地区（Quote），A、B 顺序在整个历史窗口内不变。
- 基准地区应选择：**定价中心 / 交割地 / 流动性最好**的那个，例如甲醇选太仓，纯碱选沙河或华中。
- 方向固定后，`spread > 0` 表示 B 地区更贵，潜在物流方向为 A → B（若价差覆盖运费）。
- 严禁在同一张图里把 `A−B` 和 `B−A` 混排，也不要把符号反过来解释成「套利」。

---

## 4. 异常程度必须用自己的历史分布衡量

**禁止用绝对价差金额排序。** 600 元/吨的价差在西北—华南可能是常态，在沙河—华北却可能是极端值。

统一做法：
1. 每个地区组合，单独取自己过去 N 期的同口径序列；
2. 计算当前值在该序列中的**分位（percentile rank）**；
3. 用「双侧尾部距离」做异常度：`tail = min(分位, 1 − 分位)`，`anomaly = 1 − 2 × tail`；
4. 同时给出 **z-score**（基于历史均值与标准差）作为稳健性对照；
5. 若历史样本 < 最小样本数（默认 20），不下异常结论，只标注「样本不足」。

分位阈值（可配置）：
- `|anomaly| ≥ 0.80` 且分位 ≥ 0.95 或 ≤ 0.05 → **异常（EXCESS）**
- `0.60 ≤ |anomaly| < 0.80` → **偏高（ELEVATED）**
- 其余 → **正常（NORMAL）**

---

## 5. 运费调整必须分方向

物流成本不是对称的。A→B 与 B→A 的运输成本可能完全不同（回程车空驶、上下水、港口装卸、危化品资质限制）。

因此：
- 运费参数必须按**方向**分别录入（`fee[A->B]` 与 `fee[B->A]` 是两个独立数字）；
- 调整后差异分别计算：
  - 正向（A→B）：`net_AB = (P_B − P_A) − fee_AB`
  - 反向（B→A）：`net_BA = (P_A − P_B) − fee_BA`
- 只有当 `net > 0` 且该方向**实际有物流可走**时，才可表述为「存在物流可覆盖的价差」；
- 仍然**不得**称为「套利机会」：未考虑资金成本、损耗、账期、资质、库容与执行摩擦。

**没有可靠运费时，绝不自估。** 输出 `net = None` + `freight_status = MISSING`，
并保留「裸价差」，同时在报告中明确「运费未提供，未做扣除」。

## 6. 数据缺口类型（必须显式登记）

| 代码 | 含义 |
|---|---|
| `NO_REGION_PRICE` | 该地区没有可获取的同口径价格 |
| `SINGLE_REGION_ONLY` | 该品种只有单一市场报价，无法构建区域组合 |
| `SPEC_MISMATCH` | 规格不可比（轻/重质、进口/国产、牌号不同） |
| `DELIVERY_MISMATCH` | 交货方式不可比且无运费可调整 |
| `HISTORY_TOO_SHORT` | 历史样本不足最小样本数 |
| `HISTORY_WINDOW_LIMITED` | 历史窗口短于用户要求（如要求 1 年、仅有 3 个月） |
| `DEALER_QUOTE_ONLY` | 仅有挂牌报价，无统一市场价口径 |
| `FREIGHT_MISSING` | 未提供运费，未做调整 |
