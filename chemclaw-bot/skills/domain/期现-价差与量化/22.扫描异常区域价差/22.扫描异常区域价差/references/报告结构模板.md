# 报告结构模板

## 一、HTML 交互报告（单文件，无外链依赖）

### 顶部
1. **Kicker + 标题 + 副标题**：产品池 / 数据截止 / 可比组合数 / 缺口数；
2. **胶囊行**：数据截止、价格口径、品种池、运费状态（`未提供 → 未扣除` 必须显眼）、套利判断（`本报告不提供`）；
3. **阅读前必读**（橙色警示块，固定在顶部，不可折叠）：
   - 裸价差 ≠ 套利机会
   - 异常程度按各自历史分布衡量，不按金额排序
   - 运费必须用户提供，未提供不估算
   - 价格口径为挂牌报价，非统一市场价
   - 不可比组合进缺口表，不进排行榜

### KPI 卡（6 个）
品种数 / 地区节点 / 可比组合 / 显著偏离 / 偏高关注 / 样本不足

### 筛选器（顶部吸附）
| 控件 | 行为 |
|---|---|
| 产品池 | 单选或全部 |
| 地区范围 | 全部 / 单个节点 |
| 历史窗口 | 3 / 6 / 12 / 24 / 36 月，切换即重算分位 |
| 异常阈值 | 90% / 95% / 99% |
| 运费开关 | 默认**关**；打开后用于详情页手工录入 |
| 重置 | 恢复默认 |

### 01 异常区域价差排行榜
列：`# / 品种 / 方向(基准→对照) / 当前裸价差 / 占均价% / 历史分位(带进度条) / 异常度 / 判定 / 近5期变化 / 近20期变化 / 有效样本 / 里程 / 扣除运费后`
- 主排序：异常度降序；样本不足沉底；
- 判定标签配色：显著偏高·显著偏低=红、偏高偏离=橙、正常=绿、样本不足=灰；
- 点击整行 → 展开 04 组合详情。

### 02 区域价差矩阵
- 行=基准，列=对照，单元格=`P(列) − P(行)`；
- 底色按历史分位渐变：红=历史高位、蓝=历史低位、灰=样本不足/无配对；
- 点击单元格 → 跳到该组合详情；
- 每个品种一张表，标题写清「当前裸价差（元/吨）」。

### 03 区域地图
- 节点颜色=该地区价格相对全国中位价的偏离（红高/绿平/蓝低）；
- 只画判定为偏离/异常的组合，避免连线过载；
- 连线上标当前裸价差，虚线=偏高偏离，实线=显著；箭头指向对照地区；
- 图例必须解释颜色与虚实含义。

### 04 组合详情（点击后展开）
左栏：
- 价差历史柱状图（近 N 期，hover 显示日期与值）+ 区间标注；
- KV 表：当前价差 / 历史分位 / 异常度 / z 值 / 均值与标准差 / P5·P50·P95 / 近5期·20期变化 / 有效样本 / 里程与时长；
- **运费调整区**：两个方向各一行「单价 + 单位(元/吨 或 元/吨·公里)」，录入后实时算 `net_AB / net_BA`；未填显示「未提供运费，未扣除」。

右栏：
- **区域供需与背景**：双方地区的 角色 / 产能·供给 / 需求 / 近期动态；
- **主要解释因素**：该品种当前价差的结构性成因（3—4 条）；
- **口径与来源**：规格档、报价类型、税费、口径说明、原始页面链接。

### 05 品种价格水平与口径
每个（品种, 地区）最新价 / 最新日期 / 窗口均价 / 最低 / 最高 / 有效天数 / 规格档 / 口径

### 06 数据缺口与不可比说明
类型标签 / 品种 / 相关地区或组合 / 说明。**必须解释为什么没算，而不是简单说「无数据」。**

### 页脚
生成时间、数据截止、统计口径、免责声明。

## 二、Excel 工作簿（10 sheet）

| sheet | 内容 | 关键要求 |
|---|---|---|
| **00 说明与口径** | 回答什么问题、5 条硬约束、本次参数、数据性质、sheet 导航、免责 | 「数据性质」必须写清挂牌价≠市场价 |
| **01 产品池** | 品种 / 使用规格档 / 档说明 / 地区数 / 地区清单 / 最新样本日 / 原始条数 / 口径 | — |
| **02 地区价格** | 逐日×地区：品种/地区/节点/日期/价格/规格档/交货/税/计价类型/来源 | 冻结首行 + 自动筛选 |
| **03 价差矩阵** | 每品种三张：当前裸价差 / 历史分位 / 异常度 | 用色阶（绿-白-红） |
| **04 历史分位** | 方向/当前/分位/异常度/z/均值/标准差/最小/P5/P25/中位/P75/P95/最大/样本/首末日 | 分位列用色阶 |
| **05 运费参数** | 方向/运费/单位/运输方式/里程/折算单吨/裸价差/**扣除后(公式)**/状态 | 运费列空=未提供；公式自动算 |
| **06 异常筛选** | 排行榜：排名/品种/方向/裸价差/占均价%/分位/异常度/z/判定/近5期/近20期/样本/里程/扣除后/规格档/可比 | 判定列条件格式 |
| **07 数据缺口** | 类型/代码/地区或组合/说明 | 不允许为空表，至少说明「无缺口」 |
| **08 来源清单** | 数据项/来源/口径/覆盖/取用方式/备注 | 带 URL |
| **09 原始报价** | 全部原始行 + 剔除原因 | 可审计，不隐藏剔除项 |

## 三、文字结论的写法

每条结论必须是「事实 + 位置 + 条件」三要素，例：

> 山东→江苏组合当前裸价差 +85 元/吨，处于该组合近 12 个月的 96% 分位（异常度 0.92，z=1.8），
> 属显著偏高。窗口内该组合均值为 +12 元/吨、P95 为 +70 元/吨，当前值已超出历史 95% 区间。
> 运费未提供，未做扣除；本报告不对该价差是否可执行作出判断。

**不要写**：
- ❌「华东价格明显偏高，存在套利机会」
- ❌「预计价差将回归均值」
- ❌「建议从山东调货至江苏」
