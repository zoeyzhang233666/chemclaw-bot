# 常见错误与自检清单

## A. 口径类错误（最常见，危害最大）

| # | 错误 | 后果 | 正确做法 |
|---|---|---|---|
| A1 | 轻质纯碱与重质纯碱相减 | 价差里混入品种价差，可能达数十到上百元/吨 | 分档；轻质只做同档比较 |
| A2 | 甲醇进口（太仓）与国产（山东）相减 | 把两条定价曲线之差当成区域价差 | 分档；跨档标 `WEAK` |
| A3 | 出厂价与送到价混算 | 把运费当成价差 | 统一交货方式，或先按运费调整 |
| A4 | 含税与不含税混算 | 全部价差整体平移 ~13% | 统一税率并声明 |
| A5 | 挂牌价当成交价 | 高估可成交价差 | 显式声明「挂牌报价」；不评价可执行性 |
| A6 | 大区名（华东/华北）当节点 | 无法判断物流可行性 | 落到具体城市/园区 |
| A7 | 不同计量单位（元/千克 vs 元/吨）混算 | 差 1000 倍 | 单位列强制校验 |

## B. 统计类错误

| # | 错误 | 后果 | 正确做法 |
|---|---|---|---|
| B1 | 按价差金额排序 | 高估大金额组合、低估真正异常 | 按**异常度**排序 |
| B2 | 用全体组合的分布算分位 | 混合了不同品种/不同量级 | 每个组合**各自**的窗口序列 |
| B3 | 「谁高减谁」 | 序列穿零，分位永远在中间 | 方向固定 |
| B4 | 一边缺失也算配对 | 制造假波动 | 内连接，只算两地都有报价的日 |
| B5 | 插值填补缺失 | 造出假曲线，尤其在关键区间 | 留空 + 登记缺口 |
| B6 | 样本不足仍给结论 | 分位无统计意义 | N < 20 → `INSUFFICIENT`，只标不下结论 |
| B7 | 声称 1 年/3 年分位但只有 3 个月数据 | 误导决策 | 声明实际窗口；加 `HISTORY_WINDOW_LIMITED` |

## C. 运费与措辞类错误

| # | 错误 | 后果 | 正确做法 |
|---|---|---|---|
| C1 | 自己估运费 | 结论建立在虚构数据上 | 未提供 → `MISSING`，不扣 |
| C2 | 正反方向用同一个运费 | 回程空驶/资质限制导致成本不同 | 按方向分别录入 |
| C3 | 说「存在套利机会」 | 超出数据能力，误导交易 | 只说「参考差异」 |
| C4 | 扣完为负还说「可以反向」 | 未考虑实际物流是否存在 | 明确「价差不足以覆盖该方向物流成本」 |
| C5 | 元/吨·公里 直接当元/吨 | 运费量级错一个数量级 | 乘真实里程 |

## D. 交付类错误

| # | 错误 | 正确做法 |
|---|---|---|
| D1 | 静默丢弃不可比组合 | 全部进缺口表 |
| D2 | 报告里没有数据来源 | 每个数字可追溯，08 来源清单带 URL |
| D3 | HTML 依赖 CDN | 单文件自包含，离线可开 |
| D4 | 筛选按钮点了不重算 | 前端必须真重算（窗口/阈值/运费） |
| D5 | Excel 运费列写 0 冒充未提供 | 留空 + 状态列写「未提供运费」 |

## 交付前自检（逐条打勾）

### 数据
- [ ] 每个价格点有 规格/地区/交货/税/计价类型 + 来源链接
- [ ] 剔除记录可查（哪些行被剔除、为什么）
- [ ] 窗口长度已声明，且与实际数据跨度一致
- [ ] 每个地区至少有 N 天有效样本，N 已披露

### 计算
- [ ] 方向固定，`spread = P_对照 − P_基准`
- [ ] 分位来自该组合自身序列
- [ ] 异常度 = 1 − 2×min(pct, 1−pct)
- [ ] 排行榜主排序是异常度
- [ ] 样本不足的组合没有被判成异常

### 运费
- [ ] 未提供运费时，全报告无任何扣除后数字
- [ ] 提供运费时，正反方向分别扣
- [ ] 元/吨·公里 已按真实里程折算

### 措辞
- [ ] 全文搜索「套利」= 0 处（除非出现在「不构成套利判断」的免责里）
- [ ] 未出现对后市的涨跌预测
- [ ] 未出现「建议调货/建议采购」

### 交付
- [ ] 缺口表非空（或明确写明无缺口）
- [ ] HTML 离线可开，筛选/切窗口/运费开关有效
- [ ] Excel 公式可用（05 sheet 填数后 11 列自动出数）
- [ ] 顶部警示块存在且不可折叠

## 快速自检命令

```bash
# 措辞自检：报告里不应出现"套利"作正面表述
python - <<'PY'
import re,io
t=io.open('outputs/区域价差扫描报告.html',encoding='utf-8').read()
bad=[m.start() for m in re.finditer('套利',t)]
print('套利出现次数:',len(bad))
for i in bad[:10]:
    print(' …',re.sub(r'\s+',' ',t[max(0,i-60):i+40]))
PY
```
