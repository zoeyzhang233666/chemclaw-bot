# 价差计算、历史分位与异常度定义

## 1. 单个地区价格序列的构造

对每个（品种, 地区, 规格档, 报价类型）三元组，按日汇总为一条序列：

```
P(region, spec_tier, date) = median({ 报价 | 同地区、同规格档、同日期 })
```

- 用**中位数**而不是均值：挂牌报价存在个别离群（如 11000 元/吨的试剂级碳酸钠混入工业级），均值会被拉偏。
- 同日样本数 `n` 一并输出，`n` 过小（< 2）时该日标记为稀疏点。
- 规格档（spec_tier）不是原始规格文本，而是经过映射的**可比档**，映射表见 `价格规格与地区节点清单.md`。

## 2. 两两价差

对地区对 (A, B)，固定方向：

```
S_AB(t) = P_B(t) − P_A(t)
```

- 只用**两边同日都有报价**的日期（内连接），避免一边缺失导致的假变动。
- 输出同时给出覆盖天数与匹配率 `match_rate = 有效配对日 / 窗口内交易日`。

### 2.1 标准化价差（跨品种可比）

不同品种价差量级差异巨大（纯碱几十元/吨 vs PVC 几百元/吨），排行榜跨品种排序时用：

```
S_norm(t) = (P_B(t) − P_A(t)) / 0.5 × (P_A(t) + P_B(t)) × 100%   # 占两地均价百分比
```

排行榜主排序用异常度，副排序用 `S_norm` 绝对值，**不用原始金额**。

## 3. 历史分位

给定窗口内序列 `S_AB`（长度 N）与当前值 `S_now`：

1. `pct = ( #(S_i < S_now) + 0.5 × #(S_i == S_now) ) / N`  —— 中位秩法，处理并列值；
2. `tail = min(pct, 1 − pct)`，`anomaly = 1 − 2 × tail` ∈ [0, 1]；
3. `z = (S_now − mean(S)) / std(S)`（样本标准差，N>2 时计算）；
4. `hist_min / hist_p5 / hist_p25 / hist_p50 / hist_p75 / hist_p95 / hist_max` 全量输出，
   让读者看到分布形状，而不是只看到一个分位数。

**当前值的取法**：取最新日期，若最新日无配对则向前回溯到最近的有效配对日，并记录 `asof`。

## 4. 近期变化

| 指标 | 定义 |
|---|---|
| `chg_5d` | `S_now − S(asof − 5 个有效观测)` |
| `chg_20d` | `S_now − S(asof − 20 个有效观测)` |
| `pct_chg_20d` | 上述变化相对 20 期前历史均值的位置变化（分位数变化） |
| `slope_20d` | 20 期线性回归斜率（元/吨/期） |

变化用**观测序号**而不是日历日，自动跨过周末与节假日。

## 5. 异常分级

```
if N < MIN_SAMPLES:            grade = "INSUFFICIENT"      # 不下结论
elif anomaly >= 0.80 and pct >= 0.95:  grade = "EXCESS_HIGH"  # 显著偏高
elif anomaly >= 0.80 and pct <= 0.05:  grade = "EXCESS_LOW"   # 显著偏低
elif anomaly >= 0.60:          grade = "ELEVATED"
else:                          grade = "NORMAL"
```

`MIN_SAMPLES` 默认 20，可配置。历史窗口短于用户要求时追加标记 `HISTORY_WINDOW_LIMITED`，
**不因窗口不足而放大结论强度**。

## 6. 运费调整（方向化）

```
net_AB = S_AB − fee_AB
net_BA = −S_AB − fee_BA
```

- `fee_AB`：A 发货发往 B 的单吨综合运费（含装卸/仓储/资质等按用户确认口径）
- 两个方向独立录入；缺任一方向 → 该方向 `net = None`
- `freight_status ∈ {USER_PROVIDED, MISSING}`
- 若用户给的是「元/吨·公里」，需乘以真实公路里程（来自路由 API，非估算）得到元/吨

**表述规范**：
- ✅「扣除运费后，A→B 方向参考差异为 +X 元/吨」
- ❌「存在 X 元/吨的套利空间」
- ❌ 未提供运费时省略扣除步骤

## 7. 稳健性与陷阱清单

- **样本期陷阱**：若历史窗口正好覆盖一次极端行情（如纯碱 2023 年暴涨），分位会被压缩，需并列给出全窗口与近 3 个月两个分位。
- **口径漂移**：供应商结构变化会让报价分布整体平移。检查方式：比较同一省份不同商家报价的离散度（`iqr_cv`），离散度突变说明口径在漂。
- **平值期陷阱**：价差长期为 0（同价挂牌）会让 std≈0，z 值失效。此时 `z = None` 并标注。
- **交叉点翻转**：若方向未固定，序列会跨越 0，分位几乎永远处于中间，看不出异常——所以方向固定是硬约束。
