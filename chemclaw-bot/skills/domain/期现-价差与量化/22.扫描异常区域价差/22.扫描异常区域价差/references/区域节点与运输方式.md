# 区域节点、运输方式与运费口径

> **本文件不含任何默认运费金额。** 运费必须由用户提供真实报价（或来自用户确认的物流合同数据）。
> 未提供时，报告一律「裸价差 + 运费未提供」，绝不自行估算。

---

## 2. 各品种可用的运输方式

| 品种 | 形态 | 可用方式 | 关键限制 |
|---|---|---|---|
| 重质纯碱 | 固体，50kg 袋或散装 | 公路散货车 / 铁运棚车 / 水运散货船（长江、沿海） | 吸潮，需防雨；长途水运成本显著低于公路；内陆产区（内蒙/河南）依赖铁路与公路 |
| 甲醇 | 液体，危化品 | 铁路罐车 / 公路槽罐车 / 水运（化学品船，长江与沿海）/ 管道 | 危化品运输资质与专用槽罐；内蒙—华东主要靠铁路罐车与水运；太仓进口以船运为主 |
| PVC | 固体，25kg 袋 | 公路货车 / 铁路 / 水运集装箱（出口） | 堆存体积大，长途公路成本高；华南多为船运/铁路到货 |

运输方式的选择直接改变运费水平与方向可行性，**报告中必须写明假设的运输方式**。

## 3. 运费参数录入格式（用户提供）

建议用户提供以下字段，按方向分别录入：

```json
{
  "pure_soda": {
    "N_SHAHE->H_WUHAN":  {"fee": 180, "mode": "公路散货", "unit": "元/吨", "note": "含装卸"},
    "H_WUHAN->N_SHAHE":  {"fee": 205, "mode": "公路散货", "unit": "元/吨", "note": "回程空驶加价"},
    "EC_ZIBO->S_GUANGZHOU": {"fee": 0.48, "mode": "公路", "unit": "元/吨·公里"}
  }
}
```

规则：
1. `fee` 是单吨综合成本；若单位为 `元/吨·公里`，扫描器自动乘以真实里程；
2. `mode` 必填，否则无法判断方向可行性；
3. 缺某方向的报价 → 该方向 `net = None`，不猜测；
4. 若用户只给了一个「平均运费」，报告会标注「未分方向，方向性参考价值有限」。

## 4. 运费调整的完整表述模板

```
组合：沙河（A）→ 武汉（B）
裸价差 S_AB = +85 元/吨（B 地区更贵）
运费 fee_AB = 180 元/吨（用户提供，公路散货）
扣除后 net_AB = −95 元/吨  → 价差不足以覆盖物流成本
反方向 net_BA = 未计算（未提供 B→A 运费报价）
结论：该组合当前无物流可覆盖的价差；裸价差为正不等于存在机会。
```

若未提供运费：

```
裸价差 = +85 元/吨；运费：未提供（MISSING）
按规则不做扣除，不给出「机会」判断。
```
