# 数据源与抓取说明

本 Skill 的价格主口径来自**公开可获取的省级挂牌报价聚合**。下面写清每条数据从哪来、
怎么抓、有什么坑、断了怎么处理。

---

## 2. ChemicalBook 抓取要点（最容易踩的坑）

### 2.1 两个层级
```
列表页  https://www.chemicalbook.com/PriceInfoAll_{CB}.htm      第 1 页
        https://www.chemicalbook.com/PriceInfoAll_{CB}_{n}.htm  第 n 页
明细页  https://www.chemicalbook.com/PriceInfo_{reportId}.htm
```
产品 ID：纯碱 `CB9853672`、甲醇 `CB7854099`、PVC 需另行定位。
每页 15 条报告，纯碱约 41 页（611 份）。

### 2.2 速率限制（关键）
- 单次请求 1—7 秒；**连续快速请求会返回约 1.7 KB 的拦截页**（不是报错，是 200 但内容为空）；
- 应对：**单并发 + 每请求间隔 3—7 秒随机 + 退避重试（8 次）**，实测可持续跑完 600+ 个页面；
- 判断拦截：`len(html) < 5000` 即视为被拦。

### 2.3 表格解析（非常容易写错）
单元格**带 style 属性**：`<td style="width: 100px;">750</td>`。
如果正则写成 `<td>`，会**一行都匹配不到**（表现为 `rows=0`，但页面其实正常）。

正确写法：
```python
TD = r'<td[^>]*>\s*([^<]*?)\s*</td>'
ROW_RE = re.compile(r'<tr>\s*' + TD + r'\s*' + TD + r'\s*' + TD + r'\s*' + TD + r'\s*' + TD + r'\s*' + TD + r'\s*</tr>', re.S)
# 列序：日期 | 交货地 | 厂家 | 规格/品牌 | 价格 | 单位
```

### 2.4 断点续采
- 列表落盘 `cb_list_{key}.json`，明细追加写 `cb_rows_{key}.jsonl`（每行带 `report_id`）；
- 重跑自动跳过已采 `report_id`；失败记录进 `cb_failed_{key}.json`；
- 600 页约需 1—1.5 小时，**必须允许中断**，不要设计成必须一次跑完。

## 3. 生意社 100ppi 要点

- 详情页 `https://www.100ppi.com/rawmex/detail-{ppid}.html`（纯碱 737、轻碱 226、甲醇 817、PVC 107）；
- 有 JS 安全检查页 → 带 cookie `HW_CHECK=<从页面 _0x2="..." 提取>` 可绕过；
- 图表 iframe：`https://www.100ppi.com/graph/cindex.php?f=graph_ppid_ave&ppid={ppid}`，
  只有 `graph_ppid_ave` 有数据，`graph_ppid / graph_ppid_all / graph_ppid_market` 均为空；
- 序列正则：`BoundaryGap:false,data:\[(.*?)\]\}` 与 `series:\[\{.*?data:\[(.*?)\]\}`；
- **只提供单一市场或全国口径**（重碱=河南、甲醇=山东+太仓、PVC=华东牌号），**无区域维度**，
  因此只能做校验，不能用于区域价差。

## 4. 已知不可用 / 需付费的源

| 源 | 状态 | 说明 |
|---|---|---|
| 郑商所 / 大商所官网 | 403/412 | 需绕行，期货数据改走新浪 |
| 隆众 mysteel 文章页 | 反爬 | 列表页标题可读，正文需登录 |
| 卓创 sci99 文章正文 | 客户端渲染 | 标题与快讯可读，正文为空壳 |
| 中国化工网 / 化工98 / 中宇 / 中华商务网 | SSL 失败或 JS 校验 | 不可用 |
| 甲醇网 jiachunwang | 可用但不稳定 | 有大量日期化厂家报价，可作补充源，需另写解析 |

**结论**：能稳定拿到、可追溯、可批量复现的省级报价只有挂牌报价这一类；
**付费资讯商（隆众/卓创/iFinD）的统一市场价拿不到**。这一点必须在报告里说清，
否则用户会误以为拿到的是行业标准口径。

## 5. 数据断了怎么办

| 情况 | 处理 |
|---|---|
| 某天某省无报价 | 该日该省留空，不插值；配对时用内连接，只算两地都有报价的日子 |
| 某省整体消失 | 从候选地区中移除并在缺口表登记 `NO_REGION_PRICE` |
| 报告页 404 | 记入 `cb_failed`，并在「08 来源清单」中说明缺失区间 |
| 规格口径漂移 | 比较同省不同商家的报价离散度，突变则分段统计并标注 |
