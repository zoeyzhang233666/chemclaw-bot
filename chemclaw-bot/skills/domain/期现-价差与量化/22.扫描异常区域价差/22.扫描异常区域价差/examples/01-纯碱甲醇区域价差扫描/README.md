# 示例 01 · 纯碱与甲醇区域价差扫描

本目录是一个**可直接复现的完整案例**，对应 SKILL.md 里的标准问法：

> 请扫描【重质纯碱、甲醇】在主要区域市场之间的价差，找出当前明显偏离过去【12 个月】
> 历史区间的区域组合。请分别展示裸价差和扣除【系统参考/用户输入】运费后的差异，
> 并说明相关区域近期供需变化。

## 目录内容

| 文件 | 说明 |
|---|---|
| `data/panel_long.csv` | 标准化后的价格长表（产品 × 地区 × 日期 × 规格档 × 价格），本案例的唯一价格输入 |
| `data/distances.json` | 地区节点两两之间的公路里程（OSRM 实测）与运输方式 |
| `data/catalog.json` | 产品池定义：主规格档、基准地区、可比等级 |
| `data/background.json` | 各地区的角色 / 供给 / 需求 / 近期事件，用于解释偏离 |
| `outputs/scan_result.json` | 扫描引擎输出（排行榜、矩阵、分位、缺口） |
| `outputs/区域价差扫描报告.html` | 交互式报告（单文件，双击即开） |
| `outputs/区域价差扫描工作簿.xlsx` | 10 个工作表，含可实时重算的运费公式 |
| `outputs/结论摘要.md` | 文字结论 |

## 一句话复现

```bash
# 1) 抓价格（可断点续采，重复执行只补没抓过的）
python scripts/fetch_chembook2.py soda
python scripts/fetch_chembook2.py methanol

# 2) 标准化
python scripts/build_panel.py

# 3) 补齐里程（已有 distances.json 可跳过）

python scripts/report_html.py outputs/scan_result.json
python scripts/report_excel.py inputs/scan_result.json outputs/区域价差扫描工作簿.xlsx
```

## 本案例的实测结果（数据截止 2026-10-16）

- 可比组合 **11** 个（纯碱 9 + 甲醇 2），覆盖 11 个地区
- 分级：显著偏高 1 / 显著偏低 1 / 偏高偏离 7 / 正常 2
- 头号偏离：**甲醇 江苏太仓 → 福建 +1,000 元/吨，99.1% 分位，异常度 0.98**
- 缺口 48 条，全部逐条登记（无静默丢弃）

## 复现时最容易踩的三个坑

1. **基准地区不能随便取「价格最低」**。纯碱最初取到江西（价格低），
   但江西报价稀疏，导致 42 个组合里 31 个「两地无共同报价日」，
   排行榜全是样本不足。改为「在报价覆盖度达标的地区里选低价者」后，
   基准落到山东，组合干净到 11 个。

2. **单一商家的孤立报价会造出假极值**。山东某贸易商在 2026-09-26 / 10-02 /
   10-07 / 10-17 单独挂 1,900 元/吨，而当日主流在 1,250–1,350。
   直接取当日中位数，山东价格瞬间抬高 600 元，分位直接顶到 0.2%。
   引擎会把这类日期剔除并登记在缺口表（本案例共剔除 246 个报价日）。

3. **`chg_5d` 不能用「最近 5 个观测」**。报价日期不均匀，按观测序号取样会
   实际跨越几个月。必须按日历天回溯。

## 数据边界（必须向用户说明）

- 价格为 ChemicalBook **厂家/贸易商公开挂牌报价**，不是交易所或资讯商统一口径的市场价；
  挂牌价 ≠ 成交价。价差反映「挂牌报价的区域结构」，不能直接当可成交价差用。
- 河北沙河（北方最重要的纯碱消费与交割集散地）在近 12 个月内无足够报价，
  **未纳入配对** —— 这是本案例最大的数据空白，报告里已显式标注。
- 运费用户未提供，故全部默认不扣除；报告内可按方向录入并实时重算，
  但结果只称「参考差异」，不构成套利或调货建议。
- PVC 未取得可靠的省级多区域报价，未纳入（不编造）。
