1指标定义、频率、覆盖与真实发布日期

领先滞后研究里最容易出错的一步不是统计，而是“当时能不能看到”。本节把两个指标的统计口径与信息可得时点逐项钉死。

A中国甲醇样本港口库存（周度 · 万吨）
定义华东 + 华南样本港口甲醇库存总量（隆众资讯「中国甲醇样本港口库存周数据统计」）
统计频率周度，统计日为周三（节假日顺延至最近工作日）
覆盖范围2024-10-23 至 2026-10-14，共 101 期，期内无缺失周
报告期截至统计日当日（即统计期最后一天）的时点库存
实际发布日期统计日当天 13:00–15:00（100/101 期在 14:00 前后）
可得性含义报告期结束的当天下午盘中即可见，统计日 = 发布日，无需滞后 1 期保守处理
B甲醇期货周度收益率（郑商所 MA 主连 · %）
定义MA 主连收盘价的对数收益率，以库存披露日为锚点对齐
交易时段日盘 9:00–11:30 / 13:30–15:00；夜盘 21:00–23:30
价格锚点披露前：统计日 11:30 定格收盘（当日开盘后可交易，尚未见库存）；披露后：当日 15:00 收盘
主设定收益rt = ln(P披露日15:00 / P前一日收盘) × 100，即“披露当日的价格反应”
覆盖范围期货日线 2014-12-24 至 2026-10-19（与本样本交集为研究样本）
频率统一期货日线 → 按库存披露日抽样聚合为周度，不做前向填充
为什么必须用真实发布日：库存、开工等周度指标如果直接把“统计期结束日”当作公布时间，会产生长达 0–7 天的信息泄漏——相当于让研究者提前知道尚未公开的数据，进而系统性夸大领先关系。本报告的时间轴全部取自数据源页面的“发布时间”字段（精确到秒），并逐条校验“统计日 = 发布日”。

2数据变换的选择与理由

库存与价格都是 I(1) 非平稳序列（后文 ADF 检验：库存水平 t = -1.40，价格 t = -1.17，均无法拒绝单位根）。因此主检验使用差分后的库存变化与收益率，而非水平值。两种变换都做了稳健性对照。

变换定义用途
Δ库存（万吨）I(t) − I(t−1)，差分消除单位根；对应库存方向变化主设定
Δ库存（%）(I(t) − I(t−1)) / I(t−1) × 100，对低库存期（30 万吨）波动更公平稳健性 D2
库存水平（万吨）原值，仅用于伪回归对照与回归控制对照 D4/D5
披露日对数收益ln(P(披露日15:00) / P(前一日收盘))，衡量“披露当日的价格反应”主设定 B
可用周收益P(t) / P(t−1) − 1，以披露日收盘为锚，衡量两次披露之间的全部市场收益稳健性 D3
收益率（%）报告中展示与计算统一用百分比形式展示

7稳健性：变换方式与“伪造时点”安慰剂检验

同一组关系在多种变换下不应改变结论；同时把库存的可得时点人为提前（时间上不可能），若“领先关系”依然出现，则说明它是噪声或方法伪影，而非可交易的信息优势。

伪造时点安慰剂：把库存可得时点前移/后移

Shift = −1 / −2 表示“提前 1–2 周就知道库存”（现实中不可能发生）。若在提前获得的时点下仍观察到同量级的相关性峰值，则真实时点下的峰值同样只是噪声。

8多重比较、自相关与样本量提示

!多重比较

检验 25 个 Lag 时，即便真实关系为 0，期望也有 25×5% ≈ 1.25 个 Lag 偶然达到 p<0.05。本报告用 Benjamini-Hochberg FDR 与 Bonferroni 双校正：最小 q = 0.609，无一通过。

!样本自相关

库存变化 8 阶 Ljung-Box Q = 15.93（p = 0.043），存在显著自相关；收益率一阶自相关 0.147。名义样本 n=101，有效样本 ≈ 94。所有 t 值均用 Newey-West HAC 稳健标准误重算。

!分区样本量

分阶段后每段仅 22–29 期。在 n=26 时，r=0.5 的 95% 置信区间约为 [0.14, 0.75]；r=0.6 时约为 [0.28, 0.80]。分段结果只能作为方向参考，不能作为结论。

9能否预测？——披露后收益的样本内回归

即使相关性不显著，仍可检查“已知信息能否解释披露后的收益”。以下回归全部只使用 t 期及以前已披露的变量，并在 t+L 期收益上检验（Newey-West HAC）。

单因子（库存变化 + 库存水平）在各 Lag 上 R² 均 ≤ 2.2%，系数不显著；加入江浙 MTO 产能利用率后 R² 明显上升，但显著性来自需求侧变量而非库存变化本身。这说明对甲醇边际定价更重要的是下游负荷，而不是库存的净变化。样本内 R² 不等于样本外可预测性，本节不做交易建议。

10结论：方向、稳定性与局限

F1全窗口无显著领先关系核心

Lag ∈ [−12, +12] 共 25 个设定，r 的绝对值最大仅 0.231（Lag=−6），FDR 校正后 q 全部 ≥ 0.609。没有任何一个 Lag 能在 5% 水平上通过多重比较校正。

F2同期相关本身接近零核心

Lag = 0 时 r = −0.045（n = 100，p = 0.656）。库存增加与期货上涨/下跌在披露当天都没有可辨关系，说明库存信息在公布前已基本被价格消化或未被当作边际定价因子。

F3“最优 Lag”随阶段漂移，且方向不一致稳定性

四个市场阶段的最强 Lag 分别为 +8（r=0.531）、−12（r=0.595）、+10（r=0.492）、+11（r=0.597），正负方向与期数都在变；三个年度（2024/2025/2026）的最强 Lag 分别为 +1、−9、+11。这正是“挑最大相关系数”最容易制造伪结论的场景。

F4发布时点是干净的，虚假领先来自噪声而非数据泄漏机制

101 期库存数据全部在统计日当天 13:00–15:00 之间发布（100 期在 14:00 前后），即报告期结束当天盘中披露。我们以披露日 11:30 的定格收盘价构造“披露前价格”，以 15:00 收盘构造“披露后价格”。伪造时点安慰剂检验显示：把库存可得时点前移 1–2 期（时间上不可能的“提前知道”）后，最强相关系数仍在 0.20 左右且位置整体平移——说明观测到的弱相关是噪声水平的产物，不是泄露信号。

F5水平对水平的强相关是伪回归陷阱

库存水平与价格水平的相关系数在 Lag=−11 达到 −0.616（q<0.001），但 ADF 检验显示库存水平 t = −1.40、价格水平 t = −1.17，均无法拒绝单位根。两个 I(1) 序列的相关系数不能解读为领先/滞后关系。差分之后（Δ库存 vs 收益）该关系即消失，这是典型伪回归特征。

F6真正有解释力的是需求侧，而非库存变化产业解释

加入江浙 MTO 装置产能利用率后，披露后 1–2 周收益的回归 R² 从 2.0% 升至 5.1%，MTO 利用率变化项 t 值为 ±1.98；而库存变化项在整个滞后网格中始终不显著（|t| < 1.2）。产业解释：港口库存是结果变量，其变化同时反映供给到港与下游消化，净信号被对冲掉；对甲醇边际定价更敏感的是沿海 MTO 的负荷。

F7有效样本量比名义样本更小统计

库存变化的 8 阶 Ljung-Box Q = 15.93（p = 0.043），存在显著自相关；据此估算有效样本量约 94（名义 101）。分阶段检验中每段仅 22–29 期，即便 r 达到 0.5，其 95% 置信区间也宽达约 ±0.35，不足以支撑方向性判断。

什么时候有效、什么时候失效

本样本中不存在可以被称为“有效”的时期——所有分段得到的峰值相关性都未通过多重检验校正，且样本量不足以拒绝“无关系”。可以明确的是：

  • 失效（不可依赖）：2024 年 10–12 月（仅 10 期）；2025 年春节与 2025 年国庆前后（发布间隔 14–15 天，信息缺口期）；任何单一年度或单阶段的“最强 Lag”。
  • 需要谨慎：2025 年（n=51）与 2026 年（n=40）虽各自出现 p<0.05 的 Lag，但方向与期数相反（−9 与 +11），互不印证。
  • 仍成立的事实：库存变化与披露当日价格反应同步相关接近 0，即“披露即消化”，价格在库存公布前已反应了大部分信息。

产业解释：为什么库存不领先价格

  • 库存披露滞后于价格：港口库存反映的是过去 7 天的到港与出库，而这 7 天的市场情绪已经体现在期货价格中——库存是价格的滞后确认，不是先行指标。
  • 库存是供需的净结果：到港量（供给冲击）与 MTO 负荷（需求）同时驱动库存，二者对价格方向相反，净库存变化被部分对冲，信息含量下降。
  • 港口库存绝对水平偏低（30–156 万吨），且样本期内单周变化标准差 7.7 万吨，噪声比例高。
  • 披露时点在 14:00 前后，属于盘中披露，价格反应在同一交易日内完成并被日线收盘价吸收，周度 Lag 上自然看不到持续效应。

局限与不可越界的解释

  • 统计上的领先（相关性）不代表因果关系，更不代表可交易的预测能力。本报告未做任何回测或收益验证。
  • 样本区间仅约 2 年、101 个观测，覆盖了完整的库存下行周期与一次显著的价格上行，结构可能不足以代表长期规律。
  • 库存数据为隆众资讯「中国甲醇样本港口库存」口径（华东 + 华南样本港口），与其他资讯商（金联创等）口径存在差异，不可混用。
  • 本报告不构成投资建议。
