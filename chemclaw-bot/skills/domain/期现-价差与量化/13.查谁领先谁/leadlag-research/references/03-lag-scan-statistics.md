# Lag 扫描的统计方法

## 1. 符号约定（必须显式声明）

```
Lag = k：配对 (A_t, B_{t+k})
  k > 0  →  A 领先 B k 期（用 A 的过去预测 B 的未来）
  k = 0  →  同期
  k < 0  →  B 领先 A k 期（A 滞后于 B）
```

一份报告必须在首页写清这个约定。行业内也有用「A 领先 B 用正 Lag」和相反的，混用是最常见的沟通事故。

## 2. 逐 Lag 计算（全部 Lag 都要报）

对每个 `k ∈ [−K, K]`：

```
配对集合 S_k = {(a_t, b_{t+k}) : 两者均非缺失}
n_k = |S_k|
r_k = Pearson(a, b) on S_k
t_k = r_k·√(n_k−2) / √(1−r_k²)        # 朴素 t，自由度 n_k−2
p_k = 2·(1 − T_cdf(|t_k|, n_k−2))
```

**必须报告的表：** `k, n_k, r_k, CI_lo, CI_hi, p_k, t_nw, p_nw, q_bh, q_bonf, n_eff`。

禁止只报 `max|r_k|`。原因见第 4 节。

## 3. 重叠样本 → Newey-West HAC

当 `k ≠ 0` 时，相邻观测共享部分期数，残差自相关。朴素 t 值会**系统性偏大**（可虚高 2–4 倍）。

Newey-West（Bartlett 核）方差估计：

```
V_β = (X'X)^{-1} · S · (X'X)^{-1}

S = Σ_{t} x_t x_t' u_t²
  + Σ_{l=1..L} w_l · Σ_{t=l+1..n} (x_t x_{t-l}' u_t u_{t-l} + x_{t-l} x_t' u_{t-l} u_t)
w_l = 1 − l/(L+1)                       # Bartlett 权重
L   = ⌊1.5·|k|⌋ + 1                     # 带宽随 Lag 增大
```

实现要点（踩过的坑）：

- `V = XtX^{-1} @ S @ XtX^{-1}`。**不要**把 `XtX^{-1}` 预先乘进 `S`。
- 小样本修正：`S *= n/(n−k_params)`。
- 当 `n − k` 过小时返回 `None` 而不是硬算，避免出现 t = 1169 这种荒谬值。

## 4. 多重比较校正

扫描 `m = 2K+1 = 25` 个 Lag，就是做 25 次假设检验。即使真实关系为 0，期望也有 `25 × 0.05 ≈ 1.25` 个 Lag 偶然达到 p<0.05。

**Benjamini–Hochberg (FDR)：**
```
将 p 升序排列 p_(1) ≤ … ≤ p_(m)
q_(i) = min_{j ≥ i} ( p_(j) · m / j )
```

**Bonferroni（FWER，最保守）：**
```
p_adj = min(1, p·m)
```

判定：**只有 q_bh < 0.05 才算候选**，并需稳定性支持。Boltzmann 校正后无人通过时，正确结论是「未发现稳健领先关系」。

甲醇案例实测（n=101）：

| Lag | n | r | p | q_BH | q_Bonf |
|---|---|---|---|---|---|
| −6 | 95 | +0.231 | 0.024 | 0.609 | 0.609 |
| +11 | 89 | +0.203 | 0.056 | 0.677 | 1.000 |
| 0 | 100 | −0.045 | 0.656 | 0.922 | 1.000 |

→ 最小 q = 0.609，**无一通过**。若只报「Lag=−6 时 p=0.024 显著」，就是典型的挑樱桃。

## 5. 置信区间

Fisher-z 变换：
```
z = atanh(r) = 0.5·ln((1+r)/(1−r))
SE(z) = 1/√(n_eff − 3)
CI(r) = tanh(z ± 1.96·SE)
```

在小样本下，r 的 CI 极宽。n=26 时 r=0.5 的 CI ≈ [0.14, 0.75]，n=10 时几乎覆盖 −1 到 1。**这是判断分段结果能否作为结论的关键依据。**

## 6. 领先滞后矩阵

把 `±K` 排成一个二维矩阵：
```
M[k] = r_k ，k ∈ [−K, +K]
```
左半（k<0）= B 领先 A；右半（k>0）= A 领先 B。

**判读原则：**真实领先关系应在**相邻多个 Lag 上形成同色山脊**（因为传导有持续性）。孤立的单点峰几乎必然是噪声。

## 7. 滚动相关

```
r_w(t) = corr( {a_{t−W+1..t}}, {b_{t+k−W+1..t+k}} )    W = 26
近似显著阈值: ±1.96/√(W−3) ≈ ±0.39
```

用途：看是否存在样本期内由稳定转为失效（或反之）的结构变化。若滚动相关系数在 0 附近随机穿越，说明整体无关系。

## 8. 预测回归（可选的补充证据）

```
b_{t+L} = α + β·Δa_t + γ'·X_t + ε_t
```
- 仅使用 t 期已公布的信息。
- 标准误用 NW HAC。
- 报告 R²、调整 R²、各系数 t 值。

**注意：**样本内 R² 高 ≠ 样本外可预测。报告必须写明这一点，并且不做收益回测结论。

甲醇案例：
- 仅库存因子：R² = 1.0%~2.2%，ΔI 系数 t = 0.14~0.93，全不显著
- 加入 MTO 产能利用率：R² 升至 5.1%，显著项是 **ΔMTO（t=±1.98）**，而非库存变化

产业解读：库存是供需净结果，被对冲；MTO 负荷才更贴近边际需求冲击。
