# 陷阱速查表

按「错误 → 表现 → 正确做法」组织。带 ⚑ 的是最难自我发现、最容易骗过审阅者的。

## A. 时点类

| # | 错误 | 表现 | 正确做法 |
|---|---|---|---|
| A1 ⚑ | 用统计期结束日当发布日 | 前视偏差，夸大领先关系，且方向偏向「A 领先 B」 | 抓取真实发布字段，逐条校验 `stat_date == pub_date` |
| A2 | 「一般周三发布」于是推断发布日 | 节假日/特殊期错位，3 期在周四却被当成周三 | 规律只用于校验，不用于填充 |
| A3 | 用当日收盘价当「公布前价格」而公布发生在盘中 | 混入了公布后的价格反应 | 盘中公布时用 11:30 定格价作 `P_before` |
| A4 | 对低频数据做前向填充 | 同一库存值对应多个价格，n 虚增、相关性虚高 | 把高频采样到公布日，不反向填充 |
| A5 | 不同资讯商口径混用 | 同一期出现 24.82 与 30.51 两个值 | 锁定单一来源，交叉核对仅用于验证发布时点 |
| A6 | 时区未统一 | 跨市场研究错位 8 小时 | 全部换到交易所时区并注明 |

## B. 统计类

| # | 错误 | 表现 | 正确做法 |
|---|---|---|---|
| B1 ⚑ | 只报最大相关系数 | 25 个 Lag 中期望 1.25 个偶然 p<0.05 | 报告全部 Lag + BH-FDR + Bonferroni |
| B2 ⚑ | 忽略重叠样本 | Lag≠0 时朴素 t 虚高 2–4 倍 | Newey-West HAC，带宽 L=⌊1.5·\|k\|⌋+1 |
| B3 ⚑ | 水平对水平做相关 | r 可达 0.6+ 且「极其显著」，纯属伪回归 | 先 ADF；非平稳则差分；水平设定只作反例 |
| B4 | 用 n 而不用 n_eff 算置信区间 | CI 过窄，虚假精确 | `n_eff = n(1−ρ_aρ_b)/(1+ρ_aρ_b)` |
| B5 | 小样本分段当结论 | n=25 时 r=0.5 的 95% CI 宽达 ±0.35 | 分段只作方向参考，报告 CI 宽度 |
| B6 | 忽略序列自相关 | 库存变化常有一阶/八阶自相关（LB Q(8) 显著） | Ljung-Box 检验 + HAC 标准误 |
| B7 | HAC 方差实现错误 | 出现 t=1169 这类荒谬值 | `V = XtX⁻¹·S·XtX⁻¹`；S 不要预先左乘；小样本修正 S·n/(n−k) |
| B8 | 多重检验只对「子集」校正 | 只对 p<0.1 的 Lag 做 FDR，等价于放宽阈值 | 校正必须覆盖全部被检验的假设 |

## C. 设计与解释类

| # | 错误 | 表现 | 正确做法 |
|---|---|---|---|
| C1 ⚑ | 根据「哪段更显著」选切分点 | 切分本身成为数据挖掘的一部分 | 按价格路径/库存周期等客观依据切分，写明理由 |
| C2 ⚑ | 把统计领先说成因果或可预测 | 读者直接拿去建仓 | 结论必须声明「相关≠因果≠可交易」；不做回测建议 |
| C3 | 忽略安慰剂检验 | 噪声被当成信号 | 伪造发布时点（提前 1–2 期）后重做扫描 |
| C4 | 只跑一种变换 | 结论由变换方式决定 | 至少 6 种变换，比较最强 Lag 是否漂移 |
| C5 | 隐藏不显著的分段 | 只展示支持结论的时期 | 全部分段都要列出，包括 n<20 的无效段 |
| C6 | 只报「最优窗口」滚动相关 | 从多个窗口里挑最好看的 | 预先固定窗口（如 26 期）并说明理由 |
| C7 | 样本期覆盖不足却下长期结论 | 2 年数据说「长期规律」 | 明示样本区间与局限 |

## D. 数据工程类

| # | 错误 | 表现 | 正确做法 |
|---|---|---|---|
| D1 | 网页正文用 urllib 直接 decode | 得到乱码（服务器返回 brotli 压缩） | 改用站点 JSON 列表 API，或加 brotli 解码 |
| D2 | 解析分项未加总校验 | 总量 ≠ 华东 + 华南，错行 | 每期校验 `total == east + south` |
| D3 | 期数看似连续实则缺期 | n 对不上日历周数 | 检查 `stat_date.diff().days` 分布，列出所有异常间隔 |
| D4 | 交易日缺失（节假日） | 收益为 NaN 或错配到上一交易日 | 显式记录并跳过，不填充 |
| D5 | 主连合约换月 | 价格跳空被当成真实收益 | 使用后复权主连，或对换月日做标记 |

## E. 交付物类

| # | 错误 | 表现 | 正确做法 |
|---|---|---|---|
| E1 | HTML 依赖 CDN | 离线/内网打不开 | 全部内联，原生 SVG 绘图 |
| E2 | JS 语法错误 | 页面空白或表格 0 行 | 用无头浏览器跑，捕获 pageerror |
| E3 | p/q 视图固定 y 轴 | 数据挤在底部 7% | y 轴上限按数据自适应 |
| E4 | SVG 文字碰撞 | 标签重叠、看不清 | 用 bbox 碰撞检测脚本自动发现 |
| E5 | 图例文案与实际渲染不符 | 说「上排/下排」实际是「左半/右半」 | 逐句核对文案与绘图代码 |
| E6 | XlsxWriter 写空单元格方式错误 | 文件打不开（XML 损坏） | 只用 `write_blank(r, c, None, fmt)` |
| E7 | Excel 里把数字存成字符串 | 无法排序/计算 | 数值用 `write_number`，公式用 `write_formula` 并写缓存值 |
| E8 | 报告只放最终结论图 | 读者无法复核 | 附原始数据表、完整 Lag 表、对齐明细 |
