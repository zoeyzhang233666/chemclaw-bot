# 数据变换与单位根

## 先做单位根检验，再决定能不能直接相关

两个非平稳序列（如库存水平与价格水平）即使毫无经济联系，也常常出现很高的相关系数——这就是**伪回归（spurious regression）**。

判断方法（ADF 检验，含常数项，滞后阶按 AIC 自动选择）：

```
Δy_t = α + γ·y_{t-1} + Σ_{i=1..p} b_i·Δy_{t-i} + e_t
```

检验 `γ = 0`。5% 临界值约 **−2.86**（含常数项）。

| ADF t 值 | 判断 |
|---|---|
| < −2.86 | 拒绝单位根，序列平稳 |
| ≥ −2.86 | 不能拒绝单位根，视为 I(1)，需差分 |

甲醇案例的实测：

| 序列 | ADF t | 判定 |
|---|---|---|
| 港口库存水平 | −1.397 | 非平稳（I(1)） |
| 甲醇期货价格水平 | −1.174 | 非平稳（I(1)） |
| 库存变化 ΔI | −4.179 | 平稳 |
| 期货收益率 | −6.097 | 平稳 |

因此**水平对水平**的相关系数（本案例 Lag=−11 时 r=−0.616，q<0.001）**不可解释为领先关系**，只能作为伪回归的反例展示。差分之后该关系消失。

## 推荐的变换组合

一个稳健的研究应同时跑下面 6 种设定，并比较「最强 Lag」是否漂移：

| 编号 | A 变换 | B 变换 | 用途 |
|---|---|---|---|
| D1 | ΔA（绝对量） | 公布日对数收益 | **主设定** |
| D2 | ΔA / A_{t-1}（百分比） | 公布日收益 | 对低水平期更公平 |
| D3 | ΔA | 可用周收益（周期收益） | 保守口径 |
| D4 | A 水平 | B 价格水平 | **伪回归对照**，仅用于反例 |
| D5 | A 水平 | 公布日收益 | 检验水平效应 |
| D6 | 浮动比例（52 周区间位置） | 公布日收益 | 消除绝对量纲 |

### 各变换的适用场景

**绝对差分 ΔA**：最常用。单位为原始单位（万吨）。缺点是在 A 水平较低时，同样的绝对变化对应更大的相对冲击。

**百分比变化 ΔA/A**：消除量纲，适合比较不同时期。缺点是 A 接近 0 时会爆炸，需设下限或改用对数差分。

**浮动比例（floating scale position）**：
```
scale_t = (A_t − min_{52w} A) / (max_{52w} A − min_{52w} A)
Δscale_t = scale_t − scale_{t-1}
```
把库存变化放在「过去一年的区间」里衡量，等效于把 30 万吨时的 −5 万吨与 150 万吨时的 −5 万吨区别对待。产业上更贴近「市场感知的紧张程度」。

**收益率**：
- 对数收益 `ln(P_t/P_{t-1})`：可加、近似正态，推荐。
- 简单收益 `P_t/P_{t-1} − 1`：直观但不可加。
- 公布日收益（见 01 文档）：衡量「公布当日的价格反应」。
- 可用周收益：衡量两次公布之间的全部市场收益，更保守。

## 自相关与有效样本量

差分并不保证消除自相关。带趋势/季节性的周度数据常有滞后 1–8 期的结构。

检验：**Ljung-Box**
```
Q = n(n+2) Σ_{k=1..K} r_k²/(n−k)  ~  χ²(K)
```
甲醇案例：ΔI 的 Q(8) = 15.93（p = 0.043），存在显著自相关；收益率 Q(8) = 7.47（p = 0.487），基本白噪声。

影响与处理：

1. **有效样本量**（Bartlett 近似）：
   ```
   n_eff = n · (1 − ρ_a·ρ_b) / (1 + ρ_a·ρ_b)
   ```
   其中 ρ 为一阶自相关系数。甲醇案例：n = 101 → n_eff ≈ 94。
2. **置信区间**用 n_eff 而非 n：
   ```
   z = atanh(r),  SE = 1/√(n_eff − 3),  CI = tanh(z ± 1.96·SE)
   ```
3. **标准误必须用 HAC**（见 03 文档）。

## 缺失值与对齐

- **不要插值。** 缺失周就减少一片样本，`n` 如实减少。
- 首尾的 Lag 会损失样本：`Lag=+k` 时可用配对数约为 `n−k`。报告必须逐 Lag 显示 n。
- 频率不一致时，把高频降到低频的**公布时点**，不做反向填充。

## 单位与展示

- 报告正文统一用百分比展示收益率（`×100`），表格保留 3 位小数。
- 库存用原始单位（万吨）并注明。
- Excel 中保留真实数值格式，不要用字符串存数字。
