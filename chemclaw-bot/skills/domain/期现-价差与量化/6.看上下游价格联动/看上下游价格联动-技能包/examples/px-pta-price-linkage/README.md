# 完整案例：PX → PTA 价格联动与理论加工价差

> 这是本技能的「参考答案」。换任何一组上下游品种时，照着这个案例的结构做。

## 一、结论摘要（先看这里）

| 判断 | 结论 | 数字 | 依据 |
|---|---|---|---|
| 产业关系是否支持算价差 | **支持** | 单一主料，λ=0.655 t/t | 长江期货 2023-12-18；天风证券 2019-12-14 表4（8 套装置） |
| 长期价格是否同向 | **高度同步** | 水平 r = 0.955（N=369，p<1e-100，95%CI 0.945~0.963） | 日频，成对有效观测 |
| 逐日传导是否明显 | **不明显** | 日收益率 r = 0.096（N=368，p=0.065，不显著，CI −0.006~0.197） | 同上 |
| 为什么水平高、收益低 | 共同成本中枢（原油—石脑油）驱动，两者同标尺编制 | log-log 斜率 1.05（HAC se 0.037） | 锚定系数检验 |
| 价差当前处于什么位置 | 中性偏低 | 当前 177 元/吨，历史分位 0.391 | P10=24、P50=220、P90=703 |
| 价差中枢 | 约 300 元/吨 | 均值 302，标准差 276 | λ=0.655，其他成本取 0（收入型加工费） |
| 领先/滞后 | **近乎同步定价** | 收益率峰值 lag=−2，r=0.152；lag=0 处即达高位 | 交叉相关 + Granger |
| 是否存在明显背离阶段 | 存在，均为供给端事件驱动 | 见下方阶段表 | 装置检修/重启/地缘 |

**一句话**：PX 与 PTA 长周期高度同向，但逐日价格传导很弱；价差波动主要由两者对共同成本的
反应幅度差异、以及 PTA 自身供给（检修/重启）决定，属于「同步定价 + 供给扰动」型关系，
不是「上游涨价、下游紧随其后」的传导型关系。

## 四、关键发现

### 1. 相关性的两个口径必须分开

- 水平 r=0.955：只能说明「两者同属一个成本体系、长期中枢同步」
- 收益率 r=0.096（p=0.065）：说明「逐日的价格变化几乎不同步」

**业务含义**：如果按「上游涨多少、下游跟多少」做合同挂钩或成本预测，
用水平相关会严重高估传导速度与幅度。

### 2. 有效样本量问题

水平序列自相关很高（ρx≈0.77、ρy≈0.84），Pyper-Peterman 校正后有效 N 仅约 80。
这意味着水平 r 的 p 值（1e-196）被极度高估——真实的独立信息量只有 80 个观测。

### 3. 锚定系数检验说明了什么

`log(PTA) = a + 1.05·log(PX)`，斜率接近 1 → 两者按**同一价格标尺**编制。
因此「PTA − PX」恒为负（约 −2478 元/吨），没有经济含义；
而「PTA − 0.655×PX」落在真实加工费量级（约 300 元/吨），是行业通用的收入型加工费口径。

**这是一个容易踩的坑**：如果不做这个检验，可能会误以为「PTA 比 PX 便宜 2400，
所以算错了」，或者反过来把 raw spread 当加工费解读。

### 4. 单耗敏感性

λ 从 0.600 到 0.700，价差均值从约 1050 元/吨 线性降至约 −450 元/吨。
每 0.005 的 λ 差异 ≈ 50 元/吨（PX 10000 元/吨时）。
所以报告必须给区间，不能只给一个数。

### 5. 领先滞后

- 交叉相关（收益率）：峰值在 lag=−2（r=0.152），lag=0 处 r≈0.1
- Granger：双向弱显著，但 F 值小
- 结论：**近乎同步定价**，统计上不存在可利用的稳定领先关系

## 五、为什么会出现背离

| 时期 | 现象 | 产业原因 | 数据支持 |
|---|---|---|---|
| 2026-06 起 | PTA 相对 PX 走强，价差走阔 | PTA 工厂大范围检修，产能利用率跌至近 13 年低位，现货去库 | SCI99 2026-08-20：年度平均加工费 414.26 元/吨（同比 +29.79%） |
| 2026-07 起 | 价差自 650 元/吨高位收缩 | 虹港、福海创、逸盛大连等装置重启，PTA 供给回升 | 中国金融信息网 2026-07-15 |
| 2026-03~04 | 上游涨、下游跟涨但幅度不足 | 美伊/红海冲突推升 Brent，石脑油—PX 成本传导成为 PX 定价主导 | 华金期货 2026-09-11；SCI99 |
| 2026-10-13 | PTA 短期偏强 | 独山能源 4#（300 万吨/年）停车；郑商所调整交割仓库 | 生意社 PTA 商品情报 2026-10-13 |

**注意表述**：以上是「时间窗口一致」，不是因果证明。检修与价差走阔同时发生，
也可能同时受需求、库存、成本预期影响。

## 六、本案例的局限（必须一起交付）

1. **未扣能源与折旧**：价差是收入型加工费，不等于企业利润
2. **醋酸价格缺失**：其他成本按 0 处理，实际应再加 100~300 元/吨
3. **无库存/开工率连续序列**：事件解释只能到「新闻级」，无法做定量回归
4. **现货 vs 期货基差**：2026-10-20 PX 现货 10500 元/吨 vs 期货约 9430 元/吨，
   基差 +10.19%，跨口径比较会失真
5. **样本窗口**：约 3 年，覆盖一轮完整的扩能—过剩—检修周期，但不覆盖更长周期
