# 看上下游价格联动

## 这个技能解决什么问题

业务方问的通常是三句话：

1. **上游涨了，下游跟不跟？跟得有多快？**
2. **现在的价差是高是低？还能不能做？**
3. **为什么那段时间上下游走势反了？**

回答这三句话，必须先把「能不能算价差」这件事查清楚，再谈统计。
**顺序错了，结论一定是错的。**

## 什么时候用

- 「PX 和 PTA 的价格是什么关系」「最近三年加工费怎么走的」
- 「原料涨了 10%，成品只涨了 3%，为什么」
- 「这个价差在历史上算高还是低」
- 「上下游谁领先谁」
- 「我们的合同该不该挂钩上游价格」

**不要用**：只需要单品种行情（用 `chem-market-brief`）、只需要相关系数（用 `12.查两个指标的相关性`）、
需要找客户名单（用 `b2b-lead-sourcing`）。

## 硬约束（违反即返工）

| 编号 | 约束 | 具体做法 |
|---|---|---|
| R1 | **不得编造工艺参数** | 单耗/收率/辅料耗量必须来自文献或公告，逐条记入 `references/02-工艺与单耗台账.md`；查不到就写「未核实」，不出数 |
| R2 | **先判断是否多原料** | 先画产业图，确认上游是否为唯一下游主要原料；若是多路线（如煤基/油基并存），加工价差只能按路线分别算，不能混算 |
| R3 | **相关性 ≠ 因果** | 任何「传导」表述必须同时给出水平口径与收益率口径；禁写「A 导致 B」 |
| R4 | **水平 vs 收益率分开报** | 两条曲线都要给 r、N、p、95%CI；水平相关虚高要写明原因（共同趋势/共同成本） |
| R5 | **口径写全** | 日期基准、地区、税费、计量单位、发布时点、频率、有效样本数，缺一不可 |
| R6 | **缺失不插值** | 缺哪天写哪天，统计用成对有效样本；样本不足输出「样本不足」而不是凑数 |
| R7 | **不给交易建议** | 不出目标价、不做多做空、不说「建议买入/卖出」 |

## 标准流程（七步）

### 第 0 步：先问清楚三件事
- 上下游具体品种与规格（PX 是对二甲苯，不是 PX 期货；PTA 是精对苯二甲酸）
- 时间范围与频率（用户说「近三年」→ 明确到日频还是周频）
- 用户真正关心的判断（传导强弱？价差高低？背离原因？）

### 第 1 步：核实产业关系（决定能否算价差）
产出：产业关系图 + 单耗台账。必须回答：
- 上游是不是下游的**唯一主要原料**？（PX→PTA：是）
- 有没有**第二条原料路线**？（PX→PTA：无商业化替代路线 → 可以算）
- **主料/辅料/溶剂**分别是什么、单耗多少？（PX 0.655 t/t；醋酸 0.030–0.039 t/t）
- 单耗的**代际差异**有多大？（0.647–0.657，±0.8%）

判定规则：
- 单一主料 + 单耗可追溯 → 算「理论加工价差」，并给敏感性区间
- 多主料并列（如丙烯酸有丙烷/丙烯两条路线）→ 分路线各算，或只做传导统计不算价差
- 主料不唯一或单耗无出处 → **不出价差**，只做价格联动统计，并在报告显著位置说明原因

### 第 2 步：取数并对齐口径
- 优先**同一机构、同一口径**的上下游序列，避免跨源拼接
- 核对：单位（元/吨 vs 美元/吨）、税费（含税 vs 不含税）、地区（华东 vs CFR 中国）、
  现货 vs 期货、发布时点（当日 08:30 vs 次日）
- **日期错位是隐形杀手**：两套数据若一个按报道日、一个按价格日，会造成约一个涨跌幅的系统偏差。
  用重叠期「同日 vs 错一日」的平均绝对差判定对齐方式（见 `scripts/validate_sources.py`）
- 双源互校：两个独立来源在重叠期应高度一致；不一致就查是不是口径不同

### 第 3 步：画价格曲线
- 原始水平曲线（元/吨）
- 标准化指数（首日=100），用于比较涨跌幅
- 分年度/分阶段的区间涨跌表

### 第 4 步：算理论加工价差
```
价差 = 下游价格 − λ × 上游价格 − 其他成本
```
- λ 用主口径值，**同时**给敏感性表（λ 每 ±0.005，价差平移约上游价×0.005）
- 历史分位用 `PERCENTILE.INC`（与 Excel 一致），给出 P10/P50/P90 与当前分位
- **锚定系数检验**：回归 log 下游 对 log 上游，斜率接近 1 说明两者同标尺（此时应用 raw spread，
  即下游−上游），接近单耗（0.65）才适合用单耗折算。这一步能防止「公式对了但口径错了」

### 第 5 步：滚动相关性
- 至少三个窗口（如 20/60/120 观测），默认报中间窗口
- 窗口内有效样本 < 80% 不出数（留空，不画）
- 同时报水平 r 与收益率 r，并给「|r|≥0.8 的窗口占比」作为稳定性指标

### 第 6 步：阶段划分与背离识别
- 阶段按**产业逻辑断点**预先定义（扩能投产、检修、政策、地缘），**不得按统计结果反复切**
- 背离定义要写清楚并可复现，例如「20 观测内 |Δ上游| ≥ 3% 且下游方向相反」
- 每个背离区间挂接事件（装置检修、库存、需求、政策），事件只用于解释，不用于证明因果

### 第 7 步：领先/滞后
- 交叉相关（水平与收益率两套），最大滞后阶数与频率匹配（日频 20 阶、周频 8 阶）
- Granger 检验给 F/p/N；说明「Granger 只说明时序上有增量信息，不是因果」
- 峰值贴近 0 且两侧快速衰减 → 结论写「近乎同步定价」，而不是「存在传导时滞」

## 交付物

1. **交互式 HTML 报告**（单文件，无外部依赖）：产业关系图、双价格曲线（可切水平/指数/收益率）、
   加工价差+分位（单耗滑块实时重算）、滚动相关、交叉相关、背离区间点击定位事件、结论与限制
2. **Excel 工作簿**（全部为活公式）：说明、口径与来源、参数（命名区域）、原始数据、单耗台账、
   单耗敏感性、加工价差、历史分位、相关性、滚动相关、领先滞后、阶段与背离、公式说明
3. **分析结果 JSON**：供二次开发

生成命令见 `scripts/run_all.py`。

## 报告必须包含的段落

1. 产业关系图 + 「能否算价差」的判定与理由
2. 口径对齐表（逐项：单位/税费/地区/日期/频率/校验）
3. 价格曲线与分区间涨跌
4. 理论加工价差 + 分位 + 单耗敏感性 + 锚定系数检验
5. 滚动相关性（水平 vs 收益率）
6. 阶段表 + 背离区间 + 事件台账
7. 领先滞后（交叉相关 + Granger）
8. 结论、适用边界、**禁止事项**

## 常见错误（都是踩过的）

| 错误 | 后果 | 正确做法 |
|---|---|---|
| 直接用水平相关说「传导很强」 | 结论被共同趋势污染，r≈0.95 实际日传导仅 0.1 | 必须并列收益率口径 |
| 单耗系数随手取 1.0 或 0.7 | 价差出现假趋势（差 0.35×上游价） | 用文献值 + 敏感性 + 锚定检验 |
| 上下游数据日期错一天 | 价差系统性偏差（示例：约 80 元/吨） | 用重叠期错位检验判定对齐 |
| 按结果反复切分阶段 | 过度拟合，结论不可复现 | 预先定义阶段并写进配置 |
| 缺失日插值补全 | 人为平滑，夸大相关性 | 成对有效样本，样本不足就说不足 |
| 把加工价差当利润 | 高估企业盈利 | 明确「不含折旧、能源、物流」 |
| 只给一个数字不给 N | 无法判断可信度 | 每个统计量都带 N、窗口、区间 |

## 复用路线

换一组上下游品种时：

1. 改 `scripts/config.py` 的品种、单耗、阶段定义
2. 换 `processed/` 下的价格 CSV（日期,上游,下游）
3. 跑 `python scripts/run_all.py`
4. 重写 `references/02-工艺与单耗台账.md`（这是唯一不能省的人工步骤）
