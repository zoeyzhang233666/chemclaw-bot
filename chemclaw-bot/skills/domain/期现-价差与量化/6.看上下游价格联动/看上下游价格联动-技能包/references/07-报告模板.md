# 07 报告模板（章节骨架与写作规范）

> 报告的读者通常是要拿去做判断的人，不是统计学家。
> 结构上先给结论、再给证据；证据必须能被复核。

## 一、整体结构（九节，顺序不要改）

```
0  头部：标题 + 数据标签（真实数据/口径/频率/N/窗口）
1  产业关系核验：能否算价差
2  口径对齐：日期/地区/税费/单位
3  价格曲线与变化
4  理论加工价差与历史分位
5  滚动相关性：传导是否稳定
6  跟随与背离阶段
7  领先/滞后统计
8  事件核对：装置/库存/需求
9  结论、适用边界与禁止事项
```

第 1 节和第 2 节**不能省**。省了这两个，后面所有数字都可以被质疑。

## 二、头部标签要写什么

- 数据性质：真实公开数据 / 模拟数据（明确标注）
- 数据源：主源名称 + 备份源
- 频率与样本：日频，成对有效观测 N=xxx
- 研究窗口：YYYY-MM-DD ~ YYYY-MM-DD
- 单耗系数与出处

## 三、每节的写作规范

### §1 产业关系核验

必须有：产业关系图（带单耗标注）+ 「能否算价差」的明确判定句。

> 判定：PX 为 PTA 唯一主要原料，单耗 0.655 t/t 有文献支撑（长江期货 2023-12-18），
> 代际差异仅 0.647~0.657，**可以**计算理论加工价差。
> 但该价差不含折旧与能源，只能读作收入型加工费。

### §2 口径对齐

用表格，逐项列：价格定义 / 计量单位 / 税费 / 日期基准 / 频率 / 交叉校验。
最后给一条「口径风险」提示。

### §3 价格曲线

- 三条线：上游、下游、价差（价差单独缩放，否则会被压平）
- 可切换形态：水平 / 标准化指数 / 收益率
- 附分区间涨跌表

**必须写的一句**：水平相关高是因为共同趋势，不能作为传导强的证据。

### §4 加工价差

- 当前值 + 历史分位 + P10/P50/P90
- 单耗敏感性表
- **锚定系数检验**结果与解释
- 交互滑块说明（λ、其他成本）

### §5 滚动相关

- 三档窗口切换
- 稳定性指标（|r|≥0.8 占比）
- 水平与收益率分开画

### §6 阶段与背离

- 背离区间表（点击可定位事件）
- 分阶段统计表（N / 涨跌 / 价差 / 两种相关口径）
- 一句免责：方向冲突是利润再分配，不是数据失真

### §7 领先滞后

- 交叉相关柱状图（正 lag = 上游领先）
- Granger 表（F/p/N + 结论标签）
- 峰值贴近 0 时要写「近乎同步」

### §8 事件核对

表格：日期 / 类型 / 事件 / 说明（产业数据支持）/ 对价差方向。
每行都有来源。

### §9 结论与禁止事项

分两栏：
- 左：3~5 条结论，每条带数字与 N
- 右：**不能做的事**（因果、利润、交易建议、编造系数、插值）

## 四、语言规范

| 场景 | ✅ 这样写 | ❌ 不要这样写 |
|---|---|---|
| 相关 | 「水平 r=0.955，日收益率 r=0.096」 | 「相关性极高，传导明显」 |
| 原因 | 「与该阶段检修窗口一致」 | 「因为检修所以上涨」 |
| 结论强度 | 「统计显著但经济意义有限」 | 「显著，因此可以用于预测」 |
| 缺口 | 「醋酸价格序列未取得，其他成本按 0 处理」 | 「估计其他成本约 300 元」 |
| 建议 | （不给） | 「建议在价差低于 P10 时做多」 |

## 五、图表规范（HTML）

- 深色底、三条主色区分（上游蓝、下游绿、价差黄）
- 每个图下方一行图例 + 一行口径说明
- 分位参考线用虚线并标注 P10/P50/P90 具体数值
- 所有交互控件旁写明默认值与含义
- 打印/投屏时不能依赖 hover 才能看懂

## 六、交付前自检

- [ ] 每个数字都能在工作簿里找到对应单元格
- [ ] 每个相关系数都带 N
- [ ] 每个「显著」都带 p 值
- [ ] 每个阶段都能在 config 里找到
- [ ] 每个事件都有来源
- [ ] 没有出现「导致」「因此会」「建议」
- [ ] 缺口全部显式标注
