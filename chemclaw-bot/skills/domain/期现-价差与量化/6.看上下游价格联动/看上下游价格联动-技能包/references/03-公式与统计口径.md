# 03 公式与统计口径说明

> 每一个公式都标注：算什么、怎么算、在 Excel 里怎么写、什么情况下会出错。
> 报告与工作簿中的数字必须能用这里的公式复核。

## 1. 理论加工价差

```
Δ(t) = P_down(t) − λ · P_up(t) − C_other
```

- λ：主料单耗（PX→PTA 取 0.655）
- C_other：其他成本（默认 0，即收入型加工费）

Excel：`=C5-Lambda*B5-OtherCost`（Lambda / OtherCost 为命名区域）

**陷阱**：λ 每变化 0.001，Δ 平移 `P_up × 0.001`。PX 10000 元/吨时即 10 元/吨。
敏感性表必须给。

## 2. 收益率

```
r(t) = P(t)/P(t−1) − 1        （简单收益率，日频）
```

Excel：`=B6/B5-1`

**为什么用简单收益率**：与业务语言一致（「涨了几个点」），且日频下与对数收益率差异可忽略。
若做长周期回归，改用对数收益率更稳。

## 3. Pearson 相关系数

```
r = Σ(x−x̄)(y−ȳ) / √[Σ(x−x̄)² · Σ(y−ȳ)²]
```

Excel：`=CORREL(x, y)`；`R² = RSQ`

**陷阱**：
- 水平序列含趋势 → r 虚高，必须同时给收益率口径
- 对异常值敏感 → 加 Spearman 复核

## 4. Spearman 秩相关

对秩求 Pearson。Excel 无直接函数，用辅助列：

```
秩 = COUNTIF(区域,"<"&x) + 1 − (COUNTIF(区域,x) − 1)/2      ← 平均秩
ρ  = CORREL(秩x, 秩y)
```

注：`RANK.AVG` 直接返回数组时要按 `Ctrl+Shift+Enter` 录入，在部分读取器里会失效；
本技能改用「Python 侧预先算好平均秩写入辅助列 + CORREL」的方式，保证活公式可算。

## 5. t 统计量与 p 值

```
t = r·√(n−2)/√(1−r²),   df = n − 2
p = 2·(1 − T.cdf(|t|, df))          # 双尾
```

Excel：`=B5*SQRT((D5-2)/(1-B5^2))`，`=T.DIST.2T(ABS(E5),D5-2)`

**陷阱**：n 必须是**有效样本数**（成对可得），不是自然日数；自相关序列需另做有效样本校正。

## 6. Fisher z 置信区间

```
z  = atanh(r)
se = 1/√(n−3)
CI = tanh(z ± z_{1−α/2} · se)
```

Excel：`=TANH(ATANH(B5)-NORM.S.INV(1-Alpha/2)/SQRT(D5-3))`

**陷阱**：n < 10 时不可靠；r 接近 ±1 时区间会塌缩。

## 7. 有效样本量（Pyper & Peterman）

```
N_eff = N · (1 − ρx·ρy) / (1 + ρx·ρy)
```

ρx、ρy 为两序列一阶自相关。
Excel：`=B16*(1-C16*D16)/(1+C16*D16)`

示例：水平序列 N=369，ρx≈0.77、ρy≈0.84 → N_eff≈80。
含义：水平相关的「有效信息量」只有约 80 个独立观测，p 值被严重高估。

## 8. 分位数

```
PERCENTILE.INC(range, p)   ← 线性插值，含端点，p∈[0,1]
PERCENTRANK.INC(range, x)  ← x 在历史中的位置
```

**陷阱**：`PERCENTILE.EXC` 结果不同（示例 P10 差 224 元/吨）。报告与工作簿必须统一用 INC，
并在公式说明页写明。

## 9. 滚动相关

```
r_t(w) = CORREL(P_up[t−w+1..t], P_down[t−w+1..t])
```

有效样本门槛：`count ≥ w × 0.8`，否则空值。

**陷阱**：
- 窗口短 → 噪声大；窗口长 → 看不见拐点。至少给三档
- 窗口内某序列为常数（连续平盘）→ CORREL 返回 `#DIV/0!`，需 `IFERROR` 处理

## 10. 交叉相关（领先/滞后）

```
ρ(k) = CORREL(P_up[1..n−k], P_down[1+k..n])     k > 0：上游领先
ρ(k) = CORREL(P_up[1−k..n], P_down[1..n+k])     k < 0：下游领先
```

**陷阱**：水平序列做交叉相关，会因为共同趋势而在所有 lag 上都偏高，
必须用收益率口径复核；峰值 lag 的经济解释仍需产业机制支持。

## 11. Granger 因果检验

对 `y_t = α + Σa_i·y_{t−i} + Σb_j·x_{t−j} + ε`，检验 `H0: b_1=…=b_p=0`

```
F = [(RSS_r − RSS_u)/p] / [RSS_u/(n−k)]
```

**陷阱**：Granger ≠ 因果。它只说「x 的过去值对预测 y 有增量信息」。
共同驱动因子（如原油）会让双向都显著。

## 12. 背离识别规则

```
20 观测窗口内：
  若 |ΔP_up| ≥ 3% 且 sign(ΔP_down) ≠ sign(ΔP_up) → 记为方向冲突
  连续 ≥ 10 个观测存在冲突 → 输出为一个背离区间
```

规则必须写死在代码里并写进报告，保证别人能复现。

## 13. Excel 兼容性注意事项（踩坑记录）

| 函数 | 是否加 `_xlfn.` 前缀 | 说明 |
|---|---|---|
| PERCENTILE.INC / PERCENTRANK.INC / T.DIST.2T / NORM.S.INV / STDEV.S | **要加** | 2010 版新增函数，Excel 存储时带前缀 |
| CORREL / STDEV / MEDIAN / RANK.AVG / SKEW / KURT | **不能加** | 2007 版函数，加了反而 `#NAME?` |
| SUMPRODUCT 数组比较 | 谨慎 | 不同读取器对 `--(range<x)` 解析有差异 |
| INDEX(range, cell) 动态行号 | 谨慎 | 建议用字面行号或 OFFSET |
| `IF("TRUE",…)` | 禁用 | 文本 "TRUE" 不等于布尔 TRUE，需用 `IF(1=1,…)` |

以上均已固化在 `scripts/xlfn_fix.py` 与 `scripts/verify_excel.py` 的校验中。
