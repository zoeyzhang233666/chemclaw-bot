# 01 方法论：上下游价格联动怎么做才算严谨

## 为什么这件事容易做错

上下游价格联动看起来只是「画两条线、算个相关系数」，但有四个陷阱会系统性地把结论带偏：

1. **水平相关虚高**：两个都是石化产品，都受原油驱动，水平价格天然同涨同跌。r 接近 0.95 很常见，
   但这不等于「上游涨价会传到下游」。示例案例中水平 r=0.955，而日收益率 r 只有 0.096。
2. **单耗系数用错**：价差公式里的系数每错 0.01，价差平移就是「上游价格 × 0.01」。
   PX 10000 元/吨时，0.01 的误差等于 100 元/吨——足以把「亏损」翻成「盈利」。
3. **日期错位**：一个序列按报道日、一个按价格日，会让加工价差带上一个涨跌幅量级的系统偏差。
4. **把价差当利润**：理论加工价差只扣原料，不扣能源、折旧、人工、物流、检修损失。

## 正确顺序

```
产业关系核验 → 口径对齐 → 水平描述 → 价差构造 → 相关性分解 → 阶段/背离 → 领先滞后
```

**不能跳步**。尤其第一步：如果上游不是下游唯一主要原料，后面所有价差计算都无意义。

## 一、产业关系核验清单

| 检查项 | 若是 | 若否 |
|---|---|---|
| 上游是否是下游唯一主要原料 | 可以做单耗折算价差 | 分路线/分工艺分别算，或只做联动统计 |
| 是否存在第二条原料路线 | 同上 | 需要按实际产能占比加权 |
| 主料单耗是否有公开出处 | 用文献值 + 区间敏感性 | 不出价差，只做价格统计 |
| 辅料/溶剂耗量是否可忽略 | 并入「其他成本」参数 | 单独列项，缺价格序列就写缺口 |
| 下游是否有替代品/回料 | 在限制中说明 | — |
| 产品是否有多个牌号/规格 | 指定基准规格 | 混算会产生虚假价差 |

## 二、口径对齐清单

每一条都要能回答「是什么、哪来的、什么时候发布」：

- **品种与规格**：优等品/合格品、基准牌号
- **地区**：华东/华南/山东；进口货是 CFR 还是到岸完税
- **税费**：含税/不含税（差 13% 增值税，不能混）
- **计量单位**：元/吨、美元/吨；汇率与关税
- **价格性质**：现货成交/现货基准/期货结算/评估价
- **发布时点**：当日 08:30 / 收盘后 / 次日上午
- **频率**：日/周/月；周末是否更新
- **有效样本**：成对可得的天数，不是自然日数

### 日期错位的检测方法

用重叠期做两种对齐比较：

```
同日对齐：     mean|上游(d) − 上游参考(d)|
错一日对齐：   mean|上游(d) − 上游参考(d+1)|
```

取平均绝对差更小的那种。示例发现英文站「页面日期 = 报道日」，价格实际对应链接日期，
即标称日期比价格口径晚一天；校正后两源差异为 0 元/吨。

## 三、水平 vs 收益率：必须分开报

| 口径 | 反映什么 | 通常数值 | 用途 |
|---|---|---|---|
| 价格水平相关 | 共同趋势、共同成本中枢 | 0.9 以上很常见 | 说明「同属一个成本体系」，**不能**说明传导 |
| 日收益率相关 | 逐日联动的强度 | 常在 0.1~0.5 | **判断传导强度的主口径** |
| 周收益率相关 | 略滞后于日频的联动 | 通常高于日频 | 稳健性复核 |
| 滚动相关 | 联动是否随时间变化 | — | 找结构断点 |

**表述模板**：
> 水平 r=0.955（N=369），日收益率 r=0.096（p=0.065，不显著）。说明两者同属一个成本体系、
> 长期中枢同步，但逐日的价格传导很弱，价差波动主要来自两者对共同成本的反应幅度不同。

## 四、理论加工价差

```
价差 = 下游价格 − λ × 上游价格 − 其他成本
```

- λ 必须是文献/公告值，写进台账
- 其他成本 = Σ(辅料单耗 × 辅料价格) + 动力 + 折旧（缺数据就置 0 并说明这是「收入型加工费」）
- 分位：`PERCENTILE.INC`，给 P10/P50/P90 与当前分位
- 敏感性：λ 在合理区间内步进，看价差均值与分位怎么动

### 锚定系数检验（重要，能救很多错误）

回归 `log(下游) = a + b·log(上游)`：

- b ≈ 1（示例 1.05）→ 两者按**同一价格标尺**编制，下游 ≈ 上游 + 加工费。
  此时「下游 − λ×上游」会引入 `(1−λ)×上游` 的假趋势，应改用 raw spread。
- b ≈ 单耗（0.65 左右）→ 上游按成本进入下游，`下游 − 0.655×上游` 才有经济含义。

示例案例中 b=1.05 且均值 PTA/PX=0.70，处于两者之间：
PTA−PX 恒为负（约 −2400），PTA−0.655×PX 落在真实加工费量级（约 300 元/吨）。
因此主口径用 0.655，但报告必须写明「PX 与 PTA 的基准价编制标尺相近」这一风险。

## 五、滚动相关

- 窗口：至少给 3 个（短/中/长），默认报中间
- 有效样本门槛：窗口内 < 80% 不出数
- 稳定性指标：|r| ≥ 0.8 的窗口占比
- 解读：滚动 r 突然塌陷 = 出现结构性变化（装置事故、政策、扩能投产）

## 六、阶段与背离

- 阶段**预先**按产业事件定义，写进配置，不得按结果反复切（否则是数据窥探）
- 背离定义要可复现：「20 观测窗口内 |Δ上游| ≥ 3% 且下游方向相反」
- 每个背离区间必须挂事件，否则只能写「原因待核」

## 七、领先/滞后

- 交叉相关：分别用水平与收益率，正 lag 表示上游领先
- Granger：`检验上游是否对下游有增量预测力`，给 F/p/N
- **解读纪律**：
  - 峰值在 0 附近、两侧快速衰减 → 「近乎同步定价」
  - 峰值明显为正且右侧持续 → 可写「统计上存在滞后」，但仍需产业机制佐证
  - Granger 显著但幅度很小 → 写「统计显著但经济意义有限」

## 有效样本量校正（可选但要会）

自相关序列的显著性会被高估。用 Pyper & Peterman 校正：

```
N_eff = N × (1 − ρx·ρy) / (1 + ρx·ρy)
```

ρx、ρy 是两序列各自的一阶自相关。示例中水平序列 N=369，有效 N 仅约 80。
报告里给「原始 N」与「有效 N」两个数，读者自己判断。

## 输出纪律

每个数字都要能回答五个问题：
**口径是什么？样本区间？有效样本数？是否显著？来源在哪？**

答不上来的数字，不要写进报告。
