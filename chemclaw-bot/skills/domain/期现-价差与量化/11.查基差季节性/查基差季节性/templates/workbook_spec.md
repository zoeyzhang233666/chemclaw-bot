# Excel 工作簿表结构规范

15 个表，顺序固定。每张表的用途、字段、以及哪些列必须是**真实公式**都写在下面。

设计原则：
1. **每个数字可追溯到来源**——现货表带原文链接，映射表带合约代码
2. **关键统计保留公式**——让读者能改数据后自动重算
3. **缺口显式标注**——不允许留空白的"友好"处理

---

## 00_封面与口径

单列键值表，回答"这份数据是什么、能不能用来做决策"。

| 行 | 内容 |
|---|---|
| 研究标的 | 品种 + 交易所 + 现货口径 |
| 基差定义 | `基差 = 现货 - 期货`（写死符号） |
| 现货口径 | 地区/规格/税基/单位/频率 |
| 现货口径警示 | 若与用户要求不一致，此处必须用醒目底色标出 |
| 现货来源 | 完整 URL 模板 |
| 期货来源 | 接口地址 + 合约数量 |
| 期货合约规则 | 最后交易日/品级/交割单位 |
| 映射规则1/2/3 | 每种口径的定义文字 |
| 频率与对齐 | 骨架、周月对齐方式 |
| 分位方法 | 经验分位说明 |
| 缺失数据处理 | 明确写"未做任何插值" |
| 数据缺口 | 列出所有不可得数据 |
| 使用边界 | "不构成预测"声明 |

**格式要求**：带"★"的行用红色底色（`#ffe4e4`），确保读者不会漏看口径警示。

## 06_日度基差 ★核心表

| 列 | 字段 | 类型 |
|---|---|---|
| A | 日期 | 文本 |
| B | 年 | 数值 |
| C | 月 | 数值 |
| D | 现货(元/吨) | 数值 |
| E | 期货(元/吨) | 数值 |
| F | **基差(元/吨)** | **公式 `=D{r}-E{r}`** |
| G | 合约 | 文本 |

**F 列必须是公式**，浅蓝底色（`#f2f7fb`）标出。
表尾追加两个校验公式：

```
=AVERAGE(F4:F{last})   基差均值
=COUNT(F4:F{last})     样本数
```

## 09_经验分位 ★含公式复算

三个区块：

**一、月度分位表**

| 月份 | 有效样本年数 | 均值 | 中位数 | p10 | p25 | p75 | p90 | 最小 | 最大 |

**二、公式复算示例**

必须放一段能被 Excel 实际计算出来的公式区，证明预计算表没问题：

```
指标        | Excel 公式结果              | 辅助列(该月各年基差)
均值        | =AVERAGE(跨表引用...)      | -17.25
中位数      | =MEDIAN(...)              |  63.67
p10        | =PERCENTILE(G12:G15,0.1) |  31.83
p25        | =PERCENTILE(G12:G15,0.25)|  -9.83
p75        | =PERCENTILE(G12:G15,0.75)|
p90        | =PERCENTILE(G12:G15,0.9) |
样本数      | =COUNT(...)               |
对照(预计算) | 17.11 11.00 -15.02 ...   |
```

**关键坑（本次踩过）**：
- `PERCENTILE.INC` 在部分重算引擎（LibreOffice）下报 `#NAME?` → **用 `PERCENTILE`**（两者算法相同）
- `PERCENTILE({跨表引用,跨表引用}, 0.1)` 的数组字面量形式会返回 `#N/A` → **必须用本表连续区域**
- 所以：先把该月各年基差写到本表辅助列（连续），再用 `PERCENTILE(本表区域, q)`

**三、周度分位表**

| ISO周 | 有效年数 | 均值 | 中位数 | p10 | p25 | p75 | p90 |

## 10_当前年位置

| 口径 | 类型 | 当前值 | 同期分位 | z分数 | 历史均值/标准差 |
|---|---|---|---|---|---|
| 近月连续 | 月度(10月) | 631.67 | 100% | z=5.49 (样本4年) | 54.38 / 105.21 |
| 近月连续 | 周度(W43) | 631.67 | 100% | z=6.82 (样本4年) | 42.00 / 86.41 |
| 主力连续 | 月度(10月) | 823.67 | 100% | z=5.09 (样本4年) | 74.38 / 147.14 |
| 主力连续 | 周度(W43) | 823.67 | 100% | z=6.36 (样本4年) | 57.50 / 120.42 |

**必须有"重要提示"合并单元格**（黄色底色）：
> 10月历史同期样本仅4年，100%分位与 z>5 属于小样本下的极端读数，
> 不能据此推断基差必然收敛。

## 12_固定交割月

| 交割月 | 合约 | 样本日数 | 起始 | 结束 | 基差均值 | 基差中位 | 最小 | 最大 | 说明 |

## 13_数据缺口与限制

| 缺口/风险项 | 说明 | 处理方式 |

用颜色区分状态：
- 红色（`#ffe4e4`）= 硬缺口，无法解决
- 黄色（`#fff4d6`）= 受限，需提示
- 绿色（`#e3f6ea`）= 已处理

## 样式约定

| 用途 | 格式 |
|---|---|
| 标题 | 17pt 粗体，深蓝 `#0e3a5c` |
| 表头 | 白字，深蓝底 `#14405f`，居中，换行，冻结窗格 |
| 数值 | `#,##0.00`，边框 `#dde6ee` |
| 整数 | `#,##0` |
| 百分比 | `0.0%` |
| 公式单元格 | 浅蓝底 `#f2f7fb` |
| 口径警示 | 红底 `#ffe4e4` |
| 受限提示 | 黄底 `#fff4d6` |
| 已处理 | 绿底 `#e3f6ea` |
| 负值 | 绿色 `#067647` |
| 正值 | 红色 `#b42318` |

**注意**：中国金融惯例是**红涨绿跌**，与欧美相反。基差为正（现货升水）用红色。
