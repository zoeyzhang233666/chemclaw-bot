# 数据源可用性实测结论

本文件记录各数据源在**实际抓取中**的可用性，避免后来者重复踩坑。
测试时间：2026-10。所有结论都来自真实请求，未经实测的渠道不写入本表。

---

## 一、现货数据

### 1. 生意社（100ppi）—— 全国基准价，可用 ✅

**可用渠道：资讯列表页（非图表）**

```
https://me.100ppi.com/news/list--1217-{page}.html     page = 1..37（38 起为空）
```

列表中每篇文章标题即含当日基准价，正则提取标题即可，无需进详情页：

```
ROW   = <a href="(https://www\.100ppi\.com/news/detail-(\d{8})-\d+\.html)"[^>]*>([^<]{4,140}?)</a>
VALUE = (\d{1,2})月(\d{1,2})日生意社甲醇基准价为([\d,]+\.?\d*)元/吨
```

**实测结果**：1083 条，覆盖 2022-08-17 → 2026-10-20，每条都附原文链接。
交叉验证方式：用另一套独立的解析脚本重跑，条数与数值完全一致。

**口径说明（务必照抄进报告）**：
- 生意社官方定义："基于价格大数据与价格模型产生的**交易指导价**"
- 公式：`结算价 = 基准价 × K + C`，其中 C 吸收区域价差与物流
- 因此它是**全国口径、含税、元/吨**的参考价，**不是**华东/太仓仓库成交价

**不可用渠道**：
- `https://www.100ppi.com/news/detail-817.html` 等详情页 → 返回 636 字节的反爬 JS 壳，无法取数
- 品种页内嵌图表 → 数据经自定义 packer 编码，解码后数值约为 1300（真实值 2500–4800），存在未公开的基准偏移，**不可使用**。已在 `ppi_graph_info.py` 中确认此偏移存在，放弃该路径。
- 区域图表 → 仅保留硬编码的 93 天窗口，且坐标标签比文章日期系统性偏移 1 天

### 2. 隆众资讯（oilchem）—— 需登录 ❌

```
GET https://dc.oilchem.net/ndc/price/list/queryPricePage
    params: varietiesId=146 (甲醇), regionId=3 (华东) / 154 (太仓) / 83 (江苏)
```

返回体中 `pricePowerSee: false`，价格字段字面值 **"请登录"**。
无公开价格数据。区域细分（太仓/江苏）同样不可得。

### 3. 卓创资讯（sci99）—— 返回空 ❌

```
GET https://prices.sci99.com/api/zh-cn/product/multi/datavalue
    params: ppid=12608 (甲醇), region=20 (华东)
```

返回 `{"data": ""}`，无数据。需付费订阅。

### 4. 东方财富 / 新浪 / 郑商所 现货接口 ❌

| 接口 | 结果 |
|---|---|
| `RPT_FUTU_SPOTPRICE` | `报表配置不存在` |
| `RPT_FUTU_BASIS` | `报表配置不存在` |
| 郑商所官网现货/仓单 | HTTP 412 |
| `hq.sinajs.cn` 实时行情 | HTTP 403（需 Referer 仍失败） |

### 现货数据结论

**华东区域优等品现货的 5 年历史，在免费渠道不可得。**
这不是抓取技巧问题，是数据本身被付费墙锁住。

因此遇到"华东甲醇现货基差"这类需求时，正确做法是：
1. 明确告知用户目标口径不可得及原因
2. 提出降级方案（全国基准价口径）
3. 让用户确认后再继续，并在所有交付物中显式标注降级

**绝不可**把全国基准价标成华东现货价。

## 二、期货数据

### 新浪财经逐合约 K 线 —— 可用 ✅

```
https://stock.finance.sina.com.cn/futures/api/jsonp.php/var%20t=/InnerFuturesNewService.getDailyKLine?symbol=MA2501
备选域名：stock2.finance.sina.com.cn
```

返回 JSONP，字段：

| 字段 | 含义 |
|---|---|
| `d` | 日期 |
| `o` | 开盘 |
| `h` | 最高 |
| `l` | 最低 |
| `c` | 收盘 |
| `v` | 成交量 |
| `p` | 持仓量（OI） |
| `s` | 结算价 |

**实测**：甲醇可取得 95 个合约（MA1905 ~ MA2703），每个合约含完整日线。
这是**构建自行映射的基础**——必须逐合约拉取，不能只拉连续合约。

### 新浪主力连续 MA0 —— 可用但规则不明 ⚠️

```
symbol=MA0
```

**实测对比结论**：MA0 与"持仓量最大"规则在 1 644 个交易日中有 **48 天不一致**，
且不一致集中在换月日附近——MA0 **滞后一天**，多保留旧合约一天。

例：2026-09-11，MA0 收盘 3 016，对应 MA2701（持仓 564 760），
而当日 MA2610 持仓 538 818（更小），说明 MA0 的切换点不等于 max-OI 切换点。

**结论**：MA0 可以用于快速查看，但**不能作为可复现研究的输入**。
必须从逐合约数据自行构建连续序列。

### 技术注意事项

1. **必须处理 `Content-Encoding: br`**。很多站点返回 Brotli 压缩。
   ```bash
   pip install brotli
   ```
   未安装时 `requests` 会抛 `ModuleNotFoundError: brotli`。
2. 部分站点需要 `Referer` 头。
3. 反爬返回的空壳页通常很小（数百字节）；按**响应长度 + 页面标题**双重判定，不要只看状态码 200。
4. 正则中含 `api`、`(` 等字符时务必 `re.escape()`，否则会报
   `missing ), unterminated subpattern`。

## 三、库存/仓单数据 —— 不可得 ❌

| 来源 | 结果 |
|---|---|
| 郑商所仓单日报 | HTTP 412 |
| 郑商所库存周报 | HTTP 412 |

**处理原则**：既然不可得，就**留空并标注"数据缺口"**。
不得用任何代理变量估算，不得编造。

报告中"极值阶段的库存/仓单背景"一栏明确写：数据不可得，未做任何估算。

---

## 四、给后来者的检查顺序

1. 先试生意社资讯列表页（现货）→ 大概率可用
2. 再试新浪逐合约 K 线（期货）→ 大概率可用
3. 库存/仓单先试交易所 → 大概率 412，直接判定缺口
4. 区域现货（隆众/卓创）如果用户坚持要，提前告知需付费

抓完立刻做两件事：
- **交叉验证**：用两套独立解析逻辑重跑，比对条数与数值
- **落盘原始数据**：`raw/` 目录保留原始响应，`out/` 保留清洗结果，每条附来源链接
