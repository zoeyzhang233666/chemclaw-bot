# 统计方法说明

## 1. 基差定义

```
basis_t = spot_t − fut_t
```

固定符号，全程不变。正 = 现货升水。

---

## 2. 时间对齐

### 2.1 骨架选择

以**期货交易日**为骨架。原因：期货交易日是确定且连续的，现货发布可能有缺报。

### 2.2 现货缺失处理

现货缺报的交易日：

- **不插值**
- **不前值填充**
- **不删除整行**（保留日期，标记 `缺失`）

统计时仅纳入双端都有的样本，并在报告中给出缺失计数。
甲醇实测：1 020 个期货交易日中有 1 003 天有现货，缺失 17 天。

### 2.3 周度对齐

```
ISO 周 = ISO 8601 周编号（周一为周首）
周度值 = 该 ISO 周内最后一个有配对数据的交易日的基差
```

使用 `date.isocalendar()`，注意 ISO 年可能与自然年不同（跨年周）。

### 2.4 月度对齐

```
月度值 = 该自然月最后一个有配对数据的交易日的基差
附带月度均值 = 该月所有基差的算术平均
```

月末值与月均值都要给：月末值用于分位统计（口径纯净），月均值用于观察月内波动。

## 3. 经验分位（核心算法）

### 3.1 定义

对某季节位置（如"10 月"）的历史值集合 `v[0..n-1]` 升序排列，求 q 分位：

```python
def pctile(vals, q):            # q ∈ [0,100]
    s = sorted(vals)
    if len(s) == 1:
        return s[0]
    pos = (len(s) - 1) * q / 100.0
    lo = int(pos)
    hi = min(lo + 1, len(s) - 1)
    return s[lo] + (pos - lo) * (s[hi] - s[lo])
```

这是**线性插值经验分位**，与以下实现等价：

| 实现 | 调用 |
|---|---|
| numpy | `np.percentile(v, q, method='linear')`（默认） |
| Excel | `PERCENTILE(v, q/100)` 或 `PERCENTILE.INC` |
| R | `quantile(v, q/100, type=7)` |

### 3.2 为什么不用正态分位

样本通常只有 4–5 个点，正态假设完全不成立。
经验分位至少保证分位点落在实际观测区间内。

### 3.3 样本量门槛

```
MIN_SAMPLES = 3
```

有效样本 < 3 年 → 标记 `样本不足 (n_sufficient=False)`，不参与形态判断。

### 3.4 必须同时报告

- `n_years`：该季节位置实际有数据的年数
- `years`：具体是哪几年

因为"10 月的 p90 = 471"如果不带 n=5，读者会误以为是稳健估计。

## 4. 集中趋势：均值与中位数并列

```
mean   = Σv / n
median = 中位数
```

**为什么必须并列**：

极端年份会把均值拉飞。甲醇 9 月实测：

| 指标 | 值 |
|---|---|
| 均值 | 263.33 |
| 中位数 | 14.83 |
| 最大 | 1 201.00 |

均值是中位数的 **17.8 倍**，因为 2026 年 9 月出现极端升水。

**判据**：当 `|mean − median| / |median| > 2` 时，以中位数为主要形态判据，
并在报告中解释背离原因。

## 5. 稳定性指标

### 5.1 季节性方差占比

```
grand_mean        = 全部月度观测的均值
between_month_SS  = Σ_m n_m × (mean_m − grand_mean)²
within_month_SS   = Σ_m Σ_i (v_mi − mean_m)²
total_SS          = between_month_SS + within_month_SS

seasonal_ss_share = between_month_SS / total_SS
```

**含义**：季节形态（月份）解释了基差总方差的多少比例。

| 取值 | 解读 |
|---|---|
| > 0.5 | 季节性很强，月份是主导因素 |
| 0.25–0.5 | 季节性中等 |
| < 0.25 | 季节性弱，年份间波动主导 |

甲醇实测：**0.190（19.0%）** → 季节性弱。

### 5.2 跨年变异系数

```
CV_m = sd(v_m) / |mean(v_m)|
```

| 取值 | 解读 |
|---|---|
| < 0.5 | 该月形态稳定 |
| 0.5–1.0 | 中等 |
| > 1.0 | 不稳定，跨年差异大于均值本身 |

甲醇实测：只有 4 月（CV 0.224）稳定，多数月份 CV > 1，11 月最差（CV 6.0）。

### 5.3 升水年份占比

```
pos_ratio_m = count(v_m > 0) / n_m
```

用来回答"这个月历史上是升水还是贴水"。
甲醇 8 月实测：`pos_ratio = 0.0`（5 年中 8 月**全部**贴水）——这是最可靠的季节特征之一。

### 5.4 分位极差

```
spread_m = p90_m − p10_m
```

宽度上的稳定性，与 CV 互为补充。

## 6. 当前年位置

### 6.1 经验排名

```
below_ratio = count(历史同期值 < 当前值) / n_hist × 100%
```

直观：当前值超过了历史上百分之多少的年份。

### 6.2 z 分数

```
z = (当前值 − mean_hist) / sd_hist
```

用样本标准差。n < 3 时不计算。

### 6.3 关键警告：小样本下的极端读数

甲醇 10 月实测：`below_ratio = 100%`、`z = 5.49`、`n_hist = 4`。

这个"100% 分位 + 5.5 个标准差"看起来是极强的信号，但：
- 4 个样本点算出的标准差本身极不稳定
- 100% 分位只意味着"比另外 4 年都高"
- 只要有 1 个样本落在极端位置，分位就会顶到 0% 或 100%

**正确表述**：
> "当前基差处于 10 月历史同期 100% 分位（样本仅 4 年，含 2026 年本身的极端值），
> 这是一个弱样本强读数，不能据此推断基差必然收敛。"

**错误表述**：
> "基差处于历史极值，必然回归。"

## 7. 换月污染量化

### 7.1 跨日跳空

```
gap_k = close_移入(换月日) − close_移出(换月日−1)
```

### 7.2 同日两合约价差（更干净）

```
spread_k = close_旧(换月日) − close_新(换月日)
```

同一天两个合约同时报收，剥离了市场日内波动，纯粹反映合约间价差。

### 7.3 污染控制评估

```
ratio = mean(|Δbasis| 换月日) / mean(|Δbasis| 非换月日)
```

| ratio | 结论 |
|---|---|
| < 1.5 | 污染已控制 |
| 1.5–3.0 | 部分控制，结论需提示 |
| > 3.0 | 未控制，映射规则需改进 |

甲醇实测：51.6 / 43.3 = **1.19** → 已控制。

## 8. 典型阶段识别

对月度中位数序列求相邻月差值：

```
diff_m = median_{m+1} − median_m
```

排序取最大 3 个（基差走强阶段）与最小 3 个（走弱阶段）。

**必须用中位数而非均值**做这一步，否则极端年份会主导排序结果。

甲醇实测（中位数口径）：
- 走强：1→2 月、2→3 月、6→7 月（7 月转弱前的反弹）
- 走弱：6→7 月最显著（175 → 7），8 月触底（−16）

## 9. 复算与自检

所有统计必须满足：

1. **脚本可重跑**：给定 `raw/` + `out/` 的 CSV，一条命令复现全部数字
2. **Excel 公式可核**：关键统计在 Excel 中保留 `AVERAGE`/`MEDIAN`/`PERCENTILE`/`COUNT` 公式
3. **交叉验证**：至少用两种独立方式算同一数字并比对

本次甲醇项目的三重校验：
- Python 脚本算的基差均值 66.4402
- Excel 公式 `=AVERAGE(F4:F1006)` 重算 → 66.4402
- 预计算表 1 月分位 vs Excel `PERCENTILE` 重算 → p10/p25/p75/p90 全部一致
