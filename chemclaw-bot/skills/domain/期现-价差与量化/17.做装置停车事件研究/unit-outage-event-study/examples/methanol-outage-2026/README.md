# 甲醇大型装置停车事件研究（2026 年案例）

这是一个**真实数据、端到端可复现**的案例：8 条候选事件 → 6 条纳入判断 → 5 条可比样本 → 期货路径、分布、相对基准异常收益。

> **先说结论的边界**：可比样本只有 **5 个**。任何均值都只是这 5 次行情的记录，不是“停车事件的一般规律”。
> 现货与基差在历史区间**没有公开逐日数据**，本案例按严格口径留空，不插值。

## 复现步骤

```bash

python scripts/selftest.py

# 2. 重建主力连续 + 基准（若 data/ 已存在可跳过）
python scripts/build_prices.py --raw examples/methanol-outage-2026/raw_contracts/MA \
    --out examples/methanol-outage-2026/data --prefix MA --min-volume 500
python scripts/build_benchmark.py --root examples/methanol-outage-2026/raw_contracts \
    --legs MA,L,PP,TA,EG,V --out examples/methanol-outage-2026/data/benchmark.csv --min-volume 500

# 3. 出待确认样本表
python scripts/build_event_table.py --project examples/methanol-outage-2026 \
    --out examples/methanol-outage-2026/output/事件样本确认表.html

# 4. 确认后跑正式研究（一键出 HTML + Excel + 自检）
python scripts/build_all.py examples/methanol-outage-2026 --benchmark market_model
```

## 主要结果（可比样本 n=5）

原始收益（甲醇主力连续，后向复权）：

| 窗口 | n | 均值 | 中位 | 上涨/下跌 |
|---|---|---|---|---|
| t+1 | 5 | +0.72% | +0.24% | 3 / 2 |
| t+5 | 4 | −4.06% | −3.53% | 0 / 4 |
| t+10 | 2 | −1.60% | −1.60% | 1 / 1 |
| t+20 | 2 | −0.12% | −0.12% | 1 / 1 |

相对等权化工期货指数的异常收益（t+5）：

| 事件 | 标的 | 基准 | 异常 |
|---|---|---|---|
| EV-01 | −10.00% | −6.80% | **−1.56%**（β=1.28 调整后） |
| EV-03 | −0.58% | +1.27% | −2.00% |
| EV-04 | −7.48% | −2.70% | −5.06% |
| EV-05 | −8.57% | −0.85% | −7.61% |

**关键观察**：EV-01 的 −10% 里，扣掉板块共同波动后只剩约 −1.6% 属于“超出市场的部分”。
这正是必须做基准调整的理由——不做基准，会把 Beta 当成事件效应。

## 数据边界（必须随结论一起引用）

| 序列 | 覆盖 | 缺口 |
|---|---|---|
| 甲醇期货逐合约日线 | 2018-05 ~ 2026-10，101 个合约 | 2018 年前只用 MA0 参考，无法精确复权 |
| 甲醇逐日现货 | 近 93 天（100ppi） | **历史基差路径不做推断** |
| 装置级停车新闻 | 约 2026-04 起可稳定检索 | **样本量小是硬限制** |
| 化工基准指数 | 2018-06 起（自建，6 品种等权） | 非官方指数，成分见 `data/benchmark_meta.json` |

## 同期干扰（不能忽略）

- **2026-06 中东地缘冲突**：供给中断与航线受阻同时发生，EV-01/EV-02 无法拆开；
- **下游 MTO 负反馈**：南京诚志二期 60 万吨 7 月 16 日停车、诚志一期计划 10 月 20 日停车 → 需求端与供给端同向，价格方向不能唯一归因；
- **成本端**：煤价与天然气价格同期波动未被单独控制。

因此本案例的结论只能是：**在 5 个样本中，停车事件后 t+5 多为下跌，且相当一部分来自板块共同波动**；
不能据此宣称“停车导致价格下跌”，也不能用于预测。
