# 装置停车事件研究（Event Study）

## 这个技能解决什么

“某套装置停车了，价格会怎么走？”——这是化工研究里最常被问、也最容易答错的问题。
常见错误有三种：

1. **把一条新闻当成一次事件**：同一次停车被 8 家媒体转载，变成 8 个样本；
2. **把三个日期混着用**：拿公告日、实际停车日、媒体报道日随便挑一个当事件日；
3. **只说“涨了/跌了”**：不扣除同期整个化工板块的涨跌，把 Beta 当成 Alpha。

本技能把这三件事都做成可审计的流程：**事件表 → 明确事件日 → 交易日对齐 → 分布统计 → 相对基准的异常收益 → 因果边界声明**。

## 两条硬规则（违反其一，结论即失效）

> **规则一：先出样本表，等确认，再算。**
> 未经用户确认的样本，只能展示“方法设计 + 明确标注为演示的结果”，**绝不能当作结论呈现**。
> 任何“演示/模拟”数字必须在标题、图注、文件名里同时标注，不能只写在角落。

> **规则二：缺数据就留空，不许补。**
> 现货价格取不到就写“现货序列缺失”，不要用期货价±基差倒推、不要插值、不要前向填充。
> 报告中每一条缺失都要能追溯到“为什么缺、缺在哪一列”。

## 工作流程

### 第 0 步：确认口径（必须先问，不要猜）

用一次提问把下面 4 项定下来，再开始检索：

| 需要确认 | 为什么必须先问 | 示例选项 |
|---|---|---|
| **品种与事件范围** | 决定检索词与阈值 | 只做甲醇 / 甲醇+乙二醇 / 全链条 |
| **产能阈值**（单套，非合计） | 决定哪些事件进样本 | 国内≥60 万吨/年、中东≥100 万吨/年 |
| **事件日定义** | 决定所有对齐结果 | 市场首次获知日（推荐）/ 企业公告日 / 实际停车日 |
| **现货与基差要不要做** | 决定能否算基差路径 | 有现货源就做 / 严格留空 |

若用户没回答就继续，用默认值（首次获知日 + 只做期货 + 阈值见上），并在报告首屏写明“用的是默认口径”。

### 第 1 步：建事件库（`references/01-event-taxonomy.md`）

按 `references/02-event-table-spec.md` 的字段建 `events.csv`。关键动作：

- **一次停车只留一条**：合并重复报道，保留最早披露日与最高证据来源；
- **同日多套装置合并为 1 个事件**，产能取较大单套（不求和）；
- **产品必须核验**：甲醇企业的乙二醇装置检修 ≠ 甲醇供给事件（本技能自带的反面样例 `EV-REJ-02` 就是这种情况）；
- 每条必须有 `quote`（原文摘录，能在原文里搜到）与 `source_url`。

### 第 2 步：先给用户看样本表，等确认

运行 `scripts/build_event_table.py` 生成 **可编辑 HTML/CSV 事件表**，让用户可以：

- ☑ 取消勾选不可比事件（区域级、无单一事件日、跨月滚动）；
- ✎ 直接改三种日期（尤其是纠正“媒体报道日 ≠ 盘面反应日”）；
- 🗑 删除产品不符、重复的样本。

**这一步的输出是“待确认样本”，不是研究结果。** 确认方式见 `references/07-confirmation-protocol.md`。

### 第 3 步：价格对齐（`references/04-method.md`）

```
事件日 → 若非交易日则顺延到首个交易日（并登记顺延）
→ 估计窗口：事件前 20 个交易日
→ 事件窗口：t+1 / t+5 / t+10 / t+20，前锚 t-1 / t-3 / t-5 / t-10
→ 收益 = 复权后收盘价之比 - 1
```

**换月必须处理**：事件窗口跨主力换月时，未复权的“主力连续”会把换月价差算成涨跌。
`scripts/build_prices.py` 按成交量选主力并做后向复权，使换月日的收益等于**旧合约的真实涨跌**。

### 第 4 步：统计与异常收益

- 均值 / 中位数 / P05–P95 分位 / 上涨占比；
- **n<10 时禁止做显著性宣称**，只给描述；
- 异常收益 `AR = R − (α + β·R_bench)`，基准用等权化工期货指数（`scripts/build_benchmark.py` 自建，成分与缺口写进报告）；
- 逐条说明“同期还有什么在动”（成本端、宏观、下游 MTO 开工、地缘）。

### 第 5 步：交付出报告

```bash
python scripts/build_all.py <项目目录> --benchmark market_model
```

产出：
- `output/<品种>_报告.html`：单文件交互报告，样本表可点改、图表即时重算、点击事件展开企业/装置/原因/引文；
- `output/<品种>_工作簿.xlsx`：11 张表（说明 / 事件样本 / 日期口径 / 价格路径 / 分布 / 异常收益 / 筛选 / 重叠 / 来源 / 现货基差 / 参数）；
- `build/`：`event_results.csv`、`stats.json`、`overlap.json`、`duplicates.json`，供复核。

最后跑 `scripts/check_report.py` 自检：表齐全、无禁用措辞、缺失已标注、样本量警告存在。

## 必须写进报告的三段话

1. **样本量警告**（n<10 时必须置顶）：只能作个案记录，不能当一般规律；
2. **因果边界**：事件窗口内的涨跌 ≠ 停车导致。同期成本端、宏观、下游负反馈、地缘都是竞争性解释；要识别因果需要更外生的事件与干净对照组；
3. **数据缺口清单**：哪条序列缺、缺哪段时间、为什么不补。

## 脚本清单

| 脚本 | 作用 |
|---|---|
| `scripts/core.py` | 事件读写、交易日历、去重、重叠检测、统计工具 |
| `scripts/build_prices.py` | 逐合约日线 → 主力连续（流动性门槛 + 换月后向复权） |
| `scripts/build_benchmark.py` | 多品种主力 → 等权化工指数 |
| `scripts/eventstudy.py` | 事件对齐、窗口收益、市场模型异常收益 |
| `scripts/build_event_table.py` | 生成待确认的可编辑事件表 |
| `scripts/build_html.py` / `build_excel.py` | 报告与工作簿 |
| `scripts/build_all.py` | 一键流水线 |
| `scripts/check_report.py` | 交付前自检 |
| `scripts/selftest.py` | 用合成数据验证算法（可离线跑） |
