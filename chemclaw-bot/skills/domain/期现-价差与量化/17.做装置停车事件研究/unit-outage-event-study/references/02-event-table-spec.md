# 02 · 事件表规范（events.csv）

事件研究的全部可信度都压在“事件日”这一列上。这张表只做一件事：**把一次装置停车，钉死到一个可核验、可复现、可审计的日期上**。

## 1. 为什么必须三种日期分开

| 字段 | 含义 | 谁会产生它 | 典型误差 |
|---|---|---|---|
| `announce_date` 企业公告日 | 上市公司/交易所公告披露日 | 交易所信息披露 | 无（除非未上市则留空） |
| `first_market_date` **市场首次获知日（默认事件日）** | 媒体首次报道、或盘面首次出现的反应日 | 行业媒体、期货公司晨报 | 报道可能晚于盘面 1–2 天 |
| `actual_start_date` 实际停车日 | 装置真正停止进料/降负 | 企业、行业调研 | 常晚于公告几天，也可能“计划 10 日停产”实际 8 日就停 |
| `actual_restart_date` 实际重启日 | 恢复生产 | 同上 | 影响“事件窗口”长度定义 |

**三者不同时绝不能混用**。常见的三种错误：

1. 用“公告日”当事件日 —— 但市场可能在公告前已经从媒体/调研得知（信息提前泄露）；
2. 用“实际停车日”当事件日 —— 但价格早在实际停车前就反应了（公告先行）；
3. 三个日期都拿不到，就用“新闻搜索里出现该企业的第一天”凑 —— 这是伪造。

本技能默认 `first_market_date`，因为事件研究要测的正是“**市场从什么时候开始知道这件事**”。若某事件只有公告日、没有媒体日，则用公告日并标 `first_market_source=announce_fallback`。

## 2. 字段字典

| 列名（中文表头也可） | 必填 | 说明 |
|---|---|---|
| `event_id` | ✅ | 唯一编号，如 `EV-2026-01` |
| `event_name` | ✅ | 一句话：谁、哪套装置、什么原因 |
| `company` / `unit_name` | ✅ | 企业 + 装置（含产能），装置尽量到“几期、几号炉” |
| `product` | ✅ | **必须写清产品**。甲醇企业同时有乙二醇装置，检索命中不等于本品种事件 |
| `capacity_wt` | ⬜ | 单套产能，万吨/年。**不能用“全集团产能”或“合计产能”代替单套** |
| `region` / `country` | ✅ | 影响传导路径（内地 vs 港口，国产 vs 进口） |
| `event_type` | ✅ | `planned` 计划检修 / `unplanned` 意外停车 / `restart` 重启 |
| `announce_date` | ⬜ | 见上表 |
| `first_market_date` | ✅（或 actual） | 默认事件日 |
| `actual_start_date` | ⬜ | 用于稳健性：以实际停车日为锚重跑 |
| `actual_restart_date` / `duration_days` | ⬜ | 用于判断窗口是否覆盖整段停车 |
| `in_comparison_set` | ✅ | 是否进入主比较集（人工判断） |
| `include_flag` | ✅ | 是否纳入（筛选结果） |
| `screening_reason` | ✅ | **写了才能审计**：为什么纳入/剔除 |
| `evidence_grade` | ✅ | E1–E5 |
| `product_verified` | ✅ | 正文写的是不是本品种（是/否） |
| `source_title` / `source_media` / `source_url` | ✅ | 可点击回溯 |
| `quote` | ✅ | **原文摘录**，不许改写。引号里的字必须能在原文中找到 |
| `notes` | ⬜ | 合并/拆分说明、口径争议 |

## 3. 拆分与合并规则

- **同一次停车被多家媒体重复报道** → 合并成 1 条，保留最早披露日与最高证据等级来源，其余记入 `notes` 与 Excel“重复报道清单”。
- **同一日披露的多套装置**（如“Kimiya 165 万吨 + ZPC 一套 165 万吨同日停车”）→ 合并成 1 个事件（同日、同一冲击源），产能取**较大单套**而非简单加总，并在 `notes` 注明。
- **区域级描述**（“中东多套装置停车”）→ 只有当能拆出至少一套 ≥ 阈值的单套装置时才可作正式样本；否则只能作“区域级”事件单列。
- **滚动的持续停车**（“伊朗多数装置维持停车”每周都报道）→ 只取**首次披露**那周；后续报道是状态更新，不是新事件。

## 4. 校验钩子（build_all 会自动跑）

- 首次获知日 **晚于** 实际停车日 → 警告（可能把“事后报道”当成了“事前获知”）；
- 公告日 **晚于** 首次获知日 → 警告（可能把媒体日当公告日）；
- 三个日期全空 → 报错；
- `unplanned/planned` 但 `quote` 为空 → 警告（证据无法核验）；
- 疑似重复 → 列出待人工裁决，**不自动删除**。
