# 06 · 报告与工作簿的呈现规范

## 1. HTML 报告：九段式结构

固定顺序（不要打乱，用户会按这个顺序核对）：

| 段 | 标题 | 必须包含 | 不许包含 |
|---|---|---|---|
| 首屏 | 标题 + 数据口径条 | 品种、期货口径、日历覆盖、数据缺口摘要 | 任何结论性判断 |
| ① | 研究设计：三种日期 | 三张卡片解释公告/获知/停车 | 具体事件结果 |
| ①' | 口径切换控件 | 锚定日、重启纳入、证据下限、产能阈值、去重叠 | — |
| ② | 事件样本表 | 可改日期、可取消勾选、可删除、点击展开详情 | 直接写死的不可改表格 |
| ②' | **样本量警告条**（n<10 时显示） | n、还差几个、为何不能推广 | 弱化措辞 |
| ③ | 对齐窗口与逐事件结果 | 归一价格路径图 + 逐事件收益表 | 只有图没有数值 |
| ④ | 平均/中位路径与分布 | 均值线、中位线、箱线图 + 散点 | 只画均值 |
| ⑤ | 分布统计表 | n/均值/中位/SD/P05–P95/胜率/符号检验/CI | 只报均值 |
| ⑥ | 异常收益 | 标的 vs 基准 vs 异常，注明基准成分 | 无基准时编造基准 |
| ⑦ | 重叠与同期事件 | 重叠对、同期干扰清单 | 假装各事件独立 |
| ⑧ | 数据缺口 | 逐条序列缺口 | 隐去缺口 |
| ⑨ | 结论与限制 | 因果免责声明 | 因果宣称 |

## 2. 交互要求

- **样本表可编辑**：日期用 `<input type="date">`，纳入用复选框，删除有按钮；任何改动**全页即时重算**；
- **点击事件展开**：企业、装置、产能、停车原因、原文引文、来源链接；
- **口径切换即时生效**：改锚定日后，结果表与所有图表同步刷新；
- **导出当前样本**：一键下载编辑后的 CSV，便于回填 `events.csv`；
- **单文件、离线可开**：ECharts 内联，不依赖 CDN。

## 3. 视觉规范

| 元素 | 规定 |
|---|---|
| 背景 | 深色 `#0f1419`，面板 `#161d24`，便于长时间读图 |
| 涨跌色 | 涨 `#ef5350`（红）、跌 `#26a69a`（绿），**中式配色**，不要用欧美绿涨红跌 |
| 数字 | 等宽字体，右对齐，保留 2 位小数 |
| 缺失 | 显示 `—` 或“缺失”，**绝不用 0 或空白冒充 0** |
| 缺口提示 | 红色文字 `class="gap"`；口径提示黄色 `class="flag"` |
| 类型标签 | 计划检修=蓝、意外停车=红、重启=绿 |
| 图表底部 | 必须有一行说明：窗口定义、归一方式、样本数 |

## 4. Excel 工作簿：11 张表

| 表 | 内容 | 关键要求 |
|---|---|---|
| 00 说明与免责 | 研究边界、三种日期、证据等级、样本量警告 | 模拟数据必须红色标注 |
| 01 事件样本 | 可编辑主表（23 列） | 产能缺失标黄、剔除标红 |
| 02 日期口径对照 | 三种日期并列 + 锚定与顺延说明 | 顺延时必须写明原日期 |
| 03 价格路径 | 逐事件逐窗口价格与收益 | 缺窗口写“越界/缺失”，不填 0 |
| 04 分布统计 | 全样本 + 去重叠子样本 | n<10 加“仅描述”备注 |
| 05 异常收益 | β、α、估计样本数、AR | 无基准时明确留空并给补齐方法 |
| 06 样本筛选 | 逐条判定明细 | 可逐条审计 |
| 07 事件重叠 | 重叠对与去重叠保留集 | — |
| 08 数据与来源 | 每条序列的口径/频率/区间/来源/缺口 | 缺口必须写 |
| 09 现货与基差 | 留空模板 + 补齐说明 | 不许倒推 |
| 10 参数假设 | 复现所需全部参数 | — |

## 5. 措辞红线

**禁止**：保证、必然、一定会涨/跌、目标价、建议买入/卖出、稳赚、抄底、满仓。

**推荐**：
- “在本次样本中，t+5 收益中位数为 −2.96%”
- “扣除同期化工板块后，异常收益为 −1.56%，量级明显小于原始收益”
- “样本仅 5 个，以上为描述性观察，不构成对一般规律的推断”
- “同期还存在 X、Y 等竞争性解释，无法单独归因”

## 6. 文件名规范

```
output/<品种>_装置停车事件研究_<年份>_报告.html
output/<品种>_装置停车事件研究_<年份>_工作簿.xlsx
output/事件样本确认表.html          ← 第 2 步的待确认表
```

模拟/演示产物必须带 `_演示` 或 `_DEMO` 后缀，且页面首屏红色标注。
