# 09 · 因果边界政策（不得宣称因果）

## 1. 一句话立场

**事件窗口内的价格变动 ≠ 停车导致的价格变动。**
本技能产出的是“对齐后的价格路径描述”与“相对基准的异常收益”，
**不是因果效应**，除非满足第 4 节的全部条件。

## 2. 为什么不能宣称因果：四类竞争性解释

| 竞争性解释 | 机制 | 在本技能里的处理 |
|---|---|---|
| **成本端** | 煤/天然气/原油同步变动，压低或抬升整个化工估值 | 基准里含板块，部分吸收；但仍需在“同期事件”里点名 |
| **宏观与地缘** | 地缘冲突同时造成供给中断与航线受阻、风险偏好切换 | 必须列出，且不能拆开 |
| **需求端负反馈** | 下游 MTO 因利润差停车，需求下降与供给下降同向 | 下游停车**不能**当供给事件，但必须作为干扰列出 |
| **预期与抢跑** | 计划检修提前被定价，事件窗口内反而回落 | 用前锚 `t-10 ~ t-1` 检查是否已抢跑 |

## 3. 允许 / 禁止的表述

### ✅ 允许

- “在本次 5 个可比事件中，t+5 收益中位数为 −2.96%。”
- “扣除同期等权化工板块后，t+5 异常收益中位数为 −2.0%，量级小于原始收益的一半，说明相当一部分跌幅来自板块共同波动。”
- “该窗口内同时存在下游 MTO 停车与地缘升级，两者与停车事件方向相反/相同，无法从本样本中分离。”
- “样本量不足以支持任何显著性判断。”

### ❌ 禁止

- “停车导致甲醇下跌 X%。”
- “检修事件对价格的冲击是显著的。”
- “据此可以推断，下次停车会…… ”
- “事件研究证明供给冲击主导本轮行情。”

## 4. 若真要做因果识别，需要什么

| 条件 | 说明 |
|---|---|
| **外生性** | 事件发生与价格无关（突发事故、天气、地缘导致的非预期停车）优于计划检修 |
| **对照组** | 有干净的反事实：同类品种未受影响、同期其他装置正常 |
| **控制变量** | 成本、宏观、下游开工、库存进入回归 |
| **足够样本** | 通常 n ≥ 30 才谈得上统计识别 |
| **安慰剂检验** | 把事件日随机前后平移，看“效应”是否消失 |

本技能**不自动**做上述因果识别；若用户需要，应在报告中明确升级为“因果推断研究”，并单列方法。

## 5. 报告里必须出现的免责段落（可直接复制）

> **因果说明**：本报告计算的是特定事件窗口内的价格变动，以及与同期市场基准的比较。
> 这些结果**不构成停车导致价格变动的证据**。同一窗口内通常还并存成本端波动、宏观与地缘事件、
> 下游开工变化等竞争性解释，且本样本量（n=__）远不足以分离这些影响。
> 本报告可用于记录历史路径、检验“停车后一定涨/跌”这类经验说法是否在样本中成立，
> 但不能用于预测或作为交易依据。

## 6. 与下游使用的衔接

如果报告将被用于：
- **内部复盘** → 允许呈现描述性结论，但保留免责段；
- **对外发布/投研观点** → 必须同时呈现“同期其他重大事件”与“样本量警告”，不得删节；
- **交易决策** → 明确标注“本结论不构成投资建议”。
