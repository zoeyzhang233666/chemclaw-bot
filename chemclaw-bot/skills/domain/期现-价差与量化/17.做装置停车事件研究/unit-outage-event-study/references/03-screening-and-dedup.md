# 03 · 筛选阈值与去重规则

## 1. 产能阈值：为什么必须写“单套”

阈值的作用是**把“能移动价格的事件”和“只是新闻的事件”分开**。用错口径会让样本要么全被剔除、要么混进噪音。

| 口径 | 正确写法 | 错误写法 | 后果 |
|---|---|---|---|
| 单套 | 该装置年产能 ≥ 阈值 | 集团产能 ≥ 阈值 | 混入大量无关小装置 |
| 合计 | 同一次事件多套合计 ≥ 阈值，且注明 | 用合计冒充单套 | 低估冲击，误判为“小事件” |
| 减产量 | 停车时长 × 日产 ≥ 阈值 | 用年产能代替减产量 | 短期停车被高估，长期被低估 |

**本技能默认阈值**（可按品种调整）：

| 品种/区域 | 单套阈值 | 依据 |
|---|---|---|
| 国内甲醇 | ≥ 60 万吨/年 | 国内单套主流规模 60–180 万吨 |
| 中东进口甲醇 | ≥ 100 万吨/年 | 中东单套 165/230 万吨级，100 万吨为影响进口的量级 |
| 一般国产大宗（PTA/EG 等） | ≥ 该品种主流单套的 50% | 按品种临时设定 |

**产能未披露怎么办**：不要估算，标记 `capacity_wt` 为空，并在筛选表中注明“产能未披露 → 不进入阈值合规子样本”。它可以留在 **全样本**，但不能出现在“满足阈值”的统计里。

## 2. “区域供应影响显著”的替代标准

有些事件确实重要，但没有单套产能可查（如“伊朗多套装置胀库停车”）。判定链条：

1. 该区域占我国进口/供应的比重（如伊朗占我国甲醇进口相当份额）；
2. 事件是否导致**进口到港量同比低位**、港口库存去化；
3. 是否有**下游可观测反应**（基差拉升、MTO 降负）。

三条里满足 2 条以上，可标为“区域级显著”纳入，但要在报告里**单独标注口径为区域级**，不能和单套事件混算均值。

## 3. 去重：四个层次

### 3.1 同一事件的重复报道（必须合并）

判定信号（满足 2 项以上即高度可能重复）：

- 事件主体（企业＋装置名）相同；
- 首次披露日相差 ≤ 2 个自然日；
- 产能数字相同或高度接近；
- 原文引文措辞高度相似（Jaccard 相似度高）。

处理：保留**最早披露日**与**最高证据等级**来源，其余记入 `notes`；Excel 的“重复报道清单”里列出全部 URL 供复核。

### 3.2 同一冲击源的多次披露（合并）

例：同一天报道“Kimiya 165 万吨 + ZPC 一套 165 万吨停车”。这是**同一天、同一冲击源**，合并为 1 个事件，产能取较大单套（165），`notes` 注明另一套。

### 3.3 滚动状态更新（只取首次）

例：伊朗装置 7 月开始停车，8 月、9 月、10 月每周都报道“仍在停车”。这是**同一次停车**，只有 7 月那次是事件，后续是状态跟踪。

### 3.4 窗口重叠（不删除，但要单独统计）

即使事件本身不同，如果两个事件的**事件窗口相交**（本技能定义 `[t-5, t+20]`），它们的价格路径就不独立：
第二个事件的“事件前窗口”已经包含了第一个事件的影响。

处理：
- **不删除**（删除会引入选择偏差）；
- 另设**去重叠子样本**（按时间先后保留先发生者），两套结果并列展示；
- 如果全样本显著、去重叠子样本不显著 → 结论极可能只由一次行情驱动，必须写明。

## 4. 证据等级（E1–E5）

| 等级 | 来源 | 可否进正式样本 |
|---|---|---|
| E1 | 交易所公告、企业公告、政府/协会文件 | ✅ |
| E2 | 行业权威媒体（期货日报、行业协会） | ✅ |
| E3 | 综合财经媒体（证券时报、每日经济新闻） | ✅（默认下限） |
| E4 | 期货公司晨报/研报转述 | ✅ 但需交叉验证 |
| E5 | 单一未具名信息源、社交媒体、无法回溯原文 | ❌ |

**判级不看媒体名气，看能否回溯到原文的一个具体句子**。`quote` 字段里的字必须能在 `source_url` 打开的页面里搜到。

## 5. 与用户确认的分工

| 环节 | 脚本自动做 | 必须人工/用户确认 |
|---|---|---|
| 阈值判定 | ✅ 按配置算 | 阈值取值是否合理 |
| 产品核验 | ⚠️ 只标记，不判断 | ✅ 读正文主体 |
| 重复检测 | ✅ 列候选组 | ✅ 最终裁决合并不合并 |
| 重叠检测 | ✅ 算区间相交 | ✅ 是否采用去重叠子样本 |
| 事件日确认 | ⚠️ 只做交易日顺延 | ✅ 日期是否真实 |
