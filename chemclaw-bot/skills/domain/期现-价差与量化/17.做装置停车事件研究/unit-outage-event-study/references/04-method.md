# 04 · 方法：对齐、窗口、基准与统计

## 1. 交易日对齐（最容易出错的一步）

```
原始事件日（自然日）
   ↓ 若为周末/法定节假日/停牌 → 顺延到其后第一个交易日
锚定日 t=0（交易日）
```

**必须登记顺延**。报告中每一个被顺延的日期都要写明“原日期 → 顺延后日期”。
未顺延而直接按自然日切片，会把周末的价格变动摊到错误的交易日上。

**节假日效应**：事件日紧邻长假（春节、国庆）时，节后首个交易日往往集中释放信息，`t+1` 会异常放大。本技能在事件表里对此打 `flag` 提示。

## 2. 窗口定义

| 窗口 | 含义 | 用途 |
|---|---|---|
| `t-10 ~ t-1` | 事件前 10 个交易日（前锚） | 判断是否已经抢跑 |
| `t-20 ~ t-1` | 估计窗口 | 估计 β、α 与基准波动 |
| `t+1 / t+5 / t+10 / t+20` | 事件后累计收益 | 主结果 |
| `t+0`（事件日当天） | 首日反应 | 常与公告时点（盘中/盘后）冲突，谨慎解读 |

**累计收益定义**：`R(t+k) = P(t+k) / P(t) − 1`，其中 `t` 是锚定日收盘。
若锚定日当天信息在盘后发布，则首日反应应在 `t+1`，报告需说明。

## 3. 主力连续与换月复权（关键）

### 为什么不能用现成的“主力连续”直接算

主力连续在换月日把两个不同合约的价格直接相连，产生**并非真实成交的跳空**。
若事件窗口跨换月，这段假跳空会被算进收益。

### 本技能的构造

1. 逐日取成交量最大的合约作为主力；
2. **流动性门槛**：成交量 ≥ 1000 手、持仓 ≥ 5000 手、成交量/持仓 ≥ 0.02，不满足的合约当日不参与选主力（防止临近到期小合约的极端报价污染）；
3. **后向复权**：换月日 `d`，旧合约在 `d` 收盘 `C_old`，新合约在 `d` 收盘 `C_new`；
   令 `k = C_old / C_new`，把 `d` 之前的全部价格乘以 `k`（多段换月连乘）。
   于是调整后 `d` 的价格 = `C_old`，`d` 与 `d−1` 之比恰为**旧合约当日真实涨跌**，换月价差被剔除。

**验证方法**（`scripts/selftest.py` 会跑）：
换月日的复权收益必须等于旧合约当天的真实涨跌，而**不等于**新旧合约的价格跳空。

## 4. 异常收益（相对基准）

### 4.1 市场模型

```
R_i,t = α + β · R_m,t + ε_i,t     （用 t-20 ~ t-1 估计）
AR_t  = R_i,t − (α̂ + β̂ · R_m,t)
CAR(t+k) = Σ AR
```

### 4.2 为什么必须有基准

“甲醇事件日后涨了 3%”不等于“停车让甲醇涨了 3%”。如果同期整个化工板块涨了 2.5%、
甲醇 β=1.2，那么 β 贡献就是 3%，异常收益约为 0。**没有基准的事件研究，本质是把 Beta 当 Alpha 卖。**

### 4.3 本技能的基准

`scripts/build_benchmark.py` 用 **L / PP / TA / EG / MA / V** 六个品种的主力日收益等权平均，构造研究用指数：

- 只对“当日有交易”的品种求均值，缺失腿不按 0 代入（否则会低估板块波动）；
- 这是**自建基准，不是交易所官方指数**，成分、权重、缺口必须写进报告；
- 若用户有更合适的基准（板块指数、原油、煤化工指数），替换 `data/benchmark.csv` 即可。

### 4.4 基准缺失时怎么办

**不做替代性估算**。报告明确写“未配置基准，本页不计算异常收益”，
并把原始收益标为“未经市场调整”。绝不允许用“行业平均涨跌”之类主观数字顶替。

## 5. 统计：小样本的正确姿势

| 指标 | 何时可用 | 注意 |
|---|---|---|
| 均值 | n ≥ 3 | 极端值敏感，必须同时给中位数 |
| 中位数 | n ≥ 3 | 小样本更稳健 |
| 分位数 P05/P95 | n ≥ 20 才有意义 | n<20 时标注“仅供参考” |
| 标准差 | n ≥ 3 | |
| 符号检验 | n ≥ 6 | 只检验方向，不做幅度推断 |
| 自助法 CI | n ≥ 5 | 小样本 CI 会很宽，恰好说明不确定性 |
| t 检验 | n ≥ 20（且近似正态）| **n<10 时不要用**，会把偶然说成显著 |

**禁止的说法**：“显著为正/为负”“具有统计意义”——除非 n 足够且有明确检验。

## 6. 稳健性检验清单

同一份数据，至少跑这几遍，看结论是否稳定：

1. **锚定日切换**：市场首次获知日 / 实际停车日 / 公告日；
2. **窗口切换**：t+1 / t+5 / t+10 / t+20 各自独立看，不要只报最好的那个；
3. **去重叠子样本**：删掉窗口相交的事件；
4. **基准切换**：市场模型 vs 均值调整 vs 无基准；
5. **异常值剔除**：去掉最大最小各一个，看均值变化多大。

结论只在多数口径下同向、且幅度量级接近时，才值得写进结论。
