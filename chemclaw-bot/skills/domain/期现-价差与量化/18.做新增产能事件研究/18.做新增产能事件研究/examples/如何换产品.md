# 使用示例：如何把这套 skill 用在别的产品上

假设现在要做 **PVC（聚氯乙烯）新增产能事件研究**。下面是逐步操作。

---

## 第 0 步：判断适不适合做

**适合的信号**：
- 有期货合约（PVC 有，大商所 v0）
- 有可核实的投产公告（PVC 新建项目通常有上市公司公告）
- 项目规模相对行业够大（≥20 万吨/年，PVC 行业约 2800 万吨/年，所以单项目 1–3%）

**不适合的信号**：
- 没有期货，也没有可获得的日频/周频现货序列 → 只能做定性分析
- 项目全是技改扩能（3–5 万吨），对市场无感
- 投产日期普遍查不到"开车成功"原文 → 样本不可靠

---

## 第 1 步：圈定样本

```
产品：PVC（聚氯乙烯，电石法 + 乙烯法）
市场：中国大陆
时间：2020-01 → 当前
门槛：≥20 万吨/年
```

---

## 第 2 步：核实项目（最耗时的环节）

对每个候选项目，**必须找到这几句话之一**才算正式投产：

```
一次开车成功并产出合格产品
投料成功，产出合格 PVC 树脂
打通全流程
```

**不能用的表述**：
```
计划 / 预计 / 拟于 / 有望 / 争取
试生产运行 / 阶段性达产
投产仪式 / 建成投产仪式
```

搜索建议（按命中率排序）：
1. `"项目名" 一次开车成功`
2. `"项目名" 产出合格`
3. `"项目名" 打通全流程`
4. `site:cninfo.com.cn 项目名`  ← 巨潮资讯的上市公司公告
5. `"母公司名" 公告 年产 XX 万吨 PVC 投产`

> 用 `domain_search` 的 `cninfo` 引擎查上市公司公告，命中率远高于普通搜索。

---

## 第 3 步：建事件库

复制 `templates/events_template.json`，按项目逐个填写。

**每个项目至少要有一个 `startup` 事件**，否则该项目对事件研究无用（只能作为背景）。

```json
{
  "project_id": "PVC-2023-EXAMPLE",
  "name": "XX化工 40万吨/年 PVC 装置",
  "owner": "XX化工股份有限公司（600XXX）",
  "location": "内蒙古 鄂尔多斯",
  "region": "西北",
  "process": "电石法",
  "design_capacity": 40,
  "upstream": "配套 60万吨/年 电石",
  "stages": {
    "startup": {
      "date": "2023-06-15",
      "grade": "A",
      "single_source": false,
      "quote": "公告编号 2023-045：装置于2023年6月15日一次开车成功，产出合格PVC树脂",
      "date_precision": "day"
    }
  }
}
```

---

## 第 4 步：准备价格数据

### PVC 期货（大商所）

```python
url = ("https://stock2.finance.sina.com.cn/futures/api/jsonp.php/"
       "var%20_v0=/InnerFuturesNewService.getDailyKLine?symbol=v0")
# 修改 run_event_study.py 中 load_series() 的 symbol
```

### PVC 现货

| 源 | 可用性 | 备注 |
|---|---|---|
| 生意社 100ppi（UA 绕过） | ✅ | 品类编号需替换，见网站分类 |
| 中国氯碱网 | ⚠️ 部分 | 需注册 |
| 卓创/隆众 | ❌ | 付费墙 |

**电石法与乙烯法价格不同**，要分别取，不要混成一条序列。

---

## 第 5 步：产能基数

PVC 总产能（万吨/年）参考值（**必须自行核实后再用**）：

| 年份 | 产能 |
|---|---|
| 2020 | ~2700 |
| 2022 | ~2800 |
| 2024 | ~2900 |

> 电石法和乙烯法产能要分开统计，因为成本曲线位置完全不同。

---

## 第 6 步：跑分析

```bash
$PY scripts/run_event_study.py
```

输出 `out/analysis.json`，重点看：

1. `aggregate` 里 `var=futures, stage=startup` 的各跨度结果
2. `placebo` 的 p 值
3. 若 p > 0.1 → 结论写"无稳健证据"

---

## 第 7 步：改报告文案

`build_html.py` 的 `HTML_TMPL` 中需要替换：

| 位置 | 原文 | 改为 |
|---|---|---|
| `<title>` | 中国聚丙烯(PP)大型新增产能 | 中国聚氯乙烯(PVC)大型新增产能 |
| `h1` | 聚丙烯(PP) | 聚氯乙烯(PVC) |
| `.sub` | 2020–2026 年可核验的 29 个 PP 大型新增产能项目 | 更新 |
| 混淆因素第4条 | 原油/丙烯/甲醇成本 | 电石/乙烯成本 |
| 数据缺口 | 生意社 PP 现货 | 对应品类 |

---

## 第 8 步：检查交付

按 `SKILL.md` 末尾的自检清单逐项过。

**特别检查**：
- [ ] HTML 在浏览器打开不是白屏（用 Chrome headless 截一次图或 dump-dom）
- [ ] Excel 里每个数字都能指回一个来源单元格
- [ ] 报告里没有"显著"二字用于 n < 3 的分组
- [ ] 爬坡曲线标注了"工程假设"
