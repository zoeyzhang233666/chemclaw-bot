# 爬坡与产能口径

## 一、核心区分：设计产能 ≠ 投产当天新增产量

这是本类研究**最容易犯、后果最严重**的错误。

| 概念 | 定义 | 典型值 | 用途 |
|---|---|---|---|
| **设计产能** | 铭牌/环评批复的名义年产能 | 60 万吨/年 | 计算"占现有产能比例"、衡量项目地位 |
| **投产当天实际产量** | 开车成功那一周的合格品产量 | 接近 **0** | 几乎不可用 |
| **爬坡后产量** | 达到设计负荷后的年化产量 | 设计产能 × 负荷率 | 测算真实供给增量 |
| **商业负荷** | 稳定运行的常规负荷 | 设计产能 × 85–95% | 长期供给测算基准 |

**把 60 万吨/年的设计产能当作"投产当天多出 60 万吨供给"，会把供给冲击高估 20–50 倍。**

## 二、爬坡曲线（工程假设，非项目披露）

本 skill 使用的默认爬坡曲线：

```python
DEFAULT_RAMP = [0.30, 0.55, 0.75, 0.85, 0.90, 0.93, 0.95, 0.97, 0.98, 1.00]
#              M1    M2    M3    M4    M5    M6    M7    M8    M9    M10
```

含义：投产第 1 个月按设计负荷的 30% 运行，第 3 个月 75%，第 6 个月 93%，约 10 个月后达到满负荷。

### ⚠️ 必须显式标注这是假设

```
本爬坡曲线为工程经验假设，不是任何项目的官方披露值。
实际爬坡速度因工艺、原料、市场、操作团队而异，差异可达 ±50%。
引用测算结果时必须同时引用这句话。
```

### 依据与不确定性

| 依据 | 说明 |
|---|---|
| 行业经验 | 新建聚烯烃装置常见 3–10 个月达产 |
| 实际案例 | 广西石化 PP：2025-10-16 投产，2025-11-15 披露"产能利用率稳定保持 90% 以上"（约 1 个月到 90%，属较快） |
| 实际案例 | 宝丰宁东三期：2023-11 进入试生产，PP 未达设计负荷（爬坡慢） |
| 不确定性 | 工艺不同（气相法 vs 环管法）、原料不同（油制 vs PDH vs MTO）爬坡速度差异大 |

**若项目方披露了实际负荷，用披露值替换假设值，并在报告中注明来源。**

## 三、月度产量换算

```python
def monthly_output(design_capacity, month_index, days=30):
    """design_capacity: 万吨/年; month_index: 0=第1个月"""
    ramp = DEFAULT_RAMP[min(month_index, len(DEFAULT_RAMP)-1)]
    return design_capacity * ramp * days / 365
```

示例：60 万吨/年装置

| 月份 | 负荷 | 当月产量（万吨） | 年化（万吨） |
|---|---|---|---|
| M1 | 30% | 1.48 | 18.0 |
| M3 | 75% | 3.70 | 45.0 |
| M6 | 93% | 4.59 | 55.8 |
| M10+ | 100% | 4.93 | 60.0 |

**首 12 个月累计产量** ≈ 47.6 万吨（设计产能的 79%）。

## 四、产能基数：一个真实的口径冲突

中国 PP 总产能这个数字，不同机构给的完全不同：

| 来源 | 时点 | 数值（万吨/年） | 口径 |
|---|---|---|---|
| 公开报道 | 2020-12 | 2882 | 总产能（含拟建？） |
| 卓创 | 2022-11 | 3487 | 总产能 |
| 隆众"全样本" | 2025-02 | 4511 | 全样本纳入时点差异 |
| 公开报道 | 2025-12 | 4916.5 | 总产能 |
| 隆众"全样本" | 2026-10 | 4461 | 样本口径 |

**同样的年份，4511 和 4916.5 差 400 万吨——这不是笔误，是统计样本纳入时点不同。**

### 处理规则

1. **一个研究内部只用一套基数**，不要混用
2. **引用时必须带口径和日期**："隆众全样本口径 2026-10-15：4461 万吨/年"
3. **占比的计算要说明分子分母**：
   ```
   某 60 万吨项目占 2025 年产能比 = 60 / 5000 = 1.20%（基数取 2025 年末 5000 万吨）
   ```
4. **年份缺基数时，宁可标"—"也不要外推**

### 本 skill 使用的基数（示例）

```python
CAPACITY_BASE = {
    "2020": 2554, "2021": 2944, "2022": 3320,
    "2023": 3880, "2024": 4440, "2025": 5000,
}
```

> 注意：这些数字本身来自公开报道的年末总产能，与隆众"全样本"口径不同。
> **换产品/换年份时必须重新核实，不要照抄。**

## 五、区域价差：本类研究最大的数据缺口

需求里常要求"区域价差"（如华东 − 华南、华东 − 华北）。

**现实**：没有任何公开的逐周/逐日"华东−华南"PP 价差数值序列。只有：
- 年度区间文字描述（"2023 年华东-华南价差多在 100–300 元/吨"）
- 单点报价（某日华东 7200、华南 7350）

**处理**：
1. 如实写"未获得公开的区域价差连续序列"
2. 若必须做，用**分区域现货报价的单点值**做事件前后的水平对照（不是路径分析）
3. 不要用"全国均价 − 期货"假冒区域价差

## 六、检修对冲：别忽略反向供给

新增投产的同时，同期装置检修会抵消供给增量。

```
净供给变化 = 新增产能 × 爬坡负荷 − 同期检修损失量
```

**实测**：PP 装置检修损失量 2026-06-04 达 35.9 万吨/月，相当于 430 万吨/年的产能停摆——比很多单个新项目的设计产能还大。

**所以在解释"为什么投产了价格没跌"时，检修是必须检查的第一个对冲因素。**

## 七、口径冲突清单（引用数据前必查）

| 冲突项 | 表现 | 处理 |
|---|---|---|
| 两油库存 vs 生产企业库存 | 两油是**聚烯烃(PE+PP)**口径，数值更大 | 不可混用，分开存 |
| 开工率两个口径 | 隆众"产能利用率"66–84% vs 周报"平均开工率"88–93% | 拆成两条序列，**不要拼接** |
| 总产能多个口径 | 4511 vs 4916.5 vs 4461 | 引用带口径+日期 |
| 设计产能 vs 有效产能 | 老装置长期停车，实际有效产能 < 名义 | 报告注明 |
| 粉料 vs 粒料 | 只有粉料不算完整投产 | 单列标注 |
| 主力连续 vs 具体合约 | 主力连续换月有跳空 | 算基差用同日主力结算价，不要用连续序列直接减 |
