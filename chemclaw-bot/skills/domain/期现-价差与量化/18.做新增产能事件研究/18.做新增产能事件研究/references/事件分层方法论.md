# 事件分层方法论：十个信息节点与判别标准

## 为什么必须分层

新增产能的"投产"不是一个时点，而是一条**被多次披露的链条**。市场在每个节点获得的信息量完全不同：

| 节点 | 市场获得的新信息 | 反应机制 |
|---|---|---|
| 宣布 / 备案 | "未来某时会有供给" | 预期定价，反应最弱但最早 |
| 环评公示 | 产能数字被官方确认 | 强化预期 |
| 开工 | 时间表变得可信 | 开始计入供给曲线 |
| 中交（机械竣工） | 工程完成，只差开车 | 预期接近兑现 |
| 试车 | 装置能出料了 | 预期基本兑现，可能有"试车不顺"的负面意外 |
| **正式投产** | 合格品进入市场 | 供给兑现，但市场早已预期 |
| 打通全流程 | 上下游贯通 | 消除"卡在某一环节"的疑虑 |
| 商业运营 | 财务口径确认 | 对股票有意义，对现货意义有限 |
| 达产标定 | 实际负荷确认 | 真正的供给增量被验证 |

**核心洞察：正式投产当天的"新闻价值"往往最低**，因为市场从宣布那天就开始定价了。这就是为什么只研究投产日经常得出"没影响"的结论——不是没影响，是影响发生在更早的节点。

## 十个阶段的定义

| key | 中文 | 判别标准（必须满足） | 常见误标 |
|---|---|---|---|
| `announce` | 宣布 | 有正式的立项/投资决策公告，含产能数字 | 把"规划研究"当宣布 |
| `record` | 备案 | 政府投资项目备案回执 | 与环评比混 |
| `eia` | 环评 | 环评批复或公示，产能被确认 | 环评第一次公示（非批复）只算预期 |
| `construction` | 开工 | 土建/安装开工仪式或实质开工 | **仪式日 ≠ 开工日**，但仪式日可作为披露日 |
| `mechanical` | 中交 | 机械竣工验收（机械竣工、中间交接） | 与"试车"混为一谈 |
| `commissioning` | 试车 | 有"试车""投料""开车"字样，但**未明确写出产出合格品** | **最容易出错**：很多新闻写"试车成功"，没说产出合格品 |
| `startup` | **正式投产** | 明确写出"一次开车成功""产出合格品""投料成功并产出合格产品" | 把"试生产运行"当正式投产 |
| `first_product` | 打通全流程 | 上下游全流程贯通的明确表述 | 与正式投产是同一天时，两个都记 |
| `commercial` | 商业运营 | 官方宣布"转入商业运营" | 财务口径，非供给口径 |
| `rampup` | 达产标定 | 完成满负荷/高负荷标定，或披露具体负荷 | 把"阶段性达产"当全面达产 |

## 判别实操规则

### 规则 1：search 时必须搜那几句原话

正向关键词（可判为正式投产）：
```
一次开车成功 / 开车成功并产出合格 / 投料成功 / 产出合格(聚丙烯|聚乙烯|PVC|...)产品
打通全流程 / 全流程贯通 / 一次投料开车成功 / 首车产品发运（仅作辅助）
```

负向关键词（**不能**判为正式投产）：
```
计划 / 预计 / 拟于 / 有望 / 争取 / 目标
试生产 / 试运行 / 试车成功（若未提合格品）
阶段性达产 / 部分装置运行
投产仪式 / 建成投产仪式 / 举行投产仪式
```

### 规则 2：一句话里有"合格品"才升级为 startup

对比两个真实案例：

- 镇海炼化 3# PP（2022-02-28）：原文"**开工试车圆满成功**" → 只有 `commissioning`
- 广东石化 50 万吨 PP（2023-02-08/09）：原文"15:18 反应器投入主催化剂…15:40 开始出料"+"13:20 挤压造粒开车成功，装置**打通全流程**" → `startup` + `first_product`

**若原文只说"试车成功"而没说产出合格品，一律归 `commissioning`，不得归 `startup`。**

### 规则 3：仪式日单独标注

山东京博 60 万吨 PP（2023-03-17）：只有"建成投产仪式，首车产品发运"，没有"一次开车成功"的原始通报。

处理：登记为 `startup` 但 `note` 写明"日期为投产仪式日而非开车通报日，证据偏弱"，并在报告中可降级视作 `commissioning`。

### 规则 4：两段式投产要拆成两个事件

古雷炼化 35 万吨 PP：
- 2021-03-21：产出合格粒料，**随即停工待料**
- 2021-08 下旬：乙烯装置投料后，恢复连续商业生产

处理：登记 `startup`(2021-03-21) + `commercial`(2021-08)。**真正的连续供给在 8 月**，研究供给冲击应以 8 月为主事件，3 月作为"首次出料"事件单独研究。

### 规则 5：只有粉料、没有粒料 ≠ 正式投产

中韩石化 30 万吨 PP（2021-03-26）："产出 PPH-T03 **粉料**"，造粒机未到位，04-02 即停车检修。

处理：登记为 `startup` 但 note 标注"严格说未产出合格粒料，不构成完整正式投产"，统计时作为"边角事件"单列或剔除。

### 规则 6：试生产运行 ≠ 正式投产

宁夏宝丰宁东三期 50 万吨 PP（2023-11-07）：公告"已全面进入**试生产运行**，主体装置已经阶段性达产"。

处理：归 `commissioning`，`date_precision="month"`，note 写"无明确产出合格品日"。

## 证据等级定义

| 等级 | 来源类型 | 示例 |
|---|---|---|
| **A** | 政府批复、上市公司公告、央企官网、交易所披露 | 东华能源公告编号 2021-043；生态环境部环评批复 |
| **B** | 权威媒体 | 新华社、人民日报、央广网、中国化工报、科技日报 |
| **C** | 行业资讯机构 | 流程工业/PROCESS、隆众资讯、卓创资讯、中国石化新闻网 |
| **D** | 自媒体转载 | 搜狐号、雪球、企业公众号转载 |

**跨源核验规则**：同一日期 ≥2 个独立来源 = "已交叉验证"；仅 1 个来源标注 `single_source: true`，统计时降权或单列。
