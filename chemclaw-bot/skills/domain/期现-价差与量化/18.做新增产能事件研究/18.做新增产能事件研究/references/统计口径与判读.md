# 统计口径与判读

## 一、三个口径的数学定义

设某序列在事件日的观测为 $P_0$，事件后第 $k$ 期为 $P_{+k}$，事件前 1 期为 $P_{-1}$，事件前第 $k$ 期为 $P_{-k}$，市场（反事实）同期平均变化为 $M_k$。

### 1. 累计变化（cumulative）

$$C_k = \frac{P_{+k}}{P_{-1}} - 1$$

**含义**：从事件前到事件后总共变了多少。

**致命缺陷**：包含事件前的趋势漂移。如果标的在事件前 3 个月已经在下跌，这 3 个月的跌幅会被算进"事件效应"。

> 实测案例：浙江石化 4# PP（2022-03-20）投产前后 60 日累计 −8.2%，但事件前 60 日已累计 −6.1%，真正在事件点之后的变化只有 −2.1%。

### 2. 超额变化（abnormal）— **主口径**

$$A_k = C_k - M_k$$

其中 $M_k$ 是**相对日历对齐的反事实基准**：把所有事件的"第 −k 期到第 +k 期"变化取平均，作为"如果没有这个事件、只是随时间流逝"的基准。

**为什么这样做**：扩能期多个项目并行投产，$M_k$ 会自动吸收"同期其他项目也在投产"的共同效应，从而分离出单个项目的**相对**影响。

**局限**：这是"平均效应减去平均效应"，只能得到相对值。若所有事件效应同向，$M_k$ 也同向，$A_k$ 会互相抵消。

### 3. 突变（surprise）— 二阶差分

$$S_k = C_k - \left(\frac{P_{-1}}{P_{-k}} - 1\right)$$

**含义**：事件点前后，趋势是否发生了拐折。

**局限**：对噪声极敏感，样本小时完全不稳定。仅作为**交叉验证**，不作为主结论。

### 判读规则表

| 累计 $C$ | 超额 $A$ | 突变 $S$ | 结论 |
|---|---|---|---|
| 显著 | 显著 | 同向 | **稳健效应**，可下结论 |
| 显著 | 不显著 | 任意 | 是市场整体趋势，**不是**项目效应 |
| 不显著 | 显著 | 同向 | 项目效应被大盘掩护，**谨慎可报** |
| 不显著 | 不显著 | 不显著 | **无稳健证据**，如实写 |

## 二、窗口对齐的两种口径

### 口径 A：相对交易日（日频序列）

事件日 = 0，取第 −k 到第 +k 个**有数据的交易日**。

适用：期货日线、日频现货价、日频基差。

```
compute_paths(series, event_date, horizons=(20,60,120))
```

### 口径 B：自然日（低频序列）

事件日 = 0，取事件后第 $n$ 个**自然日**内最近的观测。

适用：周度库存、周度开工率、月度产量、月度检修损失量。

```
compute_paths_by_days(series, event_date, horizons=(20,60,120))
```

**为什么必须分开**：
- 一个只有 29 个观测点的周度库存序列，±120 交易日的窗口需要 121 个观测点，根本凑不出来。
- 如果用 k-观测窗口，120 期实际是"事件后第 120 周 ≈ 2.3 年"，语义完全错乱。
- 自然日版本会返回 `obs_count`（窗口内实际观测个数）；`obs_count < 2` → 判为不可计算，返回 `None`，**不能填 0**。

### 一个真实的坑

早期版本用 k-观测窗口跑周度库存，结果所有事件都算出 `0.0000` 的变化——因为事件日前后最近的观测是同一个点，`post_value == base_value`，百分比变化为 0。看起来像"库存完全没变"，实际是"这个事件根本不在序列覆盖范围内"。

**修正**：加 `obs_count < 2 → pct = None` 的闸门。

## 三、统计量

### 基础统计

$$\bar{x} = \frac{1}{n}\sum x_i, \quad s = \sqrt{\frac{\sum (x_i - \bar{x})^2}{n-1}}, \quad t = \frac{\bar{x}}{s/\sqrt{n}}$$

### 符号检验（精确二项）

对"变化为正"的比例做二项检验，$H_0: p = 0.5$。

- $n \le 25$：用**精确二项分布**，不要用正态近似
- $n > 25$：正态近似 $z = \frac{k - n/2}{\sqrt{n}/2}$

```python
def sign_test(values, null=0.0):
    vals = [v for v in values if v is not None]
    n = len(vals)
    k = sum(1 for v in vals if v > null)
    if n == 0: return {"pos_share": None, "p": None, "n": 0}
    p = 2 * min(sum(comb(n, i) for i in range(k, n+1)) / 2**n,
                sum(comb(n, i) for i in range(0, k+1)) / 2**n)
    return {"pos_share": k/n, "p": min(1.0, p), "n": n}
```

### Bootstrap 置信区间

```
有放回重抽 2000 次 → 每次算均值 → 取 5% 与 95% 分位
```

不依赖 scipy。n < 3 时不给 CI。

### 样本量下限

| n | 给什么 | 不给什么 |
|---|---|---|
| ≥ 3 | mean, median, sd, t, 符号检验, 90% CI | — |
| < 3 | mean, median | **t、p 值、CI、任何"显著"字样** |

标记字段：`insufficient: true`

## 四、安慰剂检验

**目的**：证明"真实事件点的效应"与"随便挑一天"的效应有区别。

**做法**：
1. 把每个事件日随机平移 $d \sim U(-180, +180)$ 天，得到一组伪事件日
2. 用同样的方法计算伪事件的累计变化均值
3. 重复 400 次（序列长、可用日期多时可到 400）
4. 计算真实事件均值在伪分布中的分位数与双尾 p 值

```python
def placebo_test(series, event_dates, horizon=60, n_draw=400):
    real = mean(compute for each real event)
    draws = []
    for _ in range(n_draw):
        fake = [d + random_timedelta(-180, 180) for d in event_dates]
        draws.append(mean(compute for each fake event))
    p = 2 * min(share(draws <= real), share(draws >= real))
    return {"real_mean": real, "placebo_mean": mean(draws), "placebo_sd": sd(draws),
            "p_value_two_sided": min(1.0, p), "real_percentile": pct_rank(real, draws)}
```

**判读**：
- $p < 0.10$：真实事件与随机日期有差异，效应可能是真的
- $p \ge 0.10$：**与噪声无法区分**，不能声称有影响

## 六、事件密集度（contamination）指标

对每个事件 $i$，计算 ±120 日内**其他项目**的事件数：

```python
def concurrent_count(event, all_events, window_days=120):
    return len({e.project_id for e in all_events
                if e.project_id != event.project_id
                and abs((e.date - event.date).days) <= window_days})
```

报告时必须列出这个指标。如果某事件 `concurrent ≥ 3`，该事件的窗口被严重污染，应单独标注或从主样本剔除后做稳健性检验。

## 七、常见统计陷阱

| 陷阱 | 表现 | 修正 |
|---|---|---|
| 用计划日期 | 效应出现在"没有供给增加"的时点 | 只用核实过的实际日期 |
| 预期与兑现合并 | 效应被平均掉，显示为 0 | 分层统计，永不合并 |
| 基差百分比 | 出现 140% 这种数字 | 基差是绝对值差额，看元/吨，不看百分比 |
| 小样本报 t 值 | n=2 报 t=2.8 说"显著" | n<3 一律置空 |
| 忽略事件前漂移 | 累计变化把趋势当效应 | 用超额口径 |
| 序列覆盖不足 | 大量 0 变化 | `obs_count` 闸门 |
| 单一来源日期 | 日期本身是错的 | `single_source` 打标 + 降权 |
| 口径混用 | 两油库存(PE+PP)与纯 PP 混算 | 口径写进字段，不同口径不拼接 |
