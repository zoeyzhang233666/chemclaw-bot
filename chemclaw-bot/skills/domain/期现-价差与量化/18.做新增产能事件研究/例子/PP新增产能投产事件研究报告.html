中国聚丙烯(PP)大型新增产能 · 正式投产事件研究

以 2020–2026 年可核验的 29 个 PP 大型新增产能项目 / 45 个分层事件为样本， 区分「宣布 → 备案 → 环评 → 开工 → 中交 → 试车 → 正式投产 → 打通全流程 → 商业运营 → 达产」， 研究各信息节点前后 ±20 / ±60 / ±120 个交易日 PP 期货、现货、基差与库存、开工率的变化。 所有数值均带来源；设计产能不等于投产当天的新增实际产量。

① 候选新增产能项目表与证据

先核实项目，再谈事件。下表只收录有公开来源证实的项目；「设计产能」是名义口径， 与「实际投产当天新增产量」不是一回事（见第 ④ 节爬坡测算）。点击任意一行查看该项目的历史变化路径。

本表最重要的三条纪律： ① 新闻里的「计划 X 月投产」不得当作投产日；
② 同一项目的开工 / 中交 / 试车 / 投料 / 合格品 / 达产是不同事件，绝不合并统计；
③ 仅一个来源的日期单独标注 单一来源，统计时降权处理。

② 事件时间线：投产日期分层

同一项目在不同阶段被披露，市场反应的性质完全不同：宣布/开工/试车属于「预期信息」， 正式投产/合格品/商运属于「供给兑现信息」。把两者混为一谈，是这类研究最常见的错误。

④ 汇总统计（样本可比性优先）

只有样本 ≥ 3 才给 t 值与显著性；样本 < 3 一律标 样本不足，不做过度解读。 三个口径并列展示，避免用单一数字掩盖口径差异。

读法（重要）： 累计变化 = 事件后 k 期水平 − 事件前 1 期水平（含事件前的趋势漂移，不等于"事件效应"）； 超额变化(主口径) = 累计变化 − 同期"相对日历对齐"的市场平均变化（扣除大盘）； 突变 = 累计变化 − 事件前同长度前段变化（二阶差分）。 三者若同向，结论才稳。

安慰剂检验：真实事件 vs 随机平移日期

把每个事件的日期随机平移 ±180 天重复 400 次，看真实事件的"效应"是否显著区别于噪声。 p 值大 = 这个效应很可能只是噪声。

基差(basis)序列的百分比要谨慎读：基差 = 现货 − 期货，是绝对值差额（元/吨）， 不是价格指数。当基差本身接近 0 时，百分比变化会放大成几十甚至上百个百分点 （例如基差从 +750 元/吨到 +1803 元/吨记为 +140%），这在数学上正确但不是“价格涨了140%”。 基差应看绝对变化（元/吨），价格序列才看百分比。

⑦ 数据边界、混淆因素与使用限制

数据可用性与缺口（如实披露）

必须同时考虑的混淆因素

  1. 市场提前反映。新增产能的宣布、环评、开工、试车都会提前定价；正式投产当天的"新闻价值"往往已被消化。 因此本报告把预期类节点与兑现类节点分开研究，不做合并平均。
  2. 达产爬坡。设计产能 ≠ 投产当天产量。爬坡 3–10 个月是常态，且本项目多数未披露逐月负荷。
  3. 同期其他新增产能。PP 在 2020–2026 属密集扩能期，任一季度都有多个项目并行。 本报告用"相对日历对齐"的反事实扣除大盘，但无法完全分离单个项目的影响。
  4. 成本端驱动。PP 价格主要受原油/丙烯/甲醇成本推动，供给事件常被成本波动淹没。
  5. 检修与停车对冲。同期装置检修会抵消新增供给，单独看投产会高估净增量。
  6. 需求季节性。春节前后、农膜旺季、旺季备货都会显著改变库存与价格的季节形态。
  7. 日期精度不齐。部分项目仅能精确到"月"，部分为仪式日或试车日，样本内部并不同质。

如何把它当作决策输入（而不是结论）

本报告给出的是可复核的证据链与统计骨架，不是方向判断。正确用法是： 用候选事件表确认样本 → 用分层时间线确定信息节点 → 用超额变化与安慰剂检验判断"有没有效应" → 再用逐项目路径检查是不是由个别异常项目驱动。若三个口径不同向、或安慰剂 p 值大，就应当结论为"无稳健证据"。
