# 统计口径与公式

## 一、分位数：必须锁死到同一种算法

| 环境 | 写法 | 算法 |
|---|---|---|
| Excel | `PERCENTILE.INC(区域, q)` | 经验分位，线性插值 |
| Python | `numpy.percentile(a, q*100, method='linear')` | 同上 |
| R | `quantile(x, probs=q, type=7)` | 同上 |
| 手算 | `pos = (n-1) * q`，取 floor/ceil 两点线性插值 | 同上 |

**不要用** `PERCENTILE.EXC`（改算法，对小样本结果差异明显），也不要用 `method='nearest'` / `'lower'`。

```python
def percentile_linear(values, q):
    v = sorted(float(x) for x in values); n = len(v)
    if n == 0: return None
    if n == 1: return v[0]
    pos = (n - 1) * q
    lo, hi = int(math.floor(pos)), int(math.ceil(pos))
    if lo == hi: return v[lo]
    return v[lo] + (v[hi] - v[lo]) * (pos - lo)
```

## 二、样本量红线

| 同周样本年数 n | 允许输出 | 必须附带 |
|---|---|---|
| n = 0 | 只有“缺口” | 缺口原因 |
| n = 1 | 只有该点值 | “单年观测，无分布信息” |
| n = 2 | 均值、中位数、极差 | “n=2，分位无意义” |
| 3 ≤ n < 5 | 均值、中位数、P10/P25/P75/P90、极差 | **“样本不足，仅供参考”** |
| n ≥ 5 | 全部 | n 与年份列表 |

**为什么 n=1 时算出来的 P10 和 P90 会相等**：线性插值下 `pos=(1-1)*q=0`，无论 q 取多少都返回 `v[0]`。
所以“P10=68.2, P90=68.2”看起来像有个区间，实际是**退化的伪区间**。这正是要禁止的情形。

## 三、对齐方式

### 3.1 ISO 周（自然周）

```python
iy, iw, _ = datetime.date.fromisoformat(d).isocalendar()   # 2026-W42
```

若数据以“周期截止日”登记，取**该周期内地最后一个工作日（通常是周四）** 的 ISO 周号。

Excel 等价写法（**不要用 `ISOWEEKNUM`**，LibreOffice 与 Excel<2013 不支持，会返回 `#NAME?`）：

```excel
自然年  =YEAR(A1+4-WEEKDAY(A1))
年序周次 =1+INT(((A1-WEEKDAY(A1))-(DATE(B1,1,1)-WEEKDAY(DATE(B1,1,1))))/7)
```

> 已实测：对 2026-W30…W42 共 12 个周四，该公式与 `isocalendar()` **逐行一致，0 处不符**。

### 3.2 春节相对周（移动节假日）

春节日期逐年漂移：

| 年份 | 春节 | 所在 ISO 周 |
|---|---|---|
| 2021 | 02-12 | W06 |
| 2022 | 02-01 | W05 |
| 2023 | 01-22 | W04 |
| 2024 | 02-10 | W06 |
| 2025 | 01-29 | W05 |
| 2026 | 02-17 | W08 |

漂移幅度可达 **4~5 个 ISO 周**。因此 1—3 月必须另算：
`春节相对周 = 本周起始日 − 春节所在周起始日`（单位：周）。

两套视图**并列输出**，不互相替代：
- ISO 周视图：用于回答“通常这个季节负荷多高”；
- 春节相对周视图：用于回答“节前/节中/节后负荷怎么变”。

## 四、变化率

| 指标 | 定义 | 陷阱 |
|---|---|---|
| 环比（源数据口径） | 与**上一个发布日**的观测之差 | 不是 ISO 周−1！发布节奏跳跃时会错配 |
| 同比（源数据口径） | 与**上年同一发布日当周**之差 | 跨年周号漂移，52 周近似须注明 |
| 4 周变化 | 本周 − 第 5 个**观测**（not 4 个自然周） | 有断档时按日历减会跨过缺口 |
| 12 周变化 | 本周 − 第 13 个**观测** | 观测数 <13 时必须返回“缺口”，不能拿首周冒充 |

**判据**：若用 ISO 周−1 匹配环比，**全部行都“不一致”**，说明对齐错了，不是数据错了。
改用真实发布间隔（`0 < 间隔天数 < 14`）后应能对齐。

## 五、位置指标

```
低于本周占比 = #{历史同周观测 < 本周值} / n_hist        （仅在 n_hist ≥ 3 时输出）
z 值        = (本周值 − 同周均值) / 同周样本标准差        （仅在 n_hist ≥ 3 时输出）
```

小样本警示：n=3 时 z 值的抽样误差极大，只作方向参考，不作“显著偏离”的结论。

## 六、季节性强度

```
seasonal_ss_share = SS_between / SS_total
SS_total  = Σ(x − 总均值)²
SS_between = Σ_g n_g * (均值_g − 总均值)²        g = 周号
```

| 取值 | 解读 | 前置条件 |
|---|---|---|
| < 0.4 | 季节性弱 | **必须 ≥3 个年份** |
| 0.4 ~ 0.6 | 中等 | 同上 |
| > 0.6 | 显著 | 同上 |

**关键陷阱**：只有 1 个年份时，每个周号只有一个观测 → `SS_within = 0` → `seasonal_ss_share = 1.0`，
必然“显著”。这是**数学上是伪显著**。因此本指标必须在 `覆盖年份数 < 3` 时直接判为“不足以判定”。

## 七、异常年份判定

三条标准同时看，且必须写明基准：

1. 年均值相对“多年均值”的偏离（需要 ≥3 年才有基准）；
2. 年内极差（最大−最小）；
3. 变异系数 `CV = 标准差 / 均值`。

样本年数不足时输出 **“样本不足（<5 周）不可判定常年规律”**，不硬凑结论。

## 八、复算一致性检查

报告里的分位、均值、变化量，必须能在 Excel 里由同一份原始数据**独立算出同一个数**。
本项目实测：`C9−C5` 出现 `-3.60000000000001` → 计算列统一包 `ROUND(...,2)`。
