# 可比性审计清单

按顺序逐项打勾。任一项未通过，**不得**把两段数据放进同一条序列。

## A. 定义层

- [ ] 指标全称是什么？（开工率 / 开工负荷率 / 产能利用率 / 开机率）
- [ ] 分子是什么？（产量 / 原料加工量 / 运行负荷）
- [ ] 分母是什么？（设计产能 / 有效产能 / 在产产能 / 计入检修的产能）
- [ ] 是否剔除“僵尸产能”？剔除标准？（常见：连续停车 ≥2 个自然年，每年年底清理）
- [ ] 是否有价值量 vs 实物量的混用？（统计局口径是**价值量**，行业样本是**实物量**）

## B. 样本层

- [ ] 样本企业数与厂区数是否多年未变？列成一张“期数 × 样本数”的表。
- [ ] 有无企业/装置进出样本？生效日期？退出装置的开工水平？（影响方向）
- [ ] 分工艺（电石法/乙烯法、联碱/氨碱、煤制/气制）的样本是否与整体口径同源？
- [ ] **月度产量样本**与**周度利用率样本**是否是同一套？（常常不是！禁止互相推算）

## C. 产能基数层

- [ ] 产能基数最近一次变更的日期与数值。
- [ ] 变更是“新增产能投产”还是“样本调整”？前者是真实供给变化，后者是**口径变化**。
- [ ] 基数变更后，跨变更点的比较是否已在图上标注？

## D. 时间层

- [ ] 统计周期是自然周、上周五~本周四，还是周五~次周四？
- [ ] 发布日是周几？节假日是否顺延？
- [ ] 有没有断档（合并发布 / 两周一次 / 数据缺失）？逐期算 `间隔天数`。
- [ ] 环比锚点是“上一个发布日”还是“上一个日历周”？
- [ ] 同一期在不同来源上的“周期截止日”是否一致？（常见 off-by-one：发布日 vs 周期日）

## E. 跨来源层

- [ ] 同一周，两家机构的差值是多少？（记录到“异口径登记表”）
- [ ] 差值是否稳定？如果方向相反，说明至少一家的口径或样本有大差异 → 只做定性讨论。
- [ ] 是否有人把两家数据“首尾拼接”出一条更长的线？（**绝对禁止**）

## F. 输出层

- [ ] 每个数字是否能点开到原文 URL？
- [ ] 每个缺口是否被显式标为“缺口”而不是留空/填 0/填前一值？
- [ ] 分位数在 n<3 时是否被拒绝输出？
- [ ] 结论里的“历史低位/高位”是否附带了分位、n 和年份？
- [ ] 是否写明了“本期不出具哪些结论”及原因？

## 实战判例：三个真实的坑

### 坑 1：用 ISO 周−1 匹配环比 → 全表“不一致”

现象：19 行环比锚点全部判为“不一致”，差值 −6.6 ~ +4.9pp，无规律。
错误推断：“原文数据有误”。
真相：原文的环比 = 与**上一个发布日**比；而 2026 年 7—8 月发布节奏是 7/24→7/31→8/7→8/14→8/20
（8/20 距上一期只有 6 天）。用 ISO 周号匹配时 8/20 会去对 8/14，但实际应基于 8/13 的发布。
修正：改为按真实日期间隔匹配后即对齐。

**教训**：当所有环比都“不一致”时，先怀疑自己的对齐逻辑。

### 坑 2：n=1 却算出 P10–P90

现象：某周号只有 1 个观测，`PERCENTILE.INC` 仍返回一个数，四舍五入后 P10/P50/P90 完全相同。
错误用法：把它画成“历史分位带”，看起来有区间。
真相：线性插值在 n=1 时 `pos=0`，必然返回该点值。这是**退化区间**。
修正：n<3 时直接输出“缺口”。

### 坑 3：拿首周冒充“12 周前”

现象：只有 12 个观测的序列，用 `w[n-13]` 计算 12 周变化 → 实际访问到 `undefined`，前端显示空白或 NaN。
错误用法：改用 `w[0]` 顶替，得到“12 周变化 = −5.55pp”。
真相：`w[0]` 是 11 个观测间隔之前，不是 12 周。这会让读者以为已经跌了 12 周。
修正：观测数 <13 时返回“缺口”，另用“窗口涨跌幅”措辞并注明跨度。

**教训**：所有滚动窗口计算都要显式处理“窗口不足”分支，并返回缺口而不是近似值。
