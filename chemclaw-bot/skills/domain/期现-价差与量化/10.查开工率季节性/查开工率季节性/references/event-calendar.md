# 事件台账：春节 / 检修 / 产业事件

季节性结论必须能追到**机制**。本文件给出各类事件的登记格式与判读规则。

## 一、判读规则：机制 vs 一次性冲击

| 事件 | 是否属于季节性 | 判据 |
|---|---|---|
| 春节、国庆长假 | ✅ 是（春节为移动季节性） | 每年都发生，只是日期漂移 |
| 集中检修（春检 3—5 月、夏检、秋检 9—10 月） | ✅ 是 | 每年固定窗口，有检修计划表可证 |
| 需求淡季（冬季施工停工、农业用肥季节） | ✅ 是 | 每年固定窗口 |
| 能耗双控 / 限电 | ❌ 一次性冲击 | 有明确起止时间与政策文号，非年年相同 |
| 装置事故停车 | ❌ 一次性冲击 | 单点事件 |
| 新产能集中投产 | ❌ 结构变化 | 改变产能基数，不是周期性 |
| 节能监察、环保督察 | ❌ 政策性冲击 | 可能常态化，但需逐年核实是否重复发生 |

**铁律**：一次性冲击要写进“本年路径解释”，**不能**写进“季节性特征”。
把 2026 年 9 月的检修高峰说成“季节性规律”，需要先证明 2021—2025 年 9 月也有同样的高峰。

## 五、各品种的常见季节性机制（起手假设，需逐年验证）

| 品种 | 通常的低负荷窗口 | 机制 |
|---|---|---|
| PVC | 二季度（4—6 月） | 集中检修 + 下游施工淡季 |
| 尿素 | 二季度末—三季度 | 农业用肥间歇 + 夏季检修 |
| 纯碱 | 一季度末—二季度 | 检修 + 玻璃冷修 |
| 甲醇 | 三季度 | 西北装置检修 + 天然气限供（冬季） |
| PTA | 二季度、四季度 | 检修窗口，与聚酯负荷联动 |
| 烧碱 | 四季度—一季度 | 氯碱平衡（以碱补氯/以氯补碱） |

**这些只是“假设”**。每个品种必须用**该品种自己的** ≥3 年逐周数据验证后才可写成结论。

## 六、填写顺序

1. 先把**春节日期表**填满（这是确定的、公开的数据，随时可补）；
2. 再填**检修台账**（从资讯机构的检修损失量报告里取）；
3. 最后填**政策与事件**（从公告/政策文号取）；
4. 每填一行，回到周度数据里找对应周的观测值，能对上才算登记完成。

没有对应观测值的事件行，仍然保留，但要标注“无对应观测（缺口）”。
