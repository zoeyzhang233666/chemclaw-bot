# 价格数据来源与溯源

> 政策是"事实"，价格也是"事实"。两条事实链都要能回溯，研究才站得住。

## 一、数据源优先级

| 级别 | 来源 | 说明 |
|---|---|---|
| 1 | 交易所官方（郑商所/大商所等） | 期货结算价、交割基准价。权威但站点常反爬 |
| 2 | **AKShare `futures_spot_price_daily`** | **一次调用返回现货基准价 + 主力/近月合约价 + 基差**，是最省事的期现一体口径 |
| 3 | 生意社 / 隆众 / 卓创 日更报价 | 现货基准价原始出处，页面逐日可溯，但列表回溯浅 |
| 4 | 期货公司日报/周报 | 常同时给"现货均价 + 基差 + 分工艺利润"，适合做关键时点锚点 |
| 5 | 国家统计局 / 海关总署 | 产量、进出口月度数据（做产业指标） |

**AKShare 用法**：

```python
import akshare as ak
# 单日：返回全品种期现表
df = ak.futures_spot_price(date="20211015")
row = df[df['symbol'] == 'SA']
# 字段：spot_price, near_contract, near_contract_price,
#       dominant_contract, dominant_contract_price, dom_basis, dom_basis_rate

# 区间批量（按年切片，每段约 1~2 分钟）
df = ak.futures_spot_price_daily(start_day="20210101", end_day="20211231", vars_list=['SA'])
```

> 实测：`futures_spot_price_daily` 的 `vars_list` 不传会拉全品种（很慢）；
> 一定要传 `vars_list=['SA']` 这类单品种参数。按自然年切片最稳。

## 二、必须做的双源交叉验证

不要只说"数据来自 XX 所以可信"。要**用两条独立路径取同一序列，逐日比对差异**。

纯碱案例的验证：

| 路径 A | 路径 B | 结果 |
|---|---|---|
| 100ppi.com 逐日页面 `sf/day-YYYY-MM-DD.html` 的"纯碱 现货价格"列 | AKShare `futures_spot_price_daily` 的 `spot_price` | **1546 个交易日，差异 > 0.01 的：0 个** |

这才是"数据已验证"。报告里写上"双源零差异"比写"数据可靠"有力得多。

验证脚本模式：

```python
A = {r['date']: r['spot'] for r in path_a_rows}
B = {r['date']: r['value'] for r in path_b_rows}
common = sorted(set(A) & set(B))
diff = [d for d in common if abs(A[d] - B[d]) > 0.01]
print(f'{len(common)} 个共同交易日，差异 > 0.01 的有 {len(diff)} 个')
```

## 三、口径陷阱（每条都会导致结论错误）

### 陷阱 1：全国均价 ≠ 交割地价

现货序列常是"全国综合均价"，而期货交割基准是特定地区。

> 纯碱：生意社"重质纯碱基准价"为全国均价；SA 期货交割基准为华东/华北。
> 两者存在约 **2%~7% 的恒定水平偏误**。

影响：
- **基差水平值不可直接用于交易决策**（会系统性偏移）；
- 但 **Δ基差 在同期内口径恒定**，用于事件比较是安全的。

报告写法：明确声明"基差水平含约 2~7% 的恒定水平偏误，仅用其变动值做事件分析"。

### 陷阱 2：重质 vs 轻质

纯碱分重碱/轻碱，价差可达 100~300 元/吨。抓报价页时**必须确认抓的是哪一列**。

验证方法：取同一天，比对已知的重碱/轻碱基准价，看数值对上哪一个。
> 纯碱案例：2026-10-20 抓取值 1062.86 = 当日"重质纯碱基准价 1062.86"，而当日轻碱为 1050.00 → 确认是重碱。

### 陷阱 3：含税 / 不含税 / 出厂 / 送到

六项口径缺一不可：**数值 · 规格 · 地区 · 含税与否 · 数据日期 · 来源**。缺任何一项不得进表。

### 陷阱 4：上市日边界

期货上市前没有期货价，**也就没有基差**。不要用现货去"替代"期货拼一个基差出来。

> 纯碱 SA 于 **2019-12-06** 上市；2020-06 前连现货连续序列都没有。
> 因此 2020 年以前的政策事件无法做基差实证，只能定性讨论。

### 陷阱 5：台阶结构（连续多日不变）

生意社基准价由多报价取均值合成，常连续多日不变（约 50% 的值为 1/3 整数倍）。
- 做**事件窗口变动**：没问题，是真实报价；
- 做**日波动率/相关性**：需先去平台化或转周频，否则会严重低估波动。

## 四、数据缺口必须显式记录

`research.json` 的 `dataQuality.gaps` 每一条要说明三件事：
**缺什么 · 为什么缺（尝试过什么） · 对结论有什么影响**。

纯碱案例的实际缺口：
```
2015-01 ~ 2020-05 无连续现货序列（逐日验证 100ppi 该期间无纯碱行，非抓取失败）
华东/华北区域日频价完全缺失（公开免费渠道无历史可回溯）→ 无法做区域价差型检验
月度开工率/库存/进出口无完整序列（仅零散锚点）→ 产业指标只能定性描述
GB 29140-2024 三级限值数值未录入（官方平台需浏览器预览）
德令哈"限产50%"原始通知未取得（存在性由督察通报背书）
2021年9月地方限电无统一成文文件（仅作背景变量）
```

## 五、期货日线备选接口（按可用性排序）

| 接口 | 状态（实测） |
|---|---|
| `stock2.finance.sina.com.cn/...getDailyKLine?symbol=SA0` | ✅ 可用，返回主连日线，覆盖上市至今 |
| `push2his.eastmoney.com/api/qt/stock/kline/get?secid=115.SAM` | ❌ RemoteDisconnected / 502 |
| AKShare `futures_zh_daily_sina('SA0')` | ✅（底层同为新浪） |
| czce.com.cn 历史日数据 | ❌ 返回 412（需浏览器 UA + 完整头） |

**注意**：主连（SA0）是拼接合约，换月处有跳空。做长周期事件研究时，
若窗口跨越主力换月，需改用具体合约或做主力价差调整；短窗（±20 日）通常可接受，但要在报告里注明。
