# 可比性规则：这些政策事件能不能放在一起统计

> 事件研究最常犯的错不是算错，而是**把不该合并的事件合并了**，然后对一个混合样本算平均值，
> 得出一个"平均效应"，而这个平均值并不对应任何一个真实事件。

## 一、五个可比性维度（逐项判断，任一不过则不合并）

### 1. 约束性：强制 vs 指导

| | 强制 | 指导 |
|---|---|---|
| 例 | 能耗限额国标、产业结构调整目录、督察整改 | "实施指南""技术指南""新版能效标杆的对标值" |
| 传导 | 直接改变合法产能与成本 | 只改变长期预期 |
| **处理** | 单独成组 | **必须单独成组**，不可与强制合并比较"效应大小" |

判据：看原文动词。"不得""禁止""限期完成""原则上应于X年底前完成"= 强制；
"引导""鼓励""推动""支持"= 指导。

> ⚠️ 注意"原则上应在2025年底前完成技术改造或淘汰退出"——虽含"原则上"，但属限期约束，归强制。

### 2. 覆盖范围：全国 vs 区域

区域事件的供给冲击量级通常远小于全国事件。
> 青海德令哈 3 家碱企约占全国纯碱产能 5%~8%；全国性能耗约束覆盖 100%。

两者混算，全国事件的信号会被区域事件稀释，反之区域事件会被系统误差淹没。
**区域事件单独成组**，并注明其产能占比。

### 3. 政策方向：收紧 vs 放松

> 准入条件**废止**（放松，理论上利空）与 能耗约束**加严**（收紧，理论上利多）方向相反。

方向相反的事件放进同一均值，均值接近 0 是**数学必然**，不代表"政策无效"。
若两者都要用，做**配对对照**（一松一紧）而非算平均。

### 4. 传导渠道

| 渠道 | 例 | 反应时滞特征 |
|---|---|---|
| 供给约束 | 能耗双控、环保限产 | 快，但取决于执行力度，常滞后 1~3 个月 |
| 成本传导 | 煤价/电价干预 | 快，与成本品同步 |
| 准入门槛 | 产业目录、准入条件 | 极慢，影响未来供给，短期可能无反应 |
| 无渠道 | placebo | 应为 0 |

渠道不同，**不应期待同样的窗口反应**。把"准入门槛"类事件与"能耗限产"类混算，会掩盖前者本就没有短期效应这一事实。

### 5. 市场背景

同一政策力度，在短缺周期与过剩周期中的反应可以完全相反。

> 2021 年：供给短缺 + 光伏需求爆发 + 商品普涨 → 收紧型政策反应强烈
> 2023 年：天然碱新增产能投放 + 需求走弱 → 同类政策被新增产能对冲
> 2025 年：产能过剩 + 价格贴成本线 → 政策利多钝化

**必须逐事件标注所处周期**，并在报告中说明背景差异。

## 二、分组规则

```
G1  全国性强制约束      → 唯一可能达到 n≥5 的组
G2  全国性指导性        → 通常 n=2~3，只做描述
G3  同一政策的多个节点  → 配对设计，不可当独立样本
G4  区域性事件          → 通常 n=1~2
G9  系统性冲击(非品种特异) → 必须单列，严禁并入 G1
GPL 安慰剂对照          → 检验噪声水平
G0  市场基础设施        → 样本边界，不进统计
```

**G3 要特别小心**：征求意见稿与定稿是同一政策的两个节点，直接合并是**重复计数**。
正确做法是配对呈现：两个节点的反应差 = 该政策"预期修正"的价值。

## 三、何时禁止汇总统计（判据）

出现以下任一情况，**只做逐事件分析，不做组均值**：

| 条件 | 判据 |
|---|---|
| 组内 n < 5 | 硬门槛，`event_study.py` 会自动把 p 值置空 |
| 组内方向混合 | 正负各有若干，均值无经济含义 |
| 窗口重叠 | 两事件相距 < 最大窗口（如 20 交易日），贡献无法分离 |
| 背景差异过大 | 一个是短缺周期、一个是过剩周期 |
| 存在信息污染 | 窗内有已确认的虚假信息/操纵 |

## 四、纯碱案例的实际结论（可作模板）

| 组 | 成员 | n | 能否汇总 |
|---|---|---|---|
| G1 | E2 准入废止、E3 双控晴雨表、E4 双控方案、E7 能效标杆、E11 能耗限额国标 | **5** | ✅ 勉强达标，**但剔除放松型的 E2 后仅 4，又跌破门槛** |
| G2 | E6 节能指南、E10 设备更新 | 2 | ❌ |
| G3 | E9a 征求意见稿、E9b 定稿 | 2 | ❌ 配对设计 |
| G4 | E8 青海督察 | 1 | ❌ |
| G9 | E5 煤价干预 | 1 | ❌ 系统性冲击 |
| GPL | E12 出口退税 | 1 | ❌ 安慰剂 |

**在这个样本下，唯一能说的是**：G1 事件后 +20 日现货全部为正（5/5），
方向一致但 p≈0.19 不显著；且锚点从"首知日"换到"生效日"后结论会变。
**不能说的是**："纯碱环保政策平均使价格上涨 X 元"。

## 五、写进报告的措辞模板

✅ 可以写：
- "在 5 个全国性强制约束事件中，+20 日现货变动中位数为 +120 元/吨，5 个全部为正，方向一致。"
- "该方向一致性未达统计显著（p≈0.19，n=5），且样本量不足以支持推断。"
- "事件窗内同期存在 A、B 两项产业因素，无法在本样本中分离其贡献。"

❌ 禁止写：
- "该政策使纯碱价格上涨了 X 元。"
- "环保政策对纯碱价格有显著正向影响。"
- "经检验，政策效应为显著的 +N%。"
