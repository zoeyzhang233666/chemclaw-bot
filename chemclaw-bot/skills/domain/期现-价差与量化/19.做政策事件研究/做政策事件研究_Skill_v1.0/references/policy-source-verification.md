# 政策原文核验方法

> 这一步决定整份研究的地基。核验做错，后面所有统计都是精致的垃圾。

## 一、必须区分的四种"政策"

| 类型 | 例子 | 能否直接做事件研究 |
|---|---|---|
| **全国性成文政策** | 发改委令、部委公告、强制性国标 | ✅ 首选。有文号、有确切日期 |
| **地方成文政策** | 内发改环资字〔2021〕209号 | ⚠️ 可做，但须限定覆盖区域，不能代表全国 |
| **新闻稿 / 表态** | 发改委"研究依法对煤炭价格实行干预" | ⚠️ 无文号、无条款。只能当"预期冲击"，须注明非规范性文件 |
| **地方执行 / 临时限电 / 传言** | 2021年9月各地限电；2025年2月青海停产传言 | ❌ 不设单一事件日。作背景变量或直接剔除 |

**传言必须单独处理**：核实到官方通报、证监会处罚等才能用；查不到就写"已证伪/无官方依据"，不许放进候选库。

## 二、六个必核字段

```
policy_name        文件全称（含"征求意见稿"等状态字样，别简写）
doc_no             发文字号（公文编号；国标写标准号）
issuer             发布机关全称
publish_date       正式对外公布日（不是成文日，也不是媒体报道日）
market_first_aware 市场第一次能获知的时间（征求意见稿/提前吹风/媒体先曝）
effective_date     条款开始有约束力的日期
official_url       能打开的原网页或官方 PDF 直链
verification       原文 / 二手转载 / 存疑 / 未找到
```

**成文日 ≠ 发布日**：文件落款常早于挂网数天到数周。以挂网日为准，但要分别记录。

## 三、四类高频坑（全部在纯碱案例中实际踩过）

### 坑 1：文件名中途改了

> 征求意见时叫《产业结构调整指导目录（**2023年本**，征求意见稿）》，
> 正式发布才改称《（**2024年本**）》。

只搜"2024年本 征求意见稿"永远搜不到。**正确做法**：搜索"同序列文件 + 年份 ± 1 + 征求意见"，
或直接去发改委"意见征集"系统按日期翻。公告本身会写明文件全名。

### 坑 2：条款在征求意见稿阶段就已改动

> 2019年本："**新建**纯碱（井下循环制碱、天然碱除外）"
> 2023征求意见稿（07-14）："**纯碱**（…、全部采用工业废盐综合利用制碱除外）" ← 已无"新建"
> 2024年本（12-29）："**纯碱**（井下循环制碱、天然碱除外）"

结论：真正的新信息日是 **2023-07-14**，不是 2023-12-29。若用后者做事件日，
会把 5.5 个月前的信息当成新冲击，得出错误的"政策无反应"。

**必须做三版逐字比对**：旧版本 / 征求意见稿 / 正式本，标出差在哪一条、差在哪两个字。

### 坑 3：政策根本不包括该品种

> 财政部 税务总局公告 2024 年第 15 号：附件2 共 209 个税号，覆盖球化石墨、成品油、硅片、
> 石材、陶瓷砖、玻璃及玻璃纤维、电池。**全文检索 "2836" 与 "纯碱" 均为 0 命中。**

**必须下载附件全文逐税号检索**，不能看正文标题就说"涉及化工品"。
查到"不适用"后，别扔掉——**改作安慰剂对照**（placebo），检验模型会不会把无关事件读成"有效应"。

### 坑 4：措辞差异改变方向判断

> 督察通报原文："没有落实德令哈市政府整改整治中**限产50%的要求**，以虚假台账应付现场检查"
> 常见转述："环保督察**导致**碱企**停产**"

前者是"已有约束未执行"（整改压力↑），后者是"新增停产"（供给↓）。
方向可能同向，但**量级与持续性完全不同**。**必须引原文，不引转述。**

## 四、站点技术特性（实测）

| 站点 | 特性 | 对策 |
|---|---|---|
| czce.com.cn（郑商所） | 对非浏览器 UA 返回 **HTTP 412** | 用 `/cn/rootfiles/`、`/cn/uploadfile/` 官方 PDF 直链；或用带完整浏览器头的抓取 |
| 100ppi.com（生意社） | 反爬 JS（HW_CHECK cookie） | 抓取前先请求首页拿 cookie；列表页只能回溯 25~90 天 |
| NBS easyquery | 间歇 502 / SSL 失败 | 重试 + 换口径；拿不到就记缺口 |
| 发改委 PDF | 附件常是独立 PDF，正文网页不含条款 | **必须下载附件**，正文往往只有一句话通知 |
| 国标全文公开系统 | 限值表格需浏览器在线预览 | 用 playwright 截图/预览；或明确标注"限值数值待核" |

## 五、核验产出格式

每条政策一张卡片，字段见第二节。另需单独一节 **"已排除/存疑清单"**：

```
| 政策 | 判定 | 理由 |
|---|---|---|
| 出口退税公告2024-15 | ❌ 不适用 | 附件1(59项)+附件2(209项)全文检索，HS2836 零命中 |
| 纯碱错峰生产 | ❌ 不存在 | 全国及省级均未检索到；错峰对象历来是水泥/砖瓦/陶瓷/玻璃 |
| 内蒙禁纯碱新增 | ⚠️ 部分 | 正式稿确证含纯碱，但挂"西部鼓励类项目除外"豁免，且印发日缺失 |
```

**否定性结论同样有价值**，它能防止后续研究被错误事件污染。

## 六、与市场的对接：查"信息污染"

做事件研究前必查一件事：**证监会及其派出机构对该时段的处罚决定**。
市场操纵、编造虚假信息会把"政策效应"污染成"谣言效应"。

> 纯碱案例：四川证监局〔2026〕2 号认定，账号"帝侃"于 2023-11-28、11-30 编造碱企停产与地震传言，
> 交易纯碱期货获利 8.5 万元被处罚。该区间正与 2023-12-01 青海督察通报的事件窗重叠。

查法：在 csrc.gov.cn 检索"行政处罚 + 品种/行业关键词 + 年份"。
