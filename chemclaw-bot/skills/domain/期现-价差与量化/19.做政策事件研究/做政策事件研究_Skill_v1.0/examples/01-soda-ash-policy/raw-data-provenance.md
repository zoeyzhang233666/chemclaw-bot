### 1.2 ⭐ 口径判定的关键证据（重要）

生意社从未在页面上明确写出该“现货价格”对应哪一种纯碱。本任务通过三条独立证据确定其为 **重质纯碱基准价**：

1. **数值精确吻合**：2026-10-20 该页 `现货价格 = 1062.86`；同日 `https://www.100ppi.com/sf/737.html` 页面“商品动态”栏中出现快讯标题 **“10月20日生意社重质纯碱基准价为1062.86元/吨”**。二者完全一致。
2. **同期轻碱为另一数值**：同日 **“10月20日生意社轻质纯碱基准价为1050.00元/吨”**，与 1062.86 不同 → 排除轻碱。
3. **样本均值结构**：序列中约 **50.9%** 的数值为 1/3 的整数倍（X.33 / X.67），说明基准价由若干厂家/地区报价取算术平均合成，符合生意社价格模型特征。轻碱指数的官方说明也印证此法：“10月20日获取到样本价格区间为：1100 - 950，平均报价1050.00。”（https://www.100ppi.com/cindex/list-226.html）

### 1.3 已知缺陷（必须在使用前阅读）

| 缺陷 | 说明 |
|---|---|
| **含税** | 生意社图表图注为“国内 混合价 **含税** ；优等品”（来自图表页 `https://www.100ppi.com/graph/cindex.php?f=graph_ppid_ave&ppid=737` 解包后的 JS 文本）。**含税成立，但“含税XX%”的具体税率未在页面明示**。 |
| **区域** | 为**全国综合均价**，**不是华东或华北**。与“华东重碱”口径存在系统性偏差（见 §4 交叉验证） |
| **区间取中值** | 生意社价格由报价区间中值合成 → 序列呈现“台阶式”跳动（同一价位维持多日），非逐笔成交价 |
| **起点 2020-06-01** | 2019-12-06 至 2020-05-29 的页面中，郑商所表格里**完全没有纯碱行**（已逐日验证：该期间 116 天全部 `NOROW`）。说明生意社在 2020-06 才将该品种纳入现期表，**非抓取失败**。 |
| **1/2/10 月覆盖偏低** | 1、2 月约 14-20 天，10 月约 9-17 天（节假日 + 个别日页面缺该行）。2026-10 仅 9 天（截至 10-20）。 |
| **2020 年 1、2 月全缺** | 2020 年 1 月、2 月为 0 条（在纯碱行上线之前，不影响序列内部一致性） |
| **反爬** | 网站有 JS cookie 挑战（`HW_CHECK`），脚本已处理；但**高频请求会被拦截**，本任务使用 6 并发 + 每线程独立 Session，成功率 1546/1793 工作日（其余均为节假日/缺行） |
| **不可回溯性** | 100ppi 的 `/news/list---533-N.html`、`/price/plist-533-N.html`、`/cindex/ptrade-226.html`、`/graph/` 等页面**均只能回溯约 25-90 天**，无法扩展至 2015-2020 |

## 6. 使用者须知（计算基差时的注意事项）

1. **口径不匹配**：`rows` 是**全国重碱均价**；SA 期货交割基准为**华东/华北重碱**。直接用会产生恒定偏误（约 −2% ~ +7%，方向随区域价差变化）。建议：用 §2 的锚点做一次水平校准（level adjustment），而不是直接相减。
2. **含税**：SA 期货价格含税（13% 增值税），生意社基准价亦标“含税” → 理论上可比；但生意社税率未明示。
3. **台阶结构**：生意社价格是区间中值合成，日频但**非日更**（常连续多日不变），计算基差的日波动时应先做去平台化/或改用周频。
4. **事件研究**：2021-10/11 峰值、2024-06~08 下跌段、2025-2026 低迷段均在序列内，可直接用；2020 年疫情段（2-5 月）**缺序列**，只有 2020-01 与 2020-05 两个锚点，**建议该事件用锚点做单点分析，不要插值**。
5. **不可外推**：`anchors` 中 `precision` 为 `month`/`year` 的锚点（2017-10、2025 年）不要转成“日价”。
