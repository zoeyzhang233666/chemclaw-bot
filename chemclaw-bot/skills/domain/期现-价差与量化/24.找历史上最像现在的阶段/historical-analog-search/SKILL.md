# 找历史上最像现在的阶段（Historical Analog Search）

## 这个 Skill 干什么

把「现在」变成一个可比较的**状态向量**，在过去找最像的几个窗口，然后老老实实告诉你它们后来发生了什么。

四件事，缺一不可：

1. **当前状态是什么** —— 观察日 + 每个指标的原始值，不许含糊其辞。
2. **过去哪几段最像** —— 每个指标先做**适合它自己的**标准化（避免量纲和波动率把距离带偏），再加权排序、去重、聚成行情轮次。
3. **像在哪、不像在哪** —— 逐指标给出「同向 / 反向 / 无数据」，而不是一句「高度相似」。
4. **后来怎么走的** —— 每个窗口之后 1 个月、3 个月的价格、库存、基差、月差实际演化。

**绝不做的事**：把历史相似说成未来预测；用未来数据去构造历史状态；在无数据处补数、插值、外推；把相邻日期全部塞进前五名。

## 什么时候用 / 不用

用：判断「现在这个位置在过去有没有参照」；给持仓或谈判找一个历史锚；复盘某段行情的相似结构；回答客户「以前这样的时候后来怎样」。

不用：单指标价格查询（→ `chem-market-brief`）；采购议价（→ `chem-procure-brief`）；两个指标的相关性（→ `two-indicator-correlation`）；季节性规律（→ `查库存季节性`）；任何要求你预测价格或给交易建议的场合。

## 执行流程（9 步）

### 第 0 步：确认数据真的到手了

**没有真实历史序列就不要往下走。** 先跑体检：

```bash
python scripts/search_analogs.py --csv data/your.csv --date-col date --qc-only --outdir build
```

逐列报告首个/末个观测、缺失率、频率是否稳定。缺失率 > 50% 的列会明确告警——它决定了这份研究能做到多细。

### 第 1 步：固定观察日，写下当前状态

观察日必须**明确到某一天**，并说明为什么是这天（最新统计日？最新交易日？）。把当天每个指标的原始值列出来。数据缺失就写「无数据」，不要用相邻日期顶替。

### 第 2 步：逐指标选标准化方法（不要一刀切）

| 指标形态 | 方法 | 为什么 |
|---|---|---|
| 价格、库存、开工率、到港量（有量纲、中枢会漂） | `rolling_z`（2 年窗口） | 去中心 + 缩放，跨年份可比 |
| 比率型且可正可负（基差率、月差） | `rolling_z` | 保留符号信息，量级已归一 |
| 「贵不贵」的直觉判断（价格 52 周分位） | `rank` | 天然无量纲，不受通胀与换月影响 |
| 波动极大、右偏、偶有极端值（到港量） | `pctile_rank` | 比 z 分数稳健 |
| 量级差异极大的同类指标 | 先取对数或变化率，再 `rolling_z` | 防止大数指标压倒小数指标 |

**关键**：任一历史日 t 的均值/标准差/分位，只能用 **t 当日及以前** 的数据估计。这是本 Skill 的第一硬规则。公式见 `references/02-标准化与相似度公式.md`。

### 第 3 步：明确窗口长度、权重、相似度方法

- **窗口长度**：默认 4 周（状态 + 形态）。1 周只看点位，13 周更能区分「趋势中」和「拐点处」，但也更容易把噪声算进距离。
- **权重**：来自行业判断，不是拟合结果。默认基差率最高（1.5），其次近月结构与库存（1.2）。
- **方法**：`mae`（默认，稳健可解释）/ `rmse`（惩罚大偏差）/ `cosine`（只看方向）。

**三者都必须写进报告**，否则结论无法复核。

### 第 4 步：只使用时点数据（最容易翻车的一步）

三条具体做法：

1. **滚动统计**：`[t-lookback, t]`，不足最小样本数就不出值（不硬算）。
2. **周度基本面**：以「统计截止日之后的下一个观测日」作为首次可用时点。统计日 14:00 才发布的数字，不允许在当天使用。
3. **补齐口径**：换月、换样本、换机构必须单独标注；换月造成的跳空不能当成行情变化。

### 第 5 步：计算并排序，然后**必须去重**

按综合分降序取，若候选与已选窗口观察日相距不足 `min-gap-weeks`（默认 8 周）就跳过——否则 5 个名额会被同一段行情的相邻几周占满。

同时把命中窗口聚成「行情轮次」：相邻间隔 < 3 倍最小间隔的算同一轮。**如果 5 个窗口只有 1~2 轮，必须在报告里直说样本集中。**

### 第 6 步：逐指标给出相同 / 不同

对每个命中窗口、每个指标，给出：原始值、标准化偏离、方向是否一致（同向 / 反向 / 无数据）。

**只有当大多数权重落在「同向」时，「相似」才站得住**，这也是默认设 `min_sign_match=0.75` 的原因。

### 第 7 步：后续 1M / 3M 的实际演化

对每个窗口取其后 1 个月、3 个月（按日历月推断到最近交易日）的：

- 价格（主力/现货）涨跌幅
- 基差率水平
- 港口库存水平
- 月差水平

**必须标注 N**。5 个窗口的「平均涨幅」是个位数样本的均值，不是期望值。

### 第 8 步：检查是否重叠、是否集中在同一段行情

输出：命中窗口的最短间隔、行情轮次数量、按年月分布、覆盖的自然年数。

若全部落在同一两年，**这份类比的时间代表性不足**，要写明。

### 第 9 步：写清局限（三方面，缺一不可）

1. **结构变化**：供给格局、下游结构、统计口径变了，形态相同不代表机制相同。
2. **样本范围**：各指标历史长度不同，「指标齐全」的可比窗口可能只有寥寥几个。**这一条通常是最致命的，必须量化说出有几个窗口。**
3. **方法局限**：距离尺度和权重是人定的；指标之间高度相关会重复计入；换方法名单可能就变了（附敏感性表）。

## 交付物

1. **自包含交互 HTML**：改品种/指标/权重/窗口/样本区间/method 即整页重算；当前状态、排行榜、逐指标并排对比、1M/3M 演化、命中详情（含当时产业事件）、重叠检查、敏感性、局限。
2. **多表 Excel**：数据口径、当前状态、标准化说明、方法与权重、相似窗口、全部候选、逐指标对比、去重证据、后续演化、敏感性、事件、数据质量、局限、原始面板。
3. **结果 JSON**：供二次分析。

## 覆盖率分层：本 Skill 的核心诚实机制

实测经验（甲醇）：价格和基差能回到 2015 年，但港口库存/厂库/到港量最早只有 2022 年，装置开工率要等到 2025 年 7 月。若严格要求「全部指标都有值」，近 5 年样本里**只剩 1~3 个可比窗口**。

所以本 Skill 强制输出三层对照：

| 口径 | 含义 | 用途 |
|---|---|---|
| **A** 全部可得指标 | 覆盖率 ≥ 90% 才纳入 | 最严格，窗口可能极少——少就要直说少 |
| **B** 自动剔除覆盖不足指标 | 把历史太短的基本面剔掉后重跑 | 展示「去掉短历史指标后结论变多少」 |
| **C** 长样本（仅价格/基差/月差） | 拉满 10 年 | 看更长历史里有没有真正的参照 |

**如果 A 只剩 1~2 个窗口，正确结论是「样本内没有足够的可比对象」，而不是「找到了唯一答案」。**

## 命令速查

```bash
# 体检
python scripts/search_analogs.py --csv data/x.csv --date-col date --qc-only

# 完整研究（默认严格口径）
python scripts/search_analogs.py --csv data/methanol_weekly_panel.csv --date-col date \
    --config data/config_methanol.json --asof 2026-10-14 \
    --freq-days 7 --price-col fut_close \
    --display-cols fut_close,spot,basis,port_inv,operating_rate \
    --forward-cols fut_close,basis_pct,port_inv \
    --name methanol --outdir build

# 放宽（允许历史时点缺指标）
python scripts/search_analogs.py ... --allow-partial --coverage-min 0.5
```

配置格式见 `data/config_example.json`；每个指标要有 `key / name / unit / weight / std_method / lookback / source / rationale`。

## 常见错误

| 错误 | 后果 | 正确做法 |
|---|---|---|
| 用全样本均值/标准差做标准化 | 未来信息泄漏，回测虚高 | 只用 t 及以前 |
| 周度库存直接用统计日当天 | 用了尚未发布的数字 | 对齐到下一个观测日 |
| 不去重直接取前 5 | 5 个名额同一段行情 | 非极大值抑制 |
| 只报「相似度 0.85」 | 无法复核 | 逐指标给同向/反向 |
| 把 5 个窗口均值说成「大概率」 | 误导 | 标 N，说「历史既成事实」 |
| 缺数据就插值 | 编造 | 留空 + 分层对照 + 写进局限 |
