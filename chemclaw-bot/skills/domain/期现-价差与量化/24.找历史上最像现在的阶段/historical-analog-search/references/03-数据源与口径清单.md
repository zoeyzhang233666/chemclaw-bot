# 03 · 数据源与口径清单

本 Skill 只接受**宽表 CSV**（每行一个观测日，每列一个指标），不绑定固定数据商。下面列出常见可得来源、真实覆盖范围与坑。

## 1. 免费公开源（已在甲醇上实测）

| 数据 | 来源 | 频率 | 实测覆盖 | 坑 |
|---|---|---|---|---|
| 现货基准价 | 生意社 100ppi `sf2/day-YYYY-MM-DD.html` | 日 | 2015-01 起 | 有反爬 challenge cookie；HTML 结构逐年变化，用字符串切分而非正则解析 |
| 期货主力价 | 同表 / 新浪 `MA0` 日线 | 日 | 2015 / 2014-12 起 | 主力换月有跳空，绝对价不可直接跨期比较 |
| 基差、基差率 | 100ppi 表内直接给 / 自行计算 | 日 | 2015-01 起 | 与新浪主力收盘交叉校验：中位差 0.00，>0.5% 的差异集中在换月日 |
| 各交割月合约 | 新浪 K 线接口 `MAnnm` | 日 | **2018-05 起** | 更早合约接口不提供，月差样本因此更短 |
| 港口样本库存 | 隆众资讯（我的钢铁转载）周报正文 | 周 | 2022-03 起 | 统计日 14:00 发布；样本港口调整会造成跳变 |
| 样本生产企业库存 | 同上 | 周 | 2022-04 起 | 与港口口径不可相加 |
| 周度到港量 | 同上 | 周 | 2022-03 起 | 波动极大、右偏 |
| 装置产能利用率 / 周产量 | 同上 | 周 | **2025-07 起** | 早期周报正文未公开完整数值 |
| 产业事件/资讯 | 我的钢铁搜索 API | 日 | 2010 起 | 可用于给窗口配「当时发生了什么」 |

**重要**：把上表原样写进报告的「数据质量」表。读者看到「开工率只有 2025-07 起」，自然会问「那 2022 年的相似度是不是只看了一半指标」——这正是分层对照要回答的。

## 2. 自建/客户数据

若用户提供 Excel：

- 必须有**明确的日期列**，且是「可获得日」而非「统计期标签日」。
- 周度指标要问清：统计截止日是哪天？几点发布？——这决定 PIT 对齐。
- 出现「本期」「上期」这类相对标签时，先还原成绝对日期。
- 同一指标多来源不一致时，**选一个主源并记录**，不要拼接。

## 3. 各指标口径要点

### 3.1 现货价

- 税基：含税 / 不含税。跨品种比较必须统一。
- 交货方式：库提 / 送到 / 出厂。
- 区域：华东 / 华南 / 内地，价差可能比波动还大。
- **绝对价格不适合进状态向量**（受通胀与换月污染），用相对指标替代。

### 3.2 期货价

- 主力连续 vs 指数：换月差异明显。
- 结算价 vs 收盘价：日盘数据一般用收盘，但保证金计算用结算价。
- 夜盘：若所在交易所开夜盘，日频数据应包含夜盘。

### 3.3 基差 / 基差率

```
基差      = 现货 − 期货（主力）
基差率(%) = 基差 / 现货 × 100
```

基差率是**期限结构最直接的度量**，也是本 Skill 默认权重最高的指标。

### 3.4 月差

```
月差(%/月) = (近月 − 次月) / 近月 / 相隔月数 × 100
```

- 正值 = backwardation（近强），负值 = contango。
- 只在**当日有成交**的合约间计算，死合约不参与，否则会算出假价差。
- 主力换月前后要留意「近月」定义是否切换。

### 3.5 库存

- 港口样本 vs 全样本：不可混用。
- 周期性与趋势并存：直接看到「下降」可能是季节性，建议同时用**分位**而非仅水平。
- 拆成「水平」+「周变化」两个指标，信息量显著增加。

### 3.6 开工率 / 产量

- 口径：产能利用率 vs 开工负荷率，两者不同。
- 检修季效应明显，用滚动 z 时窗口要覆盖至少一个完整年度。
- **历史覆盖通常是最大短板**，务必如实写出起始日期。

## 4. 数据体检会检查什么

`--qc-only` 输出 8 类信息：

1. 行数、日期范围
2. 日期能否解析、有无重复
3. 相邻间隔是否等于目标频率（`--freq-days`）
4. 每列的 n、缺失率、首个/末个观测、min/max
5. 全空列告警
6. 缺失率 > 50% 列的告警
7. ERROR 清单（有 ERROR 不应继续）
8. 结论：这份数据能支撑到哪一层（A / B / C）

## 5. 已知的数据陷阱

| 陷阱 | 表现 | 处理 |
|---|---|---|
| 公告日 vs 数据期 | 周三调查的库存被记在周一 | 以发布日为准对齐 |
| 样本调整 | 某年港口样本从 12 个变 15 个，库存凭空跳增 | 标注断点，必要时截断 |
| 合约换月 | 主力价连续但合约变了 | 用比率，不用绝对价 |
| 节假日 | 周锚点落在非交易日 | 取当周最后一个交易日 |
| 反向修正 | 上周数据本周被修正 | 只能用「当时发布的初值」，不可用修正后数据回测 |
| 单位不一致 | 万吨 vs 吨、元/吨 vs 元/千克 | 建表时统一并写进口径表 |
