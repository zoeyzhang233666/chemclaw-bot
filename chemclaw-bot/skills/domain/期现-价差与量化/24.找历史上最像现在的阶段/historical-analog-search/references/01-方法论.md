# 01 · 方法论

## 1. 问题定义

「现在最像历史上哪个阶段」本质上是一个**最近邻检索**问题：

> 给定一个观察日 t₀ 的状态向量 x(t₀) ∈ ℝᵏ，
> 在过去样本 T = {t < t₀} 中找出使距离 d(x(t), x(t₀)) 最小的若干 t。

难点不在算法，而在下面四件事，任何一件做错，结论就不可用：

| 难点 | 做错会怎样 | 本 Skill 的处理 |
|---|---|---|
| 尺度扭曲 | 价格（3000 元）压倒基差率（18%） | 逐指标标准化到同一量级 |
| 未来信息 | 回测很美，实盘无法使用 | 滚动统计只用 t 及以前 |
| 重复命中 | 5 个名额被同一段行情占满 | 非极大值抑制 + 行情轮次 |
| 数据缺失被掩盖 | 用 1 个指标算出「相似度」 | 覆盖率门槛 + 分层对照 |

## 2. 状态向量怎么定

一个实用的状态向量应覆盖 **价格位置 / 期限结构 / 供需 / 波动** 四类：

| 维度 | 代表指标 | 回答的问题 |
|---|---|---|
| 价格位置 | 近 4 周涨跌、52 周分位 | 涨到哪了、涨多快 |
| 期限结构 | 基差率、近月-次月月差 | 现货紧不紧、市场怎么定价 |
| 供需 | 港口库存、厂库、开工率、到港量 | 真实缺口有多大 |
| 波动 | 20 日实现波动率 | 现在是不是「最容易出事」的状态 |

**不建议**放进状态向量的：绝对价格（会被通胀和换月污染）、持仓量（金融属性强但不稳定）、单一事件（不可重复）。

## 3. 时点原则（Point-in-Time）

> 任一历史日 t 的标准化参数，只能使用 t 当日及以前**已经公布**的数据。

三条落地规则：

**R1 滚动统计边界**
```
μ(t) = mean( x[s] : s ∈ [t - L + 1, t] )
σ(t) = std ( x[s] : s ∈ [t - L + 1, t] )
z(t) = clip( (x(t) - μ(t)) / σ(t), -3, +3 )
```
若区间内有效观测 < `min_obs`，输出 NaN，**不硬算**。

**R2 周度指标的可用时点**

| 环节 | 错误做法 | 正确做法 |
|---|---|---|
| 库存统计日 | 统计日当天就使用 | 统计日 **14:00 发布** → 首次可用为当日之后的下一个观测日 |
| 到港量统计日 | 同上 | 同上 |
| 装置周报 | 周报标题日期当可用日 | 以**正文发布日**为准 |

实现上，`build_panel` 类脚本在把周度序列对齐到日/周锚点时，要求锚点**严格晚于** `asof`。

**R3 换月与口径变化**

期货主力换月造成的价格跳空不是行情变化；统计样本调整（如港口样本增删）造成的库存跳变不是去库。遇到这类断点应：
- 在报告中单独标注；
- 优先用比率/月差而非绝对价；
- 必要时截断样本，而不是把断点抹平。

## 4. 相似度

### 4.1 为什么不用欧氏距离

原始欧氏距离被量纲主导。先标准化再算距离，等价于用**马氏距离的对角近似**（假设指标独立）。

### 4.2 四种方法

| 方法 | 公式 | 特点 | 何时用 |
|---|---|---|---|
| `mae` | sim = 1 − Σwᵢ\|zᵢ−zᵢ'\| / Σwᵢ / 3 | 稳健，不受单点极端影响 | **默认** |
| `rmse` | sim = 1 − √(Σwᵢ(zᵢ−zᵢ')²/Σwᵢ) / 3 | 惩罚大偏差 | 你认为「某一维极不像」就不该入选 |
| `cosine` | sim = (cos θ + 1) / 2 | 只看方向不看幅度 | 关心「结构同型」而非「程度」 |
| `mahalanobis` | sim = exp(−½ dᵀ Σ⁻¹ d) | 考虑指标相关性 | 样本充足、指标高度相关 |

除以 3 的含义：z 已截断在 ±3，最坏情况 MAE = 3，故 sim ∈ [0,1]。

### 4.3 综合得分

```
score = 0.7 × 状态相似度 + 0.3 × 路径相似度
```
路径相似度 = 窗口内每一周形态的逆平均偏离（同样除以 3）。用 30% 权重是为了区分「同样是高基差，一个是刚冲上去，一个是高位横了三个月」。

## 5. 去重与行情轮次

### 5.1 非极大值抑制（NMS）

```
按 score 降序遍历候选：
  若该候选与所有已选窗口的观察日间隔 ≥ min_gap 周 → 选中
  否则跳过
直到选满 top_n
```

`min_gap` 默认 8 周。设太小会重复，设太大会漏掉真正的独立性。

### 5.2 行情轮次

把命中窗口按时间排序，相邻间隔 ≥ 3×min_gap 周则进入新一轮。

**诊断意义**：若 5 个窗口只落在 1 轮里，说明这段时间只有一次可比行情，**样本的时间代表性不足**，必须在结论中说明。

## 6. 后续表现的正确读法

```
1M 表现 = x(t₀ + 1 个日历月 ≈ 最近交易日) / x(t₀ 起 4 周均值) − 1
```

三点提醒：

1. **N 很小**。5 个窗口就是 5 个观测，且彼此可能相关。
2. **这不是分布**。没有置信区间可言，不能算「概率」。
3. **幸存者偏差风险**：如果样本只覆盖近 2 年，它只代表那 2 年的市场结构。

## 7. 覆盖率分层（本 Skill 的核心机制）

### 7.1 问题

不同指标的历史长度差异巨大。以甲醇为例：

| 指标 | 起始 | 原因 |
|---|---|---|
| 价格 / 基差 / 波动率 | 2015 | 公开日频数据 |
| 月差 | 2018-08 | 合约日线仅 2018 起可获取 |
| 港口库存 / 厂库 / 到港 | 2022-03 | 公开周报的检索覆盖范围 |
| 装置开工率 / 周产量 | 2025-07 | 早期周报正文未公开数值 |

若严格要求「全部指标都有值」，2021-10 起的 5 年样本里**只剩个位数窗口**。

### 7.2 三层对照

| 层 | 规则 | 回答的问题 |
|---|---|---|
| **A** 全部可得指标 | 覆盖率 ≥ 90% | 严格条件下有没有可比对象 |
| **B** 剔除覆盖不足指标 | 自动去掉样本内覆盖 < 90% 的指标 | 去掉短历史指标后结论变多少 |
| **C** 长样本 | 用价格+基差+月差，拉满 10 年 | 更长历史里有没有真参照 |

### 7.3 正确的结论写法

> A 口径下只剩 1 个可比窗口，说明在本数据条件下「基本面齐全 + 时点无未来函数」的严格类比对象几乎不存在。B 口径扩充到 5 个窗口，但这些窗口只覆盖 2 个自然年。因此本研究的结论应视为**结构参照**，不足以支撑概率判断。

这句话不好听，但它是真的。**Skill 的价值一半在于告诉你「什么时候不能下结论」。**

## 8. 什么时候不该用这个方法

- 数据不足 2 年 → 滚动窗口都不够，无法标准化。
- 品种刚上市 → 没有完整周期。
- 发生了**制度性断裂**（合约规则大改、交割标准变了）→ 历史不可比，应先分段。
- 你其实想预测价格 → 这不是预测工具。
- 你只有 2~3 个指标 → 状态向量太薄，「相似」近乎必然，没有信息量。
