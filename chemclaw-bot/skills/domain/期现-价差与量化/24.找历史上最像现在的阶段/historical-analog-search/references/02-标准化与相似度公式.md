# 02 · 标准化与相似度公式

所有公式均与 `scripts/analog_lib.py` 的实现一一对应，可据此复核代码。

## 1. 标准化

记原始序列为 x(t)，指标权重 wᵢ > 0。

### 1.1 rolling_z（默认）

```
μ(t) = (1/n) Σ_{s=t-L+1}^{t} x(s)           n = 区间内有效观测数
σ(t) = sqrt( Σ (x(s) − μ(t))² / (n−1) )     样本标准差
z(t) = (x(t) − μ(t)) / σ(t)
z(t) = clip(z(t), −3, +3)
```

- `L` = lookback（默认 104 期 ≈ 2 年周度）
- 若 n < `min_obs`（默认 52）→ z(t) = NaN
- 若 σ = 0 → z(t) = NaN（避免除零）

**适用**：价格、库存、开工率、到港量、基差率、月差、波动率。

### 1.2 expanding_z

同 rolling_z，但 `L → t`（从样本起点累积）。适用于「只想和过去所有历史比」的场合。缺点：早期极度不稳定，通常不推荐。

### 1.3 rank / pctile_rank

```
r(t) = #{ s ∈ 窗口 : x(s) < x(t) } / (n − 1)
z(t) = (r(t) − 0.5) × 2               → 映射到 [−1, +1]
```

- `rank` 用滚动窗口 L
- `pctile_rank` 用累积窗口

**适用**：价格 52 周分位、库存分位、波动率分位等「贵不贵 / 高不高」的直觉指标。

优点：完全无量纲，对偏态和极端值稳健。缺点：丢失幅度信息（历史最高和「高一点点」都是 1.0）。

### 1.4 diff_std

```
d(t) = x(t) − x(t−1)
z(t) = rolling_z(d(t))
```

**适用**：想刻画「变化速度」而不是「水平」的指标，例如库存周变化。

### 1.5 为什么不能一刀切

| 若统一用 | 后果 |
|---|---|
| 原始值 | 价格 3000 与基差率 18 之间的「距离」由价格完全主导 |
| 全样本 z | 未来信息泄漏：2020 年的 z 用了 2026 年的均值 |
| 统一 rank | 丢失幅度：18% 和 40% 的基差都变成「接近最高」 |

## 2. 距离与相似度

记当前状态 zᵢ、历史状态 zᵢ'，权重 wᵢ，有效权重 WE = Σ_{i∈V} wᵢ（V = 两端都有值的指标集）。

### 2.1 MAE（默认）

```
d = Σ_{i∈V} (wᵢ/WE) · |zᵢ − zᵢ'|
sim = 1 − d / 3
```

### 2.2 RMSE

```
d = sqrt( Σ_{i∈V} (wᵢ/WE) · (zᵢ − zᵢ')² )
sim = 1 − d / 3
```

### 2.3 Cosine

```
sim_raw = Σ wᵢ zᵢ zᵢ' / ( sqrt(Σ wᵢ zᵢ²) · sqrt(Σ wᵢ zᵢ'²) )
sim = (sim_raw + 1) / 2
```

### 2.4 Mahalanobis

```
d² = (z − z')ᵀ W Σ⁻¹ W (z − z')
sim = exp(−d²/2)
```
Σ 用收缩估计：`Σ = (1−α)S + α·diag(S) + εI`，α = 0.5，保证可逆。

### 2.5 关于「除以 3」

z 已截断在 [−3, 3]，故任意两项之差 ≤ 6，加权平均 |差| ≤ 3（当且仅当一项 +3、一项 −3）。因此 `sim = 1 − d/3 ∈ [0, 1]`：

- sim = 1.0 → 完全一致
- sim = 0.8 → 平均偏离 0.6σ
- sim = 0.5 → 平均偏离 1.5σ
- sim = 0.0 → 平均偏离 ≥3σ

## 3. 路径相似度

在状态窗口（默认 4 周）内，逐周比较：

```
for 每个指标 i:
    a = z_i[t−W+1 … t]         历史窗口
    b = z_i[t₀−W+1 … t₀]       当前窗口
    若有效重叠 < 0.8W → 跳过该指标
    dev_i = mean(|a − b|)
path_sim = 1 − ( Σ wᵢ devᵢ / Σ wᵢ ) / 3
```

**综合得分**：
```
score = 0.7 × sim + 0.3 × path_sim
```
若路径无法计算（W = 1），则 score = sim。

## 4. 覆盖率与有效权重

```
覆盖率 cover(t) = Σ_{i: zᵢ(t) 非空} wᵢ / Σ_i wᵢ
```

规则：

| 场景 | 处理 |
|---|---|
| 当前时点某指标无值 | 该指标不进入状态向量，权重也不进分母（保证「当前状态」完整可解释） |
| 历史时点 cover < `coverage_min`（严格模式 0.9） | **该候选直接剔除** |
| `--allow-partial` 模式 cover < 0.5 | 剔除 |
| `--allow-partial` 且 0.5 ≤ cover < 0.9 | 保留，但 sim 乘以惩罚并标记 |
| 同向指标权重占比 < `min_sign_match`（默认 0.75） | 剔除 |

## 5. 去重（NMS）与行情轮次

```
gap_days = min_gap_weeks × 7

候选按 score 降序：
    if ∀ 已选 s : |date − s.date| ≥ gap_days → 选中

行情轮次：把选中窗口按时间排序，
    if date_k − date_{k−1} ≥ 3 × gap_days → 轮次 +1
```

## 6. 硬间隔（lag）

```
(asof − t).days ≥ lag_at_least_days     默认 21 天
```

防止「当前」和「三周前」互相比。若观察日附近有剧烈行情，建议调到 8~12 周，让历史窗口真正独立。

## 8. 复核清单

想验证结果是否可信，按这个顺序查：

1. 观察日的 z 值是否都在 ±3 内且方向合理？
2. 候选数量（`n_candidates`）是不是太少？少于 20 个就要警惕。
3. 命中窗口之间最短间隔是否 ≥ min_gap？
4. 行情轮次是否只有 1 轮？
5. 逐个剔除指标后 Top 名单重合率是多少？（< 60% 说明结论对单个指标过于敏感）
6. 换 mae/rmse/cosine 后名单变了吗？
7. 逐指标方向：同向比例是多少？
