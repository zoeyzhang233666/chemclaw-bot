# 04 · 分组统计与推断

> 目标：给出每组"有多少样本、分布多宽、和别的组差多少、这个差有多可信"。

## 4.1 分组方案（固定，不寻优）

| 维度 | 分组 | 阈值来源 |
|---|---|---|
| 库存水平（F1） | Q1 <p20 · Q2 p20–50 · Q3 p50–80 · Q4 ≥p80 | 时点 expanding 分位，固定 20/50/80 |
| 周度变化（F3） | 大幅去库 ≤−3 · 小幅去库 −3–0 · 小幅累库 0–3 · 大幅累库 >3（万吨） | 按品种量级设定一次后固定 |
| 连续状态（S） | 连续≥2周去库 · 连续≥2周累库 · 其他 | 固定 2 周 |

**不要**因为某组样本少就调阈值，也不要比较多个切点后挑最显著的。

## 4.2 每组必须报告的 9 个数字

| 指标 | 说明 |
|---|---|
| `n` | 有效样本数（非重叠意义上的"周数"） |
| 均值 | 期望水平的点估计 |
| 中位数 | 抗异常值 |
| 标准差 | 离散度 |
| P25 / P75 | 分布主体范围 |
| 95% CI | **块 bootstrap** 区间（见 4.4） |
| 上涨占比 | 方向一致性 |
| 与其余组差异的 p | Welch t（不假设方差齐性） |
| Mann-Whitney p | 中位数差异的非参检验 |

## 4.3 均值 vs 中位数必须同时看

- 均值 ≈ 中位数 → 分布近似对称，结论较稳
- 均值 ≫ 中位数 → 少数极端周把均值拉高，**不要**只报均值
- 甲醇案例：连续去库组均值 +1.11%、中位数 +0.43%，说明效应部分来自少数极端周 —— 报告必须写出这一点

## 4.4 置信区间：块 bootstrap，不是普通 t 区间

普通 t 区间假设样本独立。但 h 周窗口互相重叠，实际有效样本远少于名义样本。

```python
def block_bootstrap_ci(x, block, n_boot=2000, alpha=0.05, seed=7):
    rng = np.random.default_rng(seed)
    n = len(x); nb = int(np.ceil(n / block))
    stats = np.empty(n_boot)
    for b in range(n_boot):
        starts = rng.integers(0, n, nb)
        idx = np.concatenate([(s + np.arange(block)) % n for s in starts])[:n]  # 环形
        stats[b] = x[idx].mean()
    return np.quantile(stats, [alpha/2, 1-alpha/2])
```

块长 = 窗口周数（1/2/4），保证重叠结构被保留。

## 4.5 重叠窗口的三种处理（都做）

| 方法 | 作用 | 实现 |
|---|---|---|
| **HAC / Newey-West** | 修正 t 统计量的自相关 | 带宽 = 窗口 − 1，Bartlett 核 |
| **非重叠子样本** | 检验"显著性是否来自重叠" | `df.iloc[::h]` 重新检验 |
| **块 bootstrap** | 无分布假设的区间 | 见 4.4 |

```python
def hac_ols(y, x, lag):
    X = np.column_stack([np.ones(len(x)), x])
    b,*_ = np.linalg.lstsq(X, y, rcond=None)
    e = y - X @ b
    XtXi = np.linalg.inv(X.T @ X)
    EX = e[:, None] * X
    meat = EX.T @ EX
    for k in range(1, lag+1):
        w = 1 - k/(lag+1.0)
        A = EX[k:].T @ EX[:-k]
        meat += w * (A + A.T)
    V = XtXi @ meat @ XtXi
    return b, np.sqrt(np.diag(V))
```

**有效样本折算**：`有效独立观测 ≈ 周数 / 窗口`。甲醇 228 周 / 4 周 = 57 个 —— 报告里必须写出这个数，否则读者会高估证据强度。

## 4.6 效应量表达：用"可理解的口径"

不要只报 ρ 和 p。至少给出：

- 分组间**均值差**（百分点 / 元每吨）
- 若用斜率：**每 1 万吨库存变化，未来 1 周现货变化 X%**

甲醇案例：F3 对 1 周现货斜率 −0.043（每累库 1 万吨，未来 1 周现货平均低 0.043%），n=227，HAC t=−2.29。
这样读者能判断"这个效应对我有没有意义"。

## 4.7 报告中的显著性标注约定

| 标注 | 含义 |
|---|---|
| `***` | 原始 p < 0.001 |
| `**` | p < 0.01 |
| `*` | p < 0.05 |
| `ns` | 不显著 |

并且**必须**并列展示 HAC p 与 BH q，因为：
- 原始 p 忽略重叠 → 偏乐观
- BH q 忽略的是"试了多少次" → 决定结论能否作为"发现"
