# 02 · 库存序列构建

> 目标：把散落在公告、周报、新闻里的库存数字，组装成一条**口径一致、日期对齐、可追溯**的周度序列。

## 2.1 三种构建路径

### 路径 A：有官方连续周报（首选）

直接解析官方发布页，得到 `asof / pub_ts / value / url` 四元组。

```python
# 典型：从正文中抽取"截至 + 总量"
RE_TOTAL = re.compile(
    r"截至(?:(?P<y>20\d\d)年)?(?P<m>\d{1,2})月(?P<d>\d{1,2})日"
    r"[^。；]{0,80}?(?:港口|沿海)[^。；]{0,40}?(?:甲醇)?[^。；]{0,40}?库存"
    r"(?:总量|合计|总计)?(?:在|为|达)?\s*(?P<v>\d{2,3}(?:\.\d{1,2})?)\s*万吨")
```

要点：
- 年份可能省略 → 用 `pub_ts` 的年份反推，并校验 `asof ≤ pub_ts + 1天`
- 排除误匹配：匹配窗口前的 30 字符若含 `煤 / LNG / 尿素 / 保税 / 地炼` 等词则丢弃
- 同一篇多个候选值时取**带"总量/合计"**的那一个，而非首个数字

### 路径 B：只给了分地区数据

若官方只列 `江苏 / 浙江 / 广东 / 福建`，则：

```
港口总量 = 江苏 + 浙江 + 广东 + 福建
```

**必须同时检查加总合理性**，否则会把"江苏子库区之和"误当江苏总量：

| 检查项 | 做法 |
|---|---|
| 江苏 vs 子库区之和 | 若 江苏 ≈ 太仓+张家港+江阴+南通，说明抓的是子项，须重取 |
| 加总口径 | 严格用 `江苏甲醇库存在 X 万吨` 这类**整区**表述 |
| 缺项处理 | 缺任何一区则**不生成**当期总量（`min_count=4`），或标 `carried` 并单独统计 |
| 继承 | 仅允许沿用**上一周**的值，且标记 `carried`；跨两周禁止沿用 |

### 路径 C：只有零散引用

如仅能从行业评论中得到"华东华南港口库存合计 52.47 万吨（截至6月25日）"：

- 该路径**不足以**构成连续序列，只作补点
- 补点规则：`|pub - asof| ≤ 7 天`，且数值落在合理区间（如甲醇 8–220 万吨）
- 同一周多个候选：取**相互印证**（差值 ≤3%）的众数，`n_agree` 记录印证条数
- 单一来源的补点必须标 `n_agree = 1`，并在报告中披露

## 2.2 周度归位（canonical week）

库存周报常以"周三"为截止，但个别期落在周二/周四/周日。统一规则：

```python
def canon_week(d):
    if d.weekday() <= 2:            # 周一~周三 → 本周三
        return d + timedelta(days=2 - d.weekday())
    return d - timedelta(days=(d.weekday() - 2) % 7)   # 周四~周日 → 上周三
```

归位后**每期只能有一条记录**；同一 canonical week 出现多条时，保留 `pub_ts` 最早的一条（避免用到补发）。

## 2.3 序列质检清单

对最终序列逐项输出并检查：

| 检查 | 阈值（甲醇参考） | 不通过的含义 |
|---|---|---|
| 数值范围 | 5 – 260 万吨 | 解析错误或单位错误 |
| 相邻周跳变 | \|Δ\| / prev ≤ 40% | 可能是子项/总量混用 |
| 周间隔 | 中位数 = 7 天 | 间隔结构断裂 |
| 年内周数 | 48 – 53 | 大片缺失 |
| 重复周 | 0 | 归位失败 |
| 回填比例 | 报告 `pub_ts - asof > 3天` 的占比 | 实时性风险 |

甲醇主样本实测：228 期，中位间隔 7 天，范围 30.51 – 155.78 万吨，2022–2026 每年 38–51 周。

## 2.4 口径变更时的处理原则

当同一机构在年份之间更换样本（覆盖率从"重点库区"改为"40家库区98%"）：

1. **不拼接**为一条序列；
2. 分段建模，各自独立做检验；
3. 重叠期若有两条口径并存，可计算两条序列的相关性作为**可比性证据**；
4. 报告中把"口径变更"列为结论的主要限制之一。

## 2.5 反例：这些做法都会得到假结果

- ❌ 用全样本最大值/最小值做归一化，再去和前几年比
- ❌ 把"月度"库存按月初日期对齐到周频
- ❌ 把第三方转述的"约 100 万吨"当成精确值混入序列
- ❌ 在缺口年份用线性插值补齐后当真实序列用
- ❌ 用机构**后来修订**的年度数据代替当时发布值
