# 06 · 报告与工作簿规范

## 6.1 HTML 报告结构（12 个章节，顺序固定）

| # | 章节 | 必须包含 |
|---|---|---|
| 0 | Hero | 标题、样本期、周数、检验组数、名义/FDR 显著数 |
| 1 | 数据与口径 | 库存/现货/期货/基差四类口径表、真实公布时点、数据边界警示、逐期发布记录（含链接） |
| 2 | 时点管理 | 时间轴图（asof → pub → 价格公布 → 基期 → 终点）、四条硬性规则、因子可得性表 |
| 3 | 探索性总览 | 库存 vs 价格双轴时序（可切区间/叠加目标）、连续去库着色、同期相关 KPI |
| 4 | 因子×未来表现 | 可筛选表格（因子/目标/窗口/排序/只看显著）、热力图（ρ + 显著性标记） |
| 5 | 分组分布 | 分组柱/点图（均值+中位数+bootstrap CI）、分组明细表 |
| 6 | 分年度稳定性 | 年度分组柱状图、年度明细表、样本内 vs 样本外 |
| 7 | 显著性 | 三重校正 KPI、安慰剂表、共线性控制回归 |
| 8 | 失效与反向 | 分年度失效区间、按水平分层、regime 差异 |
| 9 | 方法论自查 | 重叠/修订/泄漏/多重检验四项，各带"已处理/部分受限"徽章 |
| 10 | 结论 | A 成立的 / B 不成立的 / 产业解释 / 使用限制 / 一句话总结 |

### 交互要求

- 纯内联 SVG 绘图，**无外部 CDN**（离线可用）
- 悬停显示逐点明细 tooltip
- 所有控件（筛选、分组、窗口、区间）切换后表格与图同步更新
- 深色专业配色，移动端不横向溢出

### 文案红线

- ❌ "建议买入/卖出"、"胜率 XX%"（若不报成本）、"可以稳定获利"
- ✅ "历史上 X 组之后 1 周现货平均 +Y%，安慰剂 p=Z"
- 结论段必须明确出现"**不构成交易信号**"

## 6.2 Excel 工作簿（12 张表）

| 表名 | 内容 | 关键要求 |
|---|---|---|
| `0_研究摘要` | 口径速查 + 核心结论 | 单屏可读完 |
| `1_原始库存数据` | asof / pub_ts / 值 / 环比 / 转载时间 / 一致性校验 / 链接 | 每行可回溯 |
| `2_因子构造` | 全部因子列 + 公布时间 | 每列可解释 |
| `3_未来收益` | 基期价、终点日期、1/2/4W 三目标 | 基期日期列必须存在 |
| `4_分组统计` | n / 均值 / 中位数 / std / P25 / P75 / CI / p | 三个分组维度合并，带"分组维度"列 |
| `5_样本数量` | 分年周数、各窗口有效数、判定阈值覆盖、重叠折算表 | 明示有效独立观测 |
| `6_分年度结果` | 年度 × 窗口 × 目标 | 高低差列 |
| `7_显著性检验` | 54 组：ρ / p / 斜率 / HAC t,p / BH q | 名义显著与 BH 显著两列 |
| `7b_安慰剂与控制` | 45 组安慰剂 + 共线性回归 + 分层 | 必含安慰剂 p |
| `8_稳健性检验` | 非重叠子样本、样本内外、regime、历史样本 | 明确"未拼接" |
| `9_价格与基差日度` | 日度现货/期货/近月/基差 | 原始价格留档 |
| `10_口径与数据说明` | 五节文字说明 | 含已知限制 |

### 格式规范

- 表头深蓝底白字、冻结首行、开启自动筛选
- 数值右对齐；百分比 `0.00%`；基差 `+0.00;-0.00`
- 每表首行加标题 + 一行口径注释
- 列宽自适应，关键链接列加宽

## 6.4 必备的"负面结论"呈现方式

报告结尾必须有一段**"不成立的"**列表，例如：

- 库存绝对水平对 1/2/4 周现货/期货/基差均无显著关系（ρ 全部 <|0.12|，p>0.11）
- 同比因子全部不显著（9 组 p>0.12）
- 4 周窗口基本失效（所有因子 p>0.22）
- 连续累库对价格无解释力（各分层 p>0.30）
- BH-FDR 后 0/54 组通过

只报"发现了什么"而不列"没发现什么"，是这类研究最常见的失真来源。
