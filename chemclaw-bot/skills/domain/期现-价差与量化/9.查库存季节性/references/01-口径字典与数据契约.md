# 01 口径字典与数据契约

## 为什么口径是第一优先级

库存数字本身没有意义，**“谁的库存、在哪里、按什么标准统计”** 才有意义。
同一周，“甲醇库存 52 万吨”和“甲醇库存 150 万吨”可以同时为真——它们统计的是不同的池子。

本 Skill 强制在计算分位之前锁定五元组：

> **产品 × 库存类型 × 地区/样本范围 × 统计机构 × 频率**

任何一个缺失，都不得输出“处于历史 X 分位”的结论。

---

## 四类库存的口径差异

### 1. 港口库存（Port Inventory）

| 属性 | 说明 |
|---|---|
| 统计对象 | 指定样本港口/码头的**显性罐存** |
| 经济含义 | 可流通、可交割的现货松紧，与现货价格、区域基差最直接相关 |
| 典型样本 | 甲醇：江苏（太仓、张家港、南通、常州）+ 浙江（宁波、嘉兴）+ 广东 + 福建 |
| 单位 | 万吨 |
| 频率 | 周度（多为周三发布） |
| 常见陷阱 | ①样本港口会增减（口径变更）②某期只采到部分港口（局部采样）③“全国总量”与“华东”不是包含关系的简单加总，若样本港口有重叠会重复计算 |

**与价格的关系**：港口库存是显性库存，对基差与月差影响直接；但不等于全部供应，进口在途、下游原料备货都看不见。

### 2. 生产企业库存（Producer / Plant Inventory）

| 属性 | 说明 |
|---|---|
| 统计对象 | 上游工厂的**厂库成品 + 订单待发** |
| 经济含义 | 厂家出货压力与议价能力 |
| 单位 | 万吨 / 千吨 |
| 频率 | 周度或日度，样本厂数量常变动 |
| 常见陷阱 | ①样本厂数量变化会让总量跳变 ②检修期库存自然下降，不是需求好转 ③与港口库存常此消彼长（套利窗口打开时厂家往港口发运） |

**与价格的关系**：厂家库存高 → 出货压力大 → 现货报价易松动；但若厂家库存转移到港口，社会总库存未必下降。

### 3. 社会库存（Social Inventory）

| 属性 | 说明 |
|---|---|
| 统计对象 | 港口 + 厂库 + 贸易商 + 下游原料的合计（各机构定义不同） |
| 经济含义 | 全链条压力，最适合判断“真实过剩/短缺” |
| 常见陷阱 | **定义各家不一**。有的含下游备货，有的只含港口+厂库。跨机构数据绝不可拼接 |
| 使用建议 | 只有当能拿到完整定义文档时才使用；否则退化为“分项分别看” |

### 4. 交易所仓单（Exchange Warehouse Receipts）

| 属性 | 说明 |
|---|---|
| 统计对象 | 已完成注册、可用于期货交割的货物 |
| 经济含义 | 近月合约的交割压力与挤仓风险 |
| 单位 | 张 / 手 / 吨 |
| 频率 | 日度 |
| 常见陷阱 | ①仓单是“可交割品质”，不等于当地总供应 ②注销（出库）会突然减少仓单但不代表被消费 ③交割库分布集中，地域代表性有限 |

**与价格的关系**：仓单高 → 近月交割压力大 → 月差易走弱；但仓单低也可能只是还没注册，不代表没货。

## 绝对不可混算的组合

| 错误做法 | 后果 |
|---|---|
| 港口库存 + 厂库拼成“总库存” | 若两者此消彼长，总量平稳但被解释成“无变化”，丢掉真实结构 |
| 华东港口与全国港口直接比大小 | 全国含华南，规模天然更大，分位无意义 |
| 仓单量当库存量 | 仓单只是可交割部分，且注销不等于消费 |
| 不同机构的“社会库存”接续 | 定义不同，断点处的跳变会被误读为累库/去库 |
| 早期口径序列与现行序列拼接 | 统计范围不同，接缝处会出现虚假巨幅变化 |

## 字段契约（周度库存数据）

`build_cache.py` 期望的输入结构：

### 输入 1：周度原始记录 `lz_weekly.json`

```json
[
  {
    "post_id": "1234567",
    "asof": "2026-10-14",
    "title": "[港口库存]：中国甲醇样本港口库存周数据统计(20261014)",
    "url": "https://example.com/a/1234567_abc.html",
    "table": {"江苏": 19.5, "浙江": 11.0, "广东": 6.1, "福建": 0.1, "总计": 36.7}
  }
]
```

### 输入 2：正文文本 `bodies.json`

```json
{ "1234567": "……港口库存总量在36.72万吨，较上一期数据增加6.21万吨。其中，华东地区窄幅去库，库存减少3.16万吨；华南地区累库，库存增加9.37万吨……" }
```

解析正则（在 `build_cache.py` 顶部，可替换）：

```python
RE_TOTAL = r"港口库存总量在([\d.]+)万吨"
RE_CHG   = r"较上一期数据(增加|减少)([\d.]+)万吨"
RE_REG   = r"华东地区[^，。]*?(增加|减少)([\d.]+)万吨[^。]*?华南地区[^，。]*?(增加|减少)([\d.]+)万吨"
```

> **注意**：`RE_REG` 的 4 个捕获组对应 [华东方向, 华东量, 华南方向, 华南量]，
> 华东取 group 1-2、华南取 group 3-4。曾因误取 group 5-6 导致 `IndexError`。

### 输出：`a_sample.pkl` 关键列

| 列名 | 含义 | 备注 |
|---|---|---|
| `asof` | 数据截止日 | datetime |
| `iso_year` / `iso_week` | ISO 周年/周次 | 季节坐标 |
| `port_total` | 全国港口样本合计 | 万吨 |
| `east` | 华东（江苏+浙江） | **可能为 None**（水平缺失期） |
| `east_method` | 华东取值方式 | `east_table` 表格直接 / `east_est` 增减额递推 / None |
| `jiangsu` / `zhejiang` / `guangdong` / `fujian` | 分省 | 可能为 None |
| `ev_east_chg` | 原文披露的华东增减额 | 优先使用 |
| `east_dchg` | 实际采用的增减额 | 官方优先，缺失回退表格差分 |
| `east_dchg_table` | 两期表格值相减 | 仅用于核对 |
| `is_chg_official` | 增减额是否来自原文 | bool |
| `east_from_port` | 华东替代值（全国港口 × 近一年华东占比） | **仅定位，禁入分位** |
| `gap_days` | 距上一期间隔 | 天 |
| `week_missing` | 是否缺报（>16 天） | bool |
| `prov_full` | 四省是否齐全 | bool |

## 单位与换算

| 场景 | 处理 |
|---|---|
| 万吨 / 千吨 | 统一到万吨，报告中标注单位 |
| 张 → 吨（仓单） | 按合约乘数换算，并在报告中写明乘数 |
| 百分比 vs 绝对值 | 分位与偏离用百分比；库存水平用原始单位；不可混用“万吨”和“%” |

## 边界声明模板（写进每份报告）

> 本报告统计对象为【机构】发布的【品种】【地区】**港口库存**（显性罐存），单位万吨，周度。
> 不包含生产企业库存、社会库存总量与交易所仓单；与上述口径的数值**不可直接比较**。
> 覆盖范围为样本港口，非全国全量。
