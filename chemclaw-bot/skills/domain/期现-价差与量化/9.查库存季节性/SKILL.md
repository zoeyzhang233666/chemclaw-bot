# 查库存季节性

## 这个 Skill 解决什么

库存的“高”与“低”只有在**同口径、同覆盖、同季节时点**下才有意义。本 Skill 的标准动作是：

1. **先确认统计对象**——港口库存 / 生产企业库存 / 社会库存 / 交易所仓单，四者不可混算；
2. **再取真实历史**——期数、单位、覆盖范围、频率、来源全部登记；
3. **按周次对齐多年**——用 ISO 周年 + 周次作季节坐标，不用公历日期；
4. **算出历史同期分布**——均值、中位数、p10/p25/p75/p90 分位带；
5. **定位今年**——今年值落在历史同期的第几分位；
6. **算实际幅度**——近 4 周、12 周到底累库还是去库，多少万吨；
7. **检查样本是否变过**——断点、披露降级、局部采样，逐项标注并做异常年份分析。

**最重要的一条护栏：库存高于或低于历史均值，不直接推导价格方向。**
本 Skill 只回答“库存处在历史季节性水平的什么位置、最近实际累去库多少”。价格方向需要另行检验基差、到港节奏、开工率、装置利润与合约结构。

## 什么时候用

| 用户说法 | 本 Skill 的回应 |
|---|---|
| “甲醇港口库存季节性怎么样” | 先问/确认口径与地区，再给 5 年季节性 + 今年位置 |
| “现在华东港库处于历史什么水平” | 给同期分位 + 去季节分位 + 与均值偏离 |
| “最近是累库还是去库” | 给 4/12 周累计、连续周数、历史同周次速度分位 |
| “库存比去年高好多，是不是要跌” | 明确拒绝由库存水平直接推价格；给分位与幅度，把方向判断留给多因子 |
| “这个数据好像变了” | 进断点登记表，比对披露口径与覆盖范围，标注断点两侧不合并 |
| “帮我做成报告” | 出交互式 HTML + Excel 工作簿 |

## 执行流程（7 步，一步都不能跳）

### 第 1 步：确认口径（不做这步后面全废）

必须同时锁定五项，缺一项不做分位结论：

1. **产品**（甲醇、纯碱、尿素、玻璃、PVC…）
2. **库存类型**：港口库存 / 生产企业库存 / 社会库存 / 交易所仓单 / 其他
3. **地区或样本范围**：如“江苏+浙江”“华东”“全国样本港口”
4. **统计机构**：隆众、卓创、钢联、交易所、国家统计局…
5. **频率与发布时点**：周度（周三 14:00）、日度、月度

同时把**单位**（万吨/千吨/吨）和**是否含税/含贸易商**等边界一并写进 `config.json`。
详见 `references/01-口径字典与数据契约.md`。

### 第 2 步：取历史数据并登记来源

- 每一期都要有：截止日、原始数值、**原文标题与链接**、增减额（若有）。
- 区分「表格直接披露值」与「由增减额递推值」，逐行标注 `east_method`。
- 记录期数、起止、间隔分布（周报应有 7 天中位间隔；春节前后常见双周报）。
- 来源清单模板见 `references/02-数据源与取证清单.md`。

### 第 3 步：按周次对齐

- 用 **ISO 周年 + ISO 周次**；跨年周整周归其 ISO 年。
- 相邻两期跨度 > 16 天才算缺报；10–16 天视为双周报，**不要当缺报剔除**（这是最常见的误判）。
- 本年数据不进入历史分布，只作为“今年值”叠加。

### 第 4 步：历史同期分布

对每个周次 w，取过去 N 年（默认 5 年）同周次 ±1 周的样本，计算：
均值、中位数、p10、p25、p75、p90、最小、最大。
样本年数 < 4 的周次标记 `insufficient`，只报区间不报结论。

### 第 5 步：今年定位与分位

分位定义：

```
rank = (小于当期值的样本数 + 0.5 × 等于当期值的样本数) / 样本数 × 100
```

并**再加一个去季节分位**（本 Skill 的关键增量）：

```
ln I_t = trend_t + f(week_t) + e_t
```

把今年的值除以季节基准得到残差 e，再放到历史同期残差分布里定位。
这样能区分两种情况：

- 绝对值偏低，是因为“这个季节本来就该低”→ 去季节分位会回到正常区间；
- 扣掉季节性仍然偏低 → 去季节分位依然在极低端，说明是真实偏离。

**分位端点必须诚实地表述**：0 分位不是“精确排第 0 名”，而是“低于同期全部 N 个样本（最小值 X）”。

### 第 6 步：累去库幅度

- 周度增减额**优先取原文披露值**，不要用两期表格值相减——局部采样补报会产生虚假跳变。
- 算 1/4/12/26/52 周累计，以及连续累库或去库的周数。
- 4 周累计变化与历史同周次的 4 周累计分布比较，给出速度分位。
- **速度 ≠ 方向**：去库快不等于要涨，只说明实物边际在收紧。

### 第 7 步：样本变化与异常年份

逐项登记（见 `references/04-样本变化与断点.md`）：

- 统计范围变更（如样本港口增减）
- 披露方式降级（逐地区表 → 只剩总量 + 分区增减额）
- 局部采样（某期只采到部分港口）
- 数据中继/口径断裂（早期序列不可拼接）
- 极端年份（供需格局突变），预登记 `exception_windows`

断点两侧**不合并统计**，只做敏感性对照。

## 换一个品种怎么用

1. 复制 `examples/01-甲醇-华东港口库存/config.json`，改 `product`、`metric_name`、`asof`、`run_date`、指标与地区定义、断点列表。
2. 准备同结构数据：周度原始 JSON（含标题、链接、原文总量与分区增减额）+ 逐地区表格值。
3. 若新数据源字段不同，只改 `scripts/build_cache.py` 里的解析正则（`RE_TOTAL`/`RE_CHG`/`RE_REG`），统计层与出图层不用动。
4. 先跑 `selftest.py` 看口径断言是否通过，再看报告。

## 硬性纪律（违反即作废）

1. 口径不明不做分位。港口、厂库、仓单不混算。
2. 不同覆盖范围的绝对水平不可直接比大小（华东 vs 全国港口）。
3. 原文增减额优先于表格差分。
4. 水平值缺失时必须标注“不可得”，不得用替代值冒充公布值。
5. 库存水平不直接推导价格方向。
6. 断点前数据不得与断点后合并统计。
7. 样本年数 < 4 不报结论。
8. 分位端点（0/100）用“低于/高于全部样本”表述，不给伪精度。
