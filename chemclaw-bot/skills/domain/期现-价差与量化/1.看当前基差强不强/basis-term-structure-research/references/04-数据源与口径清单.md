# 04 数据源与口径清单

> 全部为**免费、无需 API Key** 的公开来源。每条数据落盘时必须带 `source_id`。

## 一、期货行情（按合约）

### 新浪财经 日K JSONP（推荐，含已摘牌合约）

```
https://stock2.finance.sina.com.cn/futures/api/jsonp.php/var%20_<SYM>=/InnerFuturesNewService.getDailyKLine?symbol=<SYM>
```

- `SYM` 写法：`MA0`（主力连续）、`MA2701`（具体合约）、`MA2605`（已摘牌也可取）。
- 返回 JSONP，需剥离 `var _xxx=([...]);` 外壳。
- 字段：`d`（日期）、`o/h/l/c`（开高低收）、`v`（成交量）、`p`（持仓量）、`s`（结算价，部分为空）。
- 覆盖：甲醇可回溯到 **2014-12**。
- 注意：日K接口**不返回合约列表**，需自己按命名规则枚举（`MA` + `YYMM`）。

### 郑商所官方日行情 txt（用于核对收盘价/结算价）

```
http://www.czce.com.cn/cn/DFSStaticFiles/Future/2026/YYYYMMDD/FutureDataDaily.txt
```

- **GBK 编码**，制表符分隔。
- `web_fetch` 只支持 https，需用 `curl` / `requests` / `urllib` 抓。
- 用途：官方口径核对（本文案例中 10-20 MA2701 收盘 3157 与新浪一致）。

## 二、仓单与交割

### 郑商所 仓单日报

```
http://www.czce.com.cn/cn/DFSStaticFiles/Future/2026/YYYYMMDD/FutureDataWhsheet.txt
```

- GBK，含**每个仓库/厂库的明细**与"小计/总计"行。
- 解析要点：
  1. 以**紧跟明细行之后的"小计"行**为该机构有效仓单量；
  2. 按机构名称是否含"厂库"区分仓库 / 厂库口径；
  3. 校验：各"小计"之和 == "总计"，不等则告警。
- 关键洞察：**合计仓单可能全部集中在厂库，实体仓库为 0**。此时合计数会误导人以为
  "可交割现货充足"，实际该地区港口仓库根本提不出货。

### 交割标准与升贴水

查交易所"指定交割仓库名录 / 升贴水公告"。甲醇要点：

- 标准品：GB/T 338-2011 工业用甲醇 优等品，**不限乙醇质量分数**；
- 交易单位 10 吨/手，最小变动 1 元/吨，涨跌停 ±4%；
- 最后交易日 = 交割月第 10 个交易日；交割方式含 EFP 与仓库/厂库标准仓单；
- 完税仓单每年 5 月、11 月第 15 个交易日前须注销；
- 仓储费 2 元/吨·天（2021-05 第 16 个交易日起）；
- **太仓阳鸿石化（仓库 0801）升贴水 0 元/吨 → 太仓为基准交割地**。

## 三、现货价格

### 隆众资讯（oilchem.net / pobo 转载）

- 主站 `https://chem.oilchem.net/chemical/methanol.shtml` 有日评列表，但**正文需登录**，抓不到价格。
- 可用替代：门户转载的"早盘日评"（pobo.net.cn 的 ASP.NET 分页归档、
  `webnewslt1.pobo.net.cn/DaoHangList.aspx?DIR=NENG`），可回溯历史页。
- 本站首页有**历史分位**模块，且给出明确定义：
  "一年历史分位数 98%，指当前价格在其一年期历史价格中，超过其它 98% 的价格。"

**解析要点（极易出错）**：

- 只认"现货商谈/实单 3960-4000"这类**同时给出区间**的表述；
- 排除"现货暂无报价""报盘稀缺"的日子 → 留空，不补；
- 警惕"9 下纸货 4450-4550"这类**不同交割月**的报价，不能当现货。

### 交叉校验源

- 国内商品基差报告（门户转载）：给"现货价 / 主力收盘 / 基差 / 基差率"，可整体核对。
- TradingEconomics 甲醇：CFD 口径，**不是华东现货**，只能看趋势，不能算基差。

## 四、库存与开工

| 指标 | 来源 | 口径风险 |
|---|---|---|
| 港口库存 | 隆众 / 卓创 / 交易所转述 | **多套口径并存，数值不可互换** |
| 内地厂库 | 隆众 | 样本企业变动会跳变 |
| MTO / 下游开工率 | 隆众、期货公司周报 | 行业均值为估算，非普查 |
| 到港量 | 船期统计 | 延迟 3–7 天 |

**纪律**：同一日不同来源的数字**并列呈现**，不平均、不相减。

## 五、研报与事件

优先用期货公司周报/月报（PDF，公开可下载），可提供：

- 现货区域价（太仓/鲁北/内蒙/CFR 中国）；
- 开工率、产量、进出口、到港；
- 价差结构（MA11-1、PP-3MA 等）；
- 政策与地缘事件。

引用时必须记录：机构、报告日期、原文数值、URL。

## 六、落盘格式约定

```
raw/spot_<region>.csv       date,spot_low,spot_high,quote_kind,source_id
raw/futures_all.csv         date,contract,open,high,low,close,settle,volume,oi
raw/warehouse_receipts.csv  date,receipt_total,receipt_chg,warehouse,factory
raw/inventory.csv           date,item,value_wan_ton,chg_wan_ton,note,source_id
raw/events.csv              date,category,event,bearing_on_basis,source_id
raw/sources.csv             id,title,url,publisher,retrieved
```

一律 **UTF-8 带 BOM**，Excel 直接打开不乱码。
