# 05 报告写作模板

> 结构固定，避免每次自由发挥导致关键项缺失。方括号内为必填槽位。

## 一、页面骨架（HTML 首屏顺序）

1. **标题**：`[地区][品种] · [交易所][品种代码] 基差研究`，副标题写数据截止日
2. **口径行**：基差定义 + 现货六项口径 + 期货合约类型 + 单位
3. **四张指标卡**（必须同屏可见）
   - 当前基差（含具体合约代码）
   - 近 N 个交易日变化（含现货/期货贡献）
   - 可用样本分位 **（必须带 n=，并注明"非历史分位"）**
   - 区间峰值基差（含日期）
4. **免责/限制横幅**：直接写"不作回归判断" + 分位为何不可计算

之后依次：双价格图 → 基差曲线（可切合约）→ 归因 → 合约口径与换月 → 基本面证据表
→ 库存仓单 → 历史极值 → 事件时间线 → 数据缺口 → 数据来源。

## 二、结论段模板

```
以「[现货完整口径]」对「[具体合约]」计，[日期] 基差 [+/-][数值] 元/吨（基差率 [x]%），
为[深度现货升水 / 贴水]。

近 [N] 个交易日基差 [Δ] 元/吨，其中现货 [Δs]（贡献 [x]%）、期货 [Δf]（贡献 [y]%），
[基差回落由期货上涨主导 / 由现货补跌主导]。

历史分位：[可用 → 「1 年分位 X%（N=..）」 / 不可用 → 「不可计算，原因：…」]。
可比参照：[行业经验区间 + 当前偏离幅度]。

支持强势：[1–4 条，带数字与日期]
不支持：[1–4 条，带数字与日期]
存疑：[口径冲突、数据滞后等]

以上为基差所处位置与变化原因的描述，不构成"基差必然回归"的判断，也不构成交易建议。
```

## 四、写作禁忌

| ❌ 不要写 | ✅ 改写为 |
|---|---|
| "基差处于历史高位，必然回归" | "基差 [+823]，显著高于行业经验区间上限（约 500），但历史分位不可计算" |
| "基差 1 年分位 89.7%" | "可用样本仅 13 个，不足以计算 1 年分位" |
| "现货 3980，期货 3157，基差 823"（不说合约） | "现货 3,980（太仓出罐含税）对 MA2701 收盘 3,157，基差 +823" |
| "仓单 6,633 张，可交割资源充足" | "仓单 6,633 张，但全部在厂库、实体仓库为 0" |
| "库存 36.72 万吨" | "隆众口径 10-14 为 36.72 万吨；另有终端口径 10-15 为 41.33 万吨，两者不可互换" |
| "基差走弱 170，现货贡献 +45，期货贡献 +215" | "…现货贡献 −26%、期货贡献 +126%（以 Δ基差 为分母）" |

## 五、图表规范

| 图 | 必须包含 |
|---|---|
| 双价格图 | 现货与期货两条线 + 图例写明口径 + 关键事件标注 |
| 基差曲线 | 零轴虚线 + 起止日期 + 合约口径说明 + 是否复权 |
| 分位分布 | 当前值竖线 + 每个 bin 的样本数 + 明确标注样本量很小 |
| 库存/仓单 | 单位 + 数据频率 + 是否连续序列 |

**所有图表都必须能在离线状态下打开**：内联 SVG，不用 CDN。

## 六、数据缺口声明（必写）

逐条列出，不要用一句话概括：

```
- 现货日度序列：仅有 2026-09-21 起 13 个有价日；2025 年及以前不公开，故 1/3/5 年分位无法用真实序列计算。
- 港口库存：存在两套口径，数值不可互换。
- 库存周度：仅有峰值/谷值/周度更新点，未取得连续周序列。
- MTO 开工率：仅有行业叙述，无官方周度序列。
```

## 七、交付前自检清单

- [ ] 每个数字都能指到来源编号
- [ ] 现货六项口径齐全（规格/地区/税费/数量/合约/日期）
- [ ] 基差的合约代码写出来了，不是"主力"
- [ ] 历史分位带 N；N 不够就写"不可计算"
- [ ] 换月已量化，未跨不可比合约拼接
- [ ] 归因口径（分母）已说明
- [ ] 支持与不支持证据都 ≥ 2 条
- [ ] 数据缺口逐条列出
- [ ] 没有"必然回归""建议做多/做空"这类表述
