# 01 口径核查：先确认可比，再算基差

> **本文件是全 Skill 的第一道闸门。** 基差数字的一半错误来自口径不可比，而不是算错。

## 一、为什么必须先查口径

基差是"两个东西之差"，这两个东西必须描述同一个经济标的。只要其中一项不同——地区、品质、
环节、税费、数量、时点——差值里就混进了别的东西，此时：

- 数值再精确也没有意义；
- 历史分位会被系统性偏置（口径变了，分布在变）；
- "现货升水"可能只是运费或税差。

## 二、六项必填口径（原样写进 Excel「01 口径与规格」）

| 口径项 | 必须写到 | 典型取值示例（甲醇） |
|---|---|---|
| 品种与交割标准 | 交易所标准交割品的**标准号** | GB/T 338-2011 工业用甲醇 优等品 |
| 现货地区与环节 | 城市/库区 + 出罐/送到/自提 | 江苏太仓，出罐自提 |
| 税费 | 含税/不含税、现汇/承兑 | 含税、现汇 |
| 数量与优惠 | 小单/大单、整车/船货 | 商谈区间报价，取中点 |
| 期货合约 | **具体合约代码**，不是"主力" | MA2701（郑商所） |
| 价格类型与时点 | 收盘/结算/盘中；报价时刻 | 当日收盘价；现货为早盘商谈 |

**时点差异是常态，不是错误**：现货在上午商谈、期货 15:00 收盘，当天基差天然含至多数小时的时滞。
写进报告即可，不要为此调数。

## 三、四项可比性核查

### 1. 品质可比

- 现货规格是不是交割标准品？
- 标准品有"限制性条款"吗？例如甲醇交割标准品**不限乙醇质量分数**，而某些现货报价是"精醇"，
  两者在乙醇含量上要求不同。若现货为更高纯度，基差会被高估。
- 结论：`可直接计算` / `需品质升贴水调整后计算` / `不可比`。

### 2. 地区可比（最容易出错）

必须查交易所**指定交割仓库名录与升贴水表**，而不是凭直觉用运费估。

以甲醇为例（郑商所）：

| 仓库 | 编号 | 升贴水 |
|---|---|---|
| 太仓阳鸿石化 | 0801 | **0 元/吨（基准交割地）** |
| 其他港口仓库/厂库 | — | 以交易所公告为准，多为非零 |

因此：

- **太仓现货 vs MA 期货**：地区、品质均对齐，**可直接计算**。
- **鲁北/内蒙现货 vs MA 期货**：必须先扣地区升贴水（或明确声明"未调整，仅方向参考"）。
  内蒙与华东价差长期在数百元/吨，直接算会得到完全失真的"基差"。

### 3. 税费可比

期货交割价通常含税；现货若报不含税或承兑价，须统一。
经验量级：承兑价较现汇价高约 30–80 元/吨，足以改变分位结论。

### 4. 环节可比

| 环节 | 与期货标的的关系 |
|---|---|
| 仓库标准仓单 | 与期货最接近（期货即"可交割的仓单"） |
| 厂库标准仓单 | 可交割，但提货方式、地点受限 |
| 现货出罐自提 | 通常与仓单接近，需付仓储/出库费 |
| 送到价 | 含运费，须扣运费后才可比 |

**特别提示**：当某个地区的**仓库仓单为 0、仓单全部集中在厂库**时，"买期货交割拿货到该地区"实际上
不可行，该地区现货理应享有结构性升水。这是解释高基差的关键事实，不要只看仓单总数。

## 四、结论只有三种

```
可直接计算                 → 正常进入第 2 步
需调整后计算（列调整项）    → 写清每项调整的数值与来源
不可比（说明原因）          → 不出基差数字，先换口径或换数据
```

## 五、三个真实踩坑记录

1. **"华东"太粗**：华东含太仓、南通、常州、宁波等多个库区，价差可达上百元/吨。
2. **同一现货、不同合约，基差差 227 元/吨**：深度 Back 结构下，1701 与 2611 的基差完全不同。
   报基差必须报合约。
3. **两套库存口径**：隆众与卓创/交易所转述的港口库存数值不同，同一日并列呈现，**不合并、不相减**。
