# 02 公式与统计口径（全文统一，不得改义）

## 一、核心定义

```
基差              basis      = 现货价格 − 期货价格
基差率            basis_rate = (现货价格 − 期货价格) / 现货价格 × 100%
现货中点          spot_mid   = (报盘低端 + 报盘高端) / 2
```

**符号约定**：

- `basis > 0` → 现货升水（Back），现货比期货贵；
- `basis < 0` → 现货贴水（Contango），期货比现货贵；
- 报告里必须写出"现货升水/贴水"字样，不能只给数字——读者容易把正负号理解反。

**缺失处理**：任一价格缺失 → 基差为 `None`，整行不参与统计，**不插值、不用近似值、不用基差反推现货**。

## 二、近期变化归因

```
Δ基差 = Δ现货 − Δ期货
Δ现货 = spot_t − spot_0
Δ期货 = fut_t   − fut_0
```

**贡献度（推荐口径：以 Δ基差 为分母）**

```
现货贡献 = Δ现货 / Δ基差 × 100%
期货贡献 = −Δ期货 / Δ基差 × 100%
```

性质：两项之和恒为 100%。现货上涨推升基差（正），期货上涨压低基差（负）。

示例（近 23 个交易日）：

| 项目 | 变化 | 贡献 |
|---|---|---|
| 现货 | +45 | −26.47% |
| 期货 | +215 | +126.47% |
| **基差** | **−170** | **100%** |

读法：基差走弱 170，其中现货上涨本应推升基差，但被期货更大的上涨（215）压过，
所以基差净走弱，且期货是主导项。

**备选口径（稳健型，结果接近 0 时不爆炸）**

```
贡献 = 该变量变化 / (|Δ现货| + |Δ期货|)
```

缺点：两项符号可能相同（+17% / −83%），容易读反方向。**用哪种必须写明。**

⚠️ 当 `Δ基差 ≈ 0` 时两种口径都会数值失控，此时应只描述绝对变化，不给百分比贡献。

## 三、经验分位

```
pct = #{ x ∈ 样本 : x ≤ 当前值 } / N × 100%
```

**必须同时报 N，以及窗口的起止日期与覆盖率。**

### 样本充分性判定（硬规则）

| 条件 | 处理 |
|---|---|
| `coverage ≥ 0.8` 且 `N ≥ 60` | 可给历史分位 |
| `0.5 ≤ coverage < 0.8` | 可给，但标注"样本覆盖不足，仅供参考" |
| `coverage < 0.5` 或 `N < 20` | **不给历史分位**，只给区间描述 |

其中：`coverage = 真实配对样本数 / 应有交易日数`，应有交易日按每年约 244 个估算。

> **实测教训**：13 个样本（全在同一次极端行情内）算出的"1 年分位 15%"与
> "3 年分位 96.6%"同样不可信——分布里根本没有正常年份。正确做法是拒绝给分位，
> 改报"区间最高/最低/中位 + 行业经验区间 + 当前偏离幅度"。

## 四、分布描述量

```
均值   = Σx / N
中位数 = 排序后中间值（偶数取中间两数均值）
标准差 = sqrt( Σ(x − mean)² / (N − 1) )        ← 样本标准差
q 分位 = 线性插值（仅用于描述，不用于"历史分位"结论）
z      = (当前值 − 均值) / 标准差
```

## 五、主力合约与换月

```
主力合约 = 当日持仓量(oi) 最大的合约        ← 不用成交量，避免交割月噪声
gap   = 切换日 新主力收盘 − 同一日 旧主力收盘
shift = 前一日 新主力收盘 − 前一日 旧主力收盘
```

**为什么需要两个量**：

- `gap` 含换月当日的行情涨跌，回答"如果直接拼接会伪造多大跳空"；
- `shift` 把合约阶梯与当日行情分开，**是复权唯一正确的量**。

## 六、前复权连续序列

```
adj(t) = close(t) + Σ { shift(k) : k 为 t 之后的所有换月日 }
```

性质（可用 `selftest.py` 验证）：

1. 最新一段 `adj(T) = close(T)`，与原始价格一致；
2. 复权后换月日的收益率**恰好等于新合约自身当日收益率**；
3. 未复权直接拼接会伪造跳空。例：MA2610 3411 → MA2701 3043，伪跳空 −10.8%，
   而复权后正确显示 MA2701 自身收益 3043/3310−1 = −8.07%。

**已验证的市场惯例**：行情商发布的 MA0 主连在换月当日仍打印**旧合约**收益，价格阶梯推到次日
（2026-09-11 显示 −12.07%，而所有固定合约当日实际变动仅 −1%~+1%）。

## 七、仓单折吨

```
吨数 = 仓单张数 × 交割单位
```

甲醇：10 吨/手，即 1 张仓单 = 10 吨。6,633 张 ≈ 6.63 万吨。
