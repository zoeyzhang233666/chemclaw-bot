# 看当前基差强不强（Spot-Futures Basis & Term Structure Research）

## 这个 Skill 干什么

回答一个问题：**当前基差处于什么历史位置、近期为什么变化、有哪些基本面数据支持或不支持这种强势。**

拆成五件必须分别交代的事：

1. **基差是多少**——统一定义 `基差 = 现货 − 期货`，并写清规格、地区、税费口径、合约、日期、来源六项。
2. **这个数可不可比**——先核实**交割标准品与现货规格是否可比**，再算基差。不可比就先修口径，不要先算数。
3. **近期怎么变的**——`Δ基差 = Δ现货 − Δ期货`，把变化拆成现货贡献与期货贡献，看是现货补跌还是期货补涨。
4. **历史上排在哪**——1/3/5 年经验分位，**但必须同时报出真实样本数 N**；N 不够就写"不可计算"，不硬给百分位。
5. **有没有基本面支撑**——库存、仓单、交割、开工、进出口、产业事件，逐条标"支持/不支持/存疑"。

**绝不做的事**：因基差处于极端分位就直接断定"必然回归"；把不可比的合约价格拼成一条历史基差曲线；在缺数据的日期上插值、补数、用近似值；把不同机构、不同地区的口径混算。

## 什么时候用 / 不用

**用**：有期货合约的化工品，问现货与期货价差、基差强弱、近远月结构、换月后基差口径、现货升贴水是否正常、期现套利空间。

**不用**：单品种绝对价格走势判断（→ `chem-market-brief`）；采购决策和议价（→ `chem-procure-brief`）；两个指标共变强度（→ `two-indicator-correlation`）。

## 执行流程（8 步）

### 第 0 步：先钉死口径，再动数

**基差数字有一半的错误来自口径，不是来自计算。** 开工前必须填满下面这张表，缺一项就标"缺口"，不允许默认：

| 口径项 | 必须写清楚 | 常见坑 |
|---|---|---|
| 品种与交割品质 | 交易所标准交割品的标准号（如甲醇 GB/T 338-2011 优等品） | 现货是国标优等品还是"精醇"、是否限乙醇含量 |
| 现货地区与环节 | 具体到城市/库区 + 出罐/送到/自提 | "华东"太粗，太仓与鲁北价差可上百元 |
| 税费 | 含税/不含税、增值税、现汇/承兑 | 承兑价通常高 30–80 元/吨 |
| 数量与优惠 | 小单/大单、整车/船货 | 大单常低 50 元/吨以上 |
| 期货合约 | **具体合约代码**（MA2701），不是"主力" | "主力"天天可能变，历史拼接必错 |
| 价格类型 | 收盘/结算/盘中 | 结算价与收盘价可差 20–40 元/吨 |
| 日期与时点 | 现货报价时刻 vs 期货收盘时刻 | 现货早盘商谈、期货 15:00 收盘，属常规时滞 |

### 第 1 步：核实可比性（**这一步不能跳过**）

逐项对照，写进 Excel「01 口径与规格」：

1. **品质**：现货规格是否是交割标准品？不是则不能直接算基差，需先做品质升贴水调整，或明确声明"非标准品，基差仅作方向参考"。
2. **地区**：现货地是否为基准交割地？查交易所指定交割仓库的**升贴水表**。甲醇太仓阳鸿（仓库 0801）升贴水 0 元/吨，太仓即基准地，可直接算；若用鲁北、内蒙现货，必须扣/加地区升贴水并注明是按公告还是按市场运费估算。
3. **税费**：期货交割价一般含税，现货报价需同为含税口径。
4. **环节**：期货对应"仓库/厂库标准仓单"（可交割状态），现货"出罐自提"与"送到"之间差运费。

**可比性结论只有三种**：`可直接计算` / `需调整后计算（列出调整项与数值）` / `不可比（说明原因，不出基差数字）`。

### 第 2 步：抓数据（每行带出处）

至少要拿到：固定合约的期货日行情、现货日度报价、库存、仓单。数据源清单见 `references/04-数据源与口径清单.md`，含免费可用的接口。

**关键纪律**：

- 期货按**具体合约**存（`MA2611`、`MA2701`），同时单独存主力连续 `MA0`——但 `MA0` **只能用于描述趋势，不能用于计算跨换月的价格水平或基差**。
- 现货区间报价取中点，并把低端/高端都留下；原文没给绝对价就留空，**不要用基差反推现货**（会污染数据）。
- 每个数值都要能回答：哪家机构、哪天、什么口径、哪个 URL。

### 第 3 步：确定主力合约与换月跳空

```
主力 = 当日持仓量最大的合约（不用成交量，避免交割月噪声）
换月跳空 gap = 切换日 新主力收盘 − 同一日 旧主力收盘
```

**必做的验证**：换月当日的 `MA0` 收益率，是旧合约的收益，不是新合约的。跳空会被推到**次日**。判断方法：比对 `MA0` 当日涨跌幅与各固定合约当日涨跌幅，若 `MA0` 与旧主力一致、次日才出现异常跳空，即确认此惯例。

所以：

- **跨换月比较必须前复权**：`adj(t) = close(t) + Σ{ gap : 所有晚于 t 的换月 }`，最新一段等于原始价格，历史段整体平移。
- **基差曲线优先用固定合约**；非要连续序列时，必须标注复权方式与累计调整量。
- 一次 −368 元/吨的换月跳空，足以把"基差 1000 还是 600"完全改写，所以这一步绝不能省。

### 第 4 步：算基差与近期变化

```bash
python scripts/calc_basis.py --spot data/spot.csv --futures data/futures.csv \
    --asof 2026-10-20 --windows 1y,3y,5y --out build/basis.json
```

输出：当前基差、基差率、各合约口径对比、30 天变化、现货/期货贡献、换月跳空清单、分位及其 N。

贡献度写法（两种都合法，但要说明用的哪种）：

- 常用：`贡献 = Δ现货/Δ基差` 与 `−Δ期货/Δ基差`，两者之和恒为 100%，可直接读"基差变化里现货占多少"。
- 稳健：`贡献 = 变化 / (|Δ现货|+|Δ期货|)`，避免基差变化接近 0 时爆炸。

### 第 5 步：历史分位——**先算 N，再决定给不给**

这是本 Skill 与"随便报个百分位"最大的区别：

1. 明确窗口：1/3/5 年，写清起止日期。
2. 算**真实配对样本数**（同一天既有现货又有期货的交易日）。
3. 用 `coverage = 实际样本 / 应有交易日` 判断：
   - `coverage ≥ 0.8` 且 `N ≥ 60` → 可给历史分位，写"1 年分位 X%（N=…）"。
   - `0.5 ≤ coverage < 0.8` → 给分位但**必须标"样本覆盖不足，仅供参考"**。
   - `coverage < 0.5` 或 `N < 20` → **不给历史分位**，改给区间描述（区间最高/最低/中位）+ 行业经验区间，并写清为什么给不了。
4. 分位定义统一为经验分位：`#{x ≤ 当前值} / N × 100`。

> **实测教训**：某次研究里现货日度数据只公开了近一个月，13 个样本全落在一次极端行情内，算出来的"1 年分位 15%"完全没有意义——因为样本里根本没有正常年份。这种情况下正确做法是**拒绝给分位**，并改用"行业经验区间 + 当前偏离幅度"来描述强度。

### 第 6 步：基本面证据表（支持 / 不支持 / 存疑）

基差强势必须有产业事实解释，逐条打分，**并且必须两边都列**：

| 方向 | 典型证据 | 要看什么 |
|---|---|---|
| 支持基差强 | 库存历史低位、进口断档、到港少、可交割资源不足、仓单为 0 或下降、现货流通货源集中 | 库存是否真的低于正常区间；仓单是仓库口径还是厂库口径 |
| 不支持 | 库存开始累积、仓单增加、下游对高价负反馈（装置停车/减产）、价差结构已让下游亏损、进口利润窗口打开 | 变化方向比绝对水平更重要 |
| 存疑 | 两套库存口径不一致、同一指标不同机构数字打架、数据滞后 | 并列呈现，不相减、不合并 |

**必查的三个易错点**：

- **仓库仓单 vs 厂库仓单**：全部集中在厂库时，"买期货去交割拿现货"这条路基本走不通，现货升水有制度性支撑；只看合计仓单会漏掉这个信息。
- **两套库存口径**：隆众、卓创、交易所口径数值不可互换，同一日不同来源的数字并列写出来，绝不平均。
- **下游负反馈**：MTO/下游装置因原料太贵而停车，是基差见顶的经典信号，必须写进"不支持"。

### 第 7 步：历史极值时期的基本面背景

找出历史上基差的极值时点（不是价格极值，是基差极值），回到当时查：供给侧有没有断供/检修、需求侧是不是旺季、库存处在什么位置、有没有政策或地缘事件。

**用途只有一个**：判断"这次和上次像不像"。像就更要小心（因为上次后来怎么走的可以参考），不像就不能套用上次的结论。

### 第 8 步：写结论——**可以描述，不可以断言回归**

结论模板（照抄可用）：

> 以「现货口径」对「具体合约」计，2026-10-20 基差 **+823 元/吨**（基差率 20.68%），为深度现货升水。
> 近 23 个交易日基差 −170 元/吨，其中现货 +45（压低基差 26%）、期货 +215（压低基差 126%），**基差回落由期货上涨主导**；而自区间峰值（2026-10-09，+1,537）以来基差 −714，其中现货 −895（占 125%），**这一段由现货补跌主导**。
> 历史分位：**不可计算**——现货日度数据仅有 13 个真实有价日，且全部落在 2026 年 9–10 月同一轮极端行情内，无法代表 1/3/5 年分布。可比参照是行业经验区间（正常年份多在 ±100 元/吨内，紧张时高点通常在 500 元/吨以内），当前 +823 显著高于该区间。
> 支持强势：港口库存处历史低位；进口连续 9 个月归零；仓单 6,633 张全部在厂库、实体仓库为 0。
> 不支持：库存已转为累积；沿海 MTO 集中停车形成需求负反馈；仓单自 5,216 张升至 7,083 张；现货自身在补跌。
> **以上为基差所处位置与变化原因的描述，不构成"基差必然回归"的判断，也不构成交易建议。**

## 工具与依赖

- `basislib.py` / `calc_basis.py` / `selftest.py`：**仅标准库**，任何机器可跑。
- `build_workbook.py`：需要 `openpyxl`；`build_report.py`：只需标准库。
- 自检：`python scripts/selftest.py`——含基差基本式、归因符号、换月跳空、前复权方向、样本不足判定等已知答案断言。

## 红线（逐条照做）

- ❌ **不因为基差在极端分位就说它必然回归。** 极端基差可以因为可交割资源不足而持续很久。
- ❌ **不把不可比的合约价格拼成一条历史基差曲线。** 固定合约、主力连续、不同换月规则必须分开，跨换月要说明复权方式。
- ❌ **不在样本不足时给历史分位。** N 不够就写"不可计算"并解释原因，不许用 13 个样本冒充 5 年分布。
- ❌ **不插值、不补数、不用近似值**。缺失留空，并在"数据缺口"里列出。
- ❌ **不混合不同机构/地区/税费口径**算出"平均基差"。
- ❌ 不把仓库仓单和厂库仓单合计后当成"可交割现货充足"。
- ✅ 每个数字都能追溯到：口径 + 地区 + 合约 + 日期 + N + 来源。
- ✅ 基本面证据必须**两边都列**：支持和反对都要出现，不许只挑对自己结论有利的。
- ✅ 给交易/采购建议要用户明确要求，且必须附风险声明。
