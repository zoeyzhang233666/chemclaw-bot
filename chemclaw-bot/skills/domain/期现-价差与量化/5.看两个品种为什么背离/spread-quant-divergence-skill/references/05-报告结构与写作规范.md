# 05 · 报告结构与写作规范

## 5.1 HTML 报告八节结构（固定）

| 节 | 标题 | 必须包含 |
|---|---|---|
| 顶部 | 核心纪律警示条 | 明示"只做统计描述+事实核查，相关性≠因果" |
| 1 | 先回答：为什么值得比 | 四层结构表（共性/差异性）+ "值得比"的两个条件 |
| 2 | 价格可比性检查 | 七项检查表 + "可比但非同质/价差无硬锚"三句话 |
| 3 | 三种视图 | 归一化 / 价差 / 比价 / 滚动相关 / z分数，**五个可切换视图** |
| 4 | 相关性 | 四组系数表 + 分年度演变 + 滚动相关图（含显著性带） |
| 5 | 背离识别 | 四步规则清单 + **4 组参数的段表**（可切换） |
| 6 | 双边基本面 | 六维度分侧核查，**每条带来源与日期** |
| 7 | 结论与局限 | 统计事实 / 待验证假设（含证伪条件）/ 证据局限 |
| 8 | 数据来源与缺口 | 来源清单表 + **明确缺口列表** |

## 5.2 Excel 工作表（13 表固定）

```
01_说明        口径、索引、纪律、缺口声明
02_价格数据    逐日价格 + 来源列 + 缺口说明列
03_归一化比价  归一化价、价差、比价、相对强弱
04_收益率      对数收益、1/5/20/60日涨跌、波动、回撤
05_滚动相关    20/60/120 期 × 水平/收益 + 显著性带
06_价差统计    描述统计（均值/标准差/分位）+ 分年度
07_背离识别    4 组参数的段明细 + 识别参数明细
08_z分数       z 序列 + 滚动均值/标准差 + 阈值触发标记
09_双边基本面  六维度 × A/B 侧 × 来源（缺口显式标注）
10_事件时间线  日期、事件、类别、来源
11_数据来源    来源清单 + 获取状态（已获取/部分/缺口）
12_统计方法    15 条公式与参数说明
13_结论与局限  类型（结论/假设/局限）、命题、证据、证伪条件
```

## 5.3 措辞纪律（最重要的一节）

| ❌ 不许写 | ✅ 应该写 |
|---|---|
| "A 的减产导致了背离" | "A 侧出现减产（数值+日期），**若**其为主导因素，则价差应向上修复；**证伪条件**：若 B 侧同期检修同比例上升，则不能归因于 A 单边" |
| "相关性下降说明 A 走弱" | "收益率相关从 X 降至 Y，同步性在统计上不再成立；**成因待查**（见第6节假设清单）" |
| "两者高度相关" | "收益率相关 R（水平相关 L）。水平高于收益时，图示平行主要来自共同趋势" |
| "库存偏低支撑价格" | "库存数据**缺口**，未作判断" |
| "预计价差将回归" | "价差无硬锚，**回归不保证发生**" |
| "根据我们的模型" | 给出公式、参数、窗口、阈值，可复现 |

**通用规则：**
- 每个数字后面跟来源与日期。
- 每个归因后面跟证伪条件。
- 每个缺口后面跟"未估算"。

## 5.4 视觉规范

- 深色背景 `#0d1117`，面板 `#161b22`，边框 `#30363d`。
- A 品种固定 **橙色 `#f0883e`**，B 品种固定 **绿色 `#3fb950`**，统计量 **蓝色 `#58a6ff`**。
- 显著性带、阈值线用**灰色虚线 `#484f58`**，不用彩色以免与数据混淆。
- 图不做"美化式截断 Y 轴"——必须从数据范围外扩 8% 留白，避免夸大波动。

## 5.5 自包含要求

HTML 必须是**单文件**：CSS 内联、JS 内联、数据以 `const D = {...}` 内联，
**不得引用任何 CDN、字体、图片外链**。用原生 `<canvas>` 手绘折线，不引图表库。
这样报告可以离线打开、邮件发送、归档多年。

## 5.6 落地检查清单

- [ ] 所有 `__PLACEHOLDER__` 已替换（`grep -c "__[A-Z]"` 应为 0）
- [ ] 内联 JSON 的 dates / 各序列长度一致
- [ ] HTML 中 `<canvas>` 数量 = 2（主视图 + 滚动相关）
- [ ] 偏离段表至少能显示 1 段（若为 0，需说明"该口径下无满足规则的段"）
- [ ] Excel 打开无警告，13 个 sheet 均有数据
- [ ] 报告内**至少 3 处**出现"相关性≠因果"或"假设/证伪"表述
- [ ] 缺口清单至少列出 3 项
