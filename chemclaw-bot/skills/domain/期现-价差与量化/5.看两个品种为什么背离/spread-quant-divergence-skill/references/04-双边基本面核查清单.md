# 04 · 双边基本面核查清单

## 核心原则

**必须两边都查。** 最常见的失败是：看到图上 A 强 B 弱，就直接去 A 那边找"利好"，
找到一条就收工——这叫**确认偏误**，不是研究。

正确做法：**对 A 和 B 分别填满同一张六维度表格**，谁的证据更强、谁的更弱，让表格说话。
查不到的，写"缺口"，不许用推理补。

## 六维度 × 双边表格（逐格填写）

### 维度 1 · 库存
| 要取的数据 | A 侧 | B 侧 | 来源 |
|---|---|---|---|
| 上游/石化企业库存（周度） | | | |
| 社会库存 / 贸易商库存 | | | |
| 港口库存（如有进口） | | | |
| 交易所仓单 | | | |
| 库存环比变化率 | | | |

> **方法学提示**：行业研究（如同花顺 L-PP 复盘）指出，
> 「聚烯烃上游企业**周度库存环比变化率之差**」对 L-PP 价差有较好拟合度。
> 这是最值得优先补的数据——**它比任何价格衍生指标都更接近供需真相**。

### 维度 2 · 供需平衡
| 要取的数据 | A 侧 | B 侧 |
|---|---|---|
| 产能（万吨）、近 10 年增速 | | |
| 当年新增名义产能及增速 | | |
| **当年标品有效产能增速**（关键！） | | |
| 投产时点分布（上半年/下半年） | | |
| 产量、开工率 | | |
| 表观消费量、进出口 | | |

> **"名义"vs"有效"是本维度最容易出错的地方。** 名义产能大增，但若装置在下半年投放、
> 或转产高附加值牌号、或推迟，则**标品有效供给增速可能远低于名义增速**，甚至方向相反。
> 只看名义数字会得出完全错误的相对强弱判断。

> **"预防性降负"是重要的行为信号**：企业因担心原料断供而主动减产，
> 说明供应端在收缩，且这种收缩**不是价格下跌导致的**，而是外生冲击。

### 维度 4 · 成本
| 要取的数据 | A 侧 | B 侧 |
|---|---|---|
| 主要原料及价格（元/吨） | | |
| **分工艺路线成本**（多条路径分别列） | | |

> **工艺占比是成本敏感度的换算系数。** 举例：若煤制在 A 中占比更高，
> 则**煤价对 A 的影响大于 B**——这是可检验的结构性差异，不是修辞。

## 从"事实"到"假设"的转换模板

填完表，**不要直接下结论**。每条候选归因必须写成四列：

| 可能来源 | 支持证据（带日期与数值） | 强度 | 证伪条件 |
|---|---|---|---|
| A 侧 · 成本（某工艺深亏） | 某日该工艺利润 −2,064 元/吨，远深于其他路线 | 较强 | 若该利润修复而价差未回落，则链条不成立 |
| A 侧 · 供应收缩 | 周损失 25.9 万吨、多套装置停车 | 较强 | 若 B 侧同期检修同比例上升，则不能归 A 单边 |
| B 侧 · 有效产能增速骤降 | 标品有效增速约 4%，远低于上年的 24% | 中等 | 若装置实际投料超预期，则支撑消失 |
| B 侧 · 需求季节性 | 下游有双峰季节性 | 中等（未量化） | 需下游开工率连续序列验证 |
| 共同 · 成本/地缘 | 原油一度 85 美元/桶，同时抬升两侧 | 共同因子 | 若两侧成本涨幅接近，则不能解释分化 |
| **统计假象** | 水平相关受趋势污染；窗口切换制造突变 | **必须排除** | 用收益率口径 + 显著性带检验后仍显著，方可排除 |

**"证伪条件"这一列不许留空。** 留空说明你写的是信念，不是假设。

## 常见错误

1. **只查一边**（确认偏误）→ 强制双边填表。
2. **把"时间上吻合"当因果** → 必须给证伪条件。
3. **用名义产能替代有效产能** → 找"标品有效增速"口径。
4. **忽略共同因子**（原油、宏观）→ 先检验两侧成本涨幅是否接近。
5. **把季节性当背离** → 检查下游季节形状是否错位。
6. **库存查不到就跳过** → 必须显式写"缺口"，并说明它如何限制结论强度。
