# 03 · 统计方法

## 3.1 三种口径，缺一不可

| 口径 | 公式 | 优点 | 缺点 / 何时失效 |
|---|---|---|---|
| **归一化价格** | `P_norm = P_t / P_0 × 100` | 消除绝对水平，直观看相对强弱 | 依赖起点；只消水平不消趋势 |
| **价差** | `Spread = A − B`（元/吨） | 产业习惯，换算直接 | 随两者价位整体漂移，跨年不可比 |
| **比价** | `Ratio = A / B`（无量纲） | 对长期成本中枢下移更稳健 | 分母小的时候爆炸 |

**必须三个一起给，互为交叉验证。** 若价差与比价给出相反的"背离方向"，说明是价位水平变化而非相对强弱变化。

## 3.2 水平相关 vs 收益率相关（本方法论的核心）

```python
level_corr = corr(P_A,            P_B)          # 价格水平
ret_corr   = corr(ln(P_A/P_A-1),  ln(P_B/P_B-1))# 对数收益率
```

**为什么必须分开报**：两个都上涨的序列，其"水平相关"可以接近 1，但它们可能完全**不同频**——
一个稳步上涨，一个剧烈震荡后上涨。用水平相关解释联动，会把**共同趋势**误读成**紧密耦合**。

**判断规则**：
- `ret_corr` 高 → 真正的同步性，背离是"异常事件"。
- `level_corr` 明显低于 `ret_corr` → 说明共同趋势贡献大，**图上的"平行"不可信**。
- 两者都低 → 缺乏共同驱动，不适合做背离研究。

## 3.3 滚动相关与显著性

```python
rc = r_A.rolling(w).corr(r_B)   # w = 20 / 60 / 120
band = 1.96 / sqrt(w - 3)       # Fisher z 近似，95%
```

- 相关曲线**跌破 ±band** → 同步性在统计上不成立，可称"背离"。
- **窗口切换本身会制造"相关突变"**：20 期敏感但抖，120 期平滑但滞后。**三个窗口同画**，看是否一致。
- 不要把"20 期相关从 0.9 掉到 0.5"当成重大发现，除非 60/120 期也同步下行。

## 3.4 z 分数：背离的量化

```
z_t = (I_t − μ_{t-w:t}) / σ_{t-w:t}
```

- `I` = 价差或比价；`μ,σ` = **滚动**均值与标准差。
- **必须用滚动，不能用全样本**：全样本均值/标准差用到了未来信息（前视偏差），
  会让"此刻是否异常"的判断被未来数据污染。
- `min_periods` 建议取 `w/2`，避免窗口开头几个点数值爆炸。

## 3.5 规则化背离识别（状态机）

```
进入：|z| ≥ z_entry (默认 1.5)
退出：|z| < z_exit  (默认 0.5)
约束：同一段内 sign(z) 必须一致（否则是穿越中枢，不是背离）
过滤：段长 < min_periods (默认 5) 丢弃
```

为什么用**双阈值**而不是单阈值：单阈值会在阈值附近反复触发/解除，产生大量碎片段。
引入"退出阈值 < 进入阈值"形成**迟滞（hysteresis）**，段才稳定。

**必须跑 4 组**：`价差×20 / 价差×60 / 比价×20 / 比价×60`，公开全部结果与敏感性。

## 3.6 辅助统计

- **年化波动**：`σ_daily × √252`
- **最大回撤**：`min(P/cummax(P) − 1)`
- **beta**：`r_B = α + β·r_A + ε`（OLS）。**仅作统计描述**，β≠因果弹性。
- **分年度统计**：按年给涨跌、水平相关、收益相关、价差均值、比价均值——**看清中枢迁移**。
  中枢的方向性反转（如价差均值从 −741 到 +317）比任何单日信号都重要。

## 3.7 伪相关陷阱清单

| 陷阱 | 表现 | 对策 |
|---|---|---|
| 共同趋势 | 水平相关高但收益相关低 | 主用收益率口径 |
| 前视偏差 | 用全样本均值判断"此刻异常" | 用滚动均值 |
| 前向填充 | 缺口期序列变平，相关性虚高 | 缺口就是缺口，不填 |
| 窗口切换 | 相关"突变"其实是旧数据滚出窗口 | 多窗口对照 |
| 小样本 | 20 期相关的置信区间极宽（±0.47） | 画显著性带，别过度解读 |
| 单位/税基不一致 | 价差系统性偏移 | 可比性七项检查 |

## 3.8 自检
