# 02 · 数据获取与口径

## 2.1 口径标注规范（每个价格都必须带）

`日期 + 规格 + 地区 + 合约 + 来源`

例：`2026-10-19 | PP拉丝 | 华东 | 现货出库价 | Mysteel/隆众「地区PP品类价格」日报`
例：`2026-10-20 | 主力连续PP0 | — | 期货收盘 | 新浪财经行情接口`

**没有这五项的价格，不许进报告。**

## 2.2 期货：优先且最可靠

| 来源 | 接口 / 路径 | 备注 |
|---|---|---|
| 新浪财经 | `https://stock2.finance.sina.com.cn/futures/api/jsonp.php/var%20_=/InnerFuturesNewService.getDailyKLine?symbol={SYM}` | GBK 解码；`re.search(r'\((\[.*\])\)', txt)` 取 JSON；主连用 `PP0`/`L0`，单合约用 `PP2701`。**无 key、最稳** |
| 东方财富 | `push2his.eastmoney.com/api/qt/stock/kline/get?secid=114.pp2701` | 实测常 `RemoteDisconnected`，作备用 |
| 交易所 | DCE `publicweb` | 实测 `HTTP 412`，仓单/持仓日报难取 |

**主连 vs 单合约**：主连适合做长序列统计，但**换月处有跳空**，会污染收益率与相关性。
若需严谨，应使用单合约拼接并按换月做价差调整（本 Skill 尚未内置该调整，需在局限中声明）。

## 2.3 现货：最难的一环

| 来源 | 路径 | 实测结论 |
|---|---|---|
| 生意社 | `https://www.100ppi.com/sf/{id}.html` | 近 ~90 天日度现货 + 主力 + 基差。**必须用 utf-8 解码**（不是 gbk）。id：718=PP拉丝、435=LLDPE、107=PVC |
| 生意社 | `pdata.100ppi.com/m/?f=basket&dir=futures&ppid={id}` | 固定 10 个点，且忽略分页/日期参数 |
| 生意社 | `/news/detail-YYYYMMDD-{id}.html` | 文章 ID **全局自增**，无法按日期枚举（同日不同品种 ID 相邻） |
| Mysteel/隆众 | `/oilchem/article/{cat}/{page}.html` | **推荐**。`cat=pxsp5e`（PP品类价格）、`xkiude`（LLDPE市场行情）、`paboel`（PE全国汇总）。页码即页号 |
| Mysteel 文章 | `/oilchem/a/{YYMMDDHH}/{HASH}.html` | 表格式价格。**部分文章 `meta allow=1` 表示正文需登录，只放出摘要截断**——需检查 `allow` |

### 关键坑位（都踩过）
- **100ppi 是 UTF-8**，用 gbk 会得到乱码且搜不到"基准价"。
- **Mysteel 旧文章（2024）表格塞在 `<meta name="description">` 里**，正文 `div` 里反而没有。解析要合并 meta。
- **最新一篇的"主流价"常是上一交易日的**（尤其周一）。例：`2026-10-20 华东PP` 页里拉丝 10737 实为 10-19 值。
  必须用同系列相邻两天的 `涨跌值` 交叉验证，或与另一口径（生意社基准价）对照。
- **`allow=1` 的文章**（全国汇总类）正文被截断成"…"，无法取全表 → 改用**按市场分篇**的栏目。

## 2.4 缺失处理规范（硬规则）

| 情况 | 正确做法 | 错误做法 |
|---|---|---|
| 某日无报价（节假日/停更） | 标注为缺口，或用前后交易日的**真实报价**（不是插值） | 用均值/线性插值填补 |
| A 与 B 起点不同 | 分别声明覆盖区间，只在**交集区间**做对比 | 前向填充造出共同起点 |
| 库存/开工拿不到 | 写"缺口，未估算" | 用价格反推、专家访谈"估计" |
| 口径变更（如栏目改版） | 分段说明，或改用同口径替代源 | 直接拼接不同口径 |

**前向填充为什么危险**：它把"没数据"变成"价格没变"，人为压低波动率，
并让两条序列在缺口期"完美同步"，**系统性高估相关性**。

## 2.5 抓取工程要点

- 并发 5–6 线程 + `time.sleep(0.25)` 足够；过高会触发超时。
- Mysteel 偶发 `WinError 10060` 超时，**重试 3–4 次**并退避，不要直接判失败。
- 索引页与文章页分开抓：先批量拿"标题→URL"映射（可断点续传存 JSON），再解析文章。
- 用**标题里的日期**作为日期字段，而非抓取时间。

## 2.6 长序列到底怎么解决

单靠现货日报很难覆盖 3 年（栏目改版、正文受限）。**分层策略**：

1. **统计主序列 = 期货主力连续**（可回溯 10+ 年，稳定）。
2. **现货序列 = 能拿多长拿多长**，如实声明起点（如 PP 现货 2024-10 起、LLDPE 现货 2025-06 起）。
3. **基差与现货价差只在交集区间**呈现。
4. 报告中**显式列出缺口清单**（见 `templates` 的来源表）。

这样比"编一条 3 年现货"诚实得多，也更有说服力。
