# 期现价差与量化研究 · 看两个品种为什么背离

## 这个 Skill 解决什么问题

有人指着两条价格曲线说「它们以前一起走，现在分开了，为什么？」。
天真的回答是「相关性下降了，所以 A 的某个因素导致了背离」——**这是错的**，
而且错得很常见：相关性变化既可能来自 A 边，也可能来自 B 边，还可能只是**共同趋势**
或**滚动窗口切换**造成的统计假象。

本 Skill 的产出是一套**可辩护的诊断流程**：先用产业关系论证"为什么值得比"，
再用价格可比性检查排除"不可比"的低级错误，然后用**三种视图 + 收益率口径相关 + 规则化背离识别**
把"分开了"变成一个有起止日期、有幅度、可复现的事件，
最后**分侧**核查双方的库存、供需、开工、成本利润与事件——并把每条归因都写成**待验证假设**，
附上**证伪条件**，同时声明数据缺口。

## 何时用 / 何时不用

**用**：两个品种有共同原料或替代关系，需要解释价差/比价异动；需要判断背离来自哪一边；
需要一套可复现的背离识别规则；需要向他人解释"为什么不能只看相关系数"。

**不用**：单一品种的行情判断（用 `chem-market-brief`）；采购议价（用 `chem-procure-brief`）；
寻找下游客户（用 `b2b-lead-sourcing`）；纯粹的价格预测。

## 工作流（六步，不可跳步）

### 第 0 步：先确认"为什么值得比"
不要一上来就画图。先回答：**共性**（为什么会一起动）与**差异性**（为什么会背离）。
只有当「收益率相关足够高（以便异常有信息量）」**且**「差异足够大（以便异常能持续）」时才值得做。
写进报告的产业关系表必须分层：原料端 / 工艺结构 / 需求端 / 替代性。
详见 `references/01-产业关系与可比性.md`。

### 第 1 步：价格可比性检查
逐项核对：计价单位、合约规模、交割地、基准规格、上游原料、下游用途、替代弹性。
**不同质的品种，价差没有硬锚，回归不保证发生**——这句话必须写进报告。
详见 `references/01-产业关系与可比性.md`。

### 第 2 步：取价并标注口径
每个价格必须带 **日期 + 规格 + 地区 + 合约 + 来源**。缺失一律标为**缺口**，**不估算、不前向填充**。
前向填充会制造"假平坦"，低估波动、高估相关性。
数据获取的具体渠道与失败退路见 `references/02-数据获取与口径.md`。

### 第 3 步：三种视图 + 两级相关
- 视图：①归一化价格（首日=100）②价差 A−B（元/吨）③比价 A/B（无量纲）——**三者同列，互为交叉验证**。
- 相关：**必须同时给"价格水平相关"和"收益率相关"**。水平相关高常常是共同趋势的假象；
  判断背离**以收益率相关为主**。滚动窗口用 20/60/120，并画 Fisher z 显著性带 ±1.96/√(n−3)。
公式与陷阱见 `references/03-统计方法.md`。

### 第 4 步：规则化背离识别（四要素全部公开）
指标（价差 or 比价）→ 中枢（滚动均值/标准差，**用滚动不用全样本，避免前视偏差**）
→ 双阈值状态机（进入 |z|≥1.5，退出 |z|<0.5，段内符号一致）→ 噪声过滤（持续期 ≥5）。
**至少跑 4 组参数组合**（价差/比价 × 20/60），把敏感性摊开给读者看。
实现见 `scripts/spread_core.py` 的 `detect_divergences()`。

### 第 5 步：分侧基本面核查（本 Skill 的核心价值）
**必须两边都查**，不允许只查看上去"有故事"的那一边。六个维度：
库存 / 供需 / 开工 / 成本 / 利润 / 重大事件。每条事实带来源与日期；查不到就写"缺口"。
查完之后，把每条归因写成：**可能来源 | 支持证据 | 强度 | 证伪条件**。
清单见 `references/04-双边基本面核查清单.md`。

### 第 6 步：结论必须带局限
结论分三类：**可直接引用的统计事实**（数值）／**待验证假设**（带证伪条件）／**证据局限**（缺口清单）。
并明确重申：**相关性变化不等于因果**。

## 三条硬纪律

1. **不把相关性当因果。** 报告里任何"背离来自 A（或 B）"的表述，都必须出现在"假设"栏，且带证伪条件。
2. **不估算缺失值。** 现货起点不同、库存拿不到，就如实写"不可比 / 缺口"，不填补、不外推。
3. **不隐瞒参数敏感性。** 背离段数量随阈值与窗口变化，必须公开多组结果，不得只报最有利的那一组。

## 快速开始

```bash
python scripts/run_pipeline.py --a data/pp.csv --b data/lldpe.csv \
  --aname PP --bname LLDPE --out ./out
```
输入为两列 CSV（date, price），脚本自动完成对齐、标准化、相关、背离识别，
并输出 `result.json`、HTML 报告与 Excel 工作簿。

## 自检

`scripts/spread_core.py` 内置 `self_test()`：用合成数据（前段同步、后段人为背离 10%）
验证能否识别出背离段，并演示"水平相关 0.97 但收益相关 0.85"的伪相关陷阱。
**改动统计逻辑后必须运行它。**
