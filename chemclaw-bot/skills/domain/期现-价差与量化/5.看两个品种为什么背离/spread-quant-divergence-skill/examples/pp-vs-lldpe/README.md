## 结论速览（供对照校验）

| 指标 | 数值 |
|---|---|
| 共同交易日 | 726（2023-10-20 → 2026-10-20） |
| PP 区间涨跌 | 7441 → 9376，**+26.0%** |
| LLDPE 区间涨跌 | 7954 → 8726，**+9.7%** |

> 图上看两条线"平行靠近"，其实主要来自共同趋势，不是紧密耦合。

## 本案例的诚实结论

1. **统计事实**：两者收益率高度相关（0.917），但水平相关更低（0.755）；
   价差中枢从 −741 系统性迁移到 +317 元/吨，属**结构性相对强弱切换**。
2. **待验证假设**（每条都带证伪条件，见 `narrative.json`）：
   - PP 侧 PDH 制利润 −2,064.85 元/吨（2026-03-05），为全路线最深，L 无对应路径；
   - PP 侧周损失量 25.944 万吨、多套装置停车、出现"预防性降负"；
   - PE 侧 2026 年 LLDPE 标品**有效**产能增速仅约 4%（2025 为 24%）；
   - PE 侧农膜双峰季节性 vs PP 下游节奏错位（未量化）。
3. **证据局限**：**无连续库存序列**（最大空洞）、无分品种开工率连续序列、
   无下游开工率序列、主连未做换月调整、规格非同质（价差无硬锚）。

> **不得**把上述假设写成"PP 减产导致背离"这类因果断言。时间上吻合只是必要线索。
