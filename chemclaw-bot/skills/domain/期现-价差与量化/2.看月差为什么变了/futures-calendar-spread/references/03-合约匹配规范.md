# 03 · 合约匹配规范

> 目标：给定“我要看近月和远月的月差”，脚本能稳定地把这句话翻译成一对**具体合约代码**，
> 并在合约不存在、未挂牌、当日无报价时明确拒绝，而不是悄悄换一个。

## 一、合约代码结构

郑商所品种：`SA2612` = 品种代码 `SA` + 年份末两位 `26` + 月份 `12`。

```python
code_to_delivery('SA2701')  # -> (2027, 1)
code_to_delivery('SA2613')  # -> ValueError: 月份非法
```

上市周期约定：品种上市于 2019-12-06，首批合约为 SA2005/SA2009/SA2012，
因此**2019 年 12 月之前不存在任何 SA 合约**。任何“3 年可比样本”的说法都必须先检查这一点。

## 二、别名表

`scripts/match_contracts.py` 支持的写法：

| 写法 | 解析结果 | 说明 |
|---|---|---|
| `SA2612` | 该合约 | 最明确，推荐 |
| `2612` / `202612` | `SA2612` | 缺品种前缀时自动补 |
| `近月` / `当月` | 当日最近到期且有报价的合约 | 按 dtd 最小 |
| `次近月` | 次小 dtd | |
| `远月` | 当日最远到期且有报价的合约 | 按 dtd 最大 |
| `主力` | 当日持仓量最大 | **不是**按成交额，避免短线噪声 |
| `第N月` | 按 dtd 升序的第 N 个 | `第3月` |

## 三、拒绝规则（重要）

脚本会在以下情况**直接报错退出**，而不是返回一个“差不多的”合约：

1. 代码格式非法（`SA26`、`SA2613`）。
2. 合约在该日期**尚未挂牌**（首个 K 线晚于基准日）。
3. 合约在该日期**已过最后交易日**。
4. 合约在该日期**无有效报价**（价格缺失或为 0）。
5. 两个月合约**没有重叠交易日**（无法构成月差）。

原因：这四种情况如果被静默处理成“最近可用合约”，产出的月差就会是一个**不同合约对**的数字，
而报告仍然写着原来那个合约名——这是最危险的一类错误。

## 四、月份组合（gap）计算

```python
gap = (year_b*12 + month_b) - (year_a*12 + month_a)
```

例：

| 合约对 | gap | 是否同组 |
|---|---|---|
| SA2612 / SA2701 | 1 | ✅ 与 SA2512/SA2601、SA2412/SA2501 同组 |
| SA2612 / SA2703 | 3 | ❌ 不同组 |
| SA2612 / SA2709 | 9 | ❌ 不同组 |
| SA2612 / SA2612 | 0 | 非法（同一合约） |

**顺序会影响 gap 的符号**，所以脚本内部统一按 `(a, b)` 原样计算并原样保存，
在可比样本检索时以 `abs(gap)` 匹配同组，再按 `(a, b)` 顺序重新计算月差符号。

## 五、距交割交易日（dtd）

```python
dtd = trading_days_between(date, delivery_date(year, month))
```

- `delivery_date` 默认取**交割月第 10 个交易日**，用该合约自身 K 线日历推算。
- 之所以用合约自身日历：不同年份节假日不同，用固定自然日推算会累积误差。
- `SA2612` 在 2026-10-20 的 dtd = **40**；`SA2701` 的 dtd = **63**。

## 六、合约规则登记表

`references/contracts_registry.json` 记录每个品种的：交易所、上市日、交割月份、最后交易日规则、交易单位、最小变动价位、推荐价格口径。

```json
"SA": {
  "contract_months": "1-12 月（全月份挂牌；实际流动性集中在 1/3/5/9/12 月）",
  "last_trading_day": "合约交割月份的第 10 个交易日",
  "unit": "20 吨/手",
  "settle_basis": "close",
  "verify": ["code", "list_date", "contract_months", "last_trading_day", "unit"]
}
```

**`verify` 字段的意义**：只列出已核实的字段。凡未列入的（如 `tick`、`last_delivery_day`），
报告里必须写“待核实”，不得凭空填一个数字。
若某品种在登记表中不存在，脚本照常运行，但 `--no-registry` 语义等价，并在报告中标注“规则未核实”。

## 七、流动性陷阱

- **新挂牌合约的占位报价**：SA2705 在 2026 年 5–6 月挂出时，价格恒定、持仓极低，
  若不加 `min_oi` 过滤，会导致期限结构末端出现“假平水”。
- **即将交割合约**：临近最后交易日时流动性骤降，价格可能脱离主流。建议 dtd < 5 时不上榜，
  或至少在图上标注。
- **主力 ≠ 近月**：纯碱主力常在 01/05/09，近月可能是个流动性很差的合约。
  因此“近月”与“主力”必须是两个不同的概念，不能互换使用。
