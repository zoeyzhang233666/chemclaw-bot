# 04 · 数据源与口径清单

> 每一列数字都必须能追到一个可复核的来源和覆盖区间。没有来源的数字不进报告。

## 一、行情数据（A 级：交易所原始数据，经公开接口转述）

| 项目 | 内容 |
|---|---|
| 来源 | 新浪财经期货 K 线接口 `InnerFuturesNewService.getDailyKLine` |
| 端点 | `https://stock2.finance.sina.com.cn/futures/api/jsonp.php/var%20_SA/SYMBOL/InnerFuturesNewService.getDailyKLine?symbol=SA2612&_=...` |
| 字段 | date, open, high, low, close, volume, open_interest, settle |
| 粒度 | **单合约日线**（不是主力连续） |
| 覆盖 | 各合约上市首日至今；SA 品种自 2019-12-06 |
| 清洗 | 剔除 settle ≤ 0 的行；不改动其余数值 |
| 脚本 | `scripts/fetch_futures.py --product SA --years 3 --extra ...` |

**为什么必须用单合约日线**：主力连续合约在换月日会出现价格跳空，
这个跳空会被错误地计入月差，等于凭空制造一次价差变动。单合约序列没有这个问题。

实时行情另取 `hq.sinajs.cn/list=nf_SA2612`（GB18030 编码），只用于“当前值”交叉核对，
不参与历史序列计算。

## 二、仓单 / 库存（A 级品种级 + B 级产业口径）

| 项目 | 内容 |
|---|---|
| 来源 | 东方财富数据中心 `RPT_FUTU_STOCKDATA`（转载郑商所仓单日报） |
| 端点 | `https://datacenter-web.eastmoney.com/api/data/v1/get?reportName=RPT_FUTU_STOCKDATA...` |
| 粒度 | **品种级**，单位“张”（纯碱 1 张 = 20 吨） |
| 覆盖 | 接口只回溯约 3 个月（本次：2026-07-13 ~ 2026-10-20，66 个交易日） |
| 脚本 | `scripts/fetch_industry.py warrant SA --out data/external/warrant_SA.csv` |

### 口径警告（必须写进报告）

1. **品种级不能拆成合约级**。仓单是所有已入库纯碱的总量，无法回答“近月合约的仓单是多少”。
2. **纯碱以厂库交割为主**，交易所仓单绝对量小，仓单低 ≠ 近月偏紧。
3. **交易所仓单 ≠ 社会库存**。真正压制价格的是厂库（样本企业库存），量级差两个数量级：
   - 仓单：约 3,214 张 ≈ 6.4 万吨
   - 样本企业厂库：约 179 万吨
   两者不能相加，也不能互相替代。

### 厂库 / 开工 / 产量 / 利润

目前**没有**可稳定调用的公开接口能给出连续历史序列。本技能的处理方式：

- 从财经媒体（东方财富期货频道）检索带日期的报道，逐条录入 `data/external/events_SA.json`；
- 每条标注**数值、日期、来源链接、证据等级**；
- 报告里明确写“B/C 级，未经交易所确认，需二次核对”；
- **不**把零散报道拼成一条“库存时间序列”去算分位——那是伪造数据。

## 三、现货参考价

| 项目 | 内容 |
|---|---|
| 来源 | 生意社 100ppi 报价中心 |
| 端点 | `https://www.100ppi.com/mprice/plist-1-533-1.html` |
| 粒度 | 企业/市场报价，同一天取中位数 |
| 覆盖 | 仅当日快照（2026-10-20：1200 元/吨，30 条报价，区间 1100–1350） |
| 脚本 | `scripts/fetch_industry.py spot SA --out data/external/spot_SA.csv` |

**注意**：这是厂家报价中位，**不是**交易所标准仓单价，不能直接算成基差去和期货比。
只用于判断“现货大方向在期货之上还是之下”。

## 四、合约规则

| 字段 | 来源 | 核实方式 |
|---|---|---|
| 交割月份 1-12 月 | 东方财富 SA 品种页 | 与首批合约并列验证 |
| 最后交易日 = 交割月第 10 个交易日 | 同上 | 用 K 线最后一行交叉验证 |
| 交易单位 20 吨/手 | 同上 | 与仓单单位换算一致性 |
| 上市日 2019-12-06 | 三份首批合约首根 K 线 | 完全一致 |
| 最小变动价位 | **未核实** | 报告中写“待核实” |

## 五、事件台账的证据分级

| 等级 | 含义 | 本案例示例 |
|---|---|---|
| **A** | 交易所原始数据，可逐笔复核 | 收盘价、持仓量、仓单 |
| **B** | 第三方机构统计，口径随机构 | 厂库 179.26 万吨、开工率 76.2%、周产量 75.16 万吨 |
| **C** | 媒体/机构观点，非数据 | “近强远弱”“供大于求格局难以逆转” |
| **D** | 传闻 / 未标注日期 | **不录入** |

录入规则：
- 必须有**明确日期**（不是“近日”“近期”）；
- 必须有**原文链接**；
- 数值必须能被引用为“某报告称”，不能写成“事实是”；
- C 级观点只能作为解释方向，**不得**参与任何计算。
