# 05 · 报告写作模板（“看月差为什么变了”）

> 目标：交出去的不是一堆图，而是一个能被人追问三层而不塌的结论。
> 核心纪律：**先给数字，再给结构，最后才谈原因；原因必须挂来源、必须允许被反证。**

## 一、七问对照表（用户的原话必须逐条被回答）

| 用户要的 | 报告里对应位置 | 交付物里对应 |
|---|---|---|
| 1) 两个合约最新价格及历史序列 | §1 KPI + §2 走势图 | HTML 图1 / Excel `03-合约价格`、`04-月差历史` |
| 2) 月差 = A − B，顺序一致 | §0 口径卡 | HTML §0 / Excel `01-使用说明`、`13-计算公式` |
| 3) 当前月差 / 近期变化 / 1年·3年分位 | §1 | Excel `05-近期变化`、`06-历史分位` |
| 4) 当前挂牌合约完整期限结构 | §4 期限结构 | HTML 图3 / Excel `08-期限结构` |
| 5) 历史相同月份组合、相近距交割 | §5 逐年对照 | HTML 图5 / Excel `07-可比样本` |
| 6) 库存·仓单·交割规则·季节性·已知事件 | §6 | Excel `10`、`11`、`12` |
| 7) 近月与远月的贡献分解 | §7 | HTML 图7 / Excel `09-贡献分解` |

**不要跳过第 2 项。** 大多数月差报告崩在这一步：读者最后不知道你说的“月差”到底是哪个减哪个。

## 二、固定叙事骨架

### 第 0 段：一句话说清“变没变”

> 先回答：用户问的“为什么变了”，**到底变没变**。

- 如果月差基本没动 → 直接说“月差本身几乎没动（−5 → −4，+1 元）”，然后指出**真正变了的是什么**（水平？结构？）。
- 如果确实变了 → 给出变化幅度在可比样本中的位置（百分位），而不是裸数字。

反面教材：一上来就说“因为库存高所以月差走弱”。库存高是长期事实，解释不了上周 +1 元。

### 第 1 段：把口径钉死

三行字：月差定义、价格口径、合约剩余期限。
并明确：**固定合约价差 / 跨年同组合 / 动态近远月** 三者不可混谈。

### 第 2 段：结构（比月差本身信息量更大）

- 期限结构全貌：从最近月到最远月，每档在哪。
- 关键对比：去年同一天的结构 vs 今年同一天的结构。**同月同日、同挂牌月份**，可比性最强。
- 指出变化发生在曲线的哪一段：近端塌了？远端抬了？整条平行下移？

本案例的正确答案：
> 整条曲线近乎平行下移约 230 元；真正变形的是**近端**——去年同位置最近月→次近月是 +11 元升水，
> 现在只有 +4 元；而 3 个月前（锚 SA2609）这个数字还是 +97 元。

### 第 3 段：产业证据（挂来源、标等级）

按“供给 / 需求 / 库存 / 成本 / 产能”分类，每条给：**日期 + 数值 + 来源 + 等级**。

必须区分：
- 能解释**水平**的证据（高库存 → 整条曲线低）；
- 能解释**结构**的证据（远期新产能 → 远端升水受限）；
- 能解释**近端**的证据（厂库回升、检修复产 → 近端升水消失）。

本案例三者恰好分属不同证据，混在一起讲就会变成一锅粥。

### 第 4 段：交割与仓单的“不解释”

**要敢于说某个数据解释不了。**

本案例：仓单只有 3,214 张（≈6.4 万吨），对 1,000 万吨级的年产/月产来说量级太小，
无法解释近端升水的消失。它只能作为“交割压力不大”的旁证，不能当主因。
讲清这一点，比硬凑一个故事更有说服力。

### 第 5 段：贡献分解

- 近 1 周：两腿各跌 22/23 元，贡献 −2.33% / +2.42%，**相抵** → 月差稳定。
- 近 1 月：两腿各跌 79/81 元，贡献 −8.12% / +8.28%，**仍然相抵** → 月差只挪了 2 元。

结论句应写成：“**月差的变化不是由某一腿单边推动的**”，而不是“近月主导/远月主导”。
只有当两腿贡献差异超过 25% 时才可以说“主导”。

### 第 6 段：限制与反证（这一段决定报告可不可信）

必须写：
1. 哪项分位是**不可用**的（样本不足）；
2. 哪项数据**缺失**（库存历史序列）；
3. 哪些是**同期而非因果**；
4. 什么证据会**推翻**当前解释。

本案例的反证条件：
> 若 11 月厂库见顶回落、开工率跌破 70%，且近端价差重新回到 +15 以上，
> 则“近端升水已被抹平”就不是结构性结论，只是季节性波动。

## 三、语言纪律

| 不要写 | 改成 |
|---|---|
| 月差走强 → | 月差从 X 变为 Y（+Z 元） |
| 远月承压 | 远月合约 SA2709 相对最近月升水 X 元，较上月收窄 Y 元 |
| 库存高所以月差… | 库存为 X（来源/日期）；同期月差为 Y。两者方向一致，但未做因果检验 |
| 建议关注 / 可考虑 | **删除**（红线：不给交易建议） |
| 大概率 / 预计 | 删除，或改成“若 A 则 B”的条件句并注明这是条件推演 |

## 四、页脚必写

- 数据截止时间与价格口径；
- 不含交易建议；
- 生成脚本与快照文件名（便于复现）。
