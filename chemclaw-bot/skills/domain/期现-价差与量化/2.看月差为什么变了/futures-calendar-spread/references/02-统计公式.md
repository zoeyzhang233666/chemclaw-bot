# 02 · 统计公式与实现口径

所有公式都在 `scripts/spreadlib.py` 中以纯标准库实现，`scripts/selftest.py` 用已知答案逐条校验。
Excel 版公式在 `13-计算公式` 页，全部是可重算的真实公式。

## 1. 月差与变化

```
spread(t)      = P(t, A) − P(t, B)
Δspread        = spread(t1) − spread(t0)                    [元/吨]
Δspread%       = (spread(t1) / spread(t0) − 1) × 100         [分母接近 0 时不可用]
chg_a          = P(t1, A) − P(t0, A)
chg_b          = P(t1, B) − P(t0, B)
```

**近 1 周 / 2 周 / 1 月 / 3 月 / 半年** 的窗口，按“该两腿都有报价的交易日”计数取第 N 个交易日前，
而非自然日历日。理由：节假日会让“日历周”变成 3 个交易日，窗口不可比。

## 2. 描述统计

| 指标 | 公式 | 备注 |
|---|---|---|
| 均值 | `Σx / n` | |
| 中位数 | 线性插值 50 分位 | |
| 样本标准差 | `√( Σ(x−x̄)² / (n−1) )` | n−1 分母，样本口径 |
| P_k | 线性插值（numpy `linear`） | 等价于 Excel `PERCENTILE` |
| 极值 | min / max | |

线性插值分位点的定义（与 numpy / Excel 一致）：

```
pos = (n − 1) × k / 100
lo  = floor(pos), hi = ceil(pos)
P_k = x[lo] + (x[hi] − x[lo]) × (pos − lo)
```

## 3. 分位（当前值站在历史的哪个位置）

```
percentile(v) = #{ x ∈ 样本 : x ≤ v } / n × 100
```

用 `≤` 而非 `<`：当期值恰好等于历史某值时，应计为“已达到该位置”，而不是 0%。
`tests`: `[1..10]` 中 `v=10 → 100%`、`v=0 → 0%`、`v=5.5 → 50%`。

## 4. 可比样本（本技能的核心）

```
可比(a, b) = { 历史合约对 (a', b') : gap(a', b') == gap(a, b)
                ∧ |dtd(a', 当月) − dtd(a, 当月)| ≤ dtd_tol }
```

- `gap` = 两合约交割月份差（按年 × 12 + 月 计算），`SA2612→SA2701` 为 1。
- `dtd` = 距本腿交割的交易日数。
- `dtd_tol` 默认 10 个交易日（约半个月），可按流动性放宽到 15。

**为什么两个条件都要**：
- 只按日历月份对齐 → 会混入“不同月份组合”，季节供需差异直接污染分布；
- 只按 dtd 对齐 → 会把 3 月合约对 4 月合约的月差和 12 月对 1 月的月差混在一起。

## 5. 期限结构

```
TS(t, c) = P(t, c) − P(t, nearest(t))
slope    = TS(t, 最远月) − TS(t, 最近月)
slope_per_month = slope / (最远月与最近月的月份差)
```

形态判定：相邻 TS 差分全 ≥ 0 且末项 > 0 → contango；全 ≤ 0 且末项 < 0 → backwardation；其余 → humped/mixed。

## 6. 贡献分解（近月 vs 远月谁推的）

用**对数差分**，因为它可加且无残差：

```
Δln(spread) = ln(P1(A)/P0(A)) − ln(P1(B)/P0(B))
            = c_A + c_B
其中  c_A =  ln(P1(A)/P0(A))        ← 近月贡献（A 涨，则 c_A > 0，把月差往上推）
      c_B = −ln(P1(B)/P0(B))        ← 远月贡献（B 涨，则 c_B < 0，把月差往下压）
```

- **两者之和恒等于 Δln(spread)**，数学上精确，没有残差项。
- `contrib_*_dln × 100` 即“百分点”形式的贡献，Excel 中按百分比格式显示。
- 可换算成“元/吨”的近似贡献：`c_A × spread` —— 但这是线性化，**只在 |spread| 远大于变化量时才可靠**。
  本技能只把对数贡献作为主指标，元/吨近似仅作辅助说明。

### 为什么不能用 `chg_a / Δspread` 求占比

当 `Δspread ≈ 0`（本案例近 1 周 Δspread = +1），`chg_a / Δspread` 会瞬间变成 −2200%，
完全失去意义。对数贡献没有这个毛病：它描述的是“哪条腿的相对涨跌更强”，与 Δspread 是否接近 0 无关。

### 判读规则

| c_A 与 c_B 的形态 | 含义 |
|---|---|
| c_A < 0 且 c_B > 0，且 `min(|c_A|,|c_B|)/max(...) > 0.8` | **两腿同步（相抵）**：月差几乎没动，只是整体涨跌 |
| c_A > 0 且 \|c_A\| > 1.25×\|c_B\| | 近月主导走强 |
| c_B < 0 且 \|c_B\| > 1.25×\|c_A\| | 远月主导走弱 |

本案例近 1 周：`c_A = −2.33%`、`c_B = +2.42%`，比值 0.96 → 判为“两腿同步（相抵）”。
**此时追问“谁主导月差”是错误的提问方式**，正确说法是“月差没动，两腿一起跌了 22–23 元”。

## 7. 数据质量门槛

任一 `ERROR` 级问题出现时，报告的结论区块必须标红并停止给出解读。检查项：

| 等级 | 检查 | 处理 |
|---|---|---|
| ERROR | 日期非升序 / 重复 | 阻断 |
| ERROR | 价格 ≤ 0 | 阻断该行 |
| ERROR | 单日跳变 > 15% | 阻断并报警 |
| WARN | 结算价缺失 | 标注，不填充 |
| WARN | 持仓 < min_oi | 从期限结构剔除 |
| INFO | 两腿无重叠交易日 | 返回空，不报错 |
