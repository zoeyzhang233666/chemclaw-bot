# 02 统计方法公式与边界条件

全部实现于 `scripts/hypothesis_stats.py`，纯标准库（不依赖 numpy/pandas），
并由 `scripts/selftest_stats.py` 对照 scipy / 手工参考值做 20 项自检。

## 1. 比例区间：Wilson score interval

$$\frac{\hat p+\frac{z^2}{2n}\pm z\sqrt{\frac{\hat p(1-\hat p)}{n}+\frac{z^2}{4n^2}}}{1+\frac{z^2}{n}}$$

* 为什么不用正态近似：n<30 时 Wald 区间会越界（上限>1），Wilson 不会。
* 自检：k=30,n=100 → (0.2189, 0.3958)。

## 2. 两比例检验

$$z=\frac{\hat p_1-\hat p_2}{\sqrt{\hat p(1-\hat p)(\frac1{n_1}+\frac1{n_2})}}$$

* 适用：n₁,n₂ ≥ 10 且每格 ≥5；小格用 Fisher 精确检验（2×2 超几何）。
* 自检：0.6/50 vs 0.4/50 → z=2.0，p=0.0455。

## 3. Welch t（不等方差）

$$t=\frac{\bar x_1-\bar x_2}{\sqrt{s_1^2/n_1+s_2^2/n_2}},\quad
\nu=\frac{(s_1^2/n_1+s_2^2/n_2)^2}{\frac{(s_1^2/n_1)^2}{n_1-1}+\frac{(s_2^2/n_2)^2}{n_2-1}}$$

* p 值用**精确的 t 分布**（正则化不完全贝塔 I_{ν/(ν+t²)}(ν/2,1/2)），不是正态近似。
* 自检：[9,11]×10 vs [8,10]×10 → t=3.0822, df=38, p=0.003813（与 scipy.ttest_ind 一致到 1e-13）。

## 4. Mann-Whitney U / Cliff's δ

$$U=\sum_{i,j}\mathbf 1[x_i>y_j]+\tfrac12\mathbf 1[x_i=y_j],\qquad \delta=\frac{2U}{n_1n_2}-1$$

* p 值用正态近似 + 结校正方差。
* δ 的解释：δ=0.5 表示信号组有 75% 的概率高于对照组。

## 5. 置换与移动块置换

* 普通置换：打乱标签 3000 次，看 |均值差| 超过观测值的比例。
* **移动块置换**：按时间顺序切成连续块（块长≈季节性窗口），整块打乱。
  为什么：库存/基差有强自相关，独立置换会低估方差，产生假显著。

## 6. 平稳自助（stationary bootstrap）

以几何分布长度重抽样，构造均值序列的经验分布取 2.5%/97.5% 分位。

## 7. OLS + Newey–West HAC

$$\hat\beta=(X'X)^{-1}X'y,\quad
\widehat{\mathrm{Var}}_{HAC}=(X'X)^{-1}\hat\Omega(X'X)^{-1},\quad
\hat\Omega=\sum_{l=-L}^{L}w_l\sum_t \hat u_t\hat u_{t-l}'x_tx_{t-l}'$$

* 带宽 `lags = floor(4(n/100)^{2/9})`，Bartlett 核。
* 输出 `hac_inflation = SE_HAC/SE_classical`，>1 说明存在序列相关（本项目约 1.2）。

## 8. Benjamini–Hochberg FDR

升序 p，找最大 k 使 $p_{(k)}\le \frac{k}{m}q$，前 k 个拒绝。

* 本项目预登记检验数上限 18，实际登记 17 个；q<0.10 视为通过校正。

## 9. 有效样本量

$$\rho=\mathrm{AR}(1),\qquad n_{\text{eff}}=n-\text{重叠损耗}$$

本项目的实现为 `effective_n(rho, ..., n)`：重叠窗口下名义 N 与独立信息量差别可达 2–5 倍，
因此报告时同时给出「名义 N / 非重叠 N / 月度 N」。

## 10. 什么时候不要用这些检验

| 情形 | 不要用 | 改用 |
|---|---|---|
| 信号 < 12 个 | 任何显著性检验 | 只报描述统计 + 明确"样本不足" |
| 极端值主导 | 均值差 t 检验 | Mann-Whitney、中位数差 |
| 强自相关 | 普通置换 | 块置换、HAC |
| 结构断点（口径调整） | 全样本合并 | 分段检验 + 明示不可比 |
| 多口径试了又试 | 单次 p 值 | BH-FDR + 全量登记 |
