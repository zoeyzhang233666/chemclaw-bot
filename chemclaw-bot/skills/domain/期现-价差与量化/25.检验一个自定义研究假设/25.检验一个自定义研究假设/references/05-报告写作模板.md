# 05 报告写作模板

## 一、结论的三种标准句式

### A. 历史数据支持

> 样本期 {起止}，共 {N} 个独立信号、{M} 个对照观测。在 {信号定义} 之后 {窗口} 交易日内，
> {指标} 的均值变化为 {效应量}（95% CI [{lo}, {hi}]，Welch t, p={p}；BH 校正后 q={q}），
> 方向一致率 {a}% vs 对照 {b}%。分年稳定性未见系统性反向。**历史数据支持该假设**，
> 但请注意：这是条件相关性，未计入交易成本，不构成投资建议。

### B. 证据不足（本项目采用）

> 去重后独立信号仅 {N} 个，低于事前设定的最小样本规则（信号≥12），
> 按设计约定不报告显著性，**结论为「样本不足，无法判断」**。
> 在放宽去重口径后（每周计一次，{N'} 个信号），主检验 p={p}、均值差 {x} 元/吨，
> 置信区间 [{lo}, {hi}] 横跨 0；再放宽换月限制（{N''} 个信号）p={p''}、均值差 {x''}。
> 四个口径一致，均未给出"连降 → 基差走强"的正向证据。

### C. 与历史相反

> 主检验显著，但方向与假设相反（均值差 {x}，p={p}），且在 {哪些稳健口径} 下一致反向。
> **该假设与历史数据不一致**，需重新审视"库存下降 → 基差走强"的传导链条
> （例如：库存下降可能已被市场提前定价，或下降来自需求走弱而非供给收紧）。

## 二、必须同时给出的六项数字

1. **样本量**：信号 n、对照 n、可用总观测、剔除原因分布
2. **效应量 + 95% CI**（不是只给 p）
3. **方向一致率**及区间
4. **分年**稳定性（每年 n 与方向）
5. **分阶段/分状态**稳定性（库存高低位、基差正负）
6. **多重检验校正后**的 q 值

## 三、禁止的措辞

| 禁止 | 原因 | 改写 |
|---|---|---|
| 「基本可以认为成立」 | 模糊，无判据 | 「p=…，方向一致，支持」或「证据不足」 |
| 「有一定倾向性」 | 把不显著说成有意义 | 「不显著，CI 横跨 0」 |
| 「大概率上涨」 | 概率来源不明 | 给出方向一致率与区间 |
| 「验证了假设」 | 观测数据无法"验证"因果 | 「与历史数据一致 / 不一致」 |
| 「数据显示未来会…」 | 样本外外推无依据 | 「在样本期内表现为…」 |

## 四、交付物清单

### HTML 研究页（9 个标签）

1. 研究设计：原始假设、变量拆解表、待确认问题
2. 参数确认：审批状态、数据指纹、最小样本规则
3. 数据可用性：真实/模拟双轨卡片、覆盖度、回源核验分布
4. 样本（真实）：KPI + 跳过原因 + 逐条样本表
5. 统计（真实）：全量检验登记表 + 修订口径对照
6. 稳定性 + 事件研究：分年/分位条形图 + 前后路径图
7. 模拟演示：整段紫色 SIMULATED 标记
8. 局限与风险：风险表 + 四类错误自查表
9. 复现说明：数据指纹、重建命令

### Excel 工作簿（15 sheet）

`0-封面与结论 / 1-研究设计 / 2-参数确认 / 3-数据来源与口径 / 4-原始数据-库存 /
5-原始数据-价格 / 6-因子定义 / 7-样本面板 / 8-统计结果 / 9-稳定性 /
10-修订口径对照 / 11-事件研究 / 12-模拟演示(SIMULATED) / 13-局限与风险 / 14-复现说明`

## 五、结论页的固定结构（照着填）

```
【假设】<原文照抄>
【结论】支持 / 证据不足 / 与历史相反　+ 一句话依据
【样本】信号 n / 对照 n / 样本期
【主检验】效应量 + 95%CI + p + q
【稳健性】敏感性口径、非重叠、月度、安慰剂 是否一致
【稳定性】分年是否一致；哪个分位带最强
【为什么是这个结论】三句话以内
【局限】最致命的那一条
【下一步】怎么拿到更多样本（自有数据/付费库/延长样本期）
```

## 六、给用户的三个「不要」

1. 不要把「证据不足」读成「假设是错的」——样本不够时我们什么也不知道。
2. 不要只看 p 值——效应量 2 元/吨即使显著，也覆盖不了手续费与滑点。
3. 不要把一个样本期的结论外推到另一个产业结构——2025–2026 的进口紧张与 2022–2024 的宽松完全不同。
