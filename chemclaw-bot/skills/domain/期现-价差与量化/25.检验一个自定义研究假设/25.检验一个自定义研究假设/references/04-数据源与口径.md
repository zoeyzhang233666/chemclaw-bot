# 04 数据源与口径（全部免密钥、可实测）

## 1. 港口库存（周度，最关键、也最难拿）

**来源**：隆众《中国甲醇样本港口库存周数据统计》，经我的钢铁网转载。

```
https://nenghua.m.mysteel.com/a/{YYMMDDHH}/{SHA16}_abc.html
```

**页面结构**：

* 标题：`[港口库存]：中国甲醇样本港口库存周数据统计(YYYYMMDD)`
* 正文：`截至YYYY年M月D日，中国甲醇港口库存总量在X万吨，较上一期数据增加/减少Y万吨`
* 区域表：江苏 / 浙江 / 华东总计 / 广东 / 福建 / 华南总计 / 港口总计
* 样本覆盖率：2022 年 95%，2024 年 98%（逐年变化，注意口径漂移）

**抓取教训（重要）**：

* 邻居链接块只会给出相邻文章，从最新一篇往回爬只能到达 live edge，
  实测只能拿到 3 周（2024-07-10/17/24）；
* Mysteel 无公开分页/检索接口（分页 404，TLS EOF），主流搜索引擎也不收录该子站 URL。

**正确做法（本项目采用）**：拿到历史时间序列后，**逐条回源核验**：

```bash
python scripts/verify_inventory_provenance.py \
  --csv 历史库存.csv --workers 6 --out build/verification_full.json
```

核验规则：页面可打开 + 标题日期 == 观测日 + 正文库存总量 == 记录值。
本项目 228/228 全部通过（`verified_ratio = 1.0`）。

> 如果核验通过率不足 80%，这批数据只能标 `PROVENANCE_UNVERIFIED`，
> 结论里必须写明，且不得用于正式检验。

## 2. 现货基准价 + 近月/远月期货（日度）

**来源**：生意社 100ppi 每日「商品现货与期货价格对比表」

```
https://www.100ppi.com/sf/day-YYYY-MM-DD.html
```

**解析要点**：单元格被 `<font>` 和 `<table>` 包裹，正则要同时兼容：

```python
CELL = r'<td>\s*(-?(?:[\d.]+)?)\s*(?:&nbsp;)?\s*</td>'
NUM  = r'<font[^>]*>\s*(-?[\d.]+%?)\s*</font>'
```

**锚点校验**（每次重新抓取都必须做）：

* 2022-08-17：原文「甲醇基准价为 2425.00 元/吨，与 8 月 1 日(2555.00 元/吨)相比下降 5.09%」→ 与抓取值一致
* 2024-07-24：现货 2537.00，近月 MA2409 2465

**已知口径陷阱**：

* 100ppi 现货是**综合区域基准价**（指数化），不是太仓出罐价；基差方向可用，水平不可直接当交易价。
* 「近月」列随交割日逐月切换（MA2204→MA2205…，实测 56 次），换月日价格跳变数十元。
* 该页自己算的基差按 0.5 取整，与 spot−near_fut 有 ±0.5 的差异（626 行），本 Skill 用原始两列重算。

## 3. 期货日线 / 60 分钟线（复核与入场时点）

```
https://stock2.finance.sina.com.cn/futures/api/jsonp.php/var%20_{SYM}=/InnerFuturesNewService.getDailyKLine?symbol={SYM}
https://stock2.finance.sina.com.cn/futures/api/jsonp.php/var%20_{SYM}=/InnerFuturesNewService.getFewMinLine?symbol={SYM}&type=60
```

* 需要 `Referer: https://finance.sina.com.cn`，否则被拒。
* `c` = 收盘，`s` = 结算价。
* MA0 为未复权拼接，换月有跳空；60 分钟数据只保留约 1023 根（本项目从 2026-01-28 起）。

## 4. 其他可核查补充源

| 用途 | 站点 | 说明 |
|---|---|---|
| 仓单日报 | 郑商所 `czce.com.cn` 每日仓单 | 解释基差走强的另一条腿 |
| 到港/船期 | 隆众/卓创公开摘要 | 库存的领先指标，可用于替代变量 |
| 宏观与成本 | 国家统计局、Wind/Choice（需付费） | 阶段划分依据 |
| 政策原文 | 发改委、海关总署、生态环境部 | 外生冲击，适合因果设计 |

## 5. 单位与精度约定

| 指标 | 单位 | 精度 | 备注 |
|---|---|---|---|
| 港口库存 | 万吨 | 2 位小数 | 原文精度，0.01 也是变化 |
| 现货/期货价 | 元/吨 | 整数或 0.5 | 100ppi 原文精度 |
| 基差 | 元/吨 | 由两列相减得出 | 可能带 0.5 |
| 收益率 | % | 4 位小数 | (P₁−P₀)/P₀×100 |

## 6. 复现性要求

* 每次抓取写 manifest：url / status / sha16 / bytes / fetched_at
* 入库时记录 `verified_at`
* 交付时给出数据文件 sha256 前 16 位（见 `build/research_design.formal.json` 的 `data_fingerprint`）
