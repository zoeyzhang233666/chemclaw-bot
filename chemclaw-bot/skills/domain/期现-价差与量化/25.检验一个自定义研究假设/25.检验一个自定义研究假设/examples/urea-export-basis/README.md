# 案例三：尿素出口环比大增 → 国内基差走强（设计就绪，待数据）

## 状态

`DESIGN_READY` —— 设计已冻结，等待海关月度出口数据接入。无结果数字。

## 假设

> 尿素月度出口量环比大增后，随后一个月国内尿素基差更容易走强。

## 设计要点

| 项目 | 取值 | 说明 |
|---|---|---|
| 品种 | 尿素（郑商所 UR） | 出口敏感品种 |
| X | 月度出口量（万吨，海关总署） | 需预先固定阈值，如环比 ≥ +30% |
| Y | Δbasis_20（小颗粒主产区现货 − UR 主力） | |
| 信号 | 环比增幅 ≥ 30% | **阈值必须事前登记**，不可事后挑 |
| 窗口 | 20 个交易日 | |
| 入场 | 海关数据发布日（通常次月 20 日前后）收盘 | 发布时点必须核对，否则前视 |

## 为什么这个假设不能照案例一的方法跑

1. **样本量天生极小**：月度数据，5 年只有 60 个月，其中"环比 +30%"可能只有 8–12 次。
   按最小样本规则，大多数情况下结论必然是「样本不足」。
2. **政策外生性**：法检、配额、出口关税变动会让"出口量"本身不连续 → 更适合做**事件研究**
   （政策前后 ±20 日路径），而不是均值差检验。
3. **发布时点**：海关数据是月度汇总，发布日与研究用的"自然月末"相差 2–3 周，
   这段时间的基差变化不能算进信号后窗口 → 必须以**发布日**而非月末为 T0。

## 建议的研究设计升级

* 主设计：政策事件研究（检验政策公告前后基差路径是否突变）
* 辅助设计：出口量环比分档（<0 / 0–30% / >30%）的基差变化分布
* 必须配对：出口量与国内厂库同时看，否则无法区分"出口拉动"与"减产收紧了国内供给"
