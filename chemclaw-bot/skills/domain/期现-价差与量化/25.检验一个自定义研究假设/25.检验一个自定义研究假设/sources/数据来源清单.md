# 数据来源、核验记录与审计痕迹

本目录记录本次示范案例（甲醇港口库存 × 基差）所用**全部真实数据**的来源与核验方式。
所有数字都可以按下面的 URL 逐条复核。

## 1. 港口库存（周度）

| 项目 | 内容 |
|---|---|
| 原始发布 | 隆众资讯《中国甲醇样本港口库存周数据统计》 |
| 转载载体 | 我的钢铁网 `nenghua.m.mysteel.com` |
| URL 规则 | `https://nenghua.m.mysteel.com/a/{YYMMDDHH}/{SHA16}_abc.html` |
| 覆盖 | 228 周，2022-04-06 → 2026-10-14 |
| 抓取方式 | 本次实时爬取只能到达 live edge（3 周：2024-07-10/17/24），其余来自本地历史索引 |
| **核验方式** | 逐条重新抓取原页，校验①页面可打开 ②标题日期==观测日 ③正文「港口库存总量在X万吨」==记录值 |
| **核验结果** | **228/228 通过，通过率 100%**（明细：`examples/.../build/verification_full.json`） |
| 字段 | 港口总计 / 华东（江苏+浙江）/ 华南（广东+福建） / 样本覆盖率 |

**口径风险**：样本库区数与覆盖率逐年变化（2022 年 95%、2024 年 98%），因此本研究只使用
周度变化量 ΔI 的符号，不使用跨年可比的绝对水平。

## 2. 现货基准价与近月/远月期货（日度）

| 项目 | 内容 |
|---|---|
| 来源 | 生意社 100ppi 每日「商品现货与期货价格对比表」 |
| URL 规则 | `https://www.100ppi.com/sf/day-YYYY-MM-DD.html` |
| 覆盖 | 1119 个交易日，2022-03-01 → 2026-10-20 |
| 缺失 | 现货 / 近月 / 基差 全部 0 缺失 |
| 锚点校验① | 2022-08-17 原文「甲醇基准价为 2425.00 元/吨，与 8 月 1 日(2555.00 元/吨)相比下降 5.09%」→ 抓取值一致 |
| 锚点校验② | 2024-07-24 现货 2537.00 / 近月 MA2409 2465 |
| 换月识别 | 近月合约代码逐月切换，实测 56 次（MA2203→MA2204 … MA2609→MA2610） |

**口径风险**：基准价是指数化的综合区域价；近月逐月换月造成价格跳变（主样本已剔除窗口内换月）。

## 5. 抓取过程中遇到的问题（供后人避坑）

1. **Mysteel 无分页/检索接口**：分页参数 404，TLS 偶发 EOF；邻居链接只给相邻文章，
   从最新一篇回溯只能到达 live edge。
2. **搜索引擎不收录该子站**：cn.bing / DDG / sogou / 360 均返回 0 条 Mysteel URL。
3. **2023 年库存有 49 个周度观测**（个别周双报告或顺延），由「观察间隔 5–10 天」规则自动剔除 24 条。
4. **100ppi 页面自身算的基差按 0.5 取整**，与 spot−near_fut 有 626 行 ±0.5 差异；本研究用原始两列重算。
5. **60 分钟数据只有近期**：2026-01-28 之前的 pre15 入场退化为当日收盘代理（82 周），已如实计数。

## 6. 如何复核

```bash
# 重新核验全部库存 URL（需要联网，约 3–5 分钟）
python scripts/verify_inventory_provenance.py \
  --csv examples/methanol-port-inventory-basis/data/port_inventory_weekly.csv \
  --workers 6 --out /tmp/verification.json

# 抽查任意一行：把 URL 贴到浏览器，核对标题日期与正文档位
# 例：https://nenghua.m.mysteel.com/a/24072414/11A9767949A17F06_abc.html  → 103.44 万吨
```
