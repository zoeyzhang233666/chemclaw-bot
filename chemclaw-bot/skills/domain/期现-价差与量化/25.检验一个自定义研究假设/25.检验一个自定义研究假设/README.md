## 示范案例的结论（甲醇，2022-04 → 2026-10）

| 项目 | 结果 |
|---|---|
| 库存样本 | 228 周，**逐条回源核验 228/228 通过** |
| 价格样本 | 1119 个交易日（100ppi 现货+近月+基差，0 缺失） |
| 主口径信号 | 10 个（状态转变去重 + 剔除窗口内换月） |
| 主检验 | 触发最小样本规则 → **结论：样本不足，无法判断** |
| 修订口径 AM-1（每周都算，24 个信号） | 均值差 −0.9 元/吨，p=0.96 |
| 修订口径 AM-3（最宽松，48 个信号） | 均值差 +7.2 元/吨，p=0.69，CI [−28.6, +42.9] |
| 事件研究 | 信号组在 T0 **之前**基差已高于对照组 → 存在选择效应 |

**一句话解读**：把口径放到最松，也没有出现"连降两周 → 基差走强"的正向显著证据；
而且信号往往出现在基差已经走强的阶段，所以哪怕未来样本更多，也要先解决选择效应才能谈"因果"。

## 为什么这个案例值得看

它完整演示了四种"很想作弊但没作弊"的诱惑：

1. **只有 3 周库存时** → 没有用模拟数据顶替，而是去找可核验的历史序列并逐条回源。
2. **信号只有 10 个时** → 没有偷偷改成"每周都算"来凑够样本，而是主口径如实写"样本不足"，
   修订口径单列对照。
3. **某一年看起来显著时** → 没有只说那一年，分年表全列。
4. **窗口内换月会污染价格时** → 主动剔除 41 个观测，宁可样本更少。

## 环境

* Python 3.9+，**统计部分零依赖**（纯标准库）
* Excel 生成需要 `openpyxl`（工作区自带 Python 即可）
* 抓取部分需要联网；不联网也能跑自检、重算、出报告

## 三条使用纪律

1. 先跑 `python scripts/selftest_stats.py`，全部 PASS 再动数据。
2. 参数确认（`approve_design.py`）之后再跑统计；跑完不要回头改参数。
3. 任何结论都必须能回答："这个 p 值背后有多少个**独立**观测？"
