# 模板说明

## `极端基差扫描看板_template.html`

已在 `2026-10-20` 真实数据上渲染完成的看板，可直接当模板复用。

- **自包含**：ECharts 全量内嵌，无任何外链，双击即可离线打开
- **结构**：顶部样本长度提示条 → 6 个 KPI → 阈值/窗口滑杆 → 排行榜 + 分位分布
  → 覆盖核验表 → 点击品种展开详情（5 张图 + 口径 + 仓单 + 事件）
- **交互**：拖动「极端阈值」和「历史窗口」滑杆，前端按与后端完全相同的
  中位秩公式**实时重算**分位与判定，不需要重跑脚本

### 作模板用

里面的真实数据在 `<script>` 标签的 `const DATA = {...}` 处。重新生成时：

```bash
python -m basis_scan.make_html --result out/scan_result.json --out "out/新看板.html"
```

`make_html.py` 会读取 `scripts/assets/echarts.min.js` 并内联，
然后替换模板里的 `/*__ECHARTS__*/` 与 `/*__DATA__*/`。

### 不要做的事

- 不要手工改 HTML 里的数字 —— 会与 Excel 不一致。改数据请改 `scan_result.json` 后重跑。
- 不要把 ECharts 换成 CDN 链接 —— 会失去离线可用性。

## `化工极端基差扫描_数据工作簿.xlsx`

13 个 sheet 的成品模板：

| sheet | 内容 |
|---|---|
| 01_说明与口径 | 口径、公式、样本长度边界、免责 |
| 02_极端排行榜 | 按品种内分位排序 + 条件格式 + 柱状图 |
| 03_历史分位分布 | P10~P90、均值、标准差、极值 |
| 04_数据覆盖核验 | 样本数、有效日期、合约映射、校验通过率、数据指纹 |
| 05_品种池 | 12 品种现货/期货口径 + 排除品种原因 |
| 06_现货期货快照 | 最新交易日价格与基差 |
| 07_基差月表 | 月度末值与均值 |
| 08_日度基差明细 | 1,310 行长表，可直接透视 |
| 09_近1月变化 | 基差与分位的月度位移 |
| 10_极端品种聚焦 | 仓单、换月跳变告警、产业事件 |
| 11_无法扫描品种 | 样本不足与口径不可比清单 |
| 12_数据来源 | 逐条 URL 与校验方式 |
| 13_口径字典 | 字段定义与计算方式 |

重新生成：

```bash
python -m basis_scan.make_xlsx --result out/scan_result.json --out "out/新工作簿.xlsx"
```

生成后建议跑一次结构检查：

```bash
python <office-skills>/scripts/check_office.py "out/新工作簿.xlsx" --out checks.json --count 13
```
