# 实战案例：2026-10-20 化工品极端基差扫描

> 本文全部数字来自真实抓取（数据截至 **2026-10-20**），可用包内脚本原样复现。

## 一、任务

「扫描甲醇、纯碱、PVC、PP、LLDPE、PTA、乙二醇这批化工品的极端基差品种。
不要只扫有结果的那几个就说是全市场排名；每个品种要独立算分位，不能直接比金额；
要展示样本长度、有效日期、合约映射规则；不要把高低分位直接当多空信号。」

## 二、执行

```bash
export PYTHONPATH=$PWD/src

python -m basis_scan.fetch_spot --codes MA,SA,V,PP,L,TA,EG,UR,SH,EB,FG,PX \
    --max-pages 12 --out data/raw/spot --cache data/cache
python -m basis_scan.fetch_futures --codes MA,SA,V,PP,L,TA,EG,UR,SH,EB,FG,PX \
    --years-back 6 --cache data/cache
python -m basis_scan.fetch_fund --root . --out out/fundamentals.json
python -m basis_scan.scan --window-years 3 --threshold 0.10 --min-obs 120 --out out
python -m basis_scan.make_html --result out/scan_result.json --out "out/极端基差扫描看板.html"
python -m basis_scan.make_xlsx --result out/scan_result.json --out "out/化工极端基差扫描_数据工作簿.xlsx"
```

品种池从用户点名的 7 个扩到 12 个（加了尿素、烧碱、苯乙烯、玻璃、PX），
以确保「扫描覆盖面」本身是可信的。

## 三、关键发现：样本长度远小于名义窗口

这是本次最重要的结论，**必须先讲清楚再讲排名**。

| 项 | 期货侧 | 现货侧 |
|---|---|---|
| 可回溯长度 | 1600~1880 个交易日（逐合约，2019 年起） | **96~150 个交易日**（约 7 个自然月） |
| 瓶颈 | — | **是** |

生意社栏目只保留最近约 10 页文章，历史文章 ID 无规律不可枚举，站内搜索不可用。
所以名义上的「3 年窗口」实际只能落到 **2026-03-09 ~ 2026-10-20**。

**因此本次分位只能解释为「近 7 个月内处于什么位置」，不能称为 3 年历史分位。**
样本不足 1 个自然年，尚未覆盖完整季节性周期。

## 五、口径校验：两个品类差点算错

### 玻璃：单位差 80 倍

初次运行基差为 **−607 元/吨**，看着像深度贴水。回查源站文章正文：

```
10月20日生意社现货基准价为11.95元/平方米。
市场基差=现货价格-期货价格=11.95/0.0125-846=110元/吨。
```

现货是**元/平方米**，期货是**元/吨**，100ppi 用 `/0.0125`（即 ×80）换算。
- 错误算法：11.95 − 846 = −834.05（把平方米价直接减吨价）
- 正确算法：11.95 × 80 − 846 = **110**（与源站一致）

修正后从「疑似极度贴水」变成「高位极端但幅度温和」。**分位也从 99.7% 降到 90.5%。**

### 烧碱：32% 液碱要折百

同样问题。现货 629 元/吨 是 32% 液碱，期货是折百价：

```
市场基差=现货价格-期货价格=629/0.32-1707=258.625元/吨
```

- 错误：629 − 1707 = −1078（符号都反了）
- 正确：629 × 3.125 − 1707 = **258.62**

修正后从「基差−1078、看似深度贴水」变成「基差+259、实为升水」。
**这是符号级别的错误，不查就会得出完全相反的结论。**

### 交叉校验最终结果

| 品种 | 校验通过率 | 单位系数 | 系数来源 |
|---|---|---|---|
| 甲醇/纯碱/PVC/PP/LLDPE/尿素/PX | 100% | 1.0 | 源站基差公式反解 |
| 玻璃 | 100% | 80 | 源站换算式 `现货/0.0125` |
| 烧碱 | 98.67% | 3.125 | 源站换算式 `现货/0.32` |

烧碱未达 100%，是因为 **2026-03-09、03-10 两天源站自己的标题基差与正文公式不一致**
（标题 −1774 / −1649，正文算出 −354.5 / −208.25）。这两天记为 `src_drift`，
如实保留，未静默修正。

## 七、边界与免责

1. **不是多空信号**。分位只描述历史位置。基差在 99.7% 分位不代表会回落。
2. **实际样本只有 7 个月**，未覆盖完整季节性，不能外推为多年分位。
3. **基差金额不可跨品种比较**。烧碱 258.62 与 PVC −39.00 之间没有「谁更极端」的含义。
   排行榜只按分位排序。
4. **现货含税、期货不含税**，基差天然含约 13% 增值税项，绝对值不能与无税基差经验值对照。
5. 玻璃属建材板块，此处因用户池含玻璃而纳入，可按需剔除。
