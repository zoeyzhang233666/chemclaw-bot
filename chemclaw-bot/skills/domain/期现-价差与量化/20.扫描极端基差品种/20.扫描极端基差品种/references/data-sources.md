# 数据源与接口

全部免费、无需 API Key。抓取结果落盘缓存（SHA1 键），重跑不重复请求。

## 1. 现货基准价 —— 生意社 100ppi

### 栏目页（文章列表）

```
https://www.100ppi.com/data/dlist-{channel}--{ppid}-{page}.html
```

- `channel` 板块号：11 能源 / 12 有色 / 13 钢铁 / **14 化工** / **15 橡塑** / **16 化纤** / 17 建材 / 18 农副
- `ppid` 商品 ID（见下表）
- `page` 从 1 起，**越大的页码越老**；实测每页 10–28 条，最多约 10 页
- 栏目只保留最近约 10 页 → **这就是现货历史通常只有 3–8 个月的根本原因**

### 文章页

```
https://www.100ppi.com/data/detail-{YYYYMMDD}-{id}.html
```

正文含三行关键信息：

```
10月20日生意社玻璃市场基差为110元/吨。
10月20日玻璃期货主力合约2701收盘价为846元/吨。
10月20日生意社现货基准价为11.95元/平方米。
市场基差=现货价格-期货价格=11.95/0.0125-846=110元/吨。
```

最后一行是**源站自证公式**，有两处价值：
1. 反解单位换算系数（`1/0.0125 = 80`，`1/0.32 = 3.125`）
2. 做交叉校验（我方独立算的基差应等于它）

### 反爬处理

首次请求会返回 636 字节的「正在进行安全检查」页，其中含 `var _0x2 = "<hex>"`。
把该 hex 作为 `Cookie: HW_CHECK=<hex>` 重发即可。`http.py` 已自动处理（最多重试 6 次）。

其他注意：
- 详情页偶发 404（同一 URL 重试即成功）→ 不要缓存 404
- 站点偶有栏目页返回空 → 换页或稍后重试
- 请求间隔建议 ≥0.3 秒

## 2. 期货日线 —— 新浪财经

```
https://stock.finance.sina.com.cn/futures/api/jsonp.php/var%20t=/InnerFuturesNewService.getDailyKLine?symbol={SYMBOL}
```

- `symbol=MA2701` → 单个合约，返回**最近 242 根日线**（约 1 年，含上市初期）
- `symbol=MA0` → 主连，可回溯至上市首日（甲醇 2009 起、PP 2014 起、纯碱 2019 起）
- 字段：`d` 日期 / `o h l c` 开高低收 / `v` 成交量 / `p` 持仓量 / `s` 结算价

**注意**：`MA0` 主连的换月规则由新浪维护、未公开，且历史段可能做过平滑，
因此本项目**不用主连**，而是逐合约抓取后自建连续序列（规则透明、可复现）。

## 3. 库存 / 仓单

| 用途 | 接口 | 说明 |
|---|---|---|
| 郑商所仓单日报 | `akshare.futures_warehouse_receipt_czce(date='YYYYMMDD')` | 返回 dict，按品种分表；`TA` 的键名是 `PTA` |
| 库存序列 | `akshare.futures_inventory_em(symbol='烧碱')` | 东方财富，约 66 个交易日 |
| 大商所仓单 | `akshare.futures_warehouse_receipt_dce(date=...)` | 接口常返回非 JSON，失败时回落 |

**重要**：`futures_inventory_em` 的「库存」列实测等于交易所**注册仓单合计**，
与 `futures_warehouse_receipt_czce` 的「总计」逐日一致（如纯碱 3214、甲醇 6633）。
因此必须在表里标注为「交易所仓单」而非「社会库存」。真实社会库存/港口库存需另接资讯源。

## 4. 产业事件

100ppi 各品种栏目里除价格稿外，还会有：
- `XX产业链情报` / `XX产业价格涨跌榜`（如「2026年10月14日氯碱产业价格涨跌榜」）

**站内搜索不可用**（`/mprice/?f=search&terms=...` 只返回小程序广告页），
因此事件只能从栏目列表的标题级线索获取，**不含数值**。
在交付物中必须注明「标题级线索，非数值」。

## 5. 已废弃的尝试（避免重复踩坑）

| 尝试 | 结果 |
|---|---|
| `news/list-{ch}-{ppid}-{page}` 新闻归档 | 只覆盖约 30 页（≈3 个月），且与 dlist 重复 |
| `news/list-14-1217-{page}` 全局新闻 | 只返回当天 |
| `news/list-{ch}----{page}` 分类 | 只返回当天 |
| `IndexService.getInnerFuturesDailyKLine` 连续指数 | 返回 0 行 |
| 历史文章 ID 枚举（`detail-20251020-1xxxxxx`） | ID 无规律，无法枚举 |
