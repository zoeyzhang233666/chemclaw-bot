# 方法论与边界

## 1. 基差定义

```
basis = 现货基准价(换算到期货计价单位) − 期货主力收盘价
```

- 符号固定，不许按品种翻转
- 现货为**含税**基准价，期货为**不含税**价 → 基差天然含约 13% 增值税项
- 不做插值、不用前值填充；期货缺该交易日即当日不出基差
- 同日对齐：现货日期必须等于期货日期，不跨日匹配

## 2. 合约映射

### 主力连续（默认）

每交易日取**持仓量最大**的合约 `argmax(oi)`。
换月日 = 主力合约代码变化的那天，标记 `is_roll=1`。

### 近月连续（可选）

交割月 ≥ 当日的最近月份合约；若其持仓量 < 主力持仓的 5%，则顺延到下一月份（避免流动性陷阱）。

### 换月跳空

换月日前后，两个不同月份合约的价差会直接体现在基差上，形成**伪跳变**。
处理原则：**保留不修正，但必须披露**。
- 窗口内换月次数
- 跳变 ≥30 元/吨 的日子（`roll_jumps_big`）在详情页与 Excel 10 页列出
- 不修正的理由：平滑掉会让历史基差失真，用户无法复核

## 3. 分位计算（三种，都报出来）

给定窗口内 n 个有效基差，当日值 x：

| 名称 | 公式 | 用途 |
|---|---|---|
| 严格分位 `pct_strict` | `count(v < x) / n` | 最小值=0%，最大值<(1−1/n) |
| **中位秩分位 `pct_midrank`** | `(count(v < x) + 0.5·count(v = x)) / n` | **极端判定用这个** |
| 含当日分位 `pct_le` | `count(v ≤ x) / n` | 经验 CDF，最大值=100% |

三者都报，是因为单一口径会被质疑。极端判定统一用中位秩，避免
「当日就是历史最高 → 严格分位 = 100% 但其实一天都不超过」这类边界歧义。

## 4. 极端判定

```
中位秩 ≤ threshold          → 低位极端
中位秩 ≥ 1 − threshold      → 高位极端
否则                        → 常态
```

默认 `threshold = 10%`。
**判定结果只是「位置描述」，不是多空信号。** 基差在历史高位不等于该做空，
因为它可能继续走高；本工具不给出任何方向性建议。

## 5. 样本长度 —— 最需要诚实的地方

这是本项目最重要的方法论约束。

名义窗口 `--window-years 3` 只是**上界**。实际样本取决于：
```
实际样本 = min(名义窗口内的交易日, 公开可回溯的现货稿天数)
```

实测（2026-10-20）：生意社栏目窗口内，现货样本为 **96~150 个交易日**，
只覆盖约 **7 个自然月**。而期货侧有 1600+ 个交易日。

**所以瓶颈在现货，不在期货。**

必须做的披露：
1. 看板顶部红色提示条：实际 n 个交易日、覆盖约几个月
2. KPI 卡「数据截至」
3. 覆盖核验表逐品种样本数
4. 样本 < 250 日（不足 1 自然年）时明确声明：
   > 尚未覆盖完整季节性周期与极端行情，分位只能说明"近 n 个交易日内处于什么位置"，
   > 不能外推为多年历史分位。

**禁止**：因为名义窗口是 3 年，就在报告里写"3 年历史分位"。

### 为什么不能回溯更长

100ppi 栏目只保留最近约 10 页文章；历史文章 ID 无规律不可枚举；站内搜索不可用。
唯一可行的长期方案是 `archive.py` **每周增量归档**，逐步累积：
```bash
python -m basis_scan.archive --codes MA,SA,V   # 每周跑一次，自动按日期合并去重
```
`scan.py` 优先读取 `data/archive/spot_{code}.csv`，没有再读 `data/raw/spot/{code}.csv`。

## 6. 单位换算

现货与期货计价单位可能不同，**必须在相减前统一**。

确定系数的优先级：
1. **源站换算式反解**（最可信）：`629/0.32-1707=258.625` → 系数 = 1/0.32 = 3.125
2. 由 `基差 + 期货 = 现货×系数` 反解，再吸附到常见整系数（1/20/80/100/1000）
3. 品种池声明的 `spot_to_fut_factor`
4. 1.0

判定系数对不对，**看交叉校验通过率**。系数错 → 通过率崩 → 回查。

已知需要换算的品种：
- 玻璃 FG：现货 元/平方米 × 80 = 元/吨（100ppi 计价习惯，非教材上的 ×20）
- 烧碱 SH：现货 32% 液碱 × 3.125 = 折百（100%）当量

## 7. 交叉校验

用源站稿自带公式做逐日比对：
```
|我方独立计算的 (现货−期货) − 源站稿基差数值| ≤ 0.05 元/吨 → 一致
```
通过率应 ≥95%。低于此值必须回查：单位系数、日期对齐、合约是否同源。

### 源站自身漂移

有时「标题里的基差」≠「正文公式算出来的基差」（实测烧碱 2026-03-09/10 两天）。
这类日子归入 `src_drift`，**如实记录、不静默修正**，因为它说明源站自身前后口径不一致。

## 8. 不可扫描品种的分类

| 类别 | 判据 | 处置 |
|---|---|---|
| 历史窗口样本不足 | 窗口内有效交易日 < `min_obs`（默认 120） | 不参与排名，写明实际 n 与缺口 |
| 口径不一致 | 现货与期货基准不可比（进口 CFR vs 国内含税等） | 不扫描，写明需要的换算条件 |
| 无逐日序列 | 现货只有零星报价 | 不扫描，写明建议数据源 |

「只覆盖 X/Y 个品种」必须明说，**不得把部分扫描包装成全市场排名**。
