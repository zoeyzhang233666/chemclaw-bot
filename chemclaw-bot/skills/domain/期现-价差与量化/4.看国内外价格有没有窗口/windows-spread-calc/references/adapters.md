# 三类典型场景的参数模板

同一个 Skill 可以覆盖几乎所有「海外报价 vs 国内现货」的比较。
差别只在**术语、运费口径、税、规格系数**四件事。下面给三类最常见场景的参数骨架。

---

## 场景 A：普通化工品，境外供应商报 FOB，买方自付海运

**特征**：液袋/ISO 罐或干散货，卖方只负责到装运港，运费波动大且是决策重点。

```jsonc
"overseas": { "term": "FOB", "region": "装运港（如鹿特丹/釜山）", "currency": "USD",
              "tax": "不含中国进口税" },
"cost_params": {
  "ocean_freight": 45.0,          // ← 必须填，这是主要变量
  "insurance_rate": 1.1,
  "insurance_rate_pct": 0.0015,   // ← FOB 需自购保险
  "discharge_fee": 12.0,
  "inland_dest": 80.0,
  "duty_rate": 0.055,             // 查税则，注意暂定税率
  "vat_rate": 0.13, "vat_credit_ratio": 1.0, "other_tax_rate": 0.0
},
"sensitivity": {
  "freight": [20, 40, 60, 90, 130],   // 运费是主矛盾，区间要宽
  "fx": [6.4, 6.6, 6.8, 7.0, 7.2],
  "matrix": { "fx": [6.5, 6.7, 6.9, 7.1], "freight": [20, 40, 60, 80, 100] }
}
```

**重点**：运费与汇率二维矩阵是这个场景最有用的图。运费每 10 USD/t ≈ 67 元/吨（汇率 6.7）。

---

## 场景 B：液态散化，卖方报 CFR/CIF 中国主港（本 Skill 的示例场景）

**特征**：船货、罐容紧张、港杂与罐租占比不低、报价已经含运保。

```jsonc
"overseas": { "term": "CIF", "region": "中国主港", "tax": "不含中国进口税" },
"cost_params": {
  "ocean_freight": 0.0,           // ← 术语已含，填 0 是口径结果
  "insurance_rate_pct": 0.0,      // ← CIF 已含保险
  "discharge_fee": 0.0,           // ← 本 Skill 未取证，进缺口
  "inland_dest": 0.0,
  "duty_rate": 0.0,
  "vat_rate": 0.13, "vat_credit_ratio": 1.0
},
"gaps": [
  { "item": "目的港卸货费未取证", "impact": "低估约 70~200 元/吨", "severity": "高" },
  { "item": "实际执行关税率待确认（最惠国 5.5% vs 暂定 0%）", "impact": "影响约 250 元/吨", "severity": "高" }
]
```

**重点**：术语含运费时，敏感性里的运费维度**只有在改用 FOB 口径后才有意义**，
报告必须在矩阵下方说清楚这一点，否则读者会误以为运费不重要。

## 场景 C：固体袋装，卖方报 CIF，需皮重折算

**特征**：25kg 袋/吨袋，毛重与净重差 0.2~1%，下游按纯品计价。

```jsonc
"meta": { "spec": "99.5% 含量，25kg 编织袋，含托盘" },
"cost_params": {
  "insurance_rate_pct": 0.0,        // CIF 已含
  "purity": 0.995,                  // ← 折纯
  "gross_weight_factor": 1.002,     // ← 毛净比
  "discharge_fee": 8.0,
  "inland_dest": 120.0,             // 袋装内陆运费高于散水
  "unload_fee": 15.0,               // 拆袋、托盘、损耗
  "duty_rate": 0.055, "vat_rate": 0.13
},
"sensitivity": {
  "price": [800, 900, 1000, 1100],
  "duty": [0, 0.02, 0.055, 0.10]    // 税率档位差异大，必须敏感
}
```

**重点**：`unit_net` 才是与国内「元/纯吨」可比的数。若国内报的是「元/实物吨」，
必须同样折纯后再比，否则会比错。

## 通用替换清单

换品种时按这张表逐项确认，不要只改价格：

| 要改的 | 在哪 | 怎么定 |
|---|---|---|
| HS 编码 | `meta.hs_code` | 海关税则，按形态/纯度归类 |
| 关税率 | `cost_params.duty_rate` | 最惠国 / 暂定 / 自贸协定，**注明用的是哪档** |
| 增值税率 | `cost_params.vat_rate` | 一般为 13% |
| 消费税/其他税 | `other_tax_rate` | 税则列明，多数为 0 |
| 单位 | `meta.unit` | 元/吨 / 元/千克 / 元/立方米 |
| 规格与纯度系数 | `meta.spec`、`purity` | 折纯基准必须与国内口径一致 |
| 国内基准地 | `meta.dom_region` | 主消费地港口/集散地 |
| 运费口径 | `term` + `ocean_freight` | 先定术语，再决定填不填 |
| 港杂规模 | `discharge_fee` | 液体罐租 > 固体堆存 |
| 内陆运距 | `inland_dest` | 港口到主要下游集群的距离 |

## 反过来用：出口视角

若你是**卖方**，想看「中国的货卖到海外划不划算」，做法完全相同，只是把
`overseas` 换成「目标市场到岸价」、`domestic` 换成「中国出厂价/内贸送到价」，
并把关税换成**目的国**的进口关税，`vat_rate` 换成目的国的增值税（如欧盟 VAT、
东南亚各国 GST），`vat_credit_ratio` 按当地能否抵扣设定。

此时结论的读法是「中国货在对方市场的价格空间」，仍不是利润——
还要扣掉目的国的清关代理费、内陆配送、渠道折扣，这些应作为 `unload_fee` 或缺口列出。
