# 贸易术语 × 费用层 对照矩阵

## 一、矩阵（● = 报价已含，○ = 报价不含）

| 费用层 | 代码键 | EXW | FCA | FOB | CFR | CIF | DAP |
|---|---|:--:|:--:|:--:|:--:|:--:|:--:|
| 货值 | `goods` | ● | ● | ● | ● | ● | ● |
| 出口国内陆运费（工厂→装运港） | `inland_origin` | ○ | ● | ● | ● | ● | ● |
| 出口报关/单证 | `export_clear` | ○ | ● | ● | ● | ● | ● |
| 国际海运费（→目的港） | `freight` | ○ | ○ | ○ | ● | ● | ● |
| 海上运输保险 | `insurance` | ○ | ○ | ○ | ○ | ● | ● |
| 目的港卸货/港杂（THC） | `discharge` | ○ | ○ | ○ | ○ | ○ | ● |
| 进口国内陆运（→收货地） | `inland_dest` | ○ | ○ | ○ | ○ | ○ | ● |

此矩阵是 `core.TERM_INCLUDES` 的直接呈现，代码与文档必须同步修改。

## 二、本 Skill 的截断位置（重要）

真实 DAP 还含进口清关与进口税费；本 Skill 只处理到「进口国境内运输」，
**关税与增值税始终由进口方承担、始终单独计算**。因此：

- 选 DAP 时，`inland_dest` 被屏蔽，关税/增值税照算；
- 若你拿到的是 DDP（完税后交货）报价，那报价里已含中国关税与增值税，
  此时**不应再算税费**——请把 `duty_rate`、`vat_rate` 设为 0，并在缺口里显式说明"DDP 一口价"。

## 三、四种高频误配

### 误配 1：CFR 报价又加运费（最常见）

```
报价：CFR 中国 685 USD/t
错误：成本 = 685×汇率 + 运费 40×汇率 + …
后果：成本虚高约 270 元/吨，把"有窗口"算成"没窗口"
```
本 Skill 处理：`inc[freight]=1` ⇒ 运费系数为 0，`check_terms` 报 `DOUBLE_COUNT_OCEAN_FREIGHT`。

### 误配 2：CIF 报价又加保险

```
报价：CIF 上海 1200 USD/t
错误：再按 0.15% 算一次保险费
后果：成本虚高约 12 元/吨（量级小，但暴露口径没理清）
```

### 误配 3：FOB 报价忘了加运费（方向相反，更危险）

```
报价：FOB 中东 600 USD/t
错误：直接当到岸价与国内比
后果：成本低估 200~400 元/吨，凭空算出"窗口"
```
本 Skill 处理：选 FOB 时运费不屏蔽，若 `ocean_freight=0` 会在参数面板与缺口里提示。

### 误配 4：CIF 报价当成"到厂价"

```
报价：CIF 中国主港
错误：直接与国内「送到厂、含税」价比
后果：漏掉港杂、内陆运费与税费，价差被系统性高估
```
正确做法：CIF → 加卸货 → 加关税/VAT → 加内陆 → 得到 landed_cash；再与含税送到价比。

## 四、快速判断口诀

> **看报价里"运到哪儿"和"保没保"，剩下的都得自己加。**

1. 报价里有没有「运输」？→ 决定是否加运费
2. 报价里有没有「保险」？→ 决定是否加保险费
3. 报价有没有过「目的港」？→ 决定是否减/加卸货费
4. 报价有没有过「中国关境」？→ 决定是否加关税与增值税

前三个「有」到哪一步，就是术语的字母位置；第四个永远是「没有」（除非 DDP）。

## 五、术语命名陷阱

| 写法 | 规范 | 说明 |
|---|---|---|
| `C&F`、`CNF` | `CFR` | 旧称，代码 `TERM_ALIASES` 自动归一 |
| `CIP`、`CPT` | 不在本 Skill 支持范围 | 适用于集装箱/多式联运；若遇到，请按 `CIF`/`CFR` 近似并**在缺口里说明** |
| `DDP` | 不在支持范围 | 见上文第二节 |
| `FOB 上海`（卖方在中国） | 逻辑上不成立 | FOB 是出口方术语；中国卖家报 FOB 给海外买家时，你看到的是**出口**口径，不是进口口径 |

## 六、卖方口头报价的识别

业务中真正拿到的常是一句话，而不是标准术语。按下面顺序问三个问题：

1. 「这个价是到港还是离港？」→ 到港 ⇒ CFR/CIF；离港 ⇒ FOB；出厂 ⇒ EXW
2. 「保险你们买还是我们买？」→ 他们 ⇒ CIF；我们 ⇒ CFR/FOB
3. 「港杂和内陆谁付？」→ 他们付到厂 ⇒ DAP；我们付 ⇒ CIF/CFR

三个答案凑齐，术语就唯一确定了。**术语不确定时，宁可把费用写成显式参数并把术语设为最低档（EXW），
也不要猜一个高包含度术语**——前者只会多算显式费用，后者会静默漏算。
