# 报告结构规范（HTML 十节）

本文件规定报告**每一节要回答什么问题、用什么图表、文案怎么写**。
目的：让不同人做出来的报告长得一样，业务方不用重新学怎么读。

---

## 全局原则

1. **一屏之内先给结论**。业务方只看第 0 节也要能拿到「现在差多少、分几个口径」。
2. **每个数字可追溯**。要么链接到来源，要么标在公式里，要么进缺口清单。
3. **不出现祈使句**。全文没有「建议」「应当」「可以考虑」「建仓」「点价」的祈使用法。
4. **图表只承载一种信息**。曲线管趋势、瀑布管构成、矩阵管稳健性，不混用。
5. **颜色语义固定**：红 = 国内更强（正价差），绿 = 进口更便宜（负价差），
   紫 = 第三方参照（国内价/隐含成本），青 = 核心序列。

---

## 第 0 节：基准时点的四层成本与四口径价差

**回答**：现在、按统一口径，海外折算成本与国内价各是多少？差怎么读？

- 上排四张卡：CIF 折人民币 / 税费现金支出 / 可抵扣进口增值税 / 可比经济成本
- 下排四张卡：G1 / G2 / G3 / G4，带正负号与颜色
- 下方一段话必须包含：
  - 「国内含税 X ÷ 折人民币 CIF Y = Z 倍」
  - 「价差结构里 N% 来自成本项（运费、保险、卸货、税、国内端），其余为商品本身的国际-国内价格差」
  - 「G1 是纯价格差，G3 才是抵扣完增值税后的经济成本差；两者相差越大，税制成分越重」

**禁止**：在这一节出现「窗口打开/关闭」「有利润」之类判断性表述。

---

## 第 1 节：交互面板

**回答**：结论对外生参数的依赖有多强？

- 三排控件：报价/国内价/汇率/术语 → 运费/保险/卸货/内陆/附加 → 关税/其他税/增值税/抵扣比例
- 改任意一格，全页重算（浏览器内 `WSC.import_cost`，与 Excel 同式）
- 术语选择器自动屏蔽已含费用，并在下方给出「口径检查通过 / 冲突」提示
- 提供「恢复基准值」与时间窗切换（近 3/6/12 月、全部）

**文案**：说明「这些参数即模型全部外生输入，改动后所有图表与表格同步重算」。

---

## 第 2 节：成本瀑布

**回答**：从美元报价到可比经济成本，钱都花在哪一步？

- 左侧横向条形清单（带累计），右侧 ECharts 累计瀑布
- 分三段：报价→CIF、CIF→含税到岸、含税到岸→经济成本
- 恒为 0 的项自动隐藏，避免视觉噪声

**读法提示**：CIF 与 landed_cash 之间的落差就是「进口环节的税费与港杂」，
landed_cash 与 net_cash 之间的落差就是「可抵扣增值税」。

---

## 第 3 节：历史价差曲线

**回答**：这个差是持续存在，还是一闪而过？

- 主图：G3 走势（带填充）、G2 虚线、G1 点线、市场隐含其余成本（次轴）
- 四张统计卡：最新、区间变化、区间最低、隐含成本均值
- 明细表：逐点日期、报价、汇率、运费、CIF、到岸、经济成本、国内价、G3、来源标记

**必须写**：曲线的数据密度（本例为离散观测，非逐日行情）与「任一时点缺一项即跳过，不插值」。

---

## 第 4 节：驱动分解

**回答**：这段时里价差变了多少，各因子各占多少？

- 逐项替换法：海外报价 / 汇率 / 运费 / 关税 / 抵扣 / 保险 / 国内价
- 表格给贡献值，图给横向条形
- 必须显示闭合残差，并声明「<1e-6 才算闭合」

**文案**：先说「哪一个是主因」，再说「其余因子互相抵消了多少」。

---

## 第 5 节：敏感性

**回答**：哪个参数最能把结论翻过来？

- 上：单参数灵敏度（每个参数独立变动，其余保持当前值），显示区间与极差
- 下：运费 × 汇率二维矩阵，单元格为该组合下的 G3 价差，颜色深浅表示幅度
- 矩阵下方必须说明：**行是运费、列是汇率**，以及当前术语是否已含运费

---

## 第 6 节：口径守卫

**回答**：这个报价里到底含了什么、还差什么？

- 左：费用层 × 是否已含 的清单（货值/出口内陆/出口报关/海运费/保险/卸货/进口内陆）
- 右：当前术语的一句话总结 + 「同一批货不能算两遍」的解释 + 全部术语的包含矩阵

---

## 第 7 节：数据口径（六要素）

**回答**：每个数字从哪来、什么规格、含税吗、哪天、谁发的？

- 表：角色 / 规格·地区·含税·数值 / 日期 / 来源与链接 / 可信度
- 海外报价要写明「原文表述」与「本报告按哪个术语处理」
- 国内价要写明「是采样加权参考价，不是成交价」

---

## 第 8 节：数据缺口

**回答**：这次结论哪里还不牢？

- 每条写成四段：缺什么 / 对结论的影响（方向 + 量级）/ 怎么补 / 严重度
- 默认展开前三条（通常是影响最大的）
- **不得写成免责套话**（见 `qa-checklist.md` 的正反例）

---

## 第 9 节：底层公式

**回答**：这些数字是怎么算出来的，我自己能复现吗？

- 表：编号 / 项目 / 公式 / 当前值 / 单位
- 公式必须与 `core.py`、Excel「公式表」一致
- 当前值随面板参数实时变化

---

## 第 10 节：边界与声明

四条底线：

1. 本报告是成本与价差的对照测算，不是交易建议；G1~G4 不等于可实现的利润。
2. 海外报价为二手引用，未取得原始报盘单、船期与供货商名称。
3. 历史曲线每行标注取值方式，凡标「假设」的行只能读作条件性结果。
4. 不含任何价格预测；所有外生参数均由面板显式给出。

---

## 文案风格

| 要 | 不要 |
|---|---|
| 「G3 为 498 元/吨，即国内含税送到价比可比经济成本高 498 元/吨」 | 「进口有 498 元/吨的利润空间」 |
| 「技术上可行」 | 「建议立即采购」 |
| 「若关税按 5.5% 计，成本上升约 250 元/吨，结论将改变」 | 「关税可能上调，需谨慎」 |
| 「该缺口使成本可能低估 70~200 元/吨，方向是真实价差更小」 | 「数据不足，仅供参考」 |
| 「海外报价缺失期间的价差无法计算，曲线在此断开」 | 「用邻近月份数据推算」 |

---

## 排版约定

- 正文字号 14px，行高 1.62；数字统一等宽字体并千分位；负号用真减号 `−`
- 单位跟在数字后，用小一号灰字
- 表头 sticky，长表可滚动，默认高度 420~520px
- 关键结论用 `note` 色块，警告用琥珀色，口径冲突用红色
- 所有链接 `target="_blank" rel="noopener"`，并显示去掉协议头的可读形式
