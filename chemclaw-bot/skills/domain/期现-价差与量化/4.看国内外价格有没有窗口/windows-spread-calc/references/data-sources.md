# 数据来源与取数口径

本文件记录「看国内外价格有没有窗口」场景下各类数据的公开来源、实际可用性、
以及踩过的坑。星级 = 本 Skill 实际验证过的可获取程度。

---

## 一、海外报价（最难的一环）

| 来源 | 可获得性 | 内容 | 备注 |
|---|---|---|---|
| **生意社「外盘XX价格一览」** | ★★★★ | 中国到岸价、船货/近洋货区分、环比 | 二手转述，离散发布（约每周 2~3 次），免费可见 |
| 隆众资讯（oilchem）美金市场 | ★★ | CFR/CFR 中国主港日报 | 正文与明细多在登录墙后，只能看到标题 |
| 我的钢铁网 mysteel `/oilchem/a/*` | ★★★ | 转述隆众的张家港/美金行情 | 正文常被截断，适合取单点 |
| 卓创 CCF | ★ | 最专业 | 基本需付费账号 |
| Platts / ICIS | ★ | 权威 | 全付费 |

**取数纪律**：
1. 先确认报价口径写的是「到岸价」还是「离岸价」。中文媒体的「中国到岸价」一律按 **CIF** 处理，
   并在报告的缺口里写明「原文未拆分 CFR 与保险」。
2. 记录**发布日期 vs 报价日期**。媒体常在 T+1 发布 T 日报价，`date` 应填报价对应日。
3. 区间报价（如 680-690）取中值，并把区间原文写进 `source` 字段。

## 二、国内现货价

| 来源 | 可获得性 | 内容 | 口径说明 |
|---|---|---|---|
| **生意社基准价**（100ppi.com） | ★★★★★ | 每日 08:30 更新的「XX基准价」 | 经销商/厂采样加权，**含税参考价**；非成交价 |
| 隆众张家港/华东日评 | ★★★ | 买盘/卖盘/基差 | 常经同花顺、我的钢铁网转述，可抓到单日买卖盘 |
| 期货交易所结算价 | ★★★★★ | 日结算价、收盘价 | **不含税**（期货报价为不含税），不能直接与现货含税价比 |
| 生意社拍卖/起拍价 | ★★★★ | 出厂价、现汇/承兑差异 | 适合校验内地出厂与港口价的价差 |
| 卓创/隆众付费终端 | ★ | 最权威 | 付费 |

**关键坑：同一时点不同来源可以差近千元。** 以乙二醇 2026-10-19 为例：

| 口径 | 数值（元/吨） | 性质 |
|---|---|---|
| 生意社基准价 | 5966.67 | 采样加权，含税参考 |
| 隆众张家港买盘/卖盘 | 5630 / 5640 | 当日市场报价 |
| EG0 期货收盘 | 4976 | 不含税，含预期 |

报告必须在首页声明用的是**哪一个**，并在缺口里写明这种差异的量级与影响方向。
**不要**在同一个报告里混用两套国内口径。

## 三、汇率

| 来源 | 接口 | 说明 |
|---|---|---|
| **欧洲央行 ECB / Frankfurter** | `https://api.frankfurter.app/<start>..<end>?from=USD&to=CNY` | 免费、无需 key、逐工作日；本 Skill 默认 |
| 中国外汇交易中心 CFETS | `https://www.chinamoney.com.cn/r/cms/www/chinamoney/data/fx/ccpr.json` | 央行中间价，每日 9:15 |
| 新浪/东方财富 | 多为页面接口 | 易变，不建议用于历史回填 |

**差异**：ECB 参考汇率与 CFETS 中间价通常相差 0.3~0.8%，对 5000 元/吨级别的商品
意味着 15~40 元/吨。报告应说明用的是哪个，并把差异计入缺口。

**历史回填纪律**：不要用「今天的汇率」算历史价差。若某日无汇率，取 7 天内最近的前值，
超期即判 gap。

## 四、海运运费

| 来源 | 可获得性 | 内容 |
|---|---|---|
| 上海航运交易所 SCFI | ★★★ | 分航线集装箱运价指数（周度） |
| 波罗的海交易所 BDI/BCTI | ★★★ | 干散货/油轮 |
| 船司/货代报盘 | ★★★★ | 最贴合实际，但需询价 |
| 行业公告 | ★★ | 涨价函、附加费通知 |

**本 Skill 的立场**：拿不到逐期运价时，**宁可把该期标为 `assumed_base` 并在缺口里写清量级**，
也不要用一个均值伪装成实测。若报价本身已是 CIF/CFR 到岸价，则运费已含、置 0 不影响结论——
但此时更要写清楚「置 0 是口径结果，不是缺数据」。

## 五、税率

| 项目 | 来源 | 注意事项 |
|---|---|---|
| HS 编码与税率 | 海关总署税则、各类 HS 查询站 | **最惠国税率 ≠ 实际执行税率** |
| 暂定税率 | 国务院关税税则委员会年度公告 | 常把某些化工品降到 0~1% |
| 自贸协定税率 | 原产地规则 | RCEP/东盟等，需原产地证 |
| 反倾销/反补贴 | 商务部公告 | 会按厂商、税率档次分列 |
| 增值税 | 财政部/税务总局 | 化工品一般 13%，原油/农产品等有差异 |
| 消费税 | 税则列明 | 多数化工品为 0 |

**纪律**：查到的税率必须标注「这是哪一档」。若实际执行税率无法确认，
默认值取保守（较高）或 0 并在缺口里列出敏感性（本 Skill 的「口径 E」情景就是为此设计）。

## 六、交叉验证数据（不进入成本计算，只用于校验口径合理性）

- **期货主力合约日线**：新浪 `InnerFuturesNewService.getDailyKLine`，免费可用。
  用于看「现货-期货基差」是否与你的国内价口径自洽。
- **港口库存**：东财/生意社/隆众周报，用于解释价差变动的供需侧背景。
- **开工率、检修计划**：同上。

**用法**：如果算出来的成本与国内价差异远超价格波动区间，先怀疑数据口径，
而不是相信「窗口出现了」——这是本 Skill 反复强调的。

## 七、接口可用性实测记录（2026-10 验证）

| 接口 | 状态 | 备注 |
|---|---|---|
| 新浪期货 JSONP | ✔ 可用 | 需带 UA，返回 JS 包裹，去掉前缀后解析 |
| Frankfurter (ECB) | ✔ 可用 | JSON，无 key |
| chinamoney CCETS | ✔ 可用 | 返回 JSON，字段名会变，需容错 |
| **东财行情 API** | ✘ 被拦截 | 返回空或 403 |
| **Yahoo Finance** | ✘ 被拦截 | 需要 crumb，常超时 |
| 100ppi 商品页 | ✔ 可用 | 需带浏览器 UA + `Referer`；偶发 SSL EOF，需重试 |
| 100ppi 新闻列表分页 | ✔ 可用 | 按日期分页，越界页码会回落到最新页（注意去重） |
| mysteel /oilchem/a/* | ✔ 部分 | 正文可能截断，适合取单点 |
| 隆众 oilchem 正文 | ✘ 登录墙 | 只能取标题 |
| 同花顺 news | ✔ 可用 | 转述隆众内容，可作为交叉验证 |

**抓取通用纪律**：带浏览器 UA、带 Referer、失败重试 3~4 次、间隔 ≥0.3 秒；
分页抓取必须做「页码越界回落检测」，否则会重复抓同一页并误判为已覆盖。
