# 04 产业面数据源与可信度分级

异常月差只说明"价格结构不对劲"，**为什么不对劲要靠产业面回答**。
本技能要求每个产业面数字都带 **日期 + 单位 + 来源 + 可信度**。

## 1. 可信度分级（强制）

| 级别 | 定义 | 使用方式 |
|---|---|---|
| **A** | 交易所/官方统计原文，抓取到正文，日期明确 | 可直接引用 |
| **B** | 专业资讯机构或媒体报道转述，未获原始文件 | 可引用，须标 B |
| **C** | 口径不明、数值区间模糊、或来源未说明统计方法 | 仅作背景，不作结论依据 |
| **D** | 仅听说、无任何可引用出处 | **不写入报告**，一律留空 |

报告与工作簿里，每一行产业面数据都必须显示级别。**缺数据写"未获取"，不估算。**

## 2. 仓单（优先级最高的产业面指标）

仓单是可交割资源的直接计量，对近月月差解释力最强。

| 品种 | 来源 | 抓取地址 | 级别 |
|---|---|---|---|
| MA / SA / TA | 郑商所仓单日报 | `http://www.czce.com.cn/cn/DFSStaticFiles/Future/{YYYY}/{YYYYMMDD}/FutureDataWhsheet.txt` | A |
| PP | 大商所（官网对脚本返回 HTTP 412） | 退化为媒体转述 | B |

解析要点：

- 文件按"品种："分段，每段末尾有"总计"行
- 表头含 `每张仓单= N 手合约 * M 吨/手`，据此把"张"换算成"吨"
- 郑商所三种品种的单位不同：MA 10 吨/张，SA 20 吨/张，TA 5 吨/张
- 大商所 PP 用"手"计，1 手 = 5 吨
- 注意区分**注册仓单**与**有效预报**（后者是待注册，不等同可用资源）

> 实例警示：PTA 仓单 10-08 约 1,002 张 → 10-09 骤增至约 36,187 张（约 35 倍），
> 抓取到的页面均未解释原因。这种情况**只记录事实、标 C，不作"大幅累库"的结论**。

## 3. 库存

常用口径（**不同机构口径不可混算**）：

| 品种 | 常见口径 | 机构 |
|---|---|---|
| MA | 中国沿海港口库存 / 港口社会库存 | 隆众、卓创、金联创 |
| SA | 厂家总库存（分轻碱/重碱） | 隆众、卓创 |
| PP | 商业库存、两油石化库存 | 隆众 |
| TA | 社会库存 | 隆众、CCF |

> 实例警示：甲醇港口库存同时存在隆众 30.51 万吨（10-08）、卓创 37.41 万吨（10-08）、
> 金联创 30.44 万吨（10-15）三个数。**不能拿 A 机构的上期与 B 机构的本期算环比。**

## 4. 现货与基差

- 现货价必须写清：**地区 + 品级/规格 + 提货方式（自提/送到）+ 含税与否**
  - 例："沙河重碱自提 951 元/吨"、"太仓甲醇 3,965 元/吨"、"华东拉丝 10,775 元/吨"
- 基差 = 现货 − 近月期货。若给基差，必须说明用的是哪个现货与哪个合约
- 现货口径不明确时降级为 C

## 5. 供需事件（解释期限结构的关键）

重点追踪这六类，因为它们直接影响"近端紧还是远端松"：

| 类别 | 为什么影响期限结构 | 影响哪一端 |
|---|---|---|
| 新增产能投产 | 未来供应增加 | 压远月（远月贴水加深） |
| 装置检修/停车 | 当前供应减少 | 抬近月 |
| 进口受阻 / 物流中断 | 近端可交割资源骤减 | 抬近月，近月升水扩大 |
| 下游负反馈 / 减产 | 需求走弱 | 压近月 |
| 旺季/补库 | 短期需求集中 | 抬近月 |
| 成本端（煤、原油、石脑油） | 抬升成本曲线 | 抬远月（远月有成本支撑） |

事件记录格式：

```json
{"date": "2026-10-14", "event": "华东300万吨PTA装置按计划检修",
 "impact": "阶段性供应收缩", "direction": "bullish_near"}
```

`direction` 取值：`bullish_near` / `bearish_near` / `bearish_far` / `bullish` / `bearish` / `bullish_cost`。

> **事件只用来解释"为什么这个月差在这里"，不用来预测方向。**
> 事件与月差方向一致 ≠ 可以交易 —— 市场可能已经定价，也可能有反向力量。

## 6. 可用的公开数据入口

| 数据 | 地址 | 备注 |
|---|---|---|
| 郑商所每日行情 | `czce.com.cn/cn/DFSStaticFiles/Future/{Y}/{YMD}/FutureDataDaily.txt` | 结算价，管道分隔 |
| 郑商所仓单日报 | 同上目录 `FutureDataWhsheet.txt` | 含每张仓单吨数 |
| 逐合约日线 | 新浪财经 `InnerFuturesNewService.getDailyKLine` | 含 settle 列 |
| 大商所行情 | `futsseapi.eastmoney.com/list/114` | 官网 412，走东财；只有最新价 |

`list/{mkt}` 编号：113 = 上期所，114 = 大商所，115 = 郑商所。

## 7. 抓取纪律

- 每次抓取**记录 URL 与抓取时间**，写进 JSON 的 `source` / `url` 字段
- 同一指标多来源时**全部保留**，在 `note` 里说明差异与取舍理由
- 抓不到就写 `未获取`，**不允许用相邻日期或别的机构数据顶替**
- 数字与文字分离存储，便于后续公式引用
