# 01 方法说明

## 1. 月差定义

```
月差 spread = P_near − P_far
```

- `P_near`：近月合约价格；`P_far`：远月合约价格；单位均为元/吨
- 硬性要求：`far` 的交割月必须晚于 `near`，否则判 `ORDER_REVERSED` 拒绝
- **正值**：近月比远月贵 → 近月升水 / 正向市场（contango）
- **负值**：近月比远月便宜 → 近月贴水 / 反向市场（backwardation）

> 为什么规定"近月减远月"而不是反过来：这样正号永远指向同一个经济含义
> （现货紧张、近端挤升水），跨品种、跨组合讨论时不会符号错乱。

### 价格口径

| 品种 | 交易所 | 口径 | 来源 |
|---|---|---|---|
| MA 甲醇 | 郑商所 | `settle` 结算价 | 交易所每日行情文件 |
| SA 纯碱 | 郑商所 | `settle` 结算价 | 交易所每日行情文件 |
| TA PTA | 郑商所 | `settle` 结算价 | 交易所每日行情文件 |
| PP 聚丙烯 | 大商所 | `last` 最新价 | 东方财富（大商所官网对脚本返回 412） |

结算价是当日加权均价，比收盘价更抗尾盘异动，所以优先。
PP 拿不到结算价，只能用最新价 —— **这是口径差异，必须在所有输出里标注，且不得与结算价口径混算**。

## 2. 为什么必须逐合约取价

主力连续合约在换月日会发生价格跳空，这个跳空是**合约拼接的产物，不是市场变化**。
用它算月差会把换月噪音当成真实价差波动，污染整个历史分布。

本技能一律从逐合约日线读取，只在同一天、同一对合约都存在有效报价时才产生一个观测点。

### 无效观测的判定

以下任一情况，该交易日直接跳过，**不插值、不向前填充**：

- 结算价为空 或 等于 0
- 结算价缺失（部分品种部分日期只披露收盘）
- 成交量 = 0 **且** 持仓量 = 0（说明当日无成交挂牌，价格不具意义）

## 3. 可比历史样本 —— 本方法的核心

### 3.1 为什么必须"同组合同期限"

"SA 1–5 月差现在 −64，算不算极端？"这个问题只有在下述意义上才有答案：
**过去几年，在同样还有 3 个月就要交割、同样是 1 月对 5 月的时刻，这个价差是多少？**

如果拿 SA 5–9 的历史来比，比的是不同的交割季节性；
如果拿"任意剩余期限"的 SA 1–5 来比，比的是不同时间距离，价差天然随剩余期限衰减。

所以样本必须同时钉住三个维度：

| 维度 | 对齐方式 |
|---|---|
| 品种 | 相同 |
| (近月, 远月) 月份组合 | 完全相同 |
| 剩余期限 | 同一整周数 `floor((近月交割月结束日 − 观测日).days / 7)` |

### 3.2 每个历史年份只取 1 个样本

**这是修复过的一个严重错误，务必理解。**

早期实现用的是"±2 周窗口"：在当前剩余期限附近取前后各 2 周的日度观测。
看起来每年取了很多点，样本量 N 从 5 涨到 57，似乎更"稳"。

但它错在：**这 20 个日度点几乎全部自相关** ——
相邻交易日的月差变化只有几元，彼此高度依赖。
把它们当独立样本，等于把同一条信息数了 20 遍，导致：

- 标准差被严重低估 → Z 分数虚高（出现过 Z = 8.4 的荒谬值）
- 分位被压缩到中间 → 真正的极端值反而显示成 80 分位

**正确做法：每个历史年度只贡献 1 个样本**，N = 可比年度数量（本技能上限 5）。

修正后同一组合的对照：

| 组合 | 修正前 N | 修正后 N | 修正前分位 | 修正后分位 |
|---|---|---|---|---|
| SA2701-SA2705 | 57 | 5 | 失真偏向中位 | 40.0 |
| PP2701-PP2705 | 57 | 5 | 失真 | 100.0 |

### 3.3 样本不足时的处理

N < `min_n`（默认 3）时：**不给分位、不给 Z、不给评级**，只报当前月差并标注"样本不足"。

典型样本不足情形：
- 跨年度长组合（如 2611−2705，跨度 6 个月以上、跨交割年度）—— 历史年份根本不存在同结构的合约对
- 新品种上市不足 3 年
- 挂牌深度不足，历史上该月份从未同时有双边有效报价

**不要为了让 N 变大而放宽剩余期限窗口。** 放宽窗口换来的是虚假样本量。

## 4. 分位、Z 分数与极端度

```
分位 percentile = ( #{样本 < 当前} + 0.5 × #{样本 == 当前} ) / N × 100
Z 分数          = (当前 − 样本均值) / 样本标准差 (n−1)
极端度            = |分位 − 50| × 2
```

- 分位用 `+0.5×等于` 是为了处理并列值，避免虚高或虚低
- 极端度把"离中位多远"线性映射到 0–100，**两端等价**：
  分位 100%（近月远贵于历史）与分位 0%（近月远便宜于历史）都是极端度 100
- 同时输出 q05/q25/q50/q75/q95 与 min/max，方便看分布形状而不只看一个数

### 评级阈值（默认）

| 条件 | 评级 |
|---|---|
| 分位 ≥ 95% | 极端（近月升水） |
| 分位 ≥ 80% | 偏高（近月升水） |
| 20% < 分位 < 80% | 正常 |
| 分位 ≤ 20% | 偏低（近月贴水） |
| 分位 ≤ 5% | 极端（近月贴水） |
| N < min_n | 样本不足 |

扫描排序另有提醒线 10/90，分位落在该区间外即视为"值得看一眼"。

## 5. 近 1 个月变化

```
change_1m = 当前月差 − 30 个自然日前最近一个有效交易日的月差
```

用"最近一个有效交易日"而非严格 30 天前，是为了避开非交易日与停牌日。
该值为空表示 30 天前该组合无有效双边报价。

## 6. 期限结构形态：为什么用 OLS 斜率

判定 contango / backwardation，两种做法：

- ❌ **端点相减**（末月价 − 首月价）：只要曲线中段有个跳变就会误判。
  实测把 SA（明显逐月递增）判成 contango 的错误就来自这里。
- ✅ **OLS 斜率**（价格 ~ 距交割月数）：对整条曲线做回归，抗单点扰动。

```
斜率 = SLOPE(结算价序列, 距交割月数序列)
斜率 < −3 元/月 → 正向市场 contango
斜率 > +3 元/月 → 反向市场 backwardation
否则平坦
```
另附单调性相关系数 `r`，接近 ±1 说明曲线单调整齐，接近 0 说明曲线扭曲。

## 7. 扫描范围

- 排除最前 2 个交割月（临近交割，报价受单边交割逻辑扭曲，且历史无可比样本）
- 组合间隔上限 `max_gap`（默认 6 个月）：跨度太远的两腿用同剩余期限口径构造不出可比样本
- 流动性下限 `min_oi`（默认 500 手）：任一条腿持仓低于此值标 `ILLIQUID` 提醒

## 8. 已知局限（必须随报告披露）

1. 历史合约仅覆盖近 5 个年度，N 上限为 5，分位的分辨率有限（5 个样本只能表达 10/30/50/70/90 这几个位置）
2. 月差未扣除仓储费、资金成本、交割费用、品级与地区升贴水
3. 不同品种月差的绝对元数不可直接横比（交易单位、价格水平不同），**可比的是分位**
4. PP 价格口径为最新价，与 CZCE 结算价口径存在细微差异
5. 交易所规则中的保证金分级、限仓额度以交易所最新公告为准，本技能给出的是最低档
