# 05 交付检查表

交付前逐项打勾。任一项未过，不要发出去。

## A. 数据真实性

- [ ] 所有价格都来自当日抓取的原始文件，不是记忆或估算
- [ ] 逐合约日线覆盖了要扫描的每个合约（`data/raw/` 有对应 csv）
- [ ] 结算价为 0 / 空、成交与持仓同时为 0 的交易日已被剔除
- [ ] 没有插值、没有向前填充、没有用主力连续合约
- [ ] 行情与逐合约日线交叉核对通过（口径内 0 不一致）
- [ ] 产业面每个数字都有日期 + 单位 + 来源 + 可信度
- [ ] 缺数据的地方写的是"未获取"，没有编数

## B. 可比性（最容易出错的地方）

- [ ] **每个月份组合有自己的分布**，没有和别的组合合并
- [ ] 历史样本钉住了：同品种 + 同(近月,远月) + 同剩余期限整周数
- [ ] **每个历史年份只贡献 1 个样本**，N = 独立年度数
- [ ] N < 3 的组合标"样本不足"，**没有算出分位**
- [ ] 当年合约没有被算进历史样本
- [ ] 不同机构口径的库存没有互相算环比
- [ ] PP（最新价）与 CZCE（结算价）口径已标注且不混算

## C. 口径与定义

- [ ] 月差 = 近月 − 远月，符号方向一致（正 = 近月升水）
- [ ] 远月确实晚于近月，倒序组合已被拦截
- [ ] 期限结构形态用 OLS 斜率判定，不是端点相减
- [ ] 排除了最前两个交割月
- [ ] 分位公式含并列值处理 `+0.5×等于`
- [ ] 极端度 = |分位−50|×2，两端等价

## D. 红线（必须出现在成品里）

- [ ] HTML 与 Excel 都写明了"不构成跨期套利/交易建议"
- [ ] 明确说明月差未扣仓储费、资金成本、交割成本、品级与地区升贴水
- [ ] 没有把"分位高/低"翻译成"买/卖"
- [ ] 没有把跨品种月差绝对元数直接横比（比的是分位）
- [ ] 异常未解释的事项（如 PTA 仓单跳升）只记事实、不下结论
