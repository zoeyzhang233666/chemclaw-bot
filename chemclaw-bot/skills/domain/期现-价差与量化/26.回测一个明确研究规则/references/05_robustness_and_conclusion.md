# 05 · 敏感性、样本外与结论分级

## 为什么不能"找最好的参数"

如果你试了 21 组参数，挑出收益最高的那组报告，你实际上做了 21 次假设检验但不做多重校正。在纯噪声上试 21 次，期望也有 1 组表现显著为正。

**本技能禁止这样做。** 正确流程：

1. 在**运行前**把网格写进规格文件（`analysis.sensitivity`）。
2. 跑**全部**变体，包括亏损的。
3. 报告基准的**排名**、中位数、正收益占比。
4. 结论必须能经受"相邻参数同向"的检验。

## 网格设计原则

| 原则 | 做法 | 反例 |
|---|---|---|
| 窄幅 | 参数只在其经济含义允许的范围内小幅变化 | 库存阈值从 0 试到 100 万吨 |
| 单一维度为主 | 一次只变一个参数，做 1-D 扫描 | 21 个参数全组合（组合爆炸） |
| 预设 2-D 角落 | 挑两个最相关的参数做交叉，检验交互 | 事后挑最相关的两个 |
| 基准必须在网格里 | `base` 变体使用原始参数 | 只报最好的 |

示例网格（21 个变体）：

- 连降周数：2, 3（基准 2）
- 通道窗口 n：2, 3, 4（基准 2）
- 通道阈值：0.0, 0.25, 0.5 万吨（基准 0.0）
- 持有期：5, 10, 15 个交易日（基准 10）
- 基差分位：0.7, 0.8, 0.9（基准 0.8）
- 2-D 角落：连降周数 × 基差分位（2×3 = 6 组，其中 1 组与 base 重合）

## 怎么读敏感性表

| 现象 | 解读 |
|---|---|
| 多数变体收益同向且量级接近 | 稳健 |
| 收益符号随参数翻转 | 不稳定，很可能是噪声 |
| 只有基准点为正，相邻点全负 | 过拟合，不可用 |
| 基准排名靠中间 | 好迹象（说明基准不是被挑出来的） |
| 基准排名第 1 | 可疑——检查是否有隐含的选择偏差 |

引擎输出字段：`share_positive_return`（正收益变体占比）、`median_return`、`base_return_rank`、`spread_return`（最优−最差）。

## 样本外设计

**切分点必须在看结果前定。** 写进 `analysis.oos.split_date`。

常见错误：

- 看到样本外表现差，回头调整切分点 → 样本外变样本内。
- 用样本外结果反复调参 → 同样的问题。
- 只报告样本内 → 明显偏袒。

本技能强制报告三个数：

| 指标 | 样本内 | 样本外 |
|---|---|---|
| 笔数 | | |
| 累计收益 | | |
| 最大回撤 / 胜率 / PF | | |

**只要样本外笔数 < 5，就不能声称规则在样本外有效。** 正确表述是"样本外样本不足以判断"。

## 稳健性检验（三件套）

### 1. 块自助重抽样

把每笔交易的净盈亏做一个 block bootstrap（默认块长 3，2000 次），得到"平均每笔盈利 > 0"的概率。

- `p_positive ≥ 0.95` 才有统计意义
- `p_positive 0.7–0.9` → 弱证据
- `p_positive < 0.7` → 不成立

### 2. 单一年份主导

若是某一年贡献了全部利润（`share > 100%` 意味着其他年份合计为负），那么结论完全依赖那一年。

### 3. 逐年剔除

依次去掉每一年，看剩余净盈亏是否仍为正。若去掉某一年后大幅转负 → 结论由该年单独支撑。

## 结论分级（强制使用）

| 等级 | 措辞 | 条件（全部满足） |
|---|---|---|
| **A 稳健** | "在该样本内，规则在多数相邻参数下同向，样本外未失效" | 网格 >60% 变体同向；样本外同向；无单一年份贡献 >60%；p_positive ≥ 0.9 |
| **B 弱证据** | "方向一致但样本不足，不足以支持结论" | 笔数 < 30，或 p_positive < 0.8 |
| **C 不成立** | "在该样本内未表现出稳定优势" | 网格多数反向，或样本外反向 |
| **D 数据不足** | "数据缺口导致无法判断" | 可核验样本覆盖不足（strict 模式笔数 < 10） |

**默认落点是 B 或 D。** 周频指标 + 10 日持有 + 数年样本，天然只有十几到几十笔。诚实地说"证据不足"比编造一个 A 级结论更有价值。

## 报告模板

```
结论：C 不成立（或 B 弱证据 / D 数据不足）

样本：<起始> 至 <结束>，<N> 笔完整交易
参数敏感性：<M> 个变体，<x>% 为正，基准排名 <r>/<M>，中位收益 <v>
样本外：<n_out> 笔，累计收益 <v_out>
块自助：P(均值>0) = <p>
单年主导：<year> 贡献 <s>%

判断：基于以上，<结论等级与措辞>。不构成未来收益保证。
```
