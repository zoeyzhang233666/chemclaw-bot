# 06 · 常见错误案例

> 每条都附"错在哪 / 后果多大 / 怎么发现 / 怎么改"。这些都是在真实区域价差研究里踩过的坑。

---

## 错误 1 · 出厂价减送到价

```python
spread = exw_shandong(1300) - delivered_hebei(1375)   # = -75
```

**错在哪**：两个数不是同一个位置的价格。一个货在厂里，一个货已到厂。

**后果**：−75 里至少有一半是运费，不是价差。若内运费 96 元/吨，真实价差可能只有 +21。

**怎么发现**：看报价口径表——两个地区的 `quote_basis` 不一致，但 `total_steps = 0`。
这是矛盾信号：口径不同却没有换算步骤，说明**换算被漏了**。

**怎么改**：统一口径。要么都换到送到（需要产地运费），要么都换到出厂（需要目的地的内含运费）。
内含运费未知 → **不比较**。

---

## 错误 2 · 从送到价里再扣一遍运费

```python
ref = delivered_hebei(1275) - (delivered_shandong(1370) + freight(96))
```

**错在哪**：送到价里**已经含运费**（重碱除西北以外地区采用送到价）。
再扣一遍 = 重复扣减。

**后果**：凭空让目的地看起来便宜 96 元/吨，可能把"未覆盖"算成"覆盖"。

**怎么发现**：`freight_embedded_in_price = true` 但同时在用 `freight_adjusted_spread`。

**怎么改**：送到价口径下，裸价差本身就是"到货后差多少"。
运费调整只在**出厂价口径**或做物流可行性核对时才有意义。报告里必须写这句话。

---

## 错误 3 · 用市场运费替代"内含运费"

```python
exw = delivered(1375) - market_freight(96)     # 假的反推出厂价
```

**错在哪**：`内含运费`（卖方报价里打包的）≠ `市场运费`（你查到或问到的一口价）。
卖方可能是长协价、可能有回程车、可能就在隔壁 40 公里。

**后果**：反推出的"出厂价"是假数，再拿它做任何比较都错。

**怎么改**：`货运内含运费` 未知时标 `missing`，不换算。要出厂价就去拿出厂价报价。

---

## 错误 4 · 缺失填 0

```python
df["price"] = df["price"].fillna(0)
```

**错在哪**：0 不是"没有"，0 是一个极端观测。

**后果**：
- 价差从"空"变成 −1300
- 均值被拖低几百
- 分位全乱（0 变成历史最低点）
- 异常阶段识别产出大量假信号

**怎么发现**：价差序列里出现远超价格量级的数字；图上出现垂直跳崖。

**怎么改**：一律 `None`。Excel 留空。CSS 图上 `connectNulls: false`。

---

## 错误 5 · 插值填缺口

```python
df["price"] = df["price"].interpolate()
```

**错在哪**：插出来的点不是观测值。

**后果**：
- 分位被平滑，尾部变薄 → 真正的异常看起来"不算异常"
- N 虚高（看起来 156 期，实际只有 152 期）
- 异常阶段被"拉直"，识别不出

**怎么改**：剔除缺口，记入 `dropped`，并在报告里列出具体日期。
样本变少是**诚实的代价**。

## 错误 6 · 用 PERCENTRANK 算并列值

```excel
=PERCENTRANK(range, v)      ← 并列取最小秩
```

**错在哪**：价差有大量重复值（整数报价、缺口前后持平）。最小秩会系统性偏低。

例：S = [10, 20, 20, 30]，v = 20
- `PERCENTRANK` → 25%
- 正确（中秩）→ 50%

**后果**：所有分位偏低，`P91` 被算成 `P88`，本来"历史高位"的价差被判定为"偏高但不极端"。

**怎么改**：
```excel
=(COUNTIF(r,"<"&v) + 0.5*COUNTIF(r,v)) / COUNT(r) * 100
```

## 错误 7 · 把"覆盖运费"说成"套利机会" ★最严重

```
价差 110，运费 85，净赚 25 → 有套利空间！
```

**错在哪**：只算了运费，漏掉了至少 6 项成本，而且忽略了批量对价格本身的反作用。

未计入：
- 资金占用与利息（吨价 × 账期天数 × 资金成本率 / 365）
- 运输损耗
- 账期与承兑贴息
- 卸货地短驳
- 仓储
- 开票与结算风险
- **可成交批量**：沙河月用纯碱约 9 万吨。一次调 5000 吨进沙河，会直接压低沙河价格，价差自己消失。

**后果**：客户按这个建议下单，亏钱。

**怎么改**：只写「价差覆盖了承运成本」，并列出未计入项。**永远不写"套利机会"**。

## 错误 8 · 省级产能凑数

```
山东纯碱产能约 600 万吨（估算）
```

**错在哪**：省级产能合计在公开源里【未查到】权威发布。600 是凑出来的。

**后果**：用它算区域份额、算自给率、算调入调出，全是错的。而读者无法分辨。

**怎么改**：只给**企业级已核实产能**并明确"这是已核实企业加总，不是统计口径产能"。

```
山东：可核实产能 430 万吨（山东海化 280 氨碱 + 山东海天 150 氨碱）。
省级合计未查到权威发布——宁缺不假。
```

## 错误 9 · 相关当因果

```
河北碱多，所以河北便宜。
```

**错在哪**：
1. 事实可能相反——江苏可核实产能 570 万吨 > 山东 430 > 河北 340，但江苏价格最贵（1385）。
2. 产能 ≠ 供给（开工率、检修、库存才是）。
3. 价格差异的主因可能是运输半径与下游结构，不是产能绝对量。

**怎么改**：
```
山东 1370、河北 1275、江苏 1385。三地可核实企业产能分别为 430 / 340 / 570 万吨，
产能规模与价格水平不是单调关系——河北产能最低但价格居中，江苏产能最高但价格最高。
区域价差的形成需要结合开工率、库存、下游结构与物流半径，本报告未做因果检验。
```

## 错误 10 · 月份对不齐

```
用"2025-06-02 发布"的数据当作 2025-06-02 的报价
```

**错在哪**：很多机构是"周一发布上周数据"。发布日 ≠ 数据所属期。

**后果**：如果另一个地区是当日报价，价差里混进了 1 周的时间差。在快速波动期（如 2025-06 纯碱急跌），
一周 50–100 元/吨的差异会完全盖过真实空间价差。

**怎么改**：按**数据实际所属期**配对。周度数据用 ISO 周对齐（周五锚）。
换机构 = 口径断点，要在 `note` 里标出。

---

## 错误 11 · 地域归属搞错

```
中盐昆山位于山东（❌ 实际在江苏昆山）
```

**错在哪**：企业名称里的地名 ≠ 实际厂址。

**后果**：产能加错省，区域结论全歪。

**怎么改**：每个企业都核一遍厂址。本 Skill 的企业表里 `city` 字段就是为这个准备的。

---

## 错误 12 · 用「全国基准价」代替区域价

```
山东 = 河北 = 江苏 = 生意社全国重碱基准价 1225.71
```

**错在哪**：全国基准价是三地价格的加权平均，不是任何一个地区的价格。

**后果**：三个"地区"价格完全一样，价差恒为 0。这显然不对，但很容易在大意时发生。

**怎么发现**：价差序列标准差 ≈ 0，或者三个地区序列完全相同。

**怎么改**：区域价必须来自区域源。没有就标 DEMO 或标缺口。

---

## 错误 13 · 异常阶段方向说反

```
[河北−江苏 走阔] → "河北价格走强"      ← 未核实
```

**错在哪**：`spread(HB, JS)` 走阔，可能是河北涨，也可能是江苏跌，或两者皆有。

**怎么改**：看 `region_snapshots` 里各地区的 `change_vs_prior_yr`，再下结论。

```
河北−江苏 价差由 −78 走阔至 −45（走阔 +33）。
河北阶段均价 +92，江苏阶段均价 +124 —— 江苏涨得更多，
所以是江苏相对河北走强，不是河北走弱。
```

## 快速自检表

| 症状 | 可能的错误 |
|---|---|
| 价差有极端异常值（±1000+） | 错误 4（缺失填 0） |
| 三个地区序列完全一致 | 错误 12（用了全国价） |
| `total_steps = 0` 但口径不同 | 错误 1（漏换算） |
| 分位普遍偏低 | 错误 6（最小秩） |
| 几乎所有周都是"异常" | 错误 5（插值平滑）或阈值太松 |
| N 比预期多 | 错误 5（插值补了缺口） |
| 覆盖运费的方向特别多 | 错误 2（重复扣减）或错误 3（假出厂价） |
| 产能加起来对不上全国 | 错误 11（地域归属） |
