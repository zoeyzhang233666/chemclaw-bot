# 01 · 方法说明

## 为什么区域价差不能"直接相减"

三个地区的报价名字都叫"重质纯碱价格"，但实际含义常常不同：

- 山东某厂的**出厂价** 1300，河北某市场的**送到价** 1375。相减得 −75。
  这个 −75 **没有任何经济含义**：一个是货还在厂里，一个是货已经送到。
- 一个报**含税**，一个报**不含税**。相减会凭空多出 13%。
- 一个报**承兑价**，一个报**现汇价**。相减多出贴息。
- 一个报**上周三**的价，一个报**本周一**的价。相减是时间错配，不是空间价差。

所以第一步永远不是"取数相减"，而是**把三个报价放到同一把尺子上**。

## 四层结论，逐层可追溯

```
层 1  可比性      规格 / 税率 / 计量 / 交付 / 付款 / 时点   → 换算到同一口径（或明确标不可比）
  ↓
层 2  裸价差      spread(a,b) = P(a) − P(b)                 → 只是价格差，不含任何成本
  ↓
层 3  运输成本    里程 × 方式 × 单价 + 装卸短驳               → 物理搬运的代价
  ↓
层 4  扣费后差异  P(目的) − (P(产地) + 综合运费)             → 是否覆盖承运成本（≠ 套利）
```

**四层必须分开呈现。** 把它们合成一句"价差 95，扣完运费还能赚 20，有套利空间"是本领域最常见的重大错误：
第 2 层的数字（95）本身可能就是口径不一致的产物；第 4 层正数也不等于机会。

## 为什么主口径选「送到价」

对纯碱，行业报价规范是这样的（期货日报，2019-12-01，S1）：

> 轻碱统一采用出厂价；**重碱除西北以外的地区采用送到价**，西北地区采用出厂价。

这带来一个直接后果：**山东、河北、江苏的重碱报价里，运费已经含在里面了。** 三个报价天然同口径。

所以本 Skill 的默认设计是：

| 口径 | 角色 | 用途 |
|---|---|---|
| 送到价 delivered | **主口径** | 直接可比，价差即"到货后差多少" |
| 出厂价 exw | **对照口径** | 把运费显性化，做物流可行性核对 |

并且必须在报告里提示：**送到价口径下，不要再拿整段运费去扣一次**——那是重复扣减。

如果用户只拿到出厂价（或产品本身没有"送到价"惯例，比如很多液体化学品按厂提报价），
把主口径切成 `exw`，此时第 3、4 层才是必需的。

## 为什么缺口剔除而不是插值

周度数据总会有停报：

- 春节前后一周不报价
- 某地区装置检修期该机构停止采样
- 数据源改版导致某几周缺失

三种处理方式，结果完全不同：

| 处理 | 后果 | 本 Skill |
|---|---|---|
| 前向填充 | 价差被"冻住"，异常阶段的 z 值被稀释，识别不出 | ✗ |
| 线性插值 | 分位被平滑，尾部变薄，N 虚高 | ✗ |
| **剔除** | 可用周数变少，N 变少 | ✓ |

剔除的代价是**样本变少**，但换来的是**每个留下来的点都是真实的**。
所以报告里必须有一张"对齐质量"表：每个地区进入样本多少周、剔除多少周、剔除的是哪些日期。

特别注意：**不同口径的缺口不同**，所以送到价口径可能是 152 期、出厂价口径是 154 期。
这不是 bug，是正确行为——它在提醒你两个口径的信息量本来就不一样。

## 为什么要算全部有序对

三个地区，两两组合是 3 个，但**有序对是 6 个**：

```
SD−HB = +95      HB−SD = −95
SD−JS = −15      JS−SD = +15
HB−JS = −110     JS−HB = +110
```

只算无序对会丢掉两件事：

1. **方向**。"价差 95"不说是谁减谁，读者无法判断谁贵。
2. **自检**。`M[i][j] = −M[j][i]` 是一个硬约束，任何违反都说明配对逻辑有 bug。
   本 Skill 的矩阵表里有一列"等价校验"，必须全部打 ✓。

## 为什么用经验分位而不是正态分位

价差分布通常是**厚尾 + 有偏**的：装置事件会让价差在几周内冲到极端值，然后又慢慢回来。
用正态假设（比如"±2σ 之外算异常"）会有两个问题：

- 把正常的厚尾当成异常
- 把真正的异常当成"不太可能"

所以本 Skill 一律用**经验分布（ECDF）**：直接数"历史上有多少比例的周，价差比现在更小"。
不假设任何分布形状。

**并列值必须用中秩**：如果 20 个周里价差都一样是 50，那"50 的分位"应该是这 20 个点的中位位置，
而不是最前面那个位置。`(#{x<v} + 0.5·#{x=v}) / N` 就是中秩。
Excel 的 `PERCENTRANK` 用的是最小秩，会系统性偏低——所以工作簿里用 `COUNTIF` 手写。

## 异常价差阶段怎么定

```
z_t = (spread_t − mean(spread_{t−52..t})) / sd(spread_{t−52..t})
异常阶段 = 连续 ≥3 周 |z| ≥ 1.0
```

三个参数的选择理由：

- **滚动 52 周基准**：价差的"正常水平"本身会漂移（产能扩张、需求结构变化），用全样本均值会把
  2023 年的高波动和 2025 年的低波动混在一起。
- **|z| ≥ 1.0**：不是 2.0。因为周度价差噪音大，2.0 会漏掉大量有产业意义的阶段；1.0 配合"连续 3 周"
  可以把单周噪音滤掉。
- **连续 ≥3 周**：单周冲高通常是报价节奏（某机构晚发一天），不是真实供需变化。

识别出来后，**每一段都要能点开看**：该阶段三地区的价格快照、同期事件、经济链条。

## 事件怎么挂上去

事件库只收**可核对**的事件，字段固定：

```json
{
  "id": "E05",
  "date": "2025-05-18",
  "end": null,
  "kind": "产能",
  "regions": ["江苏"],
  "title": "连云港碱业 110 万吨联碱新装置投产",
  "price_effect": "宽松",
  "detail": "老厂 2021–22 已关停（协会 2022-12 产量为 0），新装置 2025-05-18 投产",
  "verified": true,
  "economic_link": "区域供给增加 → 江苏本地价格承压 → 江苏相对山东/河北走弱 → HB−JS 价差走阔"
}
```

`economic_link` 是**必须**的：它把"事件"和"价差"之间的传导路径写出来，而不是让读者自己联想。
措辞上永远是"可以解释为 / 与该阶段方向一致"，绝不写"因为…所以…"。

## 相关不等于因果（这一节要在报告里说）

价差扩大和某个事件在时间上重合，**不能**推出"是这个事件导致的"。可能：

- 两个地区同时受第三个因素影响（比如全国性煤价下跌，天然碱占比高的一方跌得少）
- 事件本身的时点就不精确（产能公告日期 ≠ 实际达产日期）
- 价差变化先于事件发生（市场提前反应）

所以本 Skill 的表述纪律是：**"该阶段价差走阔，同期有 X、Y 两件事，方向一致"**，仅此而已。
详见 `07-措辞纪律.md`。
