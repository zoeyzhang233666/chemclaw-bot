# 02 · 计算口径与公式

本文件是**唯一的公式权威**。`spreadlib.py`、`app-core.js`、`build_excel.py` 三处实现必须与本文件一致。
任何不一致都以本文件为准，改代码，不改文档。

---

## 1. 记号

| 记号 | 含义 |
|---|---|
| `P_r(t)` | 地区 r 在时点 t 的价格（已换算到同一口径） |
| `N` | 有效样本数（三地区同时有报价的期数） |
| `F_ab` | a → b 方向的综合运费 |
| `sd` | 样本标准差（n−1） |

---

## 2. 口径换算（normalize）

按顺序依次套用，**任何一步参数缺失就整条序列不可比**（抛 `missing`，不填 0）。

### 2.1 税基换算

```
含税 → 不含税： P_ex = P_inc / (1 + 0.13)
不含税 → 含税： P_inc = P_ex × (1 + 0.13)
```

中国增值税 13%（2019-04-01 起由 16% 下调）。纯碱**全国统一 13%，无区域税率差异**——
所以税率不构成区域价差的来源，一定要在报告里写清这一点，否则读者会怀疑。

### 2.2 付款方式换算（承兑 → 现汇）

```
P_cash = P_acceptance − 贴息(元/吨)
```

**贴息数值在公开源中【未查到】。** 因此：

- 遇到承兑报价时，`payment_discount` 必须由用户提供
- 用户没提供 → 记为 `missing`，该序列**不参与**跨地区比较
- **绝不填 0**（填 0 等于假装承兑价 = 现汇价，会低估成本 20–50 元/吨量级）

### 2.3 交付方式换算

```
出厂 → 送到： P_del = P_exw + 内含运费
送到 → 出厂： P_exw = P_del − 内含运费
```

⚠️ **`内含运费`（freight_embedded）≠ `外部运费`（freight）。**

- 内含运费 = 卖方报价里已经打包进去的运费，只有卖方/报价机构知道
- 用外部查询到的市场运费去替代内含运费 → 换算基数是错的，换出来的"出厂价"是假的
- 未知时：`missing`，不换算

### 2.4 计量与包装

纯碱吨包（1 吨/包）与散装通常同价，直接可比。
若遇到"小包装加价"或"轻/重碱"，属于**不同商品**，必须分列，不能换算。

## 3. 对齐（align）

### 3.1 三种模式

| 模式 | 规则 | 适用 |
|---|---|---|
| `exact` | 同一天的报价配对 | 日度数据 |
| `asof` | 取 ≤ 目标日期的最近一条，超出 `max_staleness` 天的丢弃 | 发布频率不一致 |
| `weekly` | 按 ISO 周（周一至周日）配对 | **默认**，周度数据 |

### 3.2 ISO 周锚点

```
week_end(d) = d − weekday(d) + 4      # 该周周五
iso_week(d) = (ISO 年, ISO 周序号)
```

同一 ISO 周内的多条报价 → 取该周最后一条（周五锚），并在 `max_staleness` 中记录滞后天数。

### 3.3 缺口处理

```
某期只要有一个地区缺失 → 整期剔除（记入 dropped，写明缺了谁、滞后的天数）
```

**禁止**：前向填充、线性插值、均值填补、删除该地区后重算（会让不同价差的 N 不同且不可比）。

### 3.4 对齐质量指标

| 指标 | 定义 |
|---|---|
| `n_used` | 进入样本的期数 |
| `n_dropped` | 被剔除的期数 |
| `max_staleness[r]` | 地区 r 的最大滞后天数 |
| `dropped[]` | 每次剔除的日期 + 缺失地区 + 滞后天数 |

## 4. 价差（spread）

### 4.1 定义

```
spread(a, b) = P_a − P_b
```

**正数 = a 比 b 贵。** 永远写清方向，不出现裸的"价差"。

### 4.2 有序对

n 个地区 → `n(n−1)` 个有序对。三元地区 = 6 个。

```
SD-HB = +95    HB-SD = −95
SD-JS = −15    JS-SD = +15
HB-JS = −110   JS-HB = +110
```

### 4.3 矩阵

```
M[i][j] = P_i − P_j ,  M[i][i] = 0
```

硬约束（自检）：`M[i][j] = −M[j][i]`，`M[0][1] + M[1][2] + M[2][0] = 0`（闭合性）。

### 4.4 描述统计

| 指标 | 公式 |
|---|---|
| 均值 | `mean = Σx / n` |
| 标准差 | `sd = sqrt(Σ(x−mean)² / (n−1))`（样本标准差，n−1） |
| 中位数 | `quantile(x, 0.5)` |
| 分位 | 见 §5 |

## 5. 历史分位（percentile）

### 5.1 经验分布 + 中秩

```
percentile(v, S) = ( less + 0.5 × equal ) / n × 100
其中 less  = #{x ∈ S : x < v}
     equal = #{x ∈ S : x = v}
     n     = |S|
```

为什么 0.5：并列值应占据它们中位的位置。S = [10, 20, 20, 30]，v = 20：
`(1 + 0.5×2) / 4 = 50%`。若用最小秩 `1/4 = 25%`，会系统性偏低。

**Python**：`spreadlib.percentile_of(v, sample)`
**JS**：`Core.percentileOf(v, sample)`
**Excel**：`=(COUNTIF(r,"<"&v)+0.5*COUNTIF(r,v))/COUNT(r)*100`

### 5.2 窗口

```
sample(end, w) = { spread_t : end − w ≤ t ≤ end }
默认 w ∈ {365 天, 1095 天}（1y / 3y）
```

窗口内 n < 30 → 标注"低置信"（本 Skill 仍给数值，但报告里显式提示）。

### 5.3 滚动分位

```
roll_t = percentile(spread_t, { spread_s : t−365 ≤ s ≤ t })
```

窗口样本 < 30 时不计算（留空），避免"用 10 个点算出一个看起来很确定的分位"。

### 5.4 分位标签

| 分位 | 标签 |
|---|---|
| ≥ 90 | 历史高位（≥P90） |
| 75 – 90 | 偏高（P75-P90） |
| 25 – 75 | 中枢区间（P25-P75） |
| 10 – 25 | 偏低（P10-P25） |
| ≤ 10 | 历史低位（≤P10） |

⚠️ 标签是**描述**，不是信号。`P91` 意思是"这 1 年里只有 8.7% 的周比现在更高"，
**不**意味着"会回落"。

### 5.5 分位插值（quantile）

```
quantile(x, q): x 升序，pos = q × (n−1)
  i = floor(pos), frac = pos − i
  return x[i] + frac × (x[i+1] − x[i])
```

## 6. 运输与运费（freight）

### 6.1 综合运费

```
F_ab = 主运费 + 装货费 + 卸货费 + 短驳费 + 其他
```

| 分量 | 典型值 | 说明 |
|---|---|---|
| 主运费 freight | 路线相关 | 公路/铁路/内河 |
| 装货费 loading_fee | 8 元/吨 | 装车或装船 |
| 卸货费 unloading_fee | 10 元/吨 | 卸车或卸船 |
| 短驳费 short_haul | 0–30 元/吨 | 厂区↔站台/码头 |
| 其他 handler | 2 元/吨 | 过磅、代理、单证 |

**任一项为 `None` → `F_ab = None` → 下游全部不计算。**

### 6.2 到货成本

```
Landed_ab = P_a + F_ab
```

### 6.3 扣费后参考差异

```
Ref_ab = P_b − Landed_ab = (P_b − P_a) − F_ab
```

- `Ref > 0` → 价差覆盖了承运成本
- `Ref ≤ 0` → 未覆盖

⚠️ **`Ref > 0` ≠ 套利机会。** 未计入：资金占用与利息、运输损耗、账期与承兑贴息、
卸货地短驳、仓储、开票与结算风险、可成交批量对本地价格的反作用。

### 6.4 里程与运价

```
运费 ≈ 里程(km) × 吨公里运价(元/吨·km) − 整车折让
吨公里运价经验区间：0.20 – 0.40 元/吨·km
已核实反推锚点：阿拉善 → 石家庄 1500 km / 300 元/吨 ≈ 0.20 元/吨·km
```

### 6.5 方式选择惯例

```
里程 ≤ 300 km  → 公路汽运为主
里程 > 300 km  → 铁路为主
沿江/沿海      → 可内河或海运（水运 30–120 元/吨）
```

## 7. 异常阶段识别（regime）

### 7.1 滚动 z 分数

```
z_t = (spread_t − mean(W_t)) / sd(W_t)
W_t = { spread_s : t−365 ≤ s < t }      # 前 52 周，不含 t 自身
```

窗口样本 < 20 或 `sd = 0` → 该点不判定。

### 7.2 阶段判定

```
异常阶段 = 连续 ≥ 3 期满足 |z_t| ≥ 1.0
direction = "走阔" if mean(阶段内 z) > 0 else "收敛"
definition = z 相对谁：spread(a,b) 走阔 = a 相对 b 变贵
```

### 7.3 阶段统计

| 字段 | 定义 |
|---|---|
| `start` / `end` | 阶段首末日期 |
| `n` | 阶段期数 |
| `mean_spread` | 阶段内价差均值 |
| `base_mean` | 阶段前 52 周的价差均值 |
| `deviation` | `mean_spread − base_mean` |
| `region_snapshots` | 每地区：阶段均价、较前一年变化、阶段区间 |
| `events` | 与该阶段在时间上重叠的事件 |

## 8. 数据质量（data quality）

| 检查 | 判据 | 级别 |
|---|---|---|
| 样本长度 | ≥ 52 期 | WARN if < 52 |
| 缺口 | 逐期列出 | INFO |
| 换算缺失 | 逐地区列出缺失参数 | ERROR if 用来做跨区比较 |
| 运费来源 | `provided` / `default_ref` / `not_available` | WARN if 无 provided |
| 数据状态 | REAL / DEMO / CLIENT | WARN if DEMO |
| 口径一致性 | 五要素逐项 | ERROR if 不一致且未换算 |

## 9. 三处实现的一致性要求

| 公式 | Python | JS | Excel |
|---|---|---|---|
| 价差 | `spread_series` | `Core.spreadSeries` | `=E-F` |
| 分位 | `percentile_of` | `Core.percentileOf` | `=COUNTIF/…` |
| 窗口 | `window_sample` | `Core.windowSample` | `SUMPRODUCT` |
| 综合运费 | `freight_total` | `Core.freightTotal` | `=SUM(G:J)` |
| 参考差异 | `freight_adjusted_spread` | `Core.freightAdjusted` | `=E-L` |
| z / 阶段 | `regime_scan` | `Core.regimeScan` | 预计算 |

**验收标准**：`check_html.py` 比对 JS 与 Python（差 < 0.15 分位点）；
`verify_excel.py` 用 LibreOffice 重算后比对 Excel 与 Python（差 < 0.01）。
