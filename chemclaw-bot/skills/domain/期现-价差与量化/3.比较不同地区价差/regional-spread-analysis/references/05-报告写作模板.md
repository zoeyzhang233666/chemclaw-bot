# 05 · 报告写作模板

> 结构固定，措辞务实。不写套话，不写结论先行但没有证据支撑的句子。

---

## 报告骨架

```
一、结论摘要（4 条，每条带数字）
二、口径与来源（先给可比性证据）
三、价格与对齐（走势 + 对齐质量）
四、两两价差（矩阵 + 明细）
五、历史分位（1y / 3y + 滚动）
六、物流与运费（距离、方式、费用；裸价差/运费/扣费后差异分列）
七、异常价差阶段（可点击下钻：装置、库存、需求事件）
八、区域产业结构（产能、工艺、下游）
九、已知缺口与免责声明
```

---

## 一、结论摘要

**写法**：4 条，每条**必须带数字**，不许只写形容词。

```
价格水平：山东 1370（1 年分位 62.1%），河北 1275（1 年分位 48.3%），江苏 1385（1 年分位 71.5%）。

价差现状：山东 − 河北 = 95（历史均值 62；1y 分位 91.3%，3y 分位 89.1%）；山东 − 江苏 = −15（1y 分位 33.7%）。

处在历史边缘的价差：山东 − 河北（1 年高位 91.3%）、江苏 − 河北（1 年高位 95.2%）。
分位只说明「在这段历史里偏高」，不预示回归。

运费与套利：主口径为送到价，运费已内含在报价中。按默认参考运费参数，6 个方向中 0 个方向的价差覆盖承运成本。
这只是敏感性参考，不等于套利机会。
```

**禁止**：
- ✗「价差较大，存在套利空间」
- ✗「预计价差将回归」
- ✗「河北碱多所以便宜」
- ✓「该阶段价差走阔，同期有 X 事件，方向一致」

---

## 二、口径与来源

**必写三件事**：

1. **报价口径是什么**（送到价 / 出厂价 / 港口平仓）
2. **三地区是否一致**（若一致，明说"换算步数为 0，无需调整"）
3. **运费在哪里**（已内含 / 未包含 / 未知）

模板：

```
三地区报价口径均为「重质纯碱送到价」，规格统一为 GB/T 210-2022 Ⅱ类优等品
（Na₂CO₃ ≥ 99.2%），均含 13% 增值税，计量单位统一为 元/吨，均为周度同一时点采集。
换算日志显示三地区换算步数均为 0——即报价已在同一口径上，无需调整。

⚠ 关键提醒：重碱除西北以外地区采用送到价（期货日报，2019-12-01），
因此三地区报价中的运费已经内含。本节及后续的运费调整仅用于：
①在出厂价口径下把运费显性化；②核对某个方向的价差是否覆盖承运成本。
不得用整段运费从送到价里重复扣减。
```

## 三、价格与对齐

**必写**：

| 项 | 内容 |
|---|---|
| 样本期 | 2023-01-06 ~ 2025-12-19（152 周） |
| 频率/对齐 | 周度，ISO 周对齐（周五锚） |
| 缺口 | 主口径剔除 4 周，列出了具体日期和缺失地区 |
| 为什么剔除不插值 | 一句话解释 |

```
主口径对齐后可用 152 周，剔除 4 周（2024-02-16、2024-05-03、2025-01-31、2025-10-03），
缺失均为节假日停报。缺口未插值——插值会平滑掉价差的尾部，让异常阶段识别失效。
```

## 四、两两价差

**必须**：

- 写清减法方向（`价差 = 甲 − 乙`，正数 = 甲更贵）
- 全部有序对（6 个，不是 3 个）
- 等价校验结果（`M[i][j] = −M[j][i]` 全部通过）

```
价差定义：spread(a, b) = P(a) − P(b)，正数表示 a 地区更贵。

山东 − 河北  = +95    河北 − 山东  = −95    ✓ 互为相反数
山东 − 江苏  = −15    江苏 − 山东  = +15    ✓
河北 − 江苏  = −110   江苏 − 河北  = +110   ✓
```

---

## 五、历史分位

**必须**：

- 给**两个**窗口（1y / 3y），不只给一个
- 同时给 **N**
- 写清算法（经验分布、中秩）
- **明写"分位不预示回归"**

```
分位算法：经验分布 ( #{x<v} + 0.5·#{x=v} ) / N × 100%，并列值取中秩。
1 年窗口 N≈52，3 年窗口 N=152。

山东 − 河北：当前 +95，1y 分位 91.3%（N=52），3y 分位 89.1%（N=152）→ 历史高位

解读边界：分位高只说明「这段历史里只有 8.7% 的周比现在更高」。
它不构成"会回落"的判断，也不是交易信号。
```

## 六、物流与运费（最关键的一节）

**三段式，永远分开写：**

```
1) 裸价差        山东 → 河北：目的地价 1275 − 产地价 1370 = −95
2) 运输成本      综合运费 116（主运费 96 + 装货 8 + 卸货 10 + 短驳/其他 2）
3) 扣费后差异    −95 − 116 = −211  → 未覆盖运费
```

**必写的三句话**：

1. 「运费数据状态：真实报价 0 条 / 默认参考 6 条 / 未获得 0 条」
2. 「默认参考值不是市场报价，只能作敏感性参考」
3. 「价差覆盖运费 ≠ 套利机会。未计入：资金占用与利息、运输损耗、账期与承兑贴息、
   卸货地短驳、仓储、开票与结算风险、可成交批量」

**如果运费未知**：
```
其中 HB→JS 方向的运费【未获得】，因此该方向的扣费后差异不计算。
不以 0 元替代，也不以其他方向的运费代替。
```

## 七、异常价差阶段

每段都写：

```
【山东 − 河北 2024-09-06 ~ 2024-12-13（14 周，走阔）】
阶段均值 +45.6 元/吨，前一年均值 62，偏离 −16.4。

区域快照：
  山东  阶段均价 1580（较前一年 +50），区间 1500~1660
  河北  阶段均价 1534（较前一年 +92），区间 1450~1620

同期事件：
  [E09] 2024-09 唐山三友部分装置检修（产能 340 万吨，氨碱）— 影响 河北
  [E10] 2024-10 沙河玻璃厂补库 — 影响 河北

经济链条：河北装置检修 → 河北本地供给收紧 → 河北价格相对走强 → 山东−河北价差收敛
```

**注意方向**：先看 `region_snapshots` 里谁涨得多，再决定说"走阔"还是"收敛"是哪个方向。
不要凭事件名称猜方向。

## 八、区域产业结构

**只写有依据的**：

```
山东：可核实产能 430 万吨（山东海化 280 氨碱 + 山东海天 150 氨碱）。
      净调出地区，价格通常为华东/华北风向标之一。
河北：可核实产能 340 万吨（唐山三友 + 五彩碱业，均氨碱）。
      沙河玻璃集群月用纯碱约 9 万吨，属净调入，本地无天然碱。
江苏：可核实产能 570 万吨（实联 120 联碱、江苏华昌 70、苏盐井神 70、
      江苏德邦 60、徐州丰成 60、中盐昆山 60–80、连云港碱业新装置 110 联碱）。
      省级合计【未查到】权威发布，此处为已核实企业加总，不是统计口径产能。
```

> ⚠️ 中盐昆山在**江苏**，不在山东。这类地域归属错误要特别小心。

## 措辞黑名单

| 不要写 | 改写成 |
|---|---|
| 存在套利空间 | 价差覆盖了承运成本；未计入资金占用、损耗、账期等，不足以判断可行性 |
| 价差必然回归 | 历史上该分位附近的价差后续表现不一；本报告不做预测 |
| A 地区便宜是因为碱多 | A 地区报价低于 B；区域产能与价差的关系需要单独验证，本报告未做 |
| 由于 X 事件导致价差扩大 | 价差扩大与该事件在时间上重合，方向一致；未做因果检验 |
| 预计下周价差收窄 | （删除。本报告不含预测） |
| 运费约 100 元 | 运费为默认参考值 96 元/吨（来源：吨公里估算），非市场报价 |
