# 07 · 措辞纪律

> 区域价差报告的读者通常是**要下决定的人**（采购、销售、贸易、风控）。
> 他们会把你写的每句话当依据。所以措辞必须能扛住追问。

---

## 一、六条硬规则

### 规则 1 · 价差永远带方向

| ✗ | ✓ |
|---|---|
| 价差 95 | 山东 − 河北 = +95（山东比河北贵 95 元/吨） |
| 两地价差收窄 | 河北 − 江苏 由 −78 走阔至 −45 |
| 价差在 100 左右 | 山东 − 河北 = +95，历史均值 +62 |

写法：`spread(a, b) = P(a) − P(b)`，正数 = a 更贵。矩阵写"行 − 列"。

### 规则 2 · 三层成本永远分列

```
裸价差     +110
运输成本   −85
扣费后      +25
```

不许写成"净赚 25"。要写"扣费后参考差异 +25，仅表示价差覆盖了承运成本"。

### 规则 3 · 分位只描述位置，不预示方向

| ✗ | ✓ |
|---|---|
| 分位 95%，即将回落 | 1y 分位 95.2%，处于历史高位 |
| 价差处于极值，机会出现 | 当前价差在近 1 年中排第 95 百分位 |
| 历史规律显示会回归 | 历史上该分位附近的价差后续表现不一，本报告不做预测 |

### 规则 4 · 事件用"同期"，不用"导致"

| ✗ | ✓ |
|---|---|
| 由于唐山三友检修，河北价格上涨 | 该阶段河北均价 +92；同期有唐山三友部分装置检修，方向一致 |
| 价差扩大是因为需求塌陷 | 价差扩大与该段玻璃厂冷修在时间上重合 |
| 产能投放导致江苏价格下跌 | 江苏新装置 2025-05-18 投产后，江苏相对山东走弱 |

如果确实要提示因果方向，用**假设语气 + 检验动作**：
> 「可以进一步验证：若检修是主因，河北库存应在同期下降。本报告未取得区域库存数据。」

### 规则 5 · 缺失就是缺失，不许美化

| ✗ | ✓ |
|---|---|
| 运费约 100 元/吨 | 运费为默认参考值 96 元/吨（吨公里估算），非市场报价 |
| 承兑贴息按 30 元计 | 承兑贴息【未查到】，该地区承兑报价未纳入比较 |
| 山东产能约 600 万吨 | 山东可核实企业产能合计 430 万吨；省级合计【未查到】 |

### 规则 6 · 数据状态优先于一切结论

DEMO 数据必须在报告**顶部**打醒目标徽标，并在摘要第一段写明：
> 「本报告使用 DEMO 拟真数据，金额与分位不得用于报价、交易或对外引用。」

## 二、高频句式对照

| 场景 | 可用句式 |
|---|---|
| 价格水平 | `{地区} 当前 {价格} 元/吨，处于近 {N} 年 {分位}% 分位` |
| 价差现状 | `{甲} − {乙} = {值}（{甲} 比 {乙} 贵 {值} 元/吨）` |
| 分位解读 | `在该窗口 {N} 个观测中，有 {k} 个比当前更低` |
| 覆盖判断 | `按当前参数，{方向} 的价差{覆盖/未覆盖}承运成本 {值} 元/吨` |
| 运费缺失 | `{方向} 运费【未获得】，该方向的扣费后差异不计算` |
| 事件关联 | `该阶段{价差变化}，同期有 {事件}，方向{一致/相反}` |
| 不做判断 | `本报告仅做历史统计描述与口径核对，不构成交易建议` |

---

## 三、必须出现的六句话

复制到报告的"免责与口径声明"里，不能省：

1. 主口径为**送到价**，运费已内含在报价内，**不可重复扣减**。
2. **未提供真实运费**时，扣费后差异仅作敏感性参考，不作为套利依据。
3. **价差覆盖运费 ≠ 套利机会**（未计资金占用、损耗、账期、短驳、仓储、开票、可成交批量）。
4. 分位高**不预示**回落；分位只回答"在这段历史里排第几"。
5. 事件与价差变化的对应**只用于解释**，未做因果检验。
6. 本报告**不构成**交易建议、目标价或买卖方向。

## 四、审稿清单（交付前逐条打勾）

- [ ] 每个价差都写了"谁减谁"
- [ ] 裸价差 / 运输成本 / 扣费后差异**三项分列**
- [ ] 没有出现"套利机会"四个字（做可行性讨论除外，且必须列未计入项）
- [ ] 没有出现"预计 / 将会 / 有望"这类预测词
- [ ] 没有把相关写成因果（搜"因为""导致""由于"）
- [ ] 分位旁边有 N
- [ ] 缺失项明确标"【未查到】"，没有编数
- [ ] 运费标了来源级别（真实报价 / 默认参考）
- [ ] DEMO 数据有醒目标注
- [ ] 口径表的三地区 `quote_basis` 一致，或已说明换算
- [ ] 没有"河北碱多所以便宜"这类地域刻板印象
- [ ] 企业厂址核对过（中盐昆山在江苏！）

## 五、一句话原则

> **能算的给数字并给口径，不能算的写"未查到"，能解释的写"同期有"，能不说的不说。**
