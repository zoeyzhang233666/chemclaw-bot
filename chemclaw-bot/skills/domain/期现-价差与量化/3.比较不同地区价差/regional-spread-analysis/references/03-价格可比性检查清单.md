# 03 · 价格可比性检查清单

> 用法：跨地区比较**之前**逐项过一遍。任何一项"不一致"都必须有对应的换算动作或
> 明确的"不可比"标注。这张表就是 Excel `01 口径与来源` 表的内容来源。

---

## A. 五要素（缺一项就不可比）

### A1 · 产品规格

| 检查 | 问题 | 不一致时 |
|---|---|---|
| 品种 | 是同一个品种吗？（纯碱 vs 烧碱 vs 小苏打） | 不可比，直接停 |
| 轻重 | 重质 / 轻质 / 轻重混报？ | **必须分列**。纯碱轻重价差 100–300 元/吨 |
| 等级 | 优等品 / 一等品 / 合格品？ | 分列或按等级价差换算（需依据） |
| 主含量 | Na₂CO₃（干基）≥ 99.2%？ | 未达交割标准的不能与交割品同列 |
| 杂质 | NaCl（干基）≤ 0.6%？（期货交割要求） | 玻璃厂用碱对铁、氯有要求 |

**纯碱常用标准**：GB/T 210-2022《工业碳酸钠》，Ⅱ类优等品；
郑商所纯碱期货交割基准品为 Ⅱ 类优等品重质纯碱，NaCl（干基）≤ 0.6%。

### A2 · 税率

| 检查 | 问题 | 不一致时 |
|---|---|---|
| 是否含税 | 含税 / 不含税 / 未标明？ | 未标明 → 视为缺口，不可比 |
| 税率 | 13%？（2019-04-01 起） | 换算：`不含税 = 含税 ÷ 1.13` |
| 区域差异 | 有区域税率优惠吗？ | 纯碱**全国统一 13%**，沙河也是 13%，**不构成区域价差来源** |

> 常见错误：因为"河北税率低所以便宜"——这是**错的**。调研确认区域增值税率一致。

### A3 · 计量单位与包装

| 检查 | 问题 | 不一致时 |
|---|---|---|
| 单位 | 元/吨？（不是 元/kg、元/包） | 换算 |
| 净重口径 | 净重 / 毛重？ | 按净重 |
| 包装 | 吨包（1 吨）/ 散装 / 小包装？ | 吨包与散装通常同价；小包装加价需另计 |
| 计价基础 | 干基 / 湿基？ | 纯碱一般干基 |

### A4 · 交付方式（最容易出错的一项）

| 检查 | 问题 | 不一致时 |
|---|---|---|
| 交付点 | 出厂（exw）/ 送到（delivered）/ 港口平仓（fob）/ 到岸（cif）？ | 用**内含运费**换算，未知则不可比 |
| 装卸责任 | 装货费谁承担？卸货费谁承担？ | 明确后计入或扣除 |
| 入库/出库 | 是仓库出库价还是入库价？ | 郑商所纯碱交割库：入库费（汽车）约 25 元/吨、（火车）30 元/吨 |

> **纯碱关键事实（期货日报 2019-12-01）**：
> 轻碱统一采用**出厂价**；**重碱除西北以外地区采用送到价**，西北采用出厂价。
>
> 所以山东 / 河北 / 江苏的重碱报价 = **送到价，运费已内含**。
> ⚠️ 不要再用整段市场运费去扣一次——那是重复扣减。
> ⚠️ 也不要用外部运费去反推"出厂价"——内含运费不等于市场运费。

### A5 · 付款方式

| 检查 | 问题 | 不一致时 |
|---|---|---|
| 现汇 / 承兑 | 报价是现汇价还是承兑价？ | `现汇 = 承兑 − 贴息` |
| 贴息数值 | 多少元/吨？ | **公开源【未查到】** → 记为缺口，不填 0 |
| 账期 | 现款 / 月结 30 天 / 60 天？ | 账期不同要折现，折现率需用户给 |
| 预付比例 | 预付款有折扣吗？ | 记录并说明 |

### A6 · 报价时点

| 检查 | 问题 | 不一致时 |
|---|---|---|
| 发布频率 | 日度 / 周度 / 月度？ | 按最细的对齐，或统一降频 |
| 发布滞后 | 是当日报价还是"上周数据周一发布"？ | 按**数据实际所属期**对齐，不按发布日期 |
| 采集时点 | 上午 / 下午？ | 通常可忽略，除剧烈波动期 |
| 节假日 | 春节前后停报？ | 缺口剔除，不填充 |

## B. 常见不一致组合与处理

| 情形 | 错误做法 | 正确做法 |
|---|---|---|
| A 报出厂价 1300，B 报送到价 1375 | 直接相减得 −75 | 要么都换到出厂（需 A 的运费），要么都换到送到（需 B 的运费）；**内含运费未知则不比较** |
| A 报含税，B 报不含税 | 直接相减 | 统一到含税：`B × 1.13` |
| A 报承兑，B 报现汇 | 直接相减 | 扣贴息；贴息未知 → 标注不可比 |
| A 是重碱，B 是轻碱 | 直接相减 | **分列**，不换算 |
| A 是周三的价，B 是周一发布的上周价 | 按发布日期配对 | 按**数据所属期**配对 |
| A 有报价，B 缺一周 | 前向填充 | 剔除该周，记入 `dropped` |

## C. 换算日志（必须留痕）

每次换算都要能回答："这条价格被我改了多少、为什么？"

Excel `01` 表 → `normalize_report`，逐地区给出：

| 字段 | 含义 |
|---|---|
| `n` | 样本数 |
| `total_steps` | 实际执行的换算步数 |
| `sum_abs_adj` | 累计调整绝对值（元/吨） |
| `max_abs_adj` | 单步最大调整 |
| `warnings[]` | 提示（如"增值税率未标明，按 13% 处理"） |
| `missing[]` | 缺失参数（如"承兑贴息"） |

**`total_steps = 0` 是好消息**：说明三地区报价已经同口径，无需换算。
如果 `total_steps > 0` 且数字很大，要警觉——可能选错了口径。

## D. 提交前自问

1. 三个数字的**规格**完全一样吗？轻重分开没有？
2. **税率**一致吗？有没有人报的是不含税？
3. **交付方式**一致吗？送到价里含的运费，我是不是又扣了一遍？
4. **付款方式**一致吗？贴息我编了没有？（绝不能编）
5. 三条序列的**时点**是同一周吗？我是不是把上周的价配给了本周？
6. 缺口我是**剔除**的还是填的？填了就得改回来。
7. 换算日志里有没有 `missing`？有的话，那个地区的价差还能不能报？
8. 报告里有没有写明"**运费已内含**"或"**运费缺失**"？
9. 我把"价差覆盖运费"写成了"套利机会"吗？（不能写）
10. 我把"河北便宜是因为碱多"这种话写进去了吗？（相关≠因果）
