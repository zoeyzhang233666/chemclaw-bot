# 04 · 数据源与口径清单

> 原则：**每个源都记下它的已知缺陷**。用哪个源、为什么用、哪里不能信，都要能说清。

## A. 价格数据源

### A1 · 期货日报「纯碱现货价格」

| 项 | 内容 |
|---|---|
| 覆盖 | 轻碱 / 重碱；西北 / 华北 / 华东 / 华中 / 西南等区域 |
| 频率 | 日度 / 周度 |
| **口径关键** | **轻碱统一出厂价；重碱除西北以外地区采用送到价，西北采用出厂价** |
| 缺陷 | 区域是"大区"不是"省"；不给出城市级独立序列；部分日期停报 |
| 适用 | 区域口径判断的**权威依据**；跨省比较的主口径来源 |
| 状态 | 已核实（2019-12-01 报道，规则沿用） |

### A2 · 生意社（100ppi）基准价

| 项 | 内容 |
|---|---|
| 覆盖 | 重质纯碱全国 / 华东 / 华北基准价 |
| 频率 | 日度 |
| 缺陷 | **全国基准价 ≠ 区域价**；华东/华北是大区合成值，不是省价 |
| 适用 | 锚定绝对水平（如 2025-12-31 重碱基准价 1225.71） |
| 状态 | 已核实（单点） |

### A3 · 郑商所（CZCE）纯碱期货

| 项 | 内容 |
|---|---|
| 覆盖 | 期货合约价格、仓单、交割库 |
| 单位 | 20 吨/手，元/吨 |
| 缺陷 | 是期货价，**不是现货价**；基差需要通过交割库地区映射 |
| 适用 | 期现基差（可选扩展）；交割库入库费锚点（汽车 25 元/吨、火车 30 元/吨） |
| 状态 | 已核实 |

### A4 · 隆众 / 卓创（付费）

| 项 | 内容 |
|---|---|
| 覆盖 | 省级、城市级现货价；企业出厂价；开工率；库存 |
| 缺陷 | 付费；用户需提供账号或导出文件 |
| 适用 | **做省级价差的最佳来源** |
| 状态 | 未接入 |

### A5 · Wind / iFinD

| 项 | 内容 |
|---|---|
| 覆盖 | 宏观 + 化工品价格指数（部分有省级） |
| 适用 | 长历史序列；与宏观变量联动 |
| 状态 | 未接入 |

### B3 · 工艺成本结构

| 工艺 | 占比 | 成本区间 | 说明 |
|---|---|---|---|
| 天然碱 | 16.9% | < 1000 元/吨 | 内蒙阿拉善为主，成本最低，但运输距离远 |
| 联碱（侯氏制碱） | 45.2% | 1050–1200 元/吨 | 联产氯化铵，成本受氯化铵价格影响 |
| 氨碱（索尔维） | 36.9% | > 1300 元/吨 | 山东海化、唐山三友等 |

> 成本梯次是**区域价差的结构性来源之一**：天然碱占比高的流向区域，价格底部更低。

## D. 已知缺口登记（X 系列）

每个项目都要在报告和 Excel `15 数据质检` 里出现。

| 编号 | 缺口 | 影响 | 处理方式 |
|---|---|---|---|
| X-1 | 省级独立日度现货价（山东/河北/江苏）免费源未查到 | 无法给出真实省级序列 | DEMO 骨架 + 醒目标注；付费源或用户数据替换 |
| X-2 | 承兑贴息具体数值 | 承兑报价无法换算到现汇 | 记为缺失，不填 0 |
| X-3 | 省级产能合计 | 无法算区域产能占比 | 只给企业级；宁缺不假 |
| X-4 | 省级下游需求拆分 | 无法精确量化区域需求结构 | 全国口径已核实，省级为示意并标注 |
| X-5 | 精确公路里程 | 运费估算有偏差 | 标"估算"，建议地图 API 替换 |
| X-6 | 各地实际运费（真实报价） | 扣费后差异只能作敏感性参考 | 标 `default_ref`；用户提供后切 `provided` |
| X-7 | 区域库存数据 | 无法做库存-价差联动 | 事件库中用定性描述替代 |
| X-8 | 沙河/临沂等集散地仓库出库价 | 无法做"出厂 vs 送到 vs 出库"三口径 | 用交割库/送到价差作替代锚点 |
| X-9 | 轻碱区域价 | 轻重碱套利无法算 | 本 Skill 只做重碱 |

## E. 取数记录规范

每一行数据都要能追溯。`prices_template.csv` 的列：

```csv
date,region,price,caliber,unit,source,note
2025-06-27,SD,1350,DELIVERED,元/吨,期货日报华北,周度
```

| 列 | 必填 | 说明 |
|---|---|---|
| `date` | ✓ | `YYYY-MM-DD`；周度数据填该周锚点（周五） |
| `region` | ✓ | 地区代码，与 `project.json` 一致 |
| `price` | ✓ | 数值；缺失**留空**，不要填 0 |
| `caliber` | ✓ | `DELIVERED` / `EXW` —— 决定进哪套口径 |
| `unit` | ✓ | 必须是 元/吨 |
| `source` | ✓ | 来源机构 + 具体的表/栏目 |
| `note` | | 特殊情况说明（停报、换源、口径变更） |

> **换机构 = 口径断点。** 同一地区前后用不同机构的数据，价格水平会有台阶。
> 这种情况要么全程用一个源，要么在 `note` 里标出断点并在报告里提示。
