比较不同地区价差 —— 让 AI 帮你做一张"能对账"的区域价差研究

这个技能回答的是这一类问题：
  「请比较【重质纯碱】在【山东】【河北】【江苏】最近一年的现货价格。」

它不会只给你三个数字然后相减。它会先确认这三个价格是不是同一个东西：
  规格一样吗？（轻碱 / 重碱价差本身就有 100–300 元/吨，混算就废了）
  税率一样吗？（一个含税一个不含税，相减凭空多出 13%）
  交付方式一样吗？（一个出厂价一个送到价，相差的就是运费）
  付款方式一样吗？（承兑价 vs 现汇价，差一笔贴息）
  时点一样吗？（把"周一发布的上周数据"配给本周价格，一周就能差 50 元）

确认口径一致之后，才做四件事：
  1. 按 ISO 周对齐，缺口直接剔除（不插值、不前向填充）
  2. 算全部有序对的价差，永远写清"谁减谁"
  3. 算历史分位（1 年 / 3 年），用经验分布，并列值取中秩
  4. 叠加运费，但把"裸价差 / 运输成本 / 扣费后差异"三项永远分列

三条红线（写死在代码里，不是免责声明）：
  · 没有真实运费就不估算，也不把价差认定为套利机会
  · 缺失就是缺失，绝不用 0 顶替，算不出来就不算
  · 相关不写成因果，分位不写成预测

你会拿到两个文件：
  · 一个 HTML 报告，双击就能离线打开。可以点选地区、切口径、改运费实时重算，
    点异常价差阶段能看那段时间的装置、库存和需求事件。
  · 一个 Excel 工作簿，17 张表。改价格，价差矩阵、分位、运费调整全部自动重算——
    每个数字你都能自己复算一遍。

怎么用：
  cd regional-spread-analysis
  python scripts/build_all.py                      # 用内置纯碱样例跑一遍
  python scripts/build_all.py --prices 你的数据.csv   # 用你自己的数据

数据格式见 data/prices_template.csv，一行一个"日期 × 地区"。
缺失就留空，别填 0。

详细说明见同目录的 README.md 和 SKILL.md。
