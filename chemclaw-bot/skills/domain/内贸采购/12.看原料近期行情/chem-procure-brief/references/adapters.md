# 采集适配器（数据源与解析要点）

> 这一节讲的是**怎么把公开数据变成 research.json 里的字段**，不是让脚本去联网。
> 所有抓取都发生在"采数"阶段，产物落到 `raw/`；`scripts/` 只做离线计算与生成。

## 1. 来源分层与用途

| 层 | 来源类型 | 能给什么字段 | 常见坑 |
|---|---|---|---|
| A | 交易所行情接口、海关总署、统计局、部委公告 | 期货 `futures.series`、进出口 `balance`、政策 `events` | 接口字段名变动；公告只有 PDF |
| B | 专业资讯商日评/周评（隆众、卓创、金联创、Mysteel、生意社、CCF 等） | `spot`、`quote_series`、`balance`、`events` | 多数需订阅；免费页只给摘要；栏目结构常改版 |
| C | 期货公司日报/月报/专题（华泰、光大、创元、金联创专题、上海中期…） | 分区域现货表、库存、开工、成本模型、产业链 | 数字多为转引，需回溯到原始资讯商名 |
| D | 厂商公开报价、竞拍/交易平台成交记录 | `spot`（`quote_kind=竞拍成交/厂商报价`） | 挂牌 ≠ 成交；只代表该厂 |
| E | 综合财经媒体 | `events` | 时点模糊（"近日"）、标题党、缺量级 |

## 2. 通用采集流程

```
① 定位页面  → ② 取正文（去掉导航/广告） → ③ 正则/表格提取 → ④ 落 raw/*.txt|json
                                    ↓
                          ⑤ 人工核对关键数字（必须！）
                                    ↓
                          ⑥ 写入 research.json（手填）
```

**第 ⑤ 步不能省**：自动提取的数字一旦错位（行错列、单位错），下游全错。核对方法是把提取值和原文截图对照，至少核对锚价、区间高低点、库存、开工四类。

## 3. 各字段的典型提取位置

| 目标字段 | 原文常见表述 | 提取要点 |
|---|---|---|
| 区域现货价 | "太仓 3983（-42）" / "临沂 3360–3410，跌 190–220" | 数字后面的括号是日变动；区间取两数 |
| 基差 | "太仓基差 629（+77）" | 基差 = 现货 − 期货，需注明期货合约与日期 |
| 港口库存 | "港口总库存 36.72 万吨，周环比 +6.21 万吨" | 记 `v` 与 `prev`，并记样本（华东+华南？） |
| 开工率 | "MTO 开工 76.69%（-3.01pct）" | 注意是百分点还是百分比 |
| 成本/利润 | "内蒙煤制利润 1070 元/吨（-85）" | 利润可反推成本：售价 − 利润（注明是反推） |
| 检修 | "XX 装置 90 万吨/年 9-05 起检修，计划 25 天" | 装置名、产能、起始日、计划天数、是否已复产 |
| 投产 | "四期 280 万吨/年计划 10 月中下旬出合格品" | 区分"计划/投料/产出合格品/满负荷" |
| 进口 | "8 月进口 81 万吨，同比 -54%" | 月度/累计要分清 |
| 政策 | "三部门要求……" | 找原文链接，摘录关键条款 |

## 4. 抓取技术要点（Windows + PowerShell 环境）

1. **不要用 PowerShell 内联 Python 加中文**：`python -c "..."` 带中文引号/正则会被 ParserError 打断。一律写成 `.py` 文件再执行。
2. **stdout 编码**：先 `$env:PYTHONUTF8='1'`，否则中文输出乱码。
3. **HTML 解析优先 lxml**：`html.fromstring(text)` + `xpath`；不要用正则切 HTML。
4. **Brotli 压缩**：部分财经站返回 `content-encoding: br`，需要 `brotli` 解压后再解码。
5. **反爬**：带 UA、必要时带 Cookie（一些站点用一个简单的 `HW_CHECK` 之类的 cookie 放行）；抓取频率控制在 1–2 秒一次。
6. **动态图表**：绝大多数资讯商的价格走势图是前端渲染（canvas 或加密数据包），**通常无法从服务端还原**。遇到就放弃图表，只用文中文字披露的数字，并把这类缺口写进 `gaps`（这是常态，不是失败）。
7. **PDF 报告**：先转文本再正则；表格型 PDF 优先用 `pdfplumber` 一类的表格抽取。

## 5. 期货日线（可选）

```bash
python scripts/fetch_futures.py <symbol> --out raw/XX_daily.json
```
- 输出字段：`d,o,c,h,l,v,oi,pct`。
- 主连连续合约在**主力换月**时会跳空，必须在报告里注明"主连连续，换月处不可当真实涨跌"。
- 期货只用于"基差"与"盘面情绪"，**不参与分位与锚价**。

## 6. 把文章变成 research.json 的节奏

| 步骤 | 时间 | 产出 |
|---|---|---|
| 定题与骨架 | 15 min | `meta` + `primary_point` + 采购点清单 |
| 报价采集 | 40 min | `spot` + `quote_series`（尽量多采集几个历史日期） |
| 库存/开工/进口 | 30 min | `balance` |
| 上下游与工艺 | 40 min | `upstream` / `downstream` / `chain_proof` / `routes` |
| 事件回溯 3 个月 | 50 min | `events`（含证据级别） |
| 成本与事实卡 | 20 min | `cost_lines` / `facts` / `talk` |
| 缺口整理 | 15 min | `gaps` / `caveats` / `sources` |
| 跑流水线修错 | 20 min | 0 error 的产物 |

## 7. 采不到怎么办（对照表）

| 采不到 | 替代方案 | 若替代方案也不可得 |
|---|---|---|
| 日度现货序列 | 用多期周报/月报拼"稀疏序列"，报告标注样本数 | 只做当期价 + 区间，分位留缺口 |
| 运价 | 找物流指数或询两家物流 | 价差标 `checked:false`，禁止下"该调货"结论 |
| 进口完税折算 | 用汇率 + 明确税率假设算出，写清假设 | 只列 CFR 美元价，注明不可比 |
| 分品种下游开工 | 用下游产品价格 + 定性描述 | `direction:"gap"`，并写"未来需补周度开工" |
| 装置产能 | 用企业公告/环评公示 | 只写"某装置停车"，不写损失量 |

> 记住：**一份诚实的缺口清单，比一份编满数字的报告值钱。** 采购拿它去谈判，缺口就是他要打电话去问的问题清单。
