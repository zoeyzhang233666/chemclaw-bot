# 交付前自检清单（40 项）

> 脚本能保证"没说错"，这份清单保证"说全了、说清了、能被人拿去用"。
> 打勾前请真的打开 HTML 和 Excel 各看一遍。

## A. 数据来源（1–8）

- [ ] 1. 每条现货报价都能点开来源；转引注明"某媒体转述某机构"。
- [ ] 2. 至少两家独立来源交叉验证关键价格；只有一家时 `conf` 已降级并在 caveats 说明。
- [ ] 3. 所有报价日期是"报价日期"而非"发布/写作日期"。
- [ ] 4. 期货数据与现货分开标注，未混用。
- [ ] 5. 库存/开工数据写明"样本范围"（哪家资讯商、哪个样本池）。
- [ ] 6. 进口/出口数据注明来源（海关/机构估算）与统计口径（万吨/美元、月度/累计）。
- [ ] 7. 成本数字注明是披露值还是派生值（`derived`）。
- [ ] 8. 政策类信息有原文链接（部委/交易所/企业公告）。

## B. 口径一致性（9–16）

- [ ] 9. 每一条报价都有 `point / spec / tax / basis / date / src` 六项；缺项已在 caveats 点名。
- [ ] 10. 含税与不含税分开列；没有任何跨税号的减法。
- [ ] 11. 出厂价与送到价没有直接相减；价差说明含运费。
- [ ] 12. 外币报价已注明"不可直接与人民币价相减"，或给了完整的换算假设。
- [ ] 13. 厂商挂牌价与竞拍成交价分列，并说明二者关系。
- [ ] 14. 指数/基准价标注了"结算参考价，非成交价"。
- [ ] 15. 两套库存口径分列，并说明"不可相加"。
- [ ] 16. 单位统一（元/吨 vs 美元/吨 vs 元/方 vs 千标方），表格里有单位列。

## C. 时间序列（17–22）

- [ ] 17. 每个涨跌幅都写了基准日与基准价。
- [ ] 18. 每个分位都写了样本数与区间高低点。
- [ ] 19. 样本 < 8 的窗口已加"样本薄"说明。
- [ ] 20. 没有任何插值、补点、按月初/月末对齐的假基准。
- [ ] 21. 图上横轴只有真实报价日，说明文字已讲清"折线只是连线"。
- [ ] 22. 异常点阈值（`anomaly_pct`）在报告里写出来了。

## D. 产业链（23–27）

- [ ] 23. 上下游每一环都能说出工艺路线（反应/分离/配方）。
- [ ] 24. 每条链都有单耗与需求占比（或明确写"占比未知"）。
- [ ] 25. 没有把替代品、同板块品种、同装置联产品当上下游。
- [ ] 26. 未通过核对的链路已标红，且报告中声明"其数字不可对外引用"。
- [ ] 27. 缺运价/税费/船期的断点已登记为缺口，而不是硬算。

## E. 事件（28–32）

- [ ] 28. 每条事件都有事件日、来源、证据级别。
- [ ] 29. 检修/复产/投产事件写了装置产能与影响天数。
- [ ] 30. 传闻与待确认信息在"未采纳消息"区，且写明为什么没采纳。
- [ ] 31. 事件与价格只写"同期"，没有"因为/导致/带动"。
- [ ] 32. 同时给出了"事件日"和"首个报价响应日"。

## F. 表达与合规（33–37）

- [ ] 33. 全文搜索"将 / 预计 / 有望 / 或将 / 建议买 / 建议囤 / 抄底 / 看涨 / 看跌"——应为 0。
- [ ] 34. 没有任何隐含预测的措辞（如"下跌空间有限""底部已现"）。
- [ ] 35. 首屏写明"不预测价格、不给买卖时点建议"。
- [ ] 36. 缺口清单里每条都有"影响"和"补齐路径"。
- [ ] 37. 采购参数（库存天数/月用量）如果是假设值，已明确标注。

## G. 产物质量（38–40）

- [ ] 38. HTML 双击可开，图表与所有模块有内容；手机宽度（≤420px）不横向溢出。
- [ ] 39. Excel 12 张表齐全，缺口处没有空白单元格，来源可点。
- [ ] 40. `build_all.py` 输出：静态自检 0 error、工作簿自检 0 error、渲染 0 项失败。

## 快速跑完的自检命令

```bash
cd <项目目录>
python ../scripts/build_all.py research.json --out out --name 品种-地区 --shots shots
python - <<'PY'
import json,re,sys
p='build/data.json'; D=json.load(open(p,encoding='utf-8'))
bad=['将','预计','有望','或将','抄底','看涨','看跌','建议买']
txt=json.dumps(D,ensure_ascii=False)
for b in bad:
    n=txt.count(b)
    if n: print('注意：出现 %d 次「%s」'%(n,b))
print('gaps:',len(D.get('gaps') or []),'events:',len(D.get('events') or []),
      'quotes:',len(D.get('quotes') or []),'points:',len(D.get('points') or []))
PY
```
（上面脚本里的"将/预计"只会在新闻标题之类引用里出现，逐条确认是否可改写。）
