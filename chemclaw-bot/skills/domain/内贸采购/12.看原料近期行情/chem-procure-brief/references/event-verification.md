# 事件核验：四级证据 + 事件五问

> 采购底稿里的事件不是为了"看起来丰富"，而是为了回答："这张价格图上的每一次跳，当时发生了什么？"
> 一个没被核实的事件，比没有事件更危险——它会让采购以为"我知道原因"，从而做出错误判断。

## 1. 四级证据（`events[].evidence`）

| 级别 | 取值 | 定义 | 进时间线？ | 例 |
|---|---|---|---|---|
| 1 | `公开报道` | 媒体/机构原文可点开核对，且陈述的是已发生事实 | 是 | "某日某装置因故停车"（有明确日期与装置） |
| 2 | `机构观点` | 资讯商/期货公司的研判或统计（含"我们预计"但不含价格方向） | 是，但标注为观点 | "本周开工率下降 X 个百分点" |
| 3 | `传闻` | 只有单一来源且无法交叉验证，或来源为"市场人士称" | **否**，进"未采纳消息" | "听说某装置要复产" |
| 4 | `待确认` | 与其它已证实信息矛盾，或只有标题没有细节 | **否** | "有消息称海峡将重开"（官方无确认） |

**判定口诀**：能不能点开？说的是已经发生的事还是将要发生的事？有没有第二个独立来源？
- 三点全"是" → 公开报道
- 能点开但是"观点" → 机构观点
- 缺一点 → 传闻
- 有矛盾 → 待确认

## 2. 事件五问（每条事件都要能答）

1. **什么时候发生？** → `date`（事件发生日，不是报道日）。与价格联动的日期单独给 `mark_d`。
2. **谁说的？** → `src` + `url`。转引要写"某媒体转述某机构"。
3. **影响供给还是需求？量级多大？** → `detail` 里写装置产能、检修天数、停车/复产套数、占行业产能比。
4. **同期价格怎么动？** → `price_ref`（当日报价）+ `after`（之后的价格/供需变化）。**只陈述，不用"因此"**。
5. **有没有反证或口径冲突？** → 有就写进 `detail` 或 `gaps`（状态 `口径冲突`）。

## 3. 事件类型（`tag`）与采购的相关性

只有这七类进时间线，其余（行情评论、分析师观点、行业会议）不进：

| tag | 内容 | 对采购的意义 |
|---|---|---|
| 检修 | 装置停车检修、计划检修、故障停车 | 短期供给收缩 → 抢货窗口 |
| 复产 | 检修结束、复产、提负荷 | 供给恢复 → 议价空间 |
| 投产 | 新建/扩建装置投料、产出合格品 | 中期供给增量 |
| 库存 | 港口/工厂库存、社会库存、可流通货源变化 | 判断累库/去库拐点 |
| 物流 | 海峡/港口/铁路/内河运输、车皮紧张、罐容 | 到货周期与运费 |
| 政策 | 环保、安全、出口退税、关税、限产、能耗双控 | 合规与成本 |
| 需求 | 下游集中停车/复产、开工率跳变、新增下游投产 | 需求塌陷或放量 |

**注意**：`价格`（如"期货涨停"）可以作为事件记录，但必须归到"价格"，且不能反过来当原因。它更适合放在 `after` 字段里描述。

## 4. 事件与价格的关联写法（防因果误读）

**错的写法**：
> "因为霍尔木兹海峡封锁，甲醇涨了 60%。"

**对的写法**：
> "7-09 海峡通航近乎停滞（公开报道）。同期太仓现货从 2690 涨至 9 月中旬 3790；但同期还有进口到港收缩、港口库存降至 42.67 万吨等并存因素，无法单独归因于海峡。"

**报告里强制出现的表述**（`qa_render.py` 会检查抽屉文案）：
> "这条事件在时间上先于价格变化，但先后不等于因果。"

## 5. 传闻的处置流程

1. 记进 `events` 但 `evidence` 填 `传闻` 或 `待确认`。
2. `assemble.py` 自动把它挪到 `events_rejected`，不参与 `marks`（图上不标点）、不进时间线。
3. 报告在时间线下方单列"未采纳消息"，写清：说了什么、谁说的、为什么没采纳（缺哪个确认）。
4. 供应商引用传闻压价/提价时，**用"未采纳区"直接回应**：承认听到过，说明目前能确认的边界。

## 6. 典型"伪事件"识别

| 说法 | 问题 | 处理 |
|---|---|---|
| "某装置将于下月检修" | 未来计划，可能变更 | 标 `待确认`；只写"计划"，不写"将" |
| "市场传某厂要停车" | 无装置名/无日期 | `传闻` |
| "行业开工率下降" | 无样本范围与周次 | 要求给样本与日期，否则 `待确认` |
| "库存大幅下降" | 无数字 | 要数字；拿不到就写"据称下降，具体数字缺口" |
| "某国禁止出口" | 政策未落地 | 找官方公告；没有则 `传闻` |
| "期货涨停带动现货" | 把结果当原因 | 归到 `价格` 类，并在 `after` 里描述 |

## 7. 事件对采购行动的含义（写进 `detail` 或报告解读，不写建议）

允许写：

- "该装置产能 X 万吨/年，检修 Y 天，对应损失量约 Z 万吨（按满负荷估算，实际开工未知）。"
- "同期港口库存由 A 万吨升至 B 万吨，为 N 周来首次累库。"
- "同期报价从 A 回到 B，回落 X%。"

不允许写：

- "因此建议提前锁量""后市将继续上涨""现在是最好的进货时点"。

## 8. 事件收集清单（采数阶段照此找）

- [ ] 本月/近三月所有装置检修与复产公告（含计划与实际）
- [ ] 新建/扩建装置投料、产出合格品的时间点
- [ ] 港口库存周度数据（至少 2 家口径）
- [ ] 工厂库存与待发订单
- [ ] 行业开工率（分工艺路线/分区域）
- [ ] 进口到港量、主要出口国装置状态
- [ ] 下游集中停车/复产
- [ ] 运输：海峡/港口/铁路/内河/罐容
- [ ] 政策：环保、安全、出口、关税、能耗
- [ ] 上游原料端事件（煤价政策、气价调整、矿石供应）
