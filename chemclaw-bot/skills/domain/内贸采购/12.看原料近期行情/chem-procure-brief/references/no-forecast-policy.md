# 不预测政策：禁用词与改写对照

> 采购底稿的价值来自"可核验"，一旦掺入预测，整份文件从"依据"降级为"观点"，还会被供应商反过来利用。
> `scripts/common.py: BANNED_WORDS` 会在 `validate.py` / `check_html.py` / `check_xlsx.py` 三处强制拦截。

## 1. 硬禁用（出现即 error）

| 类别 | 词 |
|---|---|
| 方向判断 | 看涨、看跌、看多、看空、利好、利空（作为判断时）、偏强、偏弱 |
| 预测 | 预计涨、预计跌、将上涨、将下跌、会涨、会跌、有望上行、或将继续 |
| 时点建议 | 抄底、逃顶、买入、卖出、囤货、锁量（作为建议时）、观望 |
| 绝对化 | 必涨、必跌、稳赚、翻倍、暴涨（作为预期时） |
| 类比预测 | 历史会重演、按以往规律将 |

## 2. 软风险词（不报错但要人工复核）

"将会""有望""或将""预计""预期""料将""如果……则……""大概率""大概率会"
—— 出现在 `detail`/`facts`/`talk.a` 中一律改写。

## 3. 改写对照表

| ❌ 原句 | ✅ 改写 | 为什么 |
|---|---|---|
| 后市看涨，建议提前锁量 | 10-09 至 10-16 报价由 A 回落至 B；同期港口库存由 X 增至 Y | 只陈述已发生 |
| 预计短期内仍有下跌空间 | 当前处近 90 天 50% 分位；区间低点为 C（日期） | 用位置代替方向 |
| 成本支撑较强，下方空间有限 | 某路线完全成本 X 元/吨（日期），当期报价 Y | 用数字代替形容词 |
| 因装置停车导致价格上涨 | 装置于 D 日停车（公开报道）；同期报价由 A 升至 B | 先后≠因果 |
| 需求即将好转 | 下游开工率 A%→B%（日期区间）；某下游装置 D 日复产 | 已发生 vs 将发生 |
| 建议在回调时采购 | 库存可支撑至 D 日；当前价处 N% 分位；报价区间 A–B | 给事实，把决定权留给人 |
| 供应商涨价有炒作成分 | 供应商报价 X；同期竞拍成交 Y；两者差 Z（口径差异说明） | 不评判动机 |
| 地缘冲突将推高价格 | 地缘事件 D 日发生（来源）；同期报价由 A 到 B；进口量同期 C 万吨 | 不预测传导 |
| 价格已经筑底 | 近 30 天报价区间 A–B，低点出现在 D 日 | 描述事实 |
| 关注后续政策影响 | 政策于 D 日发布（原文链接）；对 X 的规定为"……" | 引用原文，不给影响判断 |

## 4. 允许出现的"方向类"表述（白名单）

这些是**描述过去**，不是预测：

- 上涨 / 下跌 / 回落 / 反弹 / 走高 / 走低（**必须带日期与幅度**）
- 利多 / 利空（**只用于 `events[].impact` 字段，且后面跟"（对价格，事后）"**）
- 累库 / 去库 / 提升负荷 / 降低负荷（带数据）
- 同期 / 之后 / 较 / 相比

## 5. 遇到"客户/供应商原话含预测"怎么办

允许保留在 `talk[].q`（提问原文），**答案必须中性化**：

```json
{"q":"价格是不是还要跌？",
 "a":"我不做方向判断。能确认的是：10-16 太仓区间 3890–4030，较 10-09 高点 4880 回落约 19%；港口库存 36.72 万吨、为近期首度累库；下游 MTO 开工 76.69% 且在下降。这些是已发生的事实，您可以根据自己的库存天数和采购节奏判断。"}
```

## 6. 为什么这条政策对采购特别重要

1. **采购要向上汇报**。含预测的底稿一旦被老板当作依据下单，事后追责落在写报告的人身上。
2. **供应商会利用预测**。"你们报告说要涨"会被拿来压价或催签。
3. **预测几乎必然错**。化工现货受装置故障、政策、地缘影响，方向预测的胜率不足以支撑决策。
4. **事实足够有说服力**。"10-16 太仓 3983、较 10-09 高点回落 19%、港口首度累库、MTO 开工环比 -3.01pct"比"后市偏弱"有力得多。

## 7. 自检方式

```bash
python scripts/validate.py research.json         # 含方向词 → error，流水线停止
grep -n "将\|预计\|有望\|抄底\|看涨\|看跌" research.json
```
第二条命令的输出逐条人工确认：是引用原文（可保留在 `talk[].q` 或事件标题里的机构原文），还是自己写的判断（必须改）。
