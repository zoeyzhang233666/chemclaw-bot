# 时间序列分析（现货报价口径）

> 现货不是期货：**没有每一天的数据**。所以采购版的一切统计都必须带"样本数"，否则就是在骗自己。

## 1. 期现货的差别（决定了算法不同）

| | 期货 | 现货报价 |
|---|---|---|
| 频率 | 每个交易日 | 不定：日度/隔日/周度/零星 |
| 缺失 | 只有节假日 | 大量缺失，且**缺失不等于没变化** |
| 处理 | 直接算 | **绝不插值**，只按真实点算 |
| 极端值 | 涨跌停有规则 | "小单最低价""高价成交"会让区间虚胖 |

因此本技能采取：**区间带（低–高）+ 中值连线 + 样本数显式标注**，而不是单线。

## 2. 区间涨跌（`chg`）

算法（`common.seq_stats`）：

```
截止日 = 序列末日（锚价日）
对每个窗口 W ∈ {7, 30, 90, 365, 1095} 天：
    基准日 = 序列中最后一个满足 date ≤ (截止日 − W) 的报价日
    涨跌额 = 末日中值 − 基准日中值
    涨跌幅 = 涨跌额 / 基准日中值
    同时输出：实际天数、期间报价点数
```

**为什么基准日要"向前找最后一个"而不是"取整月/整周"**：现货报价日不规则，取整会造成"30 天窗口实际跨了 26 天"这种隐蔽误差。向前找真实点最接近"同一口径对比"的语义。

**必须同时展示 `n_between` 与 `exact_days`**：读者要能一眼看出"这个 30 天跌幅其实只由 4 次报价构成"。

## 3. 历史分位与区间位置（`win`）

```
分位 pct_rank = #{中值 ≤ 当前价} / 样本数 × 100
区间位置 pos_in_range = (当前价 − 窗口低点) / (高点 − 低点) × 100
```

两者不同，不能混用：
- **分位**回答"在这段时间里，现在算贵的还是便宜的"（相对多数）。
- **区间位置**回答"现在离上下沿有多远"（相对极值）。
- 反例：连续 20 天在 3900–4000 之间横盘，某天突然跌到 3700，分位会很低（多数日子比现在高），但区间位置也可能很低——两者同向；而如果 20 天里 19 天都在 3800，1 天飙到 5000 再回落，分位中等但区间位置会很低。

**样本纪律**：
- 样本 < 3：不计算，报告显示"缺口"。
- 3 ≤ 样本 < 8：计算但报告必须加"样本很薄"标记（`assemble.py` 会自动加 caveat）。
- 样本 ≥ 8：正常展示。

## 4. 异常点（采购需要关注的"突然动"）

对相邻两个真实报价点计算变动率：

```
Δ = |中值₂ − 中值₁| / 中值₁
```

- 超过 `meta.anomaly_pct`（默认 3.5%，波动大的品种建议 5–8%）即标为异常点。
- 异常点必须挂上**同期事件**：这是"价格为什么动"的唯一合法解释路径，且只能写成"同期发生"，不能写成"因为"。
- 若异常点找不到任何事件：这本身是重要信息，写进 gaps（"本次异动未找到公开归因"），不要硬编理由。

## 5. 区域价差的两条铁律

1. **只在同日比**。跨日相减得到的是时间差。
2. **价差 ≠ 地区溢价**。同日价差里包含：运费 + 仓储/罐租 + 品质差 + 品牌差 + 提货方式差 + 付款条件差。拆不开就在报告里明说"含运费等，不可直接当溢价"。

采购视角的价差用法：

| 价差方向 | 采购含义 | 必须先确认 |
|---|---|---|
| 远端便宜且价差 > 运费 | 调货可能划算 | 运价、运力、到货周期、品质是否一致 |
| 港口贵、产区便宜 | 港口在赚"稀缺" | 港口库存、到港量、是否真有低价货可发 |
| 进口折算价 < 港口价 | 进口替代窗口 | 汇率、税费、船期、进口货品质、罐容 |
| 同城不同库差价大 | 换库即可省钱 | 罐租、装卸费、是否同品牌 |

**没有运价数据时**：价差只能描述，不能下"该调货"的结论。这时 `chain_proof` 里对应的"产区→销区"链路要标 `checked:false`。

## 6. 成本线怎么叠在价格图上

- 成本是**参考线**（水平虚线），不是报价，不参与分位计算。
- 三种口径分开画：完全成本 > 现金成本 > 原料成本。图上最多画两条，其余的放表格。
- 成本线跨越时间时其实是变化的（煤价会动），如果只有单点成本，必须在图上说明"成本为某日快照"。
- **"现货 − 成本"只能是参考差值**，因为成本口径往往含税含运费假设不同，报告里禁止把它叫"利润"。

## 7. 季节性怎么处理（可选）

- 只有 ≥3 年同一采购点数据时才做季节性；否则不写。
- 做法：按自然月取中位数，输出"过去 3 年各月报价中位数"，**只描述分布，不做季节预期**。
- 常见错误：用期货连续合约跨年数据做季节，遇到主力换月会得到假峰谷（本技能里换月导致的单日大跳必须识别并剔除或标注）。

## 8. 数据质量自检（每次出稿都跑一遍）

| 检查 | 阈值 | 处理 |
|---|---|---|
| 同一采购点同日重复报价 | 出现即查 | 只保留第一条（`series_from_quotes` 已去重），差异写进 caveats |
| 低 > 高 | 出现即报警 | 脚本自动交换并记录 |
| 与相邻点偏离 > 25% | 查 | 确认是否小单/大单口径，必要时单独成点 |
| 报价日期缺失 | 出现即 | 该条不进序列，只进报价表并标"日期缺口" |
| 序列中跨月大跳 | 查 | 是否为换月/合约切换（期货）或口径变更（现货） |
| 全部采购点样本 < 8 | 出现即 | 报告顶部加"样本薄"提示（自动） |

## 9. 给老板看的三个数字

首屏只放三个最能回答"贵不贵"的数字：

1. **当前价**（含日期、口径、来源）—— 我在跟谁比。
2. **近 90 天分位 + 区间**（含样本数）—— 现在处在什么位置。
3. **近 7 天 / 30 天变动**（含基准日）—— 最近在往哪走（**描述过去，不预告未来**）。

其余全部放下面，不要挤首屏。
