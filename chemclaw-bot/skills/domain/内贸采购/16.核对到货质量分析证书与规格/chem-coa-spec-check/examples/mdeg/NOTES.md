# 样例说明：工业用乙二醇（模拟）

## ⚠️ 先说清楚

本样例的**企业名称、批号、日期、全部检测数值均为模拟构造**，用于演示核对流程与判定口径，
**不得作为真实质量记录、索赔依据或任何商务结论**。所有样例文件顶部都有"模拟 SIMULATED"水印。

---

## 1. 为什么选乙二醇

它是"看起来简单、实际处处有坑"的典型：

| 坑 | 本例怎么体现 |
|---|---|
| 同指标两种单位 | 水分：规格 `≤0.08 %`，COA 报 `865 ppm` |
| 极小量杂质换单位 | 铁：规格 `≤0.5 ppm`，COA 报 `580 ppb` |
| 同名不同指标 | COA 写"纯度"，规格写"乙二醇纯度（质量分数）"，需别名表打通 |
| 方法差异 | 酸度规格约定 GB/T 14571.4，COA 未标注方法 |
| 检出限陷阱 | 批次 A 酸度报 `0.0001 %`，上限 `0.001 %`，恰为 1/5 → 疑似 LOD |
| 合同放宽标准 | 合同 ≥99.85 %，GB/T 4649 为 ≥99.9 %，**不得**按标准判不合格 |
| 批号张冠李戴 | COA 纸面批号 `DY260603B` ≠ 到货批号 `DY-EG-260603B` |
| 结论自相矛盾 | 证书写"符合优等品要求"，明细有 5 项超限 |
| 定性项 | 外观规格"无色透明、无可见机械杂质"，COA"微带浅黄色" |
| 缺检 | 灰分 / DEG / 蒸发残渣整行缺失，酸度标"未检测" |

## 3. 规格与约定（摘要）

| 指标 | 采购规格书 Rev.C | 合同技术附件（优先） | 判定依据 |
|---|---|---|---|
| 乙二醇纯度 | ≥99.9 % | **≥99.85 %** | 合同 |
| 水分 | ≤0.08 % | 同 | 规格 |
| 色度 | ≤10 Hazen | 同 | 规格 |
| 酸度（以乙酸计） | ≤0.001 % | 同 | 规格 |
| 铁 | ≤0.5 ppm | 同 | 规格 |
| 醛类（以乙醛计） | ≤5 ppm | 同 | 规格 |
| 灰分 | ≤0.002 % | 同 | 规格 |
| 二乙二醇 DEG | — | **≤0.01 %** | 合同 |
| 外观 | 无色透明、无可见机械杂质 | 同 | 规格 |
| 密度（20℃） | ≥1.112 g/cm³ | 同 | 规格 |
| 蒸发残渣 | ≤0.002 % | 同 | 规格 |

`GB/T 4649-2018`（含量 ≥99.9 %）仅作参照标准入库，
**合同已放宽到 ≥99.85 %，引擎不得用标准提高要求** —— 这是本案例的核心验证点之一。

## 4. 批次 A（干净）· DY-EG-260512A / COA-DY-2605-1182

判定：**符合 10 · 无法判断 1**，完整性 100。

唯一没判"符合"的是酸度：COA 报 `0.0001 %`，上限 `0.001 %`，
数值恰好是上限的 1/5 量级、有效位又和限值同档 ——
这符合"仪器低于报告下限时直接把 LOD 当结果打印"的特征，引擎给"无法判断"并提示核对原始图谱。
**这个不是错判，是刻意留的示范**：一个漂亮的合格数，可能是仪器在说"我没测到"。

## 5. 批次 B（重点）· DY-EG-260603B / DY-QC-26-0603

判定：**符合 2 · 不符合 5 · COA未检测 4**，完整性 30（高 3 / 中 2）。

| 指标 | COA | 限值 | 判定 | 偏离 |
|---|---|---|---|---|
| 纯度 | 99.86 % | ≥99.85 % | 符合 | — |
| 密度 | 1.1171 g/cm³（15℃） | ≥1.112 | 符合 | — |
| **水分** | **865 ppm** = 0.0865 % | ≤0.08 % | **不符合** | **+8.13 %** |
| **醛类** | **7.2 ppm** | ≤5 ppm | **不符合** | **+44.00 %** |
| **色度** | **12 Hazen** | ≤10 | **不符合** | **+20.00 %** |
| **铁含量** | **580 ppb** = 0.58 ppm | ≤0.5 ppm | **不符合** | **+16.00 %** |
| **外观** | 微带浅黄色，透明度略差 | 无色透明、无可见机械杂质 | **不符合**（定性） | 不给% |
| 酸度 | 未检测 | ≤0.001 % | COA未检测 | — |
| 灰分 | 缺行 | ≤0.002 % | COA未检测 | — |
| DEG | 缺行 | ≤0.01 % | COA未检测 | — |
| 蒸发残渣 | 缺行 | ≤0.002 % | COA未检测 | — |

证书完整性问题：
1. **批号**：纸面 `DY260603B` ≠ 到货 `DY-EG-260603B`（高）
2. **结论一致性**：写"符合优等品要求"，但有 5 项超限（高）
3. **缺失指标**：4 项规格约定指标缺失/未检测（高）
4. 无证书编号/防伪码、无签章（中）
5. 密度标 15 ℃ 而规格为 20 ℃（中）

方法差异：灰分 / DEG / 蒸发残渣"未标注方法"，酸度"方法与约定不同"。

趋势：水分 0.062 → 0.058 → 0.069 → 0.073 → 0.075 → **0.0865 %** 连续 4 批上行；
色度 4 → 3 → 5 → 6 → 5 → **12**；醛 2.4 → 2.1 → 2.8 → 3.0 → 3.1 → **7.2 ppm** 突增。
**报告只陈述事实与方向，不推断原因**（可能是检修、原料切换、储运污染……需要供应商说明）。

## 6. 怎么复现

```bash
cd chem-coa-spec-check
python scripts/build_all.py            # 重建样例 + 校验 + 生成 HTML/XLSX
```

产物在 `examples/mdeg/out/`：
- `乙二醇到货COA核对报告_20260608-核对报告.html`（单文件，双击可看）
- `乙二醇到货COA核对报告_20260608-核对工作簿.xlsx`（12 页签）

## 7. 换成你自己的产品

1. 复制 `templates/data.template.json` → `examples/<你的产品>/data.json`
2. 用 `scripts/extract.py` 把 COA/规格抽成候选 JSON，**逐项确认**
3. 填 `indicator_aliases`（这决定"能不能比"）
4. `python scripts/build_all.py --data examples/<产品>/data.json --no-samples`
