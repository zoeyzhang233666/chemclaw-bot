# 指标匹配与判定规则

六种状态，**只此六种**，不允许自造"基本符合""疑似合格"之类的中间词。

| 状态 | 含义 | 谁的责任 |
|---|---|---|
| `符合` | 可比、可量化核验，且实测在限值内 | — |
| `不符合` | 可比、可量化核验，且实测越过限值 | 供应商 |
| `规格未约定` | 合同/规格书/适用标准都没有这条限值 | 采购（采购条款未覆盖） |
| `COA未检测` | 规格约定了，但 COA 缺该项 / 空值 / 写明未检测 | 供应商 |
| `无法判断` | 有数但不能比：名称/量纲/方法/基准/限值类型任一不可比，或检出限不明 | 双方补材料 |

---

## 1. 判定顺序（**顺序本身就是规则**）

```
① 规格侧有没有这条限值？
     没有 → 规格未约定           （生产规格、供应商建议值只作提示，不改判定）
② COA 有没有这个数？
     没有 / 空 / 标未检测 → COA未检测
③ 能不能比？（可比性五维，全过才算"能比"）
     任一不过 → 无法判断
④ 数值怎么比？（按限值类型）
     上限 / 下限 / 区间 / 规定值 / 定性
⑤ 比出结果 → 符合 / 不符合（并计算偏离）
```

把它写成一条线：**先问"有没有"，再问"能不能比"，最后才问"大不大"**。
反过来（先比大小）是最典型的错误来源。

---

## 2. 可比性五维

| 维度 | 通过条件 | 不过时 |
|---|---|---|
| **名称** | 两个名字通过 `indicator_aliases` 落到同一个 `canonical` | `无法判断`："名称相似不等于同一指标，需人工确认对应关系" |
| **量纲** | 两者单位能换算到同一量纲（见 unit-conversion.md） | `无法判断`，并说明缺什么条件（如密度） |
| **方法** | 方法相同，或同属 `equivalent_methods` 的一组，或**规格侧未规定方法** | `无法判断` |
| **基准** | 都是收到基，或都是干基/溶液基，或有明确换算系数 | `无法判断` |
| **限值类型** | COA 给的值形态能支撑判定（如限值是上限、COA 报的是单值/上限/未检出+检出限） | `无法判断` |

> 细节：规格侧**没有**写方法时，方法维度记"通过"但附注"规格未规定方法，无法核对方法一致性"——
> 这不是放松，是**不把规格自己的缺失算成供应商的错**。

---

## 3. 限值类型与比较

| 规格原文 | 类型 | 判定 |
|---|---|---|
| `≤0.08` `＜0.001` | 上限 | 实测 > 上限 → 不符合（等于上限算符合） |
| `≥99.9` `＞99` | 下限 | 实测 < 下限 → 不符合（等于下限算符合） |
| `0.001~0.005` `0.001-0.005` | 区间 | 实测落在闭区间内 → 符合 |
| `99.5`（单值） | 单值 | 实测必须等于；用于标称值 |
| `无色透明` `不得检出` | 定性 | 见下节 |

### 偏离怎么算

```
上限类：偏离 = (实测 − 上限) ÷ 上限
下限类：偏离 = (下限 − 实测) ÷ 下限
```
一律**以限值为分母**（不以实测为分母），这样不同指标之间可以横向比较严重程度。
报告中同时给出绝对值与百分比：`+8.13%（0.0065 %）`。

> 例：水分 865 ppm vs 上限 0.08 % → 换算 0.0865 % → (0.0865−0.08)/0.08 = **+8.13 %**。
> 若误按实测为分母会得到 7.5 %，与"超出多少"的直觉不符，也便于被供应商反驳。

## 4. 定性/描述性指标

规则写在 `coa_lib.QUAL_KEYWORDS` / `QUAL_NEGATIVE`：

1. 规格关键词（如"无色透明"、"无可见机械杂质"）**全部**出现在 COA 描述中 → `符合`
2. COA 描述里出现**相悖表述**（如"微带浅黄"、"略显浑浊"） → `不符合`
3. 都不满足 → `无法判断`，交人工看原件的目视记录/照片

> 定性项**不给偏离百分比**。函件里写"COA 描述与规格描述不一致，以原始目视记录复核为准"，
> 不写"外观超标 20 %"——那是在编数字。

---

## 5. 检出限（最容易漏判的一环）

| COA 写法 | 处理 |
|---|---|
| `未检出` + 有检出限 `0.5 ppm`，限值 `≤1 ppm` | 检出限 ≤ 限值 → `符合`，理由注明"低于检出限" |
| `未检出` + 有检出限 `2 ppm`，限值 `≤1 ppm` | 检出限 > 限值 → `无法判断`：这个结果证明不了 ≤1 ppm |
| `未检出` + **无**检出限 | `COA未检测`：未检出 ≠ 合格，缺检出限无从比较 |
| 报了单值 `0.0001 %`，限值 `≤0.001 %` | 若恰为限值的 1/5 量级且有效位不少于限值 → 提示"疑似检出限"→ `无法判断` |

最后一行的道理：很多仪器软件在"低于报告下限"时**直接把 LOD 数值当结果打印**。
它看起来是个漂亮的合格数，其实是仪器说"我没测到"。判"符合"就是把风险当成了数据。

---

## 6. 规格的取用顺序

```
合同技术附件 (priority 1)  →  采购规格书 (priority 2)  →  适用标准 (standards)
```

- 合同条款优先。**合同放宽了标准要求时，按合同判**（本例：合同 ≥99.85 %，标准 ≥99.9 %，不得以提高要求为由判不合格）。
- 高优先级来源没有该指标时，才向下一级取，并在报告中标注实际依据来源。
- 同一优先级两份文件冲突 → 报告"口径提示"，不静默取一个。

---

## 7. 严重度

| 级别 | 触发条件 |
|---|---|
| 高 | 强制项（mandatory）超限；或偏离 ≥ 20 %；或完整性致命项（批号不符、结论矛盾、方法不可比且影响判定） |
| 中 | 一般超限；方法差异；一般完整性缺陷 |
| 低 | 提示性事项（复检期临近、包装标识不全等） |

完整性得分 = `100 − 18×高 − 8×中 − 3×低`，下限 0。
**得分低不等于货差**——它衡量的是"这份证书能不能支撑验收"。

---

## 8. 禁止的做法

- ❌ 因为名字像就直接比（`总酸` vs `酸度`、`醛类` vs `乙醛`）
- ❌ 为了让数对上而改单位、改小数点、改批号
- ❌ `未检出` 直接判符合
- ❌ 换算前后结论变了还照一个写（必须 `无法判断` + 提示回原件）
- ❌ 用生产规格/供应商建议值代替合同限值
- ❌ 输出"建议收货/建议退货"
