# 异常情况处理与人工确认

> 本文件是"不许猜"这条纪律的操作手册。**凡是本文件列出的情况，脚本必须停下来交给人。**

---

## A. 原文不清（扫描件、拍照、传真）

| 现象 | 处理 |
|---|---|
| 数字看不清（`5B0`、`86.5?`） | `value` 填 `"?"` 占位并置 `conf:"低"`，报告标"需人工确认"，**不得填最像的数字** |
| 小数点位置可疑（`0.08` 还是 `0.008`） | 两个都写进 `review_log`，判 `无法判断`，回原件 |
| 单位被裁切（只剩 `ppm` 的 `pm`） | 按"单位不可识别"→ `无法判断` |
| 表格错行（值和指标名对不上） | 整块判 `无法判断`，不要"顺一下" |
| OCR 把 `≤` 认成 `<` | 影响很小（都按上限处理），但要在 `review_log` 记录 |
| OCR 把 `≥` 认成 `≤` | **方向反转**，必须人工判；脚本层面视为不可判定 |

**复核方式**：让报告"点指标 → 跳原文位置"去比对同一行；
看不清的，回供应商要**可复制文本的电子版 COA**（PDF 文字版），这比反复 OCR 可靠。

## B. 批号 / 日期不吻合

| 现象 | 判定 | 说明 |
|---|---|---|
| 证书批号 ≠ 到货单批号（如 `DY260603B` vs `DY-EG-260603B`） | 完整性 **高** | 可能是简写，也可能张冠李戴。要供应商**出具批号对应说明**，不能在数据里"改写" |
| 无证书编号 / 无防伪码 / 无签章 | 完整性 中~高 | 无法证明证书真实性 |
| 检测日期早于生产日期 | 完整性 高 | 时间逻辑矛盾 |
| 检测日期距到货 > 常规周期 | 提示 | 需说明留样复检情况 |
| 复检期已过（相对 `meta.as_of`） | 提示 | 提醒是否仍在保质期内使用 |

---

## C. 结论与数据矛盾

COA 写"符合优等品要求"，但明细里有超限值 —— 这是异议里**最硬的一条**（证书自证其错）。
处理：列明哪些项超限、各超多少，要求"书面说明结论判定依据；如系笔误应作废重发"。
**不接受**"以结论为准"。

---

## D. 指标名称/口径差异（高频误判区）

| 情况 | 正确做法 |
|---|---|
| `总酸` vs `酸度` | 多数体系**不等价**（总酸含强弱酸/其他酸性物）→ 未确认前 `无法判断` |
| `醛类` vs `乙醛` | 醛类是总量、乙醛是单一组分 → 不等价 |
| `纯度` vs `含量` vs `主含量` | 通常等价，但若一为"100−杂质"法、一为色谱归一化，需注明方法差异 |
| `色度` vs `透光率` | 不相关，不可互相替代 |
| 干基 vs 收到基 | 需换算系数，否则 `无法判断` |
| 单位同形不同义（`%` 表示质量分数 vs 体积分数） | 必须从原文上下文确认，写进 `review_log` |

**判定口径**：只要不能从文件本身证明两个名字指同一指标，就 `无法判断`，
并在报告里写清"需人工确认对应关系"——这比判错后被打回好得多。

## E. 与合同/规格的条款冲突

| 情况 | 处理 |
|---|---|
| 合同技术附件与采购规格书限值不一致 | 按 `priority` 取合同；报告"口径提示"列出差异 |
| 合同放宽了国标要求 | **按合同判**（不得用国标提高要求） |
| 合同引用了某个国标版本，但 COA 用了另一版本 | 方法版本差异 → 落"方法差异"，要求说明 |
| 规格书没有该指标，但生产规格/供应商建议值有 | 判 `规格未约定`，把建议值作为**提示**展示，不改判定 |
| 合同未约定方法，COA 用了内部方法（如 `企标 Q/XXX`） | 记录方法，方法维度不阻断，但提示"方法未经合同约定，建议索取方法文本" |

---

## F. 数据缺失

| 缺什么 | 影响 | 处理 |
|---|---|---|
| 缺复检期 | 影响有限 | 提示 |
| 缺检测方法 | 该项 `无法判断`（若规格约定了方法） | 方法差异 + 要求补标 |
| 缺整行指标 | `COA未检测` | 合并成一条异议点，列出全部缺项 |
| 缺历史批次 | 趋势无数据 | 报告"无可用序列"，不要用单批"推趋势" |
| 缺规格文件 | 全部 `规格未约定` | **必须先拿到规格**，报告会红字警示 |

## G. 人工确认清单（每次交付前逐项打勾）

- [ ] 每个 `conf:"低"` 的抽取结果，都已回原件确认并写入 `review_log`
- [ ] 所有 `无法判断` / `规格未约定` 项，理由能一句话讲清
- [ ] 所有 `不符合` 项，偏离计算已按"以限值为分母"复核
- [ ] 发生过换算的项目，已核对"是否跨判定线"
- [ ] 批号、生产日期、检测日期、方法、结论五项已在原件上逐一确认
- [ ] 报告未出现"建议收货/建议退货/同意接收"
- [ ] `validate.py` 通过（0 错误）
- [ ] 模拟数据已标注，且未被当作真实记录流转

## H. 什么时候必须"停下来问人"

1. 规格限值本身有歧义（`≤0.08` 与 `≤0.080` 是否同一条、区间是否含端点）
2. 判定结果的严重程度会改变商务处置（已超限但幅度极小、属临界值）
3. 供应商主张方法等效
4. 出现 `无法判断` 项占比 > 20 %
5. 同一指标在两张规格里限值冲突且优先级相同

**停下来的正确写法**：在报告"后续动作"里写"需 XX 方确认 YY 后方可判定"，
而不是给一个"大概符合"。宁可少判，不可错判。
