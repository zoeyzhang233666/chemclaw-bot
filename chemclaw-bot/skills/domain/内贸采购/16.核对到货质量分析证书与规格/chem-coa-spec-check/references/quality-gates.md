# 质量门（Quality Gates）

交付前逐关通过。任何一关标 **阻塞** 的，不允许把文件交出去。

---

## G1 输入关（`validate.py` 结构层）— 阻塞

| 检查 | 通过条件 |
|---|---|
| 必备字段 | `meta.title/as_of/target_coa_batch`、`product.name/indicator_aliases` 齐全 |
| 重点批次 | `target_coa_batch` 必须存在于 `coas[].batch_no` |
| 批号唯一 | 同一份数据里批号不得重复 |
| 别名无歧义 | 同一别名不得挂在两个 canonical 下 |
| 至少一个规格 | `specs` 或 `standards` 非空 |
| 指标行完整 | 每行含 `name/name_key/value/unit` |
| 日期可解析 | `mfg_date` / `test_date` 能解析成日期（否则警告） |

## G2 语义关（判定合法性）— 阻塞

- 每条判定的状态词 ∈ {符合, 不符合, 规格未约定, COA未检测, 无法判断}
- 每条判定都有 `reason` 文本
- `不符合` 的数值型指标必须有偏离（定性项除外）
- `无法判断` 若可比性五维全通，必须能说明原因（检出限/数值结构等）
- 限值能被解析成"上限/下限/区间/单值/定性"之一

## G3 合规关（红线）— 阻塞

| 红线 | 说明 |
|---|---|
| 不得输出收货决定 | 报告中不得出现"建议收货/建议退货/同意接收/拒收该批"等（免责句中的否定式除外） |
| 模拟数据必须标注 | `simulated: true` 时全篇加水印 + 禁用说明 |
| 不得虚构数据 | 报告中的每个数值都能追到 `data.json` 的某个字段 |
| 不得隐藏无法判断 | 报告必须展示全部六种状态的计数（含 0 值） |

## G4 成品关（渲染后复查）— 阻塞

| 检查 | 通过条件 |
|---|---|
| HTML 无 `None`/`NaN`/`undefined` | 正文（去掉 script/style 后）不出现 |
| 无模板占位符 | 不出现 `{{...}}` 或 `{field}` |
| 计数一致 | `kpis.total` == 明细行数 == 报告中展示的项数 |
| Excel 可打开 | `check_office.py` 返回 pass；页签数符合预期 |
| 公式可重算 | 偏离公式经 LibreOffice 重算后与引擎值一致（±1e-9） |

## G5 可追溯关 — 阻塞

- 每个指标行都有 `loc`（COA 原文位置）与 `spec_source`（规格来源）
- 报告中点击指标能定位到"COA 第 N 行 / 规格 §x 表1 第 N 行"
- 至少一份原始文件（样例 HTML/PDF）随包提供，供验证定位

## G6 覆盖率体检 — 警告

- 可量化核验比例 = (符合+不符合) ÷ 总数
- < 50% → 警告："规格方法/单位/检出限缺失过多，建议先补规格条款"
- 报告必须写明"另外 N 项需补充条件或人工确认"，不得暗示全部已判

## 出现失败怎么办

| 现象 | 原因 | 处理 |
|---|---|---|
| `STATUS 判定词非法` | 某处手写了新状态 | 改回六种之一 |
| `ALIAS_DUP` | 别名表重复 | 合并，保一个 canonical |
| `TARGET 不在 coas 中` | 批号写法不一致 | 用 `coas[].batch_no` 的写法 |
| `DECISION` 命中 | 函件里写了"建议收货" | 改成"请贵司说明/请提供复检报告" |
| HTML `None` | 模板取到空字段 | 用 `fmt()`/默认值兜底 |
| 公式重算对不上 | 偏离分母用错 | 一律"以限值为分母" |
