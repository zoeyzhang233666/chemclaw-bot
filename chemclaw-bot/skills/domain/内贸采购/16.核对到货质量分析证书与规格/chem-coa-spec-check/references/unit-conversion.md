# 单位换算与量纲

**原则：换算必须"可逆、可写清系数、可被对方复算"。** 写不清系数的换算，一律不做。

---

## 1. 可以换算（精确系数）

### 质量分数（化工 COA 主战场）

```
1 %   = 10,000 ppm = 10,000 mg/kg = 10,000,000 ppb
1 ppm = 1 mg/kg = 1,000 ppb = 1 μg/g
1 ppb = 1 μg/kg
```

| 从 | 到 | 系数 |
|---|---|---|
| % | ppm | ×10 000 |
| ppm | % | ×0.0001 |
| ppm | ppb | ×1 000 |
| ppb | ppm | ×0.001 |
| g/kg | % | ×0.1 |

> **工程上必须记住的三笔账**（本例实际用到）
> - 水分 865 ppm = **0.0865 %** ＞ 上限 0.08 % ⇒ 超限
> - 铁 580 ppb = **0.58 ppm** ＞ 上限 0.5 ppm ⇒ 超限
> - 若把 865 ppm 当成 "865 %" 或与 0.08 直接比大小，结论全错

### 质量浓度

```
1 g/L = 1 000 mg/L；1 mg/L = 1 000 μg/L
```
（`ppm(v/v)` 按 `mg/L` 处理，仅在水溶液近似成立）

### 温度（仿射换算，不是比例换算）

```
℉ = ℃ × 9/5 + 32
```
温度是**测试条件**，不是指标值。`密度（15℃）` 与 `密度（20℃）` 是**不同条件**，
没有温度-密度数据就不换算（落 `无法判断`），并提示"密度须注明 20 ℃"。

### 密度 / 时间 / 色度

| 量 | 换算 |
|---|---|
| 密度 | `g/cm³ = g/mL`；`kg/m³ × 0.001 = g/cm³`（**必须同温度**）|
| 时间 | `h × 60 = min`；`d × 1440 = min` |
| 色度 | `Hazen = Pt-Co = 铂钴色号`；不同光源/比色皿不可比 |

## 2. 不能换算（缺条件）

| 情形 | 为什么 | 处理 |
|---|---|---|
| `%` ↔ `mg/L`、`mg/kg` ↔ `mg/L` | 质量分数 ↔ 体积浓度，需要**同温度下的密度** | 无密度 → `无法判断`，写明"缺密度（20 ℃）" |
| 干基 ↔ 湿基 | 需要水分含量或换算系数 | 无系数 → `无法判断` |
| `密度` 15 ℃ ↔ 20 ℃ | 需要温度-密度曲线 | `无法判断` + 提示 |
| `Hazen` ↔ `吸光度` / `透光率` | 不同测量原理，无通用换算式 | 视为不同量纲 |
| `mol%` ↔ `wt%` | 需要分子量 | 无分子量 → `无法判断` |

> **不要"约等于"**：`1 % ≈ 10 g/L（按密度 1）` 这种近似在验收判定里不接受。
> 想要近似值用于直觉判断，可以在报告里写成"供参考"，但**判定必须按缺条件处理**。

---

## 3. 换算台账（报告必带）

引擎对**每一次**换算都记录：

```
批次 | 指标 | 原值 | 原单位 | 规格单位 | 量纲 | 系数 | 换算后值 | 换算说明 | 是否跨判定线 | 换算后判定
```

`是否跨判定线` 的意义：

- **换算前**判"符合"、**换算后**判"不符合"（或反过来）→ 说明**单位标注或小数点很可能有误**。
  此时引擎强制落 `无法判断` 并在报告中高亮，要求比对原件（`_crosses_limit`）。
  实证：COA 写 "水分 0.865 %" 而实际是 "865 ppm"，一字之差结论相反。

---

## 4. 数字有效位与四舍五入

- **判定用全精度比较**，显示才截断。
  例：上限 0.08 %，实测 0.08004 % → 判 **不符合**，即使显示为 "0.080 %"。
- 显示规则：数值 `s ≤ 1` 用 4 位有效，`s > 1` 用 3 位有效，避免 "99.86000 %" 这种噪声。
- 不要在换算链路上多次取整（865 ppm → 0.0865 → 0.09 就毁了）。

---

## 5. 代码入口

`scripts/coa_lib.py`：

```
DIMENSIONS         # 量纲表，每项 {members:{单位:系数}, label, levels, hint}
unit_token(u)      # 单位 → (量纲, 归一化符号)，识别不了返回 (None, ...)
convert(v, u1, u2) # 返回 (新值, 说明)，不能换算时新值为 None、说明里写原因
```

新增一个单位：在对应 `_mkdim` 的 `members` 里加 `"归一化符号": 系数`，
并在 `levels` 里给出"粗/中/高精度"档位（用于决定显示位数）。
