# 分品类适配：换产品时到底要改什么

这套 skill 的骨架（证据五级、四层核验、差异判定、报价归一化）与品类无关。换产品时真正要改的只有三处：**质量维度、许可清单、问询问题**。

本文件按化工大类给出可直接套用的“自定义维度 + 必问问题 + 关键证照”。

---

## 一、大宗无机化工品

> 纯碱、烧碱、硫酸、盐酸、硝酸、磷酸、氯化钙、硫酸钠、硫化钠、碳酸氢钠

### 自定义维度（挑 2 个）
1. **产品物理形态与包装适配**：片碱/粒碱/固碱；纯碱轻质/重质；液体品的浓度与运输温度。
2. **生产装置与工艺路线**：氨碱 / 联碱 / 天然碱；离子膜 / 隔膜；是否自有配套原料（原盐、石灰石、合成氨）。
3. **副产物与联产品结构**：联碱法的氯化铵、氯碱的液氯，会反向影响主产品排产。
4. **区域供应与物流**：水运/铁运条件、散装罐车回程、交割地（若为期货品种）。

### 关键核验点
- **产能自洽**：设计产能 × 利用率 ≈ 产量，是所有大宗品的通用核验式。
- **停车检修**：大宗装置年度大修是断供主因，必须问检修窗口。
- **能耗/能效**：能效领跑者名单是很好的非上市公司能力旁证。
- **期货交割品牌名录**：能进交割品牌名录，等于被交易所核验过质量与规模。

### 必备证照
营业执照、**排污许可证**（必需）、安全生产许可证（涉危化装置）、工业产品生产许可证（**注：多数基础无机品已取消**）、食品生产许可证（食品级）。

### 高频问询
- 分牌号（轻质/重质、片/粒）的月度产量与库存？
- 年度检修计划与华东可分配量？
- 是否接受第三方 SGS/CCIC 抽检复检？

## 二、精细化工与中间体

> 医药中间体、农药中间体、染料中间体、电子化学品、香精香料、助剂

### 自定义维度（挑 2–3 个）
1. **工艺与合成路线**：几代工艺、是否为专利工艺、关键中间体是否自产。
2. **质量体系与杂质谱**：单杂/总杂上限、金属离子、残留溶剂、批间一致性（RSD）。
3. **定制化能力**：是否接受定制合成、放大能力（kg→t）、是否接受工艺转移。
4. **合规与客户审计**：是否有 GMP/ISO 15378/REACH 注册、是否通过跨国客户审计。

### 关键核验点
- **批产量与收率**：细化工的“产能”意义有限，看**单批产量 × 批次数**。
- **是否做贸易**：大量“中间体供应商”实为贸易商，必须核生产地址与反应设备清单。
- **客户结构**：是否为某单一客户专用线，会影响对其他客户的供应意愿。
- **三废处理能力**：细化工最大隐性风险，废水/危废处置资质不全者随时停产。

### 必备证照
营业执照、**排污许可证**、**危险化学品安全生产/经营许可证**（视危险性）、危废转移备案、ISO 9001/14001、REACH/REACH-like 注册（出口）。

### 高频问询
- 目标产品的**实际反应釜规格与批产量**、月批次？
- 关键杂质谱与批间一致性数据（近 10 批）？
- 三废处理方式与危废处置合同（是否自有 RTO/污水站）？
- 是否为某客户专线？我方量级能否插入排产？

## 三、高分子与树脂

> PE/PP/PVC/ABS/PC、环氧树脂、聚氨酯、橡胶、工程塑料、助剂母粒

### 自定义维度
1. **牌号与加工适配**：熔指、分子量分布、冲击强度、是否适配我方注塑/挤出/吹膜工艺。
2. **装置与产能**：单线规模、是否为大乙烯配套、检修周期。
3. **稳定供应与代工**：是否接受代工/贴牌、是否有再生料掺混风险。

### 关键核验点
- **牌号而非产能**：同一装置不同牌号价差巨大，比较必须落到具体牌号。
- **掺混与回料**：低价报价常伴随回料掺混，必须约定检测方法与抽检权。
- **交割品牌**（LLDPE/PP/PVC 期货）：交易所品牌名录是能力旁证。

## 四、溶剂与油品

> 甲醇、乙醇、丙酮、丁酮、甲苯、二甲苯、乙酸乙酯、白油

### 自定义维度
1. **纯度与水分**：色谱纯度、水分、色度（Pt-Co）、蒸发残留。
2. **储运与危化合规**：是否自有罐区、槽车资质、卸货条件。
3. **价格联动机制**：是否挂甲醇/原油指数，调价周期与幅度。

### 关键核验点
- 溶剂类供应商**贸易商比例极高**，厂家身份核验比价格更重要。
- 危化品经营许可必须在有效期内，且覆盖该品种。

## 五、食品与饲料添加剂

> 小苏打、柠檬酸、磷酸盐、维生素、氨基酸、防腐剂

### 自定义维度
1. **食品级资质完整性**：食品生产许可证（SC）+ 执行标准（GB 1886 系列）+ 重金属指标。
2. **认证与审核**：FSSC 22000 / BRC / HALAL / KOSHER。
3. **追溯与召回能力**：批号体系、留样制度。

### 关键核验点
- **SC 证与产品是否对应**：食品生产许可按**食品类别**发证，证上没有该类别就是无证生产。
- 证照有效期极易过期（常见 5 年），必须逐张核 `end` 日期。

## 六、危险化学品（通用附加）

不管哪一类，只要涉及危化品，就额外核：

- 安全生产许可证 / 危险化学品经营许可证（品种是否覆盖）；
- 运输资质（承运方道路危险货物运输许可）；
- 应急预案备案、重大危险源备案；
- 近三年事故记录（应急管理部门通报）。

## 七、改一份 data.json 的最小步骤

1. 复制 `templates/data.template.json`。
2. 改 `meta`：`product`、`doc_no`、`as_of`、`export_base`。
3. 改 `procurement`：标准、关键指标、收货地、量级。
4. 改 `suppliers`：2–5 家，填 `producer`、`site`、`plant_to_dest_km`。
5. 改 `dimensions`：把两个 `custom_*` 换成上面对应的维度，`hint` 写清判读要点。
6. 改 `evidence` 与各维度 `ev`：先有证据，再写结论。
7. 改 `questions`：套用对应品类的高频问询。
8. 跑：

```bash
python scripts/validate.py data.json
python scripts/build_all.py data.json --outdir out
```

`references/evidence-standard.md`、`quote-normalization.md`、`comparison-rules.md` 不需要修改。

## 八、跨品类的通用“三问”

无论什么产品，问询清单里都该有这三条：

1. **「你生产的是我买的这一支吗？」**——具体牌号/等级/规格，附检测报告。
2. **「你怎么证明是你在产？」**——排污许可、装置清单、发货工厂地址、装车照片。
3. **「如果我明天需要 3 倍量，你怎么给？」**——产能余量、检修计划、备选基地。
