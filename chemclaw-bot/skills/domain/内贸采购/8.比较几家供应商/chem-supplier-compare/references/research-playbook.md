# 检索手册：从哪里拿到能写进报告的东西

按“先官方后媒体、先一手后转述”的顺序检索。每一轮检索都要记录**查了什么、查到什么、没查到什么**，最后写进 `intel_reach`。

## 零、先定一个锚点日期

打开日历，记下今天的日期，写入 `meta.as_of`。之后所有“有效期是否过期”“近 12 个月”的判断都以它为准。**不要边查边改日期**，否则报告的时效口径会自相矛盾。

## 一、上市公司（信息密度最高，优先做）

### 1.1 定期报告（一站式解决 60% 的问题）

用巨潮资讯网的公告查询接口，比逐页点开快得多：

```http
POST https://www.cninfo.com.cn/new/hisAnnouncement/query
Content-Type: application/x-www-form-urlencoded

pageNum=1&pageSize=30&column=szse&tabName=fulltext&plate=
stock=000822,gssz0000822
searchkey=&secid=&category=category_bndbg_szsh;category_yjdbg_szsh;
trade=&seDate=&sortName=&sortType=&isHLtitle=true
```

- `stock=` 的格式是 `代码,orgId`，第一次可以从 `https://www.cninfo.com.cn/new/information/topSearch/query` 拿到 `orgId`。
- 沪市把 `column` 换成 `sse`、`stock` 写成 `600409,gssh0600409`。
- `category` 常用：`category_bndbg_szsh`（年报）、`category_yjdbg_szsh`（半年报）、`category_bndbg_yjdbg`（业绩预告）。

年报里要抠的段落，按优先级：

| 段落 | 能拿到什么 |
|---|---|
| 经营情况讨论与分析 | 分产品产能、产量、销量、库存、产能利用率、工艺路线 |
| 主要控股参股公司分析 | 子公司经营数据（常能发现亏损子公司） |
| 相关批复、许可、资质及有效期 | **整张许可清单**，是判断合规的黄金材料 |
| 行业情况 | 行业总产能、开工率、竞争格局（可做行业基准） |
| 公司未来发展的展望 | 在建项目、技改、产能置换 |
| 重要事项 / 诉讼仲裁 / 处罚整改 | 司法与合规风险 |
| 关联交易 | 与控股股东的采购/销售，可能影响成本与独立性 |
| 环境保护信息 | 排污、能耗、环保投入、事故 |

### 1.2 公告原文（比媒体的二手转述更准）

巨潮 PDF 直链形如 `https://static.cninfo.com.cn/finalpage/2026-03-21/1225022066.PDF`。**临时公告**（技改投资、重大合同、股权划转、处罚）往往比年报更及时，务必一起抓。

### 1.3 投资者关系互动平台

`irm.cninfo.com.cn`——公司对投资者提问的回复，常见“产能多少”“是否满产”，属于企业自述（`S`），但比官网更直白，且带日期。

## 二、政府与监管公示（唯一能给 `V` 的非上市公司材料）

| 渠道 | 用途 | 检索技巧 |
|---|---|---|
| 环评/竣工验收公示 | 拟建或在建产能、装置清单、占地、投资额 | 搜索「<企业名> 环评 公示」，优先看市级生态环境局与产业园区官网 |
| 排污许可证信息公开平台 | 是否持证、主要产品与产能、排放口 | `permit.mee.gov.cn`，可按企业名查询 |
| 国家企业信用信息公示系统 | 工商登记、股东、经营异常、行政处罚 | `gsxt.gov.cn`；常需验证码，可退化为第三方工商库并标 `M` |
| 信用中国 | 行政处罚、失信被执行人 | `creditchina.gov.cn` |
| 中国裁判文书网 | 诉讼、被执行 | 检索企业全称 + 相关案由；法院官网发布的“典型案例”也常能拿到原文 |
| 应急管理厅/局 | 安全生产许可、事故通报 | 搜「<企业名> 安全生产许可」 |
| 地方统计/工信部门 | 产能置换、能效领跑者、绿色工厂 | 能效名单是很好的“非上市公司能力旁证” |

**注意**：环评公示的是项目规模，不等于当前在产；产能置换公示要看清是“新增”还是“拆二建一、总量不变”——这两者对采购判断完全相反。

## 三、企业官网（`S`，只能当线索）

要抠的是：生产基地地址、装置构成（几条线、各多少万吨）、员工人数、产品目录（是否有重质/食品级/低盐等细分牌号）、销售分公司设置。

官网自述的“产能”，一定要回头找年报/环评/政府名单交叉验证；对不上的，就把冲突写出来。

## 四、媒体与第三方（`M`，用来发现线索，不用来定论）

- 行业媒体（流程工业、中国化工报、化工新闻网）对**在建项目、投产节点**的报道往往比官方公示更早更细。
- 财经媒体对**股权变动、技改投资、业绩预警**的报道，多数转述公告——回溯公告原文后应改用 `V`。
- 第三方百科（百度百科、企查查词条）的产能数字经常停留在几年前，或者把“集团”与“某基地”混在一起。用它做线索，别用它做结论。

## 五、非上市企业的特殊打法

非上市企业没有年报，可用材料少很多。按这个顺序榨取信息：

1. **政府公示** → 环评（产能、装置）、能效领跑者/绿色工厂名单（能力旁证）、安全生产许可公示
2. **法院文书** → 诉讼金额、原被告身份、执行情况（能反推经营状况）
3. **行业协会/交易所** → 期货交割品牌名录、行业排名、标准起草单位
4. **集团官网** → 产能、装置、员工、荣誉（`S`）
5. **老新闻** → 十年前的污染/事故报道不等于现状，但**必须写出来并注明年代**，让采购方知道要问什么

拿不到的部分，一律标 `U` 并转成问询问题。**没有人会因为“查不到”责怪调查者，但会有人因为“编了一个数”丢掉整份报告的可信度。**

## 六、运距与物流

- 距离只写量级（`≈700 km`），并注明是“公路里程量级估算”还是“直线距离”。
- 要额外看清：是否可走水运（港口、二程）、是否铁路专用线、散装罐车回程是否匹配。
- 大宗低值品（纯碱、烧碱、尿素、水泥）的运费占货值比例高，运费口径常是真实价差的来源，比出厂价更值得问。

## 七、检索覆盖要留痕

每轮结束填 `intel_reach`：

```json
"intel_reach": {
  "ids": ["E01", "E04", "E06"],
  "unselected": ["工商档案（验证码拦截）", "排污许可平台（需登录）", "现货价（付费源）"],
  "note": "非上市企业公开数据可及性有限，已整体转入问询清单"
}
```

`unselected` 不是免责声明，而是**下一轮的待办清单**。把它同时写进 `next_actions`，才叫闭环。

## 八、反面清单（这些不要做）

- ✘ 用“行业均价”给某家填一个出厂价
- ✘ 把官网“年产 X 万吨”直接写成“已核实”
- ✘ 把某年财报的产能当成今年的产能
- ✘ 把“经营范围含某产品”写成“具备该产品生产能力”
- ✘ 拿三家可查性完全不同的企业，用同一句“未发现风险”打发
- ✘ 把冲突数字取平均，或挑一个最顺眼的
