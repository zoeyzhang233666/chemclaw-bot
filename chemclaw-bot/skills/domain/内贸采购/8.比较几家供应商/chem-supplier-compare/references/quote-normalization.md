# 报价归一化：把不同口径的报价放到同一把尺子上

供应商给出的报价几乎不可能口径一致。这一步做不好，前面所有核实工作都会被一个错误的价差推翻。

## 一、八项商业条款及其陷阱

| 条款 | 必问 | 常见陷阱 |
|---|---|---|
| 价格 | 出厂价还是送到价？ | 一家报出厂、一家报到厂，直接比较必然出错 |
| 含税口径 | 含税、不含税、普票 | 13% 专票 vs 3% 普票，差 10 个点以上 |
| 运费承担 | 供方/需方/含运价 | “含运价”往往只含到指定口岸，不含卸货 |
| 包装 | 散装 / 吨袋 / 编织袋 | 吨袋与散装差价常达 40–120 元/吨，混在单价里就失真 |
| 账期 | 预付 / 货到付 / 月结 N 天 / 承兑 | 6 个月承兑的实际资金成本相当于降价 1–3% |
| 交期 | 常规交期 + 紧急插单 | 只报“随时可发”的多半没产能 |
| MOQ | 最小起订量 | 试单加价可能高达 10% |
| 有效期 | 报价有效期 | 没有有效期的报价无法锁定，等于没有 |

## 二、归一化公式

目标：算出**到厂含税等效单价（元/吨）**，这是唯一可横向比较的数字。

```
到厂含税等效单价
  = 出厂不含税单价 × (1 + 增值税率)
  + 运费（元/吨，含装卸/港杂）
  + 包装费（元/吨，若未含在单价内）
  + 损耗折价（≈ 单价 × 损耗率）
  − 账期资金成本
```

其中：

```
账期资金成本 = 报价 × 年化资金成本率 × 账期天数 / 365
承兑贴现成本 = 票面 × 贴现率 × 到期月数 / 12
```

推荐的缺省参数（写进报告，别偷偷用）：

- 年化资金成本率：按公司实际（常见 3.5%–5%）；
- 承兑贴现率：按当期市场（常见 1.5%–2.5%）；
- 运输损耗：散装 0.2%–0.5%，袋装 0.1%。

## 三、三个必须保持分离的维度

比较时**不要**把下面三组压成一个数，否则会丢掉决策信息：

1. **量档**：年量长协价 vs 试单价。用试单价冒充长约价是压低预算的经典手法，也是供应商最喜欢用的报价策略。
2. **包装**：散装 vs 吨袋。很多下游工厂本身有散装接收能力，这一项往往是最大的可优化空间。
3. **交割地**：到厂 vs 到港（如郑商所基准交割地）。期货交割品种（纯碱、烧碱、尿素、甲醇）常有“交割地价”与“工厂到厂价”两套，必须分开列。

## 四、表格怎么填

在 `data.json` 里，每家供应商的 `quote` 有 8 个字段：

```json
"price":   {"status": "quoted", "v": "2,150 元/吨（到厂含税，散装，年量）", "ev": "V:E30"},
"tax":     {"status": "quoted", "v": "13% 增值税专用发票", "ev": "V:E30"},
"freight": {"status": "quoted", "v": "含运（供方承担，常熟到厂）", "ev": "V:E30"},
"package": {"status": "quoted", "v": "散装罐车；吨袋 +65 元/吨", "ev": "V:E30"},
"payment": {"status": "quoted", "v": "月结 30 天，可收 6 个月承兑（贴息需方承担）", "ev": "V:E30"},
"delivery":{"status": "quoted", "v": "下单后 7 天到货；紧急插单 3 天（+30 元/吨）", "ev": "V:E30"},
"moq":     {"status": "quoted", "v": "30 吨/车；试单 <300 吨 +50 元/吨", "ev": "V:E30"},
"validity":{"status": "quoted", "v": "30 天，月度调价", "ev": "V:E30"}
```

- 每条报价都是证据：把报价单登记成一条 `evidence`（`type: "供应商报价单"`），标 `V`。
- 供应商口头报价、微信截图：标 `M` 或 `S`，并在 `note` 里写“待书面确认”。
- 没给的一律 `pending` + “待确认”。

## 五、处理“部分报价”

只有一两家报了价时，`quotes.status` 用 `partial`，报告会自动把未报价的条款显示为“待确认”，并在 06 表里保留空位。**不要**用行业均价去补齐——补齐的那一刻，报告就从“调查”变成了“编造”。

## 六、收到报价后的动作

1. 把报价单存档，登记为 `evidence`，填 `type: 供应商报价单`。
2. 按上表填 8 个字段，逐字段标状态。
3. 用第二节公式算到厂含税等效价（建议在 Excel 里做，保留公式以便复核）。
4. 若价差 > 5%，回头确认是不是口径没对齐（量档、包装、交割地），再下结论。
5. 把“报价与口径不一致”的地方写进 `findings`，并在问询清单里追加确认问题。

## 七、模板

`templates/报价单模板.xlsx` 是一份可直接发给供应商的标准报价单，已经把所有易错栏位拆开并加了必填标记。**先统一格式，再收报价**，比收回来再归一化省一半时间。
