# 证据标准：五级标签与判定纪律

这份文档定义**一条信息凭什么能进报告**。整套 skill 的可信度完全压在这里。

## 一、五级标签

| 标签 | 中文 | 什么算 | 典型来源 |
|---|---|---|---|
| `V` | 已核实 | 一手文件直接写明，可点开原文核对 | 上市公司定期报告、环评/竣工验收公示、法院裁判文书、政府许可与处罚公示、证照副本、海关/税务公开数据 |
| `S` | 企业自述 | 企业自己说的，没有第三方复核 | 官网“关于我们”、宣传册、公众号、招聘页、行业会议发言、投资者互动平台回复 |
| `M` | 媒体/第三方 | 别人转述的，可能有二次加工 | 主流媒体、行业媒体、第三方百科、数据库摘要、券商研报 |
| `U` | 无法核实 | 公开渠道没有，或口径互相矛盾且都无法验证 | 缺证照副本、非上市企业无财报、查不到处罚记录 |
| `X` | 风险事实 | 已发生的负面事实，有出处 | 行政处罚决定书、裁判文书、事故通报、失信/被执行记录、经营异常名录 |

**只有五种。** 任何一句话都必须能落进其中一类；落不进去，说明这句话还不该写。

## 二、三条铁律

### 1. 「无重大诉讼」是披露口径，不是事实

上市公司年报写“不存在重大诉讼、仲裁”，含义是**按信息披露标准不需要披露的诉讼不存在**。它不等于没有诉讼，更不等于没有纠纷。

- 正确写法：`年报披露“无重大诉讼、仲裁”（披露口径）；小额诉讼需在信用中国/裁判文书网另行核验`
- 错误写法：`无诉讼风险`

### 2. 「未检索到」是检索口径，不是不存在

非上市企业没有被强制披露的义务。查不到处罚记录，很可能只是没人把它放上网。

- 正确写法：`截止 2026-10-19 在公开渠道未检索到近 12 个月负面事件（U）；非上市企业披露受限`
- 错误写法：`无负面事件`

### 3. 经营范围 ≠ 生产能力

营业执照或生产许可上的“经营范围包含某化学品”，只说明**允许**经营，不说明**有产线在跑**。

判断是否真的在生产，看这组数字能不能对上：

```
设计产能 × 产能利用率 = 当年产量
```

三者来自同一份文件且自洽 → `V`；只有其中一个数 → 最多 `S`/`M`；三个数互相打架 → `U`，并把冲突本身写进报告（冲突比任何一个数都有信息量）。

同样地：
- **工业碳酸钠 / 多数基础无机化工品不在工业产品生产许可证目录内**，没有这张证是正常的，不能据此判“资质不全”。
- 真正要盯的是**排污许可证**（必须有）与**行业专项许可**（食品级→食品生产许可；危化品→安全生产/经营许可）。

## 三、标签与来源类型的对应

| 来源 | 允许标签 | 说明 |
|---|---|---|
| 上市公司年报/半年报 | `V` | 但要区分“事实陈述”与“管理层讨论” |
| 环评/竣工验收公示 | `V` | 公示的是**拟建/已建**规模，不等于当前在产 |
| 法院裁判文书 | `V` | 注意原被告身份，别把原告写成被告 |
| 政府网站（政策/名录） | `V` | — |
| 企业官网 | `S` | 包括“产能”“市占率”“行业第一” |
| 媒体报道 | `M` | 转载的公告要点可回溯原文，标 `M` 更稳 |
| 第三方百科 | `M` | 数据年份常混淆，务必看它的“数据截至” |
| 第三方转载企业简介 | `M` | 常见于高校就业网、行业协会，年份可能很旧 |

`validate.py` 会按这张表报警：年报标了 `M`、官网标了 `V`，都会提示。

## 四、同一事实的交叉核验

理想状态：**同一事实至少两条独立来源**，且其中一条是 `V`。

本次示例中的典型交叉核验：

| 事实 | 来源 1 | 来源 2 | 结论 |
|---|---|---|---|
| 海化纯碱产能 280 万吨 | 2025 年报（设计产能） | 集团官网（老线 120＋新线 160） | `V` + `S`，口径一致 |
| 海化 2025 产量 | 年报产量 272.4 万吨 | 280 × 97.29% 反算 = 272.4 | 自洽 → 能力可核验 |
| 三友 2025 产量 319.05 万吨 | 年报 | 230×85.37% + 110×111.54% | 自洽 → 能力可核验 |
| 金山纯碱产能 | 官网 330 万吨 | 第三方百科 220 万吨 | 冲突 → `U`，转问询 |
| 金大地五期 70 万吨 | 环评公示 | 行业媒体 | 一致；但另有媒体说明属“拆二建一”迁建 → 不增加集团总产能 |

**冲突不是缺陷，是发现。** 把冲突如实写出来，比强行挑一个数字更有价值。

## 五、风险分级（只针对本次采购）

| 等级 | 含义 | 例 |
|---|---|---|
| 高 | 可能直接导致断供、质量事故或合同无法履行 | 主体资质缺失、被执行、主营产品停产 |
| 中 | 可能影响价格、交期或长期稳定性 | 子公司亏损、大额诉讼（哪怕胜诉）、重大资本开支期 |
| 低 | 有记录但已闭环或不影响交付 | 已整改的环保处罚、无重大诉讼披露 |
| 无 / 未取得 | 可查性不足 | 非上市企业无财报、无处罚公示渠道 |

**这不是企业评级。** 一家财务亏损但产能真实的厂家，风险等级可能是“低”（对交付影响小），而不是“高”。报告里要写清楚分级依据。

## 六、时效纪律

- 全文唯一时间基准是 `meta.as_of`。
- 证据发布日期晚于 `as_of`：不允许（等于用未来信息）。
- `as_of` 距今 > 90 天：校验器警告，应更新证据后再出报告。
- 证照状态一律用 `as_of` 计算剩余天数：<0 已过期，≤180 天即将到期。

## 七、自检清单

出报告前逐条过：

- [ ] 每一个 `V` 都能点开链接看到原文，且原文确实写了这句话
- [ ] 没有把“经营范围”当作“在生产”的证据
- [ ] “无重大诉讼/无处罚”都标注了是披露口径
- [ ] “未检索到”都标注了检索范围与限制
- [ ] 产能类数字至少做过一次“设计能力×利用率≈产量”的自洽检验，或明确写了无法自洽
- [ ] 每一处冲突都被写出来，而不是被悄悄抹平
- [ ] 没有任何一句“最佳/推荐/综合得分”
- [ ] 没拿到报价的条款全部是“待确认”，且都进了问询清单
