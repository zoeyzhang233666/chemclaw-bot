# chem-supplier-compare

内贸化工品采购的**供应商横向比较**工具：2–5 家候选生产企业 → 一份交互式 HTML 比较报告 + 一本 Excel 评估工作簿。

核心立场：**不给分数、不给结论，只给可核验的差异和可执行的问题。**

---

## 30 秒上手

```bash
# 1. 校验数据（出报告前必须通过）
python scripts/validate.py examples/soda-ash-2026/data.json

# 2. 一键出两份交付物
python scripts/build_all.py examples/soda-ash-2026/data.json --outdir out
```

产出：

- `out/供应商横向比较_重质纯碱_海化_三友_金山.html` — 单文件，双击即开，不联网
- `out/供应商横向比较_重质纯碱_海化_三友_金山.xlsx` — 13 个工作表

## 它长什么样

**HTML（交互式）**

| 区域 | 内容 |
|---|---|
| 首屏 | 采购口径、比较对象、维度数、证据数 + 四句话的原则声明 |
| 一页读懂 | 五级证据标签的计数（已核实 / 自述 / 媒体 / 无法核实 / 风险事实） |
| 主表 | 三家 × 十个维度的横向比较；金色圆点＝真有差异；每格带证据编号，点开原文 |
| 真正不同的地方 | 自动把差异归成几组（同值同标签即视为无差异） |
| 企业档案 | 每家可展开：四层核验、许可表、该企业的全部问题 |
| 三分法 | 把同一批信息按"谁说"重排一遍：事实 / 自述 / 无法核实 / 风险事实 |
| 关键差异 | F1–F8，每条回答"为什么不同 / 意味着什么 / 核什么" |
| 动态时间线 | 近 12 个月事件 + 行业切片 |
| 许可全量表 | 按截止日自动判过期（红）、临期（黄） |
| 商业条款 | 未取得即"待确认"，不填估算 |
| 问询清单 | 逐家 8–13 条，可复制/下载 |
| 证据索引 | 每条编号可点开原文 |

交互：列头排序、隐藏列、只看某一家、只看实质差异、全文检索高亮、打印成 PDF。

**Excel（13 表）**

`00 说明` · `01 采购需求` · `02 横向比较` · `03 厂家身份` · `04 产能与生产` · `05 资质许可` · `06 报价对比` · `07 风险与事件` · `08 自定义维度` · `09 问询清单`（带回复状态下拉）· `10 证据索引` · `11 评分留白`（权重自填，公式自动加权）· `12 字段说明`

## 为什么值得信

三个机制保证报告不会"看起来很专业但站不住"：

1. **五级证据标签**：`V` 已核实 / `S` 企业自述 / `M` 媒体第三方 / `U` 无法核实 / `X` 风险事实。每条信息必须归类，没有第六类，也不能含糊。
2. **工具层面的硬约束**：`validate.py` 会拦住——引用不存在的证据、把年报标成"媒体"、把官网自述标成"已核实"、未报价却填了金额、出现"最佳供应商/综合评分"、数据截止日过期。
3. **产能可反算**：判断"是不是真在生产"，只认 `设计产能 × 利用率 ≈ 年产量` 能否自洽。对不上的，就把冲突原样写出来。

## 换一个产品要改什么

只改三处：`dimensions` 里的两个自定义维度、`questions` 里的行业问题、`procurement.spec` 的指标。规则文件不需要动。

详见 `references/portability.md`。

## 依赖

- Python 3.9+
- `openpyxl`（只有 Excel 渲染需要；HTML 零依赖）
- 可选：LibreOffice Kit（`LO_KIT_NODE` / `LO_KIT_CLI` 环境变量）用于公式重算，不配置也能用
