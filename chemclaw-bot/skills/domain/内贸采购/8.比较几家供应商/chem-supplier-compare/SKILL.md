# 化学供应商横向比较（chem-supplier-compare）

## 这个 skill 解决什么问题

采购要在 2–5 家候选企业里做选择时，真正难的从来不是"收集资料"，而是三件事：

1. **分清什么是真的**——官网说 330 万吨、第三方说 220 万吨，年报能反算出来的是第三个数；
2. **不被无关信息淹没**——三家在十个维度里有七个其实一样，真正不同的只有三个；
3. **把不确定项变成可执行的动作**——查不到的东西不是报告缺陷，是问询清单的第一条。

本 skill 的输出不是"推荐哪家"，而是一张**能拿去和供应商对话**的比较表。

## 使用前提

- 输入：2–5 家候选企业（已知全称最好）、一个产品（含等级/标准）、一个收货地、量级。
- 若用户只给了产品没给企业，先问「比较哪几家」，或按 `references/research-playbook.md` 找候选（找候选不是本 skill 的主职责）。
- 若用户上传了报价单，走 `references/quote-normalization.md` 归一化后填入。

## 执行流程（严格按序）

### 步骤 1 · 定口径（不跳）

先落三件事，写进 `data.json` 的 `meta` 与 `procurement`：

- **锚点日期** `as_of` = 今天。全文时效判断以它为准，中途不改。
- **采购标的口径**：产品全称 + 等级 + 执行标准 + 关键指标。写"纯碱"是错的，写"重质纯碱 GB/T 210-2022 ≥99.2%、堆积密度 ≥0.90 g/cm³"才对。
- **收货地与量级**：决定运距、运费口径与两档报价（长协年量 / 一次性试单）。

### 步骤 2 · 逐家检索（证据优先）

按 `references/research-playbook.md` 的顺序：上市公司定期报告 + 临时公告 → 政府公示（环评/排污/信用/法院）→ 企业官网 → 媒体/第三方。

**每拿到一条信息，先判标签再写结论：**

| 标签 | 什么时候用 |
|---|---|
| `V` 已核实 | 一手文件明确写了，能点开原文 |
| `S` 企业自述 | 官网、宣传、互动平台回复 |
| `M` 媒体/第三方 | 报道、百科、研报 |
| `U` 无法核实 | 查不到，或口径冲突且都验证不了 |
| `X` 风险事实 | 处罚、诉讼、事故等已发生的负面事实 |

三条铁律（详见 `references/evidence-standard.md`）：

1. 「无重大诉讼」是**披露口径**，不是事实；
2. 「未检索到」是**检索口径**，不是不存在；
3. **经营范围 ≠ 生产能力**。判厂家看：`设计产能 × 产能利用率 ≈ 年产量` 能否自洽。

### 步骤 3 · 判厂家身份（T1 硬门槛）

对每家给出 `producer` 判定：

| 取值 | 含义 | 判据 |
|---|---|---|
| `producer` | 生产厂家 | 营业执照主体 = 合同主体 = 许可持有人 = 发货工厂 |
| `doubt` | 厂家身份存疑 | 是厂家，但签约/开票主体可能是集团母公司或销售平台 |
| `trader` | 贸易/代理 | 无自有产线，或产能与销量严重不匹配 |
| `unknown` | 身份待核 | 材料不足 |

这一项为 `trader` / `unknown` 的，必须在问询清单里放到最高优先级。

### 步骤 4 · 填维度（含 2 个自定义）

固定 7 个维度 + 2 个自定义 + 商业条款：

1. 是否真实生产厂家及核验证据
2. 生产基地所在地及与收货地距离
3. 公开产能、企业规模及生产能力
4. 主营产品与目标产品匹配度
5. 经营资质与许可证照
6. 经营与司法风险、经营异常
7. 近期负面事件（近 12 个月）
8. 【自定义】品类专项维度 ①
9. 【自定义】品类专项维度 ②
10. 商业条款（8 项）

自定义维度按品类从 `references/portability.md` 里挑，必须写清 `hint`（判读要点）——`hint` 会直接显示在报告里，是给读者看的"这一栏该怎么读"。

### 步骤 5 · 商业条款：没拿到就写"待确认"

八项：价格、含税口径、运费承担、包装、账期、交期、MOQ、有效期。

**硬规则：没有报价单就不许填数字。** 一律 `pending` + "待确认"，并把它变成问询问题。用行业均价补齐，是本 skill 明确禁止的行为（`validate.py` 会检查未报价却出现"元/吨"的情况）。

发票模板 `templates/报价单模板.xlsx` 可直接发给供应商。

### 步骤 6 · 生成问询清单（逐家分开）

每家 8–13 条，按优先级排序，每条带 `why`（为什么要问，引用证据编号）。

问题必须**可回答、可举证**：

- ✔「请提供 2026 年 1–9 月纯碱月度产量与当月产能利用率，以及 2026 年剩余时间的检修计划（起止日期、影响产量）」
- ✘「请说明贵司产能情况」

### 步骤 7 · 校验 + 出报告

```bash
python scripts/validate.py examples/<case>/data.json
python scripts/build_all.py examples/<case>/data.json --outdir out
```

校验不通过**不允许**出报告。

## 产出物

| 文件 | 内容 |
|---|---|
| `out/<前缀>.html` | 单文件交互式报告（零依赖，可直接发邮件/内网打开） |
| `out/<前缀>.xlsx` | 13 表评估工作簿（可编辑、可复算） |

HTML 关键交互：
- 首屏即**横向比较表**（第一屏就能看到差异，不用滚动找）；
- 点列头排序、右上角隐藏列、每列可"只看某一家"；
- 「只看实质差异」一键折叠三家相同的维度；
- 每个单元格右侧是**证据标签 chip**，点编号直接跳原文；
- 企业档案卡可展开（四层核验 + 许可表 + 该企业的问题）；
- 问询清单可逐家**复制 / 下载 txt**；
- 支持打印为 PDF（`@media print` 已处理）。

Excel 十三表：`00 说明`｜`01 采购需求`｜`02 横向比较`｜`03 厂家身份`｜`04 产能与生产`｜`05 资质许可`｜`06 报价对比`｜`07 风险与事件`｜`08 自定义维度`｜`09 问询清单`（带回复状态下拉）｜`10 证据索引`｜`11 评分留白`（权重与分数留空，公式自动加权）｜`12 字段说明`。

## 绝对不做的事

- ✘ 综合评分、加权总分、"最佳供应商"结论
- ✘ 用行业均价填补未取得的报价
- ✘ 把「经营范围含该产品」当成「具备该产品产能」
- ✘ 把「无重大诉讼」写成「无诉讼风险」
- ✘ 抹平两家口径冲突（冲突要写出来）
- ✘ 用超出 `as_of` 的信息

## 环境

- Python 3.9+；Excel 渲染需要 `openpyxl`（其余脚本仅用标准库）。
- 生成 HTML 不需要任何第三方库，也不联网。
- 公式重算（可选）：设置环境变量 `LO_KIT_NODE` / `LO_KIT_CLI` 指向 LibreOffice Kit，`build_all.py` 会自动调用；不设置也能出文件，Excel 打开时会自行计算。

## 兼容性

- **ChemClaw**：作为 skill 目录直接加载；`SKILL.md` 的流程段落即为 agent 的执行指令。
- **WorkBuddy / Codex / Claude Code**：把整个目录放进 skills 目录即可；`scripts/` 是纯命令行，`references/` 是纯 Markdown，无运行时依赖。
- 单个大模型直接使用：只需读本文件 + `references/evidence-standard.md`，按步骤 1–7 走。
