# 示例说明：山东海化 · 纯碱

这份示例用来回答一个问题：**"合格的底稿长什么样"**。
它是同一套流程跑出来的成品，不是手工拼的 PPT。

- 数据文件：`data.json`（76 KB，全部内容）
- 生成物：`out/供应商准入尽调底稿_山东海化股份有限公司_纯碱.html`、`.xlsx`
- 证据：14 份，全部来自巨潮资讯网（cninfo），每条都带原文链接
- 数据截止：2026-10-19

---

## 一、场景设定（这是假设，不是供应商披露）

| 项 | 值 |
|---|---|
| 采购品类 | 重质纯碱，Na₂CO₃ ≥ 99.2%，GB/T 210 Ⅱ类 |
| 采购量 | 3.0 万吨/年 |
| 金额 | 约 3,300 万元/年（按 1,100 元/吨） |
| 用途 | 浮法玻璃配合料 |
| 关系 | 内贸、非关联方 |

**为什么把场景写进底稿**：不写场景，产能、账期、单一供应商占比这些判断就没有标尺。
3 万吨占其 280 万吨产能的 1.07%——这一句话就决定了"我方是小客户，议价能力有限，但供应保障度高"。

---

## 二、判定过程（这是示例最值钱的部分）

### 1. 先证真，再证险
主体真实性、产能真实性这两块全部用一手文件（年报）锁死：
- 信用代码、注册资本实缴、注册地址与生产地址同址；
- 产能 280 万吨 × 利用率 97.29% = 产量 272.42 万吨，**能反算**；
- 全国有效产能 4,078 万吨，其份额约 6.9%，与"一线生产商"定位吻合。

只有当"它真的是生产商"成立，后面的财务与风险分析才有意义。否则再漂亮的财务分析都是在分析一个贸易商。

### 2. 找出真正的不确定性
三条线叠在同一个时间窗口（2026–2028）：

| 线 | 事实 | 后果 |
|---|---|---|
| 财务 | 2025 净利 −13.88 亿；2026H1 经营现金流 −10.07 亿；负债率 39.6%→60% | 议价与账期空间小，预付不可接受 |
| 技改 | 48.37 亿元，= 2025 年净资产 126%；120 万吨氨碱→100 万吨联碱，24 个月 | 改造期存在断供窗口 |
| 证照 | 4 张证按年报口径已届满，3 张 2026 年内到期 | 食品级/溴素类不能下单 |

结论因此是 B 类：**主体与产能信得过，但交易结构必须收紧**。

### 3. 把"查不到"变成清单
4 项（被执行、失信、欠税、动产抵押/股权出质）未取得原始查询，
一律写"无公开信息"→ 进材料清单 M 系列 → 进实地核实 S 系列。
**没有一处用"应该没有"来填。**

---

## 三、示范了什么

- **11 个模块**：结论 / 主体 / 股权 / 产能 / 资质 / 风险 / 司法 / 安全环保 / 事件 / 清单 / 方法。
- **10 张风险卡**：每张都有事实、影响、缓释动作、证据 ID；矩阵按"证据强度 × 采购影响"落位。
- **40 项资质全量**：HTML 只展示与采购相关的 8 项，Excel 第 05 页是全量，并自动算到期状态（4 张已过期）。
- **22 项材料 + 12 项实地**：带编号、优先级、核对要点，可直接派给采购员。
- **6 项交叉核对**：供应商上传值与平台公开值逐字段比对。
- **不预测**：全文没有一句履约/交付概率，`validate.py` 会拦住这类表述。

---

## 四、这份示例的已知局限

1. **只有巨潮一条证据链**：未接入信用中国、执行信息、裁判文书、排污许可平台。
   真实项目里这些应作为补充证据（会让风险页更厚，但结论方向通常不变）。
2. **集团与上市公司口径分开**：集团 2026H1 净利 −3.05 亿是母公司口径，不能与上市公司合并报表混用。
3. **产能为年报口径**：排污许可副本里的产能可能与年报略有差异，实地核实时应对。
4. **未做价格与成本的定量模型**：本底稿只做准入，不做采购成本优化。

## 五、复用到其他品类时改什么

| 保持 | 替换 |
|---|---|
| 11 模块结构、风险卡三段式、四道闸门、两个清单 | 全部事实与数字 |
| 证据分级与状态词 | 证据来源（非上市主体换成公示系统/排污许可平台） |
| "不预测、不填空"的纪律 | 判定等级（A/B/C/D 按实际给） |

改完跑：

```bash
python scripts/validate.py mydata.json
python scripts/build_all.py mydata.json --out ./out
```
