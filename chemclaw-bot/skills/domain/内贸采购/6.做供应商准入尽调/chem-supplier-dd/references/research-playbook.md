# 调研手册：每个字段去哪儿查

原则：**一手 > 二手 > 三手**。交易所披露和政府监管平台是一手；企业官网算二手；企查查/爱企查/百度百科是三手，
只能用来"发现线索"，不能单独作为结论依据（引用时标 `pub` 并至少两源交叉）。

---

## 1. 上市公司：一份年报能解决 60% 的字段

**巨潮资讯网**（cninfo.com.cn）→ 公告 → 按代码检索。沪市也可用上交所 e 互动/公司公告，深市用巨潮。

值得逐页读的年报章节：

| 章节 | 拿到什么 |
|---|---|
| 公司简介和主要财务指标 | 信用代码、注册地址、股票代码、上市日期、员工数 |
| 股本变动及股东情况 | 前十大股东、质押冻结、实控人 |
| 管理层讨论与分析 | 产能、产量、销量、利用率、吨价、行业供需、在建工程 |
| **相关批复、许可、资质及有效期** | **资质清单的黄金来源**（多数公司会整段列表） |
| 主要客户与供应商 | 集中度、关联采购占比 |
| 关联方及关联交易 | 电汽水、包装、原料是否集团内部供应 |
| 重要事项 / 诉讼仲裁 / 处罚整改 | 披露口径的合规结论（注意只覆盖"重大"） |
| 合并财务报表附注 | 受限资金、借款结构、存货与减值、长期股权投资 |
| 环境和社会责任 / ESG 报告 | 安全环保投入、能耗、碳排、事故与演练 |

半年报补最新财务与担保，季报补趋势，临时公告补事件（技改、融资、人事、中标、处罚）。

**检索技巧**：公告列表支持全文关键词，用「许可」「资质」「安全生产」「环保处罚」「诉讼」「技改」直接搜；
PDF 用 `pypdf` 抽文本后正则定位，比肉眼翻 300 页快。

## 2. 非上市主体：政府平台组合拳

| 要查什么 | 入口 | 关键点 |
|---|---|---|
| 主体存续、股东、变更、经营范围 | 国家企业信用信息公示系统 `gsxt.gov.cn` | 变更记录能看出更名、迁址、法代频繁更换 |
| 股权出质、动产抵押、经营异常 | 同上「公示信息」栏 | 出质给谁、金额多少，比"有无"更重要 |
| 行政处罚、失信、欠税 | 信用中国 `creditchina.gov.cn` | 按主体名或信用代码搜，**留查询截图与时间** |
| 被执行、限制高消费 | 中国执行信息公开网 `zxgk.court.gov.cn` | 案号、执行标的、立案时间 |
| 裁判文书 | 中国裁判文书网 `wenshu.court.gov.cn` | 近 3 年，看案由与金额是否重大 |
| 排污许可、产能、工艺 | 全国排污许可证管理信息平台 `permit.mee.gov.cn` | 副本里常写主要产品、产能、原辅料、排口 |
| 新建/技改产能 | 生态环境部门环评公示、企业自主验收公示 | 公示里的"建设规模"就是新增产能 |
| 危化品安全生产许可 | 应急管理部 / 省级应急厅公示 | 许可证范围与核定产能是否与宣称一致 |
| 工业产品生产许可证 | 市场监管总局 / 省局查询 | 只对目录内产品（如危化品、化肥、水泥）适用 |
| 食品生产许可（SC） | 属地市场监管局、"食品生产许可获证企业"查询 | 要 SC 编号 + 明细表，**不是**营业执照 |
| ISO 体系认证真伪 | 全国认证认可信息公共服务平台 `cx.cnca.cn` | 查证书编号、覆盖范围、是否暂停/撤销 |
| 绿色工厂、能效水效领跑者 | 工信部及省级工信厅名单 | 环保督察期的"缓冲垫"，但不免责 |
| 海关信用等级 | 海关企业信用信息公示 | 涉出口时看 AEO 高级认证 |

## 3. 交叉验证的三条硬规矩

1. **同字段两源**：注册资本要同时出现在年报与公示系统；只出现一次就标 `pub`。
2. **数字要能反算**：产能 × 利用率 = 产量；收入 ÷ 销量 = 吨价；总资产 = 负债 + 权益。算不平就写出来。
3. **口径要标明**："披露无重大诉讼"和"查证无涉诉"是两句话，不能互相替代。

## 4. 化工品专属的取证重点

- **产能真伪**：排污许可副本、环评公示、年报产量，三处对不上就是红旗。
- **工艺路线**：决定成本曲线与副产品（氨碱法产氯化铵/废液，联碱法产氯化铵，天然碱法无氨）。
- **检修规律**：年报"生产经营情况"常写"年内检修 X 天"，这是保供条款的依据。
- **危化品**：安全生产许可证的许可范围必须覆盖你要买的产品；运输要看承运方资质与罐车归属。
- **食品级**：SC 证 + 产品明细 + 重金属/微生物检测报告，ISO 9001 不能替代。
- **出口**：REACH 注册号、危包证、SDS 版本、原产地证。

## 5. 常见坑

| 坑 | 后果 | 正确做法 |
|---|---|---|
| 拿企查查截图当一手证据 | 复核时无法溯源 | 只作线索，结论引公示系统/年报 |
| 只看设计产能 | 高估可供量 | 产能 × 利用率 × 自用比例 |
| 忽略"分支机构经营" | 合同主体与生产主体错位 | 合同里明确生产厂与开票主体 |
| 把集团财务当上市公司财务 | 结论反向 | 分清合并报表与母公司/集团口径 |
| 用"无重大诉讼"得出"无诉讼" | 风控打回 | 改为"披露口径无重大诉讼，未取得裁判文书原始查询" |
| 资质只抄名称不抄有效期 | 拿过期证下单 | 全部算到期状态 |
