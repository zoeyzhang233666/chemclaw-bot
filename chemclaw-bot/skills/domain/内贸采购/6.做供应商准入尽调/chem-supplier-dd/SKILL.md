# 化工品供应商准入尽调

把"这家供应商能不能进名录、以什么条件进"拆成**可核查的六件事**，每一件都落到具体文件和页码。
适用于内贸采购的**生产型**供应商；贸易商、代理商按同一骨架但删掉产能与工艺两节。

## 一、什么时候用

| 用 | 不用 |
|---|---|
| 新供应商首次准入 | 已合作供应商的年度复评（用简化版即可） |
| 老供应商新增品类/新增工厂 | 单纯的比价、询价 |
| 采购金额大、断供代价高的品类 | 一次性小额现货 |
| 危化品、食品添加剂、涉出口合规 | 内部关联方采购 |

## 二、产出物（固定三件套）

1. `<主体>_<品类>.html` — 单文件交互底稿：可筛选、可勾选导出、可打印 PDF，证据标签直链原文。
2. `<主体>_<品类>.xlsx` — 12 页签工作簿：结论 / 主体 / 股权 / 产能 / 40+ 项资质全量 / 风险清单 / 事件 / 材料清单 / 实地核实 / 交叉核对 / 证据索引。
3. 两份清单必须**可执行**：材料清单每项带编号、优先级、核对要点；实地核实每项带区域、方法、取证要求。

## 三、六条硬纪律

1. **不预测**。不写"预计交付稳定""履约概率高""大概率按期"。结论只回答"能不能进、以什么条件进"。
2. **不填空**。查不到就写"无公开信息"，并把它转成材料清单里的一条。**不允许用行业常识补位**。
3. **每条风险都要有证据 ID**。没有证据的只能标"证据弱"，不能标"无风险"。
4. **区分口径**。"上市公司披露无重大诉讼" ≠ "我方查证无涉诉"。前者是披露口径，后者才是查证结论。
5. **数字要能反算**。产能×利用率=产量、收入÷销量=吨价，至少做一次自洽校验，不自洽就写出来。
6. **时间切面固定**。全文只用一个 `as_of` 日期，所有"近 12 个月""有效期"都相对它计算。

## 四、调研流程

### P0 定义范围（10 分钟）
确定：主体全称、统一社会信用代码（或股票代码）、本次采购品类与规格、年用量与金额、`as_of` 日期。
规格决定后面的取证重点——**工业级 / 食品级 / 危化品**是三套完全不同的证书清单。

### P1 找一手文件（决定 80% 的质量）
按主体类型选入口，**优先级：交易所披露 > 政府监管平台 > 企业官网 > 第三方数据库**。

- **上市公司**：巨潮资讯网（cninfo）公告全文检索。一次拿齐：年报（主体、产能、资质、股权、诉讼与处罚披露）、半年报、季报、章程、ESG/社会责任报告、临时公告。
- **非上市生产型**：国家企业信用信息公示系统（主体、股东、变更、动产抵押、股权出质）＋ 全国排污许可证管理信息平台（产能与工艺常出现在排污许可副本里）＋ 环评公示（新建/技改产能）。
- **危化品**：应急管理部危化品登记、安全生产许可证公示、重大危险源备案。
- **食品接触**：食品生产许可证（SC）编号可在属地市场监管局查到明细。

把每份文件登记为 `E01…En`：名称、来源、日期、URL、它支撑了什么。**没有登记的文件不算证据**。

### P2 主体真实性
信用代码、成立日期、注册资本与实缴、注册地址 vs 生产地址、经营范围、更名迁址与法定代表人变更史。
要点：**注册地址≠生产地址**是贸易商特征；经营范围里"【分支机构经营】"意味着合同主体与生产主体分离，必须在合同里打通。

### P3 股权与实际控制人
控制链画到自然人/国资为止，层级越短越好；查质押、冻结、代持、一致行动人。
非上市主体重点看：股东是否为空壳、实缴是否到位、有无股权出质。
**关联交易**要单独一节——电、汽、包装、原料是否来自集团内部，直接决定"成本优势"的真假和断供连带风险。

### P4 产能与工艺
设计产能、实际产量、产能利用率、在建/技改、工艺路线（氨碱/联碱/天然碱、乙烯法/电石法、硫酸法/氯化法…）、检修规律。
**必做自洽校验**：产量 ÷ 产能 = 利用率；收入 ÷ 销量 = 吨价；产能 × 市占率 ≈ 行业总量。
技改要算**减量置换比例**和**停产窗口**——这是保供条款的依据。

### P5 资质证照
全量列出，一条一行：名称、有效期起止、许可范围、持有人。
**必须算到期状态**（`as_of` 已过期 / 180 天内到期 / 有效），并区分**与本次采购相关/无关**。
工业品常被忽略的三张证：排污许可证、安全生产许可证、工业产品生产许可证（列入目录的品类）。
食品级必须有 SC；危化品必须有安全生产许可证 + 危化品登记。

### P6 风险、司法与信用
经营异常、行政处罚（安全、环保、质量、税务）、被执行与限高、失信、欠税、股权出质、动产抵押、裁判文书。
**能查的平台一定查，查完留截图和时间**：信用中国、执行信息公开网、裁判文书网、公示系统。
查不到的，写"无公开信息"并进材料清单，不要写"无"。

### P7 安全与环保
事故台账、专项检查次数与整改率、环保投入、排污许可、能耗与碳排、园区连带风险（同园区是否有氯碱、危化装置）。
ESG 报告是上市公司最好的来源；非上市看排污许可执行报告和政府公示。

### P8 事件与缺口收口
近 12 个月按时间轴排事件，并写出**事件之间的逻辑**（融资→技改→减值→股东输血，这类链条比单条事件有用）。
最后强制输出两个清单：**材料清单**（把查不到的变成问得到的）和**实地核实清单**（把问得到的变成看得见的）。

## 五、判定规则

分级只看两件事：**主体/产能是否真实**、**不确定性能否用交易结构兜住**。

| 等级 | 含义 | 交易条件 |
|---|---|---|
| A 准入 | 主体、产能、资质、财务均无实质缺口 | 常规账期 |
| B 有条件准入 | 主体与产能真实，但存在财务/技改/证照类不确定性 | 零预付、短账期、限额、季度复核 |
| C 观察 | 关键项无法核实（如产能存疑、证照缺失） | 只做现货小单，不得签长约 |
| D 不准入 | 主体虚假、证照造假、重大安全环保或失信记录 | — |

**四道闸门**（B 类必须逐条关闭后才放量）：证照闸门、保供闸门、交易结构闸门、质量闸门。
每条闸门要写成"未关闭的后果"，让业务方知道代价。

## 六、品类适配（同一骨架，不同重点）

| 品类特征 | 额外要看 |
|---|---|
| 危化品（液碱、硫酸、甲醇、氯气） | 安全生产许可证范围与产能是否匹配；重大危险源等级；运输资质与罐车归属 |
| 食品/饲料添加剂（小苏打、磷酸盐、柠檬酸） | SC 证与明细表；重金属与微生物指标；GMP/FSSC 认证；不能只看 ISO |
| 大宗原料（纯碱、尿素、PVC、PTA） | 产能利用率与检修；区域运距；前五大客户集中度；行业新增产能 |
| 精细与专用化学品 | 单一工厂依赖；配方保密与切换成本；REACH/危包证 |
| 集团内供应为主 | 关联交易定价机制；集团资金链；连带停产 |

## 七、怎么跑（数据驱动，不写死）

```bash
# 1) 复制模板，按 references/data-contract.md 填
cp templates/data.template.json mydata.json

# 2) 校验（证据引用、状态词、风险字段、合规红线）
python scripts/validate.py mydata.json

# 3) 一条命令出 HTML + Excel
python scripts/build_all.py mydata.json --out ./out
```

- 只依赖 Python 3.9+；HTML 渲染零依赖，Excel 需要 `openpyxl`。
- 产物是**单文件**：HTML 内联全部样式与脚本，可直接邮件发送、离线打开。
- 完整可运行示例：`examples/soda-ash/`（山东海化 · 纯碱，含 data.json 与成品）。

## 八、交付前自检

- [ ] 每条风险都有证据 ID，且 ID 能在证据索引里打开原文
- [ ] 所有"无公开信息"都进了材料清单，编号连续
- [ ] 资质表算了到期状态，过期项写了"须索取新证"
- [ ] 至少做过一次数字自洽校验，并把校验过程写进正文
- [ ] 全文没有出现履约/交付概率类表述
- [ ] 结论能回答"以什么条件进"，而不只是"能/不能"
- [ ] 实地核实清单里的每一项都能拍照或签字留证

## 九、常见错误

- 把第三方数据库（企查查/爱企查）当一手来源 → 只能标"公开可查"，且需两源交叉。
- 用年报的"无重大诉讼"直接写"无诉讼" → 口径错误，会被风控打回。
- 产能只抄设计值，不验证利用率与产量 → 无法判断真实可供量。
- 风险只写"存在财务风险"，不写影响与缓释动作 → 业务方无法执行。
- 结论写"建议谨慎合作" → 不是结论，是废话。必须给等级 + 条件 + 闸门。
