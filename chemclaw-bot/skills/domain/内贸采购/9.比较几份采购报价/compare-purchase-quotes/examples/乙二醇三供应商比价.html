5标准化统一报价表（L2 · 口径转换）

把「元/公斤」「元/吨」「元/桶」统一为「元/吨」；把「含税」「不含税」统一为「不含税可抵扣」； 把不同含量折纯到 100%。

5.1 折纯判断（规格差异是否允许折纯比较）

折纯规则（三条同时满足才允许）：① 产品为同一化学物质；② 杂质项不构成下游工艺/检测障碍；③ 允许按纯物计量或价格可线性折算。
本例：询价规格为 ≥99.9%，A（99.92%）、B（99.90%）满足，可折纯；C（99.5%）不满足 —— 不仅含量低， 且未注明执行标准与水分/DEG，因此 C 默认不参与同口径排名，仅提供折纯参考价。折纯不改变「1 吨实物按 1 吨计价」的结算方式，只改变成本比较口径。

5.2 统一报价表

原始单价一栏保留各家原文，用于追溯；「换算含税价（元/吨）」仅用于横向粗看，不可作为排序依据（税费口径不同）。

11.1 成本计算主公式

// 到厂成本（元/吨，不含税、折纯口径，n = 净商品量 1 吨） L = C_goods + C_pack + C_freight + C_unload + C_inspect + C_vehicle + C_capital + C_deposit // ① 裸价：含税→不含税；不含税→原值；普通发票→全额入成本（进项不可抵扣） C_goods = 含税单价 ÷ (1 + 13%) // 专票 C_goods = 不含税单价 // 专票、原文不含税 C_goods = 含税单价 // 普票 / 税率未注明 // ② 计价单位统一：公斤→吨 ×1000；桶→吨 ÷ (桶净重 kg / 1000) 单价(元/吨) = 单价(元/桶) ÷ (220 kg ÷ 1000) // ③ 折纯：到厂成本 ÷ 含量；不折纯时 = 到厂成本 L_purity = L ÷ 含量% // ④ 运费：卖方含运 → 0（已内含）；买方自提 → 含税运费 ÷ (1+9%) C_freight = 0 或 运费(含税9%) ÷ 1.09 // ⑤ 检验费摊销：年检验总额 ÷ 年采购量 C_inspect = 每批检验费 × 年送检批数 ÷ 年采购量 ÷ (1+6%) // ⑥ 资金占用：迭代求解（成本依赖资金成本，存在循环） C_capital = (C_goods + C_pack + C_freight + C_unload + C_inspect + C_vehicle + C_capital) × r × d ÷ 360 收敛：|C_capital,k − C_capital,k−1| < 1e-9，最多 40 次 // ⑦ 加权付款天数（现金流加权，不是合同账期） d = Σ(t_i × w_i) // t_i 为第 i 笔付款距下单天数，w_i 为占货值比例 A：d = 0×50% + 21×50% ≈ 10.5 → 以迭代法精确处理 B：d = 46 天（月结30 + 月中下单 → 次月25日平均约 46 天） C：d = 0 天（款到发货） // ⑧ 保证金 / 押金占用 C_deposit = 保证金 × r × 占用天数 ÷ 360 ÷ 采购数量
