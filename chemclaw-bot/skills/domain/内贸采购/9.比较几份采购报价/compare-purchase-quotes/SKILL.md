# 比较几份采购报价

把多份格式各异、口径各异的供应商报价，**统一到「不含税可抵扣 · 折纯 · 到厂」口径**后比较到厂成本，并给出每一分钱的来源。

## 何时用

- 手上有 2 份以上同一产品的报价，想知道**哪家真正便宜**
- 报价单位不同（元/公斤、元/吨、元/桶）、税费口径不同（含税/不含税/专票/普票）、交付方式不同（自提/送货）、账期不同
- 想知道账期、保证金、运费、卸车费、检验费、罐车清洗费、包装押金各自值多少钱
- 需要一份可交付、可复核、可复算的比价材料

## 何时不用

- 不同化学物质之间比较 → 无共同基准，需分品类
- 含量/规格差异大且不可线性折算（工业级 vs 医药级）→ 折纯不成立
- 要求预测未来价格 → 用行情类技能
- 国际采购/进口（汇率、关税、信用证）→ 需扩展外币口径

## 执行步骤

### 第 1 步 · 收齐输入
按 `references/intake-and-scope.md` 的模板向用户确认：产品、数量、收货地、年化资金成本（可选）、运费/卸货/检验报价（可选）。
**任何缺失都不阻断**，但必须进入假设清单并标注。

### 第 2 步 · 抽取字段（L1 原始值）
对每份报价抽取 15 个必填字段 + 5 个建议字段，见 `references/field-mapping.md`。
- 可用 `scripts/extract_quotes.py` 做初筛（PDF/XLSX/DOCX/文本；图片需 OCR 或多模态识别）
- **抽到就照抄，不换算**；抽不到就标 `MISSING`，并给出去向供应商要什么
- 每个字段记录来源：文件名 + 页码/工作表/单元格/图片坐标

### 第 3 步 · 判断折纯
必须先过三问（同一物质？杂质可接受？可线性折算？）。
- 含量 ≥ 询价规格 → 允许折纯
- 含量 < 询价规格 → 剔除出同口径排名，单列
- 含量缺失 → 禁止折纯，待确认
规则见 `references/field-mapping.md §4`。

### 第 4 步 · 统一口径（L2 转换值）
1. 计价单位 → 元/吨（桶/袋必须取净重）
2. 税费 → 不含税可抵扣（普票按全额、税率未明按保守值 + 专票下限双情景）
3. 数量 → 按本次采购量命中阶梯档位
4. 交付 → 到厂（自提加买方运费；卖方含运计 0）
5. 付款 → 加权付款天数（不是合同「账期」）

### 第 5 步 · 计算到厂成本
公式见 `references/cost-formulas.md`，实现见 `scripts/quote_engine.py`：

```
到厂成本 = 裸价 + 包装费 + 运费 + 卸车费 + 检验摊销 + 清洗摊销 + 资金成本 + 保证金/押金占用
折纯到厂 = 到厂成本 ÷ 含量
资金成本 = (base + 资本) × 年化率 × 加权天数 ÷ 360     ← 迭代收敛，报告迭代次数
```

### 第 6 步 · 标注易忽略项
逐项检查：卸车费、检验费、罐车清洗/蒸汽置换、包装回收/押金、涨价条款、价格联动机制、短有效期、零单加价。
**未提及 ≠ 0**：一律列为待确认。

### 第 7 步 · 市场定位与压力测试
- 与市场价（生意社基准价/现货等）对齐口径后计算偏离
- 做单参数敏感性（运费、资金成本、数量、卸车费）、情景分析、价格区间扫描
- 判断结论是否会翻转（谁在什么条件下反超）

### 第 8 步 · 交付
- **交互式 HTML 报告**（单文件、离线可开）：KPI、统一比价表、成本瀑布、可展开计算明细、参数可调自动重算、敏感性表、待确认清单、原报价定位、导出
- **Excel 工作簿**（11 表）：封面说明 / 统一报价表 / 原始数据 / 标准化字段 / 计算公式 / 成本汇总（公式联动）/ 参数与来源 / 账期敏感性 / 参数敏感性 / 情景分析 / 待确认事项
- 一页结论：推荐供应商、价格差、首要风险、下一步动作

样式与结构参考 `examples/`（乙二醇三供应商完整样例）。

## 硬性规则（违反即为错误）

| 规则 | 说明 |
|---|---|
| 三层分离 | 原始值 / 转换值 / 假设值必须可区分，报告中用不同颜色标注 |
| 缺失不补零 | 报价未提及的费用不得按 0 计入，必须列为待确认 |
| 不跨口径比较 | 不同单位、不同税费、不同规格在统一前不得直接比大小 |
| 公式可追溯 | 每个结果都要能展开看到公式、输入、来源 |
| 不编造 | 无法核实的市场价、条款、金额一律不写；市场数据须带日期、规格、区域、来源 |
| 样例须声明 | 若是演示/模拟数据，报告顶部必须显著声明 |

## 常见陷阱

见 `references/pitfalls-and-market.md`，最关键的五条：
1. **单位陷阱**：6,300 元/桶 ≈ 28,636 元/吨，不是 6,300 元/吨
2. **税费陷阱**：4,850 不含税 vs 6,200 含税，表面差 22%，实则差 13% 进项
3. **自提/到货陷阱**：卖方「含运」已含在价内，不能重复加运费
4. **账期错觉**：「月结 30 天」≈ 46 天资金占用，差 16 天
5. **规格陷阱**：99.5% 与 99.9% 不可直接排名

## 自检

交付前逐条核对 `references/quality-checklist.md`。重点关注：
- 分项之和 = 合计（误差 < 0.01 元/吨）
- 差异归因合计 = 到厂成本差额
- HTML/Excel/Python 三处计算一致
- 每条缺失都带明确的问题清单
