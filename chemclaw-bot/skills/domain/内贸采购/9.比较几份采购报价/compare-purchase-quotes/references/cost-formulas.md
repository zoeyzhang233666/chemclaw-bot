# 成本计算公式与参数（cost-formulas）

> 全部公式都在 `scripts/quote_engine.py` 中实现，HTML 报告里的 `compute()` 与之逐项对应（已交叉验证，误差 < 0.01 元/吨）。
> 所有金额单位为 **元/吨**，口径为 **不含税可抵扣 · 折纯 · 到厂**。

## 0. 穿透口径定义

| 维度 | 统一口径 | 理由 |
|---|---|---|
| 数量 | 净商品量 1 吨 | 便于跨供应商比较 |
| 税费 | 不含税、增值税进项可抵扣 | 专票可抵扣，普票不可抵扣，不能混比 |
| 规格 | 折纯至 100% | 消除含量差异 |
| 交付 | 到收货地（含运费、卸车等） | 「到厂成本」而非「出厂价」 |
| 时间 | 年化资金成本 ÷ 360 × 加权付款天数 | 与生意社基准价定价公式、银行承兑口径一致 |

## 1. 主公式

```
到厂成本 L = C_goods + C_pack + C_freight + C_unload + C_inspect + C_vehicle + C_capital + C_deposit
折纯到厂成本 L_purity = L ÷ 含量
```

| 符号 | 含义 | 来源 |
|---|---|---|
| `C_goods` | 裸价（不含税可抵扣） | 报价单单价，经单位换算 + 税费分离 |
| `C_pack` | 包装费（单收部分） | 报价单包装费；已含价内记 0（明示） |
| `C_freight` | 到厂运费（不含税） | 卖方含运 → 0（价内）；买方自提 → 运费 ÷ (1+9%) |
| `C_unload` | 到厂卸车费 | 假设或合同；÷ (1+6%) |
| `C_inspect` | 检验费摊销 | 年检验总额 ÷ 年采购量 ÷ (1+6%) |
| `C_vehicle` | 槽车清洗/蒸汽置换摊销 | 元/车次 × 车次 ÷ 年采购量 ÷ (1+6%) |
| `C_capital` | 资金占用 | 见 §3 |
| `C_deposit` | 保证金/包装押金占用 | 见 §4 |

## 2. 裸价与单位/税费统一

### 2.1 计价单位换算
```
单价(元/吨) = 单价(元/公斤) × 1000
单价(元/吨) = 单价(元/桶) ÷ (桶净重kg ÷ 1000)
```

### 2.2 税费分离
```
含税 + 专票     ：C_goods = 含税单价 ÷ (1 + 税率)
不含税 + 专票   ：C_goods = 不含税单价
含税 + 普票     ：C_goods = 含税单价（全额，进项不可抵扣）
税率/票种未注明 ：C_goods = 含税单价（保守）；同时给出 ÷1.13 的乐观下限
```

> 税率通常为 13%（货物）、9%（运输）、6%（现代服务）。

## 3. 资金占用（迭代求解）

资金成本依赖成本，成本又包含资金成本 → **循环依赖**，用不动点迭代：

```
C_capital,0 = 0
C_capital,k = (base + C_capital,k−1) × r × d ÷ 360
收敛条件：|C_capital,k − C_capital,k−1| < 1e-9（最多 40 次，通常 5–8 次收敛）
```
其中 `base = C_goods + C_pack + C_freight + C_unload + C_inspect + C_vehicle`，
`r` = 年化资金成本，`d` = 加权付款天数。

**简化（无需迭代）**：若只关心单笔金额：
```
C_capital = 本次货款金额 × r × d ÷ 360 ÷ 数量(吨)
```

### 加权付款天数 d
```
d = Σ (t_i × w_i)     t_i 为付款距下单天数，w_i 为占货值比例
```
按月结的口径：`d ≈ 月结天数 + 15 天`（月中下单、次月 25 日结清 → ≈46 天）。

## 4. 保证金与包装押金

```
C_deposit(保证金) = 保证金 × r × 占用天数 ÷ 360 ÷ 本次数量(吨)
C_deposit(包装押金) = (桶数 × 押金/桶 × 不退还比例 + 桶数 × 押金/桶 × (1−不退还比例) × r × 退回天数 ÷ 360) ÷ 数量(吨)
```

## 5. 数量阶梯

```
命中单价 = 满足 (采购量 ≥ 阶梯下限) 的最大档位的单价
```

## 6. 折纯

```
折纯系数 = 含量（如 99.92% → 0.9992）
折纯成本 = 到厂成本 ÷ 折纯系数
```
仅当含量 ≥ 询价规格时参与同口径排名。

## 7. 市场定位

```
折纯含税出厂价 = 不含税裸价 × (1+13%) × 含量        （专票供应商）
               = 含税到货价 × 含量                    （含运供应商，口径偏高）
相对现货偏离 = (折纯含税出厂价 − 生意社现货) ÷ 生意社现货
```

## 8. 参考参数默认值（全部可覆盖，且均须标注性质）

| 参数 | 默认 | 性质 | 备注 |
|---|---|---|---|
| 年化资金成本 | 4.5% | 用户输入 | 缺省按 4%~6% 示例 |
| 买方自提运费 | 42 元/吨（含税9%） | 假设 | 100km 内槽车 35~55 元/吨 |
| 到厂卸车费 | 25 元/吨（含税6%） | 假设 | 与仓库确认 |
| 第三方检验费 | 1,800 元/批 | 假设 | SGS 类 |
| 年送检批数 | 6 | 假设 | 按到货批次 |
| 年采购量 | 2,400 吨 | 假设 | 摊销分母 |
| 槽车清洗 | 600 元/车次 × 8 车次/年 | 假设 | 仅散装 |
| 保证金占用天数 | 180 天 | 假设 | 待确认 |
| 包装押金退回天数 | 10 天，不退还 10% | 假设 | 待确认 |
| 年化天数 | 360 天 | 惯例 | 生意社/银行承兑口径 |
| 增值税/运输/服务税率 | 13% / 9% / 6% | 法定 | 中国大陆现行 |

## 9. 敏感性分析方法

| 方法 | 做法 | 输出 |
|---|---|---|
| 单参数扰动 | 每次改一个参数（运费 0/20/42/60/80；资金成本 0~12%；卸车 0~60；数量 30~500；车次 0~20） | 三家家到厂成本与排名 |
| 情景分析 | 同时改多个假设（剔除运费、资金成本 10%、降量 60 吨、C 折纯、C 专票） | 排名是否翻转 |
| 市场压力 | 折纯裸价在 4,800~6,800 元/吨区间扫描 | 排名稳定性、盈亏分界 |
| 盈亏平衡 | 求 `L_A(q) = L_B(q)` 的 q（数量阶梯切换点） | 采购量的关键阈值 |
