# 报价字段映射规则（field-mapping）

> 用途：把任意格式（PDF / Excel / Word / 图片 / 邮件截图）的采购报价，映射为统一的 L1 原始字段 → L2 标准化字段。
> **原则**：先照抄，后换算；单位、税费、规格三件事各自独立处理，任何一步没确认前不得比价。

## 0. 三层数据模型（所有字段都要带层标签）

| 层 | 名称 | 定义 | 规则 |
|---|---|---|---|
| L1 | 原始值 `raw` | 报价文件里逐字出现的内容 | 只照抄；不换算、不补全、不四舍五入；保留原文单位与表述 |
| L2 | 转换值 `derived` | 由公式根据 L1 + 参数计算出的结果 | 必须同时记录 `formula`（公式）、`inputs`（输入）、`value`（输出）、`source`（来源文件+位置） |
| L3 | 假设值 `assumption` | 报价缺失、由买方输入或明确标注的处理方式 | 必须进「假设清单」并标 `needs_confirm`；**禁止默认 0** |

输出 JSON 时每个字段都长这样：

```json
"price_incl_tax_per_ton": {
  "layer": "derived",
  "value": 6200.0,
  "formula": "6.20 × 1000",
  "inputs": {"raw_price": 6.20, "raw_unit": "元/公斤", "kg_per_ton": 1000},
  "source": {"file": "供应商A_报价函.pdf", "loc": "p.1 一、产品与报价"},
  "confidence": "high"
}
```

缺失字段：

```json
"tax_rate": {"layer": "assumption", "value": null, "status": "MISSING",
             "needs_confirm": true, "question": "是否开具13%增值税专用发票？",
             "handling": "按普票（进项不可抵扣）保守计入，并在情景分析中给出专票下限"}
```

## 1. 字段清单（必填 15 项 + 建议 5 项）

### A. 产品与价格
| 统一字段 | 同义写法（正则参考） | 单位/取值 | 缺失后果 |
|---|---|---|---|
| `product_name` | 产品名称 / 品名 / 物料名称 / 商品名称 / 货名 | 文本 | 无法确认前不得比价 |
| `spec` | 规格 / 含量 / 纯度 / 浓度 / 牌号 / 等级 / 执行标准 | 文本 + 数值 | 含量缺失 → 不可折纯 |
| `purity` | 含量 / 主含量 / 纯度 / assay (`≥99.9%`, `99.5%`, `99.7 min`) | 0–1 小数 | 缺失 → 折纯不可做，列入待确认 |
| `price_raw` | 单价 / 报价 / 价格 / 售价 / 出厂价 / 到货价 | 数值 | 必填 |
| `price_unit_raw` | 计价单位 / 单位 / 元/吨 / 元/kg / 元/桶 / 元/包 | 文本 | 必填，否则无法换算 |
| `tax_included` | 含税 / 不含税 / 税前 / 价税合计 / 票面价 | 是/否/不明 | 不明 → 按「待确认」走兼容口径 |
| `tax_rate` | 税率 / 13% / 9% / 6% | 0–1 | 不明 → 按税率无法分离处理 |
| `invoice_type` | 专票 / 增值税专用发票 / 普票 / 普通发票 / 不开票 | 枚举 | 普票 → 进项不可抵扣，成本按全额计 |
| `qty_tiers` | 阶梯价 / ≥N吨 / 量大从优 / 一车价 | 列表 [(下限吨, 单价)] | 缺失 → 按单一价、标注待确认 |

### B. 交付与商务
| 统一字段 | 同义写法 | 说明 |
|---|---|---|
| `pack_form` | 包装 / 包装形式 / 包装规格 / 散装 / 吨桶 / IBC / 铁桶 / 槽罐 / ISO槽 / 编织袋 | 散装 vs 桶装直接决定清洁与卸车成本 |
| `pack_cost` | 包装费 / 桶费 / 包装物费 / 是否含包装 | 若「已含」记 0（明示）；若「另计但未给金额」→ 待确认 |
| `freight_by` | 运费 / 运输费 / 是否包邮 / 买方自提 / 送货到厂 / 到货价 | 枚举：`seller` / `buyer` / `na` |
| `freight_amount` | 运费金额 / 元/吨运杂费 | 卖方含运时须判断是否已内含于单价 |
| `delivery_mode` | 交货方式 / 提货 / 自提 / 送厂 / DDP / FCA | 记录交货点，FCA 需补买方运费 |
| `payment_terms` | 付款条件 / 结算方式 / 预付 / 款到发货 / 月结 / 账期 | 原文照抄 + 结构化天数 |
| `credit_days` | 账期 / 月结30天 / 见票后N天 / 次月X日 | 统一为「自收货或收票起算的合同天数」 |
| `prepay_ratio` | 预付比例 / 首付 / 定金 | 0–1 |
| `moq` | 最小起订量 / 起订 / 一车 / 整车 / 单笔不低于 | 吨 |
| `validity` | 报价有效期 / 有效期 / 报价日有效 / 3天内有效 | 文本 + 天数；缺失记 `null` |
| `quality_std` | 质量标准 / 执行标准 / 国标 / 企标 / GB/T / 检测报告 / COA | 文本 |
| `origin` | 产地 / 生产企业 / 品牌 / 货源 | 品牌价差来源 |

### C. 容易被忽略的费用（必须逐项书面确认，默认 = 待确认）
| 字段 | 中文 | 判断要点 |
|---|---|---|
| `unload_fee` | 卸车费 / 卸货费 / 理货费 / 吊装费 | 自提时由谁卸？到厂后谁卸？ |
| `inspection_fee` | 检验费 / 检测费 / 化验费 / SGS / 第三方检测 | 首发/到货必检？由谁承担？ |
| `tank_clean_fee` | 罐车清洗费 / 洗罐费 / 蒸汽置换 / 氮封 | 散装液体必查：谁洗？价格？ |
| `pack_return_fee` | 包装回收费 / 桶押金 / 托盘回收 / 吨袋回收 | 押金金额、退还条件、未退如何处理 |
| `deposit` | 保证金 / 履约保证金 / 首次合作保证金 | 金额、占用天数、可抵扣否 |
| `price_adjust` | 涨价条款 / 调价机制 / 随行就市 / 联动 / 价格保护 | 有无幅度、机制、基准价 |
| `zero_order_surcharge` | 零单加价 / 小额订单附加费 | 起订量以下是否加价 |

## 2. 单位映射（换算系数）

| 原文单位 | 标准单位 | 系数 | 备注 |
|---|---|---|---|
| 元/公斤、元/kg、元/千克 | 元/吨 | ×1000 | 常见于化工品零售报价 |
| 元/吨、元/t、元/公吨 | 元/吨 | ×1 | — |
| 元/桶 | 元/吨 | ÷ (桶净重kg / 1000) | **桶净重必须来自报价单或书面确认**，否则待确认 |
| 元/包、元/袋 | 元/吨 | ÷ (每包净重kg / 1000) | 同上 |
| 元/升、元/L | 元/吨 | ÷ (密度 t/L) | 密度需来自 MSDS/COA |
| 元/加仑 | 元/吨 | ÷ (加仑重量 t) | — |
| 现汇/承兑 | — | 承兑贴息另计 | 银行承兑按贴现率折现，不得直接等价 |

**桶重陷阱**：`6,300 元/桶`，如果 1 桶 = 220 kg，则折吨 **28,636 元/吨**（不是 6,300 元/吨）。
务必从「包装规格」行反查每桶净重，并标注为「待确认」。

## 3. 税费口径映射

| `tax_included` | `invoice_type` | 入成本价（不含税可抵扣口径） | 说明 |
|---|---|---|---|
| 含税 | 增值税专用发票 | 单价 ÷ (1+税率) | 进项可抵扣，最大抵扣 |
| 含税 | 增值税普通发票 | 单价（全额） | 不可抵扣，成本最高 |
| 不含税 | 专票 | 单价 | 税额另开 |
| 不含税 | 普票 | 单价 | **票面含税时实际成本更高** |
| 未注明 | 未注明 | 单价；**同时给出 ÷(1+13%) 的下限情景** | 必须先确认 |

> 只要 `tax_rate` 或 `invoice_type` 任一缺失，就必须同时输出「保守值」和「乐观值」两个情景，且排名时必须用保守值。

## 4. 折纯规则（规格差异）

### 4.1 折纯前必须先过三问
1. **同一化学物质？** 完全不同的产品禁止比较（乙二醇 vs 丙二醇）。
2. **杂质是否可接受？** 水分、DEG、色度等是否影响下游工艺/检测（如聚酯级要求 DEG≤0.03%）。
3. **可线性折算？** 按纯物计量可折算，或含量差可由价格线性吸收。

### 4.2 三种处理
| 情形 | 处理方式 |
|---|---|
| 含量 ≥ 询价规格（如 99.92% / 99.90% vs 询价 99.9%） | **允许折纯**：`折纯单价 = 不含税单价 ÷ 含量`；排名用折纯价，结算价仍按实物吨 |
| 含量低于询价规格（如 99.5% vs 99.9%） | **默认剔除出同口径排名**，单列「规格不符」；用户显式接受时才按 99.5% 折纯参与，并标注 |
| 含量完全未注明 | 禁止折纯；列为待确认，「无法按规格判断」 |

### 4.3 折纯公式
```
折纯后单价（不含税） = 不含税单价 ÷ 折纯系数
折纯系数 = 实际含量 ÷ 100%（如 99.92% → 0.9992）
折纯后到厂成本 = 参考到厂成本 ÷ 折纯系数
```

## 5. 数量阶梯

```
命中阶梯 = 满足 (需求量 ≥ 阶梯下限) 的最大档位
```
- 必须按**本次采购量**命中，而不是选最低价档。
- `单笔` 与 `月累计/年累计` 口径不同，必须区分，并列为待确认项。
- 需求量低于最小起订量 → 报错并提示「不可下单」或「按零单加价计算」。

## 6. 账期 → 加权付款天数

合同上的「账期」不等于资金占用天数。应当按**现金流加权**计算：

```
d = Σ (t_i × w_i × 月末修正)
t_i = 第 i 笔付款距「下单/收货」的天数（以月为单位可直接用月数 × 30）
w_i = 该笔付款占货值比例
```

常见节奏的换算（示例）：
| 付款条件 | 加权天数 |
|---|---|
| 款到发货（预付 100%） | 0 天（但占用发生在最早期） |
| 预付 50%，货到付 50% | ≈ 10–12 天 |
| 预付 50%，见票后 7 天付余款 | ≈ 21 天 |
| 月结 30 天（次月 25 日结清） | ≈ 46 天 |
| 月结 60 天 | ≈ 76 天 |

## 7. 抽取提示：常见非标准写法

| 原文写法 | 应解析为 |
|---|---|
| 「6.20 元/公斤」 | 6200 元/吨（含税与否需看税项） |
| 「4850 不含税」 | 不含税单价，需另算税额与发票 |
| 「6300 到货价」 | 含运、含税的到货价（需确认税种） |
| 「月结30天，次月25日付」 | credit_days=30，加权 ≈ 46 天 |
| 「款到发货 / 现款结算」 | prepay_ratio=1.0 |
| 「一车起订 / 30吨/车」 | moq=30 吨 |
| 「量大从优 / 面议」 | 阶梯缺失 → 待确认 |
| 「含税、开专票」 | tax_included=true, invoice_type=专用发票 |
| 「10 天内有效」 | validity_days=10，起始日期缺失 → 待确认 |
| 「如遇原料波动保留调价权」 | price_adjust = 单方调价条款，列入风险项 |

## 8. 抽取质量门（进比价前必须全部通过）
1. 每份报价 15 个必填字段都有值，或显式标 `MISSING`。
2. 所有 `derived` 字段都带公式与来源。
3. 所有 `MISSING` 字段都带 `question`（向供应商要什么）。
4. 单位已统一到元/吨；税费已统一到「不含税可抵扣」；含量已判断是否折纯。
5. 交叉检查（分项加总 = 总额、数量 × 单价 = 金额）已通过。
