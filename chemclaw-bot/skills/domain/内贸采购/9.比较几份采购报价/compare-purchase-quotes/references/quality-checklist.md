# 质量控制清单（quality-checklist）

> 本清单用于**交付前自检**。任何一条「否」都必须在报告里显式披露，不能默默放过。

## 1. 抽取层（L1）

- [ ] 每份报价的 15 个必填字段都有值，或显式标记为 `MISSING`（不是空、不是 0）
- [ ] 原始单价保留原文写法（如「6.20 元/公斤」），没有被悄悄换算
- [ ] 每个字段保留 `source`：文件名 + 页码/工作表/单元格/图片坐标
- [ ] 报价单单位是「元/桶」「元/公斤」时，桶重/kg 换算系数有出处
- [ ] 图片/扫描件报价：OCR 或人工核对过关键数字（单价、含量、数量）
- [ ] 识别到「模拟样例 / 测试」字样时，在报告顶部显式声明

## 2. 口径层（L2）

- [ ] 三家单价都已统一到**同一计价单位**（元/吨）
- [ ] 三家单价都已统一到**同一税费口径**（不含税可抵扣）
- [ ] 普票 / 税率未注明的供应商，成本按**全额**计并单独标注
- [ ] 含量已判断是否折纯；含量低于询价规格的供应商**不参与同口径排名**
- [ ] 数量阶梯按**本次采购量**命中，且确认是「单笔」还是「累计」口径
- [ ] 卖方「含运」的价格已识别为价内，未重复加运费

## 3. 计算层

- [ ] `C_goods + C_pack + C_freight + C_unload + C_inspect + C_vehicle + C_capital + C_deposit = L`（分项之和 = 合计）
- [ ] 资金成本迭代已收敛（|Δ| < 1e-9），报告给出迭代次数
- [ ] 数量 × 单价 = 金额（含税口径与不含税口径分别校验）
- [ ] 差异归因各项之和 = 到厂成本差额（误差 < 0.01 元/吨）
- [ ] HTML 里的 JS 计算与 Python 引擎结果一致（误差 < 0.01 元/吨）
- [ ] Excel 公式与引擎计算一致
- [ ] 资金成本使用 360 天口径（与生意社定价公式一致），并在参数表注明

## 4. 假设层（L3）

- [ ] 所有假设值都在「假设清单」中出现，并带性质标签（用户输入 / 假设 / 惯例 / 法定 / 市场）
- [ ] 没有把任何「未提及」的费用默认成 0
- [ ] 每条缺失都有 `question`（明确要向供应商索取什么）
- [ ] 假设值改变后结论是否翻转已有敏感性分析

## 5. 报告层

- [ ] 顶部有「模拟样例 / 数据来源与截止日期」声明
- [ ] 能区分：原始值（紫）/ 转换值（蓝）/ 假设（黄）三层色标
- [ ] 每个数字可展开看到公式、输入与来源
- [ ] 排名表明确标注了「不参与排名」的供应商及原因
- [ ] 结论段说明了「差异来自哪里」（单位、税费、运费、账期、规格、包装）
- [ ] 如有市场价：注明日期、规格、区域、含税口径与来源链接
- [ ] 没有宣称「市场最低价」或提供无法核实的报价

## 6. 常见错误对照表

| 错误 | 正确做法 |
|---|---|
| 把 6,300 元/桶当成 6,300 元/吨 | 先除桶重 220 kg → 28,636 元/吨 |
| 用 4,850（不含税）与 6,200（含税）直接比大小 | 统一到不含税或含税再比 |
| 同一家价格用「最低阶梯档」计算 | 按实际采购量命中阶梯 |
| 「运费未提」→ 成本里记 0 | 列为待确认，或用买方假设并标注 |
| 把「月结 30 天」当作 30 天资金占用 | 49/60 天平均付款日 → 加权 ≈46 天 |
| 规格不同还直接排名 | 折纯或单独列出，并说明可比性 |
| 供应商 A 的报价含运，又加了一次运费 | 卖方含运 → 运达成本为 0 |
| 差异归因「其他」占比过大 | 拆到每个分项，合计必须对上 |

## 7. 交付物自检

- [ ] HTML 单文件可直接双击打开（无外部依赖、无网络请求）
- [ ] HTML 在无头浏览器中无 JS 报错、无 NaN/undefined、无横向溢出
- [ ] Excel 11 个工作表齐全，公式可重算
- [ ] ZIP 目录结构符合 `SKILL.md / references / examples / scripts / assets`
- [ ] ZIP 内不含个人隐私、真实企业机密（如为样例须声明）
