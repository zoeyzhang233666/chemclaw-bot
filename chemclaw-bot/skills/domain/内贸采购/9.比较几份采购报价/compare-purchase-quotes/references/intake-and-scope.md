# 采购问题模板与适用边界（intake-and-scope）

## 1. 标准输入模板

```
我要采购【产品/规格】，数量【数量】，收货地【地点】。
我上传了多份供应商报价，请：
1) 分别提取产品名称、规格、计价单位、单价、是否含税及税率；
2) 提取包装形式、包装费用、运费承担方与金额、交货方式、付款条件、账期、最小起订量、报价有效期和质量标准；
3) 如果产品含量或规格存在差异，先判断是否允许折纯比较，满足条件时统一折纯口径；
4) 统一计价单位、税费、包装、运输和交付条件，计算各供应商参考到厂成本；
5) 根据我提供的年化资金成本【比例，可选】计算不同账期对应的资金占用成本；
6) 标注卸车费、检验费、罐车清洗费、包装回收费、涨价条款及价格联动机制等容易被忽略的费用或条件；
7) 给出全部计算公式、参数和来源。
缺失字段必须列为待确认，不得自行假设。
```

### 必填
- **至少 2 份采购报价文件**（格式任意：PDF / Excel / Word / 图片 / 文本）。

### 可补充（都可缺省，缺省时按 `references/cost-formulas.md` §8 的默认值并标注「假设」）
- 年化资金成本（例：4.5%）
- 买方运费报价（元/吨）
- 税率、发票类型要求
- 卸货费用、检验费用、清洗费用
- 运输方式（槽车 / 吨桶 / 铁桶 / 袋装）
- 实际采购数量、年采购量
- 企业采购合同模板（用于条款一致性检查）
- 市场价参照（生意社 / 卓创 / 历史成交价）

## 2. 适用边界

### 适用
- 同一化学物质的**多供应商**报价比较（内贸采购）
- 混合规格（可通过含量折纯）
- 混合单位（元/公斤、元/吨、元/桶、元/袋）
- 混合税费口径（含税/不含税/专票/普票）
- 混合交付方式（自提 / 送货 / DDP / FCA）
- 1~20 份报价（超过 20 份时建议按品类分组）

### 不适用（必须显式说明并拒绝或降级）
| 情境 | 原因 | 替代做法 |
|---|---|---|
| 不同化学物质（如乙二醇 vs 丙二醇） | 无共同基准 | 分品类分别比较，或按用途价值折算并明确注明 |
| 含量/规格差异大且不可线性折算（如工业级 vs 医药级） | 不能折纯 | 不参与同口径排名，单列并说明理由 |
| 报价方为经销商、且无法确认货源与规格 | 有降级风险 | 先走「核实供应商资质/尽调」，再比价 |
| 要求预测未来价格走势 | 本技能不做预测 | 用「核实供应商报价是否合理 / 看原料近期行情」 |
| 国际采购 / 进口（需要汇率、关税、信用证） | 口径不同 | 单独扩展外币与关税口径，另做 |

## 3. 边界内必须声明的灰区

1. **含量差异不大但不能确认「可线性折算」** → 默认剔除出同口径排名，给出折纯参考价，并由用户确认。
2. **卖方含运但未拆分运费** → 不能反推运费，只能把价差归因于「价格 + 隐含运费」。
3. **税率未注明** → 默认按普票（保守），同时给专票情景。
4. **报价仅口头或聊天记录** → 必须索取盖章报价单；聊天截图只能作为初始参考。

## 4. 典型追问（当用户只给了第一句话时）

- 采购数量是一次性还是年度分摊？（影响数量阶梯、保证金摊薄）
- 是否必须取得 13% 增值税专用发票？
- 收货地的具体厂址与卸货条件（槽车、吨桶、卸车设备）？
- 可否接受低于规格的含量？
- 年化资金成本是多少（若未给，用 4.5% 示例并标注）？
- 以最近一次成交价或某平台价格作为市场参考吗？

## 5. 判定输出是否可交付

满足 `references/quality-checklist.md` 全部「是」后，再输出：

- HTML 比价报告
- Excel 工作簿（原始数据 + 标准化 + 公式 + 敏感性 + 待确认）
- 一页结论（推荐供应商、价格差、首要风险、下一步动作）
