# 示例 01：华东地区工业级乙二醇供应商报价合理性核验

一次完整演示：从**测试报价**出发，走完 6 个必需步骤，产出可交互 HTML 报告 + 13 表 Excel。

## 事实摘要（这份报告得出的结果）

| 项目 | 结果 |
|---|---|
| 供应商报价（**测试输入**） | 5,900 元/吨，工业级，含 13% 增值税，苏北工厂车板出厂，60 吨/次，30% 预付+月结 |
| 同日市场参考（含税出厂口径） | 5,580 – 5,665 元/吨，中枢 5,635 元/吨（隆众华东自提 5,635 + 同日出厂/库提差额） |
| 偏离 | **+265 元/吨，+4.70%** |
| 1 年历史分位（生意社基准价，日频 366 点） | **86.9%** |
| 1 年 / 3 年期货 EG0 分位（不含税盘面） | 86.0% / 95.3% |
| 3 个月分位 | **缺口**——只有 6 个逐日快照，少于 8 个有效样本 |
| 口径不匹配 | **规格不可比**：报价是「工业级」，市场参考是「聚酯级 ≥99.9%」，不产出该口径下的偏离数 |

## 这份示例刻意展示的三个"不做什么"

1. **不硬算不可比的口径**：工业级 vs 聚酯级，只出对比表 + 待确认清单，不出偏离数。
2. **不补序列**：3 个月现货分位是缺口，就写缺口；1 年用指数代理并注明是代理，3 年现货分位直接标缺。
3. **不用期货减现货**：现货 5,635 与期货 4,976 的差额里含增值税与基差，报告只把两者放进同一张走势图做位置对照。

## 换品种跑一遍

复制 `examples/02-template-blank/`，按 `references/product-family-specs.md` 新建 `specs/<品种代码>.json`，
再按 `references/data-contract.md` 填 `research.json`，然后 `python scripts/build_report.py <你的 research.json>`。
乙二醇的规格术语、区域、锚点、事件都锁在 `specs/meg.json` 里，不会被带到别的品种上。
