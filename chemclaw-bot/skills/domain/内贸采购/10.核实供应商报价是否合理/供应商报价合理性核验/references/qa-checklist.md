# 交付前自检清单

逐项打勾；任何一项 ✗ 都不得交付。

## A. 数据层

- [ ] 每条市场价格都有：数值、规格/等级、地区、税费、交付、日期 + 来源（六项齐全）
- [ ] 主锚（primary）只有一条，且是**同日同地区同规格**的市场价，不是挂牌价或指数
- [ ] 企业挂牌/结算/竞拍价单独列表，标注"企业定价，非市场均价"
- [ ] 期货序列标注"不含税、盘面口径"，且报告中写明**不能直接与现货相减**
- [ ] 指数序列（如有）标注"指数≠成交价"，只用于走势与分位
- [ ] 报价单原话（`raw_text`）逐字保留，未改写
- [ ] 测试报价已显著标注"测试输入"

## B. 计算层

- [ ] 单位已统一（元/kg → 元/吨）
- [ ] 含税/不含税换用 1+VAT，方向正确（含税→不含税用除）
- [ ] 缺运价时「到厂」靶心留空，**没有**用行业均运费顶替
- [ ] 缺账期资金成本时不做贴息折现，或明确写出假设参数
- [ ] 偏离金额/偏离比例/区间内位置都可由「09 计算公式」复算
- [ ] 分位只来自有效序列，样本数、频率、起止日期齐全
- [ ] **没有**用最高价/最低价推断分位
- [ ] 换窗口的分位中，报价与序列已在同一税费口径下比较

## C. 判定层

- [ ] 规格不一致（如工业级 vs 聚酯级）时**没有**产出偏离数，且报告有醒目口径不匹配横幅
- [ ] 十类口径逐项给出「已对齐 / 已有依据 / 待确认 / 不可比」之一
- [ ] "可以用证据解释的差异"每条都有同日真实价依据
- [ ] "尚待确认的差异"写成可直接问供应商的原话
- [ ] 缺口表写清"缺什么 / 影响 / 试过哪些渠道 / 为什么补不上 / 怎么补"

## D. 表达层（红线）

- [ ] 全文无"应该还价到 X""目标价""底价""合理成交价应为"
- [ ] 全文无"看涨/看跌/见底/见顶/有望/预计/后市看"
- [ ] 没有把回撤写成"抄底机会"
- [ ] 未用期货价减现货报价得出价差结论
- [ ] 结论段落只陈述事实与口径，不含方向判断

## E. 产物层

```bash
python scripts/check_output.py work/<case>_model.json <out_dir>
# 期望：结论：通过（失败 0）
```

- [ ] HTML 单文件、可断网打开（无外部 script/link）
- [ ] HTML 首屏即见：市场参考区间 + 报价标记 + 历史分位
- [ ] 走势图可切换窗口/口径；异常价格阶段可点开对应事件
- [ ] 口径不匹配横幅醒目（橙色/红色，首屏可见）
- [ ] Excel ≥ 10 张表，含价格历史、偏离比较、计算公式、来源清单
- [ ] Excel 与 HTML 数字一致（check_output.py 会抽查参考中枢）
- [ ] `check_office.py` 判定 pass

## F. 交付话术

- [ ] 回复只给：两个文件绝对路径 + 3–5 句事实摘要 + 缺口清单 + 待确认清单
- [ ] 不替采购下结论，不出现"建议"，不预测
- [ ] 明确说明"报价为测试输入/或来自 X 供应商的 Y 日报价单"
