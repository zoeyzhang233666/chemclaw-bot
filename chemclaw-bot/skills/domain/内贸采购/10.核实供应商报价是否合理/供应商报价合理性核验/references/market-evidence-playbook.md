# 市场取证手册（按品种族）

**核心原则：找不到「同规格 + 同地区 + 同税费 + 同交付 + 同日」的参考价，就不要相减。** 宁可交一份写着缺口的报告，
也不要交一份用行业均价硬算出来的偏离百分比——后者会被供应商一句话打回，还可能让采购在谈判里被动。

## 一、渠道优先级

| 级别 | 渠道 | 能得到什么 | 使用边界 |
|---|---|---|---|
| 1 | 交易所 / 官方平台（大商所、郑商所、上期所、国家级价格监测） | 期货结算价、交割品标准、库存 | **期货是不含税远期价，只能画走势、算盘面分位，不能减现货** |
| 2 | 产业资讯日报（隆众、卓创、我的钢铁网、生意社、百川盈孚） | 地区主流成交价、买/卖盘、基差 | 必须记下标题、发布时间、发布方；多数需要订阅或登录 |
| 3 | 期货公司 / 协会 / 行业媒体日报 | 现货主流价 + 基差 + 库存 + 开工 | 一条常同时解决"价格 + 事件" |
| 4 | 公开商品指数（生意社基准价等） | 日频连续序列（走势、分位） | **指数 ≠ 成交价**；只能用于历史位置，不能当现货参考价 |
| 5 | 企业挂牌价 / 结算价 / 竞拍价 | 月度挂牌、结算、起拍价 | **企业定价 ≠ 市场均价**；竞拍价可作"出厂含税"的旁证 |
| 6 | 电商 / 贸易商挂单报价 | 二手参考 | **离散度常 >20%**，地区混杂，一般不构成有效区间；只能说明"存在这个价位" |

## 二、按品种族找价

### 大宗化工品（有期货品种：甲醇、乙二醇、PTA、PVC、纯碱、玻璃、尿素、苯乙烯、PP/PE…）
1. 先取期货日线（新浪财经 `InnerFuturesNewService.getDailyKLine?symbol=EG0` 等连续合约，或用交易所历史行情），
   作为 1 年 / 3 年分位的**可比序列**（注明不含税、盘面口径）。
2. 再从级别 2 拿**同日现货主流价**（有买/卖盘更好），这是唯一能算偏离的锚。
3. 用级别 5 的**竞拍/挂牌价**校正「出厂 vs 库提」的差额——同一交易日、同一品种的出厂价与华东自提价之差，
   就是最便宜也最可靠的交付口径换算依据。
4. 现货日频序列通常是付费的：拿不到就**用指数序列做历史位置 + 逐日快照做短期区间**，两者都标注口径。

### 精细化工品（无期货品种：多数助剂、表活、香料、电子化学品…）
- 没有期货可参照，**历史分位往往拿不到**。此时：
  - 3 个月：靠供应商历史报价、合同价、同行询价记录（≥8 个点）；
  - 1 年 / 3 年：明确写缺口，只做「与本年度公开挂牌/竞拍锚点的差额」对比；
- 精细品价格离散度大，**同规格定义必须落到具体指标**（含量、色度、金属离子、水分），否则区间无意义。

### 中间体（有明确上下游但无期货）
- 用**上下游价差**校验：原料成本 + 加工区间 → 反推该中间体的"成本附近价位"仅作结构说明，
  **不得当作市场参考价**，也不能据此判断报价高低。
- 中间体常见"一单一价"，参考价证据优先级：**同厂同规格历史成交 > 同行询价 > 公开挂单**。

## 三、常见假数据与陷阱

| 陷阱 | 识别方法 | 处理 |
|---|---|---|
| 指数当成交价 | 标题写"基准价/指数/价格指数" | 只进分位与走势，不进现货表 |
| 挂牌价当市场价 | 来自企业公告"挂牌/结算" | 单列企业定价表，标注"非市场均价" |
| 跨地区混用 | 报价华东、参考山东 | 标不可比，或找到同地区参考 |
| 跨规格混用 | 工业级 vs 聚酯级、含量不同 | **不出偏离数**，只列口径矩阵 |
| 期货减现货 | 数字差几千元 | 只能同屏走势；换算需 (1+VAT) 与基差 |
| 贸易商挂单当区间 | 同日同规格离散 >20% | 不构成区间，最多作为"存在此价位"的旁注 |
| 用最高/最低价估分位 | 只有两个数 | 禁止；无序列就是缺口 |
| 过期报价 | 报价日期 ≠ 核验基准日 | 标"过期"，不参与比较 |

## 四、口径换算的可靠依据（按可靠度排序）

1. **同日、同品种、跨交付口径的两个真实报价之差**（如出厂竞拍价 vs 华东自提价）→ 得交付/地区差额；
2. **同日承兑与现汇报价之差** → 得账期/承兑贴水；
3. **同日报价中的高低价之差** → 得当日买卖价差（不等于品质价差）；
4. 公开运价/物流平台报价 → 得运费（须注明线路、车型、吨位）；
5. 行业经验值 → **只能写"待确认"，不得进公式**。

## 五、取证记录模板

每一条价格证据至少记录：

```
日期 / 时间：2026-10-19 09:30
发布方与标题：隆众资讯《[乙二醇]：10月19日（09:30）张家港市场乙二醇价格行情》
数值：5635 元/吨（买 5630 / 卖 5640）
规格：聚酯级 含量≥99.9%
地区：华东（张家港）
税费：含税
交付：自提
URL：https://...
原文要点：（引述原句，不要改写）
```

缺任何一项 → 该条不得进入「市场价格」表，只能进「数据缺口」。
