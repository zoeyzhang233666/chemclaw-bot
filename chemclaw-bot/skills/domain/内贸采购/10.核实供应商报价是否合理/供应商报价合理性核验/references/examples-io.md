# 输入输出示例（可直接拿去对答案）

## 示例 A：一个"不可比"的报价怎么处理

**输入**（供应商原话）

> 乙二醇 工业级 5900元/吨，含税，出厂连云港，60吨，30%预付余款月结

**第 0 步解析结果**

```json
{
  "product": "乙二醇", "spec_claimed": "工业级", "purity_claimed": null,
  "value": 5900, "unit": "元/吨", "tax": {"included": true, "rate": 0.13},
  "delivery": {"basis": "ex_works"},
  "unknowns": ["含量", "关键指标", "工艺路线", "有效期", "承兑口径", "阶梯价"]
}
```

**第 1 步标准化**：含税出厂 = 5,900；不含税出厂 = 5,900 ÷ 1.13 = **5,221.24**；
到厂 = **缺口**（无运价）。

**第 2 步市场匹配**（同日）

| 来源 | 口径 | 价 |
|---|---|---|
| 隆众 10-19 09:30 张家港 | 聚酯级 ≥99.9%，含税，自提 | 5,635（买 5,630/卖 5,640） |
| 潞安 10-19 竞拍 | 聚酯级（合成气制），含税，出厂 | 5,580（承兑 +50） |
| 生意社 10-19 基准价 | 聚酯级综合，含税，基准价 | 5,808.33 / 5,966.67 |

**第 3 步偏离**：含税出厂口径参考区间取 5,580–5,665，中枢 5,635 →
偏离 **+265 元/吨（+4.70%）**。

**关键判断**：报价是**工业级**，参考是**聚酯级**。
→ 该差异方向为"工业级更低"，但**金额无法从公开数据量化**（当日工业级挂单 5,300–6,600 离散 >20%）。
→ 因此这一格的结论是 `待确认`，而不是"报价高 4.7% 所以偏高"。

**结论表述示范（可直接用于交付回复）**

> 供应商报价为工业级、含税、出厂、60 吨、30% 预付+月结，与同日华东聚酯级自提价（5,635 元/吨，隆众 2026-10-19）不是同一规格，
> 因此未做直接偏离结论。把交付口径对齐到"含税出厂"后，报价高于同日出厂参考中枢 265 元/吨（+4.70%）。
> 该差额中有多少来自工业级与聚酯级的规格差异，公开数据无法量化，需供应商提供含量与执行标准后才能判定。

## 示例 B：分位缺口怎么写

**错误写法** ❌

> 报价处于历史 78% 分位（近一年区间 4,000–7,300，报价 5,900 位于该区间 68% 位置）。

问题：把"区间内位置"当成"历史分位"，且用最高/最低价推断。

**正确写法** ✅

> - 1 年分位：**86.9%**（生意社乙二醇基准价，日频 366 个样本，2025-10-19 ~ 2026-10-19，含税、全国综合口径）。
> - 3 个月分位：**未计算**——只取得 6 个逐日快照（少于 8 个有效样本），仅给区间 5,568–5,780 元/吨。
> - 3 年现货分位：**未计算**——未取得 2023-10 至 2026-10 的逐日现货序列；改用 EG0 期货日频 725 个交易日（不含税盘面），分位 95.3%。该数字**不代表现货分位**。

## 示例 C：期货数据怎么用才不出错

| 做法 | 对错 | 原因 |
|---|---|---|
| 报告中写"现货 5,635，期货 4,976，现货升水 659 元" | ❌ | 5,635 含 13% 增值税，且含基差/交割成本 |
| 报告中写"现货折不含税 4,987 与期货 4,976 接近，基差约 11 元" | ⚠️ 勉强 | 需说明基差另含交割成本与品级差异，且须注明基差来源 |
| 走势图同时画现货指数与期货收盘，图注写"口径不同，仅作位置对照" | ✅ | 不产生价差结论 |
| 用期货近 3 年分位说明"该价位在盘面历史上偏高" | ✅ | 只要标注是**盘面**分位而非现货分位 |

## 示例 D：一段合格的"待确认清单"

```
1) 请确认本批乙二醇的含量是否 ≥99.9%，执行标准号，并提供本批检验报告（UV 透过率、醛含量、水分）。
2) 请确认工艺路线（乙烯法/煤制）与品牌产地。
3) 请确认报价有效期；如随行就市，请给出调价基准与升贴水。
4) 请报「送到苏州工业园区」的到厂价，或提供连云港至苏州的运费标准（含卸车/罐费）。
5) 请说明 60 吨的最小起订量与阶梯价，以及承兑付款的加价幅度。
```

注意：**不出现"你报高了/应该降到多少"**——只问口径，结论留给采购。

──────────────── 市场参考区间（含税出厂，元/吨） ────────────────
   5,580 ⟵────────── 5,635 ──────────⟶ 5,665
                       ▲ 供应商报价 5,900（区间上沿外 +235）
