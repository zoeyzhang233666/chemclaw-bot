# 研究手册：从产品到可核事件

本手册回答两个问题：**去哪里找**、**怎么判断这条信息能不能用**。适用于任意化工品；示例中的“纯碱”只是写法示范。

---

## 0. 先定边界（10 分钟）

动手搜之前，把下面五件事写进 `meta`，否则后面一定返工：

| 边界 | 要写清 | 为什么 |
|---|---|---|
| 产品 | 品名 + 规格/牌号 + 用途（如“纯碱·重质·玻璃级”） | 同一品名不同规格的供应商、价格、下游完全不同 |
| 采购形态 | 内贸/进口、厂家直采/贸易商、长约/现货 | 决定“供应商”是生产企业还是贸易商 |
| 区域 | 全国 / 某省 / 某园区 | 决定地方处罚、环保、应急公示的检索范围 |
| 时间 | 截止日 + 3/6/12 个月窗口 | 所有事件按**发生日期**归档，不按新闻发布时间 |
| 供应商全集 | 生产商名单；是否含母公司/子公司/关联贸易商 | 主体错位是这类报告最常见的硬伤 |

**供应商全集怎么建**：
1. 上市公司：年报/半年报的“主要产品产能、生产基地、子公司”章节；交易所公告。
2. 行业协会：产能/产量排名、会员名单（如中国纯碱工业协会、中国氯碱工业协会、石化联合会）。
3. 地方政府：环评/备案/排污许可/项目公示，能反推在建与在产装置。
4. 行业媒体/咨询：隆众、卓创、生意社、期货公司研报（用于发现名字，不直接当证据）。
5. 采购侧：现有合同、询价记录、贸易商上游披露。

**产能口径**：写“名义/有效/在建/规划”，不要只写一个数字。检修、减量、试生产、许可证到期都会让可供量低于名义产能。

## 1. 五类风险 + 行业背景：取证通道

### 1.1 工商 / 治理

**看什么**
- 经营异常名录、严重违法失信名单。
- 股权冻结、股权质押异常、控制权变更、实际控制人变更。
- 注册资本大幅减资、注册地/经营范围异常变更。
- 董监高异常（失联、被留置、密集辞职）。
- 母公司对子公司的担保、资金占用、关联交易。

**去哪查**
- 国家企业信用信息公示系统 `gsxt.gov.cn`：经营异常、行政处罚、股权变更、年报。
- 信用中国 `creditchina.gov.cn`：失信被执行人、重大税收违法、行政处罚。
- 交易所：上交所 `sse.com.cn`、深交所 `szse.cn`、北交所 `bse.cn`；巨潮 `cninfo.com.cn`。
- 证监会/地方证监局：监管措施、问询函、立案调查。
- 港股：HKEXnews `hkexnews.hk`。

**查询模板**
```
"公司全称" 经营异常
"公司全称" 股权冻结
"公司全称" 控制权 变更
"公司全称" 董监高 辞职
"公司全称" 关联交易 担保
site:cninfo.com.cn "公司全称" 公告
```

**误判**
- 同名公司：用统一社会信用代码/证券代码/注册地交叉确认。
- 子公司事件写成母公司：主体写到具体法人，`supplier` 写合同相对方。
- 正常人事变动写成“治理风险”：只有涉及控制权、财务负责人频繁更换、审计意见异常时才升级。

---

### 1.2 司法 / 监管

**看什么**
- 买卖合同、建设工程、借款、票据、劳动争议等诉讼/仲裁。
- 被执行、失信、限制高消费。
- 证监会立案/行政处罚、交易所公开谴责/监管函。
- 破产重整、清算、债权人申请。

**去哪查**
- 中国裁判文书网 `wenshu.court.gov.cn`（公开量下降，能查到多少算多少）。
- 全国法院被执行人信息查询 `zxgk.court.gov.cn`。
- 信用中国、地方法院/仲裁委公示。
- 交易所“监管措施/纪律处分”栏目；证监会 `csrc.gov.cn`。
- 企业公告里的“重大诉讼、仲裁”章节。

**查询模板**
```
"公司全称" 买卖合同 纠纷
"公司全称" 被执行
"公司全称" 失信
"公司全称" 仲裁 公告
"公司全称" 证监会 立案
"公司全称" 监管函
```

**怎么判断分量**
- 标的额 / 最近一期营收或净资产：<1% 通常不构成重大；>5% 要重点看。
- 原告/被告：被告且已进入执行，比“原告起诉别人”更值得关注。
- 是否已判决/和解/上诉；只立案不等于败诉。
- 是否有多个案件、是否集中在同一供应商/客户。

---

### 1.3 行政处罚

**看什么**
- 海关：申报不实、保税料件、加工贸易、出口退税。
- 税务：虚开、偷逃税、发票违规。
- 市场监管：产品质量、价格、广告、特种设备。
- 生态环境：超标排放、未批先建、危废、排污许可。
- 应急管理：安全生产许可证、重大隐患、事故处罚。
- 交通运输：危化品运输违规。

**去哪查**
- 海关总署 `customs.gov.cn` 及直属海关“行政处罚”公示。
- 信用中国“行政处罚”栏目（按企业名/统一社会信用代码）。
- 国家税务总局各省局“重大税收违法失信主体”。
- 生态环境部/省市生态环境局“行政处罚决定”。
- 应急管理部/省市应急管理局“行政处罚”“事故调查报告”。
- 市场监管总局/省市局“行政处罚公示”。

**查询模板**
```
"公司全称" 行政处罚
"公司全称" 海关 处罚
"公司全称" 生态环境局 处罚
"公司全称" 应急管理局 处罚
"公司全称" 市场监管 处罚
"公司全称" 罚款 决定书
```

**怎么判断分量**
- 金额：相对营收/净利；几万元通常低，但“责令停产/吊销许可证”比金额更重要。
- 性质：程序性（申报差错）vs 实质性（超标排放、事故瞒报）。
- 是否整改完成、是否重复发生、是否影响许可证/报关资质。
- 不要用“有一条罚单”直接推“交付有问题”；写到“需确认整改与资质”。

### 1.4 安全环保

**看什么**
- 事故：火灾、爆炸、泄漏、中毒、窒息、坍塌。
- 环保：超标排放、异味/噪声投诉、固废/危废违规、被中央环保督察点名。
- 停产整改：事故后停产、环保督察停产、许可证到期/暂扣。
- 排污许可：无证排污、超许可排放。
- 职业健康：尘肺、中毒等职业病群发。

**去哪查**
- 应急管理部 `mem.gov.cn`：事故通报、安全生产严重失信名单。
- 省市应急管理局：事故调查报告、责令停产整顿。
- 生态环境部 `mee.gov.cn`：督察案例、行政处罚；排污许可平台 `permit.mee.gov.cn`。
- 省市生态环境局：行政处罚、信访投诉、环评公示。
- 地方政府/园区：停产整顿通知、复产验收公示。
- 主流媒体：事故首报通常快，但细节要等官方通报。

**查询模板**
```
"公司全称" 事故
"公司全称" 火灾 爆炸 泄漏
"公司全称" 停产 整改
"公司全称" 环保 处罚
"公司全称" 排污许可
"公司全称" 督察
```

**关键区分**
- **计划检修**：公告写“年度检修/计划停车”，有起止时间，通常不构成事故。
- **非计划停产**：事故、设备故障、原料断供、限电、许可证到期；对交付影响更直接。
- **减产/降负荷**：不等于停产，但要问减少多少、持续多久。
- **“未检索到事故”**：只能写“未检索到公开事故记录”，不能写“无事故”。

### 1.5 经营动态

**看什么**
- 检修/减量/复产/新装置试生产/达产。
- 半年报/年报/业绩预告：营收、净利、现金流、负债、毛利率。
- 新增产能、技改、搬迁、关停、项目延期。
- 定增、可转债、银行授信、债券违约、评级下调。
- 股权转让、控制权变更、重组、剥离。
- 重大合同、客户/供应商集中度。

**去哪查**
- 巨潮/交易所公告：定期报告、业绩预告、停产检修、项目进展、融资。
- 公司官网/公众号：检修、复产、投产。
- 环评/备案公示：新建/扩建项目的规模、进度。
- 行业协会/咨询：开工率、产量、检修损失量。
- 法院/信用中国：债务、执行、失信（与经营恶化交叉验证）。

**查询模板**
```
"公司全称" 检修 停产
"公司全称" 复产
"公司全称" 试生产 达产
"公司全称" 业绩预告
"公司全称" 定增 可转债
"公司全称" 项目 环评
"产品名" 新增产能 2026
```

**怎么判断分量**
- 检修：看损失量（万吨/月）、持续天数、是否覆盖旺季、是否有备用产线。
- 亏损：看是行业性还是个体性；经营现金流是否为正；有息负债/短债压力。
- 新增产能：试生产 ≠ 达产；达产 ≠ 稳定供货；注意质量认证周期。
- 股权变化：控制权变更可能带来战略调整，但不必然影响生产。

### 1.6 行业背景

**看什么**
- 全国/区域产能、开工率、产量、库存。
- 新增/退出产能、检修季、进口/出口。
- 价格与成本（原盐、石灰石、天然气、煤、电）。
- 下游需求（玻璃、氧化铝、洗涤剂、光伏等）。

**去哪查**
- 行业协会月报/年度报告。
- 期货公司研报（郑商所纯碱、烧碱等）。
- 隆众、卓创、生意社（部分付费）。
- 国家统计局、海关总署进出口数据。
- 上市公司年报的“行业情况”章节。

**用法**：行业背景只用来**解释事件分量**，不替代个体事件。比如“行业普遍检修”能解释为何多家同时减量，但不能证明某家不会断供。

## 2. 来源等级与引用

| 等级 | 来源 | 用法 |
|---|---|---|
| A | 公司公告、交易所、证监会/海关/生态环境/应急/法院等官方原文 | 可直接作为事实依据；尽量给原文 URL |
| B | 主流财经媒体、行业媒体、协会报告、券商研报 | 可作事实线索，但关键数字回查 A |
| C | 聚合平台、论坛、贴吧、未具名“业内人士” | 只用于发现线索，不单独支撑结论 |

**引用要求**：
- `source` 写清“谁发布的什么文件”，不要只写“网络”。
- `source_date` 是文件日期，不是抓取日期。
- `url` 尽量是原文；付费/失效链接在 `url_label` 注明“需登录/可能失效”。
- 同一事件多家转载只算一条，来源选最接近原始的。

## 3. 时间纪律

1. 以**事件发生日期**（`date`）归档；公告日期放 `source_date`。
2. 窗口边界：`start <= date <= end`，含首尾。
3. 12 个月窗口用于背景，不把 12 个月外的旧事混进 6 个月计数。
4. 旧闻再版：看正文里的“日前/近日”与原始公告日期，不要被页面“发布时间”骗。
5. 预测/计划：写“计划/预计”，不要写成已发生。
6. 截止日之后的变化不纳入；在 `meta.query_time` 写清截止时点。

## 4. 从事实到采购语言

每条事件按四层写，禁止混写：

**① fact（事实）**
- 谁（法人/基地/产线）
- 何时（发生日期）
- 发生了什么（动作）
- 数字（金额、产能、天数、负荷）
- 来源（公告/处罚决定书/判决）

**② why（采购含义）**
- 只写到“可能影响交付/合规/成本，需要确认X”的程度。
- 例：
  - 对： “检修降低短期可供量；另一条线仍在生产，不能直接推定为交付中断。”
  - 错： “该供应商即将断供，必须立即换源。”
- 结合采购用途：玻璃厂关注重质纯碱粒度与稳定供货；洗涤剂厂关注轻质纯碱与价格。

**③ questions（待确认问题）**
- 3 个，能直接问供应商/业务。
- 好问题： “检修线月度排产减少多少吨？”“另一条线能否覆盖既有合同？”“复产是否有书面确认？”
- 坏问题： “你们有没有风险？”（无法回答）

**④ action（动作）**
- 索证：许可证、处罚整改、环评批复、财务说明。
- 合同：保供条款、替代源、价格调整机制、质量异议期。
- 运营：备货、双源、小试验证、驻厂/视频验厂。
- 跟踪：下次复核日期、触发条件。

## 5. 覆盖检查：把“没查到”说清楚

`coverage_check` 固定六类，每类给出：
- `status`：查到几条 / 未检索到 / 待复核。
- `note`：查了哪些渠道、为什么可能漏、下一步怎么补。
- `level`：高/中/低/待复核/—。

示例：
```json
{"cat": "经营异常", "status": "未检索到公开记录", "note": "已查国家企业信用信息公示系统与信用中国；地方分局数据可能滞后，建议按注册地复核。", "level": "待复核"}
```

**禁止**：
- 把“未检索到”写成“无风险”。
- 只写“已全面排查”而不写渠道。
- 六类只写三类，剩下省略。

## 6. 常见误判清单

| 误判 | 正确做法 |
|---|---|
| 把集团公告当成子公司事件 | 主体写到具体法人/基地；`supplier` 写合同相对方 |
| 同名公司混入 | 用信用代码/证券代码/注册地确认 |
| 计划检修写成事故 | 看公告措辞、起止时间、是否有官方事故通报 |
| 罚单金额小就忽略 | 看是否责令停产、吊销许可证、重复发生 |
| 亏损就推断裂供 | 看现金流、负债、客户结构、是否仍在正常排产 |
| 新增产能=可供量 | 试生产/达产/质量认证分开 |
| 旧闻当新闻 | 以事件发生日期为准，来源日期单列 |
| 媒体转述当原文 | 标 B，回查公告/监管原文 |
| “未检索到”=“无风险” | 写“未检索到公开记录”，并列明未覆盖渠道 |
| 一条新闻推“必涨价/必断供” | 只写“可能影响，需确认”，给触发条件 |

## 7. 检索记录怎么留

建议在 `method.search_queries` 里保留本轮主要查询式（不必全部），方便复核：
```
"公司名" 行政处罚
"公司名" 停产 检修
"公司名" 事故
"公司名" 诉讼 被执行
"产品名" 新增产能 2026
```
并在 `method.limits` 写清：
- 哪些渠道需要登录/付费，未覆盖。
- 哪些供应商非上市，财务不公开。
- 哪些事件只有媒体转述，未拿到原文。
- 检索截止时点。

## 8. 一页流程（贴在工位上）

```
定产品/规格/区域/窗口
  → 建供应商全集（上市+非上市，母/子公司分清）
  → 五类扫一遍 + 行业背景
  → 每条事件：日期/主体/事实/来源/证据等级
  → 写 why（只到“需确认”）+ 3 个问题 + action
  → 六类覆盖检查（含“未检索到”）
  → validate.py → build_all.py → qa.py
  → 人工抽 3 条点开链接复核
```
