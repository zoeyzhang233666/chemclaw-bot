# 版式与交互：为什么它看起来像一份“能开会”的材料

目标不是“好看”，而是**一眼看出哪家有事、哪条最重、点开能核**。改版式可以，但别破坏这三件事。

---

## 1. HTML 设计系统

### 1.1 气质

- 底色是暖纸色，不是纯白；正文深海军蓝，强调用青绿/铜色/砖红。
- 标题用宋体/衬线，正文用苹方/微软雅黑；数字用等宽。
- 细网格背景 + 柔和投影，像一份印刷报告，不像后台管理系统。
- 红/橙/蓝/绿只用于风险等级，不做装饰色。

### 1.2 色板

| 变量 | 值 | 用途 |
|---|---|---|
| `--ink` | `#142B3F` | 主文字、深色块 |
| `--ink-2` | `#3D5566` | 次级文字 |
| `--muted` | `#6E7F8C` | 说明文字 |
| `--paper` | `#F4F0E6` | 页面底色 |
| `--card` | `#FFFDF8` | 卡片 |
| `--line` | `#DED7C7` | 边框 |
| `--teal` | `#0E746B` | 正向/强调/链接 |
| `--copper` | `#A9761F` | 中风险/铜色强调 |
| `--red` | `#A63A3A` | 高风险 |
| `--green` | `#3F6B4A` | 低风险/正向 |
| `--slate` | `#6C7C8B` | 中低风险/中性 |
| `--indigo` | `#565C9E` | 辅助分类色 |

风险色阶（页面与 Excel 保持一致）：
- 高：浅红底 `#F3DADA` / 深红字 `#8B1E1E`
- 中：浅橙底 `#F9ECD2` / 棕字 `#7A4E12`
- 低：浅蓝底 `#E7EEF2` / 蓝灰字 `#33556B`
- 正向：浅绿底 `#E2EFE3` / 绿字 `#2F5A3A`

### 1.3 字体

```css
--sans: "PingFang SC","Microsoft YaHei","Noto Sans SC",system-ui,...;
--serif: "Songti SC","Noto Serif SC","STZhongsong","华文中宋","SimSun",Georgia,serif;
--mono: "SFMono-Regular",Consolas,"Liberation Mono",monospace;
```

- h1 用 serif，字号 clamp(38px, 5vw, 62px)，`em` 用青绿渐变下划线。
- 正文 13–15px，行高 1.7–1.85。
- 标签/英文眉题用 9–11px、加字距。

### 1.4 页面结构

```
topbar（品牌 / 产品 / 截止时间 / 打印 / 方法）
hero（标题 + 说明 + 查询 chips + 雷达卡）
kpi 行（供应商 / 窗口事件 / 高风险 / 中风险 / 覆盖类别）
tabs（总览 / 事件时间线 / 供应商 / 方法与来源）
筛选条（3/6/12m、五分类 pills、供应商下拉、搜索、只看中高风险）
视图内容
footer（免责声明）
modal（事件 / 供应商）
```

**总览**：风险分布条 + 分类雷达 + 最近事件 + 供应商快览 + 月度柱。
**时间线**：按日期倒序，事件卡左侧日期/供应商，右侧标题/事实/标签。
**供应商**：卡片网格；点开看产能、财务、结论、覆盖、该供应商事件。
**方法**：证据分级 A/B/C、六类覆盖表、来源表、局限、免责声明。

### 1.5 交互规则

- 筛选状态存 `state`，切换视图不丢失。
- `3m/6m/12m` 只改变窗口；`chipEvents` 始终显示全部事件数，`chipInWindow` 显示当前窗口数。
- 分类 pills 可多选；再点取消。
- 搜索匹配 `title/fact/why/supplier/category/tags/source`，不区分大小写。
- “只看中高风险”过滤 `severity in {"高","中"}`。
- 事件卡/供应商卡可点击；`Esc` 关闭弹窗；点遮罩关闭。
- 打印时隐藏筛选、按钮、弹窗，保留内容与来源。
- 所有数据从 `const DATA = {...}` 读，不在 DOM 里写死计数。
- `localStorage` 读写必须 try/catch（`file://` 可能抛异常）。

### 1.6 自包含要求

- 不引用 CDN、外部字体、外部 JS/CSS、外部图片。
- SVG 图标内联为 `<symbol>`，用 `<use href="#i-...">`。
- 单文件，双击可开；大小 80–120 KB 正常。
- `lang="zh-CN"`、`viewport`、`meta charset` 必须保留。

### 1.7 响应式

- 桌面：1240px 容器，hero 两栏。
- ≤ 980px：hero 单栏，KPI 2 列，供应商卡 1–2 列。
- ≤ 640px：筛选横向滚动，事件卡单列，弹窗全宽。
- 不允许横向溢出；长供应商名/URL 用 `overflow-wrap:anywhere`。

### 1.8 打印 / PDF

- `@media print`：隐藏 `.top-actions`、`.filters`、`.tabs`、`.modal`；卡片去阴影；避免事件卡跨页。
- 打印页保留标题、截止时间、KPI、时间线、方法/免责声明。
- 需要 PDF 时优先用 LibreOffice 转 Excel，再用浏览器打印 HTML；两者版式不同，交付时说明。

## 2. Excel 设计系统

### 2.1 通用

- 字体：微软雅黑；标题 18–30pt，正文 9–11pt。
- 行高：标题 32，表头 32–34，正文 22–30，事件行 150–170（长文本）。
- 列宽按 CJK 字符估算（中文≈2 个字符宽），不要指望自动换行自适应。
- 冻结窗格：总览 `C5`，时间线 `D5`，画像 `C5`。
- 自动筛选：表头下一行到数据末行。
- 打印：横向、`fitToWidth=1`、窄边距、重复表头。
- 超链接只放在“打开原文/原文链接”列，蓝色下划线。

### 2.2 九张表

| 表 | 内容 | 关键设计 |
|---|---|---|
| `00_封面` | 标题、副标题、报告信息、图例、阅读提示、免责声明 | 深蓝标题、纸色底、信息两列 |
| `01_风险总览` | 每家供应商：事件数、高/中/低、风险等级、标签、最近事件、结论 | 风险色阶、合计行、结论列宽 |
| `02_事件时间线` | 19 列：日期/供应商/分类/严重度/事实/why/问题/来源/链接/证据 | 长文本换行、行高 165、链接列 |
| `03_分类汇总` | 分类×严重度、供应商×分类、读法 | 合计行、柱图、动态“读法” |
| `04_供应商画像` | 全称/代码/市场/基地/工艺/产能/营收/净利/同比/风险/结论 | 财务期间用 `meta.financial_period` |
| `05_待核实清单` | P1/P2/P3 问题、对象、为什么问、问谁、截止日 | 截止日按 query_date 推算 |
| `06_来源清单` | 来源、类型、日期、链接、覆盖事件 | 超链接、去重 |
| `07_方法与口径` | 范围、证据分级、六类覆盖、检索式、局限、免责 | 分节标题、说明文字 |
| `08_行业背景` | 行业事实、来源、日期、对采购的含义 | 2–4 条，别写成长文 |

### 2.3 不要做的事

- 不要在 Excel 里写公式做统计：静态值更稳，打开不会 `#REF!`。
- 不要合并大量单元格导致无法筛选；只合并标题/说明行。
- 不要把长事实塞进 10 字宽列；先估行高。
- 不要用纯红/纯绿填充整行；只给等级单元格上色。
- 不要在封面写“全面排查”“零风险”；用“未检索到公开记录”。

## 3. 改版式的最小安全线

改可以，保留：
1. 首屏能回答“几家、几条、几条高/中、窗口”。
2. 任何事件 2 次点击内能看到来源链接。
3. 任何供应商 2 次点击内能看到结论与覆盖缺口。
4. 方法页保留证据分级、六类覆盖、免责声明。
5. 页面与 Excel 的数字来自同一份数据，不手改。
