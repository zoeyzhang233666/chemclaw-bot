# 示例索引

| 目录 | 数据 | 用途 |
|---|---|---|
| [`01-soda-ash-2026-10/`](01-soda-ash-2026-10/) | 真实：纯碱 7 家 / 19 条事件 | **写作范本**。看真实颗粒度、事件四层写法、覆盖检查、成品版式 |
| [`02-minimal-demo/`](02-minimal-demo/) | 虚构：示例化工品 4 家 / 6 条事件 | **测试样本**。学最小数据契约、跑通生成器；不可用于真实判断 |

建议顺序：
1. 打开 `01` 的 HTML，点几条事件和供应商，感受交付形态。
2. 读 `01/data.json` 的前 2 家供应商与前 5 条事件，学字段写法。
3. 用 `02` 跑一遍 `validate → build_all → qa`。
4. 复制 `02/data.json` 改成自己的产品。

两个目录都含生成后的 HTML/Excel；`01` 另有 PDF。
