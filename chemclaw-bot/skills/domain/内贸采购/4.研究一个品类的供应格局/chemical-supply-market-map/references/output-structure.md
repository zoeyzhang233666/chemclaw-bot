# 交付结构（固定，不许自由发挥）

两件交付物：**单文件 HTML** + **16 表 Excel**。结构固定，内容全部来自配置。
用户额外要素材（PPT/Word）时，从这两件里摘，不要再造第三套数字。

---

## 一、HTML（单文件、零外部依赖）

生成方式：`scripts/build_all.py` 把 `assets/template.html` 的 `@@TOKEN@@` 全部替换为 `scripts/_render.py`
算出的片段，CSS 与 JS 内联，数据以 `window.DATA` 注入。

### 硬约束（`check_project.py` 会验证）

- 单个 `.html` 文件，可直接双击离线打开
- **零外部资源**：没有 `<script src="http...">`、`<link href="http...">`、`<img src="http...">`
- 有 `<!DOCTYPE html>` 与 `<meta charset="utf-8">`（否则中文乱码）
- 正文来源超链接允许（那是内容，不是资源依赖）
- 可打印：`@media print` 里展开全部标签页

### 页面结构

```
页头 masthead（品牌位 = CAS 号 · 标题 · 副标题 · 6 个 KPI 卡 · 数据截止/单位/覆盖范围）
标签导航（6 个）
├─ 01 全景     工艺环形图 / 区域条形 / 成本带 / 头部集团对比 / 核心结论卡
├─ 02 企业表   搜索 + 排序 + 集团表；点击行 → 抽屉（基地明细/优势/风险/采购判断/尽调问题）
├─ 03 项目     按年分组的时间线卡；点击 → 抽屉（毛产能/置换/净影响/进度/影响）
├─ 04 价格     年度折线 SVG + 当前价位卡 + 区域价差 + 阶段复盘表 + 四个情景块
├─ 05 采购关注 风险卡（按等级排序）+ 策略卡 + 供应商组合条 + 采购量测算表
└─ 06 数据    口径说明 / 口径提示 / 数据缺口表 / 来源列表（可点击）/ 使用限制
页脚（产品 · 地域 · 数据截止 · 集团数/基地数/来源数 · 生成日期 · 技能版本）
```

### KPI 卡（页头，最多 6 个，按以下顺序取有值的）

1. 全国产能（+ 其他口径提示 + 预测年名义产能）
2. 产量（+ 开工率 + 其他口径 + 出口）
3. CR5（+ 前 5 家名称与合计 + 预测年区间）
4. 主导工艺占比
5. 当前价格（+ 报价来源与区域 + 较峰值跌幅）
6. 样本覆盖率（+ 集团/基地/合计产能）

### 空数据处理

- `verdicts` 为空 → 显示一句默认导语，不留空卡片
- `projects` 为空 → 时间线显示「projects.json 为空」
- `companies` 为空 → 企业表显示空状态
- `sources` 无 URL → 表格里显示红色「无链接」，不隐藏

### 样式规范

- 字体统一 微软雅黑；表头深蓝 `0B1F33`；小标题青色 `0F766E`
- 所有数据表：冻结窗格、自动筛选、表头行重复、横向 A4 单页宽
- 数字格式：产能 `#,##0`，份额 `0.0%`，变化 `+#,##0;-#,##0;0`
- 缺失值写「数据缺口」文字，不写 0、不写空
- 公式必须是**活公式**（合计、加权、模拟器），不是算好的死值

### 交付前必须重算一次

```bash
node <libreoffice-kit>/lib/cli.js recalculate --input <xlsx> --output <new.xlsx>
```
用 `openpyxl(data_only=True)` 抽查 3 处合计与模拟器结果，确认公式没算错，再把重算后的文件当最终交付物。

## 四、什么时候可以偏离结构

只有两种：

1. 用户明确要求减少交付物（例如只要 HTML）→ 用 `--html-only`，交付说明里写明「Excel 未生成，原因：…」。
2. 某类数据完全没有（例如没有任何项目信息）→ 该表保留但标注「本项目未取得公开项目信息」，
   **不要删表**，否则读者以为漏了。
