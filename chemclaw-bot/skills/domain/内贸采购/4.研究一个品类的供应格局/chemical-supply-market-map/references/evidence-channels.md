# 证据通道：去哪里找、怎么判断可信

按「能拿到多少确定性」排序。先用 A 级立住，再用 B/C 补充，D 级只做线索。

---

## A 级：一手披露（最强）

| 通道 | 能拿到什么 | 怎么用 |
|---|---|---|
| 上市公司年报/半年报 | 集团产能、产量、开工率、分产品成本、在建项目、行业口径 | 巨潮资讯 / 交易所网站检索公司名 |
| 招股说明书、募集说明书 | 产能明细、单耗、原料结构、募投项目 | 同上 |
| 产能置换公告 | **净新增的唯一权威依据**（新建多少、退出多少） | 省级工信厅网站「产能置换」栏目 |
| 环评报告/公示 | 项目规模、工艺、原料用量、投产时间 | 生态环境部门公示、企业官网 |
| 能耗核查/能效标杆公示 | 单位产品能耗、产能、工艺 | 发改委/工信厅 |
| 投资者关系记录（调研纪要） | 项目进度、达产时间、成本区间 | 交易所互动易、巨潮 |

**判断可信**：有公司盖章/公告编号/发布日期 > 只有媒体转述。

---

## B 级：行业权威（强）

| 通道 | 能拿到什么 | 注意 |
|---|---|---|
| 行业协会年报/月度报告 | 全国产能、产量、工艺结构、消费结构 | 数字最稳，但更新慢 |
| 统计年鉴、石化联合会 | 产量、进出口 | 口径偏宏观 |
| 价格机构（生意社/卓创/隆众/百川/钢联） | 历史价格、区域价差、库存、开工 | 必须记：日期+规格+地区+税则 |
| 海关总署 / UN Comtrade | 进出口量价、贸易流向 | HS 编码要准确 |
| 期货交易所（交割厂库、免检品牌） | 可用于交割的品牌与厂库 | 反映质量与规模认可度 |

---

## C 级：研究材料（中）

- 期货公司品种研报（供需平衡表、成本曲线、项目跟踪）→ 找**带数据源**的，不要只抄结论
- 券商行业深度 → 适合理解结构与历史，数字要回查原始来源
- 咨询机构报告摘要 → 摘要里的量级可用，具体数字要标「据某机构」

---

## D 级：线索（弱，不作唯一依据）

行业媒体、公众号、百科、企业官网新闻、地方新闻。
用法：**发现线索 → 用 A/B 核实**。D 级单独出现时，在 `source.confidence` 写「低」。

---

## 检索式模板（换产品即可用）

```
<产品> 产能 万吨 2025 年             # 找总量口径
<产品> 产能 置换 公示 site:gov.cn    # 找净新增
<产品> 环评 报告 <企业名>            # 找项目规模与工艺
<企业名> 年报 产能 产量              # 找集团口径
<产品> 价格 华东 元/吨 <年月>        # 找价格与区域价差
<产品> 进出口 海关 HS                # 找贸易流
<产品> 工艺 路线 单耗 原料           # 找工艺结构
<产品> 集中度 CR5 格局               # 找第三方测算（交叉验证用）
```

---

## 交叉核对清单（每个关键数字过一遍）

1. **至少两个独立来源**？不同来源若同源转述（都引自同一份年报），只算一个。
2. **时点一致**？年底产能 vs 年均产能不能混。
3. **口径一致**？名义/有效、折百/实物、集团/基地。
4. **能不能被反证**？用「产量 ÷ 产能 = 开工率」验一遍，明显不合理就说明有一个数错了。
5. **和下游对得上吗**？表观消费 = 产量 + 进口 − 出口 − 库存变化，差太多要解释。

---

## 记录纪律

每条来源都要落 `sources[]`：

```json
{"id":"S1","name":"中盐化工 2025 年年度报告","publisher":"中盐内蒙古化工股份有限公司",
 "date":"2026-04-29","url":"https://…","used":"2025 总产能 4,468 万吨、工艺结构",
 "confidence":"高"}
```

- `used` 写清「这条来源支撑了哪些具体数字」，方便回查。
- URL 拿不到就留空 —— 报告里会显示「无链接」，**不要编造链接**。
- `confidence`：高（年报/公告原文）/ 中高（行业协会、多源交叉）/ 中（研报、单家机构）/ 低（媒体、百科）。
