# 指标口径与公式

所有指标都能用 `scripts/_common.py` 直接算（`hhi` / `cr_n` / `region_rollup` / `company_rollup` /
`project_rollup` / `coverage`），报告里显示的数值即这几支函数的输出。**不要在文中手搓另一套算法。**

---

## 1. 产能相关

| 指标 | 公式 | 口径提示 |
|---|---|---|
| 集团产能 | Σ 该集团所有基地 `capacity_base` | 合并口径；含已公告未投产的要在 note 里说明 |
| 样本合计 | Σ 全部 plants `capacity_base` | 只代表收录的企业，不代表全国 |
| 样本覆盖率 | 样本合计 ÷ 全国产能 × 100% | 低于 70% 时集中度会被低估 |
| 开工率 | 产量 ÷ 产能（同口径、同年份） | 跨口径相除必须注明 |
| 名义 vs 有效产能 | 名义 = 设计能力；有效 = 扣掉长期停车/环保限产 | 两者都要写，不要混用 |

---

## 2. 集中度

### CR_n（行业集中度）

```
CR_n = 前 n 大集团产能之和 ÷ 样本合计产能 × 100%
```

读法（化工品通用经验，非硬标准）

| CR5 | 含义 | 采购含义 |
|---|---|---|
| <30% | 分散 | 议价空间大，但供应商质量参差 |
| 30%–50% | 中度集中 | 要同时管成本与交付 |
| 50%–70% | 较高集中 | 头部策略变化会直接影响你 |
| >70% | 高度集中 | 单源风险实质化，必须做双源 |

### HHI（赫芬达尔指数）

```
HHI = Σ (每个集团份额²)    份额以 % 计，取值 0–10000
```
- <1000 竞争性；1000–1800 中度集中；>1800 高度集中。
- **区域 HHI** 用省级产能份额算，>1500 说明区域内可替代供应商很少。
- **工艺/子市场 HHI** 很有价值：整体 HHI 不高，但某个路线（如天然碱）HHI 可能 >5000。
  这是「低成本量集中」的量化证据，往往比 CR5 更能解释采购风险。

### 覆盖率修正

当样本覆盖率 <90% 时，CR5/HHI 都是**样本口径**。报告里必须写成「样本 CR5」，不能写成「行业 CR5」。
若已知未收录企业的粗量级，可给出区间（如 48.6%–51.8%），但要说明区间来自哪些假设。

## 3. 项目与净增

| 指标 | 公式 | 说明 |
|---|---|---|
| 毛新增 | Σ 项目 `capacity` | 项目规模，不是可增量 |
| 净新增 | Σ (新增 − 置换/退出) | 只有这一项能进供应规划 |
| 待确认净增 | Σ 项目 `capacity` where `net = null` | 单列，不进基准预测 |
| 实际可增量（第一年） | 净新增 × 爬坡系数 | 爬坡系数 50%–80%，须写明假设 |
| 空窗年 | 某年前瞻年份净新增 < 上年的 20% | 供给断档年，往往是紧平衡年 |

**三种口径必须分开写**：名义新增（公告）/ 净新增（扣置换）/ 可增量（再打折）。

## 4. 价格

| 指标 | 公式/做法 |
|---|---|
| 年均价 | 有月度数据就按量加权；没有就用机构年均值并标明来源 |
| 峰值 | **单独标注日期**，不能当年度均价 |
| 回撤幅度 | (峰值 − 当前) ÷ 峰值 × 100% |
| 成本位置 | 当前价 vs 各路线成本区间：高于上限 = 全行业盈利；区间内 = 部分盈利；低于下限 = 普遍亏损 |
| 区域价差 | 区域价 − 主产区价；差额应能由运费解释，解释不了就是结构性紧张 |
| 折百换算 | 折百量 = 实物量 × 浓度；**合同必须写折百** |

价格判断不写「涨/跌」这类无信息结论，写「区间 + 触发条件 + 采购动作」。

## 5. 采购量测算（Excel 07A / HTML 采购关注）

```
年度采购金额 = 年用量(万吨) × 10000 × (到厂价 + 运费) ÷ 10000     单位：万元
月度提货量   = 年用量 × 10000 ÷ 12                              单位：吨
安全库存量   = 年用量 × 10000 × 库存天数 ÷ 365                   单位：吨
价格弹性     = 年用量(万吨) × 100                              单位：万元/年（每涨 100 元）
```

未含：增值税、资金占用、仓储、损耗、账期成本。交付时必须写这句。

---

## 6. 供应商评分（Excel 09）

```
加权总分 = Σ(维度得分 × 权重) ÷ Σ权重        得分 1–5，权重合计 100
```
- 建议至少评 3 家，且必须包含 1 家未入围的候选（避免只评熟人）。
- 评分前先完成 `08_尽调清单`；评分不能替代试单。

---

## 7. 常见算错点

1. **把峰值当均价**：2021 年 3,681 元/吨是 10 月峰值，不是年均。年均 2022 年才是 2,859。
2. **把毛产能当净增**：搬迁项目新厂投产 ≠ 老厂关停，中间有一段双开或断供期。
3. **把集团产能按基地重复加**：一条 plants 只能属于一个集团，不要既汇总又明细各算一次。
4. **CR5 分母用错**：分母必须是同口径产能（样本合计或全国），不能一个用样本一个用全国。
5. **HHI 用产能份额但份额没归一到 100%**：样本没覆盖全国时，用样本内部份额算，并说明。
6. **折百没折**：液碱 32% 的「1 吨」和片碱 99% 的「1 吨」完全不是一回事。
