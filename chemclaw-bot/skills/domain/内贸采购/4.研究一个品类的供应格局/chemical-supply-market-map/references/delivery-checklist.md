# 交付前检查清单

逐条打勾。任一条「否」就不要交付，或明确在交付说明里写清原因。

## A. 数据（20 条）

- [ ] `product.name` / `short` / `unit` / `price_unit` 都已填
- [ ] `scope.geography` 是具体地域，不是「全球」
- [ ] `scope.basis_notes` ≥1 条，写清口径差异
- [ ] `metrics.capacity_total` 有值且有 `capacity_total_source`
- [ ] 全国产能有多套口径时，**并列展示且未取平均**
- [ ] `metrics.sample_capacity` 与 `plants.json` 加总一致（`--check` 无此警告）
- [ ] `plants` ≥10 条（小众品种 ≥5 条），覆盖 ≥5 个省份
- [ ] 每条 plant 都有 `source`，且 `source` 在 `sources[]` 里存在
- [ ] `plants` 无重复 `id`
- [ ] `status` 全部在枚举内
- [ ] `route` 全部在 `routes` 里注册（或已说明是缩写）
- [ ] `routes` 产能之和 ≈ 全国产能（差异 ≤5%，超出要解释，防重复计数）
- [ ] 前 5 大集团都有 `procurement` 判断
- [ ] 每个项目有 `date` 和 `type`
- [ ] 所有 `置换/搬迁/技改` 项目都有 `capacity_retired` 或明确的 `net`
- [ ] `prices.annual` ≥4 年，峰值与均价分开
- [ ] `prices.current` 每条带日期
- [ ] `risks` ≥5 条，每条有 `evidence` 与 `action`
- [ ] `gaps` ≥3 条，每条有 `impact` / `fill` / `priority`
- [ ] `scorecard` 权重合计 = 100

## B. 口径（7 条）

- [ ] CR5 / HHI 明确标注「样本口径」还是「全国口径」
- [ ] 样本覆盖率已写出，<70% 时报告显著提示
- [ ] 「名义产能 / 有效产能 / 产量」三者在文中有区分
- [ ] 「毛新增 / 净新增 / 可增量」三者在文中有区分
- [ ] 价格写清：日期、规格、地区、含税与否、折百与否
- [ ] 集团口径与基地口径没有混加
- [ ] 未使用任何估算/外推补值

## C. 缺口（5 条）

- [ ] 所有缺失值在表里显示「数据缺口」，不是 0、不是空
- [ ] 每个缺口在 `gaps` 里有条目
- [ ] 缺口条目按优先级排序
- [ ] HTML「数据与来源」与 Excel `10_数据缺口` 都出现了
- [ ] `check_project.py` 的 `missing_marks` > 0

## D. HTML（8 条）

- [ ] 单文件，双击能离线打开
- [ ] 无外部资源引用（`check_project.py` 无此错误）
- [ ] 6 个标签页都能切换
- [ ] 企业表：搜索、排序、点击行为都正常
- [ ] 企业抽屉：标题、基地明细、尽调问题都有
- [ ] 项目抽屉：毛产能/置换/净影响/来源都有
- [ ] 来源列表可点击（或明确标「无链接」）
- [ ] 打印时所有标签页都展开

## E. Excel（9 条）

- [ ] 16 张表齐全、顺序正确
- [ ] 图表 ≥4 个（区域/工艺/成本/项目）
- [ ] 合计行是活公式（`SUM`），不是死值
- [ ] 采购量模拟器输入格可改，结果跟着变
- [ ] 尽调清单与评分表有 1–5 数据校验
- [ ] 冻结窗格与筛选已设置
- [ ] 缺失值写「数据缺口」文字
- [ ] LibreOffice 重算后无 `#VALUE!` / `#REF!`
- [ ] 重算后的文件才是最终交付物

## F. 汇报（4 块，缺一不可）

- [ ] 数字：产能/产量/CR5/覆盖率，各自什么口径
- [ ] 结构：区域集中、工艺结构、头部集团
- [ ] 前瞻：未来 1–2 年净增多少、哪年紧张、哪些待确认
- [ ] 缺口与下一步：没拿到什么、影响什么、先补哪个

## G. 文件（4 条）

- [ ] `<简称>供应格局全景_<年>.html` 存在
- [ ] `<简称>供应格局数据包_<年>.xlsx` 存在（或已说明未生成原因）
- [ ] `data_bundle.json` 与交付物在同一目录
- [ ] 交付说明里写清了数据截止日期

---

## 一键跑完的部分

```bash
python scripts/build_all.py --dir <项目> --check     # A/B/C 大部分
python scripts/check_project.py --dir <项目>          # A部分 + D + E部分
python scripts/ui_check.py --html <报告.html>         # D 的交互部分
```

剩下 B 的措辞、F 的汇报、G 的说明，需要人（或你）逐条读一遍。
