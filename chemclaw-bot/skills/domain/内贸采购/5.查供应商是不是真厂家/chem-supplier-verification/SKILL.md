# 查供应商是不是真厂家（化工品 · 内贸采购）

把"对方说自己有厂"变成**可复核的证据链**：哪些材料能独立指向装置、哪些只能说明在做生意、哪些看着像证据其实一分不值。最后只给四种结论，证据不够就明确说不够。

适用于任何化工品。方法与产品无关，**只有"本产品什么算硬证据"需要按品类替换**——见下方[产品适配表](#产品适配表)和 [`references/regulatory-matrix.md`](references/regulatory-matrix.md)。

整件事只有一个原则：**证据不混层**。许可、装置、产量、业务旁证、伪证据，五样东西永远不能混在同一句话里。

---

## 三条不可谈判的约束

1. **"经营范围"和"厂家直销"永远不进直接证据。**
   营业执照只能证明"允许做"，宣传语只能证明"想让你信"。把它们放进直接证据，结论一定是错的——这是内贸采购最常见的翻车点。

2. **证据不够就写"证据不足暂无法确认"，不许推断。**
   四类结论之外的任何措辞（"大概率是厂家""应该是贸易商"）都不允许出现在结论栏。可以写"倾向"的只有 `next_action`，且必须说明还差哪份材料。

3. **每条证据必须能点回来源。**
   至少要有：来源机构、日期、原文摘录（带数字和单位）、一句"为什么它算/不算证据"。拿不到链接的，标"对方提供"并降级；编造链接比没有链接更糟。

---

## 第 0 步：收料与定契约（一次问全）

| 要素 | 为什么要问 | 默认 |
|---|---|---|
| **企业全名 + 统一社会信用代码** | 同名公司极多；信用代码是唯一锚点 | 从用户给的资料里读 |
| **产品 + 规格/牌号** | 决定查哪类许可、哪条产线 | 必填，不许写"化工品" |
| **判断时点 as_of** | 许可、名单、产能都会变 | **今天** |
| **品类**（危化品/食品添加剂/农药/肥料/药品/工业气体/普通工业品） | 决定硬证据清单 | 按产品判断，拿不准就问 |
| **交付物** | 默认两件套 | Excel + HTML（+ 可选 Markdown 摘要） |

用户只甩一句"帮我查查这家是不是厂家"时，**不要**先问五个问题再动手：先用企业名+产品跑一轮公开检索，把查不到的部分变成"待索取材料"，最后一次性问。

---

## 第 1 步：先定"本产品的硬证据清单"

在检索之前，先写下三列（写进 `input.json` 的 `product_profile`）：

```text
regimes       本产品能一锤定音的许可/备案（例：排污许可行业类别=颜料制造、危化品安全生产许可证、食品 SC 明细）
not_evidence  本产品最容易被误采信的材料（例：危化证对非危化品、经营范围、厂家直销）
key_specs     验货时要对的指标（含量、杂质、粒度、白度、粘度、执行标准）
```

**这一步不做，后面全错。** 例：纯碱不是危化品，拿"危化证"判断纯碱厂家必然误判；钛白粉同理，危化证只覆盖硫酸/氯气。反过来，双氧水、液氨、氯气这类产品，**安全生产许可证就是最硬的证据之一**。

品类与硬证据的对照见 [`references/regulatory-matrix.md`](references/regulatory-matrix.md)。

---

## 第 2 步：五路检索（每路都有固定动作）

| 路 | 找什么 | 典型来源 | 采信等级 |
|---|---|---|---|
| A 许可与环保 | 排污许可（行业类别）、环评批复/验收、项目备案、产能置换、专项许可 | 全国排污许可证管理信息平台、省市生态环境局、发改委 | ●●● |
| B 产能与装置 | 公开产能、产量、装置条线、厂址、原料配套、停产公告 | 上市公司年报/公告、官网工厂页、行业报道 | ●●● / ●●○ |
| C 产品与市场 | 牌号与规格、销售渠道、协会/交易所名录、客户与中标 | 官网产品页、交易所公告、协会名录、招标网 | ●●○ |
| D 运营侧痕迹 | 原料采购、生产岗位招聘、专利、物流、公开招标 | 招标平台、招聘网站、专利库、铁路/港口 | ●●○ / ●○○ |
| E 现场与第三方 | 视频验厂、磅单、COA、第三方检测、发票 | 对方提供 + 现场 | ●●●（做完才算） |

检索式、官方入口、失效链接的替代方案见 [`references/search-playbook.md`](references/search-playbook.md)。

> 一条经验：**先找"负面证据"再找"正面证据"**。先搜"企业名 + 停产/处罚/事故/被执行"，如果有非计划停产公告，反而是它在产的铁证；如果有环保处罚，说明装置真实存在但合规有瑕疵。

---

## 第 3 步：三分法归档 + 强度打分

每一条材料，先问一句：**它能不能独立指向"这套装置存在且在运行"？**

| 组 | 判据 | 例子 | 计分 |
|---|---|---|---|
| **A 直接生产证据** | 能独立指向装置/许可/产量 | 排污许可（行业类别对得上）、环评验收里的产品+产能、产能置换公示、上市公司产量、非计划停产公告 | ●●● 强 / ●●○ 中 |
| **B 间接业务证据** | 能说明"在做这门生意"，不能单独证明自产 | 官网产品页、代理授权、交易所厂库、协会名录、原料采购、生产招聘、专利 | ●●○ / ●○○ |
| **C 不构成证据** | 只能证明"允许做/想做/能垫资" | 经营范围、"厂家直销"、注册资本、可大量供货、无定位照片 | 0（不计分） |

**归档时最容易犯的三个错**（完整清单见 [`references/evidence.md`](references/evidence.md)）：

- 把"官网说自己是厂家"放进 A 组 → 官网是自述，最高只能算 B 组 ●●○；
- 把"交易所交割厂库"当成生产资质 → 厂库允许**贸易商**申请，必须看公告里写的是"生产型"还是"贸易型"；
- 把"某张许可证"当成万能证据 → 先确认这张证**覆盖不覆盖目标产品**（危化证不覆盖非危化品；液氨许可不覆盖纯碱装置）。

---

## 第 4 步：Q1→Q4 判定，不许跳步

```text
Q1 是否存在以该企业为主体的目标产品生产硬证据？
   ├─ 是 → Q2
   └─ 否 → Q3

Q2 产能、产量、厂址、许可能否互相解释？
   ├─ 能 → 生产厂家
   └─ 不能 → 生产厂家（待现场核验），并列出矛盾点

Q3 是否存在分装/复配特征？（只有分装类许可、无合成主装置、外购成品、粉碎/混合/包装设备）
   ├─ 是 → 分装或复配
   └─ 否 → Q4

Q4 是否存在贸易经销特征？（贸易商厂库、代理授权、无装置无许可、写字楼注册、以调货为主）
   ├─ 是 → 贸易经销
   └─ 否 → 证据不足，暂无法确认
```

边界案例、置信度、以及"Q1 命中了但 Q2 矛盾"怎么处理，见 [`references/verdicts.md`](references/verdicts.md)。

**判定顺序不能反**：先排除"分装"，再排除"贸易"，最后才落到"证据不足"。因为分装商也有车间、也有资质，只有看许可明细与设备清单才能与真厂家区分。

---

## 第 5 步：100 分"证据充分度"（辅助，不是结论）

| 维度 | 权重 | 看什么 |
|---|---|---|
| 生产许可与环保手续 | 30 | 排污许可行业类别、环评/验收的产品与产能、项目备案/产能置换、专项许可 |
| 产能与装置实据 | 30 | 公开产能与产量、装置条线、厂址、原料配套、停产公告 |
| 产品与市场证据 | 20 | 牌号规格、销售渠道、协会/交易所名录、客户与中标 |
| 运营侧痕迹 | 10 | 原料采购、生产招聘、专利、物流、招标 |
| 现场与第三方核验 | 10 | 视频验厂、磅单、COA、第三方检测、发票与发货地 |

分数只用来**横向比较和定位缺口**，不用于推翻 Q1—Q4 的结论。没做现场核验，第五维就是 0 分——这不是扣分，是提醒。

---

## 第 6 步：写结论（四个字段决定可读性）

| 字段 | 写什么 | 反例 |
|---|---|---|
| `headline` | 一句话说清证据结构，不复述结论 | "该公司是生产厂家"（等于没说） |
| `verdict_detail` | 3—5 句：哪几条证据、怎么互证、还差什么 | 罗列十条证据但不解释关系 |
| `gaps` | 3—6 条**可执行的**索取清单，按"能否独立证明装置"排序 | "请提供相关资料" |
| `next_action` | 基于结论的合作方式 + 一条风控动作 | "建议进一步核实" |

---

## 第 7 步：生成附件

```bash
# 一条命令出两件套（Excel + HTML）
python scripts/build_report.py input.json -o out/

# 只校验数据
python scripts/validate.py input.json

# 交付前自检（数据 + Excel + HTML）
python scripts/selfcheck.py input.json --outdir out/
```

产出：

- `out/<slug>.html` — 单文件交互报告：案例切换、证据筛选、评分环、时间线、清单勾选、话术复制、打印。
- `out/<slug>.xlsx` — 10 个工作表：说明 / 总表 / 直接证据 / 间接证据 / 排除项 / 评分模型 / 待索取材料 / 现场验厂 / 案例对照 / 数据来源。

数据契约见 [`references/schema.md`](references/schema.md)。**只改 JSON，不改产物**；两个附件必须同源生成。

若环境跑不了 Python：见 [`references/portability.md`](references/portability.md) 的降级路径——先严格按 schema 落 `input.json`，再让有 Python 的机器跑一条命令。

## 产品适配表

| 品类 | 最硬的证据（A 组） | 最容易被误当证据 | 特有坑 |
|---|---|---|---|
| **普通工业品**（纯碱、钛白粉、无机盐） | 排污许可行业类别 + 环评产能 + 产能置换 + 上市公司产量 | 经营范围、危化证、厂家直销 | 危化证不覆盖非危化品 |
| **危险化学品**（双氧水、液氨、氯气、甲醇） | 安全生产许可证（许可范围含该产品）+ 危化品登记 + 排污许可 | 经营许可证（贸易商也办）、运输资质 | 生产许可与经营许可必须分开看 |
| **食品添加剂**（食用纯碱、柠檬酸、香精） | 食品生产许可证 SC 明细（品种+是否"分装"）+ 排污许可 | 仅 SC 证号、ISO/HACCP 证书 | 分装单元 ≠ 合成产能 |
| **农药** | 农药登记证 + 农药生产许可证（范围含该剂型） | 经营许可证、委托加工协议 | 委托加工要追到实际生产厂 |
| **肥料** | 肥料登记证/备案 + 生产许可（复混肥等）+ 排污许可 | 经营备案、检测报告 | 部分品种免登记，别把"没证"当"没厂" |
| **药品/原料药** | 药品生产许可证 + GMP 符合性检查 + 登记平台 | 经营许可证、GSP | 原料药要查登记号与关联审评 |
| **工业气体** | 安全生产许可证 + 气瓶充装许可证 + 排污许可 | 经营许可证、运输车队 | 充装站 ≠ 空分装置 |
| **聚合物/树脂** | 排污许可（合成树脂）+ 环评产能 + 装置（聚合釜） | 改性/造粒车间、经营范围 | 改性造粒 ≠ 聚合生产 |

更细的许可名称、发证机关、查询入口见 [`references/regulatory-matrix.md`](references/regulatory-matrix.md)。

---

## 交付前必过（不通过不许交付）

1. 每条直接证据都有来源链接或明确标注"对方提供"；
2. 四类结论只出现四种写法，没有"大概率/应该是"；
3. `dims` 合计 = `score`；权重合计 = 100；
4. 没有一条"排除项"被打分；
5. 合成/脱敏案例已标注 `synthetic: true`，页面与表格都有提示；
6. `selfcheck.py` 输出 `[pass]`。

完整清单见 [`references/qa.md`](references/qa.md)。
