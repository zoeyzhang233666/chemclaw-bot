# 检索手册

目标不是"搜到很多"，而是**每条能点回原文**。一条证据的标准流程：找到 → 打开原文 → 摘录带数字的句子 → 记下来源/日期/链接。

---

## 总原则

1. **先搜负面，再搜正面。** "企业名 + 停产 / 处罚 / 事故 / 被执行 / 欠薪"往往比官网更有信息量：停产公告是"在产"的铁证，处罚决定书会写明装置与产能。
2. **每条证据尽量两个独立来源。** 官网说的，去公告里找；公告说的，去许可里找。只有一个来源的，降一级。
3. **摘要不算证据。** 搜索结果摘要、AI 概览、百科词条都可能编数字。必须打开原文，复制原句。
4. **链接会死。** 存"机构 + 标题 + 日期 + 关键句"，链接失效时按这四项二次检索。
5. **记录检索时间。** 许可、名单、产能随时变，`as_of` 是判断时点。

## 六类检索式

把 `{企业}` 换成全名（必要时加曾用名/股票代码），`{产品}` 换成产品名（加别名，如"纯碱 碳酸钠"）。

### A 许可与环保

```text
{企业} 排污许可证
{企业} 排污许可 行业类别
{企业} 环评 批复 {产品}
{企业} 竣工环保验收 {产品}
{企业} 产能置换 公示
{企业} 项目备案 {产品}
{企业} 安全生产许可证            ← 仅危化品
{企业} 食品生产许可证 SC          ← 仅食品添加剂
{企业} 农药登记证 / 肥料登记证     ← 仅对应品类
```

### B 产能与装置

```text
{企业} {产品} 产能 万吨
{企业} {产品} 产量 万吨 年报
{企业} 生产基地 / 分厂 / 二期
{企业} 装置 投产 / 达产 / 扩产
{企业} 停产 检修 降负荷
{企业} 项目 总投资 亿元
```

### C 产品与市场

```text
{企业} {产品} 牌号 / 规格
{企业} {产品} 官网
{企业} 经销商 授权 {产品}
{企业} 中标 {产品}
{企业} {产品} 出口 海关
{交易所} {产品} 指定交割厂库 / 注册品牌
```

### D 运营侧痕迹

```text
{企业} 招聘 生产操作 / 工艺工程师 / DCS
{企业} 采购 {原料} 招标
{企业} 专利 {产品} 制备方法
{企业} 铁路专用线 / 危化品运输
{企业} 用电 / 蒸汽 / 天然气 招标
```

### E 负面与风险

```text
{企业} 行政处罚 环保
{企业} 安全事故
{企业} 被执行人 失信
{企业} 欠薪 / 关停 / 破产
{企业} 产品质量 抽检 不合格
```

### F 现场（由对方提供）

```text
索取：排污许可副本、环评验收、磅单、COA、包装喷码、发票样本
验证：视频通话不预约走厂；地磅随机调单；包装喷码与许可地址比对
```

## 官方入口

> 入口会调整，按"机构名 + 业务名"检索即可；以下是常用起点。

| 用途 | 入口 |
|---|---|
| 排污许可证查询 | 全国排污许可证管理信息平台 `permit.mee.gov.cn` |
| 企业主体/股东/处罚 | 国家企业信用信息公示系统 `gsxt.gov.cn` |
| 失信/被执行/司法 | 信用中国 `creditchina.gov.cn`、中国裁判文书网 |
| 上市公司公告/年报 | 巨潮资讯 `cninfo.com.cn`；沪深交易所官网 |
| 环评审批公示 | 省/市生态环境厅（局）官网 → 建设项目环评 |
| 产能置换公示 | 省工信厅 / 发改委官网 |
| 危化品登记 | 应急管理部化学品登记中心 |
| 安全生产许可 | 省应急管理厅（局）→ 行政许可公示 |
| 食品生产许可 | 省市场监管局 → 食品生产获证企业查询 |
| 农药登记 | 中国农药信息网 |
| 肥料登记 | 农业农村部 / 省农业农村厅 |
| 药品与 GMP | 国家药监局 `nmpa.gov.cn` → 数据查询 |
| 标准全文 | 国家标准全文公开系统 `openstd.samr.gov.cn` |
| 期货交割厂库/品牌 | 郑商所 `czce.com.cn`、大商所 `dce.com.cn`、上期所 `shfe.com.cn` |
| 专利 | 国家知识产权局专利检索系统 |

## 三步验证一条证据

```text
1. 打开原文（不是摘要、不是转载）
2. 复制原句（带数字、单位、主体、日期）
3. 记录：code / source / date / url / quote / why
```

**对不上就降级**：主体不对（子公司/母公司）→ 降一级；产品不对（别的牌号）→ 不入 A 组；地点不对 → 降级；时间过期 → 标注"已过期"。

## 搜索引擎不给力时

| 现象 | 替代做法 |
|---|---|
| 中文公司名被拆成常用词（如"龙佰"搜出"龙"） | 加引号 `"龙佰集团"`；加股票代码；加 `site:cninfo.com.cn` |
| 结果全是日文/百科垃圾 | 换关键词：用"公司全名 + 排污许可证"而不是"公司名 + 产品" |
| 官网打不开 | 用 `site:` 限定 + 百度快照/必应缓存；或去巨潮找公告 |
| 链接 404 | 按"机构 + 标题 + 日期"重搜；政府网站改版后常换路径 |
| 需要 PDF 原文 | 加 `filetype:pdf`；上市公司公告在巨潮直接下 PDF |
| 搜不到产能 | 从"用电/蒸汽/原料采购招标"反推量级；或从行业报告找排名 |

**降级路径**：拿不到原文时，宁可在 `gaps` 里写"索取排污许可证"，也不要把二手转述写成 ●●●。

## 反模式（看到就绕开）

| 反模式 | 为什么 |
|---|---|
| 把 AI 摘要/搜索概览当证据 | 会编数字，且无法复核 |
| 百度百科/企查查简介当产能来源 | 无披露义务，常年不更新 |
| 付费排名/"十大品牌"榜单 | 商业推广，不是事实 |
| 同一篇通稿被十家媒体转载 | 只有一个信源，不构成交叉验证 |
| 官网"全球最大/行业第一" | 宣传语，除非出现在年报或交易所文件 |
| 用"没搜到"下结论 | 检索不到 ≠ 不存在，应写"公开渠道未取得" |

## 检索记录模板

```text
D1 排污许可证载明"无机碱制造"
source: 潍坊市生态环境局 · 排污许可信息公开
date:   2026-03
url:    https://...
quote:  "行业类别：无机碱制造；生产经营场所地址：山东省潍坊市……"
why:    法定许可，行业类别与厂址同时对上，直接指向装置
```

一条记录 30 秒，能省掉后面半小时的"这条哪来的"。
