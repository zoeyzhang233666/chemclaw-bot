# 待索取材料清单

原则：**一次发全、说明用途、给替代方案、P0 不到不签约。**

清单按"能否独立证明装置存在"排序，越靠前越硬。P0 = 拿不到就不进入打款与长协；P1 = 视场景；P2 = 合规参考。

---

## 通用 12 项

| # | 材料 | 优先级 | 核验目的 | 关键看点 |
|---|---|---|---|---|
| M1 | 排污许可证正本 + 副本（含主要生产设施页） | P0 | 行业类别与装置是否在证 | 行业类别、主要生产设施、排放口、有效期、厂址 |
| M2 | 项目环评批复 + 竣工环保验收 | P0 | 产品方案与产能 | 产品名、产能（万吨/年）、工艺路线、验收结论 |
| M3 | 项目备案 / 产能置换 / 节能审查 | P1 | 合规产能与项目主体 | 备案主体是否为目标企业、置换比例 |
| M4 | 近 3 个月出厂磅单 3—5 车 | P0 | 真实发货与发货地 | 车牌、日期、净重、发货单位与地址 |
| M5 | 批次质检报告（COA） | P0 | 规格与批次可追溯 | 执行标准、批号、主含量、关键杂质 |
| M6 | 包装袋 / 合格证 / 喷码照片 | P0 | 生产商名称与地址 | 喷码"生产商"是否为目标企业 |
| M7 | 增值税发票样本 | P0 | 销售主体 = 生产主体 | 销售方名称、税号、品名、税率 |
| M8 | 生产厂授权书 / 经销链（贸易商适用） | P0 | 货源合法性 | 授权方是否为真实生产厂、授权期 |
| M9 | 工艺流程图 / 装置清单 | P1 | 装置是否完整 | 主反应、分离、精制、包装是否齐全 |
| M10 | 近 3 年产量或用电/蒸汽数据 | P1 | 产量与产能是否自洽 | 量级是否匹配、是否有异常波动 |
| M11 | 第三方检测报告 | P2 | 质量一致性 | 检测机构资质、抽样方式 |
| M12 | 不预约视频验厂同意书 | P0 | 敢不敢被看 | 是否允许随机走厂、拍装置铭牌 |

## 按品类追加

| 品类 | 追加材料 | 说明 |
|---|---|---|
| **危险化学品** | 安全生产许可证（范围页）、危化品登记证、特种作业人员证 | 范围必须逐字含目标产品 |
| **食品添加剂** | SC 证及品种明细页、食品级检测（GB 1886 系列）、进口报关单（如进口） | 明细是否含"分装" |
| **农药** | 农药登记证、农药生产许可证 | 登记证持有人 ≠ 实际生产厂时要追问 |
| **肥料** | 肥料登记证/备案、生产许可证（复混肥） | 部分品种免登记 |
| **药品/原料药** | 药品生产许可证、GMP 符合性检查、原料药登记号 | MAH 可能委托生产 |
| **工业气体** | 气瓶充装许可证、安全生产许可证 | 充装站 ≠ 空分装置 |
| **聚合物/树脂** | 聚合装置清单、单体采购合同 | 改性造粒 ≠ 聚合 |

## 话术模板

**① 开场（一次发全，降低对方抵触）**

```text
王经理，我们内部立项需要把供应商资质归档，麻烦您一次性发我这几份（能拍清楚就行）：
1）排污许可证正副本（要有"主要生产设施"那几页）
2）环评批复和验收报告（产品方案、产能那两页）
3）最近 3 车的出厂磅单
4）拟供货批次的 COA
5）包装袋正面和喷码照片
6）一张增值税发票票样（金额可以遮）
这些只用于内部合规归档，不外传。
```

**② 对方说"商业机密"时**

```text
理解。那这样：许可证和环评只发带公章的那两页，价格和客户信息可以遮掉；
磅单只要车牌、日期、净重、发货地，收货方可以打码。
```

**③ 对方说"我们是贸易商，没有这些"时**

```text
没问题，那麻烦提供生产厂的授权书和最近一批的发票，我们按分销商流程走，
合同里会写明实际生产商。
```

**④ 对方只发截图/照片时**

```text
照片能看清就行，但麻烦带上时间水印或者原图，我们这边要归档留痕。
```

**⑤ 索要视频验厂时**

```text
不用特意安排，方便的时候开个视频，从大门走到包装线，我们看 10 分钟就行，
不用拍人和办公室。
```

## 收到材料后怎么用

1. **先看主体**：证照上的企业名 = 合同主体？不是就退回；
2. **再看产品**：许可范围/环评产品方案里有目标产品？没有就降级；
3. **看地点**：证载地址 = 发货地？不一致要解释（分厂/仓库）；
4. **看时间**：许可证在有效期内？验收是最终版？
5. **归档**：把新证据按 D/I/X 编号补进 `input.json`，重跑 `build_report.py`。

---

## 三个不要

- **不要**一次只问一项，来回拉扯会暴露你在"试探"；
- **不要**承诺"看完就下单"，材料是用来判断的，不是筹码；
- **不要**把对方发的截图直接当 ●●●，截图一律按"对方提供"降级，除非能与公开来源交叉。
