# 品类 → 硬证据对照表

换产品时，**先查这张表**，再动手检索。方法不变，变的是"什么算硬证据"。

判断顺序：先看**是不是危险化学品**，再看**有没有专门许可制度**（食品、农药、肥料、药品、气体、监控化学品），最后落到普通工业品。

---

## 一、先给产品归位

```text
是不是危险化学品（查《危险化学品目录》）？
 ├─ 是 → 安全生产许可证 + 危化品登记 是硬证据（见 §2）
 └─ 否 → 有没有专门许可？
          ├─ 食品添加剂/食品原料 → 食品生产许可证 SC（见 §3）
          ├─ 饲料/饲料添加剂 → 生产许可证 + 批准文号（见 §4）
          ├─ 农药 → 农药登记证 + 生产许可证（见 §5）
          ├─ 肥料 → 登记证/备案 + 生产许可（见 §6）
          ├─ 药品/原料药/药用辅料 → 药品生产许可证 + GMP（见 §7）
          ├─ 消毒产品/涉水产品 → 卫生许可（见 §8）
          ├─ 工业气体 → 安全生产许可 + 气瓶充装许可（见 §9）
          ├─ 监控化学品/易制毒/易制爆 → 特别许可/备案（见 §10）
          └─ 都不是 → 普通工业品：排污许可 + 环评 + 项目备案（见 §1）
```

**拿不准时**：去查它的**排污许可证行业类别**——这是所有工业品都有的锚点，能反推它到底在做什么。

---

## §1 普通工业化学品（非危化）

**硬证据**
- 排污许可证，行业类别与产品对应（见下方行业类别表）
- 环评批复 + 竣工环保验收，载明产品方案与产能
- 项目备案 / 产能置换 / 节能审查公示
- 上市公司年报/公告中的产量、产线
- 非计划停产/降负荷公告（反向证明在产）

**不构成证据**：经营范围、官网宣传、危化证（不覆盖非危化品）、注册资本、ISO 证书。

**特有坑**
- 危化证对非危化品毫无证明力（纯碱、钛白粉、部分无机盐）；
- "设计产能"可能是十年前的老线，要看产量与停产公告；
- 集团母公司有证 ≠ 子公司有证，主体必须逐字对。

---

## §2 危险化学品

**硬证据**
- **安全生产许可证**（许可范围逐字含目标产品）——最硬
- 危险化学品登记证
- 排污许可证（行业类别对应）
- 环评批复/验收中的产品与产能

**不构成证据**
- 危险化学品**经营**许可证（贸易商也办）
- 运输资质、押运证
- 危化品使用许可（只覆盖自用）

**特有坑**
- **生产许可与经营许可必须分开看**：有经营证只能说明能卖，不能说明能产；
- 许可范围通常精确到"产品 + 工艺 + 装置所在地"，"含氨"不等于"含液氨"；
- 安全生产许可证有效期 3 年，过期未换证是重大风险信号。

**查询**：省级应急管理厅（局）官网 → 行政许可公示；应急管理部化学品登记中心（危化品登记）。

---

## §3 食品添加剂 / 食品原料

**硬证据**
- **食品生产许可证（SC）**：证号、品种明细、生产地址、**是否含"分装"**
- 排污许可证（行业类别：食品及饲料添加剂制造 C1495）
- 环评批复/验收

**不构成证据**：仅 SC 证号（看不到品种明细）、ISO 22000 / HACCP / 清真认证、检测报告。

**特有坑**
- **分装单元 ≠ 合成产能**：SC 明细写"分装"的，就是分装商；
- 食品级与工业级可能同一集团、不同主体，别混；
- 进口分装要有海关报关单 + 入境货物检验检疫证明。

**查询**：各省市场监管局"食品生产许可获证企业查询"；国家企业信用信息公示系统（主体信息）。

---

## §4 饲料及饲料添加剂

**硬证据**：饲料添加剂/添加剂预混合饲料生产许可证 + 产品批准文号 + 排污许可。

**不构成证据**：经营许可证、养殖场合作证明。

**特有坑**：批准文号与产品一一对应，换品种要重新审批。

---

## §5 农药

**硬证据**：农药登记证（PD 开头）+ 农药生产许可证（范围含该剂型）+ 排污许可。

**不构成证据**：农药经营许可证、委托加工协议（除非能追到实际生产厂）。

**特有坑**
- 委托加工/分装很普遍，登记证持有人 ≠ 实际生产厂；
- 剂型（乳油/悬浮剂/水分散粒剂）不同，产线不同。

**查询**：中国农药信息网（登记证查询）。

---

## §6 肥料

**硬证据**：肥料登记证/备案（部分品种免登记）+ 工业产品生产许可证（复混肥等）+ 排污许可 + 环评。

**不构成证据**：经营备案、检测报告、示范田照片。

**特有坑**
- 尿素、部分单质肥**免登记**，不能因为"没登记证"就判假；
- 有机肥/微生物肥登记要求与复合肥不同；
- 委托代工普遍，要看实际生产厂。

---

## §7 药品 / 原料药 / 药用辅料

**硬证据**：药品生产许可证（范围含该剂型/原料药）+ GMP 符合性检查 + 原料药登记号（关联审评）+ 排污许可。

**不构成证据**：药品经营许可证（GSP）、MAH 持有人（可能委托生产）。

**特有坑**：上市许可持有人可以没有工厂——这是"合法贴牌"，必须追到受托生产企业。

**查询**：国家药监局数据查询（药品生产企业、GMP、原料药登记）。

---

## §8 消毒产品 / 涉水产品

**硬证据**：消毒产品生产企业卫生许可证 / 涉水产品卫生许可批件 + 排污许可 + 环评。

**不构成证据**：卫生安全评价报告备案（这是产品备案，不是生产资质）。

---

## §9 工业气体

**硬证据**：安全生产许可证（含气体品种）+ **气瓶充装许可证** + 排污许可。

**不构成证据**：经营许可证、运输车队、钢瓶检验站。

**特有坑**：充装站 ≠ 空分装置；大量"气体公司"只是分装/充装/配送。

---

## §10 监控化学品 / 易制毒 / 易制爆

**硬证据**：监控化学品生产特别许可（工信部/省级）、易制毒化学品生产备案、易制爆备案 + 排污许可。

**特有坑**：这类许可门槛极高，拿到即强烈指向真实生产；但许可范围与产品必须逐字对应。

---

## 三个万能替代证据

许可查不到时，用这三样交叉：

1. **环评公示**：省市生态环境厅"建设项目环评审批公示"，常能拿到产品方案与产能；
2. **上市公司公告**：巨潮资讯搜企业名，产量、产线、停产都在里面；
3. **产能置换公示**：省级工信/发改部门，技改与新建项目必须公示，主体与产能写得最清楚。

---

## 一句话

> **危化看"安许"，食品看"SC 明细"，农药看"登记证"，肥料看"登记/备案"，药品看"生产许可 + GMP"，普通工业品看"排污许可行业类别"。**
> 证照之外，一律按 B/C 组处理。
