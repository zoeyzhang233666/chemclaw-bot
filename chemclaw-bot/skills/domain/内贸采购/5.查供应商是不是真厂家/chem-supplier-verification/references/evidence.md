# 三分法与证据强度

一份材料属于哪一组，只有**一个测试**：

> **能不能独立指向"这套装置存在且在运行"？**

能 → A 组；只能说明"在做这门生意" → B 组；只能说明"允许做/想做/能垫资" → C 组。
**不允许"既是 A 又是 B"**，也不允许"先放 A 组看看"。放错一组，结论必错。

---

## 强度四级

| 级别 | 符号 | 判据 | 典型材料 |
|---|---|---|---|
| 强 | ●●● | 政府/交易所/上市公司等**有法定披露义务**的主体，直接记载产品与产能/产量 | 排污许可证、环评批复与验收、项目备案/产能置换公示、年报中的产量、交易所指定厂库公告、危化品安全生产许可证 |
| 中 | ●●○ | 可与第三方交叉的企业信息，或行业组织/媒体的事实性报道 | 官网工厂页与产品页、协会名录、生产岗位招聘、原料采购招标、专利、行业媒体产能报道 |
| 弱 | ●○○ | 单方自述、无法定位的图片/视频、口头承诺 | "厂家直销"、样品间照片、无定位车间图、对方口述产能 |
| 不计分 | ○○○ | 与"是否自产"无因果关系 | 经营范围、注册资本、成立年限、可大量供货、ISO 证书 |

**评分只对 A/B 组开放。** C 组永远 0 分，并且要在报告里单独展示——它的价值是告诉读者"这些看起来像证据的东西为什么不是"。

## 按来源的采信规则

| 来源 | 默认强度 | 采信前提 | 常见陷阱 |
|---|---|---|---|
| 政府许可/备案 | ●●● | 企业名称、地址、产品对得上 | 许可证可能已过期、可能只是"变更"页 |
| 上市公司年报/公告 | ●●● | 区分"生产量"与"销售量"、"设计产能"与"在建产能" | 合并口径把贸易量算进产量 |
| 交易所公告（厂库/品牌） | ●●● | 看清是**生产型**还是**贸易型** | 贸易商也能申请厂库 |
| 环评批复/验收 | ●●● | 批复≠验收；验收≠在产 | 只有批复没有验收，可能是未建成 |
| 官网 | ●●○ | 有可交叉的牌号、基地、地址 | 官网写"全球最大"是宣传，不是事实 |
| 行业协会/名录 | ●●○ | 看入会门槛与更新时间 | 付费会员制名录无筛选作用 |
| 行业媒体 | ●●○ | 引用了公司公告或实地采访 | 通稿转载会放大同一个错误 |
| 招聘信息 | ●●○ | 岗位是"生产操作/工艺"而非"销售" | 常年挂着的岗位可能是储备 |
| 专利 | ●●○ | 申请人是该企业，且是生产方法专利 | 外观/包装专利无意义 |
| 对方提供的材料 | ●○○—●●● | 必须与其他来源交叉 | 截图、复印件、无定位照片一律降级 |
| AI/搜索摘要 | 不作为证据 | 只能用来找线索 | 摘要会编造数字，必须回原文 |

## 20 个易混案例

| # | 材料 | 归组 | 为什么 |
|---|---|---|---|
| 1 | 营业执照经营范围写"XX 生产、销售" | C | 经营范围是许可事项，不是事实状态；贸易商同样可写"生产" |
| 2 | 官网首页"厂家直销、源头工厂" | C | 宣传语零成本，且贸易商最常用 |
| 3 | 官网"关于我们"写"占地 200 亩、员工 500 人" | B ●○○ | 可作旁证，但无法定位、无法验证；需与许可地址交叉 |
| 4 | 排污许可证（行业类别=目标产品） | A ●●● | 法定许可，直接指向装置与地址 |
| 5 | 排污许可证（行业类别=其他产品） | C/B | 只能证明有别的装置；不能证明目标产品 |
| 6 | 危险化学品经营许可证 | C（对非危化品） | 贸易商也办；与生产装置无关 |
| 7 | 危险化学品安全生产许可证（范围含目标产品） | A ●●● | 危化品品类里最硬的证据之一 |
| 8 | 危化品安全生产许可证（范围只含辅料，如液氨） | C（对目标产品） | 许可范围必须逐字对；纯碱案例的经典误区 |
| 9 | 环评批复（载明产品与产能） | A ●●● | 但要看是"批复"还是"验收"，验收才代表建成 |
| 10 | 项目备案/产能置换公示 | A ●●● | 政府公示，主体、产能、置换比例都写明 |
| 11 | 交易所指定交割厂库公告 | A 或 B，看类型 | 生产型厂库= A；贸易型厂库= B；**厂库资格≠生产资质** |
| 12 | 上市公司年报"生产量 319 万吨" | A ●●● | 有披露义务、口径明确；但要区分自产与代工 |
| 13 | 上市公司"设计产能" | A ●●○ | 设计产能不等于在产；需与产量、停产公告联读 |
| 14 | 非计划停产/降负荷公告 | A ●●● | 反向证明装置真实存在且在运行 |
| 15 | 官网产品页列出的牌号与规格 | B ●●○ | 证明"在卖"，不证明"在生产"；可与 COA、包装喷码交叉 |
| 16 | 生产岗位招聘（DCS 操作、工艺工程师） | B ●●○ | 说明有产线在运转；但招聘可能外包或长期挂岗 |
| 17 | 原料采购招标（如钛矿、原盐、硫酸） | B ●●○ | 有采购才可能有生产；量级要与产能匹配 |
| 18 | 专利（生产方法） | B ●●○ | 申请人为该企业、且是工艺专利才有意义 |
| 19 | 注册资本 5 亿元、成立 30 年 | C | 与装置无关；大资本也可能只做贸易 |
| 20 | 无定位车间照片/视频 | C | 无法确认拍摄地点与对象，最典型的伪证据 |

## 每条证据过五问

归档前逐条自问，五问全过才配得上 A 组：

1. **主体对不对**：证照/公告上的企业名称，和你要核的是同一法人吗？（分公司、曾用名、集团母公司要分清）
2. **产品对不对**：许可范围、环评产品方案里，写的是目标产品吗？规格/牌号对得上吗？
3. **地点对不对**：证载地址与实际发货地、官网厂址一致吗？
4. **时间对不对**：还在有效期内吗？是批复还是验收？是历史产能还是在建产能？
5. **口径对不对**：产量是自产还是包含代工/贸易？产能是设计、核定还是实际？

任何一问答不上来，就降一级，并在 `why` 里写明降级原因。

## 打分常见错误

| 错误 | 后果 | 修正 |
|---|---|---|
| 把 C 组材料算进分数 | 贸易商也能拿高分 | C 组恒为 0 |
| 官网信息给 ●●● | 高估官网 | 官网最高 ●●○ |
| 现场维度没做却给分 | 分数虚高 | 未验厂就是 0 |
| 五个案例用不同权重 | 无法横向比较 | 权重全报告统一 |
| 分数与结论绑定 | "84 分所以是厂家" | 结论只看 Q1—Q4，分数只定位缺口 |

## 一句话记忆

> **A 组看"证"，B 组看"生意"，C 组看"话术"。**
> 证要能对上主体、产品、地点、时间、口径；生意要能与证交叉；话术一条都不算。
