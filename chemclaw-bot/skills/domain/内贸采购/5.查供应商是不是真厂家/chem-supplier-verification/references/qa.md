# 交付前自检（40 项）

先跑机器检查，再人工过一遍。机器检查不过，不许交付。

```bash
python scripts/validate.py input.json
python scripts/selfcheck.py input.json --outdir out/
```

---

## A 数据与结构（机器可查，10 项）

- [ ] 1. `validate.py` 输出 `[pass]`
- [ ] 2. `dimensions` 权重合计 = 100
- [ ] 3. 每个案例 `dims` 长度 = 维度数，且 `sum(dims) = score`
- [ ] 4. 结论只出现四种写法之一
- [ ] 5. 判"生产厂家"的案例，`direct` 不为空
- [ ] 6. `excluded` 中所有 `strength = 0`
- [ ] 7. 同一案例内证据 `code` 不重复
- [ ] 8. 所有 `url` 以 `http(s)://` 开头
- [ ] 9. 每个案例 `facts` 恰好 6 条
- [ ] 10. `synthetic: true` 的案例，HTML/Excel 都有提示

## B 证据质量（人工，12 项）

- [ ] 11. 每条 A 组证据都能说清"为什么它指向装置"
- [ ] 12. 没有把官网/宣传语放进 A 组
- [ ] 13. 没有把经营范围/注册资本/照片计分
- [ ] 14. 每条证据都有来源机构与日期
- [ ] 15. 引用是原文，不是转述；数字与单位完整
- [ ] 16. 主体逐字对过（母公司 ≠ 子公司）
- [ ] 17. 产品逐字对过（牌号/规格）
- [ ] 18. 地址对过（证载 = 发货地 = 官网）
- [ ] 19. 时间对过（许可有效期、批复 vs 验收）
- [ ] 20. 口径对过（生产量 vs 销售量、设计 vs 实际）
- [ ] 21. 至少一个案例展示了"排除项"的完整理由
- [ ] 22. 至少一个案例是"证据不足"，且解释了为什么不能判

## C 结论与措辞（人工，8 项）

- [ ] 23. `headline` 说证据结构，不复述结论
- [ ] 24. `verdict_detail` 讲清证据之间怎么互证
- [ ] 25. 没有"应该是/大概率/基本确认"等推断词
- [ ] 26. "没搜到"写成"公开渠道未取得"，不是"不存在"
- [ ] 27. `gaps` 每条都可执行（能指到具体文件/页面）
- [ ] 28. `next_action` 给出合作方式 + 一条风控动作
- [ ] 29. 分数低的案例，`score_note` 解释了缺口
- [ ] 30. 没有对企业的贬义评价（皮包公司/骗子）

## D 附件（机器 + 人工，10 项）

- [ ] 31. HTML 能离线打开，案例可切换
- [ ] 32. 证据筛选按钮计数与实际条数一致
- [ ] 33. 所有外链可点，且指向原文而非首页
- [ ] 34. 打印预览下每个案例独立成页
- [ ] 35. Excel 10 个工作表齐全
- [ ] 36. 01 总表分数引用 05 表且行号正确
- [ ] 37. 06 材料表状态列可下拉
- [ ] 38. 02/03/04 三表计数与 01 总表一致
- [ ] 39. HTML 与 Excel 的结论、分数、证据数一致
- [ ] 40. 文件名 = `meta.slug`，无非法字符

---

## 三条红线

出现任意一条，**停止交付**：

1. 有证据但说不出出处（编造链接、无来源引用）；
2. 把 C 组材料当 A 组用；
3. 结论与 Q1—Q4 不一致（例如无任何硬证据却写"生产厂家"）。
