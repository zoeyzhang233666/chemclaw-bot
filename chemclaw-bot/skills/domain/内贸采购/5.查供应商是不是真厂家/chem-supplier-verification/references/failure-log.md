# 失败模式：症状 → 病因 → 处方

按症状查，不按理论查。

---

## 数据与脚本

| 症状 | 病因 | 处方 |
|---|---|---|
| `build_report.py` 报 `[abort] 数据未通过校验`，列出 dims 合计 ≠ score | 改了分数没改维度 | 让 `dims` 自动等于各维得分，`score` 用 `sum(dims)` 回填 |
| `[error] 判为生产厂家，但直接生产证据为 0 条` | 把官网/宣传语放在了 B 组，A 组空 | 要么补一条真硬证据，要么改判"证据不足" |
| `[error] 排除项 strength 必须为 0` | 给经营范围打了 1 分 | C 组恒为 0，理由写进 `why` |
| `[error] 证据编号重复` | 两个案例都用了 `D1` 且写在同一数组里 | 每个案例内重新编号（D1、D2…），跨案例可重复 |
| `UnicodeEncodeError: 'gbk' codec` | Windows 控制台 + 产品名含 `₂`/`③` | 已内置 UTF-8 切换；旧版脚本加 `sys.stdout.reconfigure` |
| Excel 打开分数全是 0 | 环境不重算公式 | 用 Excel/WPS 打开（已设 `fullCalcOnLoad`），或 `Ctrl+Alt+F9` 强制重算 |
| 01 总表分数引用错行 | 维度数不是 5 时行号写死 | 已动态计算 `5 + len(dimensions)`；自定义维度后勿手改 |
| HTML 打开空白 | 复制产物时漏了 `<script>` 或编码错误 | 重新生成；确认文件 > 20KB 且含 `<script>` |
| 中文文件名乱码（Linux 解压） | zip 缺 UTF-8 标志位 | 用本仓库的打包脚本（`zipfile` 默认写 UTF-8 标志位） |

## 判断质量

| 症状 | 病因 | 处方 |
|---|---|---|
| 贸易商被判成生产厂家 | 把官网/厂库/授权当硬证据 | 回 Q1：有没有**以该企业为主体**的许可/环评/备案？没有就进 Q3/Q4 |
| 真厂家被判成贸易商 | 只搜了官网，没搜许可/年报 | 补搜"排污许可证""环评""产能置换""年报产量"；上市公司优先查巨潮 |
| 分装商被判成厂家 | 没看 SC 明细里的"分装"字样 | 要 SC 品种明细页；看设备清单有无合成主装置 |
| 结论是"证据不足"，但用户不满意 | 检索不充分就下结论 | 先跑完五路检索；仍不足就明确说"公开渠道未取得"，并给 P0 清单 |
| 所有案例都是"生产厂家" | 只挑了知名企业 | 必须包含至少一个贸易/分装/证据不足案例，方法才有说服力 |
| 五个案例分数都很高 | 现场维度给了分 | 未验厂记 0；官网最高 ●●○ |
| 证据很多但读不出结论 | 只罗列不解释 | `verdict_detail` 写"哪几条互证、还差什么"，3—5 句 |

## 检索

| 症状 | 病因 | 处方 |
|---|---|---|
| 搜公司名出来一堆无关内容 | 关键词被拆词 | 加引号、加股票代码、加 `site:cninfo.com.cn` |
| 搜索结果全是百科/榜单 | 关键词太泛 | 换成"公司全名 + 排污许可证/环评/产能置换" |
| 链接打不开 | 政府网站改版 | 按"机构 + 标题 + 日期"重搜；或找转载并标注"转载" |
| 找不到产能 | 非上市公司不披露 | 从用电/蒸汽/原料采购招标反推；或写进 `gaps` |
| 只有 AI 摘要给了一个数字 | 摘要不可靠 | 必须打开原文；打不开就不写，或标"未核实" |

## 交付

| 症状 | 病因 | 处方 |
|---|---|---|
| HTML 与 Excel 数字不一致 | 手改了产物 | 只改 JSON，重新生成两件套 |
| 打印时只出第一个案例 | 正常行为（打印当前案例） | 需要全部案例时，逐个切换后打印，或看 Excel |
| 客户觉得"像 AI 写的" | 通篇形容词、无具体数字 | 每段至少一个可核对的事实（产能、日期、证号、地址） |
| 客户质疑"你凭什么说他是贸易商" | 只写结论没写排除过程 | 在 `verdict_detail` 写清 Q3/Q4 的排除依据，并列出 0 条 A 组证据 |

---

## 一句话

> 大多数错误不是"搜不到"，而是**把 B 组当 A 组**。回 Q1 重问一遍，结论自然对。
