05判定方法：三分法与四类结论

先分类，再判定。分类错了，结论一定错——把“经营范围”当生产证据，是内贸采购最常见的翻车点。

A / DIRECT
直接生产证据

能独立指向“这套装置存在且在运行”的材料：排污许可证（行业类别：____）；环评批复 + 竣工验收（产品与产能）；项目备案 / 产能置换公示；该品类特有的法定许可（危化品 / 食品 SC / 农药 / 肥料 / 药品 / 气瓶充装等）；以及上市公司披露的产量、非计划停产公告、厂址与装置卫星/视频。判定只看这一组。

B / INDIRECT
间接业务证据

能说明“确实在做这门生意”，但不能单独证明自产：官网产品页、自营商城、交易所交割厂库、协会名录、原料采购、生产岗位招聘、专利、行业报道。需与 A 组交叉。

C / EXCLUDED
不构成证据

最容易被误采信的材料：营业执照经营范围、“厂家直销”话术、注册资本、可大量供货、单张无定位照片。它们只能证明“允许做/想做/能垫资”，不能证明“在做”。

判定顺序（必须按 Q1→Q4 走，不能跳步）

Q1
是否存在以该企业为主体的目标产品生产硬证据？

排污许可证（对应行业类别）；或环评批复/验收载明该产品与产能；或项目备案/产能置换公示载明该企业为主体；危化品/食品/农药等另有法定许可

是 → 进入 Q2
否 → 进入 Q3
Q2
公开产能、产量、厂址与许可是否自洽？

产能与产量量级匹配、厂址与许可地址一致、工艺路线能解释原料与副产品、产品规格对得上

是 → 判定：生产厂家
否 → 判定：生产厂家（待现场核验）
Q3
是否存在分装/复配特征？

仅持有分装类许可；无合成/反应/精馏/结晶主装置；设备为粉碎、筛分、混合、稀释、包装；外购成品或半成品

是 → 判定：分装或复配
否 → 进入 Q4
Q4
是否存在贸易经销特征？

交易所贸易商厂库、生产厂代理授权、无生产装置与排污许可、注册地为写字楼、以调货为主

是 → 判定：贸易经销
否 → 判定：证据不足，暂无法确认

说明：Q1 的硬证据只需命中一条即可进入 Q2；“分装或复配”优先于“贸易经销”， 因为分装商也有资质、也有车间，只有看许可明细与设备清单才能区分。四类都不成立时，输出“证据不足暂无法确认”，不做倾向性推断。

07现场 / 视频验厂脚本

不预约、不剪辑、按顺序走。真正的工厂不怕看装置，怕看的是门牌和地磅。

CHECK 01
厂址与门牌

不预约，拍门牌与厂区

合格：与执照/许可地址一致

造假信号：写字楼或仅仓库

CHECK 02
主装置

看核心反应/分离设备并允许拍铭牌

合格：装置在运行

造假信号：只让看包装线

CHECK 03
地磅与磅单

现场看地磅，随机调 3 车磅单

合格：日期连续、车牌真实

造假信号：复印件、日期集中
