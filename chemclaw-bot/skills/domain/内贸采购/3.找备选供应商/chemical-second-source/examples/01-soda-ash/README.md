# 示例 01 · 重质纯碱第二供应源（真实研究案例）

> 这是一个**真实公开信息研究**的成品示例，用来展示“研究做到什么程度、页面/工作簿长什么样”。
> 它不是投资建议，也不是“建议更换供应商”。排序 ≠ 建议，决策权在采购。

## 场景

| 项 | 内容 |
|---|---|
| 产品 | 重质纯碱（碳酸钠），GB/T 210.1-2004 II 类优等品；Na₂CO₃ ≥99.2%，NaCl ≤0.6%，堆密度 0.9–1.1 g/cm³ |
| 现有供应商 | 山东海化（000822，氨碱，潍坊，280 万吨/年，免检“鸢都牌”） |
| 收货地 | 江苏苏州（工业园区） |
| 采购量 | 800 吨/月 |
| 用途 | 浮法 / 光伏玻璃 |
| 数据截止 | 2026-10-19 |
| 备选池 | 12 家（S01–S12） |
| 规格矩阵 | 9 项 |
| 来源 | 45 条（A/B/C 分级） |

## 关键结论（只用于缩小验证范围）

- **近场**：连云港碱业、江苏德邦、中盐昆山、华昌化工、苏盐井神距苏州 ≤500 km；前两家为 2025 年新装置，必须做 3–6 个月稳定性验证。
- **同工艺**：三友化工（氨碱 340 万吨）、海天生物（氨碱 120 万吨）规格最接近；三友运距 1,150 km，海天与金晶科技同集团、存在纵向竞争。
- **低成本**：远兴能源/中源化学/昆仑碱业为天然碱/低成本路线；远兴与中源是母子公司，**只能算一个独立源**；远兴牌非郑商所免检。
- **同源**：中盐昆山与昆仑碱业同属中国盐业集团，不同法人/基地，独立性有限；连云港碱业与江苏德邦同园区但股权不同源。
- **名称陷阱**：山东海化与山东海天生物**不是同一集团**（前者潍坊市国资委，后者金晶科技全资），名称/区域相近，容易误判。
- **现有供应商风险**：山东海化 2025 年归母净利 -13.88 亿元，纯碱营收同比 -26.31%；氨碱成本高于天然碱/联碱。这是“建第二源”的背景，不等于应立即更换。

## 使用边界

- 产能/财务/资质均为公开口径；`待核实` 事项必须以证照、COA、现场审核为准。
- 运费为“距离 × 费率”的区间估算，不是承运商报价。
- 免检品牌是交割便利/资质，不等于质量保证；新装置“全流程贯通”不等于“质量稳定”。
- 本示例的结论只适用于该场景；换产品/收货地/规格，必须重做研究，不能套用。

## 证据与来源

来源表在 `data.json` 的 `sources`，页面/工作簿 `08_数据来源` 可逐条点开。A 级包括年报、政府/交易所；B 级包括证券时报、东方财富、券商；C 级包括官网/百科（需二次核验）。
