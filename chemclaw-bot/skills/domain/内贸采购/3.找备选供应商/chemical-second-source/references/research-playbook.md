# 检索与核实 playbook

目标不是“搜到很多网页”，而是**用可复核的证据回答：这家是不是生产企业、在哪里、多大、什么工艺、能不能用、有什么坑、和现有供应商是否同源**。

## 1. 先写研究问题（避免越搜越散）

开工前写 6 行：

```text
产品/规格：
现有供应商/工厂：
收货地/月量：
下游用途/关键指标：
数据截止日：
本轮要回答的 3 个问题：
```

如果“现有供应商”不清楚，先让采购确认全称、工厂地址、牌号/COA；否则后面无法定义“兼容”。

## 2. 检索顺序（从硬到软）

1. **身份**：企业全称、统一社会信用代码、生产地址、股权链；
2. **产能/装置**：名义产能、条数、投产/技改/搬迁、实际产量；
3. **资质**：生产许可、行业准入、交割品牌、体系/食品/危化品；
4. **财务/风险**：营收/净利、亏损、涉诉、环保/安全处罚、检修/限产；
5. **物流**：到收货地的运距、运输方式、运费区间；
6. **规格**：COA、牌号、粒度/杂质/白度、客户案例；
7. **同源**：集团/实控人/销售主体/纵向竞争。

不要从“XX 供应商排名/十大品牌”开始：这类页面广告、贸易商、贴牌商混杂，最多作为线索，不能作为证据。

## 3. 查询配方（中文）

### 3.1 企业身份

```text
"企业全称" 统一社会信用代码
"企业全称" 生产地址
"企业全称" 股权 穿透
"企业全称" 实际控制人
"企业全称" 官网 关于我们
site:gsxt.gov.cn "企业全称"          # 国家企业信用信息公示系统（如可访问）
```

企查查/天眼查/爱企查可作为线索（C 级），最终以营业执照、年报、政府公示为准。

### 3.2 产能/装置

```text
"企业全称" 产能 万吨
"企业全称" 年报 主要生产基地 产能
"企业全称" 环评 批复 万吨
"企业全称" 技改 搬迁 投产
"产品" "企业简称" 装置 投产
site:cninfo.com.cn "企业全称" 年报
site:sse.com.cn "企业全称" 公告
site:szse.cn "企业全称" 公告
```

上市公司年报的“主要生产基地/主要产品产能/在建项目”通常是最硬的公开产能口径；债券募集说明书、招股书也含装置明细。

### 3.3 资质/准入

```text
"产品" 生产许可证 企业
"产品" 交割 品牌 免检 交易所
"产品" 行业准入 条件
"企业全称" ISO9001 证书
"企业全称" 食品生产许可 SC
"企业全称" 安全生产许可证
"企业全称" 排污许可证
```

不同产品的“资质”差异很大，见 `industry-adaptation.md`。**不要把“有营业执照”当“有生产资质”**。

### 3.4 财务/风险

```text
"企业全称" 2025 年报 营收 净利
"企业全称" 亏损 停产 检修
"企业全称" 环保 处罚
"企业全称" 安全生产 事故
"企业全称" 失信 被执行 裁判文书
"企业全称" 限产 重污染天气
"产品" 价格 亏损 行业
```

风险要写“事实 + 时间 + 影响”，不要写“感觉经营不善”。

### 3.5 物流/运费

```text
地图: 工厂地址 → 收货地      # 地理运距，不是实际路线
"出发地" 到 "收货地" 汽运 元/吨
"产品" 汽运 运费 元/吨公里
"收货地" 物流园 化工品 运输
铁路 货运 运费 查询
水运 内河 码头 运费
```

运距用地图/测距；运费写“区间估算 + 费率假设”，并注明“不是承运商报价”。铁路/水运/短驳/危化品资质另询。

### 3.6 规格/COA

```text
"企业简称" "产品牌号" COA
"产品牌号" 技术指标 粒度 白度 水分
"产品" 国标 优等品 指标
"下游行业" "产品" 质量要求
"企业简称" 客户 案例 "下游"
```

COA 是批次文件，不等同于“所有批次稳定”；要问最近 3–12 个月、至少 3 批。

### 3.7 同源/股权

```text
"企业A" "企业B" 同一集团
"企业A" 母公司 持股
"企业A" 实际控制人
"集团" 纯碱/产品 业务 销售公司
"企业" 销售有限公司 关联
```

同源判断见 `same-source-checklist.md`。

## 4. 来源优先级

| 等级 | 来源 | 用法 |
|---|---|---|
| **A** | 上市公司年报/公告/招股书/债券募集书；政府/园区/发改委/生态环境部门公示；交易所/交割规则；法院/信用中国 | 产能、股权、项目、处罚、资质的首选 |
| **B** | 行业协会、券商深度、主流财经媒体、行业数据机构（隆众/卓创/百川等） | 行业趋势、价格、产能交叉验证；不能单独证明“某厂可替代” |
| **C** | 企业官网、百科、招聘、招商稿、展会页 | 线索/地址/产品线；关键数字需 A/B 复核 |

**一条 A 级来源 > 三条互相抄的 C 级来源。** 媒体互相转载不算独立验证。

## 5. 身份核实（最容易翻车）

对每家企业至少核对：

- 营业执照名称 vs 宣传名称 vs 股票简称；
- 生产地址是否与环评/生产许可一致；
- 是否有**生产**许可（不是“经营/销售”许可）；
- COA 抬头是生产企业还是贸易公司；
- 官网备案主体、招聘地址、发货地是否一致；
- 同一集团多个法人：谁签合同、谁开票、谁承担质量责任。

**危险信号**：官网只有手机号/微信、无生产地址；样品由“XX 贸易”寄出；产能数字只在招商稿出现；企业名称与知名企业近似但股权无关。

## 6. 产能/产量核实

按优先级：

1. 年报“主要产品产能/产量/在建产能”；
2. 环评/能评/项目批复的“建设规模”；
3. 政府/园区“项目投产”报道；
4. 协会/券商统计（交叉验证）；
5. 官网/百科（C 级）。

记录口径：

- `capacity`：名义产能，单位统一；
- `capacity_note`：几条线、投产时间、重质/轻质比例、实际产量；
- `output`：实际产量（有就填，没有写 `—`）；
- 多厂区：锁定具体厂区，不把集团总产能当可售货源。

## 7. 资质核实

- 生产许可/安全生产许可/排污许可：看证号、有效期、许可范围；
- 交割品牌/行业准入：看交易所/协会最新名单，注意“品牌”与“生产企业”可能不是一一对应；
- 体系认证：看认证范围是否覆盖该产品/工厂；
- 食品/医药/电池：看 SC/GMP/IATF 等，不要用 ISO9001 代替；
- 客户认证：看是否有同行业量产客户，不只看“送样合格”。

## 8. 风险核实

风险台账只写可追溯事实：

```text
company / type / fact / impact / source_id / status
```

- `fact` 带时间/数字，例：“2025 年归母净利 -13.88 亿元”；
- `impact` 写对供应/质量/商务的具体影响；
- `status=已公开` 才能进结论；`待核实` 只作线索；
- 行业风险（价格/供给）与企业风险分开，不要混为一家的问题。

## 9. 同源核实

按 `same-source-checklist.md` 做股权穿透。最低限度：

- 直接股东 → 上层集团 → 实控人；
- 是否同一控制下不同法人；
- 是否同一销售公司/同一报价体系；
- 是否纵向竞争（供应商向下游延伸）；
- 同一园区/同一公用工程不构成同源，但要提示物流/政策相关性。

## 10. 物流核实

- 运距：地图测距（直线/路线），写清口径；
- 运输方式：汽运/铁路/水运/多式联运；危化品需资质；
- 运费：`距离 × 费率` 区间；注明年份/油价/回程；
- 到货条件：卸货、仓储、包装（吨袋/槽车/ISO 罐）；
- 季节因素：内河枯水、铁路车皮、北方冬季、港口拥堵。

## 11. 短名单标准（不是打分排名）

保留 5–15 家，尽量覆盖：

- 2–3 家近场（≤500 km）——物流/响应；
- 2–3 家同工艺——规格最接近；
- 1–2 家低成本路线——价格锚；
- 1–2 家规模/资质最强——保供/合规；
- 1 家“新装置/新进入者”——谈判筹码，但必须试样。

**不要**为了凑数把贸易商、同集团重复主体、明显不兼容的规格放进来。

## 12. 记录纪律

每读一条来源，立刻记：

```json
{"id":"SRCxx","name":"机构：标题（日期）","url":"https://...","grade":"A/B/C","date":"YYYY-MM-DD"}
```

正文只写来源能支持的话：

- “年报披露产能 280 万吨” ✅
- “产能 280 万吨，实际产量 280 万吨” ❌（产量没披露）
- “据官网，公司有 120 万吨装置” ✅（标 C）
- “行业龙头” ❌（没有定义/来源）

## 13. 常见坑

| 坑 | 识别 | 处理 |
|---|---|---|
| 贸易商冒充工厂 | 无生产地址/生产许可；COA 抬头是贸易公司 | 不占第二源名额；放渠道备注 |
| 集团产能当可售 | 集团多厂区/多法人 | 锁定厂区/销售主体 |
| 老产能当在产 | 退出/搬迁/长期停车 | 查最新投产/环评/公告 |
| 免检品牌=企业 | 品牌可能授权/贴牌 | 核对生产主体与品牌归属 |
| 媒体互抄 | 多家内容一模一样 | 追原始公告/政府文件 |
| 价格当成本 | 只看到市场价 | 成本需原料/能耗/工艺模型，本 skill 不构建 |
| 同源当两家 | 同集团/母子公司 | 二选一或标“不独立” |
| COA=兼容 | 单批次 COA 只证明该批 | 多批次 + 首样 + 小试 |
| 距离=运费 | 直线距离/路线距离不同 | 用区间估算，注明假设 |
| 新装置=达产 | “贯通/出货”≠“满负荷稳定” | 3–6 个月稳定性验证 |

## 14. 行业检索补充

| 行业 | 额外关键词/来源 |
|---|---|
| 纯碱/氯碱 | 郑商所交割品牌、中国纯碱工业协会、纯碱期货规则、产区（内蒙古/青海/河南/江苏/山东） |
| 钛白粉 | 硫酸法/氯化法、中国涂料工业协会、钛白粉产业技术创新战略联盟、REACH |
| 树脂/塑料 | 牌号、熔指、悬浮/本体、CLP/REACH、塑料加工协会 |
| 溶剂 | 纯度/水分/色度、危化品、VOC、港口/罐区 |
| 工业气体 | 空分/制氢、危化品、管道/槽车、园区公用工程 |
| 食品添加剂 | SC/FSSC 22000、GB 2760、客户审核 |
| 电池材料 | IATF 16949、客户认证、磁异物/水分、前驱体来源 |
| 危化品 | 安全生产许可、危化品经营/运输、重大危险源、园区认定 |

> 任何行业都遵守同一结构：身份 → 产能 → 资质 → 风险 → 物流 → 规格 → 同源。只是“资质”和“规格”的具体项不同。
