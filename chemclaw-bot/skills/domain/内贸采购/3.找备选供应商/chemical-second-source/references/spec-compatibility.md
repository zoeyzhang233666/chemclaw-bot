# 规格兼容性与试样

## 1. 核心原则

**“同品种”不等于“可替代”。** 同一化工品可能有：

- 不同工艺（氨碱/联碱/天然碱；硫酸法/氯化法；离子膜/隔膜）；
- 不同等级（工业级/食品级/光伏级/电池级/医药级）；
- 不同物理形态（重质/轻质；片碱/液碱；粉末/颗粒）；
- 不同牌号/粒度/白度/水分/杂质；
- 不同包装/运输条件（吨袋/槽车/ISO 罐/危包）。

第二源研究必须先回答：**现有供应商的哪些指标是“不能变”的？** 再判断候选是“同规格”“明确兼容”还是“需试样/需客户认证”。

## 2. 拆规格（9–15 项）

建议覆盖以下类别：

| 类别 | 示例指标 | 为什么重要 |
|---|---|---|
| 主含量 | Na₂CO₃ ≥99.2%；TiO₂ ≥93%；NaOH 32% | 有效成分，直接影响配料/成本 |
| 关键杂质 | NaCl、Fe₂O₃、水不溶物、重金属、磁异物 | 影响下游产品性能/合规 |
| 物理形态 | 堆密度、粒度分布、白度、比表面积 | 影响下料、熔化、分散、遮盖力 |
| 水分/挥发 | 水分、灼烧减量、挥发分 | 影响称量、结块、反应 |
| 稳定性 | 结块/运输稳定性、批次波动 | 影响仓储/自动投料 |
| 包装/运输 | 吨袋/50 kg/槽车/ISO 罐 | 影响卸货/安全/成本 |
| 合规 | 食品级/危化品/REACH/RoHS | 影响客户准入 |

每项写：

```json
{"id": "fe", "label": "Fe₂O₃（铁）", "target": "按客户内控/光伏玻璃要求"}
```

`target` 可以是数值、范围、标准号、客户封样要求；不确定写“按客户内控/封样”。

## 3. 三态：COA / 试样 / 审核

| 状态 | 含义 | 适用 |
|---|---|---|
| `COA` | 可凭批次 COA/出厂检验追溯；仍需核对批次与项目 | 成熟装置、常规指标、有连续 COA |
| `试样` | 必须首样/小批量验证 | 新装置、新工艺、新矿源、非准入、粒度/白度/杂质敏感、客户未用过 |
| `审核` | 需现场审核/封样/包装确认 | 食品/医药/危化品/客户审厂/包装特殊 |

**默认保守**：不确定就写 `试样`，不要写 `COA`。`COA` 只证明“该批”，不证明“长期稳定”。

## 4. 首样计划

### 4.1 取样

- 每家 20–50 kg × 3 批（新装置 5 批）；
- 覆盖不同生产日期/班次；
- 保留原包装/封条/批次号；
- 同时取现有供应商 1 批作对照（盲样编号）。

### 4.2 检测

- 按 `spec_items` 逐项检测；注明方法/标准；
- 关键项做平行样/复测；
- 需要时做下游小试/中试（熔化、分散、反应、涂布、配料）；
- 记录检测机构/日期/报告编号。

### 4.3 判定

- 全部关键项达标 + 下游小试通过 → 进入“小批量试单”；
- 关键项边缘/波动 → 加严抽样/追加批次；
- 不达标 → 终止或降为“特定用途备选”；
- 不要用“综合评分”掩盖单项不达标。

### 4.4 留样

- 留样 12 个月；
- 记录批次/生产日期/检验员/封样人；
- 客户投诉时可比对。

## 5. 新装置/新工艺

新装置（投产 <12 个月）风险：

- 负荷爬坡、批次波动；
- 重质比例/粒度/白度未稳定；
- 设备故障/停车；
- 人员/管理未磨合；
- 资质/客户认证未完成。

动作：

- `sample = 必须`；
- 至少 3–6 个月、5–8 批稳定性数据；
- 现场审核（装置/化验室/仓储）；
- 小批量试单（1–2 车）→ 再到月度比例；
- 合同中约定质量赔付/退换货/停线损失。

## 6. 工艺差异

| 产品 | 工艺差异 | 对规格的常见影响 |
|---|---|---|
| 纯碱 | 氨碱/联碱/天然碱 | 粒度、堆密度、白度、NaCl、水不溶物、结块 |
| 钛白粉 | 硫酸法/氯化法 | 粒径分布、白度、消色力、表面处理、分散性 |
| 烧碱 | 离子膜/隔膜 | 纯度、盐分、碳酸钠、色度 |
| 树脂 | 悬浮/本体/乳液 | 熔指、分子量分布、粒径、VOC |
| 溶剂 | 石油基/煤基/生物基 | 纯度、水分、色度、硫/芳烃 |
| 工业气体 | 空分/制氢/副产 | 纯度、露点、氧/氮/CO₂ 杂质 |

**同工艺也不等于同规格**：原料、设备、控制水平、客户认证都会造成差异。

## 7. 常见错误假设

| 错误假设 | 现实 | 修正 |
|---|---|---|
| “都是国标优等品，可以互换” | 国标是最低门槛，客户内控更严 | 拆客户内控 + 首样 |
| “COA 合格就能用” | COA 是单批，且可能只测常规项 | 多批次 + 下游小试 |
| “同工艺就能替代” | 原料/装置/控制不同 | 逐项比对 + 试样 |
| “粒度差不多” | 粒度分布/筛余可能差很多 | 要分布曲线/筛余 |
| “白度够” | 不同光源/仪器口径不同 | 统一光源/仪器/封样 |
| “食品级就是 SC” | SC 是生产许可，不是产品标准 | 看 SC 范围 + 产品检测 |
| “新装置更先进，肯定更好” | 爬坡期波动大 | 3–6 个月稳定性验证 |
| “价格低就能用” | 质量/合规/停线风险 | 总成本 + 风险 |

## 8. 与客户/下游确认

在送样前问清：

- 哪些指标是“红线”，哪些可协商？
- 是否有客户指定牌号/合格供方名录？
- 变更原料是否需要客户重新认证/PPAP/小试？
- 认证周期/费用/样品量？
- 是否需要现场审核/体系审核？
- 包装/标签/批次追溯要求？

**客户认证周期常常比找厂更长**；行动清单要预留。

## 9. 矩阵语义

`spec_status` 不是“质量评分”，而是“**验证方式**”：

- `COA`：先看文件，仍需核对；
- `试样`：必须做样；
- `审核`：必须现场/封样/包装确认。

页面/工作簿用三色区分，不要把它误读为“合格/不合格”。真正的合格结论来自检测报告/小试/审厂。

## 10. 交付写法

```text
规格兼容性：中高（主含量/杂质可凭 COA，粒度/白度需首样）
试样要求：必须（2025 年新装置，重质比例未披露）
建议：先 3 批首样 + 下游小试；通过后再 1 车试单；不建议直接月度切换。
```

不要写：

- “规格完全一致”（除非逐项比对且有证据）；
- “可无条件替代”（除非客户认证/小试通过）；
- “免检=免检质量”（免检是交割便利，不是质量保证）。
