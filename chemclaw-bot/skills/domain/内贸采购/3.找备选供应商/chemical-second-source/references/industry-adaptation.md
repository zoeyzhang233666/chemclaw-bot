# 行业适配指南

这个 skill 的**结构**是产品无关的：身份 → 产能 → 资质 → 风险 → 物流 → 规格 → 同源。变的是每一列的具体内容。

下面按大类给出“该查什么、该写什么”。不要把这些文字硬编码进模板；把它们写进 `meta` / `spec_items` / `meta.dd_items`。

## 1. 通用替换表

| 占位 | 纯碱示例 | 钛白粉示例 | 烧碱示例 |
|---|---|---|---|
| `product` | 重质纯碱（碳酸钠） | 金红石型钛白粉 | 32% 离子膜液碱 |
| `product_short` | 重质纯碱 | 钛白粉 | 液碱 |
| `unit` | 万吨/年 | 万吨/年 | 万吨/年（折 100%） |
| `qualification_label` | 郑商所纯碱免检交割品牌 | 硫酸法/氯化法准入 + 危化品 | 危化品安全生产/经营许可 |
| `qualification_short` | 免检 | 准入 | 危化品 |
| `grade_label` | 重质 / 品牌 | 型号 / 表面处理 | 浓度 / 等级 |
| `meta.dd_items` | 免检、SC、纯碱许可 | 工艺、REACH、客户认证 | 危化品、运输、罐区 |

## 2. 无机大宗（纯碱、烧碱、硫酸、盐酸、电石等）

**关键规格**

- 主含量/浓度、杂质（NaCl、Fe、Ca/Mg、SO₄、水不溶物）、水分、色度；
- 物理形态：重质/轻质、片/粒/液、粒度/堆密度；
- 包装/运输：吨袋/槽车/ISO 罐；危化品需危包证。

**资质**

- 生产许可、安全生产许可、排污许可；
- 危化品经营/运输（如适用）；
- 食品级 SC（如适用）；
- 交易所交割品牌/行业准入（如纯碱、烧碱期货）。

**物流**

- 汽运/铁路/水运；危化品车辆/码头资质；
- 距离远、运费占比高；天然碱/西北货源铁路车皮是瓶颈；
- 冬季/枯水/环保限产影响发运。

**风险**

- 能耗/环保限产；装置老化/检修；价格周期亏损；
- 新装置爬坡；单一基地；同源集团。

## 3. 钛白粉（颜料）

**关键规格**

- TiO₂ 含量、白度、消色力/着色力、粒径分布、吸油量、水分、水溶物、筛余；
- 晶型（金红石/锐钛）、表面处理（Al/Si/Zr）、分散性；
- 应用：涂料/塑料/油墨/造纸/化纤。

**资质**

- 硫酸法/氯化法工艺准入、危化品（硫酸/氯气）、REACH/RoHS；
- 客户认证（涂料厂/塑料厂）、ISO、IATF（如汽车）。

**物流**

- 25 kg 袋/吨袋；出口占比较高，港口/船期重要；
- 粉尘/防潮；海运集装箱。

**风险**

- 硫酸法废酸/环保；氯化法技术/原料；出口反倾销；
- 牌号差异大，同厂不同型号不能互换；
- 客户认证周期长。

## 4. 树脂/塑料（PE/PP/PVC/ABS/PC 等）

**关键规格**

- 牌号、熔指（MFI）、密度、分子量分布、冲击/拉伸/维卡；
- 粒径/粉末/颗粒、色粒/黑点、水分/挥发；
- 应用：注塑/挤出/吹膜/管材/改性。

**资质**

- ISO、IATF 16949（汽车）、UL/ROHS/REACH、食品接触；
- 客户牌号认证/PPAP。

**物流**

- 25 kg 袋/吨袋/散装罐车；防潮/防污染；
- 进口料需船期/汇率/关税。

**风险**

- 牌号切换需客户认证；装置检修/裂解原料；
- 价格随油价/供需；贸易商贴牌多，需看生产主体。

## 5. 溶剂（甲醇、乙醇、丙酮、乙酸乙酯、甲苯等）

**关键规格**

- 纯度、水分、色度（Pt-Co）、酸度、蒸发残渣、硫/芳烃/苯；
- 工业级/电子级/医药级/食品级；
- 包装：槽车/ISO 罐/200L 桶。

**资质**

- 危化品生产/经营/运输；安全生产许可；
- 电子级需 SEMI 标准/客户认证；医药级 GMP；
- 食品级 SC/FSSC。

**物流**

- 危化品车辆/码头/罐区；防静电/防爆；
- 进口/出口船期；内河/港口。

**风险**

- 安全/环保事故；VOC 治理；罐区/码头限制；
- 纯度/水分批次波动；电子级金属离子。

## 6. 工业气体（氧/氮/氩/氢/CO₂）

**关键规格**

- 纯度（99.999%）、露点、氧/氮/CO₂/CO 杂质、压力；
- 气态/液态/管道；瓶装/槽车/ISO 罐；
- 医用/食品级/电子级。

**资质**

- 危化品生产/经营/运输；气瓶充装许可；
- 医用氧 GMP/药品注册；食品级 CO₂ 认证；
- 电子级 SEMI。

**物流**

- 管道/槽车/瓶装；半径通常 200–300 km；
- 空分装置连续运行，停车成本高。

**风险**

- 单点空分/管道故障；区域垄断；医用/食品合规；
- 运输半径限制，远距不经济。

## 7. 食品添加剂/精细化工

**关键规格**

- 主含量、杂质（重金属/砷/铅）、微生物、色度、水分、粒度；
- 食品级/医药级/化妆品级；
- 包装/标签/批次追溯。

**资质**

- SC/FSSC 22000/ISO 22000、GMP、REACH/RoHS；
- 客户审核/清真/犹太/KOSHER。

**物流**

- 防潮/防交叉污染；食品级专用仓储/运输；
- 小批量/多品种。

**风险**

- 合规/客户审核；批次追溯；交叉污染；
- 小厂质量体系弱；出口注册。

## 8. 电池材料（正极/负极/电解液/隔膜）

**关键规格**

- 主含量、杂质（Fe/Cu/磁异物）、水分、粒度（D50）、比表面积、pH、振实密度；
- 电化学性能（首效/容量/循环）；
- 客户认证（PPAP/送样/中试）。

**资质**

- IATF 16949、ISO 9001/14001、客户审核；
- 危化品（如适用）、环保。

**物流**

- 防潮/防磁异物；吨袋/纸箱/真空包装；
- 运输污染控制。

**风险**

- 客户认证周期长；技术路线变化；
- 磁异物/水分控制；单一大客户。

## 9. 危化品通用

**关键规格**

- 浓度/纯度、杂质、水分、色度；
- 危化品分类/UN 编号/包装类别；
- 稳定剂/阻聚剂（如适用）。

**资质**

- 安全生产许可证、危化品经营许可证、危化品登记；
- 危包证、运输资质、押运员；
- 排污许可、重大危险源备案。

**物流**

- 危化品车辆/罐区/码头；防爆/防静电；
- 夜间/城区限行；应急演练。

**风险**

- 安全/环保事故；处罚/停产；
- 运输合规；园区认定；
- 单一装置/单一客户。

## 10. 如何写 `meta.dd_items`

默认 13 项通用清单。不同行业建议替换/增加：

**纯碱**

```json
[
  {"label":"营业执照/股权","hint":"股权穿透、统一社会信用代码"},
  {"label":"生产许可/SC","hint":"纯碱生产许可、食品级 SC（如适用）"},
  {"label":"质量体系","hint":"ISO9001/14001/45001"},
  {"label":"免检/交割资质","hint":"郑商所免检品牌、交割库/质检报告"},
  {"label":"近12月COA","hint":"至少 3 批 COA/出厂检验报告"},
  {"label":"产能/产量证明","hint":"环评/公告/统计/审计报告"},
  {"label":"环保/排污","hint":"排污许可、环保处罚、园区合规"},
  {"label":"安全/事故","hint":"安全生产许可、事故/处罚记录"},
  {"label":"财务/涉诉","hint":"审计报告、征信、重大诉讼"},
  {"label":"玻璃客户案例","hint":"浮法/光伏玻璃客户与联系人"},
  {"label":"物流/码头","hint":"到收货地的汽运/内河/铁路条件"},
  {"label":"合同/条款","hint":"最小起订、账期、赔付、包装、巡检"},
  {"label":"样品/封样","hint":"首样、封样、留样与复检规则"}
]
```

**钛白粉**

- 工艺准入（硫酸法/氯化法）、危化品（硫酸/氯气）、REACH/RoHS、涂料/塑料客户认证、表面处理型号、白度/消色力、出口反倾销。

**烧碱/危化品**

- 安全生产许可、危化品经营/运输、危包证、罐区/码头、重大危险源、应急能力、浓度/碳酸钠/盐分。

**食品添加剂**

- SC/FSSC 22000、GMP、重金属/微生物、清真/犹太、批次追溯、交叉污染、客户审核。

## 11. 不要硬编码

- 模板里不写“纯碱/免检/氨碱/海化”；
- 产品差异放 `meta` / `spec_items` / `dd_items`；
- 工艺颜色/名称放 `meta.processes`；
- 资质标签放 `qualification_label/short`；
- 尽调项放 `meta.dd_items`；
- 标签颜色放 `tag_tones`（可选）。

这样换产品只需换 `data.json`，不需要改 HTML/JS/Python。
