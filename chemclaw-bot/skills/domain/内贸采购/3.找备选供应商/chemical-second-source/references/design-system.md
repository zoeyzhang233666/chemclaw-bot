# 设计规范（HTML + Excel）

## 1. 设计目标

- **专业、可读、可打印**：像采购部内部工作台，不是营销落地页；
- **数据驱动**：所有产品/企业/标签来自 `data.json`，模板不写死某个化工品；
- **一眼看懂差异**：现有供应商永远有独立视觉锚点（深色/方形标记）；
- **不过度承诺**：排序、颜色、雷达都注明“相对刻度/研究辅助”，不出现“最佳/建议替换”。

## 2. 色彩

| 角色 | 色值 | 用法 |
|---|---|---|
| 深海军蓝 `#08243F` | 页头、表头、主标题 | 稳定、专业 |
| 深蓝 `#0C3357` | 次级表头/区块 | 层次 |
| 蓝 `#1F5EFF` | 链接、主按钮、选中 | 交互 |
| 青 `#0E7490` | 图表/辅助 | 区分 |
| 琥珀 `#B45309` | 待核实/新装置/风险提示 | 警示但不尖叫 |
| 红 `#B42318` | 现有供应商/高风险/亏损 | 仅用于强调 |
| 绿 `#067647` | 合格/近场/低成本/正向 | 通过/优势 |
| 紫 `#6D28D9` | 试样/第三方 | 辅助 |
| 浅灰蓝 `#EEF2F7` | 页面背景 | 低对比 |
| 白 `#FFFFFF` | 卡片 | 内容承载 |

工艺颜色来自 `meta.processes[].color`；不要用红/绿表示工艺（会与风险/合格混淆）。现有供应商用深灰/红色菱形，不用工艺色。

## 3. 字体与排版

- 字体栈：`"Microsoft YaHei","PingFang SC","Noto Sans SC","Source Han Sans SC",system-ui,sans-serif`；
- 正文 14px，辅助 12px，表头 9–10px，页头 `clamp(24px,3vw,38px)`；
- 数字用 `font-variant-numeric: tabular-nums`；
- 行高 1.55–1.65；卡片内边距 14–22px；
- 标题层级：页头 H1 → 区块 H2（带 `01` 编号）→ 卡片 H3 → 小节 H4。

## 4. 页面结构

```text
Hero（产品/现有供应商/场景/数字徽章/“排序≠建议”）
├─ Baseline + 4 KPI
├─ 01 采购参数（可编辑月量/费率 → 车次/运费估算）
├─ 02 备选池（搜索/筛选/排序/卡片|表格/勾选）
├─ 03 组合视角（产能×运距散点 + 工艺堆叠）
├─ 04 同源与股权关系
├─ 05 规格兼容与试样矩阵
├─ 06 公开风险台账
├─ 07 30/60/90 天行动
├─ 08 研究口径与关键判断
└─ 09 来源与免责
```

固定底栏（已选 N 家 / 清空 / 横向比较）；对比弹窗（现有 + 所选，20+ 行 + 雷达 + 差异）；打印只保留对比弹窗。

## 5. 组件规则

### KPI

- 4 个：备选数、近场数、资质数、需试样数；
- 数字大、说明小；不要放“综合得分”。

### 卡片

- 顶部：序号、企业名、集团/代码、勾选框；
- 一行差异（`diff`）；
- 4 个指标：产能、运距、运费区间、风险等级/点；
- 标签：工艺、资质、规格兼容、`tags`；
- 折叠：证据、产能/产品、风险、同源、需核实。

### 表格

- 卡片/表格切换，同一份数据；
- 表头深色、冻结首列/首行（Excel）；
- 数字右对齐/等宽；文本左对齐、换行；
- 行高按内容估算，不截断长文本（Excel `fit_row`）。

### 散点

- X=运距，Y=产能（对数）；气泡颜色=工艺；
- 现有供应商用菱形/深红；
- 近场阈值虚线；标注“产能对数/到收货地运距”；
- 气泡 `<title>` 含企业/产能/运距。

### 雷达

- 6 轴：产能规模、区位物流、成本潜力、资质合规、风险稳健、供应独立性；
- 0–100 相对刻度；现有供应商灰色虚线；
- 图下注明“相对刻度，不是评分模型”。

### 同源卡片

- flag 颜色：同源/纵向=红，同集团=琥珀，非同源=绿，单一/多厂区=灰/蓝；
- 必须显示：集团、母公司、主体、关系、影响、核实；
- 同组 2 家同时入选，页面/Excel 显著提示。

### 规格矩阵

- 行=候选，列=规格项；
- 三态颜色：COA 绿、试样 琥珀、审核 蓝；
- 表头带目标值；图例解释“三态是验证方式，不是合格/不合格”。

### 风险台账

- 列：企业、类型、公开事实、影响、来源、状态；
- 类型色：财务红、装置琥珀、资质蓝、同源紫、行业灰；
- 状态：已公开绿、待核实琥珀。

## 6. HTML 技术约束

- 单文件：`<style>` + `<script>` + JSON 全内联；无 CDN/外链字体/图片；
- 原生 JS，不用框架；`const DATA = window.__DSH_DATA__`；
- 所有用户数据经 `esc()` 转义，防 XSS/破版；
- 响应式：1100px/720px 断点；表格横向滚动；
- 打印：`@media print` 隐藏非对比区，A4 横向；
- 无网络请求；离线打开可用；
- JS 体量控制在 ~35KB（模板），生成物 80–200KB 正常。

## 7. Excel 设计

### 通用

- 字体“微软雅黑”；深海军蓝表头/白字加粗；
- 细边框 `#D9E2EC`；隔行浅底 `#FBFDFF`；
- 冻结窗格：`01` C5、`03` D7、`04` B6、`05` A6、`06` A6、`07` A6、`08` A6、`09` E6；
- 自动筛选：`01`、`04`、`06`、`08`、`09`；
- 列宽按内容；行高 `fit_row`（最小 18–58，最大 80–150）；
- 横向 A3、fitToWidth=1、fitToHeight=0；打印标题行 1:4/1:5；
- 工作表 tab 颜色区分；`00` 深蓝、`01` 蓝、`02` 青、`03` 琥珀、`04` 紫、`05` 红、`06` 棕、`07` 绿、`08` 灰、`09` 深青。

### 各表

| 表 | 设计要点 |
|---|---|
| `00_说明` | 大标题、场景参数、方法、关键判断、导航、证据/免责；纵向打印 |
| `01_备选池` | 33 列；数据条（运距/产能）；风险色阶；资质/同源条件格式；证据超链接 |
| `02_图表` | 数据区 + 3 张图（产能/运费横条、工艺饼）；图表锚在右侧 |
| `03_横向对比` | 类别列合并+竖排；现有/备选列；数值色阶；冻结 D7 |
| `04_试样计划` | 规格矩阵；状态下拉；三态条件格式；新装置备注 |
| `05_同源关系` | flag 颜色；主体/影响/核实用长文本换行 |
| `06_风险台账` | 类型/状态颜色；来源超链接 |
| `07_行动清单` | 阶段/责任/产出；状态下拉；目标完成 |
| `08_数据来源` | A/B/C 颜色；链接；日期 |
| `09_尽调清单` | 候选×尽调项；状态下拉；本次重点 |

### 条件格式

- 颜色只表达“相对位置/状态”，在图例/表头注明；
- 不要用红绿表示“好坏供应商”；只表示可量化项（运距/运费/产能/风险分）或状态；
- 数据条用于连续数值；色阶用于对比表；公式规则用于枚举状态。

## 8. 内容规则

- 页面/工作簿顶部必须出现“排序 ≠ 建议 · 决策权在采购”；
- 不出现“最佳/推荐替换/建议换成 X”；
- 所有估算写“估算/区间/假设”；
- 所有 `待核实` 用琥珀色，不与“已公开”混排；
- 来源必须可点；无链接的来源不进正文；
- 页脚写数据截止日、免责、配套工作簿文件名。

## 9. 可访问性/可读性

- 颜色对比：深色表头白字；浅底深字；
- 不依赖颜色单独传达信息：状态同时有文字；
- 表格有表头；图表有标题/轴标签/图例；
- 打印不截断关键列（fitToWidth）；
- 移动端卡片单列、筛选不吸顶遮挡。

## 10. 自定义边界

**可以改**

- `meta` 里的产品/单位/标签/工艺颜色/尽调项；
- `data.json` 全部内容；
- `style.css` 的品牌色（保持对比度）；
- `build_xlsx.py` 的列宽/颜色（不改结构）。

**不要改**

- 模板里硬编码某个产品名；
- 删除“排序≠建议”/免责；
- 把 `待核实` 改成“已确认”；
- 把雷达改成“综合得分”；
- 引入 CDN/联网资源（破坏离线单文件）。
