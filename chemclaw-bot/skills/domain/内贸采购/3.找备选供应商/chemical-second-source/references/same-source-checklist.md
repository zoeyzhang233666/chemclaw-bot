# 同源 / 独立性核查清单

## 1. 为什么单独做

“第二供应源”的价值在于**独立性**：当现有供应商出问题时，备选能独立供货、独立定价、独立承担质量责任。

如果两家：

- 同属一个集团/同一实控人；
- 是母子公司/兄弟公司；
- 由同一销售公司统一定价/签合同；
- 共用同一生产基地/装置/公用工程；
- 存在纵向竞争（供应商被下游客户控股）；

那么它们**不能同时算两个独立源**。不是“不能买”，而是“不能把 2 家当成 2 个备份”。

## 2. 十项穿透

对每家候选做以下检查，至少回答“是/否/待核”：

| # | 检查 | 具体动作 | 同源信号 |
|---|---|---|---|
| 1 | 直接股东 | 工商/年报披露的股东 | 同一股东/同一持股平台 |
| 2 | 上层集团 | 股权链向上穿透 | 同一集团 |
| 3 | 实际控制人 | 年报/工商/政府 | 同一自然人或国资委 |
| 4 | 母子/兄弟 | 持股比例、并表关系 | 母子公司/兄弟公司 |
| 5 | 一致行动/代持 | 公告、问询函、裁判文书 | 一致行动人/代持 |
| 6 | 销售主体 | 合同/发票/报价单抬头 | 同一销售公司 |
| 7 | 品牌/商标 | 品牌归属、授权/贴牌 | 同一品牌/授权 |
| 8 | 生产基地 | 厂区地址、装置、公用工程 | 同一基地/同一装置 |
| 9 | 纵向关系 | 下游客户/集团是否控股供应商 | 供应商被客户控股 |
| 10 | 关联交易 | 年报关联方、定价政策 | 大额关联采购/销售 |

## 3. 常见结构

### 3.1 母子公司

A 持有 B 51%–100%，B 并表。**同源**；只能算一个供应源。

写法：

```json
{
  "group": "A 集团",
  "parent": "A 上市公司",
  "entities": ["A（本部）", "B（A 持股 81.71%）"],
  "relation": "母子公司（并表）",
  "implication": "二者只能算一个供应源；B 的报价/排产受 A 控制。",
  "verify": "B 的销售主体、关联交易定价、A 对 B 的排产权限",
  "flag": "同源"
}
```

### 3.2 同集团、不同法人/基地

同一国资委/集团，不同上市公司/厂区。**同集团**；生产基地可能独立，但集团统一销售/价格政策会削弱议价独立性。

写法：`flag: 同集团`；`implication` 写“基地独立，但销售/价格政策可能统一，需核授权”。

### 3.3 同一实控人/一致行动人

不同公司名，同一自然人或同一持股平台。**同源**；需看是否合并报价/排产。

### 3.4 纵向竞争

供应商被下游客户/集团控股（例：纯碱厂被玻璃集团全资；钛白粉厂被涂料集团控股）。**纵向竞争**；供货优先级、价格、对第三方客户的政策可能受集团策略影响。

写法：`flag: 纵向竞争`；`implication` 写“对第三方客户的供货优先级/价格可能不利”。

### 3.5 同园区、不同股东

同一化工园区，共用码头/蒸汽/污水处理，但股权不同。**非同源**；可视为独立供应源，但提示“物流/园区政策相关”。

写法：`flag: 非同源`；`implication` 写“物流可共享，但股权独立；园区限产可能同时影响两家”。

### 3.6 同一销售公司/代理

两家工厂由同一销售公司统一定价/签合同。即使股权不同，**商务独立性有限**；标“同一销售主体”，需核授权/佣金/客户归属。

### 3.7 品牌授权/贴牌

品牌属于集团/贸易商，生产主体是另一家工厂。**品牌 ≠ 生产主体**；第二源要落到“生产主体 + 产线”，不是品牌。

### 3.8 同一厂区多法人

同一地址/同一装置，不同法人（常见于搬迁、合资、分公司）。**同源/同一基地**；不能算两个源。

## 4. 判断表

| 情形 | 能否算两个独立源 | 建议 flag | 备注 |
|---|---|---|---|
| 母子公司（持股 >50%） | 否 | 同源 | 二选一 |
| 同一实控人/一致行动人 | 否 | 同源 | 看是否合并报价 |
| 同集团不同法人/基地 | 通常否 | 同集团 | 核销售授权；基地独立不等于商务独立 |
| 同一销售公司 | 否（商务不独立） | 同源/同集团 | 核合同/发票抬头 |
| 纵向竞争（被下游控股） | 可算，但受限 | 纵向竞争 | 核第三方供货政策 |
| 同园区不同股东 | 可算 | 非同源 | 提示园区相关性 |
| 品牌授权/贴牌 | 看生产主体 | 同源/待核 | 第二源落到产线 |
| 同一厂区多法人 | 否 | 同源 | 同一基地 |
| 仅同名/同音/同区域 | 需核 | 待核 | 名称相近最容易误判 |

## 5. 名称相近陷阱

中国化工企业名称高度相似：

- “山东海化” vs “山东海天生物”：同省、名称相近，但**不是同一集团**（前者潍坊市国资委，后者金晶科技全资）；
- “中盐昆山” vs “昆仑碱业”：同属中国盐业集团，但不同法人/基地；
- “江苏德邦” vs “安徽德邦”：可能同集团，也可能只是同名，必须股权穿透；
- “XX 化工” vs “XX 化工集团”：可能是母公司/子公司，也可能完全无关。

**规则：名称相似不构成同源，也不构成独立；以股权/实控人为准。**


## 7. 页面/工作簿呈现

- HTML 同源区：每张卡片显示 `flag`、集团、主体、关系、影响、核实；
- 如果同一组有 2 家同时入选，页面/工作簿显著提示“不能算两个独立源”；
- Excel `05_同源关系` 用颜色区分 flag；`01_备选池` 的“同源关系”列同步；
- `meta.same_source_note` 写最容易被误判的一组，放在同源区下方。

## 8. 访谈/审厂时要问

- 你们和 XX 是不是同一集团？谁控股？
- 报价/合同/发票由哪个主体出？
- 排产/发货优先级由谁决定？
- 如果集团内部客户和外部客户同时要货，怎么排？
- 是否有集团统一销售/最低限价？
- 近三年与关联方的交易金额/比例？
- 品牌/商标归谁？是否授权/贴牌？

## 9. 结论写法

不要写：

- “A 和 B 是两家公司，可以双源。” ❌
- “A 和 B 同属一个集团，不能买。” ❌

要写：

- “A 与 B 为母子公司（A 持股 81.71%），**只能算一个独立源**；建议二选一，或把 B 作为 A 的备用产线而非独立第二源。” ✅
- “A 与 B 同属中盐集团但不同法人/基地，**基地独立、商务独立性待核**；需确认销售授权与集团集采政策。” ✅
- “A 与 B 同园区但股权不同源，**可视为两个独立源**；但园区限产/公用工程故障可能同时影响两家。” ✅

> 同源核查的目标不是“排除”，而是**让采购知道这个“第二源”到底有多独立**。
