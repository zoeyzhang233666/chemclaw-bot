# 证据分级与写法

## 1. 为什么要分级

采购研究最常见的失败不是“查不到”，而是：

- 把招商稿的“规划产能”当在产产能；
- 把百科/软文当事实；
- 把 2024 年数据写成 2026 年；
- 把“集团产能”当“可售货源”；
- 把“待核实”写成结论。

分级的目的不是学术洁癖，而是让读者知道**这句话能信到什么程度、下一步该核实什么**。

## 2. A / B / C 定义

| 等级 | 定义 | 典型来源 | 可直接支持 |
|---|---|---|---|
| **A** | 法定披露/政府/交易所/法院 | 上市公司年报、公告、招股书、债券募集书；政府/园区/发改/生态环境公示；交易所规则；信用中国/裁判文书 | 产能、产量、股权、项目、处罚、资质、交割品牌 |
| **B** | 行业/专业/主流媒体 | 行业协会、券商深度、主流财经媒体、行业数据机构（隆众/卓创/百川等） | 行业趋势、价格、产能交叉验证、项目进展 |
| **C** | 企业自述/百科/招聘/招商 | 企业官网、百科、公众号、招聘、展会页、招商稿 | 地址、产品线、线索；关键数字需 A/B 复核 |

**D 级（传闻/聊天/未署名截图）不进入正文**；只能放“待核实线索”，且不得作为结论。

## 3. 一条证据要带什么

```json
{
  "id": "SRC09",
  "name": "山东海化 2025 年年度报告",
  "url": "https://...",
  "grade": "A",
  "date": "2026-03-21"
}
```

正文引用时，读者应能回答：

- 谁说的？（机构/文件）
- 什么时候？（数据日期）
- 说的什么口径？（产能/产量/集团/单厂）
- 原文在哪？（URL）

**没有 URL 的来源不进 `sources`**；如果只有纸质/内部文件，写“内部资料（不可外链）”，并降为待核实/备注。

## 4. 数字的证据等级

同一个数字，不同来源可信度不同：

| 数字 | 首选 | 次选 | 不要用 |
|---|---|---|---|
| 名义产能 | 年报/环评 | 政府投产报道/协会 | 招商稿、百科 |
| 实际产量 | 年报/统计 | 协会/券商 | 用产能替代 |
| 营收/净利 | 年报/公告 | 主流财经 | 自媒体“预计” |
| 股权/实控人 | 年报/工商/政府 | 企查查（C） | 百科 |
| 资质/交割品牌 | 交易所/发证机关 | 协会名单 | 企业自述 |
| 运距 | 地图测距 | 物流公司 | 感觉 |
| 运费 | 承运商报价/运价指数 | 距离×费率估算 | 把估算写成报价 |
| 价格 | 交易所/行业数据 | 媒体 | 单一客户口径 |

## 5. 冲突处理

发现两个来源数字不一致时，不要“取平均”，写清：

```text
产能：A 来源 680 万吨（2024 年报，含中源并表）；B 来源 500 万吨（阿拉善基地）。
采用：680 万吨作为集团口径；单厂可售货源按 500 万吨另注。
影响：不影响“规模大”的判断；影响“单点保供”的判断。
```

常见冲突：

- **集团 vs 单厂**：集团并表产能 ≠ 某厂可售产能；
- **名义 vs 实际**：产能 110 万吨，2025 年实际产量 80 万吨；
- **旧 vs 新**：2023 年产能 60 万吨，2025 年技改 110 万吨；
- **品牌 vs 主体**：免检品牌属于集团/销售公司，生产主体是另一法人；
- **统计口径**：万吨/年 vs 万吨（累计）；营收亿元 vs 万元。

处理原则：**并列 + 采用 + 影响**。不要静默选一个。

## 6. “待核实”的写法

`待核实` 不是“我不知道”，而是“这是一个具体、可执行的核实项”。

坏写法：

- “财务情况待核实”
- “质量待核实”
- “股权待核实”

好写法：

- “2025 年纯碱板块毛利率未单独披露；需在审厂时索取分部报表/审计报告”
- “新线重质比例未披露；需 3 批首样检测粒度分布与堆密度”
- “与安徽德邦是否同一实控人未确认；需股权穿透图与销售主体说明”

每条“待核实”都应能落到 `verify` 数组，并对应一个动作/证据。

## 7. 候选的最低证据包

每家候选建议至少：

1. 身份：营业执照/年报/官网（A/B/C）；
2. 产能：年报/环评/政府（A/B）；
3. 资质：交易所/发证机关/协会（A/B）；
4. 风险：至少 1 条公开事实或明确“未发现公开风险”；
5. 规格：COA/牌号/客户案例（至少 C，最好 B）；
6. 同源：股权链（A/B）。

只有 1 条 C 级官网的候选，可以进“长名单”，不建议进“短名单”。

## 8. 风险证据的写法

```json
{
  "company": "双环科技",
  "type": "财务",
  "category": "财务",
  "fact": "2025 年归母净利 -153 万元；2026H1 预亏 0.55–0.85 亿元",
  "impact": "连续亏损，供应稳定性/账期需重点评估",
  "source_id": "SRC23",
  "status": "已公开"
}
```

要求：

- `fact` 是事实，不是评价；
- `impact` 是影响，不是重复事实；
- 时间/数字尽量具体；
- 行业风险（价格/供给）与企业风险分开；
- 处罚类写清机关/文号/日期（有则写）。

## 9. 证据等级与页面呈现

- HTML/Excel 在每个候选和来源处显示 A/B/C；
- C 级来源用琥珀色/提示，不隐藏；
- `待核实` 用琥珀色状态，不与“已公开”混排；
- 报告结尾写“数据缺口”：缺什么、为什么缺、下一步怎么补。

## 10. 常见错误

| 错误 | 为什么错 | 修正 |
|---|---|---|
| 用百科写产能 | C 级，可能过期/宣传 | 找年报/环评 |
| 用招商稿写“已投产” | 可能只是签约/开工 | 找政府投产报道/公告 |
| 用 2024 数据不标日期 | 读者误当当前 | 每个数字带日期/口径 |
| 把“规划”写成“在产” | 供给判断失真 | 标“规划/在建/在产” |
| 把“集团”写成“工厂” | 可售货源高估 | 锁定厂区/销售主体 |
| 把“未披露”写成 0 | 数据失真 | 写 `未披露`/`—` |
| 来源互相转载 | 不是独立验证 | 追原始来源 |
| 只写结论不写来源 | 无法复核 | 每条关键数字加 source_id |

## 11. 交付时的证据说明（模板）

```text
数据截止：2026-10-19
证据等级：A=公告/政府，B=协会/券商/主流媒体，C=官网/百科
本报告共 N 条来源；其中 A x 条、B y 条、C z 条。
主要缺口：
1) 某厂 2026 年实际产量未披露；
2) 某集团与某公司的销售主体关系待核；
3) 新装置重质比例缺少连续 3 批 COA。
下一步：审厂/取样/股权穿透/询价。
```

> 记住：**证据等级不是装饰，是读者决定“信多少、还缺什么”的工具。**
