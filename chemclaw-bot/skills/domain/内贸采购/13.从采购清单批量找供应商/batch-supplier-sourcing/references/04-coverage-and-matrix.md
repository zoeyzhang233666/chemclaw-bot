# 04 覆盖度、跨物料与稀缺判定

## 1. 三个计数器

对每个物料（第 i 行）统计：

| 指标 | 定义 | 用途 |
|---|---|---|
| `candidate_count` | 有关系的企业数（含未证实） | 说明“检索广度” |
| `degree_adv` | **厂家级（S/P/G）且已证实（●）** 的家数 | **主指标**：能不能比价 |
| `degree_adv_achievable` | 加上“可达”（确认后即可成立）的家数 | 判断“值不值得去谈” |
| `trader_degree` | 贸易商/集成商已证实的家数 | 单独看渠道层 |

> 只有 `degree_adv` 决定物料的风险等级。贸易商再多，也不能把“单一来源厂家”变成“多源”。

## 2. 风险分档

```
degree_adv == 0                  → 无厂家覆盖      （P0）
0 < degree_adv <= 2              → 厂家单一/不足   （P1）
degree_adv > 2 且 direct < 2     → 规格或证据不足  （P1）
其余                              → 覆盖充分        （ok）
```

阈值在 `assets/rules.json → scarcity_thresholds.few_adv`（默认 2）。原料标准化程度高、金额大的品类，建议把 `few_adv` 提到 3。

## 3. 企业侧：覆盖比与可靠性

```
覆盖比 = 该企业当前覆盖的物料行数 ÷ 清单总行数
可靠性 = 覆盖度分（direct 100 / partial_spec 45 / disclose 40 / dist_only 60 / not_listed 0）
        × 身份权重（S 1.0 / P 0.6 / G 0.5 / T 0.4 / I 0.5 / U 0.1）
```

**为什么 `dist_only` 的分（60）比 `partial_spec`（45）高？** 因为“确定有渠道但只能从贸易商拿”在短期执行上比“厂家有产品线但规格不明”更确定。但在**厂家覆盖**口径里 `dist_only` 不计分——两个口径分开算，不要混。

**可靠性不是商务评分**。它只回答“这条信息有多硬”，不回答“这家值不值得签”。后者还要看价格、账期、距离、服务、产能余量。

## 4. 跨物料企业（打包谈判对象）

```python
multi = [企业 for 企业 in candidates if 当前覆盖物料数 >= 2]
```

排序：`当前覆盖数 desc → 可达覆盖数 desc`。

输出时同时给两列：

- **已证实覆盖**（● 的集合）——能写进合同的
- **可达覆盖**（含 ◐/○）——需要确认的

**谈判要点必须写清“签约主体”**：一家集团常有多个子公司各自持有许可证（范例里三友化工的氯化钙在“志达钙业”，纯碱在母公司）。合同主体搞错，等于白谈。

## 5. 覆盖度的“可信度衰减”

同一个物料，`direct` 的可靠程度也分三档：

| 情形 | 处理 |
|---|---|
| 许可证载明该产品**和规格** | 最强（A 级） |
| 年报给出该产品**产量/销量数字** | 强（a 级） |
| 年报只列产品名、无数字 | 降为 P + `partial_spec` |
| 许可证只写“硫酸 4,800 t/a”但清单要硫磺 | 只能 `disclose`（原料 ≠ 产品） |

## 6. 矩阵的两个视角

**物料 → 企业**（回答：这个物料谁能供）

```
行 = 物料，列 = 企业，格 = 覆盖度符号
右侧三列：候选数 / 厂家数 / 风险判定
```

**企业 → 物料**（回答：这家能供多少）

```
行 = 企业，列 = 物料，格 = 覆盖度符号
右侧三列：当前覆盖 / 可达覆盖 / 覆盖比
```

两张表是同一份 `links` 的转置，**必须由同一份数据生成**，避免两份表互相矛盾。

## 7. 空缺（空白格）的语义

| 符号 | 含义 |
|---|---|
| 空白 | 本轮未评估该组合 |
| × | 有 A/a 级证据显示该企业**不做**这个产品 |

两者不能混用。空白是“不知道”，× 是“知道不做”。报告里如果大面积空白，说明候选池太小——应扩充检索而不是把空白当 × 。

## 8. 稀缺物料的四类成因与对策

| 成因 | 识别信号 | 对策 |
|---|---|---|
| 真·寡头 | 全国产能集中在 2–3 家（如天然碱纯碱） | 接受单一来源 + 长约锁量 + 备选进口 |
| 规格特殊 | 片碱 ≥99%、50% 双氧水、32% 氯化钙溶液 | 找“做液体/固体两条线”的厂家；必要时改规格 |
| 本轮检索不足 | 大路货却 0 家（甘油、柠檬酸） | 换检索源：排污许可、环评批复、协会名录、交易所名录 |
| 清单本身有问题 | 名称残缺（“重酸”）、数量为 0 | 先澄清，不找人 |

## 9. 建议的候选数量

| 物料金额占比 | 建议厂家数 | 说明 |
|---|---|---|
| > 30% | ≥ 3 | 必须能形成价格竞争 |
| 10–30% | ≥ 2 | |
| < 10% | ≥ 1 + 1 备选 | 可接受单一来源但要有替代方案 |

## 10. 复算示例（范例项目）

```
P02 烧碱 32%液碱
  候选 8 家：海化●、华泰●、嘉化●、上海氯碱◐、三友◐、索普◐、中盐常化○、贸易商◆
  degree_adv      = 3 家已证实（海化/华泰/嘉化）  → 但 direct 只有 3 家
  → 风险判定：覆盖充分？否 → 实际为“规格或证据不足”档
```

**注意**：`degree_adv` 统计的是“有关系的厂家”，`direct` 统计的是“已证实可直供”。范例里 P02 的判定之所以不是“覆盖充分”，正是因为只有一部分是 `direct`——这是刻意的，因为“有产品线”和“能按 32% 液碱稳定交货”是两件事。
