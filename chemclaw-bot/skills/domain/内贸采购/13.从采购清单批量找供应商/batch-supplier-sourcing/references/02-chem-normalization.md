# 02 化学标准化：名称、CAS、浓度、单位

## 1. 为什么必须标准化

同一份清单里常常同时出现：`纯碱`、`碳酸钠`、`soda ash`、`重质纯碱`、`Na2CO3`。它们可能是 1 个物料（不同浓度/形态算不同品规），也可能是 3 个不同采购项。**不标准化就没法算覆盖度，也没法把同一家厂的报价横向比。**

## 2. 三层匹配

```
第 1 层：精确名 + 别名（去空格/标点/全角半角）
第 2 层：CAS（先做校验位校验，再反查字典）
第 3 层：模糊（只在 1、2 层失败时用，且结果必须进“待确认”，不得直接采用）
```

`MaterialsDict.match_name()` 的实现要点：

- 别名表来自 `assets/materials-reference.json` 的 `aliases`（含英文、俗名、旧称）。
- 采用**最长别名优先**：`氯化钙溶液` 命中就不该再命中 `氯化钙`；`片碱` 优先于 `碱`。
- 同一 CAS 的不同形态（`纯碱` / `纯碱(轻质)` / `纯碱(重质)`）**不算歧义**，按 `form` 字段区分。

## 3. CAS 登记号校验

```python

    """CAS 校验位 = Σ 各位数字 × (位数 - 位置)，mod 10，等于最后一位。"""
```

例：`107-21-1` → `1*1 + 0*2 + 7*3 + 2*4 + 1*5 = 39` → `39 % 10 = 9 ≠ 1` … 实际正确校验方式：

```
对去掉连字符后的前 n-1 位，从右往左编号 1..n-1，
校验位 = Σ (digit_i × i) mod 10
107-21 → 从右：1(×1) + 2(×2) + 7(×3) + 0(×4) + 1(×5) = 1+4+21+0+5 = 31 → 31 % 10 = 1 ✅
```

**规则**：

- 校验失败 → **P0**，问题写“CAS 校验位不符，请核对（常见错写：107-20-1 / 107-21-1）”。
- 校验通过但与名称不符 → **P0**，冲突项。
- **绝对禁止**“自动纠正为最接近的 CAS”。客户必须自己确认，因为错的 CAS 会一路错到报关和 MSDS。

## 4. 浓度与形态（`form`）

`form` 是比 `name` 更关键的字段。清单里 32% 液碱和 99% 片碱是两种商品：

| 形态写法 | 标准化 | 备注 |
|---|---|---|
| `32%液碱`、`液碱32`、`32%`、`NaOH 32%` | `32%液碱` | 液碱通常 30–32% |
| `50%液碱` | `50%液碱` | 需保温运输，冬季易结晶 |
| `片碱`、`固碱`、`99%片碱` | `片碱` | 片碱≥99%，与液碱是两个 SKU |
| `27.5%`、`35%`、`50%`（双氧水） | 保留原值 | 许可证常按“折 27.5% 计”报产能 |
| `二水`、`无水`、`球状`、`片状`（氯化钙） | 保留 | 二水 74%、无水 94% 以上 |
| `重质`、`轻质`（纯碱） | 保留 | 密度不同，玻璃行业多用重质 |

形态对不上 → 覆盖度最高 `partial_spec`，理由必须写“形态/浓度与清单要求不一致，需确认”。

## 5. 单位标准化

| 输入 | 标准 | 系数 |
|---|---|---|
| 吨 / t / 公吨 / MT | `t` | 1 |
| 千克 / kg / 公斤 | `t` | 0.001 |
| 克 / g | `t` | 1e-6 |
| 立方米 / m³ / 方 | `m³` | 1 |
| 升 / L / 升装 | `m³` | 0.001 |
| 桶 / 件 / 袋 / 包 / 车 / 批 | 需净重 | 无法折算 → P1 |

**桶装必须追问净重**。范例里“甘油 8 桶、250kg/桶”：

```
8 桶 × 250 kg = 2000 kg = 2 t      ← 正确
8 桶 × 12（凭空假设）= 96 t         ← 错误，必须避免
```

若清单没写净重，问题写成：“单位『桶』需确认单位净重，按 250kg/桶 计为 2 t，请确认”。

## 6. 危险属性

危险属性来自字典的 `hazard` 字段（GB 12268 危险货物品名表口径）：

| 物料 | 危险属性 |
|---|---|
| 烧碱（液碱/片碱） | 第 8 类 腐蚀性 |
| 双氧水（27.5%/35%/50%） | 第 5.1 类 氧化性 + 第 8 类 |
| 硫酸 | 第 8 类 |
| 硫磺 | 第 4.1 类 |
| 硼砂 | 第 6.1 类（生殖毒性） |
| 纯碱、氯化钙、工业盐、乙二醇 | 非危险货物（乙二醇按 GB 12268 不列，但属有害液体） |

清单原文写法（`hazard_raw`）单独保留，因为客户可能写错——**报告要能指出客户写错了**，而不是跟着错。

## 7. 字典的维护

`assets/materials-reference.json` 目前覆盖 95 种大宗化工/基础化学品。扩充规则：

1. 新物料必须有：`key`（英文小写下划线）、`name`（中文标准名）、`cas`（校验通过的）、`aliases`（≥2 个别名）
2. `forms` 列出该物料的常见商品形态
3. `families` 写明所属“装置族”（用于判断跨品种供应的合理性，例如纯碱—氯化铵同属联碱装置）
4. 不确定的字段留空，**不要编**

字典没命中时不要硬猜：`status=unrecognized` + P0 问题，是最诚实也最省事的选择。
