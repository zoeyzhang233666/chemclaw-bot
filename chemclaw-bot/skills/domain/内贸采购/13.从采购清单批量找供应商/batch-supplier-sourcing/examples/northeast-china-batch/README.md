> 采购清单的品名、数量、用途、交付地均为虚构（含 8 种故意制造的脏数据）；所有企业结论都来自公开可核验渠道，逐条附链接与原文摘录。

## 这份范例演示了什么

### 1. 清单解析与标准化

21 个有效物料行（源表 30 行，含标题行/空行/合计行），覆盖：

- 6 个主料：纯碱（重质）、烧碱（32% 液碱）、氯化钙（二水片状）、双氧水（27.5%）、乙二醇（聚酯级）、工业盐
- 8 个同族形态：双氧水 35%/50%、片碱 99%、氯化钙溶液 32%、纯碱轻质、烧碱（重复行）、氯化钙（数量为 0）等
- 7 个辅料：甘油、硫磺、硫酸、柠檬酸、硼砂、乙二醇（CAS 错写）、重酸（无法识别）

### 2. 8 种脏数据的处理（都不猜）

| 行 | 问题 | 判定 | 处理 |
|---|---|---|---|
| P13 `纯碱 99.2%` | 单位 `-` | blocked / P0 | 提问“请改为吨/千克，或给出净重” |
| P21 `氯化钙` | 数量 0 | blocked / P0 | 提问“补齐需求或删除该行” |
| P19 `乙二醇` | CAS 写成 107-20-1 | conflict / P0 | 校验位失败，提问“以 MSDS 第 3 节为准” |
| P20 `重酸` | 名称无法识别 | unrecognized / P0 | 提问“补充标准化学名/CAS/MSDS” |
| P10 `甘油` | 8 桶 | ok + P1 | 提问“单位净重是多少，按 250kg/桶计 = 2 t” |
| P11 `双氧水(50%)` | 未填 CAS | ok + P1 | 按字典补 7722-84-1 并请确认 |
| P12 `烧碱(片碱)?` | 名称残缺 | ok + P1 | 命名字典，提醒“品名带问号” |
| P18 `烧碱?碱?` | 疑似与 P12 重复 | ok + P2 | 标 `dup_of`，问“是否合并统计” |

### 3. 厂家与贸易商的分离

| 身份 | 数量 | 例子 |
|---|---|---|
| S 生产厂家 | 14 | 唐山三友、山东海化、博源化工、苏盐井神、中盐昆山、华泰化工、嘉化能源、中盐常化、上海氯碱、索普新材料、卫星化学、古雷石化、华鲁恒升、齐翔腾达 |
| U 未证实 | 4 | 3 个“待补厂家”占位（甘油/柠檬酸/硼砂）+ 1 个示例贸易商 |

**反例（防伪阳性）**：

- `齐翔腾达 × 乙二醇` → `not_listed`：年报产品清单（甲乙酮/顺酐/MMA/环氧丙烷…）**没有**乙二醇。企业很强，但与清单无关。
- `区域贸易商（示例）× 氯化钙` → `dist_only`：只有口述“我们代理三友/海化”，无授权书、无许可证 → 不进比价名单。

### 4. 跨品种覆盖（打包谈判对象）

| 企业 | 已证实覆盖 | 说明 |
|---|---|---|
| 山东海化 | 7 个物料 | 纯碱、烧碱、氯化钙、双氧水三规格、氯化钙散装 |
| 三友化工 | 5 个物料 | 纯碱、烧碱、氯化钙、工业盐、纯碱轻质 |
| 苏盐井神 | 2 个物料 | 纯碱、工业盐 |
| 卫星化学 | 2 个物料 | 乙二醇（含 CAS 错写行） |

### 5. 最硬的一条证据

山东海化 2025 年年报披露的**安全生产许可证**：

> 氢氧化钠 30 万t/a …… 双氧水(折合27.5%计，含27.5%、35%、50%三种规格) 20 万t/a（氯碱树脂公司）

这是极少数把**产品规格**写进许可证的公开材料，可以直接把 27.5%/35%/50% 三行都判为 ●。

### 6. 覆盖不足的物料（缺口清单）

- **无厂家覆盖（11 项）**：片碱 99%、氯化钙溶液 32%、硫磺、硫酸、柠檬酸、硼砂、甘油、重酸等
- **厂家单一（6 项）**：双氧水 27.5%/35%/50%、乙二醇、纯碱轻质、氯化钙散装
- **规格或证据不足（3 项）**：纯碱重质、烧碱 32% 液碱、乙二醇聚酯级

> 注意：这里的“无覆盖”是**本轮公开检索的结论**，不代表市场上没有。处理动作见 Excel 第 10 表 G 行。
