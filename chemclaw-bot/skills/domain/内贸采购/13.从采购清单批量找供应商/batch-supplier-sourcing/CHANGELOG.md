# CHANGELOG

## v1.0.0 — 2026-10

首个公开版本。

### 新增

- **清单解析**（`lib_ingest.py`）：表头自动识别、多 sheet、CSV 编码回退（utf-8-sig → gb18030）、合并单元格与重复行处理。
- **化学标准化**（`lib_common.py` + `assets/materials-reference.json`）：95 种大宗/基础化学品的标准名、CAS、别名、商品形态、危险属性；CAS 校验位校验；最长别名优先匹配。
- **歧义提问生成器**：15 种脏数据形态 → P0/P1/P2 分级问题，含“问什么/为什么问/多久回”。
- **厂贸分离与证据分级**（`references/03`）：身份 S/P/G/T/I/U、证据 A/a/B/C/D/E、覆盖度 direct/partial_spec/disclose/dist_only/not_listed。
- **覆盖矩阵**（`lib_match.py`）：物料侧计数器、企业侧覆盖比、可靠性排序、跨物料企业、稀缺物料判定。
- **交互式 HTML**（`lib_html.py`）：单文件无依赖；可编辑物料表 + localStorage 留存 + CSV 导出；双向矩阵切换；按身份/省份/覆盖数/危化品过滤；点格子弹证据抽屉；一键生成 RFQ（复制/下载）。
- **13 表 Excel**（`lib_excel.py`）：封面 / 物料标准化 / 待确认 / 候选供应商 / 双向矩阵 / 多物料 / 稀缺与风险 / 证据明细 / 危险与监管 / 询价与核验 / 来源库 / 方法与字段映射。
- **校验器**（`validate_project.py`）：引用完整性、证据等级规则、U 级主体误判为厂家、证据—物料绑定、可达度不超过覆盖度。
- **完整范例**（`examples/northeast-china-batch/`）：模拟采购清单（30 行，含 8 种故意制造的问题）× 真实可核验公开企业信息（18 家企业、41 条证据、62 条关联）。

### 设计取舍

- **不做“推荐”**：只给候选池、覆盖判定与证据。没有价格、账期、服务评分，这些必须进商务流程。
- **不做“自动纠正”**：CAS 校验失败只报警不修改；单位无法折算只提问不换算。
- **允许“待补”占位**：`U` 级占位行保证“没查到”这件事本身被记录并进入缺口清单，而不是被悄悄略过。
- **两套计数器**：`degree_adv`（厂家）与 `trader_degree`（贸易商）分开，避免渠道冒充产能。

### 已知限制

- 字典仅覆盖 95 种常见化学品的常见形态；特殊牌号需扩充 `assets/materials-reference.json`。
- 不联网检索；企业与证据需由使用者/Agent 调研后填入 `project.json`。
- PDF/图片清单需先转表（`references/01` §5）。
- 覆盖度是“信息强度”，不等于商务可行性。
