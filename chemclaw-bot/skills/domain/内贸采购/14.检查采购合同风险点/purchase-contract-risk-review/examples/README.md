# 示例说明：两份合同，同一套方法

本目录用两份**风格不同、品类不同**的合同证明：Skill 不依赖某个合同模板。

| 目录 | 品类 | 合同类型 | 我方身份 | 条款数 | 风险数 | 主要看点 |
|---|---|---|---|---|---|---|
| `液碱32采购合同演示/` | 32% 工业液碱（危险化学品） | 框架合同 | 买方 | 47（含附件行） | 36 | 质量异议期、运输责任、吨桶押金、付款、危险信息传递、年末补货条款 |
| `非危化品-表面活性剂示例/` | 异构十三醇聚氧乙烯醚（非危化品） | 框架合同 | 买方 | 17 | 8 | 指标「待商量」、价格联动无锚、账期从开票起算、责任上限 |

两份合同对照可以看出：同一个检查框架下，**危化品合同**多出资质、运输、危险信息传递三块；**非危化品合同**则把重心放在指标、价格联动、账期与责任上限上。方法相同，重点随标的变。

## 一、液碱演示案例

### 1.1 文件清单

| 文件 | 说明 |
|---|---|
| `虚构演示合同-工业用32%液碱采购合同.docx` | **虚构演示合同**原件（10 页，正文 4 页 + 附件 5~7 页 + 签署页） |
| `contract.json` | 合同结构（14 个章节、47 个条款锚点） |
| `review.json` | 审查结果（36 条风险、19 条法规核对、38 条待确认问题） |
| `合同风险审查-交互页面.html` | 交互式审查页面：左原文右风险，主题筛选，点击定位，状态与备注 |
| `合同风险审查-风险事项与问题清单.xlsx` | 10 个工作表：条款索引 / 风险总表 / 原文引用 / 法规核对 / 三张清单 / 统计 |

### 1.2 合同是怎么设计的（为什么它有分析价值）

这份演示合同**不是随机写的**，而是把化工品采购中高频出现的条款风险集中在一份合同里，每一处都能对回条款：

| 条款 | 设计意图 | 对应风险 |
|---|---|---|
| 1.1 浓度 32% + 附件一「≥30.0%」 | 口径冲突 | R01 |
| 1.2「或乙方企业标准」「出厂合格即视为合格」 | 质量豁免口 | R03 |
| 1.3 / 3.2「3 日内异议」 | 异议期过短 | R04 |
| 3.3 已卸罐不退换 | 救济封闭 | R04 |
| 2.1「7 个工作日」+ 检修/物流紧张顺延 | 交付时间被卖方控制 | R08 |
| 2.3 / 2.4 运输责任全推承运人 | 风险错配 | R09 / R10 |
| 4.2 卖方单方调价、提前 3 日通知 | 价格单向 | R15 |
| 5.1 预付款 30% 无担保 | 资金风险 | R17 |
| 5.3 年末补足货款 | 实质承诺采购 | R20 |
| 5.4 账户变更微信通知即可 | 付款欺诈 | R19 |
| 6.2 / 6.3 吨桶押金「视情况退还」 | 押金悬空 | R11 / R12 |
| 7.2 / 7.4 质量违约金 2% 封顶、总责任 5% | 责任限缩 | R27 |
| 7.3 不得以质量争议拒付 | 抗辩权排除 | R28 |
| 8.1 把检修、价格波动写成不可抗力 | 商业风险伪装 | R29 |

### 1.3 审查结论摘要

36 条风险中：极高 3 条、高 14 条、中 13 条、低 6 条；其中「缺失」20 条、「表述不清」16 条。最需优先处理的是：

1. **5.3 年末补足框架量货款**——可能被解释为约 230 万元/年的最低采购承诺；
2. **5.4 账户变更凭电话/微信通知**——付款欺诈损失由买方承担；
3. **2.4 运输责任全部推给承运人**——但甲方作为接收与卸车单位仍有监管义务；
4. **6.2 吨桶押金**——按 2,000 只测算约 60 万元，退还条件写「视情况」；
5. **1.3 / 3.2 / 3.3 组合**——3 日异议期 + 卸罐后不退换，质量救济被双重削弱。

### 1.4 怎么复现

```bash
# 重新生成演示合同
python scripts/build_contract_docx.py --dir examples/液碱32采购合同演示 --out examples/液碱32采购合同演示/虚构演示合同-工业用32%液碱采购合同.docx

# 核对页码锚点（需要 LibreOffice Kit + pymupdf/pypdf）
python scripts/paginate_contract.py --docx examples/液碱32采购合同演示/虚构演示合同-工业用32%液碱采购合同.docx --dir examples/液碱32采购合同演示

# 生成交付物
python scripts/build_review_html.py --dir examples/液碱32采购合同演示 --out examples/液碱32采购合同演示/合同风险审查-交互页面.html
python scripts/build_review_xlsx.py --dir examples/液碱32采购合同演示 --out examples/液碱32采购合同演示/合同风险审查-风险事项与问题清单.xlsx
```

### 1.5 重要声明

**本案例合同为虚构演示合同**，甲乙方名称、地址、金额、条款均为编写，不对应任何真实企业或交易。审查结论仅用于演示业务审查方法，**不构成法律意见**。

法规与标准状态核对日期为 **2026-10-19**，正式使用前请通过国家法律法规数据库与全国标准信息公共服务平台重新核对。

## 二、非危化品对照案例

| 文件 | 说明 |
|---|---|
| `contract.json` / `review.json` | 17 个条款、8 条风险 |
| `合同风险审查-交互页面.html` | 与液碱案例同一渲染器产出 |
| `通用渲染模板示例.html` | 用 `render_html.py`（通用版渲染器）产出，证明换一份数据即可换一份页面 |

这个案例刻意写成「比常见模板好一些」的合同（检验期 15 日、有隐蔽瑕疵条款、管辖对我方有利），用来演示：**审查不是找茬清单，而是要找出真正影响我方的那几条**。

## 三、示例与真实审查的差别

| 项目 | 演示合同 | 真实合同 |
|---|---|---|
| 原文来源 | 由 JSON 生成 DOCX，页码由脚本校正 | 原件 PDF/Word，页码取自原件 |
| 证据 | 条款锚点齐全 | 附件、订单模板、资质文件都要拆锚点 |
| 法规核对 | 已核 2026-10-19 状态 | 每次审查重新核 |
| 交付 | HTML + Excel | 同上，另可加供应商函件 |
