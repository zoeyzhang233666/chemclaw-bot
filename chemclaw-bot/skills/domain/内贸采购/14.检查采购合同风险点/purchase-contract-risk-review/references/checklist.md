# 采购条款检查清单（10 主题 · 化学品类采购）

> 用法：每审一个主题，就沿「写了什么 → 缺什么 → 哪里不清楚 → 业务后果 → 待确认」五步走一遍。
> 本清单是**检查提示**，不是标准答案；不同化工品、不同采购模式要按实际删改。
> 每条「常见漏洞」只是提示词，**不能直接写成合同事实**。

---

## 主题 1　质量（product name / spec / concentration / grade / standard）

| 检查点 | 要读到什么 | 缺失标记条件 |
|---|---|---|
| 产品名称与俗称 | 书面名称 + 俗名（如「氢氧化钠」「液碱」「烧碱」）是否同时写明，避免歧义 | 只写商品名/代号，无化学名 |
| 规格与浓度 | 质量分数/体积分数、是以 NaOH 计还是以溶液计、有无允差 | 只有单值「32%」无允差；允差与附件不一致 |
| 等级 | 优等品/一等品/合格品，或特定用途等级 | 写「不分等级」却引用分级标准 |
| 执行标准 | 标准编号 + **年份** + 是否现行 | 只写「国标」「按企业标准」；引用已废止版本 |
| 指标上下限 | 主含量上下限、杂质项（如碳酸钠、氯化钠、铁）限值 | 附件指标格留空；只写上/下限之一 |
| 检验方法与版本 | 每项指标的检测方法编号与年份（如 GB/T 4348.1） | 只写「按 GB/T 4348 系列」无分部与年份 |
| 判定依据 | 以谁的检验结果为准、冲突时怎么处理 | 「以卖方出厂检验为准」且无复检路径 |
| 第三方检测 | 是否约定第三方机构、费用分摊 | 有异议机制但无机构与费用约定 |

**常见漏洞（提示）**：正文浓度与附件下限口径不一；「或双方认可的企业标准」变成质量豁免口；杂质项留空被解释为不限制。

## 主题 2　数量（quantity / tolerance / tail）

| 检查点 | 要读到什么 |
|---|---|
| 总量 | 确定数量，或「预计/约 X 吨」 |
| 框架量性质 | 「约」是否构成最低采购承诺？未达量是否补款？ |
| 单批/单车允差 | ±% 或 ±kg |
| 最小起送量 | 单次订单下限 |
| 尾差处理 | 最后一车不足如何处理 |
| 超量交付 | 是否接收、是否付费、按什么价 |
| 短量补供 | 欠供如何补、是否补偿 |

**缺失标记**：「合同未约定每批交付允差」「未约定超量交付是否付费」。

---

## 主题 3　验收（acceptance / inspection / dispute period）

| 检查点 | 要读到什么 |
|---|---|
| 验收标准 | 引用哪个标准/附件 |
| 抽样方法 | 每车/每桶/混合样；取样量、封样、留样期限 |
| 检验机构 | 自检 / 指定第三方 / 仲裁检验 |
| 复检路径 | 异议后几日内复检、复检期间是否付款/是否停用 |
| 异议期限 | 天数 + **起算点**（到货/卸货完成/过磅/入库） |
| 隐蔽瑕疵 | 卸罐、混罐、使用后才暴露的问题如何处理 |
| 逾期异议后果 | 「视为验收合格」的效力（提示法务判断） |

**常见漏洞（提示）**：3 日异议期 + 卸罐后不退换 = 质量救济被双重削弱。

---

## 主题 4　交付（delivery time / place / transport / risk）

| 检查点 | 要读到什么 |
|---|---|
| 交货时间 | 订单确认后 X 个工作日/自然日；以哪一个为准 |
| 顺延条件 | 哪些情形可顺延、是否需书面通知/证明、是否设上限 |
| 交货地点 | 完整地址 + 卸车条件（车位、卸车泵、接液设施） |
| 运输方式 | 自提/送货；谁安排车辆、谁承担运费 |
| 风险转移 | 到达/接管/卸完/过磅——需明确定义 |
| 途中损失 | 泄漏、洒漏、超载、事故责任归属 |
| 备选供应 | 断供时的替代安排 |

---

## 主题 5　价格与税费（price / tax / invoice / price adjustment）

| 检查点 | 要读到什么 |
|---|---|
| 计价单位 | 净重/毛重；按实际质量还是折百（按 100% 有效成分折算） |
| 价格构成 | 是否含运费、装卸、包装；押金与清洗费是否另计 |
| 暂定价与订单价 | 冲突时以哪个为准 |
| 调价机制 | 基准（指数/区域报价/第三方资讯）、幅度上限、通知期、买方选择权 |
| 税率与开票 | 专票/普票、开票时限、品名、先票后款还是先款后票 |
| 税率变动 | 风险由谁承担 |

---

## 主题 6　付款（prepayment / payment nodes / credit / other obligations）

| 检查点 | 要读到什么 |
|---|---|
| 预付款 | 比例/金额、计算基数、是否需保函、如何抵扣、未交货如何退 |
| 付款节点 | 到货验收后 X 日 / 月度对账 |
| 账期 | 30/60/90 天，起算点 |
| 质保金 | 比例、退还条件 |
| 抵扣权 | 能否从后续货款扣质量索赔 |
| 拒付权 | 「不得以质量争议拒付」这类表述 |
| 账户信息 | 收款账户变更的验证机制（防范付款欺诈） |
| 其他付款义务 | 年末补量付款、最低采购额、押金 |

---

## 主题 7　包装、容器与计量（packaging / ton-bag deposit / cleaning / weighing）

| 检查点 | 要读到什么 |
|---|---|
| 包装形式 | 罐车/吨桶/IBC/编织袋；规格（如 1,000 kg/桶） |
| 包装标志 | 危险品标志、批次、生产日期 |
| 押金 | 只数、单价、总额、退还条件与时限、破损扣款 |
| 空桶返还 | 时限、批量、运费、超期占用费 |
| 罐车清洗 | 频次、记录、残液处理、换品种运输的清洗证明 |
| 装卸分工 | 装车/卸车由谁操作、谁监护 |
| 计量 | 以谁的磅单为准、复磅权、超差处理、卸前/卸后称重 |

---

## 主题 8　违约责任（breach / liquidated damages / liability cap）

| 检查点 | 要读到什么 |
|---|---|
| 迟延交付 | 违约金比例、起算、上限、解除权、是否赔偿停产损失 |
| 质量违约 | 违约金、是否封顶、是否排除其他损失赔偿 |
| 迟延付款 | 违约金比例、上限、停供权 |
| 双向对等性 | 双方违约金比例是否一致 |
| 责任上限 | 总责任 cap 比例、是否有例外（故意/重大过失/人身/安全事故） |
| 排除条款 | 「不得以质量争议拒付」「不承担停产损失」 |

**注意**：违约金高低是否合理、责任上限是否有效、格式条款是否受限制，都要交法务判断；业务侧只描述「与我方损失规模的匹配度」。

---

## 主题 9　不可抗力、退换货与争议解决

| 检查点 | 要读到什么 |
|---|---|
| 不可抗力定义 | 是否包含检修、计划停车、原料采购困难、价格波动（这些属于商业风险） |
| 通知与证明 | 多长时间内通知、需提供什么证明 |
| 解除与善后 | 持续多久可解除、已付预付款如何退还 |
| 退换货 | 已卸罐/已使用的货能否退换 |
| 争议解决 | 仲裁机构全称、仲裁地、规则版本 / 或管辖法院 |
| 适用法律 | 是否明示 |
| 送达地址 | 是否有送达地址条款 |
| 争议期间履约 | 是否继续履行无争议部分 |

## 业务影响怎么写（正反例）

**反例 1**：`预付款条款风险较高，建议谨慎。`
→ 问题：没有环节、没有量级、没有判断依据。

**正例 1**：`按 5.1 条，合同签订后 30 日内付 69 万元（2,000 吨 × 1,150 元 × 30%），但合同为框架、以订单为准，预付款基数可能产生争议；且无履约保函、无抵扣规则。若首批未交货，已付资金需另行追偿，同时年度采购计划已锁定。`

**反例 2**：`交货时间不明确。`
→ 问题：没说明「哪句话」导致不明确。

**正例 2**：`2.1 条同时写「7 个工作日内交货」与「具体时间为甲方要求的时间」，两句优先级未定；同条又允许因「检修、装置减量、物流紧张」顺延且「不视为违约」，等于交付时点实质由卖方控制。按产线日均耗碱测算，断供 3 天即需降负荷。`

## 主题取舍

- **食品级/医药级**：加查食品生产许可、GB 2760/药典、GMP 类要求。
- **易制毒/易制爆**：加查购买备案、品种目录、台账与流向报告。
- **剧毒**：加查剧毒化学品道路运输通行证、双人保管。
- **非危化品大宗商品**：可略去主题 10，但保留包装、计量、价格波动与不可抗力。
