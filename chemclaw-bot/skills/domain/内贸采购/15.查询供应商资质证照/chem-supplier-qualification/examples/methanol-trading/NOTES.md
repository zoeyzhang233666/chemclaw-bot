# 对照示例：向贸易商采购甲醇（工业级 ≥99.9%）

## 为什么需要这个示例

主示例是**生产企业**。本示例演示**经营企业（贸易商）**路径，用来证明模板与规则不限品、也不限角色：

| 对比项 | 主示例（30% 过氧化氢） | 本示例（甲醇） |
|---|---|---|
| 供应商角色 | 生产企业 | 经营企业（不带储存） |
| 核心证照 | 安全生产许可证 | 经营许可证 + **上游工厂**生产许可证 |
| 特殊管理类别 | 易制爆（是） | 易制爆（否，全文核对）；易制毒/剧毒待核验 |
| 买方额外义务 | 5 日内流向报备 | 易制毒品购销台账（若列名） |
| 主体 | 真实企业（可核） | **虚构示例**，仅演示路径 |

## 演示要点

1. **许可跟着"活动"走**：贸易商持经营许可证，但真正决定货物合法性的是上游工厂的生产许可证——两头都要核。
2. **经营方式必须与交付方式一致**：许可为"不带储存"，如果实际在自有仓库理货、分装、暂存，就是超范围经营。
3. **否定结论也要有依据**：甲醇判为"不属于易制爆"是因为拿到了 2017 年名录全文并核对；而"剧毒""易制毒"没拿到全文 → 一律 `pending`。
4. **"可以写 / 不能写"**：`assessment.statements` 里明确禁止"甲醇属于易制爆危险化学品"这类常见错误表述。

## 生成

```bash
python scripts/build_all.py examples/methanol-trading/data.json
```

## 如何替换成真实业务

1. `subject` 填真实贸易商（公示系统查询结果 + 信用代码校验）；
2. `certs` 增加 C02（经营许可证，注明经营方式）与 C03（上游工厂生产许可证）；
3. 确认甲醇在**现行**目录与名录中的定位（本示例中标 pending 的项要逐条核完）；
4. 若属易制毒第三类，在 `erp.obligations` 把"购销台账与备案"从"视情形"改为"必须"。
