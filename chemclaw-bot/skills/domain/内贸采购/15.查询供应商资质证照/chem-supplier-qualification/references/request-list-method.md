# 索证清单编制方法（Material To Request）

索证清单是这份底稿**唯一直接产生行动**的产物。目标是：供应商收到后能一次回复齐，而不是来回三轮。

---

## 1. 什么必须进清单

按"没有它就不能证明什么"来倒推，而不是按"常见证照清单"抄。

| 触发 | 必须索取 | 优先级 |
|---|---|---|
| 产品属危险化学品 | 供应商的**生产**或**经营**许可（取决角色） | P0 |
| 产品属易制爆 | 卖方查验购买凭证与流向报备的流程说明；对方是否接入公安系统 | P0 |
| 产品属剧毒 | 购买许可证/购买凭证（买方提供，卖方查验）双向确认 | P0 |
| 产品属易制毒 | 购销台账与备案要求确认 | P1 |
| 任何危险化学品 | 现行版 SDS + 规格书 + 最近一批 COA | P0 |
| 供应商为贸易商 | **实际发货工厂**的安全生产许可证 | P0 |
| 供应商为生产企业 | 自产供货声明（含装置归属） | P0 |
| 跨主体/关联交易 | 签约主体 = 开票主体 = 持证主体声明 | P0 |
| 涉及储存/卸货 | 承运人危货运输资质、车辆与人员证照 | P1 |
| 涉及食品/消毒/药用用途 | 对应专项许可（SC、卫生许可等） | P0（该用途下） |
| 体系认证、荣誉 | 证书编号 + 认证机构（便于线上核验） | P2 |
| 企业整体合规 | 应急预案备案回执；排污许可（如需） | P2 |

> 自动派生：凡 `need = required` 且状态非 `verified` 的证照，渲染时自动补入清单（标 AUTO）。人工清单负责补充"证照之外的资料"（SDS、声明、流程说明）。

---

## 2. 每项必须写三样

1. **为什么必须索取**——挂到本单的具体事实（"当前完全缺失且公开渠道无法确认""经营方式为不带储存，与本次交付需储存不符"），不要写"常规要求"。
2. **要确认的具体问题**——可逐条回答的问句，最好带编号（①②③④）。
3. **出具机关**——让对方知道去找谁开/去哪下载。

反面例子 ❌："请提供相关资质证照。"（对方会给你一堆荣誉证书）
正面例子 ✅：
> R01 危险化学品安全生产许可证（正副本）｜浙江省应急管理厅｜P0
> 理由：生产企业合法供货的核心凭证；当前完全缺失，且无法从公开渠道确认。
> 需确认：① 证载生产地址是否覆盖实际供货装置所在厂区；② 许可范围是否逐条包含「过氧化氢溶液[含量＞8%]」；③ 许可产能与年供货能力是否匹配；④ 有效期是否覆盖合同期与质保期。

---

## 3. 优先级与放行挂钩

- **P0**：未关闭 → **不得下单、不得收货**。采购审批单里应能看到 P0 关闭状态。
- **P1**：卡合同签署/首批发货，可在谈判中并行推进。
- **P2**：档案完善，合作期内补齐；但必须有计划日期。

---

## 4. 从清单到请求函（draft）

`draft.body` 建议结构：

```
主题：<买方> 供应商资质核验 · <产品><规格>采购资料补充请求（记录号 <record_id>）

一、主体与许可（3 个工作日内）    ← P0 证照
二、产品资料（3 个工作日内）      ← SDS/规格书/COA
三、易制爆/易制毒合规（5 个工作日内）← 流程与报备
四、运输（如由贵司安排）
五、我方将提供的材料（对等承诺）   ← 营业执照、经办人身份、用途说明
六、放行条件与后续流程            ← 明确"收到 X 前暂缓下单"
附：我方核验要点（四者一致 / 范围覆盖浓度 / 有效期覆盖合同期）
```

**要点**：
- 写明**具体浓度与数量**，避免对方拿"通用资质"敷衍；
- 对等承诺（我方也给材料）能显著提高回复质量；
- 结尾要写"如资料不一致我们会主动沟通澄清"——降低对方的防御心理，避免其只挑好看的发；
- 不要写"请尽快提供全部资质"，而要写清优先级与时限。

---

## 5. 收件后的处理

| 收到的材料 | 动作 |
|---|---|
| 证照扫描件 | 先按 `ocr-extract-schema.md` 提取字段 → 与公开公示逐字段比对 → 更新 `certs[].status` |
| 带二维码的电子证照 | 扫码/编号到政务服务网核验，截图存 `evidence` |
| 只有图片无编号/被遮挡 | 退回重发（遮挡范围、有效期、编号的扫描件无法核验） |
| 对方回复"我们不需要这个证" | 要求书面说明依据条款；我方另行咨询属地应急部门确认，不得口头接受 |
| 对方提供的证照与主体不符 | 立即转 `mismatch`，暂停下单，要求澄清（关联工厂/更名/代工） |

---

## 6. 台账维护

- 每个 P0/P1 项在 Excel「09 索证清单」有"已取得?"下拉（是/否/部分）；
- 全部 P0 为"是"且证据归档后，才可把 `assessment.grade_code` 从 G2 升到 G1；
- 证照换证后编号变化：保留旧行，新增新行并注明替代关系（`E` 编号重排）。
