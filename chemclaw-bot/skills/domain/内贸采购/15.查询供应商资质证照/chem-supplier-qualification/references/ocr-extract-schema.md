# 上传证照/资料 → 字段提取模板

用于把供应商提供的营业执照、许可证、SDS、认证证书转成可核验的结构化字段。
**提取 ≠ 核验**：提取出的字段只算 A 侧，必须与 B 侧公开来源逐字段比对后才可能变成 `verified`。

---

## 0. 通用提取头（每份材料都要记）

| 字段 | 说明 |
|---|---|
| `file` | 文件名（建议 `<证照类型>_<主体简称>_<版本日期>.pdf`） |
| `doc_kind` | 营业执照 / 危化品安全生产许可证 / 危化品经营许可证 / 危化品登记证 / 体系认证 / SC / 消毒卫生许可 / SDS / COA / 声明函 |
| `scan_quality` | 清晰 / 部分遮挡 / 倾斜模糊 / 黑白复印 |
| `visible_seal` | 是否见红章（见/未见/数码章） |
| `has_qr` | 是否有二维码（有则优先扫码核验） |
| `watermark` | 是否有"仅供XX使用"水印；有则记录用途，判断是否可复用 |
| `extracted_by` / `extracted_at` | 提取人与时间 |
| `red_flags` | 拼接痕迹、字体不一致、编号位数异常、机关名称与属地不符、日期倒置 |

> 遮挡编号、有效期、许可范围的扫描件 → 直接退回重发，不做"推测录入"。

---

## 1. 营业执照

| 字段 | 校验点 |
|---|---|
| 统一社会信用代码 | 18 位；GB 32100-2015 校验码（`qclib.check_uscc`） |
| 名称 | 与合同签约主体逐字一致（含括号全/半角、分公司字样） |
| 类型 | 有限责任公司/股份有限公司…（影响是否有股东会决议） |
| 法定代表人 | 与许可证、授权委托书签署人一致性 |
| 注册资本 / 成立日期 | 与公示系统一致 |
| 住所 | 与许可证生产地址区分 |
| 经营范围 | 记原文；**不作为许可依据**，仅看是否含有"许可项目"字样 |
| 登记机关 / 发照日期 | 属地是否与生产地址一致 |

常见坑：经营范围"化工产品销售（不含许可类化工产品）"不能支持销售危险化学品。

---

## 2. 危险化学品安全生产许可证

| 字段 | 校验点 |
|---|---|
| 证书编号 | 格式如 `（浙）WH安许证字〔20XX〕XXXX`；省别代号须与发证机关一致 |
| 企业名称 | 与营业执照一致 |
| 生产地址 | **必须**覆盖实际供货装置所在厂区（门牌级比对） |
| 许可范围 | 逐条抄录品名 + **浓度/含量限定** + 年产能；确认"过氧化氢溶液[含量＞8%]"在此列 |
| 有效期 | 起止日期；剩余 <180 天预警 |
| 发证机关 | 省级应急管理厅（部分情形应急部） |
| 二维码/查询码 | 优先扫码核验 |

必须在台账里回答的四个问题：**品种是否覆盖？浓度是否覆盖？产能是否够？地址是否就是发货地？**

---

## 3. 危险化学品经营许可证

| 字段 | 校验点 |
|---|---|
| 证书编号 | 含"危化经字"类字样与年份 |
| 经营方式 | **带储存设施 / 不带储存**（甲种/乙种）——与交付方式比对 |
| 经营地址 | 与实际发货/中转地址一致 |
| 许可范围 | 含本产品与形态（如"过氧化氢溶液"） |
| 有效期 | 同上 |

常见坑：许可为"不带储存"，实际在自有仓库中转分装 → 超范围经营。

---

## 4. 危险化学品登记证

| 字段 | 校验点 |
|---|---|
| 证书编号 / 有效期 | 通常 3 年 |
| 企业性质 | 生产 / 使用 / 经营（须与本单角色一致） |
| 注册地址 | 与营业执照一致 |
| 登记品种 | 含本产品 |

---

## 5. SDS（安全技术说明书）

按 GB/T 16483 / GB/T 17519 结构提取：

| 节 | 关键字段 |
|---|---|
| 1 标识 | 产品名称、**版本号与日期**、供应商联系方式 |
| 2 危险性 | GHS 分类（含类别）、象形图、警示词、防范说明 |
| 3 成分 | 主要成分与浓度区间、CAS |
| 7 操作储存 | 储存条件、禁配物、**储存温度上限** |
| 9 理化 | 外观、pH、闪点/自燃温度（如适用）、溶解性、**有效氧/含量** |
| 14 运输 | **UN 编号、运输名称、类项、包装类、海洋污染物** |

比对：SDS 第 2 节分类 vs 目录危险性分类；第 14 节 vs 承运资质类项。

## 6. 体系认证证书（ISO 9001/14001/45001 等）

| 字段 | 校验点 |
|---|---|
| 证书编号 | 到认证机构/认可委系统查询 |
| 认证标准与版本 | 是否为现行版本 |
| 覆盖范围 | 是否含本产品的生产/销售 |
| 有效期 | 三年周期；注意监督审核是否完成（暂停/撤销状态） |
| 认证机构 | 是否具认可资质 |

> 体系认证结论只能写"参考项"，不得替代行政许可。

---

## 7. 声明函类（自产供货声明 / 用途声明 / 授权书）

必备要素：主体全称+统一社会信用代码、声明事项、**具体产品与浓度/数量**、生产装置与地址、有效期、法定代表人签字或公章、日期。
缺任一项 → 视为未提供。

---

## 8. 易制爆购买与流向材料（买方侧）

| 材料 | 内容 |
|---|---|
| 购买身份材料 | 营业执照复印件（盖章）、经办人身份证件、授权委托书 |
| 用途说明 | 品种、数量、用途、使用地点、储存条件 |
| 流向报备回执 | 县级公安机关报备回执/系统截图（含时间戳） |
| 出入库台账 | 日期、批次、数量、领用人、结存 |

---

## 9. 提取结果的落位

| 提取字段 | 写入 data.json |
|---|---|
| 证照基本信息 | `certs[i].no / issuer / valid_from / valid_to / scope` |
| 字段来源 | `certs[i].field_source = "上传扫描件（<文件名>，提取于 <日期>）"` |
| 与公示比对 | `certs[i].crosscheck[]` |
| 不一致点 | `certs[i].discrepancies[]`、必要时 `oddities[]` |
| 无法取得的字段 | 留空 + 进 `request_list` |
