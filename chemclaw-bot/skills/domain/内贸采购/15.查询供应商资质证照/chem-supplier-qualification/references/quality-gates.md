# 质检闸门（Quality Gates）

出稿前逐条打勾。**任何一条 ❌，交付即视为不合格**。
其中可自动化的部分已写进 `scripts/validate.py`（标签：F1–F10 / W1–W4）。

---

## 闸门 1 · 产品定性（G1）

| # | 检查 | 自动化 |
|---|---|---|
| 1.1 | 每个定性结论都写明「目录名称 + 条目号/条款 + 文号 + 适用条件」 | 人工 |
| 1.2 | 浓度/含量已在 `product.spec` 写死，并与目录条目阈值对齐 | 人工 |
| 1.3 | 目录逐项核对表（`classification_checklist`）非空且每项有 note | **W1** |
| 1.4 | 任何"不属于 X"都有目录全文核对依据；没有就写 `pending` | **F5**（禁用表述）|
| 1.5 | 未取得原文的标准（GB 18218、GB 12268 等）标 `pending`，不填猜测数值 | 人工 |
| 1.6 | 用途型管理（食品/消毒/药用）按实际用途判定，不默认适用 | 人工 |

## 快速自检命令

```bash
python scripts/validate.py  <data.json>          # 自动化闸门
python scripts/validate.py  <data.json> --strict  # 连 WARN 也视为不通过
python scripts/build_all.py <data.json>          # 校验 + 出 HTML + Excel
```

## 已知不可自动化项（必须人工）

- 证照真伪（拼接、篡改、PS）——需政务网扫码或致电发证机关；
- 许可范围与实际装置的对应关系——需现场或图纸核对；
- 企业内部资料（SDS、声明函、台账）真实性——需签章与后续审计；
- 地方执行口径（如流向报备时限、园区要求）——需与属地主管部门确认。
