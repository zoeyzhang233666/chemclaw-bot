# 法规与公开源手册（Regulation & Source Playbook）

本文件只回答两件事：**该查哪些制度**、**去哪个官方入口查**。
**它不回答"某个产品属于什么"**——那是每次核验时按目录原文逐条比对得出、写进 `data.json` 的结论。

> 制度会修订、平台会改版。**每次核验前先确认现行有效版本**，并在 `evidence[]` 里登记访问日期与链接。

**每一条结论必须写明**：目录名称 + 条目号/条款 + 文号 + 适用条件。

## B. 供应商侧：许可与证照的制度

| 证照 | 依据 | 发证机关 | 关键要素 |
|---|---|---|---|
| 危险化学品**安全生产许可证** | 《危险化学品安全管理条例》第20条；《危险化学品生产企业安全生产许可证实施办法》（原安监总局令第41号）；各省实施细则（如浙江 2024 版细则） | 省级应急管理厅（部分品种/企业由应急部） | **许可范围（品种+产能）**、生产地址、有效期；编号常见形如 `（浙）WH安许证字〔年〕编号` |
| 危险化学品**经营许可证**（甲种/乙种） | 条例第33条；《危险化学品经营许可证管理办法》（原安监总局令第55号）；浙江对"不带储存经营"实行告知承诺 | 市级/区级应急管理部门 | **经营方式（带储存/不带储存）**、经营地址、许可范围 |
| 危险化学品**登记证** | 条例第67条；原安监总局令第53号 | 省级危险化学品登记办公室 | 登记品种、企业性质（生产/使用/经营）、有效期 |
| 重大危险源**备案** | 条例第25条；GB 18218 | 应急管理部门 | 辨识结论与备案号 |
| **应急预案备案** | 《生产安全事故应急条例》（国务院令第708号） | 应急管理部门 | 备案回执（不是目录页） |
| 危险货物道路运输经营许可 | 交通运输部等令2019年第29号 | 交通运输部门 | 类项覆盖、车辆道路运输证、押运员 |
| 排污许可（涉及生产装置） | 《排污许可管理条例》 | 生态环境部门 | 是否覆盖该装置 |
| 食品生产许可（SC） | 《食品安全法》《食品生产许可管理办法》 | 市场监管部门 | 食品类别是否含"食品添加剂 X" |
| 消毒产品生产企业卫生许可 | 《消毒管理办法》 | 卫健部门 | 生产类别 |
| 工业产品生产许可 | 《工业产品生产许可证管理条例》及现行管理目录 | 市场监管部门 | 产品目录与单元是否覆盖 |

> 生产企业销售**自产**危险化学品通常无需另办经营许可；但若涉及**改变物质状态后销售**（实施指南第三条）或另设经营场所，则需经营许可。这条是最常见的误判点，两个方向都会错。

## D. 公开源查询顺序（A 侧证照 ↔ B 侧公示）

1. **主管部门公示 / 政务服务网电子证照**（最强）：省级应急管理厅"危化品安全生产许可"公示、省市政务服务网电子证照核验（扫码或编号）、市场监管"双随机/许可公示"。
2. **上市公司公告 / 债券募集说明书 / 招股书**：关联方基本情况、资质清单（统一社会信用代码、住所、法定代表人、经营范围最可靠）。
3. **信用中国 / 国家企业信用信息公示系统**：登记状态、行政处罚、经营异常、严重违法失信名单。
4. **认证机构 / 认可委查询系统**：ISO 等体系证书的编号与有效性（防止"拿了过期证书图片"）。
5. **企业官网证书栏目**：只能作为 `pending` 线索；栏目内容与许可证是否一致要单独核。
6. **企业信用信息商业平台（企查查/天眼查等）**：仅作线索，禁止单独作为结论依据。
7. **注销/吊销/处罚公告**：多是 PDF/DOC 附件，要**逐条核对名单**；"不在注销名单"是弱证据，不能证明"现行有效"。

> 记住：多数省份**不逐条公示**许可证授予记录。因此"未检索到"是常态，结论只能是 `no_public` 或 `pending`，并以索证收口。

## E. 交叉核验矩阵（建议）

| 维度 | A 侧（证照/供应商材料） | B 侧（公示/公告） | 判为不一致的情形 |
|---|---|---|---|
| 主体名称 | 营业执照抬头 | 公示系统/上市公司公告 | 名称核心字号或括号形式不同 |
| 统一社会信用代码 | 营业执照 | 公示系统 | 任一字符不同，或校验码不通过 |
| 住所/生产地址 | 营业执照住所 / 许可证生产地址 | 公示/公告 | 门牌、行政区划不一致且无变更说明 |
| 许可品种 | 证载许可范围 | — | 无 B 侧时只能 `pending` |
| 许可产能 | 证载产能 | 年报/公告产能 | 差异大需说明 |
| 经营方式 | 带储存/不带储存 | 实际交付方式 | 交付需要储存但许可为不带储存 |
| 认证有效期 | 证书 | 认证机构查询 | 查询显示暂停/撤销/过期 |

## F. 时效与更新

- 每份 `evidence` 记 `date`（文件日期）与访问日期（写进 `supports` 或 `title` 里）。
- 台账维护周期：季度复审；证照到期前 **180 天**预警；供应商、装置、产品等级任一变更 → 重新核验。
- 制度修订（如目录更新、名录调整）→ 只改 `product.findings` 与 `classification_checklist`，模板不动。
