# AGENTS.md — 就近供应商寻源

当用户提出"帮我找附近的供应商 / 采购 X 的厂家 / 算运距 / 比一比这几家多远 /
这家是工厂还是仓库 / 危化品怎么运"这类需求时，使用本目录的技能。

## 何时启用

- 触发词：找附近供应商、就近采购、供应商寻源、运距、100/300/500 公里、
  工厂还是仓库、交割库、危化品运输资质、内贸采购
- 交付要求含 Excel 与/或 HTML 的采购类任务
- 不适用：找下游客户（用 lead-sourcing 类）、纯价格行情（用行情类）

## 怎么用

1. 读 `SKILL.md`（主流程与硬规则），按第 1–6 步执行
2. 需要细节时读 `references/` 下对应文档
3. 数据写成 `dataset.json`（模板：`assets/dataset.template.json`）
4. 一条命令出成品：

```bash
python assets/scripts/run_all.py --dataset dataset.json --out ./output
```

5. 按 `SKILL.md` 第 7 节自检后才能交付

## 三条不可违反的规则

1. **匹配与距离分开**：不做加权总分；排序 = 先档位（A≥85/B70–84/C<70），档内按物流分
2. **不编造运费**：只写计费口径（吨公里/整车包干/回程车），拿到书面报价才算金额
3. **缺口显式化**：查不到的写进 `gaps[]`，每条都要能落到一个动作；不要用"约/大概"掩盖

## 交付物（缺一不可）

- `<产品>_供应商运距清单.xlsx`（8 表：封面/总表/评分/证据/距离/运输合规/缺口/询价）
- `<产品>_采购雷达.html`（单文件，零外链，地图+抽屉+矩阵）
- `dataset.json`（唯一数据源，便于复算）
- `evidence-notes.md`（研究留痕：搜了什么、为什么采信、还剩什么）

## 示例

- `examples/01-soda-ash-shahe/` —— 非危化品，厂家远、仓库近（演示"近 ≠ 匹配"）
- `examples/02-caustic-soda-changzhou/` —— 危化品，厂家就在园区（演示危化分支）

两个示例的成品在各自的 `output/` 下，可直接打开对照。
