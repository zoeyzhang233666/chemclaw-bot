# 证据分级细则（A / B / C / D）

## 1. 分级标准

| 级 | 定义 | 例子 | 单独可证"在生产"？ |
|---|---|---|---|
| **A** | 监管/司法/交易所出具的正式文件 | 郑商所交割仓（厂）库公告、上市公司年报、政府环评批复、国资委通报 | 是 |
| **B** | 责任主体自己发布的正式材料 | 企业官网"生产基地"、企业公告、招聘页的单位地址 | 产能可以，产量需 A 补 |
| **C** | 第三方二手整理 | 百度百科、行业媒体、券商研报、期货公司转载 | 否 |
| **D** | 名录/摘要/推断 | B2B 名录、搜索结果摘要、AI 摘要 | 否 |

**转载降级**：期货公司转载交易所公告 → B（不是 A）；媒体转述年报 → C。

## 2. 每条证据必须带 5 个字段

```json
{
  "claim": "一句话事实（谁、在哪、多大、什么规格）",
  "kind": "生产事实 | 产能数字 | 仓储资质 | 产品符合 | 资质与证据",
  "source": "来源名称（机构 + 文档名）",
  "url": "可点击链接",
  "date": "2025-05-22 或 2025 或 —",
  "level": "A",
  "supports": "这条证据支撑了什么结论（一句话）"
}
```

`supports` 是最容易被省略、也最关键的字段：它把"事实"翻译成"结论"，
读者据此判断该不该采信。

## 3. 组合规则

- **工厂**：≥1 条 A（产量/投产/批复）或 ≥2 条 B（官网产能 + 地址）
- **仓库**：≥1 条 A（交割仓库公告）即可认定"库存在"，但**不能**认定"有货可卖"
- **"此刻能供货"**：任何公开证据都证不了，必须进 `gaps`，写成待询价项
- 证据等级为 C/D 的主体只能进 C 档，并在 `action` 里写明"需先取证"

## 4. 相互矛盾的证据怎么处理

1. 不当场选边，**两条都写进去**，标注分歧（例：中盐常州烧碱 30 万吨 vs 金坛 18+滨江 8）
2. 用"法律效力高者优先"给结论，但保留另一口径在缺口里
3. 差值 >20% 时，`供货能力` 按**低值**打分（保守原则）

## 5. 证据链的展示

HTML 抽屉里按 A→D 排序，每条显示：级别徽章、类型、日期、事实、来源链接、支撑结论。
Excel「03 证据链」一企多行，带超链接与级别底色。

## 6. 常见伪造信号（提高警惕）

- 只有"占地面积""总投资"，没有任何产线/产能描述 → 可能是园区/贸易
- 地址是写字楼/商务中心 → 注册地，不是厂区
- 官网图片为效果图/无实景 → 未投产或已停产
- 产能数字是整数且多年不变（"年产 30 万吨"）→ 名义产能，非实际
- 多层股权嵌套的"XX新材料有限公司" → 先查是否只是销售主体
