# 危化品判定与运输条款

> 三分钟能定的事，不要写成"建议咨询专业人士"。

## 1. 判定四步

1. **查 CAS**：产品主成分的 CAS 号（纯碱 497-19-8、烧碱 1310-73-2、甲醇 67-56-1）
2. **查目录**：《危险化学品目录（2015 版）》目录序号。注意是**按品名+浓度**列，
   不是所有浓度都算（例：盐酸 <10% 可能不列入，但运输仍按腐蚀性货物处理）
3. **查 UN**：联合国 TDG 编号与类别（甲醇 UN1230 / 3 类；液碱 UN1824 / 8 类；
   纯碱无 UN，非危险货物）
4. **定包装类别**（I/II/III）与是否属于**剧毒品/易制爆/重点监管**

## 3. 运输条款清单（按货物形态选）

| 形态 | 车辆 | 关键要求 |
|---|---|---|
| 固体袋装 | 厢车/高栏 | 防雨苫盖、垫板、防潮内衬 |
| 固体散装 | 自卸/粉粒物料车 | 罐体专用、防扬尘 |
| 液体（危化） | 专用罐车/罐箱 | 危货资质、押运、防波板、接地 |
| 液体（非危） | 普通罐车 | 防泄漏、限速、冬季保温 |
| 气体 | 压力容器车 | 危货资质、定期检验、充装记录 |

## 4. 必写但常被漏掉的三条

1. **浓度/形态敏感性**："32% 液碱"与"片碱"判定不同，必须写"规格变化则本条失效"
2. **混装禁忌**：酸碱、氧化剂与还原剂同车是最常见的事故源
3. **自提责任**：客户自提时，装车、绑扎、单据交接责任在谁，要写清

## 5. 与运距的联动

危化品会**实质性改变可达半径**：
- 需专用车辆 → 可用车队少 → 实际运费高于普通货
- 部分城市/园区夜间禁行、限行 → 到货时间窗变窄
- 跨省运输需备案/通行证 → 500 km 的"可议价"变成"不经济"

做法：在 `action` 里写"危化品需专用车队，建议半径控制在 300 km 内"，
但**不因此修改 L 分**（L 只反映距离），保持两轴独立。
