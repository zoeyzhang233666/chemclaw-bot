# 研究手册：怎么把候选池找全、找准

> 目标不是"搜到很多公司"，而是"每一家都能说清：在哪、干什么、凭什么说它能供货"。

## 1. 来源阶梯（从硬到软）

| 顺位 | 来源 | 能证明什么 | 典型形态 |
|---|---|---|---|
| 1 | 期货交易所公告（郑商所/大商所/上期所） | 交割品牌、交割厂库/仓库、**提货点门牌地址** | `czce.com.cn` 公告、交割手册 PDF |
| 2 | 上市公司年报/公告 | 实际产量、产能、基地分布 | `cninfo.com.cn`、`sse.com.cn` |
| 3 | 政府/园区/国资委 | 投产、环评、搬迁、地址 | 省生态环境厅、园区管委会、国资委 |
| 4 | 企业官网"生产基地/联系我们" | 厂址、装置规模 | 官网 |
| 5 | 行业协会/券商深度报告 | 产能排名、行业格局（用于找线索） | 石化联合会、券商 PDF |
| 6 | 百科/招聘页/新闻 | 地址、产能（需交叉验证） | 百度百科、BOSS/应届生 |
| 7 | 行业名录/B2B 平台 | **仅线索**，不构成证据 | 化工网、1688 |

**关键技巧**：要"仓库地址"就去查**交割仓库公告**，那里有门牌号和联系人；
要"工厂地址"就查**环评公示**和**搬迁改造公告**，比官网准。

## 2. 搜索式模板（把 `<X>` 换成产品/企业）

```
<X> 产能 排名 万吨 2025                → 找头部与量级
<X> 指定交割品牌 交割厂库 名单          → 一步拿到"有资质+有地址"的名单
<X> 交割仓库 提货点 地址                → 仓库类候选（最容易被忽略）
<企业> 环评 公示 厂址                   → 新厂/搬迁后的真实位置
<企业> 生产基地 产能 万吨               → 官网口径
<企业> 年报 产量 万吨                   → 实际产量（比产能可信）
<X> 危险化学品目录 CAS <编号>           → 危化判定
<产品> UN编号 危险货物 类别             → 运输条款
<地区> <产品> 仓储 贸易 现货            → 近场补库点
<企业> 破产/停产/退出 产能              → 剔除僵尸产能
```

## 3. 从"公司"到"工厂"的四道筛

1. **主体筛**：集团 ≠ 上市公司 ≠ 生产基地。写清是哪一层在供货（合同主体）。
2. **地址筛**：注册地常在市区写字楼，厂区在园区。两个都要，分别标注。
3. **在产筛**：产能是名义值，产量才是事实。优先找"2024/2025 年产量"字样，
   或"装置贯通/投产"新闻。
4. **规格筛**：同一企业可能只做轻质不做重质、只做片碱不做液碱。
   用交割品牌、质检单、产品目录确认**你要的那个规格**。

## 4. 坐标怎么定（按优先级）

1. 官网/地图上能定位的厂区大门 → 直接取点，误差记 `±0.5 km`
2. 只有园区名 → 取园区中心，`±2–3 km`
3. 只有区县 → 取区县中心，`±8–15 km`，并在 `coord_note` 写明
4. 境外/无地图 → 用城市坐标 + 明确标注"未定位"

坐标写进 dataset 前，用"是否落在该省/该市边界内"做一次 sanity check
（底图上肉眼可验）。所有距离都依赖它，值得多花两分钟。

## 5. 常见陷阱

- **老厂/新厂**：化工企业搬迁频繁（例：连云港碱业 2024 年底搬迁项目中交），
  按老地址算距离会错 30–50 km。查"搬迁/升级改造"关键词。
- **厂库 ≠ 工厂**：交割"厂库"有的是生产企业，有的是物流园提货点（沙玻物流就是后者）。
- **同名不同主体**：`XX化工有限公司` 与 `XX化工股份有限公司` 常是两家。
- **已退出产能**：行业报告里的"退出产能"名单要剔除，别当在产。
- **集团产能≠本部产能**：340 万吨可能含外省子公司，对本地运距无意义，要拆分。
- **贸易商伪装厂家**：官网只有"销售中心"没有"生产基地"的，一律 `trader`。

## 6. 候选数量与结构

- 目标 **10–15 家**：工厂 8–10（覆盖 100/300/500 三档）+ 仓库 3–5 + 贸易 0–2
- 必须保留 **至少 1 家"近但不匹配"** 的样本，用来展示方法（不要为了好看删掉）
- 每档至少 1 家，否则说明搜索半径没铺开

## 7. 留痕（evidence-notes.md 写什么）

每家 1–3 行：搜了什么词、命中了哪个页面、为什么采信/放弃、还剩什么没查。
交付时这份笔记比结论更有用——下一个人能接着查，而不是从头再搜。
