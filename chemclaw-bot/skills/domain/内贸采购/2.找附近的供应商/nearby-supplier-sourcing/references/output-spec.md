# 输出规范（HTML / Excel 字段与版式）

两份交付物必须来自同一份 `dataset.json`，字段一一对应，数字必须一致。

---

## A. HTML（单文件，双击可开）

### 结构（顺序固定）

| 区块 | 内容 | 数据来源 |
|---|---|---|
| 顶栏 | 标题、副标题、场景、数据基准日、样本数 | `meta.title/subtitle/generated`、`items.length` |
| 场景卡 | 产品名 + 收货地 + 规格 chips + 4 个 KPI | `meta.product`、`meta.origin`、计算 |
| 地图卡 | 省界底图、半径环、公路路径、点位、图例、底注 | `geo`、`items[].geometry` |
| 列表卡 | 卡片流：排名、档位、角色、匹配/物流条、距离 | `items[]` |
| 矩阵 | 距离（对数）× 匹配度，象限标注 | `items[].road_km/matchTotal` |
| 评分口径 | 维度表 + 档位 + 折算说明 | `match.dims/tiers`、`logistics.anchors` |
| 采购路线 | 3 步行动建议 | `playbook[]` |
| 危化判定 | 结论、依据、风险、运输要求、规格变化提示 | `hazmat` |
| 缺口清单 | 缺口最多的 6 家 + 共同缺口 | `items[].gaps`、`meta.gap_note` |
| 页脚 | 免责、口径、使用方式 | `disclaimer[]` |

### 交互（必须全部可用）

- 半径切换：`logistics.rings` 各档 + 全部（默认「全部」）
- 排序：综合（rank）/ 按匹配 / 按距离
- 筛选：全部 / 工厂 / 仓储
- 点地图点位或列表卡片 → 右侧抽屉，四页：概览 / 证据 / 距离 / 缺口
- 抽屉内「复制询价要点」→ 剪贴板
- Esc 关闭抽屉；无横向溢出（`scrollWidth == clientWidth`）

### 硬约束

- **零外链**：模板内联全部 CSS/JS，字体用系统栈；不得引入 CDN
- 证据链接是唯一的 `<a href>`，且必须 `target="_blank" rel="noopener"`
- 打印时隐藏顶栏与抽屉（`@media print`）
- 1180px 以下单列堆叠

## B. Excel（8 表，结构固定）

| 表 | 列/内容 | 关键要求 |
|---|---|---|
| `00 封面与说明` | 标题、产品块、示例提示、KPI、采购路线、导航、免责 | 示例收货点必须有 ⚠ 行 |
| `01 供应商总表` | 23 列：序号→关键动作 | 冻结前两列、自动筛选、公路/物流分数据条、缺口≥3 标红 |
| `02 匹配度评分` | 五维分项 + 合计 + 档位 + 说明 | 维度定义附在下方 |
| `03 证据链` | 一企多行，按 A→D 排序 | 级别底色、URL 超链接 |
| `04 距离测算` | 直线/公路/绕行/在途/来源/精度 | 估算来源必须写「估算」；附折算表 |
| `05 运输与合规` | 判定、依据、风险、运输要求、运费口径 | 不含任何金额 |
| `06 数据缺口` | 缺口 + 影响 + 下一步 + 状态 | 状态下拉（待确认/已确认/不适用） |
| `07 询价清单` | 企业、联系、牌号、待填价格、状态、问询要点 | 状态下拉；价格列留空不估算 |

### 版式基线

- 表头：深蓝底 `#15334C` + 白字 + 居中 + 30px 行高
- 数据：微软雅黑 9pt，顶端对齐，自动换行，隔行浅底 `#F5F8FA`
- 档位色：A `#E7F3F0` / B `#FBF1E2` / C `#EEF1F5`
- 冻结窗格、`auto_filter`、列宽按内容设定
- 打印：横向、`fitToWidth=1`（工作表 00/05 用纵向）

## C. 一致性检查（交付前跑）

```bash
# 1) HTML 中的数字与 dataset 是否同源
grep -c "__DATA__" report.html        # 应为 0
# 2) Excel 能被重新打开
python -c "import openpyxl,sys; wb=openpyxl.load_workbook(sys.argv[1]); print([s.title for s in wb])" 清单.xlsx
# 3) 两处企业数、缺口数一致
```

任何不一致都视为缺陷：先修数据，再重新生成，**不要手工改输出文件**。
