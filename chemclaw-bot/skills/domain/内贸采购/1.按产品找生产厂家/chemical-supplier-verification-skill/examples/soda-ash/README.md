# 示例一：光伏玻璃用重质纯碱（完整真实示例）

## 这是什么

一个完整跑通的真实示例，用来演示：

- 怎么建 15–30 家生产厂家的样本；
- 怎么拆集团/上市公司/基地；
- 怎么给每条产能、产量、规格配来源；
- 怎么区分生产厂家与贸易商；
- 怎么在“没有批次 COA”的情况下写规格匹配；
- 怎么生成 Excel + HTML。

**数据截止：2026-10-19。** 这是示例需求（2,000 吨/月、收货地苏州），不是真实询价结果。

## 文件

```text
project.json                                 结构化数据（唯一事实源）
output/纯碱生产厂家核验池_苏州_202610.xlsx     12 个工作表
output/纯碱生产厂家核验池_苏州_202610.html     单文件交互页
```

## 复现

```bash
python scripts/validate_project.py examples/soda-ash/project.json
python scripts/run_all.py examples/soda-ash/project.json --outdir examples/soda-ash/output
```

## 样本

- **17 家生产厂家、22 个基地、3,030 万吨样本产能**；
- 覆盖 12 个省级产区；
- 约占全国纯碱产能 4,468 万吨的 68%；
- **样本覆盖不等于市场份额**。

### 方法要点

- **证据分级**：A=定期报告/政府/环评；B=官网/IR/招聘/行业；C=新闻/间接；D=仅工商。
- **产能口径**：集团 vs 基地分列；在产 vs 在建分开；联碱双吨不直接折算单吨。
- **规格匹配**：8 项指标逐项标注“部分公开 / 未公开 / 待验证”，没有 COA 不写“符合”。
- **评分**：确定性 35% + 规格 30% + 规模 20% + 距离 15%；外销可得性单列。

### 关键结论与边界

- 5 家优先谈判、6 家重点备选、6 家观察/成本备选；
- 5 个贸易/流通样本单独列出，不进入厂家池；
- 10 项数据缺口，其中 4 项 P0（批次 COA、非上市产能口径、外销量/长协、到厂运费）；
- 53 条证据、49 个来源；
- **0 家公开连续批次 COA**：所以 HTML/Excel 中只写“可对标/部分公开”，不写“符合”。

## 怎么改成你自己的项目

1. 复制 `project.json`；
2. 替换 `meta`（产品、收货地、截止日、样本说明）；
3. 替换 `rfq` 与 `specs`；
4. 替换 `companies`、`sources`、`traders`、`gaps`、`conflicts`、`actions`；
5. 运行 `validate_project.py` + `run_all.py`。

不要只改公司名就当成新报告；来源、日期、口径必须重新核验。
