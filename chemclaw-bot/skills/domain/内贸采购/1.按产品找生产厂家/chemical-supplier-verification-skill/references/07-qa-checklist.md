# 07 · 交付前 QA 清单

## A. 研究口径

- [ ] 产品名称、等级/形态、CAS/HS 已写清；
- [ ] 下游用途、关键规格、数量、收货地已写清；
- [ ] 数据截止日已写清；
- [ ] 样本框（上市/非上市、含/不含在建、集团/基地）已写清；
- [ ] 不含项（报价、账期、运费）已写清；
- [ ] 示例 RFQ 已标注“可替换”。

## B. 生产身份

- [ ] 每家公司至少 1 条 A/B 级生产证据；
- [ ] 没有用经营范围/店铺 SKU 判定生产；
- [ ] 没有把贸易商/代理放进候选厂家池；
- [ ] 集团/上市公司/基地/销售主体已拆分；
- [ ] 同一集团多基地没有重复加总；
- [ ] 注册地址与生产地址已区分；
- [ ] 新装置/搬迁项目标注“在建/试产/达产”。

## C. 产能与产量

- [ ] 每个产能有数值、单位、年份、口径、来源；
- [ ] 产能≠产量，分列；
- [ ] 在建≠在产；
- [ ] 联产“双吨”没有直接当目标产品单吨；
- [ ] 产量未披露写“未披露”，没有倒推；
- [ ] 销量/外销量/自用比例区分；
- [ ] 产能利用率超过 100% 时没有当成错误。

## D. 规格

- [ ] 6–12 项关键指标，覆盖下游真正关心的；
- [ ] 每项有采购要求、状态、公开信息、缺口；
- [ ] 公开标准/官网宣称只写“可对标/部分公开”；
- [ ] 没有批次 COA 不写“符合”；
- [ ] 关键指标未公开有扣分/标注；
- [ ] 规格书/COA 的批次号、日期、方法可追溯。

## E. 评分

- [ ] 权重合计为 1；
- [ ] 综合分与分项、权重一致；
- [ ] 分级阈值与业务动作一致；
- [ ] 外销可得性单独展示；
- [ ] 有敏感性说明；
- [ ] 没有用规模分掩盖证据不足。

## F. 来源

- [ ] 每条来源有 ID、机构、标题、日期、等级、URL；
- [ ] 每个数字能回到来源；
- [ ] A 级来源优先于 B/C；
- [ ] 冲突口径并列保留；
- [ ] 失效链接有备注；
- [ ] 没有“据行业统计”但无来源。

## G. Excel

- [ ] 至少 10 个工作表；
- [ ] 封面 KPI 与正文一致；
- [ ] 候选池 17–30 行，排序正确；
- [ ] 证据明细条数 = 各公司证据之和；
- [ ] 规格矩阵/长表覆盖全部公司 × 全部指标；
- [ ] 工厂数与候选池基地数一致；
- [ ] 贸易商表与候选池无重叠；
- [ ] 缺口表有 P0/P1/P2；
- [ ] 来源库 ID 与正文引用一致；
- [ ] 冻结窗格、筛选、条件格式、打印设置正常；
- [ ] 没有 `#REF!`、`#VALUE!`、`NaN`、`undefined`；
- [ ] 文件能重新打开，不是 0 字节。

## H. HTML

- [ ] 单文件，无外部 CDN/字体/图片依赖；
- [ ] 断网可打开；
- [ ] 筛选/排序/搜索生效；
- [ ] 表格/卡片视图切换；
- [ ] 点击行打开抽屉；
- [ ] 抽屉四页签正常；
- [ ] 对比 ≤3 家，加入/移除/清空正常；
- [ ] 规格书上传识别正常（或明确提示需手动粘贴）；
- [ ] 复制/下载按钮正常；
- [ ] 移动端无页面级横向溢出（表格自身可滚动）；
- [ ] 打印时隐藏筛选/抽屉；
- [ ] 没有 `__PLACEHOLDER__`、`undefined`、`NaN`。

## I. 一致性

- [ ] Excel 与 HTML 的公司数、基地数、产能、评分一致；
- [ ] 标题、日期、收货地一致；
- [ ] 贸易商数量一致；
- [ ] 来源数量一致；
- [ ] 优先/备选名单一致；
- [ ] 数据缺口表述一致。

## J. 交付话术

- [ ] 明确“示例 RFQ”；
- [ ] 明确“不含报价/账期/运费”；
- [ ] 明确“产能≠产量、在建≠在产、直线距离≠运费”；
- [ ] 明确“样本覆盖≠市场份额”；
- [ ] 明确“无批次 COA，不写符合”；
- [ ] 下一步动作具体（RFQ、COA、小试、审厂、物流比价）。

## 一键检查

```bash
python scripts/validate_project.py project.json
python scripts/run_all.py project.json --outdir output
```

校验脚本通过不等于内容正确；本清单仍需人工过一遍。
