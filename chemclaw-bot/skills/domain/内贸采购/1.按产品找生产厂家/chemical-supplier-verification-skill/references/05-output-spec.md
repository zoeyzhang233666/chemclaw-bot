# 05 · 输出细目：Excel + HTML

## 1. 文件命名

```text
{产品}_生产厂家核验池_{收货地}_{YYYYMM}.xlsx
{产品}_生产厂家核验池_{收货地}_{YYYYMM}.html
project.json
README.md
```

示例：

```text
纯碱生产厂家核验池_苏州_202610.xlsx
纯碱生产厂家核验池_苏州_202610.html
```

不要让 HTML 依赖外部 CDN、字体、图片或接口；所有 CSS/JS 内联，打开即用。

## 2. Excel：12 个工作表

### `00_封面`

必须包含：

- 标题、副标题、数据截止日；
- 6 个 KPI：厂家数、基地数、样本产能、优先谈判数、公开批次 COA 数、证据数；
- RFQ 卡：产品、规格、数量、收货地、区域偏好、包装/交付；
- 规格表：全部指标、要求、单位、方法、为什么关键；
- 方法与边界：生产身份、证据分级、产能口径、规格匹配、排序、边界；
- 一句使用顺序。

### `01_候选供应商池`

一行一家生产厂家。列建议：

```text
排名、供应商、代码/属性、厂家/贸易商、综合评分、分级、生产确定性、
规格匹配、工艺/路线、主要生产基地、省/市、到收货地直线km、距离带、
产能、产能数据年、产量、产量数据年、主营产品、企业规模/员工、
成立年份、规格公开可对标、无公开数据指标、证据等级、直接证据数、
外销可得性、推荐动作、数据缺口、来源ID
```

要求：

- 冻结窗格、自动筛选、表头换行；
- 评分色阶、产能数据条、分级色块；
- 产量未披露写“未披露”，不要留空；
- 贸易商不在此表。

### `02_生产证据明细`

一行一条证据：

```text
证据ID、供应商、证据等级、证据类型、证据标题、日期、来源机构、URL、
关键原文、证明事项、来源ID、可信度、备注
```

要求：

- 等级色块；
- URL 超链接；
- 关键原文换行；
- 至少 1 条 A/B 每家。

### `03_规格匹配矩阵`

宽表：企业 × 指标。每个指标两列：

```text
公开信息 / 状态
缺口 / 动作
```

状态色：

- 部分公开：浅绿；
- 未公开：浅橙；
- 待验证：浅灰/浅红。

### `03b_规格逐项明细`

长表：企业 × 指标一行。列：

```text
供应商、指标、采购要求、状态、公开信息、缺口、下一步动作
```

要求：自动筛选；按“未公开”筛选即可生成追问清单。

### `04_工厂与产能`

一行一个基地：

```text
工厂ID、供应商、工厂/基地、省、市、详细地址、经度、纬度、工艺、
产能、产能数据年、主要产品/配套、到收货地直线km、距离带、来源ID
```

要求：

- 同一集团多基地分列；
- 地址写到园区/镇；
- 坐标只用于直线距离，注明“近似点”。

### `05_评分与排序`

```text
排名、供应商、综合评分、生产确定性、确定性依据、规格匹配、规格依据、
规模分、产能、距离分、距离、加权计算、分级、外销可得性、排序敏感性
```

要求：

- 写清加权计算；
- 写清每个分的依据；
- 写敏感性。

### `06_贸易商与排除名单`

```text
名称、类型、地区、证据等级、公开证据、为什么判为贸易/流通而非生产、
处理、什么情况下可重新考虑
```

措辞：不是“黑名单”，是“生产身份未证实”。

### `07_数据缺口与复核清单`

```text
优先级（P0/P1/P2）、数据缺口、影响企业、对采购判断的影响、复核方法、责任、截止
```

P0：不补不能定主供；P1：影响备选/试单；P2：完善画像。

### `08_来源库`

```text
来源ID、机构、标题、日期、等级、URL、用于、访问日
```

要求：每条来源可点开；失效链接保留标题/日期并备注。

### `09_RFQ与行动清单`

- 统一 RFQ 必问 10 项；
- 30 天行动（发 RFQ、收 COA、小试、审厂、物流比价、定主供/备供）；
- 主供/备供建议。

### `10_口径与冲突`

```text
主题、口径A、口径B、本报告处理、对判断的影响
```

## 3. HTML：页面结构

### 顶部

- 品牌/项目名；
- 数据截止日；
- “下载 Excel”；
- “进入候选池”。

### Hero

- 一句话：谁在真正生产 X，而不是经营范围里写了 X；
- 导语：样本数、基地数、产能、证据规则；
- RFQ 快照：产品、CAS/HS、5 项关键规格、收货地、月需/年需；
- chips：厂家数、基地数、0 家批次 COA、贸易样本数。

### 01 需求卡

- 可编辑产品/规格、月需、收货地、区域偏好；
- 上传规格书（.txt/.csv/.md）识别指标；
- 关键规格表；
- 核验流程 5 步；
- 证据分级图例。

### 02 图表

- 产能省域分布；
- 工艺/路线结构；
- 距离×综合评分散点图；
- 供给走廊（可选）。

### 03 候选池

- 筛选：身份、地区、规模、距离、证据等级、搜索；
- 排序：综合/确定性/规格/规模/距离；
- 视图：表格/卡片；
- 列：排名、供应商、身份、最近基地、产能、距离、规格、证据、综合、操作；
- 点击行打开抽屉；
- 勾选对比（最多 3 家）。

### 04 供应商抽屉

四个页签：

1. **总览**：生产身份、产能、产量、最近基地、成立年限、员工、主营产品、外销、规格公开、基地地址、评分拆解、优势/缺口；
2. **生产证据**：时间线、等级、原文、证明事项、来源链接；
3. **规格匹配**：逐项对照、结论、追问清单；
4. **准入尽调**：10 项文件/样品/现场清单、专属缺口、现场审核 6 看、下载清单。

### 05 贸易商

卡片：名称、类型、地区、证据、为什么不是生产、处理、补证条件。标红，不进入候选池。

### 06 方法/缺口/冲突/行动

- 权重条；
- 数据缺口 Top 10；
- 冲突卡片；
- 30 天行动。

### 07 来源库

表格：ID、机构、标题、日期、等级、链接；可滚动。

### 弹层

- 对比：最多 3 家，逐项高亮最优；
- 准入清单：可勾选、下载 .txt。

## 4. HTML 交互清单

- [ ] 筛选生效，结果计数正确；
- [ ] 排序生效；
- [ ] 表格/卡片视图切换；
- [ ] 点击行打开抽屉；
- [ ] 抽屉四页签切换；
- [ ] 对比加入/移除/清空；
- [ ] 对比弹窗 ≤3 家；
- [ ] 规格书上传识别；
- [ ] 复制摘要/规格清单；
- [ ] 下载尽调清单；
- [ ] 移动端无横向溢出（表格自身可滚动）；
- [ ] 打印时隐藏筛选/抽屉。

## 5. Excel 格式要求

- 表头深色、白字、加粗、居中；
- 正文 8–10pt，自动换行；
- 冻结首行/首列；
- 自动筛选；
- 条件格式：评分色阶、产能数据条、等级色块；
- 数字格式：千分位、小数位；
- 页面设置：A3 横向、fitToWidth；
- 页脚注明“数据截止 + 仅作初筛”；
- 来源 URL 超链接；
- 封面 3×2 KPI 卡片。

## 6. 交付检查

- 文件能打开，不是 0 字节；
- Excel 至少 10 个表；
- HTML 无外部依赖，断网可打开；
- 两份文件的数字一致；
- 标题/日期/样本数一致；
- 没有 `TODO`、`__PLACEHOLDER__`、`undefined`、`NaN`；
- 贸易商没有混入候选池；
- 没有“符合”但没有 COA 的表述。
