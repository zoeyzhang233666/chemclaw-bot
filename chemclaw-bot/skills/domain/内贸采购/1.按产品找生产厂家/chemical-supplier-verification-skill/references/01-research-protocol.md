# 01 · 检索与实体拆分协议

## 1. 先定义“研究边界”

开工前写清楚 8 个字段：

| 字段 | 要写什么 | 不写会怎样 |
|---|---|---|
| 产品 | 名称 + 等级/形态 + CAS/HS | 把轻碱、重碱、食品碱混在一起 |
| 下游 | 用途 + 关键指标 | 规格匹配失焦 |
| 数量 | 月需/年需 + 包装 | 无法判断规模与物流 |
| 收货地 | 城市/园区 | 距离与运费无法算 |
| 截止日 | YYYY-MM-DD | 数据时效不可比 |
| 样本框 | 上市/非上市、是否含在建、是否含集团 | 产能重复或漏算 |
| 身份 | 是否含贸易商、是否单列 | 贸易商混入厂家池 |
| 不含 | 报价、账期、运费等 | 输出被误解为成交条件 |

把这些写进 `project.json.meta` 和封面，不要只放在聊天里。

## 2. 建样本框：先求全，再求准

### 2.1 来源优先级

1. **法定披露**：年报、半年报、招股书、债券募集说明书、重大资产重组报告。
2. **政府文件**：环评/环评验收、排污许可、安全生产许可、能评、产能置换、项目备案/核准、园区规划环评。
3. **行业基础设施**：期货交割厂库/品牌、海关编码与进出口数据、行业协会会员/产能统计。
4. **企业自述**：官网产品页、IR 问答、招聘主页、企业手册、公众号。
5. **第三方**：券商研报、行业媒体、咨询报告、新闻。
6. **弱线索**：B2B 店铺、招标网、招聘广告、物流招标。

### 2.2 检索式模板

把 `{产品}`、`{地区}`、`{工艺}` 替换掉：

```text
"{产品}" 生产厂家 产能
"{产品}" 环评 公示 万吨/年
"{产品}" 排污许可 产能
"{产品}" 项目 备案 投产
"{产品}" 年会 产能 统计
"{产品}" 期货 交割 厂库 品牌
"{产品}" 上市公司 年报 产能
"{产品}" 生产基地 地址
"{产品}" 安全生产许可证
"{产品}" 产能置换
"{产品}" 搬迁 技改 扩产
"{产品}" 原料 采购 招标
"{产品}" 招聘 操作工 装置
```

按地区：

```text
"{产品}" "{省}" 产能
"{产品}" "{市}" 化工园区
"{产品}" "{园区名}"
```

按企业：

```text
"{企业名}" 年报 产能
"{企业名}" 环评 项目
"{企业名}" 官网 产品
"{企业名}" 生产基地
"{企业名}" 子公司 产能
```

### 2.3 目标数量

- 大宗品：15–30 家生产厂家、20–40 个基地；
- 精细/ specialty：8–20 家；
- 如果只能找到 5 家，不要硬凑；在 `meta.sample_note` 写“样本覆盖有限，未穷尽”。

## 3. 拆实体：集团 / 上市公司 / 基地 / 销售主体

### 3.1 四种实体

| 实体 | 作用 | 易错点 |
|---|---|---|
| 集团 | 合并产能、品牌、授信 | 把集团产能加到每个基地 |
| 上市公司/平台 | 披露口径、财务、员工 | 上市公司不等于全部生产资产 |
| 生产基地 | 真实装置、地址、产能 | 注册地址≠生产地址 |
| 销售主体 | 合同、开票、收款 | 销售公司不是生产厂家 |

### 3.2 拆分步骤

1. 先列集团/上市公司；
2. 从年报“主要子公司/生产基地/产能表”拆出基地；
3. 从环评/政府公告补基地地址与项目；
4. 从官网/招聘确认产品与装置；
5. 从关联交易/招标/海关确认销售主体；
6. 用 `group_id` 把同一集团的公司/基地串起来，避免重复加总。

### 3.3 去重规则

- 同一地址、同一装置、不同公司名：先查股权/历史沿革，能合并就合并，不能合并就并列并写冲突。
- 同一集团多个基地：`capacity_total` 用集团合计，`plants[]` 分列；两者不能相加。
- 同一基地多个产品：只取目标产品产能；联产装置写“联产，目标产品产能另计/待核”。
- 同一公司改名：保留旧名在 `aliases`，主名用最新法定名。

## 4. 产能口径

每个产能必须带 5 个属性：

```text
value, unit, year, definition, source_id
```

`definition` 至少区分：

- 设计产能；
- 在产产能；
- 核定产能；
- 在建/拟建；
- 搬迁置换；
- 集团合并/基地口径；
- 联产装置折算。

常见坑：

- 把“纯碱+氯化铵”双吨当纯碱单吨；
- 把二期在建算进一期在产；
- 把集团总产能加到每个子公司；
- 把“产能利用率超过 100%”当成错误（超产是常见现象，但要写清）；
- 把“产量”当“销量”，把“销量”当“外销量”；
- 把“食品级/工业级”共线产能重复计算。

## 5. 产量、销量、外销量

三者分开：

```text
output          实际产量
sales_volume    销量（可能含贸易/代销）
external_sales  可对外销售的量为，扣除自用/关联交易
captive_use     自用比例
```

如果只有产能没有产量，写“未披露”，不要用产能乘利用率倒推，除非披露了利用率且注明“推算”。

## 6. 规格证据

按指标逐项找：

- 产品标准（GB/T、HG/T、ASTM、客户标准）；
- 官网产品页/技术数据表（TDS）；
- COA 样本（注意批次、日期、检测方法）；
- 客户案例/审厂报告；
- 第三方检测报告。

公开标准只能证明“标准存在”，不能证明“该企业批次合格”。没有 COA 时，状态写“部分公开/未公开/待验证”。

## 7. 来源记录规范

每条来源必须有一个 `source_id`，并记录：

```json
{
  "id": "S01",
  "org": "某公司",
  "title": "2025年年度报告",
  "date": "2026-04-30",
  "grade": "A",
  "url": "https://...",
  "used": "纯碱产能390万吨；四个基地产能表",
  "accessed": "2026-10-19"
}
```

要求：

- 标题具体到“年报/环评/公告/页面”，不要写“网上资料”；
- 日期能精确到日就精确到日，不能就写年份/访问日；
- URL 尽量用可公开访问的原始链接；
- 同一事实至少两个独立来源交叉，才把确定性打到 90+；
- 链接失效时保留标题、机构、日期，并在 `notes` 写“链接失效，已存档/待补”。

## 8. 冲突处理

同一指标出现两个口径时：

1. 并列保留，不强行取一个；
2. 写清 A/B 来源、日期、口径；
3. 给出本报告采用哪个、为什么；
4. 写对判断的影响；
5. 在 Excel `10_口径与冲突` 和 HTML 方法区展示。

示例：

```json
{
  "topic": "某公司产能",
  "a": "官网简介：60万吨/年",
  "b": "企业规模页：35万吨/年",
  "resolution": "并列保留；采用60万吨作为上限、35万吨作为下限，待环评/排污许可复核",
  "impact": "影响华南可供量判断"
}
```

## 9. 反幻觉检查

写完每个数字，问自己：

- 这个数字来自哪条来源？能点开吗？
- 是产能还是产量？是哪一年？是集团还是基地？
- 是在产还是在建？
- 是目标产品还是联产品？
- 是销量还是外销量？
- 是标准值还是批次实测值？

任何一项答不上来，就改成“未披露/待核”，并写入 `gaps`。
