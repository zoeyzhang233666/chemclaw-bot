# 06 · 不同化工品的适配

这个 skill 的研究结构不变，但“生产证据、规格指标、规模阈值、距离权重”要随产品变。

## 1. 先判断产品类型

| 类型 | 例子 | 关键差异 |
|---|---|---|
| 大宗固体 | 纯碱、尿素、PVC、钛白粉 | 产能大、运输半径、包装 |
| 大宗液体 | 烧碱、硫酸、甲醇、液氨 | 槽车/ISO 罐、危化品、运输半径更短 |
| 精细化学品 | 电子级双氧水、医药中间体 | 规格/认证优先、批量小 |
| 聚合物 | PE/PP/PVC | 牌号、熔指、客户认证 |
| 工业气体 | 液氧、液氮、氢气 | 管道/槽车、半径极短、现场制气 |
| 新能源材料 | 磷酸铁、碳酸锂、电解液 | 客户验证、批次一致性 |
| 矿物/原料 | 萤石、磷矿、石英砂 | 品位、杂质、采矿权 |

## 2. 生产证据的差异

### 大宗固体/液体

- 年报/半年报“主要产品产能/产量”；
- 环评/验收、排污许可；
- 政府项目公告、产能置换；
- 期货交割厂库/品牌；
- 官网产品页/招聘。

### 危化品

额外需要：

- 安全生产许可证；
- 危险化学品登记；
- 危化品经营许可证（贸易/销售主体）；
- 危化品运输资质（物流商）；
- 园区认定/安全距离；
- 重大危险源备案。

这些是 **gate**，不是加分项。

### 精细/电子级

额外需要：

- 客户认证（Fab/面板厂/电池厂）；
- ISO9001/14001/45001；
- 洁净包装/洁净室；
- 金属杂质/颗粒/水分 TDS；
- 批次一致性/变更管理；
- 第三方检测（ICP-MS 等）。

### 工业气体

- 现场制气/管道供应；
- 空分装置/液化装置；
- 储罐/槽车；
- 安全距离/园区管道；
- 运输半径通常 100–300 km，距离权重要大幅提高。

### 聚合物/牌号产品

- 牌号而不是“产品大类”；
- 熔指/密度/冲击/维卡；
- 客户认证/加工窗口；
- 装置年产能 + 牌号排产；
- 贸易商/代理商比例高，要单独识别。

## 3. 规格指标怎么换

### 纯碱（示例）

总碱量、水分、氯化物、Fe₂O₃、水不溶物、堆积密度、粒度、灼烧失量。

### 烧碱（液碱）

NaOH 浓度、Na₂CO₃、NaCl、Fe₂O₃、SiO₂、外观、色度。

### 尿素

总氮、缩二脲、水分、粒径、强度、甲醛。

### 甲醇

纯度、水分、高锰酸钾试验、色度、酸度、铁。

### PVC

K 值/聚合度、表观密度、增塑剂吸收、鱼眼、杂质粒子、残留 VCM。

### 钛白粉

TiO₂ 含量、白度、消色力、吸油量、粒径、表面处理、分散性。

### 电子级双氧水

浓度、稳定度、TOC、金属离子（ppb/ppt）、颗粒。

### 磷酸铁

铁/磷比、比表面积、粒度、振实密度、水分、杂质。

## 4. 规模阈值

默认阈值只适合大宗品（万吨/年）。换产品时先问：

- 全国总产能多少？
- 单套经济规模多少？
- 这家是“大厂”还是“小厂”？
- 产能单位是万吨/年、吨/年、万标方/年、GWh？

把阈值写进 `scoring` 或生成器参数，不要硬套。

## 5. 距离与物流

| 产品 | 运输方式 | 距离权重建议 |
|---|---|---:|
| 大宗固体 | 汽运/铁路/水运 | 15% |
| 大宗液体 | 槽车/ISO 罐/管道 | 20–25% |
| 危化品 | 专用槽车/管道 | 25–30% |
| 工业气体 | 槽车/管道 | 30–40% |
| 精细/电子 | 空运/冷链/快递 | 10–20% |
| 出口 | 港口/海运 | 15–20% |

## 6. 贸易商识别

化工品贸易商比例高，尤其在：

- 纯碱、烧碱、尿素、甲醇等大宗；
- 钛白粉、PVC 等牌号产品；
- 电子化学品（代理商多）；
- 进口品牌（代理链长）。

识别方法：

- 看是否有生产地址/装置/环评；
- 看店铺 SKU 是否跨很多品牌；
- 看招聘岗位（销售 vs 操作工）；
- 看关联交易（采购方 vs 生产方）；
- 要求授权链 + 出厂 COA + 发货地址。

## 7. 适配检查清单

换产品后回答：

- [ ] 产品名称、CAS/HS、等级/形态是否明确？
- [ ] 规格指标是否是该产品真正关键的 6–12 项？
- [ ] 生产证据类型是否覆盖该产品（危化品许可/客户认证/牌号）？
- [ ] 规模阈值是否匹配该产品的经济规模？
- [ ] 距离权重是否匹配运输方式？
- [ ] 贸易商/代理是否单独识别？
- [ ] 是否有该产品特有的合规 gate？
- [ ] 示例 RFQ 是否标注“可替换”？

## 8. 不要直接套用的东西

- 纯碱的“联碱双吨”口径；
- 纯碱的 8 项规格；
- 纯碱的 680/390/340 万吨阈值；
- 纯碱的“到苏州 39 km”；
- 纯碱的“0 家 COA”结论。

换产品必须重新核验，不能改名字当新报告。
