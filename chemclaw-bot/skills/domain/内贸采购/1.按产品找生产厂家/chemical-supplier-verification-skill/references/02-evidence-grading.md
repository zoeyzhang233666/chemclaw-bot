# 02 · 证据分级与生产身份判定

## 1. 为什么分级

“有产能”与“有产能证明”是两件事。分级的目的不是做学术，而是让采购能判断：

- 这家公司是不是生产厂家？
- 这个产能数字能不能用？
- 还缺什么，下一步找谁要？

## 2. 四级证据

### 直接-A：法定披露 / 政府文件 / 环评

包括：

- 上市公司年报、半年报、招股书、债券募集说明书；
- 政府项目公告、项目备案/核准、环评/环评验收；
- 排污许可证、安全生产许可证、能评、产能置换公告；
- 期货交割厂库/品牌公告；
- 法院/破产重整公告中的产能资产描述。

特点：有法律/监管背书，产能/地址/项目通常可直接引用。

用法：

- 作为“生产身份成立”的主证据；
- 产能数字优先用 A 级；
- 注意年份、口径、集团/基地。

### 直接-B：企业官网 / IR / 招聘 / 企业手册

包括：

- 官网“产品中心/生产基地/关于我们”；
- 投资者互动平台（IR）问答；
- 招聘主页中的“装置/产能/产品”；
- 企业宣传册、公众号项目投产稿；
- 行业协会会员页中的产能描述。

特点：企业自述，通常真实，但可能有宣传口径。

用法：

- 与 A 级交叉后，可把生产确定性打到 90+；
- 只有 B 级时，确定性最高 85–90，且要写“待 A 级交叉”；
- 官网产能与年报冲突时，并列保留。

### 间接-C：新闻 / 行业统计 / 原料采购 / 招聘广告

包括：

- 行业媒体、券商研报、咨询报告；
- 项目开工/试车新闻；
- 原料采购招标、物流招标；
- 招聘广告中的“装置”描述；
- 海关/进出口数据；
- 关联交易中的采购/销售记录。

特点：能证明“有这件事”，不一定能证明“这个数字”。

用法：

- 做旁证、时间线、项目进度；
- 不单独作为产能数字的唯一来源；
- 关联交易只能证明“采购/销售关系”，不能证明“生产”。

### 仅工商-D：营业执照 / 店铺 SKU / 代理宣称

包括：

- 营业执照经营范围含某产品；
- 1688/爱采购店铺 SKU；
- 企业黄页/目录；
- 代理/经销宣称；
- 只写“供应某产品”的网页。

特点：几乎不能证明生产。

用法：

- 单独列入 `traders` / `exclusions`；
- 标红“不可信”；
- 不进入候选厂家池；
- 如要重新考虑，要求授权链 + 出厂 COA + 发货地址 + 产能/环评证明。

## 3. 判定表

| 问题 | 是 | 否 |
|---|---|---|
| 有明确生产基地地址？ | 继续 | 贸易/代理/待核 |
| 有装置/产能/产量/环评/政府项目之一？ | 继续 | 贸易/代理/待核 |
| 至少一条 A 或 B 级证据？ | 生产厂家候选 | 仅线索，不入池 |
| 只有经营范围/店铺 SKU？ | D 级，排除 | — |
| 产能是集团口径？ | 拆基地，避免重复 | 直接用 |
| 产能是在建？ | 标“在建”，不计入在产 | 用在产 |
| 规格只有标准？ | “可对标”，不写符合 | 要 COA |

## 4. 生产确定性打分

建议 0–100：

| 分数 | 条件 |
|---:|---|
| 95–100 | 2 条以上独立 A 级，产能/产量/基地都能对上 |
| 90–94 | 1 条 A 级 + 1 条 B 级，或 2 条 A 级但有一处口径待核 |
| 80–89 | 只有 B 级，或 A 级只证明业务、不证明产能 |
| 70–79 | B 级 + C 级旁证，产能数字有冲突 |
| 60–69 | 只有 C 级，生产身份“可能存在” |
| <60 | 只有 D 级，不入厂家池 |

注意：

- 分数不是“企业好坏”，只是“生产身份证据强度”；
- 有 A 级但产能是集团口径，分数要扣；
- 有新装置但未达产，分数要扣；
- 有产能但外销可得性低，分数不扣，但 `availability` 单独低。

## 5. 证据条目怎么写

```json
{
  "id": "E-001",
  "level": "直接-A",
  "type": "定期报告",
  "title": "2025年年度报告",
  "date": "2026-04-30",
  "org": "某公司",
  "url": "https://...",
  "quote": "公司纯碱产能390万吨；其中某基地60万吨。",
  "proves": "集团产能 + 基地产能",
  "source_id": "S01"
}
```

要求：

- `quote` 必须是原文或接近原文的摘录，不要写“公司很大”；
- `proves` 写“证明什么”，不要重复标题；
- 一条证据只证明一个事实；
- 同一事实两条证据，分别列，不要合并；
- 链接失效也要保留标题/机构/日期。

## 6. 贸易商/代理怎么判

### 典型特征

- 经营范围含“化工产品销售”，但没有生产地址/装置/环评；
- 店铺 SKU 很多、品牌很多，但没有自有工厂；
- 声称“代理某厂”，但拿不出授权链；
- 关联交易中是“采购方”而不是“生产方”；
- 地址是写字楼/商贸城，不是化工园区；
- 招聘岗位是“销售/客服”，不是“操作工/工艺工程师”。

### 处理

- 列入 `traders`，不进入 `companies`；
- 写清 `why`（为什么不是生产）；
- 写清 `action`（补什么可以重新考虑）；
- 在 Excel/HTML 单独展示，标红；
- 不要用“黑名单”措辞，用“生产身份未证实”。

## 7. 证据冲突

- 两个 A 级冲突：并列，标注日期，优先用更新/更具体（基地级 > 集团级）；
- A 与 B 冲突：优先 A，但保留 B，写“待核”；
- B 与 C 冲突：优先 B，C 做旁证；
- 只有一个来源：写“单一来源，待交叉”；
- 来源是自媒体：降一级，标 C。

## 8. 常见错误

- 把“经营范围”当“生产资质”；
- 把“关联交易采购方”当“生产厂家”；
- 把“集团产能”复制到每个基地；
- 把“在建产能”算进“在产”；
- 把“产量”当“销量”；
- 把“标准值”当“批次实测值”；
- 把“官网宣传”当“法定披露”；
- 把“新闻项目开工”当“已投产”；
- 把“直线距离”当“运费”。
