# 价格研究手册

怎么找到能用、能比、能追溯的地区现货价格。

---

## 1. 先定义"比什么"

在查任何价格之前，先把这几件事定死，否则查到的数没法比：

| 维度 | 为什么必须先定 |
|---|---|
| **品种与等级** | 纯碱「轻质/重质」是两个价，差价可达 100~200 元/吨；重碱又分工业级/食品级 |
| **规格含量** | Na₂CO₃ 98% vs 99.2%，光伏玻璃用高纯碱更贵 |
| **包装** | 散装 / 25kg 袋 / 500kg 吨包，袋装通常贵 30~80 元/吨 |
| **计价单位** | 元/吨（净重）最常见；液体化工要确认是否按立方 |
| **税费口径** | 含 13% 增值税 vs 不含税 |
| **交货口径** | 送到 / 出厂 / 自提 / 库提 —— **最容易出错的一项** |

写进 `research.json` 的 `basis` 与 `normalization` 字段。

## 2. 去哪找价格（按可信度排序）

### 2.1 资讯商分区价（首选）

- **隆众资讯**（oilchem.net）、**化盟网**（zx.hm-w.com）、**卓创资讯**（sci99）、**生意社**（100ppi）
- 分区价通常按「华北 / 华东 / 华中 / 华南 / 西南 / 西北」给区间
- **优点**：同日、同规格、同一套口径，最可比
- **陷阱**：
  - 分区 ≠ 省。山东属"华北"，河南属"华中"，但广东也在"华南"
  - 区间宽的时候（如 1100-1200）中值会掩盖低端/高端货源
  - 有些资讯商的"沙河"是**自提价**，与"华北送到价"不可直接相减

> 实战提示：化盟网 `zx.hm-w.com` 的日评正文有时直连不通，可通过搜索引擎的页面摘要拿到完整价格表；MySteel 系（mysteel.com）文章正文需登录，改用移动端域名 `nenghua.m.mysteel.com` 可读全文。

### 2.2 交易所 / 期货公司研报（交叉验证）

- 郑商所（CZCE）合约说明、期货公司日评（转引隆众/卓创）
- 用途：当分区价缺失或可疑时，用研报里的分区报价做交叉验证
- **陷阱**：基差报盘（如「01+20」「01-60」）是相对期货的升贴水，**不能直接当现货价**，折算时误差很大

### 2.3 行业门户 / 企业公告

- 上市公司公告、行业协会月报、地方价格监测
- 用途：验证产能、检修、开工率等基本面

### 2.4 电商 / 挂牌（仅参考，通常不可比）

ChemicalBook、1688、化工网报价往往是**零售挂牌或经销商挂牌**，比大宗价高 50%~150%，**不能进比价表**。如果确实要用，必须设 `comparable: false` 并在 `comparable_note` 说明原因。

## 3. 判断"能不能比"的五个问题

对每个候选价格依次问：

1. **品种等级一致吗？** （轻碱 vs 重碱 —— 不一致，直接排除）
2. **规格含量一致吗？** （98% vs 99.2% —— 差 2%，通常可容忍但要注明）
3. **税费口径一致吗？** （含税 vs 不含税 —— 必须换算到同一口径）
4. **交货口径一致吗？** （送到/出厂/自提 —— 不一致不能用裸价直接比，要标出来）
5. **日期接近吗？** （相差 > 5 个交易日，必须注明，且不能跨期拼价差）

五个问题都过了，才算一条可用报价。

## 4. 归一化怎么做

### 单位归一

```
元/千克 → 元/吨 :  × 1000
元/立方米 → 元/吨 : × 密度(t/m³)
元/袋    → 元/吨 : × (1000 ÷ 每袋净重kg)   ← 需要额外字段，否则不算
```

### 税费归一

```
含税 → 不含税 : ÷ (1 + 13%)     (纯碱等一般货物)
不含税 → 含税 : × (1 + 13%)
运费的税率是 9%（交通运输服务），与货物 13% 不同，不要混用
```

### 区间 → 单值

默认取**中值**。但必须同时保留 `price_low` / `price_high`，因为：

- 区间宽时，中值会让差异被平均掉
- 真正的采购价取决于你是拿低端还是高端货源

HTML 与 Excel 都会提示"区间宽，建议上下限各算一遍"。

## 5. 无法匹配时怎么办

**不要凑数。** 明确标注：

| 情况 | 处理 |
|---|---|
| 该区域没有重碱报价，只有轻碱 | 不填价格，登记 gap「XX 无重碱分区报价」 |
| 只有经销商零售挂牌 | 设 `comparable:false`，或干脆不用 |
| 只有西北出厂价（口径完全不同） | 登记 gap，说明"西北为出厂价，与送到价不可比" |
| 只有基差报盘 | 登记 gap，注明"基差折算为广口口径，未纳入本表" |

---

## 6. 历史序列怎么取

- 优先取**同一来源、同一定义**的连续序列（例如生意社基准价每 10 天一档）
- 区域价差序列必须**同日**，宁可只有 5 个可比日，也不要拼 20 个不同日的数
- 记录 `span` 与 `price_change_window`，让读者知道样本多长
- 不插值、不外推

## 7. 采集记录模板

每条来源都要能回答："这个数谁说的、哪天说的、什么口径、原话在哪"。

```json
{
  "id": "S1",
  "name": "化盟网《10月16日纯碱日评》",
  "url": "https://example.com/viewpoint/detail/17862",
  "type": "资讯商",
  "level": "分区现货区间",
  "retrieved_at": "2026-10-19",
  "note": "华北重碱 1100-1200；沙河为重碱自提 940-950（口径不同，单列）"
}
```
