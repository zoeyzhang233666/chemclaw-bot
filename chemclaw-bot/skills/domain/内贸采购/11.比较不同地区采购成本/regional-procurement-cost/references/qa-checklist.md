# 交付前验收清单

跑完 `validate.py` 与 `qa.py` 后，再过一遍这份人工清单。

---

## A. 数据层（`python scripts/validate.py <案例目录>`）

- [ ] **A1** 每个区域都有 `quote_id` 与 `route_id`，且都能对上
- [ ] **A2** 六要素齐全：数值 / 规格 / 地区 / 含税口径 / 日期 / 来源
- [ ] **A3** 所有 `source_id` 都在 `sources` 里登记，且有可点开的 URL
- [ ] **A4** `price` 在 `[price_low, price_high]` 区间内
- [ ] **A5** 交货口径混用时（自提 vs 送到），`gaps` 或 `assumptions` 里有对应说明
- [ ] **A6** 无"预测/看涨/看跌/必涨/抄底"类断言措辞
- [ ] **A7** 每条 `route` 都声明了 `basis`，`measured_legs` 的每条 leg 都有 `km` 和来源

## B. 计算层

- [ ] **B1** 运费全为空时，到厂成本显示"待补"，且**没有**任何排名
- [ ] **B2** 运费为空时，页面上**不出现**任何运费金额（搜索页面里有没有凭空冒出的运费数）
- [ ] **B3** 填入运价后，`Δ裸价 + Δ运费 + Δ装卸 = Δ到厂`，闭合校验显示"✓"
- [ ] **B4** 装卸费填 `0` 与留空，结果不同（0 = 计入为 0；空 = 待补）
- [ ] **B5** 改数量后，整单总额按比例变化，单位成本不变
- [ ] **B6** 取消勾选某个区域后，表格、图表、分解同步减少

## C. HTML 交付物

- [ ] **C1** 单文件：断开网络后仍能打开并交互（`qa.py` 已检查无外链）
- [ ] **C2** 首屏能看到：裸价最低区域、区域极差、距离范围、到厂完整度
- [ ] **C3** 地图上每条线路都有里程标签，收货地有高亮
- [ ] **C4** 价格表能点击跳到来源原文
- [ ] **C5** 自提价有醒目标签（橙色 `自提`）
- [ ] **C6** 宽区间（≥100 元）有提示
- [ ] **C7** 明细区展开后，公式串可直接代入复算
- [ ] **C8** 缺口区写清"缺什么/为什么缺/怎么补/影响"
- [ ] **C9** 演示数据有醒目 `demo` 横幅（若 `meta.scenario = "demo"`）
- [ ] **C10** 手机/窄屏不横向溢出

## D. Excel 交付物

- [ ] **D1** 9 个工作表齐全
- [ ] **D2** 输入格是浅黄底、计算格是灰蓝底，视觉可区分
- [ ] **D3** 改 `1-参数` 的数量，`3-到厂成本` 的到厂单价与整单总额联动
- [ ] **D4** `3-到厂成本` 填运价后，`4-因素分解` 变为"✓ 闭合"
- [ ] **D5** 汇总行在有缺项时显示"不排名（有缺项）"
- [ ] **D6** 链接列可点击

## E. 结论层（最容易翻车的地方）

- [ ] **E1** 报告的结论措辞与数据状态一致：运费缺失时**不能**说"XX 最划算"
- [ ] **E2** "便宜"与"划算"分得清：裸价低 ≠ 到厂低
- [ ] **E3** 距离区间（低端–高端）说明了为什么，不是随便给两个数
- [ ] **E4** 没有把"市场所在地"当成"产能所在地"（如沙河 vs 唐山）
- [ ] **E5** 边界明说：不含资金成本、不含损耗、不含库存成本
- [ ] **E6** 没有替用户做决定，只给判断依据与待补清单

## 常见扣分项（自查）

| 现象 | 为什么不行 | 怎么改 |
|---|---|---|
| 页面上出现"运费约 300 元/吨" | 无报价依据 | 删掉，改"待补" |
| 用"吨公里 0.3 元"算出排名 | 编造 | 删掉排名，只给裸价差与距离 |
| 沙河 945 与华北 1150 直接相减说"便宜 205" | 自提 vs 送到，口径不同 | 标注口径，说明"自提还要自付运输" |
| 用一个城市代表整个省 | 省内差异可达 400 km | 用"低端–高端"两个起点 |
| 用直线距离 | 少算 15% | 用路线库里程 |
| 拿 9 月河北价 vs 10 月山东价比 | 不同期 | 同日才能比 |
| 「区间中值」当唯一答案 | 掩盖高低端货源 | 同时给上下限敏感性 |
