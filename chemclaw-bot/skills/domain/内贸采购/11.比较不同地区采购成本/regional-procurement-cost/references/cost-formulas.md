# 计算口径：到厂成本与因素分解

本文是 `scripts/lib/geo.cjs` 的算法说明。HTML 与 Excel 用的是**同一套公式**。

---

## 一、记号

| 符号 | 含义 | 单位 |
|---|---|---|
| `P_i` | 区域 *i* 的市场裸价（含税） | 元/吨 |
| `Q` | 采购数量 | 吨 |
| `D_i` | 区域 *i* 到收货地的里程 | km |
| `F_i` | 区域 *i* 的运费总额 | 元 |
| `f_i` | 区域 *i* 的运费单价 | 元/吨 |
| `L_i` | 装车费 | 元 |
| `U_i` | 卸车费 | 元 |
| `I_i` | 检测/取样费 | 元 |
| `O_i` | 其他整单费用 | 元 |
| `C_i` | 到厂成本单价 | 元/吨 |
| `T_i` | 到厂总成本 | 元 |

---

## 二、价格归一

### 2.1 单位归一

```
P_吨 = P_原值 × 单位系数
单位系数：元/吨 → 1 ；元/千克 → 1000 ；元/立方米 → 密度(t/m³)
```

### 2.2 税费归一

货物增值税 13%：

```
不含税价 = 含税价 ÷ (1 + 13%)
含税价   = 不含税价 × (1 + 13%)
```

> 运费税率是 **9%**，与货物 13% 不同，不可混用。本模型默认所有价格已是同口径（含税），
> `priceBasis` 字段仅切换"用含税价还是不含税价比较"。

### 2.3 区间 → 单值

```
P_i = (price_low + price_high) ÷ 2     （默认取中值，保留区间用于敏感性）
```

## 三、到厂成本

### 3.1 运费求解（按优先级，绝不填默认值）

```
若 freight_total 有值:   F_i = freight_total
否则若 freight_unit 有值: F_i = freight_unit × Q
否则:                    F_i = 未定义  →  该区域到厂成本 = "待补"
```

若给了多段 `freight_lines`（如 汽运 + 内河），则每段各自求解后求和；任一段缺价，整段链即"待补"。

### 3.2 单位换算

```
f_i = F_i ÷ Q            （元/吨）
```

### 3.3 操作费用

```
操作费总额 S_i = L_i + U_i + I_i + O_i
操作费单价 s_i = S_i ÷ Q
```

其中 `loadingUnit`（元/吨）若给出，则 `L_i = loadingUnit × Q`，覆盖从整单金额换算的结果。

### 3.4 到厂成本

```
C_i = P_i + f_i + s_i
T_i = C_i × Q  =  P_i × Q + F_i + S_i
```

**完整性判定**：只有 `P_i`、`f_i`、`s_i` 三者都有定义，`C_i` 才有定义。

### 3.5 缺项清单

每个区域会生成 `gaps[]`，逐项列出缺什么：

```
装车费 / 卸车费 / 检测/取样费 / 运费（每吨运价或总运费） / 现货价格缺值
```

## 四、因素分解

以**基准区域** *r*（`benchmark_region_id`）为参照，对每个其他区域 *i*：

```
Δ裸价_i  = P_i − P_r
Δ运费_i  = f_i − f_r
Δ装卸_i  = s_i − s_r
─────────────────────────
Δ到厂_i  = C_i − C_r  ≡  Δ裸价_i + Δ运费_i + Δ装卸_i
```

### 4.1 闭合校验

三者之和必须**恒等于** Δ到厂（浮点误差 < 0.01 元）。HTML 与 Excel 都会显示"✓ 闭合"。
如果出现不闭合，说明有未计入的费用项 —— 那是 bug，不是市场现象。

### 4.2 关键性质

| 单调性 | 说明 |
|---|---|
| Δ裸价 < 0 | 该区域裸价更便宜 |
| Δ运费 > 0 | 该区域运费更贵（通常因为距离远） |
| Δ裸价 + Δ运费 > 0 | 价格优势**不足以**覆盖运输劣势 → 远距离低价区不划算 |
| Δ裸价 + Δ运费 < 0 | 价格优势**足以**覆盖运输劣势 → 值得异地采购 |

**这就是本 skill 最核心的判断逻辑**：便宜不等于划算，要看裸价差能不能被运费吃掉。

### 4.3 运输盈亏平衡点

给定裸价差 `ΔP = P_远 − P_近`（负数表示远处更便宜），有：

```
盈亏平衡运价 = |ΔP| ÷ D_远        （元/吨·公里）
```

即：只要远处线路的吨公里运价**低于**这个值，异地采购才划得来。

> ⚠️ 这个公式只用于**判断方向**，不能用来**生成运费金额**。
> 正确用法：拿到真实运价后再比较"实际运价 与 盈亏平衡运价"。

## 五、历史价差

### 5.1 同日价差

对每个"同日各区域都有报价"的日期 *d*：

```
spread_mid(d, i)  = mid_i(d) − mid_r(d)
spread_low(d, i)  = low_i(d) − low_r(d)
spread_high(d, i) = high_i(d) − high_r(d)
mid_i(d) = (low_i(d) + high_i(d)) ÷ 2
```

### 5.2 区间统计

```
历史区间 = [ min_d(区域极差) , max_d(区域极差) ]
区域极差(d) = max_i(mid_i(d)) − min_i(mid_i(d))
```

只用**可比日**，不插值、不跨期拼凑。

## 六、边界与限制

| 限制 | 说明 |
|---|---|
| 不含资金成本 | 账期、预付/到付差异不建模 |
| 不含损耗 | 运输破损、受潮不建模 |
| 不含库存成本 | 长途到货周期长，占用资金不建模 |
| 不含税费抵扣差异 | 默认均可抵扣，未区分小规模纳税人 |
| 运费口径靠用户保证 | 系统无法判断"含税/含装卸"是否一致，只在 UI 提醒 |
| 里程为路线库值 | 不含厂区到高速口短驳与末端配送 |

这些都是**已知的边界**，应在报告里明说，而不是假装没有。
