# 示例 02：纯碱（碳酸钠，氨碱法）原料成本

> 这个示例的价值不在"算出一个漂亮数"，而在**演示缺口必须被暴露**：
> 4 种原料里只有 2 种拿得到可核验价格，所以合计只覆盖 61.5% 的原料种类，
> 页面与工作簿都明确写"部分覆盖"，而不是把缺的当 0 糊过去。

- **产品**：轻质纯碱（Na₂CO₃），CAS 497-19-8
- **工艺**：氨碱法（索尔维法）：化盐 → 盐水精制 → 吸氨 → 碳化 → 过滤 → 煅烧 → 蒸氨再生
- **数据截止**：2026-10-20，含税，元/吨产品

## 一、单耗（公开行业口径，多源交叉）

| 原料 | 单耗 | 来源 | 交叉验证 |
|---|---|---|---|
| 原盐（NaCl） | **1.5 t/t** | 山东化工网《氨碱法纯碱：在变局中探寻可持续发展之路》(2025-02-27)：每吨纯碱消耗原盐 1.5 吨 | 光期研究《走进纯碱原料——原盐》：氨碱法原盐吨耗 **1.6 t/t 左右**；七禾网成本公式用 1.6 |
| 石灰石（CaCO₃） | **1.3 t/t** | 同上（山东化工网 2025-02-27） | 雪球成本拆解：石灰石 1.3 t/t |
| 动力煤 | **0.58 t/t** | 七禾网《纯碱生产成本核算》(2025-04-24)：氨碱法 1 吨纯碱成本 = 原盐×1.6 + **动力煤×0.58** + 烟煤×0.1 + 550 | 雪球：动力煤 0.6 t/t |
| 液氨（补充） | **0.004 t/t** | 行业通识：氨为循环介质，正常仅补充损失，吨碱约 2–5 kg；取 4 kg/t | — |

本模型取**保守值**（原盐 1.5 而非 1.6），因为 1.5 有更明确的行业媒体来源。

⚠️ 单耗口径提示：以上均为**行业典型值**，不是某厂实测。不同装置（规模、真空度、碳化塔型式、
盐质）差异可达 ±10%。若你有企业消耗定额，请替换后重算。

## 三、结果

| 项 | 数值 |
|---|---|
| **已计价部分合计** | **614.53 元/吨** |
| 动力煤 | 603.78 元/吨（**98.25%**） |
| 液氨 | 10.75 元/吨（**1.75%**） |
| 覆盖 | **2 / 4 种原料已计价（部分覆盖）** |

**这个数不能当成纯碱的原料成本。** 氨碱法真正的原料大头是原盐（1.5 t/t）+ 石灰石（1.3 t/t），
行业口径下原盐+石灰石约占原料成本的 55%。本示例正是要让你看到：
**缺了最关键的两项，合计只剩"燃料 + 循环介质"。**

敏感性（已计价部分）：动力煤 ±10% → ±60.38 元/吨；液氨 ±10% → ±1.07 元/吨。

历史：30 天 +31.71（+5.44%），3 个月 +118.33（+23.85%）；1 年/3 年**缺口**。

## 四、怎么把它变成完整口径

把本厂到厂价填进 `input.json`：

```json
{"id": "salt", "price": {"value": 480.0, "unit": "CNY/t", "tax_included": true,
  "spec": "工业盐 ≥96%", "region": "华东", "delivery": "送到",
  "date": "2026-10-20", "source_ref": "本厂采购合同价", "url": ""}}
```

同样补 `lime`。然后重跑：

```powershell
$env:PYTHONUTF8='1'
python scripts\build_all.py examples\02-soda-ash-solvay\input.json --out out --name 纯碱-华东
```

合计、占比、敏感性、历史曲线会立即变成完整口径。

## 五、未纳入

原盐、石灰石、烟煤（煅烧用）、能源（电、蒸汽）、人工与制造费用、
折旧/维护/环保（氨碱法废液处理成本高）、运输包装仓储、税费。
另：氨碱法碳排放成本未计入（非原料成本，但会影响完全成本竞争力——
行业数据显示氨碱法完全成本较天然碱高 400–600 元/吨）。

副产：蒸氨废液（氯化钙溶液）无商业价值，**不分摊、不抵扣**。
