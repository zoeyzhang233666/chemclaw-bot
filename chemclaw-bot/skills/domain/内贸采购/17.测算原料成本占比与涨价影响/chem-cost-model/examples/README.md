# 示例索引

两个示例都是为了证明：**同一套引擎、同一套口径规则，换产品照样能用。**

| # | 产品 | 工艺 | 特点 | 看什么 |
|---|---|---|---|---|
| 01 | **DOP**（邻苯二甲酸二辛酯，DEHP） | 酯化（苯酐 + 异辛醇） | 真实价格 + 环评单耗，两个主料都有价 | 完整的成本占比、±10% 敏感性、两主料对冲情景、贡献分解 |
| 02 | **纯碱**（碳酸钠） | 氨碱法（索尔维法） | 真实价格 + 行业单耗，**有两个原料没价格** | **缺口处理**：缺价原料不按 0 计入、合计标"部分覆盖" |

## 01-dop-dehp

```
input.json                     输入（含 93 天真实价格序列）
out/DOP-华东_理论原料成本.html   交互计算器
out/DOP-华东_理论原料成本.xlsx   公式版工作簿（11 表）
out/result.json                引擎结果（唯一数据源）
```

关键数字（数据截止 2026-10-20，含税）：

- 理论原料成本 **10,642.78 元/吨**
- 苯酐 0.383 t/t × 10,616.67 = **4,066.18 元/吨（38.21%）**
- 异辛醇 0.678 t/t × 9,700.00 = **6,576.60 元/吨（61.79%）**
- 单一原料 ±10%：苯酐 ±406.62，异辛醇 ±657.66；两主料同涨 10% → **+1,064.28（+10.00%）**
- 历史：30 天 +259.82（+2.50%），3 个月 +2,041.95（+23.74%）；1 年 / 3 年**缺口**（免费源只有 93 天）

单耗口径：净单耗 0.383 / 0.678（环评吨耗表反算），理论值 0.3792 / 0.6669 作下界，
表观投料 1:2 ~ 1:2.56 **不能当单耗**。三套口径都在页面的"工艺"标签里可切换。

辅料（钛酸酯催化剂 0.375 kg/t、NaOH 1.02 kg/t、活性炭 0.2 kg/t）单耗已知但**价格未采集**，
按缺口列示、不按 0 计入。

## 02-soda-ash-solvay

```
input.json
out/纯碱-华东_理论原料成本.html
out/纯碱-华东_理论原料成本.xlsx
out/result.json
```

关键数字（数据截止 2026-10-20，含税）：

- 已计价部分 **614.53 元/吨**（动力煤 603.78 + 液氨 10.75）
- **但这不是纯碱的完整原料成本**：原盐（1.5 t/t）与石灰石（1.3 t/t）缺可核验日度价格，
  按缺口处理。页面与工作簿都明确标注"2 / 4 种原料已计价（部分覆盖）"。
- 动力煤 ±10% → ±60.38 元/吨；液氨 ±10% → ±1.07 元/吨
- 历史：30 天 +31.71（+5.44%），3 个月 +118.33（+23.85%）

单耗来源：山东化工网（原盐 1.5 / 石灰石 1.3 t/t）、七禾网成本公式（动力煤 0.58 t/t）、
光期研究（原盐 1.6 t/t 交叉验证）。**三处独立来源互相印证。**

### 这个示例为什么重要

它演示了本技能最核心的诚实性要求：**宁愿交一个"部分覆盖"的结果，也不假装完整。**

如果你拿到本厂原盐/石灰石到厂价，把它们填进 `materials[salt].price` 与 `materials[lime].price`，
重跑 `build_all.py`，整个模型的合计、占比、敏感性与历史曲线会立刻变成完整口径。

## 自己做一个

```powershell
$env:PYTHONUTF8='1'
copy examples\input.template.json my-input.json
# 编辑 my-input.json
python scripts\build_all.py my-input.json --out out --name 我的产品
```

## 抓真实价格

```powershell
python scripts\fetch_prices.py --list
python scripts\fetch_prices.py --pid 541 --name 苯酐 --pid 489 --name 异辛醇 --out prices
```

抓到的 CSV/JSON 直接贴进 `history.materials[].rows`。
记住：该端点**只给最近 93 天**，1 年/3 年请如实写缺口。
