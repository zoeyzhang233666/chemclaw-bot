# 价格数据标准：六项口径与采集

> 采购侧的成本模型，价格错一点，结论就翻。**每条价格都必须能被人复核。**

## 1. 六项口径（缺一项即记入缺口清单）

| # | 字段 | 说明 | 例 |
|---|---|---|---|
| 1 | **规格** | 含量/品级/形态 | `≥99.0%`、`99.5% 片状`、`工业级` |
| 2 | **地区** | 市场/产区/送到地 | `华东`、`山东`、`华南送到` |
| 3 | **交货方式** | 出厂 / 库提 / 送到 | `自提`、`送到含运` |
| 4 | **含税与否** | 含 13% 增值税 / 不含 | `含税` |
| 5 | **计价单位** | 元/吨、元/千克、USD/t | `元/吨` |
| 6 | **日期 + 来源** | 数据日期（非访问日期）+ 出处 | `2026-10-20`，生意社 |

> **口径不同不相减。** 含税 vs 不含税、出厂 vs 送到、华东 vs 山东，必须先换算或分列，
> 不能"平均一下"再减。

## 2. 来源优先级

| 级别 | 来源 | 拿什么 | 可信度 |
|---|---|---|---|
| A | 交易所、海关、统计局 | 期货日线、进出口量价、PPI | 高（但不是现货） |
| B | 资讯商（隆众、卓创、金联创、生意社、Mysteel） | 分区域现货区间/均价 | 中高 |
| C | 券商/期商日报 | 现货表格、产业链利润 | 中 |
| D | 厂家挂牌/竞拍成交 | 出厂价、成交价 | 高（只代表该厂） |
| E | 综合媒体 | 事件、检修 | 低（当背景） |

**期货价 ≠ 现货价。** 用期货做成本模型必须说明基差；本技能默认要求现货价。

## 3. 可编程采集：生意社（100ppi）基准价

`scripts/fetch_prices.py` 已封装：

```powershell
$env:PYTHONUTF8='1'
python scripts/fetch_prices.py --pid 541 --name 苯酐      # 输出 CSV + JSON
```

原理：
1. 首次请求返回 636 字节 JS 拦截页，正则取 `var _0x2 = "<hex>"` → 回填 `Cookie: HW_CHECK=<hex>`；
2. 商品曲线接口 `/graph/cindex.php?f=graph_ppid_ave&ppid=<PID>` 返回 packer 混淆的 ECharts option；
3. 解包后取 `xAxis.data` + `series[0].data`。

**已知限制（必须写进报告）**：
- 该端点**固定只返回最近 93 个日历日**，任何时间参数均无效；
- 序列含周末/节假日**承袭值**，不是新报价；
- 覆盖品种有限且规格固定（如需 99.5% 片状苯酐，须加升贴水并注明是估算）。

## 4. 缺口怎么办（这是本技能的重点）

| 情形 | 做法 | 禁止 |
|---|---|---|
| 某原料完全拿不到价 | `price=null`，列为缺口，成本标"未计入" | 填 0、用同类品替代而不说明 |
| 历史只有 93 天 | 1 年 / 3 年窗口标"无法计算" | 插值、按行业趋势"补"曲线 |
| 只有期货价 | 可作参照，注明基差未扣 | 直接当现货价 |
| 只有月均价 | 可作月度序列，注明频率 | 拆成日线 |
| 规格不符（基准 99% vs 你要 99.5%） | 加升贴水并标"估算值" | 假装是同一口径 |

## 5. 区域与规格的处理

- **区域**：成本模型优先用"你实际采购地"的价。用全国均价时必须在页脚写明。
- **规格**：不同规格价差可能很大（片状 vs 熔融、优等品 vs 合格品）。差 100–300 元/吨就会被当成"降本空间"。
- **税**：默认统一到**含税**（采购视角最常用），税率 13% 默认值须企业核定。

## 6. 数据留痕（`history.materials[]`）

```json
{
  "material_id": "pa", "name": "苯酐", "unit": "CNY/t",
  "source": "生意社（100ppi.com）基准价 · 苯酐",
  "source_url": "https://www.100ppi.com/graph/cindex.php?f=graph_ppid_ave&ppid=541",
  "spec": "≥99.0%", "region": "华东", "tax_included": true, "freq": "日",
  "retrieved_at": "2026-10-20",
  "method": "曲线接口 + HW_CHECK cookie + packer 解包；端点固定返回 93 天",
  "rows": [{"date": "2026-07-20", "value": 8666.67}, ...]
}
```

`retrieved_at` 是**抓取日**，`date` 是**数据日**，两者必须分开记录。
