# 交付前人工复核清单

> 自动化检查（validate / check_result / check_xlsx / check_workbook / qa_render）跑完之后，
> 人工再过一遍下面 12 条。**任何一条打不了勾，就不要交付。**

## A. 数据可信

- [ ] 1. 每种原料的单耗都能指出「来源文件 + 字段/表号 + 适用工艺」。
- [ ] 2. 每条价格都是六项口径齐全（规格/地区/交货/税/单位/日期+来源），且链接可打开。
- [ ] 3. 所有"模拟"参数都有醒目标注，且没有混进真实数据区。
- [ ] 4. 数据截止日统一，且价格与单耗的时间口径不矛盾。

## B. 计算正确

- [ ] 5. 手算校验一处：拿占比最高的原料，`单耗 × 价格 = 单项成本` 对得上；`Σ单项 = 合计` 对得上。
- [ ] 6. ±10% 的单原料影响 = 该原料单项成本 × 10%（同比例线性）。
- [ ] 7. 全同步 ±10% 的合计变化 = 总成本 × 10%。
- [ ] 8. 历史曲线末行的成本 ≈ 当期成本（价格一致时应相等）。

## C. 表述安全

- [ ] 9. 页面/工作簿里，**没有**任何"预计/预测/建议买入/利润"字样的结论。
- [ ] 10. "理论原料成本"每次出现都带有"不含能源/人工/折旧，不等于生产成本"的说明。
- [ ] 11. 缺口清单存在且完整（缺价格的原料没有被按 0 计入）。

## D. 可交付

- [ ] 12. HTML 双击能开、图表能画、改单耗会变；Excel 双击能开、改单耗占比会变、无 `#REF!`/`#DIV/0!`。

---

## 常见退回原因（按频率）

1. 单耗把"投料比 1:2"当成单耗（错 100%+）。
2. 含税价与不含税价直接相加。
3. 缺价格的原料被填 0，导致总成本偏低。
4. 历史只有 93 天，却画了 3 年曲线（插值/编造）。
5. 用原料成本差价说成"利润"。
6. Excel 公式引用写死行号，增加原料后错位。
7. 页面上写了"预计下月上涨"。
8. 单耗来源没写工艺，导致混用不同工艺的数据。
