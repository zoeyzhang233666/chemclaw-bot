# 全量公式与推导

> 本文件是**唯一公式权威**。`scripts/cost_engine.py` 是唯一实现；`scripts/build_xlsx.py` 用 Excel 公式再现；
> `scripts/assets/app.js` 用 JS 再现。三者必须逐字一致，**改公式要同时改三处并跑 `tests/test_engine.py`**。

符号约定
--------
| 符号 | 含义 | 单位 |
|---|---|---|
| `q_i` | 原料 i 的单位产品单耗（t 原料 / t 产品） | t/t |
| `p_i` | 原料 i 的价格（目标税口径、目标币种） | 元/t |
| `c_i` | 原料 i 的单项成本 | 元/t 产品 |
| `C` | 单位产品理论原料成本 | 元/t 产品 |
| `w_i` | 单项成本占比 | % |
| `r_i` | 价格变动幅度（+10% → 0.10） | 无量纲 |
| `C_t` | 第 t 日的理论原料成本 | 元/t 产品 |

---

## 1. 核心公式

### 1.1 单项成本与总成本

```
c_i = q_i × p_i
C   = Σ_i c_i
```

### 1.2 成本占比

```
w_i = c_i / C × 100%         （Σ w_i = 100%，前提是所有原料均已计价）
```

> **重要**：当有原料缺价格时，`C` 只覆盖已计价原料，`w_i` 是"占已计价部分"的比例。
> 页面与 Excel 必须把这种口径标为"部分覆盖"，不能等同为"占全部原料成本"。

### 1.3 单项价格变动影响

```
Δc_i(r) = q_i × Δp_i = q_i × p_i × r = c_i × r
新成本    = C + Δc_i
```

### 1.4 多原料组合情景

```
C'(r_1..r_n) = Σ_i q_i × p_i × (1 + r_i)
ΔC           = C' − C = Σ_i c_i × r_i
ΔC%          = ΔC / C × 100%
```

**特例校核**：若所有 `r_i = r` 相同，则 `C' = C × (1+r)`，`ΔC% = r`。这条恒等式是 `check_result.py` 的自检基准。

### 1.5 单耗变化的影响（与价格影响同构）

```
∂C/∂q_i × Δq_i = p_i × Δq_i
```

页面中的"单耗 +1%"即 `Δc_i = 0.01 × q_i × p_i`，用来回答"单耗降 1% 能省多少钱"。

## 2. 单耗：从化学计量到工业净耗

### 2.1 理论单耗（化学计量下限）

对反应 `aA + bB → cC + dD`（C 为目标产品）：

```
q_A,theo = a × MW(A) / (c × MW(C))
```

实现：`scripts/stoichiometry.py`

```python
theoretical_dosage("C8H4O3 + 2 C8H18O -> C24H38O4 + H2O", "C24H38O4", "C8H4O3")
# -> 0.3792   (148.117 / 390.564)
```

分子量由化学式解析并按 IUPAC 2019 原子量计算，避免手抄分子量出错。

### 2.2 表观投料（含过量，不回收）

```
R          = 实际投入摩尔比 / 理论摩尔比 = 1 + 过量百分比
q_apparent = q_theo × R
```

### 2.3 净单耗（工业口径，推荐）

```
净单耗 = q_theo / (转化率 X × 收率 Y) + q_theo × (R − 1) × (1 − 回收率 ψ) × (1 + 副反应损失 λ)
```

当 ψ = 1（过量部分 100% 回收）时，净单耗 = `q_theo / (X·Y)`，即过量不影响净耗。
**这就是为什么"过量 20%"和"净单耗 0.678"可以同时成立**（DOP：过量 20% + 回收 ~96.6% + 副反应 1%）。

### 2.4 收率的两种定义（务必区分）

| 定义 | 公式 | 常见出处 |
|---|---|---|
| 以主要原料计 | `Y = 产品摩尔数 / 主要原料投料摩尔数 / 理论系数` | 教材、课程设计 |
| 以成品质量计 | `Y = 合格成品质量 / 理论成品质量` | 企业 ERP、环评 |

**不得把两种收率混乘。** 若原文写"收率 99.3%"，须确认是哪一种；确认不了就在 `process_params.notes` 写明"收率定义待确认"。

### 2.5 含量折算（规格不是 100% 时）

```
q_实际配料 = q_理论需求 / 含量%
```

例：需要 100% 的 NaOH 1.02 kg/t，用 97% 片碱 → `1.02 / 0.97 = 1.052 kg/t`。

## 3. 价格：单位与税口径

### 3.1 计量单位

```
元/kg  → 元/t ：× 1000
美元/kg → 元/t ：× 1000 × 汇率
单耗 kg/t → t/t：÷ 1000
单耗 g/t  → t/t：÷ 1 000 000
```

### 3.2 税口径（只做可逆换算，税率必须显式给出）

```
含税 → 不含税 ：÷ (1 + 税率)
不含税 → 含税 ：× (1 + 税率)
```

- 默认税率 13%（中国增值税一般纳税人常见税率），**必须在页脚与 Excel 注明"默认值，须企业核定"**。
- 小规模纳税人、享受优惠、进口货的关税+增值税，不能套 13%。
- **含税价与不含税价之间不做减法**，先统一再算。

### 3.3 交货方式

出厂 / 库提 / 送到（含运费）。送到价通常高出 50–300 元/吨，取决于距离与批量；
**不同交货方式的价格直接相减是错误**，须在 `price.delivery` 里标注。

## 4. 历史理论原料成本

```
C_t = Σ_i q_i(t) × p_i(t)
```

### 4.1 三种历史口径（必须在 `history.blend[].basis` 显式声明）

| basis | 含义 | 适用 |
|---|---|---|
| `fixed_q0` | 用当期显示的固定单耗 × 历史价格 | 默认。回答"同一条产线、同一消耗定额下成本怎么变" |
| `applied_research` | 逐年套用研究得到的历史单耗 | 有逐年单耗数据时 |
| `chained` | 单耗也随年份变化（需逐年数据） | 长周期工艺演进研究 |

### 4.2 缺口处理

- 某日某原料无价格 → 该日 `C_t` 记为 `null`，**不插值**。
- 历史窗口起点早于序列起点 → 标注"无法计算"，**不外推**。
- 周末/节假日平台承袭值：可用于画图，**不用于波动率/分位数统计**。

### 4.3 贡献分解

```
Δc_i  = q_i × (p_i,T − p_i,0)
ΔC_T  = Σ Δc_i = C_T − C_0
贡献比 = Δc_i / ΔC_T
```

`|ΔC_T| < 0.01 元/吨` 时**不给贡献比**（分母趋零，比例无意义），改为文字描述"涨跌相抵"。

## 5. 联产 / 副产 / 多产品分摊

**没有依据不得分摊。** 只有在用户提供依据时才计算，`byproducts` 字段必须写清 `basis`。

| 方法 | 公式 | 依据来源 |
|---|---|---|
| 按质量 | `成本_i = 总成本 × 质量_i / Σ质量` | 企业成本核算制度 |
| 按价值（相对销售价格法） | `成本_i = 总成本 × (质量_i × 单价_i) / Σ(质量×单价)` | 会计准则常用 |
| 副产抵扣 | `主产品成本 = 总成本 − Σ(副产品质量 × 市价)` | 需副产市价 |

DOP 副产水无商业价值 → 不做抵扣（写明理由），而不是"按 0 元抵扣"了事。

---

## 6. 与产品价格的关系（加工价差，不是利润）

```
加工价差 = 产品现货价 − 理论原料成本
价差率   = 加工价差 / 产品现货价
```

**必须同时展示"未纳入项"清单**：能源、人工、折旧、维护、包装、运输、期间费用、损耗。
仅凭价差判断"利润高不高"是外行做法——DOP 的蒸汽与电耗可占总成本 5%–10%。

---

## 7. 自检恒等式（`scripts/check_result.py` 自动执行）

1. `Σ c_i == C`（容差 0.01）
2. `Σ w_i == 100%`（所有原料都有价格时）
3. `Δc_i(0%) == 0`
4. 全同步情景 `ΔC% == r`（线性恒等）
5. 组合情景 `C' == Σ q_i p_i (1+r_i)`
6. 历史末行 `C_t` 与"当期 C"在价格一致时相等（容差 1 元）
7. 贡献分解 `Σ Δc_i == ΔC_T`
