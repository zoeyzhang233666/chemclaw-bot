# 表述边界：能说什么、不能说什么

> 采购侧的成本模型一旦被误读成"利润预测"，就会直接导致错误决策（压价压到亏、囤货囤在顶上）。
> 本文件是所有对外文字的**红线清单**。

## 1. 三个概念必须分清

| 概念 | 含什么 | 本技能是否产出 |
|---|---|---|
| **理论原料成本** | 只有"有价格的原料单耗 × 价格" | ✅ 这就是产出 |
| 生产成本 | ＋能源、辅材、人工、折旧、维护、环保 | ❌ 不产出（只列未纳入项） |
| 完全成本 / 利润 | ＋期间费用、税、销售、财务费用 | ❌ 绝不产出 |

**标准表述**：
> 本模型测算的是**单位产品理论原料成本**，只包含"已知单耗 × 已知价格"的原料部分，
> 不含能源、人工、折旧、运输与期间费用，**不等于生产成本，也不能用来推算利润或对外报价**。

## 2. 不能说的话（说了就是错）

| ❌ 禁止 | 为什么 | ✅ 改成 |
|---|---|---|
| "预计下月成本会涨到 X 元" | 预测价格 | "若原料价格同步 +5%，成本将变为 X 元（机械演算，非预测）" |
| "现在该囤货/建议买入" | 投资建议，无资质 | "敏感性显示：辛醇每涨 5%，成本 +329 元/吨，占当前成本 3.1%" |
| "该产品利润约 X 元/吨" | 用原料成本差价冒充利润 | "产品现货与理论原料成本的价差为 X 元/吨，**未扣能源/人工/折旧等**，不代表利润" |
| "单耗行业平均 0.38"（不注来源与工艺） | 口径不明 | "净单耗 0.383 t/t，来源：某环评报告书产品吨耗表，适用半连续酯化工艺" |
| "苯酐价格 10617 元" | 缺口径 | "苯酐 ≥99.0%，华东，含税，自提，2026-10-20，生意社基准价 10616.67 元/吨" |
| "历史上 2024 年成本约 X"（数据只有 93 天） | 生成虚假序列 | "1 年/3 年窗口无公开免费数据，显示为缺口；补齐路径见缺口清单" |
| "辅助材料忽略不计" | 隐含为 0 | "催化剂/碱/活性炭单耗已知但价格未采，按缺口列示（未按 0 计入）" |

## 3. 必须出现的声明（任一输出都要有）

1. 理论原料成本 ≠ 生产成本 ≠ 利润。
2. 价格口径（规格/地区/交货/税/单位/日期/来源）。
3. 单耗口径（工艺 + 来源 + 净耗/表观）。
4. 未纳入项清单。
5. 缺口清单（缺什么、为什么缺、怎么补）。
6. 敏感性为机械演算，非预测。
7. 数据截止日。

## 4. 表述模板

**总结句（可直接粘给老板）**
> 按【数据日】【区域】含税现货价与【单耗来源】净单耗测算，【产品】每吨**理论原料成本**约 **X 元**，
> 其中【原料A】占 a%、【原料B】占 b%。原料价格各涨 10% 时，成本分别 +ΔA、+ΔB 元/吨；
> 两种主料同涨 10% 则 +Δ 元/吨（+10%）。该数字只含原料、不含能源与人工，**不等于生产成本**，
> 也不含任何价格预测。

**回答"会不会涨"**
> 我不预测价格。能给你的是：现在这个价位在近 3 个月里处于什么位置、涨 5%/10% 对你成本的影响、
> 以及成本主要被哪种原料牵着走。

**回答"现在能不能下单"**
> 这属于采购决策，需要你自己结合库存、订单和账期判断。我能提供的是价格事实（口径+来源+日期）、
> 成本占比结构、敏感性，以及区域/规格价差。

## 5. 数据"美化"禁止清单

- 不得为了让曲线好看而插值、平滑、外推。
- 不得把"约""左右"用在关键数字上（成本、单耗、占比必须给到小数位）。
- 不得用"行业惯例""据了解"代替来源。
- 不得把模拟参数混进真实数据段（必须单独标注黄底 + "模拟"）。
- 不得隐去不利信息（如某原料占比 62%、单耗来源存疑、规格不匹配）。

## 6. 当用户要求"给个准数/预测"时

明确拒绝预测，但**不要空手拒绝**，给出三样替代：
1. 事实：当前价格与口径；
2. 结构：成本构成与占比；
3. 边界：涨跌 5%/10% 的机械影响 + 历史波动区间（有多少数据说多少）。
