# 研究方法：从产品到成本模型（通用六步）

> 适用于任何化工品：大宗（DOP、甲醇、纯碱、尿素、PVC），精细化工（对苯二酚、丙烯酸），化工中间体（对硝基氯苯、三聚氯氰）。
> 每一步都有"做完的信号"，没做到就停在原地，不要往下算。

## 第 1 步 产品与工艺识别

**要产出**
1. 产品标准名 + 常用名 + CAS + 分子式/结构
2. 商品规格（含量、色号、水分、应用等级）——决定原料规格
3. **主流工艺路线清单**（通常 2–4 条），每条给出：核心反应、催化剂体系、关键操作条件（温度/压力/相态）
4. **反应式**（可配平、可做质量守恒校验）
5. 联产/副产情况

**查什么**
- 工艺教科书/设计书（routes 与投料比）
- 专利实施例（最真实的操作参数）
- 环评报告书（真实装置的吨耗与规模）
- 国外机构评估文件（EPA/EU 的 TSD、BREF），常给出多工艺对比
- 企业公开的技改/招标文件（产能、单耗宣示）

**做完的信号**：能写出 `aA + bB → cC + dD` 且 `ΣMW(左) = ΣMW(右)`；
能用一句话区分两条工艺（例：DOP 的差异在"酯化是否连续"与"催化剂决定后段温度"）。

**常见错误**：只找到一条工艺就下结论；把"某厂的工艺"当成"主流工艺"。

## 第 2 步 单耗核验

**要产出**：每种原料一个 `q`，带 (口径层级, 数值, 单位, 来源, 适用工艺)。

**优先级**
1. 用户企业实测（ERP 消耗 / 领料单 / 工艺包）→ 直接用
2. 环评吨耗表（`年用量 ÷ 年产能` 交叉验证）
3. 专利实施例反算（投料量 ÷ 对应产量）
4. 行业标准/协会平均
5. 教材/设计书
6. **模拟值**（只有前五条都拿不到时才用，必须标注）

**必做的三件事**
- 口径判定（理论/净耗/表观投料/配料，见 `unit-consumption.md`）
- 与理论值比对：`q 应落在 [q_theo, 1.2 × q_theo]`；偏离超过 20% 要回头查
- 工艺一致性：主料必须同一工艺

**做完的信号**：每种原料都能回答"这个 0.383 是哪来的、什么口径、什么工艺"。

## 第 3 步 市场价格匹配

**要产出**：每种原料一条六项口径齐全的价格 + 可选的历史序列。

**匹配顺序**
1. 你实际采购地 + 实际规格 + 实际税口径的现货价（最优）
2. 同区域同规格的资讯商现货价（注明来源与日期）
3. 区域均价（注明"均价"）
4. 期货价 + 基差说明（仅作参照）

**历史序列**
- 日频/周频最好；至少要有与"用户关心窗口"匹配的长度
- 数据日期 ≠ 抓取日期，两个都要记
- **拿不到就写缺口**，绝不生成曲线

**做完的信号**：每条价格都能点开链接看到；缺口清单里每个缺口都有"补齐路径"。

## 第 4 步 建模计算

写 `input.json` → `build_all.py`：

```bash
$env:PYTHONUTF8='1'
python scripts/build_all.py input.json --out out --name DOP-华东
```

输出：`result.json`（唯一数据源）+ HTML + Excel。

**做完的信号**：`check_result.py` 全绿（±10% 恒等、占比合计 100%、贡献分解闭合）。

## 第 5 步 出稿（信息层级）

页面必须让采购人员在 10 秒内看懂四件事：
1. **每吨产品的理论原料成本是多少**（大数字 + 口径说明）
2. **钱花在哪**（成本占比，谁是大头）
3. **最近涨了还是跌了、涨了多少**（30 天/3 个月；1 年/3 年若无数据就明确说没有）
4. **再涨 5%/10% 会怎样**（敏感性 + 组合情景）

第二层（要查得到）：每个原料的历史价格、来源、贡献；公式与换算过程；缺口清单。

## 第 6 步 自检

- `validate.py`：输入完整性
- `check_result.py`：计算自洽
- `check_xlsx.py` + `check_workbook.py`：Excel 能打开、公式算得对
- `qa_render.py`：HTML 无 JS 错误、图表渲染、改参数会重算
- `qa-checklist.md`：人工过一遍"表述边界"

## 什么时候必须停下来问用户

| 情形 | 为什么停 |
|---|---|
| 产品名有多种可能（如"DOP"也可能是"邻苯二甲酸二辛酯"以外的缩写） | 算错东西全错 |
| 找不到任何可靠单耗，且用户不提供 | 模拟参数必须得到用户确认才能用 |
| 用户给的单耗与理论值差 3 倍以上 | 大概率口径错（把投料比当单耗） |
| 产品价格与原料价格明显不在同一时期 | 价差结论会误导 |
| 联产/副产占比大且无分摊依据 | 分摊比例是结论的一半 |
