# 单耗：四层口径、来源分级与工艺一致性

> 这是本技能**最容易出错、也最影响结论**的一环。单耗错 10%，成本就错 10% 以上。

## 1. 为什么"同一个产品单耗差一倍"

公开资料里同一个产品的"吨耗"可能相差 50%–120%，不是资料造假，而是**口径不同**。
判断口径靠三点：**原文用词、单位、上下文里的回收/收率描述**。

## 2. 四层口径（必选其一，写入 `dosage.basis` 与结果页）

| 层级 | 名称 | 定义 | 典型表达 | 能否直接乘单价 |
|---|---|---|---|---|
| (i) | 理论单耗 | 化学计量，100% 转化、100% 收率 | "理论耗量 0.379 t/t" | ✅ 仅作**下界** |
| (ii) | 净单耗 | 扣回收、含转化率/收率/副反应损失 | 环评"产品吨耗"、"消耗定额" | ✅ **首选** |
| (iii) | 表观投料 | 过量原料**不扣回收** | "苯酐:辛醇 = 1:2（质量）"、"摩尔比 1:2.2" | ❌ 必须先折算 |
| (iv) | 配料口径 | 按含量/湿基/包装计量 | "98% 硫酸 0.5% 催化" | ❌ 先折 100% |

### 2.1 识别陷阱的规则

- 出现 **"比例""投料比""摩尔比""m:n"** → 一律是 (iii)，**不是单耗**。
- 出现 **"吨耗""消耗定额""单耗""t/t 产品"** 且数值接近 `ν×MW/MW` 的 1.00–1.10 倍 → 是 (ii)。
- 出现 **"理论""化学计量"** → 是 (i)。
- 出现 **"含量 98%""含水""湿基"** → 是 (iv)，需 `/含量%`。
- 若资料同时给出"年用量 t/a"和"产能 t/a" → `年用量 / 产能 = 净单耗`（最可靠的自身校验）。

### 2.2 从 (iii) 折算到 (ii)

```
净单耗 = 表观投料 × (1 − 回收率 ψ)   （加上转化/收率修正）
```

ψ 常常没有数据。这时**不要硬折**——把表观投料作为"投料口径"单独列出，并在缺口清单注明
"该口径含未回收过量，实际净耗需企业回收率数据"。

### 2.3 实例（DOP，同一份材料内部的三种数）

| 数字 | 口径 | 说明 |
|---|---|---|
| 0.3792 / 0.6669 | (i) 理论 | 148.117/390.564；2×130.231/390.564 |
| 0.383 / 0.678 | (ii) 净耗 | 环评吨耗表（38250/100000；67762.8/100000） |
| 1:2、1:2.2、1:2.56 | (iii) 投料 | 教材/专利/工厂 SOP，**不可当单耗** |

**交叉校验**：`0.678 / 0.383 = 1.77`（质量比），与"1:2"完全不同——这说明前者是净耗，后者是投料。

## 3. 来源分级（写入 `dosage.source`）

| 代码 | 名称 | 例子 | 可信度 |
|---|---|---|---|
| `user` | 用户提供 | 企业 ERP 消耗台账、实际采购单 | ★★★★★ |
| `enterprise` | 企业自有资料 | 本厂操作规程、工艺包 | ★★★★★ |
| `eia` | 环评/公参文件 | 建设项目环境影响报告书"产品吨耗" | ★★★★ |
| `patent` | 专利实施例 | 实施例给出投料量与产量，可反算 | ★★★★ |
| `standard` | 标准/规范 | 国标/行标的物耗指标 | ★★★★ |
| `assoc` | 行业协会 | 塑协、氮肥协会发布的行业平均 | ★★★ |
| `textbook` | 教材/设计 | 化工工艺学、课程设计 | ★★★ |
| `research` | 券商/研究 | 行业研究报告的成本模型 | ★★ |
| `media` | 媒体/资讯 | 资讯网站的综述 | ★★ |
| `simulated` | 模拟参数 | 无可靠来源时的演示值 | ★（**必须标"模拟"**） |
| `none` | 无来源 | 用户口述未核实 | ★ |

## 4. 工艺一致性（`scope` 字段 + 校验器规则）

**同一模型里，主料的单耗必须来自同一工艺/同一产线。**

- `dosage.scope` 写法：`"工艺名（装置名，产能）"`，例：`"连续法 6 釜串联（钛酸酯催化，10 万吨/年）"`。
- `scripts/validate.py` 会：
  - 比较所有**主料**的 scope 归一化字符串，不一致 → **error（阻断）**；
  - 辅料（催化剂、碱、活性炭）来自不同文件 → **warn**，并在页面注明"辅料单耗跨文件引用"；
  - 若确有依据混用（例如催化剂取自专利而主料取自环评），须在 `meta.allowed_scope_mix` 写明依据，才放行。

## 5. 多工艺对比的正确做法

1. 每个工艺**单独建一套** materials + process_params（各自完整，不跨工艺拼）。
2. 用 `process_alternatives` 把它们列出（HTML 顶部可切换）。
3. 对比时必须说明：单耗差异来自哪一环（过量倍数、回收率、换热/脱醇方式、催化剂体系）。
4. 不同工艺的产能/规模不同，**单耗对比要注明规模**（小装置间歇法的表观投料天然更高）。

## 6. 辅助材料的取舍

- 辅料单耗通常只有 kg/t 级，金额占比小（DOP 中催化剂 + 碱 + 活性炭合计 < 1%）。
- 但只要**价格拿得到**，就应计入——它是真实的原料成本。
- 价格拿不到 → 列入 `materials` 且 `price=null`，页面显示"未计入（不是 0）"。
- **不得**因为"金额小"就把辅料直接忽略并当作 0。

## 7. 收率与联产（详见 formulas.md §2、§5）

- 收率有"以原料计"和"以成品计"两种定义，不可混乘。
- 联产/副产只有在**用户提供分摊依据**时才分摊；否则如实写"未分摊"。
