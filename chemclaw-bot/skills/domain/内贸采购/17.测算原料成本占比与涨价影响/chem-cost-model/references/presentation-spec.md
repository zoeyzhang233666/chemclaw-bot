# 版式规范：HTML 与 Excel 的信息层级

> 目标：采购人员打开就能在 **10 秒**内回答"多少钱 / 钱花在哪 / 涨了没 / 再涨会怎样"。

## 一、HTML（单文件，双击即开）

### 1. 硬性技术要求

- **单文件**：ECharts、数据、JS 全部内联，无任何外链（离线可用、可邮件发送）。
- 无 JS 错误；`qa_render.py` 必须 PASS。
- 首屏不出现横向滚动条（1560px 与 430px 宽都要检查）。
- 打印时保留数据表、隐藏交互控件（`@media print`）。

### 2. 信息层级

**第一层（首屏，必须看全）**
1. 大数字：单位产品理论原料成本 + 口径注脚（数据日、区域、含税）
2. 成本构成（饼/环图）+ 占比标签
3. 近期变化（30 天 / 3 个月；无数据则显式"缺口"）
4. 敏感性结论一句话（谁最敏感、±10% 多少元）

**第二层（滚动可见）**
5. 敏感性热力图（原料 × 档位，色阶 + 数值）
6. 组合情景（可改涨跌幅，即时重算）
7. 历史理论成本曲线（含产品价参照与价差）
8. 贡献分解（这段时间涨的钱是哪来的）
9. 缺口与未纳入项
10. 公式与数据来源

### 3. 交互规范

| 控件 | 行为 | 约束 |
|---|---|---|
| 单耗输入 | `change` 即重算全部模块 | 不接受负数或 0；空 → 该原料标"缺单耗" |
| 价格输入 | 同上 | 空 → 标"缺价格"，**不得按 0** |
| 涨跌幅 | 单原料与组合两处 | 组合行内可改，改后即时重算 |
| 工艺切换 | 只改单耗，不改价格 | 切换后需提示"单耗口径已变" |
| 保存模型 | localStorage | 键名固定，提供"重置" |
| 刷新价格 | 不能跨域抓取，**改为重置到构建时价格**并提示用脚本更新 | 不得假装"已获取最新价" |

### 4. 视觉规范

- 主色 `#2f6db3`，涨 `#c0392b`，跌 `#1f8a5f`，缺口灰 `#8a94a6`。
- 数字一律千分位、保留 2 位；占比 2 位；单耗 4 位。
- 缺口用**灰底 + 文字说明**，不用 0 或短横线敷衍。
- 每个图表必须有 `title` 与单位说明，坐标轴标单位。

### 5. 必有的声明区块

页脚固定包含：口径说明、未纳入项、不预测声明、生成时间与数据截止日。

## 二、Excel（11 表）

| 表 | 作用 | 是否含公式 |
|---|---|---|
| `0_封面说明` | 产品、口径、使用方法、未纳入项、使用限制 | 否 |
| `1_原料参数` | **唯一输入区**（黄色单元格） | G/K/L/M 为公式 |
| `2_成本构成` | 成本、占比、累计占比、排名 + 饼图/柱图 | 全部公式 |
| `3_敏感性矩阵` | A 热力图（第 5 行可改档位）｜B 单原料逐档｜C 组合情景 | 全部公式 |
| `4_组合情景明细` | 每个情景逐原料展开 | 全部公式 |
| `5_历史理论成本` | 日期 × 真实价格 × 单耗 → 成本 + 折线图 | 成本列为公式 |
| `6_贡献分解` | 各时间窗内各原料贡献 | 全部公式 |
| `7_数据来源` | 每条数据一行：类型/标题/URL/用于 | 否 |
| `8_公式与口径` | 全部公式说明与换算系数 | 否 |
| `9_缺口与待补` | 缺口清单与补齐路径 | 否 |
| `10_与产品价并列` | 理论原料成本 vs 产品现货、价差 | 全部公式 |

### 硬性要求

1. **能打开**：`check_xlsx.py` 必须 0 error（合并区域不得重叠、不得单格合并）。
2. **算得对**：`check_workbook.py` 用 Excel 重算，与引擎结果逐格比对（容差 0.01）。
3. 只用标准函数（`SUM`/`SUMPRODUCT`/`IF`/`COUNT`），**不用 `_xlfn` 前缀函数**，保证 WPS/旧版兼容。
4. 输入格统一**黄色底纹 + 蓝字**，公式格灰底；表头深色白字。
5. 所有单元格引用都必须指向 `1_原料参数` 的对应行（用 `ROW` 映射，不写死行号）。
6. 缺口原料的 L/M 列必须为空（用 `IF` 保护），不能出现 `#DIV/0!`。
