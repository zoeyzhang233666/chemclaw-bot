# 02 可比性与不可比清单

> 这份清单是这个技能的"灵魂"：**能判的不放过，不能判的不硬判。**
> 凡是列在"不可比"里的差异，一律标【无法直接比较】/【待确认】并写明原因，**不计入问题数**。

## 一、判定用语（只有这六种）

| 判定 | 含义 | 是否计入问题 |
|---|---|---|
| **一致** | 2 份及以上单证的该字段归一化后完全相同 | 否 |
| **不一致** | 同一事实在 2 份及以上单证中取值不同，且这本该相同 | 是 |
| **缺失** | 该类单证的**必备字段**未载明；或该有的单证未收到 | 是 |
| **计算错误** | 单证内部算术关系不成立（单价×数量≠金额、毛重≤净重等） | 是 |
| **待确认** | 差异存在，但成因可能是交易路径/条款变更，须书面确认后才能定性 | 否（进"待确认事项"） |
| **无法判断** | 只有 1 份单证载明该字段；或扫描件模糊/无文字层，无从比对 | 否 |

## 二、不可比清单（判【无法直接比较】）

| # | 字段 | 单证对 | 原因 | 正确的处理 |
|---|---|---|---|---|
| 1 | 金额 | 形式发票 ↔ 商业发票 | PI 是报价用的预计金额，CI 是实际结算金额；改量、改价、加减费用都会不同 | 只比**单价、数量口径、贸易术语**；金额以 CI 为准并验算 |
| 2 | 数量/件数 | 形式发票 ↔ 商业发票/提单 | PI 写的是"拟装数量"，实装常因罐容/船舱微调 | 以**提单 + 装箱单**实装数为准；差异大于 5% 才需解释 |
| 3 | 发票号 | 形式发票 ↔ 商业发票 | 本来就是两个不同编号 | 不比对 |
| 4 | 件数/净重/毛重 | SDS（第 14 节）↔ 提单/装箱单 | SDS 第 14 节写的是**该产品常规运输形式**（如"8×20MT 标准装运"），不是本船实发数 | 以提单/装箱单为准；仅当 SDS 明确写"本票货物"时才比对 |
| 5 | 通知方 ↔ 收货人 | 提单内 | 通知方与收货人本可以是不同主体（常见：收货人是买方，通知方是买方货代） | 仅在信用证明文规定"通知方须为申请人"时才构成不符 |
| 6 | 生产商 ↔ 卖方/发货人 | COA/SDS ↔ 发票/提单 | 贸易商（Trading Company）与工厂（Manufacturing Company）本是两个主体 | 核对"生产商是否为合同指定工厂"即可 |
| 7 | 原产国 ↔ 装运港国家 | COO ↔ 提单 | 转口贸易、中转港换装时二者可以不同 | 以 COO 为准；与中国—沙特等协定税率相关时须一致 |
| 8 | 包装方式表述 | 合同 "ISO TANK CONTAINERS" ↔ 发票 "ISOTANK" ↔ 装箱单 "BULK IN ISO TANK CONTAINERS" | 同一事物的不同写法 | 归一化后相同即算【一致】，不判不符 |
| 9 | 港名表述 | "KING ABDULLAH PORT, JUBAIL (SAJUB)" ↔ "JUBAIL, SAUDI ARABIA" | 全称/简称/UN-LOCODE 混用 | 归一化（去括号城市码、去 PORT/CHINA 等通用词）后比较 |
| 10 | 公司名后缀 | "NINGBO HAIYUAN … CO., LTD." ↔ "… CO., LTD" | 标点/缩写差异 | 归一化后比较；**核心字号不同才算不一致** |
| 11 | 价格构成 | 合同 CFR ↔ 发票 CFR 但另有"FREIGHT PREPAID"字样 | CFR 下运费由卖方预付是应有之义 | 不比对运费行 |
| 12 | 检验指标（规格） | 合同 "≥99.9%" ↔ COA "≥99.99%（实测 99.97%）" ↔ SDS 典型值 | COA 的"规格"是生产厂内控标准，可以严于合同 | **判据是"实测值是否满足合同下限"**，不是"两个规格字面是否相同" |

## 三、必须判【不一致】的情形（这些不能拿"结构不同"当挡箭牌）

| 字段 | 场景 | 为什么必须一致 |
|---|---|---|
| 合同号 / 提单号 / 发票号 | 不同单证互相引用同一编号 | 编号错 = 引用了别的货，单证相符直接不过 |
| 批号 | 装箱单/COA ↔ 提单 | 批号是质量追溯与索赔的唯一锚点 |
| 数量（MT） | 商业发票 ↔ 装箱单 ↔ 提单 | 三者必须为同一实装数；差一个数就是"短装/超装" |
| 毛重/净重 | 商业发票 ↔ 装箱单 ↔ 提单 | 报关重量、码头作业、运价都与它挂钩 |
| 件数 | 商业发票 ↔ 装箱单 ↔ 提单 | 理货交接按件数 |
| 单价 | 合同 ↔ 商业发票 | 结算单价必须与合同一致或另有书面变更 |
| 收货人 | 发票 ↔ 提单 | 提单收货人决定谁有提货权 |
| 买方/卖方 | 合同 ↔ 发票 | 付汇主体与收款主体错，钱会打不出去 |
| HS 编码 | 合同/发票 ↔ 提单 ↔ 报关资料 | 归类不同直接影响税率与监管证件 |
| CAS 号 | COA/SDS ↔ 合同 | 报关税号与危化品判定的基础 |
| 币种 | 合同 ↔ 发票 | 币种错等于金额错 |
| 贸易术语 | 合同 ↔ 发票 ↔ 提单 | 决定谁付运费、谁投保、价格含哪些费用 |

## 四、差异程度分级（用于决定"要不要停下来处理"）

| 级别 | 触发条件 | 处理节奏 |
|---|---|---|
| 阻断级 | 金额/数量/单价/币种/收货人/买方卖方不一致，或发票算术不成立 | 停付款、停报关，先改单 |
| 重要级 | 提单号/发票号/HS/CAS/规格不符合同下限、毛净重矛盾 | 同日发出更正函，可先报关后补正 |
| 记录级 | 表述差异（港口写法、公司名后缀、包装写法） | 归一化后一致即可，只在台账备注 |
| 观察级 | 属不可比清单内的差异 | 记入"待确认事项"，不阻断流程 |

## 五、判定顺序（防误判）

```text
该字段是否在本类单证的必备字段里？
 ├─ 否 → 该单证留「—」，不比较（可能整行变【无法判断】）
 └─ 是 → 该字段是否有"不可比"规则命中？
      ├─ 是 → 【无法直接比较】/【待确认】+ 原因
      └─ 否 → 归一化后是否唯一？
           ├─ 是 → 【一致】
           ├─ 否 → 是否只有 1 份载明 → 【无法判断】
           └─ 否 → 【不一致】（数值类同时跑计算校验）
```
