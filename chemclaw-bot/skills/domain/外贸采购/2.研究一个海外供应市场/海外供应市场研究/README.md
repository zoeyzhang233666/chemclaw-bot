# 外贸采购 · 场景 2「研究一个海外供应市场」Skill

> 输入一个**目标国家 + 产品**，输出一份可直接用于采购决策与供应商谈判的**海外供应市场研究报告**。
> 适用任何化工品与来源国：研究重点随**工艺路线**自动调整，不依赖固定行业结构。

---

## 这个 Skill 在场景链中的位置

```
1.看主要进口来源国  →  【2.研究一个海外供应市场】  →  3.找海外候选生产商
                              ↓                          ↓
                       4.核验海外供应商  →  5.算进口到厂成本  →  6/7/8/9/10
```

本 Skill 的产出（`data.json` + 企业清单 + 数据缺口表）**就是下游"找生产商/核验供应商"环节的输入底稿**。

## 快速开始

```bash
# 1) 生成 HTML 报告
python scripts/build_html.py examples/saudi-meg/data.json assets/report_template.html "output/报告.html"

# 2) 生成 Excel 工作簿
python scripts/build_excel.py examples/saudi-meg/data.json "output/工作簿.xlsx"

# 3) 运行时自检（需要 Chrome）
node scripts/verify_report.mjs "output/报告.html"
```

依赖：Python 3.10+（`openpyxl`）；Node 18+（仅自检用）。

## 研究方法的核心约束（最容易被质疑的四点）

1. **四类量不互相替代**
   名义设计产能 / 实际产量 / 出口量 / 可供采购量 —— 报告中分列，不做"产能×开工率""出口量÷产能""行业规模×份额"式推算。

2. **集团 ≠ 生产法人 ≠ 产品产能**
   SABIC 不持有装置；Sipchem 不做 MEG。产能一律挂到装置层，每套装置独立记录。

3. **每个数字带口径、年份、来源**
   证据分 A/B/C/D 四级；存在冲突时**两套数字并列**（如 Yansab 700 vs 770 kt），不取平均。

4. **查不到就写"数据缺口"**
   每条缺口给出"为什么查不到 + 怎么核实 + 影响"，而不是用估算填上。

## 实例（沙特 MEG）关键结论

| 项 | 数值 | 口径 |
|---|---|---|
| 名义设计产能 | **7,405 kt/a**（12 套） | 逐套核实（年报 + 总包公告 + 检修名录） |
| 实际产量 | **数据缺口** | 沙特无公开逐企业 MEG 产量 |
| 出口量（2025） | **6,372 kt** / 29.87 亿美元 | HS 2905.31，沙特申报 |
| 对华出口（2025） | **4,042 kt**（63.4%） | 同上 |
| 可供采购量 | **数据缺口** | 只能由企业回答 |
| 企业集中度 | CR1 28.4% / CR3 70.3% / HHI 2,073 | 法人口径；SABIC 体系合计 91.9% |
| 通道 | 东海岸 70%（霍尔木兹）／西海岸 30%（红海） | 2026 年东海岸断供、西海岸为唯一稳定通道 |
