# 海外供应市场研究（研究一个海外供应市场）

## 这个 Skill 解决什么问题

外贸采购在"谈价格"之前必须先回答一个更前置的问题：

> **这个国家到底有没有我们这款产品的生产与出口基础？主要供货主体是谁？货实际上流向了哪里？要把它变成可执行的采购，还缺哪些资料？**

不做这一步，常见的失败是：

- 把**行业总规模**当成**可供采购量**（"该国石化产能 xx Mt，总能分我一点"）；
- 把**企业全部石化产品的产能**当成**目标产品产能**（"这家公司年产 400 万吨，MEG 应该有 100 万吨"）；
- 把**集团品牌**当成**合同主体**（找 SABIC 谈，却在合同里签不出实际装置）；
- 把**名义设计产能**当成**实际产量**（再乘一个"开工率"就变成"产能"）；
- 把**出口量**当成**对你的可供量**（对方 60% 卖给中国，不代表会卖给你，合约、流向偏好、可用通道都会改变它）。

本 Skill 的输出就是把这五件事逐一分层、标注口径、给出证据等级，并明确写出**哪些问题必须回企业核实**。

---

## 何时使用 / 何时不要用

**使用场景**
- 已选定 1–3 个候选来源国，需要判断"哪个国家具备真实的可采购基础"；
- 需要一份可提交给采购决策层/供应商谈判团队的国别供应市场报告；
- 已有海外供应商名单，需要核实其身份、装置、产能与出口能力；
- 需要为后续 "找海外候选生产商 / 核验海外供应商 / 算进口到厂成本" 三个 Skill 提供输入底稿。

**不要单独使用**
- 只想知道"哪国进口便宜"→ 先用"看主要进口来源国"；
- 只要一份可签约价的成本测算 → 用"算进口到厂成本"；
- 需要逐家核验资质与财务 → 用"核验海外供应商"（本 Skill 只做"该找谁 + 缺什么"）。

## 输入清单（缺项时先问，不要猜）

| 字段 | 必要性 | 缺失时怎么办 |
|---|---|---|
| 目标国家 | 必填 | 必须问 |
| 产品名称 + 规格（纯度/等级：纤维级、工业级、树脂级…） | 必填 | 等级决定可比产能与装置，必须问 |
| HS 编码（6 位/10 位） | 强烈建议 | 由产品推导并回读确认（见 `references/01`） |
| 中国目的港 | 建议 | 默认华东主港（宁波/太仓），标"待确认" |
| 采购数量 / 年用量 | 建议 | 不影响研究结构，但不能据此反推对方产能 |
| 已有海外供应商名单 | 可选 | 有则转入"生产企业与装置"逐家核实 |
| 关注的原料与工艺 | 可选 | 由 `references/03` 工艺适配矩阵自动决定研究重点 |

**红线**：缺产品规格时不要开工。MEG 的"纤维级"与"DEG/TEG 副产"在贸易统计里可能是同一个 HS 税号，混在一起会把结论带偏。

## 六步工作流

> 每一步都产出可核查的条目（企业 / 装置 / 数据 / 事件 / 来源），最终汇入 `data.json`。**先把数据落成 JSON，再生成报告**——不要一边写 HTML 一边找数据。

### 第 0 步：定口径（10 分钟，必须做）

先写下**四类量**的定义与单位，后续所有表都按这四列分开：

| 口径 | 定义 | 典型来源 | 允许的用途 |
|---|---|---|---|
| ① 名义设计产能 | 姓名牌/设计能力，kt/a | 年报、工程总包公告、装置库 | 判断"有没有制造业基础" |
| ② 实际产量 | 实际生产量 | 少数年报分产品产量、行业协会 | 判断"生产是否正常" |
| ③ 出口量 | 海关申报离境量 | UN Comtrade / 各国海关 | 判断"货流向哪里" |
| ④ 可供采购量 | 扣除长期合约、内部自用后可购量 | 只有企业能回答 | 决定"能签多少" |

**纪律**：①→② 不做系数推算；③→④ 不做比例外推；行业规模绝不进入 ④ 的推导。

### 第 1 步：产业与生产格局（国家层面）

1. 用工艺路线反推"这个国家为什么有产能"：原料从哪来、能源成本由谁定价、园区在哪。
2. 找出**生产集中地**（工业城/化工园区），记录经纬度（地图要用）。
3. 画"海岸/通道"分布：同一国家的产品可能从不同海岸出运，**通道不同 = 风险不同**。
4. 判断该国在全球贸易中的位置（是否为第一大出口国、是否被主要进口国依赖）。

### 第 2 步：企业、装置与产能核实（本 Skill 的重心）

**企业层**——必须区分三类主体：

| 主体 | 例子 | 处理方式 |
|---|---|---|
| 集团/控股平台 | SABIC | 只记股权与销售平台，**不记产品产能** |
| 生产法人（装置持有者） | SHARQ、YANPET、United(JUPC)、Yansab、Kayan | 产能挂在这一层 |
| 关联但无该产品 | Sipchem、Tasnee | 单列"现无装置/潜在新增"，不进产能表 |

**装置层**——每套装置一条记录，字段固定：
`装置ID / 生产法人 / 装置名 / 所在地(含海岸) / 产品 / 名义产能 kt/a / 产能口径 / 投产时间 / 证据等级 / 口径冲突 / 是否待核实 / 备注(检修·工艺·扩能) / 来源ID`

**证据等级**（必须给每一套装置打标）：
- **A**：公司年报、交易所公告、国家统计、专利商/总包商公告
- **B**：国际专业行业媒体（ICIS、Argus、MEES、OGJ、S&P Global、Reuters、CCFGroup…）
- **C**：第三方数据库/估算（GlobalData、ChemAnalyst、SunSirs…）仅作交叉参照
- **D**：推算或未能取得一手来源 → 标"待核实"，并在报告与 Excel 中高亮

**交叉核对**：本报告逐套加总值 vs 第三方统计的全国/区域值，**差异要解释**，不要强行对齐。详见 `references/02`。

### 第 3 步：出口贸易结构

1. 取**近 3–5 年** HS 编码口径的出口总量（货值 + 数量），逐年。
2. 取**主要目的地**与**对华出口量、占比、均价**。
3. 计算出口量与名义产能的比值——**只作参考，必须注明"不是产量"**。
4. 识别"结构性变化"：某年出口量跳升，是否对应某装置投产？但不要单因归因。
5. 与进口国海关数据交叉校验（识别转口与申报差异）。

数据来源与抓取方法见 `references/04`。

### 第 4 步：集中度与议价结构

- 企业级 CR1/CR3、HHI（按产能或出口量，写明分母）；
- **股权体系合并口径**（如 SABIC 持股体系）往往比法人口径更高，必须单独给；
- 判断：谈判对象是"工厂"还是"统一销售平台"；现货比例是否极低。

### 第 5 步：物流与通道

- 出口港清单（工业港 / 商业港 / 企业自有泊位）；
- 到中国主要港口的**航线、航程、通道瓶颈**；
- 船型与单航次货量（决定起订量）；
- 运保费用变化（战争险、附加费）——这是"到岸成本"的关键变量；
- 通道中断史（海峡、运河、港口事件）。

### 第 6 步：政策、监管与供应事件

- 出口国：出口许可/配额、原料政策、准入门槛；
- 贸易救济：反倾销/反补贴（会影响全球流向，间接影响对华供给）；
- 进口国（中国）：税则号列、危险品、检验检疫；
- 供应事件时间线：计划检修、事故、地缘冲突、通道关闭、设施损毁；
- 每条事件标注**影响强度**（极高/高/中/低/正向）。

## 生成交付物

数据准备完毕后，用提供的脚本一键生成两个文件（模板与脚本在 `assets/`、`scripts/`）：

```bash
# 1) 生成交互式 HTML 报告（自包含单文件，离线可开）
python scripts/build_html.py examples/saudi-meg/data.json assets/report_template.html out/报告.html

# 2) 生成 Excel 数据工作簿（13 个工作表）
python scripts/build_excel.py examples/saudi-meg/data.json out/数据工作簿.xlsx

# 3) 运行时自检（可选，需要 Chrome；会输出各区块渲染长度与 JS 错误）
node scripts/verify_report.mjs out/报告.html
```

**HTML 报告的六个区块**（模板已内置，切换标签即可）：
1. 供应市场概览（KPI、四类口径分层、结论）
2. 生产企业与装置（可按企业/海岸/证据等级筛选，点击进详情抽屉）
3. 原料与产业基础（工艺链 + 强项/约束）
4. 出口贸易（5 年趋势、目的地结构、对华轨迹）
5. 物流与港口（示意地图 + 航线条件）
6. 政策与供应事件（时间线 + 风险矩阵）
7. 来源与核验（数据缺口 + 下一步接洽优先级 + 全部来源）

**`data.json` 结构**：见 `references/06` 的字段规范；可直接复制 `examples/saudi-meg/data.json` 改写。

## 质量标准（交付前自检）

- [ ] 每套装置都有**所在地 + 名义产能 + 产能口径 + 证据等级 + 来源ID**
- [ ] 集团主体**没有**被写入产品产能
- [ ] 报告中"名义产能 / 实际产量 / 出口量 / 可供采购量"**四列分开**，无系数推算
- [ ] 出口数据标注了**年份、税号、报告国口径**
- [ ] 存在**口径冲突**时两套数字并列展示（如 Yansab 700 vs 770 kt）
- [ ] 所有无法核实的项进入**数据缺口表**，每条有"核实路径"与"影响"
- [ ] 政策条目区分"可核实事实"与"需官网复核"
- [ ] 至少给出 3 条**接洽优先级**（找谁、为什么、要什么资料）
- [ ] HTML 运行无 JS 报错；Excel 全部工作表可打开、表头冻结、来源可点击

## 常见失败模式

| 失败模式 | 表现 | 纠正 |
|---|---|---|
| 规模倒推 | "全球缺口 200 万吨，我们能分 5 万吨" | 删除此类推算；改为"需企业确认月可供量" |
| 集团=产能 | 把 SABIC 合计产能写成某装置产能 | 拆到生产法人与装置层 |
| 出口量当产量 | 用出口量/产能得出"开工率 90%" | 出口量含转口与库存去化，只能作参考 |
| 单一来源 | 只有一篇媒体就写死产能 | 至少两源交叉，冲突则并列 |
| 忽略通道 | 只算 FOB 价，不谈战争险与绕行 | 物流章节必须含通道风险与费用变化 |
| 事件堆砌 | 罗列新闻但不判断影响 | 每条事件给"影响强度 + 对可供应量的机制" |

## 参考的实现范例

`examples/saudi-meg/` 是完整跑通的实例：沙特阿拉伯乙二醇（MEG），逐套核实 12 套装置、5 年出口数据、6 家生产法人、红海/波斯湾双通道物流、2011–2026 供应事件（含 2026 年霍尔木兹封闭与朱拜勒遇袭）。
复制它的 `data.json` 结构即可套用到其他国家/产品。
