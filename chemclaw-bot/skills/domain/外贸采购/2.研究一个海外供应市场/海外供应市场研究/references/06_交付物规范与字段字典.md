# 06 · 交付物规范与字段字典

本 Skill 交付三类文件：`data.json`（数据底座）、交互式 HTML（决策层阅读）、Excel 工作簿（可核查/可交接）。

---

## 1. `data.json` 顶层结构

```jsonc
{
  "meta": {...},            // 报告元信息
  "sources": [...],         // 来源记录（S01…）
  "data_grades": {...},     // A/B/C/D 定义（可选）
  "sites": {...},           // 工业城/园区（含经纬度，地图用）
  "companies": [...],       // 企业/生产法人与控股主体
  "plants": [...],          // 装置（产能挂在这一层）
  "capacity_summary": {...},// 分层汇总口径
  "ownership_groups": [...],// 股权体系合并口径
  "feedstock": [...],       // 原料与产业基础（按工艺链）
  "trade": {...},           // 出口贸易（年度 + 目的地 + 均价）
  "concentration": {...},   // 企业集中度
  "logistics": {...},       // 港口、航线、船型
  "policy": [...],          // 政策监管
  "events": [...],          // 供应事件时间线
  "risks": [...],           // 风险矩阵
  "unverified": [...],      // 数据缺口与核实路径
  "next_steps": [...]       // 接洽优先级
}
```

---

## 2. 字段字典

### 2.1 meta

| 字段 | 类型 | 说明 |
|---|---|---|
| title / subtitle | str | 报告标题 |
| country / country_cn | str | 国家（英/中） |
| product / product_cn | str | 产品（英/中） |
| hs_code / hs_note | str | 税号与覆盖范围说明 |
| research_date | str | 研究基准日（YYYY-MM-DD） |
| as_of_note | str | 重大时点说明（如冲突/停产） |
| scale_note | str | 单位口径声明 |
| prepared_for | str | 用途声明 |

### 2.2 sources[]（来源记录）

| 字段 | 必填 | 说明 |
|---|---|---|
| id | ✓ | S01…，全文引用用 |
| title | ✓ | 原文标题 |
| publisher | ✓ | 发布方 |
| url | ✓ | 可点击原文 |
| date | ✓ | 发布日期（无则写"未标注"） |
| type | ✓ | 官方统计/年报/行业媒体/券商… |
| reliability | ✓ | 高 / 中高 / 中 / 低 |
| note | ✓ | **关键摘录与口径说明**（这是最重要的一列） |

### 2.3 sites

```json
"jubail": {"name":"...", "region":"...", "lat":27.0, "lng":49.6, "coast":"波斯湾"}
```
`coast` 用于自动区分通道（东西海岸风险不同）。

### 2.4 companies[]

| 字段 | 说明 |
|---|---|
| id / name / name_en | 唯一标识与名称 |
| type | 集团/控股平台、生产法人、上市公司等 |
| listed | 上市代码或"非上市" |
| ownership | 股权结构（**必须写清各股东比例**） |
| note | 定位说明：它到底持有什么 |
| contact_hint | 接洽提示（先找谁、要什么） |

### 2.5 plants[]（核心表）

| 字段 | 必填 | 说明 |
|---|---|---|
| id | ✓ | P01… |
| company_id / company | ✓ | 指向 companies |
| plant | ✓ | 装置/产线名 |
| site | ✓ | 指向 sites（自动带出所在地与海岸） |
| product | ✓ | 产品与规格 |
| capacity_kt | ✓ | 名义产能（kt/a，数值） |
| cap_basis | ✓ | **产能口径说明** |
| startup | ✓ | 投产/商业化时间 |
| evidence_level | ✓ | A / B / C / D（可写 A/B 表示两源） |
| conflict | | 口径冲突说明（如 "700 vs 770 kt"） |
| unverified | | true 时表中高亮并计入缺口 |
| notes | ✓ | 检修史、工艺、扩能、共用单元 |
| source_ids | ✓ | 来源ID数组 |

### 2.6 trade

```jsonc
"trade": {
  "unit_volume": "kt", "unit_value": "百万美元", "hs": "290531", "flow": "出口",
  "by_year": [ {"year":2025, "world_kt":6372, "world_musd":2987,
                "china_kt":4042, "china_musd":1900,
                "partners":[{"p":"China","kt":4042}, ...]} ],
  "partners_2025_full": [...],
  "unit_prices_usd_t": [{"year":2025,"world":469,"china":470}],
  "china_import_total_kt": 7720, "china_import_year": 2025,
  "saudi_share_of_china_imports": "54%–55%"
}
```

### 2.7 concentration

```jsonc
"concentration": {"by_company_2025_kt":[{"company":"SHARQ","id":"CO3","cap_kt":2100,"note":"..."}]}
```
HTML 会自动计算 CR1/CR3/HHI（法人口径）与股权体系合计。

### 2.8 logistics

```jsonc
"logistics": {
  "ports":[{"id","name","site","coast","role","lat","lng","detail","source_ids"}],
  "routes_to_china":[{"from","to","via","normal_days","status_2026","source_ids"}],
  "vessel":{"typical_dwt","cargo_per_voyage","note"},
  "freight_2026_evidence":"...",
  "china_ports":[{"port","note"}]
}
```

### 2.9 policy / events / risks / unverified / next_steps

| 数组 | 关键字段 |
|---|---|
| policy | id, type, title, detail, level（可核验度）, source_ids |
| events | id, date, title, type, impact（极高/高/中/低/正向）, detail, source_ids |
| risks | level, title, desc, mitigation |
| unverified | item, why, how, impact |
| next_steps | priority, action, why, who |

## 3. HTML 报告区块规范

| 区块 | 必含内容 | 交互 |
|---|---|---|
| ① 供应市场概览 | KPI 四卡、四类口径分层条、3 条结论、四类口径说明 | KPI 卡、企业表点击 |
| ② 生产企业与装置 | 装置表（按产能排序）、企业卡（集团 vs 法人）、扩产规划表、检修事件表 | 按海岸/证据等级筛选、点击进抽屉 |
| ③ 原料与产业基础 | 工艺流程图、原料节点、强项/约束 | — |
| ④ 出口贸易 | 5 年趋势图、目的地环形图、年度表、对华轨迹 | 图表 hover |
| ⑤ 物流与港口 | 示意地图（装置+港口+通道）、港口表、航线表 | 地图 hover/click、港口详情 |
| ⑥ 政策与供应事件 | 政策表、事件时间线、风险矩阵 | 事件影响强度色标 |
| ⑦ 来源与核验 | 数据缺口表、接洽优先级、来源清单 | 来源超链接 |

**技术要求**
- 单文件、无外部依赖（数据内嵌为 `window.MARKET_DATA`）
- 加载无 JS 报错（用 `scripts/verify_report.mjs` 自检）
- 无横向溢出（响应式）；可打印（`@media print` 展开全部区块）

## 4. Excel 工作表规范（13 表）

| 序号 | 工作表 | 内容 | 关键列 |
|---|---|---|---|
| 00 | 说明与口径 | 四类口径定义、证据等级、表索引 | — |
| 01 | 企业与生产主体 | 集团 vs 法人、股权、产能归属 | MEG 装置数、名义产能 |
| 02 | 装置与产能 | 逐套装置 | 产能口径说明、证据等级、口径冲突、待核实 |
| 03 | 产能分层与口径 | 全国/海岸分层 + 第三方交叉 | 差异与说明 |
| 04 | 企业集中度 | 份额、CR、HHI、体系合计 | 累计份额 |
| 05 | 原料与产业基础 | 工艺链节点 | 环节/角色 |
| 06 | 出口年度 | 5 年趋势 | 同比、均价、出口量/产能 |
| 07 | 出口目的地 | 逐年主要目的地 | 占比 |
| 08 | 物流港口 | 港口、航线、船型 | 海岸、状态 |
| 09 | 政策监管 | 政策条目 | 可核验度 |
| 10 | 供应事件 | 时间线 | 影响强度 |
| 11 | 数据缺口 | 缺口 + 核实路径 | 影响 |
| 12 | 来源记录 | 全部来源 + 超链接 | 可信度、摘录 |

**格式要求**：表头冻结、自动筛选、单位写在表头、缺失写"数据缺口"、来源ID可追溯、关键行色标（A 级/待核/极高影响）。

---

## 5. 生成与校验

```bash
python scripts/build_html.py  <data.json> assets/report_template.html <out.html>
python scripts/build_excel.py <data.json> <out.xlsx>
node   scripts/verify_report.mjs <out.html>
```

`build_html.py` 内置校验：缺顶层字段、装置缺字段、site 不在 sites、来源引用不存在，都会报错或警告。
