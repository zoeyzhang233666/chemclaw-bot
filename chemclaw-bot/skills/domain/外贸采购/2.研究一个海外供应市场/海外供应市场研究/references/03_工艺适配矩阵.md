# 03 · 工艺适配矩阵（按产品工艺自动调整研究重点）

本 Skill **不依赖固定行业结构**。不同产品的"生产基础"含义完全不同：MEG 看乙烷与裂解，纯碱看盐湖/矿石与能耗，钛白粉看矿源与硫酸法/氯化法废酸，锂盐看卤水或锂辉石。所以研究重点必须由**工艺路线**推导出来，而不是套用"石化国家报告"的模板。

---

## 1. 使用方法（3 步）

1. **识别产品的主工艺路线**（下表 4.1 选一行，可多行并存）。
2. **读取该路线的"研究重点"**：决定第 1 步（产业基础）、第 2 步（装置）、第 5 步（物流）分别要查什么。
3. **读取"关键产能事实"**：决定装置表里必须包含哪些字段（例如水耗、矿权、副产物）。

若产品不在表中，按"**原料 → 主反应 → 关键中间体 → 公用工程 → 下游/副产**"五要素自行推导，并在报告中写明推导逻辑。

---

## 2. 工艺路线适配表

### 2.1 石化/烯烃衍生类（乙二醇、环氧乙烷、苯乙烯、甲醇、醋酸、PE/PP…）

| 维度 | 研究重点 |
|---|---|
| 产业基础 | 天然气/伴生气体系、乙烷供应与价格机制（谁定价）、裂解装置分布、园区公用工程 |
| 装置核实 | 裂解规模 → 下游一体化装置；同一园区多套线（如 MEG 1–4 号线）要逐线核 |
| 产能口径 | 姓名牌 per line；注意"EO/EG 共用单元"导致 MEG 实际排产可变 |
| 客户可得性 | 集团统一销售平台、长期合约比例、现货窗口 |
| 物流 | 液体散装化学品船、储罐容积、双海岸/双通道风险、战争险 |
| 风险 | 原料气涨价、计划检修季节性、通道关闭、设施损毁 |

**MEG 示例（本 Skill 的完整实例）**：乙烷 → 乙烯裂解 → EO → 水解/OMEGA 催化水合 → MEG；沙特东海岸产能全部经霍尔木兹，西海岸经红海。

### 2.2 酸碱盐类（纯碱、烧碱、硫酸、盐酸）

| 维度 | 研究重点 |
|---|---|
| 产业基础 | 原料（原盐、石灰石、卤水）与能源（煤/电/天然气）成本；副产（氯）平衡 |
| 装置核实 | 单厂产能、工艺（氨碱/联碱/天然碱；离子膜/隔膜）、投产与技改 |
| 产能口径 | 日历产能 vs 有效产能；检修与限电 |
| 客户可得性 | 多为区域贸易商；出口配额/反倾销常见 |
| 物流 | 袋装/散装、集装箱与散货船、内陆运输半径 |
| 风险 | 反倾销（多国对中国纯碱/烧碱征税）、环保限产、能源价格 |

### 2.3 矿物/冶炼衍生类（钛白粉、氧化铝、锌、锑…）

| 维度 | 研究重点 |
|---|---|
| 产业基础 | 矿源（钛矿/铝土矿/锌矿）与品位、冶炼配套、废渣处置能力 |
| 装置核实 | 硫酸法 vs 氯化法；单线产能；环保许可与副产品（硫酸亚铁/石膏）出路 |
| 产能口径 | 产能常按 TiO₂ 计，注意与矿处理量区分 |
| 客户可得性 | 品质等级（颜料级/非颜料级）、品牌与认证 |
| 物流 | 袋装、集装箱、港口散件；高价值低体积 |
| 风险 | 环保关停、矿权变化、出口限制、反倾销 |

### 2.4 农化/肥类（尿素、磷肥、钾肥、复合肥）

| 维度 | 研究重点 |
|---|---|
| 产业基础 | 气/煤（尿素）、磷矿（磷肥）、钾盐矿（钾肥）；合成氨配套 |
| 装置核实 | 合成氨-尿素一体化；单套规模；出口配额/许可 |
| 产能口径 | 实物量 vs 折纯量（N/P₂O₅/K₂O），必须写明 |
| 客户可得性 | 出口国配额制度（如中国、俄罗斯）、国家出口公司 |
| 物流 | 散货船/袋装、装船效率、季节性农时 |
| 风险 | 出口管制、能源价格、冻结/制裁 |

### 2.5 精细化工/中间体类（医药中间体、农药中间体、电子化学品）

| 维度 | 研究重点 |
|---|---|
| 产业基础 | 上游基础原料可得性、园区环保处理能力、工程人才 |
| 装置核实 | **反应釜数量与体积**比"年产能"更可信；批次数、收率、GMP/ISO 认证 |
| 产能口径 | 名义批次产能 vs 实际排产；多产品共线 |
| 客户可得性 | 定制合成（CMO）、客户认证周期长，真实性需通过审计 |
| 物流 | 吨袋/桶装、危险品空运/海运、温控 |
| 风险 | 环保风暴、园区搬迁、专利到期、单一大客户依赖 |

### 2.6 锂电/新能源材料类（碳酸锂、氢氧化锂、正极前驱体、石墨）

| 维度 | 研究重点 |
|---|---|
| 产业基础 | 资源（盐湖卤水/锂辉石/锂云母）或回收渠道；能耗与电力 |
| 装置核实 | 盐湖（蒸发结晶）vs 矿石（焙烧）路线；技改频繁 |
| 产能口径 | 名义/有效/建成/投产 四者差别极大，必须以"投产"为准 |
| 客户可得性 | 下游认证（电池厂/车厂）是硬门槛 |
| 物流 | 危险品海运、UN 编号、电池运输法规 |
| 风险 | 出口管制、价格崩塌、环保 |

### 2.7 塑料/树脂与回收料类（PET、PVC、再生塑料）

| 维度 | 研究重点 |
|---|---|
| 产业基础 | 上游单体（PTA/MEG、EDC/VCM）、再生料收集体系 |
| 装置核实 | 聚合线规模、牌号、瓶级/纤维级/膜级 |
| 产能口径 | 聚合产能 vs 单体产能；再生料按处理量 |
| 客户可得性 | 品牌认证、食品级认证（瓶级）、再生含量（rPET） |
| 物流 | 集装箱为主、体积大、运费占比高 |
| 风险 | 反倾销、碳关税（CBAM）、再生料法规 |

## 3. 派生规则：不同产品下"必查字段"不同

| 产品类别 | 装置表必含字段（除通用字段外） | 贸易数据必注 | 物流必查 |
|---|---|---|---|
| 烯烃衍生 | 原料来源、共用单元、检修季 | 税号含其他同系物 | 双通道、战争险 |
| 酸碱盐 | 工艺路线、能源类型、副产平衡 | 反倾销状态 | 危险品等级 |
| 矿物冶炼 | 矿源/品位、环保许可、副产物 | 关税与出口限制 | 散装/袋装 |
| 农化肥 | 合成氨配套、折纯口径 | 出口配额 | 农时与装船季 |
| 精细化工 | 反应釜容量/数量、认证、GMP | 多产品共线 | 温控/危包 |
| 锂电材料 | 资源路线、投产状态 | 出口管制 | UN 编号/UN38.3 |

---

## 4. 何时需要"多路线并存"

若一个国家同时存在两种工艺（如钛白粉的硫酸法与氯化法、纯碱的氨碱与天然碱），必须：

1. 产能表按工艺分组，**不要合并成一个总数**；
2. 说明两种路线的**成本结构差异**（能耗、废渣、原料）；
3. 在"风险"章节分别列示（一种路线受环保限制时，另一种可能是替代来源）。

## 5. 反例：套模板会犯的错

| 套模板的错误 | 正确做法 |
|---|---|
| 给精细化工企业写"年产能 5 万吨"却没说明是反应釜名义批次×天数 | 写"反应釜 12 台×10 m³，按每批 8 吨、年 200 批计"，并标 D 级 |
| 把钾肥的"实物量"和"折 K₂O"混用 | 全文统一口径并在表头写明 |
| 对锂盐用"规划产能"做供给判断 | 只用"已投产"数据，规划另表 |
| 对 PVC 只查单体不查 EDC/VCM | 按工艺链上下游一起查 |
