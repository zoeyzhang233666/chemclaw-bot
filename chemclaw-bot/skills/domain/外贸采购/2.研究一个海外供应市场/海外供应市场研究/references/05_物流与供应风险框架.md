# 05 · 物流与供应风险框架

对液体化工品与散装大宗品而言，**"产地产能"和"能否按时到货"是两个独立问题**。本框架用于把物流与供应中断拆成可核验的判断项。

---

## 1. 港口与通道的识别顺序

```
装置所在园区 → 最近工业港（液体散货码头/公用罐区）→ 出海口 → 海峡/运河 → 目的港
```

| 层级 | 要查什么 | 证据来源 |
|---|---|---|
| 园区 | 工业城规划机构、公用工程、厂内码头 | 国家工业区管委会、企业官网 |
| 工业港 | 液体散货泊位数、罐区容量、运营商 | 港务局公告、罐区运营商（Vopak、ACT 等） |
| 出海口 | 是否需要跨海峡/运河 | 地理事实 + 航运新闻 |
| 政治通道 | 战争险、通行限制、袭扰记录 | 保险经纪、Lloyd's List、Reuters |
| 目的港 | 接卸能力、库存地、下游距离 | 中国港口集团、行业机构 |

> **关键判断**：同一国家的不同海岸，风险与成本可能完全不同。沙特 MEG 就是典型：东海岸（朱拜勒）占产能 70%，但完全依赖霍尔木兹；西海岸（延布/拉比格）走红海，成为冲突期唯一稳定来源。

## 3. 船型与起订量

| 项目 | 说明 |
|---|---|
| 典型船型 | 液体化学品船 20,000–26,000 DWT；散装大船视产品 |
| 单航次货量 | ≈ 船型 × 装载率（通常 85%–95%） |
| 起订门槛 | 单船货量是事实上的最小批量；拼货需要中转罐区 |
| 包装形态 | 散装（主流）/ ISO 罐 / 吨桶（小批量高价） |

> 采购量小于单船货量时，要么接受拼船/中转，要么接受更高单价——这一点要在询盘前想清楚。

## 4. 运保费用与成本传导

| 费用项 | 正常期 | 风险期 | 说明 |
|---|---|---|---|
| 海运运费 | 基准 | 上涨 | 绕行导致吨海里增加 |
| 战争险保费 | 0.05%–0.3% 船价 | 可达 3%+ | 决定单航次成本量级 |
| 附加费 | — | 战争附加费、拥堵费 | 常不可预测 |
| 保险条款 | 一切险 | 需加战争险 | 谁承担要在合同（CIF/CFR/FOB）中写明 |

**折算示例（本 Skill 实例）**：25,000 DWT 船，保费由 0.3% 升至 3%，则单航次增加约 135 万美元，按 2.4 万吨计约 **+55 美元/吨**——相当于价格的 10% 以上。这类数字比"运费涨了"更有说服力。

## 5. 供应事件分级

| 等级 | 定义 | 例子 | 对可采购量的意义 |
|---|---|---|---|
| **极高** | 区域级通道关闭或主产区物理损毁 | 海峡有效关闭；主力园区遭袭 | 当期基本无法供货 |
| **高** | 单一通道中断、港口停摆、大型园区停产 | 港口中止出运；园区级停车 | 供货延迟或流向切换 |
| **中** | 单条生产线停车、检修、战争险大幅上升 | 700 kt 线检修 3 个月 | 窗口性紧张 |
| **低** | 常规维护、小幅涨价 | 常规 TAR | 可排期规避 |
| **正向** | 新增产能、通道恢复 | 新装置商业化、海峡复通 | 可供量增加 |

每条事件同时记录：**日期 / 类型 / 影响强度 / 机制（为什么影响供货）/ 来源**。

## 6. 供应风险清单（中国买家视角）

| 风险 | 识别信号 | 缓释 |
|---|---|---|
| 通道单点 | 只有一个海峡/港口 | 优先西海岸/多来源 |
| 设施损毁 | 袭击、爆炸、火灾报道 | 要求卖方提供复产公告 |
| 卖方优先他国 | 中国价格低于其他区域 | 价格与全球价差挂钩 |
| 检修叠加 | 多家同季检修 | 索取 TAR 表，避开窗口 |
| 原料断供 | 上游 NGL/气田事故 | 关注上游装置新闻 |
| 合规与制裁 | 交易对手/船东被列名 | 签约前做制裁筛查 |
| 单一供应商依赖 | 对华份额>50% 来自一国 | 建立第二来源 |

## 7. 结论写作模板

> **物流结论**：该产品出运通道为【A】，正常航程【x 天】；【年份】期间因【事件】通道【状态】。当前可稳定通道为【B】，建议合同采用【贸易术语】，战争险由【方】承担，并设置【附加费调整条款】。
> **供应风险结论**：短期最大风险为【通道/设施】，中期为【卖方流向偏好/原料涨价】，长期为【新增产能/替代来源】。
