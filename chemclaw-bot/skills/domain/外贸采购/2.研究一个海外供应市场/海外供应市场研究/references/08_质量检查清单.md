# 08 · 质量检查清单（交付前逐项打勾）

> 用法：复制本清单到任务笔记，交付前逐项确认；**任何一项打不上勾，就不要交付**。

---

## A. 范围与口径（最先检查）

- [ ] 产品规格（等级/纯度）写清楚了，不是"某化工品"
- [ ] HS 税号写明，并说明了税号覆盖的**其他产品**
- [ ] 报告显著位置声明了"名义设计产能/实际产量/出口量/可供采购量"四类口径
- [ ] 全文**没有**任何"产能×开工率""出口量÷产能""行业规模×份额"式推算
- [ ] 所有数字带单位、年份、口径与来源ID

## B. 企业与装置

- [ ] 集团/控股平台**没有**被赋予产品产能
- [ ] 每套装置都有：所在地 + 名义产能 + 产能口径 + 投产时间 + 证据等级 + 来源
- [ ] 每套装置至少 1 个 A 级或 2 个独立 B 级证据
- [ ] 存在两源冲突的装置**并列展示**了两套数字
- [ ] 无法核实项标"待核实"并在表中高亮
- [ ] 规划/获批项目**没有**进入在产产能表
- [ ] "关联但没有该产品"的企业（如 Sipchem、Tasnee）单列，不混入供给

## C. 贸易数据

- [ ] 近 3–5 年逐年数据（数量 + 金额）
- [ ] 出口均价已计算并解释异常年份
- [ ] 主要目的地（至少前 10）与对华占比
- [ ] 注明"报告国申报口径"与数据来源
- [ ] 出口量与产能的比值**注明"不是产量"**
- [ ] 与进口国（中国）海关数据做过交叉或说明差异

## D. 集中度

- [ ] 企业级 CR1/CR3/HHI（写清分母与口径）
- [ ] 股权体系合并口径单独给出
- [ ] 判断了"合同签谁、是否集团统一销售"

## E. 物流

- [ ] 出口港清单（含工业港/商业港/自有泊位区分）
- [ ] 到中国主要港口的航线、航程、关键节点
- [ ] 船型与单航次货量（起订量）
- [ ] 运保费用变化（战争险/附加费）或标为缺口
- [ ] 通道单点风险已识别（海峡/运河/单港口）

## F. 政策与事件

- [ ] 出口国出口监管（是否需许可/配额）
- [ ] 原料/能源政策（谁定价、是否在提价）
- [ ] 贸易救济（反倾销等）及对流向的影响
- [ ] 中国进口端监管（税则、危险品、检验）
- [ ] 事件时间线覆盖近 3 年，且每条有影响强度与机制
- [ ] 当前状态（截至报告日）有明确表述

## G. 结论与可执行性

- [ ] 三句话结论（有没有基础 / 谁在供 / 卡在哪）可读
- [ ] 数据缺口表：每条有"为什么查不到 + 怎么查 + 影响"
- [ ] 接洽优先级 ≥3 条，写明对象、原因、要索取的材料
- [ ] 明确写出"不能直接用于报价/签约的量"

## H. 交付物技术检查

- [ ] HTML 单文件可离线打开，切换所有区块无 JS 报错（`verify_report.mjs`）
- [ ] HTML 无横向溢出，地图/图表正常渲染
- [ ] Excel 13 个工作表齐全，表头冻结，来源可点击
- [ ] Excel 中缺失值写"数据缺口"而非 0
- [ ] 文件名包含国家 + 产品 + 类型，便于归档

## I. 常见退回原因自查

| 退回原因 | 对应检查项 |
|---|---|
| "这个产能数字是集团口径" | B 第 1 条 |
| "出口量当产量了" | C 第 5 条 |
| "哪来的数据？" | A 第 5 条、来源表摘录 |
| "为什么只列这 5 家？" | B 第 7 条（说明剔除逻辑） |
| "冲突数字怎么处理？" | B 第 4 条 |
| "现在还能不能拿到货？" | F 第 6 条、G 第 3 条 |
