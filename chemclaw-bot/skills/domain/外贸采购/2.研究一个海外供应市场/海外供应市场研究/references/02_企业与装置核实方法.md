# 02 · 企业与装置核实方法

采购谈判里最容易出错的一步：把**品牌**当成**合同主体**、把**企业总产能**当成**产品产能**。本文件给出可执行的核实路径。

---

## 1. 主体识别的三分法

```
控股平台（品牌/集团）  ←→  生产法人（装置持有者、合同主体）  ←→  关联但无该产品
        SABIC                  SHARQ / YANPET / United / Yansab / Kayan      Sipchem / Tasnee
      记：股权、销售平台          记：装置与产品的名义产能                    记：潜在新增/不作为来源
```

**判定要点**

| 问题 | 判别方法 |
|---|---|
| 它是集团还是装置持有者？ | 若公开资料只说"集团年产 xx 万吨"，且找不到厂名/装置编号 → 集团 |
| 它是不是 MEG 生产者？ | 查年报产品表、产品手册、专利商/总包商项目清单、贸易救济案件被点名企业 |
| 它有没有在产装置？ | 查"投产/商业化"公告；"规划""获批原料配额"不等于在产 |
| 合同签谁？ | 一般为生产法人；若为集团统一销售（如 SABIC 代销），合同主体仍应写生产法人或明确代理关系 |

**反例（本 Skill 实例中的真实陷阱）**
- MEES 曾把朱拜勒写成 "Red Sea downstream hub"，实际在波斯湾东岸；若照抄，物流与通道分析会全错。
- Sipchem 常被列为"沙特石化大厂"，但其产品链（甲醇、醋酸、VAM、BDO、EVA）**不含 MEG**；把它列入 MEG 供给会造成 10%–20% 的量级误判。

## 2. 建立装置清单：按什么顺序查

| 顺序 | 检索目标 | 典型命中 | 证据级 |
|---|---|---|---|
| 1 | 上市公司年报"产品产能表" | Kayan：Ethylene Glycol 1,065 千公吨/年 | A |
| 2 | 专利商/总包商项目新闻 | Toyo：Yansab 700,000 MTPA；Scientific Design：JUPC 700 KTA | A |
| 3 | 行业媒体的**检修名录** | ICIS：逐套列出 8 套装置产能（700/640/770/380/520/450/450/650） | B |
| 4 | 行业媒体的**投产/扩能**新闻 | United EG-3 700 kt（2021 试车/2022 商业化） | A/B |
| 5 | 贸易救济文件（反倾销被点名企业） | 欧盟 MEG 案点名 Yansab、Kayan、SHARQ、YANPET、Petrokemya | A |
| 6 | 第三方装置库 | GlobalData / ChemAnalyst（付费） | C |
| 7 | 企业官网产品页 | 常只有"产品组合"，无产能 → 用于确认产品是否在产 | B |

> **最有效的单条线索**：大型停产/检修报道里，媒体往往一次性列出"该公司 N 套装置及各自产能"。在本例中，一篇 ICIS 2011 年的检修预告，直接给出了 8 套装置的姓名牌数字，是后续所有装置的骨架。

## 3. 每套装置必须产出的字段

| 字段 | 必填 | 说明 |
|---|---|---|
| 装置ID | ✓ | P01… |
| 生产法人 / 企业ID | ✓ | 必须对应到企业表 |
| 装置名/产线 | ✓ | "MEG-4 号线"而非"某公司 MEG" |
| 所在地 + 海岸 | ✓ | 决定物流通道 |
| 产品 | ✓ | 是 MEG 还是 EG 总量/EO 共线 |
| 名义产能 kt/a | ✓ | 四舍五入到千吨 |
| **产能口径说明** | ✓ | 一句话：来自哪类来源、什么年份、是否合计 |
| 投产/商业化时间 | ✓ | 区分"建成""试车""商业化" |
| 证据等级 | ✓ | A/B/C/D |
| 口径冲突 | 条件 | 两个数字并存时必填 |
| 待核实标记 | 条件 | D 级必填 |
| 备注 | ✓ | 检修史、工艺、扩能、共用单元 |
| 来源ID | ✓ | 至少 1 个，最好 2 个 |

## 4. 交叉核对方法

### 4.1 逐套加总 vs 第三方全国值

| 核对项 | 本报告（逐套） | 第三方 | 差异解释 |
|---|---|---|---|
| 沙特全国 | 7,405 kt/a | 7.75 Mt/y（SunSirs） | 第三方可能含 DEG/TEG 或闲置线 |
| 东海岸（朱拜勒） | 5,205 kt/a | 5,040 kt/y（CCFGroup） | SHARQ M1 为待核值；SHARQ M3 口径 450/500 差异 |
| 西海岸 | 2,200 kt/a | 约 2,100 kt/y（CCFGroup） | Yansab 700/770 与归属口径 |

**规则**：差异在 ±5% 内视为可接受，超过则必须解释；**永远不要修改单套数字去迁就总数**。

### 4.2 装置级两源冲突的处理

| 冲突类型 | 案例 | 处理 |
|---|---|---|
| 总包口径 vs 检修名录口径 | Yansab 700（Toyo）vs 770（ICIS） | 取工程口径 700 为主，770 作为备选并列；在报告中标注 |
| 不同年份的同一装置 | SHARQ M3：2011 名录 450 vs 2024 报道 500 | 取较新（500），并列旧值；说明可能经历去瓶颈 |
| 规划值 vs 投产值 | Kayan 早期规划 MEG 700 vs 年报 1,065 合计 | 以年报为准，规划值只放入"扩产与规划"表 |

### 4.3 产能 vs 出口量的合理区间检验

用"出口量/名义产能"做**仅参考**的合理性检查：

| 年份 | 出口量 | /名义产能 | 解读 |
|---|---|---|---|
| 2021 | 2,359 kt | 31.9% | United EG-3 投产后产能增加 |
| 2024 | 6,021 kt | 81.3% | 若属实，说明开工率很高或有转口/库存 |
| 2025 | 6,372 kt | 86.0% | 同上，需企业确认 |

> 该比值 >85% 时不是"业绩喜人"，而是**警示信号**：可能存在转口、统计口径差异或产能数字偏低。**在报告中必须把这句写出来**，而不是当作利好的加工率。

## 5. 扩产、检修与装置状态记录

| 类别 | 记什么 | 用途 |
|---|---|---|
| 计划检修（TAR） | 起止时间、时长、哪条线 | 判断供货窗口，避开检修期签量 |
| 非计划停车 | 原因（事故/原料/公用工程） | 判断可靠性与索赔风险 |
| 扩能/去瓶颈 | 幅度、时间、是否已商业化 | 修正产能口径 |
| 新建规划 | 原料配额、FEED、FID、EPC、投产 | 只放"规划表"，不进产能表 |
| 装置状态变化 | 停车中/复产中/复产未证实 | 直接影响当期可采购量 |

## 6. 企业层输出模板（复制使用）

```text
企业名称（中/英）：
主体类型：集团 / 生产法人 / 关联无该产品
上市代码：
股权结构：
该产品装置：（逐套列出装置名 + 产能 + 所在地）
本产品名义产能合计：____ kt/a
销售模式：自营 / 集团统一销售（谁签合同）
接洽建议：先找谁、要哪些资料
```

## 7. 向企业索取资料的清单（用于下一环节"核验海外供应商"）

- 营业执照/商业登记（沙特为 CR 号）与生产法人名称一致证明
- 装置清单（含产线编号、设计能力、投运年份）
- 近 12 个月**发货记录**（可不含价格，但要有日期、数量、港口、买方国家）
- 年度检修计划（TAR schedule）
- 出口资质、危险品包装证明（UN 编号）、MSDS
- 质量证书（纤维级/工业级检测报告）、第三方检验机构偏好
- 是否可以提供 SGS/Intertek 到岸前检验
