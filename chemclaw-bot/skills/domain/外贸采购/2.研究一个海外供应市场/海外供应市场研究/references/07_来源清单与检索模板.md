# 07 · 来源清单与检索模板

本文件解决"**该去哪里查、用什么检索式、结果怎么分级**"。适用于任意国家/化工品，按需替换方括号中的内容。

---

## 1. 信源分级表（按可信度）

| 级 | 信源 | 获得什么 | 使用注意 |
|---|---|---|---|
| **A1** | 上市公司年报/季报（Tadawul、SEC、港交所、日交所） | 产品产能表、分产品销量、检修公告 | 中文/英文 PDF 可直接下载；注意财年 |
| **A2** | 交易所公告（临时公告） | 不可抗力、停车、投产、扩产 | 最权威的"状态变化"来源 |
| **A3** | 国家统计机构 | 港口吞吐、进出口总额 | 沙特为 GASTAT；中国为海关总署/统计局 |
| **A4** | 专利商/总包商公告 | 装置产能、工艺、承包商 | Toyo、Scientific Design、Shell、Samsung E&A、Fluor 等 |
| **A5** | World Bank WITS / UN Comtrade | HS6 出口国别结构 | 报告方口径 |
| **B1** | ICIS、Argus、MEES、OGJ、C&EN、Chemical Week | 检修、投产、事故、价格 | 常付费墙，摘要可用 |
| **B2** | Reuters、Bloomberg、OPIS | 地缘事件、设施损毁 | 最权威的"突发事件" |
| **B3** | S&P Global Commodity Insights | 原料政策、项目进展 | 深度好 |
| **B4** | CCFGroup、Mysteel、SunSirs、中国Texnet | 中国视角的到船、库存、进口 | 时效强，多为估算 |
| **B5** | 行业媒体（ChemAnalyst、Plastemart、Gulf Industry） | 产能数字、装置新闻 | 常转引 Platts/ICIS |
| **C** | GlobalData、IndexBox、券商研报 | 汇总产能与份额 | 仅交叉参照 |
| **D** | 百科、自媒体、聚合站 | 线索 | 必须回源 |

## 2. 检索式模板

### 2.1 寻找企业（第 2 步）

```
[国家英文] [产品英文] producer capacity kt
[国家] [产品] plants list "Jubail" OR "Yanbu" OR [主要工业城]
[公司名] annual report [产品] capacity 千公吨 / thousand metric tons
[公司名] "ethylene glycol" OR "[产品]" plant capacity kt/y
site:argaam.com [公司] [产品]
site:tadawul.com / saudiexchange.sa [公司] [产品]
```

### 2.2 找装置级停检记录（最有效的产能来源）

```
[国家] [产品] shutdown turnaround kt/year units
[公司] plans [产品] plant shutdown days
[国家] "[产品]" maintenance "No 1" "No 2" capacity
```

> 技巧：**停产/检修报道常一次性列出全部装置的姓名牌产能**，比产能数据库更可信。

### 2.3 找贸易救济（被点名的企业名单）

```
[进口国] anti-dumping [产品] [出口国] duties %
[产品] anti-dumping final determination [国家]
```

### 2.4 找出口数据

```
WITS [ISO3] exports [HS6]
"[HS6]" exports [国家] by country volume tonnes
中国海关 [HS] 进口 [国家] 数量 金额
```

### 2.5 找物流与通道

```
[港口名] liquid bulk chemical terminal capacity tanks
[港口名] port 2024 cargo handled tonnes
[海峡] closure chemical tanker [产品]
war risk premium [海峡] 2026
```

### 2.6 找政策与原料

```
[国家] Ministry of Energy feedstock allocation petrochemical
[国家] ethane price increase [年] petrochemical feedstock
[公司] force majeure [产品] [年]
```

## 3. 检索顺序建议（省时间）

1. 先用"公司 + 产品 + capacity"定位关键数字（3–5 分钟的快速摸底）
2. 再用"shutdown / turnaround"补齐装置级数字（这一步决定报告质量）
3. 用 WITS 一次性拉齐 5 年贸易数据
4. 用"港口/通道"补物流
5. 最后用"事件时间线"扫一遍近 3 年新闻，找地缘与事故

---

## 4. 抓取与清洗注意事项

| 问题 | 处理 |
|---|---|
| 网站被 Cloudflare 拦截 | 改用 Python `urllib`/`requests` 带浏览器 UA；或换等价来源 |
| PDF 无法直接读文字 | 用 `pymupdf` 抽取；表格用 `page.get_text()` 后正则 |
| 页面内容被截断 | 优先抓 HTML 原文正则提取正文，而非依赖工具摘要 |
| 中英文名称不一致 | 建立对照表（如 Petrokemya = Arabian Petrochemical Co.） |
| 数字单位混用 | 统一换算：Mt→kt（×1000）、kg→kt（÷10⁶）、千美元→百万美元（÷10³） |
| 同一新闻多处转载 | 追溯原始报道方，引用原始（如 ICIS 而非转载页） |

## 5. 来源记录写法（必须包含摘录）

```json
{
  "id": "S07",
  "title": "Saudi Arabia's SABIC plans heavy MEG shutdown in 2011",
  "publisher": "ICIS (via Vinachem)",
  "url": "https://...",
  "date": "2011-01",
  "type": "行业专业媒体（装置级）",
  "reliability": "中高",
  "note": "逐一列出 8 套 MEG 装置：JUPC 700/640、Yansab 770、Yanpet 380/520、Sharq 450/450、Kayan 650；SABIC 沙特 MEG 总产能 5.71 Mt/y。该文写于 Sharq 4 号线与 United EG-3 之前。"
}
```

> `note` 中必须写清：**这篇来源提供了哪个具体数字/事实、适用于哪一年、有什么局限**。没有摘录的来源等于没有来源。

## 6. 付费墙信源的替代策略

| 拿不到 | 替代 |
|---|---|
| ICIS 装置库 | 用 ICIS/Platts 转引的行业新闻（ChemAnalyst、Plastemart） |
| GlobalData 报告 | 用年报 + 总包公告 + 检修名录拼装，标"多源拼装" |
| 港口月度数据 | 用国家统计年鉴年度值 + 航运新闻事件 |

**不要**用"未公开"作为产能数字，宁可标 D 级待核实。
