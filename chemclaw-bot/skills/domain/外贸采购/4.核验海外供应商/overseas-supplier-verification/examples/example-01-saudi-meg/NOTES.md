# 案例说明：沙特 MEG 生产商核验（示例 01）

**报告编号** `OSV-SA-MEG-2026-001` ｜ **基准日** 2026-10-20 ｜ **被核验主体** Arabian Petrochemical Company (PETROKEMYA)，SABIC 全资子公司

---

## 一、这个案例演示什么

1. **一家真实可查的沙特乙二醇企业**，按七步法从"主体"查到"单据"。
2. **集团 / 生产 / 交易 / 收款四层主体**的拆解——PETROKEMYA（生产）、SABIC（集团）、PETROKEMYA（PI 抬头）、第三方 FZE（收款，模拟）分别处在什么位置。
3. **模拟 PI + 银行信息 + 名片**如何被一致性检查抓出三项缺口。
4. **供应能力的时点性**：2026 年 3 月不可抗力 → 10 月恢复，这是"有产能"与"能发货"的区别。

---

## 二、关键结论（摘要）

| 问题 | 结论 | 依据 |
|---|---|---|
| 企业是否真实存在 | **可确认存在** | SABIC 年报 CR 1010010813（E03）；PETROKEMYA 为 SABIC 全资（E04/E05） |
| 产品是否匹配 | **匹配到品类与等级层面** | SABIC 官网 MEG 产品页，2 个等级，覆盖亚洲（E02） |
| 是否实际制造商 | **生产装置在朱拜勒**，但本批次来源未闭环 | 综合体位于朱拜勒（E05）；单体与产线对应关系未逐条列示 |
| 工厂产能 | **只能给"综合体 10.46 mtpa"口径** | GlobalData 二手（E05）；MEG 单产品产能未核 |
| 官网与联系 | **子公司域名未验证成功**；模拟名片邮箱为近似域 | E12 名录 + 本次直连失败（E11） |
| 交易主体一致性 | **收款主体 ≠ 合同主体（模拟件）** | F01/F02 |
| 公开风险 | 2026-03 不可抗力、2021 欧盟反倾销；制裁未完成筛查 | E08/E09/E06 |
| 总体结论 | **仅识别身份（IDENTIFY ONLY）** | 见报告封面 |

## 三、本案例刻意保留的"未知"

**这些"未知"是案例的重点，不是遗漏。**

| 未知项 | 为什么保留 | 怎么补 |
|---|---|---|
| PETROKEMYA 的 CR 号 | 本次网络下 mc.gov.sa / petrokemya.com.sa 均连接失败（E11） | 索取 CR 证书；可访问网络下用 Wathq 核验 |
| 街道级注册地址 | 未获取可引用来源 | 索取 CR 证书 / 官网联系页 |
| MEG 单产品产能 | 公开信息只有综合体口径 | 索取装置编号与产能表 |
| 本批次可用量 | 公开信息不存在 | 索取装运计划与舱位确认 |
| 制裁名单筛查结果 | 缺 CR 号，无法做精确匹配 | 补 CR 后筛查并留痕 |
| 司法诉讼 | 沙特商事司法公开度有限 | 委托当地律所出具意见 |
