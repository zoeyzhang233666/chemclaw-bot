## 核验批注：目录与官网的等级口径对不上

| 比对项 | 供应商目录（模拟） | SABIC 官网（E02） | 判定 |
|---|---|---|---|
| MEG 等级数量 | 仅「Fiber Grade」1 个 | 官网标注 **2 个等级** | **不对应** |
| 等级命名方式 | 通用描述「Fiber Grade」 | 使用品牌等级名（SABIC® 系列） | 无法对齐批号 |
| 规格指标 | 仅纯度 99.9% | 未在页面公开逐项指标，需 TDS | 需 TDS |
| 包装形态 | Bulk / ISO Tank | 官网 TDS 列有 drum / ISO tank / flexibag（E13） | 大致相符 |
| 批号规则 | 未提及 | — | 缺失，无法与 COA 对应 |

### 为什么「等级名」重要

同一装置可能同时生产多个等级，等级决定 DEG 含量、色度、紫外透光率等关键指标。目录只写「Fiber Grade」而不给等级名与批号规则，会导致：

1. 收到的 COA 无法与合同规格逐项比对；
2. 无法确认装运的是官网所列等级中的哪一个；
3. 出现质量争议时无法追溯到生产批次。

### 索证动作

- 索取 **TDS**：确认等级名 + 各项指标限值；
- 索取 **批号级 COA**：确认检测方法与实测值；
- 要求 **装箱单 / ISO 罐箱编号** 与 COA 批号对应。
