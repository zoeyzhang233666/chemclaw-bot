## 核验批注

| 检查点 | 结论 |
|---|---|
| 企业自有域名邮箱 | ✗ 使用免费邮箱域 |
| 固定电话 / 区号 | ✗ 仅手机（+966 5 为沙特手机号段） |
| WhatsApp 主渠道 | ⚠ 非正式商务渠道 |
| 公司注册信息在名片上 | ✗ 无 |

**处置：要求对方以企业域名邮箱回函并提供官网；在取得前，仅以「待核实联系人」登记。**
