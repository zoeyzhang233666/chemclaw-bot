## 核验批注

| 检查点 | 结论 | 说明 |
|---|---|---|
| 等级名称 | ✗ | 只有纯度，无等级名（无法对应 COA） |
| 生产商名称 | ✗ | 未指明，与「自有工厂」主张矛盾（若自有，应能写出装置名） |
| 检测方法 / 规格表 | ✗ | 无 TDS |
| 批号规则 | ✗ | 无 |
| 价格口径 | ⚠ | 「Factory price」未说明是 FOB / CFR / 现货 / 长约 |

**核心矛盾：如果产品确实来自「自有工厂」，供应商应当能说出生产商名称与装置名；恰恰是这一点缺失。**
