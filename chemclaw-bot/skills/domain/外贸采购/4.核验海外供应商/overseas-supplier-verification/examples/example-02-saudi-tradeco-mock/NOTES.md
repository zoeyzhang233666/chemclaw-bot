# 反例说明：贸易商自称生产商（示例 02）

**报告编号** `OSV-SA-PG-2026-002` ｜ **基准日** 2026-10-20 ｜ **被核验主体** Gulf Horizon Petrochemical Trading LLC（**虚构示例实体**）

---

## 一、这个案例演示什么

当供应商**自称生产商**但公开资料查不到任何装置时，报告应当：

1. 把"查不到"写成**状态**，而不是**判断**（不写"造假""骗子"）；
2. 明确指出**阻断点是什么**（本例：制造关系无法证明，而不是收款不一致）；
3. 给出**结构化的下一步**（要么补制造证据，要么改签经销身份并披露货源）；
4. 用**真实生产商的证据形态**做对照，让读者知道"可信的生产商长什么样"。

## 二、与示例 01 的对照

| 核验项 | 示例 01（真实生产商） | 示例 02（虚构贸易商） |
|---|---|---|
| 名称形态 | Arabian Petrochemical Company（法定名） | … Petrochemical **Trading** LLC |
| 装置信息 | 朱拜勒综合体，可被 GlobalData 记录 | "自有装置 120 万吨/年"，无对应 |
| 产能口径 | 能说明是综合体口径 | 直接说单产品 120 万吨，无法对应 |
| 集团归属 | SABIC 全资，可查 | "无集团，独立运营" |
| 联系渠道 | 有官网、有固定电话 | 免费邮箱 + 仅手机 |
| 文件标识符 | 官网列 CR/许可证（Yansab 参照） | 无 CR、无许可证、无装置名 |
| 报告结论 | 仅识别身份 | **暂停推进（HOLD）** |

## 三、本案例的关键判断（写的是事实，不是结论）

| 说法 | 本报告的表述 |
|---|---|
| ❌ "这是一个骗子公司" | ✅ "自述『自有装置』在公开资料中无对应记录，制造关系无法证实" |
| ❌ "120 万吨产能是假的" | ✅ "该数字在沙特公开装置清单中找不到对应装置，标『存在疑点』" |
| ❌ "低风险但有瑕疵" | ✅ 不给风险等级；给阻断项与补件动作 |
| ❌ "免费邮箱所以一定是骗子" | ✅ "使用免费邮箱域，无法与企业身份建立关联，标『存在疑点』" |

---

## 四、给采购的三条实操启示

1. **先问身份，再要文件**：一句话就能试出来——"请书面确认您是生产商还是经销商，如为经销商请注明生产商名称"。
2. **产能不能自证**：产能数字若不能对应到"装置名 + 地点 + 许可证"，只能记为线索。
3. **"查不到"要写在纸上**：写清检索了哪些渠道、用了什么标识符、什么时间。这样结论可复核、可反驳、可更新。
