# 公开风险检索法

> 原则：**只列查得到的事实。检索不到 ≠ 不存在。任何结论都要写明"查了什么、用什么标识符、什么时候"。**

---

## 一、检索前置：三个标识符

制裁与司法筛查**必须**用不超过以下三要素的组合：

| 要素 | 例 |
|---|---|
| 英文法定全称 | ARABIAN PETROCHEMICAL COMPANY |
| 注册号 | CR 1010010813 |
| 地址 | Riyadh / Al Jubail |

只有一个名称就下结论 → 不合格。
只有中文名 → 先拿到英文登记名（这是补件清单里必列的一项）。

---

## 二、制裁与出口管制

| 名单 | 维护方 | 查什么 |
|---|---|---|
| OFAC SDN & Consolidated | 美国财政部 | 名称、别名、地址、注册号 |
| BIS Entity List / Denied Persons | 美国商务部 | 实体清单 |
| EU Consolidated Financial Sanctions List | 欧盟 | 实体与个人 |
| UN Security Council Consolidated List | 联合国 | 1267 等 |
| UK OFSI | 英国 | 综合名单 |
| 中国反制清单 / 不可靠实体清单 | 商务部 | 如适用 |

### 操作要点

- 用**拉丁转写**，并用别名（former names）再查一次；
- 记录：查询日期、名单版本、匹配/未匹配结果；
- **模糊匹配 ≠ 命中**：同名不同主体很常见，必须用注册号/地址二次确认；
- 命中后不要自行定性，升级到合规/法务。

### 输出范式

```
| 制裁名单 | 未检索到与「法定名称 + CR号 + 地址」匹配的记录（OFAC/EU/UN，查询日 2026-10-20） | 未核实 |
注：本次未能取得 CR 号，筛查仅基于名称，属不完整筛查。
```

## 三、司法与信用

| 维度 | 查什么 | 来源 |
|---|---|---|
| 诉讼/仲裁 | 被告/原告记录 | 法院公开网、RegTech 平台、当地律所 |
| 破产/重整 | insolvency 记录 | 官方破产登记 |
| 被执行/失信 | 执行记录 | 各国执行登记（中国对境外企业通常查不到） |
| 行政处罚 | 环保/安全/税务处罚 | 监管机构公告 |

**现实限制**：多数国家商事司法公开度有限，尤其海湾国家。
做法：如实写「未检索到 / 公开渠道不可得」，并建议委托当地律所出具法律意见（升级动作）。

## 四、供应能力类风险（时点敏感）

这一项**最容易被忽略，但对采购最关键**。要查：

| 事件 | 检索词示例 |
|---|---|
| 不可抗力声明 | `force majeure` + 产品/公司 |
| 停产/减产 | `shutdown` / `force majeure` / `outage` |
| 计划检修 | `turnaround` / `maintenance` + 装置 |
| 事故 | `fire` / `explosion` / `leak` + 工厂名 |
| 物流中断 | 海峡/港口/航线 + 相关国家 |
| 制裁导致的贸易流变化 | 出口限制、禁运 |

### 为什么重要

"这家企业有工厂"和"这家企业现在能给我发货"是两个问题。
**供应中断期间，任何产能都存在，但可交付量可能为零。**

### 输出范式（时间轴）

```
2026-03-26  SABIC 就 EG 等产品宣布不可抗力（霍尔木兹关闭）   [E08]
2026-10-19  沙特方向到港恢复至约 12 万吨                      [E10]
```

## 五、贸易救济

化工品进口高频遭遇反倾销，这一类信息对"这家企业是不是真出口商"有交叉印证价值。

| 渠道 | 说明 |
|---|---|
| 中国商务部贸易救济调查局 | 对华反倾销调查、措施公告 |
| 欧盟委员会 TDI（trade.ec.europa.eu） | 欧盟措施 |
| 美国 ITC / Commerce（antidumping） | 美国措施 |
| WTO Dispute Settlement | 成员国磋商/争端 |

**用法**：若反倾销调查名单中出现某企业，说明该企业在**对某市场出口该类产品**——这是"真实出口生产商"的间接证据（但仍需结合其他证据）。

## 六、负面报道

| 类型 | 价值 |
|---|---|
| 调查报道（欺诈、伪造单据） | 高 |
| 劳资/环保争议 | 中（影响供应稳定性） |
| 一般商业新闻 | 低（但可印证活跃度） |

**注意区分**：同名企业的负面报道 ≠ 本企业。必须用注册号/地址确认。

## 七、检索记录表（报告附录）

建议在报告里固定一张表：

| 议题 | 检索渠道 | 检索标识符 | 查询日 | 结果 |
|---|---|---|---|---|
| OFAC/EU/UN 制裁 | 官方名单库 | 名称（缺 CR） | 2026-10-20 | 未匹配（不完整） |
| 司法诉讼 | 公开检索 | 名称 | 2026-10-20 | 未检索到 |
| 供应中断 | 行业媒体 | 产品+集团 | 2026-10-20 | 有（2026-03 不可抗力） |
| 贸易救济 | 欧盟/ WTO | 产品+国别 | 2026-10-20 | 有（2021 反倾销） |

## 八、红旗清单（红旗 → 动作，不是结论）

| 红旗 | 含义 | 动作 |
|---|---|---|
| 拒提供注册号 | 主体可识别性差 | 暂停 |
| 收款方在无关第三国 | 资金路径异常 | 三件套 + 回呼 |
| 邮箱近似域 | 沟通对手存疑 | 官网回呼 |
| 免费邮箱 + 仅手机 | 非企业级沟通 | 要求企业邮箱 |
| 100% 预付 + 首次合作 | 资金风险 | 改 L/C 或降低预付 |
| 催单 + 限时话术 | 时间压力战术 | 暂停 24h 复核 |
| 无装置证据却称"厂价" | 身份与话术不符 | 要求制造证据 |
| 制裁名单模糊命中 | 合规风险 | 升级合规/法务 |
| 近期不可抗力未解除 | 交付能力受限 | 索取装运计划 |

**红旗不构成风险评级**。它们的意义是：**触发下一步验证动作。**
