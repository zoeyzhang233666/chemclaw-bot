# 制造关系取证：工厂 / 产能 / 授权链

> 本文解决：**"它到底是不是生产商？这批货是不是它生产的？"**

---

## 一、先问三个问题

1. **有没有装置？**（有工厂 vs 只有办公室）
2. **装置在哪、生产什么？**（地址 + 产品范围）
3. **这批货是不是从那个装置出来的？**（批号级证据 ← 最关键）

第 3 问才是真正决定"厂价直供"能不能成立的。

---

## 二、身份自查：四类供应商

| 自述 | 应能提供 | 若提供不了 |
|---|---|---|
| "我们是生产商" | 装置名、地址、工业许可证、产能表、批号 COA | 大概率是贸易商 |
| "我们是集团销售公司" | 集团持股证明、生产公司授权 | 授权链存疑 |
| "我们是授权经销商" | 授权书（产品/区域/期限）、生产商 COA | 货源不可控 |
| "我们是贸易商" | 真实货源披露、供货确认 | 正常，但来源要能追 |

> **重要**：贸易商本身不是问题。问题是**自称生产商但没有制造证据**。

---

## 三、工厂存在的证据（由强到弱）

| 强度 | 证据 | 说明 |
|---|---|---|
| ★★★★★ | 工业许可证（含产品范围） | 政府签发，可直接核验 |
| ★★★★★ | 环保许可（环评批文） | 通常公开可查，含装置信息 |
| ★★★★ | 上市公司年报/公告提及其装置 | 有法定披露责任 |
| ★★★★ | 交易所公告（投产/检修/不可抗力） | 硬证据 |
| ★★★ | 行业数据库列示装置与产能 | GlobalData / ICIS / Wood Mackenzie |
| ★★★ | 行业媒体独立报道（投产、扩产、检修） | 需注明媒体与日期 |
| ★★ | 卫星影像可识别装置（罐区、塔器、码头） | 需地址先确认 |
| ★ | 官网"我们有工厂" | **不算证据** |
| ✗ | 通用图库照片 | 不算证据（常见伪造手段） |

### 现场照片的最低要求

- 门牌/厂牌（含公司名）
- 装置铭牌（含设备编号）
- 时间水印
- 可识别地标（烟囱、储罐排列、码头）

只要缺一项，就不能当"工厂存在"的证据。

---

## 四、产能口径（最容易误导的三个数字）

```
┌─────────────────────────────────────────────────────────┐
│ ① 综合体总产能  GlobalData 口径：整个工业区所有产品合计   │  ← 不能当MEG产能
├─────────────────────────────────────────────────────────┤
│ ② 装置产能      单套装置单产品（如 700 kt/y MEG）        │  ← 只能当上限
├─────────────────────────────────────────────────────────┤
│ ③ 可供量        合同约定/装运计划分配给我方的吨位        │  ← 只有这个能交货
└─────────────────────────────────────────────────────────┘
```

公开信息通常只能拿到 ① 和 ②。**报告里必须写明口径**，否则读者会把 ① 当成 ③。

### 常见误导写法（禁止）

| 错 | 对 |
|---|---|
| "该厂产能 1000 万吨" | "该综合体石化总产能约 1046 万吨/年（GlobalData 口径，含全产品）" |
| "月供 5 万吨" | "月可供量未确认；公开信息仅显示集团层面 MEG 到港量" |
| "产能很大，随便订" | "产能为上限参考；本批次可用量需装运计划确认" |

## 五、授权链的三种形态

### 5.1 集团内授权
```
集团母公司 ──授权/销售协议──→ 生产公司（工厂）
                │
                └──授权──→ 集团销售公司（签约主体）
```
**要问**：销售公司是否有权以自己名义签约？收款是否由集团资金中心执行？

### 5.2 经销商授权
```
生产商 ──独家/非独家授权书──→ 经销商
                （须写明：产品、区域、期限、是否可转授权）
```
**要问**：授权是否覆盖我方市场？是否在有效期内？是否可转售给中国买方？

### 5.3 贸易商（无授权）
```
贸易商 ──采购──→ 生产商/经销商 ──发货──→ 我方
```
**要问**：真实货源是哪家？能否拿到生产商 COA？B/L 发货人是谁？

## 六、判断"这批货是不是它生产的"

按单据链条逐环验证：

| 环节 | 看什么 | 指向 |
|---|---|---|
| COA | 生产商名称（抬头） | 生产主体 |
| 原产地证 CO | 生产国 | 与工厂所在国是否一致 |
| 商业发票 | 卖方抬头 | 与合同主体一致？ |
| 提单 B/L | 发货人 | 卖方或其授权方？ |
| 装箱单 | 批号 | 与 COA 批号一致？ |
| SDS | 生产商名称 | 与 COA 一致？ |

**六环全部对上 → 可以认定"这批货来自该生产商"。**
**任一环对不上 → 标「存在疑点」，装运前澄清。**

---

## 七、化工品专用检查

| 检查项 | 要点 |
|---|---|
| 等级/牌号 | 同一装置可产多个等级；等级决定关键指标 |
| 批号 | 必须能追溯到生产批次与检测记录 |
| 检测方法 | COA 是否注明方法（如 ASTM D1176、ISO 方法） |
| 包装/运输 | 散装船、ISO tank、IBC、桶；决定成本与损耗 |
| 储罐 | 贸易商是否有罐区（影响能否混批） |
| 危险品 | SDS 的 UN 编号、危险类别、包装类别 |
