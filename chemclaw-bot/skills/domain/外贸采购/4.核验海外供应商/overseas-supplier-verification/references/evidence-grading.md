# 证据分级与五态门槛

> 本 Playbook 的目的：让"已核实"三个字有统一、可复核、可反驳的标准。

---

## 一、五态定义与判定门槛

| 状态 | 中文 | 判定门槛 | 典型反例（不得判为已核实） |
|---|---|---|---|
| `verified` | 已核实 | ①官方/监管一手来源；或 ②≥2 个**相互独立**来源交叉印证，且原文可回溯 | "官网上写着"（官网自述不算一手，除非含可核标识符） |
| `doubt` | 存在疑点 | 两个以上来源/单据之间存在**具体矛盾**，或差异需要解释后才能放行 | 只有一处小瑕疵就给人扣"欺诈"帽子 |
| `unverified` | 未核实 | 有说法，但只有单一来源或企业自述 | 单一媒体转述 |
| `unknown` | 未知 | 检索后没有可引用来源，或来源因地域/权限不可访问 | 用"大概/应该"填空 |
| `na` | 不适用 | 该国无对应制度，或该问题对本笔交易不存在 | — |

### 关键区分

- **未核实 vs 未知**：未核实 = 有人说过但证据不够；未知 = 压根没找到说法。
- **存在疑点 ≠ 高风险**：疑点是"信息冲突"的中性描述，不是风险评估结论。

## 二、证据分级

| 等级 | 名称 | 包含 | 能否单独支撑「已核实」 |
|---|---|---|---|
| `primary` | 一手/官方 | 政府登记、监管披露、上市公司公告、企业官网原件（含可核标识符）、许可证、银行确认函 | ✅ 可以 |
| `secondary` | 二手/媒体 | 行业协会、行业数据库（GlobalData/ICIS）、主流财经媒体、贸易资讯、上市公司报道 | ⚠️ 需第二个独立来源 |
| `tertiary` | 三手/百科 | 百科、黄页、B2B 平台、论坛、转述 | ❌ 只能作线索 |
| `mock` | 模拟件 | 为演示制作的虚构文件 | ❌ 永远不能作为事实依据 |

### 企业官网算几手？

**两种情况要区分：**

| 情况 | 例子 | 等级 |
|---|---|---|
| 官网披露**可被第三方复核的标识符** | "CR No. 4700009432, Industrial License S/1367" | primary |
| 官网只是**宣传性表述** | "world-class facilities, 100 countries" | 不算证据（不进入证据表） |

判据：**这段话能不能被第三方拿去核对？** 能 → 一手；不能 → 宣传。

## 三、证据条目必须包含的字段

```json
{
  "id": "E05",
  "claim": "被核验的事实陈述（一句话）",
  "publisher": "发布方",
  "type": "industrial_db",
  "grade": "secondary",
  "stance": "support",
  "url": "https://…",
  "published": "2023-05-04",
  "accessed": "2026-10-20",
  "quote": "逐字原文摘录（不能转述）",
  "used_for": "支撑哪一条结论",
  "note": "这份证据的局限"
}
```

### 为什么必须逐字摘录

1. 复核人可以直接 Ctrl+F 到原文；
2. 防止模型在转述时把"约"变成"是"、把"计划"变成"已投产"；
3. 争议时可以引原文。

### `stance` 三态

| 值 | 含义 | 用法 |
|---|---|---|
| `support` | 支持某事实成立 | 支撑"已核实" |
| `context` | 提供背景，不单独构成认定 | 行业格局、市场价格、历史事件 |
| `note` | 记录限制或方法性说明 | 说明"官方系统打不开" |

## 四、独立性判定（何谓"两个独立来源"）

**独立** = 不是同一个消息源的转述。

| 情形 | 是否独立 |
|---|---|
| 官网 + 官网托管的新闻稿 | ❌ 同源 |
| 媒体 A 引用媒体 B 的报道 | ❌ 同源（找到原始出处再判） |
| 上市公司年报 + 行业数据库 | ✅ 独立 |
| 上市公司年报 + 行业媒体独立采访 | ✅ 独立 |
| 两个不同的财经媒体各自报道同一事件 | ⚠️ 可能同源，看是否都引用同一份公告 |

**实操**：优先用"一个官方 + 一个独立第三方"的组合。

## 五、冲突处理

### 5.1 冲突不合并，要并列

发现两个来源矛盾时，**不要**选一个"更可信的"然后隐藏另一个。正确做法：

| 来源 A | 来源 B | 处理 |
|---|---|---|
| 说产能 X | 说产能 Y | 并列展示，标「存在疑点」，写清冲突点，要求补件 |

### 5.2 常见冲突类型

| 类型 | 例子 | 处置 |
|---|---|---|
| 数字冲突 | 复合体产能 10.46 mtpa vs 单装置 700 kt/y | 不是冲突，是**口径不同**；必须写明口径 |
| 时间冲突 | 一个说 1985 投产，一个说 1987 | 标「存在疑点」，索取投产证明 |
| 主体冲突 | 报道说是 A 公司，另一处说是 A 集团 | 回到主体映射 |
| 地理误标 | 把港口在波斯湾的装置写成"红海枢纽" | 记录为来源质量问题，不引用该细节 |

### 5.3 口径混淆（最容易被误读）

> **综合体总产能 ≠ 单产品装置产能 ≠ 可供给我方的量**

对外部数字，必须标注它属于哪种口径。**报告里不写口径的产能数字，是误导。**

## 六、时效性规则

| 证据类型 | 建议刷新周期 |
|---|---|
| 供应能力 / 停产 / 不可抗力 | 3 个月 |
| 制裁名单 | 每次付款前重查 |
| 注册状态 | 12 个月 |
| 产能/装置 | 24 个月 |
| 贸易救济措施 | 12 个月（措施会到期/复审） |

证据 `published` 超过 3 年且用于支撑「已核实」→ validate.py 会给出 W03 提示，引用前需刷新。

## 七、反模式清单

| 反模式 | 为什么错 | 改法 |
|---|---|---|
| 给"低/中/高风险"标签 | 没有可比基准时是伪精确 | 用五态 + 缺口 |
| 打风险分（0–100） | 分数无法解释、无法反驳 | 删掉，改用事实清单 |
| "未检索到负面信息 = 无风险" | 检索范围有限 | 写「未检索到」+ 检索范围 |
| 用宣传语当证据 | 任何人都能写 | 只收含标识符的证据 |
| 用第三方名录当官方登记 | 名录不具法律效力 | 标「未核实」并索取证书 |
| 把"差异"写成"欺诈" | 混淆事实与判断 | 写"需进一步验证" |
| 用"大概/应该/估计"填空 | 破坏可复核性 | 写「未知」+ 补件动作 |
