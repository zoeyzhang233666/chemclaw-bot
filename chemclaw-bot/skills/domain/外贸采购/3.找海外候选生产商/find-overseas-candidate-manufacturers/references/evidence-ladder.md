# 制造证据分级细则（Evidence Ladder）

## 为什么需要分级

"是不是厂家"看起来是二元问题，实际是一条证据链的强弱问题。二元标签会逼人**在证据不足时做二选一的猜测**，而分级允许说"我不知道，但我把它标出来"。

本分级回答的问题只有一个：**能否确认该法人拥有、运营该产品的生产装置，并提供该规格产品。**

## 四级定义

### A · 有直接公开制造证据

满足任一：

- **A1 装置级数据**：数据商/协会/专业媒体记载"某企业某基地的某装置，产能 X，工艺 Y"（如装置检修新闻点名 520 kt/a MEG 装置）。
- **A2 EPC/许可方项目记录**：工程承包商官网项目页写明"客户 = 该企业，产品 = 目标品，产能 = X"，且完工年合理。
- **A3 企业自身产品页/产能表**：企业官网以自身名义列出该产品与装置产能（KTA/MTPA）。
- **A4 官方新闻稿/交易所披露**：该具体工厂的投产、商业运营、扩产、检修公告。

**必要附加条件**：证据必须同时指向 **法人名 + 产品 + 基地** 三者。只指向两个的不算 A。

### B · 有产品业务关联但制造身份待核验

- 只有年报/环境许可层面的产品表（E5），无装置级证据；
- 或只有第三方转述（E6），但有具体产品记载；
- 或证据链存在**明显矛盾/缺口**：口径冲突、"glycol 类"未细分、项目已公告但未投产、集团称"附属公司在境外生产"但未指名。

**处理**：列入"待核验生产商"，发询证问题，不得直接询价签约。

### C · 仅存在行业相关性

- 属石化/化工集团或其附属，但产品清单中**没有**目标品；
- 或明确生产的是**近似品**（如目标 MEG，但实际做的是 PG / 丁基乙二醇醚 / 聚醚多元醇 / DEG）；
- 或只有原料段装置，无目标产品装置。

**处理**：从生产商清单移出，但**保留在报告里作为"证伪记录"**，防止同事再搜一次又把它捡回来。

### D · 贸易/代理/身份不明

- 贸易商、代理商、经销商；
- B2B 平台挂牌卖家、第三方名录条目；
- 无法确认法人主体（只有品牌名、贸易公司名）。

**处理**：只有当采购方"接受贸易商"时才进入候选；否则作为排除项记录。

## 判级决策树

```
有证据指向"该法人 + 该产品 + 该基地"吗？
├─ 没有 → 有该产品的任何产品级记载吗？
│         ├─ 有，但只是年报/第三方/矛盾线索 → B
│         └─ 没有，只是"化工集团/近似品" → C
└─ 有 → 证据属于 A1–A4 吗？
          ├─ 是 → A
          ├─ 只有 E5/E6 → B
          └─ 证据指向的是销售主体/贸易商 → D
```

## 边界案例与判例

| 情形 | 判级 | 理由 |
|---|---|---|
| 官网产品页写"produces 600 KTA of MEG"（WAF 拦截，仅索引摘要可见） | A（并标注"需截图存档") | 企业自述生产事实，但需二次核验存档 |
| 承包商项目页写"Client = 某合资公司，EG 700,000 MTPA" | A | 第三方专业记录，指向明确 |
| 集团年报说"我们是全球最大 XX 生产商" | 不构成 A | 集团口径，未指名装置 |
| 集团 affiliates 页列出甲醇/BDO/醋酸，但无目标品附属 | C（该集团不生产目标品） | 反向证据成立 |
| 反倾销名单把某公司列为出口商 | 不构成 A | 名单口径混杂，仅线索 |
| 平台把这家企业标为 "Chemical Trading Company" | 不改变判级 | 平台标签无意义；以企业自身与第三方专业证据为准 |
| 企业官网说"首家生产 Glycol Products"，但产品页只列 PG/多元醇 | C | 关键词误导，实质非目标品 |
| 数据商给出 380 kt/a，另一媒体说 520 kt/a | 仍可 A，但产能标"口径冲突" | 制造存在性成立，数量存疑 |
| 只有 2012 年的装置清单 | B | 时间过旧，不能证明当前 |

## 置信度标签

每条证据另打置信标签，与判级正交：

- **高**：企业官网全文读取 / 官方文件 / 承包商正式项目页
- **中**：权威媒体、数据商、索引原文命中但直连被拦
- **低**：聚合站点、平台、维基、二手转述

A 级企业至少要有 1 条"高"或 2 条"中"。

## 自检问题

判完级后，逐家自问：

1. 如果对方是采购经理，会被这份证据误导吗？会 → 降级。
2. 这条证据有没有可能被同一来源"自我引用"（A 转述 B，B 又引用 A）？同源证据只算一条。
3. 我判 A，是因为"真的看到了装置证据"，还是因为"它看起来很像"？
4. 我判 C/D，有没有留下可被复核的理由？（理由要能写进报告）
