# 逐企业核验清单（Verification Checklist）

对每一家企业走一遍。**未取得 = 写"待核验" + 生成问题编号**，不允许留空或猜测。

## A. 主体（Lawful existence）

- [ ] 法定英文/当地语言全称（照抄官网）
- [ ] 注册号 / 商业登记号（如沙特 CR No.、印尼 NIB、越南 ERC）
- [ ] 注册地址 vs 工厂地址是否同一
- [ ] 成立时间、上市代码（若上市）
- [ ] 集团归属与持股比例（注明来源年份；多来源冲突时并列）

## B. 工厂与装置（Manufacturing proof）

- [ ] 拥有哪些生产装置（逐套列名）
- [ ] 每套装置的产能与单位
- [ ] 装置所在地（工业城/园区/港口）
- [ ] 原料来源与是否配套上游装置（决定稳定性）
- [ ] 工艺许可方（Scientific Design / Shell / 自有工艺…）
- [ ] EPC 承包商与完工年份
- [ ] 近 3 年运行状态（投产/扩产/停车/检修/复产）
- [ ] 是否存在"EO 外售 vs 内转"等影响目标产品可供量的运行模式

## C. 产品（Product fit）

- [ ] 是否提供目标产品（而非近似品）
- [ ] 牌号/等级（纤维级、瓶级、工业级、电池级…）
- [ ] 关键规格：外观/色度（APHA）/水分/铁/酸度/灰分/氯化物/UV 透过率（视产品）
- [ ] 规格是"官网典型值"还是"实测 COA"
- [ ] 近 12 个月 COA 样本是否可获得
- [ ] 包装：散装/ISO tank/桶/IBC/袋，是否支持中国常用形式
- [ ] 联产品（DEG/TEG 等）规格

## D. 产能与供货（Supply reality）

- [ ] 名义/设计产能（带来源）
- [ ] 近 12 个月实际产量或负荷率（若公开）
- [ ] 当前可分配量 → **默认"待书面确认"**
- [ ] 装运港、典型到中国的航程
- [ ] 最小起订量、可接受的贸易术语（FOB/CFR/CIF）
- [ ] 是否有年度合约/slot 机制

## E. 质量与合规（Quality & Compliance）

- [ ] 工厂级 ISO 9001/14001/45001/50001 证书编号与有效期
- [ ] 产品是否在 REACH/其他法规下注册
- [ ] SDS（GHS，含中文版）
- [ ] 危化品/非危判定与运输文件
- [ ] 反倾销/贸易救济历史（出口目的地相关）
- [ ] 环境许可/排污许可（若公开可查）

## F. 商业与渠道（Channel）

- [ ] 对外签约主体（工厂 / 集团营销 / 合资方营销 / 代理）
- [ ] 是否接受中国买家直签
- [ ] 官方邮箱/电话/联系页（**只登记官网公开的**）
- [ ] 是否有中国区办事处/代表

## G. 风险与红旗（Red flags）

- [ ] 官网多年未更新
- [ ] 只出现在第三方名录、无自有官网
- [ ] 平台标签为 Trading Company
- [ ] 产品清单无目标品，但营销材料提及
- [ ] 产能数字来源单一且过时
- [ ] 装置长期停车新闻
- [ ] 联系方式只有一次性表单，无固定电话/域名邮箱
- [ ] 与已知贸易商同名或共址

## 结论写法

每家输出一段 **判定理由**，结构固定：

1. 结论（A/B/C/D + 一句话定性）
2. 依据（哪几条证据、指向什么）
3. 缺口（哪几项没拿到）
4. 下一步（对应问题编号）

示例：

> **A · 有直接公开制造证据**。官网产品表以企业自身名义列出目标产品 700 KTA；承包商项目页载明"客户 = 该企业，产能 700,000 MTPA，EPC 完工 2021"。缺口：工厂级 ISO 证书编号、近 12 个月 COA 未取得。下一步：QS-05、QS-06、QS-07。
