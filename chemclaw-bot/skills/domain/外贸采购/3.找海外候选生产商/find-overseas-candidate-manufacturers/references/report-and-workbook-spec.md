# 交付物规格：交互式 HTML 报告 + Excel 寻源工作簿

两者必须**同源于一份 `case_output.json`**，禁止手工分叉。

---

## 一、交互式 HTML 报告

### 版式（从上到下，章节编号固定）

| # | 章节 | 必含元素 |
|---|---|---|
| 1 | 顶部 Hero | 标题、一句话结论式导语、5 个统计块（主体数、A/B/C/D 或问题数）、报告编号/产品/日期 chips |
| 2 | 目标产品与采购口径 | 产品、CAS/HS、规格、工艺路线、包装、批量、认证、是否仅接受厂家；**关键判断规则**说明框 |
| 3 | 制造证据等级定义 | A/B/C/D 四色卡片，含定义 |
| 4 | 筛选漏斗 | 初始候选 → 产品级线索 → 装置级证据 → 可询盘主体 |
| 5 | 关系图谱 | 内嵌 SVG，展示集团/合资方/工厂/销售/贸易的关系，两类连线（控股实线、营销虚线） |
| 6 | **企业清单：生产商 / 贸易商分栏** | 工具栏筛选 + 左右两栏卡片 |
| 7 | 产品规格与产能口径对照 | 表格，含"口径冲突"与"当前供货能力" |
| 8 | 市场背景 | 2–3 条带来源的数据，用于解释"为什么必须找工厂" |
| 9 | 询证问题清单 | 全量表格 + 生成/复制/下载按钮 |
| 10 | 证据来源 | 全量来源表 + 免责声明 |

### 筛选器（必须有）

- 分栏切换：全部 / 生产商 / 贸易及销售主体
- 证据等级 A–D
- 工厂所在地
- 企业类型（七类）
- 公开产能（≥ 某阈值 / 未获证）
- 关键词搜索

筛选后两栏计数实时更新，空结果显示提示而非空白。

### 企业卡片（默认折叠，点击展开）必含

1. 排名、法定名、中文名/当地语名、证据等级徽章、主体类型徽章
2. 六宫格：所属集团、股权归属、工厂所在地、成立/投产、公开产能、生产工艺
3. **判定理由**色块（按等级配色）
4. 产品与规格表 + 产能口径明细 + 警示（口径/运行风险）
5. 官方公开联系渠道表（含核验状态）+ 认证表
6. **制造证据链表**：证据ID、类型、置信度、原文摘要、来源链接
7. 出口与贸易信息、风险提示
8. 该企业的询证问题列表
9. 三个按钮：**核验该海外供应商**（弹窗给出下一步核验顺序）、**生成询证问题清单**（生成可复制文本）、**复制询盘要点**（英文询盘）

### 技术约束

- **单文件**，离线可用：CSS/JS 内联，图标用内联 SVG，不引用 CDN/外部字体（中文用系统字体栈）。
- 无外部网络依赖；`file://` 直接打开即可运行。
- 响应式：>1000px 双栏，以下堆叠为单栏。
- 打印友好（`window.print()` 可导出 PDF）。

## 二、Excel 寻源工作簿

### 工作表（12 个）

| # | 表名 | 内容 | 关键列 |
|---|---|---|---|
| 00 | 封面与说明 | 产品口径、等级体系、导航、免责声明 | — |
| 01 | 企业总表 | 全部主体一表呈现 | 企业名、企业类型、**分栏**、证据等级、集团、工厂、产能、证据编号、联系方式、待核验问题数、判定理由 |
| 02 | 生产商清单 | 仅 A/B 级制造主体 | 工厂、产能口径、首要制造证据、来源URL、规格、可供货量（待确认） |
| 03 | 贸易与销售主体 | 销售主体 / 近似品 / 贸易商 | 归类、为什么不能当工厂、处理建议 |
| 04 | 制造证据台账 | 逐条证据 | 企业、证据ID、类型、性质、置信度、原文、来源URL |
| 05 | 产能与规格对照 | 产能口径 + 规格明细 | 口径明细与冲突、当前供货能力判断 |
| 06 | 官方联系渠道 | 渠道与核验状态 | 渠道类型、公开信息、状态 |
| 07 | 认证与质量文件 | 认证状态 | 认证、状态、下一步动作 |
| 08 | 询证问题清单 | 全部问题 | 编号、企业、问题、**状态下拉**、回复要点、负责人 |
| 09 | 证据来源 | 全部来源 | 标题、URL、日期、收录状态 |
| 10 | 筛选漏斗 | 收敛过程 + 柱状图 + 等级统计 | — |
| 11 | 新建候选_模板 | 空白录入表（15 行） | 16 列，含类型与等级**数据验证下拉** |

### 格式要求

- 每表：标题行（合并）+ 副标题说明（含免责声明提示）+ 表头（深底色白字）+ 冻结窗格 + 自动筛选。
- 证据等级列按 A/B/C/D 上色（绿/黄/灰/红）。
- 长文本列设置合理列宽与自动换行，行高足够阅读。
- 不使用需要外部链接的图片；图表用原生 BarChart。

### 一致性检查

- 企业数、问题数、来源数、证据条数与 HTML 一致。
- 分栏规则一致：`entity_type ∈ {MANUFACTURER, JV_MANUFACTURER} 且 grade ∈ {A,B}` → 生产商栏，否则贸易/销售栏。
