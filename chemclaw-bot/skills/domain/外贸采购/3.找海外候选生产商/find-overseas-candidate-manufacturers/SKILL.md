# 找海外候选生产商（Find Overseas Candidate Manufacturers）

## 这个 Skill 解决什么问题

采购方要的不是"一批公司名字"，而是：**在目标国家，哪些企业真的拥有这个产品的生产装置，证据是什么，剩下哪些必须核实**。

失败模式几乎总是同一种：拿到一份第三方供应商名录或搜索结果，把"经营范围包含该产品""平台挂了商品链接""集团很大"直接当成"这是生产厂家"，然后拿它去报价、签合同。本 Skill 的全部设计就是为了在结构上阻止这件事。

**核心原则（不可违反）**

1. **制造证据分级，不给单一"是否厂家"标签。** 每家主体必须落到 A / B / C / D 四级之一，并写明判定理由。
2. **主体分离。** 集团（holding/营销）、生产实体（plant company）、销售实体（sales/affiliates）、贸易中间商必须分开登记。集团官网说"我们是全球最大 XX 生产商"是**集团口径**，不能证明集团法人拥有装置。
3. **公开设计产能 ≠ 当前可供货能力。** 产能字段必须带口径来源与注意事项；当前可售量一律标"待书面确认"。
4. **单位与口径照抄，不换算、不合并。** 同一产品在不同资料里可能给出 380 / 420 / 520 / 660 kt/a，必须并列记录并标"口径冲突待核验"，而不是"取一个合理的"。
5. **不虚构。** 产能、认证、电话、邮箱、装置许可方、投产日期——拿不到就写"待核验"，并转成一条询证问题。绝对不要编造联系方式或证书编号。
6. **反向证据同样要写。** 证伪（"这家做的是丙二醇不是 MEG""这家只是营销方"）比再多正面线索都值钱，必须落表。

---

## 何时使用 / 何时不用

**用本 Skill**：从国家 + 产品出发找真实生产商；核验"这家到底是不是工厂"；区分生产商与贸易商；为后续询盘/验厂准备结构化证据。

**不要用本 Skill**：已经锁定 1 家供应商要做尽调打分（用供应商核验类 Skill）；算进口成本（用成本测算类 Skill）；研究某国市场规模与竞争格局（用市场研究类 Skill）。本 Skill 的产出会成为这些流程的输入。

## 执行流程（六步，顺序不可颠倒）

### Step 0 · 锁定采购口径（10 分钟，别跳）

缺失任何一项，就在报告里标"未提供，建议确认"，**不要假设**：

| 字段 | 为什么必须先问 | 缺失时的处理 |
|---|---|---|
| 目标国家/地区 | 决定候选池范围（是否含海湾自贸区、转口国） | 必须问 |
| 产品 + 化学名/CAS | 决定同义词与易混淆品（如 MEG vs DEG vs PG vs 聚醚多元醇） | 必须问 |
| 纯度/牌号/规格 | 决定对方是否真有该牌号（纤维级≠工业级≠电池级） | 标待确认，仍可调查 |
| HS 编码 | 决定贸易数据与反倾销核查口径 | 自行推断并标"建议确认" |
| 预计采购量 | 决定谈判地位与最小起订量现实性 | 标待确认 |
| 是否只接受实际厂家 | 决定贸易商要不要进表 | 默认"是"，并保留贸易商栏 |
| 需要的认证/包装 | 决定证据采集重点（ISO/SDS/COA/散装 or 桶装） | 标待确认 |

输出一份 `case_input`（见 `templates/case_input.template.json`）。

### Step 1 · 建候选池（宁可多，不可漏）

候选来源按可靠性从高到低：

1. **工艺流程反推**：该产品需要什么原料/装置（如 MEG 必须有乙烯 → EO/EG 装置）。凡是"有乙烯+EO"的综合石化基地就是候选，哪怕它没宣传这个产品。
2. **国家石化/化工产业带**：工业城、园区、自贸区的入驻企业清单（如沙特朱拜勒、延布）。
3. **集团族谱**：大集团的附属公司列表（affiliates），逐个看产品表。
4. **EPC/技术许可方项目清单**：承包商（Toyo、Samsung E&A、CTCI、Fluor…）的项目页常写"客户 + 产能 + 工艺"，这是极强的制造证据。
5. **官方文件**：年报、交易所披露、投产公告、环评/环境许可、整改公告。
6. **贸易救济/反倾销名单**：能证明"该国出口过该产品"，但**常常把集团关联方混列**，只能当线索。
7. **行业媒体与数据商**：装置级产能、停车检修新闻（能证明"真实在运行"）。
8. **B2B 平台与第三方名录**：**只用来发现名字**，绝不用来证明制造身份。

把候选写进 `candidates` 列表，每个候选至少要有：名字、为什么被列为候选（一行）。

### Step 2 · 逐家取证（本 Skill 的核心工作量）

对每个候选，按下面的"证据获取清单"逐项尝试，并把**拿到/没拿到**都记下来。

**2.1 制造证据的六个层级（越靠上越硬）**

| 层级 | 证据 | 典型载体 | 强度 |
|---|---|---|---|
| E1 | 装置级产能/运行数据 | 数据商、行业协会、装置级检修新闻（"某某 520 kt/a MEG 装置 5 月停车"） | 最强 |
| E2 | EPC/技术许可方项目页 | 承包商官网项目页：客户名 + 产品 + 产能 + 工艺 + 完工年 | 强 |
| E3 | 企业自身产品页/产能表 | 官网 Products 表：产品 + 装置产能 + 用途 | 强 |
| E4 | 官方新闻稿/交易所文件 | 投产、商业运营、检修公告，带具体工厂名 | 强 |
| E5 | 年报/环境许可/整改文件 | 产品表、装置表、排污许可 | 中强 |
| E6 | 第三方转述 | 媒体、名录、维基、平台挂牌 | 弱（仅线索） |

**判级规则**

- **A 有直接公开制造证据**：至少一条 E1–E4，且指向"该法人 + 该产品 + 该基地"。E5 可作为补强，单独出现时最多 B。
- **B 有产品业务关联但制造身份待核验**：只有 E5/E6，或证据链存在矛盾（口径冲突、只说"glycol 类"没说是哪种、项目公告但未见投产）。
- **C 仅存在行业相关性**：是石化/化工集团或附属，但产品清单里根本没有目标品，或明确生产的是易混淆的近似品。
- **D 贸易/代理/身份不明**：贸易商、平台卖家、代理、无法确认主体。

> 判级时问自己一句：**"如果采购经理拿这份证据去签合同，会被骗吗？"** 会 → 降级。

**2.2 产品规格与产能的采集口径**

- 规格：只抄原文指标（色度 APHA、水分、铁、酸度、UV 透过率、馏程…），标注"企业公开典型值 / 需索取规格书"。
- 产能：必须记录 **单位、口径（设计/名义/实际）、数据年份、数据来源**。同一家企业多个数字 → 全部并列，不要合并。
- 工艺：许可方（Scientific Design / Shell OMEGA / 高化学等）、原料路线（乙烯/煤/天然气）。工艺是判断"能不能出该牌号"的关键。
- **运行状态**：有没有近年的停车、检修、扩产？这是"公开产能 ≠ 可供货"的直接证据。

**2.3 联系方式**：只登记官网公开的地址、总机、传真、官方邮箱、联系页 URL。**绝不推测邮箱格式**（如猜 info@xxx）。取不到就写"官网未公开，待核验"。

**2.4 认证与质量文件**：ISO 9001/14001/45001/50001、REACH、SDS、COA、产品认证。要点：**必须对应到具体工厂**，集团证书不能替代工厂证书。拿不到证书编号就标待核验。

### Step 3 · 主体归类与关系图谱

每个主体打两个独立标签（不要合并成一个"供应商类型"）：

- **主体性质**：制造企业 / 合资制造企业 / 集团销售主体 / 附属公司销售主体 / 一般贸易商 / 代理经销商 / 身份不明
- **证据等级**：A / B / C / D

然后画关系：谁持股谁、谁营销谁的产品、谁是签约窗口。特别注意三种常见陷阱：

1. **集团 = 营销方**，工厂在附属公司（"我们是最大生产商"≠ 集团法人有厂）。
2. **合资方的销售公司**可能是对华的实际签约窗口，但它本身没有装置（比如日方联合体营销合资厂约 1/3 产品）。
3. **集团 affiliates 列表里没有该产品的生产附属**，往往说明集团确实不生产该产品。

### Step 4 · 生成询证问题清单

每一处"待核验"都要变成一条可发出的问题。模板见 `references/question-bank.md`，至少覆盖：

- 主体一致性：签约主体、注册号、注册地址 vs 工厂地址
- 制造一致性：是否拥有该装置、装置名称/许可号、能否提供装置照片或铭牌
- 规格一致性：COA 常规项、近 12 个月批次样本
- 产能口径：名义 vs 实际、近 12 个月产量/负荷
- 供货能力：可分配量、装运港、最小起订量、贸易术语
- 认证：工厂级证书编号与有效期
- 渠道：是直营还是经集团营销方/代理

编号规则：`QS-序号`，并在 Excel 里带状态列（未发出/已发出/已回复/需跟进/已关闭）。

### Step 5 · 产出交付物（两份，缺一不可）

1. **交互式 HTML 报告**：产品口径 → 分级定义 → 筛选漏斗 → 关系图谱 → 生产商/贸易商**分栏**清单（可筛选：证据等级、工厂所在地、企业类型、公开产能、关键词）→ 逐企业证据链与"核验此供应商 / 生成询证清单"按钮 → 规格产能对照 → 问题清单 → 来源清单。
2. **Excel 寻源工作簿**：至少 10 个工作表（企业总表、生产商分栏、贸易/销售分栏、制造证据台账、产能与规格对照、官方联系渠道、认证与质量文件、询证问题清单、证据来源、筛选漏斗/统计、新建候选模板）。

模板：`templates/report_template.html`、`templates/workbook_spec.md`。生成脚本：`scripts/build_report.py`、`scripts/build_workbook.py`（读取 `case_output.json`，无需改代码）。

### Step 6 · 自检（不通过不得交付）

跑 `scripts/self_check.py`，并人工确认：

- [ ] 每条 A 级企业至少有一条指向"法人+产品+基地"的 E1–E4 证据
- [ ] 没有任何企业仅凭"经营范围/名录/平台标签/关键词"被判为厂家
- [ ] 所有联系方式都能在来源 URL 里对得上
- [ ] 所有产能都带来源与口径说明，冲突已并列
- [ ] 所有未取得字段写"待核验"，且都有对应问题编号
- [ ] 产品规格没有把近似品（如 PG/DEG/聚醚多元醇）当成目标品
- [ ] 报告开头有免责声明：公开资料、仅供寻源、不得替代验厂

## 检索与取证技巧（通用，与行业无关）

- **先搜公司名 + 产品缩写**，再搜 `"装置" OR "plant" OR "unit" + 产能数字`；数字（`700,000 t/y`、`600 KTA`）往往比文字更能命中装置页。
- **反向搜索易混淆品**：搜 `产品名 + "not"`、"其他 glycol"、"polyols"，确认对方真正在做什么。
- **用 EPC 承包商名录反查**：搜承包商名 + 国家 + `EO/EG`、`acetyl`、`cracker`，项目页常直接给客户与产能。
- **用交易所/年报 PDF 的"产能表"页**：Tadawul、SGX、SET、IDX 等都有 PDF，产品产能表通常在第 10–30 页。
- **装置级运行新闻**：搜 `"shut" / "turnaround" / "restart" + 公司 + 产品`，能证明"真实在运行"，也能暴露"长期停车"。
- **抓取失败是常态**：很多企业站有 WAF/Cloudflare。抓不到时：
  - 记录"检索索引原文命中"并标注"直连被拦，需二次核验"；
  - 用搜索引擎缓存/摘要作为线索，但**不把它当成 A 级证据的唯一来源**；
  - 在来源状态列写清楚（已核验全文 / 索引命中 / 直连失败）。
- **注意日期**：老资料（10 年以上的装置清单）只能证明历史；产能变化、装置关停必须用新资料覆盖或标"待更新"。

## 数据契约

`case_output.json` 的字段定义见 `references/data_contract.md`。最简结构：

```json
{
  "meta": {...产品与采购口径、免责声明、分级定义...},
  "groups": [{"id":"G-1","name":"...","note":"..."}],
  "companies": [{
    "id":"C-1","legal_name":"...","entity_type":"MANUFACTURER",
    "grade":"A","grade_reason":"...",
    "group":"G-1","site":"...","capacity":{"meg_mtpa":"...","detail":"...","caveat":"..."},
    "evidence":[{"id":"E1","type":"...","grade":"直接","src":"S1","text":"原文摘要","conf":"高"}],
    "official_channels":[...], "certifications":[...], "open_questions":["QS-01"]
  }],
  "questions": [{"id":"QS-01","company":"C-1","q":"..."}],
  "sources": [{"id":"S1","title":"...","url":"...","date":"...","status":"..."}]
}
```

产品字段名（`meg_mtpa`）在通用版本里统一用 `capacity.expr`（自由文本，带单位），模板已按通用字段设计；沙特 MEG 案例保留了原字段以直读。

## 常见误区（每条都对应真实翻车方式）

1. **把"集团"当"厂家"** ——集团法人往往只控股+营销。
2. **把"销售公司"当"厂家"** ——合资方的营销平台常被误当生产商。
3. **把"glycol"当目标品** ——丙二醇、丁基乙二醇醚、聚醚多元醇都会命中 glycol 关键词。
4. **把"被反倾销名单列名"当"生产商"** ——名单口径会把集团关联方混列。
5. **把"平台挂牌"当"生产商"** ——平台甚至在同一页面把生产企业标成 "Trading Company"。
6. **把"设计产能"当"可供货量"** ——装置可能停车、检修、或原料不足。
7. **把"多份资料的数字"合并成一个** ——数字冲突必须保留冲突，这才是最有价值的询证线索。
8. **自己编联系方式** ——一次编造就毁掉整份报告的可信度。
