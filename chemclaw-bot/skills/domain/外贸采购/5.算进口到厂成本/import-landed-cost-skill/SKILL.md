# 进口到厂成本测算（Import Landed Cost）

把一张外币报价变成工厂里可决策的人民币每吨成本，并让每一个数字都能回答三件事：
**谁给的、什么时候核的、失效条件是什么**。

---

## 0. 开工前必须问清的四件事

按顺序确认，缺一项就在输出里标「待确认」，**不要替他猜**：

| # | 要确认 | 为什么必须先确认 |
|---|---|---|
| 1 | **产品 + HS 编码（或可推断的产品描述）** | 税率、监管条件、法检全挂在 HS 上 |
| 2 | **数量与计价单位**（吨 / 柜 / 整批） | 港杂、报关、仓储是按票的，摊到每吨随量变化 |
| 3 | **Incoterms 术语 + 指定地点 + 版本**（例：`CIF 宁波 Incoterms 2020`） | 决定哪些费用已在报价里，防止重复计入 |
| 4 | **报价币种与价格基准**（USD/吨？含包装？含税？） | 决定汇率口径与包装费是否另加 |

用户如果直接说"帮我算一下"，先按上面四条把信息补全再动手；信息不全时，
**先给出带「待补全」标记的框架 + 明确的补数据清单**，不要用行业平均值填空。

---

## 1. 五条铁律（违反任何一条，输出即废）

1. **不许把未确定的费用默认成 0。** 未填 = 空 = 待确认。完整到厂成本显示为「待补全」，
   同时单独给出「已知成本小计」，并注明这是下限、不是完整到厂价。
2. **不许把可抵扣增值税算进最终经济成本。** 增值税是现金流出、是进项，抵扣后回流。
   必须分两栏：`现金支出（含增值税）` 与 `最终经济成本（−可抵扣进项）`。
3. **不许重复计费。** CFR/CIF 的海运费已在报价里，CIF/CIP/DDP 的保险费已在报价里。
   再算一遍就是虚增成本。用术语矩阵机械判定，不靠记忆。
4. **不许把演示费率说成实时报价。** 运费、保险费率、港杂、仓储若来自假设，
   必须逐项标注「模拟情景」，并说明真实数据该找谁要。
5. **不许用市场汇率替代海关计征汇率。** 两者口径不同（见 §5）。
   海关汇率不明时如实标「待确认」，但允许在**明确标注为占位值**的前提下列示演示结果。

## 2. 计算链（按顺序，每步都可能产生"待补全"）

```
① 货值(原币)        = 单价 × 数量
② 包装费             = 已含于单价 ? 0 : 另计金额        ← 《关税法》第25条：包装费计入计税价格
③ 起运港/出口侧费用   = 术语已含 ? 0 : 实付金额
④ 海运费             = 术语已含 ? 0 : (USD/MT × 数量 或 整票报价)
⑤ 保险费             = 术语已含 ? 0 : 实付保费 或 (货值+运费)×费率×110%
        ——— 以上合计 = 到岸成本（CIF 等值，原币）———
⑥ 海关计征保险费       = 有保费 ? 实际保费 : (货值+运费+…)×0.3‰ ÷ (1−0.3‰)
⑦ 完税价格(CNY)      = (①+②+③+④+⑥) × 海关计征汇率
⑧ 应纳关税           = ⑦ × 实征关税税率                （永久成本，不可抵扣）
⑨ 反倾销/反补贴税     = ⑦ × 措施税率
⑩ 增值税基数          = ⑦ + ⑧ + ⑨ (+消费税)
⑪ 进口环节增值税       = ⑩ × 13%                        （现金支出）
⑫ 境内费用           = 港杂 + 报关 + 检验 + 仓储 + 内陆运输 + 资金成本   （不进计税价格）
⑬ 整票现金支出        = 到岸成本(CNY) + ⑧ + ⑨ + ⑪ + ⑫
⑭ 最终经济成本        = ⑬ − 可抵扣进项(⑪×可抵扣比例)
⑮ 每吨                = ⑬、⑭ 分别 ÷ 数量
```

**为什么 ⑥ 用 `r/(1−r)`**：如果直接用 `(货价+运费)×0.3‰`，海关又把这道保险费并进完税价格后
再按 0.3‰ 复核，会形成递归。取 `保费/(货价+运费) = r/(1−r)`（r=0.3‰）是唯一自洽解，
等价于"以含保险费的价格为基数"。见 `references/china-import-tax-rules.md` §4。

## 3. 术语 → 费用归属（机械判定，不靠记忆）

完整 11 项见 `references/yaml/incoterms_2020_matrix.yaml`。核心三条：

| 你要加的 | 只在这些术语下要加 | 在这些术语下**不能**加 |
|---|---|---|
| 海运费 | EXW / FCA / FAS / FOB | CFR / CIF / CPT / CIP / DAP / DPU / DDP |
| 保险费 | EXW / FCA / FAS / FOB / CFR / CPT / DAP / DPU | CIF / CIP / DDP |
| 起运港/出口侧费 | EXW / FCA | FAS 及以上 |

> 自检口诀：**FOB 加两样（运费+保险），CFR 加一样（保险），CIF 一样都不加。**

同一批货换成三个口径报回来，若经济实质相同（运费、保险相同），
**到厂成本应当几乎相等**，差额只来自卖方对运费/保险的加价——这才是议价抓手。
详见 `examples/02_case_saudi_meg_ningbo.json` 与 `examples/walkthrough_saudi_meg.md`。

## 4. 关税：先过四道闸门，再谈税率

`references/hs-and-preferential-origin.md`

1. **归类**——按 GRI 归到 8 位/10 位，确认监管条件（法检、许可）。
2. **税率栏位**——协定 < 暂定 < 最惠国 < 普通。有协定税率时**不得**再用暂定税率。
3. **原产地资格**——协定必须已生效 + 产品在降税清单内 + 满足原产地规则 + 有有效证书。
   四道缺一，就只能走最惠国（MFN）。例：中国—海合会 FTA 未生效 → **沙特产地不享受协定税率**。
4. **贸易救济**——反倾销/反补贴是否覆盖该国家、该企业（税率可能按企业分档）。

必须在输出里写明税率的**核验日期**，因为税则每年调整。

## 5. 两个汇率，不要混用

| | 市场参考汇率 | 海关计征汇率 |
|---|---|---|
| 用途 | 货值、运费折算成人民币看现金 | 完税价格、关税、增值税的折算 |
| 口径 | 银行结售汇 / 中间价 / ECB 交叉 | **申报日所属月份上一个月的第三个星期三**的央行中间价（遇节假日顺延） |
| 示例 | USD/CNY 6.6807（ECB 交叉，2026-10-19） | 申报日 2026-10-20 → 用 2026-09-16 的中间价 |

工具：`scripts/fetch_fx.py` 一次拉两种，海关那一路拿不到时返回 `status: 待确认`，
**绝不**用市场汇率顶替。详见 `references/fx-and-sensitivity.md`。

## 6. 交付什么

### 6.1 HTML 交互式计算器 `assets/import_landed_cost_calculator.html`
单文件、离线可用。首屏 KPI（到厂成本 / 现金支出 / 到岸成本 / 较报价高多少）→
口径切换 → 成本瀑布 → 明细表（每项带来源徽标）→ 增值税拆分 → 双汇率 →
敏感性（汇率 ±3%、运费 ±20%、数量 0.5–2×、龙卷风）→ **可替换输入区** → 数据来源表。

### 6.2 Excel 工作簿 `assets/import_landed_cost_calculator.xlsx`
8 页：使用说明 / FOB / CFR / CIF / 口径对照 / 敏感性分析 / 数据来源 / 术语规则。
**全部为活公式**，改黄色单元格即重算；空白用 `ISNUMBER()/COUNT()` 判定，
不会悄悄变 0；改到关键项缺失时状态自动变「待补全」。

### 6.3 计算引擎 `scripts/landed_cost_engine.py`
单一事实来源。HTML 与 Excel 都必须与它逐项对账（见 §8）。

## 7. 复用流程（换产品/换国家/换港口）

```bash
# 1) 拿汇率（市场 + 海关两条线）
python scripts/fetch_fx.py --date 2026-10-20 --base USD --to CNY --out fx_snapshot.json

# 2) 按你自己的产品改写输入 JSON（不要改引擎里的数字）
#    模板：examples/02_case_saudi_meg_ningbo.json；字段说明：references/templates/input_schema.yaml

# 3) 算
python scripts/landed_cost_engine.py --input ..\examples\02_case_saudi_meg_ningbo.json --pretty --sensitivity

# 4) 自检
python scripts/validate_costs.py
```

**换产品时只需改**：HS 编码、关税率（重新核验）、增值税率（多数 13%，少数 9%）、
原产地与协定资格、内陆距离与运费、港口与费用、币种与汇率对。
**不要**在代码里写死 MEG 的 5.5% 或 45 USD/MT —— 本技能所有数值都在输入文件里。

## 10. 常见错误（真实踩过的）

| 症状 | 原因 | 处置 |
|---|---|---|
| 到厂成本比国内采购贵一大截 | 把可抵扣增值税算进了成本 | 拆成现金口径 vs 经济口径 |
| CIF 报价算出来比 FOB 还贵很多 | 在 CIF 上又加了一次运费/保险 | 查术语矩阵，运费保险置 0 |
| 海关核定税额比自己算的高 | 用了市场汇率/漏了运保费进完税价格 | 用计征汇率，确认运保费已并入 |
| 税则上明明有协定税率却不能用 | 沙特等产地协定未生效 | 过四道闸门，退回 MFN |
| 每吨成本随数量剧烈变化看不懂 | 按票费用没摊薄 | 看数量敏感性，固定费除以吨数 |
| 空白格被当成 0，结果偏乐观 | 公式用了 SUM 直接吞掉空值 | 用 COUNT/ISNUMBER 判定完整性 |

## 11. 免责

本技能产出的是**决策测算**，不是报关申报文件。汇率、税率、口岸费用均有生效时点；
最终以海关核定完税价格、实际单据与货代实盘报价为准。
