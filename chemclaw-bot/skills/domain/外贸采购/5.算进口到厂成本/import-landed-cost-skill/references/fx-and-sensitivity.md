# 汇率口径与敏感性分析

---

## 1. 双轨汇率（不可混用）

| 汇率 | 用途 | 取值规则 | 结果页要求 |
|---|---|---|---|
| **市场参考汇率 `fx_market`** | 购汇现金、采购决策、敏感性的基准 | 银行牌价 / ECB 参考汇率交叉 / 市场中间价；必须注明类型+日期+来源 | 显示"汇率类型：市场参考" |
| **海关计征汇率 `fx_customs`** | 关税计税价格、进口环节增值税的折人民币 | 《关税法》第六十条：人民币汇率中间价，取"申报之日对应日期的上月第三个星期三"（节假日顺延） | 显示"汇率类型：海关计征"，并显示取数日 |
| 差异 | — | `fx_gap = fx_customs − fx_market` | 显示"汇率差异对税费的影响金额" |

> 若两者不同：`关税税额 = 计税价格(外币) × fx_customs × 关税税率`；而 **货值现金支出 = 货值(外币) × fx_market**。二者差异必须单独列出，不得用同一个数。

### 1.1 工具
```bash
python scripts/fetch_fx.py --date 2026-10-20 --base USD --to CNY --out fx.json
```
输出：市场参考汇率（exchangerate-api 实时牌价 + ECB 交叉核对）与**海关计征汇率取数日**。
海关计征汇率若无法从接口取到历史中间价 → 输出 `status: 待确认`，由人工录入。**严禁用市场汇率或最新中间价替代。**

## 2. 敏感性分析方法

### 2.1 汇率 ±3%（两个口径各跑一次）
```
Fx 敏感：fx_market × (1 + k)，k ∈ {−3%, 0, +3%}
Fx 海关：fx_customs × (1 + k)
到厂成本(k) = f(货值(k), 关税(k), 增值税(k), 境内费用(不变))
```
输出：整票到厂成本与元/吨到厂成本，并给出**每 1% 汇率变动对应的元/吨成本变动**（弹性）。
> 计算器实现：`fx_elasticity = Δ到厂成本/到厂成本 ÷ Δ汇率/汇率`，并给出"汇率每变动 1%，元/吨成本变动 ≈ X 元"。

### 2.2 运费变化（±10% / ±20%，或 ±X USD/MT）
- 运费自身变化：`Δ到岸成本 = Δ运费`
- **运费还通过计税价格放大**：`Δ关税 = Δ运费 × fx_customs × 关税率`；`Δ增值税 = Δ运费×(1+关税率)×fx_customs×增值税率`
- → 运费每变动 1 美元/吨，送到厂成本变动**大于** 1 美元（被关税与增值税放大）。
> 计算器实现：`freight_pass_through = 1 + 关税率 + (1+关税率)×增值税率`（可抵扣时）；不可抵扣时 = `[1+关税率]×(1+增值税率)`。

### 2.3 采购数量变化
- 数量影响**非随量变动**的费用摊薄：海运（按柜）、港杂（按柜/票）、报关（按票）、国内运输（按车次）；
- 若输入的费用是"整票包干价"，数量变化→元/吨成本反比例变化；若输入的是"元/吨单价"，则不变；
- 模型对每个费用标注 `basis`: `PER_TON`（随量） / `TOTAL`（整票包干） / `PER_CONTAINER`（按柜），分别处理。
> 计算器实现：数量情景 = {0.5Q, 0.75Q, 1.0Q, 1.5Q, 2.0Q}，输出元/吨与整票成本。

### 2.4 一维敏感性表 + 龙卷风图
- 一维表：对 `汇率、运费、关税率、数量、港杂、国内运输` 分别上下浮动，计算 `Δ元/吨到厂成本`；
- 龙卷风：按 |Δ| 排序，直观显示哪个因素最敏感；
- 双因素热力图（可选）：汇率 × 运费。

---

## 3. 结果表达纪律

1. 敏感性分析必须基于**同一个基准（口径一致：市场汇率或海关汇率，且注明用的是哪个）**；
2. 每一项变化都要写清"变化了什么、放大系数是多少"；
3. 不要给出"±3% 汇率导致成本变化 3% 左右"这种拍脑袋结论——化工进口中，**运费与关税的放大效应**常常使汇率弹性 > 1；
4. 所有模拟值必须标注"模拟情景（非实时市场报价）"。
