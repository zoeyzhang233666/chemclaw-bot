# 运费、保险、港杂、报关、仓储与国内运输

> 本文件解决"**费用不重复、不遗漏**"和"**缺数据不默认零**"两个问题。
> 计价单位：化工液体散货常用 `USD/MT`、`USD/柜`、`USD/FEU`、`元/吨`、`元/柜`、`元/票`、`元/天`。

---

## 1. 海运报价常见口径与重复计费陷阱

| 口径 | 通常包含 | 通常不含 | 陷阱 |
|---|---|---|---|
| **FOB → 报价用 Ocean Freight** | 海运费 + 起运港附加费 | 目的港 THC、换单费、码头堆存 | 与起运港 FOB 报价中的"装载费"重复 |
| **CY-CY（门到港）** | 海运费 + 起运港装柜 + 目的港卸柜（THC 视报价函） | 目的港后续费用 | **报价函必须写明目的港 THC 是否含**，含了就不能再算一次港杂 |
| **THC 预付 vs 到付** | 预付=计入海运费；到付=计入目的港费用 | — | 同一笔 THC 只能出现一次 |
| **BAF/CAF/PSS/LSS** 燃油/币值/旺季附加费 | 通常已含在海运报价中 | — | 若随运费单列要和海运报价对齐，避免重复 |
| **选港费、滞期费、免箱期外堆存** | 不含 | — | 化工散货到港后到工厂通常 3~10 天内提完，超期才产生，默认应留 0 并在"仓储"项另计 |

> 规则：**同一费用项目只能出现在一个字段**。在输入区为每个费用标注"是否已包含于报价/运费"。

## 2. 保险

| 情形 | 计入到厂成本的保费 | 计入海关计税价格的保费 |
|---|---|---|
| CIF / CIP / DDP 报价 | 已含（并在用户输入中标注"已含"） | 按报价视为包含；若报的是 CIF 又单列了保费，需避免重复 |
| CFR / CPT / FOB / EXW 且买方实际投保 | 实际支付保费（外币） | 若属于起卸前保险，应计入；实际支付≥0.3‰时取实际 |
| CFR / FOB 且未实际投保 | 0（但标"风险提示：无保险"） | **按（货价+运费）×0.3‰ 计算**（213号令第三十六条） |

- 保险费率常见 0.1%~0.6%（取决于货值、危险品、战争险附加）。**必须用真实保单/保费确认，不能把行业区间当报价。**
- Incoterms 2020 下 CIF 最低保障 110% 合同价；CIP 要求 A 条款。

## 4. 国内运输

- 港口→工厂：按整车/散货/危化品资质车计价；**化工品常需危化品运输资质**，运费高于普通货车；
- 宁波北仑→苏州（约 250~300 km），集卡整车按车次或元/吨计价；
- 超期用箱、掏箱、危险品申报、计量（地磅/流量计）另计；
- **不要用里程×单价推算运费**，除非用户明确同意作为模拟情景，并标注"模拟"。

---

## 5. 仓储

- 只在**入厂前实际发生**时计入：滞港堆存、保税仓存储、租库中转；
- 免箱期（通常 7~14 天）内不提货产生的滞箱费**属于运营超期成本**，未发生不得计入；
- 化工液罐仓储常按 元/吨·天 或 元/罐·月 计价。

## 6. 缺失数据规则（硬性）

| 缺失项 | 处理 |
|---|---|
| 海运费 | **阻断**：到岸成本、税费、到厂成本全部"待补全"；只展示"已知成本小计（货值等）" |
| 港杂费 | **阻断完整到厂价**：到岸成本可算，到厂成本标"待补全" |
| 报关费 | 同上（金额小但不可默认 0） |
| 国内运费 | 同上 |
| 仓储费 | 若用户确认"无仓储"可填 0 并注明"无；到港后直接提货"；未确认则标待补 |
| 保险费 | 不阻断（可依 0.3‰ 海关口径 + 标记"实际保费待补"），但必须同时在到厂成本中显示"保险（待补）" |
| 关税税率 | **阻断税费计算**；无法确认优惠资格时按 MFN 计算并提示"可能适用协定税率，需核验" |
| 汇率 | **阻断**；海关计征汇率必须单独填写 |
