# 中国进口税费规则底稿（关税 / 进口环节增值税 / 消费税）

> 本文件是"算进口到厂成本"的**计税层**依据。每条规则都给出条文来源与核验日期。
> 核验日期：**2026-10-20**。汇率、税率、政策均可能变动，每次计算都必须重新核验并在结果页标注"核验日期"。
>
> ⚠️ 本文件为业务整理，不构成税务/海关专业意见。落地金额以海关实际核定为准。

## 2. 关税税率体系（《关税法》第十条—第十四条）

### 2.1 五类税率

| 税率 | 适用对象 | 条文 |
|---|---|---|
| 最惠国税率 (MFN) | WTO 成员、与我国签有相互给予最惠国待遇条款条约的国家/地区 | 第十二条一款 |
| 协定税率 | 原产于与我国签署**含关税优惠条款的国际条约、协定**的国家/地区，且**符合协定原产地规则** | 第十二条二款 |
| 特惠税率 | 原产于我国给予**特殊关税优惠安排**的国家/地区 | 第十二条三款 |
| 普通税率 | 上述以外，或**原产地不明** | 第十二条四款 |
| 暂定税率 | 在一定期限内对特定货物实行 | 第十条、第十三条 |

### 2.2 适用顺序（不要搞错，这是最容易出错的一步）

1. **先定原产地**（第十一条）：关税税率的适用应符合相应原产地规则；完全获得的货物按获得地，两个以上国家参与生产的按"最后完成实质性改变"的国家/地区。
2. 再定税率：
   - 适用最惠国税率 + 有暂定税率 → **用暂定税率**；
   - 适用协定税率 + 有暂定税率 → **从低**；若最惠国税率低于协定税率且无暂定税率 → **用最惠国税率**（第十三条二款）；
   - 适用特惠税率 + 有暂定税率 → 从低；
   - **适用普通税率的不适用暂定税率**。

> 计算器实现：`tariff_selection()` 按"最惠国 / 暂定 / 协定 / 普通"四个输入 + 原产地标识，按上述规则取"实征税率"，并把"取哪个、为什么"写进结果"依据"栏。

### 2.3 税率适用日期（第二十条）
- 适用纳税人**完成申报之日**实施的税率；
- 先行申报的，适用**运输工具申报进境之日**的税率；
- 保税内销、减免税货物转让、暂时进境不复运出境、租赁留购 → 适用办理**纳税手续之日**的税率（第二十一条）。

### 2.4 从价计征（第二十三条）
```
应纳关税 = 计税价格 × 关税税率
```

## 3. 计税价格（完税价格）

### 3.1 定义（第二十四条）
进口货物计税价格 = **成交价格** + 该货物运抵**中华人民共和国境内输入地点起卸前**的**运输及相关费用** + **保险费**。

### 3.2 应计入（第二十五条）
1. 由买方负担的**购货佣金以外**的佣金和经纪费；
2. 由买方负担的、与该货物视为一体的**容器**费用；
3. 由买方负担的**包装材料费用和包装劳务费用**；
4. 买方免费或低于成本提供、并与生产及对华销售有关的**料件、工具、模具、消耗材料**及类似货物价款，境外开发/设计等相关服务费用；
5. 作为对华销售条件必须支付、与该货物有关的**特许权使用费**；
6. 卖方直接或间接从买方获得的该货物进口后转售、处置或使用的**收益**。

### 3.3 不计入（第二十六条）
1. 进口后建设、安装、装配、维修和技术服务费用（**保修费用除外**）；
2. 运抵境内输入地点**起卸后**的运输及相关费用、保险费；
3. **进口关税及国内税收**。

> 计算器实现：`landed_cost_model()` 中，`customs_value`(外币) = EXW 货值 + 包装另计部分 + 起运港费用 + 出口侧费用 + 海运 + 保险费（按当期是否属于"起卸前"）。港杂费、报关费、国内运输、仓储一律**不进**计税价格；关税与进口环节增值税不进计税价格（但增值税计税价格以"计税价格+关税+消费税"为基础）。

### 3.4 运费的计算（第三十五条，213 号令）
- 按**买方实际支付或应当支付**的费用计算；
- 无法确定的，按该货物**进口同期正常运输成本**确定。

### 3.5 保险费的计算（第三十六条，213 号令）——**最容易漏掉的一项**
- 按**实际支付**的保费计算；
- **无法确定或未实际发生**的，按"**货价加运费**"两者总额的 **3‰（0.3%）** 计算：
```
保险费 = (货价 + 运费) × 0.3‰ 口径
```
> 计算器实现：`insurance_customs_basis`：当报价为 FOB/FCA/EXW 且"保险已含=否"且未填保费时，按 0.3‰ 计算应计入计税价格的保险费，并同时标成"需买方补办的保险实际成本"（两者可不同：实际投保保费 ≥ 海关认定的 0.3‰ 时，以实际支付计入）。

### 3.6 成交价格不符合条件时（第二十七条）
按顺序估定：相同货物成交价 → 类似货物成交价 → 境内第一级销售价倒扣 → 计算价格 → 合理方法。
> 触发条件：买方处置受限、价格受搭售影响无法确定、卖方获取转售收益未调整、买卖双方有特殊关系且影响价格。到厂成本模型里，只要供应商与买方是关联方，就要提示"可能被估价"的风险。

## 4. 进口环节增值税

### 4.1 计税公式（《关税法》第七十条 + 《增值税法》及其实施细则口径）
```
组成计税价格 = 关税计税价格 + 实征关税税额 + 实征消费税税额
应纳进口环节增值税 = 组成计税价格 × 增值税税率
```
若为消费税从价计征品：
```
消费税组成计税价格 = (关税计税价格 + 关税) / (1 − 消费税比例税率)
消费税 = 消费税组成计税价格 × 消费税比例税率
```

> 官方口径原文（商务部法规库对《关税法》配套计算办法）："计征进口环节增值税的计算公式为：应纳税额＝（完税价格＋实征关税税额＋实征消费税税额）×增值税税率；从价计征进口环节消费税的计算公式为：应纳税额＝〔（完税价格＋实征关税税额）/（1－消费税率）〕×消费税税率。"

### 4.2 税率（2026 年）
- 一般货物（含乙二醇等绝大多数化工品）：**13%**；
- 低税率货物（农产品、自来水、天然气、图书报纸杂志、饲料、化肥、农药、农机、食用植物油等）：**9%**。
> 注意：判断依据是**产品税目**，不是"是不是进口"。乙二醇属有机化学品，适用 13%（与国内销售环节一致）。

### 4.3 现金支出 vs 可抵扣进项税额（**本 Skill 的核心分歧点**）
| 场景 | 进口环节增值税 13% 的处理 | 计入到厂成本？ |
|---|---|---|
| 进口方为**一般纳税人**，取得**海关进口增值税专用缴款书**，且货物用于**应税项目** | 缴纳时是**现金支出**；缴款书可作为**进项税额抵扣** | **不进最终成本**（仅在"现金支出"与"资金占用"中体现） |
| 一般纳税人但货物用于**免税项目/集体福利/个人消费** | 不得抵扣 | **进最终成本（含税成本）** |
| 小规模纳税人 / 未办理一般纳税人登记 | 不得抵扣 | **进最终成本（含税成本）** |
| 代理进口：缴款书同时标明代理方与委托方 | 按国税发〔1996〕32号，缴款书抬头与抵扣主体需对应；需在合同中明确谁抵扣 | 按实际抵扣主体判断 |

> 计算器实现（`vat_treatment()`）：
> - `deductible=true`：`final_economic_cost = 到岸成本 + 关税 + 不可抵扣的其他税费 + 境内费用`；`增值税`只进 `cash_outflow` 与 `working_capital`；
> - `deductible=false`：`final_economic_cost` 包含增值税全款；
> - 两种情形都必须**同时展示**"整票现金支出"与"可抵扣进项税额"，禁止只给一个数。

### 4.4 增值税的现金流出与抵扣时间差（资金成本）
- 进口环节增值税在**货物放行前**缴纳（一般由报关行代缴，时效 T+0~T+15）；
- 抵扣发生在**取得缴款书并完成勾选认证后的次月申报期**；
- 因此存在 1~2 个月的资金占用。资金成本 = 可抵扣税额 × 资金年化成本率 × 占用月数/12。**默认不当成本算，除非用户选择计入**。

## 5. 汇率：市场参考汇率 vs 海关计税汇率

### 5.1 海关计征汇率（《关税法》第六十条）
- **"进出口货物的价格以及有关费用以人民币以外的货币计算的，按照纳税人完成申报之日的计征汇率折合为人民币计算。前款所称计征汇率，是指按照海关总署规定确定的日期当日的人民币汇率中间价。"**
- 海关总署规定的"确定日期"（《进出口货物征税管理办法》，沿用原关税条例口径）：**海关每月使用的计征汇率为上一个月第三个星期三**（第三个星期三为法定节假日的，顺延采用第四个星期三）**中国人民银行公布的外币对人民币的基准汇率**（中间价）；
- 以基准汇率币种以外的外币计价的，采用同一时间**中国银行公布的现汇买入价和现汇卖出价的中间值**（人民币元后四舍五入保留 4 位小数）。
- 上述汇率发生重大波动，海关总署可另行规定并对外公布。

### 5.2 市场参考汇率
- 用于**采购决策与汇率敏感性分析**，类型可以为：银行牌价、ECB 参考汇率交叉、市场中间价。
- 与海关计征汇率**必然存在差异**，差异会造成"计划成本 ≠ 实际报关成本"。

### 5.3 计算器实现
- 两个汇率字段：`fx_declare`（市场参考，用于购汇现金换算）与 `fx_customs`（海关计征，用于税费计算）。
- **两者不同时**，结果页必须显示"汇率差异影响"：`Δ = (fx_customs − fx_declare) × (计税价格等相关外币金额) × (1+关税率) × (1+增值税率)`。
- **海关计征汇率不得用市场汇率替代**；接口拿不到历史中间价时，标"待确认"并要求人工录入（不得估算）。
- 工具：`scripts/fetch_fx.py`（抓市场汇率 + 提示海关计征汇率取数日）。

## 6. 反倾销 / 反补贴 / 保障措施（第十六条—第十九条）

- 若产品被采取反倾销/反补贴/保障措施，需在**最惠国或协定税率之外加征**；
- 第十九条：涉及第十六、十七、十八条措施的货物，纳税人未提供证明材料或无法排除原产于措施国的，按"（措施税率 + 适用税率）"与"普通税率"两者**较高者**征；
- → **模型里必须单列"反倾销税等加征"字段**，默认 0 但需人工核实，不得默认为无。（是否适用必须查商务部公告，不能在模板里写死。）

## 7. 免税额与关税配额的边界（第三十二条—第三十四条）
- 国务院规定的免征额度内的一票货物、无商业价值货样等免征关税；**"免征关税"不等于"免征进口增值税/消费税"**，差额计税仍涉及代征税。
- 化工品贸易中的常用例外：保税区内仓储、加工贸易手册、暂准进境等。本 Skill 的默认模型为**一般贸易（0110）**，其他监管方式须在"税务处理方式"中切换并重新核验。

## 8. 结果输出的硬性要求

1. 每一项必须标注来源：`用户输入` / `公开查询（含 URL 与核验日期）` / `计算推导（含公式）` / `模拟情景（非实时报价）` / `待确认`；
2. **缺失关键费用不得默认为 0**，必须：
   - 显示"已知成本小计"与"待补项清单"；
   - 把完整到厂成本标为 `待补全`，不输出虚假完整到厂价；
3. 增值税必须**分两栏**展示：`现金支出` 与 `可抵扣进项税额`；
4. 关税税率不得写死在模板中，必须来自税则查询/用户录入，并记录核验日期与来源。
