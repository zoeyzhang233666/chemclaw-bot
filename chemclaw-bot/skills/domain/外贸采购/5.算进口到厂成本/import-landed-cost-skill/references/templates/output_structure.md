# 输出结构（所有 Agent 统一使用）

结果页 / Excel 的报告必须按以下结构组织，字段名与 Python `landed_cost_model()` 输出一致。

---

## 1. 首屏 KPI（5 个卡片）
| 卡片 | 字段 | 说明 |
|---|---|---|
| 报价 | `quote.price_display` | 如 `USD 640.00/MT CIF 宁波`，含 Incoterms 版本 |
| 到岸成本 CIF 等值 | `kpi.cif_equivalent_per_ton_cny` / `total_cny` | 含税与否要写明"不含税进口成本" |
| 进口税费（现金） | `kpi.duty_cny`、`import_vat_cash_cny` | 关税不可抵扣；增值税单独列 |
| 参考到厂成本 | `kpi.landed_per_ton_cny` / `total_cny` | 若待补全，显示 `≥已知小计` 与"待补 N 项" |
| 每吨差额 | `kpi.vs_quote_delta_per_ton_cny` | 到厂 vs 报价的单价差（说明加价幅度） |

若 `full_landed_cost_status = 待补全`：
KPI 必须显示 **"已知成本小计"** 与 **"待补项数"**，不得显示一个看似完整的到厂价。

## 2. 费用分解（按阶段）
```
A 海外货值与出口侧
B 国际运输与保险
C 进口税费（关税 / 消费税 / 增值税现金 / 增值税可抵扣）
D 口岸与境内物流（港杂 / 报关 / 检验 / 仓储 / 国内运输）
E 资金与结算（可选）
```
每个行：`项目 | 原币金额 | 汇率 | 人民币金额 | 元/吨 | 是否计入计税价格 | 来源`

## 3. 三列对照：现金流 vs 可抵扣 vs 最终经济成本
| 口径 | 组成 | 用途 |
|---|---|---|
| **现金支出（Cash out）** | 货值+运费+保险+关税+增值税全款+境内费用 | 资金计划、授信、L/C |
| **可抵扣进项税额** | 进口环节增值税（一般纳税人+应税用途） | 税务抵扣、现金回流 |
| **最终经济成本** | 现金支出 − 可抵扣进项 | 真实采购成本、与国内价比价 |

> 不可抵扣时：最终经济成本 = 现金支出，并显著标注"进项不可抵扣，增值税 13% 全额进入成本"。

## 4. 增值税专表
```
关税计税价格(CNY)
+ 关税
+ 消费税
= 组成计税价格
× 13% = 进口环节增值税
其中：现金支出  |  可抵扣进项  |  不可抵扣部分（计入成本）
```

## 5. 敏感性
- 汇率 ±3%（市场口径与海关口径各一次）
- 运费 −20%/−10%/基准/+10%/+20%（并给"运费放大系数"）
- 数量 0.5Q/0.75Q/1Q/1.5Q/2Q（元/吨摊薄）
- 一维龙卷风：按 |Δ元/吨| 排序

## 6. 数据来源表（**必填**）
`项目 | 数值 | 类型(用户输入/公开查询/计算推导/模拟情景/待确认) | 来源(URL/文件名/日期) | 核验日期 | 失效条件`

## 7. 待确认清单
`字段 | 影响 | 补齐方式 | 补齐后对到厂成本的影响方向`

## 8. 免责
> 本测算基于 <核验日期> 的税率、汇率与费用口径；模拟项已显式标注；缺失项未按 0 处理；最终金额以海关核定、实际合同与账单为准。
