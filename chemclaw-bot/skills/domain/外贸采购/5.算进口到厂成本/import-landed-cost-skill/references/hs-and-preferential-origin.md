# HS 归类与优惠原产地核验手册

> 目的：**不让"优惠关税"变成拍脑袋的假设**。优惠税率不是填 0 就完事，必须同时满足：① 有生效的协定；② 产品在该协定降税清单内；③ 符合协定原产地规则；④ 有有效原产地证明且申报时正确填报。
> 核验日期见各条；本文件为业务整理，不构成归类意见。

---

## 1. 先归类，再谈税率

### 1.1 归类依据（《关税法》第九条）
商品归类按《税则》目录条文、**归类总规则（GRI）**、类注、章注、子目注释、本国子目注释及其他归类注释确定。

### 1.2 化工品归类的实战要点
| 情形 | 归类思路 |
|---|---|
| 单一有机化学品（MEG、PG、甲醇等） | 第 29 章；按化学结构归入相应税目；**纯度**、是否为混合物、是否用于特定用途影响归类 |
| 水溶液 | 浓度影响：（如"乙二醇水溶液"浓度降低可能仍归 29 章，也可能因添加物进入 38 章） |
| 混合物/制剂 | 第 38 章；按用途/成分归类 |
| 包装与零售 | 归入类注是否影响（如"零售包装的化学试剂"有专门税目） |
| 溶剂回收料 / 副产 | 可能归入 38 章"其他化学工业产品"，税率与原品不同 |

### 1.3 已知样例（**示例值，不得作为通用税率**）
| 税则号 | 货物 | MFN | 暂定 | 普通 | 备注 |
|---|---|---|---|---|---|
| **29053100** | 1,2-乙二醇（MEG） | **5.5%** | 未列 | 30% | 2026 税则基线；协定税率适用于智CL/新西兰NZ/哥CR/冰IS/澳AU/毛MU等，**不含沙特阿拉伯** |

> 来源：2026 年进出口税则 8 位号列检索，`https://www.zhengdao.ai/tariff/2026/29053100/`（页面标注"税则核验于 2026-07-15"）。最终适用取决于归类、原产地、暂定税率、措施及申报日期。**每次新计算必须重新查询并记录查询日期。**
>
> 重要：8 位税则不承载增值税率。**增值税率按货物税目查《增值税税目注释》**，不要从 8 位税则推。
> 10 位申报编码需另查（部分公开库仅收录部分 10 位编码，不等于无拆分）。

## 2. 优惠原产地的"四道闸门"

```
闸门1 协定是否已生效？           —— 商务部中国自由贸易区服务网 https://fta.mofcom.gov.cn
闸门2 产品是否在降税清单？       —— 协定附件（RCEP/中国-东盟/中国-智利 等关税减让表）
闸门3 是否满足协定原产地规则？   —— 完全获得 / 税则改变(CTC) / 区域价值成分(RVC) / 特定工序
闸门4 证明与申报是否合规？       —— 原产地证书（FTA Certificate of Origin）或原产地声明；
                                     进口时按规定填报"优惠贸易协定代码/原产地证明类型/编号/原产国"
```

海关管理依据：《中华人民共和国海关进出口货物优惠原产地管理规定》；《优惠贸易协定项下享惠进出口业务指引》（青岛海关 2024-09-12）。
> 填报字段：报关单需填报"优惠贸易协定代码""原产地证明类型""原产地证明编号""优惠贸易协定项下原产地""原产地证明商品项号"。

### 2.1 常见资格判断（截至 2026-10-20）
| 来源国/地区 | 对华优惠框架 | 化工品能否享受？ | 判断依据 |
|---|---|---|---|
| 沙特阿拉伯 / 巴林 / 阿联酋 / 卡塔尔 / 科威特 / 阿曼 | **中国—海合会自贸区：仍在谈判中，未生效** | **不能**（按 MFN 或暂定税率） | 商务部中国自由贸易区服务网"中国—海合会自由贸易区"专栏（2024-10 第11轮谈判、2025-05 仍在推进） |
| 日本 / 韩国 / 澳大利亚 / 新西兰 / 东盟 | RCEP、中韩、中澳、中国-东盟 | 需逐项查降税表与原产地规则 | fta.mofcom.gov.cn |
| 智利、哥斯达黎加、冰岛、瑞士、秘鲁、格鲁吉亚、毛里求斯、塞尔维亚 | 双边协定 | 视清单 | 税则协定栏 + 协定附件 |

> ⚠️ **注意"原产地 ≠ 起运国"**：从沙特起运、但在阿联酋转船/分装的货物，原产地仍是沙特；反之在第三国完成实质性改变的货物，原产地可能改变，从而改变可用协定。

### 2.2 优惠丧失的四种典型情形
1. 无原产地证书 / 证书与提单信息不一致；
2. 证书过期或签发后货物未在规定期限内进口；
3. 原产地判定被海关否定（如加工仅构成简单混合/分装，未满足 CTC/RVC）；
4. 申报时未选择适用协定税率（事后补办受限）。

### 2.3 反倾销/反补贴的叠加
- 是否被采取措施要查商务部公告；措施往往按**具体税号 + 具体原产国**落地；
- 若无法排除原产于措施国，按《关税法》第十九条取"（措施税率+适用税率）"与"普通税率"较高者。
- 到厂成本模型须保留 `anti_dumping_rate` 字段（默认 0，但必须人工核实后再计算）。

## 3. 抽样核验流程（每次计算必做，5 分钟）

```
1) 用 8 位税号查 2026 税则 → 记录：MFN、暂定、协定、普通 + 查询来源 + 查询日期
2) 查"是否有反倾销/反补贴/保障措施" → 记录公告编号或"未查到（不等于不存在）"
3) 若来源国可享协定 → 逐项核 4 道闸门 → 全过才填协定税率，否则一律按 MFN/暂定
4) 在结果页"税率依据"栏写明：税号、适用税率类型、取值、来源 URL、核验日期、失效条件
5) 若任一闸门无法确认 → 税率字段标"待确认"，不得默认 0
```
