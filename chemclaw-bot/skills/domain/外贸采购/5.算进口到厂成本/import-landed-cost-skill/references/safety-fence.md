# 适用边界与校验（跨 Agent 通用）

本 Skill 由不同 Agent 调用，**误用比不会用更危险**。以下为硬性边界。

---

## 1. 适用范围

✅ 适用：
- 一般贸易（0110）进口到中国的成本测算；
- 化工品（散货、桶装、ISO 罐、集装箱液袋）为主，也适用一般工业品；
- 贸易术语 EXW / FCA / FAS / FOB / CFR / CIF / CPT / CIP / DAP / DPU / DDP（Incoterms 2020）；
- 币种 USD / EUR / CNY / SAR / AED / JPY 等（非人民币需汇率折算）；
- 起运国任意，目的港为中国任一港口，最终收货地为中国境内工厂。

❌ 不适用（必须拒绝或降级并声明）：
- 加工贸易、保税仓储转内销、跨境电商零售进口、暂时进境（税率适用日期与计税价格口径不同）；
- 需要做商品归类的最终判定（本 Skill 只提供候选与核验流程，不替代归类意见）；
- 免税/减免税货物（法定减免清单不同）；
- 涉及反倾销措施的精确计税（需公告原文的征税对象与税率，必须人工核验后录入）。

---

## 2. 数据来源纪律

| 数据类型 | 允许来源 | 禁止 |
|---|---|---|
| 供应商报价 | 用户上传 PI / 报价邮件 | 用网络传闻价冒充报价 |
| 关税税率 | 官方税则（财政部/海关）或经核验的税则库 + 核验日期 | 凭印象写税率，或把某产品税率当默认 |
| 汇率 | 银行牌价 / 公开牌价 / ECB 交叉；海关计征汇率按中间价规则 | 用一个汇率同时算购汇与计税 |
| 运费/港杂/国内运输 | 用户货代报价 / 官方口岸收费公示（并注明"公示口径≠报价"） | 用"行业平均"当实际报价 |
| 保险 | 保单/用户输入；海关口径 3‰ 是**计税规则**不是市场价 | 把 3‰ 说成"保险费率" |

每项数据须打标签：`用户输入 | 公开查询 | 计算推导 | 模拟情景 | 待确认`。

---

## 3. 硬性校验（脚本可自动执行，见 `assets/validate_costs.py`）

1. **不重复计费**：FOB/CFR/CIF 报价按 Incoterms 矩阵；`CFR` 报价不得再加海运，`CIF` 报价不得再加保险，`FOB` 报价不得再加起运港费用。
2. **不漏项**：`in_landed_cost=true` 的费用字段全部有值（0 也算有值，但必须显式填写；未填 = 待确认）。
3. **不默认零**：缺失的阻断项把 `full_landed_cost_status` 置为 `待补全`，并输出 `gaps` 清单。
4. **口径一致**：`customs_value` 只含 EXW 货值 + 应计入项目；不得包含港杂/报关/国内运输；不得包含关税与增值税。
5. **增值税拆两栏**：输出必须同时有 `import_vat_cash`（现金支出）与 `import_vat_input_credit`（可抵扣进项）；抵扣情形下 `final_economic_cost` **不得**包含可抵扣部分。
6. **双汇率**：`fx_market` 与 `fx_customs` 分别单列，并输出差异影响。
7. **单位一致**：散货按吨；若报价为 USD/MT 而数量为 柜（FCL），必须换算成 MT 再计算（禁止用柜数直接乘单价）。
8. **交叉校验**：港口→工厂的国内运输里程与元/吨，若显著偏离公开区间，提示"请核对单位"而不是静默接受。
9. **敏感性可复现**：任何敏感性结论须能由基准情景按公式重算复现（`validate_costs.py` 会重算比对）。

---

## 4. 输出免责与标注

- 结果页必须含：`本测算基于 <日期> 核验的税率与汇率；模拟项已标注；缺失项未按 0 处理；最终金额以海关核定与实际合同为准。`
- 不得出现"实时市场报价""实际成本"等误导性措辞，除非数据确实来自实时公开报价。

---

## 5. 失败模式清单（先自查再给结论）

| 症状 | 根因 | 修正 |
|---|---|---|
| 到厂成本比国内采购还低很多 | 漏算关税/增值税/港杂，或误把可抵扣增值税从货值里扣了 | 用 `validate_costs.py` 对账 |
| 同一票里 THC 算两次 | 海运报价 CY-CY 已含 + 港杂又算一次 | 标注运费是否含目的港费用 |
| 优惠关税 0% | 未经 4 道闸门核验就填 0 | 回退至 MFN，并标"优惠资格待核验" |
| 汇率用同一个数 | 混淆市场汇率与海关计征汇率 | 拆成 `fx_market` / `fx_customs` |
| 元/吨与整票不一致 | 数量单位混用（柜 vs 吨） | 统一按数量口径重算 |
