# 完整案例：沙特 MEG → 宁波 → 苏州

> 演示情景。单价、海运费、保险费率、港杂、仓储均为**模拟数值**，不是实时市场报价。
> 每个数都能在 `examples/02_case_saudi_meg_ningbo.json` 里改。

## 一、交易背景

| 项目 | 内容 |
|---|---|
| 产品 | 工业级乙二醇 MEG，≥99.9% |
| HS 编码 | 29053100 |
| 原产国 | 沙特阿拉伯（SA） |
| 装运港 → 目的港 | 朱拜勒 Al Jubail → 宁波 |
| 最终目的地 | 江苏苏州工厂（约 250 km） |
| 数量 | 62.5 吨 = 25 个 40' ISO 罐 × 2.5 吨？→ 实际按 25 柜 × 2.5 吨折算，演示取 62.5 吨 |
| 三种报价 | FOB 640.00 / CFR 685.00 / CIF 685.05 USD/MT |

> 三口径的经济实质相同：FOB 640 + 海运 45 + 保险 ≈ 0.05 = CIF 685.05。
> 所以三者的到厂成本应当几乎一样 —— 这正是用来验证"没重复计费"的方法。

## 二、先确认哪些钱已经在报价里

| 费用 | FOB | CFR | CIF |
|---|---|---|---|
| 货值 | 已含 | 已含 | 已含 |
| 包装 | 已含（单价含包装） | 已含 | 已含 |
| 起运港/出口侧 | 已含 | 已含 | 已含 |
| **海运费** | **要加** | 已含 | 已含 |
| **保险费** | **要加** | **要加** | 已含 |

口诀：FOB 加两样，CFR 加一样，CIF 一样都不加。

## 三、FOB 口径逐行手算（可对着 Excel 的 FOB 页核）

### 第一层：货值 → 到岸

| 项 | 原币 USD | 说明 |
|---|---|---|
| 货值 | 640.00 × 62.5 = **40,000.00** | 单价 × 数量 |
| 包装费 | 0 | 单价已含包装（《关税法》第25条要求包装费计入计税价格，此处已内含） |
| 起运港/出口侧 | 0 | FOB 已含装运港作业 |
| 海运费 | 45.00 × 62.5 = **2,812.50** | 朱拜勒→宁波（模拟） |
| 保险费 | (40,000+2,812.50) × 0.55% × 1.10 = **259.02** | 按 110% 投保额（模拟费率） |
| **到岸成本（CIF 等值）** | **43,071.52** | |

### 第二层：税费（海关口径）

| 步 | 计算 | 结果 |
|---|---|---|
| 海关计征汇率 | 演示占位值 | **6.7200**（须替换为申报日对应上月第三个星期三中间价） |
| 完税价格 | 43,071.52 × 6.7200 | **289,440.58 元** |
| 最惠国关税 | 289,440.58 × 5.5% | **15,919.23 元** |
| 反倾销税 | × 0% | 0 |
| 增值税基数 | 289,440.58 + 15,919.23 | **305,359.82 元** |
| 进口环节增值税 | 305,359.82 × 13% | **39,696.78 元** |
| 其中可抵扣 | 一般纳税人 · 应税用途 | **39,696.78 元**（全额抵扣） |
| 其中不可抵扣 | | 0 |

### 第三层：境内费用（人民币，不进计税价格）

| 项 | 金额 | 来源 |
|---|---|---|
| 港杂费（THC、港建、换单等） | 600 | 模拟情景 |
| 报关代理费 | 500 | 宁波港公示区间 100–500 元/票 |
| 检验检测费 | 0 | 无 |
| 仓储费（免箱期内） | 3,000 | 模拟情景 |
| 国内运输 宁波→苏州 | 0.5 元/吨·km × 250 km × 62.5 t = **7,812.50** | 公开费率 × 假设距离 |
| 资金/信用证成本 | 0 | 本案例不计 |
| **合计** | **11,912.50** | |

### 汇总：两种"总成本"

| 口径 | 计算 | 整票 | 每吨 |
|---|---|---|---|
| 到岸成本 | 43,071.52 × 6.6807 | 287,747.87 | 4,603.97 |
| **整票现金支出** | 287,747.87 + 15,919.23 + 39,696.78 + 11,912.50 | **355,276.38** | **5,684.42** |
| 减：可抵扣增值税 | −39,696.78 | | |
| **最终经济成本** | 355,276.38 − 39,696.78 | **315,579.61** | **5,049.27** |

> 报价 640 USD/MT × 6.6807 = **4,275.65 元/吨**。
> 到厂 **5,049.27 元/吨**，比报价高 **773.63 元/吨（+18.09%）**。
> 拆开看这 773.63 元：关税 254.71 + 运保费 328.32 + 境内费用 190.60 = 773.63。

## 四、为什么必须分开看"现金"和"成本"

- **看现金流**（要准备多少钱）：355,276.38 元整票，其中 39,696.78 元是垫付的增值税。
- **看真实成本**（这批货到底花了多少）：315,579.61 元 ≈ 5,049.27 元/吨。
- 如果错误地把可抵扣增值税算进成本，每吨会虚高 **635.15 元**，可能直接导致误判"进口不划算"。
- 反过来，若企业不能抵扣（小规模纳税人 / 用于免税项目），**5,684.42 元/吨**才是真实成本
  （= 现金支出每吨，此时可抵扣为 0，两者相等）。

同一个案例，`vat_deductible` 一个开关，答案差 635 元/吨 —— 这是进口测算里最容易被忽略的分叉。

## 五、三口径对照（验证没有重复计费）

| 指标 | FOB | CFR | CIF |
|---|---|---|---|
| 报价 USD/MT | 640.00 | 685.00 | 685.05 |
| 到岸成本 元/吨 | 4,603.97 | 4,603.97 | 4,576.61 |
| 应纳关税 元 | 15,919.23 | 15,919.23 | 15,824.66 |
| 增值税现金 元 | 39,696.78 | 39,696.78 | 39,460.94 |
| 整票现金支出 元 | 355,276.38 | 355,276.38 | 353,236.44 |
| **最终经济成本 元/吨** | **5,049.27** | **5,049.27** | **5,020.41** |

结论：
1. **FOB 与 CFR 完全一致（5,049.27）** → 说明"FOB 加运费"与"CFR 报价已含运费"没有重复算运费。
   这是最重要的一条自检：**同一批货两口径到厂成本必须相等**，不相等就是重复计费或漏计。
2. **CIF 低 28.86 元/吨**，来源是卖方 CIF 报价里的保险加价（685.05 − 685.00 = 0.05 USD/MT
   ≈ 0.33 元/吨）低于我方按 0.55%×110% 实际投保的成本（259.02 USD 整票 ≈ 4.14 USD/MT）。
   差额说明卖方在保险上基本没加价，**这块没有议价空间**；真正的议价点在运费和单价。
3. 三个口径到厂成本都落在 5,020–5,050 元/吨区间 → 报价结构本身没有隐藏收费。

## 六、敏感性（基准 FOB，5,049.27 元/吨）

| 情景 | 到厂 元/吨 | Δ 元/吨 | Δ% |
|---|---|---|---|
| 市场汇率 −3% | 4,911.15 | −138.12 | −2.74% |
| 市场汇率 +3% | 5,187.39 | +138.12 | +2.74% |
| 海关计征汇率 ±3% | | ±7.64 | ±0.15% |
| 海运费 −20% | 4,985.44 | −63.84 | −1.26% |
| 海运费 +20% | 5,113.11 | +63.84 | +1.26% |
| 数量 ×0.5（31 吨） | 5,239.87 | +190.60 | +3.78% |
| 数量 ×2（125 吨） | 4,953.97 | −95.30 | −1.89% |

关键读数：
- **市场汇率弹性 ≈ 23.02 元/吨 per 1%**。注意这**小于** 1% 的比例（50.49 元/吨）——
  因为增值税会随汇率同步上升、又同比例被抵扣掉，真正留下来的是被关税率放大的那部分。
  若增值税不可抵扣，弹性会明显大于 1。**这是"可抵扣"最反直觉的推论**：
  可抵扣增值税像一个缓冲垫，把汇率波动的净影响削掉一半以上。
- **海关计征汇率只影响 ±7.64 元/吨（±0.15%）**，因为汇率变动被 5.5% 的关税率放大后
  又经增值税抵扣抵消。所以真正的汇率风险在**购汇现金**，不在税额。
- **运费传导系数 1.055** = 1 + 5.5% 关税率。运费每涨 1 USD/MT，到厂约涨 7.05 元/吨。
- **数量翻倍只降 95.30 元/吨**，因为港杂/报关/仓储/运输是按票固定费用，
  在 5,000 元/吨的成本里总共只占 190.60 元/吨。想降本要靠价格和运费，加量收效有限。
- **影响力度排序**（龙卷风）：数量 ±50%（285.90）> 市场汇率 ±3%（276.24）
  > 海运费 ±10%（127.67）> 海关计征汇率 ±3%（15.28）。
  但注意数量那一条是 ±50% 对 ±3%，单位不同，不能直接比"敏感度"，只能比"金额风险敞口"。

## 七、这份测算还需要补什么

| 待补项 | 为什么重要 | 找谁要 |
|---|---|---|
| 海关计征汇率（申报日 → 上月第三个星期三中间价） | 直接决定税额 | 中国货币网 / 海关 |
| 真实海运报价 | 占成本 4–5%，且波动大 | 货代（要注明含/不含 THC） |
| 实际保险费率 | 影响计税价格 | 保险公司 / 货代 |
| 宁波港口岸实际收费 | THC 是否已含在运费里是关键陷阱 | 货代报价单（逐项列明） |
| 反倾销核验结论 | 可能成倍加税 | 商务部贸易救济局公告 |
| 协定税率资格（沙特） | 中—海合会 FTA 未生效 → 目前不适用 | 海关原产地业务 |

任一未补齐，`完整到厂成本` 就应显示「待补全」，只能用「已知成本小计」做下限参考。
