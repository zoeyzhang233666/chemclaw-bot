# 示例 03：欧元计价 + 欧盟原产地（协定税率场景）

适用：报价用 EUR、原产地是欧盟成员国，需要考虑协定税率与币种换算的叠加效应。
本示例**不绑定具体产品**——把 HS 编码与税率换成你实际核到的那一组即可。

---

## 一、这个场景与 MEG 案例的三个不同点

| 维度 | 沙特 MEG 案例 | 欧盟 EUR 案例（本例） |
|---|---|---|
| 币种 | USD | EUR（**没有交叉盘就直接取 EUR/CNY**） |
| 协定税率 | 不适用（中—海合会 FTA 未生效） | **可能适用**（欧盟各国与中国无 FTA，但部分成员国有单独安排；必须逐一核验） |
| 原产地证据 | 主要看反倾销 | 必须能出具原产地证书，且需满足原产地规则 |

> 重点：**"原产于欧盟"不等于"享受协定税率"。** 中国目前与欧盟整体**没有**生效的自由贸易协定，
> 中欧之间适用的是**最惠国税率**。仅有个别国家（如瑞士、冰岛、挪威、塞尔维亚等欧洲国家）
> 与中国有生效的自贸协定。所以"欧洲来的货"要逐个查国家，不能一刀切。
>
> 这个坑非常常见：业务员看到"欧洲进口"就默认有关税优惠，结果核到 MFN。

---

## 二、币种处理（EUR 的三条注意）

1. **取 EUR/CNY 直接汇率**，不要用 EUR/USD × USD/CNY 手算（会引入两次舍入误差）。
   `scripts/fetch_fx.py --base EUR --to CNY`。
2. **海关计征汇率同样取 EUR/CNY**，口径与 USD 相同：申报日所属月份上一个月第三个星期三的中间价。
3. **欧元报价常含 VAT/含运费的混淆**：欧洲供应商习惯报 EXW 或 FCA 工厂价，
   报价里通常**不含**出口报关后的国际段。要特别确认术语，别把 EXW 当 FOB 用。

## 三、算例（演示数值，非实时报价）

假设：某化工品，HS 编码按实际核到的填；欧盟某成员国原产；数量 20 吨。

| 输入 | 取值 | 来源 |
|---|---|---|
| 术语 | EXW 鹿特丹 Incoterms 2020 | 用户输入 |
| 单价 | 1,250.00 EUR/吨 | 模拟情景 |
| 数量 | 20 吨 | 用户输入 |
| 市场参考汇率 EUR/CNY | 7.8500 | 需现查（演示占位） |
| 海关计征汇率 EUR/CNY | 7.8200 | 需现查（演示占位） |
| 出口侧 + 起运港费用 | 450.00 EUR | 模拟情景 |
| 海运费 | 95.00 EUR/吨 | 模拟情景 |
| 保险费率 | 0.60% | 模拟情景 |
| 最惠国关税税率 | 6.5% | **必须按 HS 重新核验** |
| 协定税率 | 不适用（中欧无 FTA） | 核验结论 |
| 进口增值税 | 13% | 一般货物 |
| 港杂 / 报关 / 仓储 | 800 / 500 / 2,600 元 | 模拟情景 |
| 内陆运输（上海港→苏州） | 0.5 元/吨·km × 110 km × 20 t = 1,100 元 | 公开费率 × 假设距离 |

### 计算过程

```
货值            = 1,250.00 × 20              = 25,000.00 EUR
出口侧+起运港    = EXW → 必须加               =    450.00 EUR
海运费          = 95.00 × 20                 =  1,900.00 EUR
保险费          = (25,000+450+1,900) × 0.60% × 110%
                = 27,350 × 0.0066            =    180.51 EUR
到岸成本(EXW→CIF等值) = 25,000+450+1,900+180.51 = 27,530.51 EUR
完税价格(CNY)   = 27,530.51 × 7.8200         = 215,288.59 CNY
应纳关税        = 215,288.59 × 6.5%          =  13,993.76 CNY
增值税基数      = 215,288.59 + 13,993.76     = 229,282.35 CNY
进口增值税      = 229,282.35 × 13%           =  29,806.71 CNY
境内费用        = 800+500+2,600+1,100        =   5,000.00 CNY
现金支出        = 到岸(CNY) + 关税 + 增值税 + 境内
到岸(CNY)       = 27,530.51 × 7.8500         = 216,114.50 CNY
                = 216,114.50 + 13,993.76 + 29,806.71 + 5,000
                = 264,914.97 CNY
最终经济成本    = 264,914.97 − 29,806.71     = 235,108.26 CNY
每吨            = 235,108.26 / 20            =  11,755.41 元/吨
```

### 关键结论

- **EXW 报价的"隐形"成本很大**：出口侧 450 + 海运 1,900 = 2,350 EUR，占总货值 9.4%。
  若误把 EXW 当 FOB，这 2,350 EUR 就整块漏算。
- **币种波动叠加**：EUR/CNY 从 7.85 跌 3% 到 7.61，到厂成本约降 3%×（可折算部分占比）。
- **税率假设的破坏力**：如果这个 HS 其实有 3% 的暂定税率而误按 6.5% 算，
  关税多算 7,535 元 ≈ 377 元/吨。**税率错一档，结论就翻。**

## 四、协定税率的四道闸门（欧洲场景特别容易踩第 1 道）

```
闸门 1：该国有生效的自贸协定吗？
        欧盟整体 → 没有。瑞士/挪威/冰岛/塞尔维亚等 → 有。逐一查。
闸门 2：这个 HS 在降税清单里吗？（不是所有商品都降）
闸门 3：满足原产地规则吗？（完全获得 / 实质性改变 / 区域价值成分）
闸门 4：能出具有效原产地证书吗？（FORM E/原产地证等，且与发货人一致）
```

四道全过才能用协定税率。**任何一道不确定，就按 MFN 算，并在输出里注明"若能取得协定资格可降 X 元/吨"。**

## 五、用本技能跑这个场景

```bash
# 1) 拿 EUR/CNY 双汇率
python scripts/fetch_fx.py --base EUR --to CNY --date 2026-10-20 --out fx_eur.json

# 2) 复制案例 JSON 改成 EUR 场景
#    examples/02_case_saudi_meg_ningbo.json → 改 currency, unit_price, incoterm=EXW,
#    tariff_* , origin_country, 各费用项

# 3) 计算 + 敏感性
python scripts/landed_cost_engine.py --input my_eur_case.json --pretty --sensitivity
```

在 HTML 计算器里操作：
1. 术语切到 EXW（会自动把起运港/出口侧费用变成"要填"）。
2. 填 EUR 单价、EUR/CNY 的两个汇率。
3. 关税税率填核验后的值；若不确定，先填 MFN，并在备注写"待核验协定资格"。
4. 看状态徽标——只要有一项没填，就仍是「待补全」。

## 六、本示例中不能提供的东西

- 具体 HS 编码与税率：**必须按你的实际产品自行核验**，本示例不预设。
- 鹿特丹/上海港的真实费用：需向货代索取逐项报价。
- EUR/CNY 的真实汇率：需现查，本示例的 7.85/7.82 是演示占位值。
