# 示例 01：FOB ↔ CFR 换算，以及"不许重复计费"的自检

适用：供应商给了 FOB 价，但你想和另一家 CFR 价比；或有人把 CIF 价又加了一遍运费。

---

## 一、换算公式（只在同一批货内成立）

```
CFR 价 = FOB 价 + 海运费(USD/MT)
CIF 价 = CFR 价 + 保险费(USD/MT)
保险费 ≈ CIF 价 × 费率 × 110%      ← 注意基数是 CIF 而不是 FOB
```

最后一条是常见错误点：保险费应以**含运费的 CIF 价**为基数。若只有 FOB 价，
要把保险倒推进去（自反解）：

```
设 F = FOB, T = 运费/吨, r = 费率 × 110%
CIF = (F + T) / (1 − r)
保费 = CIF × r
```

**数值验证**（费率 0.55% × 110% = 0.605%，r = 0.00605）：

| 项 | 计算 | 结果 |
|---|---|---|
| FOB | — | 640.0000 USD/MT |
| 运费 T | — | 45.0000 |
| F+T | | 685.0000 |
| CIF = (F+T)/(1−0.00605) | 685 / 0.99395 | 689.1695 |
| 保费 = CIF × 0.00605 | | 4.1695 |
| 校验：F+T+保费 | 685 + 4.1695 | 689.1695 ✓ |

> 因此"CFR 685 + 保险"应当报成 **CIF 689.17**，而不是 685.05。
> 案例里卖方报 685.05，说明他的保险只加了 0.05 USD/MT ≈ 0.33 元/吨，
> 远低于按 0.55%×110% 自保的实际成本（约 4.14 USD/MT）。**这是卖方的让利，不是我们算错。**

---

## 二、自检等式（每次算完都要过一遍）

### 检查 1：三口径到厂成本应当相等

```
到厂成本(FOB 640 + 运费 45 + 保险自算)  ==  到厂成本(CFR 685 + 保险自算)
```

案例实测：均为 **5,049.27 元/吨**（差 0.00）。相等 → 没重复计费。

CIF 口径有 28.86 元/吨的差，且**只可能**来自"卖方报价里的保险加价 ≠ 我方自算保费"。
若 CIF 差得很多（比如几百元/吨），就要怀疑：卖方 CIF 里是否已经含了目的港 THC？

### 检查 2：到岸成本必须等于六项之和

```
到岸成本 == 货值 + 包装 + 起运港 + 出口侧 + 海运 + 保险
```

任何一项重复或漏计，这个等式会立刻失衡。

### 检查 3：关税基数必须等于到岸成本 × 海关计征汇率

```
完税价格 == 到岸成本(原币) × 海关计征汇率
```

若你把市场汇率塞进了完税价格计算，或忘了把运费并入完税价格，这里会露馅。

### 检查 4：增值税基数

```
增值税基数 == 完税价格 + 关税 + 反倾销税
```

关税必须进增值税基数——这是最容易漏的一步。

## 三、错误示范 vs 正确示范

| 场景 | 错误做法 | 后果 | 正确做法 |
|---|---|---|---|
| 供应商报 CFR，你又加了运费 | 到岸成本 = CFR 价 + 45×量 | 虚增 18,789 元（约 300 元/吨） | CFR 运费项置 0 |
| 供应商报 CIF，你又加运费+保险 | 到岸成本多加两项 | 虚增约 320 元/吨 | CIF 两项均置 0 |
| 用市场汇率算关税 | 6.6807 而非 6.7200 | 关税少算 93.10 元 | 分开记两个汇率 |
| 忘了运费进完税价格 | 只用货值×汇率 | 关税少算 1,039.50 元 | 运保费必须并入 |
| 空着港杂费等默认 0 | SUM 吞空值 | 到厂成本偏乐观 | 用 COUNT/ISNUMBER 判定完整性 |
| 把可抵扣增值税算进成本 | 现金口径当成本口径 | 虚高 635 元/吨 | 拆现金 vs 经济两栏 |

## 四、一张 PI 到手后的标准动作

1. 抄下：术语、指定地点、单价、币种、计价单位、数量、包装是否含、有效期。
2. 判断术语是否明确写出地点与版本（`CIF 宁波 Incoterms 2020`）。没有 → 先问。
3. 用 `references/yaml/incoterms_2020_matrix.yaml` 机械判定要补哪些费用。
4. 缺的运费/保险/口岸费，逐项列成"待补清单"，**不填默认值**。
5. 填进 `assets/import_landed_cost_calculator.html`，看 KPI 与状态徽标。
6. 状态为「待补全」→ 只能报「已知成本小计」，并说明缺哪几项。
7. 补齐后状态变「完整」→ 才能对外说"到厂价 X 元/吨"。
