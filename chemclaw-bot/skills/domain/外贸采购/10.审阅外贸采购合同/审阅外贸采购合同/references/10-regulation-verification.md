# 10 法规与标准核对的纪律（第 11 项展开的方法要求）

> 这份文件是写报告时的**红线清单**。合同中涉及法规/标准的内容，最容易出现「看起来专业但其实是编的」。
> 原则：**能查证的才写，查不到的写「未核对」，绝不猜测。**

---

## 1. 什么必须核对、核对到什么程度

| 类型 | 必须核对 | 可接受的表述 |
|---|---|---|
| 中国法律/行政法规 | 全称、通过日期、施行日期、现行状态 | 「《XX法》（2025年12月27日通过，2026年5月1日施行）」+ 核对日期 |
| 国家标准（GB/GB/T） | 标准号、年份、名称、现行/废止 | 「GB/T 4649—2018《工业用乙二醇》，现行，核对日期 2026-XX-XX」 |
| 部门规章/公告/目录 | 发布机关、公告号、发布日期 | 「商务部、海关总署 20XX 年第 XX 号公告」 |
| 国际规则（Incoterms/UCP/CISG） | 版本、条款号 | 「UCP 600 第 14 条(b)」 |
| 行业惯例 | 不作为法律依据引用 | 「行业常见做法」并说明来源 |
| ASTM/ISO 等技术标准 | 编号 + **版本年份**；未核对年份必须标注 | 「ASTM E202（未逐条核对现行版本年份）」 |

---

## 2. 检索与核验流程（四步）

```
① 确定要核什么          —— 只核合同里实际出现或直接影响结论的法规/标准
② 找到权威来源          —— 政府/官方机构/标准发布机构/公约保存机构
③ 核对三要素            —— 名称全称 + 现行状态 + 生效/施行时间（以及是否被修订）
④ 记录到 legal_refs     —— 名称 / 适用点 / 状态 / 核验依据 / 关联 / 链接 / 核对日期
```

**权威来源示例**

| 对象 | 优先来源 |
|---|---|
| 中国法律 | 全国人大网（npc.gov.cn）、国家法律法规数据库 |
| 国家标准 | 国家标准全文公开系统、全国标准信息公共服务平台 |
| 部门公告/目录 | 商务部、海关总署、应急管理部官网 |
| Incoterms / UCP | ICC 官网（iccwbo.org） |
| CISG 缔约方与保留 | UNCITRAL 官网（uncitral.un.org） |
| 化学品信息 | PubChem、ECHA、供应商 SDS |
| 仲裁规则 | 各仲裁机构官网（SIAC / HKIAC / CIETAC） |

> 检索失败时（官网打不开、PDF 403）：换镜像站或改用权威二次来源，并在 `status_basis` 中写明「经 XX 站点核对」，**不要因为打不开就直接写结论**。

## 3. 六条禁写（出现即返工）

| ❌ 不要写 | 为什么 | ✅ 改写为 |
|---|---|---|
| 「根据《XX法》第 X 条，本合同条款无效」 | 法律判断，超出范围 | 「该条款与……的关系需由法务判断」 |
| 「中国禁止进口该产品」 | 定性结论，需权威依据 | 「是否需进口许可，需报关行按现行目录核对」 |
| 「该产品属于危险化学品」 | 三套体系易混 | 「需由 EHS 依据现行目录与 SDS 书面确认」 |
| 「按 GB/T XXXX 规定，纯度应为 99.9%」 | 可能记错标准内容 | 「可要求以 GB/T XXXX 作为第二基准，具体指标以标准原文为准」 |
| 「SCC A 规则自 2023 年起适用于所有沙特交易」 | 过度概括 | 「SCCA 规则现行版本为 2023-05-01 生效，是否适用取决于当事人约定」 |
| 「对方违反了 CISG 第 35 条」 | 需先确认公约适用 | 「若 CISG 适用，货物相符性义务见第 35 条，适用性需法务确认」 |

## 4. 版本与时间：最容易过期的部分

法规与标准会修订、会被新公告调整。写报告时必须：

1. **记录核对日期**（`review_meta.law_check_date`），并在报告页脚与 Excel 04 表显示。
2. 对**逐年调整**的对象（关税税则、自动进口许可目录、危化品目录增补）明确写「逐年/持续调整」。
3. 对**新近生效**的法律，写清施行日期，并提示「以施行时有效版本为准」。
4. 对**未核对的版本**（如 ASTM 年份）显式标注「未逐条核对」，不要留空让人以为核过了。

## 5. `legal_refs` 的写法规范

每个条目必须能回答「凭什么这么写」：

```jsonc
{
  "name": "《中华人民共和国危险化学品安全法》（2025年12月27日通过，2026年5月1日施行）",
  "scope": "危险化学品的目录管理、安全标签与进口相关义务",
  "status": "现行",
  "status_basis": "全国人大网公布，2026-05-01 施行；核对日期 2026-10-20",
  "relevance": "对应第 7.2 条中文标签义务分配",
  "url": "https://…"
}
```

**status 取值建议**：`现行` / `现行（持续调整）` / `需核对（未逐条核对…）` / `对本案适用需个案判断`。

**校验规则**（脚本已实现）：`findings[].law_refs` 中的每一项必须能在 `legal_refs[].name` 中找到，否则报「未登记」——防止报告里出现没登记来源的法规。

---

## 6. 什么时候必须承认「不知道」

以下情形**一律**写「未核对/需确认」，不要补全：

- 记不清标准年份、条款号、公告号
- 不确定某国是否为某公约缔约方、有无保留
- 不确定某产品是否列入某目录
- 不确定某仲裁规则的最新版本
- 官网打不开且没有可靠二次来源

> 一份写着「此处需由法务核对」的报告，比一份自信但错了一处法条的报告有价值得多——因为前者会被复核，后者会被直接引用。
