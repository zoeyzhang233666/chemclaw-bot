# 06 违约、责任限制与不可抗力（第 9 项展开）

> 这段决定「出事以后能拿回多少钱」。三个数字 + 一个清单：
> **违约金率 / 违约金上限 / 责任总上限 / 免责清单。**

---

## 1. 责任总上限：最狠的一条

本案第 11.2 条：

> `The Seller's aggregate liability under this Contract shall in no event exceed the amount of the advance payment actually received by the Seller, and shall exclude all indirect and consequential losses.`

换算：责任上限 = 已收预付款 = **USD 768,000**（合同额的 30%）。

三条叠加效应：

1. **上限随付款进度变化**：付款越多上限越高，但在**最需要保护的时点（已付全款、货出问题）**，上限恰好被「已收预付款」这个措辞锁在 30%。
2. **排除间接损失**：停产损失、断料损失、对下游客户的违约赔偿通常被归为「间接损失」——而这恰恰是进口原料断供的主要损失形态。
3. **没有例外清单**：欺诈、故意、伪造单据、人身伤害通常必须排除在上限之外；本案一个都没有。

**审查动作**：

```python
上限金额 = 合同金额 × 上限比例      # 例：2,560,000 × 30% = 768,000
上限覆盖货值 = 上限金额 / 合同金额    # 30%
```

如果「上限覆盖货值」< 100%，就直接写进报告：**「最坏情况下，卖方对全部损失的赔偿不超过货值的 X%」**。

**要争取的例外**（几乎所有司法辖区都倾向于不保护下列情形，但**不要在报告里下法律结论**，只写「建议要求排除」）：

- 欺诈、故意不当行为、重大过失
- 伪造/虚假单据（COA、SDS、原产地证）
- 违反出口管制、制裁、反商业贿赂承诺
- 人身伤亡与财产损害
- 保密义务违反
- 预付款的退还义务（这一条尤其重要：不退还预付款不应受上限限制）

## 2. 违约金（Liquidated Damages）

| 要素 | 本案 | 审查要点 |
|---|---|---|
| 日费率 | 0.05%/天 | 是否足以覆盖断料成本；行业常见 0.1%/天 |
| 上限 | 5% | 触顶天数 = 上限/日费率 = 100 天 |
| 触发条件 | 迟延交货 | 是否也覆盖「未交货」「部分交货」 |
| 与解约权的关系 | **无解约权**（R19） | 触顶后买方无退出机制 |
| 与损害赔偿的关系 | 未写 | 可能被解释为「唯一救济」 |

**计算模板**：

```
日违约金 = 合同金额 × 日费率            = 2,560,000 × 0.05% = 1,280 USD/天
触顶天数 = 上限比例 ÷ 日费率            = 5% ÷ 0.05% = 100 天
触顶金额 = 合同金额 × 上限比例          = 128,000 USD
```

## 3. 其他违约情形：别只盯迟延

| 违约类型 | 本案是否约定 | 后果 |
|---|---|---|
| 迟延交货 | 有（0.05%/天，上限 5%） | 见上 |
| **不交货** | 无专门条款 | 只能按一般违约处理 |
| **质量不符** | 只有换货（第 9.2 条） | 无降价、无退货、无解约 |
| **数量短少** | 无 | 见 `04` §4 |
| **单据不符/单据延误** | 无 | 影响付款与清关 |
| **违反合规承诺**（制裁/出口管制） | 无 | 无对应救济 |
| **保密违反** | 单向且无违约后果 | 见 §4 |

## 4. 单向义务：容易被忽略的不平衡

本案第 11.3 条：买方对「合同内容与交易信息」承担**永久**保密义务，而卖方无对应义务，且无「法定披露例外」（监管、审计、银行、律师、诉讼）。

后果：

- 我方在**仲裁或诉讼中**披露合同内容，理论上构成违约——这等于给维权设置障碍。
- 银行、审计、母公司尽调需要提供合同时，也落入风险。

**要争取**：

1. 期限（如终止后 3 年）。
2. 法定披露例外清单。
3. 双向对称。

## 5. 不可抗力：清单比标题重要

本案第 12.1 条把下列事项列入不可抗力：

> `… changes in market conditions or prices, equipment breakdown, shortage of raw materials …`

这是**商业风险包装成不可抗力**。市场行情变化、设备故障、原料短缺都是卖方的经营风险，把它们列入不可抗力的效果是：**行情上涨时卖方可以合法不发货且不担责**。

**审查动作**：逐项读定义清单，凡是「商业性/可归责于卖方」的事项，一律列为「表述不清」或「对我方不利」。

**要争取**：

| 要素 | 建议 |
|---|---|
| 定义 | 限于不可预见、不可避免、不可克服的事件（自然灾害、战争、政府行为、疫情管制等） |
| 通知 | 事件发生后 7 日内书面通知，附证明（商会证明、政府公告） |
| 减损义务 | 受影响方应采取合理措施减少损失 |
| 持续期 | 超过 60 天，买方有权解除并要求退还预付款 |
| 已付款处理 | 明确不可抗力下的退款义务与利息 |

## 6. 完整协议与既往文件（Entire Agreement）

本案第 14.2 条：

> `This Contract constitutes the entire agreement … and supersedes all prior … communications, including the proforma invoice dated 2 October 2026.`

**问题**：合同第 2.1 条引用的「卖方标准规格」只出现在**邮件**里，而完整协议条款把这些邮件全部排除。结果是：**合同引用了一份不在合同内的文件，且该文件的效力已被排除。**

这是「技术附件没有并入合同」的经典事故（R27）。审查时要专门检查：

1. 合同里所有「refer to / as per / in accordance with」指向的外部文件，是否都作为附件并入？
2. 完整协议条款是否把这些附件排除？（常见写法是 `together with its Annexes`，必须确认附件被包含）
3. 形式发票（PI）中的价格、付款条件是否与合同一致？若不一致，以谁为准？
