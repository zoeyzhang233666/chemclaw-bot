# 示例：中国买方进口沙特 MEG（CIF 宁波）

**本目录是一份完整可运行的模拟案例**，用于演示与测试本 Skill 的完整链路：
合同 → 条款索引 → 12 项审查 → 四件套交付物。

> ⚠ **模拟声明**：本合同为**模拟合同（Simulated Contract）**。双方名称、地址、金额、条款均为演示编写，
> 不对应任何真实交易或主体，不得用于真实签约或对外引用。合同中的 CAS 号错误、预付款无担保、
> 异议期过短等，都是**刻意植入**的审查点，用于考察审查能力。

## 刻意植入的 30 个审查点

按审查主线分四类（完整清单见 `review.json`）：

### A. 预付款保护不足（R01、R20）
- 30% 预付款**无任何担保**，且明确 `non-refundable`
- 卖方责任总上限 = **已收预付款**，并排除间接损失 → 最坏情况只能拿回 30% 货值

### B. 质量异议期限过短（R09、R10、R06、R08）
- 异议期**到港后 7 天**，短于「卸货 + 取样 + 检测」实际耗时
- 质量以**卖方实验室 COA 终局**，第三方机构也由卖方指定 → 程序上封死
- 质量基准是「卖方标准规格」，且卖方**可随时修订**
- **CAS 号写成 7732-18-5（水的 CAS）**，正确为 107-21-1

### C. 付款单据约定不明确（R02、R03、R04、R05）
- 尾款存在**三条互相冲突的触发条件**（信用证 / 到货验收后付款）
- 开证行写成「卖方银行」，方向颠倒
- 单据清单有开放兜底项 `(g) such other documents as the Seller may reasonably require`

### D. 争议解决条款存在歧义（R23、R24、R26）
- 仲裁条款内部矛盾：SIAC 规则「in Singapore」+ 仲裁地 DIFC
- 卖方单方保留「在任意有管辖权法院起诉」的权利
- 「中英同等有效」+「英文优先」+「仲裁协议以中文为准」三重矛盾

### 其余（R07、R11–R19、R21、R22、R25、R27–R30）
规格表缺方法版本与空白限值、数量短量无允差、救济只有换货、风险绑在「收到提单」、
保险被保险人是卖方、装运期无最迟装船日、违约金 0.05%/天上限 5% 且无解约权、
不可抗力含商业事由、单向永久保密、完整协议排除被引用的规格书、SDS/中文标签义务错配、
实际生产商未披露。

## 这个案例教了什么

| 教训 | 对应风险 |
|---|---|
| 预付款比例谈不下来时，要谈**担保** | R01 |
| 信用证只保单据，不保货物质量 | R02、R03 |
| 三种互相冲突的付款路径 ≠ 双保险 | R03 |
| 异议期要看**起算点与检测周期**，不只看天数 | R09 |
| 责任上限要换算成「能拿回几成」 | R20 |
| **风险转移 ≠ 所有权转移** ≠ 保险责任期间 | R14、R15、R16 |
| 仲裁地、仲裁规则、准据法是三个概念 | R23 |
| 合同引用的外部文件必须并入附件，否则被完整协议条款排除 | R27 |
| CAS/HS 这类硬标识错误必须书面更正 | R08 |
| 危险化学品的定性交 EHS，不交审查报告 | R28、R29 |
