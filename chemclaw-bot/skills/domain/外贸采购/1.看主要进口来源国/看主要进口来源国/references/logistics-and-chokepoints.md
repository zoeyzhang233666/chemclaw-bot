# 物流与咽喉点核实方法

## 为什么物流必须单独核实

一张"港口 → 航程 → 中国"的表看起来最像常识，也**最容易在几个月内变成废纸**。

2026 年的实例：霍尔木兹海峡自 2026-02-28 起被封锁，中东 9 个装货港全部不可执行。
任何在 2025 年做好的"沙特 18–24 天到张家港"的表格，在 2026 年已经不能用了——
而且它**看起来完全正常**，不会报错。

**规则：物流章节必须核实"当前状态"，不能只抄历史航程。**

## 核实清单（按顺序）

### 1. 装货港在哪个水域

判定该国出口港是否依赖某个咽喉：

| 水域 | 必经咽喉 | 受影响国家（示例） |
|---|---|---|
| 波斯湾 | 霍尔木兹 | 沙特(除延布)、科威特、卡塔尔、阿联酋、伊朗、巴林 |
| 红海 | 曼德海峡/苏伊士 | 沙特延布、埃及、约旦 |
| 黑海 | 土耳其海峡 | 俄罗斯、乌克兰 |
| 波罗的海 | 丹麦海峡 | 芬兰、瑞典、波罗的海三国 |
| 美湾/东岸 | 巴拿马或苏伊士 | 美国、墨西哥湾、加拿大东岸 |
| 西太平洋 | 无 | 中国台湾、韩国、日本、东南亚 |

### 2. 查咽喉当前状态

对每个咽喉，记录：

- 状态：正常 / 限航 / 高风险 / 封闭
- 起始日期
- 事实（一句话，可核对）
- 对哪些来源国有影响

**必须带核实日期。** 冲突类事件状态变化快，报告里要写明"截至 YYYY-MM"。

### 3. 距离怎么来

优先级：

1. **港口距离表**（ports.com、searates.com）——最权威，但常不可达
2. **船公司/货代公布的航程**
3. **大圆距离 × 绕行系数**——必须写明算法与系数来源

**若用了第 3 种，必须明示"表内无一条来自港口距离表"。**

大圆距离公式：

```python
import math
def great_circle_nm(lat1, lon1, lat2, lon2):
    p1, p2 = math.radians(lat1), math.radians(lat2)
    dp = p2 - p1
    dl = math.radians(lon2 - lon1)
    a = math.sin(dp/2)**2 + math.cos(p1)*math.cos(p2)*math.sin(dl/2)**2
    return 3440.065 * 2 * math.atan2(math.sqrt(a), math.sqrt(1-a))
```

绕行系数（用已知距离标定）：

| 航线 | 系数 | 标定依据 |
|---|---|---|
| 波斯湾 → 中国 | ~1.63 | Jebel Ali → Shanghai 5,696 nm |
| 西北欧 → 中国（经苏伊士） | ~2.20 | Rotterdam 10,666 / Antwerp 10,662 |
| 美湾 → 中国（经巴拿马） | ~1.49 | 已扣除休斯顿航道段 |
| 加拿大西岸 → 中国 | ~1.15 | Vancouver 5,584 |
| 东南亚 → 中国 | ~1.08 | Singapore 2,226 |

航时换算：18–20 节为常规；件杂化船（美湾/大西洋—加拿大）按 12–16 节。
**未计拥堵与等泊**——必须写明。

### 4. 中国侧卸货港

区分两个完全不同的概念：

| 概念 | 有无公开数据 | 用途 |
|---|---|---|
| 港口**库存**分布 | 有（罐区样本） | 判断集散中心 |
| 港口**进口量份额** | 通常无 | 判断主卸货港 |

**最常见的错误：把库存份额写成进口份额。**

例（MEG，2025-10-20 华东样本 51.3 万吨）：
张家港 34%、太仓 26%、江阴+常州 18%、宁波 17%、上海+常熟 4%。
但宁波日出库仅约 2,000 t/日（张家港约 5,000），说明宁波是**分拨节点**而非主卸货口。
这个判断来自"库存 + 出库"两个证据，而**不是**"进口量份额"。

## 输出表结构

| 来源国 | 装货港 | 中国卸货港 | 必经咽喉 | 距离 nm | 航时 | 状态 | 距离算法 | 风险 |
|---|---|---|---|---|---|---|---|---|

`状态` 取值必须明确：`可执行` / `可执行但受限` / `不可执行` / `理论上唯一绕行`。

## 必须写进缺口表的三项

1. 咽喉点今日通行状态（会变，订舱前重查）
2. 各港口距离的权威口径（若只能推算）
3. 直航服务是否存在（无法访问 Alphaliner/Lloyd's List 时，只能写"需向货代核实班期"）

## 保险与合规的联动

- 战争险附加费随咽喉风险变动，报价里要单独列，不能混在海运费里
- 制裁相关航线的保险可能失效（伊朗等）
- 转口国的原产地规则问题：经新加坡中转不产生新加坡原产地
