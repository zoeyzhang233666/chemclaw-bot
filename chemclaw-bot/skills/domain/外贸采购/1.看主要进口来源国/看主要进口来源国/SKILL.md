# Skill: 看主要进口来源国（外贸采购 · 自海外进口至中国）

## 概述

本技能用于回答一个具体采购问题：**这个产品，中国实际从哪些国家进口、各自规模多大、变化如何、哪些国家值得进一步找供应商。**

它不属于"全球产能分析"，也不属于"价格行情"。它的骨架是**中国进口统计**：先用海关/Comtrade 数据确定"中国实际从谁买、买了多少"，再用出口国自报数据做镜像核对，最后才叠加产能、关税、物流三类约束。

**核心信念：来源国的重要性由贸易数据验证，不由行业印象或 Wikipedia 列表预设。**

---

## 何时使用

触发词：`看主要进口来源国`、`进口来源`、`这个产品从哪国进口`、`海外供应商在哪些国家`、`哪些国家向我们出口这个产品`、`进口国别结构`、`自海外采购…到中国`。

**不适用**：产品尚未确定的行业扫描；纯国内供应源分析；纯价格行情（另一技能）；出口销售视角。

---

## 输入要求

| 字段 | 必填 | 说明 | 缺失时 |
|---|---|---|---|
| 产品名称 | ✅ | 中英文 | 无法开始 |
| CAS 号 | 推荐 | 用于确认是否单物质 | 按名称推断，标注"待核" |
| 规格/级别 | 推荐 | 工业级/食品级/聚合级 | 按 HS 六位整体处理，说明未拆分 |
| 用途/下游 | 推荐 | 决定 HS 归类与联产品混淆风险 | 按主用途推断 |
| 数量/年 | 可选 | 用于物流与议价规模 | 标注"未提供" |
| 目标价 | 可选 | 用于比价 | 标注"未提供" |
| 现有供应商 | 可选 | 用于交叉验证 | 标注"未提供" |
| 到货地 | 可选 | 决定卸货港选择 | 默认华东/长江下游 |

## 工作流（六步）

### Step 1 · HS 编码确认（不可跳过）

1. 从 CAS + 名称查 HS 六位；**必须给出候选表**，至少包含：
   - 本体税号
   - 同章易混物（异构体、同系物、联产品）
   - 相邻口径（制剂、混合物、成品）
2. 明确写出：**该税号覆盖什么、不覆盖什么**。
3. 中国 8/10 位税号单独列出（如 2905310000）。
4. 检查该六位是否为"一码多物"（如 2905.32 含丙二醇但 2905.31 只含乙二醇）。

> ⚠️ 反例：用 290944/290949（乙二醇醚）的贸易救济去推断 MEG 被反倾销，是最常见的错误。

### Step 2 · 中国进口主数据（决定后续一切）

数据源优先级：
1. **UN Comtrade**（HS 六位，全部伙伴国，可编程、可复现）
2. 中国海关总署统计（8/10 位，但通常需订阅）
3. 行业协会/研究院公开年度数据（做交叉核验）

必做：
- 至少 **5 个完整年度**；优先 10 年
- 抓取 **金额 + 净重** 双口径（缺失年份必须标注）
- 抓取**全部伙伴国**，不预设名单
- 计算：份额（金额/数量）、5 年均份额、同比、CAGR、单位价值 USD/t
- **镜像核对**：中国自报进口 vs 出口国自报对华出口，偏差 >30% 必须入表并解释

### Step 3 · 出口国自报数据（镜像侧）

对 Step 2 中份额 >1% 的所有国家，抓取其自报出口（对世界 + 对中国）：
- 判断该国出口对中国的依赖度（输华占其总出口比）
- 识别"该国其实主要卖给别处"的情况
- 识别转口/转运（出口统计含中转货）

### Step 4 · 产能与工艺（公开信息，逐条附证）

- 装置级产能优先于集团级；集团合计必须**单独标注**且不重复计入
- 每条必须带：企业、装置/地点、产能、数据年份、工艺、来源 URL、原文引文、可信度
- **明示"未找到"**，不用估计值填坑
- 计算"产能覆盖倍数"（公开产能 ÷ 对华出口量），并解释其局限

### Step 5 · 关税、协定与非关税措施

- MFN 税率 + 暂定税率 + 协定税率，逐国列出
- 必须标注**税率依据的年度文件**
- 检查：自贸协定是否已签署（不是"在谈"）、贸易救济是否针对**本产品**（不是相邻产品）
- 记录暂停/加征的**到期日**

### Step 6 · 物流与可执行性

- 装货港 → 中国卸货港，逐条标注必经咽喉点
- **必须核实咽喉点当前状态**（战争/封锁/限航会让整张表失效）
- 距离优先引用距离表；若只能推算，必须写明算法
- 中国侧卸货港：区分"库存分布"与"进口量份额"——后者通常无公开数据

## 硬性规则（违反即返工）

1. **不预设来源国排名**。名单由 Step 2 数据决定，不能先写结论再找数据。
2. **不判断"哪个国家最优"**。输出"值得进一步核实什么"，不输出"最佳来源国"。
3. **每个数字必须带：年份 + 单位 + 来源**。三者缺一，视为无来源。
4. **区分三件事**：贸易事实 / 公开产能 / 对实际供应能力的推断。三者不得混写在同一句里。
5. **公开产能 ≠ 可供中国采购量**。必须写明需扣除：本地需求、长协锁定、检修、物流限制。
6. **缺口是结论的一部分**。"未找到"和"待核"必须出现在交付物里，不能悄悄删除。
7. **单位价值不是价格**。USD/t 报关加权平均值不能用于报价。
8. **区分全球出口国统计与中国进口来源统计**。两者口径不同（CIF/FOB、转口、统计定义），不得混用。
9. **"其他亚洲（nes）" 之类的合并口径不得擅自拆分成单一国家**。
10. **咽喉点/制裁/关税暂停等时效性事实必须标注核实日期**。

## 输出物

### A. 交互式 HTML 报告（单文件，离线可用）

必须包含：
1. 产品输入回显 + HS 候选确认表
2. 关键指标卡
3. 时间序列图（金额/数量/单位价值）+ 份额堆叠图
4. **世界地图**（按中国进口份额着色），点击展开国别详情
5. **可排序、可筛选的主表**（份额/金额/数量/增速/关税/产能）
6. **2–5 国横向对比**面板
7. 装置级产能证据表（附原文引文）
8. 关税表 + 非关税措施表 + 物流表 + 咽喉点状态
9. **证据抽屉**：点任意国家看到该国全部事实、来源、缺口
10. 数据校验表 + 数据缺口表

技术要求：
- **完全离线**：ECharts/Leaflet/地图数据全部内联，无 CDN 依赖
- 地图底图用内嵌矢量陆地数据，不依赖在线瓦片
- 响应式：1280 / 768 / 420 三档无横向溢出
- 无 console 错误

### B. Excel 工作簿（多 sheet）

至少 12 个 sheet：
`00_封面与结论` `01_关键指标` `02_中国进口来源逐年` `03_出口国自报` `04_国家汇总`
`05_生产企业与产能` `06_生产工艺` `07_关税` `08_非关税措施` `09_物流与港口`
`10_建议与不确定性` `11_数据来源` `12_缺口与方法`

## 数据源与可达性

| 来源 | 用途 | 可达性 |
|---|---|---|
| UN Comtrade public preview API | 主数据 | ✅ 可直接调用（有配额限速） |
| Comtrade partnerAreas.json | 国家代码映射 | ✅ 必须用它，勿凭记忆 |
| 中国海关 / 税委会 / 商务部 | 税率、措施 | ❌ 多数政府域名不可直连，需二手交叉 |
| 企业官网/年报 | 产能 | ✅ 部分可达 |
| WITS API | 备选 | ❌ 常被墙 |
| ports.com / searates.com | 距离 | ❌ 常不可达，需推算并标注 |

**Comtrade 调用要点**：
- 一次只查 1 个年份：`period=2024`（多期会报错）
- 不传 `partnerCode` 即为全部伙伴国（传 `*` 或 `all` 会 400）
- 限速约 1 请求 / 1.5 秒；超限返回 `403 Out of call volume quota`
- 必须落盘缓存原始 JSON，便于复现

## 常见错误清单

| 错误 | 后果 | 纠正 |
|---|---|---|
| 直接用 Wikipedia 产能列表排序国家 | 结论与贸易事实脱节 | 以 Step 2 数据为准 |
| 把 2905.32（丙二醇）数据当 MEG | 数量级错误 | 逐码核对 |
| 把集团总产能当作单一装置产能 | 重复计算、虚高 | 集团行单独标记 |
| 忽略转口（新加坡/阿联酋/香港） | 高估本地供给能力 | 标注"转口枢纽" |
| 用历史航线表不做时效核实 | 封锁后整表失效 | Step 6 强制核实 |
| 把"库存分布"写成"进口份额" | 港口判断错误 | 明确二者区别 |
| 2025 等最近年份当作终值 | 数据后续被修订 | 标注"初步数" |
