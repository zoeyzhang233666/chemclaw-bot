# 示例：工业级乙二醇（MEG）中国进口来源国研究

本目录是一份**完整跑通的真实案例**，可直接对照格式复用。

## 文件

| 文件 | 内容 |
|---|---|
| `input.json` | 采购方实际提交的输入（产品、CAS、规格、用途、年份区间） |
| `data.json` | 装配后的完整数据骨架（HTML 与 Excel 都由它渲染） |

## 这个案例演示了什么

1. **HS 候选表**：290531 被选中，290532/290941/382000 被排除并写明原因。
2. **份额由数据决定**：先抓全部伙伴国，再按价值份额排序，没有预设名单。
3. **镜像核对**：美国出现 -160% 的偏差（中方报 559.7 kt，美方报 214.7 kt），
   被写入 `checks` 并解释为"加拿大货经美转运"。
4. **产能只认公开数字**：36 条装置级记录，其中 11 条是 `not found`，
   明确写进缺口表，不用估计值填补。
5. **产能与贸易的两个合理缺口**：沙特已披露 3,242 kt 只覆盖 80% 装置，
   却对应 4,226 kt 对华出口；加拿大 860 kt 覆盖 67%，对华出口 1,033 kt。
   这两条在校验里是 WARN（有解释），不是 FAIL。
6. **物流时效**：霍尔木兹自 2026-02-28 封闭，9 个中东装货港标为"不可执行"，
   而不是照抄历史航程。
7. **不给最优结论**：输出的是"值得核实什么"。

## 校验结果

```
PASS:33 WARN:4 FAIL:0
  [WARN] V06-unit-value: 瑞典/瑞士极小金额样本导致单位价值异常（样本过小，非数据错误）
  [WARN] V07-evidence-gap: 11 条装置产能未公开披露（已入缺口表）
  [WARN] V09-capacity-vs-trade: 沙特（覆盖 80%）、加拿大（覆盖 67%）披露不全
```

**4 个 WARN 全部是有解释的已知缺口，没有 FAIL。** 这正是本技能期望的状态：
不是"没有问题"，而是"每个问题都被写出来了"。

## 复用方式

1. 复制 `input.json`，填入新产品。
2. 按 `references/comtrade-playbook.md` 抓数据，装配出同结构的 `data.json`。
3. 用 `templates/report_template.html` 与 `templates/workbook_template.xlsx` 渲染。
4. 跑 `scripts/validators.py data.json`，把每条 WARN/FAIL 处理掉或写进缺口表。
