## 三、关键发现（这是本示例想演示的东西）

### 1. 两套体系必须分开判

```
危险化学品：目录第903项，门槛「含量 > 8%」，本单 30% → 命中
危险货物：  UN2014，门槛「20% ≤ 含量 ≤ 60%」，本单 30% → 命中
```

两者**同时成立**，义务**叠加**，但不能互相替代：
- 危化品义务 → 中文 SDS、中文标签、危化品登记、包装要求；
- 危险货物义务 → UN 包装认证、类项标志、DG 订舱与申报、积载隔离。

**易错点**：易制爆的「氧化性液体 类别 2」与运输的「包装类别 II」数字相同纯属巧合，依据完全不同。
另外，易制爆名录写「＜60%」而 IMDG 写「≤ 60%」——**60% 边界两套文件口径不同**，必须回原文核对。

### 2. 一个「溶液」条目的隐性前提

目录第 903 项的对象是「过氧化氢溶液」。应急管理部的官方答复明确：
> 浓度 > 8% 的过氧化氢溶液中，若添加了**稳定剂、惰性化学品以外**的其他化学品，即不属于该水溶液条目，需另行开展危险特性鉴定。

所以判定不是「浓度够了就行」，还要证明**添加剂只有稳定剂**。
本示例中供应商 SDS 第 3 节只写「phosphate based stabiliser」，没给 CAS 与精确百分比 —— 这就是为什么结论停在「视条件适用」，而不是「适用」。

### 3. 协定税率不能用第三方数据

两个第三方页面分别给出 1.1% 与 2.8%，另一个来源又说该类产品已零关税。三者互相矛盾，且都没写协定年度与降税阶段。

按 CIF ≈ USD 24,200 测算：

| 情景 | 关税（CNY） |
|---|---|
| 最惠国 5.5% | ≈ 9,474 |
| 中韩 FTA 1.1%（待核实） | ≈ 1,895 |
| 零关税（若成立） | 0 |
| 普通税率 30%（最坏） | ≈ 51,677 |

**差额足以改变这单生意的盈亏**，但结论只能是「必须由报关行在单一窗口实查」。

### 4. 上传文件的交叉冲突

| 冲突 | 细节 |
|---|---|
| PI 贸易术语 | 货物栏写 CIF Busan ×2，条款写 FOB Busan —— 同一份文件三处表述 |
| 标签语言 | 纯英文，无中文品名、无中文 H/P 说明、无中国境内 24h 应急电话 |
| SDS 版本 | 无版本号、无修订日期 —— 无法证明是现行版本 |
| COA 缺项 | 铁 / 氯化物 / TOC 未检测，且未列检测方法编号 |

这些都不是「文件没给」，而是「给了但不合格」—— 属于 `partial`，不是 `missing`。
区分这两者对判断「还来不来得及」很关键。

## 八、这个案例的边界

- 只对「30% 水溶液 / 稳定剂型 / 工业级 / PCB 微蚀用途 / 30 kg 桶装 / 海运整柜 / 韩国」成立。
- 换成 50% 或 10%，易制爆分档与 UN 编号**全部改变**，必须重跑 P3–P4。
- 换成配方型清洗剂，可能**不再落入**第 903 项，须先做危险特性鉴定。
- 用途改为食品添加剂或消毒产品，监管路径完全不同。
- 不构成法律意见，不替代海关、应急管理、公安部门的实际认定。
