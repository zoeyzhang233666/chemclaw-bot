# references/dangerous-goods-vs-hazchem.md — 危险化学品 ≠ 危险货物

> 这是整份技能最容易被写错的一块。请把本文当作判定的**模板**，而不是某产品的答案。

---

## 1. 两套体系为什么必须分开

| 维度 | 危险化学品 | 危险货物 |
|---|---|---|
| 法域 | 中国境内安全生产监管 | 运输（国际规则 + 国标） |
| 核心文件 | 《危险化学品目录（2015 版）》 | UN Model Regulations / IMDG / IATA；GB 6944、GB 12268 |
| 判定单位 | 「条目 + 含量条件」 | 「UN 编号 + 类项 + 包装类别」 |
| 分级语言 | GHS 类别（类别 1/2/3…） | 包装类别 PG I/II/III；类项 1–9 |
| 主管 | 应急管理部 | 交通/海事/民航 + 海关（申报） |
| 触发后果 | 中文 SDS/标签、包装、登记、许可 | 包装认证、标志、申报、积载隔离 |

**核心命题**：
> 属于危险货物 ⇏ 属于危险化学品；属于危险化学品 ⇏ 属于危险货物。
> 两者同时成立时，义务是**叠加**的，不是二选一。

---

## 2. 三套分档数字不能互抄

一个含量型产品，可能同时被三套文件分档，而分档边界**不完全一致**：

1. **危险化学品目录**：常以「含量 > X%」设门槛（是否成立）；
2. **易制爆名录**：按含量再分「类别 1/2/3」（治安管理强度）；
3. **运输 UN 条目**：按含量分不同 UN 编号与包装类别（运输条件）。

典型问题：
- 易制爆写「20% ≤ 含量 < 60%」，而运输规则里对应条目写「not more than 60%」。**边界上的那个点**（正好 60%）两套文件口径不同 —— 必须**回原文核对**，不能相互推定。
- GHS 的「氧化性液体 类别 2」与运输的「包装类别 II」数字相同纯属巧合，**依据完全不同**。

  entry:   <目录条目原文>
  threshold: <含量/形态条件>
  consequence: <触发哪些义务>

  regime:  <运输规则名>

  - ...

## 4. 必查清单

### 危险货物侧

- [ ] 是否属 GB 6944 / UN 九类中的某一类项？
- [ ] UN 编号是多少？（**按含量查表，不按商品名**）
- [ ] 包装类别是 I / II / III？
- [ ] 正确运输名称（英文原文）是什么？
- [ ] 有无次要危险？
- [ ] 需要哪几个类项标志？（例如同时有主危险与次要危险时，两个标志都要）
- [ ] 包装指令（Packing Instruction）与特殊规定（Special Provision）是什么？
- [ ] 积载与隔离要求？（尤其与氧化剂、酸、易燃物、食品的关系）
- [ ] EmS 或等效应急措施代码？
- [ ] 运输方式不同（海运/空运/陆运）结论是否相同？**不得混用。**
- [ ] 国内标准版本是否为现行版（GB 6944/12268 有 2025 修订版，2025-10-01 实施）？

### 危险化学品侧

- [ ] 是否列入《危险化学品目录》最新版？哪一条？
- [ ] 该条目的含量条件是什么？本单是否满足？
- [ ] 若为「溶液」条目，添加剂是否仅为稳定剂/惰性物质？
- [ ] 若为混合物，是否已做危险特性鉴定？
- [ ] 是否触发中文 SDS / 中文标签 / 包装 / 登记 / 经营许可？

### 易制爆侧（若适用）

- [ ] 是否列入《易制爆危险化学品名录（2017 年版）》？哪一项？
- [ ] 落在哪一档（类别 1/2/3）？
- [ ] 购买凭证、流向报备的属地口径是什么？

## 5. 表述纪律

| 可以写 | 不能写 |
|---|---|
| 「危险货物：UN 2014 / 5.1 / 次要危险 8 / PG II」 | 「八类危险品」「五类一」之类口语 |
| 「危险化学品：高度可能适用目录第 N 项，条件为……」 | 「属于危险化学品」（未证实前） |
| 「易制爆：落入类别 2，触发购买凭证与流向报备」 | 「易制爆就等于要办许可证」（不完全，要看主体身份与情形） |
| 「两套分类分别成立，义务叠加」 | 「是危险货物就不用管危化品了」 |

---

## 6. 一个反直觉但重要的提醒

> **「不在危险化学品目录里」≠「不危险」。**

目录是以 GHS 分类为基础**筛选**出来的清单，并非穷举所有危险物质。未列入目录的物质，仍可能有危险特性，仍可能被判定为危险货物（运输），也仍可能因其他法规（环保、新化学物质、职业健康）承担义务。

同理：
> **「稀释后不是危险货物」≠「不需要 SDS 与安全措施」。**
