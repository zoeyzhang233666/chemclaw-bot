# references/hs-classification.md — HS 归类的推理与表述

---

## 1. 归类输出不是「一个编码」

合格输出必须包含：

```
首选编码 + 品目描述
  ├─ 归类依据（章注 / 子目注释 / 品目条文）
  ├─ 成立条件（商品必须满足的事实）
  ├─ 置信度（高 / 中 / 低）
  ├─ 备选与兜底路径（不成立时去哪）
  └─ 不确定点 + 是否需要预裁定
```

只给编码而不给依据的，视为不合格。

---

## 2. 六步法

### 第 1 步：确定商品的实际状态

按**报验状态**判，不按最终用途判。需要写清：

- 化学身份（CAS、分子式/结构）
- **浓度与含量**（混合物必须给各组分百分比）
- 物态（固体/液体/气体；是否水溶液）
- 是否含添加剂（稳定剂 / 防尘剂 / 着色剂 / 功能性添加剂）
- 包装规格（有时直接决定税目或子目）
- 用途（仅在与归类有关时才用）

### 第 2 步：找章注与子目注释

《进出口税则》的「类注、章注、子目注释」优先级**高于**品目条文。
常见的有用注释：

- 第 28 章类注/章注一：本章税目适用于哪些「单独化学元素/化合物」，以及**这些产品的水溶液**；
- 为保存或运输需要加入**稳定剂**的，是否仍归本章；
- 「零售包装」「剂量包装」类注释会影响是否落入制剂品目。

### 第 3 步：读品目条文（四位）

按**列名**优先：有明确列名的，不走兜底品目。
兜底品目（如「其他无机化合物」「其他化学工业产品」）只有在没有更具体品目时才使用。

### 第 4 步：走子目与八位/十位

- 六位是国际统一；八位/十位是国家层面细分。
- 中国十位编码后还有** CIQ 扩展码**（十三位），用于法定检验检疫，必须与含量/用途/包装匹配。

### 第 5 步：写成立条件

用「若 A 且 B 且 C，则归 X」的形式。条件要能被第三方独立验证：

- 好：「主成分为过氧化氢，溶剂仅为水，添加剂限于运输所必需的稳定剂」
- 差：「属于过氧化氢产品」（无法验证）

### 第 6 步：写推翻路径

每种情形都要能回答「如果不成立，去哪」：
- 加功能性添加剂 → 可能落入制剂品目；
- 稀释到某浓度以下 → 可能改变归类或不再受特定监管；
- 改为零售包装 → 可能改归其他品目。

## 3. 置信度定义（可直接写进报告）

| 置信度 | 判据 |
|---|---|
| 高 | 有明确列名品目，且章注支持；构成条件已全部满足或可验证 |
| 中 | 有列名品目但构成条件需推测；或缺关键事实（如添加剂明细） |
| 低 | 只能靠兜底品目或类比；存在多个同等可能的品目 |

**「低」不必然要申请预裁定，但必须写进待确认事项。**

---

## 4. 规范申报要素

不同税则号列的「申报要素」不同，顺序与内容由当年税则规定。填报时：

1. 从单一窗口/税则原文取该商品编号的要素清单；
2. **严格按顺序**用 `|` 分隔填写；
3. 要素缺项不要留空，用「无」「非必填」等口径处理，按报关行要求；
4. 成分含量要素必须与 SDS/COA 一致。

常见要素类别（示例性质，具体以当年税则为准）：
品牌类型 / 出口享惠情况 / 用途 / 成分含量 / 包装规格 / 型号 / GTIN / CAS / 其他。

---

## 5. 预裁定：什么时候值得做

- 建议做：成分复杂、存在两个以上同等可能品目、金额大、多次进口、历史上有争议。
- 可不做：单一成分、有明确列名、章注直接支持。

依据：海关预裁定制度（海关总署令第 236 号）。预裁定有适用范围与时限，须按现行规定申请。

---

## 6. 与监管条件的联动

同一个十位编码可能对应不同**监管条件代码**（如入境货物通关单、两用物项等）。归类一改，监管条件、税率、CIQ 码可能全部改变。因此：

> **归类不是终点，而是监管与税费判定的入口。**
> 归类的任何变动都必须回头重跑监管清单与税费测算。

## 7. 表述纪律

| 可以写 | 不能写 |
|---|---|
| 「建议归入 XXXX，依据为……，置信度高」 | 「归入 XXXX」（好像已获海关认定） |
| 「本单归类置信度高，建议报关行复核后申报」 | 「归类已确认无误」 |
| 「若添加剂为功能性，则可能改归 YYYY」 | 「肯定就是这个编码」 |
| 「CIQ 码段按含量分段，本单应落 YYYY.ZZ」 | 「CIQ 码无所谓」 |
