# references/regulation-map.md — 法规地图：查什么、去哪查、依据到条款

> 本文件只提供**查询路径与判定框架**，不含任何具体产品的结论。
> 所有条目在使用时必须带上：查询日期 + 适用条件 + 来源等级（A/B/C）。

---

## 0. 先分清五套互相独立的制度

进口化学品最常犯的错，是把下面五套制度混成一套。它们各有自己的目录、门槛和主管机关。

| 制度 | 管什么 | 核心依据 | 谁主管 |
|---|---|---|---|
| **危险化学品** | 生产、储存、使用、经营、**进口企业登记**、中文 SDS/标签、包装 | 《危险化学品安全法》（2026-05-01 施行）；《危险化学品目录（2015版）》 | 应急管理部牵头 |
| **危险货物** | **运输**环节的包装、标志、装载与隔离 | UN Model Regulations / IMDG / IATA；GB 6944、GB 12268 | 交通运输、海事、民航 |
| **易制爆** | 特定危险化学品的**治安**管理（购买凭证、流向报备） | 《易制爆危险化学品名录（2017年版）》；《危险化学品安全法》第 58、60–62 条 | 公安部 |
| **两用物项** | 进出口**许可**（防扩散） | 《出口管制法》《两用物项出口管制条例》；年度《两用物项和技术进出口许可证管理目录》 | 商务部、海关总署 |
| **检验检疫** | 进出口**报关检验**的范围、材料与内容 | 海关总署公告 2020 年第 129 号 | 海关总署 |

**关键推论**：一套成立不必然推出另一套成立。危险化学品有「含量 > 8%」这种目录内阈值，危险货物按 UN 分档，易制爆名录又用第三套分档。必须分别判定。

## 1. 危险化学品：三步判定

### 第 1 步：是否「列入目录」

- 目录全称：《危险化学品目录（2015 版）》，以十部门公告 2015 年第 5 号发布，2015-05-01 施行。
- 之后有调整：应急管理部等部门公告 2022 年第 8 号（柴油条目调整）、2026 年第 3 号（新增若干品种）。判断时必须用**最新版**，并记录所用版本的更新日期。
- 查询处：应急管理部官网《危险化学品目录》页面 / 各省应急管理厅转载 / 具备 A 级效力的行业数据库（须交叉核对）。

### 第 2 步：命中哪一条（用 CAS 与浓度筛）

目录里每条都带：序号、品名、别名、CAS 号、备注。
筛选顺序：**CAS 精确匹配 → 品名/别名匹配 → 备注中的含量条件**。

三个高频陷阱（来自目录的《说明》）：

1. **无含量说明的条目，指工业产品或纯度高于工业产品的化学品。**
   若你的产品是「工业级」，条目又不带含量条件，则该条目通常适用。
2. **「溶液」在目录中如无特殊说明，指水溶液。**
   所以「某酸溶液」「某碱溶液」类条目默认是水溶液。
3. **在溶液条目中加入了稳定剂、惰性化学品以外的其他物质，就不再属于该「溶液」条目。**
   必须另行开展危险特性鉴定，再决定是否按危险化学品管理。

> 第 3 条是「配方型产品」与「纯溶液」的分水岭。进口实务中最容易在这里出错：
> 供应商的 SDS 只写「stabiliser」，而实际配方里含功能性添加剂（缓蚀剂、润湿剂、增稠剂等）。

### 第 3 步：判定四态

| 判定 | 含义 | 允许的表述 |
|---|---|---|
| 适用 | 已用 CAS + 浓度 + 形态证实命中某条目 | 「适用《危险化学品目录》第 N 项」 |
| 视条件适用 | 命中高可能，但缺关键事实（如添加剂明细） | 「高度可能适用，条件为……」 |
| 待核验 | 资料不足或来源未核实 | 「待核验」——**不得**写成「不适用」 |
| 不适用 | 有明确依据排除（如含量低于阈值，且已核实） | 「不适用，依据为……」 |

### 第 4 步：进口企业侧的连带义务（法律第 31、32、86 条）

- 中文**化学品安全技术说明书**与中文**安全标签**（第 31 条）；
- 包装符合要求（第 32 条）；
- 进口企业办理**危险化学品登记**（第 86 条）；
- 若转售：危险化学品**经营许可**（第 53 条）；
- 若为易制爆：购买凭证与流向报备（第 58、60–62 条）。

## 2. 易制爆：单独的目录与三档分级

- 名录：《易制爆危险化学品名录（2017 年版）》，公安部 2017-05-11 发布。
- 组织方式：按危险特性分为若干大类，每项给出品名、别名、CAS 与**按含量的危险类别分档**。
- 查询处：公安部官网、各省公安厅转载。

**要点**：
1. 易制爆的门槛与危险化学品门槛**可以不同**（例如危化品是「含量 > 8%」，易制爆也写「含量 > 8%」，但分档细到三类）。
2. 易制爆的分档**不等于**运输的包装类别。两者数字可能恰好相同，但依据完全不同，不能互相引用。
3. 义务落在**购买与销售**：销售方须查验购买方凭证、如实记录、按期报送流向信息；购买方须持相应许可证或单位出具的合法用途说明。

## 3. 危险货物：按 UN 体系走

### 查询顺序

1. 定性：是否属 GB 6944 / UN 九类中的某一类项。
2. 定编号：查 GB 12268《危险货物品名表》或 IMDG 危险货物清单，按**化学性质 + 浓度**找 UN 编号。
3. 定包装类别：PG I/II/III（由 UN 条目给定，不由进口商自选）。
4. 定正确运输名称：用 UN 条目原文，不自行翻译。
5. 定标志与积载隔离：按类项与 IMDG 积载要求。

### 标准版本要核

- GB 6944《危险货物分类和品名编号》与 GB 12268《危险货物品名表》均有 2025 年修订版，2025-10-01 实施。引用时必须写清版本号与实施日期，旧版结论可能已失效。

### 常见误区

- 把 GHS 的「类别 1/2/3」当成运输的「包装类别 I/II/III」。**两套分档依据不同。**
- 只凭商品俗名判断（「双氧水」「漂白水」「洗板水」都不是运输名称）。
- 认为「稀释了就不用按危险货物运」。有些物质稀释到一定浓度才退出危险货物，这个阈值要查具体 UN 条目，不是拍脑袋。

## 4. 两用物项：只能查当年目录

- 依据：《出口管制法》《两用物项出口管制条例》；商务部与海关总署每年公布《两用物项和技术进出口许可证管理目录》。
- **必须逐年重查。** 监管条件代码里的「两用物项」类代码可能是**定向**（只针对某方向），不能据此推断另一方向是否需证。
- 结论只能来自：当年目录原文 + 报关行/商务主管部门的书面确认。

---

## 5. 检验检疫：海关总署公告 2020 年第 129 号

这是进口危险化学品**报关材料清单**的主要来源。要点（引用时须核对原文）：

1. **范围**：海关对列入《危险化学品目录》**最新版**的进出口危险化学品实施检验。
2. **报关填报**：危险类别、包装类别（散装除外）、UN 编号、联合国危险货物包装标记（包装 UN 标记）。
3. **随附材料**：进口危险化学品企业符合性声明；抑制剂/稳定剂名称与数量说明；中文危险公示标签样本；中文安全数据单样本。
4. **检验内容**：成分/理化特性/危险类别，以及标签与 SDS 与货物是否相符。
5. **包装检验**：包装型式、标记、类别、规格、单件重量与使用状况。
6. **特殊用途**：用作食品、食品添加剂的，还须符合食品安全相关规定。

## 6. 关税与优惠

| 事项 | 规则 | 查询处 |
|---|---|---|
| 税则号列与税率 | 每年由国务院关税税则委员会发布《进出口税则》，以当年版本为准 | 税委会公告原文 / 单一窗口 |
| 最惠国 vs 普通 | 按原产地是否适用最惠国待遇区分 | 税则「备注」列 |
| 暂定税率 | 若设置，优先于最惠国税率 | 当年关税调整方案 |
| 协定税率 | 以自贸协定为条件，须原产地证书 + 原产地规则 + 直接运输 | 单一窗口「优惠税率查询」 |
| 增值税 | 进口环节由海关代征，计税价格 = 完税价格 + 关税 + 消费税 | 增值税相关法规 |
| 消费税 | 仅限应税消费品 | 消费税税目表 |

**硬规则**：第三方网站给出的协定税率只能作为「线索」，不能作为结论。必须由报关行在单一窗口按「HS + 对方国家 + 年度」实查，并留存截图。

## 7. 判定时必须写出的七个字段

每条监管结论都要能回答这七问，缺一项即为不合格结论：

1. **依据**：哪部法律/公告/标准，第几条/第几项；
2. **适用条件**：什么情况下成立（含量、形态、用途、包装、流向）；
3. **本单是否满足**：满足 / 不满足 / 未知；
4. **判定**：适用 / 视条件适用 / 待核验 / 不适用；
5. **后果**：触发哪些义务（文件、许可、检验、登记）；
6. **责任方**：供应商 / 进口商 / 承运人 / 报关代理 / 检测机构；
7. **来源等级与查询日期**：A/B/C + YYYY-MM-DD。
