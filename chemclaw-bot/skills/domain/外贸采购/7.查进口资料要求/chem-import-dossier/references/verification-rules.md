# references/verification-rules.md — 法规核验规则（硬纪律的可执行版）

> 本文件约束**怎么写**。凡与本文件冲突的表述，一律视为不合格输出，即使内容正确。

---

## 1. 证据三档

| 等级 | 定义 | 能否作唯一依据 |
|---|---|---|
| **A** | 官方一手：法律原文、行政法规、部委公告、官方答复、国标原文、税则原文 | 可以 |
| **B** | 官方转载/政务数据库：地方政府网站转发、单一窗口业务参数、官方数据库镜像 | 可以（需注记转载路径） |
| **C** | 行业数据库、商业平台、供应商提供的第三方资料 | **不可以**，仅作交叉参考 |

**规则**：
- 任何一条监管结论至少要有 1 条 A 或 B 级来源；仅有 C 级来源的结论必须标为「待核验」。
- 每条来源必须记录 `标题 / 发布机关 / 日期 / 效力状态 / URL / 支撑了哪条结论 / 查询日期`。
- 查询日期必须是**实际访问日**，不是「大概」。

## 2. 阈值判定：三值逻辑，禁止二值化

涉及含量/浓度/数量阈值的判定，只能有三种结果：

```
True   —— 已核实满足
False  —— 已核实不满足
None   —— 事实不足，无法判定  → 输出「待核验」
```

**严禁**把 `None` 当成 `False`（把「不知道」写成「不适用」）。
**严禁**把 `None` 当成 `True`（把「可能」写成「适用」）。

写进报告时：

- `True` → 「适用」
- `False` → 「不适用，依据为……」
- `None` → 「待核验」或「视条件适用（条件为……）」

> 只要结论依赖「未知的浓度/是否含添加剂/是否属某目录」这类事实，
> 结论就只能是「视条件适用」或「待核验」。

---

## 3. 四态判定 + 「不适用」的门槛

| 判定 | 何时可用 | 必须附带 |
|---|---|---|
| 适用 | 条件已核实满足 | 依据条文 + 触发义务 |
| 视条件适用 | 条件大概率满足但缺事实 | **写出缺失的事实**与补齐路径 |
| 待核验 | 资料不足或来源未核实 | 谁去核、怎么核、什么时限 |
| 不适用 | **有明确条文排除**，且已核实事实 | 排除依据 + 已核实的事实 |

「不适用」是最容易被滥用的判定。使用前自问：

1. 我是否引用了具体的排除条款？
2. 我是否核实了支持排除的事实（含量、用途、流向）？
3. 如果这个事实错了，结论会不会翻转？

任一答案为「否」，就不能写「不适用」。

## 4. 禁用表述清单

| 禁用 | 为什么 | 改成 |
|---|---|---|
| 保证通关 / 包过 / 100% 合规 | 没有人能保证 | 「按现有资料，报关材料可满足……，最终以海关认定为准」 |
| 绝对 / 肯定 / 一定（用于法规结论） | 事实未证实时是错的 | 「高度可能」「在……条件下适用」 |
| 没问题 / 没风险 | 掩盖不确定性 | 「未发现需要补正的问题；残余风险为……」 |
| 听说 / 一般都要 / 通常都得 | 无来源的口头经验 | 「依据 X 公告第 N 条」或标为「待核验」 |
| 应该可以 / 大概没问题 | 模糊承诺 | 明确判定四态之一 |
| 归入 XXXX（用作已确定） | 未经海关认定 | 「建议归入 XXXX」 |
| 等同于（用于跨体系） | 不同体系不能等同 | 「两套体系分别成立」 |

**负面清单自检**：渲染前扫一遍全文，命中即报错。

## 5. 时效性规则

1. **法律/条例**：必须核对是否有新法替代旧法。旧法与新法并存期间，明确写「以新法为准」。
   例：《危险化学品安全管理条例》部分条款已被《危险化学品安全法》覆盖 —— 引用时必须注明。
2. **标准**：必须写「标准号 + 年份 + 实施日期 + 是否现行」。有新版但未实施时，写清「新旧并行期」的处理口径。
3. **公告**：海关/部委公告常有「自 X 日起实施」，注意是否有后续替代公告。
4. **目录**：以最新版为准，并记录该版本的更新日期（如「2015 版 + 2022 年第 8 号 + 2026 年第 3 号」）。
5. **税率**：按当年税则。跨年进口要注明按哪一年的税率。（税率按申报适用口径，不是到货口径。）
6. **证书**：SDS/COA/原产地证的有效期与批次对应关系。

**一条规则**：所有结论的时间基准统一用底稿的 `as_of` 日期，不用「今天」。

## 6. 数值与计算规则

1. 所有金额写明**币种**与**汇率**，并注明汇率来源与日期。
2. 进位规则统一为**四舍五入到分**；试算与正式申报可能差几元，需注明。
3. 税费公式必须显式写出：
   - 关税 = 完税价格（CIF）× 适用税率
   - 增值税 = (完税价格 + 关税 + 消费税) × 增值税率
4. 区间值写「下限–上限」，不写单点。
5. 百分比写清是**质量分数**还是**体积分数**——这两者在浓度阈值判定中后果完全不同。

## 7. 交叉一致性硬规则

以下任一项不一致，必须单独成条列进「问题」并在报告首页可见：

1. CAS 不一致
2. 浓度不一致（差 0.1 个百分点也要记）
3. 贸易术语不一致
4. 运输信息（UN/类项/PG）与 SDS 第 14 节不一致
5. 包装规格与总净重算不平
6. 中文文件与英文原件内容不一致（不只是翻译问题）
7. 报关填报的包装 UN 标记与实际包装不符

## 8. 「待确认事项」的写法

每个待确认项必须包含**五个字段**，缺一不可：

```
事项        —— 一句话说清要确认什么
为什么不能自判 —— 缺什么事实/来源为什么不可靠
谁确认      —— 报关行 / 合规顾问 / 属地公安 / 应急管理 / 供应商 / 承运人
怎么核实    —— 具体渠道或方法
判断错的代价 —— 如果这一项判错，会发生什么（退运/处罚/补税/事故）
```

**「谁确认」不能写「相关人员」**，必须落到具体主体。

---

## 9. 责任划分规则

每份资料必须绑定**一个**主责主体，且主体名称必须落在下列集合内：

`海外供应商 / 进口商 / 承运人 / 报关代理 / 第三方检测机构 / 监管机构`

（允许组合，如「进口商/海外供应商」，但必须写明各自负责哪一段。）

**原则**：
- 技术事实（成分、稳定剂、分类、运输信息）→ 供应商
- 中国法定中文文件与登记 → 进口商
- 运输合规与订舱申报 → 承运人/货代
- 报关填报与税额 → 报关代理
- 鉴定/检测 → 第三方机构

## 10. 渲染前自检清单

- [ ] 每条监管结论都有「来源编号」
- [ ] 每条「适用」都写了条件
- [ ] 每条「不适用」都有排除依据
- [ ] 「待核验」没有被写成「不适用」
- [ ] 全文无禁用表述
- [ ] 时间基准统一为 `as_of`
- [ ] 危险化学品与危险货物**分别**判定
- [ ] 单证清单里同时有中文文件与英文文件
- [ ] 每个缺口都有「为什么 / 怎么要 / 谁负责」
- [ ] 每个待确认项都有「判断错的代价」
- [ ] 模拟件已显式标注
- [ ] 首页有结论口径（可以写 / 不能写）
