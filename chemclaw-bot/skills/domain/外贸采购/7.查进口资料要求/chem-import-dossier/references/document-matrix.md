# references/document-matrix.md — 单证矩阵与核查要点

> 矩阵给的是**方法论**：哪一类产品该准备哪一组文件、每份文件要核查什么、谁来出。
> 具体某项是否「必须」，取决于第 3 节的判定逻辑。

---

## 1. 四层分组

```
A. 海外供应商资料    —— 技术事实的源头（SDS / COA / TDS / PI / 包装证明 / 运输申报）
B. 中文合规文件      —— 中国法规要求的中文载体（中文 SDS / 中文标签 / 符合性声明 / 稳定剂说明）
C. 进口报关资料      —— 报关与贸易单证（发票 / 箱单 / 合同 / 提单 / 报关单 / 许可）
D. 运输与到货资料    —— 危险货物订舱与申报、国内段危货运输
```

分组的意义：**A 层缺 → 供应商的问题；B 层缺 → 进口商的问题（可委托翻译，但技术内容必须供应商确认）；C 层缺 → 双方配合；D 层缺 → 货代/承运人的问题。**

---

## 2. 文件清单与核查要点

### A. 海外供应商资料

| 文件 | 必须核查的内容 | 常见问题 |
|---|---|---|
| SDS（英文） | 16 节齐全；**版本号与修订日期**；第 3 节各组分 CAS 与精确百分比；第 14 节 UN 编号/类项/包装类别/海洋污染物；第 9 节物态 | 无版本号；稳定剂只写类别不给 CAS；第 14 节与浓度不匹配 |
| COA（按批） | 批号；检测项目；**检测方法**；规格上下限；实测值；签发人与日期 | 无方法；缺下游关键项；实测值跨阈值 |
| TDS / 规格书 | 关键指标表；储存条件；保质期；相容性 | 只有 SDS 没有 TDS，下游无法验证工艺适配 |
| PI（形式发票） | 品名规格；数量单价；**贸易术语唯一且前后一致**；装运港/目的港；HS 编码；原产国 | 同一份 PI 出现 CIF/FOB 混用；不列 HS 与港口 |
| 稳定剂/抑制剂说明 | 名称 + CAS + 精确添加量 + 「无其他功能性添加剂」声明 | 只写「stabiliser」；无签署 |
| UN 包装性能证书 | 包装代号；包装类别字母；生产年份；制造厂；性能试验结论 | 只有桶的照片，没有证书；标记照片模糊不可辨 |
| DGD / 危险货物申报 | UN、类项、PG、件数、毛净重、24h 应急电话 | 与 SDS 第 14 节不一致 |
| 原产地证书 | 与发票 HS 六位一致；原产地标准；直接运输证明 | 只写「Made in …」，不作原产地证书 |
| 生产商声明 | 生产厂名称地址；与 PI 抬头关系 | 抬头为贸易公司但无生产厂信息 |

### B. 中文合规文件

| 文件 | 必须核查的内容 | 依据 |
|---|---|---|
| 中文 SDS | 中文整册；与英文 SDS 逐节对应；16 节顺序与要素符合国标；第 14 节与运输分类一致 | 《危险化学品安全法》第 31 条；GB/T 16483；GB/T 17519 |
| 中文危险公示标签 | 中文品名；**成分及含量**；象形图；信号词；H 码与 P 码；供应商信息；**24 小时中文应急电话**；进口产品的境内责任人 | 同上第 31 条；GB 15258；GB 30000.1 |
| 符合性声明 | 采用海关公告附件格式；企业盖章；声明符合我国强制性规范 | 海关总署公告 2020 年第 129 号 |
| 稳定剂/抑制剂说明（中文） | 与 A 层同内容，可随报关提交 | 同上 |

> **注意**：中文 SDS/标签可以由进口商翻译制作，但**分类与 H/P 码的技术判断必须回到供应商**。
> 进口商自行「按经验」改分类，是常见的高风险操作。

### C. 进口报关资料

| 文件 | 核查要点 |
|---|---|
| 商业发票 | 与 PI 一致性；原产国；成交方式；币制 |
| 装箱单 | 件数、毛净重、体积、包装规格、唛头；与报关数量逻辑闭合 |
| 采购合同 | 规格与浓度公差（**不得跨监管阈值**）；SDS 版本；中文标签责任；检验与索赔条款；危险货物责任划分 |
| 提单 | 危险货物须载明 UN 编号与正确运输名称；收发货人；通知方 |
| 报关单/委托书 | 规范申报要素（按顺序）；危险类别；包装类别；UN 编号；包装 UN 标记 |
| 入境货物通关单 | 法检商品；与报关联动 |
| 许可证（如适用） | 当年目录比对结论；证面信息与报关一致 |
| 原产地证书/享惠声明 | 与 HS、发票一致；直接运输 |

### D. 运输与到货资料

| 文件 | 核查要点 |
|---|---|
| 危险货物订舱确认 | 提前期通常长于普货；注明 UN/类项/PG/包装 |
| 海运危险货物申报 | 与 DGD 一致；舱单一致 |
| 国内段危货运输 | 承运企业许可、车辆营运证、驾驶/押运人员资格 |

## 3. 「必须 / 视情形 / 建议」怎么定

不要凭习惯标「必须」。判定逻辑：

```
若 产品被判定为危险化学品（适用或视条件适用）
   → 中文 SDS、中文标签、符合性声明、稳定剂说明 = 必须
   → 危化品登记（进口企业侧）= 必须
若 产品被判为危险货物
   → UN 包装证明、DGD、订舱申报、危货提单 = 必须
若 拟享受协定税率
   → 原产地证书 + 直接运输证明 = 必须（否则按最惠国）
若 产品可能落入两用物项目录
   → 目录比对结论 = 必须；许可证 = 视比对结果
若 仅作技术参考/质量追溯
   → TDS、生产商声明 = 建议
```

**状态取值**（四态 + 不适用）：
`齐备 / 有但不完整 / 缺失 / 待定（需外部确认） / 过期或版本失效 / 不适用`

> **「待定」不是「不适用」。** 未取得书面结论的，只能标「待定」。

## 4. 交叉一致性检查（最容易漏的一步）

单份文件都合格，四份文件互相矛盾，一样过不了关。必查：

1. **CAS 一致**：SDS 第 3 节 = COA = PI = 标签
2. **浓度一致**：SDS = COA 实测 = PI = 标签「成分及含量」栏
3. **运输信息一致**：SDS 第 14 节 = DGD = 提单 = 报关填报
4. **贸易术语一致**：PI 货物栏 = PI 条款 = 合同 = 发票
5. **包装规格一致**：PI = 箱单 = 报关「包装规格」= 实际件数×单件净重 = 总净重
6. **语言合规**：中文 SDS / 标签是否为中文（不是「中英混排但关键项只有英文」）
7. **版本时效**：SDS 版本号、标准版本号（GB 是否现行）、证书有效期

任何一项不一致，都要单独列为一条问题，写清「谁改、改成什么」。

---

## 5. 上传件检查的标准输出

每份上传件都应产出三块内容：

```
1) 已提取字段      —— 字段名 / 值 / 在文件哪一页哪一节
2) 检查项          —— 检查内容 / 结果（通过/不通过/存疑/不适用）/ 说明
3) 结论            —— 可用 / 可用于修正后 / 不可用 + 一句话理由
```

**没有「已提取字段」的检查是不可复核的。** 必须写出值来自哪一节，方便他人回查。
