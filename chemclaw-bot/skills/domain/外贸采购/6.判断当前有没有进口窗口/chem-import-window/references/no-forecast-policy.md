# 不预测、不指令：表述边界

> 本 Skill 的输出是**口径对齐后的比较结果**，不是投资/采购指令，也不是价格预测。这条边界必须写进文档、页面、Excel 与口头汇报。

## 一、这条红线的来源

用户要的是"现在有没有进口窗口"，而不是"明天价格会怎样"。给出预测或指令会：

1. 把"数据核对"变成"投资建议"，责任性质完全不同；
2. 用有缺口的数据（运费未取得、税率待确认）去支撑确定性结论；
3. 一旦价格反向，报告的可信度连带被质疑。

## 二、措辞对照表

| 场景 | ✅ 可以说 | ❌ 不能说 |
|---|---|---|
| 当前价差 | "当前口径下国内含税现货比进口含税净成本高 1,033 元/吨" | "现在进口能赚 1,033 元/吨" |
| 方向判断 | "理论价差为正，说明国内价相对海外价偏高" | "进口窗口已打开，建议立即下单" / "建议观望" |
| 盈亏平衡 | "若汇率升到 8.1161，价差归零" | "汇率会涨到 8.11" / "等汇率到 8.11 再进" |
| 敏感性 | "海外报价若下跌 3%，价差扩大到 1,178 元/吨" | "报价还会跌 3%" |
| 历史 | "近 4 个可配对交易日价差在 1,000–1,139 元/吨区间" | "价差呈上升趋势，后市看涨" |
| 库存/开工等 | "10-19 华东主港库存 16.3 万吨，较上周 +4.8 万吨" | "库存累积说明价格要跌" |
| 机会 | "运费是当前最大未知项，取得实盘后价差可能移动 ±300 元/吨" | "建议压价 300 元/吨" |
| 合约价 vs 现货 | "MEGlobal 11 月 ACP 为 880 美元/吨，现货收盘 685 美元/吨" | "合约价高于现货，说明现货被低估" |

## 三、页面上的固定声明

每份 HTML 底部与每份 Excel「0-说明」都必须包含：

> 本页只做同一口径下的折算与比较，不构成进口交易指令，不预测价格走势。理论价差不等于可执行贸易利润。

`validate.js` 会扫描 case 数据与生成的 HTML，命中禁用词即报错：

```
必涨 / 必跌 / 将会上涨 / 将会下跌 / 建议买入 / 建议卖出 / 建议采购 / 建议囤货 /
目标价 / 后市看涨 / 后市看跌 / 大概率上涨 / 大概率下跌 / 抄底 / 抢货
```

## 四、"理论价差"与"可执行利润"的差距（必须写出来）

| 理论价差里**没有**的东西 | 量级 |
|---|---|
| 国际运费（若为 FOB 且缺运费） | 270–600 元/吨 |
| 港杂、报关、商检、仓储、短驳 | 50–120 元/吨 |
| 保险费 | 5–15 元/吨 |
| 资金成本（信用证/授信/锁汇，90 天） | 30–60 元/吨 |
| 计量损耗与质量索赔 | 0.1%–0.5% 货值 |
| 罐容与滞期 | 事件驱动 |
| 对手方与结算风险 | 定性 |

页面「07 理论价差 ≠ 可执行贸易利润」把这些逐条列出，并标注"是否已计入"。

## 五、自检问句

交付前问自己三句：

1. 我把任何一句话读给客户听，会不会被理解成"你在建议我买/卖"？
2. 我有没有在某个数字上用了"约""大概""预计"来掩盖缺口？
3. 如果明天价格反向走，我的报告里哪些句子会变成打脸？——把这些句子改掉。
