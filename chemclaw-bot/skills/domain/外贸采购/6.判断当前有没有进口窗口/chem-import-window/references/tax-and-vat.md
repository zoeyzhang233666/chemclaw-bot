# 关税与进口环节增值税

## 一、税率的四个层级（从高到低适用）

| 层级 | 何时适用 | 查询依据 |
|---|---|---|
| **普通税率** | 无最惠国待遇、原产地不明 | 《进出口税则》普通税率栏 |
| **最惠国税率（MFN）** | 有最惠国待遇（大多数贸易伙伴） | 《进出口税则》最惠国税率栏 |
| **暂定税率** | 国务院关税税则委员会每年公布，**低于**最惠国税率 | 每年《关税调整方案》附件 1「进口商品暂定税率表」 |
| **协定税率** | 有自贸协定且提供**原产地证书** | 公告附件「自由贸易协定和优惠贸易安排实施税率表」 |

**适用规则**：同时符合多项时取**最低**者；但暂定税率与协定税率并存时，通常适用二者中较低者，且协定税率必须凭原产地证书申报。

## 二、核验步骤（本项目实际做法）

1. 找到当年《关税调整方案》公告与其附件 1（进口商品暂定税率表，官方 PDF）。
2. 在 PDF 中检索该 HS 编码：
   - **在表内** → 有暂定税率，取表内值（通常远低于最惠国）；
   - **不在表内** → 按最惠国税率执行（要再去《进出口税则》查最惠国税率，不能凭记忆）。
3. 若原产地为自贸协定伙伴国（如沙特、东盟、韩国、澳大利亚），再查协定税率表 + 确认能否取得原产地证书。
4. 最终以**报关日税则 + 实际报关税号**为准，报告里写明"待报关确认"。

**示例（乙二醇 2026）**：在 2026 年暂定税率表中逐行核对 2905 章，可见 29011010 乙烷（2/1）、29031500（5.5/1）、29053990 1,3-丙二醇（5.5/3）、29054500 丙三醇（8/3）等，但 **29053100 未列入暂定税率表** → 乙二醇按最惠国税率执行。该税率的权威原值本次未取到，案例按 5.5% 处理并标记 `provisional: true`，引擎据此把口径等级降为 `fragile`。

## 三、进口环节增值税

```
进口环节增值税 = (关税完税价格 + 关税) × 增值税率
```

- 化工品适用 **13%** 标准税率（增值税一般纳税人）。
- 由**海关代征**，取得《海关进口增值税专用缴款书》后可作为进项税额抵扣。
- 计税价格里**不含**港杂费、境内运输费（这些按国内服务取得增值税专票另行抵扣）。

### 抵扣与不可抵扣

| 情形 | 处理 |
|---|---|
| 一般纳税人，进口货物用于应税项目 | **可抵扣** → 不构成成本，比较时用"含税净成本" |
| 小规模纳税人 / 非增值税纳税人 | 不可抵扣 → 计入成本 |
| 用于免税项目、集体福利 | 不可抵扣 → 计入成本 |

**这决定价差的正负**：本例 685 美元/吨 CFR 对应增值税 628 元/吨。若误把可抵扣增值税计入成本，价差会从 +1,033 直接变成 +405 元/吨。

## 四、其他可能涉及的税费（按品类判断）

| 项目 | 何时涉及 | 备注 |
|---|---|---|
| 消费税 | 仅限应税消费品（化工品基本不涉及） | —— |
| 反倾销税 / 反补贴税 | 特定原产地的特定商品 | **必须按原产地单独查**，影响可能是决定性的 |
| 保证金 / 关税保证保险 | 加工贸易、暂时进口 | 资金占用 |
| 港口建设费 / 检验检疫费 | 已并入"境内费用" | 属地口径不同 |

> **反倾销税是进口窗口判断里最容易被漏掉、又最能翻盘的一项。** 结论前必须查：该商品 + 该原产地是否在反倾销/反补贴名单内。

## 五、报关价与完税价格

海关以**成交价格**为基础审定完税价格，通常包含：

```
完税价格 = 货价 + 运抵中国境内输入地点起卸前的运输费 + 保险费 + 相关杂费
```

因此：
- CIF 报价 → 运保费已含，直接用；
- CFR 报价 → 保险费需并入完税价（金额小，可忽略但应注明）；
- FOB 报价 → 运费 + 保险都要并入，**这也是"FOB 缺运费就不能算"的法规原因**。

若存在买方佣金、特许权使用费、特殊关系影响成交价格等，需要调整，见 `cost-formulas.md` 的 `A` 项。
