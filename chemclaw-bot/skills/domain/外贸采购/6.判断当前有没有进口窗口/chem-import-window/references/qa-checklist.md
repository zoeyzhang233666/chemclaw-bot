# 交付前自检清单

## A. 数字级（错了就是硬伤）

- [ ] 海外报价的**术语**（FOB/CFR/CIF）与**日期**已写在页面上
- [ ] 汇率是**价格当日**的值，且标了来源（CFETS 中间价 / ECB 参照）
- [ ] 关税税率标了 HS 编码与"是否暂定/协定/待确认"
- [ ] 进口增值税按 (完税价+关税)×13% 计算，**未重复加价**
- [ ] 是否抵扣已明确，且国内与进口两端口径一致
- [ ] 境内费用：有实票则填，无实票则显示"未取得"而非 0
- [ ] 保险费：CIF 不计，CFR/FOB 已计（哪怕金额小）
- [ ] 价差 = 国内含税价 − 进口含税净成本（符号方向正确：>0 表示国内更贵）
- [ ] 三路一致性：Python 基准 = JS 引擎 = Excel 公式（`selftest.py` 通过）

## B. 口径级（错了结论就反了）

- [ ] 规格一致（含纯度/等级/关键指标）
- [ ] 日期一致，或已标注"近似"并降级
- [ ] 交货方式两端对齐（都是口岸/罐区，都无内陆配送）
- [ ] 数量口径已说明（船批 vs 罐区零单）
- [ ] 反倾销/反补贴税已按原产地核查
- [ ] 协定税率适用性已核查（原产地证书能否取得）
- [ ] 合约价与现货价没有混用

## C. 历史与图表

- [ ] 每个历史点都用**当日**报价 + 当日汇率 + 当期税率
- [ ] 缺日留空，**无任何插值/前值填充**
- [ ] 1 年/3 个月曲线若无数据，页面明确写"数据不足，不生成"而非画一条假线
- [ ] 图表坐标轴单位、双轴归属清楚（价差用右轴时要标明）
- [ ] 异常阶段是"描述"（相对中位数偏离），不是"预测"

## D. 表述级（越界就变性质）

- [ ] 全文无"建议买入/卖出/采购/囤货"
- [ ] 全文无"将上涨/将下跌/后市看涨看跌/目标价"
- [ ] 盈亏平衡写成"若……则价差归零"，不是"会走到……"
- [ ] 敏感性写成"若 X 变动，价差变为 Y"，不是"X 会变动"
- [ ] 「理论价差 ≠ 可执行利润」区块存在且列出未计入项
- [ ] 页面/工作簿含"不构成交易指令、不预测价格"的声明

## E. 工程级

- [ ] `validate.js` 通过（schema + 必填 + 禁用词）
- [ ] HTML 单文件、**零外部请求**（`qa_render.py` 已断言）
- [ ] Excel 无 `#REF!`/`#VALUE!`/`Err:xxx`，且**公式是活的**（改汇率会重算）
- [ ] 页面在 1560px 与 430px 下都无横向溢出
- [ ] 缺口清单条数 = 页面显示条数，且每条有"补法"
- [ ] 来源清单每条都有可点 URL 与含数字的原文摘录

## F. 一句话总结检查

把这段话读一遍，若有一句不成立就回去改：

> "在 [日期]，[商品] [规格] 的 [海外市场] [术语] 报价为 [X] 美元/吨；
> 按 [汇率] 与 [关税/增值税] 口径折算，到 [中国某港] 的进口含税净成本为 [Y] 元/吨；
> 同期 [国内区域] [交货方式] 含税现货价为 [Z] 元/吨；
> 理论价差为 [Z−Y] 元/吨，该数字的口径等级为 [full/indicative/fragile]，
> 尚缺 [缺口列表]，因此不能等同于可执行贸易利润，也不构成交易建议。"
