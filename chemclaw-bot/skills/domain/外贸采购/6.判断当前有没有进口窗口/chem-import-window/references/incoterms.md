# 贸易术语 → 到岸成本 转换矩阵

## 一、Incoterms 2020 与进口比价相关的六个术语

| 术语 | 卖方责任止于 | 谁付主运费 | 谁付保险 | 能否直接与国内价比较 |
|---|---|---|---|---|
| EXW | 卖方工厂 | 买方 | 买方 | 否（还缺出口报关与内陆段） |
| FCA | 交给买方指定承运人 | 买方 | 买方 | 否（同上） |
| **FOB** | 装上船（装运港） | 买方 | 买方 | 否，**需加运费+保险** |
| **CFR** | 到达目的港（不含保险） | 卖方 | 买方 | 否，**需加保险**（金额小） |
| **CIF** | 到达目的港（含保险） | 卖方 | 卖方（最低险别） | 接近，仍需注意险别与免赔 |
| DAP/DDP | 买方指定地点（含进口清关） | 卖方 | 卖方 | 接近，但需扣回内陆段 |

## 二、换算路径

```
EXW ─┬─ + 出口报关代理 + 内陆运输 → FOB
FCA ─┘

FOB ─┬─ + 国际运费        → CFR
     └─ + 国际运费 + 保险 → CIF

CFR ─── + 保险            → CIF

CIF ─── （已是到岸基准，直接进入完税价计算）

DAP/DDP ─ 扣回"港口→交货地"的内陆段 → 回到 CIF 基准
```

## 三、常见误用（按发生频率排序）

| 误用 | 后果 | 纠正 |
|---|---|---|
| 把 FOB 报价直接 × 汇率当到岸成本 | 少算 270–600 元/吨，虚增"窗口" | 必须加运费；没运费就登记缺口 |
| 把 CFR 当 CIF 用 | 少算保险 5–15 元/吨（量级小但口径不严） | 加 `CIF×110%×r_ins` |
| 用 CIF 价再算一遍运费 | 重复计算，压低进口成本 | CIF 已含运费，不再加 |
| 忽略 DAP/DDP 里的内陆段 | 进口成本虚高、国内价虚低（双重偏差） | 统一回到"口岸/罐区"基准 |
| 把"起运港 FOB 中国"当成进口 | 方向搞反 | 进口看的是"海外 → 中国" |

## 四、本 Skill 的默认基准

**比较基准 = 到中国主港（CIF 口径）⟷ 国内罐区自提（ex-tank）。**

理由：
1. 两者都**不含**中国境内配送，天然对齐；
2. 华东/华南主港的罐区自提是进口货实际流通的最常见形态；
3. 若企业需要送到厂，两端同时加"口岸→工厂"的内陆运费即可，不影响价差的相对判断。

## 五、术语与运费字段的对应关系

| `quote.term` | `freight.usd_per_ton` 是否参与计算 | 说明 |
|---|---|---|
| `CIF` | 否 | 运费保险已含 |
| `CFR` | 否（但计入保险） | 运费已含 |
| `FOB` | **是，必须有值** | 缺值 → 引擎返回 `blockers: NO_FREIGHT`，不出价差 |
| `EXW` | 是，且需补出口报关与内陆段 | 一般不用于进口比价 |

> 引擎在 `term = FOB` 且运费为空时**拒绝计算**，而不是按 0 计算 —— 这是刻意的设计。
