# 中国可核验数据源检索路径与坑

> 全部来自本 Skill 实际执行 MEG 案例时的踩坑记录（2026-10）。

## 一、国内现货价

| 来源 | 可取什么 | 坑 |
|---|---|---|
| 隆众资讯 `oilchem.net/seo-<id>-7.html` | 该商品的"全国主流市场均价"7 日/30 日序列（HTML 表格，可直接解析） | **是"全国主流市场均价"，不是单一区域单点价**；与华东实际成交可差 100–200 元/吨 |
| 隆众 日评（经 Mysteel 等转载） | 张家港/太仓等主港的买盘/卖盘/基差 | 原文正文常有会员墙（"注册为会员…15 天免费浏览"）；转载站有时给全 |
| 我的钢铁网 `nenghua.mysteel.com` | 隆众转载的日度行情 | 首页 403，但**具体文章 URL 可直接抓**；标题日期编码在 URL 里（`26101913` = 2026-10-19 13 时） |
| 生意社 `100ppi.com` | 各地贸易商挂牌、涨跌 | 有 JS 安全检查 cookie（`HW_CHECK`）需先拿 cookie 再请求；**低价挂牌多为工业级/中间商噪声**，不可与聚酯级比价 |
| 金联创 `chem.315i.com` | 企业出厂价、竞拍价 | 栏目结构常变 |
| 同花顺 iFinD 衍生页面 | 到岸价汇总、库存、期货 | 免费页只给摘要行，够做交叉验证 |

## 二、海外/进口价格

| 来源 | 可取什么 | 坑 |
|---|---|---|
| ChemPriceHub | 亚洲 CFR 中国日评、MEG/DEG 国内外价、库存、基差表 | 英文正文可读，**表格最可靠**；不同品种文章 slug 不同 |
| 同花顺 iNews "国际市场 XX 到岸价汇总" | 逐日"到岸价：中国/东南亚" | 只有摘要行（价格+涨跌），无完整口径说明 |
| CCFGroup `ccfgroup.com` | 日评、周报 | 正文需登录；标题与摘要可读 |
| MEGlobal / 生产商官网 | ACP 合约价 | **合约价 ≠ 现货**，只能作"合约-现货价差"参考 |
| ICIS / Platts | 权威评估价 | 付费 |
| 券商周报（国金、华泰等，`pdf.dfcfw.com`） | 产业链价格、开工率、装置动态、区域价差 | PDF 可下载可解析，但要**区分"研报观点"与"援引数据"** |

## 三、汇率

| 来源 | 可取什么 | 坑 |
|---|---|---|
| CFETS `chinamoney.com.cn` | 每日 9:15 中间价（官方） | 免费接口 `CcprHisNew` 有反爬：curl 带 `Referer` 可过；**Python urllib 会 403**；连拉多页会临时封 |
| Frankfurter API（ECB 参照汇率） | 历史日序列，免费无鉴权 | **不是 CFETS 中间价**，差 0.2%–0.5%（约 8–20 元/吨）；用作历史序列时必须在来源里标明 |

## 四、运费

| 来源 | 可取什么 | 坑 |
|---|---|---|
| 货代/船东询价 | 唯一真正可用的散装液货运价 | 需要实时问，公开渠道基本没有 |
| SCFI（上海航运交易所） | 集装箱运价指数 | **集装箱 ≠ 散装液货**，不能换算成吨运费；分航线数值在 JS 里，HTML 里取不到 |
| Baltic / Platts 化学品船运价 | 行业基准 | 付费；公开报道多为"某航线 $X/吨"的转述，只能作参照 |
| 行业博客/媒体 | 运价水平的**量级感** | 航线不同、船型不同，**不要当成本案例的运价** |

**结论**：运费要靠人工询价补齐。本 Skill 在拿不到时一律登记缺口。

## 五、税率

| 来源 | 可取什么 | 坑 |
|---|---|---|
| 财政部 gss.mof.gov.cn 公告附件 PDF | 当年《进口商品暂定税率表》逐行 | 站点 SSL 拦 Python；**用 curl 带 UA 可下载**；PDF 表格可 pdfplumber 解析 |
| 商务部 mofcom 政策转载 | 同上，带附件下载链接 | 同为反爬站点 |
| 《进出口税则》纸质/官方数据库 | 最惠国税率原值 | 需权威渠道 |
| 海关总署公告 | 反倾销/反补贴税率 | **必须按"商品+原产地"单独查**，极易漏 |

## 六、反爬通用处理

```python
# 1) 100ppi 的 JS 安全检查：先请求拿 cookie，再带 cookie 重试
# 2) gzip/br 响应体要显式解压（否则 19KB 二进制乱码）
# 3) 请求头加 Accept-Encoding: identity 可绕过压缩问题
# 4) SSL: UNEXPECTED_EOF_WHILE_READING 多为站点拦非浏览器 ClientHello → 改用 curl
# 5) PDF 必须用二进制方式下载（用文本方式保存会损坏、pdfplumber 报 header check 错）
```

## 七、证据留存规范

每一条被抓取的数字，都要在 `sources` 里留：

```jsonc
{
  "id": "S-XXX",
  "publisher": "隆众资讯",          // 是谁说的
  "title": "...",                   // 原文标题
  "date": "2026-10-19",             // 发布日
  "url": "https://...",             // 可点开
  "excerpt": "原文关键句（含数字）",   // 便于复核，不用再打开
  "tier": "A|B|C"                   // 官方 / 专业资讯或研报 / 转述或参照
}
```

**excerpt 要摘到"数字所在的那一句"**，不能只写"该文报道了价格"。
