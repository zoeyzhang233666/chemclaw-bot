# 进口成本折算公式全集

> 与 `scripts/lib/import-window-engine.js` 一一对应。改口径必须同时改引擎、本条文档与 Excel 公式，并跑 `selftest.py`。

## 记号

| 记号 | 含义 | 单位 |
|---|---|---|
| `P_q` | 海外报价 | USD/吨 |
| `P_prem` | 品质/船期升贴水 | USD/吨 |
| `F` | 国际运费 | USD/吨 |
| `r_ins` | 保险费率 | % |
| `FX` | 汇率 | CNY/USD |
| `r_duty` | 关税税率 | % |
| `r_vat` | 进口环节增值税率 | % |
| `C_inland` | 境内费用合计（港杂/报关/仓储/短驳） | 元/吨 |
| `C_other` | 其他费用 | 元/吨 |
| `R` | 国内含税现货价 | 元/吨 |

## 一、从三种术语入手

### 1) 拿到 FOB 报价

```
CFR = P_q + P_prem + F
保险 = CIF × r_ins × 110%       （按 CIF×110% 投保）
CIF = CFR + 保险
    ⇒ CIF = (P_q + P_prem + F) / (1 − r_ins × 1.1)
```

> 保险费按"到岸价×110%×费率"计，所以是隐式方程，解出上式。`r_ins = 0.2%` 时，保险 ≈ CFR × 0.22%。

### 2) 拿到 CFR 报价

```
CIF = P_q + P_prem + 保险，其中 保险 = CIF × r_ins × 1.1
    ⇒ CIF = (P_q + P_prem) / (1 − r_ins × 1.1)
```

### 3) 拿到 CIF 报价

```
CIF = P_q + P_prem        （保险与运费均已含）
```

## 二、人民币完税与税费

```
完税价格(CNY) = (CIF + A) × FX
    A = 完税价调整项（USD），如：境外运保杂费需并入、买方佣金、特许权使用费
        A = CIF × dutiable_adjust_rate / 100

关税        = 完税价格(CNY) × r_duty / 100
增值税基数   = 完税价格(CNY) + 关税
进口增值税   = 增值税基数 × r_vat / 100
```

## 三、两种成本口径（**不要混用**）

### A. 进口含税净成本（与国内含税价比较用）

```
净成本 = 完税价格 + 关税 + C_inland + C_other
              + (增值税不可抵扣时，再加 进口增值税)
```

### B. 进口全口径付现（资金测算用）

```
付现 = 完税价格 + 关税 + 进口增值税 + C_inland + C_other
```

> A 用于**报价比较**，B 用于**资金占用**。混用是最高频的错误。

## 四、价差

```
理论价差      = R − 净成本
价差占国内价   = 理论价差 / R × 100%
价差占进口成本 = 理论价差 / 净成本 × 100%
```

**符号约定**：价差 > 0 表示"国内更贵 → 理论上进口有空间"；价差 < 0 表示"国内更便宜 → 理论上无空间"。它**不是**利润，也不是交易建议。

## 五、盈亏平衡（数学零点，非预测）

价差对各项的敏感度：

| 变量 | 每单位变化引起的净成本变化 |
|---|---|
| 汇率 +1% | 净成本 × 约 0.99%（因为境内费用不随汇率变） |
| 海外报价 +1 USD/吨 | `FX × (1 + dutiable_adjust) × (1 + r_duty/100)` 元/吨 |
| 运费 +1 USD/吨（FOB 口径） | 同上 |
| 关税 +0.5 个百分点 | 完税价格 × 0.005 元/吨 |

令价差 = 0 反解，即得：
- 汇率盈亏点 `FX*`；
- 海外报价盈亏点 `P*`（及其涨跌幅）；
- 运费盈亏点 `F*`。

> 这些点是"当前参数下的零点位置"，**不是价格预测**。表述必须写"若……则价差归零"，不能写"汇率将走到……"。

## 六、逐项影响量级（经验参考，非本案例数据）

以 6,000 元/吨级液体化工品为例：

| 项目 | 典型量级 | 占货值 |
|---|---|---|
| 海外报价波动 ±3% | ±120~150 元/吨 | 3% |
| 汇率 ±3% | ±140~160 元/吨 | 2.5% |
| 国际运费 40–90 USD/吨 | 270–600 元/吨 | 5–10% |
| 关税 5% / 5.5% | 230 / 250 元/吨 | 4% |
| 进口增值税 13%（可抵扣） | 620~640 元/吨（**不计入成本**） | 现金流占用 |
| 港杂/报关/仓储/短驳 | 50–120 元/吨 | 1–2% |
| 资金成本（90 天） | 30–60 元/吨 | 0.5–1% |

## 七、Excel 与引擎的一致性

`2-进口成本折算` 工作表逐行复刻上面的公式；`9-引擎校验` 把引擎结果并列，差值 >0.02 元/吨即报"复核"。

- `check_xlsx.py` 会用 LibreOffice 真正重算一遍，确认公式不是死值；
- `cross_check.js` 用独立 Python 实现重算，确认引擎没有算错。

三路（Python 基准 / JS 引擎 / Excel 公式）必须一致，才算通过。
