# 历史序列对齐规则

> 目标：画出一条**每个点都站得住**的价差序列。宁可只有 4 个点，也不要 30 个假点。

## 一、一个价差点需要同时具备的 5 个要素

| # | 要素 | 缺失后果 |
|---|---|---|
| 1 | 当日海外报价（同术语、同规格） | 无价差 |
| 2 | 当日国内现货价（同规格、同交货地、含税） | 无价差 |
| 3 | 当日汇率（USD/CNY） | 无价差 |
| 4 | 当期生效的关税/增值税税率 | 无价差（禁止用当前税率倒推） |
| 5 | 当期运价（仅 FOB/CFR 口径需要） | 标记"参照口径"，降级 |

引擎 `buildHistory()` 逐日检查这 5 项，缺任一者输出 `status: "gap"` 并写明 `gap_reason`。

## 二、五条硬规则

### 规则 1：同日配对，不跨日借用

海外价 10-16、国内价 10-19 → **不配对**。若必须近似，须：
- 标注 `date_match: false`；
- 口径等级从 `indicative` 降一档；
- 在页面明示"价差仅作同期近似"。

### 规则 2：缺日留空，不插值

禁止线性插值、前值填充、样条平滑。周末与节假日无报价是正常的，图上就断开。

**为什么**：价差本身波动 50–200 元/吨，插值出来的点看起来"平滑"，会让人误以为市场很平稳，属于用方法制造的信息失真。

### 规则 3：税率按生效版本取用（`tax.profiles[]`）

```jsonc
"tax": { "profiles": [
  { "effective_from": "2026-01-01", "duty_rate": 5.5, "vat_rate": 13 },
  { "effective_from": "2025-01-01", "duty_rate": 5.5, "vat_rate": 13 }
]}
```

- 取 `effective_from <= 该日` 的最新一版；
- 若该日**早于所有版本**，引擎返回 `NO_TAX` → 该点不出价差（而不是借用后来的税率）。

### 规则 4：汇率序列精确匹配

`fxOnDate()` 只做**精确匹配**，找不到就返回 null。禁止"用最近一天的汇率顶上"——汇率 ±3% 的影响量级与价差本身相当。

### 规则 5：运费必须区分"实盘"与"参照"

| `freight.quality` | 含义 | 历史点标记 |
|---|---|---|
| `actual` | 货代/船东对同航线的实盘报价 | 正常 |
| `proxy` / `reference` | 其他航线或指数的参照值 | `reference_only: true`，图上用虚线/淡色 |
| `simulated` | 模拟值 | 强制 `reference_only`，页面显著标注"模拟" |
| `missing` | 未取得 | FOB 口径当日不出价差 |

## 三、历史窗口与实际可得性

| 用户要的窗口 | 现实条件 | 输出 |
|---|---|---|
| 近 30 天 | 需 30 个可配对点（约 22 个交易日） | 有则画，无则只画可得点并说明 |
| 近 3 个月 | 同上 | 同上 |
| 近 1 年 | 需一年海外 + 国内 + 汇率三序列 | 若无，页面明示缺口，不画 |

**做法**：页面永远保留 30 天/3 个月/1 年三个选项，但内容由数据决定。数据不足时显示"当前可配对交易日 N 个"，并给出补齐路径（灌数据即自动延长，无需改页面）。

## 四、数据接入清单（补齐长序列时要什么）

| 序列 | 建议来源 | 字段 |
|---|---|---|
| 海外 CFR 中国 日/周 | 隆众、CCF、ICIS、Platts、iFinD | 日期、CFR 价、规格、评估机构 |
| 国内现货 日 | 隆众、卓创、生意社、企业实际成交 | 日期、价格、含税、交货方式、单点市场 |
| 汇率 日 | CFETS 中间价（官方）、ECB 参照汇率 | 日期、USD/CNY |
| 运价 | 货代月度/航次报价、Platts 化学品船运价 | 日期、航线、船型、批量、USD/吨 |
| 税率 | 每年《关税调整方案》+ 反倾销公告 | 生效日、税率、依据文号 |

把这些按 `schema/data.schema.json` 的 `quotes_hist` / `domestic_hist` / `fx.rows` / `freight.series` 灌入，引擎自动扩展曲线。

## 五、异常阶段识别

`anomalyPhases()` 用**滚动中位数偏离**做描述性识别：

```
deviation = (当期价差 − 邻近 ±5 点中位数) / |中位数| × 100%
|deviation| ≥ 25% → 标记为异常偏高/偏低
```

这是**描述**，不是判断，也不是预测。点太少（<5 个可配对点）时引擎不触发异常标记，并在页面说明"当前可用点位太少"。
