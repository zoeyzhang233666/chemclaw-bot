# 内外盘可比性检查

> 价差算得再准，口径不对也是错答案。**先过这 9 项，再谈价差。**

## 检查总表

| # | 检查项 | 通过标准 | 不通过怎么办 |
|---|---|---|---|
| 1 | 产品规格 | 牌号/纯度/等级完全一致 | 不同规格 → **不可比**，必须换同规格报价，或按品质差价折算后注明 |
| 2 | 价格日期 | 海外与国内价格**同日** | 差 1–2 日可作"近似"，须降级为 `indicative` 并写明；超过 3 日不得出价差 |
| 3 | 贸易术语 | FOB/CFR/CIF 可识别且能折算到 CIF | 术语缺失 → 不可换算；FOB 缺运费 → **不给价差** |
| 4 | 国内价含税 | 明确标注"含 13% 增值税" | 不含税 → 先 ×1.13 换算，并确认国内端进项抵扣条件 |
| 5 | 增值税抵扣 | 进口增值税能否抵扣已明确 | 未定 → 两套口径都算，取保守的一侧做结论 |
| 6 | 交货地点/方式 | 两端都到"口岸/罐区"，都不含内陆配送 | 国内是送到价 → 要么扣回配送费，要么把进口成本也加到厂 |
| 7 | 交易数量/包装 | 同为散装船批，或已说明零单溢价 | 船批 vs 罐区零单 → 标注价格基础不同 |
| 8 | 汇率 | 用**价格当日**的 USD/CNY，注明来源 | 无当日汇率 → 该日不出价差（禁止插值） |
| 9 | 运费 | 有当期、同航线、同船型的运价，或 CIF 已含 | 无运价 → 登记缺口；FOB 不得计成本 |

页面「01 口径核对」把 1–9 项自动跑一遍，并给出 `comparable / comparable_with_caveats / needs_info / blocked` 四级判定。

## 逐项详解

### 1. 产品规格

同一个名字，不同等级完全不可比。以乙二醇为例：

| 等级 | 典型用途 | 与聚酯级价差 |
|---|---|---|
| 聚酯级（≥99.9%，UV 透过率达标） | 聚酯/涤纶 | 基准 |
| 纤维级 | 部分纤维 | 与聚酯级接近，需看具体指标 |
| 工业级 / 防冻液级 | 冷却液 | 低 300–800 元/吨 |
| 回收料 / 副产 | —— | 低 1,000 元/吨以上且成分不稳 |

**做法**：把 `quote.spec` 与 `domestic.spec` 都写成完整描述字符串（含纯度与关键指标），不一致时引擎直接判 `fail`。

### 2. 价格日期

- 海外指数通常按**亚洲工作日**评估，中国遇节假日（如国庆 10-01~10-07）期间可能无评估值。
- 国内现货按**中国工作日**报价。
- 因而"同日"经常凑不齐：这很正常，**如实留空**比硬凑一个数强得多。

**判定**：`quote.date == domestic.date` 才算 pass；否则 warn/fail。

### 3. 贸易术语

只有 CFR / CIF 能直接进入"到岸成本"。FOB 必须先有运费。EXW 还缺出口报关与内陆运输，一般不作为进口比价起点。

### 4 与 5. 含税口径与抵扣（最容易出错的一项）

国内现货价 = 不含税价 × 1.13（增值税一般纳税人）。

进口环节增值税 = (完税价格 + 关税) × 13%，由海关代征，取得**海关进口增值税专用缴款书**后可抵扣。

所以正确的比较是：

```
国内含税价  ⟷  进口含税净成本（= 完税价 + 关税 + 境内费用，不含可抵扣的进口增值税）
```

**错误做法**：`国内含税价 − (完税价 + 关税 + 增值税 + 费用)` —— 多算了 13% 的增值税（本例 628 元/吨），结论会从"有窗口"翻成"没窗口"。

**若进口方不能抵扣**（小规模纳税人、非增值税一般纳税人、货物用于免税项目）：增值税变成真实成本，须计入；同时国内端对应的进项抵扣也不存在，两边都要按"含税总成本"口径重算。

### 6. 交货地点与方式

国内现货的常见报价方式：

| 方式 | 含义 | 与进口到岸价的差 |
|---|---|---|
| 出厂价 / ex-works | 工厂门口交货 | 进口还多一段港口→工厂运输 |
| 罐区自提 / ex-tank | 买方到罐区提货 | **与到岸价最接近**（都不含内陆配送） |
| 库提 / 送到 / DAP / DDP | 卖方送到买方仓库 | 进口成本要加上同段运费才可比 |

本 Skill 的默认比较是 **"CFR 中国主港" ⟷ "华东罐区自提"**，两端都不含内陆配送，这一点是对齐的。

### 7. 数量与包装

5,000 吨船批的到岸价，与 100 吨罐区零单的价格基础不同：后者含贸易商的持仓成本、资金与风险溢价（通常 50–150 元/吨）。大宗散装液体尤其明显。

### 8. 汇率

必须用**价格当日**的 USD/CNY 中间价或海关适用汇率：

- 中间价：CFETS 每交易日 9:15 公布；
- 海关计征：按报关日/当月适用汇率，与中间价有 ±0.3% 左右偏差，折合 8–20 元/吨；
- **禁止**用今天汇率套上周的价格：汇率 ±3% 时价差可移动 ±150–300 元/吨。

### 9. 运费

只有三种可接受来源：

1. 供应商 CIF/CFR 报价（已含）；
2. 货代/船东对**同航线、同船型、同批量**的实盘报价（记录询价日）；
3. 公开运价指数（仅限该品类对应市场 —— 集装箱指数 SCFI 不能用于散装液货）。

"某航线的参考值""大概几十美金"都不行。宁可留缺口。

## 判定等级对照

| 等级 | 含义 | 页面表现 | 可否对外汇报 |
|---|---|---|---|
| `full` | 9 项全过 | 绿色徽章 | 可以，但仍需声明非交易建议 |
| `indicative` | 关键项齐，有口径不一致 | 蓝色徽章 | 可以，须同时说明保留项 |
| `fragile` | 关键项靠假设/待确认（如税率、运费参照值） | 黄色徽章 | 仅内部参考 |
| `none` | 缺关键项，算不出 | 红色徽章 + 明示原因 | **不得给出价差** |
