# 敏感性分析与变化归因

## 一、敏感性：改什么最"咬"价差

本 Skill 默认做三个单因素情景：

| 因素 | 情景范围 | 为什么选这个范围 |
|---|---|---|
| 汇率 | ±3%、±1.5% | 一个季度常见的波动带（本例 6.69 → 6.72 已在 0.5% 内） |
| 海外报价 | ±3%、±1.5% | 一周内 CFR 中国常见波动 3–5% |
| 国际运费 | ±20%、±40%（基准：现有运费）或 ±10/20 美元/吨 | 地缘事件下运价可翻倍 |

输出：
1. **单因素曲线**：横轴变动幅度，纵轴价差，两条线（汇率、海外价）+ 零轴；
2. **龙卷风图**：按"价差波动跨度"排序，一眼看出谁是主要风险源；
3. **盈亏平衡点**：价差归零时的汇率 / 报价 / 运费。

### 龙卷风图的读法

```
汇率 ±3%        ██████████  跨度 290 元/吨
海外报价 ±3%     ██████████  跨度 290 元/吨
运费 ±10 USD     ▏           跨度 0（本例无运费）
```

跨度越大，越需要把该参数确认到实处。

## 二、盈亏平衡（表述边界！）

计算结果形如："汇率需达 8.1161 时价差归零"。

**这只能表述为**：
- ✅ "在当前参数下，汇率需上行至 8.1161 才能让价差归零；这相当于本币贬值约 21%。"
- ✅ "海外报价需下跌约 X% 价差才归零。"

**绝不能表述为**：
- ❌ "汇率会涨到 8.11"
- ❌ "等报价跌到 590 美元再进"
- ❌ "价格即将下跌"

盈亏平衡是**数学零点**，不是预测，也不是目标价。

## 三、变化归因（`Δ价差` 拆解）

两个相邻可配对点 a → b：

```
Δ价差 = Δ国内价 − Δ进口成本
Δ进口成本 ≈ FX_a × (1 + r_duty) × Δ海外报价      （价格项）
          + 海外报价_b × (1 + r_duty) × Δ汇率      （汇率项）
          + Δ运费 × FX × (1 + r_duty)             （运费项，若有）
```

本 Skill 采用**单向近似**（用 a 期的汇率配 Δ报价，用 b 期的报价配 Δ汇率），并在页面注明"未做精确分解"。

### 为什么不用更"精确"的方法

- 两因素交互项（Δ报价×Δ汇率）量级很小（<1 元/吨），不影响结论；
- 简单拆解更容易被业务方看懂和复核；
- 复杂分解需要更多历史点，本例只有 4 个。

### 归因的正确用法

```
10-15 → 10-16：价差 1,063 → 1,033（−30）
  海外报价 685 → 685（0 USD）
  汇率 6.6910 → 6.6862（−0.0048，人民币小幅升值 → 进口成本略降）
  国内现货 5,898.33 → 5,865.33（−33）
→ 主要驱动是国内现货下跌，汇率贡献 +32 元/吨（抵消了一部分）
```

**只说事实与算术，不说"所以价格会继续跌"。**

## 四、常见错误

| 错误 | 问题 |
|---|---|
| 只做汇率敏感性 | 忽略运费波动 —— 在地缘事件下运费才是主因 |
| 敏感性区间拍脑袋定 ±10% | 与商品实际波动不匹配，结论会误导 |
| 把敏感性结果当成"安全区间" | 它只是"参数动到这个数、价差会这样"的映射 |
| 用敏感性反推"目标价" | 等同于价格预测，越过红线 |
| 归因时混用不同期汇率 | 拆出来的各项加起来对不上 Δ价差 |
