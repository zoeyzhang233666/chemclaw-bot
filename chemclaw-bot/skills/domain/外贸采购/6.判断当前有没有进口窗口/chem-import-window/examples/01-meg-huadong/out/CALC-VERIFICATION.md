# 计算验证报告 · 进口乙二醇（MEG）→ 华东

- 案例：`examples/01-meg-huadong`
- 基准日：**2026-10-16**（海外 CFR 中国价与华东现货唯一同日可得的一天）
- 生成日：2026-10-20
- 引擎：`scripts/lib/import-window-engine.js` v1.0.0

> 本报告只做同一口径下的折算与比较，**不构成进口交易指令，不预测价格走势**。理论价差不等于可执行贸易利润。

## 二、折算过程（逐步可复核）

| 步 | 项目 | 公式 | 结果 |
|---|---|---|---|
| ① | 海外报价（CFR） | — | 685.00 USD/吨 |
| ② | CIF | CFR（保险按 0 计，缺口） | 685.00 USD/吨 |
| ③ | 关税完税价格 | 685 × 6.6862 | **4,580.05 元/吨** |
| ④ | 关税 | 4,580.05 × 5.5% | **251.90 元/吨** |
| ⑤ | 进口环节增值税 | (4,580.05 + 251.90) × 13% | 628.15 元/吨（**可抵扣，不计入成本**） |
| ⑥ | 境内费用 | 未取得（按 0） | 0 元/吨 |
| ⑦ | **进口含税净成本** | 4,580.05 + 251.90 + 0 | **4,831.95 元/吨** |
| ⑧ | 全口径付现（参考） | ⑦ + 628.15 | 5,460.10 元/吨 |
| ⑨ | 国内含税现货 | — | **5,865.33 元/吨** |
| ⑩ | **理论进口价差** | 5,865.33 − 4,831.95 | **+1,033.38 元/吨** |
| ⑪ | 价差占国内价 | 1,033.38 ÷ 5,865.33 | **+17.62%** |
| ⑫ | 价差占进口成本 | 1,033.38 ÷ 4,831.95 | +21.39% |

**关键校验**：若误把可抵扣增值税计入成本，价差会变成 5,865.33 − 5,460.10 = **+405.23 元/吨**，与 +1,033.38 相差 628.15 元/吨。这正是"含税 vs 不含税"口径错误造成的典型偏差。

## 三、三路交叉校验

同一公式由三套独立实现计算，必须一致（容差 0.02 元/吨）：

| 实现 | 完税价格 | 关税 | 增值税 | 净成本 | 价差 |
|---|---|---|---|---|---|
| JS 引擎 | 4,580.0470 | 251.9026 | 628.1534 | 4,831.9496 | 1,033.3804 |
| Python 基准 | 4,580.0470 | 251.9026 | 628.1534 | 4,831.9496 | 1,033.3804 |
| Excel 公式（LibreOffice 重算） | 4,580.0470 | 251.9026 | 628.1534 | 4,831.9496 | 1,033.3804 |

- `cross_check.js`：**382 项检查全部一致**（含 360 个参数组合场景：FOB/CFR/CIF × 5 档运费 × 4 档关税 × 3 档汇率 × 2 档抵扣）
- `check_xlsx.py`：106 条活公式、0 个公式错误；「9-引擎校验」页 5 项全部"一致"
- **活公式验证**：把 Excel 汇率从 6.6862 改为 6.8868（+3%），净成本 4,831.95 → 4,976.92、价差 1,033.38 → 888.41，证明公式会随输入重算，而不是先算好再写死。

**纪律说明**：

- 近 30 天 / 3 个月 / 1 年视图在页面上保留，但**只显示这 4 个可配对点**；1 年连续序列在公开渠道不可得，不生成曲线。
- 只有 4 个可配对点 < 5，引擎**不触发异常阶段识别**（页面明示"可用点位太少"）。

## 六、变化归因（10-15 → 10-16）

## 九、验证结论

1. **折算正确**：三路独立实现（JS / Python / Excel）在 382 项检查上完全一致。
2. **口径正确**：含税口径两端对齐（国内含税价 ⟷ 进口含税净成本），可抵扣增值税未计入成本。
3. **历史诚实**：4 个可配对点、1 个缺日留空、无插值、无倒推；1 年曲线明确标注不可得。
4. **表述守界**：全文无价格预测、无交易指令；盈亏平衡标注为"数学零点"并给出可达性判断。
5. **降级可靠**：另有 `examples/02-fob-no-freight` 证明在"FOB 无运费 + 无历史序列"时，页面与 Excel 都拒绝给出价差，并说明原因。

> **最终提醒**：+1,033 元/吨 是"同一天、同一口径下国内价相对进口到岸成本高出多少"，**不是**可执行贸易利润。扣除资金成本、计量损耗、罐容约束、对手方风险与议价空间后，实际空间可能只剩一半甚至更少。
