# 更新日志

## 1.0.0 — 2026-10-21

首个可用版本。

### 新增

**八项核心能力**
1. 四类汇率取值与报价方向确认（市场汇率 / 中间价 / 银行购汇价 / 海关计征汇率）
2. 1 年 / 3 年 / 5 年真实历史序列、趋势图与当前分位
3. ±1% / ±3% / ±5% 人民币付款额敏感性
4. 到厂成本影响（含关税、增值税、人民币固定费用的稀释效应）
5. 多汇率情景下的毛利额与毛利率
6. 盈亏平衡汇率（0% 与指定目标毛利）
7. 分批付款按批次、按结算日的敞口矩阵
8. 四类汇率口径的清晰区分与法规依据

**交付物**
- 交互式 HTML 计算器（单文件、离线可用、深色主题）
- 7 页签 Excel 工作簿，**293 个可运行公式**
  - `01 参数与汇率` 唯一输入区（A 交易信息 / B 四类汇率 / C 到厂成本 / D 销售毛利 / E 分批付款）
  - `02 付款额与敏感性`
  - `03 到厂成本`
  - `04 毛利与盈亏平衡`
  - `05 分批付款`
  - `06 历史汇率与分位`
  - `07 汇率口径与法规`
- `案例说明.md`：MEG 沙特 100 万美元案例完整叙述，每个数字可回溯

**脚本**
- `fx_engine.py`：计算引擎，全参数化，无硬编码币种
- `build_html.py`：HTML 生成
- `build_xlsx.py`：Excel 生成（xlsxwriter，写入活公式）
- `xlsx_recalc.py`：纯 Python Excel 公式求值器（无第三方依赖）
- `verify_calc.py`：三层校验，**32 项断言**
- `cdp_check.mjs`：HTML 无头 DOM 校验（25 项断言）

**数据**
- `data/fx_real_data.json`：1,743 个交易日真实汇率序列，2019-12-31 → 2026-10-19
- 覆盖 USD/EUR/GBP/JPY/SGD/AUD/KRW/INR/HKD → CNY，及 SAR（挂钩折算）

### 已修复（开发期问题，记录以备后人）

| 问题 | 根因 | 修复 |
|---|---|---|
| Excel 敏感性表引用错行 | 公式里用 0-based 的 `{r}` | 统一改为 `{r+1}` |
| 03 表 `B6 = B6*B7` 循环引用 | `RATE_CELL` 跨表未加表名前缀 | 引入 `RATE_X = "'02 付款额与敏感性'!" + RATE_CELL` |
| 03 表成本构成全部自我引用 | `items` 定义位置早于批量替换脚本的起始行 | 单独修正 |
| 盈亏平衡算出 3.19 等荒谬值 | 基准毛利已低于目标仍强行求解 | 增加 `applicable: False` + 原因说明 |
| **基准毛利率算成 5.73% 而非 1.87%** | `breakeven_rate()` 漏掉非汇率成本 `OC` | 增加 `other_fixed_cny` 参数并入 `NF`；Excel 同步改为 `((LC − FX0) + OC)` |
| 分位恒为 0% | 日期写成文本，`COUNTIFS` 日期比较失效 | 改为 `write_datetime` 真日期类型 |
| 目标毛利率显示 500% | 写入 `5.0` 却按百分比格式显示 | 统一 `/100.0` + `0.0%` 格式 |
| 公式单元格全部返回 `None` | 求值器 `t` 属性分支优先于公式检测；`evaluate` 用 3 元组索引 2 元组字典 | 提前 `f is not None` 判断；分离 `cell_key` 与 `stack_key` |
| `IF` 分支空串参与算术报错 | `_n` 对空串抛异常 | 空串按 0 处理；补充 `ISNUMBER` / `ISTEXT` |
| `B1=""` 比较抛 `TypeError` | 数字与文本直接比较 | 重写 `_compare` / `_rank`，按 Excel 跨类型排序规则 |
| `round(0.5)` 得 0 | Python 银行家舍入 | 改用 `Decimal` + `ROUND_HALF_UP` |

### 设计决策

- 汇率统一按 `FC_CNY`（1 外币 = X 人民币）内部表示，`CNY_FC` 输入自动取倒数
- 基准口径优先级 `bank` > `pboc` > `market`，缺失时降级并告警
- 增值税默认 `deductible`（不计入成本）
- 徽标体系：🟢 真实 / 🟣 模拟 / 🟡 演示
- 全程无汇率预测、无避险产品推荐
- 只有采购金额时，强制跳过毛利模块
