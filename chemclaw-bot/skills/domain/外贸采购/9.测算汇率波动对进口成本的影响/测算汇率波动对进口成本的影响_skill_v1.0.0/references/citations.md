本 Skill 所有数据、法规、税率均可追溯。以下为完整出处清单。

## 一、法规与官方规则

### 1.1 海关计征汇率

> 《中华人民共和国海关进出口货物征税管理办法》
> **海关总署令第 272 号**
> 公布日期：2024-10-28｜施行日期：2024-12-01｜同时废止：海关总署令第 124 号
> **第十三条**：海关每月使用的计征汇率为上一个月第三个星期三中国人民银行授权中国外汇交易中心公布的人民币汇率中间价，第三个星期三非银行间外汇市场交易日的，顺延采用下一个交易日公布的人民币汇率中间价。

- 用途：确定 `customs` 口径汇率的适用日期
- 实现：`fx_engine.customs_rate_date()` / `third_wednesday()` / `next_trading_day()`
- 校验：`fx_engine.py --demo` 第 4–6 项

### 1.2 银行间外汇市场浮动幅度

> 《中国人民银行关于扩大外汇市场人民币兑美元交易价浮动幅度的公告》
> **中国人民银行公告〔2014〕第 5 号**
> 自 2014-03-17 起，银行间即期外汇市场人民币兑美元交易价浮动幅度由 1% 扩大至 **2%**；
> 外汇指定银行为客户提供当日美元最高现汇卖出价与最低现汇买入价之差，由 2% 扩大至 **3%**。

- 用途：解释 `bank`（现汇卖出价）与 `pboc`（中间价）之间为何存在点差
- 引用位置：`references/rate-basis.md` 第 3 节

### 1.3 增值税

> 《中华人民共和国增值税暂行条例》及财政部、税务总局相关公告
> 进口环节增值税 = (关税完税价格 + 关税 + 消费税) × 增值税率
> 一般货物适用税率 **13%**（自 2019-04-01 起）

- 用途：`vat_rate` 默认 13%，`vat_mode = deductible` 时不计入到厂成本

### 1.4 消费税

> 《中华人民共和国消费税暂行条例》
> 从价计征：应纳税额 = 完税价格 × 消费税率

- 用途：`cdc_rate` 参数；MEG 等化工原料不属应税消费品，`cdc_rate = 0`

## 二、汇率数据源

| 项目 | 内容 |
|---|---|
| 发布机构 | 中国人民银行授权中国外汇交易中心 |
| 接口 | `https://www.chinamoney.com.cn/r/cms/www/chinamoney/data/fx/ccpr.json` |
| 发布时点 | 每交易日 **9:15** |

| 项目 | 内容 |

## 四、历史序列说明

| 项目 | 内容 |
|---|---|
| 文件 | `data/fx_real_data.json` |
| 区间 | 2019-12-31 → 2026-10-19 |
| **观测数** | **1,743 个交易日** |
| 覆盖币种 | USD EUR GBP JPY SGD AUD KRW INR HKD → CNY，及 SARCNY |
| 构建规则 | 仅保留全部币种同日有数据的交易日；**不插值、不平滑、不填补** |
| 统计量 | 最低 **6.3104**（2022-02-28）；最高 **7.3498**（2025-04-09）；均值 **6.9113** |

### 4.1 分位结果（当前中间价 6.7200）

| 区间 | 分位 |
|---|---|
| 近 1 年 | 13.7% |
| 近 3 年 | 4.6% |
| 近 5 年 | 16.6% |
| 全样本 | 27.0% |

### 4.2 分位结果（当前市场汇率 6.6807）

| 区间 | 分位 |
|---|---|
| 近 1 年 | 0.4% |
| 近 3 年 | 0.1% |
| 近 5 年 | 11.9% |
| 全样本 | 22.9% |

> 算法：`(区间内 ≤ 当前值的观测数 − 1) / (区间内观测数 − 1)`，即**排除当前观测本身**，避免当前值抬高自己的分位。
>
> 90 天前（2026-07-22）ECB 报价 6.7730，当前 6.6807，变动 **−1.36%**。

## 六、数据可达性说明

以下域名在部分网络环境下存在 **TLS 指纹阻断**，`urllib` / `curl` 返回 `SSL: UNEXPECTED_EOF_WHILE_READING` 或 `curl exit 35`：

- `pbc.gov.cn`
- `safe.gov.cn`
- `customs.gov.cn`
- `boc.cn`
- `mofcom.gov.cn`
- `gov.cn`
- `gss.mof.gov.cn`

**应对**：改用可达镜像（hsbianma.com、zhengdao.ai、flfgsc.cn）或通过浏览器取数，并如实标注实际来源。**不因取不到而编造数字。**

## 七、引用格式建议

在正式报告中引用本 Skill 的数据时，建议格式：

> 人民币汇率中间价 6.7200（中国外汇交易中心，2026-10-20 09:15）；
> 即期市场参考汇率 6.6807（欧洲央行欧元参考汇率，2026-10-19，经 EUR 交叉折算）；
> 计征汇率适用依据《海关总署令第 272 号》第十三条。
