方向关系（务必确认）：汇率以「1 单位外币 = x 人民币」标价。x 上升 = 外币升值 / 人民币贬值 → 同样金额的外币需要更多人民币，付汇成本增加； x 下降 = 人民币升值 → 付汇成本下降。金额变动严格等于 外币金额 × 汇率 × 变动幅度。

计算公式与口径说明

// 0. 方向约定：x = 1 单位外币折合人民币（CNY per FC） 基准人民币付款 = 外币金额 × x 敏感性 = 外币金额 × x × (1 + Δ%) // Δ%>0 表示人民币贬值 变动额 = 外币金额 × x × Δ% // 1. 海关计征汇率（海关总署令第272号 第十三条） 计征汇率 = 上一个月 第三个星期三 中国人民银行授权中国外汇交易中心公布的 人民币汇率中间价；该日非交易日则顺延下一交易日 // 2. 完税价格（以 CIF 为基数，按计征汇率折算） 完税价格 = (货值 + 运费 + 保费 + 其他予计入费用) × 计征汇率 关税 = 完税价格 × 关税率 增值税 = (完税价格 + 关税 + 消费税) × 增值税率 // 3. 人民币到厂成本 到厂成本 = 货值×x + 运费×x + 保费×x + 关税 + 消费税 + 增值税(不可抵扣计入时) + 人民币费用 // 注：一般纳税人取得合规增值税专用缴款书，进项税额可抵扣/留抵，不计入成本 // 4. 毛利 不含税收入 = 含税售价 × 数量 ÷ (1 + 增值税率) // 若为不含税售价则不需除 毛利额 = 不含税收入 − 到厂成本 − 其他非汇率成本 毛利率 = 毛利额 ÷ 不含税收入 // 5. 盈亏平衡汇率（换算断点） 令 汇率相关成本 FX0 与汇率成正比，非汇率成本 NF 固定，R0 = 基准不含税收入 λ* = [R0·(1 − 目标毛利率) − NF] ÷ FX0 平衡汇率 = 基准汇率 × λ* // 6. 分批付款 第 i 批人民币 = 外币金额_i × x_i // x_i 为该批结算日汇率或已锁定汇率 合计变化 = Σ(外币金额_i × Δx_i)
