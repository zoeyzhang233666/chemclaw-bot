# 测算汇率波动对进口成本的影响（外贸采购）

## 这个 Skill 解决什么

采购手里有一张进口合同：外币金额、币种、付款时点、到厂费用、可能的国内售价与目标毛利。
需要回答的问题是：**“汇率动一动，我的人民币成本会变成多少？”**

难点从来不在乘法，而在下面六件事：

1. **报价方向先对齐**——`USD/CNY = 6.72` 是“1 美元 = 6.72 人民币”，`CNY/USD = 0.1488` 是反过来。方向搞反，结论全错。
2. **四类汇率不能混用**——市场汇率、银行实际购汇价（现汇卖出价）、海关计征汇率、人民币中间价，四个数不一样，用途也完全不同。
3. **人民币贬值 = 采购成本上升**——外币价格没变，但换成人民币要多付。方向关系必须一次说对。
4. **只给采购金额时只能算付款额变化**——不得据此倒推利润、不得假设售价与毛利。
5. **历史数据必须是真的**——分位数再漂亮，价格序列是编的就毫无价值。
6. **不做预测、不推产品**——测的是“如果汇率在 X，成本是 Y”，不是“汇率会到 X”。

本 Skill 把上述六点做成**可执行、可校验、可交付**的流程。

## 硬性边界（违反即视为失败）

| # | 红线 |
|---|---|
| 1 | **不得预测汇率未来走势**。不写“预计人民币将贬值到 7.0”“大概率上行”。所有情景一律表述为条件式：“若汇率为 X，则成本为 Y”。 |
| 2 | **不得推荐具体外汇避险产品或交易操作**。不出现远期结售汇、期权、掉期、自然对冲比例等任何产品名与买卖建议。 |
| 3 | **必须先确认币种与报价方向**再进行任何计算。币种不明或方向不明时，先问，不要猜。 |
| 4 | **方向关系不得出错**：人民币贬值（汇率数值上升）→ 购汇人民币成本上升；人民币升值 → 成本下降。输出中必须显式写出该判断。 |
| 5 | **只有采购金额时，只算人民币付款额变化**。不得凭空假设售价、成本结构或利润率；毛利与盈亏平衡必须在用户提供售价/成本/目标毛利后才计算，并标注其为模拟值。 |
| 6 | **所有公式与输入参数必须明示**。每个结果都要能追到“哪个数 × 哪个数”。 |
| 7 | **历史汇率必须用真实数据**，不得伪造、不得平滑、不得插值造点。拿不到就写“数据缺口”并给出获取路径。 |
| 8 | 最终目的是**帮采购把敞口算清楚**，**不是代替用户做采购或避险决策**。所有措辞须体现这一点。 |

## 工作流程

### 第 0 步：确认币种与报价方向（不可跳过）

必须拿到并回述三件事：

- **币种**：合同结算币种（USD / EUR / JPY / SAR …）。若为日元等习惯用“100 单位报价”的币种，需说明已折算为每 1 单位。
- **报价方向**：本 Skill 内部统一用 **`FC_CNY` = 1 单位外币折合多少人民币**。若用户给的是 `CNY/FC`（如 `CNY/USD = 0.1488`），自动取倒数并在报告中注明“已由 CNY/FC 换算为 FC/CNY”。
- **金额口径**：合同外币金额、是否含运保费（CFR/CIF/FOB）。

> 回述示例：“合同币种 USD，金额 1,000,000.00 USD，报价方向按 **1 USD = 6.7435 CNY**（FC_CNY）计算。若您的报价是 CNY/USD，请告知，我会取倒数。”

### 第 1 步：取四类汇率并标明时间与来源

四类口径**分别取数、分别标注**，不得用一个数顶替另一个：

| 口径 | 含义 | 典型来源 | 用途 |
|---|---|---|---|
| `market` 市场汇率 | 银行间/公开市场即期参考价 | ECB 参考汇率、Frankfurter、ER-API | 趋势与分位、概览 |
| `pboc` 人民币汇率中间价 | 中国外汇交易中心受权公布 | CFETS / 中国人民银行 | 分位基准、官方参考 |
| `bank` 银行实际购汇价 | **现汇卖出价**（银行卖外汇给你） | 银行牌价（中行/招行等） | **实付人民币** |
| `customs` 海关计征汇率 | 上月第三个星期三中间价 | 海关总署令第 272 号第十三条 | **完税价格折算** |

每条记录必须带：**数值 + 报价方向 + 数据时点（含时区/9:15 这类发布时点）+ 来源**。

若银行实际购汇价拿不到，**不得**用中间价冒充。做法：以中间价 + 明确标注的价差基点（如 +35 bp）生成**演示值**，并在 HTML/Excel 中用黄色“演示”徽标标出，报告中明确写“银行实际购汇价需以成交当日银行牌价替换”。

### 第 2 步：真实历史序列与当前分位

- 拉 1 年 / 3 年（可选 5 年与全样本）日频序列，画趋势图。
- 算统计量：观测数、最低、最高、均值。
- 算**当前汇率的历史分位**：区间内 ≤ 当前值的观测占比。

> **分位算法要点**：计算分位时须排除“当前观测”本身，否则当前值会把自己的分位往上抬。窗口边界建议按“当前日往前 N 年”取，并在报告中说明边界口径；Excel 与引擎因边界包含规则不同可能差 0.01 个百分点，属正常范围，需注明。

### 第 3 步：±1% / ±3% / ±5% 敏感性

对每档变动率 `Δ`，依次算：

```
新汇率        R' = R_base × (1 + Δ)
人民币付款额  P' = 外币金额 × R'
变动额        ΔP = P' − P_base
变动幅度      ΔP / P_base   （线性，应恒等于 Δ）
```

必须显式输出**方向判定**：`Δ > 0` → “人民币贬值 · 成本 ↑”；`Δ < 0` → “人民币升值 · 成本 ↓”。

### 第 4 步：到厂成本影响

按键值阶梯计算（**不要把所有项都乘汇率**）：

```
货值（人民币）   = 外币金额 × R
完税价格         = (CIF 外币合计) ÷ R_base × R_customs
进口关税         = 完税价格 × 关税率
消费税           = 完税价格 × 消费税率
进口增值税(计税)  = (完税价格 + 关税 + 消费税) × 增值税率
增值税入成本      = 可抵扣 ? 0 : 进口增值税
人民币固定费用    = 港杂 + 报关代理 + 内陆运输 + 仓储 + 银行手续费
到厂成本         = 货值 + 运 + 保 + 其他外币费用 + 关税 + 消费税 + 增值税入成本 + 人民币固定费用
```

关键洞察：**人民币固定费用不随汇率变动**，会稀释敏感性。输出“汇率相关成本占比”，让用户看到真正的敞口比例。

> 增值税默认按**可抵扣**处理（不计入成本，仅占资金）。若用户为小规模纳税人或该笔进项不可抵扣，须改为 `cost` 口径重算，两者差异往往很大。

### 第 5 步：毛利与毛利率（仅在有售价与成本时）

```
不含税收入 = 含税售价 ÷ (1 + 增值税率) × 数量   （若售价为含税）
总成本     = 到厂成本 + 非汇率相关成本
毛利额     = 不含税收入 − 总成本
毛利率     = 毛利额 ÷ 不含税收入
```

**售价与非汇率成本若为模拟值，必须在输出中标注“模拟”，并在标题区/徽标中可见。** 不得把模拟售价说成市场价。

### 第 6 步：盈亏平衡汇率（条件满足时）

设汇率相关成本 `FX0`（正比于汇率）、其余固定成本 `NF`、收入 `R0`、目标毛利率 `m`：

```
λ*  = [ R0 × (1 − m) − NF ] / FX0
平衡汇率 = 基准汇率 × λ*
```

其中 `NF = (到厂成本 − FX0) + 非汇率相关成本`。

**适用性判断（必须做）**：若基准毛利率已低于目标毛利率，则“汇率涨到多少会跌破目标”没有商业含义，必须标记 **“不适用”并说明原因**，而不是硬算出一个数。此时可给出 `reference_rate` 作为参考，但要标注“仅供参考、不构成适用结论”。

### 第 7 步：分批付款敞口

对每一批次：`比例 × 外币金额 × 该批汇率`。该批汇率可来自：

- 情景矩阵（按结算时点 × ±变动率）；
- 或“已锁汇率”（手工填入）——填入后该批不再随情景变化，可直观看到部分锁定如何降低整体敏感度。

输出：各批基准金额、结算日、合计，以及情景下的合计变动。

### 第 8 步：输出交付物

1. **交互式 HTML 计算器**（单文件、离线可用）——滑块调汇率、表格逐档、四口径对照、徽标区分真实/模拟/演示。
2. **Excel 工作簿**（7 个页签，**公式可运行**）——修改任一参数，全部结果自动重算。
3. **案例说明**——完整叙述，每个数字可回溯到公式。

## 公式速查

| 名称 | 公式 |
|---|---|
| 币种方向换算 | `FC_CNY = 1 / CNY_FC` |
| 人民币付款额 | `P = A_fc × R` |
| 敏感性 | `P(Δ) = A_fc × R × (1+Δ)`；`ΔP = P(Δ) − P_bas​e` |
| 完税价格 | `DV = CIF_fc ÷ R_base × R_customs` |
| 关税 | `Duty = DV × 关税率` |
| 进口增值税 | `VAT = (DV + Duty + 消费税) × 增值税率` |
| 到厂成本 | `LC = 货值 + 运 + 保 + 其他 + Duty + 消费税 + VAT入成本 + 人民币费用` |
| 汇率相关占比 | `share = (LC − 人民币固定费用) ÷ LC` |
| 不含税收入 | `Rev = 含税价 ÷ (1+增值税率) × 数量` |
| 毛利率 | `GM% = (Rev − LC − OC) ÷ Rev` |
| 盈亏平衡 | `λ* = [Rev(1−m) − NF] ÷ FX0`，`R* = R_base × λ*` |
| 分批合计 | `Σ 比例ᵢ × A_fc × Rᵢ` |

## 计征汇率的日期规则（易错）

海关总署令第 **272 号**《中华人民共和国海关进出口货物征税管理办法》**第十三条**：

> 海关每月使用的计征汇率为上一个月第三个星期三中国人民银行授权中国外汇交易中心公布的人民币汇率中间价；第三个星期三非银行间外汇市场交易日的，顺延采用下一个交易日公布的人民币汇率中间价。

即：**申报月份 M 的计征汇率 = M−1 月第三个星期三的中间价**。第三个星期三是法定节假日时顺延到下一个交易日。

实现：`customs_rate_date(reference_date)` 返回适用的中间价日期，报告中须同时给出“申报日 → 适用中间价日期 → 数值”。

## 常见错误（本 Skill 已内置拦截）

| 错误 | 后果 | 拦截方式 |
|---|---|---|
| 报价方向搞反 | 成本变动方向全错 | `quote_direction_guard()` 强制声明方向 |
| 用中间价当银行购汇价 | 实付人民币被低估约 0.3%–0.5% | 四口径分离，缺 `bank` 时降级并告警 |
| 完税价格用当日汇率 | 税款算错 | 计征汇率独立取值，缺失时回退并打标记 |
| 增值税默认计入成本 | 到厂成本虚高 13% 量级 | 默认 `deductible`，需显式切换 |
| 只有金额却算毛利率 | 编造利润 | 缺 `sales` 时跳过毛利模块 |
| 分位含当前观测 | 分位偏高 | 计算时排除当前点 |
| 基准毛利已低于目标仍给平衡汇率 | 结论无意义 | `applicable: False` + 原因 |
| 人民币固定费用也乘汇率 | 敏感性被放大 | 固定费用单列，不参与汇率折算 |

## 输出措辞要求

- 说“**若**汇率为 X，成本**将为** Y”——不说“汇率**会**到 X”。
- 说“**敞口**为 Z 元，占成本 W%”——不说“建议锁定 Z 元”。
- 说“**银行实际购汇价**需以成交日牌价为准”——不说“按中间价付款即可”。
- 毛利率、售价凡为模拟值，一律在**标题、表头、徽标**三处标注。
