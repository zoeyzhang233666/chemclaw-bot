## 明确保留的限制

- 公司 MCP 尚缺用户在连接器中提供的新 Key，真实鉴权与公司工具返回结果未验收。
- 真实 Windows 上，DSH 0.2.1-rc.2 的关联应用列表枚举返回 COM E_FAIL（HTTP 500）。默认系统打开、定位和预览通过；没有修改上游或更改用户文件关联。测试明确记录此异常。
- 六类任务的工具链与文件格式验证不能证明具体模型的研究、客户筛选或策略结论质量。上线前仍需用配置好的模型，对有参考依据的任务进行业务评审。
- 第三方数据可变化或不可达；免费行情不保证实时。原始数据缺失时保留缺口。
- 当前地理样例为原创示意网格，不是行政地图；真实地图需提供许可明确的 GeoJSON 和可核验坐标。
- Windows 构建未使用商业代码签名。macOS 保持源码兼容，未在 macOS 设备验收。

打包产物、最终命令结果和安装检查会补充在本记录中。不要把未执行的验收视为通过。
