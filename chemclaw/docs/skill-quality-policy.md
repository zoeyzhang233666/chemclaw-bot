# ChemClaw Skill 质量策略

## 优先级

| 层 | 来源 | 用法 |
|----|------|------|
| L1 | `skills/domain`（junction 到已跑通场景包） | 业务流程、字段、溯源、MCP |
| L2 | `skills/community`（grill / superpowers / PPT 等） | 成稿、质询、计划；不改写事实 |
| L3 | 当前强模型 | 在 L1 契约内超越 Flash 示例版式 |

## 硬规则

1. **跟流程，不跟像素** — `examples/` 仅参考；禁止复现坏地图、字体遮挡。
2. **弱模型产物 ≠ 上限** — domain skill 多用 DeepSeek Flash 跑通；强模型应做得更好。
3. **冲突** — 业务事实信 L1+数据；版式信 L3。
4. **禁止编造** — 价格/企业必须可追溯或标 `gap:`。
