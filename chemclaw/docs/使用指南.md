# ChemClaw 小白使用指南

## 选哪一种

- 想直接使用：安装 Windows EXE。
- 已使用官方 DSH：安装 ChemClaw 的 `.tgz` 插件。
- 想改功能并马上看效果：安装 Node.js 24 LTS，在项目根目录双击「启动 ChemClaw.cmd」。

源码启动后会自动打开桌面窗口，无需复制网页链接；终端中的 `token=<hidden>` 是登录凭据脱敏。使用期间保留终端窗口，更新启动脚本后先关闭旧终端再重新双击。

源码启动器会自动构建并同步插件。首次需要下载依赖，终端出现错误时保留错误信息，不需要反复打包 EXE。用「开发 ChemClaw.cmd」启动后，修改会触发构建与重启。开发数据与正式应用隔离。

## 第一次打开

1. 在设置中配置模型。ChemClaw 沿用 DSH 的模型能力，也允许给专家单独选模型。
2. 侧栏已列出全部专业 Bot 和业务协作群。点击即可开始对话；在「Bot」和「群聊」页可按分类查看用途、输入、成员分工及示例，无需启用。
3. 输入产品、区域、时间、规格和目的。例如：「帮我研究华东甲醇近一个月行情，用于采购谈价，标出缺失数据和来源，交付 HTML 与 Excel。」
4. 有原始材料时直接附上。示例中的价格、客户名单和地图只供参考，不能当真实研究数据。
5. 要文件时说清格式：**有价格趋势或要交互图表 → 优先 HTML**；**只做汇报页、不要交互趋势 → 可用 PPT**；**有明细/底稿 → 必须同时要 Excel**。

## 公司数据 Key 怎么填

打开 ChemClaw 设置 → 连接器 → 芯化和云数据中台 → 连接。

点击「领取 API Key」前往 <https://mcp.chem-cloud.cn/>，把获得的 Key 粘贴到输入框。不要添加 `Bearer`，不要输入变量名，也不要发到聊天里。应用自动添加认证头。等待状态显示已连接；若失败，可重试或换 Key。断开会删除该服务的本地 Key。

已有旧 `CHEM_DATA_HUB` 会迁移到连接器的安全用途范围。高级 `mcpServers` JSON 入口支持 HTTPS HTTP MCP；认证转入本地密钥库。不允许给已保存服务换地址并沿用旧 Key；换服务请用新名字。

化工社公开查询、PubChem、OPSIN、维基百科无需公司 Key。发布安装包和插件包内置历史行情所需的 Python、AKShare 及其必要依赖，首次启动只需本地解包，无需用户安装 Python 或联网下载环境。没有内置归档的源码开发安装会自动下载行情组件。额外的分子分析、高级统计和科学绘图库不默认安装；化工社和 PubChem 公开查询本身也不依赖这套科学库。环境只放在 ChemClaw 自己的目录，不修改系统 Python。获取最新行情仍需联网访问数据源。

## 文件怎么打开

Bot 完成后应给出带说明的文件卡和 Markdown 链接。点击文件卡即可预览；HTML 在聊天旁显示，可缩放或切换侧栏。文件卡右侧按钮可定位文件，菜单可使用系统应用打开。

官方 DSH 的交互 HTML 开关由用户控制；连接器页有开启入口。独立应用默认启用公开的交互预览设置。Web 环境没有本机能力时使用预览或下载。移动、删除文件后，旧卡片仍保留记录，但会明确提示文件不存在。

本机 DSH 0.2.1-rc.2 的 Windows「关联应用列表」枚举出现过 COM 错误；这与 HTML 预览不同。默认系统打开和定位单独验证。若菜单无法列出应用，先定位文件，再在资源管理器中打开。插件不修改 DSH 来绕过该错误。

普通报告生成无需安装 Python。已有文档转换或 Excel 公式重算需系统 LibreOffice；没有转换器时不得声称已完成重算。PDF 简单生成器以文字和表格为主，含复杂图表时可打印同名 HTML。

## 数据放哪里

独立应用默认聊天和密钥在 `~/.chemclaw`，工作文件在 `~/ChemClaw`，两者互不包含。普通首次启动无需选文件夹；高级设置可修改，并在同一界面显示冲突与建议。取消返回原设置。

源码开发默认使用项目下 `.chemclaw-dev` 和 `.chemclaw-workspace`。原 DSH 的 `~/.dsh` 不被写入。不要把测试指向自己的正式应用数据。

## 常见问题

- 连接失败：区分认证失败、网络不可达和超时，核对服务状态后重试。不能只看 Key 已保存。
- 看不到地图：让 Bot 检查 GeoJSON、坐标精度和离线资源；没有可靠坐标时使用区域分布表，不补虚构坐标。
- 免费行情不更新：它是历史或延迟数据，查看交易日、来源和抓取时间，可重试或导入自己的 CSV/XLSX。
- 改源码无变化：使用根目录启动器，它会同步 `app/node_modules/chemclaw-bot` 副本；单独 `npm start` 不会同步。
- 启动器退出：安装 Node.js 24 LTS 后重新启动终端；依赖下载需要网络。不要把密钥写进启动脚本。

ChemClaw 只辅助研究和分析，不执行生产控制或自动交易。强模型可以改进技能示例的分析和版式；仍须保留数据口径、来源和证据链。


本轮新增模型入口：侧栏「模型」或设置「模型」→ APIHub。领取链接 https://apihub.chem-cloud.cn/，无需切换经典 DSH 界面。模型 Key 与公司 MCP Key 是两种不同用途的凭据。高级 MCP 和密钥录入表单均随当前主题配色。EXE 会在界面确认后再打包。
