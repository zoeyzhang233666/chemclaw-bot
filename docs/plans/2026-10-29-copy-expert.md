# 复制专家（NewChat 入口）

- 日期：2026-10-29
- 相关：（实现时补 Issue / PR）

## 为什么

侧栏右键「复制一份」和设置页「复制为新 Bot」都能复制专家，但左上角「+」打开的新建面板里没有对等入口。用户希望在熟悉的「发给：」选人界面里挑一个专家直接复制，视觉与「新建群聊 → 设为管理员」一致，结果与右键复制相同。

## 已定的行为

1. 侧栏左上角「+」打开现有 `NewChat`（`mode: 'new'`）。初始选项顺序为：
   - 新建 Bot
   - **复制专家**（新增）
   - 新建群聊
   - 添加 DSH Agent（仅当团队尚无 DSH Agent 时出现）
   - 其后为 Bot 列表
2. 「复制专家」使用与右键菜单相同的 `DuplicateIcon`。
3. 点击「复制专家」后进入 `copy` 选人态（可直接以 `openNewChat('copy')` 进入，例如命令面板）。
4. 选人列表展示**全部** Bot（含 ChemClaw / 主 Bot），支持按名称与角色搜索；悬停或键盘选中时，右侧提示为「复制专家」，不是「设为管理员」。
5. 点击某一 Bot：调用既有 `actions.duplicateBot(id)`，再 `openSession(copy.id)`，关闭面板。效果与右键「复制一份」相同（同一 host API、同一命名与能力复制规则）。
6. 底部消息输入区**保留显示**（布局与新建群聊一致）；复制流程不读取、不发送其中内容；copy 态下输入框 Enter 不触发复制。
7. 复制进行中防重复点击；失败时在面板内展示错误，不关闭面板。
8. 键盘：↑↓ 移动、Enter 确认，与现有选人列表一致。

## 实现要点

- 主要改动：`chemclaw-bot/src/client/new-chat.js`（`copy` 态与选项）、`chemclaw-bot/src/client/i18n.js`（英文源文案 + 中文）。
- 可选：`palette.js` 增加「复制专家」命令 → `openNewChat('copy')`。
- 改完 `src/client` 后 `npm run build`，并提交生成的 `client.js`。
- **不**改 host / `duplicate-bot` / `roster.duplicateBot`。

## 不做什么

- 不新建独立弹窗组件。
- 不隐藏底部输入框。
- 不改右键「复制一份」或设置页「复制为新 Bot」的现有行为。
- 不在复制前要求改名或二次确认。
- 不从列表中排除主 Bot。

## 已知限制

- copy 态仍显示底部输入框，可能让人误以为可以边复制边发消息；按产品选择保留布局一致性，复制本身不使用该框。
- 复制结果（名称规则、能力是否继承、不复制记忆/浏览器授权等）完全依赖既有 `duplicateBot`；本功能只增加入口。
