# 对话产物的 PPT 预览验收

Issue #48，属于 #25。用户报告生成的 PPT 点击后右侧栏 Office 转换失败。基础样例和 ChemClaw 自身生成、包含表格与图表的合成演示，均已通过 libreoffice-kit 与 DSH 公开 OfficeToPdf 接口得到有效 PDF。这不能替代对话链接到右侧预览的完整验收，也不能代表尚未取得的原始报错文件。

新增独立的隔离应用验收路径：生成实际 PPTX，从对话中的 present 卡打开，检查右侧真实 PDF 页面和可见错误，保留截图。不得仅以 iframe 存在认定预览成功。区分文件定位、会话授权、转换、传输与前端呈现的首个失败环节，再修复 ChemClaw 负责的部分。

仅使用 DSH 公开插件 API 与配置，不修改 DSH 安装文件。若最终属于原始文件兼容问题，需取得脱敏复现并明确记录；不通过猜测参数、伪造预览或覆盖用户原文件声称解决。平台发布仍等待整批门禁。
