# ChemClaw product composition

ChemClaw is a separately named DSH plugin and Electron application. Both load
`chemclaw-bot`; neither patches DSH or writes the user's existing DSH home.

The versioned catalog contains 50 role templates and 15 task-oriented group
templates. As requested on 2026-10-23, bootstrap provisions all 50 Bots and 15
groups automatically. Existing teams receive the missing presets once. Creation
is serialized and idempotent, records template provenance, and never replaces
user instructions, model selections, custom names or uploaded avatars. Recorded
deleted presets stay deleted. The Bot directory is one list of actual Bots,
without an enable step or a separate built-in expert tab. Sidebar categories are
expanded and show every preset; group entries come first. Template-only Bots
inherit the configured default model and do not send automatic greetings.
Skills are packaged resources, resolved relative to the installed plugin, with
business evidence requirements independent of presentation examples.

The 2026-10-26 group revision includes the same ChemClaw coordinator in all 15
preset groups, while their specialist admins continue to lead ordinary messages.
Users and members can call the coordinator by its current name for cross-domain
work, conflicting conclusions or an explicitly requested review. Coordination
stays in the group and is on demand; there is no passive listener or automatic
review of every deliverable. Explicit all-member calls and everyone mode retain
their existing behavior.

Catalog version 4 appends the coordinator once to every existing preset group,
including groups with customized membership or admins, preserving their other
members and settings. Full 12-member groups are skipped with a diagnostic for
manual action. Deleted presets stay deleted and user-created groups are not
changed. The attempt is recorded per group; removing the coordinator afterwards
or freeing space in a skipped group does not trigger another automatic addition.
Only unmodified generated notices are refreshed. Runtime group instructions name
the actual admin and coordinator, including when either has been renamed.

Connectors own authentication and shared MCP mounts. Company credentials remain
in the existing local secret store, outside model inputs and shell scopes.
Chemical Data Hub uses HTTPS; Huagongshe's public tools work anonymously. Legacy
per-agent capabilities must not mount a connector a second time.

Deliverables use DSH's documented present tool, Markdown navigation and document
preview; interactive HTML retains DSH's sandbox. The standalone profile enables
the documented presentation preference without changing an official Desktop
profile. Source development uses separate data and synchronizes the installed
plugin copy before starting. Release updates require a ChemClaw-specific feed.

Default UI: Simplified Chinese with English available, paper theme, original
lobster role artwork and blue-cloud application icon. Existing user theme,
sessions, role customizations and files survive upgrades.

The crew uses original lobster silhouettes with role insignia and distinct
shape/color pairs for all 65 presets. Empty conversations show a concise purpose
and task example; group notices carry the owner, member roles and deliverables.
Bot details and the host workspace sidebar share the right side by switching,
including automatic file-preview opens. On narrow windows details overlay the
conversation instead of reserving space that would collapse its text column.

The 2026-10-22 UI revision integrates the expert catalog into Bots and group
templates into Group chats. There is no separate scenarios page or permanent
composer setup card. All new controls use the shared theme tokens. Models and
credentials are available directly in ChemClaw, with the user-verified APIHub
endpoint https://apihub.chem-cloud.cn/v1 and portal https://apihub.chem-cloud.cn/
featured first. No model key is sent to MCP services.

Keyless search uses the separately licensed dsh-free-search 0.9.12 plugin through
the public DSH web seam. Native model-based search is not the default. Huagongshe
anonymous capabilities live in Public research data; optional authentication is
folded separately. A new Windows EXE requires explicit user confirmation after
reviewing the source GUI; existing build files do not represent the revision.

Validation uses isolated mock-model homes, plugin unit/lint/generated-client
checks, desktop tests, packaged and official DSH profile smoke tests. Live data
checks distinguish transport availability from correctness of an analysis.

The 2026-10-24 response revision preserves the standard skill, research, file and
presentation tools for both direct and group specialist Sessions. Removing the
skill tool makes DSH correctly replace its catalog with an empty catalog; hiding
tools is therefore not a response-time optimization. Connected company MCP mounts
restore asynchronously at startup, independently of opening the Connectors page.
Research instructions use the connected company sources for covered current facts
and public/search sources where appropriate, without requiring the user to name a
transport. This is source selection guidance, not a claim every answer used a tool.

Only role-assigned skill summaries enter the routine catalog. A clear business
task may load one matching skill through the public scoped skill registry during
pre-step, once per Agent turn. Its actual instructions are recorded as sourced
context; referenced resources and other skills remain available on demand. No
synthetic skill tool execution or claim of data retrieval is inserted. Capability
metadata in routine roster responses omits full skill bodies; the editor requests
one item through the read-only capability-detail endpoint. Human-facing capability
labels use the business description while stable technical IDs remain unchanged.

The client relies on DSH's catalog preview cache and selected-conversation follow
instead of refreshing projections for all 65 presets on first roster arrival.
Group draft text remains visible until the corresponding reply is committed.
APIHub is prioritized by provider identity or display name in the shared model
picker, preserving saved routes and the order of other providers. Public research
data reports the actual bundled dsh-free-search plugin's runtime state separately
from network reachability.

New uncustomized presets inherit the profile model without eagerly persisting 50
redundant selections. Capability restoration consults the public live Agent
registry for presets; a cold Agent mounts its assigned capabilities on creation.
Existing explicit selections and already-applied routes retain their sync policy.

The independent app composes out workspace-changes by default through its public
profile patch, respecting an explicit existing profile override. Git snapshots
are a developer changed-files feature and can block every group relay tool and
turn closure for the documented 30-second command timeout when the research
workspace is inside a large checkout. Research files still use normal file tools
and present. Installing the plugin in official DSH does not change this host
setting. The GUI latency bench compares this configuration with an enabled-Git
baseline, using the same public profile APIs and separate Host process as the app.
