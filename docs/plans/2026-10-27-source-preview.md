# 本地源码预览的入口与版本

Issue #34。用户在旧 main 工作区运行 CMD，看不到其他工作树中已开发的布局，且两边版本号相同，无法核对。

开发启动器可从本机忽略文件 `.chemclaw-dev/source.json` 的 `source` 字段选择工作区，`--source` 显式覆盖；不是有效 ChemClaw 源码时明确失败，不偷偷退回旧版本。转发后不再次读取来源配置，避免循环。开发数据、Shell 状态与工作区继续使用原入口的目录，源码不会迁移或覆盖用户数据。`--info` 仅打印来源、分支、提交与数据目录，不构建、不启动、不读取数据内容。

启动时打印实际来源和提交，关于页面展示开发分支与提交及本地改动标记；正式安装包不显示开发信息。测试只使用临时项目和独立 mock 数据。

完整插件测试 1131 项通过、1 项 Windows 平台跳过，桌面单元测试 114 项通过，构建检查与 lint 通过。真实 Electron 隔离验收确认布局、两种宽度、思考开关与关于页面的来源标记；原入口 `--info` 已确认选择开发工作区并保留原开发数据路径，`--sync-only` 成功，未启动或测试用户数据。
