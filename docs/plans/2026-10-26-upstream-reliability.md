# 上游可靠性更新适配

用户在核实差异后要求继续执行分批同步。本工作基于最新 ChemClaw main
`da4f95ec`，保留此前体验修复提交 `bb556709`，上游参考固定为 `de55888a`。
代码与回归测试按对应 PR 逐组适配，来源记录于根目录和插件 NOTICE。
不修改 DSH、不降级 rc.3、不覆盖角色、技能、MCP、APIHub 或应用更新配置。

## 群聊接力暂停与继续

替换按成员/轮次丢弃调用的旧上限。用户消息直接选中的成员仍可回答；
Bot 之间的调用单独计数，默认上限为成员数的三倍，用户可设为 1～200。
达到上限时，将待执行成员和调用来源持久保存到群状态，并说明哪些成员在等待。
用户点击继续或发新消息时重置计数并恢复，不重复安排已在等待的同一成员。
修改上限仅允许用户；Bot 管理员与主 Bot 都不能自行提高上限。

继续操作通过 DSH 正常 followup 和群队列执行。群公告、协调员、资料引用、
技能请求和指定执行成员仍沿用 ChemClaw 现有路径；不创建另一个调度运行时。
成员静默超时会留下通知，已经在后台工作的成员继续按原有机制交回结果。
旧 lateRounds 字段迁移移除，既有群成员、文件夹、模型和权限设置保持原值。

回归验证覆盖用户中途插话、忙成员、迟到结果、连续接力、暂停和继续、
用户改上限、只读状态、群成员变更，以及原有 ChemClaw 技能选择与群组升级。

## 请求去重

message_bot 新增可选 request_id，按调用 Bot 与私聊/群会话范围保存内容指纹和收据。
请求在派发前必须成功持久保存；相同内容重试返回首个结果，内容不同则报冲突。
并发调用共享在途收据；重启或派发异常导致结果不确定时，不重新发送。
收据不按时间或数量自动淘汰，防止旧请求再次触发副作用。
沿用未读消息合并、群内调用和现有权限；不提供 request_id 的旧调用继续兼容。
明确在发送前拒绝的超长请求不占用 ID，释放收据失败时保留“不确定”状态。

## 完整交接结果与遗漏回复恢复

超过状态文件保留长度的下级结果先写入独立结果文件，再由工作状态引用。
重启后按引用读取完整文本；写入失败、文件丢失或长度不符时明确标明不完整。
结果文件的清理等待状态保存成功，且再次检查磁盘上的状态引用，防止关闭或
锁丢失时 save 没有写入而提前删掉唯一副本。文件名由安全 ID 或哈希生成。

插件重载期间未接到的回合结束事件通过公开 Session inspect 读取持久日志核实。
已经收到的回复不重复投递；成功结果、模型失败、用户停止和无法读取记录分别处理。
确实被中断的工作沿用原有一次恢复策略，不能确认结果的工作不自动重复执行。
群内技能调用的 skillNames 继续持久保留，未用上游通用实现覆盖这部分定制。

## 记忆事务与失败反馈

一条修改先持久写入 pending.json，再按顺序修改正文、主题索引和 journal。
失败保留事务记录，下次启动或读取前先幂等完成；日志以事务 ID 避免重复。
被中断的半行日志另外保留，再补写完整记录，不把损坏数据悄悄当成成功。
事务记录限制大小并校验路径，正文与记录读取失败均阻止覆盖。
这部分包含 #430 的记忆读取保护作为 #492 的前置依赖，不改动其 secrets 模块。

记忆提示词在事务未完成时只使用已提交的冻结快照；没有安全快照时说明暂不可用。
另外补齐一个只读窗口边界：有待完成事务时既不恢复写入，也不从半写文件读取；
等待拥有写权限的进程完成恢复。独立回归验证只读期间文件和事务均保持原样。

remember/forget 的拒绝与保存异常改为结构化工具错误，保留已有权限和敏感内容
校验；聊天显示简短中文原因及记忆管理入口，成功、重复保存和失败有不同提示。
错误提示不重复显示可能含个人信息的记忆原文。
