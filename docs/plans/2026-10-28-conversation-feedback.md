# 对话中的插话与角色变化反馈

日期：2026-10-28；Issue #54；上游 #598/#587/#584，固定 main 4a7b55069a。

尚未被读取的中途插话显示本地化未读标识；普通排队消息不重置当前工作时间。
用户将排队消息插入 next-step 时记录送达时间，当前活动行从新输入重新计时，
不依赖瞬时的客户端 pending 状态。回合结束清除该时间。

角色或指令实际变化后，在 Bot 私聊送达最新配置。相同补丁、仅改颜色等不额外通知；
私聊自己修改自己的工具结果已足够，不制造第二次回复；群内自改仍通知私聊。
等待首次模型选择的 Bot 不提前启动，新 kickoff 自带最新设定。指令与群内技能、
模型路由、记忆仍沿用现有机制，不新建 Agent 运行时或强制任务预算。
