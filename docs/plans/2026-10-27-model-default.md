# 首次对话自动采用可用模型

Issue #30，属于 #25。继承 #29/#27/#24，整批就绪前不合并。

用户连接 APIHub 后可以直接和预设 Bot 或群聊交谈，无需再挑模型。默认值仅从已提供凭据的模型中选择：保留可用的 DSH 默认，其余优先目录中的 APIHub。已有可用的显式 Bot 选择保留；失效或缺密钥的历史选择临时使用可用路线，不覆盖选择，凭据恢复后可继续使用原模型。

通过 DSH rc.3 公开 `agent/request` waterfall 在模型准备之前返回调用配置，覆盖冷启动的预设 Bot、已有群成员 Session 的旧 request header 和新群成员。保持温度等调用控制；只有当前模型支持的思考档位才传递。不创建 50 个闲置 Session，不修改 DSH 安装，不读取密钥正文。没有可用模型时在调用前给出设置入口提示。

测试使用合成凭据，模拟缺密钥的官网默认、APIHub 刚保存、单聊/群聊首次请求、保留用户有效选择、撤销与恢复凭据，以及非 Bot Session。
