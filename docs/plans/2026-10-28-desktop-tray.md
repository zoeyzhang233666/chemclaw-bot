# 桌面后台运行与托盘

日期：2026-10-28；Issue #55；上游 #549，固定 main 4a7b55069a。

关闭窗口先解释一次后台行为，用户确认后隐藏窗口，Host、研究和日程继续运行。
托盘打开恢复窗口，退出停止 Host 后关闭进程。重复启动、macOS Dock 和菜单提供
一致入口；托盘不可用时不能让窗口消失，提供明确退出选择和菜单退出入口。
系统结束会话、更新安装、首次设置取消与数据复制中断均沿用正确的真实退出路径。

窗口被销毁后可重建并连接同一个 Host。登录启动 URL 只消费一次，后续使用原会话
的 cookie，不输出其值。原生 Bot 浏览器视图等待并重新附着，下载处理只绑定一次。
更新提示在隐藏/最小化时延后，用户恢复窗口才显示；安装前停止 Host，保留
ChemClaw 独立更新源、Linux AppImage/deb 与 macOS 手动下载差异。

托盘使用 ChemClaw 原创云朵图标，未复制上游产品图片。单元测试覆盖关闭提示、
托盘降级、更新等待、菜单、单实例与 Host 握手；真实 Electron 验证隐藏/重开/
重建和退出。测试只用唯一隔离目录。真实用户数据和当前开发预览选择均不修改。
