# 浏览器人工交接卡

日期：2026-10-28；Issue #51；上游 #591，固定 main 4a7b55069a。

私聊中 browser_handoff 或 browser_task 内的交接保留外层调用标识，展示原因、站点及
跳过、接管、我完成了三个操作。接管保留卡片；跳过或完成只通知一次，失败恢复卡片。
面板交还只表示控制权已返回，不能冒称用户已完成登录或核对。旧卡、错误调用、未知结果
明确拒绝；重启后的非持久交接不补造成功记录。历史保存理由及结果。

群聊与子 Agent 沿用面板交接，工具结果要求在当前聊天说明所需人工操作。嵌套任务
在交接处立即停止，不继续执行同一响应的其它浏览器动作，并将人工指引交回外层 Bot。
不引入任意脚本模式；保留每 Bot 串行、跨 Bot 隔离、取消、写入审批与截图附件修复。
用户主动接管只能由用户交还；Bot 发起的暂停可在用户回复后通过 browser_resume 继续。

界面沿用问答卡、主题和本地化，提供键盘焦点。行为通过宿主、卡片交互及取消回归验证，
最终整批运行 mock 和真实 Electron 检查。DSH 保持 rc.3；未完成验收前不合 main 或发版。
