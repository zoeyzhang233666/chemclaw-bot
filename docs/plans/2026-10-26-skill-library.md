# 中文技能库与完整技能安装

按用户确认的方案实现；后续界面评审将「能力」入口改名为「技能库」，
取消工具服务页签。工具服务配置只在已有「连接器」页维护，避免重复入口。

## 浏览与中文内容

技能库沿用 Bot 与群聊目录的主题、搜索和两列卡片，窄窗口使用一列。
技能显示业务名称、中文用途、交付物和来源；技术标识与完整文件树在详情中。
108 个化工技能的中文展示元数据单独维护，不改写原始技能正文。
同场景不同工作流有不同名称：客户情报周报、品种周报、产业链结构图、
产业链价格地图、库存季节性与其完整资源版本。

分类显示条目数量，只显示有技能的业务分组；「我的安装」按来源筛选。
导入时可选择分组，每个检测到的技能也能独立改组。已知原始技能名可继承
内置目录的中文用途和分类，外部未知技能保留原文并允许编辑中文别名。
点击详情、使用或安装后，直接将设置滚动容器回到顶部。

## 安装与存储

支持 ZIP、SKILL.md、文件夹，以及公开 GitHub 仓库、子目录和 SKILL.md 链接。
先在 ChemClaw 自有 home 的 skills/staging 中识别并预览；安装将整个技能
目录复制到 skills/installed/<uuid>，索引提交成功后才切换版本。
同名默认跳过，替换或另存必须由用户明确选择。失败恢复原索引，原目录不变。
ZIP 不执行代码，拒绝穿越路径、大小写冲突、链接、特殊文件及加密文件；
上传上限 100 MB，展开上限 500 MB，最多 50,000 个文件，说明正文最多 1 MB。
导入令牌 30 分钟过期，取消与插件释放清理暂存文件。GitHub 使用 HTTPS
官方 API 和 codeload，不接收凭据，不自动更新，不自动安装脚本依赖。

技能摘要不带完整正文或存储路径。详情按需读取文件树，提示 Python 与依赖
声明文件；正文与相对资源位置由同一个目录加载器提供。
原有内联文字技能、稳定 ID、Bot 绑定、能力包展开和权限规则保持兼容。
默认元数据升级保留用户修改与中文别名；恢复内置说明不重置别名。

## 调用

人类目录与 Bot 自动目录分离。人类可以从完整技能库和中文斜杠菜单单次
调用允许手动调用的技能；Bot 的自动技能目录仍仅含岗位分配的摘要。
岗位 provider 使用 DSH 的公开 skills.registerProvider，提供 path、
resourceBase 与按需加载正文。另一个 scoped provider 发布仅供用户调用的
完整目录，不扩大 Bot 的模型目录。产品复用上游原生菜单组件，只投影中文
展示元数据；中文搜索 source 只补充原生搜索未命中的条目，避免重复候选。

产品通过公开 inputTriggers source 注册中文候选、资源预览和引用序列化，
输入同一个稳定 /ID 或点击技能卡片均进入 DSH 的原生显式加载边界，
群成员接收中继任务时使用同一目录加载器与 renderSkillContent。
原始作者的 user-invocable 与 disable-model-invocation 策略保留在索引中。
显式调用优先于自动匹配，同一轮不重复加载。普通 Agent 会话不注册产品候选。
安装和卸载直接更新产品目录，不依赖原生技能菜单缓存的失效方式。

按用户后续评审，取消独立的使用表单和二次选择。卡片「使用」直接返回当前
正常对话框，插入中文技能引用并聚焦，保留已有草稿与附件；用户在正常
输入框填写需求后发送。斜杠菜单同样直接插入引用，不跳转设置。
群聊默认负责人，用户可在正常输入框 @ 一位成员改派；选择随用户消息进入 room 队列，并随
成员交付的 source.skillNames 保存。全员回复模式也不重复执行单次技能。
排队、重试和重启恢复保留 skillNames，不根据后来出现的群消息重新猜测。
聊天区展示中文引用和真实加载事件；失效引用明确报错。

## 工具服务与来源

连接器中的新增向导接收服务地址、服务商 JSON 或本机命令。解析后显示摘要，
用户确认后才保存并测试。认证值存入现有本地凭据库，普通索引仅保留引用；
本机服务通过 DSH MCP 插件启动，不增加另一套运行时。

网页演示技能的 MIT 许可和完整资源从已固定 revision 的子模块整理为普通
文件目录，npm 包不再依赖子模块是否初始化。旧 ppt-master 来源许可未确认，
不激活，也不纳入发布包；可编辑 PowerPoint 使用 ChemClaw 原创工作流与
已有 chem_deliver 工具。NOTICE 和来源清单保留许可信息。
