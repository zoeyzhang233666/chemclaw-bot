# 侧栏专家、专家群与分类筛选

按 2026-10-28 用户明确提出的界面调整，更新 2026-10-27 侧栏设计的视觉与入口约定：

- 主控下方显示「专家 / 专家群 / 最近」。专家与专家群按分类展示；最近跨分类按活动时间展示。保留现有专家、群头像和纸张等主题变量。
- 删除设置中的排序控件、侧栏的「更多」及最近活动/手动/关注优先模式菜单。保留原排序按钮外观，改称「筛选」，使用单选分类；顺序直接拖拽分类标题和行手柄调整，分类视图不再随新消息自动重排。
- 专家与专家群各有自己的筛选分类。快捷标签优先使用稳定分类 id「内贸销售」「产业研究」，然后遵循拖拽分类顺序；跳过当前列表已展示的第一个分类，分类改名后标签跟随更新。使用 ResizeObserver 与实际按钮宽度，只显示一行内可容纳的完整按钮；窄侧栏保留第一个可用标签，宽侧栏自动增加，其余从筛选选择。最近提供全部/专家/专家群快捷选择，筛选下拉分开显示专家分类与专家群分类。
- 使用内置群现有 templateInfo.category，15 个群分成内贸销售（2）、内贸采购（2）、进出口（3）、产业研究（3）、期现量化（2）、生产辅助（2）、方法与复核（1）。自建未归类群放到其他专家群。
- 分类默认展开。每次选择筛选、点击快捷标签或切换视图，都先展开本次结果，忽略之前收起的记录；之后仍可手动收起。手动操作继续写入 prefs.sidebar.collapsed，筛选的初始展开状态只留在当前视图。空的自建分类也显示，可直接选来归类新专家或群聊。
- 筛选下拉支持新建分类与修改分类名称。新建专家/群聊时可选择或新建分类；已有专家/群聊在设置的侧栏卡中可重新归类。
- 新建分类保存后立即选中、展开并显示空分类提示；从最近页新建时切到对应的专家或专家群视图，避免新分类被原筛选条件或最近的平铺布局隐藏。保存必须核对 set-prefs 返回的分类信息；旧后端忽略字段时显示失败与重启提示，不再报告成功。
- 专家中的 PDF、纪要、方法与复核（含方法与复合旧名）合并到通用交付。内置两位复核专家的新模板使用通用交付，旧模板、角色和同名自定义分类通过稳定归类规则兼容。专家群的业务方案评审分类不受影响。
- 分类 registry（稳定 id、kind、name）和 item→category 归属通过现有 set-prefs API 保存到 prefs.sidebar.categories / categoryAssignments。改名不变 id，保留拖拽顺序、折叠状态及归属。分类管理不改已有专家的指令、群成员或会话内容。
- 分类标题改为 13px 半粗与更深主题文字色；拖拽手柄改为常显的原创六点 SVG、扩大操作范围。保留全部现有专家及群头像、纸张主题及其他主题变量。
- 左上角改为设置、技能库入口。左下角龙虾菜单使用「专家」「群聊」，保留设置及自动化入口，移除菜单中的用量与连接器。设置导航中 Bots 显示为专家。
- 侧栏滚动条默认透明，悬停侧栏或键盘聚焦时显示细主题滚动条；触屏保留可见提示，不产生横向滚动。
- 设置中的专家/群聊目录使用同一分类 registry、显示名称、拖拽顺序与 item 归属，自建空分类也同步显示。新建群聊切换到专用创建表单并滚动、聚焦，完成后打开新群设置。
- 新建群聊使用不收缩的普通流卡片，管理员与成员是独立、有搜索和限高滚动的两块选人区；未选管理员时显示成员占位提示。群名、分类和页脚有独立空间，窄窗口自动改为单列。不得通过压缩各区高度把大量头像溢出到下一区。
- 侧栏筛选、单个专家/群聊设置的分类选择器、专家/群聊设置目录的「分类管理」共用创建、改名、删除入口。删除先选择同类型接收分类，一次 set-prefs 保存成员归属、合并后的顺序及 deletedCategories 记录；只移除分类，不删除专家、群聊、成员或历史。空分类可直接删除，已删除的内置分类不会因模板再次出现。通用交付、其他专家群是保留的兜底分类，禁用删除并显示说明。
- 专家和群聊均可拖到同类型其他分类的行前或标题（含空分类）中。一个 set-prefs 请求原子写入新归属及源/目标两边顺序，并展开目标；主控、专家与专家群之间不允许互相归类。

本次不改变 Bot 会话及群聊运行架构；多 Chat 侧栏按独立已确认设计继续实现。旧排序偏好保持可读取，但界面只使用拖拽顺序；最近视图独立按时间排序。
