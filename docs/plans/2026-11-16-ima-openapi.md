# 腾讯 ima 知识库内置数据源

- 日期：2026-11-16
- 相关：feat/ima-openapi-connector

## 为什么

用户已经在 ima 持续维护经过筛选的微信公众号研究资料。ChemClaw 不应要求用户重新下载 PDF、OCR 和重建一个检索库。数据源应能直接读取、检索和管理授权用户自己的 ima 知识库。

## 已定的行为

1. **官方接口**：只使用 `https://ima.qq.com/openapi/{wiki|note}/v1/...`；不模拟 WorkBuddy 扫码授权，不借用微信 Cookie，不把 ima Web 页面的内部接口当作官方能力。
2. **连接**：设置 → Connectors → 腾讯 ima 知识库。用户输入其 ima 官方页面提供的 Client ID、API Key；保存进 ChemClaw 现有的 secrets.json，默认不向 Bot shell 公开。连接后通过只读 API 验证凭证；可重试、换密钥和断开。
3. **浏览/检索**：列出可写知识库、搜索知识库与条目、分页浏览文件夹、检查同名文件、获取媒体信息；查询笔记及笔记本、读取笔记内容。
4. **写入**：导入微信公众号或普通网页链接、上传工作目录里的本地文件、添加已存在的知识内容；导入 Markdown 笔记、追加或编辑笔记。已列入支持范围的文件夹创建、知识条目重命名/移动及标签功能，通过官方 API 尝试，若服务端不支持就返回真实错误。
5. **文件上传**：文件名检查 → ima create_media 获取临时 COS 凭证 → 仅向腾讯云 COS 上传本地文件 → ima add_knowledge 登记。限制为支持的类型、50MB 以内、Bot 工作目录内的真实文件，禁止 symlink 越界；默认拒绝重复文件名。凭证和临时 COS 签名绝不返回模型。
6. **工具**：`ima_openapi` 使用明确的端点枚举和 JSON 对象参数，不接受任意 URL 或未经确认的删除操作；`ima_upload_file` 负责本地文件上传，要求用户明确提出上传。
7. **隐私**：ima 私人资料不要主动转发到群聊、公开服务或公司数据中台。用户需要明确提出跨数据源分析时才读取与组合。
8. **兼容性**：该功能属于 chemclaw-bot DSH 插件，无需修改 DSH 源码；第一次安装与已存在团队都能在连接器页配置。


## 芯化智数订阅知识库（新增）

- 在 Connectors → 腾讯 ima 显示公司运营的「芯化智数 · 化工产业知识库」推荐入口，仅用用户提供的官方分享 URL 引导至 ima 订阅。分享链接里的 `shareId` 不是 OpenAPI 的 `knowledge_base_id`，不得混用。
- 用户在 ima 网站按其官方登录流程登录（可能需要微信扫码），并在 ima 官方智能体授权页面创建个人 Client ID 与 API Key。此流程不等同于 WorkBuddy 内置扫码 OAuth，也不能通过扫描二维码自动将凭证传给 ChemClaw。
- 连接后，先用 `search_knowledge_base` 查询**可读取**的知识库，而不是 `get_addable_knowledge_base_list`（后者偏向可写权限）。查询可分页。
- 用户在列表中选择默认研究知识库时，后端使用 `get_knowledge_base` 获取名称，并用 `get_knowledge_list` 验证其实际读取权限，成功后才在本机状态中保存 ID 和名称；单纯点击分享链接不意味着连接成功。
- Bot 的 `wiki.search_knowledge` / `wiki.get_knowledge_list` 在未显式指定库 ID 时自动使用已验证的默认库。用户可以取消默认库；更换账号或断开ima连接会清除原默认库。
- 管理员权限与普通订阅用户权限独立。写入仅在具体调用通过官方权限校验时执行，不共用公司管理员的 Client ID 和 API Key。
- 普通订阅者能否通过官方 OpenAPI 实际访问此库，须使用非管理员账号完成端到端测试；在此之前不宣称已实现公开订阅后的无障碍检索。


## 不做什么

- 不承诺第三方微信扫码 OAuth。公开可用的是 Client ID + API Key。
- 不开放删除知识库、删除笔记、批量破坏性操作：现阶段没有确认的官方 OpenAPI。
- 不定期全量同步研报内容，不绕开 ima 自有检索而再次建立一个重复索引。
- 不把文件上传的临时 COS 凭证展示给模型。
- 不在未经授权的情况下修改用户已有笔记。

## 已知限制

- 用户尚未提供测试凭证，真实线上 ima 服务与 COS 上传需用户在测试包中验证；CI 使用模拟响应。
- `get_media_info` 可能只返回媒体 URL、受保护的请求头或笔记 ID，不保证能直接获得 PDF/微信文章全文。
- 部分扩展的知识管理及新版笔记方法可能因账号、版本或接口权限而不可用，以官方响应为准。
- 仅从当前 Bot 工作目录上传文件。上传更大文件、多段上传或任意路径文件选择不在本次范围内。
- 公开 OpenAPI 错误、HTTP 429、权限不足会向用户明确报告，不尝试绕过。
