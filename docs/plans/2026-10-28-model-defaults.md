# 模型默认值与工具命名

日期：2026-10-28；Issue #57；上游 #586/#575，固定 main 4a7b55069a。

新建 Bot 未触碰思考级别时继承 profile 的默认选择，前提是实际所选模型支持该值。
明确选择模型默认（null/空串）不继承 profile 的显式级别；复制 Bot 保留原选择语义。
APIHub 首次可用路由选择、用户保存的模型、50 模板惰性初始化继续沿用 ChemClaw。

Bot 模型枚举工具统一命名 list_bot_models，提示词、注册列表、权限限制、测试一致。
list_models 名字留给其它插件；不保留冲突别名。模型选择仍通过 DSH 公开服务。
