# 密钥文件读取失败保护

适配 DS-Bot #430 的 secrets 部分，参考固定 main de55888a；记忆部分已在前一批完成。
读取失败不等于空文件，加载器记录阻断原因并重试读取，所有保存路径和使用时间
后台保存都受阻断。文件恢复可读后再允许保存，不把原文或 JSON 解析片段放进日志。

无效 JSON 或不符合存储格式的文件，只有持有写权限的进程才能先保留原始副本，
成功后才允许重建；备份失败则阻断保存。只读进程既不建备份也不写新文件。
排队写入在真正落盘前再次检查写权限，避免加载后失去权限仍继续写。

不迁移或删除任何用户密钥；测试只使用隔离临时目录中的随机假值。

接管写权限时，先等待仍在途的共享读取及随之启动的可写重读完成，再修改密钥表。
这避免旧读取完成时清掉新保存记录，或遗漏前一个写入窗口的最后一次修改。
用人工延迟读取的回归稳定复现过旧错误，并验证接管后保留旧、新和本次添加的记录。
