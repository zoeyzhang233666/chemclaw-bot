# ChemClaw v0.3.2

本次发布重点改善 macOS 安装与启动台图标体验，并修复 macOS 安装包构建时的卡顿问题。Windows 和 Linux 继续使用相同的 ChemClaw 功能版本，统一版本号为 0.3.2。

## macOS 改进

- **DMG 安装引导**：新增暖色纸张风格的安装窗口背景、中英双语提示和橙色拖拽箭头；Finder 中的 ChemClaw 和 Applications 图标仍为系统原生可拖拽对象（[#121](https://github.com/zoeyzhang233666/chemclaw-bot/pull/121)）。
- **启动台图标比例**：保留用户确认的原始 Scheme A 高质感 PNG、米白底板和橙色云朵，将绘制区域调整为 820×820 并置于透明的 1024×1024 画布，以更接近其他 macOS 应用的视觉大小（[#120](https://github.com/zoeyzhang233666/chemclaw-bot/pull/120)、[#122](https://github.com/zoeyzhang233666/chemclaw-bot/pull/122)）。
- **稳定的图标打包**：使用 macOS CoreGraphics/Swift 原生处理图标，不再为 PNG 缩放额外启动 Electron，修复 macOS CI 在“Downloading Electron binary...”处卡住、超时取消的问题（[#123](https://github.com/zoeyzhang233666/chemclaw-bot/pull/123)）。

以上文件名为本次发布计划输出项；应以 GitHub Release 页面实际完成的全部构建产物为准。Mac 两个架构保留 ZIP 备用包。现有 0.3.1 发布资产不覆盖。

## 安装及安全提示

打开 DMG 后，将 ChemClaw 拖至 Applications，再从“应用程序”中启动。更新前请完全退出旧版本。原有用户聊天记录和配置不应因重装而被主动清空，建议重要数据做好备份。

**macOS 开发者验证**：当前构建仍采用临时（ad-hoc）签名，尚未使用付费 Apple Developer Program 的 Developer ID 证书完成正式签名和 Apple 公证。因此首次下载打开仍可能触发 Gatekeeper 安全提示。请勿将图标/DMG 的修复理解为已解决 Apple 公证问题。仅在确认来源可信时，按照 macOS 的「系统设置 → 隐私与安全性」提示操作；不建议关闭全局系统安全功能。
