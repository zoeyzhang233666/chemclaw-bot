# ChemClaw v0.4.0

## 即时通讯

- 在 **设置 → 即时通讯** 连接微信、QQ、飞书、企业微信、钉钉、Telegram、Discord 或 Slack，使用常用聊天应用与 ChemClaw 对话。[PR #162](https://github.com/zoeyzhang233666/chemclaw-bot/pull/162)
- 支持的图表可作为图片发送，生成的 SVG、HTML 等可作为文件附件接收。格式和大小取决于平台，钉钉会将其接口无法直接发送的格式打包为 ZIP。
- 平台重投的消息只处理一次，同一轮里重复生成的正文和附件会去重。

## 桌面体验

- 经典模式的新会话保持独立，专家或群聊的后台回复不会接管当前会话。正文和原生卡片可同时显示，普通工具详情仍可展开。[PR #159](https://github.com/zoeyzhang233666/chemclaw-bot/pull/159) · [PR #161](https://github.com/zoeyzhang233666/chemclaw-bot/pull/161)
- 支持的桌面环境增加按专家授权的电脑使用控制，提供停止和用户接管。功能默认关闭。[PR #157](https://github.com/zoeyzhang233666/chemclaw-bot/pull/157)
- macOS 源码启动器可从 GitHub 同步主分支或选中的 PR，并使用独立预览配置。[PR #162](https://github.com/zoeyzhang233666/chemclaw-bot/pull/162)

## 下载

- Windows x64：`ChemClaw-0.4.0-win-x64.exe`
- macOS Apple 芯片：`ChemClaw-0.4.0-mac-arm64.dmg`
- macOS Intel：`ChemClaw-0.4.0-mac-x64.dmg`
- Linux x64：`ChemClaw-0.4.0-linux-x86_64.AppImage` 或 `ChemClaw-0.4.0-linux-amd64.deb`
- DSH 插件：`chemclaw-bot-0.4.0.tgz`

macOS 两个架构均提供 ZIP 备用包。Mac 构建继续使用临时签名，首次安装时请按系统提示核对应用来源。

## 验证范围

本版通过跨平台构建和安装包自动化检查，并在模拟网关验证了 IM 去重和附件传输。微信和 QQ 的真实手机账号验收待补。
