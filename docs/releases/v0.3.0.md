# ChemClaw 0.3.0

本次版本整合截至 2026-11-02 已合并到 `main` 的化工研究、技能库、图表、Office 原生交付及桌面安装包修复，包括 PR #108 的 macOS UI 自动化验收和 PR #109 的 Office 侧栏预览修复。

## 主要更新

- **技能库与中文示例**：内置技能按业务场景分类，展示完整的中文能力说明与可直接提问的化工任务示例；区分内置技能和用户自行安装的技能，并展示 DSH 原生技能。
- **Office 原生交付与右侧栏预览修复**：整合 DSH Office 工具与离线运行时，支持生成和处理 Word、PPT、Excel。修复 Windows 安装包中 `libreoffice-kit` 缺依赖、Electron ASAR 虚拟路径无法启动转换引擎导致 PPT 右侧栏「读取失败」的问题；用户无需单独安装 WPS、Office、LibreOffice 或 Node 即可使用内置 Office 预览。
- **行情和数据图表**：增强 K 线、时间轴、行情事件标注和多图展示；现货与期货查询强化口径区分，避免用期货价格冒充现货报价。
- **研究与网页交付**：补充巨潮公告研究数据源；减少群聊网页生成的重复审核循环，保留已完成的读数卡和对话内图表，网页由模型自主组织设计。
- **桌面体验**：优化欢迎页、经典模式入口、插件入口、群聊停止交互和技能管理；精简安装包里重复生成的示例文件，保留技能代码与核心资料。
- **macOS UI 自动化验证**：在 Apple Silicon 和 Intel Mac GitHub Actions 中实际启动打包应用，检查中文技能库、欢迎页、版本信息、图表、对话及文件交付，并保留截图附件供排查。

## 下载与升级

- Windows x64：`ChemClaw-0.3.0-win-x64.exe`。
- macOS Apple 芯片：`ChemClaw-0.3.0-mac-arm64.zip`；Intel：`ChemClaw-0.3.0-mac-x64.zip`。
- Linux x64：`ChemClaw-0.3.0-linux-x86_64.AppImage` 或 `ChemClaw-0.3.0-linux-amd64.deb`。
- DSH 插件：`chemclaw-bot-0.3.0.tgz`，或使用 `github:zoeyzhang233666/chemclaw-bot#v0.3.0&path:/chemclaw-bot` 安装。

安装升级前建议备份重要工作区与数据。Windows 可使用应用内更新检查；macOS 会提示下载对应新版本。安装包未配置商业代码签名，系统首次运行可能要求手动放行。

## 发版验收门禁

- 发版前确认 `app/package.json`、`chemclaw-bot/package.json` 及对应锁文件均为 `0.3.0`。
- 运行 Release 工作流的 `dry_run=true`，检查全部系统打包作业和安装包测试。
- Windows 实际安装并验证「设置 → 关于 ChemClaw」显示 0.3.0，确认聊天、技能库、图表与 Office 基础流程。
- 重点验收 **PPTX 在 ChemClaw 右侧栏能直接显示幻灯片**：验证干净 Windows 环境中内置转换器完整、真实 PPTX→PDF 成功，且安装包中的 Office 右侧栏预览自动测试通过；再复核实际生成的 PPT 文件。
- macOS 自动测试不等同于 Apple Developer ID 公证或普通用户首次打开的 Gatekeeper 验收；首次启动可能需要手动放行。
- 本说明为候选发布记录；只有正式发包工作流成功后，才将安装包视为已发布。
