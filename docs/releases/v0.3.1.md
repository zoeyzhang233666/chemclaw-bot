# ChemClaw 0.3.1

本次是 Windows 与 macOS 桌面稳定性更新，包含 #113、#114 及 #116 的累计修复。

## 主要修复

- **聊天记录保护与恢复**：团队索引读取失败或损坏时保留最后可用状态，阻止用空团队覆盖原索引，并允许重新读取。历史消息与团队关联分别处理，避免暂时读取失败导致全部对话不可见。
- **进程与连接恢复**：为 DSH 启动、必需插件就绪和渲染进程恢复增加有界等待与重试；支持明确重启 Host，修复 WebSocket 和浏览器断连后的恢复路径。重复的上下文拒绝有持久化重试预算，避免持续新建对话分段。
- **Office 预览**：随包提供 Node、Python 和 Office 运行资产，补齐 Windows 转换器所需的匹配运行库；不替换系统 DLL，也不要求用户另装 Office、WPS 或 LibreOffice。
- **macOS 安装与浏览器**：检测运行中应用被移动或替换的情况，在浏览器操作前停止团队并提示退出重开；从“应用程序”之外启动时，先退出，再引导用户在 Finder 中拖入“应用程序”。

中断的任务可能已经产生文件或外部操作；重试前请核对已完成部分。

## 下载与升级

- Windows x64：`ChemClaw-0.3.1-win-x64.exe`。
- macOS Apple 芯片：`ChemClaw-0.3.1-mac-arm64.dmg`；Intel：`ChemClaw-0.3.1-mac-x64.dmg`。保留同架构 ZIP 作为备用下载。
- Linux x64：`ChemClaw-0.3.1-linux-x86_64.AppImage` 或 `ChemClaw-0.3.1-linux-amd64.deb`。
- DSH 插件：`chemclaw-bot-0.3.1.tgz`，或使用 `github:zoeyzhang233666/chemclaw-bot#v0.3.1&path:/chemclaw-bot`。

macOS 请完全退出旧版，打开 DMG，将 ChemClaw 拖到窗口中的 Applications 图标，再从“应用程序”打开。当前仍使用临时签名，未配置 Developer ID 或 Apple 公证；首次运行可能需要在“系统设置 → 隐私与安全性”对本应用选择“仍要打开”。临时签名不能保证消除系统提示。DMG 提供 Finder 拖拽安装窗口，ZIP 作为备用下载保留。

v0.3.1 首次发布遗漏了此前验收的 DMG。补包直接使用已发布 ZIP 中的应用，核对源码标签、签名、架构，以及 DMG 与 ZIP 中每个文件内容和符号链接目标；不更换原有资产或移动版本标签。
