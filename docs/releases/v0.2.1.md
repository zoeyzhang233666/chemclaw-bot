# ChemClaw 0.2.1

- 新增中文技能库：按业务分类搜索、查看和安装完整技能包，从卡片或 `/` 菜单直接在当前聊天调用，保留草稿与附件。
- 桌面版默认检查 ChemClaw 更新；「设置 → 关于 ChemClaw」支持手动检查。Windows 下载后可重启安装；macOS 提示下载对应架构的 ZIP。
- 修复交付文件缺少本机打开操作的问题，并限制大型工作区 Git 快照的等待时间。
- 发布流程自动生成并校验插件 TGZ、Windows 安装包与更新文件、两个 macOS ZIP；文件齐全后才公开 Release。

## 下载与升级

- Windows x64：下载 `ChemClaw-0.2.1-win-x64.exe`。
- macOS：Apple 芯片下载 `ChemClaw-0.2.1-mac-arm64.zip`，Intel 下载 `ChemClaw-0.2.1-mac-x64.zip`；解压后放入「应用程序」。
- 官方 DSH 插件：安装 `chemclaw-bot-0.2.1.tgz`，或使用 `github:zoeyzhang233666/chemclaw-bot#v0.2.1&path:/chemclaw-bot`。

此前关闭更新检查的旧版桌面应用，需要先手动安装一次 0.2.1；后续版本可通过应用检查更新。升级保留团队数据。安装包没有开发者证书签名，首次运行可能需要系统放行。
