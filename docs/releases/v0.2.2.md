# ChemClaw 0.2.2

- 群聊接力可暂停继续；Bot 请求去重与记忆失败会明确提示；中断后的交接结果与记忆事务更可靠地恢复。
- 对话支持图表、本地计算和沙箱 HTML 视图，历史可完整回放蓝图。
- 群聊产物链接可正确打开工作区里的 HTML / Excel。
- 已安装用户启动时回填中文技能元数据；`/` 技能菜单缩短过长标题，并补充更多原生技能中文文案，避免菜单行叠字。

## 下载与升级

- Windows x64：下载 `ChemClaw-0.2.2-win-x64.exe`。
- macOS：Apple 芯片下载 `ChemClaw-0.2.2-mac-arm64.zip`，Intel 下载 `ChemClaw-0.2.2-mac-x64.zip`；解压后放入「应用程序」。
- 官方 DSH 插件：安装 `chemclaw-bot-0.2.2.tgz`，或使用 `github:zoeyzhang233666/chemclaw-bot#v0.2.2&path:/chemclaw-bot`。

升级保留团队数据。安装包没有开发者证书签名，首次运行可能需要系统放行。
