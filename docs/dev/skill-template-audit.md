| 其他技能自检 | 修复客户市场价核验、库存季节性、基差的恒真断言或陈旧期望。基差复权算法未改变。 |

## 实际调用来源与 v3 修复

用户后续提供的执行命令确认，生成器来自 `~/.agents/skills/chem-market-brief/scripts/build_all.py`。
只修改工作树或 DSH 链接的插件目录没有覆盖这份独立技能副本；重启 DSH 也不会更新它。
因此源码测试通过不能代表用户调用的脚本已经更新，必须分别验证资源路径与内容哈希。

v3 同步修复独立技能、链接源码及开发预览包中的资源，并保留修改前备份。
新增测试参数 `--sales-skill` / `--buying-skill` 可直接验收实际调用路径。
HTML 带生成器版本和模板 SHA256；静态检查同时核对版本、模板、可执行图表脚本以及按月聚合的数值，
防止旧模板或只改变颜色的日线图再次被宣称为通过。

无有效数据的区域价差、毛利、产业链、走势、分位、事件等可选章节及对应指标卡隐藏，
口径、来源与未纳入项默认收起。现价查询不再被要求强制制作完整报告。
另补充开发启动器对 `skills/` 的缓存失效范围，避免仅改模板时仍复用旧预览包。

原油专项使用明确标为合成数据的回归样本：6 个交易日分布在 3 个月，
独立核对月均为 101、202、303，验证蜡烛图有效、日线与月均的点数和数值不同、
无区域价差和毛利时模块不可见。反例包括旧版本标记、错误蜡烛渲染代码、错误月均数据和换色冒充月均。
自检先重建例子再验收，避免只检查旧产物。

```powershell
python scripts/test-skill-charts.py --browser chrome --sales-skill <实际行情技能目录> --buying-skill <实际采购行情技能目录>
```

## v4：日线粒度

按用户确认，日K线和日收盘价在所有窗口都保留逐交易日数据。
“全部”范围原来选择 `all_w` 周线，现改为独立的全样本日线 `all`；周线底表仍可供原有工作簿使用。
月度均价继续从实际日收盘价逐月计算，与日线视图分开；日线横轴显示完整日期，月均价显示月份。
回归样本特意包含同一周的多个交易日，检查“全部”范围仍有全部 6 个日点，而不是被合为周点。
生成器标记为 `chem-market-brief:price-charts-v4-daily`。

用户提供的参考文件只用于检查图表表达：日度与月度拥有独立时间轴、单位、图例、来源和缩放。
未复制其实现、研究结论或行情数字。6 点合成样本用于边界断言，不代表正式行情图的数据密度。
