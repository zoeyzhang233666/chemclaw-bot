# 内置技能模板修复记录（2026-10-29）

本次针对用户报告的行情 K 线缺失、无数据毛利模块占位，以及其他内置示例的相同风险进行检查。
修改在 `chore/skill-template-repairs`，从当时最新 `chemclaw/main` 开始；未修改用户 DSH 数据或发布应用。

## 修复

| 位置 | 原因与处理 |
| --- | --- |
| 看产品近期行情 | 日期已经作为横轴，却又把日期传入蜡烛的数值列。改为四列 OHLC；折线也明确只传数值。 |
| 月度均价 | 原按钮复用了所选原始序列。改为从真实日线逐月计算收盘均价，说明首末月可能不完整。 |
| 工艺路线毛利 | 无数据仍保留 300px 画布。现在无有效数值时移除整个子模块并让供需表使用可用宽度；零毛利仍展示，缺项记入缺口清单。 |
| 看原料近期行情 | 区间带的基底用了上沿，带本身又没有参与同组堆叠。改为下沿 + 上下沿差额。无成本数据时隐藏成本模块；无价差图时消除预留空白。 |
| 跨品种单位 | 报价输入、话术及页脚中的元/吨写死。改用数据的单位，并检查元/桶。 |
| 看两个品种为什么背离 | 图表读取不存在的 `series.fut`，标准化列名与数据不一致；显著性带从数组错误取值。修复生成脚本及两份报告副本。 |
| 行情渲染检查 | 坐标轴像素被当作行情渲染成功。新增主数据图元检查、四列 OHLC 检查、模式切换与失败反例；缺少浏览器或渲染异常不再算通过。 |
| 其他技能自检 | 修复客户市场价核验、库存季节性、基差的恒真断言或陈旧期望。基差复权算法未改变。 |
| 中文名称 | 中文展示元数据缺失时，按稳定编号回退到已有中文业务名称。保留内部编号、绑定与用户自定义别名。 |

更新了原始模板、销售/采购报告副本及销售数据包，避免模型继续参照损坏的示例。
文件交付技能补充了：无数据可选模块不预留空间、零值区别于缺失、主数据图元验收、无法渲染时明确未验证。

